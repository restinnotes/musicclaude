# Op.61｜关系图（逐段综合 61e）

**Center：**不可复返的旧日生活与面向外界的责任，始终因旧梦珍藏的心愿相连，却不能互相替代。

### 1–23　（没在想）

- 他怀念一段曾令自己动心的往事；那份吸引仍在，却无法再回到当时。

### 24–65　（正在面对）

- 面对已无法挽回的眷恋，他压住情绪，不愿失了体面。
  - ← 提供理由：（1–23）「怀念难返」
- → → 后来，克制愈发费劲；牵念未消，藏着的情绪慢慢外露。
  - ← 限制：（1–23）「怀念难返」

### 66–91　（没在想）

- 不舍让他更难抑住心绪，思绪暂时离开那件事，轻松了一阵。

### 92–115　（正在面对）

- 松快过后，往日情景又鲜活起来，温柔与幸福随之浮现。
- → → 可那段日子回不去了，幸福转成刺痛，思念又缠住他。
  - ← 限制：（1–23）「怀念难返」

### 116–147　（正在面对）

- 那些回忆仍然动人，他不愿把它们看轻，却因再也回不去而心痛。
  - ← 提供理由：（92–115）「旧事回暖」

### 148–180　（正在面对）

- 他对那段往事仍抱着盼头；静下来时，这愿望像祈求，指向遥远难料的可能。
  - ← 提供理由：（116–147）「守住分量」
  - ← 限制：（1–23）「怀念难返」

### 181–205　（正在面对）

- 某个熟悉的旧日细节忽然闪现，他才发现那样的生活已离自己很远。
- → → 这份亲近感把无法重来的事实推到眼前，原先平静的期待也跟着动摇。

### 206–213　（正在面对）

- 失去感刚让那份期望动摇，它又短暂浮起，更像朝未知祈愿。
  - ← 限制：（181–205）「盼望受扰」

### 214–215　（正在面对）

- 从前的日常琐事让失去再度变得真切，熟悉的茫然又回来；但他知道自己正失去什么。
  - ← 唤起：（181–205）「旧日逼近」

### 216–225　（正在面对）

- 明白所失后，茫然化作“今后怎么生活”的追问；几番寄望落空，他一时不知该往哪走。
  - ← 改写：（214–215）「茫然有了内容」

### 226–241　（正在面对）

- 未来怎么过仍让他害怕，却已不只是茫然，而是他必须面对的责任。
  - ← 改写：（216–225）「疲惫的生活追问」
- → → 受挫后，那份念想仍会回来；前路未明，他仍愿前行。

### 242–253　（正在面对）

- 受挫后复起的希望，这回转成面向外界的责任感，让他愿以行动继续生活。
  - ← 提供理由：（226–241）「盼望支撑前行」
  - ← 改写：（226–241）「追问转为承担」

### 254–288　（正在面对）

- 他一度觉得，向外付出终于呼应旧梦珍藏的心愿。
  - ← 提供理由：（242–253）「把盼望化为承担」
- → → 可旧日生活终究无法重来：他仍得继续尽责，却补不回那段日子。
  - ← 限制：（1–23）「怀念难返」
  - ← 提供理由：（226–241）「追问转为承担」
