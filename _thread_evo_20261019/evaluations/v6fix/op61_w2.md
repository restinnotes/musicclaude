# Op.61｜关系图（A2 整首修补 w2）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他心里有股不肯停的劲，却连自己在等什么都说不清，整个人也还没安顿下来。
- → 熟悉感先牵住了他，他还没想清它意味着什么，心里已隐约有了往前的牵引。可认出它也不能让过去回来。
- 他怕一直停着，最后会把眼前这样当成理所当然。
- 真把心力投进去，他又怕会丢下别的珍惜之物。
- → 他想找个能说服自己的理由，可每次快信了，不舍又回来，让他为非得想透才肯动而难堪。

### S02｜24–65 小节　（正在面对）

- 他想到再等下去，珍惜的东西还会继续受损，于是先接下眼前能承担的一份。
  - ← 改写：（1–23）「非得想透」
  - ← 提供理由：（1–23）「理所当然」
- → 接下这一步后，他确实有了些力气，也短暂为自己撑住而骄傲。
- → 他不甘心被失落压垮，把力气投进去时也尝到一阵痛快，便想再多承担一些。
  - ← 限制：（1–23）「珍惜之物」
- 他仍牵挂那种曾经相信的生活，却不能像从前那样拥有它。
- → 他把软弱压到一边，努力维持挺立。牵挂一回来，他又得说服自己没事、重新聚力。

### S03｜66–91 小节　（没在想）

- 他把自己撑得很紧，失落和不甘仍推着他，却没让他定下该往哪走。
- → 那种曾让他觉得亲近、无需防备的生活浮上来，他暂时沉进去，终于能从难题里喘口气。
  - ← 唤起：（24–65）「不能像从前」
- → 可眼前仍不是那种生活，刚得到的轻松便留不住，原先的决定又被他想起。
- ⟲ 仍在起作用：（24–65）「重新聚力」；（24–65）「继续受损」

### S04｜92–115 小节　（正在面对）

- 短暂松开后，他仍记得那个决定曾让自己从僵住里动起来，所以还愿意坚持。
  - ← 唤起：（66–91）「原先的决定」
  - ← 提供理由：（24–65）「继续受损」
- 那种熟悉的温暖他舍不得抹掉。正因记得它有多好，他才难接受它不能原样回来。
- → 他怕一停下就得承认那种亲近回不来，便反复追问当时还能怎样，始终问不出安心。
  - ← 限制：（24–65）「不能像从前」
- ⟲ 仍在起作用：（24–65）「不能像从前」

### S05｜116–147 小节　（正在面对）

- 那个决定曾把他从犹疑里带出来。一想到失望，他就怕自己辜负当初的认真。
  - ← 提供理由：（92–115）「从僵住里动起来」
- 他心里仍牵挂那种亲近生活，想到它时会柔软下来，却不敢停下。
- → 他想停一停，却把受苦当成自己还不够坚定，硬压下疲惫继续撑。
  - ← 说明：（92–115）「反复追问」
- → 他把不能软弱当成要求，最后发现自己像在逼一个疲惫的人硬撑。
- → 他停下催逼后仍没安心。压住的想念才浮出来，他承认自己舍不得那种不必防备的生活。
- ⟲ 仍在起作用：（92–115）「舍不得抹掉」

### S06｜148–180 小节　（没在想）

- 他想要的是曾真心相信过的生活，不只是眼前一时的轻松。
  - ← 说明：（116–147）「不必防备的生活」
- 他盼着人与人亲近时不必防备，珍惜的东西也不必靠争夺留住。
- 他也盼着不必反复证明自己值得被爱，靠近时不用先准备受伤。
- → 相信这样的生活曾让他快乐，正因那份快乐真切，他舍不得把愿望说成软弱。
- → 他暂时不拿责任审问这份爱惜，也不急着问它有没有用、值不值得排在前面。
- → 他终于肯把愿望想得更深，心里也柔软下来。想要的变得迫切，到最后仍有说不尽的地方。
- → 那份满足让他几乎忘了先前的疲惫，一时舍不得离开。

### S07｜181–205 小节　（正在面对）

- 刚尝到的亲近生活忽然显出仍未实现的事实，他身体先一紧，才从安宁里回到眼前。
  - ← 提供理由：（148–180）「忘了先前的疲惫」
- → 他想起当初不肯再等，是因为不愿继续看着珍惜的东西受损。只留在怀念里，眼前的事不会停。
  - ← 唤起：（24–65）「继续受损」
- → 他试着重新投入，却怕争取会磨掉刚尝到的温柔。必要和代价反复在他心里打转，让他停不下来。
  - ← 改写：（1–23）「珍惜之物」
  - ← 限制：（116–147）「疲惫的人硬撑」

### S08｜206–213 小节　（没在想）

- 两难又让那种曾给他满足的安宁短暂靠近，他舍不得立刻把心收紧。
  - ← 唤起：（148–180）「忘了先前的疲惫」
- → 他记得那份满足曾真实地让自己放松，这次没有马上拿它来责问自己。
  - ← 提供理由：（148–180）「忘了先前的疲惫」
- → 他让自己再停一会儿。眼前的事仍没改变，所以这口喘息从一开始就短暂。
  - ← 限制：（181–205）「身体先一紧」
- ⟲ 仍在起作用：（181–205）「必要和代价」

### S09｜214–215 小节　（正在面对）

  - ← 唤起：（206–213）「这口喘息」
- → 他认出自己舍不得的是那种不必防备、可以安心亲近的生活，可这仍没让他知道下一步怎么走。
  - ← 改写：（148–180）「不必靠争夺」

### S10｜216–225 小节　（正在面对）

- 他知道自己舍不得那种生活，却还是提不起力气。一想到争取会把自己逼得疲惫，他就迈不动。
  - ← 限制：（214–215）「舍不得的生活」
- → 行动曾让他从僵住里动起来，安宁也曾让他暂时松口气。可眼前的威胁仍在，两样都护不住那种生活。
  - ← 说明：（92–115）「从僵住里动起来」
  - ← 说明：（148–180）「忘了先前的疲惫」
  - ← 限制：（181–205）「身体先一紧」
- 他若还要争取，就得记得当初不肯继续等的缘由。
- 他想留住安宁，也得记着妨碍那种生活的事仍在。
- → 他反复惦记那点微弱的愿望，仍想不出兼顾的办法。可他记得行动和安宁都曾帮过自己，选边的逼迫才松了一点。

### S11｜226–241 小节　（正在面对）

  - ← 限制：（181–205）「身体先一紧」

  - ← 改写：（116–147）「疲惫的人硬撑」
  - ← 限制：（181–205）「必要和代价」
- → 想到争取会磨损温柔，他仍心疼，也盼着有条容易些的路。可继续等，妨碍它实现的事还在。
  - ← 提供理由：（181–205）「身体先一紧」
- → 他仍怕付出代价，也不知道会失去什么，却把眼前该承担的事接过来做。
