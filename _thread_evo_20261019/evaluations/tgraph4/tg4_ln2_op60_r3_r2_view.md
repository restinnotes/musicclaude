# Op.60｜关系图

**Center：**亲密的幸福与留不住它的痛楚难以分开

### 1–3　（还说不清）

- 起初，他不知道自己在盼望什么。
- 独处原本安稳，如今他却觉得少了什么。
- 他想靠近对方。
- 他不敢确信自己的心意会被接住。
- 他没有把握，却也不退缩。
- 想到也许能在对方面前不那么小心，他已有些欢喜。

### 4–16　（正在面对）

- 他慢慢把心放开一些。
  - ← 提供理由：（1–3）「想靠近」
  - ← 唤起：（1–3）「有些欢喜」
- 对方真的接住了他。
- 他原以为想被理解，就得先把自己弄明白。
- 他原以为想被喜欢，就得藏起不讨喜的部分。
- 他发现自己不必时时做得好，也能被亲近。
  - ← 改写：（1–3）「不敢确信」
- 原先独自承受的柔软和迟疑，如今在对方面前也不难堪。
- 他觉得先前冒险敞开是值得的。
- 他愿意再多敞开一点。
- 每次不必收住心意，他都更放松。
- 他渐渐享受到自然做自己的舒畅。
  - ← 改写：（1–3）「少了什么」

### 17–23　（正在面对）

- 他开始关心对方快不快乐。
  - ← 提供理由：（4–16）「不必时时」
- 他仍想知道自己在对方心里有多重要。
- 他想让对方在自己面前同样自在。
  - ← 唤起：（4–16）「做自己」
- 使对方幸福，也让他感到满足。
- 他急切地想把得到的好给予对方。
  - ← 唤起：（4–16）「接住」
- 付出让他感到丰足，并没有委屈。
- 他终于不必总守着自己的那点需要。

### 24–34　（没在想）

- 他不再时时察看彼此是否同样热切。
  - ← 提供理由：（17–23）「同样自在」
- 他不再细算自己爱了多少、得到多少。
  - ← 提供理由：（17–23）「感到丰足」
- 有时他连追求幸福这件事都忘了。
  - ← 唤起：（17–23）「感到满足」
- 他尽情喜欢对方。
- 他坦然接受对方的喜欢。
- 他不再从每份亲近里寻找更深的证明。
- 他原以为珍贵的东西得格外用心才能得到。
- 如今他在亲密中忘记了用力。
- 他让心意自然流向对方。
  - ← 改写：（4–16）「多敞开」
- 他很喜欢这样的自己。
- 他很喜欢彼此不必费力的信任。
- ⟲ 仍在起作用：（4–16）「做自己」

### 35–39　（还说不清）

- 眼下他没有失去什么，也不怀疑对方。
- 他忽然有一点舍不得。
  - ← 唤起：（24–34）「都忘了」
- 他希望这样的幸福一直延续。　✦ 满足照出未满足
  - ← 唤起：（24–34）「不必费力」
- 这个念头让他短暂地发紧。
- 眼前的幸福随即安抚了他。
  - ← 提供理由：（24–34）「坦然接受」
- 他暂时没把不安当成真正的问题。
- 他只觉得自己太喜欢这一切，才提前舍不得。

### 40–50　（正在面对）

- 他不愿让这点舍不得搅扰快乐。
  - ← 提供理由：（35–39）「真正的问题」
- 他开始更用心地珍惜。
  - ← 唤起：（35–39）「一直延续」
  - ← 改写：（24–34）「忘记了用力」
- 他觉得幸福不该被漫不经心地度过。
- 他想爱得更充分。
- 他想把每一点好都感受得更深。
- 他希望以后想起时，这些感受仍能给他力量。
  - ← 唤起：（35–39）「短暂地发紧」
- 他想到将来未必总能如此满足。
- 他觉得此刻得到的幸福确实存在过。
- 他认为自己这样爱得更郑重。
- 他还没意识到自己想靠认真留下些什么。
- ⟲ 仍在起作用：（24–34）「格外用心」；（35–39）「一直延续」

### 51–61　（正在面对）

- 他开始检查此刻是否还像刚才那样好。
  - ← 提供理由：（40–50）「感受得更深」
- 他检查自己的心是否依然饱满。
- 他检查对方的亲近是否足以让他确信一切。
- 即使没有变化，他也忍不住比较。
- 即使仍感到被爱，他也想知道能否一直如此。
  - ← 唤起：（40–50）「给他力量」
- 那些细微的好成了他反复辨认的凭据。
- 用心珍惜带来的细心，如今让他难以安宁。　✦ 办法的限度
  - ← 失效：（40–50）「更用心」
- 他其实不觉得对方不爱自己。
- 他明明拥有亲密，却无法毫无顾虑地享受。
  - ← 动摇：（24–34）「忘记了用力」
- 他一心想确认没失去，却仿佛已失去了什么。
- 这种委屈让他有些羞愧。
- 他不明白得到的好都是真的，自己为何还不满足。
  - ← 提供理由：（40–50）「确实存在过」
- ⟲ 仍在起作用：（35–39）「一直延续」

### 62–71　（正在面对）

- 他开始厌烦自己不断追索保证。
  - ← 唤起：（51–61）「有些羞愧」
- 他发现自己把对方的心意当成必须交出的东西。　✦ 办法的限度
  - ← 限制：（24–34）「不必费力」
- 他试着收住不断比较的念头。
  - ← 失效：（51–61）「反复辨认」
- 他不再要求每一刻都胜过上一刻。
- 起初，这样做并不容易。
- 少了一分盘问，他确实又轻松一些。
  - ← 唤起：（4–16）「做自己」
- 他慢慢记起自己喜欢的是对方这个人。
  - ← 唤起：（17–23）「同样自在」
- 他不再要求每次亲近都带来安心。
  - ← 改写：（51–61）「无法毫无顾虑」
- 他仍做不到完全不担忧。
- 他不再要求对方立刻消除担忧。

### 72–77　（正在面对）

- 不再索取保证后，他仍想长久相爱。　✦ 办法的限度
  - ← 限制：（62–71）「立刻消除」
- 他发现苦恼不能全怪自己过分计较。
  - ← 改写：（62–71）「必须交出」
- 他仍怕这样的幸福以后会改变。
- 他希望以后仍能与对方亲密相伴。
- 真实得到过的快乐让他无法轻易责备自己贪心。
  - ← 提供理由：（17–23）「感到满足」
- 他明白对方愿意爱他，未必能永远如他所愿。　✦ 分清
  - ← 提供理由：（4–16）「接住」
- 他明白自己的珍惜无法保证以后。　✦ 办法的限度
  - ← 失效：（40–50）「更用心」
- 他愿意承认这个分别，心里仍旧疼。
- 他知道不该索取，却依然想要。
- ⟲ 仍在起作用：（35–39）「一直延续」；（62–71）「做不到」

### 78–83　（正在面对）

- 他不再勉强自己装作无所谓。
  - ← 提供理由：（72–77）「依然想要」
- 他不愿为了防备失去先把爱收回。
- 他珍惜对方自由给予的亲近。
  - ← 提供理由：（4–16）「接住」
- 他也想不附带永不改变的要求地爱。
  - ← 改写：（72–77）「未必能永远」
  - ← 改写：（62–71）「立刻消除」
- 即使不能保证以后，他仍愿把心交出去。
  - ← 限制：（72–77）「无法保证」
- 这个选择没有让他更安全。　✦ 选择的代价
- 他重新感到坦然。
- 他不再等待不会受伤的保证才允许自己爱。
- ⟲ 仍在起作用：（72–77）「以后会改变」

### 84–92　（没在想）

- 少了暗中的计较，他又能毫无保留地欢喜。
  - ← 提供理由：（78–83）「交出去」
- 他不再羞愧于自己的热切。
  - ← 改写：（51–61）「有些羞愧」
- 他不再为显得清醒而克制喜爱。
- 他感到自己多么需要对方。
- 他不再觉得想被爱和想让对方幸福会互相争夺。
  - ← 改写：（17–23）「有多重要」
- 他喜欢自己在爱里变得柔软。
  - ← 唤起：（4–16）「不必时时」
- 他喜欢自己能够这样慷慨。
- 经过犹疑，他仍愿相信对方的心意。
  - ← 提供理由：（78–83）「坦然」
- 有一阵子，他幸福得不再追问未解的问题。
- ⟲ 仍在起作用：（17–23）「同样自在」；（17–23）「感到丰足」

### 93–102　（正在面对）

- 幸福如此饱满，他难以只把它当成此刻。　✦ 满足照出未满足
  - ← 唤起：（84–92）「不再追问」
- 他疼于无法靠自己留下这份圆满。
- 他想再靠近对方一些。
- 他恨不得两人的心意完全相融。
- 他想消除可能令他们分离的距离。
- 他知道再亲近也无法变成同一个人。
  - ← 说明：（72–77）「未必能永远」
- 他知道此刻圆满也无法阻止以后的变化。
  - ← 提供理由：（72–77）「无法保证」
- 这些认识反而使他的渴望更炽烈。　✦ 知道更多反而更尖锐
- 他不肯因此减少自己的爱。
- 他更想倾注所有的眷恋。
  - ← 唤起：（84–92）「互相争夺」
- 能这样去爱，他幸福得几乎无法承受。
- 想到这样的幸福仍换不来永远，他又强烈地疼。
- 他分不清急切是因快乐还是因知道留不住。
- 他舍不得到几乎不能安静地幸福。
- ⟲ 仍在起作用：（35–39）「一直延续」；（78–83）「交出去」；（72–77）「仍旧疼」

### 103–110　（正在面对）

- 这样的急切终于让他感到无力。
  - ← 提供理由：（93–102）「不能安静」
- 爱得再深，仍无法替未来作保证。　✦ 办法的限度
  - ← 限制：（78–83）「交出去」
  - ← 限制：（40–50）「感受得更深」
- 他甚至希望自己不曾懂得这么多。　✦ 知道更多反而更尖锐
  - ← 唤起：（93–102）「更炽烈」
- 他想如果仍像最初那样只知靠近，或许少些疼。
  - ← 唤起：（1–3）「不知道」
- 他想过把这份幸福牢牢记住。
  - ← 唤起：（40–50）「给他力量」
- 他知道记得幸福过，无法让他再次拥有它。　✦ 办法的限度
  - ← 失效：（40–50）「给他力量」
- 记忆可以证明他得到过幸福。
  - ← 提供理由：（40–50）「确实存在过」
- 记忆却无法让已得到的幸福永远停留。
- 他仍确信先前的快乐真实。
- 他也没有觉得自己投入得错了。
- 正因如此真实，他难以劝自己放下。
- 他有一瞬间埋怨自己爱得太深。
  - ← 唤起：（93–102）「无法承受」
- 他却无法真心希望那些幸福从未发生。
  - ← 提供理由：（84–92）「不再追问」

### 111–116　（正在面对）

- 他舍不得否认已经拥有过的一切。
  - ← 提供理由：（103–110）「无法真心希望」
- 他分清希望长久相爱源于真心爱对方。　✦ 分清
  - ← 改写：（72–77）「长久相爱」
- 他发现要求永远不变会让自己无法自由地爱。
  - ← 提供理由：（62–71）「必须交出」
- 他不再为盼望长久而羞愧。
- 他不愿再用永不改变的要求束缚彼此。
- 即使分清，他仍因无法确定而心口发紧。
- 他不再急着责备自己的舍不得。
  - ← 改写：（51–61）「为何还不满足」
- 他不再让舍不得否定已得到的快乐。
  - ← 提供理由：（40–50）「确实存在过」
- 他知道自己确实幸福过，才会如此留恋。
  - ← 提供理由：（93–102）「无法承受」
- 他因无法留住，幸福时也会疼。
- 他知道快乐消除不了这份痛楚。
- 他不愿为了免于疼痛而减少快乐。
- 他仍想靠近对方，也仍愿继续爱。
- 他仍有一点不甘心。
- 他不愿收回已经付出的心意。
- 他也舍不得那个因爱过才会如此舍不得的自己。
  - ← 提供理由：（103–110）「无法真心希望」
- 即使没有安心的保证，他也不愿退回最初的自己。
  - ← 改写：（103–110）「或许少些疼」
  - ← 改写：（1–3）「不知道」
- ⟲ 仍在起作用：（72–77）「依然想要」；（103–110）「未来作保证」；（78–83）「交出去」；（93–102）「换不来永远」；（78–83）「先把爱收回」
