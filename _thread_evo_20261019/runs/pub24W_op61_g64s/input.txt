你是一名负责钢琴曲大众版「边听边看」视频的屏幕文字编辑。

你的任务是把已经定稿的珠子和线，编辑成观众一边听音乐、一边扫一眼就能看懂的屏幕稿。观众不应该需要停下来细读，也不应该觉得文字像提纲、翻译腔或者刻意写出来的诗。

本次指定：线的形态是「句子」。每条线都必须是一句完整、自然、平常人会说的话。感受也必须是人话，可以更短，但不能变成生硬的词组或被截断的半句话。

同时保留已经有效的排法：线与感受上下交替，要点先行，关键词放大，感受分成独立的小块。每条线根据自身情绪选择一种颜色类别，它下面的感受跟它同色；同一段里有不同性质的情绪，就应当出现不同颜色。

最终要同时实现四件事：好扫读、知道为什么、感受细腻、每段字数接近现行视频。

### S01
[S01-B1]（另一侧面；小节 1–23）开头那下有分量的和弦，也可以听成一个人强迫自己挺直背脊，提醒自己不能倒下；可自由琶音马上把这份郑重带回内心的游移。尊严还在，行动的方向和力气却不稳——“我不能倒下，可我其实很想停下来。”
[S01-B2]（主体验；小节 1–6；局部）先听开头那一下沉重、郑重的和弦：它像要宣告什么，紧接着的自由上行琶音却没把这份重量接住，反而像烟雾往高处散，声音轻了、远了，悬在半空。也可以把它听成一次召唤，只是停顿里仿佛还等着回声。
[S01-B3]（另一侧面；小节 1–23）短句像叹息，刚冒出来就被长停顿截断；听着余音在冰冷的空气里慢慢散尽。心里明明有东西，却还分不清这份不平静究竟是愤怒、遗憾还是怀念——这是一种尚未找到对象、也尚未找到语言的失落。
[S01-B4]（另一侧面；小节 1–23）换一种从身体感觉出发的听法：像刚从漫长的昏沉中醒来，四周冷而空，胸口有些发紧，视线还模糊着；伸出颤抖的手去摸，摸到的却只有虚空。这里不是已经哭出来的悲伤，而是连自己身在何处都还没弄清的恍惚。
[S01-B5]（段内变化；小节 9–17；18–23；局部）约9–17小节，旋律轮廓稍稍清楚，像一幕旧场景忽然回来：当时的声音、光线和某种熟悉的感觉都回来了；可记忆再清晰，过去也不会因此重新变成现在。到18–23小节，波兰舞曲的步态逐渐浮现，像身体先于意识，隐约记起了该如何迈步。这还只是向前的牵引，主题要到第24小节才真正站稳。

### S02
[S02-B1]（主体验；小节 24–65）波兰舞曲的步态终于清楚了，却不像英雄凯旋；主旋律更像一首从远处传来的旧歌，你依稀记得它，却只能模糊地哼出几句。也可以把它听成两层声音：舞曲带着一点面向众人的庄严，歌声却像私人记忆里的低声哼唱。那些自己珍惜的东西仿佛还在，却已经无法像从前那样拥有它们。
[S02-B2]（另一侧面；小节 24–65）它不是士兵的步伐，更像腿脚虚浮的人，在记忆中挪动舞步。节奏本身庄严、傲慢，旋律却脆弱凄婉；底下的伴奏还有细碎、不安的半音在蠕动。
[S02-B3]（段内变化；小节 38–65；局部）听它怎样起伏：38–43小节，音乐猛地往上推，却又退下来；44–65小节再次聚拢力量，52–63小节一带更焦灼，最后仍没有舒舒服服地落地。56–65小节连绵的三连音，仿佛把呼吸催得越来越急。
[S02-B4]（另一侧面；小节 24–65）这种挺拔的姿态，可以听成一种强烈的自我控制。像一个人整理好衣服、抬起头，不让别人看见动摇；到44–65小节，它又像反复对自己说“我没事”：第一次还有几分相信，第二次开始努力让自己相信，说到第三次，连反复说这句话本身都暴露出：其实还是很在意。悲伤还在，只是不愿把自己完全交给悲伤。
[S02-B5]（另一侧面；小节 44–65）另一种心理动因是，44–65小节的激昂像一句“我不甘心就这样消亡”：不是轻松恢复自信，而是负隅顽抗。这股力量可以与自我控制同时存在。

### S03
[S03-B1]（主体验；小节 66–91；m.66的和弦重击为条件性细节；局部）第66小节的和弦若被突出，会像重锤砸下，带着愤怒与抗拒；这一段忽强忽弱的起伏，加上切分节奏，让人心里一悬。音乐离开前面的端正步态，转入更灵活、流动却不安的舞蹈性格，像想往前走，却无法平静地决定方向。
[S03-B2]（段内变化；小节 66–79→80–91；局部）一种听法把前半段（66–79小节）听成焦躁、急切，后半段（80–91小节）则忽然柔和、亲切，带一点近乎田园的轻盈。有人会想到故乡夏日的麦浪与微风；也有人会联想到曾经轻松、亲近、不必时时防备的时刻。温柔得让人心颤，也刺痛得让人绝望：越怀念，越能感觉它与眼前处境的距离。
[S03-B3]（另一侧面；小节 66–91）也可以沉进旋律里细听：像多个人在耳边低声絮语，彼此缠绕，找不到出口；调性又像流沙，抓不住重心，四处漂移。
[S03-B4]（另一种理解；小节 66–91）也可以听成：这股活动感也可以听成一次短暂的侧身离场：不再正面迎着那个沉重的问题，像是聊点别的，或出去走走，让注意力暂时离开伤口。那一刻的轻松可以是真的，并非假装；只是它没有替心里的事找到答案。
[S03-B5]（另一种理解；小节 66–91）也可以听成：如果换一种感受，这里不像重新获得活力，更像前一段的昂扬正在慢慢退潮。音乐变得流动、含蓄、若有所思，仿佛心里冒出一句自问：我刚才是真的相信那些话，还是只是在努力让自己相信？

### S04
[S04-B1]（主体验；小节 92–107）熟悉的波兰舞曲主题又回来了，流动的伴奏和装饰音让旋律更抒情、更像在独自说话；旧记忆也忽然变得鲜活，甚至带出感激、亲密、柔情和短暂的幸福。可原来的姿态回来，却显得更柔软、更容易受伤：外在的步伐还在向前，里面却有了更多回声。这份坚定也可能是他努力想成为的样子，而不再是一个毫无疑问的事实。
[S04-B2]（段内变化；小节 92–115，转折集中在108–115；局部）92–107小节的温暖没有一路把音乐带向安稳：到108–115小节，音乐忽然显出风暴般的激烈与紧绷，越是用力，反而越不安稳。可以把这一转折听成记忆带来的刺痛：不是记忆变坏了，而是它太好了——过去无法原样回来。同一段里，半音阶下行又带来另一股反向的力，像在撕扯中步步后退，抵抗显得疲惫而仓促。
[S04-B3]（另一侧面；小节 92–115）若把注意力放到身体上，细碎的音符像急促的脚步或乱了拍的心跳；左手低音在追赶，右手狂乱地挣扎，像被时间催着往前跑，连身体都仿佛已经被这节奏逼得无法停下。
[S04-B4]（另一侧面；小节 94–115）另一个可以同时听见的层次，是脑子里停不下来的自问：“如果当时……”“是不是还可以……”“究竟为什么会变成这样……”。表面上动作越来越多，实际上并没有真正抵达哪里；不停地往前赶，只是为了避免停下来。思绪就这样反复盘旋，试图想清楚，却始终无法停歇。

### S05
[S05-B1]（主体验；小节 116起；私语感延续于116–147；局部）第116小节一转，音乐像换了一个人开口，语气柔和了许多：歌唱变得亲近，却仍然克制。两只手仿佛夜色里两个影子，彼此低声说话。
[S05-B2]（另一侧面；小节 116–127；局部）116–127小节里，柔和的歌唱并没有抹掉向前的劲：音乐仍像被压力推着走，情绪比前面更直接、更有宣告性，仿佛在说：“这件事不能就这样算了。”里面可以同时有愤怒、悲伤，也有想维护自己的那股劲。
[S05-B3]（另一种理解；小节 116–147）也可以听成：这段柔和的歌唱，也像是旧日记忆重新有了温度。它可能指向某个人，也可能是故乡或过去的生活；可正因已经过去，眷恋里也带着失落。
[S05-B4]（段内变化；小节 128–147，尤其128–129、139–144附近；局部）从第128小节起，右手的快速音型仍在往前流，随后这股流动渐渐放缓、变稀，最后化成较慢、较疏的和弦。尤其在128–129、139–144小节附近，旋律几乎单独露出来，像脚下原有的地板忽然不见了，只剩一个声音自己说话。
[S05-B5]（段内变化；小节 约132–147，重点在144–147；局部）约第132小节以后，躁动和不安又加深；到144–147小节，才像几次深呼吸，或一声深深的叹息，紧绷短暂松开。声音稀疏下来，心里却未必平静：这一下松动，也像是“不是已经想通了，而是抵抗得累了”。

### S06
[S06-B1]（主体验；小节 148–180整体，尤其148小节起的换境与持续安静感；局部）第148小节起，音乐像毫无征兆地滑进一片与此前世界隔开的静谧。声音绵长、从容，近乎停驻；整个世界像被一层透明玻璃罩隔开，连呼吸都不愿惊动它。它也像母亲在耳畔轻轻哼唱的摇篮曲，温柔得让人暂时松开戒备；可这份安宁并不意味着现实已经变好，也不是一个能永远停留的地方。
[S06-B2]（另一侧面；小节 148–180整体；约160小节的远方显现；局部）这里先有近似圣咏的庄严，旋律却又像藏在心里的秘密念头。它像是一个人终于不用再向别人解释自己为什么难过，也不必维持“我应该坚强”的姿态；那些压住的愿望、委屈和思念，终于有机会浮现。歌唱又像向某个遥远、并不确定的对象祈求，愿望真切，音乐却没有许诺回应。约第160小节，还会浮现另一幅短暂的画面：远方忽然被照亮，已经远去的家园在梦里显现——虽然无法回到那里，却远远地看见了它。
[S06-B3]（段内变化；小节 148–151；152–167；168–180；约180小节的未完感；局部）可以沿着旋律听它怎样一步步敞开：148–151小节还含蓄、试探，152–167小节歌唱逐渐展开，像终于鼓起勇气说出心里的话。到了168–180小节，歌唱再次展开，情感变得更充实、更迫切。临近180小节，它又像停在一句没说完的话上。
[S06-B4]（另一种理解；小节 148–180整体，不定位到单一小节）也可以听成：也可以把注意力放在“看”而不是“抓”：明知有些事已经挽不回，便放轻声音，好好看着它。像看着自己珍惜的东西，不必立刻把它抓回来。

### S07
[S07-B1]（主体验；小节 182附近；局部）第182小节附近，高音区忽然浮出一串轻得像游丝、却带着刺骨寒意的长颤音。它像寒风猛地吹开紧闭的窗，把人从甜梦里生生拽回严寒；后颈一凉，脉搏也剧烈跳动。梦境骤然破裂，身体先一步被惊醒。
[S07-B2]（段内变化；小节 182–197）同一转向里，带马祖卡色彩的舞蹈性材料闯了进来，和前一刻近乎祈祷的静谧形成反差。它不像沿着刚才那条深沉的思路继续往下讲，而像突然换了一个场景，原先的思绪被截断，音乐从别处重新开讲。这种突兀的换向并不等于情绪好转；新出现的舞步可以很鲜明，内心却未必因此安定下来。
[S07-B3]（段内变化；小节 198–205；局部）到了198–205小节，连续颤音让紧张一层层累积，思绪像不停翻转，想停也停不下来。事情表面上仿佛已经过去，身体和情绪却还没有完全相信一切已经结束。心里有东西在颤动，想要冲出去，却始终找不到真正的出口；在先前的惊醒之后，紧张仍在持续盘旋、难以平复。
[S07-B4]（另一侧面；小节 181–205）另一个可以同时浮现的联想，是一种非常具体、非常生活化的记忆突然闯进深沉的感受里：一个熟悉的动作、一次舞蹈、一段曾经习以为常的生活。这样的亲切感未必安慰人；恰恰因为那些细节具体而熟悉，反而更容易意识到自己已经失去了什么。
[S07-B5]（另一种理解；小节 182–197）也可以听成：182–197小节，也可以听成先前那些更有宣告意味、带着波兰舞曲气息的声音再次出现；只是它已不再像最初那样，以完整而鲜明的姿态建立秩序。

### S08
[S08-B1]（主体验；小节 206–213）206–213小节，前面那种缓慢、宽广的歌唱短暂地回来，让人又能认出那种沉思、近乎祈求的气息，像心里熟悉的柔软处重新打开了。
[S08-B2]（另一侧面；小节 206–213）但那份安静停留得太短：你刚认出它，还没来得及重新安顿下来，它就又退去了。像一个人已经准备离开，却在最后一刻回过头，再看一眼刚才待过的地方；那一眼里有温柔，也有不舍。
[S08-B3]（另一侧面；小节 206–213）换一个角度，也可以只留意身体的感觉：激烈的思绪之间，忽然像是获得了一次短暂的呼吸，胸口仿佛终于吸进一口气。它只是瞬间的喘息，并不等于整个人重新安顿下来。

### S09
[S09-B1]（主体验；小节 m.214–215；颤音光晕的来源描述覆盖mm.206–215。门槛意象只指开头姿态重新显现，后续向前的推进尚未在此展开。）双手铺开巨大的颤音光晕，开头沉重的引子从中阴冷地闪现回来，却不再像最初那样郑重召唤。声音短暂落稳，又向高处漂去，刚有的一点稳定感随即散掉；像是从另一面重新看见了同一扇门，真正向前的步伐还没聚起来。
[S09-B2]（另一侧面；小节 m.214–215的开头姿态回返；心理意味借由此前全曲的经历成立，相关原稿多以mm.214–225为讨论范围。）像是重新遇见那个不知道怎么办的自己——只是这一次，你已经知道那个过去的自己经历过什么。最初的问题又浮上来，却没有因此得到一个简单的答案。

### S10
[S10-B1]（主体验；小节 216–225）到了214–215小节，作品开头那种自由、试探的姿态一闪而过；接下来的216–225小节，并没有出现一段完整、站稳的旋律，熟悉的声音只是轻轻地、断断续续地浮现，像几块碎片。它们既像先前如歌旋律的碎片，也像那些舞曲主题的残片；另一种更凄厉哀婉的听法，是听见先前那段摇篮曲破碎地重现，只是这次变成了F小调。声音回来了，却没有完整铺开。
[S10-B2]（另一侧面；小节 221–225；局部）到了221–225小节，听感像忽然失重，整个人悬在半空，辨不清方向；声音零碎飘忽，连身体也像暂时失去了着落。
[S10-B3]（另一种理解；小节 216–225）也可以听成：如果把这次回返听成心理上的回望，开头的试探姿态仿佛把问题重新递回来：“那么，我究竟要怎样继续生活？”相似的迟疑此时不再只是尚未开始时的茫然，而是历经许多之后，仍未能获得彻底答案的疲惫。
[S10-B4]（另一种理解；小节 216–225）也可以听成：这些轻弱、零碎的声音，也像一个疲倦的人在回想一件往事：明明知道它很重要，却已经没有力气把它重新讲述一遍。

### S11
[S11-B1]（另一侧面；小节 226–237的反复冲击与紧张未解；低音和弦的重压从226小节开始，推动延续至241小节）左手涌起滚滚低音波涛，右手的和弦像重锤一样砸下。每次爆发之后，紧张都没有完全解除，反而又形成新的压力。这不像顺境中的凯歌，更像绝境中的困兽之斗：不是顺畅地奔跑，而是一次次顶住、再用力。
[S11-B2]（主体验；小节 226–241；226–229的试探与238–241的向上积聚标出这条变化弧线；局部）波兰舞曲的步子不是一下子整齐地回来：起头几小节还像在试探前方有没有路，随后步伐一点点聚拢，到最后四小节，前进感越来越不可回避。它不只是恢复旧姿态，仿佛把前面柔软、私密、近乎祈祷的声音带回可以迈步的节奏里——祈祷开始变成意志。
[S11-B3]（另一侧面；小节 226–241；这一心理理解贯穿全段，238–241的向上推进使前进感更难回避）如果把这股推进听成人的处境，最动人的不是忽然变得无所畏惧，而是害怕还在，脚却已经往前走了。紧张并没有解除，却有一丝奇特的解脱：不是问题解决了，而是停滞本身松开了一点。

### S12
[S12-B1]（另一侧面；小节 242–253，与此前主题姿态形成回顾性的对照）这份挺立也可以听成经历动摇后的主动选择：即使知道自己会犹疑、疲惫、想念，仍然可以决定怎样站立。它不要求人假装自己从未受过伤。
[S12-B2]（主体验；小节 242–253，主题回归起于m.242）m.242，熟悉的波兰舞曲主题以全键盘雷鸣般的声势轰然回归，一下占满前景，像沉重的步子终于踏实落地，声势几乎把人推着向前。它也可以听成一种面向外部、公开的昂扬，甚至带一点集体感。

### S13
[S13-B1]（主体验；小节 254–270；局部）先前像私下安慰、近乎祈祷的柔软歌唱重新出现，却被带进开阔、宏大的音响里，像一支温柔的歌忽然站到了明亮处，甚至有如管风琴般庄严庞大。密集的音符又像狂飙的激流向天空喷涌，仿佛一颗心脏以最高负荷跳动；柔软并没有被力量压下去，而是也被带进了高潮。这份公开的气势，还可以让人想到故土、共同记忆和希望。
[S13-B2]（段内变化；小节 269–280；局部）约第269小节，钢琴展开快速、炫目的八度进行，明亮、迅疾的音型向前冲出，把积累的能量一下子释放出来。如果说前一刻像在宏大地放声歌唱，那么这一刻更像身体被一股气流推着往前跑，兴奋得几乎来不及喘息。
[S13-B3]（段内变化；小节 281–287；局部）但这股冲势没有一直持续。约第281–285小节，音乐收敛下来，颤动般的装饰音重新带来一点不安，仿佛刚刚建立的成功又被轻轻问了一句：它真的已经牢固了吗？同一段回落也可以听成事情已经说完、终于能停下来喘口气。从容与细微的不安不必互相排斥，平静也不一定意味着疑问已经消失。
[S13-B4]（段内变化；小节 末尾几小节；局部）狂潮退去，喧嚣像骤然静止。低音区像呼出最后一口气，沉沉吐出两记耳语般的和弦；随后，钢琴最高音区忽然亮起一记透明、孤悬如寒星的高音和弦，像一声清脆的钟响。低处的轻声与高处的亮光形成鲜明反差，结尾的力量不必只靠更猛烈的敲击。
[S13-B5]（另一种理解；小节 286–288；局部）也可以听成：最后的高音和弦可以听作一个决定，也可以听作一个人忽然从梦中醒来。前一种听法更像意志终于落定，后一种更像从梦境中骤然清醒。

【一、先理解原稿，再决定哪些内容上屏】

完整阅读所有材料，理解全曲的人物关系、经历、处境、行为、判断、选择、情绪变化，以及音乐引出的具体身体和心理体验。

在内部建立信息清单，但不要输出清单。

对每条原始线，分别找出：发生了什么、人物发生了什么变化、他为什么这样想、他凭什么得出判断、为什么在这个时候做出选择，以及哪些前情或对方的反应支撑了后面的变化。

对每颗珠子，分别找出：具体身体感觉、心里真实浮现的话、独特的画面和比喻、情绪内部的细微变化、互相矛盾的感受，以及一种状态转向另一种状态时那些不能省略的连接。

内部将信息分成三类：
A类是必须保留的关键因果、判断依据、重要选择和不可替代的独特体验；B类是值得保留、能够增加体验颗粒或补足人物状态的细节；C类是可以删除的同义重复、替代性说法、空泛解释和纯技术信息。

不能只按剧情重要程度决定取舍。一个不起眼的身体感觉或内心疑问，也可能是整颗珠子最值得让观众看到的内容。

删掉任何内容之前，先确认它有没有提供其他地方没有的原因、证据、感受或转折。删重复，不删差异。

只能使用原稿有依据的信息。不能补造事件、动作、心理动机、人物关系、因果关系或新意象。原稿没有解释的事情，不得自行猜出一个理由。

【二、最重要的语言标准：所有文字都要像人话】

把每一句文字想象成一个人真的会对朋友说出来的话。要求自然、具体、容易听懂，不需要观众替编辑者补全句子。

严格避免以下写法：
1. 为了压字数删掉主语、谓语或必要连接，留下不完整的短语。
2. 把一个自然句子硬切成几个词组，每块单看都不成话。
3. 把原本直白的感受改成抽象名词、四字短语、书面词或故作深沉的格言。
4. 使用不合日常习惯的词语搭配，或者把普通动作说得玄乎。
5. 为了显得有文学感，刻意堆叠形容词、对仗、拟人和空泛比喻。
6. 所有句子都采用相同句式，反复出现机械的「因为……所以……」「虽然……但是……」。
7. 用「某种情绪」「内心深处」「逐渐产生变化」等空话，替代原稿里真正发生的事或真正感受到的东西。
8. 为了把字压短，将人物真实的内心话改写成旁观者的心理分析。

允许自然的长短句变化，也允许疑问、犹豫、停顿、转折、直白的内心话。原稿本来朴素的地方就保持朴素，不要强行写得漂亮。

一块文字如果需要观众读第二遍才能搞懂在说什么，就重写。宁可多几个字把话说顺，也不要省出一句别扭的话。

注意：本轮线的文字形态是完整句子，不是碎裂词组。画面上的上下错落和视觉分散可以保留，但不能通过破坏语法来制造所谓的碎裂感。

【三、line：一句完整自然的话，先让人抓到要点，同时保住为什么】

line负责人物经历、关系变化、重要判断、行为选择及其因果依据。它不是标题，也不是情绪标签，更不是把原稿压缩出来的一串关键词。

每个line.text必须是一句能够单独读懂的自然句子，有明确的事件、人物状态、判断或行动。可以根据上下文自然省略重复称呼，但不能省略到指代不清。

优先让观众在句子的前半部分抓到最重要的变化、行动、判断或选择，再自然交代与之有关的原因。不过不要为了机械地把结论放在最前面而扭曲正常语序。要点先行是一种阅读效果，不是一套僵硬句型。

重要行为、判断和选择必须保留原稿提供的关键依据。特别检查：
- 以前发生过什么，才让人物现在改变了态度？
- 对方做过什么、持续表现出什么，才让人物得出这个判断？
- 人物为什么想坚持、停下、靠近、退开或做出其他选择？
- 他明明还在犹豫，为什么最后仍然行动了？
- 为什么这个变化发生在此刻，而不是更早？

不要求每一条线都回答所有问题，只要求凡是原稿明确交代、而且影响观众理解的理由，不能在压缩时消失。

如果一个行为与理由能用一句自然的话说明白，就放在同一句里。如果确实包含两步独立的信息，可以写成两条连续的line，但两条都必须分别是完整自然的句子，不能把「因为某件事」单独切成一行，再把「所以做了某事」单独切成另一行。

不要为了让线变短，把多次发生的经历归纳成一个抽象心理词，也不要把不同时间的独立事件合成一句笼统总结。

line的长度以一眼读懂、读起来顺为准。通常可以在约20至45个汉字之间自然浮动；关键因果需要时可以稍长，但不要拖成一段心理分析。这个范围是提醒，不是必须执行的截断线。不得为了凑字数而拉长句子，也不得为了达到某个数字而牺牲语法、因果或自然表达。

每条line设置1至2个keys，选择最值得放大的行动、判断、关系变化或关键状态。关键词尽量出现在句子的前半部分，但不要为了提前关键词而把句子写别扭。

keys中的每个值必须逐字等于text中连续出现的文字，不能改写、跳字或自行创造。不要把整个句子选为关键词。

每条line必须填写emotion，并且只能从「炽热、欢喜、亲密、安心、孤单、不安、悬着」中选择一个。

每条line的from必须包含真实的原始线编号。允许合并或拆分，但必须保持信息来源准确，不得编造编号。

最终把全曲所有line单独连起来读一遍：读者必须能理解重要经历、关系如何变化、判断从何而来、人物为什么这样选择。不能只剩一串结果。

【四、feel：短小独立，但必须像人在描述真实感受】

feel负责line没有提供的体验，包括身体感觉、感官变化、心里的话、独特画面、微妙情绪，以及看似矛盾的两种状态如何同时存在。

每个feel item只表达一个相对独立的体验中心，或者一个本身不可拆开的矛盾和转折。

重点保护五种信息：
1. 具体身体感觉：呼吸、温度、触感、轻重、松紧、心跳，以及原稿中有辨识度的生理感受。
2. 真实内心话：疑问、担心、犹豫、自我安慰、没敢说出口的想法。能保留具体心声，就不要改写成抽象情绪标签。
3. 独特比喻和画面：原稿中真正提供了体验入口的画面，不能只留下它背后的情绪结论。
4. 情绪微状态：一点点放松、短暂的高兴、迟迟没散的不安，以及程度、方向和质地不同的感受。
5. 连接和矛盾：一件心事还没解决，但此刻没那么困扰；一种愿望仍在，却不知道会不会实现；人物同时感到两种难以调和的心情。

对于不可拆分的矛盾体验，要把两层关系一起保留，不能只留下其中一边，也不能分别拆成失去联系的两个残句。

feel可以比line短，可以是口语里自然成立的短句，也可以是完整句子，但绝不能像从一段文字里剪出来的几个残缺词语。不要把短小误解为主语和动作都不见了。

一块感受通常约12至35个汉字；如果把体验说清楚需要稍长一些，可以自然增加。长度服从自然表达和独立体验，不服从硬性截字。

不同的体验分别写成不同item。同一种体验的不同说法，只留下最具体、最自然、最好理解的一种。同一颗珠子可以保留多块真正不同的感受，但不能把几种近义说法一起搬上屏。

一个feel row可以包含多块相近时刻、情绪颜色一致的独立感受，通常1至3块较容易扫读。不要让items连起来变成一篇需要细读的段落。

feel不能只是对line再说一遍。line交代人物做了什么和为什么，feel让观众知道那一刻具体是什么感觉。两者即使都涉及心理，也应当各自提供不可替代的信息。

音乐术语只在它确实是体验入口时少量保留。不要把纯粹的旋律、节奏、和声或声部分析当成feel，也不要因为删掉技术解释，就连它带出的具体感觉一起删除。

任何体验都不得添加原珠子没有的动作、物体、心理解释或比喻。每个item必须对应一个真实bead编号。

【五、颜色：每条线独立选情绪，下面的感受继承它】

颜色不是装饰，而是让观众不用细读，也能感觉到这一刻情绪性质的视觉信号。

每条line根据它所表达的当下状态，选择一个emotion：
炽热：强烈的投入、渴望或情绪推动。
欢喜：明亮、愉快、轻快的情绪。
亲密：靠近、连接、被理解或彼此在意。
安心：放松戒备、安稳、可以暂时放心。
孤单：无人回应、距离、空落或失去陪伴。
不安：担心、害怕、紧张或无法放心。
悬着：等待、未定、还不知道结果、心里有事放不下。

这些定义用于辨别颜色性质，不是要求把这些标签写进text。文字必须呈现具体经历或真实感受，不要把标签冒充内容。

每条line的emotion只选一个，以此刻最主要的情绪为准。遇到复杂或矛盾情绪时，保留文字里的复杂关系，不要把内容强行改成单一情绪。

同一段出现几条情绪性质不同的线时，要分别判断并使用不同的emotion。例如亲近带来的放松，与仍然等待结果的忐忑，不应因为处在同一段就全部归成同一种颜色。

同一种情绪确实持续时，可以重复使用同一emotion。不要为了做出彩虹效果，强行给性质相同的线换颜色，也不要为了全段统一而抹平本来不同的感受。

每个feel row放在与它最相关、情绪性质相符的line下面，继承上方最近一条line的emotion，不单独输出颜色字段。一个feel row里的items应当能合理共用这种情绪颜色。如果感受属于另一条线的情绪，应当拆开排列到对应位置，而不是全部塞在同一颜色下面。

不能为了配色而颠倒真实时间顺序，也不能为了给一块感受安排颜色，就编造原稿没有的line。若素材确实没有可引用的线，可以保留独立feel，不得凭空添加叙事来源；呈现端可继承此前最近的真实线色，不需要增加JSON字段。

输出的emotion就是画面使用的情绪颜色类别。不要另外输出色号、颜色名称、RGB、样式或渲染说明。

【六、排版顺序：上下交替、关键词突出，但不机械拼接】

按音乐和叙事实际发生的顺序安排rows。

优先使用「line在上、相关feel在下」的交错结构，让观众先抓住人物正在经历什么，再看见那一刻的具体感受。

可以出现line、feel、line、feel，也可以出现连续两条line再跟一个feel row，或者一条line下面跟多块性质不同但同色的感受。不要强制一条线配一块感受。

每条line是一句完整的话。不能为了画面上的上下交替，把原本完整的句子拆成两个不通顺的行。

feel作为小块散落，不能重新汇成长段。不同小块之间要有独立的信息价值，不能只是一个句子被硬拆成几块。

如果原稿没有说明先后关系，不要使用「然后」「接着」「最后」等词伪造时间推进。只有素材明确发生了变化，才能写成前后变化。

所有要放大的字由keys指定，不要在text里加入特殊符号、加粗标记或排版说明。

【八、编号与bars的硬性规则】

sections只能使用原材料真实存在的段落编号，并按原有顺序排列。

line.from只能填写真实的原始线编号，允许多个来源，但不能编造编号。

feel item的bead只能填写一个真实的珠子编号。不能把不同珠子的内容揉成一个item后随意选择来源。

每个feel item必须带有bars字段，且必须是字符串。

只有原珠子明确指出某个局部体验属于哪些小节时，bars才填写相应范围。该范围不得超出珠子明确写出的范围，不得自行推算、扩展或猜测。

如果珠子只写了整体范围，或者这块体验属于整颗珠子的整体感受，bars一律填写空字符串。

小节号只允许出现在bars字段中。plan、line.text和feel item.text都不得出现小节号、小节范围或定时指令。

【九、plan：交代全曲编排和前后呼应】

plan简洁说明全曲如何从一个阶段推进到下一个阶段、哪些早期经历支撑了后来的判断或选择，以及哪些有原稿依据的关键词、意象或情绪在前后呼应。

如果同一个关键词在不同段落里的含义或情绪发生变化，可以指出这种变化。不要为了制造结构感而发明原稿没有的主题、象征或对应关系。

plan不必逐段复述所有line和feel，也不要写成论文。不要包含具体小节号。

【十、输出前的内部验收】

必须在内部完成以下检查，不要把检查过程写进输出。

人话检查：把每一条line和每一块feel逐字读出来。是否真的像日常说话？有没有生硬搭配、书面短语、缺少必要成分、刻意对仗或硬切开的半句话？有就重写，而不是只改一两个形容词。

句子检查：每条line能否独立读懂，是否是一句完整自然的话？有没有为了关键词靠前而扭曲语序？有没有为了省字删掉关键主语、动作、判断依据或连接词？

因果检查：只读全曲line，是否知道人物经历了什么、为什么形成某种判断、又为什么做出重要选择？把原始线中的关键因果逐项核对，不能出现只有结果没有依据的情况。

体验检查：逐颗核对珠子中的身体感觉、内心话、比喻、微状态和连接转折。是否把性质不同的体验误当成重复？是否把有内容的疑问、矛盾或感觉压成了一个抽象情绪词？是否引入了原稿没有的新画面？

【最终输出格式】

只输出一个合法JSON对象，不要Markdown代码块、前言、解释、注释、验收报告或结论。

严格使用下面的结构和字段：

{
  "plan": "全曲怎么排、哪些词前后呼应",
  "sections": [
    {
      "sec": "S01",
      "rows": [
        {
          "kind": "line",
          "text": "线这一行完整、自然的话",
          "keys": ["text里连续出现的关键词"],
          "emotion": "安心",
          "from": ["S01-1"]
        },
        {
          "kind": "feel",
          "items": [
            {
              "text": "一块自然、具体的感受",
              "bead": "S01-B2",
              "bars": ""
            }
          ]
        }
      ]
    }
  ]
}

以上只是字段结构示意，正式输出必须使用输入中的真实编号和实际内容，不能照搬示意文字。

字段要求：
- plan：一个字符串，简述全曲编排、重要因果承接和有依据的前后呼应。
- sections：按原始段落顺序排列。
- sec：真实段落编号。
- rows：按实际展示顺序排列line行和feel行，不要求机械一一配对。
- line.text：一句完整、自然、要点清楚、有必要因果依据的话。
- line.keys：1至2个要放大的关键词或短语，必须与text中的连续文字完全一致。
- line.emotion：只能是炽热、欢喜、亲密、安心、孤单、不安、悬着中的一个。
- line.from：一个或多个真实原始线编号组成的数组。
- feel.items：一个或多个独立感受块，内容自然，同一个feel row里的感受应当适合继承同一种情绪颜色。
- feel item.text：一块短小、具体、有辨识度、说得通的感受，不得包含小节号。
- feel item.bead：一个真实珠子编号。
- feel item.bars：字符串，只有原珠子明确标出对应局部小节时才填写范围，否则为""。

line对象只允许kind、text、keys、emotion、from字段。feel对象只允许kind、items字段，item只允许text、bead、bars字段。不得增减字段或输出任何额外配色、动画和排版数据。

最重要的底线：不要为了短而写得不像人话；不要为了好扫而删掉人物为什么这样做；不要为了恢复细节而重新写成长段；不要为了多种颜色而扭曲真实情绪。句子要完整自然，感受要具体细腻，每段字数要接近参照，整份稿子要能让普通观众边听边看。
