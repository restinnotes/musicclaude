# Op.61｜关系图

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### 1–23　（还说不清）

- 他心里有股不肯听任下去的劲，仿佛放任就会让一切显得理所当然，可真要投入又怕失去什么。
- → 他试着找一个足以停止犹豫的理由，刚觉得自己想通，另一番舍不得又浮上来，连刚才的确信也渐渐陌生。
- → 反复摇摆让他难堪，他开始怀疑自己是否非得把心里的事全想妥，才肯向前一步。

### 24–65　（正在面对）

- 他受不了再拿没想清楚当作等候理由，先认下能承担的那一份，虽然没有保证、牵挂也没消失，却真切感到自己有了力量。
  - ← 改写：（1–23）「为反复摇摆难堪」
- → 他从前反复问值不值得，如今至少愿意尽力，并为自己仍有疑虑却不再受其支配而骄傲。
- → 投入之后，他渐渐热切，付出的过程让不满仿佛终于有了去处，他也开始贪恋倾尽全力的畅快，不想再时时审视自己或因一点软弱停下。
- → 可用力到深处，他偶尔仍感到心里一小块地方没有跟着昂扬，隐约知道坚决并未顾全所有牵挂。　✦ 满足照出未满足

### 66–91　（没在想）

- 正因为已经认真投入过，他眼下反而能从原先反复自问里松开一点。
  - ← 提供理由：（24–65）「贪恋倾尽全力的畅快」
- → 他发现自己也会因不再畏缩而高兴，在向前的热情里感到轻盈，偶尔忘记自己为何如此用力时，他也不觉得自己背叛了什么，那是许久没有尝过的自由。
- → 他顺着这份自由走了一程，没有急着赋予它更大的意义。
- → 只是快乐不再那么饱满时，先前作过的决定仍在等着他。

### 92–115　（正在面对）

- 他仍愿意坚持先前的决定，因为它曾带他走出动弹不得的犹豫、带来真实的轻快，心里仍有缺口，他也不愿把一切判错。
  - ← 提供理由：（66–91）「向前时感到轻盈」
- 曾让他昂起头的坚定此时无法使他安心，他想确认自己仍有力量时，也看见心里另有要求不能由力量代替。　✦ 满足照出未满足
- → 他渐渐看清行动确有价值，却满足不了心里所有要求，虽不情愿也无法再装作不知。　✦ 分清
- ⟲ 仍在起作用：（66–91）「快乐退去后决定仍在」

### 116–147　（正在面对）

- 明知行动不够，他仍不肯撒手，因为它曾救他脱离犹疑，他怕眼下的失望意味着自己变了心。
  - ← 提供理由：（92–115）「不愿否定曾经的收获」
- → 因此他更用力催逼自己，把心里的难处当成能够克服的迟疑，想停一停又担心那是退缩。
- → 他知道自己正在受苦，却不知道除了继续坚持，还能怎样对得起最初的决意。
- → 原先让他昂扬的要求容不下脆弱，慢慢从鼓励变成对自己的苛责。　✦ 办法的限度
- → 他想保持坚定，却渐渐觉得自己像在勉强一个已经疲惫的人，终于不想再证明有多坚强。
- → 暂时放下催逼没有立刻让他安心，却让一直被压住的依恋有了回来的余地。
- → 他有些茫然，也有些松懈，仿佛终于允许自己感到，除了必须去做的事，他还真心舍不得一些东西。
- ⟲ 仍在起作用：（92–115）「行动值得却仍不够」

### 148–180　（没在想）

- 不再催逼自己后，他才看清那份依恋不只是想免于辛苦，还盼望人与人不必时时防备，珍视之物也能不靠争夺留下。
  - ← 改写：（116–147）「舍不得失去某些东西」
  - ← 改写：（1–23）「不肯听任却怕失去」
- 他也盼望自己因喜欢而付出，靠近别人时不必先做好受伤的准备。
- 这份盼望早已给过他快乐，他知道它并非为了逃避才临时编出的安慰，也让他感到自己不只需要承担和坚强。
- → 他也曾感到人与生活可以亲近，不必时时用力维持，因此此刻无法把这份愿望当作软弱。
- → 他终于肯完整地待在这份盼望里，不急着问这样的生活能否得到，也不急着拿它和眼前的坚持比较。
- → 他仅仅允许自己这样去爱、去相信，就感到深深满足，仿佛重新柔软地活着，沉浸其中时几乎忘了疲惫，也暂时不想离开，眼下确实得到了一直需要的东西。

### 181–205　（正在面对）

- 正因为这份安宁如此真实，他渐渐无法满足于只在心里拥有它。　✦ 满足照出未满足
  - ← 提供理由：（148–180）「允许爱惜带来满足」
- → 重新感到那些东西为何可贵后，他不甘心只停在怀念里，觉得使它们受损的事情仍得面对。
- → 他几乎责怪自己，刚刚沉浸在满足里，竟忘了还有必须面对的事。
- → 他试着振作，却已无法毫无顾忌地投入，怕艰难争取会耗尽温柔，最后只剩意志，失去让一切值得的那份心意。　✦ 选择的代价
- → 他舍不得那份安宁，又无法放下它受到的威胁，向前和停留都让他不安。
- → 他曾以为找到足够坚定的理由就能平静下来，如今理由更多，心里反而比从前更难平静。　✦ 知道更多反而更尖锐
- ⟲ 仍在起作用：（1–23）「不肯听任却怕失去」

### 206–213　（没在想）

- 那份温柔又短暂贴近，他明知不能一直停留，仍不忍立刻推开，因为它曾给过他深深的满足，他愿再爱惜片刻，暂时不拿未解之事审问自己。
  - ← 提供理由：（148–180）「允许爱惜带来满足」
- → 这点安静仍使他欢喜，只是欢喜里已经有了不舍。

### 214–215　（正在面对）

- 等这点安静退去，熟悉的迟疑又回来，仿佛走了很远仍回到原处。
  - ← 失效：（206–213）「安静中已有不舍」
- → 可他如今知道自己始终放不下什么，那份迟疑里也藏着他不愿失去的生活希望，不能只当作怯懦。　✦ 分清
- ⟲ 仍在起作用：（148–180）「盼望不必防备的生活」

### 216–225　（正在面对）

- 知道自己舍不得什么，并没有让他立刻勇敢，他无法只凭起初的决心向前，也无法安心沉浸在旧愿里，两种办法都给过他东西，也留下难处。　✦ 办法的限度
  - ← 限制：（214–215）「迟疑里有生活希望」
  - ← 说明：（92–115）「行动值得却仍不够」
  - ← 说明：（148–180）「允许爱惜带来满足」
- → 他一时没有力气要求自己作出多大改变，只剩一个很轻的愿望，争取时别忘了为何争取，爱惜安宁时也别放弃面对使它难以存在的事情。
- → 他还不知道怎样做到，只反复想着这点微弱的意思，心里非得舍弃一边才能继续的逼迫似乎稍稍轻了些。

### 226–241　（正在面对）

- 他不愿再简单否定其中任何一边，尽管两种收获都留有不能忽略的难处。
  - ← 说明：（92–115）「行动值得却仍不够」
  - ← 说明：（148–180）「允许爱惜带来满足」
- → 要让两样收获都毫发无伤地留下，恐怕很难，他想保有无需时时奋力的安宁，为它争取又得承担失去安宁的可能。　✦ 选择的代价
- → 过去他总因这种难受责怪自己，仿佛坚定的人就不该如此，如今渐渐看见代价来自自己珍视的东西不止一种。　✦ 分清
- → 这种认识没有让他轻松，想到仍要付出，他还是心疼，也盼着能有一条不必如此艰难的路。
- → 他知道继续等待不会让那条路自然出现，若只因害怕损伤珍贵之物就不再争取，所爱惜的也未必能留下。
- → 他终于不再要求自己先变成毫不害怕的人，舍不得、没有把握、受苦，都不必成为停止的理由。
- → 他一点点重新聚起力量，愿意带着不舍往前，真正接近承担时，他反而更清楚自己仍会怕，却不想让惧怕替自己决定。

### 242–253　（正在面对）

- 他不再等待毫无损失的办法，终于能重新挺直身来，久违的昂扬也回来了，却不必靠否认脆弱维持它。
  - ← 改写：（226–241）「带着不舍重新聚力」
- → 先前他多少想借坚定证明自己有能力改变些什么，如今仍愿尽力，却不再要求尽力证明自己无所不能。　✦ 分清
  - ← 改写：（24–65）「先承担能做的部分」
- → 他知道自己要承担什么，也知道为何难以割舍，不必把害怕和珍惜藏起来才显得勇敢。
  - ← 提供理由：（226–241）「代价来自珍视不止一种」
- → 他不再把这些牵挂看成行动的拖累，愿意为自己真心爱惜的一切负起责任。
- → 这次决心仍然热烈，却比最初踏实，他不必等疑虑消失才允许自己坚定。

### 254–288　（正在面对）

- 当他能够带着全部牵挂向前，连自己也有些意外，旧愿似乎没有远去，反而比从前更亲近了。
  - ← 改写：（242–253）「不必等疑虑消失」
- → 过去他以为只有从争取中撤回才能保住旧愿，如今正因为知道它多么可贵，他更不愿任由妨碍它实现的事情存在。
  - ← 提供理由：（148–180）「盼望不必防备的生活」
- → 他第一次真切感到，温柔可以成为不肯袖手旁观的理由，若在争取中丢掉这份向往，即使显得坚强，努力也会失去意义。
- → 他仍想过无需拼命就能好好生活的日子，却知道为珍惜它，有时不能停留在它给予的安宁里。
- → 他仍须提醒自己，投入的多少无法保证旧梦实现，怀着美好愿望也不能让每份付出都值得。
- → 他仍得留心争取会不会损伤想守护的东西，顾虑也开始提醒他该怎样坚持，不再只让他退缩。
- → 重新理解这份希望后，他感到更宽广的喜悦，发现依恋和责任竟能一同支持他向前。
- → 他不必再把依恋藏起来，也不再因责任感到厌倦，经历许多怀疑与疲惫后，这份快乐已不再理所当然。
- 喜悦渐渐平静后，他仍知道有些事没有答案，无法保证自己的承担会改变什么，也没有真的回到无须防备的生活。
- → 往后他仍可能疲惫，也可能因不得不付出的代价而动摇，即使把两种渴望一同带着，它们仍可能相互牵制。
- → 他不再急着用一种满足遮住另一种需要，也不因某种需要未满足就否定已经得到的东西。
- → 过去的快乐、失望、疲惫和依恋此刻都仍属于他，让他看清什么值得付出，什么不能在付出中轻易牺牲。
- → 他仍向往安宁，也仍愿意行动，虽然不知道最终能留下多少珍贵的东西，却不愿忘记任何一边来求得平静。
- → 他可以带着这样的不舍继续向前，也不再为自己的愿意寻找更多证明。
- ⟲ 仍在起作用：（1–23）「不肯听任却怕失去」
