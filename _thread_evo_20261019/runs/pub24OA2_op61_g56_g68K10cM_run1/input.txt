感受：双手铺开巨大的颤音光晕，开头沉重的引子从中阴冷地闪现回来，却不再像最初那样郑重召唤。声音短暂落稳，又向高处漂去，刚有的一点稳定感随即散掉；像从另一面重新看见同一扇门，真正向前的步伐还没聚起来（到时出现） / 也可以听成重新遇见那个不知道怎么办的自己——只是这一次，已经知道过去的自己经历过什么。最初的问题又浮上来，却没有因此得到一个简单的答案（到时出现）

### S10（屏幕停留 28 秒）
话：他慢慢觉得自己最舍不得的，还是从前有人把他当作自己人的日子；可就算真的回去，【还能像从前那样吗】？当初那些让他难受的事也不能当作没发生，光凭舍不得，他还是没法放心回去。开头自由、试探的姿态一闪而过；接下来的部分没有完整站稳的旋律，熟悉的声音只是轻轻、断断续续地浮现，像先前如歌旋律和舞曲主题的碎片。另一种更凄厉哀婉的听法，是摇篮曲在F小调里破碎地重现。【声音回来了】，却没有完整铺开。
感受：听起来忽然失重，整个人悬在半空，辨不清方向；声音零碎飘忽，连身体也像暂时失去了着落（到时出现）
话：他翻来覆去想得很累，还是没个答案，连眼下的日子都过得不踏实。如果把这次回返听成心理上的回望，开头的试探仿佛把问题重新递回来：“那么，我【究竟要怎样继续生活】？”相似的迟疑此时不再只是尚未开始时的茫然，而是经历许多之后，仍没有彻底答案的疲惫。这些轻弱、零碎的声音，也像一个疲倦的人在回想一件往事：明明知道它很重要，却已经【没有力气把它重新讲述一遍】。

### S11（屏幕停留 22 秒）
感受：明知道回去未必找得回那份亲近，他却还是忍不住想：万一能呢？再心动，也不愿只凭这点指望，就回去过从前那种忍让的日子 / 回不回去以后再说，先把眼下日子过稳些，也许更踏实。他仍怕以后遇上难处只能自己扛，心里没多少底，可这回不想因为害怕就把刚才的打算收回去
感受：左手涌起滚滚低音波涛，右手和弦像重锤砸下；每次爆发后，紧张都没有完全解除，反而又形成新的压力。这不像顺境中的凯歌，更像绝境里的困兽之斗：一次次顶住，再用力（到时出现） / 波兰舞曲的步子不是一下子整齐回来：起头几小节还像试探前方有没有路，随后一点点聚拢，到最后四小节，前进感越来越不可回避。它仿佛把前面柔软、私密、近乎祈祷的声音带回能迈步的节奏里，祈祷开始变成意志（到时出现） / 如果把这股推进听成人的处境，最动人的不是忽然无所畏惧，而是害怕还在，脚却已经往前走了。紧张没有解除，却有一丝奇特的解脱：不是问题解决了，而是停滞本身松开了一点（到时出现）

### S12（屏幕停留 25 秒）
话：他想，当初那些气不该忍，和那些人在一起也确实开心过，这回【不逼自己选边】了。m.242，熟悉的波兰舞曲主题以全键盘雷鸣般的声势轰然回归，一下占满前景，像沉重的步子终于【踏实落地】，声势几乎把人推着向前；也可以听成面向外部的公开昂扬，甚至带一点集体感。
话：想起那些好时候，他还是会心软，也怕往后一个人熬；可他不再怪自己当初离开，更不愿只为有人陪着就回头，愿意【带着想念继续过日子】。这份挺立也可以听成经历动摇后的主动选择：即使知道自己会犹疑、疲惫、想念，仍然可以【决定怎样站立】，不必假装自己从未受过伤。
感受：昂扬没有一路直冲到底，音乐忽然换了一下色彩，像脚步正往前时地面短暂斜了一下，随后却仍继续向前（到时出现）

### S13（屏幕停留 62 秒）
感受：想起从前那些自然亲近的日子，他心里又热了起来，也盼着以后还能有那样的相处 / 先前像私下安慰、近乎祈祷的柔软歌唱重新出现，却被带进开阔、宏大的音响里，像一支温柔的歌忽然站到明亮处，甚至有如管风琴般庄严庞大。密集音符又像狂飙的激流向天空喷涌，仿佛一颗心脏以最高负荷跳动；柔软没有被力量压下去，而是一起进入高潮。这份公开的气势，还可以让人想到故土、共同记忆和希望（到时出现）
感受：这么想着，他倒真有了劲头，想把往后的日子好好过起来，不再整天跟从前的事较劲 / 随后，钢琴展开快速、炫目的八度进行，明亮、迅疾地向前冲，把积累的能量一下释放出来。若说前一刻像宏大地放声歌唱，这一刻更像身体被一股气流推着往前跑，兴奋得几乎来不及喘息（到时出现）
感受：劲头稍缓，他又怕还要等很久，才能再遇上那样亲近的人，心里渐渐静了下来 / 随后，音乐收敛下来，颤动般的装饰音重新带来一点不安，仿佛刚建立的成功又被轻轻问了一句：它真的已经牢固了吗？同一回落也可以听成事情已经说完，终于能停下来喘口气。从容与细微的不安可以并存，平静也不一定意味着疑问消失（到时出现）
感受：将来要是再有人愿意把他当自己人，他会好好珍惜；即使一直没有，他也愿意自己好好过下去，不再为了留住谁把那些委屈咽下去 / 末尾狂潮退去，喧嚣像骤然静止。低音区像呼出最后一口气，沉沉吐出两记耳语般的和弦；随后钢琴最高音区忽然亮起一记透明、孤悬如寒星的高音和弦，像一声清脆的钟响。低处的轻声与高处的亮光形成反差，结尾的力量不必只靠更猛烈的敲击（到时出现） / 最后的高音和弦也可以听作一个决定，也可以听作一个人忽然从梦中醒来：前一种听法更像意志终于落定，后一种更像从梦境中骤然清醒（到时出现）
