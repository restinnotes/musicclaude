**S02**　他不愿让对旧日归属的怀念替自己决定眼下怎么做，但还没想好该怎样把这个愿望落实下来。 / 他努力让自己镇定下来，心里却并不踏实；好不容易聚起一点力量，很快又被不安打散。 / 他不甘心就这样被失落拖住，仍想守住自尊，只是这份抵抗并没有让他真正安稳。

**S03**　他不甘心接受眼下的处境，在守住自尊和顺着怀念之间来回衡量，先前那点确信也慢慢淡了，仍没决定接下来怎样做。 / 有时他想起从前那种熟悉、亲近、无需处处防备的感觉，心里会柔软下来，可紧接着又感到如今已经回不去了。 / 念头常常挤在一起，他一时分不清自己究竟在意哪一部分，也找不到明确方向。 / 偶尔他能暂时把这件事放到一边，轻松片刻；可那份轻松过去后，原来的衡量还在。

**S04**　想到过去时，他仍会感到温暖和感激，也明白那种熟悉的生活已经不能重新成为现在。 / 他决定不再等怀念淡下去，也不让它替自己决定眼下怎么做，仍按自己认可的尺度行事。 / 这个决定没有让他立刻松下来，紧张和不甘仍在；那些已经无法改变的部分，他也还会反复设想别的可能，却始终得不到答案。

**S05**　他开始照着这个决定行事，不再把怀念是否消退当作开始行动的前提。 / 对旧日生活的眷恋仍然柔软而私密，越是想起那份熟悉，眼下的孤单越明显。 / 他心里仍有悲伤和不甘，想守住自己的尊严，却发现原先支撑自己的那股劲并不总在。 / 绷得久了，他偶尔会松下来一会儿，那更像是累了，并不是事情已经过去。

**S06**　有一段安静的时候，他不必一直向自己证明什么，压在心里的愿望、委屈和思念才慢慢浮出来。 / 他仍盼望有一天能重新感到那份归属，也知道那种生活不能重新成为现在，只能继续珍惜它。 / 这份安静没有持续多久，也没有让他轻松下来；他还是得带着这些感受继续按自己的尺度行事。

**S07**　原本稍微安稳的状态忽然被打断，他一下警觉起来，心思也变得活跃纷乱，却没有因此轻松，反而久久不能平复。 / 旧日熟悉的日常感突然变得鲜明，让他短暂觉得亲近，随即又更清楚地感到它已不在眼前。 / 他没有重新审查要不要坚持，只继续守着已经选定的行为尺度；这份熟悉的自持却不再像从前那样稳当。

**S08**　有一小段时间，他没想到旧日生活，只把注意放在眼前该守住的分寸上。 / 那会儿心里短暂安静了一点，熟悉的柔软感也像是回来过；可这份松弛很快过去，没有真正安顿下来。

**S09**　旧日归属的念头又突然回来，他一下分了神，刚才那点安静也散了。 / 这份无措仍很熟悉，只是他没有从头衡量，只把眼前的事接了下去，照原先选定的尺度继续做。

**S10**　分神过去后，他把心思留在眼前的事上，继续把已经选定的做法维持下去。 / 过去的感受只是零零碎碎地浮现，他仍记得那段生活的重要，却没法再完整地接近那种熟悉感。 / 心里仍有些悬着，像没找到真正的依托；眼下怎么做已经清楚，更远的日子会怎样却说不准。

**S11**　长久这样守住自己的尺度，让他明显感到疲惫；每次稍微松下来，压力还是会回来。 / 他仍有一点想继续的力量，尽管害怕和不安没有消失，做下去也并不轻松。

**S12**　他仍按自己认可的尺度行事，却开始担心，长期把自己绷得这么紧，会不会让自持变成一种僵硬的防守。 / 这份担心有时让他短暂失了稳，但他仍然没有停下眼前的行动。

**S13**　那份眷恋一时变得格外有力量，不再只是柔软的回望，也给了他继续行事的一股劲。 / 这股劲退下后，轻微的不安仍在；他可以暂时松一口气，却没有得到长久的把握。 / 到最后，纷乱的感受慢慢收拢，他仍按自己认可的尺度行事，旧日生活和归属也仍留在心里；往后怎样长久承受，他还没有答案。
