# Op.60｜DAG v3 关系图（m0）

**Center：**亲密的幸福与留不住它的痛楚难以分开

### S01｜1–3 小节　（没在想）

- 起初他没觉得这有什么了不得
- 想到那个人，他惯常的紧绷松了一点
- 这点松动还不足以让他相信什么
- 他已经舍不得离开这种感觉
- 他暂时不急着表现得更好
- 他暂时不急着藏起自己的需要

### S02｜4–16 小节　（没在想）

- 这份轻松渐渐让他觉得可以依靠
  - ← 提供理由：（1–3）「紧绷松了」
- 起初他仍不敢显露太多欢喜
- 他仍为依恋留几分余地
- 他怕显露需要会成为别人的负担
- 他渐渐更愿向那个人敞开
  - ← 提供理由：（1–3）「藏起自己的需要」
- 他喜欢自己的欢喜有了去处
- 他脆弱时不必马上变回独自承受的人
- 亲近没有让他觉得欠下什么
- 他能自然地喜欢、需要和给予
- 他曾羞于承认的依恋也变得可爱
- ⟲ 仍在起作用：（1–3）「相信什么」

### S03｜17–23 小节　（没在想）

- 他开始盼望更多亲近
  - ← 唤起：（4–16）「欢喜有了去处」
- 他想把还没说清的感受交给对方
  - ← 唤起：（4–16）「更愿向那个人敞开」
- 他想让彼此尚未触及的部分渐渐熟悉
- 他仿佛觉得眼下很好，往后还能更好
- 他如今为心里有这么多爱意而高兴
  - ← 改写：（4–16）「别人的负担」 —— 他开始喜欢自己有这么多需要和爱意
- 每多一分亲近，他就多一分愿意
- 对未来的期待让眼前幸福更加鲜亮
- ⟲ 仍在起作用：（4–16）「自然地喜欢」

### S04｜24–34 小节　（还说不清）

- 他开始毫无保留地享受亲近
- 他喜欢上亲近时敞开的自己
  - ← 提供理由：（4–16）「独自承受」
- 他不用时时猜自己是否值得被爱
- 他不再刚一欢喜就顾虑重重
- 他仿佛还有无数温柔可以给予
- 他每次给予都感到幸福更丰盛
- 快乐太满的一瞬，他忽然舍不得
  - ← 唤起：（17–23）「未来的期待」
- 那一刻他明明什么也不缺，心口却收紧
- 他担心这样的亲近往后能否一直如此
  - ← 动摇：（17–23）「往后还能更好」
- 那个念头没停留多久
- 他隐约感觉自己比想象中更在乎这份亲密
- ⟲ 仍在起作用：（4–16）「更愿向那个人敞开」

### S05｜35–39 小节　（正在面对）

- 那一点舍不得还没完全散去
- 稍想亲近不能一直这样，他心里就发酸
  - ← 提供理由：（24–34）「毫无保留」 —— 他已经真切得到过这份幸福
- 他还谈不上害怕，只是格外珍惜
  - ← 提供理由：（24–34）「更在乎这份亲密」
- 他的温柔里多了一点不愿松开的心思
- ⟲ 仍在起作用：（24–34）「忽然舍不得」；（24–34）「往后能否一直如此」

### S06｜40–50 小节　（正在面对）

- 那份酸楚没妨碍他安心地亲近
- 他不因一时的不舍怀疑眼前幸福
  - ← 提供理由：（4–16）「可以依靠」 —— 他对这份温暖已有切身的信任
- 他不必时时确认彼此有多亲近
- 他不必把每一分心意都表达完整
- 他依然觉得自己被对方放在心上
- 这样的余地比热烈回应更让他舒服
  - ← 提供理由：（4–16）「欠下什么」
- 他可以安静地享受亲近
- 他任凭爱意在心里慢慢生长
- 有时一切都好，他仍轻轻心疼
- 他也舍不得失去那个不必防备的自己
  - ← 提供理由：（24–34）「敞开的自己」
- ⟲ 仍在起作用：（35–39）「格外珍惜」

### S07｜51–61 小节　（正在面对）

- 这份自在使他想靠近得更深
  - ← 唤起：（40–50）「热烈回应」
- 他已不满足于只是感到被爱
  - ← 限制：（40–50）「放在心上」 —— 他还希望自己的情意能抵达对方
- 他想让最深、最难说的情意被对方领受
- 他想把更多爱意给出去
- 他想把对方的温柔完整接住
- 他有一点急切，舍不得心里还有保留
- 失去的担忧反而催他尽情相爱
  - ← 改写：（35–39）「心里就发酸」 —— 失去的可能使他更急于把眼下的爱给足
- 他不愿为了将来少痛就眼下少爱
- 平日让他迟疑的顾虑暂时显得很小
- ⟲ 仍在起作用：（17–23）「还没说清」；（35–39）「不愿松开」

### S08｜62–71 小节　（还说不清）

- 更深的亲近确实给了他想要的快乐
  - ← 提供理由：（51–61）「靠近得更深」 —— 他盼望的更深亲近已经发生
- 有一阵他几乎顾不上别的
- 他觉得自己从未这样满足过
  - ← 提供理由：（51–61）「完整接住」
- 欢喜稍平缓，他心里仍有一处空落
- 他不愿承认自己仍觉得不够
- 他为仍然不满足感到一点委屈
- 他又有些羞愧，仿佛辜负了幸福
- 刚才的亲密仍让他觉得真切
- 他难受于那份充盈不能始终保持
- 他仍有一种自己也说不清的渴
- ⟲ 仍在起作用：（51–61）「暂时显得很小」；（24–34）「往后能否一直如此」

### S09｜72–77 小节　（正在面对）

- 那种渴渐渐让他更难受
- 他似乎已不只想要更多温柔和亲近
- 他得到过那些，不安却没有消失
  - ← 动摇：（62–71）「从未这样满足」
- 他想幸福时不必想到它终会过去
  - ← 唤起：（62–71）「一处空落」
  - ← 改写：（24–34）「往后能否一直如此」 —— 那一瞬的疑问变成了他想摆脱的念头
- 他知道对方多爱他也给不了这一点
- 他知道自己的在乎留不住最好的时候
- 他有些无措
- 他没有理由责怪谁
- 他胸口的舍不得比先前更清晰
- ⟲ 仍在起作用：（62–71）「说不清的渴」；（35–39）「心里就发酸」

### S10｜78–83 小节　（正在面对）

- 无措让他对那个人生出柔软的疼惜
  - ← 唤起：（72–77）「有些无措」
- 他不愿让对方替他承担所有不安
  - ← 提供理由：（72–77）「给不了这一点」
- 他喜欢对方有自己的心意
- 他舍不得让依恋束缚对方
  - ← 提供理由：（40–50）「热烈回应」 —— 他珍惜亲近时不必相互催逼的感觉
- 他不愿束缚对方，心里的眷恋却更深
- 他仍觉得亲近很甜，甜里带一点酸
- 他也喜欢自己能这样爱着对方
- 他因美好不能由自己把握，不知疼惜该落向哪里
  - ← 提供理由：（72–77）「最好的时候」
- ⟲ 仍在起作用：（72–77）「比先前更清晰」

### S11｜84–92 小节　（没在想）

- 重新沉浸在亲近里，他又被欢喜充满
- 难受没使他减少对亲近的向往
- 他如今知道那个人真的能让他这样快乐
  - ← 提供理由：（62–71）「想要的快乐」
  - ← 改写：（1–3）「紧绷松了」 —— 最初轻微的松动已变成确切尝过的快乐
- 先前的疼惜仍在，他却愿继续敞开
- 熟悉的温暖让他想交出整个自己
  - ← 提供理由：（40–50）「放在心上」
- 他不想再藏起最容易受伤的地方
- 快乐重新涌满，他仍愿意领受
- 他仿佛觉得此刻只有爱值得保留
- ⟲ 仍在起作用：（78–83）「柔软的疼惜」；（51–61）「眼下少爱」

### S12｜93–102 小节　（正在面对）

- 亲近带来的快乐压过了旧有顾虑
  - ← 改写：（62–71）「仍觉得不够」 —— 先前对自己所求太多的难堪暂时退下
  - ← 动摇：（4–16）「别人的负担」
- 他惊讶自己竟能喜欢得这样深
- 他平日难放下的计较失了分量
- 他不愿让欢喜有一点减损
- 他恨不得把爱意全部给出去
- 他恨不得接住对方全部的温柔
- 尽情相爱时，他更舍不得这一切
- 那一点不安使幸福显得更珍贵
  - ← 提供理由：（35–39）「格外珍惜」
- 他几乎分不清胸口的热是欢喜还是怕失去
  - ← 提供理由：（62–71）「不能始终保持」
- 他欢喜得近乎疼痛
- 他仍一点也不愿退开
- ⟲ 仍在起作用：（51–61）「完整接住」；（24–34）「往后能否一直如此」；（51–61）「眼下少爱」

### S13｜103–110 小节　（正在面对）

- 这份幸福已深得有些难承受
- 他仍想让幸福继续加深
- 他尤其舍不得自己能这样全心爱着
  - ← 改写：（40–50）「不必防备的自己」 —— 他如今还珍惜自己能毫无保留地爱
- 他从未觉得心里的爱这样丰盛
  - ← 提供理由：（62–71）「从未这样满足」
- 他清楚感到爱如此丰盛也留不住此刻
  - ← 提供理由：（62–71）「不能始终保持」
- 一想到会失去，他已无法轻轻带过
- 那份痛楚没有让幸福变得虚假
- 他连欢喜和不舍中的任何一种都不盼消失
- 他发现舍不得的正是让他快乐的东西
  - ← 说明：（93–102）「幸福显得更珍贵」
- ⟲ 仍在起作用：（84–92）「整个自己」；（93–102）「几乎分不清」

### S14｜111–116 小节　（正在面对）

- 强烈情绪渐渐平缓，依恋却没减轻
- 他已无法像起初那样轻松，仿佛幸福没有代价
  - ← 改写：（1–3）「紧绷松了」 —— 如今的轻松已带着失去的可能
  - ← 提供理由：（103–110）「留不住此刻」
- 他如今爱得更深，也更容易难受
- 得到过的快乐让他无法后悔敞开
  - ← 提供理由：（84–92）「这样快乐」
- 他不愿少爱一点来减少牵挂
- 他不愿因终究留不住就轻看此刻幸福
  - ← 改写：（103–110）「无法轻轻带过」 —— 明知会痛，他仍看重眼前的快乐
- 他甚至比先前更喜欢那个人
- 即使美好时刻不能停留，他仍想完整地爱
- ⟲ 仍在起作用：（103–110）「让他快乐的东西」；（78–83）「眷恋却更深」；（103–110）「继续加深」；（93–102）「不愿退开」
