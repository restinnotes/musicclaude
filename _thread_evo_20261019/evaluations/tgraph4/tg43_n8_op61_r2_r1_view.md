# Op.61｜关系图

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### 1–23　（还说不清）

- 起初，他不知道自己究竟在等什么，心里却有股劲，仿佛放任一些事继续就是亲手承认它们理所当然。
- 可真要把自己投进去，他又觉得会丢下什么。
- → 他试着找一个足以让自己不再犹豫的理由，刚觉得想通，舍不得又浮上来。
- → 他有时几乎相信自己已经想通，过一会儿却连刚才的确信也觉得陌生。
- → 反复摇摆让他难堪，他开始怀疑自己是否非得先把心里一切安排好才肯向前。

### 24–65　（正在面对）

- 他受不了再拿“还没想清楚”当等待理由，便先认下自己能承担的那一份。
  - ← 改写：（1–23）「先理清再向前」
- → 没有保证，牵挂也没消失，可他开始承担自己能做的部分后，真切感到自己有了力量。
- → 他终于能说自己至少愿意尽力，也因发现尚有疑虑仍可行动而骄傲。
- → 投入使他热切起来，付出的过程本身带来快乐，仿佛不满终于有了去处。
- → 他舍得给出更多，甚至有些贪恋倾尽全力的畅快，不再时时审视自己或因软弱停下。
- → 用力到深处时，他偶尔触到心里一小块始终没有跟着昂扬起来的地方。
- → 这点地方虽不妨碍他继续，却让他隐约知道，变得坚决并未照顾到所有牵挂。　✦ 满足照出未满足

### 66–91　（没在想）

- 因为已经认真投入过，他反而能从原先反复自问里松开一点。
  - ← 提供理由：（24–65）「投入带来快乐」
- → 他发现自己也会因不再畏缩而高兴，愿意向前时能感到轻盈。
- → 偶尔忘了自己为何如此用力，他并不觉得自己背叛了什么，那一刻反而像久违的自由。
- → 他顺着这份自由走了一程，没有急着给它更大的意义。
- → 快乐不再那么满时，先前那项决定仍在等他。

### 92–115　（正在面对）

- 他重新面对自己作过的决定，仍愿意坚持，因为它曾把他从动弹不得的犹豫里带出来。
  - ← 提供理由：（24–65）「认下能担之事」
- → 他不愿因心里尚有缺口，就把先前的一切都判作错误。
- → 曾使他昂起头的坚定，此时却无法使他安稳。
- → 每当他想确认自己仍有力量，就会察觉内心另有一种要求无法由力量代替。
- → 他只能带着两种不相称的真实继续：行动值得，行动也不够。　✦ 分清
- → 这个答案让他不愿承认，却已无法继续假装不知道。
- ⟲ 仍在起作用：（66–91）「决定仍在等他」

### 116–147　（正在面对）

- 明知行动不够，他仍不肯撒手。
- → 正因为行动曾救他脱离犹疑，他格外怕眼下的失望意味着自己变了心，于是更用力催逼自己。
  - ← 提供理由：（24–65）「认下能担之事」
- → 心里有难处，他也把它当成可以克服的迟疑；想停一停，又担心那是退缩。
- → 他知道自己正在受苦，却不知道除了坚持，还能怎样对得起最初的决意。
- → 原先让他昂然的要求容不下脆弱，慢慢变成对自己的苛责。　✦ 办法的限度
- → 他想保持坚定，却觉得自己像在勉强一个已经疲惫的人。
- → 他终于不想再证明自己有多坚强了。
- → 暂时放下催逼没有立刻让他安心，却让一直被压住的依恋有了回来余地。
- → 他有些茫然也有些松懈，仿佛终于允许自己承认，除了必须做的事，他还真心舍不得一些东西。
- ⟲ 仍在起作用：（92–115）「行动值得却不够」

### 148–180　（正在面对）

- 他向往一种无需时时防备的生活，珍贵的东西不必靠争夺留下，人也不必不断证明自己值得被爱。
  - ← 唤起：（116–147）「承认自己真心舍不得」
- → 他希望付出更多出于喜欢，靠近什么也不必先做好受伤的准备，他曾自然地相信这种生活可能存在。
- → 这份盼望早已给过他快乐，他知道它并非如今为了逃避才临时编出的安慰。
- → 他曾在其中感到人与生活可以亲近，不必时时用力维持，因此不能把它当作软弱。
- → 他终于肯完整地待在这份盼望里，不再让爱惜先经过责任的审问，也不急着证明它有用。
- → 他不急着问这种生活还能否得到，也不比较它和眼前坚持谁更重要。
- → 他仅仅允许自己这样去爱、去相信，就已经感到深深满足。
- → 他仿佛又能柔软地活着，几乎忘了先前的疲惫，暂时不想离开这份真实的安宁。

### 181–205　（正在面对）

- 正因为这份安宁真实，他渐渐不能满足于只在心里拥有它。　✦ 满足照出未满足
  - ← 提供理由：（148–180）「沉入真实的安宁」
- → 他想到，若那种生活值得爱惜，使它难以存在的事情就不能只靠怀念改变。
- → 他想起，最初不肯被动等待，是因为有些重要的东西不能任其受损。
- → 重新感到它们何以重要后，他又不甘心只是留恋。
- → 他刚沉浸在满足里就忘了尚有必须面对的事，因此懊恼，几乎想责怪自己。
- → 他试着要求自己重新振作，却再也不能像先前那样毫无顾忌地投入。
- → 他充分感到温柔的可贵，如今想到艰难争取，就怕那份温柔会被一点点耗尽。
  - ← 提供理由：（148–180）「沉入真实的安宁」
- → 他怕最后只剩不肯退让的意志，却失去原本让一切值得争取的心。
- → 想到安宁，他舍不得；想到它所受的威胁，他又放不下。
- → 他曾以为找到坚定理由就不会再为难，如今理由更多，他心里反而更难平静。　✦ 知道更多反而更尖锐
- ⟲ 仍在起作用：（1–23）「不肯就此算了」

### 206–213　（没在想）

- 那份温柔又短暂地贴近他，他明知不能一直停留，仍不忍立刻推开。
- → 他想到，既然它确实给过深的满足，每次想起都不必急着拿它审问自己。
  - ← 提供理由：（148–180）「沉入真实的安宁」
- → 他愿意再爱惜片刻，暂时不想那些尚无答案的事。
- → 这点安静仍使他欢喜，只是欢喜里已有不舍。

### 214–215　（正在面对）

- 等这点安静退去，熟悉的迟疑又回来，仿佛走了很远仍回到原处。
  - ← 失效：（206–213）「欢喜里已有不舍」
- → 可他如今知道，自己始终放不下的是什么，迟疑里也有他不愿失去的生活希望。
  - ← 说明：（148–180）「无需防备的生活」

### 216–225　（正在面对）

- 知道自己舍不得什么，并没让他立刻勇敢起来。
  - ← 限制：（214–215）「迟疑里有生活希望」
- → 他无法再只凭决心往前，也无法安心沉浸旧愿，两种办法都给过他东西，也都留下难处。　✦ 办法的限度
  - ← 说明：（24–65）「认下能担之事」
  - ← 说明：（148–180）「沉入真实的安宁」
- → 他希望若还要争取，自己不要忘记为何争取。
- → 他也希望若仍爱惜那份安宁，就别因此放弃面对使它难以存在的事情。
- → 他还不知道怎样才能做到，只反复想着这点微弱的意思。
- → 他心里那种非得舍弃一边才能继续的逼迫，似乎稍稍轻了一些。

### 226–241　（正在面对）

- 他凭着这点尚不牢靠的心意，重新想自己能够怎么办。
  - ← 提供理由：（216–225）「舍弃一边的逼迫」
- → 他亲身体会到，尽力承担能让人重新感到自己有力量，却不能替人消除所有牵挂。　✦ 办法的限度
  - ← 说明：（24–65）「认下能担之事」
- → 他也充分尝过，心中的美好能带来安慰，却不能仅靠这份安慰保护所爱惜的生活。　✦ 办法的限度
  - ← 说明：（148–180）「沉入真实的安宁」
- → 两样收获都是真的，他不愿简单否定其中任何一个。
- → 他想保有无需时时奋力的安宁，却知道为它争取就得承担再次失去安宁的可能。
- → 过去他总因这种难受责怪自己，仿佛坚定的人就不该如此。
- → 他渐渐明白，这些代价源于他珍视的东西不止一种，意志再强也未必能免去。　✦ 选择的代价
- → 他仍会心疼，也希望能有一条不必如此艰难的路。
- → 可他知道，再等下去也不会让那条路自然出现。
- → 若只因害怕损伤珍贵之物便不再争取，所爱惜的也未必能留下。
- → 他不再要求自己先变成毫不害怕的人，允许舍不得、没把握和受苦都存在。
- → 他一点点聚起力量，愿意连同不舍一起往前，不再试图压倒犹豫。
- → 接近真正承担时，他更清楚地感觉自己仍会怕，却不想再让惧怕替自己决定。

### 242–253　（正在面对）

- 他不再等待毫无损失的办法，久违的昂扬终于又回来了。
  - ← 提供理由：（226–241）「代价来自多种珍视」
- → 先前他多少想借坚定证明自己能改变些什么，如今仍愿尽力，却不要求尽力证明自己无所不能。
- → 他知道自己要承担什么，也知道自己为何难以割舍。
- → 那些怕失去、想珍惜的东西，不必藏起来才能显得勇敢。
- → 他愿为真心爱惜的一切负责，因此这次的决心虽热烈，却比最初踏实。
- → 他仍有犹疑，却不再等犹疑消失，才允许自己坚定。　✦ 分清
- ⟲ 仍在起作用：（226–241）「不让惧怕作决定」

### 254–288　（正在面对）

- 带着全部牵挂向前时，他意外地发现旧愿没有变远，反而似乎更亲近了。
  - ← 改写：（242–253）「不等犹疑消失」
- → 他仍盼望人们无需时时防备就能相爱，珍贵的东西也不必靠争夺留下。
- → 他也怀念付出不会耗尽自己、信任无需不断经受考验的生活。
- 过去一想到旧愿，他就想从艰难争取中撤回，仿佛这样才能完整保住它。
- → 如今他深知这种生活多么可贵，反而更不愿任由妨碍它实现的事情存在。
- → 他感到温柔也能成为不肯袖手旁观的理由，若丢掉这种向往，尽力和坚强又为了什么？
  - ← 提供理由：（148–180）「沉入真实的安宁」
- → 他仍想要无需拼命就能好好生活的日子，却愿意承认，为了珍惜它，有时不能停在安宁里。
- → 他清楚，投入再多也未必更接近旧梦，怀着美好愿望也不能保证每份付出都值得。
- → 他仍须留心争取会不会损伤所爱之物，这些顾虑也提醒他该怀着怎样的心坚持。
- → 他重新理解这份希望后，感到比先前更宽广的喜悦。
- → 曾分头拉扯他的两股心意，此刻竟能共同支持他。
  - ← 改写：（226–241）「承担带来力量」
  - ← 改写：（226–241）「美好能安慰却难保护」
- → 他不必因依恋而羞于向前，也不再因责任而厌倦保有依恋。
- → 他重新尝到最初相信生活时的快乐，但历经怀疑与疲惫，这份快乐已不再理所当然。
- → 喜悦平静后，他仍没有答案，也不能保证自己的承担足以改变什么。
- → 他并未回到无需防备的生活，往后也仍可能疲惫，或因必须付出的代价而动摇。
- → 他即使愿意同时带着两种渴望，它们仍可能彼此牵制。
  - ← 限制：（226–241）「承担带来力量」
  - ← 限制：（226–241）「美好能安慰却难保护」
- → 他不再急着用一种满足遮盖另一种需要，也不因某种需要未满足就否定已有所得。
- → 过去的快乐、失望、疲惫和依恋仍属于他，也让他看清什么值得付出、什么不能轻易牺牲。
- → 他仍向往安宁，也愿意行动，却不知道最终能留下多少珍贵的东西。
- → 他不愿再靠忘掉其中任何一边，换来片刻不必为难自己的感觉。
- → 他愿意带着这份仍未消失的不舍继续向前。
- → 这一次，他不再需要为自己继续向前反复寻找证明。
- ⟲ 仍在起作用：（148–180）「无需防备的生活」；（226–241）「代价来自多种珍视」
