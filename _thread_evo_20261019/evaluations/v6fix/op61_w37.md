# Op.61｜关系图（在 v6 上修补，w37）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他还不知道自己究竟在等什么，只是不肯就此算了。
- → 他怕照旧就等于认定这一切本该如此，也怕投入会失去别的东西、再不能回头，便想停一停。
- → 熟悉感一回来，他就想继续，可过去不会因此回来，他还要找理由才敢往前。
- → 每次刚觉得想通，舍不得又回来，连确信也变陌生，他为非得想透才肯动而难堪。

### S02｜24–65 小节　（正在面对）

- 他没想透值不值，结果也没把握，却不再等算清才动，接下能做的事，尽力去做，渐渐有了力气和骄傲。
  - ← 改写：（1–23）「非得想透才肯动」
- → 他发现投入本身让他快乐，愿意给得更多，贪恋倾尽全力的畅快，不再时时审视自己或因一点软弱停步。
- → 投入越让他高昂，心里仍有一小块没跟着振奋，因为还有别的牵挂没得到照顾。
- → 他投入得越深，越怕最后仍是白费，便一遍遍说服自己别退，想尽快证明这一步没选错。
- ⟲ 仍在起作用：（1–23）「照旧就等于认了」

### S03｜66–91 小节　（正在面对）

- 他偶尔闲聊或散步，暂忘为何用力，却不觉得这背弃了尽力的决定，也不急着解释。
- → 他想要自在亲近、不必时时防备的生活，却找不到过法，仍不甘心，想到它时还会松口气。
  - ← 说明：（24–65）「没跟着振奋」
- → 快乐渐淡时，难处还在，他想到实现这愿望，便想起曾决定尽力，疑心那股劲是否真心。
  - ← 动摇：（24–65）「不再等算清」

### S04｜92–115 小节　（正在面对）

- 他尝过自在亲近的快乐，那次决定让他走出动弹不得的犹豫，虽知坚定靠努力撑着，做得不够仍觉那步没白走。
  - ← 提供理由：（24–65）「不再等算清」
- 他怕停下就得承认亲近回不到从前，便硬撑着不肯停，反复追问过去还能怎样，却仍无法安心。
  - ← 限制：（66–91）「自在亲近」

### S05｜116–147 小节　（正在面对）

- 行动明明还不够，他仍逼自己不松手，怕承认失望就是变心，也怕停下会辜负最初的决意。
- → 他怕一软就停步，不肯放下那份曾让他骄傲的要求，渐渐容不下脆弱，难受也怪自己不够坚定。
- → 他明知自己正在受苦，却把难处当成还要克服的迟疑，越想坚持越逼自己。
- → 他发现自己还在逼自己坚持，便不想再证明自己有多坚强。
- → 他不再逼自己坚持，却没因此安心，才承认自己舍不得那种不必防备的亲近。
  - ← 提供理由：（66–91）「自在亲近」
- ⟲ 仍在起作用：（24–65）「不再等算清」

### S06｜148–180 小节　（没在想）

- 他舍不得的不是一时舒服，而是曾真心相信、也真正快乐过的生活。
- → 他不愿把这份向往说成软弱，因为他想要珍惜不必争抢，付出只因喜欢，也不必证明自己值得被爱和接纳。
  - ← 改写：（116–147）「曾让他骄傲」
- → 他暂时不再担心心里一软就会停步，才肯承认自己也有委屈和思念。
  - ← 提供理由：（116–147）「证明自己有多坚强」
- → 他重新允许自己相信这份向往值得珍惜，不急着求它实现或证明有用，便感到满足和安宁，一时也不想离开。

### S07｜181–205 小节　（正在面对）

- 熟悉的亲近让他觉得向往的生活近在眼前，可现实没变，他懊恼自己又沉进去了。
- → 他认出当初那份不再等待、主动争取的决意又回来了，因为他仍想让向往的生活成为现实。
  - ← 唤起：（24–65）「不再等算清」
- → 安宁越真切，他越不能只满足于心里拥有那种生活，因为这反而提醒他愿望还没实现。
- → 他当初不肯再等，是怕珍惜的东西继续受损，光在心里想着那种生活也护不住它们。
- → 他仍怕一旦重新投入，反而会失去珍贵的东西，这份顾虑始终没有消退。
- → 他原以为理由越充分越能安心，如今经历越多、理由越多，反而越难安定。
- → 他如今还怕争取到最后只剩硬撑的意志，却连觉得这种生活值得争取的心也没了。
- → 他想重新投入，却怕耗尽刚找回的温柔，也怕顾不上想留住的生活，不知怎样争取才不伤这份温柔。
- ⟲ 仍在起作用：（1–23）「照旧就等于认了」

### S08｜206–213 小节　（没在想）

- 他想到那种生活确实给过自己满足，便不必每次想起都立刻审问自己。
  - ← 提供理由：（148–180）「满足和安宁」
- → 他知道那种生活还没真正过上，便不能在这份安宁里久留。
  - ← 限制：（181–205）「心里拥有」

### S09｜214–215 小节　（正在面对）

- 他知道自己想要自在亲近的日子，却不知怎样才能过上，也不愿拿这份盼头去冒险，便迟迟不敢再试。
- ⟲ 仍在起作用：（181–205）「刚找回的温柔」

### S10｜216–225 小节　（正在面对）

- 他暂时提不起劲争取，也无力逼自己改变，却说不清为何仍舍不得当初那一步和安宁。
- → 他知道尽力曾帮他走出犹豫，如今却让他难以继续，若再争取就得面对当初不肯等的理由。
  - ← 提供理由：（181–205）「珍惜的东西」
- 他知道向往的生活曾给他安宁，可威胁它的事还在，珍惜这份安宁也不能把那些事放下。
- → 他还不知道往后怎么过，仍反复想究竟想护住什么，歇一歇不等于放弃，也不急着在争取和安宁间选边。
- ⟲ 仍在起作用：（181–205）「刚找回的温柔」

### S11｜226–241 小节　（正在面对）

- 他知道争取给过他力量，却消不掉所有牵挂，心里的安宁也是真的，却护不住现实中珍惜的东西。
  - ← 提供理由：（24–65）「没跟着振奋」
- → 他发现争取和安宁难以两全，难处不只是自己不够坚定，而是珍惜的东西不止一样，便重新想还能承担什么。
  - ← 说明：（216–225）「威胁它的事」
- → 他怕争取会伤到珍惜的东西，心里仍疼，也知道若只因害怕而不争取，未必留得住它们，还可能让它们继续受损。
- → 他知道再等也不会等来容易的路，便带着不舍和痛苦继续争取，不再要求自己先不害怕。

### S12｜242–253 小节　（正在面对）

- 他知道眼下该做什么，能做多少先做多少，不再要求每分努力都证明一切能改变。
- → 他不再把脆弱和牵挂当成行动的拖累，久违的昂扬又回来。
  - ← 改写：（24–65）「没跟着振奋」
- → 真要继续争取时，他仍怕努力伤到所爱，便又迟疑了一下。
- ⟲ 仍在起作用：（226–241）「心里仍疼」

### S13｜254–288 小节　（正在面对）

- 他曾以为退回安宁就能守住那种生活，如今越知它可贵，越想靠行动让它成为现实。
  - ← 提供理由：（226–241）「心里仍疼」
- → 他发现眼前行动也在替那种生活争取，想珍惜它的心愿和责任感都推着他往前。
- → 他不必因为心里有责任就厌倦这份生活，也不必因仍然依恋它而羞愧。
- 他觉得那份向往近了些，又重拾当初相信它时的快乐，经历过怀疑和疲惫后更知这份快乐难得。
- → 他知道愿望未成也没抹掉那份快乐，可心里的满足终究代替不了真正过上那种生活，便不再沉在满足里。
- → 他发现那份向往和眼前行动都能推他向前，却也可能彼此牵扯，仍不知道自己最终能守住多少。
- → 他愿为那种生活吃苦，却知道付出再多也未必更靠近它，不能认定每一分付出都值得。
- → 他得留心别在争取时把所爱耗尽，真要付出代价时，他仍可能因难以承受而想退回安宁。
- → 他已知道自己想要那种生活，不必再靠争取证明心意，做完眼下能做的便可歇下。
  - ← 改写：（216–225）「歇一歇」
