# si_n6_op61_IA_rs_r2_r2

### 1–23

**他开始察觉，自己坚持时既在保护自我价值，也在抵抗曾接纳他的世界已经不再给他位置。**
→ 两种愿望都无法马上满足，他既不想让失去击垮自己，也舍不得放下过去，只能先寻找自己还控制得住的事情。

### 24–65

**他把注意力转向克制、庄重和共同准则，借自己仍能做到的事重新站稳。**
◎ 共同价值过去曾让他清楚自己是谁，也让他知道自己为何值得被尊重；失去原来的位置后，他自然又从这些准则里寻找确认。
→ 这些做法让他重新感到自己能够掌握自己的行为，但他仍不知道，那个曾经接纳他的世界是否还给他留着位置。

### 66–91

**他发现，自己已经能够维持自尊，心里却仍然焦躁，因为他不知道别人是否还认他。**
← 克制只能约束自己的行为，不能替对方作出回应；原来关系中的空缺依旧存在，他也就无法靠自己的坚定消除等待。
↺ 原以为只要守住共同准则，就能重新确认自己的位置，现在他看见，自己仍在等别人记得他、认出他。
→ 他需要弄清自己放不下的究竟是什么：一个值得维护的名号，还是曾经真切接纳过他的生活。

### 92–115

**他开始从过去的具体经历里辨认自己失去了什么，想念有了清晰的内容。**
◎ 他曾经无需反复解释就能被理解，也曾自然地拥有自己的位置；这些经历如今让他确认，那份温暖确实发生过。
↺ 原以为自己放不下的只是一个值得维护的身份，现在他知道，自己怀念的是曾经被理解、被接纳的日子。
→ 过去确实给过他位置，却无法证明那个位置今天仍然存在；他开始面对记忆与眼前现实之间的距离。

### 116–147

**他不再把自己的愿望藏在对共同准则的坚持里，开始承认自己想被记得、被认出，也希望对方主动回应。**
← 他已经看清，自己失去的包含一段曾经真实存在的关系。即使他始终珍惜过去的价值，也无法独自确认对方是否还愿意接纳他。
↺ 原以为守住过去留下的价值就足以让自己站稳，现在他看见，自己还需要知道对方是否记得他，是否仍愿意给他留出位置。
→ 他可以承认自己在等，却不能决定答复何时到来，也无法保证对方仍愿意回应；没有保证的等待让他再次感到无力。

### 148–180

**他开始允许过去留在心里，不再逼自己马上追回原来的关系，也不必靠贬低过去来接受眼前的变化。**
← 他已经确认，那些被理解、被接纳的日子确实存在；但对方现在如何看待他，并不由他的怀念决定。
↺ 原以为接受失去就得把过去放低，现在他可以继续珍惜那段经历，同时承认原来的关系尚未恢复。
→ 暂时不再追问，让他获得了一些平静，但他还不知道这份平静能否帮助他面对仍然没有答案的现实。

### 181–205

**他看清，记忆能够留下过去给予他的温暖，却无法让眼前的关系重新向他敞开。**
← 正因为过去确实有人理解他、接纳他，现在缺少回应的感受才如此清楚。记忆让他保住了对来处的认识，也让他更清楚自己仍然没有得到什么。
↺ 原以为只要确认过去真实存在，就能靠这份记忆承受失去，现在他发现，自己仍然需要眼前的人给出回应。
→ 过去已经有了明确的位置，现实中的问题却没有消失；如果记忆不能替对方回答，他是否仍愿意面对自己正在等待？

### 206–213

**他重新承认自己仍然期待回应，也开始正视这个期待可能落空。**
← 此前的平静解决了他是否应该怀疑过去的问题，却没有改变现在的关系，也没有让他知道对方是否还记得他。
↺ 原以为保住过去的真实就能找到足够的答案，现在他知道，自己仍在等待一个无法由自己决定的答复。
→ 想到期待可能没有结果，他又开始担心主动需要回应会让自己暴露在拒绝面前，熟悉的强硬姿态因此重新变得有吸引力。

### 214–215

**面对可能落空的期待，他本能地想恢复强硬和自立的姿态，把自己对回应的需要藏起来。**
← 当他无法控制对方的态度时，熟悉的防御方式让他暂时把注意力转回自己，试图减少等待带来的无力感。
→ 但他已经知道，自己能够站稳，并不能让别人重新认出他；这次强硬能否让他不再期待，仍然没有答案。

### 216–225

**他发现，自己仍然怀念那个曾经接纳他的世界，这份感情来自过去真实给予过他的温暖。**
← 强硬能够暂时遮住他的需要，却无法改变那些经历对他的影响；他仍然在意，是因为那段生活曾让他自然地感到自己被理解。
↺ 原以为承认怀念会显得软弱，现在他发现，自己可以维护自尊，也可以承认仍想得到回应。
→ 既然他不必再否认自己的需要，接下来就要面对另一个问题：他怎样珍惜过去，又不让往后的人生一直停在等待里？

### 226–241

**他开始看见，若总用强硬压住自己的需要，他就难以面对真实的感情；若一直停留在过去，眼前的生活也会被等待拖住。**
← 他无法替对方恢复原来的关系，而曾经被接纳的经历又确实重要，所以他很难彻底放下期待，也很难说服自己从此不再怀念。
↺ 原以为找到一种坚持到底的方式就能保护自己，现在他意识到，反复压住需要或一味回望过去，都可能让他迟迟无法决定眼前该怎样生活。
→ 他需要找到可以实际做到的方向：保留过去对他的意义，允许自己仍然受伤，同时不再把生活的开始交给一个未知的答复。

### 242–253

**他重新把共同价值用在眼前的选择和责任上，允许自己带着尚未消退的伤痛继续行动。**
← 这些准则过去帮助他确认自己珍视什么，如今仍然值得实践；但他已经知道，按这些准则生活，无法换来对方的回应。
↺ 原以为实践共同准则能够把自己带回原来的位置，现在他开始按照自己珍视的价值决定怎么做，不再把每一次行动都当成换取接纳的办法。
→ 他已经能够在没有完全恢复的情况下继续生活，下一步是重新面对现实中的人群，不再要求自己先获得旧日的位置才有资格向前。

### 254–288

**他开始带着怀念和仍未满足的需要重新面对生活，不再等那个曾经接纳他的世界恢复原样后才肯往前走。**
← 他无法决定对方是否还会记得他，却可以保留过去给予他的温暖，继续实践自己珍视的价值，并承担眼前的责任。
↺ 原以为必须先得到回应，自己才能放心继续生活；现在他仍然希望被记得，也允许这个愿望暂时没有结果，不再让它决定自己能不能开始下一步。
→ 他以后仍可能等不到回应，也可能再次因失去而难过。新的变化在于，这些感受出现时，他仍然能够决定自己接下来要做什么。
