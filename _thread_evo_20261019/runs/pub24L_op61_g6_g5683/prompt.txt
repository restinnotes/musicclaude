请阅读下面这段中文。

它是一条跟随音乐发展的“线”：写的是一个人在这首曲子里经历的一件事，按段写成条目。〔〕表示这句话提到的前文出处。这段文字会和音乐听感记录一起给读者看，希望读起来像一个人在平平常常地讲自己的经历。允许含蓄，不要求补造具体人物、事件或场景。

请作为第一次读到它的普通中文读者，独立评审它的语言质量。你不知道作者此前修改过什么，也不要预先假定它有哪些毛病。

评审分成三个步骤：

第一步：连续阅读整篇。

先从头到尾阅读，把它当作一段完整的叙述，而不是一组需要逐句批改的句子。

注意实际的阅读体验：哪些地方自然流畅，哪些地方读着费劲，整篇读完后有没有留下明显的不舒服、不顺畅或者单调的感觉。

此时先不要着急改写句子，也不要预设问题类别。

第二步：检查局部语言。

逐处指出真正读起来不通顺、不像人话、让人别扭或需要停下来想一想的表达。

每处引用原文，说明为什么不自然，并给一个更自然的说法。

只指出实际存在的问题。没有问题的地方不用提，不要为了凑数挑毛病。

改写时尽量保留原句的意思、人物的心理区别和前后关系，不要为了让句子好听而擅自改变人物经历。

第三步：独立检查整篇的累积效果。

这一步很重要。请暂时放下第二步挑出的具体问题，重新从头到尾看整篇。

检查是否存在这样的情况：某一种写法单独出现时并没有明显错误，甚至完全自然，但在多处反复出现之后，让整篇的阅读体验变差。

不要只寻找单句中的错误，也不要只把第二步的问题重新归纳一遍。要真正检查连续阅读时产生的效果。

对于发现的每一种累积性问题：

1. 引用多处原文作为证据。如果问题跨越全文，尽量选取不同段落的例子；如果问题集中在同一小节，可以引用几句相邻的原文。
2. 解释为什么这些表达连起来会造成问题。不能仅仅因为某种写法出现次数多，就认定它不好。
3. 区分这种写法在哪些情况下本来是自然、必要或有效的，哪些地方才是真正多余或影响阅读的。不要把所有相似表达一律判错。
4. 说明这种累积问题的实际影响有多大，是轻微、中等还是严重。
5. 如果值得修改，提出具体的改进方向，并选择一两个代表性位置示范改写。不必机械地修改所有同类表达。

不要预设必须找到多少种累积性问题。某一种写法反复出现也可能完全合理，甚至是叙述所需要的。如果没有充分证据，就不要把它列为问题。

最后作出整体判断。

给语言质量打 1–10 分。

说清楚最影响阅读体验的是什么，哪些是次要问题。不要因为某类问题比较容易统计、比较容易举例，就高估它的重要性。

请特别注意：局部语言问题与全文累积问题是两种不同的判断。前者需要证明那句话本身不自然；后者需要证明多处表达连起来产生了不理想的效果。一种表达即使单独没有问题，也可以成为累积问题的证据，但必须讲清楚累积影响。

感受：突然像失重，整个人悬在半空。 / 辨不清方向，脚下也没了着落。 / 声音零碎地飘着，身子也像飘着。

### S11（屏幕停留 22 秒）
话：明知回去未必找得回那份亲近，他还是忍不住想：万一能呢？
感受：低处像涌起一阵阵沉重的浪。 / 重重砸下，又把压力推得更高。 / 爆发之后，紧张一次也没真正解除。
话：但他不想只凭这点指望，就回去过总要忍让的日子。
感受：不像顺境里的凯歌，更像困兽一次次顶住。 / 脚步起先还在试探前面有没有路。 / 不是忽然就有了整齐坚定的步伐。
话：回不回去以后再定，先把眼下的日子过稳，兴许更踏实。
感受：步子慢慢聚拢，前进终于难以回避。 / 像把先前私下的祈求，带回能迈步的节奏。 / 祈祷还在，却开始变成意志。
话：他仍怕往后得独自扛，却不愿再因害怕收回这个打算。
感受：害怕没有消失，脚却已经向前走了。 / 问题还没解决，停滞却松开了一点。 / 紧张依旧在，却有了一点奇特的解脱。

### S12（屏幕停留 25 秒）
话：他承认当初那些气不该忍，和那些人在一起也确实开心过。
感受：熟悉的步态突然以雷鸣般的声势回来。 / 沉重的一步终于踏实落地。 / 气势一下占满眼前，把人推着向前。
话：想起好时候仍会心软，也怕孤单，可他不再怪自己离开。
感受：站直身子，是经历摇晃之后的选择。 / 不必假装自己从来没有受过伤。 / 这次的昂扬，像要让外面所有人听见。
感受：有种面向众人的声势，不再只是私下挺住。
话：他不愿只为有人陪就回头，愿意带着想念继续过日子。
感受：向前的地面忽然像斜了一下。 / 脚步晃过那一下，却没有因此停住。

### S13（屏幕停留 62 秒）
话：又想起从前自然亲近的日子，他心里重新热了起来。
感受：先前低声的安慰，忽然来到开阔明亮处。 / 像温柔的歌，被带进庄严庞大的声浪。 / 甚至像一座管风琴在放声歌唱。
感受：柔软没有被力量压下，反而一同冲向高潮。 / 仿佛心脏正在用尽全力跳动。 / 也让人想起故土、共同的记忆与希望。
话：他也盼着以后，还能遇到那种自然亲近的相处。
感受：密集的声音，像激流一下喷向高空。 / 明亮的疾驰，忽然把积攒的劲放出来。 / 像被一股气流推着，身体不由得往前跑。
话：这么想着，他真有了劲，想把往后的日子好好过起来。
感受：冲得太快，兴奋得几乎来不及喘息。 / 那一刻不只是大声说话，简直在奔跑。
话：他不想再一天到晚，跟从前那些事较劲了。
感受：狂奔渐渐收住，声音也重新有了空隙。 / 细小的颤动，又悄悄带回一丝不安。 / 仿佛有人问：刚才的踏实真的牢固吗？
话：劲头稍缓，他想到往后仍会孤单，不知何时才有人亲近。
感受：像事情说完了，终于可以喘口气。 / 从容可以和一点点疑虑同时存在。 / 安静下来，也不等于疑问已经消失。
话：要是以后有人真把他当自己人，他会好好珍惜。
感受：狂潮退去，喧嚣像忽然静止。 / 低处沉沉吐出两声耳语般的和弦。 / 仿佛呼出了最后一口气。
话：即使一直没有，他也愿意好好过，不再为留住谁忍下委屈。
感受：高处忽然亮起，像一颗透明孤悬的寒星。 / 又像一记清脆的钟响，留在空中。 / 低处轻声与高处亮光，隔得那么鲜明。
感受：也可听作一个终于落定的决定。 / 或像一个人忽然从梦中醒来。 / 结尾的力量，并不全靠更猛烈地敲击。
