一、先建立整条经历

选择一条人物经历作为主体。
可以吸收其他候选中相容且有根据的内容，
但成品必须是同一个人经历的同一件事。

从开头到结尾保留人物已经获得的历史。

区分：
- 已经发生或已经知道的；
- 此刻只是感觉到或猜测的；
- 想要但尚未得到的；
- 已经作出、不能再次当作新决定的选择；
- 至今没有得到回答的问题。

任何新的认识，都不能抹掉以前已经成立的内容，
除非此前的经历给出了改变它的理由。

二、人物自己推动

每个真正的变化必须有人的前因。

前因可以来自相邻段，也可以来自很早以前。
前因应该说明此刻为什么会有这种感受或回应，
而不仅是两段在讨论同一个主题。

一份经历可以在后来产生不同作用，但必须交代
人物此刻比上一次多经历了什么、知道了什么，
或对同一件事产生了怎样不同的感受。

不要求每段取得新的认识，不要求每段有行动、
办法、失败、突破或决定。

某段如果只是继续享受、继续在意、暂时走神，
就直接写这种经历，不额外制造一次心理进展。

不要靠反复否认、重新接受、再次决定同一件事
来形成推进感。

三、保留情绪的实际经历

写清他具体向往什么、舍不得什么、怕什么、
有什么让他高兴或难受。

可以写复杂的心理关系，但要用人平常能理解
的说法，让关系出现在具体感受和经历里面。

不要连续用心理分析、抽象标签、自我评价或
哲理判断代替实际经历。

不要为了使文字显得具体而编造新的外部事件、
人物行为、对白、物件或场景。

不禁止自然的人类感受和持续处境，
但不能借用音乐的画面、比喻和情节。

四、与珠子相接

覆盖诊断中的体验性质是适配要求，
不是人物经历的事实清单。

尽可能让同段的人物处境自然具有这些性质。
允许一份人物经历同时支持几种相容的体验。

不要为了逐颗对应而不断添加新的心理动作、
认识或故事事实。

如某个覆盖要求与整条经历的因果、自足性冲突，
优先保持真实的经历，留下这个覆盖缺口。

不得仅把珠子的体验性质换一种说法写成条目。
要写人物为什么处于那样的境地。

五、关系图

按指定段落顺序输出。

每段通常写2–4条。
一条包含一份完整、可自然说出的意思。
相关的原因和感受可以放在同一句里。
不同的事情才分成不同条目。

短段如果内容少，就用短句。
不要为了达到相同长度而补内容。

每条只写自己此刻需要说的内容。
前文已经充分说过的事实，可以具体引用，
不必完整重述。

跨段引用 cite：
- 只能指向此前实际写出的条目；
- 只有确实提供理由、前提或改变当前理解
  的前文，才允许引用；
- 主题相近不构成引用理由；
- 引用必须具体到条目；
- 不能用引用来掩饰当前缺少前因；
- 不要求每段都强制出现引用。

段内关系 after：
- 只在当前条目确实由同段此前条目引出时填写；
- 不因相邻就自动关联；
- 每条文字本身仍需独立可读。

不标关系类型。
引用只表示实际存在的内容联系。

六、每段与 Center 的关系

每段标注下列状态之一：

还说不清：他受这件事牵动，但此刻还不能
说清自己面对的是什么。

正在面对：他正在想着、处理、回应或明确
承受这件事的困难。

没在想：他此刻沉浸在别的感受或生活经验里，
没有在权衡整件事的困难。

根据最终写出的正文判定状态，不继承候选标签。
不要为了让三种状态分布均衡而修改正文。

标为没在想的段落，不能同时让人物明确思考
整件事的中心难题。

七、Center
Center 已经给定：亲密的幸福与留不住它的痛楚难以分开
不改写它，输出的 center 字段原样填入。它是回头看整首时把各段组织起来的那件事，不预告路线，不是每段都要回应。不要为了符合它，在后半篇反复证明同一结论。

八、语言

统一第三人称“他”。
句子完整自然，像在平常地讲一个人的经历。

不使用电报式、省略过多的提纲语言。
也不使用心理报告、哲理总结和刻意整齐的句式。

不机械禁止某个字或句式。
重复用词和句式只有损害阅读时才需要改变。
优先保证内容准确，再考虑表达变化。

不要让每段结尾都成为一句总结。
结尾写他走到这里实际还有什么、
改变了什么、什么仍不知道。

九、输出

只输出 JSON：

{
  "center": "完整关系句",
  "segments": [
    {
      "sec": "S01",
      "bars": "该段小节范围",
      "relation": "还说不清/正在面对/没在想",
      "items": [
        {
          "id": "S01-1",
          "text": "条目正文",
          "cite": [],
          "after": []
        }
      ]
    }
  ]
}

全部段落必须覆盖。
id 按最终顺序稳定编号。
cite 只允许引用更早段落的 id。
after 只允许引用当前段更早条目的 id。

不增加 key、kind、关系类型或文字解释。
不输出分析过程、覆盖说明或附加散文。
