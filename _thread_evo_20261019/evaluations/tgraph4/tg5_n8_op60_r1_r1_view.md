# Op.60｜关系图

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3　（还说不清）

- 他心里有了一个格外想亲近的人，想到对方就会不由自主地柔软。
- → 他想让这份感觉多停留一会儿，却又本能地把心往回收。
- 眼下并没有什么事逼他作决定，他也说不清自己为何这样谨慎。
- 这份喜欢轻得仿佛随时能放下，他却偏偏舍不得放下。

### 4–16　（正在面对）

- 他还不知道自己怕什么，便不急着决定这份在意要走向哪里。
  - ← 提供理由：（1–3）「说不清为何谨慎」
- → 他不必现在弄清两人以后怎样，也不必因为喜欢就向对方期待什么。
- → 他喜欢自由地给予温柔，不必时时确认对方有没有领受。
- → 他发现认真在乎一个人也可以自在，不必因此抓住对方。
- → 这份快乐让他不再提防自己的喜欢，也有些满意自己能如此宽和。
- → 他希望亲近一直这样自然，不用追问计较，当时觉得这样已经足够。

### 17–23　（正在面对）

- 因为这份亲近已让他尝到幸福，他开始希望喜欢不只属于眼前。
  - ← 提供理由：（4–16）「不再提防喜欢」
- → 他能决定怎样珍惜对方，却不能决定对方是否同样珍惜自己。
- → 原先无需确认的事，此刻竟开始牵动他的心。
- → 他偶尔忍不住想，自己在对方心里是不是也很特别。
- → 只多了这一点期待，他就不再像先前那样安稳。
- → 他有些意外，原来已经令人满足的亲近仍会让人盼望更多。　✦ 满足照出未满足

### 24–34　（正在面对）

- 他不愿让新添的紧张毁掉先前的快乐，也不想让喜欢变成对方的催促。
  - ← 提供理由：（17–23）「期待打破安稳」
- → 他提醒自己，珍惜一个人可以是关心、给予、为对方高兴，不必索取保证。
- → 这样想确实让他轻松下来，也让他更愿意付出，不再衡量心意多少。
- → 他为这种毫不勉强的热切感到幸福，仿佛心里的温柔终于能尽情给出去。
- → 那一阵他甚至相信，只要不提出要求，就能尽情去爱而不会失去什么。

### 35–39　（还说不清）

- 欢喜稍退，他仍想知道自己是否也被对方放在心上。
  - ← 动摇：（24–34）「无要求就无损失」
- → 这个念头让他难堪，他开始怀疑体贴里是否藏着不愿承认的期待。
- → 他觉得自己若认定毫无所求，已不够诚实，却也知道先前的快乐并非为了换取对方的珍惜。
- → 他暂时答不出，只让自己留在不自在里，不急着辩解或用热烈遮过去。

### 40–50　（没在想）

- 这份难堪没有让他不再喜欢，却让他不愿再用慷慨证明自己。
  - ← 提供理由：（35–39）「停在不自在里」
- → 他不想时时检查对方是否在意，也不愿逼自己变成毫无期待的人。
- → 他只留心此刻愿意给予的关切，安静惦念对方、盼对方好，不再拿这些心意去猜两人有多亲近。
- → 有些快乐只需留在心里就已鲜明，他觉得细细喜欢一个人本身很甜。
- → 他暂时顾不上对方是否同样在意，先享受心里的甜意，先前的疑问仍未解开。

### 51–61　（正在面对）

- 这份不声张的甜意留得久了，喜欢已不像起初那样轻巧。
  - ← 改写：（40–50）「细细喜欢很甜」
- → 他对对方的珍惜渐渐加深，心意难以收放，常常满心惦念，也盼关切被领会。
- 他仍觉得不催促对方是对的，舍不得用自己的期待换来别人的迁就。
- → 为了不让对方为自己的期待为难，他只能独自想着那些还不知道会不会实现的愿望。　✦ 办法的限度
- 他不觉得这份喜欢不值得，因为它曾带给他细细的甜蜜，他舍不得减轻。
- ⟲ 仍在起作用：（24–34）「不想让喜欢变催促」

### 62–71　（正在面对）

- 这份喜欢已经很深，他忽然不想再把它看成必须小心收住的心思。
  - ← 提供理由：（51–61）「盼关切被领会」
- → 他发现此前感到的幸福，并不是靠对方给出承诺才发生的。　✦ 分清
  - ← 说明：（4–16）「不再提防喜欢」
  - ← 说明：（24–34）「慷慨喜欢的幸福」
  - ← 说明：（40–50）「细细喜欢很甜」
- → 即使仍有期待，他也不觉得自己的幸福因此可疑，不愿因怕受伤而小心翼翼地高兴。
- → 他想让自己充分地喜欢一次，不急着追问结果，也不先替以后安排退路。
- → 他不再衡量自己给了多少，也不再每当心意深一点就提醒自己收回。
- → 有一阵欢喜真的压过顾虑，他知道没有保证，却几乎感觉不到这件事带来的不安。

### 72–77　（正在面对）

- 欢喜稍退，他才发现自己想从这份亲近里得到什么已不能含糊过去。
  - ← 唤起：（62–71）「充分喜欢一次」
- → 他不只想尽情喜欢，也想知道对方是否同样渴望靠近。
- → 他明白自己喜欢得很深，却不能因此要求对方也用同样的热烈来爱他。　✦ 分清
- 他怕退回先前的谨慎，会辜负刚刚才敢承认的心意。
- 继续盼望下去，他又怕分不清自己是在爱对方还是要对方满足自己。
- → 他想不出兼顾两边的办法，心里委屈，也厌倦反复为难自己。

### 78–83　（正在面对）

- 他终于不再逼自己立刻选择，暂时不决定什么。
  - ← 提供理由：（72–77）「找不到两全办法」
- → 他不必因想靠近就立即向前，也不必为了不催促对方而把眷恋压得看不见。
- → 两种心思仍都在，他可以带着愿望安静喜欢，也承认自己没有把握。
- → 这样暂时放过自己让他松了一点，为难仍在，却不必时时和它争执。

### 84–92　（正在面对）

- 不再逼自己消除渴望后，他重新尝到亲近一个人的快乐。
  - ← 提供理由：（78–83）「暂时放过自己」
- → 这次的快乐已经不同，他尝过期待的紧张和难堪，却仍然愿意喜欢。
- → 他不必再靠压下期待来证明自己体贴，也不因想被珍惜就怀疑自己的真心。　✦ 分清
  - ← 改写：（24–34）「无要求就无损失」
- → 他愿意全心投入，不再躲避自己喜欢得有多深，也不再为自己的热切羞怯。
- → 他为自己仍能如此高兴而感动，也发现那些曾让他警惕的愿望可以和喜欢并存。
- → 他知道自己仍可能受伤，却依然愿意充分承认这份幸福。
- ⟲ 仍在起作用：（72–77）「深情不要求同样热烈」

### 93–102　（没在想）

- 他不再遮掩渴望后，更清楚自己有多想和这个人亲近。
  - ← 提供理由：（84–92）「不靠压下期待证明」
- → 他想让积攒的温柔被对方珍惜，让亲密不只停在自己的愿望里。
- → 他想知道两人能共同拥有的幸福究竟可以有多丰盛。
- → 那些曾让他紧张难堪的愿望仍在，此刻却暂时不再让他觉得缺少什么。
- → 他感到自己有许多感情可以给予，甚至觉得已经没有什么需要增加。
- → 想靠近、想被爱、想全心交付的心愿仿佛一齐得到抒发，他感到一阵强烈得几乎难以平复的满足。
- → 他没有得到新的保证，却觉得这样爱着已让生命充实，一时顾不上以后。

### 103–110　（正在面对）

- 他此刻才更清楚，心里的满足仍缺少对方同样深切的选择。　✦ 满足照出未满足
  - ← 说明：（93–102）「一时顾不上以后」
- → 他可以充分拥有自己的深情，却无法凭它得到对方同样深切的选择。
- → 这份酸楚没有推翻欢喜，反因欢喜如此真实而更难忽略。
- → 他知道自己爱得多深，已不能再轻易说对方是否珍惜自己都无所谓。　✦ 知道更多反而更尖锐
- → 他不愿把自己能否安心全交给对方决定，也不想让对方负责消除自己的不安。
- 他也不愿因怕得不到，就故意削弱那些曾给他巨大幸福的感情。
- 他知道克制曾让他安心，却没有使渴望消失。
- 尽情投入确实让他幸福，却不能让失望从此不再可能。
- → 他终于明白，单靠克制或尽情投入，都不能让他既不受伤又不压下感情。　✦ 办法的限度
- → 两种心思都没有退让，他也更难假装自己只在意其中一边。
- → 他宁愿暂时不轻松，也不想为了求轻松而舍弃其中一边。
- ⟲ 仍在起作用：（72–77）「深情不要求同样热烈」

### 111–116　（正在面对）

- 他不再要求自己找到一种绝不会受伤的爱法。
  - ← 提供理由：（103–110）「两种办法都不够」
- 他仍想被对方选择，因为对方重要，也真切盼着两人彼此亲近，即使愿望未必实现也不必假装不存在。
- 他舍不得放弃克制，因为对方有自己的心意，也有不必与他相同的自由。
- → 他不愿让对方负责消除全部不安，怕那样会让亲近失去自在。
- 他仍会遗憾，却不再觉得必须先把遗憾消掉，才能好好爱一个人。
- 他不再因为过去的快乐没解决最后的问题，就把它们看成徒劳。
- → 他终于更清楚这个人对自己有多重要，也明白自己为何一再愿意向前。
  - ← 提供理由：（24–34）「慷慨喜欢的幸福」
  - ← 提供理由：（62–71）「顾虑暂时变轻」
- 他仍盼对方同样珍惜自己，却不再凭对方是否如此来判断自己的真心。
- 他仍会有所保留，却不再用保留多少证明自己清醒。
  - ← 改写：（103–110）「克制没能消除渴望」
- 他知道以后仍可能失望，也可能因不能更近一步而疼痛，但不把这些当作否认感情或催促对方的理由。
- → 他愿意继续把这个人放在心里，认真喜欢、充分欢喜，也接受对方的心意由不得他决定。
- → 他可以想被爱、想靠近，不必压下愿望，也不把它变成对方的义务。
- 他也能珍惜对方的自由，不必因此把自己的心收回去。
- → 他没有得到想要的一切，却不再为了保护彼此而先放弃最想给予的爱。
- ⟲ 仍在起作用：（72–77）「深情不要求同样热烈」；（78–83）「暂时放过自己」；（4–16）「不再提防喜欢」；（24–34）「慷慨喜欢的幸福」；（40–50）「细细喜欢很甜」；（62–71）「顾虑暂时变轻」；（93–102）「一时顾不上以后」；（84–92）「不靠压下期待证明」
