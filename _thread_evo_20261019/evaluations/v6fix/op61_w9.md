# Op.61｜关系图（在 w8 上逐段聚焦重修 w9）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他心里像有股劲在催，却说不清在等什么，连不安从哪儿来都不知道，整个人也安顿不下来。
- → 他想停却还撑着，怕任由事情照旧就等于认了“本来就该这样”，真投进去又怕丢下别的。
- → 熟悉感已经牵着他想动，可他仍想找个够有力的理由，好让自己终于不再犹豫。
- → 刚觉得自己想通了，舍不得又冒出来，那点确信也靠不住，他还说不清舍不得什么，也为非得想透才肯动而难堪。

### S02｜24–65 小节　（正在面对）

- 他不再拿没想清楚拖住自己，先接下眼前能做的事。
  - ← 改写：（1–23）「非得想透才肯动」
- → 他仍没底，却不再只算值不值得，愿意尽力、再多给一些，做起来也觉得痛快、有劲和骄傲。
- 他仍惦记着那些珍惜的东西，却再不能像从前那样自然地拥有它们，也说不清该怎么靠近。
  - ← 说明：（1–23）「够有力的理由」
- 他努力维持镇定，越想藏住动摇，越显出他其实很在意。

### S03｜66–91 小节　（没在想）

- 认真投入过一回，他暂时少问自己该不该走，也因没再退缩而高兴，怒气和抗拒仍搅着他，方向难定。
  - ← 提供理由：（24–65）「再多给一些」
- → 那种不用时时防备的亲近又让他松了口气，可越觉得它可贵，越清楚眼下离它很远。
  - ← 唤起：（24–65）「自然地拥有」
- → 他一时忘了为何用力，放松下来待了一会儿，也不觉得这会儿放松就是背弃了先前的决定，不急着向自己解释。
  - ← 提供理由：（24–65）「眼前能做的事」
- → 松快渐退，他想起自己当初不肯再等，也怀疑刚才那股劲是不是出于真心。
- ⟲ 仍在起作用：（24–65）「藏住动摇」

### S04｜92–115 小节　（正在面对）

- 轻松退去后，他还记得那一步确实让自己重新动起来，所以仍愿意坚持。
  - ← 唤起：（66–91）「松快渐退」
  - ← 提供理由：（24–65）「再多给一些」
- 他真尝过那份亲近带来的快乐，当时的坚定也有他努力撑住自己的成分，可眼下不安没让他认定那一步错了。
- → 他怕停下就得承认那份亲近回不到从前，便硬撑着把自己催得停不住，脑子反复追问过去还能怎样。
- → 可他还想要那种不用防备的亲近，光靠坚持仍没法让他安心。

### S05｜116–147 小节　（正在面对）

- 行动还不够，他却舍不得松手：那次决定曾救他脱离犹疑，他怕自己一失望就算变了心，便逼得更紧。
  - ← 提供理由：（92–115）「重新动起来」
- → 他仍惦记那种不用时时防备的亲近，心里一软，又把心思拉回自己定下的事。
  - ← 唤起：（66–91）「防备的亲近」
- → 一想到停下就像辜负最初的决意，他便认定眼下难受只是自己还在迟疑，逼自己继续撑。
- → 他把坚持变成不许示弱的规矩，连自己累了都不肯认，后来发现自己只是在逼一个累了的人证明够坚强。
- → 他不再逼自己硬撑，心里仍不安，也有些茫然，才肯承认舍不得那份熟悉的亲近。
  - ← 改写：（92–115）「光靠坚持」
- ⟲ 仍在起作用：（92–115）「反复追问」；（24–65）「藏住动摇」

### S06｜148–180 小节　（没在想）

- 催逼停下来后，他认出自己舍不得的不是一时舒服，而是曾真心相信过的生活。
  - ← 说明：（116–147）「熟悉的亲近」
- → 他盼着人与人靠近时不用时时防备，珍惜的东西也不必靠争抢才能留住。
- 他盼着付出只因喜欢，靠近时不必先防着受伤，也不用反复逞强来证明自己值得被爱、被接纳。
- 他不肯把这份向往说成软弱或幻想。
- → 他先只敢认下这点心愿，后来暂时不问它能不能成、有没有用，也不急着分清它和责任谁更要紧。
- → 他由着自己舍不得，也愿意相信这份向往，压住的委屈和思念浮出来，满足和柔软慢慢回来，疲惫暂时淡了。
- → 这份满足让他一时不想把心思从这份向往上移开，可他盼的生活还没真正实现。

### S07｜181–205 小节　（正在面对）

- 熟悉的亲近让他觉得生活近在眼前，身体先绷紧，才察觉现实没变；他懊恼怎么又沉进去，忘了还有事要面对。
  - ← 唤起：（148–180）「向往上移开」
- → 他当初不肯再等，是怕珍惜的东西继续受损，光在心里想着那种生活也护不住它们。
  - ← 提供理由：（24–65）「自然地拥有」
- → 他想重新投入，却已不能毫无顾忌，怕自己又只顾硬撑，把刚找回的温柔磨掉，连想留住的生活也顾不上。
- → 他原以为想清为何不能再等就能安心，如今还得想怎样争取才不伤温柔，理由更多了，还是定不下来。

### S08｜206–213 小节　（没在想）

- 为难时，他还是会被那种亲近打动。
- → 这回他不急着把留恋看成自己又在躲着该面对的事。
  - ← 提供理由：（148–180）「真心相信过的生活」
- → 他还愿意多停一会儿，心里欢喜，也舍不得这点安静这么快过去。
  - ← 提供理由：（148–180）「向往上移开」

### S09｜214–215 小节　（正在面对）

- 他刚才只是歇了口气，原先那道难题又摆到眼前，他还是拿不定主意。
  - ← 唤起：（206–213）「多停一会儿」
- → 他知道自己有些胆怯，怕往前又把自己逼得太狠，也舍不得那种不必防备的生活。
  - ← 提供理由：（181–205）「磨掉温柔」
- ⟲ 仍在起作用：（181–205）「理由更多」；（148–180）「不用时时防备」

### S10｜216–225 小节　（正在面对）

- 他知道那种生活仍重要，却累得连自己为什么舍不得都说不清，也提不起劲争取。
  - ← 说明：（181–205）「理由更多」
- → 他舍不得丢开那一步，也舍不得那份安宁。
  - ← 提供理由：（92–115）「重新动起来」
  - ← 提供理由：（148–180）「软弱或幻想」
- → 他怕再往前又把自己逼得太狠，可那些妨碍那种生活的事仍让他放不下。
  - ← 提供理由：（214–215）「不必防备的生活」
- → 他反复想着自己究竟想护住什么，想歇一歇也不等于要把它丢下。
  - ← 改写：（148–180）「向往上移开」
- → 他还不知道往后该怎么过，却不再急着判哪一边错，逼自己立刻选边的劲也松了一点。
- ⟲ 仍在起作用：（148–180）「不用时时防备」；（181–205）「不肯再等」

### S11｜226–241 小节　（正在面对）

- 他心里仍没底，开始重新想眼前还能承担什么。
  - ← 提供理由：（216–225）「选边的劲也松」
- → 那股力气没能让他放下对那种生活的牵挂。
  - ← 提供理由：（148–180）「向往上移开」
- → 他又想怪自己不够坚定，可安宁和争取这两样，他都舍不得，再狠也未必都护得住。
- → 每想到真要争取，他还是心疼，也盼着能少伤一点，可他知道再等下去也不会让眼前的事更好办。
- → 他心里还怕，也没把握，还是先接下眼前该担的事。
  - ← 提供理由：（216–225）「选边的劲也松」

### S12｜242–253 小节　（正在面对）

- 他没再等一个不伤到任何东西的办法，久违的劲头又回来了。
  - ← 提供理由：（226–241）「少伤一点」
  - ← 提供理由：（226–241）「接下眼前」
- → 他还是会尽力做事，不再逼自己每一步都得把局面扳回来。
  - ← 限制：（226–241）「安宁和争取」
- → 他舍不得那种不用时时防备的生活，想护住它又怕争取会伤到它。
- → 这份担心让他一度又想退回去，可他没等心里完全踏实，还是接着把该做的事做下去。
  - ← 改写：（24–65）「眼前能做的事」
  - ← 改写：（116–147）「不许示弱」
- ⟲ 仍在起作用：（226–241）「安宁和争取」；（226–241）「接下眼前」

### S13｜254–288 小节　（正在面对）

- 带着对那种不必防备的生活的牵挂往前，他反倒觉得它近了些。
  - ← 提供理由：（181–205）「不肯再等」
- → 以前他怕争取会磨掉那点温柔，就想退回安宁，仿佛这样还能保住它。
- → 他不再把舍不得看成软弱，想护住那种生活的心也推着他担起眼前的事，没有让他厌倦自己珍惜的生活。
  - ← 改写：（116–147）「不许示弱」
  - ← 提供理由：（148–180）「软弱或幻想」
  - ← 改写：（226–241）「安宁和争取」
- → 熬过怀疑和疲惫，他又尝到当初相信那种生活时的高兴，不敢把它当成理所当然。
  - ← 唤起：（148–180）「满足和柔软」
  - ← 说明：（181–205）「理由更多」
- → 他怕自己又把疲惫当软弱，硬撑到最后，反而磨掉想护住的温柔。
  - ← 提供理由：（116–147）「不许示弱」
- → 那种生活还没回来，他也不肯把曾经得到的安宁说成没用。
  - ← 提供理由：（216–225）「舍不得丢开」
- → 他不知道眼前的努力究竟能护住多少。
  - ← 限制：（216–225）「逼得太狠」
- → 真要付出代价时，他仍可能犹豫，想找个少伤一点的退路。
  - ← 提供理由：（226–241）「安宁和争取」
- → 他不再靠硬撑证明自己该往前，力气放下来，想护住那种生活的心还在。
  - ← 改写：（116–147）「不许示弱」
  - ← 说明：（242–253）「久违的劲头」
