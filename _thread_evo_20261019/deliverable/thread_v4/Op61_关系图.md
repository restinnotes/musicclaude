# Op.61｜关系图

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### 1–23　（还说不清）

- 他起初不知自己究竟在等什么，只隐约觉得放任某些事，仿佛就是认了它们理所当然。
- 他想把自己投进去，却又怕丢下什么，还分不清两股牵扯各自指向哪里。
- 他试着寻找一个足以不再犹豫的理由，刚有些把握，另一份舍不得便浮上来。
- 他有时几乎相信自己想通了，过一会儿却连刚才的确信也觉得陌生。
- 反复摇摆让他难堪，他怀疑自己是否非得把心里的事都理清才肯向前。

### 24–65　（正在面对）

- 他渐渐无法再拿没想清楚作等待的理由，决定先承担自己能够承担的部分。
  - ← 提供理由：（1–23）「放任某些事等于默认」
  - ← 动摇：（1–23）「因反复摇摆而难堪」
- 没有保证，心里的牵挂也没有消失，但开始行动后，他真切感到自己有了力量。
- 他不再反复追问值不值得，转而愿意尽力，并为没有任疑虑支配自己而骄傲。
  - ← 改写：（1–23）「寻找不再犹豫的理由」
- 投入与付出令他热切而快乐，仿佛原先无处可去的不满终于有了去处。
- 他乐意付出更多，甚至贪恋倾尽全力的畅快，不愿再为一点软弱停下来审视自己。
- 用力到深处，他偶尔触到心里仍未跟着振奋的一处，隐约知道坚定没照顾到所有牵挂。　✦ 满足照出未满足
- ⟲ 仍在起作用：（1–23）「想投入却怕丢下什么」

### 66–91　（没在想）

- 那点隐约的不安还不足以使他停下，认真投入过后，他反倒能稍稍放下反复自问。
  - ← 提供理由：（24–65）「行动中感到力量」
- 他为不再畏缩而高兴，偶尔忘了为何用力，也觉得这一时的轻松并不算背叛。
  - ← 提供理由：（24–65）「不问值不值得而尽力」
- 那种许久没有的自由使他轻盈，他顺着它走了一程，没有忙着赋予更大意义。
- 当快乐渐渐不再那么满，他发现此前的决定仍等着自己，不能一直忘在一旁。
- ⟲ 仍在起作用：（24–65）「不等想清楚便先承担」

### 92–115　（正在面对）

- 他重新面对自己作过的决定，仍愿坚持，不愿因心里尚有缺口就否定此前的行动。
  - ← 提供理由：（24–65）「行动中感到力量」
  - ← 提供理由：（66–91）「为不再畏缩而高兴」
- 从前令他振奋的坚定，此时已无法使他安心。
  - ← 失效：（24–65）「贪恋倾尽全力的畅快」
- 他试图用坚定确认自己还有力量，却察觉心里另有要求无法被它照顾。
  - ← 唤起：（24–65）「振奋中仍有未安之处」
- 他虽不情愿，仍不得不承认，值得继续的行动也留下了无法满足的要求。　✦ 办法的限度

### 116–147　（正在面对）

- 明知行动仍有欠缺，他怕失望意味着自己变了心，于是更用力地催逼自己坚持。
  - ← 提供理由：（24–65）「行动中感到力量」
  - ← 唤起：（92–115）「行动留下未满足的要求」
- 心里难受时他把它当成要克服的迟疑，想稍微停下，又担心自己是在退缩。
- 他知道自己正受苦，却想不出除了坚持，还有什么能对得起最初的决意。
- 从前令他昂扬的要求渐渐变成苛责，连脆弱也容不下，他仿佛在逼迫疲惫的自己。　✦ 办法的限度
  - ← 失效：（24–65）「贪恋倾尽全力的畅快」
- 他终于不愿再证明自己有多坚强，便暂时停下对自己的催逼。
- 停下仍未让他安心，却让被压下的依恋浮现，他仿佛肯承认自己还真心舍不得一些东西。
  - ← 唤起：（24–65）「振奋中仍有未安之处」

### 148–180　（没在想）

- 他慢慢发现，自己舍不得的是曾经真心相信能有的生活，并不只求免于辛苦。　✦ 分清
  - ← 提供理由：（116–147）「停止逼迫自己」
  - ← 改写：（1–23）「想投入却怕丢下什么」
- 他盼望人与人无需时时防备，珍爱的东西也不必靠争夺才能保住。
- 他还盼望无需不断证明值得被爱，能因喜欢而付出，靠近时也无需先防备受伤。
- 他曾自然地相信这种生活可能，也确实在其中感到快乐与不费力的亲近。
  - ← 唤起：（116–147）「停下后依恋浮现」
- 因那份快乐曾经真实，他不愿把如今的盼望看作逃避时编出的安慰，也不肯说它软弱。
- 他终于肯尽情爱惜那份盼望，不再拿责任审问自己，也不急着问它能否得到或是否更重要。
  - ← 改写：（116–147）「昂扬要求变成苛责」
- 只需允许自己这样爱、这样相信，他就感到深深满足，仿佛又能柔软地生活。
- 他沉浸在这份真实的安宁中，几乎忘了先前的疲惫，一时也不想离开。

### 181–205　（正在面对）

- 真实的安宁渐渐让他意识到，只靠心里的怀念无法改变那种生活所受的威胁。　✦ 满足照出未满足
  - ← 提供理由：（148–180）「沉浸真实安宁不愿离开」
- 重新感到那份生活值得爱惜，他便不甘心再被动等待，想重新面对那些威胁。
- 他随即懊恼自己刚才沉浸在满足里，竟忘了那些必须面对的事。
- 他试着重新催促自己振作，这一次却无法像先前那样毫无顾忌地投入。
- 他怕艰难的争取慢慢耗尽心中温柔，最后只剩不肯退让的意志，却忘了为何要争取。
  - ← 提供理由：（148–180）「曾相信亲近可以轻松」
- 他既舍不得刚感到的安宁，也放不下它所受的威胁，向前与停留都使他不安。
- 如今他能找到的理由反而更多，内心却比从前更难作决定。　✦ 知道更多反而更尖锐
  - ← 改写：（1–23）「寻找不再犹豫的理由」
- ⟲ 仍在起作用：（1–23）「放任某些事等于默认」

### 206–213　（没在想）

- 为难中，那份温柔又短暂贴近他，明知无法一直停留，他仍不忍立刻推开。
  - ← 唤起：（148–180）「沉浸真实安宁不愿离开」
- 他想到它曾给过深深的满足，便愿意再爱惜片刻，暂时不拿它审问自己。
  - ← 提供理由：（148–180）「允许自己柔软地生活」
- 他短暂放下那些还无答案的事，安静仍使他欢喜，欢喜里却已经带着不舍。
- ⟲ 仍在起作用：（181–205）「安宁与威胁难以两全」

### 214–215　（正在面对）

- 当这点安静退去，熟悉的迟疑又回来了，他仿佛走了很远仍回到原处。
- 他终于知道迟疑里除了怯懦，还有自己真心不愿失去的生活希望。　✦ 分清
  - ← 提供理由：（148–180）「舍不得曾相信的生活」
  - ← 改写：（1–23）「想投入却怕丢下什么」
- ⟲ 仍在起作用：（1–23）「因反复摇摆而难堪」

### 216–225　（正在面对）

- 明白舍不得什么仍未使他勇敢起来，他既无法只凭决心向前，也难安心待在旧愿里。
  - ← 限制：（92–115）「行动留下未满足的要求」
  - ← 限制：（181–205）「怀念无法改变生活威胁」
- 他一时无力再逼自己作大改变，只盼再次争取时，别忘记自己为什么争取。
- 他也盼能继续爱惜那份安宁，同时不回避那些使它难以存在的事。
  - ← 提供理由：（181–205）「重新面对威胁不再等待」
- 他还不知道怎样才能两边都顾及，只是反复想着，非舍弃一边不可的逼迫似乎轻了一点。
- ⟲ 仍在起作用：（181–205）「怕争取耗尽心中温柔」

### 226–241　（正在面对）

- 凭着这点尚不牢靠的愿望，他又想自己能怎么办，不愿轻易否定两份真实的收获。
  - ← 提供理由：（216–225）「非此即彼的逼迫减轻」
- 他渐渐明白，想保有那份无需时时奋力的安宁，一旦为它争取，就可能再失去安宁。　✦ 选择的代价
  - ← 说明：（92–115）「行动留下未满足的要求」
  - ← 说明：（181–205）「怀念无法改变生活威胁」
- 他不再把这样的难受全怪作自己不够坚定，开始承认自己确实珍惜着不止一种东西。　✦ 分清
  - ← 改写：（1–23）「因反复摇摆而难堪」
- 即使这样想，他仍会心疼，仍希望能有一条不必如此艰难的路。
- 但他也明白继续等下去不会自然得到那条路，怕损伤珍爱的东西就停下，也未必能留住它。
- 他不再要求自己先变得毫不害怕，愿意带着舍不得、没把握和可能的痛苦去承担。
- 他一点点重新聚起力量，真正要承担时仍清楚自己会怕，却不再愿意让惧怕替他决定。
- ⟲ 仍在起作用：（181–205）「怕争取耗尽心中温柔」

### 242–253　（正在面对）

- 不再等毫无损失的办法后，他重又感到昂扬，这一次无需否认自己的脆弱。
  - ← 提供理由：（226–241）「不让惧怕替自己决定」
  - ← 改写：（116–147）「昂扬要求变成苛责」
- 他仍愿尽力，却不再急着借坚定证明自己有能力改变事情，也不要求自己无所不能。
- 他肯让怕失去的和想爱惜的留在心里，不再为了显得勇敢而将它们藏起来。
  - ← 提供理由：（214–215）「迟疑藏着生活希望」
- 他开始愿意为真心爱惜的一切负责，牵挂也不再使他觉得行动受了拖累。
  - ← 提供理由：（226–241）「承认自己珍惜多种事物」
- 这份决心仍热烈，却比最初踏实，他不再等疑虑消失才准许自己坚定。
  - ← 提供理由：（226–241）「不让惧怕替自己决定」

### 254–288　（正在面对）

- 重新决定向前时，他意外发现，那份曾使他想退回去的旧愿，似乎比从前更亲近。
  - ← 改写：（1–23）「想投入却怕丢下什么」
- 如今他因珍惜那份生活，反而更不肯放任使它难以实现的事情继续存在。
- 他第一次真切觉得，自己珍惜温柔的心也能成为行动的理由，令他不肯袖手旁观。
  - ← 提供理由：（148–180）「曾相信亲近可以轻松」
- 他想要的仍是无需拼命便能好好生活的日子，却愿意承认爱惜它有时就得离开安宁。
  - ← 提供理由：（226–241）「争取安宁反失安宁」
- 他不敢认定多付出就能更接近旧愿，也不因愿望美好便觉得一切付出都值得。　✦ 办法的限度
  - ← 限制：（92–115）「行动留下未满足的要求」
- 他仍会留意自己是否在争取中失去想保护的东西，这些担心如今也提醒他如何坚持。
- 两股心意这时竟能一同支持他，他因而欢喜，不再为依恋羞愧，也不厌倦该尽的责任。
  - ← 改写：（216–225）「非此即彼的逼迫减轻」
- 他重新尝到全心投入的畅快，但经过怀疑和疲惫，已不再把这份快乐视为理所当然。
  - ← 唤起：（24–65）「付出带来热切快乐」
- 喜悦渐渐平静后，他仍不知道努力究竟能改变多少，那种无需防备的生活也未到来。
- 他清楚以后还可能疲惫、因代价而动摇，两份愿望也可能再次相互牵制。
- 他不再拿一种满足盖住另一种需要，也不因心里还有缺口就否认自己确实得到的东西。
- 他仍向往那种生活，也仍愿行动，虽不知能留下多少珍贵的东西，却肯带着不舍向前。
  - ← 提供理由：（226–241）「不让惧怕替自己决定」
- 这一次，他不再需要为自己的愿意寻找更多证明。
  - ← 提供理由：（242–253）「尽力却不求无所不能」
- ⟲ 仍在起作用：（148–180）「盼望亲近不必争夺」；（181–205）「怕争取耗尽心中温柔」；（226–241）「争取安宁反失安宁」
