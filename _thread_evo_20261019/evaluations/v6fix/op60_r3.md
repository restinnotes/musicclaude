# Op.60｜关系图（v6 修补 r3）

**Center：**对亲密的投入与自我克制始终相互牵制。

### S01｜1–3 小节　（还说不清）

- 他一想到那个格外想亲近的人，心里就软下来，却还没习惯自己这么在意对方。
- → 他怕对方看出自己有多在意后，两人相处就会变样，所以先把心收住。
- → 眼下还不必决定两人以后会怎样，他先把这事放一放。
- 他觉得自己随时都能放下这点喜欢，真要放下却舍不得。

### S02｜4–16 小节　（没在想）

- 想到喜欢不等于对方欠他回应，他才敢安心靠近，也从真心对人好里得到满足，不用总看对方有没有回应。
- → 他格外珍惜眼前的亲近，想让这样的相处久一点，却知道日子仍在往前走。
  - ← 唤起：（1–3）「随时都能放下」
- → 相处得舒服时，他有一阵只顾着喜欢这个人，没去想这份喜欢以后该怎样。
- → 那时他真觉得，只要能一直这样自然地亲近，就已经够了，不必再向对方多要什么。
- ⟲ 仍在起作用：（1–3）「把这事放一放」

### S03｜17–23 小节　（正在面对）

- 他从眼前的亲近里尝到了幸福，开始盼以后也能一直这样相处。
  - ← 提供理由：（4–16）「安心靠近」
  - ← 改写：（4–16）「久一点」
- → 想到往后，他可以照自己的心意珍惜对方，却没法替对方决定是否也珍惜他。
- → 他没想到偶尔还会想自己在对方心里是不是也很特别，却没打算向对方问明白。
- → 他原先觉得这样就够了，可这个念头一冒出来，心里就没那么踏实了。
  - ← 动摇：（4–16）「已经够了」
- ⟲ 仍在起作用：（4–16）「只顾着喜欢」

### S04｜24–34 小节　（正在面对）

- 他舍不得眼前的亲近，怕它留不住，也知道对方没答应过什么，不愿因新期待催对方回应。
  - ← 提供理由：（17–23）「没那么踏实」
  - ← 限制：（17–23）「替对方决定」
- → 他试着重新只想着怎样关心对方、替对方高兴，先不追问对方是否同样在意。
  - ← 唤起：（4–16）「安心靠近」
- → 这办法确实让他暂时松了口气，更愿意付出，不再算给了多少，也不怕显得更在乎。
- → 他把这阵轻松当成保证，以为不提要求就能尽情去爱，也不会失去什么。
- ⟲ 仍在起作用：（17–23）「替对方决定」

### S05｜35–39 小节　（还说不清）

- 欢喜稍稍平息，他仍想知道对方是否也把他放在心上，却没把握两人能否一直这样亲近。
  - ← 动摇：（24–34）「当成保证」
- → 他一想到先前对对方好也许是在等回报，就觉得难堪。
- → 他替对方高兴时也真心开心过，所以舍不得把那些时刻全说成是在等回报。
- → 他一时没法再靠不提要求来让自己安心。

### S06｜40–50 小节　（没在想）

- 这份难堪没让他少喜欢，对对方再好，他也没法因此不再盼着回应。
  - ← 提供理由：（35–39）「觉得难堪」
- → 他不再反复查看对方是否在意，也不再追问自己是不是想换来回应，真心盼对方过得好时就照常关心。
- → 想到这个人时，心里就发甜，暂时顾不上对方会不会回应。

### S07｜51–61 小节　（正在面对）

- 想到对方时，他总想再多回味一会儿心里的甜，回味久了，想靠近的念头也收不住。
  - ← 改写：（40–50）「心里就发甜」
- → 他想把喜欢留在心里，免得对方为难，也不想让期待牵着自己走。
  - ← 限制：（24–34）「眼前的亲近」
  - ← 提供理由：（40–50）「难堪没让他少喜欢」
- → 可越珍惜两人已有的亲近，就越常惦念对方，也越盼自己的关心能被对方领会。
- → 他仍不肯催对方回应，只能自己带着没着落的盼望，眼前这样亲近的时刻也留不住。
- → 他记得真心关心对方时有多快乐，舍不得少关心对方一点。
  - ← 提供理由：（40–50）「照常关心」
  - ← 说明：（40–50）「心里就发甜」
- ⟲ 仍在起作用：（4–16）「久一点」

### S08｜62–71 小节　（没在想）

- 他舍不得少喜欢一点，也不想再因怕受伤，一高兴就把心收回去。
  - ← 提供理由：（51–61）「有多快乐」
- → 他想起安心靠近、真心对人好、独自想着对方时都曾很快乐，这些快乐并非等到对方许诺才有。
  - ← 说明：（4–16）「安心靠近」
  - ← 说明：（24–34）「松了口气」
  - ← 说明：（40–50）「心里就发甜」
- → 他肯顺着想亲近的念头多停一会儿，心里也有了些玩心。
- → 他知道对方没给过保证，也还盼着回应，可有一阵他只顾着高兴，几乎顾不上担心会落空。
- → 他刚肯放开喜欢，心里就隐约怕这样的亲近转眼过去。
- ⟲ 仍在起作用：（51–61）「没着落的盼望」；（4–16）「久一点」

### S09｜72–77 小节　（正在面对）

- 欢喜稍稍落定，他才看清，自己不只想尽情喜欢，也盼对方主动靠近、把他放在心上。
  - ← 唤起：（62–71）「只顾着高兴」
- → 他顾着对方能不能自在地靠近，不想让对方因为自己的认真就觉得非回应不可。
  - ← 限制：（24–34）「眼前的亲近」
- → 他舍不得收回盼望，连想被珍惜都得小心，退回谨慎又像辜负刚承认的心，越掂量越委屈，也厌倦自问该不该盼。
- ⟲ 仍在起作用：（51–61）「没着落的盼望」

### S10｜78–83 小节　（正在面对）

- 他没把握对方会不会主动靠近，便让盼望和顾虑都留着，暂时不逼自己选边。
  - ← 提供理由：（72–77）「越掂量越委屈」
- → 他不再一冒出想靠近的念头就立刻压住，也不急着往前，忍着的喜欢和委屈终于能出来，身体也跟着卸了劲。

### S11｜84–92 小节　（正在面对）

- 他肯让想靠近的念头留下来，亲近对方的快乐又回来了。
  - ← 提供理由：（78–83）「不急着往前」
  - ← 唤起：（4–16）「安心靠近」
- → 他想被珍惜时，仍记得自己真心替对方高兴过，不再把先前的体贴看成讨回报，心里有些满足。
  - ← 说明：（62–71）「安心靠近」
  - ← 改写：（35–39）「觉得难堪」
  - ← 限制：（72–77）「非回应不可」
- → 犹疑了这么久，他竟还会因为喜欢而高兴，心里有些感动。
  - ← 提供理由：（72–77）「越掂量越委屈」
- → 他知道对方没给新的保证，高兴时仍怕落空，却还是愿意好好享受这份喜欢。
- ⟲ 仍在起作用：（72–77）「才看清」；（78–83）「暂时不逼自己选边」；（62–71）「转眼过去」

### S12｜93–102 小节　（没在想）

- 他更清楚自己想要的不只是眼前的亲近。
  - ← 提供理由：（84–92）「快乐又回来」
- → 他想尽情对对方好，也盼对方同样珍惜他，想知道两人若都愿意靠近，能有多幸福。
- → 愿望涌来，他觉得有好多喜欢可给、亲近可珍惜，仿佛什么都不缺，幸福得几乎招架不住，连自己都顾不上。
  - ← 唤起：（84–92）「快乐又回来」
- → 眼前的亲近让他暂时顾不上那份没着落的盼望，只想尽情享受这一刻。
- 对方还没有给他新的保证，他想被同样珍惜的愿望仍没着落。
- ⟲ 仍在起作用：（84–92）「好好享受」

### S13｜103–110 小节　（正在面对）

- 刚才的幸福让他真切感到自己有多喜欢对方，没法再把对方会不会选择自己当成无所谓。
  - ← 唤起：（93–102）「几乎招架不住」
  - ← 提供理由：（93–102）「愿望仍没着落」
- → 他不愿逼对方回应，也不想让对方替自己消除所有不安。
  - ← 限制：（72–77）「非回应不可」
- → 把喜欢留在心里时，他曾安心些，还是想靠近。后来尽情喜欢，他也快乐过，却仍没把握对方会不会选择自己。
  - ← 提供理由：（51–61）「留在心里」
  - ← 说明：（51–61）「没着落的盼望」
  - ← 说明：（84–92）「好好享受」
- → 他仍急着想靠近，也不愿因怕落空就少喜欢一点。两边都放不下，他难受，却不愿假装自己不在乎。
- ⟲ 仍在起作用：（78–83）「暂时不逼自己选边」

### S14｜111–116 小节　（正在面对）

- 这个人对他很重要，他仍想被选择、彼此靠近，不能如愿时还是会疼。
  - ← 提供理由：（103–110）「有多喜欢对方」
- → 收住心时，渴望还是会回来，尽情喜欢也没能避开失望，所以他不再等到不怕受伤才继续喜欢。
  - ← 说明：（103–110）「还是想靠近」
  - ← 改写：（103–110）「少喜欢一点」
- → 小心靠近、不求确认地付出、独自珍藏、尽情欢喜，都曾让他真切快乐，让他舍不得把喜欢丢下。
  - ← 说明：（4–16）「安心靠近」
  - ← 说明：（24–34）「松了口气」
  - ← 说明：（40–50）「心里就发甜」
  - ← 说明：（62–71）「只顾着高兴」
- 他想要的是对方自愿靠近，不想把所有盼望都压到对方身上换回应。
  - ← 限制：（72–77）「非回应不可」
- 他不再靠收住心证明自己清醒，也不因对方未必回应就认定自己不该喜欢。
  - ← 改写：（1–3）「相处变样」
  - ← 提供理由：（103–110）「少喜欢一点」
- → 他仍愿意认真喜欢，也让自己尽情欢喜。
  - ← 提供理由：（103–110）「少喜欢一点」
- ⟲ 仍在起作用：（84–92）「好好享受」
