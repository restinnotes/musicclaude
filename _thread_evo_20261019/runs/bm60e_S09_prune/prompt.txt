      ← 提供理由：（62–71）「尽兴投入」

## 路C
第1段（1–3）［没在想］
  他心里有份说不清指向何处的期待，连自己也不知道究竟在盼什么。
第2段（4–16）［正在面对］
  那份无所指的期待在亲近中初次有了方向，他因此尝到温柔的满足。
      ← 提供理由：（1–3）「无名的期待」
第3段（17–23）［正在面对］
  这份靠近已变得切身，他忽然在意对方是否也珍惜它；念头一闪，留下等待回应的牵挂。
      ← 提供理由：（4–16）「期待有了方向」
第4段（24–34）［正在面对］
  先前的牵挂让这份亲近更有分量；他再次感到满足时，投入也更深。
      ← 改写：（17–23）「等待回应」
第5段（35–39）［正在面对］
  投入更深后，他再想到对方是否珍惜这份亲近，对自己想被珍惜的期待有些难为情。
      ← 唤起：（17–23）「等待回应」
      ← 改写：（24–34）「欢喜加深」
第6段（40–50）［正在面对］
  那点羞怯让他沉入自己的眷恋，单是喜欢这个人便带来柔软的甜意。
      ← 改写：（35–39）「想被珍惜的难为情」
第7段（51–61）［正在面对］
  独自品尝喜欢的甜意，开始转成想再靠近对方的切身渴望。
      ← 提供理由：（40–50）「私下的甜意」
第8段（62–71）［正在面对］
  想再靠近时，旧有的回应牵挂转成兴奋的期待，他盼对方也靠近。
      ← 提供理由：（51–61）「甜意转成靠近」
      ← 改写：（17–23）「等待回应」
  → 这份期待带着舍不得，他盼彼此靠近的时刻能继续。
第9段（72–77）［正在面对］
  他被亲近本身的美好吸引，自己的回应期待暂时退到次要位置。
      ← 唤起：（40–50）「私下的甜意」
      ← 改写：（62–71）「舍不得亲近结束」

## 路D
第1段（1–3）［还说不清］
  一份愿望在他心里有了分量，他想顺着它走下去，又在意自己能否掌握投入的程度。
第2段（4–16）［正在面对］
  愿望所指的亲近终于有了实感，他从这份靠近本身尝到柔软的满足。
      ← 提供理由：（1–3）「投入的分寸」
  → 这份满足使他愿意停在当下，亲近本身成了可以安心享受的快乐。
第3段（17–23）［正在面对］
  亲近有了实感后，他对投入多少的在意变得切身，满足之中生出难理清的牵扯。
      ← 提供理由：（1–3）「投入的分寸」
      ← 唤起：（4–16）「亲近有了实感」
第4段（24–34）［正在面对］
  尝过真实亲近的满足后，他这次更敢让心意显露，也想投入得更深一些。
      ← 提供理由：（4–16）「安住当下」
  → 可要把心意交得更深时，先前的分寸牵扯又让他迟疑。
      ← 限制：（17–23）「投入分寸的牵扯」
第5段（35–39）［正在面对］
  想更深地显露心意时，分寸牵扯让他感到自己对亲近的需要格外脆弱。
      ← 提供理由：（24–34）「更敢投入」
      ← 限制：（24–34）「交付时的迟疑」
第6段（40–50）［正在面对］
  亲近让他的需要显得脆弱，心意暂时回到自身；仅仅感到自己仍然喜欢，也带来清亮而陌生的自在。
      ← 提供理由：（35–39）「亲近需要显露」
第7段（51–61）［正在面对］
  承接上段的自在，喜欢本身转成推动他深入亲近的力量。
      ← 改写：（40–50）「内在的自在」
第8段（62–71）［正在面对］
  顺着喜欢的推力，他这次尽情投入亲近，热情本身就成了欢喜。
      ← 提供理由：（51–61）「自在转为推力」
第9段（72–77）［没在想］
  尽情投入后的欢喜使他短暂被更宽广的美好打动，心思从自己的愿望转向安静的惊叹。
      ← 提供理由：（62–71）「尽兴投入」

## 路E
第1段（1–3）［没在想］
  他心里有份说不清指向何处的期待，连自己也不知道究竟在盼什么。
第2段（4–16）［正在面对］
  那份无所指的期待在亲近中初次有了方向，他因此尝到温柔的满足。
      ← 提供理由：（1–3）「无名的期待」
第3段（17–23）［没在想］
  刚才的满足让他整个人松弛下来，心绪舒展开来，安然沉在此刻的舒服里。
      ← 提供理由：（4–16）「期待有了方向」
第4段（24–34）［正在面对］
  安稳过后，熟悉的亲近再现，他更想把心意放得深一些。
      ← 提供理由：（17–23）「沉在满足里」
  → 这份更深的投入让他感到畅快，亲近也像在唤醒他更多的生命力。
第5段（35–39）［正在面对］
  更深的投入让这份亲近变得切身，他开始在意对方是否也珍视它，心里有些不安。
      ← 唤起：（24–34）「欢喜扩展」
第6段（40–50）［正在面对］
  亲近里浮起一点安静的酸楚：心意虽真切，彼此的内心却未必完全相通。
      ← 改写：（35–39）「盼被珍视」
第7段（51–61）［正在面对］
  那点独自承受的酸楚化成身体里的迫切，他沉浸在亲近唤起的生命热度里，欲望本身推着他向前。
      ← 改写：（40–50）「亲近中的独处感」
第8段（62–71）［没在想］
  那股迫切此刻变成畅快，他尽兴地享受着喜欢一个人的感觉。
      ← 改写：（51–61）「沉入热望」
  → 欢喜刚舒展开，他已经开始留恋这份自在。
第9段（72–77）［正在面对］
  尽兴之后，他更切身地在意这份亲近对两个人是否同样重要。
      ← 改写：（62–71）「留恋余欢」
      ← 唤起：（35–39）「盼被珍视」
