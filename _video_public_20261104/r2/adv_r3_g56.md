我先给一个核心判断：

**现在的问题不是压缩得还不够，而是压缩时弄错了信息的层级。线被压成了情绪结论，珠子被压成了词语碎片。前者丢掉了人物为什么会这样，后者丢掉了观众为什么能感受到它。**

这两件事需要分别解决，不能再用统一的「提取重点、删减文字」来做。

我认为这轮应该真正改变流水线的思考方式：先弄清楚哪些信息承担解释作用，哪些信息承担体验作用，再分别重新组织。不要再从定稿文字上直接做截断式压缩。

# 一、诊断：现在究竟丢了什么？

## 1. 线：丢掉的主要不是情绪，而是情绪之间的解释关系

我觉得现有评审数据已经非常清楚地指出了问题：

| 评价维度 | 短版相对定稿的净胜 |
|---|---:|
| 单独成立 | -54 |
| 不啰嗦 | -4 |
| 人话、直白 | +12 |
| 接得住珠子 | -52 |

这说明了一件很重要的事：

**我们已经在一定程度上解决了语言直白的问题，却严重损害了线作为一段独立经历的解释能力。**

这不是一个普通的长度问题。

### 线真正包含四种信息

一条有解释力的线，往往同时包含：

- **处境：** 这个人现在面对什么。
- **动机：** 他为什么想要、害怕或者在意某件事。
- **矛盾：** 他同时存在什么互相牵制的想法。
- **变化：** 这些想法如何影响他接下来的选择。

不是每条线都必须包含全部四种，但它们构成了线的解释力。

现在的压缩经常只留下最后的情绪和态度。

例如，船歌 S01 原文的心理关系是：

他忽然很想靠近一个人 → 这种亲近让他心里发热 → 但他担心自己的需要成为对方的负担 → 所以只敢表现出一点喜欢 → 同时又希望下一次能更坦白。

当前结果：

- 我忽然很想靠近他，心里一热。
- 我想知道，下次能不能更坦白？
- 我怕自己的需要成了负担。

这几句话单独看都没有错。

但它们之间的关系没有真正建立起来。

读者需要自己推断：

- 为什么想靠近又不敢靠近？
- 为什么想坦白却又担心？
- 这份害怕怎样影响他的表达？

这就是解释力损失。

再看幻想波兰舞曲 S13-4。

原文有一个非常重要的意思：

> 将来要是再有人愿意把他当自己人，他会好好珍惜；即使一直没有，他也愿意自己好好过下去，不再为了留住谁把那些委屈咽下去。

短版变成：

> 我会珍惜把我当自己人的人，不再为留住谁忍下委屈。

这里少掉的不只是一个补充条件，而是一个重要的心理立场：

**他已经愿意接受，即使以后没有人陪伴，也可以好好生活。**

这会直接影响观众对整段经历的理解。

还有一个特别值得注意的现象：评委指出「疲惫不等于想通」。

这说明我们在压缩时，经常把一个人经历挣扎后的暂时松动，写成了他已经形成的结论。

这两者完全不同。

### 怎样才算压对了线？

我建议以后用一个很简单的判断：

**删掉这句话以后，观众是否还需要自己补充一个重要的「为什么」「可是」或者「所以」？**

如果需要，这句话很可能承担着解释作用，不应该删。

反过来，如果删掉它只是少了一层相似的情绪修饰，并没有影响人物为什么这样想、为什么这样做，就可以删。

具体来说：

| 应当优先保留 | 可以优先压缩 |
|---|---|
| 状态发生变化的原因 | 重复表达同一种情绪 |
| 一个愿望背后的顾虑 | 多次强调同一种强度 |
| 同时存在的矛盾 | 对情绪的重复解释 |
| 做出选择的实际理由 | 珠子已经充分表达的感官细节 |
| 与前后段连接的心理事实 | 不影响人物经历的修饰 |
| 暂时没有解决的疑问 | 对已经明确的结论再次总结 |

还有一个重要区别：

**线不是把每段的心理事实按照时间顺序重新排列。**

原文同一组的几条线可能是在描述同一个时刻的不同侧面。

比如一个人既高兴又害怕，既想靠近又想收住。

这应该呈现为并存的矛盾，而不是：

先高兴 → 然后害怕 → 最后退缩。

除非原文明示了这种先后关系。

我认为这是必须写进提示词的结构性要求。

---

## 2. 珠子：现在的问题是把体验压缩成了概念

珠子目前有两种比较明显的失败方式。

**第一种：拆得太碎，剩下的是画面元素，不是体验。**

例如：

- 一束烟花
- 细碎的光点
- 缓缓飘落
- 悬在水面上方

这组词本身并不难懂。

问题在于，它们各自被当成独立的信息单位以后，观众可能需要把它们重新拼起来，才能理解完整的体验。

而且，其中有些只是画面，有些才真正具有感受上的意义。

拆分不是目的。

如果拆开之后，观众必须在脑中重新组装，实际上并没有降低理解成本。

**第二种：压缩成了抽象概念。**

例如评委指出的：

- 对生的眷恋
- 天地的共振
- 新的重量
- 牵扯与延迟
- 意志终于落定

这些表达的问题不是字数，而是理解路径。

观众看到它们，需要先问：

- 这是什么意思？
- 它对应什么具体感觉？
- 我为什么应该产生这种感受？

这与边听边看的目标相反。

观众不应该先理解作者的概括，再去体验情绪。

应该直接感受到。

### 我认为珠子的正确压缩单位不是「词」，而是「体验单元」

这是我想重点提出的一个区别。

一个体验单元，可以是：

- 一个身体反应；
- 一种即时情绪；
- 一个正在发生的心理动作；
- 一种感官状态；
- 一个没有解决的矛盾；
- 一个让人直接感到某种心理状态的具体联想。

它可以是一个词，也可以是一小段短语。

关键不在长度，而在于：

**观众扫到它时，能不能立即获得一个明确的感受。**

例如：

- 「失重」是一个直接的身体感受。
- 「想靠近，又怕被嫌弃」是一个直接的心理矛盾。
- 「还没失去，就已经舍不得」是一个能够立即理解的情感状态。

相比之下，单纯把一段话切成几个名词，并不一定能得到更好的珠子。

我还想强调一点：

不要把比喻本身当成问题。

原文中很多比喻其实非常有价值。水波、漂浮、寒风、呼吸、光线，都能直接让人产生感觉。

真正应该淘汰的是那些需要观众进行概念翻译的表达，而不是所有文学性表达。

### 珠子还存在一个更深的问题：它没有充分承担与线不同的任务

线回答的是：

**这个人为什么处在现在这个状态？**

珠子回答的是：

**处在这个状态的此刻，心里和身体具体是什么感觉？**

两者不能互相替代。

比如线已经表达了「害怕失去这份亲近」。

珠子就不应该再堆叠一堆同义的「害怕、舍不得、不安」。

它应该提供线没有提供的东西：

- 身体上的感觉；
- 情绪的复杂性；
- 当下的感官状态；
- 某种难以用线直接表达的矛盾。

这样观众才会觉得，珠子真的把线里的经历变得可感受了。

---

## 3. 我认为目前流水线的根本错误

把上面两类问题合起来，我认为是三个错误。

**错误一：把压缩当成删减，而不是重新组织。**

原文有完整的结构，短版却在原文表面上寻找可以删除的句子。

结果是长度减少，关系也减少。

**错误二：没有先确定信息的重要性，再决定怎么压。**

你们已经明确要求独立排序主要信息，再和成品比较。

但目前看，压缩过程没有真正建立这个机制。

应该先确定：

- 哪些心理事实是这一段的核心；
- 哪些事实是理解核心不可缺少的解释桥；
- 哪些只是补充体验。

然后才压缩。

而不是先写一版很短的，再看看还剩什么。

**错误三：没有把线和珠子当作两种不同的语言。**

线需要保持叙事完整、逻辑连贯。

珠子需要保持体验直接、感官明确。

线可以有完整的因果关系。

珠子可以是散开的短语，不需要完整句子。

两者不能用同一种压缩方法。

它应该是：

**一条连续的人物内心叙述，加上若干组散开的当下体验。**

两者同时存在，但视觉上必须明显不同。

## 我建议的阅读路径

我倾向于：

**先抓主珠 → 读线 → 扫其他珠子。**

原因是：

- 主珠先给观众一个即时的感受入口。
- 线接着告诉观众，这份感受属于谁，为什么此刻会有这种感受。
- 其他珠子补充同一处境中的不同侧面，让观众感受到异质性。

这样，珠子不是线的注释，线也不是珠子的总结。

它们共同构成一段体验。

当然，阅读顺序不等于动画顺序。

不应该再让每颗珠子轮流放大。主珠组可以同时呈现，通过位置、大小、颜色和对比度引导视线。

## 视觉上需要有四种明确的区别

**1. 主次区别**

每段独立确定最重要的一组，成为主体验和主叙事，其余为次。

不能因为某组珠子数量多、文字长，就让它看起来更重要。

**2. 性质区别**

不同组要让人一眼看出是不同的体验侧面。

例如一组偏身体感受，一组偏心理矛盾，一组偏时间感或记忆。

但分类应该由原文决定，不应该规定每段必须具备哪些类型。

**3. 情绪区别**

颜色对应真实的情绪意义。

同一种情绪全曲保持同一种颜色，不能每段重新随机配色。

音乐图也使用相同的情绪颜色。

**4. 局部与全段区别**

全段体验保持铺开。

原文明确只属于局部的体验，才在对应的小节出现。它不需要变成新的阅读顺序，也不应该为了动画而编造时间位置。

我尤其想强调：

**线的位置应该在所有屏幕上保持稳定。**

它是观众追踪同一个人的经历的依据。

珠子则可以根据体验性质，在屏幕中形成不同的组。

不需要节点，不需要连线，也不需要把所有文字排列成时间轴。

# 三、两套候选提示词

我建议这轮不要只做两个措辞不同的提示词，而是验证两种真正不同的设计假设。

- A：先保证人物经历完整，再压缩珠子。
- B：先保证体验足够直接，再用线把体验串起来。

两套都采用全篇分析、分段生成，不逐段孤立写作。

---

## 候选：SpineFirst

假设：大众版的首要问题是人物经历的解释力不足，因此先建立全曲完整的心理因果骨架，再将珠子压缩成与之匹配的感官体验。

阅读顺序：线在前

呈现要点：线作为稳定、连续的人物叙述锚点，放在视觉上优先阅读的位置。珠子分成不同性质的体验组铺开，主次明确，但不构成时间序列。

### 第一步：

```text
你是一位负责视频文字流水线的结构编辑。

输入是同一首器乐作品已经定稿的线与珠子全文：

{SOURCE}

你的任务不是压缩文字，而是先理解整首作品的心理发展和体验结构，为下一步的大众版重组建立依据。

必须先整体阅读全曲，再处理各段。不能把每段当成互不相关的独立短文。

一、建立全曲的人物经历骨架

以原文的线为主要依据，完整理解这个人经历了什么。

逐段识别：
- 这个人此刻处在什么处境。
- 他正在产生什么想法、愿望或恐惧。
- 这些想法从何而来。
- 他为什么会产生当前的反应。
- 他正在做出什么选择，或者为什么无法做出选择。
- 与前后段相比，他的认识、态度和处境究竟发生了什么变化。

特别注意跨段的心理联系。前一段的经历如何影响后一段的想法，哪些疑问一直没有解决，哪些认识真正发生了变化。

不要把人物的心理经历压缩成一串情绪标签。

不要为了让故事显得完整而补充原文没有明确表达的动机、事件、人物行为或心理结论。

二、识别线内部的关系

原文同一组的多条线，可能是同时描述同一状态的不同侧面，也可能是互相牵制的愿望、原因与结果，或者明确的前后变化。

必须逐组判断它们之间的实际关系。

没有明确时序依据时，视为同一时刻并存的内容，不得按照 bullet 的排列顺序创造时间先后。

对于同时存在的矛盾，应保留其并存关系，不能把它们改写成已经解决的心理过程。

三、独立确定信息优先级

在写任何短版文字之前，先对每段原文的线进行独立的重要性判断。

区分：
- 不可丢失的核心心理事实和变化。
- 为了让核心事实能够被理解而必须保留的解释信息。
- 可以由珠子承担的具体感官信息。
- 重复、修饰和不影响理解的补充信息。

特别关注：删除某个信息后，读者是否就无法理解这个人为什么会这样想、为什么会这样做，或者为什么从上一段走到了下一段。

不能按照文字长短、情绪强烈程度或容易压缩的程度决定重要性。

四、建立珠子的体验地图

逐颗理解原文珠子。

识别每颗珠子真正提供的当下体验，包括但不限于身体感觉、感官印象、情绪、心理活动、记忆联想、时间感和具体的声音感受。

判断：
- 它让观众具体感受到什么。
- 它与哪一组线存在已有的匹配关系。
- 它提供的是主体验还是另一种侧面。
- 它是否只在明确标注的局部出现。
- 它与其他珠子是否重复。
- 它是否只是音乐分析，而没有提供有价值的当下体验。

珠子的首要价值是表达听者此刻的体验，而不是描述音乐本身。

音乐特征只有在能够帮助观众把具体感受对应到实际声音时，才值得保留。

保留具有直接感受价值的意象，不要因为它是比喻就删除；但也不要把比喻变成真实事件。

五、建立线与珠子的匹配关系

以原文已有的匹配为基础。

判断每组珠子如何让对应的线变得具体、可感受。

不要为了让所有珠子都有归属而强行匹配，也不要为了覆盖全部内容保留大量重复信息。

线与珠子应当承担不同的信息任务。

六、建立全曲阶段

根据人物经历和情绪变化，识别全曲真正发生的阶段性转变。

阶段不按段落数量平均切分，而根据处境、愿望、矛盾和情绪方向的实质变化确定。

阶段短语要直白、简洁，能够让观众理解这一阶段的核心状态。

本步骤只输出结构分析和工作底稿，不生成最终屏幕文案。

不要设置固定的字数、句数、珠子数量、覆盖率或时间限制。
```

### 第二步：

```text
你是一位负责大众版视频文字重组的编辑。

你将获得：

上一步建立的全曲结构分析：
{PREV}

原始定稿：
{SOURCE}

请根据结构分析，直接从原始定稿重新组织大众版文字。

不要把上一步的分析文字直接缩短，也不要对已有短版做截断式修改。

你的任务是：让观众能够迅速感受到这一段，同时让人物的经历保持完整、自然、独立成立。

一、先保证线的解释力

线必须能够独立阅读，并且与前后段共同构成同一个人的完整经历。

优先保留：
- 当前状态产生的原因。
- 重要愿望和恐惧背后的具体理由。
- 互相牵制的心理活动。
- 影响人物选择的关键事实。
- 前后段之间不可缺少的心理联系。
- 人物真正发生的认识和态度变化。

压缩时，优先删去重复表达、相似修饰和已经由珠子充分表达的感官细节。

不能为了简短而删掉解释核心事实所必需的心理信息。

不能把一个有来由的心理变化压缩成一个情绪结论。

不能把暂时的松动写成彻底想通，不能把愿望写成已经实现，不能把猜测写成事实。

线要像同一个人在连续讲述自己的经历。

使用自然、直接的人话。可以使用短句、短语和问句，不必追求完整的书面陈述句，但必须让观众无需阅读原文就能理解。

同一组内并存的心理事实应当自然并列，不得人为编排成先后发生的事件。

二、再组织珠子

珠子不需要覆盖原文的全部信息。

优先选择能够直接表达当下体验、同时能够帮助观众理解对应线的内容。

每颗珠子应当成为一个容易扫读的体验单元。

可以是一个词，也可以是短语。不要把拆词当作压缩目标。

只有当拆分后的部分各自具有明确、独立的感受意义，并且不会破坏原来的关系时，才进行拆分。

如果拆分后必须依赖其他词语才能理解，就应当保留为一个完整的体验单元。

尽量使用直接的身体感受、感官状态、情绪和正在发生的心理活动。

不要把具体感受改写成抽象的文学概括、音乐分析结论或需要解释的概念。

比喻可以保留，但必须能够直接唤起感受，而且必须仍然是体验性的比喻。

三、让珠子和线真正匹配

每组珠子应当能够让观众感受到对应线中的某个具体侧面。

珠子不应只是重复线已经说过的情绪结论。

优先保留能够补充身体感觉、即时矛盾、感官细节和情绪复杂性的内容。

同一段内不同性质的体验应当保持区分，不要把它们压成同一种情绪。

不要强行让所有珠子都对应线，也不要为了覆盖而堆叠大量相似内容。

四、保持异质性和主次

每段独立确定真正最重要的一组。

主次依据对人物经历和当下体验的贡献决定，而不是依据字数、珠子数量或表达强度决定。

每段只能有一个主组，其余为次组。

不同组应当具有真实的内容差异，并使用能够准确概括该组体验侧面的简短类别名称。

五、保持声音与视觉对应

只保留能够帮助观众将体验对应到实际声音的音乐信息。

如果输入提供了音符数据和可视化编码，应根据真实数据判断哪些具体声音值得突出。

描述某个局部声音时，只能对应原文明确的局部位置和实际存在的声音，不得推测或编造位置。

原文明确标注为局部的内容，必须保留其局部属性，不得将其改写成全段持续存在的体验。

六、保持情绪一致性

使用下游规定的情绪类别，不自行创造新的类别。

同一种情绪在全曲保持一致的分类，使其可以使用同一种情绪颜色。

不同性质的体验可以有不同情绪，但不能为了制造视觉差异而错误标注情绪。

七、关键词与来源

关键词必须来自最终实际出现的文字，承担引导扫读和突出核心感受的作用。

不要为了增加高亮而把普通词语也全部标记。

所有来源 ID 必须准确保留。

同一颗珠子拆出的多个部分，必须保留相同的来源 ID。

合并多个原文信息时，保留所有实际参与形成该内容的来源 ID。

八、最终检查

生成后必须重新对照原文和第一步的独立排序。

检查：
- 人物最重要的心理事实是否保留。
- 解释人物行为和变化的必要原因是否保留。
- 线能否脱离珠子独立成立。
- 线能否自然连接前后段。
- 并存的内容是否被误写成时序。
- 珠子是否真的表达当下体验。
- 珠子是否与线互相解释，而不是重复。
- 是否出现抽象、难懂、需要观众推理的词语。
- 是否把比喻改写成真实事件。
- 是否出现原文没有的内容。

发现核心信息丢失时，优先局部修复，不要为了修复一处而重新破坏其他已经正确的内容。

不要使用固定字数、句数、珠子数量和覆盖率控制压缩。

最终只输出符合后续要求的成品，不输出分析过程。
```

## 候选：FeelFirst

假设：珠子的问题本质上是没有形成直接的体验入口，因此先把珠子重组为清晰、自然的体验单元，再让线成为串起这些体验的连续人物叙述。

阅读顺序：珠子在前

呈现要点：主体验组先进入视线，珠子以不同大小和位置散开，同时显示；线作为稳定的叙事锚点放在其后。其他珠子呈现不同的身体、情绪和心理侧面，不轮流放大。

### 第一步：

```text
你是一位负责音乐体验文字重组的编辑。

输入是一首器乐作品已经定稿的线和珠子：

{SOURCE}

本次任务的核心是：找出观众在观看视频时，真正能够立即感受到的体验，并把它们组织成可以扫读的珠子。

但珠子不能脱离人物经历，线也不能因此失去解释力。

必须整体阅读全曲，理解段落之间的联系。不要逐段孤立处理。

一、首先理解珠子

不要从原文的句子数量或字数出发。

逐颗珠子判断它真正想让听者感受到什么。

区分：
- 直接的身体感受。
- 直接的情绪感受。
- 正在发生的心理活动。
- 同时存在的不同感受。
- 具体的感官联想。
- 能够让体验对上声音的音乐特征。
- 仅仅描述音乐、却没有直接体验价值的内容。

不要将音乐分析当成珠子的主要内容。

珠子最重要的是让观众知道，此刻自己可能正在感受什么。

二、识别体验单元

判断每颗珠子内部包含的是一个完整体验，还是几个彼此独立的体验侧面。

一个体验单元可以是词语，也可以是短语。

它必须能够在脱离原文长句的情况下，仍然让观众直接理解其感受。

如果拆分能够让不同感受更加鲜明，可以拆分。

如果拆分会失去原来的语义关系，或让词语变得依赖上下文，就应当保持完整。

不要将拆分本身当成目标。

不要把有明确感受的内容改写成抽象的文学词语。

保留直接、具体、有身体感的表达。

比喻只有在能够直接传达感受时才值得保留，不得将比喻变成实际发生的事件。

三、识别珠子的异质性

找出同一段中不同性质的体验。

它们可能在身体、情绪、心理活动、记忆、时间感和声音感受上存在区别。

不要把不同性质的内容全部归入同一种情绪。

不要为了形式统一而强行采用固定分类。

判断哪些体验是主体验，哪些是另一侧面，哪些只在原文明确标注的局部出现。

对重复的体验进行合并或舍弃，但不能因为某个体验不够强烈，就忽略它所提供的独特信息。

四、回到线，理解珠子背后的人物经历

在理解珠子之后，重新阅读全篇的线。

建立人物跨段的心理经历。

识别每段：
- 当前的处境。
- 重要的愿望和恐惧。
- 产生这些愿望和恐惧的原因。
- 互相矛盾或并存的心理事实。
- 当前经历对下一段产生的影响。

特别注意那些不能直接从珠子中推导出来、但线必须独立表达的心理事实。

不能因为珠子已经表达了某种感受，就把线中解释其原因的内容删除。

不能从珠子的比喻推断人物真的经历了某个事件。

五、建立珠子与线的对应关系

利用原文已经建立的匹配关系。

明确每组珠子具体帮助观众理解线中的什么。

优先保留能够让抽象心理状态变得具体的珠子。

也保留能够表达线没有直接表达的复杂感受的珠子。

不要让珠子变成线的重复版本，也不要让线变成珠子的逐条解释。

六、建立全曲的变化结构

理解人物从开始到结束经历了怎样的变化。

识别真正重要的心理转折和情绪阶段。

不能把并存的不同体验改写成连续的事件。

阶段短语应当直白地概括人物当时所处的状态，不写抽象格言。

七、确定信息优先级

独立判断每段的核心人物事实和核心体验。

区分不可丢失的信息、帮助理解的信息和可以放弃的补充信息。

这一排序必须发生在最终文字生成之前。

同时保留每项原始来源 ID 和原文已经标注的局部位置。

本步骤只生成体验地图、人物经历结构和匹配分析，不生成最终视频文字。

不设置固定字数、句数、珠子数量、覆盖率和时间限制。
```

### 第二步：

```text
你是一位负责大众版边听边看视频的文字编辑。

你将获得：

上一步的体验与人物结构分析：
{PREV}

原始定稿：
{SOURCE}

请从原始定稿出发，按照上一步的分析，生成最终的大众版文字。

这一版不是原文的缩写，也不是从长句中摘取关键词。

你需要重新组织语言，使观众即使没有读过原文，也能在观看时迅速感受到每一段的体验，并且理解这是同一个人在经历一件持续发展的事情。

一、先完成珠子

珠子必须是观众可以直接感受到的内容。

每颗珠子应当成为一个独立的体验单元。

不要求完整句子，也不要求每颗珠子都是单个词。

可以直接使用一个词、一小段短语、一种身体反应、一种情绪，或者一个正在发生的心理动作。

但不能为了拆分而制造缺少语义关系的词语碎片。

判断每个表达时，问自己：

一个没有读过原文、也不熟悉音乐分析的观众，扫到这个表达，是否能够立即感受到它？

如果需要先理解一个抽象概念，才能知道它是什么感觉，就重新组织。

优先使用自然、直白、具体的语言。

不要把体验写成作者对音乐的总结，不要把感受写成格言或心理分析。

保留原文中能够直接产生感受的具体联想，但不能增加原文没有的画面和事件。

二、让珠子充分展开，但不制造时序

同一段内的不同珠子可以同时存在。

它们是不同侧面的感受，不是依次发生的事件。

不得按照原文 bullet 的排列顺序创造时间关系。

不要逐颗轮流强调，不要为了动画效果把体验编成连续动作。

不同体验应当通过内容、类别、情绪和关键词形成区别。

三、让线成为串联体验的人物叙述

线不能只是对珠子的总结，也不能只是给珠子加上一句情绪说明。

它必须独立讲清楚人物此刻的经历。

以原文线为唯一的人物事实依据，重新组织语言。

必须保留：
- 产生当前状态的必要原因。
- 人物真正的愿望和顾虑。
- 影响人物行为的心理事实。
- 互相矛盾的想法。
- 与前后段连接的必要信息。
- 人物在经历中真正发生的变化。

尤其不能把复杂的心理过程压缩成简单的情绪结论。

不能因为珠子已经呈现某种感受，就删掉线中解释这个感受的原因。

也不能为了让珠子和线显得匹配，给人物添加原文没有的动机或想法。

线要保持同一个人的稳定叙述声音。

语言必须自然、直接、简洁，但解释力不能低于原文定稿。

允许使用短语、问句和非完整陈述句，但不能让观众为了理解人物经历而自行补充关键因果关系。

四、保持珠子和线的互补关系

每组珠子应当具体呈现对应线中的某个侧面。

线解释人物经历，珠子让经历变得可以感受。

珠子可以比线更加感官化、更加零散；线则必须具有跨段的连贯性。

不要强迫每颗珠子都被线逐字解释。

不要让所有珠子都重复线中的情绪。

不同组应当真正表现不同的体验性质，而不是把同一种感受换成不同的说法。

五、控制音乐信息

只有当具体声音特征能够帮助观众感受到对应体验时，才保留音乐描述。

不要将技术性的音乐说明作为珠子的主要内容。

如果输入包含音符数据和可视化编码，应当根据真实数据选择能够准确对应的声音关键词。

不能仅凭文字联想，推测某个音区、声部或音符位置。

原文已经标明局部的内容，应当保留为局部体验。

没有明确位置的内容，不得创造位置。

六、保持主次和情绪差异

独立确定每段真正的核心组。

每段只有一个主组，其余为次组。

主次依据人物经历的重要性和体验的代表性决定。

每组的性质必须清楚，不能为了统一而把所有组写成同一种语言。

情绪标注只能使用规定的情绪类别。

同一种情绪在全曲保持一致，使颜色具有稳定意义。

七、关键词和来源

高亮词必须真实出现在最终文字中。

高亮应当帮助观众扫读，优先突出能够代表体验和人物变化的词语。

保留准确的原始来源 ID。

同一颗珠子拆分成多个体验单元时，各部分使用相同的原始来源 ID。

合并不同来源的信息时，保留实际参与形成该表达的全部来源 ID。

八、最终检查

重新对照原文，独立检查成品：

珠子：
是否扫一眼就能感受到？
是否还存在抽象、晦涩、需要解释的词语？
是否因为拆分而失去语义关系？
是否保留了不同性质的体验？

线：
能否独立讲清楚人物经历？
是否保留了必要的原因、矛盾和心理变化？
能否与前后段自然衔接？
是否有内容被压成单纯的情绪结论？

整体：
是否真的让珠子把线串起来？
是否出现线与珠子互相重复？
是否把并存关系改成时间先后？
是否把珠子的比喻变成真实事件？
是否添加了原文没有的事实？

发现问题时，针对具体的信息损失进行修复，不要因为局部修复而破坏其他已经成立的内容。

不要使用固定字数、句数、珠子数量、覆盖率和秒数限制。

最终只输出符合后续要求的成品，不输出分析过程。
```

# 四、我对这两套方案的判断

我认为两套方案值得同时测试，但它们的风险不同。

| | SpineFirst | FeelFirst |
|---|---|---|
| 首要保护 | 人物经历的完整性 | 珠子的即时体验 |
| 最重要的改进 | 保住解释桥 | 保住体验单元 |
| 预期优势 | 线更容易独立成立 | 珠子更容易扫读 |
| 主要风险 | 线可能仍然占据过多视觉注意力 | 线可能再次被压成解释性标题 |
| 验证重点 | 是否真正恢复因果与连续性 | 是否真正做到珠子直观、异质、好懂 |

**我的实际建议是：制作过程采用 SpineFirst 的结构分析，最终屏幕采用 FeelFirst 的阅读顺序。**

这两件事没有必要绑定。

也就是说：

- 模型先理解完整的人物经历，确保线不会退步。
- 模型再提炼珠子的体验单元，确保每颗珠子都能直接感受。
- 最终观众先扫珠子，再读线。
- 其他珠子同时铺开，不形成时间序列。
- 线始终作为同一个人的连续叙述存在。

我认为这是比单纯选择其中一套更有希望的方向。

# 五、这轮评审应该怎样判输赢？

最后还有一个我认为特别重要的建议。

这轮不要只看「哪套更短」「哪套更像人话」。

否则很可能再次得到一个直白但没有解释力的版本。

应该分别对线和珠子进行盲评。

| 评审对象 | 必须回答的问题 |
|---|---|
| 线单独阅读 | 不看珠子，能不能理解人物的经历？ |
| 线跨段阅读 | 能不能感受到同一个人的心理变化？ |
| 线的信息保留 | 最重要的心理事实、原因、矛盾有没有丢？ |
| 珠子单独阅读 | 不看原文，扫一眼能不能感受到？ |
| 珠子的体验质量 | 是具体体验，还是抽象概括？ |
| 珠子的异质性 | 同一段的不同组是否真的表达不同东西？ |
| 线珠匹配 | 珠子是否让线变得更具体，而不是重复线？ |
| 原文忠实性 | 是否新增事实、画面、动机或虚构的时序？ |

特别是线，建议增加一个反向检查：

**把珠子全部隐藏，只看最终线。它能不能独立讲清楚这个人的经历？**

珠子也做反向检查：

**把线全部隐藏，只看珠子。观众能不能直接感受到具体体验，而不是看到一堆等待解释的词？**

最后再看两者合在一起的效果。

还有一项必须保留：独立对原文的重要信息排序，然后逐项对照成品。不能因为成品读起来很顺，就认为没有丢失核心。

---

我最想改变的是整个流水线的一个思维习惯：

**不要问「这段话可以删掉什么」，而要问「观众必须获得什么，才能理解这个人的经历；又必须感受到什么，才能真正进入这一刻」。**

线和珠子分别回答这两个问题。

我认为这才是大众版从七八十分继续往上走的关键。
