<WritingBlock id="58314" variant="document">**（1—23）**

**我刚知道自己想要什么，就立刻开始怀疑自己，像是有顾虑就没资格决定。**
← 因为每个选择都能找到合理的反对理由，我分不清自己还没想透，还是不敢承认。
→ 于是我不敢做主，只能反复审问自己，连开头的摇摆都像是找不到立足点。

**（24—65）**

**我终于尝到自己说了算的踏实，却又怕一改主意就证明自己根本没变。**
← 因为反复审问自己让我很难做主，我靠直接说“我就要这个”找回了果断的感觉。
→ 于是我开始逼自己不能改口，昂扬的舞步里也多了证明自己的压力。

**（66—91）**

**我犹豫，是因为我还在乎别人，也不愿把复杂的事说得轻巧。**
← 因为我把坚定当成必须守住的状态，心软和顾虑就成了我眼里的麻烦。
→ 于是我既舍不得刚得到的力量，也不肯否认自己会心疼人，明亮的舞曲里开始有了阴影。

**（92—115）**

**我还是坚持了原来的决定，可心里的顾虑根本没有消失。**
← 因为我知道一直想下去就不会有结果，也没法再把所有犹豫都算成软弱。
→ 于是我只能带着顾虑往前走，熟悉的主张再次响起，却不再那么稳。

**（116—147）**

**我终于承认，自己也想被理解，累了能有人让我靠一会儿。**
← 因为我开始看见，自己除了想做主，也有需要别人支持的时候。
→ 于是我更明白自己为什么害怕，却仍不知道怎么选；轻柔的旋律像是在等我把心里的话说完。

**（148—180）**

**我以为说清自己的感受就能安稳下来，结果做选择还是让我为难。**
← 因为我想顾及别人，也不愿处处让步，还想周全每件事，却没法一直拖下去。
→ 于是我开始看见，迟迟不决定也在消耗自己，只是代价暂时没那么显眼；舒缓的音乐让我更难回避这一点。

**（181—205）**

**我知道自己得选，却还担心每次都这么费劲，是不是说明我不够坚定。**
← 因为我不能再靠“再看看”躲开责任，也没法保证决定之后不会后悔。
→ 于是我只能承认自己会舍不得，仍然接过选择的责任；旧旋律再次催我站出来，却不再许诺一切都会顺利。

**（206—213）**

**我刚下决心，“可是”又冒出来了，我不想把心软的自己赶走。**
← 因为那些顾虑里有我对别人的在乎，也有我想被理解的需要。
→ 于是我得带着这些不安往前走，不再让它们每次都取消我的决定；慢主题短暂回来，提醒我两边都还在。

**（214—215）**

**我又开始摇摆，但这次我知道自己想要什么，也知道怕失去什么。**
← 因为我已经听见决定两边的声音，却还没习惯带着这些拉扯往前走。
→ 于是我得问自己，敢不敢认下这是我的选择；开头的犹疑又响起，却没那么茫然。

**（216—225）**

**我不再等到百分之百确定，才肯承认自己还是想试试。**
← 因为我开始容许自己仍会想到另一条路，也不再因此否定眼前的愿望。
→ 于是我能带着发抖先迈一步，轻柔、断续的音乐也像在陪我试一试。

**（226—241）**

**我还怕后悔，也看得到别的路，但不想再拿这些理由拖着不动。**
← 因为我开始问自己愿不愿为选择负责，不再只顾着判断自己够不够坚定。
→ 于是心里的争执还在，我已经开始行动，舞曲的步子也重新聚拢。

**（242—253）**

**我现在能说清自己为什么选，也不必先把心软的那面压下去。**
← 因为我知道自己曾靠强硬迈出步子，也知道一味顾及别人时会拖着不决。
→ 于是我不用先证明哪一面错了才行动；昂扬的主旋律回来，我站出来了，也承认以后可能会变。

**（254—288）**

**我以后还会摇摆，甚至改主意，但不必因此认定之前的努力全是假的。**
← 因为我尝过果断带来的踏实，也吃过硬撑的苦，知道拖着不选同样会付出代价。
→ 于是每次怀疑回来，我都重新想清自己要什么、怕伤到谁、愿付什么代价；即使心软、心里还有矛盾，我也能认下自己的决定。</WritingBlock>
