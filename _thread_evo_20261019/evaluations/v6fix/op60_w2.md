# Op.60｜关系图（A2 整首修补 w2）

**Center：**对亲密的投入与自我克制始终相互牵制。

### S01｜1–3 小节　（还说不清）

- 他一想到这个人就柔软起来，已经很想靠近了。
- → 这份喜欢才刚冒出来，他想多留它一会儿，又怕自己一下子陷得太深，便先收住了。

### S02｜4–16 小节　（没在想）

- 他暂且不替这份喜欢安排去向，只想先让眼前的亲近自然发生。
  - ← 提供理由：（1–3）「怕陷得太深」
- → 他不拿每次靠近来核对回应，便能安心相处、真心关心对方，当时觉得眼前这样就够了。
- → 他享受着眼前的亲近，也隐约舍不得它过去，明明还没失去，心里已先泛起酸楚。
- → 那股喜欢有时一下涌上来，他任自己热切了一阵，随后还是想给自己留点余地，慢慢收回来。
- ⟲ 仍在起作用：（1–3）「怕陷得太深」

### S03｜17–23 小节　（正在面对）

- 他还沉在刚才相处的满足里，安静下来也觉得舒服，心思一时飘远。
  - ← 提供理由：（4–16）「眼前这样就够」
- → 他开始盼着这份亲近能长久，也知道自己只能决定怎样珍惜对方，不能替对方作主。
  - ← 提供理由：（4–16）「先泛起酸楚」
- → 他原以为眼前的亲近已经够了，没想到竟会想知道自己是不是特别；这个念头偶尔冒头，又让原先的自在卡住。
  - ← 动摇：（4–16）「先泛起酸楚」

### S04｜24–34 小节　（正在面对）

- 一想到自己开始想要更多，他怕这份新期待毁掉眼前的亲近，也不愿催对方给答案。
  - ← 提供理由：（17–23）「是不是特别」
- → 他把心思转回眼前能给的关心，提醒自己真心对对方好，不必每次换来表示或保证，这样想确实让他轻松。
- → 轻松下来后，他更愿意付出，也不再盘算自己给了多少，连显得更在乎也没那么让他害怕。
- → 热情一度冲到高处，他想把眼前的亲近抓牢，却又担心自己的急切会弄坏它，慢慢把心收了回来。
- → 他把这份暂时的轻松当成了保证，以为只要不提要求，就不会失去。
- ⟲ 仍在起作用：（4–16）「先泛起酸楚」

### S05｜35–39 小节　（还说不清）

- 热情退下去后，他又想知道对方有没有把他放在心上；刚才的满足没法替他回答。
  - ← 失效：（24–34）「不会失去」
  - ← 唤起：（17–23）「是不是特别」
- → 他因此难堪，怀疑自己体贴时是不是也盼着被珍惜，开始承认自己并非毫无所求。
- → 他不愿把先前的快乐算成交换，那份真切的快乐也让他慢慢松开抓紧当下的劲头。

### S06｜40–50 小节　（没在想）

- 他发现多给一些也没让自己不再盼回应，便不再拿慷慨证明自己无所求。
  - ← 提供理由：（35–39）「并非毫无所求」
- → 他把心思放回眼前愿意做的关心，真心盼对方过得好，也不再时时核对对方是否在意。
  - ← 提供理由：（35–39）「松开抓紧」
- → 有些担心，他知道只能自己慢慢消化；安静下来，它又会冒出来。
- 独自惦念对方本身仍让他觉得甜，可这份心意没有回应可依，心底也会有一点孤单。

### S07｜51–61 小节　（正在面对）

- 独自惦念本身就让他觉得甜，他舍不得少喜欢一点，后来心思越发常落在对方身上，想靠近的念头也更难收住。
  - ← 提供理由：（40–50）「独自惦念的甜」
- → 他仍觉得不催促才是对的，也怕自己的期待牵着自己走。
- → 可他还是盼对方能领会自己的关心，只能把想被回应的心思留给自己。
- ⟲ 仍在起作用：（24–34）「不愿催对方」

### S08｜62–71 小节　（没在想）

- 靠近时的安心、给予时的满足、独自惦念的甜都是真实的；他不想再因怕受伤压住这阵欢喜。
  - ← 说明：（4–16）「眼前这样就够」
  - ← 说明：（24–34）「不必换来保证」
  - ← 说明：（40–50）「独自惦念的甜」
  - ← 提供理由：（51–61）「更难收住」
- → 他让自己顺着想靠近的兴致高兴一会儿，心里有了点玩心，也暂时不拿未来来检查自己。
- → 他刚刚才允许自己尽情欢喜，格外舍不得这份少有的轻松退去，心里也重新冒出想被对方同样珍惜的愿望。

### S09｜72–77 小节　（正在面对）

- 欢喜稍落下来，他才承认自己想要的不只是把喜欢给出去，也想让对方主动靠近、把他放在心上。
  - ← 唤起：（62–71）「想被同样珍惜」
- → 他怕自己一直盼回应，会让对方觉得非答应不可，真要把渴望压回去，他又很难受。
- → 眼前的亲近本身仍然珍贵，让他心里的不安暂时退开，可他找不到两全的做法，还是委屈又疲惫。

### S10｜78–83 小节　（正在面对）

- 他先不逼自己马上选边，仍带着盼望喜欢，也承认自己不知道对方会不会同样靠近。
  - ← 提供理由：（72–77）「委屈又疲惫」
- → 不用立刻决定后，他压着的委屈和渴望松开一点，连身体都轻了；这只是喘口气，不是答案。

### S11｜84–92 小节　（正在面对）

- 不再逼自己选边后，他又能享受熟悉的亲近；这回他承认自己确实想被珍惜。
  - ← 提供理由：（78–83）「带着盼望喜欢」
- → 他不再拿无所求来证明体贴，压着的欢喜一下涌上来，浓烈得胸口发疼。
  - ← 改写：（35–39）「并非毫无所求」
- → 他仍不知道对方会不会同样选择自己，但这阵满足确实发生了，并不是对方给了新的保证。
- ⟲ 仍在起作用：（72–77）「主动靠近」

### S12｜93–102 小节　（没在想）

- 他想靠近这个人的心意变得格外清楚，也开始盼对方同样深切地珍惜自己。
  - ← 提供理由：（84–92）「确实想被珍惜」
- → 这阵欢喜大到把他整个人卷进去，他一时顾不上以后会怎样，连自己的得失都暂时退到一旁。
- → 这阵欢喜没有让他不再想要回应，他仍盼对方同样选择自己，甚至觉得眼前的满足还不够。
  - ← 限制：（84–92）「没有新保证」
- → 欢喜稍稍退去，未回答的事又回到心里。

### S13｜103–110 小节　（正在面对）

- 欢喜仍在，他却又想起自己最想要的是对方也选择自己；这一点并没有得到回答。
  - ← 动摇：（93–102）「还想要回应」
- → 收住心意那阵，他照样想被珍惜；尽情喜欢时，他也只能等对方自己作决定。
- → 他不催对方替自己消除不安，也不因怕落空就压下渴望，只能自己承受这份拉扯。

### S14｜111–116 小节　（正在面对）

- 这些办法都没让他得到保证，他不再等到完全安心才肯继续喜欢。
  - ← 提供理由：（103–110）「等对方决定」
- → 这个人对他很重要，他仍想和对方互相靠近，也愿意让对方自己作决定。
- → 他在自在靠近、真心给予、独自惦念和尽情欢喜里都真实快乐过，这些经历让他更舍不得这个人，也愿意继续喜欢。
  - ← 说明：（4–16）「眼前这样就够」
  - ← 说明：（24–34）「不必换来保证」
  - ← 说明：（40–50）「独自惦念的甜」
  - ← 说明：（62–71）「有了点玩心」
- → 他不再一想到可能受伤就把喜欢收回，也不逼自己立刻解决，心里仍热，身体却慢慢安静下来。
  - ← 改写：（1–3）「怕陷得太深」
- ⟲ 仍在起作用：（72–77）「非答应不可」
