# Op.61｜关系图（在 v6 上修补，w27）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他怕由着事情照旧就等于认了它们本该如此，也怕真投进去会失去别的东西。
- → 他还想找个理由才敢往前走。
- → 每次刚觉得想通，舍不得又回来，连那点确信也变得陌生，他也为非得想透才肯动而难堪。

### S02｜24–65 小节　（正在面对）

- 从前他总要先问值不值得，如今还没想透，也先接下自己能做的一份，尽力去做。
  - ← 改写：（1–23）「非得想透」
- → 结果还没把握，疑虑和牵挂也还在，可他做着做着有了些力气，也有点骄傲，越投入越痛快。
- → 他还是舍不得过去，也没找到放下它的理由；开始做眼前的事，并不能让过去回来。
- → 一察觉自己又在惦记那些放不下的事，他就急着把心思拉回眼前，免得又陷回非得想透才肯动的老样子。
- → 一想到仍放不下的事，他就又难以把心思放在眼前的事上；可他还是重新提起劲，继续做自己能做的那一份。

### S03｜66–91 小节　（正在面对）

- 他真往前走了，少问自己该不该走，也庆幸没退。
- → 他想要自在亲近、不必时时防备的生活，眼下还做不到，但他暂时不急着追问自己为何非得用力。
- → 眼前的难处还在，他又想起当初不肯再等、先做能做的那一份，也重新掂量起当初的选择。

### S04｜92–115 小节　（正在面对）

- 轻松退去后，他还记得那一步确实让自己重新动起来，所以仍愿意坚持。
  - ← 唤起：（66–91）「先做能做」
- 他确实经历过那样的亲近，所以眼下的不安还不足以证明当初那一步是错的。
- → 他怕一停下来，就得承认那份亲近回不到从前，所以一直逼自己往前做，想躲开这个承认。
- → 可他还想要那种不用防备的亲近，光靠坚持仍没法让他安心。

### S05｜116–147 小节　（正在面对）

- 那一步曾救他脱离犹豫，行动明明还不够，他却舍不得松手，怕承认失望就是变心，便逼得更紧。
  - ← 提供理由：（92–115）「重新动起来」
- 他想到那种不必防备的亲近，却怕自己因为舍不得它而停下行动。
  - ← 唤起：（92–115）「不用防备的亲近」
- → 他把眼前的难处当成还没克服的迟疑，便认定自己还得继续逼自己往前。
- → 他曾在行动中感到有力量，便要求自己一直撑住，一累就怪自己不够坚定，连歇一下都觉得不该。
  - ← 提供理由：（24–65）「越投入越痛快」
- → 他发现自己一直拿坚不坚强来要求自己，终于不想再证明自己多坚强。
- → 他终于承认，自己舍不得的是那种不必防备的亲近，继续逼自己往前并不能代替它。

### S06｜148–180 小节　（没在想）

- 催逼停下来后，他发现自己舍不得的不是一时舒服，而是曾真心相信过的生活。
  - ← 提供理由：（116–147）「证明坚强」
  - ← 说明：（116–147）「不必防备的亲近」
- → 他盼着和人亲近时不必时时防备，也盼着珍惜的东西不用靠争抢才能留住。
- → 他想付出时只是因为喜欢，不必反复证明自己值得被爱、被接纳，也不必先想着靠近会受伤。
- → 他以前确实经历过那样的亲近，不愿只因眼下做不到，就把这份向往说成软弱。
  - ← 提供理由：（92–115）「那样的亲近」
- → 他不再急着证明自己有多坚强，也就不再把心里柔软看成会停步的危险。
  - ← 提供理由：（116–147）「证明坚强」
- → 他允许自己去爱、去相信，不再要求这份向往立刻证明有用，也不拿它和责任比轻重。
- → 他终于明白，想要那种生活并不等于不肯承担眼前的事。
- → 他暂时不愿把心思拉回眼前的难处，因为他不想又把自己真正向往的生活搁到一边。

### S07｜181–205 小节　（正在面对）

- 他把熟悉的亲近误认为那种生活已经回来，后来才发现现实并没有变；他懊恼自己又沉浸在那种生活里，忘了眼前还有事要面对。
  - ← 唤起：（148–180）「搁到一边」
- → 他当初不肯再等，是怕珍惜的东西继续受损，光在心里想着那种生活也护不住它们。
  - ← 提供理由：（24–65）「放下它的理由」
- → 他想重新投入，却已不能毫无顾忌，怕自己又只顾硬撑，把刚找回的温柔磨掉，连想留住的生活也顾不上。
- → 他原以为想清为何不能再等就能安心，如今还得想怎样争取才不伤温柔，理由更多了，还是定不下来。

### S08｜206–213 小节　（没在想）

- 为难时，他想起自己曾真心相信过那种不必防备的生活，不愿因为眼前做不到就把这份向往压下去。
  - ← 提供理由：（148–180）「亲近经历」
- → 他愿意再爱惜片刻，把没答案的事先搁一边。
- → 他不必再靠不停往前证明自己够坚定，因为一味硬撑会让他顾不上真正想留住的生活。
  - ← 提供理由：（116–147）「证明坚强」
  - ← 提供理由：（181–205）「磨掉温柔」

### S09｜214–215 小节　（正在面对）

- 他还没想出怎么做，才能不让珍惜的东西受损，也不把刚找回的温柔磨掉。
  - ← 提供理由：（181–205）「珍惜的东西」
  - ← 限制：（181–205）「磨掉温柔」
- → 他这回知道自己为什么迟疑：怕往前又把自己逼得太狠，也舍不得那种不必防备的生活。
- ⟲ 仍在起作用：（181–205）「磨掉温柔」

### S10｜216–225 小节　（正在面对）

- 他不想再靠硬撑去争取那种生活，可又没想出不伤温柔的办法。
  - ← 提供理由：（116–147）「证明坚强」
  - ← 限制：（181–205）「磨掉温柔」
  - ← 说明：（181–205）「理由更多」
- → 他舍不得丢开那一步，也舍不得那份安宁。
  - ← 提供理由：（92–115）「重新动起来」
  - ← 提供理由：（148–180）「亲近经历」
- → 他怕再往前又把自己逼得太狠，可那些妨碍那种生活的事仍让他放不下。
  - ← 提供理由：（214–215）「不必防备」
- → 他反复想着自己究竟想护住什么，想歇一歇也不等于要把它丢下。
  - ← 改写：（148–180）「搁到一边」
- → 他还不知道往后该怎么过，却不再急着判哪一边错，逼自己立刻选边的劲也松了一点。
- ⟲ 仍在起作用：（148–180）「时时防备」；（181–205）「珍惜的东西」

### S11｜226–241 小节　（正在面对）

- 他心里仍没底，开始重新想眼前还能承担什么。
  - ← 提供理由：（216–225）「立刻选边」
- → 他已经试过，行动带来的力气并不能消掉对那种生活的牵挂。
  - ← 说明：（24–65）「越投入越痛快」
- → 他想到，难处不在自己不够坚定：行动给他力气，那种生活给他安慰，两样都舍不得，却很难不伤到其中一样。
  - ← 改写：（116–147）「还没克服」
  - ← 提供理由：（148–180）「亲近经历」
  - ← 限制：（181–205）「磨掉温柔」
- → 想到要付出的代价，他心里还是疼，盼着别失去太多。
- → 他没想出两全办法，也怕争取伤到安宁，可他知道不争取也护不住珍惜的东西，便决定先做眼前能做的事。
  - ← 提供理由：（181–205）「珍惜的东西」
- ⟲ 仍在起作用：（181–205）「磨掉温柔」

### S12｜242–253 小节　（正在面对）

  - ← 提供理由：（226–241）「不争取」

  - ← 限制：（226–241）「两样都舍不得」
- → 他舍不得那种不必时时防备的生活，也愿为真心爱惜的一切负责，不再把这份牵挂当成行动的拖累。
  - ← 改写：（226–241）「两样都舍不得」
- → 他知道争取仍可能伤到那种生活，却还是按自己已经作出的决定往前做。
- ⟲ 仍在起作用：（226–241）「不争取」

### S13｜254–288 小节　（正在面对）

  - ← 提供理由：（181–205）「珍惜的东西」
  - ← 提供理由：（226–241）「不争取」
- → 他不再嫌自己肩上有事还惦记那种生活，发现这份惦记和眼前该做的事都推着他向前，心里很高兴。
  - ← 改写：（226–241）「两样都舍不得」
- → 他记得自己当初确实因相信那种生活而快乐过，所以眼下还没过上，也不愿否认那段经历。
  - ← 唤起：（148–180）「承担眼前」
  - ← 说明：（148–180）「搁到一边」
- → 他试过光靠坚持往前，仍没法让自己安心，所以不再把加力当成唯一办法。
  - ← 失效：（92–115）「不用防备的亲近」
- → 他愿意为那种生活吃苦，也会想想再使劲会不会把刚找回的温柔搭进去。
  - ← 改写：（181–205）「磨掉温柔」
  - ← 限制：（226–241）「两样都舍不得」

- ⟲ 仍在起作用：（148–180）「时时防备」；（242–253）「作出的决定」
