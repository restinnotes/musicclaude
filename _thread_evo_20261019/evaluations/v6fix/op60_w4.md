# Op.60｜关系图（A2 整首修补 w4）

**Center：**对亲密的投入与自我克制始终相互牵制。

### S01｜1–3 小节　（还说不清）

- 他一想到这个人就柔软起来，很想亲近，自己也被这份心意来得突然吓了一下。
- → 他想让这份喜欢多留一会儿，却怕心意露得太明白会改变关系，靠近时便收住一点。
- → 眼下还没非得决定关系去向，喜欢也轻得不稳，他却舍不得就这样放下。

### S02｜4–16 小节　（没在想）

- 他暂且不替喜欢安排去向，只让眼前的亲近自然发生。
  - ← 提供理由：（1–3）「多留一会儿」
  - ← 提供理由：（1–3）「轻得不稳」
- → 他不因喜欢就要求对方回应，也不总查看对方有没有接住，所以能安心关心对方。
- → 那时他真觉得，能这样安静地亲近对方，眼下已经够了。
- → 相处得这样舒服，他已盼着这一刻慢一点过去，可时间仍在往前走。
- → 偶尔他想多给一点，热情刚涌上来，又因还不敢把心意全交出去而慢慢收住。
- ⟲ 仍在起作用：（1–3）「多留一会儿」

### S03｜17–23 小节　（正在面对）

- 安静下来后，他仍沉浸在刚才的亲近里，心思飘远，暂时不急着去哪里。
  - ← 提供理由：（4–16）「安心关心」
- → 正因为眼前的亲近已经让他满足，他开始盼它能长久。
  - ← 改写：（4–16）「眼下已经够了」
  - ← 提供理由：（4–16）「慢一点过去」
- → 想到长久，他才发现自己能决定怎样珍惜对方，却不能决定对方是否也珍惜自己。
- → 他还没打算向对方索取答复，只是偶尔想知道自己在对方心里是不是特别。
- → 这念头一冒出来，原先顺畅的亲近就被绊住，他仍陶醉，却没法完全走神。

### S04｜24–34 小节　（正在面对）

- 他开始在意自己是不是特别，又怕这份期待会让对方觉得被催，对方并没答应过什么。
  - ← 提供理由：（17–23）「索取答复」
- → 他把心思放回能做的关心，真心盼对方过得好，提醒自己这本身也能让他快乐。
- → 这想法让他轻松，也更愿意付出。他不再盘算给了多少，显得更在乎也没那么可怕，心里很充实。
- → 他想把喜欢给得更足时，又担心太急会给对方压力，那股热情便没能一路往前。
- → 他把这次轻松当成了保证，以为只要不提要求，就能尽情去爱，也不会失去亲近。
- ⟲ 仍在起作用：（4–16）「慢一点过去」

### S05｜35–39 小节　（还说不清）

- 欢喜退下去后，他又想知道对方有没有把他放在心上，刚才的满足帮不了他确认。
  - ← 唤起：（17–23）「索取答复」
- → 他承认自己并非真能无所求，还是盼被珍惜，想到先前把话说得太满便觉得难堪。
  - ← 失效：（24–34）「尽情去爱」
- → 可先前关心对方、享受亲近，并不是为了换来回应，他不愿把那些快乐说成交易。
- → 他把想抓紧当下的劲头松开，让难堪先留一会儿。

### S06｜40–50 小节　（没在想）

- 难堪没让他少喜欢，却让他不再靠多给一些来证明自己毫无所求。
  - ← 提供理由：（35–39）「盼被珍惜」
- → 他把心思放回眼前愿意做的关心，仍真心盼对方过得好，也不再时时查看对方是否在意。
  - ← 说明：（35–39）「换来回应」
- → 专心想着怎样关心对方时，他偶尔忘了自己为什么那么在意回应，那个念头暂时退到后面。
- → 他把喜欢留在心里慢慢体会，单是这样也有甜意，暖意、渴望和遗憾混在一起，让他一时顾不上方向。
- ⟲ 仍在起作用：（35–39）「帮不了他确认」

### S07｜51–61 小节　（正在面对）

- 独自惦念的甜让他舍不得把喜欢减轻，他觉得这份喜欢值得留着。
  - ← 提供理由：（40–50）「顾不上方向」
- → 他不再只盼这一刻慢一点，也开始怕眼前的亲近终究留不住。
- → 他原想把喜欢留在心里，不让期待牵着自己走，也觉得不催对方才是对的。
- → 他仍盼对方能领会自己的关心，又不想给对方添负担，只能自己消化想被回应的心思。
- ⟲ 仍在起作用：（24–34）「被催」

### S08｜62–71 小节　（没在想）

- 安心靠近、真心给予、独自惦念的甜，都不是等对方许诺才有，他不想再因怕受伤压住欢喜。
  - ← 说明：（4–16）「安心关心」
  - ← 说明：（24–34）「不再盘算」
  - ← 说明：（40–50）「顾不上方向」
  - ← 提供理由：（51–61）「值得留着」
- → 他不再压着想亲近的心，任自己高兴，连玩心也冒出来，给得多了也不再一笔笔算。
- → 他明知对方没给保证，却高兴得一时顾不上那份沉重，也不急着替未来留退路。
  - ← 说明：（35–39）「帮不了他确认」
- → 欢喜还没散，他已经舍不得它结束，想被对方同样珍惜的愿望也跟着冒出来。
  - ← 唤起：（51–61）「自己消化」

### S09｜72–77 小节　（正在面对）

- 欢喜稍落下来，他才承认自己不只想把喜欢给出去，也想让对方主动靠近、把他放在心上。
  - ← 唤起：（62–71）「舍不得它结束」
- → 他知道再喜欢也不能把回应当成对方欠他的，可继续盼下去，又怕变成催促。
- → 真把盼望压回去，他又像在否认刚承认的心，越想越委屈、疲惫，偶尔也觉得眼前的亲近本身很好。

### S10｜78–83 小节　（正在面对）

- 他先不逼自己马上选边，承认自己想靠近，也不知道对方是否同样愿意。
  - ← 提供理由：（72–77）「委屈、疲惫」
  - ← 提供理由：（72–77）「主动靠近」
- → 他让自己慢一点靠近，也不再硬压住那份眷恋。
- → 那一刻他能喘口气，委屈和渴望都松开些，对方的心意仍没答案。

### S11｜84–92 小节　（正在面对）

- 他不再逼自己压下渴望或立刻决定去留，熟悉的亲近之乐又回来，犹疑这么久还能高兴，竟让他感动。
  - ← 提供理由：（78–83）「喘口气」
- → 他曾因想被珍惜而怀疑自己的关心是不是交换，如今能承认自己也想被珍惜，仍是真心关心对方。
  - ← 改写：（35–39）「盼被珍惜」
  - ← 说明：（35–39）「换来回应」
- → 他仍不知道对方会不会同样选择自己，却愿意把这阵欢喜感受到底，浓烈得胸口发疼。
  - ← 限制：（72–77）「怕变成催促」

### S12｜93–102 小节　（没在想）

- 他不只想靠近、被同样珍惜，也想把积攒的关心给对方，看看两个人能过上怎样的日子。
  - ← 提供理由：（84–92）「不是交换」
- → 他不再为想被珍惜自责，欢喜把他整个卷进去，旧日难堪暂时退下，连自己的得失也顾不上。
  - ← 提供理由：（84–92）「竟让他感动」
  - ← 提供理由：（84–92）「不是交换」
- → 他真想把积攒的关心都给出去，欢喜浓得难以承受，可对方仍没给新保证，他还盼同样的选择。
  - ← 限制：（84–92）「胸口发疼」
- → 他一时顾不上以后，只想让这阵欢喜多留一会儿，等它稍退，尚未得到回应的期待又回到心里。

### S13｜103–110 小节　（正在面对）

- 刚才的欢喜那么真切，他更舍不得这个人，也更难把对方还没选择自己的酸楚放到一旁。
  - ← 动摇：（93–102）「新保证」
- → 他曾因不再查看对方的反应、只管关心而安稳过，可想被珍惜的愿望仍会回来。
  - ← 说明：（4–16）「安心关心」
  - ← 唤起：（35–39）「盼被珍惜」
- → 后来他也尽情喜欢过，确实幸福，却不能凭自己的投入替对方决定要不要靠近。
  - ← 说明：（84–92）「胸口发疼」
- → 他不想让对方负责消除自己所有的不安，也不愿为怕落空而故意削弱这份喜欢。
- → 他仍想靠近，却不肯逼对方回应，两边都舍不得否认，想到这点就难受。

### S14｜111–116 小节　（正在面对）

- 他起初怕喜欢会改变关系，后来试过收住和投入，仍没法替对方决定，所以不再等到完全安心才继续喜欢。
  - ← 改写：（1–3）「多留一会儿」
  - ← 提供理由：（103–110）「愿望仍会回来」
  - ← 提供理由：（103–110）「不能替对方决定」
  - ← 提供理由：（103–110）「舍不得否认」
- → 他仍盼对方也想靠近，但愿不愿意只能由对方自己决定。
- → 他记得安心关心、真心给予、独自惦念和尽情欢喜都曾让自己快乐，这些快乐让他舍不得把喜欢收回。
  - ← 说明：（4–16）「安心关心」
  - ← 说明：（24–34）「不再盘算」
  - ← 说明：（40–50）「顾不上方向」
  - ← 说明：（62–71）「玩心也冒出来」
- → 以后若对方没有同样靠近，他还是会疼，但不把这当成真心不够的证明，也不靠收紧心意装作看开。
  - ← 提供理由：（103–110）「消除所有不安」
  - ← 提供理由：（103–110）「舍不得否认」
- → 他不拿这份疼去催对方改变心意，先把这阵欢喜感受完，心里还热，身体却慢慢安静下来。
- ⟲ 仍在起作用：（17–23）「不能决定」；（72–77）「怕变成催促」
