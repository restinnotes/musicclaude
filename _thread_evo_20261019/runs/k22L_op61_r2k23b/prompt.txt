二、先查全曲重复，再重写
1. 先在内部建立全曲事实表：列出每个独立事实、证据、愿望、顾虑、认识和选择，标明它第一次出现在哪段，以及后面再次出现时是否真的增加了新作用。此表不输出。
2. 同一个事实只在首次出现时完整交代一次。后面不得换近义词重复它。若它再次影响人物，只写这次新增的推断、代价、愿望、顾虑或选择；可以简短指回前情，不得重新讲一遍前情。
3. 每段必须有区别于前段的叙事作用，但不强迫每段制造新转折。若该段只有重复事实、没有原料支持的新认识或新后果，就不把重复内容写进新线；宁可该段lines为空，也不编造发展。
4. 反复回望只有在改变人物此刻的理解、愿望、代价或选择时才保留。仅仅再次怀念、再次生气、再次犹豫，不算递进。

三、每条线写一个完整的心理动作
1. 每段通常写1—2条，最多3条；没有新内容时可以为0条。不得按原料条目数量逐条改写。
2. 每条表达一个主要心理变化，并保留它的为什么：触发它的事实或前情，以及由此产生的当下认识、所求、顾虑或选择。原因可以简短指回前文，但不能删掉。
3. 一条可以有一个紧密的因果关系，但不得塞入多个阶段或互不相干的意思。通常12—36个汉字，使用自然口语。
4. 每段至少明确：这一段新增了什么；它与前面哪项事实有关；它把人物推向什么新的认识、需要、担心或选择。若没有新增内容，不伪造。
5. 后面再次触及Center的两面时，必须有新证据、新解释、新代价或新选择；不能把两面轮流重说，也不能把矛盾写成必然逐步解决。

四、Center、依赖和语言
1. Center是整条故事的方向，不是每段都要重复的口号。relation准确描述人物此刻与Center的实际关系，不要全曲反复使用同一个笼统标签，也不要为了变化而硬造标签。
2. 后条目若确实依赖前面某条线，在refs中列出对应的前序输出条目编号；只列真实依赖，不为显得连贯而滥用。refs不得引用未来条目。
3. 使用平常话，写具体事实和心理动作。避免抽象心理词、哲理、格言、外部解说、工整对称句和多层长句。
4. 每条都要让人看出人物为什么此刻这样想；但不要机械使用因为、所以等连接词。

五、自检与输出
1. 从头读到尾，逐项检查是否有同一事实换词重复；若有，保留首次完整表达，后面只留真正新增的作用。
2. 检查每段是否有真实新信息，是否保留必要原因，是否误把矛盾写成解决，是否编造事实。
3. 只输出合法JSON，不要解释、不要Markdown。段数和段号与输入一致。每段lines可为0—3条；id在段内从1开始连续编号。refs只引用前面已输出的条目编号。
