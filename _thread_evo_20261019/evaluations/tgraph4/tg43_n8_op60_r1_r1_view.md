# Op.60｜关系图

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3　（还说不清）

- 他心里有了格外愿意亲近的人，想到对方便不由自主地柔软。
- → 每当他想让这份喜欢多停留一会儿，又会本能地往回收。
- → 眼下并没有什么要求他决定的事，他也说不清自己为何谨慎。
- 这点喜欢轻得似乎随时可以放下，他却偏偏舍不得。

### 4–16　（正在面对）

- 他还说不清自己怕什么，便不急着决定两人以后会怎样，也不因喜欢向对方期待什么。
  - ← 提供理由：（1–3）「说不清为何谨慎」
- → 这样想着，他慢慢能够安心地亲近那个人。
- → 他喜欢心里有温柔可以自由给予，不必时时确认对方是否领受。
- → 对方再重要，他也不必失去从容，甚至觉得自己比先前更自在。
- → 这份快乐让他渐渐不再提防自己的喜欢，也满意自己能够宽和。
- → 那时他觉得，只要亲近始终自然、不追问不计较，这样已经足够。

### 17–23　（正在面对）

- 尝到亲近的幸福后，他开始希望这份喜欢不只属于眼前。
  - ← 唤起：（4–16）「觉得自然亲近足够」
- → 一想到长久，他便想到自己能决定怎样珍惜对方，却不能决定对方是否也珍惜自己。
- → 原先无需确认的事，此刻开始牵动他的心。
- → 他偶尔忍不住想，自己在对方心里是否也有特别的位置，却没打算索取什么。
- → 仅多了一点期待，他便不再像先前那样安稳。
- → 他有些意外，原来已经令人满足的亲近仍会让人盼望更多。　✦ 满足照出未满足
  - ← 动摇：（4–16）「觉得自然亲近足够」

### 24–34　（正在面对）

- 他不愿让新添的紧张破坏先前得来的快乐，也不想把喜欢变成无形的催促。
  - ← 提供理由：（17–23）「期待打破安稳」
- → 他提醒自己，关心、给予并由衷为对方高兴，本身就是真实的快乐。
- → 这样想让他轻松下来，也更愿意付出，不再小心衡量心意的多少。
- → 他不再担心多给一点会显得自己更加在乎，反而为这种热切感到幸福。
- → 那一阵，他甚至相信，只要不提出要求，就能尽情地爱而不失去什么。

### 35–39　（还说不清）

- 欢喜稍平后，他仍想知道自己是否也被对方放在心上。
  - ← 动摇：（24–34）「无要求便能尽情爱」
- → 这个念头让他难堪，因为他刚刚还为自己的无所求而高兴。
- → 他没法说自己毫无所求，也知道此前的快乐并非为了换取回应。
- → 他只能暂时停在这份不自在里，不替自己辩解，也不急着用新的热烈盖过去。

### 40–50　（没在想）

- 这份难堪没有让他不再喜欢，却使他不愿再用慷慨证明自己。
  - ← 提供理由：（35–39）「无所求后的难堪」
- → 他不想时时检查对方是否在意，也不逼自己变成完全没有期待的人。
- → 他转而留心当下确实愿意给予的关切，不再忙着想两人以后会怎样。
- → 他可以盼对方好、安静惦念，也因心里有这个人而生出柔和喜悦。
- → 这种细细喜欢让他暂时忘了自己为何在意回应，只觉得它很甜。

### 51–61　（正在面对）

- 那份不声张的甜意渐渐不再轻巧，喜欢也变得难以收放。
  - ← 改写：（40–50）「暂忘为何在意回应」
- 他原想把喜欢留在自己这里，不让对方为难，也不让期待牵动自己。
- → 珍惜对方的心更深后，他常常惦念，也希望自己的关切能被领会。
- → 他仍觉得不催促对方是对的，却只能独自容纳那些没有着落的盼望。　✦ 办法的限度
- → 他并不觉得这份喜欢不值得，正因尝过细致的甜蜜才舍不得减轻它。
  - ← 提供理由：（40–50）「细细喜欢带来甜意」

### 62–71　（正在面对）

- 这份心意已经很深，他忽然不想再时时把它当作需要约束的东西。
  - ← 提供理由：（51–61）「舍不得减轻喜欢」
- → 他回想安心亲近、愿意付出的满足和独自珍藏的甜蜜，都不靠对方承诺才发生。
  - ← 说明：（4–16）「安心亲近那个人」
  - ← 说明：（24–34）「不再担心给得更多」
  - ← 说明：（40–50）「暂忘为何在意回应」
- → 即使仍有期待，这些幸福也不因此可疑；他不想再因怕受伤而小心高兴。
- → 他想充分地喜欢一次，不急着追问结果，也不急着替以后安排退路。
- → 积攒许久的眷恋成了他可以坦然享受的热情，不再逐一衡量或收回。
- → 有一阵，欢喜大过所有顾虑，他几乎感觉不到没有保证的沉重。

### 72–77　（正在面对）

- 欢喜稍落定后，他发现自己不只想尽情喜欢，也想让深情得到回应。　✦ 满足照出未满足
  - ← 唤起：（62–71）「欢喜盖过顾虑」
- → 他想知道对方是否也渴望靠近，是否愿意让彼此在心里占据重要位置。
- → 他明白自己想要得很深，却不能把真心当作对方应当回应的理由。　✦ 分清
- → 他怕退回先前的谨慎会辜负刚承认的心意，也怕继续盼望会变成要求。
- → 两边都有他舍不得放弃的东西，他想不出办法兼顾，感到委屈又厌倦。

### 78–83　（正在面对）

- 他终于不再逼自己立刻选择，暂时不决定如何处理这份感情。
  - ← 提供理由：（72–77）「委屈又厌倦为难」
- → 他不必因想靠近就马上向前，也不必为了谨慎把眷恋压到看不见。
- → 两种心思仍在，他可以带着愿望安静喜欢，也承认自己没有把握。
- → 暂时放过自己让心里松开一点，先前的为难却没有消失。
- → 那份被拉扯得发紧的温柔，又能自然地留在心里。

### 84–92　（正在面对）

- 不再强迫自己消除渴望后，他重新感到亲近一个人的快乐。
  - ← 唤起：（78–83）「温柔重新自然留存」
- → 他尝过期待的紧张、无从确认的难堪，也知道深情不能替对方作答，却仍愿意喜欢。
- → 他不必再用无所求证明体贴，也不因偶尔想被珍惜就怀疑感情的真诚。　✦ 分清
- → 他不再躲避感情的深度，也不为热切羞怯，并因犹疑后仍能高兴而感动。
- → 过去让他警惕的愿望，如今都可以与喜欢一同存在。
- → 他知道自己仍可能受伤，心里并未变得无忧无虑，仍愿充分承认幸福。
- ⟲ 仍在起作用：（17–23）「期待打破安稳」；（35–39）「无所求后的难堪」；（72–77）「不把真心当义务」

### 93–102　（正在面对）

- 他不再遮掩渴望后，更清楚地感到自己多么想亲近这个人。
  - ← 提供理由：（84–92）「警惕的愿望也能共存」
- → 他想把积攒的温柔都给对方，也想让珍贵的亲密不只停在自己的愿望里。
- → 他想被同样深切地珍惜，也想知道两人共同的幸福能有多丰盛。
- → 这些愿望曾让他紧张、难堪并不得不克制，如今仍在，却暂时不再折磨他。
- → 他觉得自己有许多感情可以给予，也有许多值得珍惜的东西，仿佛无需再增加什么。
- → 那一刻，他仿佛觉得所有心愿都已得到抒发，尽管没有任何新的保证。
- → 他一时顾不上以后会怎样，只愿让这份幸福完整地留在此刻。

### 103–110　（正在面对）

- 幸福还很鲜明时，他忽然察觉自己仍有一个愿望没有实现。
  - ← 动摇：（93–102）「只愿幸福留在此刻」
- → 他能充分拥有自己的深情，却无法凭此拥有对方同样深切的选择。
- → 正因为刚才的欢喜真实，那份酸楚反而格外难以忽略。　✦ 满足照出未满足
  - ← 提供理由：（93–102）「只愿幸福留在此刻」
- → 他已知道自己能爱得多深，不能再轻易说对方怎样回应都无所谓。
- → 他不愿把自己的安稳全交给对方，也不想让对方负责消除全部不安。
- → 他也不愿因害怕得不到，就故意削弱那些曾给他巨大幸福的感情。
- → 他曾靠克制得到安心，却没能因此让渴望消失。　✦ 办法的限度
- → 尽情投入曾让他幸福，却没能让失望从此不再可能。　✦ 办法的限度
- → 他仍迫切想靠近，也坚持不勉强对方，两股心思都没有退让。
- → 他比先前更强烈地感到冲突，因为如今已舍不得否认任何一边。　✦ 知道更多反而更尖锐
- → 他不愿为了轻松就匆忙舍弃其中一种，宁可承受不轻松，也不欺骗自己。

### 111–116　（正在面对）

- 带着这份仍未平息的牵挂，他渐渐不再要求自己找到一种不会受伤的爱法。
  - ← 改写：（103–110）「不为轻松匆忙舍弃」
- 他仍想被选择，因为对方重要，也盼两人彼此亲近，即使未必如愿也不假装没有这愿望。
- 他喜欢得很深，也仍舍不得放弃克制，因为对方有自己的心意，不必与他相同。　✦ 分清
- → 若为安心要求对方承担全部期待，他盼望的亲近也会失去自在。　✦ 选择的代价
  - ← 提供理由：（103–110）「不把安稳全交对方」
- → 他仍会遗憾，却不再觉得必须消灭遗憾才能好好爱一个人。
- → 小心亲近、不求确认地付出、独自珍藏和尽情欢欣，都曾给他真实的幸福。
  - ← 说明：（4–16）「安心亲近那个人」
  - ← 说明：（24–34）「不再担心给得更多」
  - ← 说明：（40–50）「暂忘为何在意回应」
  - ← 说明：（62–71）「欢喜盖过顾虑」
- → 这些快乐虽没解决最后的问题，却没有白费，还让他一再向前、看清对方重要。
- → 他曾努力收住，也曾尽情投入，因此知道两种办法都不能免去爱人的风险。　✦ 办法的限度
  - ← 说明：（103–110）「克制没让渴望消失」
  - ← 说明：（103–110）「投入没让失望不再可能」
- → 他仍盼回应，也偶尔收住心意，却不再用回应有无判断真心，也不拿克制多少证明清醒。
- 他知道以后仍可能失望，也会因不能更近一步而感到疼痛。
- → 这些疼痛不必让他否认感情，也不必成为催促对方的理由。
- → 他愿继续把对方放在心里，认真喜欢、充分欢喜，也承受无法决定的部分。
- → 他可以渴望被爱而不把渴望变成对方的义务，也能珍惜对方自由而不收回自己的心。
- → 他没有得到想要的一切，却不再为了保护彼此而先放弃最想给予的爱。
- ⟲ 仍在起作用：（72–77）「不把真心当义务」
