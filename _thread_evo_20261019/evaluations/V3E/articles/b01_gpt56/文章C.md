# 文章C

# 肖邦《船歌》

**1–3**

两下和弦猝然亮起来，细碎的光还悬在半空，没有落稳。我已经把那句话想得很清楚，连一个字也不必再找：我想告诉你，我对你的心意早已深到不能轻轻带过。可舌尖抵着牙关，迟迟没有松开。说出去以后，你再看我时，眼神里会不会多出一点我无法收回的东西？光点一粒粒往下落，我把后半句压进呼吸里，连开口前的气息都不敢惊动。

**4–16**

低音摇摇荡荡地托住我，两条歌声贴近耳边，像你就在我不必防备的距离里。这样的静默竟容得下我，我把那句话往前送了一点，声音才碰到高处，尾音便自己轻了下去。别惊动这一刻，我在心里说。可下一句又跟着出来，低得几乎只够我自己听见。柔软的落音擦过胸口，甜意里藏着一点刺。我想再靠近些，呼吸却先替我收了回来。那一阵心意明明已经涌到嘴边，我甚至尝到了它即将出口的滋味，最后却只轻轻吐出一口气，任自己重新漂回这片安静里。

**17–23**

歌声退远，水纹般的摇晃还在身下慢慢托着我，连沉默也变得松软。我把刚才没说完的半句含在心里，竟可以不急着替它找下文。两三个短音忽然急急蹿起，那句被压住的话也跟着顶到喉咙：你听见了吗？我还没把问句想完，声音已经沉了回去。水面一圈圈荡开，底下却像有什么拖住脚踝。我顺着它漂，试着让刚才的念头自己散去；可每当我以为它已经远了，那几个没说完的字又从碎光里闪出来，彼此挨着，却再也拼不回刚才那样完整的一句话。

**24–34**

熟悉的歌声重新贴近，双音间的花腔一层层密起来，我又把那句话往外递，像多补上一点，你就能听见它全部的重量。高处的颤音亮得刺眼，我的喉咙也在那一瞬收紧；最想说的几个字挤在一起，舌根发麻，没能落下去。我把手攥得更紧，掌心被指甲压出浅浅的痛，旋律却还把我往前推。我想把刚才收回去的部分也交给你，连那些不敢承认的渴望，一并放到声音里。尾音一边向上颤，一边慢慢退弱，鼻尖先酸起来，嘴唇仍停在下一句话的开头。水波没有停，我的手也没有松开，仿佛只要再撑住一瞬，那句话就能越过喉咙，真正抵达你那里。

**35–39**

水波和摇晃突然撤走，只剩一线旋律悬在空中。我嘴边那句话失了着落，刚才几乎交到你面前的心意，一下子又退回我自己这里。静得只听见一个没能问出口的问题：这份幸福，究竟能留多久？我慢慢松开攥紧的手，掌心的酸痛还在，胸口却空出一块。刚才那些贴得那么近的声音，此刻竟像隔着很远的水面。我吸进一口深气，气息到了底，那个问句仍悬着；我没有再追着旋律说下去，也没有办法把它从心里拿走。

**40–50**

摇摆重新回来，却薄成一层层细小的水纹；清亮的旋律落在耳边，像凉月照进刚刚退潮的地方。我把心里那句话轻轻放下：算了，先不说了。新歌清清地舒展开来，我跟着它慢慢呼吸，甚至可以想象自己已经不必再把每个字藏好。可低处的波纹一圈圈碰回来，另一条细声又在旁边应和，刚刚安静下去的念头重新浮起。我垂下眼，想让自己只听这支干净的歌，嘴唇没有动，胸口却仍替我把它念着。算了。我又说了一遍。尾音还没有散尽，那几个字就已经轻得托不住自己；我仍然听着，等那句话再一次从水底冒上来。

**51–61**

那支歌声又回来了，低音一下一下敲近，内声部沿着水底攀上来，连我的呼吸也被催快。我不愿再把心意折成那种轻轻一碰就能收回的形状；我想让它向前，越过唇边，落到你那里。每一个低音都像撞在胸骨后面，越往下听，身体里越有东西被推着往上涌。我想起那些刚要靠近便收回去的尾音，想起手指攥得发痛时仍没有说完的几个字，忽然连安静地待在这里都显得太窄。我想再近一点，再多一点，想让这份心意终于有一个能被你听见的声音。可暗流只管催我往前，心跳只管越来越急；我明明已经被卷进去，仍舍不得从中抽身。

**62–71**

旋律忽然铺开，明亮得像风一下穿过胸腔，歌句一口气向上伸展。我跟着它唱，心里那句话不再一字一字经过审查；我几乎能把它完整地交到你手里，甚至忘了自己一直在等一个安全的时刻。音色轻快起来，身体也松了，我终于可以让声音越过那些反复设下的边界，任它舒展，任它发亮。原来我也能这样痛快地想你，连停顿都不必事先准备。歌句继续向上，我还想跟着它走得更远，胸口已经张开，气息也正好够用。可句尾忽然向上散开，声音像热气一样消失。我还保持着那口要接下去的气，下一句却迟迟没有回来；那份畅快仍留在身体里，我已经开始想念它。

**72–77**

刚要冲出去的声音忽然收住，熟悉的摇摆退到远处，只剩颤音和轻柔的和弦悬在半空。我胸口那股热还没退，嘴唇却像被按住；刚才那样畅快地唱过，究竟算不算真的向你说了？我听见这个问句沿着变暗的音符一层层往下沉，渴望仍在最深处翻动，却不肯再替我往前一步。我想抓住刚才那几秒，把它们重新放回耳边，听听自己是否真的没有退缩。可声音越轻，刚才的明亮就越像一件无法确认的事。接下来呢？我把这三个字含在舌尖，没有让它们出声。

**78–83**

高处的细音像雨丝落下来，一串琶音从上方倾泻，节拍忽然宽出一块空地。我松开肩膀，长长吐出一口气；眼泪到了眼眶，终于不必被牙关压回去。胸腔轻得像失去重量，心里那句话也暂时不必排成完整的句子，只剩温热的一团，随着呼吸微微颤动。我不必马上决定该不该说，不必立刻替每一个可能的结果找到位置，只让那些积在身体里的东西顺着眼泪慢慢流出来。风从高处掠过，我轻得几乎感觉不到自己仍在这里。可最后几颗音已经开始散去，我刚打开的胸腔还没来得及装满什么，耳边便又传来那支熟悉的歌。

**84–92**

熟悉的歌一开口便沉沉托起我，厚重的和弦压下来，左手的水波翻成横跨胸口的巨浪。我把那句话从喉咙深处推到声音最亮的地方：这是我的感情，我不再为它道歉。那些曾经只敢低声递出的字，此刻不必再缩小，不必每说一半便替自己找退路。我听见它们在胸腔里轰然展开，几乎压得我喘不过气，连呼吸都得从浪与浪之间找缝。那次停在高处、颤着退回去的尾音又浮上来；我记得它怎样迟迟没有落地，也记得掌心里那阵无法松开的酸痛。这回我不再急着把声音收回来，我让它继续向前，托着那份心意往更高处去。可到了最高处，力量仍然悬着，我的胸口绷得发疼，等着那口气真正落下来。

**93–102**

晴朗的歌再次展开，宽广的声浪几乎容不下我，私下里反复咀嚼的那句话像越过一个人的胸口，朝更远处振荡。我想再说得完整些，再高一点，把那些没能落下的字全都送出去；每次旋律抬头，喉咙便紧一分，内声部却从两侧拉扯，拖着句子不肯放行。笑意和泪意一起涌上来，我几乎被这片声音整个淹没，连自己最初是怎样把那句话含在舌尖，都快要记不清了。眼前只剩不断抬高的歌声，我想把全部的心意都交出去，想让它越过那些一次次收回的停顿，抵达一个再也不必藏匿的地方。可旋律又一次向上伸展，紧绷的声音迟迟不肯放开。我追着它，胸口越来越满，呼吸却仍卡在那最后一点没有松动的地方。

**103–110**

那口气终于透出来，旋律猛地向前，我听见自己把那句悬了很久的话完整地交出去。声音没有停，仍一遍遍往上推；我也跟着在心里重复，像只要再确认一遍，它就不会从这一刻滑走。我说过了。我真的说过了。每一次重现，我都想再听清一点，再把那份心意握牢一点，仿佛一停下来，刚才得到的东西便会从指缝里流走。可明亮里渐渐刺进几道尖细的暗声，低处的脚步稳稳踩着，上方的音一声声往下落。我刚刚说了“是”，心里却贴着那片阴影响起一句：可是呢？我还在听那句“是”留下的回声，那个问句已经沿着低处跟了上来。

**111–116**

最后一股浪头猛地翻起，终结句才一点点松开，胸口还热着，呼吸却慢慢落回原处。低处传来一声沉沉的歌，像我把最深的那半句从身体里接了回来；细碎的琶音随后溅起，亮了一瞬，又散进安静。我不再追着每个音往上走，手指终于一点点松开，掌心里那阵酸痛也慢慢退去。几下沉重的和弦落下来，像铁锚穿过水面，船身终于不再摇。我合上嘴，听着最后的余音沉下去，胸口仍留着那份说出口之后的温热。那句“可是呢？”贴着下一口呼吸，轻得没有落音。
