# Op.61｜关系图（在 v6 上修补，w35）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他起初连自己在等什么都说不清，只剩一股不肯就此算了的劲。
- → 他怕照旧就等于认了它们本该如此，便硬撑着不肯倒下，却又想停一停，怕真投进去会失去别的东西、回不了头。
- → 熟悉的感觉一回来，他就下意识想继续，可过去不会因此回来，他还想找个理由才敢往前走。
- → 每次刚觉得想通，舍不得又回来，连那点确信也变得陌生，他也为非得想透才肯动而难堪。

### S02｜24–65 小节　（正在面对）

- 他没想透值不值，结果也没把握，却不再等算清才动，接下能做的事，尽力去做，渐渐有了力气和骄傲。
  - ← 改写：（1–23）「那点确信」
- → 他发现投入本身让他快乐，愿意给得更多，贪恋倾尽全力的畅快，不再时时审视自己或因一点软弱停步。
- → 投入越让他高昂，心里仍有一小块没跟着振奋，因为还有别的牵挂没得到照顾。
- → 他投入得越深，越怕最后仍是白费，便一遍遍说服自己别退，想尽快证明这一步没选错。
- ⟲ 仍在起作用：（1–23）「硬撑着」

### S03｜66–91 小节　（正在面对）

- 他投入后不再反复自问，不再畏缩也让他高兴，偶尔聊别的或散步，暂时忘了为何用力也不觉背叛先前决定，不急着解释。
- → 他想要自在亲近、不必时时防备的生活，却找不到过法，仍不甘心，想到它时还会松口气。
  - ← 说明：（24–65）「没跟着振奋」
- → 快乐淡去、难处仍在，他一想到实现这愿望，就想起先前决定尽力，又怀疑那股劲是否真心。
- ⟲ 仍在起作用：（24–65）「一遍遍说服」

### S04｜92–115 小节　（正在面对）

- 他确实尝过自在亲近带来的快乐，所以虽知道当时的坚定也靠努力撑着，眼下虽不安仍愿意坚持。
  - ← 说明：（24–65）「一遍遍说服」
- → 他当初坚持的决定曾让他从动弹不得的犹豫里走出来，眼下做得还不够，他仍觉得那一步没白走。
- → 他怕停下就得承认那份亲近回不到从前，便硬撑着不肯停下，反复追问过去还能怎样，却仍无法安心。
- ⟲ 仍在起作用：（24–65）「不再等算清」

### S05｜116–147 小节　（正在面对）

- 行动明明还不够，他仍逼自己不松手，不只怕承认失望就是变心，也怕停下会辜负最初的决意。
- → 他怕一软就停步，不肯放下那份曾让他骄傲的要求，渐渐容不下脆弱，难受也怪自己不够坚定，还想克服迟疑。
- → 他发现自己还在逼着一个累了的人硬撑，终于不想再证明自己多坚强。
- → 他终于松了劲，却没因此安心下来，这才肯承认自己舍不得那种不必防备的亲近。
- ⟲ 仍在起作用：（92–115）「没白走」；（66–91）「找不到过法」

### S06｜148–180 小节　（没在想）

- 催逼停下来后，他发现自己舍不得的不是一时舒服，而是那种他曾真心相信、也真正快乐过的生活。
  - ← 说明：（116–147）「不必防备的亲近」
- → 他曾相信，珍惜的东西不用靠争抢才能留住，付出只是因为喜欢，不必先证明自己值得被爱和接纳。
- → 他想靠近时不必先怕受伤，也不用向别人解释自己为什么难过，更不必维持应该坚强的样子。
- → 他不愿把这份向往说成软弱，因为那是他真心想要的生活。
- → 他暂时不再担心心里一软就会停步，才肯承认自己也有委屈和思念。
  - ← 失效：（116–147）「克服迟疑」
- → 他重新允许自己相信后，感到满足和安宁，几乎忘了先前的疲惫，一时也不想离开。
- → 他允许自己去爱，也先珍惜心里向往的生活，不急着求它实现或证明有用，更不拿责任和它比轻重。

### S07｜181–205 小节　（正在面对）

- 熟悉的亲近让他觉得向往的生活近在眼前，可现实没变，他懊恼自己又沉进去了。
- → 他认出当初那份不再等待、主动争取的决意又回来了，因为他仍想让向往的生活成为现实。
  - ← 唤起：（24–65）「不再等算清」
- → 安宁越真切，他越不能只满足于心里拥有那种生活，因为这反而提醒他愿望还没实现。
- → 他当初不肯再等，是怕珍惜的东西继续受损，光在心里想着那种生活也护不住它们。
- → 他原以为理由越充分越能安心，如今经历越多、理由越多，反而越难安定。
  - ← 失效：（24–65）「一遍遍说服」
- → 他想重新投入，却怕耗尽刚找回的温柔，也怕顾不上想留住的生活，不知怎样争取才不伤这份温柔。

### S08｜206–213 小节　（没在想）

- 他先前反复盘算怎样争取才不伤那份温柔，安宁曾让他感到很满足，此刻便暂且不再审问自己。
- → 他在这份为难里又短暂感到那份温柔靠近，舍不得立刻推开，仍想爱惜片刻。
- → 他知道心里拥有的那种生活还没成为现实，便不能在这份安宁里久留。
  - ← 限制：（181–205）「愿望还没实现」
- ⟲ 仍在起作用：（181–205）「刚找回的温柔」

### S09｜214–215 小节　（正在面对）

- 他走了很远，也尝过自在亲近的日子，最后仍回到最初不知怎么办的地方，只是这回知道自己想要什么。
  - ← 改写：（1–23）「不肯就此算了」
- → 他有些怯懦，不愿拿过上那种生活的盼头去冒险，便迟迟不敢再试。
- ⟲ 仍在起作用：（181–205）「刚找回的温柔」

### S10｜216–225 小节　（正在面对）

- 他暂时提不起劲争取，也没力气要求自己彻底改变，却说不清为何还舍不得丢开当初那一步和那份安宁。
- → 他知道尽力去做确实帮过他，如今却也让他难以继续，若还争取就得记住当初为何不肯再等。
  - ← 提供理由：（181–205）「珍惜的东西」
- 他知道自己向往的生活确实曾让他安宁，可威胁它的事还在，珍惜这份安宁也不能把那些事放下。
- → 他反复想着自己究竟想护住什么，想歇一歇也不等于要把那种生活丢下。
- → 他还不知道往后该怎么过，却不再急着判争取和安宁谁对谁错，也不再逼自己立刻选边。
- ⟲ 仍在起作用：（181–205）「主动争取」

### S11｜226–241 小节　（正在面对）

- 他知道争取给过他力量，却消不掉所有牵挂，心里的安宁也是真的，却护不住现实中珍惜的东西。
  - ← 提供理由：（24–65）「没跟着振奋」
- → 他发现争取和安宁难以两全，难处不只是自己不够坚定，而是珍惜的东西不止一样，便重新想还能承担什么。
  - ← 说明：（216–225）「威胁它的事」
- → 他怕争取会伤到珍惜的东西，心里仍疼，也知道若只因害怕而不争取，未必留得住它们，还可能让它们继续受损。
- → 他知道再等也不会等来容易的路，便带着不舍和痛苦继续争取，不再要求自己先不害怕。

### S12｜242–253 小节　（正在面对）

- 他知道该做什么，能做多少先做到多少，不再要求每一分努力都证明自己能改变一切。
- → 他舍不得那种不必证明也能被爱、被接纳的生活，也怕失去它，却不再等一个没有损失的办法才肯行动。
  - ← 改写：（226–241）「继续争取」
- → 他仍愿为所爱负责，不用等犹疑消失才坚定，也不必否认自己的脆弱。
- → 他不再把这份牵挂当成行动的拖累，久违的昂扬又回来了。
- → 他真要继续争取时，仍怕自己的努力会伤到所爱，便又迟疑了一下。
  - ← 动摇：（226–241）「心里仍疼」

### S13｜254–288 小节　（正在面对）

- 他仍向往那种不必拼命的生活，正因舍不得它，才不能只待在安宁里旁观，得出去争取。
  - ← 提供理由：（181–205）「珍惜的东西」
- → 他发现眼前的行动也在替那种生活争取，珍惜它的愿望和承担责任的心也能一起推着他往前。
- → 他想留住的不只是自己的安宁，还有故土和共同记忆，所以这份向往也不只属于他自己。
- → 他不必因为肩上有责任，就厌倦自己真正想珍惜的生活，也不必为这份依恋羞愧。
- → 旧愿近了些，他又尝到最初相信它时的快乐，却因经历过怀疑和疲惫，知道这份快乐并非理所当然。
- → 愿望未成，并没抹掉这份快乐，可他想起现实未变，心里的满足不能代替真正过上那种生活，便清醒过来。
- → 他发现旧愿和眼前行动能一起推着他，却仍可能彼此冲突，因为争取未必能按他所愿保护一切。
- → 他愿为那种生活吃苦，却知道再多付出也未必更靠近它，不能只因心愿就认定每分付出都值得。
- → 他得留心别在争取时耗尽所爱，真要付代价时，仍可能累得想退回安宁。
- → 他仍不知道最后能保住多少珍贵的东西，所以不敢把这场争取当成必有结果。
- → 他这一刻能做的已经做完，不必再靠不停争取证明心意，暂时歇下来也不等于放弃。
- → 他不再反复找理由证明自己该往前，因为清楚知道那种生活正是自己想要的。
- ⟲ 仍在起作用：（242–253）「伤到所爱」
