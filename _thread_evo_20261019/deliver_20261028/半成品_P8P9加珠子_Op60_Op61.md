# 半成品：两版线 + 珠子（10-28 晚）

两版都是逐段往下写：每段看着这一段的珠子和各篇独立稿的解释，写出“他此刻为什么会这样”，并写出这一段新确立的变化，后面的段必须接在上面。
写稿（独立稿）从头到尾没看过珠子。每段写完都由另一位评委核对：有没有编前史、有没有把音乐当原因、递进成不成立、不看珠子能不能读懂；不合格的退改一次。

- **P9（不用底稿）**：只用独立稿的解释池和珠子，Center 是全曲写完后按这条线回头写的。少了接线这一步，每部作品约省 100 次调用。
- **P8（有底稿）**：多给了一条事先接好的线（P4d）每段原来的解释作参考。Op.60 的 Center 用 P4d 的；Op.61 的 Center 写完后回头写。

## 肖邦《船歌》Op.60

**P9 的 Center**：他在乎那份真切的亲近：它让他深深喜欢，也让他总想确认自己能不能安心待在其中。

**P8 的 Center**：他盼着两个人能够相爱，在亲近时高兴得忘了自己，在快乐过去时又心疼得舍不得；他越来越清楚自己有多喜欢对方，却不能替对方决定心意，也不能让眼前的好时光停下来。

### S01 ｜ 1–3 小节

**P9**

- 一阵强烈的心动突然涌上来，兴奋而郑重，也带着一点紧张。
  → 想靠近的心意来得太直接，身体先有了反应。他还没来得及安顿，就已经感到这件事对自己很重要，不能轻轻带过。
- 激动渐渐变得柔和、谨慎，期待仍然悬着，不能完全放心。
  → 他已经清楚自己想靠近，却还没有任何根据相信这份亲近真的成立。越是珍惜这种可能，越不敢把强烈的心愿当成已经拥有的幸福，只能带着期待小心地等待。

**P8**

- 一阵强烈的欣喜突然涌上来，心也跟着绷紧。
  → 他忽然真切地感到，自己多么想与对方亲近。那份可能带来的高兴一下子冲了上来，身体先激动起来，心却还没来得及在这份高兴里站稳。
- 激动渐渐柔和下来，他却更加小心，满怀期待又不敢安心。
  → 刚才那阵激动让他更清楚自己想要什么，却没有让他知道对方是否也愿意。他明白自己的心动不能算作对方的答应，便收住急切，不敢贸然把可能的亲近当成已经拥有的幸福。

**珠子**

- **B1**［主体验］（1–3 小节）开头那两下响亮的和弦，有一点突然。声音像夏夜威尼斯上空升起的一束烟花，先向高处迸发，细碎的光点再缓缓飘落。落下来以后，却还没有真正落稳，仿佛仍悬在水面上方；稳定的船歌摇荡尚未真正建立。
- **B2**［另一侧面］（1–3 小节）像一个人准备对很亲近的人说一件已经想了很久的事，话还没出口，先有几秒钟沉默。你并不是不知道自己想说什么；恰恰因为太知道，而且明白有些话一旦说出来，关系就会改变，所以反而谨慎。
- **B3**［另一侧面］（1–3 小节）也可以把开场听成一脚踏上小船：木板微晃，水波在脚下荡开，身体有一瞬失重。有些演奏让开头仿佛已经在水上轻摇，另一些则让声音先悬在空中。这里是刚刚踏上船板的感觉，还不是整个人已经安稳地交给规律起伏的水浪。

### S02 ｜ 4–16 小节

**P9**

- 先前绷着的心慢慢松开，他愿意被温柔托着，不急于落定。
  → 上一段他已经发现，单靠想靠近换不来确定；此刻一种持续的安适先让身体放松，他暂时不再逼自己掌控结果。即使一切还在向前，他也愿意安心待在其中。
- 他仿佛与人贴得很近，觉得亲昵、自在，沉默也甜蜜。
  → 刚才不再急着抓住保证，他才有余地体会亲近本身：不必努力证明什么，就能感到仿佛有人相伴的温暖。先前只能向往的好，如今第一次成为可以慢慢享受的感觉。
- 越觉得这一刻好，他越微微鼻酸，想让它慢一点过去。
  → 此前他只为亲近能否成立悬心；如今已经尝到其中的快乐，才开始舍不得它流走。眼前的好仍在，但他已经知道心意再强也不能保证留住它，所以这份甜开始带上一点酸。
- 他的喜欢忽然涌得更热切，随后柔和下来，仍有余恋。
  → 刚才的快乐已经珍贵到让他舍不得，他一度想更充分地靠近，让这份心意得到更多。可热切并不能替亲近换来保证，所以激动退下后，他仍留在这份温柔里，没有急着把心事说尽。

**P8**

- 他还带着一点悬念，却渐渐放松，敢安心待在这份亲近里。
  → 上一段他确认了想靠近的心意，却只能收住冲动等待。如今这份亲近持续着，并没有因为他不再急着争取就消失，身体便先于念头松下来，暂时不必追问结果。
- 他觉得两人近得令人安心，连安静待着都甜蜜。
  → 先前他太在意能否靠近，不得不把自己的急切收住。现在亲近已经持续了一阵，他的注意力渐渐不再围着自己的等待转，而是落到那个人身上；即使还不知道对方的心意，光是感到这样近，就已经让他高兴。
- 他忽然有点鼻酸，明明还在快乐，却已经舍不得。
  → 刚才他终于能放下紧张，真切享受这份亲近，才发现自己已经在幸福里度过了一段时间。那些美好的瞬间还没来得及留住就过去了；眼前的好并没有减少，他却因为太喜欢，第一次这样具体地心疼时间的流逝。
- 他的喜欢一时热切得藏不住，随后又柔和下来，仍有眷恋。
  → 原先收着的喜欢，经过这阵真实的快乐和刚生出的不舍，渐渐积得太满，他忍不住想让对方更明白自己的心意。可再热切也不能替对方决定心意，于是他重新收住，不把这一刻的幸福当作已经有了结果。

**珠子**

- **B1**［主体验］（约6–16 小节）右手两条贴得很近的歌声，像两个紧挨在一起的人耳语，肩膀挨着肩膀，连呼吸与体温都近得化不开。也像相识已久的人安静坐着，不必拼命找话题；对方偶尔望来一眼，沉默也不让人紧张。若把这份温存听成肌肤的感觉，又仿佛夏末水面潮湿、温热的微风，裹在皮肤上有些黏稠。
- **B2**［另一侧面］（4–16 小节）第4–5小节，歌声还没真正浮出来，左手已经像心跳，也像无止境的水浪，一下一下地摇着。脚下仿佛不必再踩实地面，可以放弃对重力的控制，把身体交给船底温柔的托举。但水波不会停：人在船上舒服地漂着，暂时不急着靠岸，水却一直在流，时间也一直在走。
- **B3**［演奏条件］（约6–11 小节）初次歌唱向高处伸展，谱上却要求声音收弱。若演奏者把这股反过来变轻的动作弹得清楚，就像话已经到了嘴边，又轻轻咽回去：“我很靠近你，但我还不肯把全部重量压上去。”第8–11小节，有时又像本来已经可以停下，却忍不住接着说；声音仍不敢太大，仿佛一响就会惊碎眼前的安静。
- **B4**［另一侧面］（约7–11 小节）几次柔软的落音，像一根温柔的刺。它既像是甜蜜的确认，又带着一点无法排遣的惆怅：眼前的好还在，心里却已经有一点鼻酸。因为太喜欢眼前的东西，所以还没有失去，就已经生出一丝舍不得，忍不住希望这一刻再慢一点过去。
- **B5**［段内变化］（12–16 小节）到第12–14小节，先前小心收着的歌声忽然往上涌了一次，像感情终于忍不住说得热切了一些，连呼吸都跟着改变。可是第14–16小节，它没有继续冲向高潮，而像轻轻呼出一口气，重新回到柔和。声音短暂落稳，又漂起来一点，没有把心事彻底说死。

### S03 ｜ 17–23 小节

**P9**

- 他还沉在刚才的幸福里，舒服地走着神，暂时什么也不想做。
  → 先前他已发现，即使亲近还没有保证，那份感觉本身也能让他安心。如今他舍不得这份快乐过去，便只想顺着它的余温停留，暂时不急着追求更多。
- 安静中忽然生出一点急切，想抓住什么，却很快又沉回温柔里。
  → 前面的快乐已经让他盼着这份亲近能多停留一会儿，所以心里偶尔会忍不住想把它抓得更稳。但满足感仍在，他还没有真的失去安心，这点急切便没有变成持续的追问。
- 温柔仍在，他却渐渐有些放不下，心思绕来绕去，难以安稳。
  → 正因为刚才曾不费力地享受幸福，如今又舍不得它过去，他才察觉，想让这份好一直持续，并不能让自己始终同样自在。越想留住刚才的安稳，心里反而越有一点牵挂。

**P8**

- 刚才的热切渐渐退下，他仍沉浸在亲近的快乐里，舒服得有些走神。
  → 先前他已发现，即使没有对方心意的保证，也能安心享受亲近；又因为舍不得刚才的快乐，心还留在那份余味里。此刻不急着表达或求证，只想任自己在其中多待一会儿。
- 舒服之中忽然有点心急，像有话想说，却很快又安静下来。
  → 前一段他已开始想让对方知道自己有多喜欢。刚才的陶醉稍稍退开，这个愿望便突然冒出来；可他也知道自己的热切不能替对方回答，心里一时没有把话继续说下去的把握，于是又收住了。
- 温柔还在，心却渐渐绕住了，带着一点说不清的牵挂和迟疑。
  → 先前他已经能够不求答案地享受亲近，如今却又想把自己的喜欢传给对方。刚才想说的念头起了又落，愿望仍留在心里；他越想继续舒服地沉浸其中，越察觉有一部分心思放不下来，却还没有什么能够解决。

**珠子**

- **B1**［主体验］（17–23（原稿所述状态约从15小节开始延续） 小节）刚才的歌声渐渐退到后面，剩下一阵阵流动、盘旋，水波般的摇曳托着身体，只感觉自己在摇晃、漂浮，暂时“不去哪里”。像说过一句重要的话以后，人还停留在那句话里面，有一点陶醉，有一点走神。也可以想成亲密交谈后忽然安静下来：沉默并不尴尬，反而很舒服；身体还在这里，心却已经慢慢漂远。
- **B2**［段内变化］（约20–21 小节）约在第20–21小节，持续摇曳中忽然冒出几句短促、稍显急切的声音。像某个念头突然想说话，却很快又沉回去；它只在水面上露了一下头，没有变成一场真正的倾诉。
- **B3**［另一侧面］（17–23（暗流、滞留特别指向约20–22；碎裂倒影来自明确标为16–23的原稿，不限定在20–22） 小节）水波还在晃，流动却像被什么拖住。约在第20–22小节，平稳的“对话”有一种被水下暗流拖住的感觉，音乐绕远、滞留，某些声音像被挂在半途。还有一种更纷乱的听法：思绪像被风吹碎的倒影，粼粼闪烁却难以拼凑完整；仿佛亲密的谈话触碰到了某些无法解开的结。音乐没有突然变成悲剧，只是那份顺畅之中出现了阻力。

### S04 ｜ 24–34 小节

**P9**

- 熟悉的亲近又回来了，他欢喜，也松了口气。
  → 先前他已尝过亲近的快乐，也发现越想留住它，安心越难自然。如今同一种温柔仍能让他高兴，便多了一层庆幸，而不是多了任何保证。
- 欢喜越涨越满，甜得发酸，他不自觉地抓紧。
  → 上次幸福让他舍不得，后来想留住又使心里绷紧。这次越觉得美好仍在，越想再多感受一点；用力不是因为已经失去，而是怕此刻不够长。
- 他几乎想把心意全倾出来，却激动得发颤。
  → 他早知道心意再强也不能保证亲近，如今又带着想留住幸福的紧张。越想把感情表达得彻底，越觉倾尽自己也不能把这一刻定住，最热烈处反而有了哽咽。
- 热切渐渐退下，他安静了，却仍恋恋不舍。
  → 刚才他已经把欢喜推得很满，再用力也不能让它停得更久。身体终于慢慢松开，心里的舍不得却还在；这份安静并不意味着原来的疑问有了答案。

**P8**

- 悬着的心忽然松开，熟悉的亲近让他惊喜又庆幸。
  → 上一段里，连舒服的安静都被没说出口的喜欢牵住，他没法完全放松。如今那份温柔仍能让他真切地快乐，身体先松下来，才格外感到它的可贵。
- 喜悦越来越满，他想抓紧这份亲近，也更想让对方知道自己的喜欢。
  → 他已经尝过亲近的快乐，也尝过它退去后的不舍；上一段又让藏着的喜欢自己浮起来。此刻重新尽情高兴，他便不满足于只是安静享受，越投入越想把这份好留住、把心意表达出来。
- 最激动时，他几乎想把喜欢全说出来，却又心颤得没底。
  → 上一段已让他发现，没说出口的喜欢不会因亲近而安静；如今欢喜越强，那份心意就越难藏。可亲近仍不能替对方回答，他越想毫无保留地交出去，越感觉到自己没有把握。
- 热烈渐渐退去，他仍甜得心酸，安静下来却越发舍不得。
  → 先前他已经尝过快乐过去后的不舍，这一次却比先前高兴得更满。他还在享受亲近，就已心疼它终究留不住；越想抓紧，越觉得自己无力让它停下，激动退去后便留下温柔的眷恋。

**珠子**

- **B1**［主体验］（24–34（主题加饰重现有明确定位；补话和双音贴耳的比喻来自跨段宽述，不细定起止） 小节）第24小节，熟悉的歌声又回来了。两道紧贴的声线仍像两个人在耳边低语，呼吸挨得很近；但这一遍比第一次更华丽、更迫切。细密的花腔仿佛水面折射的光斑，突然晃得人睁不开眼。也可以像听一个人谈往事：刚开始还能微笑着讲，讲着讲着语速变了；本来一句话已经够了，却忍不住再说一遍，又折回来补上更多细节。
- **B2**［段内变化］（约30–34（30–32为局部高点；32–34为高音颤音和退弱的重心；34为放慢、退开） 小节）到第32小节附近，高处的长颤音像夕阳在水面切出的最后一道金光，亮得几乎刺眼，仿佛把情绪一下照到最炽热的地方。也可以听成想把最深的情意说出口，却在喉咙口颤抖、哽咽：右手在高处悬停，左手的水波却仍推着你往前走。这股情绪一瞬间像是完整地打开了，可音乐一边往上争取，一边又在退弱，并没有稳稳落下。到第34小节，摇晃渐渐放慢，仿佛刚说出口的话还在空气里回荡，人却安静下来。
- **B3**［另一侧面］（24–34（握手变化来自23–39的宽述；拥抱与失衡明确涉及32–34） 小节）还有一种近乎落在手指里的感觉：原本只是轻轻握着另一个人的手，后来不自觉地握得更紧。自己也许还没有意识到在害怕什么，动作已经先透露了出来。另一个更晃荡的画面，是想用力抱紧对方、牢牢抓住当下；但你越用力，水面的颠簸就越剧烈，船舱内的平衡就越脆弱。

  → 最初他想要一份能长久依靠的保证，后来却已经充分经历、也清楚肯定了这份幸福。如今连最后的留恋都走到了尽头；保证仍未得到，但经历不能因此作废。他不必再用力留住什么，也能让这一切真正结束。

**P8**

- 从几乎无法承受的紧绷里突然松开，疲倦、温暖和余下的不舍一起留下。
  → 前一段他没有提前从幸福里抽身，而是把珍惜与心疼一直承受到尽头；因此此刻一旦真的走完，身体可以先松下来，不必立刻靠抓紧来抵抗结束。
- 安静下来后，最早那种私人的亲近又回来，却已经带着回忆的温柔。
  → 他早已学会让过去的亲近在回味中继续温暖自己；而经过前一段不逃开的承受，这一次不只是某个快乐瞬间，连整段亲近都开始成为已经发生过的事。
- 最后仍有舍不得和一点疼，却出现了清楚、踏实而郑重的结束感。
  → 他已经不必靠更强的激动确认自己有多在乎，也知道没有保证并不会抹掉真实得到过的幸福。因此此刻可以停止追赶，而不把尚无答案误认成这一切没有成立。

**珠子**

- **B1**［主体验］（116 小节）音乐没有像梦一样慢慢飘走。第116小节，最后几下和弦干脆、沉重，低音像铁锚落入水底，把还在摇荡的小船一下定住。也可以想成一个人经历了强烈的内心震荡后，站起来，整理衣服，关上门。
- **B2**［段内变化］（111–115（承接110–111小节交界的最后冲击） 小节）110–111小节交界，最后一股浪头像是又猛推了一下；进入终结句，音乐才真正松下来、轻下来。心里仍然温热，身体却慢慢恢复了平静。也像从一场美梦里醒来，还记得梦里的光。
- **B3**［另一侧面］（113–115 小节）就在声音渐渐变轻的时候，第113小节左手内声部幽幽地唱出一句，像男中音独自沉思。先前熟悉的歌唱与摇荡，仿佛又回来了一次。到115小节，右手一道细碎的琶音像水花溅落夜空——低低的一声回望之后，还有最后一闪。
- **B4**［另一侧面］（113–116 小节）尾声似乎还在与全曲开头隔空说话。第113小节附近，熟悉的声响像隔着很远应了一声；到116小节，最后那几下向上的和弦动作，又像接住开头悬着的话，终于把它说完。

## 肖邦《幻想波兰舞曲》Op.61

**P9 的 Center**：他珍惜那份亲切的美好，想安心地留在其中，却始终无法把握它。

**P8 的 Center**：他在乎那份亲切，既想让它有可靠的着落，又不愿自己的珍惜只能靠抓紧和逼迫来维持。

### S01 ｜ 1–23 小节

**P9**

- 先是猛地一紧，郑重，却不知道该把这份重量放在哪里。
  → 事情还没来得及被理解，身体已经先觉得它不能轻轻带过；可又没有现成的解释，于是只能收紧、停住。
- 惊动退下后，留下的是悬着的失落和迟疑。
  → 最初那一下没有真正散去，他开始发现这不是一阵马上会过去的反应；越继续待在里面，越无法随便给它定性。
- 迟疑里渐渐有了亲切和暖意，却仍伴着抓不住的难过。
  → 他在这份感觉里待久了一些，开始真切感到它对自己有吸引力；可一想确认这种亲切能不能留下，就发现自己仍没有把握。
- 到最后仍没想明白，却已经有一点郑重地向前的劲。
  → 反复靠近又停住以后，他至少确认这份在意不会自行消失；没有答案，但他开始能承受这种不确定，不必一直悬在原地。

**P8**

- 猛地郑重地绷紧，随即又悬空，茫然得不知该往哪里着力。
  → 他还没弄清是什么触动了自己，身体已经先觉得不能倒下，想用力挺住。可这份郑重并不能告诉他究竟该抓住什么，刚提起的劲便落了空。
- 紧绷慢慢变成失神和孤单，心里难过，却说不清在难过什么。
  → 最初的惊动过去后，他本以为停一停就能缓过来，可那份空落并没有散去。越是安静地待着，越觉得心里确实少了什么，却连自己在惦念什么都还不知道。
- 恍惚中渐渐感到亲切和温暖，随之又生出难以言说的惆怅。
  → 他一直没有离开这份惦念，渐渐从茫然中摸到一种仿佛早已熟悉的感觉。可越觉得它亲近，越发现这份亲近只能在心里感到，不能就此变成眼前能够握住的东西。
- 仍有失落和迟疑，却慢慢有了一点想向前的劲，还不敢说站稳了。
  → 刚才短暂的亲切虽然留不住，却让他知道自己确实还想靠近。几次悬着、停住以后，他不再只是等着心情平复，身体先有了一点迈步的准备，尽管心里仍没有把握。

**珠子**

- **B1**［主体验］（1–6 小节）先听开头那一下沉重、郑重的和弦：它像要宣告什么，紧接着的自由上行琶音却没把这份重量接住，反而像烟雾往高处散，声音轻了、远了，悬在半空。也可以把它听成一次召唤，只是停顿里仿佛还等着回声。
- **B2**［另一侧面］（1–23 小节）短句像叹息，刚冒出来就被长停顿截断；听着余音在冰冷的空气里慢慢散尽。心里明明有东西，却还分不清这份不平静究竟是愤怒、遗憾还是怀念——这是一种尚未找到对象、也尚未找到语言的失落。
- **B3**［另一侧面］（1–23 小节）换一种更身体化的听法：像刚从漫长的昏沉中醒来，四周冷而空，胸口有些发紧，视线还模糊着；伸出颤抖的手去摸，摸到的却只有虚空。这里不是已经哭出来的悲伤，而是连自己身在何处都还没弄清的恍惚。
- **B4**［段内变化］（9–17；18–23 小节）约9–17小节，旋律轮廓稍稍清楚，像一幕旧场景忽然回来：当时的声音、光线和某种熟悉的感觉都回来了；可记忆再清晰，过去也不会因此重新变成现在。到18–23小节，波兰舞曲的步态逐渐浮现，像身体先于意识，隐约记起了该如何迈步。这只是往前的牵引，还不是第24小节起的主题已经站稳。
- **B5**［另一侧面］（1–23 小节）另一个听法是：开头那下有分量的和弦，像一个人强迫自己挺直背脊，提醒自己不能倒下；可自由琶音马上把这份郑重带回内心的游移。尊严还在，行动的方向和力气却不稳——“我不能倒下，以及我其实很想停下来。”

### S02 ｜ 24–65 小节

**P9**

- 他终于站得端正、有尊严，心里却有一缕酸楚。
  → 上一段让他知道，没答案也能带着在意向前；此刻他试着把自己收束得郑重。那份挺立是真的，可心底的亲切仍像隔着距离，触得到却握不稳。
- 他一度振奋，随即感到这份坚定有些吃力。
  → 既然端正能让自己站住，他便愿意把更多感情托上去；但越投入，越觉出底下的脆弱和不安还在。奋起不是假的，只是暂时托不住全部。
- 他再次挺起，热切里开始有焦躁和不甘。
  → 刚才退下来，心里的在意并未退，他不愿就此松开，便反复鼓动自己撑住。可越想证明自己能承受，越显出那份珍惜还在疼。
- 他越撑越急，最后仍绷着，没能安心。
  → 前面那份自持确实管用，才让他一次次想靠它站稳；可维持它要不断加力，解决的只是怎样不退开，不是怎样让珍惜得到安顿。

**P8**

- 他终于有了庄严和底气，心里却仍有柔软的伤感。
  → 先前那份亲切虽不能当成已经拥有的东西，却让他真切地想靠近。如今他不再只顾着弄清它，而是郑重地承认自己的珍惜，因此能挺直起来；但这份力量并没有消除亲切背后的失落。
- 他越来越激昂，也越来越急切，甚至有些不甘心。
  → 刚才的郑重确实让他站住，也让他更清楚这份亲切有多值得珍惜。可越投入，他越感觉到，能够挺住并不等于能够安心；他开始不甘心总要靠用力承受才能守住这份珍惜。
- 他一次次把自己稳住，坚定里渐渐透出紧张。
  → 刚才他已经尝到郑重承认心意所带来的力量，于是更想保持这份挺直。但每次重新收束自己，都让他察觉不安其实还在；越要维持镇定，越显出这件事对他有多重。
- 高涨渐渐收敛，他仍舍不得放下，也没有安心。
  → 几次重新振作都确实让他站住了一阵，却始终没能让那份亲切变得可以把握。等强烈的自持渐渐收住，原先没有解决的牵挂仍在那里；他还愿意坚持，却已知道坚持不能代替安心。

**珠子**

- **B1**［主体验］（24–65（旧歌质地主要在24–43） 小节）波兰舞曲的步态终于清楚了，却不像英雄凯旋；主旋律更像一首从远处传来的旧歌，你依稀记得它，却只能模糊地哼出几句。也可以把它听成两层声音：舞曲带着一点面向众人的庄严，歌声却像私人记忆里的低声哼唱。那些珍惜的东西仿佛还在，却已不能像从前那样拥有。
- **B2**［另一侧面］（24–65 小节）它不是士兵的步伐，更像腿脚虚浮的人，在记忆中挪动舞步。节奏本身庄严、傲慢，旋律却脆弱凄婉；底下的伴奏还有细碎、不安的半音在蠕动。
- **B3**［段内变化］（38–65（38–43、52–63、56–65为局部标记） 小节）听它怎样起伏：38–43小节，音乐猛地往上推，却又退下来；44–65小节再次聚拢力量，52–63小节一带更焦灼，最后仍没有舒舒服服地落地。56–65小节连绵的三连音，仿佛把呼吸催得越来越急。
- **B4**［另一侧面］（24–65（24–43的姿态；44–65的自我说服） 小节）这份挺直可以听成一种强烈的自我控制。像一个人整理好衣服、抬起头，不让别人看见动摇；到44–65小节，它又像反复对自己说“我没事”：第一次还有几分相信，第二次开始努力让自己相信，说到第三次，连这句话本身都暴露出其实很在意。悲伤还在，只是不愿把自己完全交给悲伤。
- **B5**［另一侧面］（44–65 小节）另一种心理动因是，44–65小节的激昂像一句“我不甘心就这样消亡”：不是轻松恢复自信，而是负隅顽抗。这股力量可以与自我控制同时存在，但不必把两种原稿的说法拼成同一个人的确定剧情。

### S03 ｜ 66–91 小节

**P9**

- 一股愤懑和急切突然涌上来，想挣开，却越动越心慌。
  → 先前的郑重确实给了他力量，却也让他看清，再坚持也抓不住珍惜的东西。此刻他仍想凭自己的力量往前，却不知道该往哪里去；越不肯停下，越感到抗拒和焦躁。
- 心里像有许多声音纠缠，连刚才的坚定也变得可疑。
  → 他已经知道那份力量需要不断维持。如今越是找不到方向，越忍不住怀疑：刚才是真的相信自己能够承受，还是一直在努力说服自己？原来能让他站稳的做法，此刻反而使他分不清自己的心意。
- 他暂时不再跟自己较劲，竟感到一阵真实的轻松。
  → 刚才越想凭意志找到方向，心里越乱，他便暂时不再逼自己弄明白。注意力从那件沉重的事上移开，紧绷也跟着松了些；他发现即使不时时守着那份郑重，自己仍能感到亲切和愉快。
- 温柔得几乎舍不得，却又因这份亲切而心酸。
  → 刚才松开以后，他才尝到一种不必时时防备的自在，像自己珍惜的美好原来也可以如此亲近。但先前的坚持并没有使它变得可把握；越真切地感到这份柔和，越难受于自己还不能安心拥有它。

**P8**

- 刚才的笃定一松，他反而焦躁、抗拒，急着往前却找不到方向。
  → 前面他靠郑重坚持站稳了，却仍不安心；如今更不想一直硬撑。旧办法刚松，新的着力点又没有，他便急着找路，也忍不住怀疑刚才的笃定有几分是自己撑出来的。
- 他暂时把心思移开，确实轻松了一些，却仍游移不定，难以安静。
  → 先前一直用力守住自己的珍惜，已经让他疲惫；此刻不再紧盯那个问题，便有了喘息的余地。轻松是真的，可原先压在一旁的疑问并没有散，少了那股坚持压着，反倒纷纷冒了出来。
- 忽然有一阵熟悉的温柔，让他觉得轻盈、亲近，却又心酸。
  → 暂时不再费力证明自己站得住，早先触动过他的那份亲切反而自然浮现。他发现，不必硬撑也能从珍惜中得到快乐；可越是这样自然地感到亲近，越让他难过于这份温柔仍不是自己能留住的。

**珠子**

- **B1**［主体验］（66–91；m.66的和弦重击为条件性细节 小节）第66小节的和弦若被突出，会像重锤砸下，带着愤怒与抗拒；这一段强弱跳动、切分让人心口悬起。音乐离开前面的端正步态，转入更灵活、流动却不安的舞蹈性格，像想往前走，却无法平静地决定方向。
- **B2**［段内变化］（66–79 → 80–91 小节）一种听法把前半（66–79）听成焦躁、急切，后半（80–91）则忽然柔和、亲切，带一点近乎田园的轻盈。有人会想到故乡夏日的麦浪与微风；另一种相近的联想，是曾经轻松、亲近、不必时时防备的时刻。温柔得让人心颤，也刺痛得让人绝望：越怀念，越能感觉它与眼前处境的距离。
- **B3**［另一侧面］（66–91 小节）也可以把耳朵收进旋律里：像多个人在耳边低声絮语，彼此缠绕，找不到出口；调性又像流沙，抓不住重心，四处漂移。
- **B4**［另一种理解］（66–91 小节）这股活动感也可以听成一次短暂的侧身离场：不再正面迎着那个沉重的问题，像是聊点别的，或出去走走，让注意力暂时离开伤口。那一刻的轻松可以是真的，并非假装；只是它没有替心里的事找到答案。
- **B5**［另一种理解］（66–91 小节）另一个听法不是把这里听成重新获得活力，而是前一段的昂扬慢慢退潮。音乐变得流动、含蓄、若有所思，仿佛心里冒出一句自问：我刚才是真的相信那些话，还是只是在努力让自己相信？

### S04 ｜ 92–115 小节

**P9**

- 熟悉的坚定又回来了，却更温柔亲近，带着感激和脆弱。
  → 他曾靠郑重获得力量，也已怀疑那力量是否靠硬撑；刚才又尝到不必追问的亲切。如今再次认真面对，便不必只摆出坚强，也能让眷恋和柔软露出来。
- 越回味这份温柔，越舍不得它过去，心里开始发酸。
  → 前一段让他尝到不必强撑的快乐，也让他想要它久留。此刻熟悉的亲切再次回来，他更深地感到：重新体会一种美好，不等于能让它停住；曾有的快乐越真，无法留住它就越刺痛。
- 温柔忽然变成猛烈的焦急，身体越绷越紧，最后显出疲惫。
  → 他已知道坚持能给力量，却不能带来把握；又刚体会过不必强撑的快乐。此刻越想留住这份亲切，越忍不住加力，连身体都像被催着往前赶；可加力仍换不来安心，反而只剩拉扯和疲惫。
- 他反复追问为什么仍无法安心，念头越转越乱。
  → 先前他已怀疑自己的坚定是否靠不断用力维持，刚才又真切体会过不追问的快乐。此刻亲切与无把握同时存在，他便反复想弄清为何仍不能安稳；一个疑问牵出另一个，却始终没有新答案。

**P8**

- 熟悉的郑重让他重新踏实，却也有了柔软的欣喜和感激。
  → 前面他已知道，认真珍惜能让自己站稳，却不能换来安心；又尝过不必硬撑的亲切。如今重新认真起来，他不再急着证明自己够坚定，反而更清楚自己珍惜的东西有多好。
- 越觉得亲切幸福，他越心酸，越舍不得它再过去。
  → 刚才那份不用勉强的快乐是真的，却没能让温柔留下。现在这份亲近再次出现，他已不能只为它回来而高兴，也会想到它可能仍是短暂的；不安就贴在了眷恋里。
