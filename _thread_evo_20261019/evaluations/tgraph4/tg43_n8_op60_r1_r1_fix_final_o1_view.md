# Op.60｜关系图

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3　（还说不清）

- 他还说不清自己盼什么；只是心里有了想亲近的人，一想到对方就柔软起来。
- → 可这份喜欢才想多停留一会儿，他又下意识地把心收了回去。
- → 明明眼下没有什么逼他作决定，他还是谨慎，连自己也说不清缘由。
- → 这点喜欢轻得仿佛随时可以放下，他却偏偏舍不得。

### 4–16　（没在想）

- 既然还说不清自己怕什么，他先不替喜欢安排去向；两人以后怎样，可以以后再说。
  - ← 提供理由：（1–3）「明明眼下没有什么逼他」
- → 这样想着，他才慢慢敢安心地靠近那个人。
- → 心里的温柔可以直接给出去，不必时时打听对方有没有接住。
- → 原来认真在乎一个人未必让人不安；对方再重要，他也能从容，甚至比以前自在。
- → 这份快乐让他渐渐不再提防自己的喜欢，也有点欣赏自己的宽和。
- → 那时他真觉得，只要亲近自然，不追问、不计较，就已经够了。

### 17–23　（正在面对）

- 尝过亲近的幸福后，他开始盼这份喜欢能延续，不只属于眼前。
- → 一想到长久，他就想到：自己能珍惜对方，却决定不了对方是否也把自己放在心上。
- → 从前觉得无需确认的事，如今竟开始牵动他的心。
- → 他没打算索取什么，只是偶尔想知道，自己对对方是否也很特别。
- → 期待只多了一点，原先的安稳就松动了。
- → 他有些意外：明明已经觉得满足了，怎么还是会盼着更多？　✦ 满足照出未满足
  - ← 动摇：（4–16）「那时他真觉得，只要亲」

### 24–34　（正在面对）

- 他怕新添的紧张毁掉好不容易得来的快乐；何况对方从没答应过什么。
  - ← 提供理由：（17–23）「期待只多了一点，原先」
- → 于是他提醒自己：关心对方、愿意给予、真心替对方高兴，本来就是快乐。
- → 珍惜一个人，不必每次都换来对方的表示或一句保证；他试着把心放宽。
- → 这样想真的让他松下来，先前那股想确认对方心意的紧张渐渐退去。
- → 轻松些后，他更愿意付出，也不再一笔笔计算自己给了多少。
- → 多给一点不再让他怕自己显得更在乎；尽情地对一个人好，反而让心里丰盈。
- → 那阵子他相信，亲近可以不伤人：只要不提要求，就能尽情去爱，也不会失去什么。

### 35–39　（还说不清）

- 欢喜稍稍平下去后，他还是想知道：对方有没有也把他放在心上。
  - ← 动摇：（24–34）「那阵子他相信，亲近可」
- → 刚为无所求而高兴，转眼又盼着被看见；这让他觉得难堪。
- → 他开始怀疑，那些体贴里是不是一直藏着不肯承认的盼望。
- → 说自己毫无所求不够诚实；可先前的快乐也确实不是为了换来什么。
- → 他暂且停在这份不自在里，不替自己辩护，也不拿新的热烈把它盖住。

### 40–50　（没在想）

- 这份难堪没让他少喜欢，却让他不想再靠多付出来证明自己。
  - ← 提供理由：（35–39）「刚为无所求而高兴，转」
- → 他不想天天查看对方在不在意，也不逼自己变成一个全无期待的人。
- → 与其盘算两人以后怎样，他转而留心此刻：自己真心愿意为对方做什么。
- → 他盼对方过得好，安静地惦记着，也会因心里有这个人而欢喜。
- → 这样细细地喜欢，让他暂时忘了自己为何那么想知道对方的心意，只觉得甜。

### 51–61　（正在面对）

- 可甜意留得越久，喜欢越不再轻巧，也渐渐难以收放。
  - ← 改写：（40–50）「这样细细地喜欢，让他」
- → 他原想把喜欢留在自己心里，免得对方为难，也免得期待牵着自己走。
- → 越珍惜对方，他越常惦念，也越盼对方能懂得自己的关心。
- → 他仍觉得不催对方才是对的；只是那些没着落的盼望，只能自己放在心里。　✦ 办法的限度
- → 这份喜欢并非不值得；正因尝过那么细的甜，他才舍不得把它减轻。
  - ← 提供理由：（40–50）「他盼对方过得好，安静」

### 62–71　（没在想）

- 喜欢已经这么深，他忽然不想再时时把它当成必须管住的东西。
  - ← 提供理由：（51–61）「这份喜欢并非不值得；」
- → 他想起最初的安心、付出时的满足和独自珍藏的甜，都不是对方许诺后才有的。
  - ← 说明：（4–16）「这样想着，他才慢慢敢」
  - ← 说明：（24–34）「多给一点不再让他怕自」
  - ← 说明：（40–50）「这样细细地喜欢，让他」
- → 即使仍盼着对方珍惜自己，那些快乐也不因此虚假；他不想再怕受伤而小心高兴。
- → 这一次，他想尽情喜欢，不急着问结果，也不忙着替未来留退路。
- → 积攒已久的眷恋成了坦然的热情，不必每给深一点就提醒自己收回。
- → 有一阵，欢喜盖过所有顾虑；没有保证这件事，几乎也压不到他心上。

### 72–77　（正在面对）

- 欢喜稍落定，他才看清：自己不只想尽情喜欢，也盼对方同样把他放在心上。　✦ 满足照出未满足
  - ← 唤起：（62–71）「有一阵，欢喜盖过所有」
- → 他想知道对方是否也渴望靠近，是否愿意把彼此当成重要的人。
- → 可他喜欢得再深，也不能因此要求对方同样喜欢自己。　✦ 分清
- → 退回谨慎，像是在辜负刚承认的心；继续盼下去，又怕自己把爱变成要求。
- → 两边都舍不得，他找不到两全的办法，越想越委屈，也厌倦反复为难自己。

### 78–83　（正在面对）

- 他终于不再逼自己马上选一边，先不决定该怎么处理这份感情。
  - ← 提供理由：（72–77）「两边都舍不得，他找不」
- → 想靠近时，不必立刻往前；想守住分寸，也不必把眷恋藏得看不见。
- → 想靠近和想守住分寸都还在；他可以带着盼望喜欢，也承认自己没把握。
- → 这样暂且放过自己，心里松了一点；那份为难仍然存在。
- → 只是原本绷紧的温柔，终于又能自然地留在心里。

### 84–92　（正在面对）

- 不再逼自己消除渴望后，他又尝到最初亲近一个人的快乐。
- → 这一次，他尝过期待的紧张和求证的难堪，也知道再深的喜欢替不了对方作决定，却仍愿意喜欢。
- → 于是无需再用无所求证明体贴，也不必因想被珍惜就怀疑真心。
- → 他不再躲着这份感情，也不为自己的热切害羞；犹疑了这么久仍能高兴，让他感动。
- → 从前让他警惕的愿望，如今也能和喜欢一起存在。
- → 他并未变得无忧无虑，只是知道可能受伤，仍愿把幸福充分认下来。
- ⟲ 仍在起作用：（17–23）「期待只多了一点，原先」；（35–39）「刚为无所求而高兴，转」；（72–77）「可他喜欢得再深，也不」

### 93–102　（没在想）

- 不再遮掩渴望，他反而更清楚：自己有多想靠近这个人。
  - ← 提供理由：（84–92）「从前让他警惕的愿望，」
- → 他想把攒下的温柔都给出去，也想让亲密不只停在自己的愿望里。
- → 他想被同样深切地珍惜，也想知道两人能共同拥有多丰盛的幸福。
- → 这些愿望曾让他紧张、难堪，如今仍在，却暂时不再以缺憾折磨他。
- → 此刻他觉得自己有很多爱可以给，也有很多值得珍惜，仿佛再无所缺。
- → 那一刻，满足几乎满得让他招架不住，仿佛所有心愿都已说尽；对方却没给新保证。
- → 他顾不上以后，只想让这一刻的幸福完整地停留。

### 103–110　（正在面对）

- 幸福还鲜明着，他就察觉：心里仍有一块地方没有着落。
  - ← 动摇：（93–102）「他顾不上以后，只想让」
- → 他能尽情拥有自己的深情，却不能靠这份深情换来对方同样的选择。
- → 刚才的欢喜越真实，眼下的酸楚就越难忽略。　✦ 满足照出未满足
  - ← 提供理由：（93–102）「他顾不上以后，只想让」
- → 他已知道自己爱得多深，再也不能轻易说对方怎样选择都无所谓。
- → 他不想把安稳全交给对方，更不愿让对方负责消除自己所有的不安。
- → 也不肯因为害怕落空，就故意削弱那些曾给他巨大幸福的感情。
- → 克制曾让他安心，却没让渴望消失；尽情投入也曾让他幸福，却不能保证他不失望。　✦ 办法的限度
- → 他依然迫切想靠近，也坚持不勉强对方；两股心思都不肯退。
- → 如今他更看清两者的冲突，反而觉得更难，因为两边都已舍不得否认。　✦ 知道更多反而更尖锐
- → 他不愿为求轻松就草草丢掉一边，宁可不舒服，也不拿自欺换平静。

### 111–116　（正在面对）

- 带着仍没平息的牵挂，他渐渐不再逼自己找出一种绝不会受伤的爱法。
  - ← 改写：（103–110）「他不愿为求轻松就草草」
- → 他还是想被选择：因为这个人重要，他真心盼两人彼此亲近，即使未必如愿。
- → 也正因为喜欢得深，他舍不得放弃克制；对方有自己的心意，不必和他一样。
- → 若为求安心就要对方接住全部期待，这份亲近反而会失去原有的自在。
  - ← 提供理由：（103–110）「他不想把安稳全交给对」
- → 遗憾还会有，但他不再认为非得先消灭遗憾，才能好好喜欢一个人。
- → 小心靠近、不求对方确认地付出、独自珍藏，以及尽情欢喜，都曾给他真切的快乐。
  - ← 说明：（4–16）「这样想着，他才慢慢敢」
  - ← 说明：（24–34）「多给一点不再让他怕自」
  - ← 说明：（40–50）「这样细细地喜欢，让他」
  - ← 说明：（62–71）「有一阵，欢喜盖过所有」
- → 这些快乐没解开最后的难题，却没有白费；它们让他一次次愿意靠近，也看清对方有多重要。
- → 他试过收住，也试过尽情投入，终于明白哪种做法都不能让爱一个人毫无风险。
  - ← 说明：（103–110）「克制曾让他安心，却没」
- → 他仍盼对方也喜欢自己，偶尔也收住心意；却不再拿对方的选择判真心，也不拿克制证明清醒。
- → 往后他仍可能失望、想要更多，也会因不能更近一步而疼；没人能保证未来。
- → 这些愿望和疼痛，不再成为他否认感情或催促对方的理由。
- → 他愿继续认真喜欢、尽情欢喜，也接受有些事只能由对方决定。
- → 他可以渴望被爱，却不把这份渴望变成对方的义务；珍惜对方的自由，也不必收回自己的心。
- → 他没有得到想要的一切，却不再为了保护彼此，先放弃最想给出的爱。
- ⟲ 仍在起作用：（72–77）「可他喜欢得再深，也不」
