# Op.61｜关系图

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### 1–23　（还说不清）

- 起初他不知道自己究竟在等什么，心里却有股不肯就此算了的劲。
- → 他仿佛觉得，若任由某些事继续下去，就像亲手承认它们理所当然。
- → 可真要把自己投进去时，他又觉得自己会丢下什么。
- → 他试着寻找一个足以让自己不再犹豫的理由。
- → 有时他几乎相信自己想通了，另一份舍不得便浮上来，连刚有的确信也很快变得陌生。
- → 反复之后，他开始难堪于自己的摇摆，甚至疑惑自己是否非得理清心里一切才肯向前。

### 24–65　（正在面对）

- 他渐渐不愿再拿“还没想清楚”当作等候理由，先做自己能做的那一份。
  - ← 改写：（1–23）「难堪于反复摇摆」
- → 没有保证，也没有牵挂消失，但他不再只是等待，真切感到自己有了力量。
- → 他从反复追问值不值得，转而觉得至少自己愿意尽力。
- → 这种改变让他骄傲起来，他发现自己仍有疑虑，也可以不让疑虑支配自己。
- → 他投入得更热切，付出的过程本身让他快乐，仿佛不满终于有了去处。
- → 用力时，他察觉有一处心意并未随之昂扬，坚定也没顾到所有牵挂。

### 66–91　（没在想）

- 因为已经认真投入过，他反而能从原先反复自问里稍稍松开。
  - ← 提供理由：（24–65）「投入付出本身带来快乐」
- → 他在向前的热情里感到轻盈，偶尔忘了用力的缘由也不觉得背叛，仿佛尝到久违的自由。
- → 他顺着这份自由走了一程，没有急着给它更大的意义。
- → 快乐不再那么满时，先前作出的决定仍在等着他。

### 92–115　（正在面对）

- 他重新面对先前的决定，仍愿意坚持，因为它确实曾把他从无法动弹的犹豫里带出来。
  - ← 唤起：（66–91）「快乐减退后决定仍在」
  - ← 提供理由：（24–65）「不再拿没想清楚等候」
- → 那一阵轻快也是实在的收获，他不愿因心里仍有缺口就说先前一切都错了。
- → 可曾让他昂起头的坚定，此时已经无法让他安稳。
- → 他不情愿地看见，行动值得，却仍然不够，这个答案已无法再被他装作不知。　✦ 满足照出未满足

### 116–147　（正在面对）

- 明知行动仍不够，他却不肯撒手，因为行动曾救他脱离犹疑。
  - ← 提供理由：（92–115）「因曾脱困仍愿坚持」
- → 他害怕眼下的失望意味着自己变了心，于是更加用力催逼自己。
- → 他知道自己在受苦，却把心里的难处当成必须克服的迟疑，想停一停又怕那是退缩。
- → 他不知道除了继续坚持，还能怎样对得起最初的决意。
- → 他越想维持坚定，越把疲惫和脆弱当成错，开始苛责自己。　✦ 办法的不足
- → 终于，他不想再证明自己有多坚强，暂时放下了对自己的催逼。
- → 放下催逼并未立刻使他安心，却让一直被压住的依恋有了回来余地。
- → 他有些茫然，也有些松懈，仿佛终于允许自己承认，除了必须做的事，他还真心舍不得别的东西。

### 148–180　（没在想）

- 不再催逼自己后，他看清那份依恋指向一种曾真心相信的生活，那里有他想要的亲近与温柔。
  - ← 说明：（116–147）「承认舍不得别的东西」
- → 他盼望人与人无需时时防备，珍惜的东西也不必靠争夺才能留下。
- 他希望人不必反复证明自己值得被爱、被接纳，付出也能出于喜欢。
- 他也希望靠近珍惜的人和事时，不必预先做好受伤的准备。
- → 他曾体验过那种柔软亲近的生活，因此不肯把这份盼望看作软弱。
- → 他暂不逼这份向往证明有用，只让自己去爱与相信，终于感到真实满足，连疲惫也淡了，也暂不想离开。

### 181–205　（正在面对）

- 这份安宁太真实，他不愿只把它留在心里，也知道阻碍这种生活的事不能只靠怀念改变。　✦ 满足照出未满足
  - ← 提供理由：（148–180）「不逼向往证明有用而感到满足」
- 他想起自己起初拒绝被动等待，也正因不愿重要的东西继续受损。
- → 一阵懊恼随之而来，他几乎责怪自己刚沉浸在满足里就忘了仍要面对的事。
- → 他试着要求自己振作，却已无法像从前那样毫无顾忌地投入。
- → 因为已充分感到温柔可贵，他害怕重新投入艰难争取会一点点耗尽它。
- → 他怕最后只剩不肯退让的意志，失去原本让一切值得争取的心。
- → 于是向前和停留都让他不安，他舍不得安宁，也放不下它所受的威胁。
- → 他曾以为只要找到足够坚定的理由便不会再为难，如今理由更多，心却更难平静。　✦ 知道更多反而更尖锐
- ⟲ 仍在起作用：（1–23）「不愿默认事情理所当然」

### 206–213　（没在想）

- → 他知道不能一直停留，却不再一想起这份温柔就责问自己，愿意再珍惜片刻。
  - ← 提供理由：（148–180）「不逼向往证明有用而感到满足」
- → 这点安静仍使他欢喜，只是欢喜里已经带着不舍。

### 214–215　（正在面对）

- 安静退去后，熟悉的迟疑又回来，仿佛走了很远仍回到原处。
  - ← 唤起：（206–213）「欢喜中已经带着不舍」
- → 他如今知道自己始终放不下什么，那份迟疑里有怯懦，也有他不愿失去的生活希望。　✦ 分清
  - ← 改写：（148–180）「依恋指向曾信的生活」

### 216–225　（正在面对）

- 知道自己舍不得什么，并没立刻使他勇敢起来。
  - ← 限制：（214–215）「迟疑藏着怯懦与希望」
- → 他看出，决心曾带他向前，旧愿曾给他安慰，可如今两者都不足以独自带他继续。　✦ 办法的不足
  - ← 说明：（92–115）「因曾脱困仍愿坚持」
- → 他只愿争取时记得缘由，也在爱惜安宁时继续面对威胁它的事。
- → 这样想着，非得舍弃一边才能继续的逼迫，似乎稍稍轻了一些。

### 226–241　（正在面对）

- 凭着这点尚不牢靠的心意，他重新思考自己还能怎么办。
  - ← 提供理由：（216–225）「非此即彼的逼迫稍减」
- 他亲身体会到，开始行动能让他不再干等，却不能消除所有牵挂。　✦ 办法的不足
  - ← 说明：（24–65）「行动后感到有力量」
- 他也尝过，心中美好能给人安慰，却不能单靠安慰保护所珍爱的生活。　✦ 办法的不足
  - ← 限制：（148–180）「不逼向往证明有用而感到满足」
- → 两样收获都是真的，他不愿简单否定任何一个。
- → 他想保有无需时时奋力的安宁，可为它争取也可能让自己失去安宁。
- 过去他常因这种为难责怪自己，仿佛坚定的人不该如此。
- → 如今他渐渐承认，珍视的东西不止一种，它们有时难以兼顾。　✦ 选择的冲突
- → 这份承认没有让他轻松，他仍为将要付出的东西心疼，也盼有更容易的路。
- → 他知道再等下去不会让那条更容易的路自然出现。
- → 若只因害怕损伤珍贵之物便不再争取，他所爱惜的也未必能留下。
- → 越接近真正行动，他越清楚自己仍会怕，却不肯让惧怕替自己决定。

### 242–253　（正在面对）

- 不再等一个毫无损失的办法，他终于重新愿意向前行动。
  - ← 提供理由：（226–241）「不让惧怕替自己决定」
- → 久违的昂扬回来了，他不再否认脆弱，也不必等疑虑消失才敢坚定。
- → 他仍愿尽力，却不再要求这份尽力证明自己有能力改变一切。
- → 他愿为珍惜的东西负责，不再藏起害怕失去什么，也不把牵挂当作拖累。
- ⟲ 仍在起作用：（226–241）「珍视多样事物难以兼顾」

### 254–288　（正在面对）

- 带着全部牵挂重新向前时，他有些意外，旧日的愿望并未因此远去，反而似乎更亲近。
  - ← 改写：（242–253）「为珍惜负责不藏怕失去」
- 过去想到这种生活，他常想从艰难争取中撤回，仿佛这样才能完整保住它。
- → 如今正因知道它多么可贵，他更不愿任由使它难以实现的事情继续存在。
- → 他承认，想保住那份温柔，有时就得离开眼前的安宁去行动。
- → 他不把更多投入当作接近旧梦的保证，也不把美好愿望当作所有付出的理由。　✦ 办法的不足
  - ← 限制：（226–241）「行动打破无力却难消牵挂」
  - ← 限制：（226–241）「美好能安慰却难护生活」
- → 他会留意争取时是否又在催逼自己，不让那份温柔被磨掉。
  - ← 改写：（181–205）「怕争取艰难耗尽温柔」
- → 他发现，珍惜那种温柔生活，也能让他更愿意为它行动。
  - ← 改写：（226–241）「珍视多样事物难以兼顾」
- → 他重新尝到最初相信生活时的快乐，可历经怀疑与疲惫后，这份快乐已不再理所当然。
- → 喜悦平静后，他仍不知道许多事会怎样，也无法保证自己的行动能改变什么，生活仍需防备。
- → 他不再用行动时的畅快遮住对温柔生活的眷恋，也不因眼下仍不满足就抹去行动的收获。
  - ← 改写：（92–115）「看见行动值得却不够」
  - ← 改写：（148–180）「不逼向往证明有用而感到满足」
- → 他明白，自己想改变的正是那些让温柔生活难以实现的事，而不是温柔本身。
  - ← 提供理由：（24–65）「投入付出本身带来快乐」
  - ← 限制：（116–147）「坚定渐成自我苛责」
  - ← 提供理由：（148–180）「不逼向往证明有用而感到满足」
  - ← 限制：（181–205）「怕争取艰难耗尽温柔」
- → 他仍想过安宁的日子，也愿为它行动，虽不知能留住多少，仍不必抹去任何一边。
- ⟲ 仍在起作用：（148–180）「盼人与人不必时时防备」；（181–205）「想起起初拒绝被动等待」
