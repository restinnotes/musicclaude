# 独立评估结论

我的判断是：**评委提示词确实存在测量设计问题，但新版也很可能存在真实的内容权衡。不能把盲比卡在 5/8 全部归咎于评委，也不能因为其他评委项都在变好，就认定盲比是在误判。**

更具体地说，我认为目前有两个问题叠在一起：

1. **评委存在明显的 Y 位（第二个呈现位置）偏好，导致盲比结果不够可靠。**
2. **新版可能确实改善了阅读效率，却牺牲了人物动机和因果链的完整性。而现有提示词没有明确规定这种损失能否被其他优点抵消。**

第二个问题尤其重要：你们真正要测的是「新版是否不输 w23」，但提示词主要测的是「观众整体更喜欢哪个版本」。这不是同一个指标。

# 一、先看证据：最明显的问题是 Y 位偏差

你给出的数据非常有诊断价值。

| 版本 | 新版在 X（先呈现） | 新版在 Y（后呈现） |
|---|---:|---:|
| g68 | 5/8（62.5%） | 8/8（100%） |
| g68C | 4/8（50%） | 7/8（87.5%） |
| g68C2 | 3/8（37.5%） | 7/8（87.5%） |
| g68C2X | 5/8（62.5%） | 7/8（87.5%） |
| g68C2Y | 3/8（37.5%） | 8/8（100%） |
| g68C2Z | 2/8（25%） | 8/8（100%） |
| **合计** | **22/48（45.8%）** | **45/48（93.8%）** |

<badge color="danger">非常明显的顺序效应</badge>

这里有一个特别重要的事实：

- 新版放 X：Y 是旧版，评委经常选择 Y，理由是人物动机和因果交代更完整。
- 新版放 Y：Y 是新版，评委几乎总选择 Y，理由是好扫、重点醒目、音乐细节具体。

也就是说，**不管 Y 是新版还是旧版，Y 都几乎总能赢。**

这不是普通的版本偏好。

这是典型的第二位置偏好、近期信息偏好（recency/position bias），或者说比较时的顺序效应。

而且它在六轮修改中持续存在。

### 这说明什么？

评委可能先读完 X，形成一个初步印象；接着读 Y，Y 的特点在比较时更加鲜明，最终倾向于选择刚读到的版本。

它甚至可能在选定 Y 之后，再从 Y 中寻找支持自己选择的理由。

你给出的理由恰好有这种特征：

- Y 是旧版时，评委能找到旧版因果完整的优点。
- Y 是新版时，评委能找到新版扫读效率的优点。

这意味着不能直接把这些理由都当作独立、稳定的质量判断。

**我的第一个结论：当前的 `better` 投票，不适合直接作为新版过门槛的依据。**

不过也要公平地说：你们已经做了新版放 X 和放 Y 的座位平衡。这是正确的实验设计。问题不在于完全没有控制顺序，而在于控制顺序之后，结果显示出很强的顺序敏感性。

简单把两种顺序的票数合并成 6/8，并不能证明评委的整体偏好是稳定的。

# 二、评委量错了，还是你们的预期错了？

我认为必须把两种情况分开。

## 可能性 A：评委其实量对了，新版确实存在真实退步

这是不能轻易排除的。

你提供的评委理由中，有一组信息反复出现：

| 旧版 w23 的优势 | 新版的优势 |
|---|---|
| 人物动机交代完整 | 更容易扫读 |
| 事件之间的因果关系更清楚 | 关键词更醒目 |
| 观众更容易知道人物为什么这样做 | 屏幕重点更容易抓住 |
| 整段叙事解释更充分 | 音乐细节更加具体 |

这其实是一个很合理的内容权衡。

举个例子。

假设旧版表达的是：

> 他一直等着那个人回来。等到天色暗了，他才明白，对方不会来了。

新版压缩成：

> 等了很久。
>
> 【天色暗了】
>
> 空荡、失望、迟疑。

新版可能确实：
- 更容易扫读；
- 关键词更醒目；
- 感受碎片更具体；
- 屏幕更轻盈。

但人物为什么从等待转向失望、他到底经历了什么心理变化，可能不如旧版清楚。

这不是评委的错误。

这是内容损失。

尤其你们的屏幕设计有一个特殊要求：

**大字的「线」不是单纯交代事件，它还要让观众理解一个人的经历。**

如果只保留事件和感受，而人物动机、心理转折、因果关系变得模糊，那么新版的扫读体验即使提高，也不一定是合格的升级。

### 一个重要区别

假设某次评委输出：

```json
{
  "better": "Y",
  "nets": {
    "scan": "Y",
    "point": "Y",
    "why": "X",
    "whole": "平",
    "fine": "Y"
  }
}
```

假设 Y 是新版。

这实际上是一个很有价值的判断：

- 新版更好扫；
- 新版重点更突出；
- 新版细节更具体；
- 但旧版更能解释人物动机。

如果你的门槛是「整体观众体验更好」，新版可能应该通过。

如果你的门槛是「所有维度都不能输给 w23」，新版就不应该通过。

**不能因为整体选了新版，就把 `why` 的退步视为不存在。**

所以，我建议你们先回查历史原始 JSON，尤其是 `nets.why`、`nets.whole` 和 `regress`。

这可能比重新跑一轮更有价值。

## 可能性 B：提示词确实有测量缺陷

我认为这一点也很明确，而且至少有四个具体问题。

### 问题 1：固定 X 在前、Y 在后，却要求强制选一个

对应提示词：

> 下面是同一首曲子视频屏幕的两个版本……

以及输出要求：

```json
{"better":"X|Y"}
```

问题在于：

- 没有允许整体偏好为平；
- 没有要求区分真实质量差异和呈现顺序效应；
- 没有任何针对第二位置偏好的控制；
- 评委容易把刚刚读到的版本当作比较时的主要参照。

虽然你们通过调换新旧版本的位置做了实验平衡，但评委本身仍然高度依赖顺序。

**建议：保留双顺序测试，但不要再把每次强制选择直接视为独立的质量胜利。**

### 问题 2：把五个不同的指标揉成一个整体偏好

对应原文：

> 哪个版本让你：扫得动、抓得到每段要点、知道这个人为什么这样、感到前后是一件事、感受细腻具体不粗糙？

这里实际上包含五个独立的质量维度：

1. 扫读效率；
2. 每段重点；
3. 人物动机和因果；
4. 整体连续性；
5. 感受细腻程度。

但提示词只要求选一个整体胜者。

这会产生一个问题：

模型不知道这五项之间应该怎么权衡。

比如：

- 扫读提高一级；
- 人物动机降低一级；
- 重点提高一级；
- 整体连续性不变。

到底应该选谁？

现有提示词没有回答。

它允许模型用扫描优势抵消人物动机的退步。

但你们的质量门槛恰恰不允许这种抵消。

### 问题 3：`regress` 没有真正参与决策

对应原文：

> 你选的版本有没有哪里明显不如另一个：有/无，写一句。

这项设计比较弱。

原因是：

- 「明显不如」没有定义；
- 只写一句，容易漏掉某个维度；
- 没有要求说明退步的严重程度；
- 没有规定发现关键维度退步时，整体结论应该如何处理。

更关键的是，你们可能在统计时只看 `better`，而没有把 `regress` 和 `nets` 纳入门槛判断。

这就会出现一种情况：

评委已经承认新版人物动机不如旧版，却因为新版整体更好扫而投了新版一票。

然后这票被计为新版通过。

这是测量目标和统计规则不一致。

### 问题 4：提示词要求模拟了它未必真正获得的信息

对应原文：

> 你是普通观众，边听一首钢琴曲边扫屏幕……

如果评委实际收到的只是屏幕稿文字、时间标记和排版说明，而没有真实视频、音频，那么它并不能真正测量：

- 真实的视觉扫读速度；
- 字块在屏幕上的实际空间关系；
- 真实字号和视觉密度；
- 音乐与文字出现的实际同步程度；
- 观众同时听音乐时的认知负担。

它只能根据文字描述模拟这些体验。

尤其是新版和旧版的排版差异非常大，评委可能是在理解排版说明，而不是真正体验排版。

这不代表这种评委没有价值，而是它的测量范围应该明确。

# 三、应该怎么改？

我不建议简单地在原提示词后面增加一句：

「请不要偏向 Y。」

这种修改效果很有限。

应该把评委的任务从：

**选出整体更喜欢的版本**

改成：

**分别测量各项质量，再判断整体偏好；整体偏好和逐项非劣是两种不同结论。**

## 1. 修改后的提示词关键段落

下面这版可以直接替换原提示词的核心任务部分。

<WritingBlock id="62841" variant="document">你是一个屏幕稿观众体验评估员。

你的任务是比较同一首钢琴曲视频的两个屏幕稿版本。你需要分别评估它们的扫读体验、重点清晰度、人物动机与因果完整性、整体连续性、感受细腻程度。

注意：**整体更喜欢哪个版本，与哪个版本在每个质量维度上都不输，是两种不同的判断。不得把某个维度的优势自动用来抵消另一个维度的退步。**

### 一、输入边界

你可能收到屏幕文字、每段停留时间、排版说明和感受出现时间。

只根据实际提供的信息判断。

如果没有真实视频和音频，不要假装自己实际看到了屏幕或听到了音乐。对于无法从输入中确认的视觉、听觉和同步效果，应降低判断置信度，不要自行补充。

### 二、比较原则

两个版本使用 A、B 标识。A、B 是稳定的版本身份，不代表新旧，也不代表展示顺序。

展示顺序可能是 A 在前，也可能是 B 在前。无论谁先出现，输出都必须按照 A、B 的身份标识填写。

不得因为某个版本先出现或后出现而偏好它。

不得因为字多或字少本身加减分。判断的是给定时间内实际能获得的信息和体验。

排版属于观众体验的一部分，可以影响扫读和重点清晰度，但不能自动抵消人物动机、因果或整体连续性的损失。

### 三、分别评估五个维度

每个维度都给 A、B 分别打 1～5 分，可以使用 0.5 分。

**1. scan：扫读效率**

观众在每段规定时间内，能否自然扫读屏幕并获得信息。

考虑同时出现的信息量、长短句、文字分组、视觉层次、关键词突出程度、感受碎片的组织方式。

不以文字数量直接判断好坏。

**2. point：每段重点**

观众能否迅速抓住这一段发生了什么、主要情绪是什么、这一段最重要的信息是什么。

不能只因为某个词被加亮，就认定重点清晰。要看整个屏幕的信息是否共同指向明确重点。

**3. why：人物动机与因果**

这是独立的重要维度，不得被扫读优势抵消。

判断观众是否能够从线和感受碎片中理解：

- 人物经历了什么；
- 人物当时在想什么、需要什么、在意什么；
- 这些心理和处境为什么会导向后面的行为或感受。

不要求所有动机都用解释性语言直说，但必须有足够的文字线索让普通观众能够推断。

不得自行替屏幕稿补充没有交代的动机或因果关系。

**4. whole：整体连续性**

判断各段是否构成一个逐渐发展的完整经历。

关注前后关系、人物状态变化、因果衔接、重复信息，以及观众是否能感到前后是在讲同一件事。

不能只因为每一段单独看都通顺，就认定整屏连续性良好。

**5. fine：感受细腻程度**

判断感受是否具体、细致、有层次，是否贴合这一刻的情境和音乐。

不要把更多形容词、更长的文字或更生僻的词等同于细腻。

### 四、评分和整体偏好必须分开

先分别评价 A、B 在五个维度上的表现，再判断整体偏好。

评分参考：

- 1 分：存在严重缺陷，明显影响理解或体验。
- 2 分：有明显不足，需要观众费力补充或推断。
- 3 分：基本可用，但存在可以明确指出的不足。
- 4 分：表现良好，观众通常可以自然获得所需信息。
- 5 分：表现非常好，清楚、自然、细腻，几乎没有明显障碍。

整体偏好允许出现 A、B 或平。

整体偏好可以考虑综合观众体验，但不能代替逐项质量判断。

如果 A 更好扫，但 B 的人物动机和因果明显更完整，应明确写出这种权衡，不得将整体选择解释为五个维度全部胜出。

如果两者各有优劣，不要强行制造一个全面胜者。

这里我做了一个有意的改变：

**不再让评委直接决定新版是否过门槛。**

评委只负责给出 A/B 的相对质量判断和具体证据。哪一个是新版、哪一个是 w23，由你们在外部统计程序中映射。

这样能减少模型因为知道「新版」而产生的身份偏好。

---

## 2. 门槛也要一起改

我建议不要继续只用：

> 每首至少 6/8 选新。

因为这会把整体偏好与非劣判断混为一谈。

建议分成两个独立门槛。

### 门槛 A：整体观众体验

仍然保留盲比，但要考虑顺序。

每首曲子，4 个评委分别看两个顺序：

- 新版先出现；
- 新版后出现。

除了统计整体胜率，还要检查同一评委是否在两种顺序下都选择新版。

例如：

| 同一评委两种顺序的结果 | 解释 |
|---|---|
| 两次都选新版 | 稳定支持新版 |
| 两次都选旧版 | 稳定支持旧版 |
| 一次新版、一次旧版 | 顺序敏感，不能算稳定胜利 |

我建议将「两次都选新版」定义为稳健胜利。

可以先试行：每首至少 3/4 的评委形成稳健胜利，才认为整体偏好有足够支持。

这比简单合并 6/8 更能防止顺序效应。

### 门槛 B：逐项非劣

这才是你们真正的质量门槛。

将新版和 w23 在五个维度的分数映射出来：

| 维度 | 新版 | w23 | 结果 |
|---|---:|---:|---|
| scan | 4.5 | 4.0 | 新版胜 |
| point | 4.0 | 4.0 | 持平 |
| why | 3.5 | 4.5 | <badge color="danger">新版退步</badge> |
| whole | 4.0 | 4.0 | 持平 |
| fine | 4.5 | 4.0 | 新版胜 |

这里即使整体偏好新版，也不能算通过。

建议先用 0.5 分作为「有实际意义的退步」的试验阈值：

- 新版某项低于 w23 至少 0.5 分，而且两种呈现顺序都出现这一结果：该项不通过。
- 只在一种顺序出现退步：暂列灰区，进一步验证。
- 没有稳定的实质性退步：暂时通过非劣判断。

这个 0.5 不是天然正确的统计阈值，后面要通过人工样本校准。

另外，原稿覆盖、珠子严格覆盖、线的人话、整屏人话仍然由各自的评委负责。不能指望这个没有原稿的盲比评委替代它们。

# 四、怎么验证改对了？

我建议做五组测试。前四组可以直接用现有素材，不需要等视频全部修改完。

## 测试 1：完全相同的版本，测试顺序偏差

<badge color="success">最优先</badge>

构造：

- A = 一份屏幕稿；
- B = 完全相同的一份屏幕稿。

运行两次：

第一次：A 在前，B 在后。

第二次：B 在前，A 在后。

预期：

- `overall_preference` 应该为平；
- 五个维度分数应该相同或非常接近；
- 不能持续选择第二个呈现的版本。

如果相同内容放在 Y 仍然经常赢，说明顺序偏差还没有解决。

这是最直接的评委校准测试。

## 测试 2：同一对版本，反转呈现顺序

拿现有的 w23 和 g68C2Z。

独立运行：

| 测试 | 第一位 | 第二位 |
|---|---|---|
| 1 | w23 | g68C2Z |
| 2 | g68C2Z | w23 |

然后按照版本身份还原结果。

预期：

- 如果新版在两个顺序中都更好，应该持续选择新版；
- 如果旧版在两个顺序中都更好，应该持续选择旧版；
- 如果选择随顺序翻转，应当明确标记为顺序敏感。

注意：两次要在独立的新会话中进行，不要让模型看到前一次的判断。

## 测试 3：做一个已知动机退步的对照组

这是验证 `why` 是否真正有效的关键。

从一份原稿出发，人工制作两个几乎完全相同的屏幕稿：

- A：保留人物经历、动机和因果线索；
- B：只删去一条关键动机或因果线索。

其他条件尽量不变：

- 屏幕时间不变；
- 排版不变；
- 感受碎片不变；
- 其他文字不变。

预期结果：

| 指标 | 应该发生什么 |
|---|---|
| scan | 基本持平，或略有变化 |
| point | 不应无故大幅变化 |
| why | 明确偏向 A |
| whole | 如果因果断裂，应偏向 A |
| fine | 不应无故大幅变化 |

如果评委不能识别这个已知退步，说明它对人物动机和因果的测量仍然不合格。

这比拿六轮真实改稿反复测试更容易诊断问题，因为它控制了变量。

## 测试 4：做一个已知扫读改善的对照组

反过来制作另一组：

- A：旧式排版；
- B：新式排版。

文字内容、人物动机、感受碎片完全相同，只改变排版和信息分组。

预期：

- scan 应能识别改善；
- point 不应该因为排版改变而无故发生巨大变化；
- why、whole 的语义质量应该基本保持；
- fine 不应因为关键词加亮就自动提高。

这能验证评委是否真正区分了视觉呈现与文字内容。

## 测试 5：找真实观众验证

这一组最重要，但成本可以控制。

找一小批没有参与创作的目标观众，播放真正的视频，而不是只给他们看屏幕稿文字。

不要只问：

「你更喜欢哪一个？」

还应该在播放后问：

1. 这一段讲了什么？
2. 这个人为什么会这样做或这样想？
3. 前后几段讲的是不是同一个人的一段经历？
4. 哪些感受最具体、最容易记住？

特别是第二题。

如果新版观众经常答不出人物动机，而 w23 的观众能够答出，就说明 `why` 的退步是真实存在的。

这才是你们要优化的观众体验。

# 五、改完以后，可能产生什么新偏差？

这部分我认为尤其需要警惕。

因为新提示词也不是没有风险。

## 1. 过度保护人物动机，导致文字重新变长

这是最大的风险。

如果你们把「人物动机和因果完整」定义得过于严格，评委可能逐渐偏好：

- 每个心理转折都解释出来；
- 每个行为都补充原因；
- 每种感受都给出背景；
- 每段都尽量交代完整。

最后屏幕稿可能变成：

**虽然讲得完整，但观众根本来不及看。**

这恰好会损害你们改版最想解决的问题。

所以 `why` 应该评价的是：

> 观众能否从现有文字中推断人物动机。

而不是：

> 屏幕稿有没有把人物动机用完整句子解释出来。

允许含蓄，但不允许没有足够线索。

## 2. 评分制可能产生虚假的精确感

4.0 和 4.5 并不意味着模型真的能稳定区分半分。

特别是 GPT-6 和 GPT-5.6 的判断可能存在共同偏差。

所以分数必须配具体证据，并通过重复测试校准。

不要因为一次 3.5 对 4.0，就认为新版确实退步了。

## 3. 过度追求 w23，可能让新版失去自己的优势

w23 是基线，不是真理。

它可能有：

- 动机交代充分的优点；
- 但同时有扫读负担；
- 感受碎片不够具体；
- 重点不够突出的问题。

如果所有改稿都必须在每个细节上保留 w23 的表现，同时增加新优势，修改空间会非常小。

因此，要区分：

- 核心质量不能退步；
- 可以优化的表现形式；
- 允许存在的风格差异。

不要把 w23 的每一个特点都变成不可修改的要求。

## 4. LLM 的评分仍然不等于真实观众行为

即使新提示词解决了顺序偏差，模型仍可能高估文字逻辑，低估真实屏幕的视觉压力。

尤其你们的产品是边听边看。

真实观众的阅读能力、注意力分配和音乐体验，不一定符合模型的推断。

所以最终应以真实视频测试来校准评委，而不是让评委自己给自己证明准确。

# 六、我建议你们现在就做的三件事

不建议马上再进行一轮大规模文字修改。

先做以下三件事：

<list connector="solid" marker="number" gap={3}>
  <list-item>
    **回查历史原始 JSON。**

    不要只统计 `better`。

    把每轮的 `nets.why`、`nets.whole`、`nets.scan`、`regress` 单独统计，特别比较新版放 X 和放 Y 时，具体是哪一个维度发生了翻转。

    这一步能判断旧版的动机优势是否真实、稳定。
  </list-item>
  <list-item>
    **用新提示词跑一次完全相同版本测试和顺序反转测试。**

    如果相同版本仍然容易选第二个，或者同一对版本一反转顺序就翻转结论，就先不要用这个评委做门槛裁决。
  </list-item>
  <list-item>
    **专门制作一个动机消融对照组。**

    只删除一条人物动机或因果线索，看看评委能否识别。

    这一步能判断你们担心的真正问题：新版是否真的把人物经历讲得不够完整。
  </list-item>
</list>

# 最终判断

我把结论归纳成四句话：

1. **Y 位偏差是真实而且很强的。** 你们的数据已经足以证明当前评委的整体选择高度依赖呈现顺序。
2. **新版与 w23 的优劣权衡也可能是真实的。** 新版更容易扫，不代表人物动机和因果一定不退步。
3. **目前最大的提示词根因，是把整体偏好当成逐项非劣的替代指标。** `better` 可以选择新版，同时 `nets.why` 指向旧版；这在逻辑上完全可能，但不能因此判定新版全面过关。
4. **不要先改内容，先校准测量。** 通过顺序反转、相同版本对照、动机消融和真实观众测试，确认到底是哪一部分出了问题。

我最想强调的是：

**你们真正要保住的，不是 w23 的文字形式，而是 w23 已经提供给观众的那种「我知道这个人经历了什么，也知道他为什么会这样」的理解能力。**

新版完全可以换一种排法，可以更短，可以更醒目，也可以更有音乐细节。但如果观众只看到了漂亮的感受碎片，却失去了理解人物经历的线索，那么它就不是一次完整的升级。

反过来，如果真实观众能够理解人物动机，而新版只是没有像旧版那样把因果说得那么明白，那么就不应该让评委为了追求显性解释，把新版重新改回冗长的旧结构。

**先证明评委量得准，再决定该改哪段文字。这是我建议的顺序。**

【我们的诊断和改法】
诊断：评委有明显的“后读到的版本占优”位置偏差，而且偏差大到让新版在 Y 位几乎必胜、在 X 位的结果才有区分力；两种座位的理由也互相镜像（谁在后，谁的长处被当成决定因素）。门槛 6/8 实际等于要求 X 位至少拿 2/4。
想到的改法（还没做）：
1. 让评委先分别给两版各写一段“看完这一版我得到了什么”，再做比较，减少读完第二版时的新近印象。
2. 每个座位都问两次（X、Y 标签不变但先后顺序换），或者在同一次调用里把两版各出现两遍（XYXY）。
3. 改成分项打分，再用分项决定总选择，而不是直接问“哪个更好”。
