# Op.61｜关系图

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### 1–23　（还说不清）

- 起初，他还说不清自己究竟在等什么。
- 他心里有股不肯就此算了的劲，仿佛任由一些事过去，就等于亲手认定它们本该如此。
- 可一想到真把自己投进去，他又怕会丢下心里舍不得的东西。
- → 他试着找个能让自己不再犹豫的理由，刚觉得想通，舍不得的念头又浮上来。
- → 反复摇摆让他难堪，他开始怀疑自己是否非得把心里一切都想清楚才肯向前。

### 24–65　（正在面对）

- 他渐渐受不了再拿还没想清楚当作等待理由，决定先认下自己能做的那一份。
  - ← 改写：（1–23）「非得想清一切吗」
- → 尽管没有保证，牵挂仍在，可一旦不再只是等待，他真切感到自己有了力量。
- → 他终于能说，至少自己愿意尽力，也为有疑虑却没被疑虑牵着走而骄傲。
- → 付出的过程本身让他快乐，原先无处可去的不满仿佛终于有了去处。
- → 他舍得给出更多，甚至有些贪恋倾尽全力的畅快，也不想总停下来审视软弱。
- → 可用力到深处，他偶尔感到心里一小块始终没跟着昂扬起来，隐约知道还有牵挂没顾到。

### 66–91　（正在面对）

- 他发现自己不只会觉得沉重，也会因不再畏缩而高兴。
  - ← 提供理由：（24–65）「付出本身带来快乐」
- → 他偶尔忘了自己为何如此用力，也不再把这份轻松当成背叛，仿佛尝到久违的自由。
- → 他顺着这份自由走了一程，暂时不急着替它找个更大的说法。
- → 快乐没那么满时，先前作过的决定仍在等他。
- ⟲ 仍在起作用：（24–65）「先认下能做的那份」

### 92–115　（正在面对）

- 他仍愿坚持先前的决定，因为它曾把他从无法动弹的犹豫里带出来，也带给他一阵轻快。
  - ← 提供理由：（24–65）「不再等待有了力量」
- → 他不愿因为心里还有未满足的需要，就把先前的一切都说成错了。
- → 他想确认自己仍有力量，却发现心里另有一种要求，光靠力量满足不了。　✦ 办法的限度
  - ← 限制：（24–65）「牵挂仍未被照顾全」

### 116–147　（正在面对）

- 他明知行动还不够，仍舍不得放手，怕失望意味着自己变了心。
  - ← 提供理由：（24–65）「不再等待有了力量」
- → 他把心里的难处当成必须克服的迟疑，想停一停又怕自己是在退缩。
- → 他不知道除了继续坚持还能怎样对得起最初的决意，便不断催逼自己。
- → 可原先让他昂扬的要求，连脆弱也容不下时，渐渐成了苛责。
- → 他终于不想再证明自己有多坚强，暂时放下对自己的催逼。
- → 他没有立刻安心，却让被压住的依恋慢慢回来，仿佛终于肯看清自己舍不得一些东西。

### 148–180　（没在想）

- 不再催逼自己后，他才看清自己舍不得的是一种曾真心相信过的生活。
  - ← 说明：（116–147）「依恋重新露出来」
- → 他盼人与人不必时时防备，珍贵的东西也不用靠争夺才能留下。
- → 他希望付出出于喜欢，不必总因觉得该做才去做，靠近什么也不用先准备受伤。
- → 这份盼望并非如今为逃避才编出的安慰，它确实曾给过他快乐，让他感到自己不只需要坚强。
- → 他曾感到自己可以被爱、被接纳，人与生活的亲近也能自然延续。
- → 他终于允许自己待在这份盼望里，暂且只感受它，不忙着问能否实现或和眼前坚持孰轻孰重。
- → 只让自己这样去爱、去相信，就让他感到深深满足，仿佛那个只顾向前的自己又能柔软地活着。
- → 他沉浸其中，几乎忘了先前的疲惫，也暂时不想离开。

### 181–205　（正在面对）

- 这份安宁如此真实，他渐渐不能满足于只在心里拥有它。　✦ 满足照出未满足
  - ← 说明：（148–180）「盼望带来深深满足」
- → 他想到，若这种生活值得珍惜，使它难以存在的事情就不能只靠怀念改变。
  - ← 提供理由：（1–23）「不肯任由事情过去」
- → 刚沉浸在满足里就忘了必须面对的事，他一度懊恼，试着重新催自己振作。
- → 想到重新投入艰难争取，他就怕温柔被耗尽，最后只剩硬撑的劲，丢了让一切值得争取的心。　✦ 知道更多反而更尖锐
  - ← 提供理由：（148–180）「盼望带来深深满足」
- → 向前让他不安，停留也让他不安，因为他舍不得那份安宁，又放不下它受到的威胁。
- → 他原以为只要找到足够坚定的理由就不会再为难，如今理由更多，反而更难决定。

### 206–213　（没在想）

- 为难中，那份温柔又短暂地贴近他，他明知不能一直停留，仍不忍立刻推开。
- → 他觉得既然这份温柔曾给他深深满足，想起时不必每次都拿它审问自己。
  - ← 提供理由：（148–180）「盼望带来深深满足」
- → 他愿意再爱惜片刻，暂时不想那些尚无答案的事，这份安静仍让他欢喜，却已有不舍。
- ⟲ 仍在起作用：（181–205）「怕争取耗尽温柔」

### 214–215　（正在面对）

- 安静退去后，熟悉的迟疑又回来，仿佛他走了很远仍回到原处。
  - ← 失效：（206–213）「再爱惜安静片刻」
- → 可他如今知道自己舍不得什么，那份迟疑里也有他不愿失去的生活希望。　✦ 分清
  - ← 说明：（148–180）「相爱不必时时防备」

### 216–225　（正在面对）

- 知道自己舍不得什么，却没让他立刻勇敢起来。
  - ← 说明：（214–215）「迟疑里有生活希望」
- → 只凭决心向前已让他为难，沉浸旧愿带来的安心也难以长久。　✦ 办法的限度
  - ← 限制：（92–115）「力量满足不了别的需要」
  - ← 限制：（148–180）「盼望带来深深满足」
- → 他一时没力气要求自己作出多大改变，只盼若还要争取，就别忘了为何争取。
- → 若还想爱惜那份安宁，他也得面对那些使它难以存在的事情。
- → 他还不知道怎样做到，只反复想着这点微弱意思，心里非得舍弃一边才能继续的逼迫似乎轻了些。

### 226–241　（正在面对）

- 他凭着那点还不牢靠的心意，重新想自己还能怎么办。
  - ← 提供理由：（216–225）「舍弃一边的逼迫减轻」
- → 他渐渐看清，珍惜的东西不止一种，争取其中一样时就可能伤到另一种。　✦ 选择的代价
  - ← 限制：（92–115）「力量满足不了别的需要」
  - ← 限制：（148–180）「盼望带来深深满足」
- → 他想保有那份无需时时奋力的安宁，可为它争取也可能再次失去安宁。
- → 他过去总把这种难受怪到自己头上，如今开始觉得，心疼也可以与坚定同时存在。
- → 想到这里，他仍不轻松，心疼即将付出的东西，也盼有条不必如此艰难的路。
- → 但他知道继续等待，路也不会自己出现，若因怕受损而停下，所爱也可能失去。
  - ← 提供理由：（181–205）「怀念不能改变威胁」
- → 他终于允许自己带着害怕、舍不得和没把握继续往前，即使受苦也照样可以行动。
- → 他一点点重新聚起力量，愿意带着不舍和犹豫一起往前。
- → 快要真正向前时，他仍清楚感觉到害怕，却决定由自己作主。
- ⟲ 仍在起作用：（1–23）「不肯任由事情过去」

### 242–253　（正在面对）

- 不再等一个毫无损失的办法后，他终于又感到久违的昂扬。
  - ← 改写：（226–241）「惧怕不再替他决定」
- → 这回他的劲头容得下脆弱，尽力也不再需要证明自己无所不能。
- → 他知道自己想做什么，也知道为何难以割舍，带着害怕和珍惜照样可以向前。
- → 他愿为真心爱惜的一切继续尽力，心里仍有犹豫，也照样可以作决定。　✦ 分清
  - ← 改写：（226–241）「珍惜两样东西会相伤」

### 254–288　（正在面对）

- 他带着全部牵挂重新向前时，意外发现旧日盼望似乎离自己更近了。
  - ← 提供理由：（242–253）「不等疑虑消失再行动」
- → 过去他以为退出争取才能保住旧愿，如今珍惜它，便想让伤害它的事有所改变。
- → 他第一次真切感到，温柔也能成为他不愿袖手旁观的理由，若争取时丢掉它，尽力又为了什么？
  - ← 提供理由：（148–180）「盼望并非逃避安慰」
- → 他仍想过不必拼命的日子，也渐渐明白，为了珍惜它，有时不能只留在安宁里。
- → 他知道投入再多也未必更接近旧梦，愿望再美好，每次付出仍得仔细掂量。
- → 他仍须留心会不会在争取中丢掉所爱，顾虑也开始提醒他该怎样坚持。
- → 两种心意终于能一起推着他向前，他带着依恋行动，也仍愿做自己觉得该做的事。　✦ 分清
  - ← 改写：（226–241）「珍惜两样东西会相伤」
- → 他重新尝到最初相信生活时的快乐，经历怀疑与疲惫后，这份快乐已不再理所当然。
  - ← 说明：（116–147）「不再证明坚强」
- → 喜悦平静后，他仍不知道努力能改变多少，眼前也还不是那种无需防备的生活。
- → 往后他仍可能疲惫、因要付出的东西而动摇，两种渴望也可能互相妨碍。
- → 他愿意同时顾及两种需要，也珍惜已经得到的东西，即使另一种需要还没满足。
  - ← 改写：（226–241）「珍惜两样东西会相伤」
- → 过去的快乐、失望、疲惫和依恋仍属于他，让他看清什么值得尽力、什么不能轻易丢掉。
  - ← 提供理由：（92–115）「力量满足不了别的需要」
  - ← 提供理由：（148–180）「盼望带来深深满足」
- → 他仍向往安宁，也愿意行动，虽不知道最终能留下多少，却不愿忘掉任何一边。
- → 他愿带着这份不舍继续向前，这回不再需要替自己的决定寻找更多证明。
  - ← 改写：（242–253）「脆弱也能容进劲头」
- ⟲ 仍在起作用：（148–180）「相爱不必时时防备」；（181–205）「怀念不能改变威胁」；（226–241）「珍惜两样东西会相伤」；（254–288）「两种心意共同向前」
