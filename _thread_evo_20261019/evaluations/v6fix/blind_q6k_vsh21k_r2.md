| S01 | h21k：X保留了“还不知道自己到底在难过什么”的未成形状态，同时用“往前投入会不会丢下另一份珍贵”解释了为何刚有向前牵引又迟迟起不了步；Y过早把失落钉死在归属、接纳和旧日生活上。 | h21k：X的三条分别交代受损、投入顾虑和混乱停滞，功能分得开；Y连续几条反复说明旧日安心、如今无着落和放不下过去，信息重叠更多。 | 新版：Y说“不用费力争取接纳、不用证明自己值得留下”比X反复用“珍贵的东西”“过去那种生活”更像一个人在讲具体处境。 |
| S02 | 差不多：X更能解释庄严行动里为什么始终夹着私人牵挂和不安，Y则更直接解释了挺直、自我控制、反复说服自己和不甘退下，两版各抓住珠子的一半。 | h21k：X用“先做—得到力量—没顾上另一边—逼自己别退”就形成完整弧线，Y在坚持、要求、装作没事、守住看重之事之间有些重复铺陈。 | 新版：Y的“别等别人安慰”“不肯放低对自己的要求”“装作没事”比X的“能做的事”“另一份牵挂”“投入白费”更像现实中的自述。 |
| S03 | h21k：X把短暂轻松、对亲近生活的想念、愤怒以及“我刚才究竟是真信还是硬撑”的自问都放在前一段真实经历之后，因此更能解释这一段为何忽然侧身、变软又重新混乱。 | h21k：X三条已经把休息、牵挂和自我怀疑接起来，Y额外设置“只要不退让缺憾就伤不了自己”等心理命题，环节更绕。 | h21k：“如今亲近人也得防备”“想自在地跟人亲近”“认真做过一回所以敢歇一歇”都比Y的“缺憾伤不了自己”“光靠坚持解决一切”更接近日常心里话。 |
| S04 | 新版：Y先用“已经不再把怀念当软弱”解释为什么旧日亲近会突然鲜活而温暖，再用现实仍缺那份安心、时间又不停下来解释108小节后的紧绷和盘旋，整段转折与珠子更贴合。 | h21k：Y前三条都在扩写旧日亲近和被爱，略有重复；X只保留“旧生活是真的好、行动也确实帮过自己”这一矛盾，再直接进入停不下来的原因。 | 新版：“想起从前的亲近、理解”“不用证明自己值得被爱、值得留下”比X的“那种生活”“做得不够”更具体。 |
| S05 | h21k：X清楚交代了“不能承认失望—继续逼自己—逼得太苦—不再靠坚持证明—终于承认真正舍不得什么”的变化，因此柔和、仍有推进、最后因疲惫而松开的几个侧面都有前因。 | h21k：X三步就完成从硬撑到疲惫再到承认眷恋的转折，Y又加入责怪自己、重新被接纳、压下回忆、温和考虑两边等多个环节，显得稍碎。 | 差不多：X的“怕承认失望就等于变心”和Y的“再怎么坚持也找不回来”“不想以后都独自撑着”都很像真实人的说法，只是各自落点不同。 |
| S06 | h21k：X最能解释这一段为何像进入与现实隔开的安静空间：他暂时不再要求愿望有用、不急着证明或解决什么，只允许喜欢、依恋和旧日生活本身被好好看着。 | 差不多：X较长但每条分别承担允许、展开愿景、生活方式和接受不可追回的限制，Y更短却增加了“旧日亲近如何塑造勇气和善待别人”的概念性推导，两边都没有明显压倒性的简洁优势。 | h21k：“可以亲近、相信别人，不用防着受伤”“不逼自己立刻过上那种生活”“只想好好爱惜它”比Y的“照那时的心意认真生活”“肯定自己”更有生活质感。 |
| S07 | h21k：X不只写梦醒后的心酸，而是说明为什么这次惊醒会立刻变成紧张：怀念保护不了正在受损的东西，可重新用力又可能把所珍惜的温柔耗掉。 | h21k：X的三条围绕“怀念不够—行动也有代价—因此仍不敢投入”是一条紧凑的两难链，Y第三条把宽厚、勇气、坚持一起拿来稳住自己，概念较多却没有真正推进冲突。 | h21k：“从前跟人说话不用防备的日常”“怕一投入就只顾用力，连温柔也耗掉”比Y的“旧日留下的宽厚、勇气和如今的坚持”更像具体生活经验。 |
| S08 | h21k：X把它写成问题暂时退到一边、他只想在刚恢复的亲近感里多停一会儿，并明确写到感觉正在消退，正好解释了短暂回望和喘息而非重新解决问题。 | h21k：X两条就完成“回来—正在退开—仍不催自己放下”，Y三条反复说明安宁没有使现实恢复、难处没有解决，重复较明显。 | h21k：“只想在这份感觉里多留一会儿”“还是守着这份喜欢”比Y的“既珍惜从前的好，也肯定自己的坚持”更像当下真实心情。 |
| S09 | h21k：X直接把开头的茫然重新召回，同时让这次回返带上已经获得的新认识：他现在知道迟疑里不只有害怕，还有对那种亲近生活的真舍不得。 | h21k：两版都只有两条，但X第二条让重复出现的问题发生了改写，Y只是“舍不得安宁—缺憾仍得面对”，推进更少。 | h21k：“不知道怎么往前走才不会丢掉珍爱的东西”“这回明白自己是真舍不得”比Y的“往后的缺憾还是得自己面对”更具体也更个人。 |
| S10 | h21k：X把零碎、悬空和疲惫解释成前面用力过头后暂时无力再争取，同时又舍不得行动带来的畅快和亲近带来的安宁，所以此刻既不能推进也不愿把任一边扔掉。 | h21k：X三条各自说明疲惫来源、现实限制和休息的合法性，Y先决定坚持、再重复愿望不能满足和骄傲不足，最后又写疲惫，绕了一圈。 | h21k：“之前用力太狠，他提不起劲再争取了”“歇一歇不算放弃”比Y的“决定还肯不肯坚持对自己的要求”更像人在累极时会说的话。 |
| S11 | h21k：X把“害怕仍在但脚开始往前走”建立在已经验证过的两件事上：行动能给力量却会遗漏牵挂，单靠内心安宁又护不住现实，因此重新承担不是突然振作，而是权衡后的选择。 | h21k：X的三条围绕过去证据、重新掂量承受力和最终选择逐步推进，Y的“悲愤—两头放不下—不能为接纳让步”把冲突改成道德二选一，反而多出一个此前并未充分建立的假设。 | 差不多：X的“怕争取时伤了那份温柔、重新掂量能承担什么”和Y的“既不委屈自己，又想有亲近的人依靠”都很像真实困境，只是Y后面的“辜负坦然和勇气”稍显总结化。 |
| S12 | h21k：X直接把雷鸣般的回归写成“还怕、还舍不得，却不等完全不怕就先做”，同时保留249–253那一下重新犹豫，因此昂扬、主动选择和短暂失衡都有清楚来由。 | h21k：X三条分别承担决定、力量恢复和仍有风险，Y四条多次重复“不再压怀念、仍会难过、仍坚持、仍不否定自己”，信息更散。 | h21k：“不等完全不怕了，就先做眼下能做的事”“不再强求每次尽力都管用”比Y的“看重的事仍值得认真守下去”更像人在实际行动前后的想法。 |
| S13 | h21k：X既解释了柔软歌唱为什么能被带进宏大行动——他终于知道自己争取的正是那种能真心亲近的生活——也解释了高潮后为何可以歇下、空落并仍保留一点盼头，覆盖了整段从喷涌到收束的弧线。 | h21k：X四条分别对应重新出力、力量高涨、主动节制和高潮后的回落，Y四条几乎都再次围绕“从前、怀念、坚持、勇气”重述已经建立的整合，重复更多。 | h21k：“做一阵也肯歇下，免得把真心待人的温柔耗光”“歇下时忽然感到那种生活还没回来”比Y的“仍愿意善待别人”“认真过以后的日子”更具体、更像一个人的实际经验。 |
