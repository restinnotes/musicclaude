# 文章E

# 船靠岸以前
*肖邦《船歌》Op. 60*

**1–3小节**

头顶的烟花忽然炸开，第一声落在胸口，第二声把水面照得发白。你坐在我身边，外套内袋露出一角明早的车票。我把那句话默念了一路——“我想请你……”嘴唇刚动，光点已经从天上散下来，落在你眼睛里，一颗一颗摇晃。我伸手去碰船沿，指尖凉得像刚从水里捞出来。

**4–16小节**

船身随着水纹轻轻起伏，你的肩膀贴着我的肩膀。我们说起桥边那家关门的咖啡馆，说起你把薄荷糖塞进我掌心的那天；两条话音挨得很近，偶尔同时开口，又都笑着让对方先说。我把“留下来”换成“下次还来吗”，你答“当然”，手指替我抚平袖口的一道皱褶。旋律抬高一点，随即轻下来。你把头靠过来，发梢擦着我的脸，船底仍托着我们，岸边的灯却一盏盏向后退。

**17–23小节**

你的声音慢慢退远，桨叶搅开的水声留在脚边。我们暂时都没说话，我听见自己指甲刮过船沿，轻轻两下；第三下刚要落下，你忽然叫了我的名字，声音短得像碰了一下玻璃，随即又望向河心。水里的灯影被暗流拖成长条，断开后又勉强拼回去。我张了张嘴，舌尖抵住上齿。你没有催我，只把手从膝上挪到身侧，指尖悬在离我很近的地方。

**24–34小节**

你提起第一次见面那场雨，我接着说那把伞骨断了一根，说你走到街角才发现半边肩膀湿透。说到这里，我又补上一句：那天我在街对面站了很久，手里攥着买给你的热栗子，等到纸袋都凉了才敢走过去。你笑起来，眼睛被桥灯照亮；我也笑，声音却在最后一个字上抖了一下。我想把那天剩下的事全说出来，连你当时没有看见的、我转身后又回头的那几次，也一并说给你听。高处的音一粒粒颤着，亮得人几乎不敢直视，你的手还在我旁边，隔着一寸水气似的距离。船慢慢放缓，我的手指在船沿上蜷了起来。

**35–39小节**

摇晃忽然撤掉，船仿佛从水面上被提起来，只剩一条细长的声音悬在黑暗里。你把手从船沿收回，指背沾着的水珠滑进袖口；我仍把手弯着，掌心留着刚才那一点温度。

“我想请你——”

我终于开口。你转过脸，等我说完。桥洞深处落下一滴水，打在两人之间。我吸进一口气，后半句话还卡在喉咙里。你没有移开眼睛，我却先低下了头，拇指在自己的掌心里反复摩挲。

**40–50小节**

出了桥洞，水面薄得像一层月光，摇摆又回来，细细碎碎。你问我还记不记得第一次坐船时晕得脸色发白，我说记得；你从口袋里摸出一颗薄荷糖，像那次一样放进我掌心，糖纸硌着纹路，凉意一下醒过来。我们说起那年夏天，说起你在站台上等错了方向，说起一场没下成的雨。你的声音清清的，我一边听一边把糖纸慢慢折小，拇指沿着折痕来回压。你偶尔停下来，等我接话，我便把那些已经讲过的细节再讲一遍。你口袋里那张车票隔着布料抵着我的膝盖，我没有挪开。

**51–61小节**

你的掌心覆上来，我把薄荷糖和皱纸一并攥住，糖在手心里渐渐软了。低音一下一下顶着船底，水下的暗流把船头推偏，又很快拉回来。你叫我的名字，这回没有望向河心；你的嘴唇擦过我的耳廓，呼吸带着薄荷的凉。我反手扣住你的手，力气重得你指节缩了一下，你却把手指一根根嵌进我的指缝。河岸和灯火加快往后退，我的膝盖抵着你的膝盖，连那张隔在布料之间的车票也被挤得折起了边。

**62–71小节**

你忽然把刚才那句“当然”拖长了说，像故意把最后一个音留给我。我笑着去捂你的嘴，你躲开，又把我的手拉回去贴在自己胸前。船边溅起的水打湿了袖口，我们互相替对方擦，指尖追着指尖，像一场不肯结束的小把戏。你的胸口随着笑声轻轻震动，我也跟着笑，直到眼角发酸，才发现自己一直抓着你的衣襟。

歌句越唱越开，风从河道尽头吹来，你的笑声扬到高处，忽然轻轻散掉。你看着我，终于说：“明天……”

那两个音停在唇边，后面只剩我的名字。

**72–77小节**

船忽然像停在两道灯影之间，熟悉的摇摆退开，只剩一串细颤的光落在水上。你抬眼看我，嘴角还留着没散尽的笑，拇指停在我腕骨上。我的脸一点点靠近，你的呼吸轻轻碰到我的上唇；谁都没有再往前，水从船侧滑过去，带走一条灯影。你的手仍压着我的脉搏，脉搏在指腹下跳得太清楚。我想起你刚才那个没说完的词，嘴唇动了一下，最后只是把额头抵上你的额头。

**78–83小节**

我把咬紧的牙关松开，长长吐出一口气，才发觉眼角有一滴水沿着脸侧滑到嘴边。高处的琶音像一阵细雨从我们头顶落下来，肩膀忽然轻了。你把额头靠在我肩上，我的手从你腕骨移到掌心，摊开；你在掌心里轻轻蜷了一下手指。我没有把那只手合拢，只让它安安静静地躺在那里。船身重新摇晃，风从领口灌进来，你的呼吸慢慢落到我的颈侧。

**84–92小节**

开头那两下和弦再次撞过来，船底的水波一下翻成跨越整条河的浪。我抬起头，把桥洞里没说完的话接下去：

“我爱你。我想请你留下来。”

声音出去以后，我没拿笑声把它盖住，也没急着替这句话添上别的解释。你攥紧我的袖口，布料在指间皱成一道深痕；你的眼睛里闪着桥灯，像第一次见面那场雨里没说出口的东西终于抬起了头。我伸手覆住你的手背，指腹碰到你微微发凉的指节。高处的声音颤动着悬住，你的嘴唇动了动，呼吸先落在我脸上。

**93–102小节**

你终于把我拉近，额头抵住额头，吻落下来时，河面上的灯火像一齐往外涨。刚才只够贴在耳边的歌忽然铺满夜色，船身被宽阔的水波托高；我笑了一声，随即把脸埋进你肩窝，闻见雨后衣料和薄荷糖的气味。你抱得很紧，指尖却在我背上一次次换位置，像找不到能安稳停住的地方。我抬手摸你的后颈，掌心贴着温热的皮肤，听见你在我耳边喊我的名字，一遍，又一遍。

乐句一遍遍向上伸展，迟迟不肯落下。我的手沿着你的外套滑过去，碰到内袋里那张车票，硬纸边沿隔着布料划过指节。你抱着我的手忽然停了一瞬，随后又收紧，额头抵着我的额头，眼睛始终没有闭上。

**103–110小节**

我把手从车票边缘移开，指节留下一道浅浅的压痕。你也低头看了一眼口袋，拇指隔着布料反复磨那道折线；抱着我的手往下滑了一寸，又重新扣紧。你像要说“我会……”嘴唇才动，船底的低音便一下一下踩过来。

我们还贴在一起，灯火却沿着河岸一盏盏掠过。你把额头抵在我肩上，长长地呼气，呼出的热意很快散在夜风里。我摸着你后背被自己攥出的褶皱，一点点将它抚平；你也伸手来抚我的袖口，那道旧皱褶仍在原处。上方的旋律继续向前冲，几声暗沉的音从里面落下来。你低头吻了吻我的手背，拇指沿着指骨慢慢移动，最后停在无名指根部。

**111–116小节**

最后一阵浪头猛地抬起船首，水花落在你袖口，也溅到我手背。你把车票折回内袋，替我拢好被风吹开的衣领，手指在领口停了短短一瞬，随后滑进我的掌心。低处传来一声温厚的回唱，细碎的琶音像水花飞上夜空；你抬头看了一眼河岸，嘴唇轻轻抿着，另一只手仍攥着我的袖口。

船夫收桨，船身慢慢贴近石阶。最后几下和弦沉沉落下，像铁锚入水。你仍握着我的手，口袋里的纸张轻轻响了一声。我用拇指压住你的指节，你也回握了一下。船身停稳时，你的手心还是温热的。
