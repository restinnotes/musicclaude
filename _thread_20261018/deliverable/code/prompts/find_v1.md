## 我们要找的东西

Thread 是这首音乐里**一件持续发生、不断积累、会让后面的音乐获得不同意义的人类事情或关系**。

它让人明白：从前面到现在，是哪一件事还在发生；后面某个时刻之所以有现在这样的分量，是因为前面已经经历过的东西仍然活在这里。

它不是：
- 一份心理成长账本（某某已经被承认、某某已经成立、某某因此改变）；
- 一个哲学主题或一句总结；
- 一条 A 导致 B、B 导致 C 的因果链；
- 把彼此不同的体验都收进同一套情绪走向（例如幸福、失去、接受）。

可以有不止一个方向。它可以停留、回返，或者在某些段落根本不更新；有的段落可以独立存在，不被线吞掉。不要预设只有一个中心。如果你认为有一个贯穿全曲的核心关系，把它写成一句有主语、有谓语的最小关系判断：什么和什么、它们怎样相关，并且这句话从较早处到结尾都成立、不包含后来才得到的结果。不要默认这段关系是冲突、牵制或两极对立；谓语是什么只能由材料决定。

## 时间纪律

研究时你可以看完整首作品。但凡是说"走到某个时刻，这一刻成了什么"，只能依靠那一刻以前已经发生的音乐和经验：假设后面的音乐完全不可见，这层意义也应当成立。不要用后来才出现的东西冒充当时已经成立的认识。

## 请交付

写给一位懂音乐、想真正听懂这首曲子的人。用普通中文，不要发明术语。

1. **候选 Thread（一到三条）**。每条：
   - 用一两句人话说清：持续发生的到底是什么人类事情或关系；如果有核心关系句，写出来。
   - 它怎样在作品里走：只挑真正重要的几个时刻（不必每段都有），每个时刻写清——此刻听到的具体音乐事件（注明小节）；此前哪些东西仍然活着；所以此刻成了什么、和它单独出现时有什么不同。也写出它停留、回返或不更新的地方。
   - 它解释不了、或者不应该被它吞掉的体验（注明段落或小节），以及为什么让它们保持独立。
   - 它最容易被误写成的套路说法，以及这首曲子的哪些具体音乐事件让它和那个套路不同。
2. **你对这些候选的比较**：哪一条最能让人从头到尾看到同一件事在不断换状态，哪一条最贴近这首曲子独有的音乐事实，各自的弱点是什么。
