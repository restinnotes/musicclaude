### 第12段　第 93–102 小节
- 【主体验】（93–102；超出个人的感受在原稿中明确对应94–102）第62–71小节那支异常温柔、晴朗的歌，在这里被放到了最大尺度：声音明亮、开阔，近乎英雄式，内声部却彼此拉扯，音乐一浪高过一浪。前面做梦、走神般的状态忽然聚焦到“此时此地”，内心的私语仿佛放大成天地的共振。倒不是“我的感情终于变得比一切都伟大”，反而像整个人被卷进一个比自己更大的世界，连“我”都暂时退到了后面。
- 【侧面】（93–102；久别重逢的类比来自覆盖94–104的原稿，不能进一步细定位）这份狂喜像高烧。它也可以像久别重逢：刚才还能够微笑、寒暄，忽然却抱紧对方，久久不愿松手；又可以是喉咙发紧、眼眶湿润，快乐到连自己想笑还是想哭都分不清。
- 【段内变化】（93–102；尤其96–100附近，释放发生于102–103交界）这股声浪却不是一路畅通地冲到顶。原本温柔的歌带上近乎恳求的力量，旋律一次次向上伸展，仿佛还想要更多，却始终不能完全满足。到第96–100小节附近，乐句末端仍有牵扯、延迟与紧张，那口悬着的气一直带到102–103小节交界，才得到一次重大的释放。

# 各条路

## 路A
第1段（1–3）［没在想］
  心里浮起一种空缺感，让他隐约觉得自己在等着什么，却说不清究竟是什么。
第2段（4–16）［正在面对］
  亲近让无名的等待有了方向：他盼自己的心意也能得到回应，欢喜里因此带着一点酸涩。
      ← 改写：（1–3）「不明的空缺」　——S01-1的等待原本没有对象；亲近让它首次指向心意能否得到回应。
第3段（17–23）［没在想］
  亲近已带来真实欢喜，此刻他沉浸于靠近本身，心情暂时松弛下来。
      ← 提供理由：（4–16）「等待指向回应」　——S02-1中的亲近已经带来欢喜，这份实际感受让他此刻能安住于亲近本身。
第4段（24–34）［没在想］
  亲近带来的欢喜已如此真切，他开始舍不得这一刻过去，温柔里生出急切。
      ← 提供理由：（17–23）「沉浸于亲近」　——先前的亲近已给他真实而具体的欢喜；正因为确实享受到了这份满足，他开始留恋眼前的亲近。
第5段（35–39）［正在面对］
  他开始疑惑，自己如此在意的亲近，是否也同样被对方珍惜。
      ← 提供理由：（24–34）「舍不得当下」　——留恋让这段亲近变得切身，他在意的由能否留住此刻，转到心意是否相互。
      ← 唤起：（4–16）「等待指向回应」　——先前对心意得到回应的盼望重新浮现，但这次他已经尝过真实的亲近，更在意对方是否同样珍惜。
第6段（40–50）［没在想］
  亲近带来的欢悦变得浓烈而直接，他更深地投入其中，心底仍有一点不安。
      ← 提供理由：（24–34）「舍不得当下」　——他已舍不得眼前的亲近，这份留恋在此处表现为想更充分地体验亲近本身。
      ← 限制：（35–39）「心意是否相互」　——他仍在意对方是否珍惜，所以投入虽浓烈，快意里仍留着一丝不安。
第7段（51–61）［没在想］
  亲近让他真切感到自己鲜活，满足本身成了吸引力，他想继续深入体验。
      ← 提供理由：（40–50）「投入的浓烈快意」　——前一段的投入已经带来切身而强烈的欢悦，这份真实经验使他此刻受到感受本身的吸引，生出继续深入的冲动。
第8段（62–71）［没在想］
  他从投入中尝到随兴的乐趣，亲近本身便足以使他尽兴。
      ← 改写：（51–61）「追随感受本身」　——前段让亲近体验本身成为吸引力，这一段则把继续深入的冲动展开为随兴享受其中的乐趣。
  → 欢喜还在心里，他已开始留恋这份让自己尽兴的亲近。
第9段（72–77）［正在面对］
  尽兴之后，他开始在意这份亲近在对方心里是否也有同样分量。
      ← 提供理由：（62–71）「尽兴后的留恋」　——他已经开始留恋这份让自己尽兴的亲近，所以在意的焦点转向这份亲近在对方心里的分量。
      ← 唤起：（35–39）「心意是否相互」　——先前对是否被同样珍惜的疑问，在更深的尽兴和留恋之后重新变得切身；这次牵动他的是已经亲身体验的具体亲近。
第10段（78–83）［没在想］
  他被自己对这份亲近的深切在意触动，柔情里透出易受伤的脆弱。
      ← 唤起：（72–77）「在意是否相互」　——他已开始在意这份亲近在对方心里的分量，这份牵挂使自己的感情变得切身，也唤出柔软的脆弱。
第11段（84–92）［没在想］
  亲近的欢喜浓烈得近乎疼痛，他感到自己对这份感情的深切在意已无遮掩地暴露出来。
      ← 改写：（78–83）「柔情中的脆弱」　——前段的深切在意已使他感到柔软脆弱；熟悉的亲近再次出现时，这份脆弱不再只是温柔的感动，而在强烈的投入中变成近乎疼痛的暴露感。
第12段（93–102）［没在想］
  他在亲近中尝到超出个人计较的满足，连自己的得失也显得轻了。
      ← 改写：（84–92）「欢喜中的脆弱」　——前段的深切在意已让亲近成为近乎疼痛的体验；此处同一份投入带来超出自我衡量的满足。

第10段（78–83）［没在想］

      ← 提供理由：（72–77）「美好大过愿望」　——喜欢本身已成为值得沉浸的美好，这份内在满足使他从欣赏心意转向自然流露情绪。
第11段（84–92）［没在想］

      ← 提供理由：（78–83）「喜欢带来自在」　——上一刻喜欢本身带来的满足已使收着的情绪自然流露，这次热烈的展开便能成为他坦然承认自身心意的幸福。
第12段（93–102）［没在想］
  坦然承认热切之后，这份欢喜不再只是关于他自己的心意，而使他一时忘我。
      ← 提供理由：（84–92）「坦然承认热切」　——上一刻他已把热切本身当作幸福；这份承认让欢喜不止是对自己心意的确认，而成为他整个人都能沉浸其中的体验。

      ← 提供理由：（51–61）「快意成动力」　——前段的感官快意已推着他继续寻求；此刻这股动力落在眼前的亲近上，让他全心享受当下。
第9段（72–77）［正在面对］

      ← 限制：（62–71）「自在尽兴」　——尽兴只能说明他自己的欢喜真实，不能替他确认对方是否同样珍惜这份亲近。
      ← 唤起：（4–16）「等待指向回应」　——先前对心意得到回应的盼望，在亲近已经带来真实欢喜后再次浮现，具体变成对这份亲近是否相互的在意。
  → 这份在意压住了追逐的热切，渴望仍强，却一时变得迟疑。
第10段（78–83）［没在想］
  回应上的迟疑让他心里绷紧，此刻柔软与脆弱自然浮现。
      ← 提供理由：（72–77）「热切收敛」　——上一段的在意压住了追逐的热切，使他心里承受着紧绷；此刻的柔软因此像是受压的感受终于获得了舒展。
第11段（84–92）［没在想］
  熟悉的亲近重新带着重量，喜悦里也透出刺痛。
      ← 提供理由：（62–71）「自在尽兴」　——他曾尽兴地体验过亲近的满足，因此这次重现有真实的幸福感作底。
      ← 限制：（72–77）「回应之疑」　——他在尽兴后已在意对方是否同样珍惜，这份不确定让重现的欢喜带上刺痛。
第12段（93–102）［正在面对］
  他盼对方也把这份亲近放在心上，回应未明使这份期待格外沉重。
      ← 改写：（72–77）「回应之疑」　——此前他在意对方是否同样珍惜；到这里，这份在意转成了迫切盼望对方也珍重这份亲近的心情。
      ← 提供理由：（84–92）「欢喜带刺」　——熟悉的亲近已经让喜悦带上刺痛，回应是否相互因此成为这份期待沉重的原因。
