# Op.61｜关系图

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### 1–23　（还说不清）

- 起初他不知道自己究竟在等什么。
- 他不肯任由一些事情就此算了。
- 他仿佛觉得听任下去就是默认那些事理所当然。
- 他又怕真投入会丢下什么。
- 他想找个足以让自己不再犹豫的理由。
- 他刚觉得有把握，另一番舍不得又浮上来。
- 他有时几乎相信自己已想通，过一会儿又觉得确信陌生。
- 他渐渐为自己的摇摆感到难堪。
- 他怀疑自己是否非得先理清心事才肯向前。

### 24–65　（还说不清）

  - ← 提供理由：（1–23）「就此算了」
- 他仍没有保证，心里的牵挂也没消失。
- 不再只是等待，他真切感到自己有力量。
- 他至少愿意尽力。
- 他为自己能带着疑虑行动而骄傲。
  - ← 改写：（1–23）「摇摆」
- 他投入得十分热切。
- 付出的过程本身让他快乐。
- 他觉得积压的不满好像终于有了去处。
- 他愿意给出更多，甚至有点贪恋倾尽全力的畅快。
- 他不愿再因一点软弱停下来审视自己。
- 他偶尔触到心里一处没跟着昂扬的地方。
- 他隐约知道自己还有牵挂没得到照顾。　✦ 办法的限度
- ⟲ 仍在起作用：（1–23）「丢下什么」；（1–23）「舍不得」

### 148–180　（没在想）

- 他发现自己盼望的生活远不止免于辛苦。　✦ 分清

  - ← 改写：（1–23）「丢下什么」

- 他曾自然地相信这样的生活可能存在。

  - ← 提供理由：（116–147）「行动以外」
- 他暂时不问这份爱惜是否尽责、是否有用。
  - ← 提供理由：（116–147）「证明自己」
  - ← 提供理由：（116–147）「放下」
- 他不急着问这种生活能否得到，也不与眼前的坚持比较。

- 他暂时不想离开这份安宁。
