**1–3**

**越想靠近一个人又怕丢掉自己，就越难说清自己究竟想要什么。**

**4–16**

**真正让人敢靠近的，不是保证永不分开，而是靠近时不必丢掉自己。**
← 因为既渴望回应又害怕失去自我，才开始发现亲密与自由未必冲突。
→ 于是愿意相信彼此能够回应，却还不敢把眼前的幸福当成永远。

**17–23**

**越珍惜一段关系，越会追问它能走多远，而不只满足于当下有多甜。**
← 因为亲密带来了真实的快乐，却无法保证长久，幸福才引出了疑问。
→ 于是开始检验这份信任，却不愿因此否定过去的幸福。

**24–34**

**怀疑一段关系，不等于否认它；看清它的局限，反而更能珍惜它。**
← 因为反复追问后，仍确认曾经的亲近真实存在，即使不能永远维持也不等于虚假。
→ 于是珍惜亲密，却不再要求它满足所有需要，开始追问自己还想要什么。

**35–39**

**有了安稳，人才能腾出心力，看见自己还想成为谁。**
← 因为亲密带来的满足不再占据全部注意力，其他未被照顾的愿望才浮现出来。
→ 于是开始认真追求成长，不愿为了守住已有的幸福而停止探索。

**40–50**

**越想成为更好的自己，越会担心改变也会动摇让自己安心的关系。**
← 因为主动追求成长后，问题不再只是有没有被爱，还包括改变会付出什么代价。
→ 于是既期待未来，又害怕失去现在，开始面对亲密与自由之间的冲突。

**51–61**

**越认真想要成长，越会发现难题不是选哪一边，而是怎样不牺牲另一边。**
← 因为成长确实带来充实，却不能自动解决亲密与自由的矛盾。
→ 于是拒绝在被爱与做自己之间二选一，开始寻找兼顾两者的办法。

**62–71**

**如果每次得到都只盯着还缺什么，再多幸福也会变成不够。**
← 因为总把已有的满足当作下一步的起点，就永远看不见它本身的价值。
→ 于是尝试享受已经拥有的，却仍分不清自己确实有所欠缺，还是根本不习惯满足。

**72–77**

**真正难的不是没有幸福，而是几种真实的幸福为何总像要互相让位。**
← 因为亲密、成长和享受当下都能带来满足，却没有自然地融为一体。
→ 于是不再只问下一步该去哪，而开始寻找让不同需要共存的生活方式。

**78–83**

**知道不能二选一，不等于已经知道怎么两全。**
← 因为亲密与成长各有价值和局限，想通道理并不能自动消除现实冲突。
→ 于是接受暂时没有答案，不再靠贬低某种需要换取轻松，也不让分析代替生活。

**84–92**

**一段关系真正经得起考验，不是你不再改变，而是改变后仍能容得下你。**
← 因为已经知道亲密有局限、成长也有价值，才开始追问改变后的自己能否仍被关系接纳。
→ 于是不再假装问题不存在，重新审视曾经深信不疑的亲密。

**93–102**

**做自己未必会远离别人，靠近别人也未必得缩小自己。**
← 因为亲密让人不必独自承担一切，成长又提醒人不能为了被接纳而放弃自己。
→ 于是开始把两种满足带进同一种生活，不再每次都逼自己站队。

**103–110**

**一次和谐不代表矛盾永远消失，旧的不安也不代表以前的努力白费。**
← 因为两种需要曾经同时得到满足，并不保证以后不再发生冲突。
→ 于是重新分清哪些需要已经得到回应、哪些愿望仍不能放弃，不再靠更强烈的幸福证明自己选对了。

**111–116**

**真正的平静，不是找到一个万能答案，而是不再要求一种满足替所有需要作主。**
← 因为亲密有限不代表虚假，成长令人不安不代表错误，已有的满足也不会抹去未实现的愿望。
→ 于是既能珍惜已经得到的，也能追求尚未实现的；可以停下，也可以继续，不必逼所有需要归于同一个答案。
