你负责一次写出一首器乐作品最终使用的 Thread（线），供读者在逐段听感记录旁边顺序阅读。线写的是同一个人经历的同一件事；只读线也应清楚、连贯、有发展，每段又能自然接上相应的体验性质。它不是音乐解说，也不把珠子的比喻写成真实情节。

【段落】
{SECTIONS}

【Center（已给定，不修改）】
{CENTER}
Center是读者回头看时组织整件事的中心，不是人物从开头就知道的答案，也不是每段要重述的主题。

【已通过宏观评审的路线候选】
{ROUTES}

【珠子的体验性质 TARGETS】
{TARGETS}
你看不到原始珠子，不推测它们的原话、画面、动作或声音细节。

【第一步：选择可持续展开的一条路线】
从ROUTES只选一个base_route，不拼接，不改Center。优先选择人物的处境可以在不同阶段给他留下不同的余地、牵挂或无法确定之处的路线；不是选择可能结果最多、情感最极端或决定最频繁的一条。输入已经确定的事实仍是边界，未知事实不因为人物期望而成真。

【第二步：在内部建立“此刻还可能怎样”的地形】
整篇写作前，把同一件事放到人物当时感到的可能性之中：哪些东西眼下确实拥有或正在失去，哪些还盼得上却拿不准，哪些代价已经得承受，哪些事不是靠自己愿意就能定下。这里只记人物所处的现实余地与不确定性，不画情绪曲线、不逐段寻找新结论，也不把它简化为两种选择的对抗；不需要固定类别都出现。

随着段落向前，让人物在这片可能性里生活：有时正被一种希望占满，有时感到某个余地正在缩小，有时接受已经发生的事，有时只是留在尚无答案的日子里。即使外界没有新的事实，这些可能性对他当下的分量也会因他此前确实经历过的感受而不同；但单凭想得更厉害不能证明现实改变。让已经作出的选择继续有效，片刻的好受并不注销尚存的难处。中心不必变成关于“控制未来”或“选择正确”的议论；人物也不必每段都计算得失。

【第三步：把可能性写成正在经历的事】
写出来的是人物当时的盼望、难受、放松、舍不得或承受，而不是“他的可能性空间扩张了”之类的模型报告；不要为保持地形变化而编造新行动。TARGETS在写作全过程参与决定本段需要的体验性质和力度，但不能替人物确认一项结果；同段的复杂体验可以并存，不必用一次实际选择解开。后面若显得更加坚定，应来自前面他真正已经走过的部分；后面若仍犹疑，也无需伪装为把同一个问题又重新发现了一遍。

【共同写作边界】
沿给定段落顺序一次写出全篇，不逐段分别调用或事后加一层补珠子、压缩、润色。每段2–4条，每条一句完整、自然的话，只承担一件有用的事；事情少就用两句短句，不靠多重心理步骤凑长度。条目连读是一个人真正经历的一件事，允许余波、持续、暂时沉浸、失望或未解，不要求每段突破，也不强迫结尾解决。人物的进展来自已呈现的自身经历，不增编事件、前史、道具、地点、对白、他人的新举动或隐秘意图；不把想象当事实，不让音乐的强弱、停顿、上行下行机械决定人物反应。要写得让普通人一读就知道他在乎什么、难在哪里；自然语言，不套用心理分析、格言、对称归纳，也不机械禁用某些词。

【第四步：按最终正文标注】
正文定稿后填写元数据，不用元数据倒造故事。cite仅引用本条真正提及或作为前因依赖的更早item ID，允许本段前面条目，单纯主题相同不算。covers只列该条实际接得上的本段bead_id，一条可以对应多颗，不为补覆盖改写人物事实；不能覆盖且强行覆盖必须新增外部事实的，才写入uncovered_targets并解释原因，否则为空数组。relation从正文在“没在想/还说不清/正在面对”中选择；仍挂念或回味Center不能标“没在想”。delta_type从六种固定类型中选择，情绪加强不等于新变化；delta没有实质新增留空。established只记正文中首次真正成立的重要状态、认识、意愿或选择，first_established精确指向对应条目。

【输出】
仅输出合法JSON，不输出解释、检查过程、Markdown或多余字段，接口固定：
{
  "base_route": "route_id",
  "segments": [
    {
      "sec": "S01",
      "relation": "没在想/还说不清/正在面对",
      "items": [
        {"id": "S01-1", "text": "...", "cite": [], "covers": ["bead_id"]}
      ],
      "delta_type": "新变化/后果/实行已有想法/延续/回到旧处但有新增/暂时没在想",
      "delta": "本段真正新增的心理事实；没有则为空字符串"
    }
  ],
  "uncovered_targets": [
    {"bead_id": "...", "reason": "若强行覆盖就必须虚构外部事实的原因"}
  ],
  "established": [
    {"claim": "首次成立的重要认识或状态", "first_established": "Sxx-x"}
  ]
}
segments按输入段落顺序完整填列，示例仅说明字段形状，不增加字段。
