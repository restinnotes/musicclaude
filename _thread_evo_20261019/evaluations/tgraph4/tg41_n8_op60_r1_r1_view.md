# Op.60｜关系图

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3　（还说不清）

- 他还说不清自己究竟盼什么，只知道心里有一个格外想亲近的人。
- 想到对方，他便不由自主地柔软，想让这份感觉多停留一会儿。
- 明明没有事需要他立刻决定，他却本能地收住喜欢，不明白自己为何这样谨慎。
- 那点喜欢似乎随时都能放下，他却偏偏舍不得放下。

### 4–16　（正在面对）

- 因为还不知道自己怕什么，他决定先不替这份喜欢安排去向。
  - ← 提供理由：（1–3）「本能地收住」
- 他允许自己亲近对方，暂时不问两人会怎样，也不急着向对方期待什么。
  - ← 唤起：（1–3）「舍不得放下」
- 他能自由地给予温柔，无须时时确认对方是否领受，反而觉得亲近很自在。　✦ 分清
  - ← 唤起：（1–3）「多停留」
- 他渐渐不再提防自己的喜欢，甚至为能够如此宽和而有些满意。
- 当时他觉得，若亲近能一直自然发生，不必追问计较，这样已经足够。

### 17–23　（正在面对）

- 尝到这份亲近的幸福后，他开始希望喜欢能持续下去，不只属于眼前。　✦ 满足照出未满足
  - ← 唤起：（4–16）「已经足够」
- 一想到长久，他就意识到自己能决定怎样珍惜，却不能决定对方会不会同样珍惜。　✦ 分清
- 他偶尔忍不住想，自己在对方心里是否也有特别的位置，却还没打算索取什么。
  - ← 改写：（4–16）「暂时不问」
- 这点期待原本不强烈，却已使他不如先前安稳，他对此有些意外。
  - ← 改写：（4–16）「自由地给予」

### 24–34　（正在面对）

- 他怕新添的紧张损坏先前的快乐，也不愿让没作过承诺的对方感到催促。
  - ← 唤起：（17–23）「不如先前安稳」
- 他试着放宽心，觉得关心、给予和为对方高兴本来就有快乐，不必索取保证。
  - ← 提供理由：（17–23）「不能决定」
- 这样想让他确实轻松起来，想确认的紧张退去，反而更愿意付出。
- 他不再衡量给出去多少，也不怕多给一点会显得自己更在乎。
- 毫不勉强的热切让他幸福，仿佛谨慎珍藏的温柔终于可以尽情给予。
- 那一阵他甚至相信，只要不提出要求，就能尽情爱着，也不会失去什么。
  - ← 改写：（4–16）「已经足够」
- ⟲ 仍在起作用：（4–16）「自由地给予」

### 35–39　（正在面对）

- 等这阵欢喜平息一点，他仍想知道，自己是否也被对方那样放在心上。　✦ 办法的限度
  - ← 限制：（24–34）「不会失去什么」
- 他因又盼望被看见而难堪，怀疑自己的体贴里是否一直藏着期待。
  - ← 唤起：（24–34）「不会失去什么」
- 他觉得说自己毫无所求似乎不够诚实，但先前的快乐确实没有用来换回应。　✦ 分清
  - ← 说明：（24–34）「尽情给予」
- 这个疑问他一时答不上来，只愿留着不自在，不替自己辩解，也不靠热烈遮掩。
- ⟲ 仍在起作用：（17–23）「特别的位置」

### 40–50　（没在想）

- 难堪没减轻喜欢，却让他不愿再靠自己的慷慨来证明什么。　✦ 办法的限度
  - ← 唤起：（35–39）「盼望被看见」
- 他不想总查对方是否在意，也不想强迫自己成为完全没有期待的人。
  - ← 提供理由：（35–39）「不够诚实」
- 他转而只留意此刻愿意给出的关切，暂时不去想两个人以后会怎样。
  - ← 改写：（24–34）「索取保证」
- 希望对方好、安静地惦念，都能让他心里生出甜意，他不再用这些衡量关系。
- 这份更隐秘的喜欢让他暂时忘了为何在意回应，只觉得细细喜欢一个人很甜。

### 51–61　（正在面对）

- 不声张的甜意留得久了，喜欢渐渐有了重量，已经不容易收放自如。　✦ 办法的限度
  - ← 改写：（40–50）「暂时忘了」
- 他更加惦念对方，也更想让关切被领会，有时无缘由便满心都是那个人。
- 他仍觉得不能催促对方，舍不得拿自己的期待换取对方的迁就。
- 为了不让对方承担，他只好独自容纳那些没有着落的盼望。　✦ 选择的代价
  - ← 限制：（40–50）「愿意给出」
- 那些细致的甜蜜仍让他珍惜这份喜欢，即使不再轻巧，他也舍不得减轻。
  - ← 提供理由：（40–50）「生出甜意」
- ⟲ 仍在起作用：（17–23）「特别的位置」；（24–34）「感到催促」

### 62–71　（正在面对）

- 心意已经这样深，他忽然不想再时时提醒自己收住喜欢。
  - ← 唤起：（51–61）「舍不得减轻」
- 他意识到先前的快乐并不依赖承诺，即使自己仍有期待，那些幸福也是真的。　✦ 分清
  - ← 说明：（4–16）「不再提防」
  - ← 说明：（24–34）「尽情给予」
  - ← 说明：（40–50）「生出甜意」
- 他不想因为怕受伤就连高兴都小心翼翼，决定尽情喜欢一次，暂不追问结果。
  - ← 改写：（51–61）「独自容纳」
- 积攒的眷恋让他坦然投入，不再计算给出多少，也不提醒自己每次热切都得收回。
  - ← 改写：（24–34）「多给一点」
- 有一阵欢喜确实盖过顾虑，他知道没有保证，却几乎感不到那份沉重。

### 72–77　（正在面对）

- 欢喜稍稍落定后，刚才那次尽情喜欢让他再难含糊自己真正想要什么。　✦ 知道更多反而更尖锐
  - ← 唤起：（62–71）「几乎感不到」
- 他想让自己的深情有所相遇，想知道对方是否也愿靠近、彼此珍惜。
  - ← 改写：（51–61）「被领会」
- 他看清愿望的分量后，也更明白自己的真心不能成为对方必须回应的理由。　✦ 分清
- 退回谨慎仿佛辜负刚承认的心意，继续盼望又怕把爱变成对对方的要求。　✦ 选择的代价
  - ← 改写：（1–3）「本能地收住」
- 他想不出能兼顾这两边的办法，感到委屈，甚至厌倦了反复为难自己。
- ⟲ 仍在起作用：（51–61）「不能催促」；（62–71）「尽情喜欢一次」；（24–34）「感到催促」；（51–61）「独自容纳」

### 78–83　（正在面对）

- 既无法减轻喜欢，也无法决定对方的心意，他终于不再逼自己立刻作选择。
  - ← 提供理由：（72–77）「反复为难」
- 想靠近时他可以暂不向前，想克制时也无需把心里的眷恋都压下去。　✦ 分清
- 他容许愿望和没把握同时留在心里，不再让两种心思互相催逼。
  - ← 改写：（35–39）「答不上来」
- 暂时放过自己使他松了一点，先前的为难仍在，温柔却重新自然起来。
  - ← 改写：（72–77）「退回谨慎」
- ⟲ 仍在起作用：（72–77）「不能成为」；（62–71）「收住喜欢」

### 84–92　（正在面对）

- 不再逼自己消除渴望后，他又感受到最初亲近对方时的快乐。
  - ← 提供理由：（78–83）「松了一点」
- 这次他已知道自己会期待更多，也知道对方未必回应，却仍为亲近而高兴。　✦ 分清
- 他不再拿无所求证明体贴，也不再因想被珍惜就怀疑整份感情的真诚。　✦ 分清
  - ← 改写：（35–39）「不够诚实」
- 明知自己可能受伤，他依然愿意全心投入，不再为感情深或自己热切而羞怯。
  - ← 改写：（35–39）「盼望被看见」
- 经历过许多犹疑还能如此高兴，让他甚至有些感动，仿佛那些愿望都能一同留着。
  - ← 提供理由：（78–83）「没把握」
- ⟲ 仍在起作用：（4–16）「自由地给予」；（17–23）「不能决定」

### 93–102　（没在想）

- 不再遮掩渴望后，他更清楚自己有多想靠近这个人。
  - ← 提供理由：（84–92）「想被珍惜」
- 他想让积攒的温柔在两人之间得到回应，想被深切珍惜，也想拥有共同的幸福。
- 那些曾让他难堪的愿望如今暂时不再折磨他，他只觉得自己有许多可以给予。
  - ← 提供理由：（84–92）「有些感动」
- 那一阵他甚至觉得无需再添什么，想靠近与被爱的心愿仿佛都得到了抒发。
  - ← 改写：（62–71）「几乎感不到」
- 没有得到新的保证，他却因能够这样爱而感到几乎难以承受的充实，一时顾不上以后。
- ⟲ 仍在起作用：（72–77）「深情有所相遇」

### 103–110　（正在面对）

- 幸福仍鲜明时，他发现自己再怎样深情，也无法凭此得到对方同样深切的选择。　✦ 满足照出未满足
  - ← 唤起：（93–102）「得到抒发」
- 想到这里他仍会酸楚，刚才的欢喜如此真实，他再难说服自己不在乎回应。　✦ 知道更多反而更尖锐
  - ← 限制：（93–102）「一时顾不上」
- 他担心把安稳全交给对方，会让对方连他的全部不安也必须负责消除。　✦ 选择的代价
- 他也不愿因怕得不到，就有意削弱那些带给自己巨大幸福的感情。
- 他终于看出，克制虽曾带来安心，却没消除渴望，尽情投入也无法排除失望。　✦ 办法的限度
  - ← 限制：（24–34）「不会失去什么」
  - ← 限制：（62–71）「几乎感不到」
- 想靠近的迫切和不肯勉强对方的坚持都没有退去，他因此更强烈地感到冲突。　✦ 知道更多反而更尖锐
- 他宁可承受这份不轻松，也不愿再为求轻松而匆忙舍弃其中一边。　✦ 选择的代价
  - ← 改写：（78–83）「不再逼自己」
- ⟲ 仍在起作用：（72–77）「深情有所相遇」；（72–77）「不能成为」；（51–61）「舍不得减轻」；（72–77）「退回谨慎」

### 111–116　（正在面对）

- 牵挂仍未平息，他渐渐不再要求自己找出一种不会受伤的爱法。
  - ← 提供理由：（103–110）「无法排除失望」
- 他仍想被对方选择，因为对方确实重要，即使未必如愿，也不愿假装不曾期盼。
- 他不愿放弃克制，因为对方有自己的心意，他不想为了安心而逼对方迁就。　✦ 分清
  - ← 提供理由：（103–110）「全部不安」
- 他依旧会遗憾，但不再觉得必须先消除这份遗憾，才能继续喜欢。
  - ← 改写：（103–110）「再难说服」
- 即使疑问没得到回答，他仍珍惜先前那些真实的快乐，也因此知道对方多重要。
  - ← 说明：（4–16）「不再提防」
  - ← 说明：（24–34）「尽情给予」
  - ← 说明：（40–50）「生出甜意」
  - ← 说明：（93–102）「得到抒发」
- 他仍盼回应，也仍会克制，却不拿回应的有无检验真心，或拿克制多少证明清醒。　✦ 分清
  - ← 改写：（35–39）「不够诚实」
- 他知道今后还会想靠得更近，仍可能因得不到而疼，却不把疼痛变成否认或催促。
- 他愿继续把这个人放在心里，认真地喜欢，尽情欢喜，也接纳无法替对方决定的部分。
  - ← 提供理由：（103–110）「宁可承受」
- 即使没有得到想要的一切，他仍可以盼着被爱而不强求，也能尊重对方而不收回心意。　✦ 分清
- ⟲ 仍在起作用：（103–110）「同样深切的选择」；（72–77）「退回谨慎」；（72–77）「不能成为」；（62–71）「尽情喜欢一次」
