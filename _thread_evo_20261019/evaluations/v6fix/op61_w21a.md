# Op.61｜关系图（在 w20 上逐段聚焦重修 w21a）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他心里有股不肯停的劲，熟悉的感觉又回来，他却说不清在等什么，过去也回不来了。
- → 他不甘心就这么由着事情照旧，硬撑着不肯垮下去，心里也想停一停，怕真投进去会失去别的东西。
- → 他想找个理由让自己敢往前走，可刚觉得想通，舍不得又回来，自己却说不清舍不得什么，连那点确信也变得陌生。
- → 他为自己非得想透才肯动而难堪。

### S02｜24–65 小节　（正在面对）

- 从前他总要先问值不值得，如今还没想透，也先接下自己能做的一份，尽力去做。
  - ← 改写：（1–23）「非得想透才肯动」
- → 结果还没把握，疑虑和牵挂也还在，可他做着做着有了些力气，也有点骄傲，越投入越痛快。
- → 他还是舍不得那些说不清的珍贵东西，它们仿佛还在，却已不能像从前那样拥有。
- → 一察觉失落，他就急着把心思拉回眼前，反复劝自己撑得住，越劝越显出他其实很在意。
- → 他不甘心就这样垮下去，可一想到仍放不下的事，刚撑起的劲又泄了，只好重新提起劲，心里始终安顿不下来。

### S03｜66–91 小节　（正在面对）

- 他真往前走了，少问自己该不该走，也庆幸没退，可他还是拿不准该往哪使劲，心里恼火又不甘。
  - ← 提供理由：（24–65）「珍贵东西」
- → 他想要自在亲近、不必时时防备的生活，想到它便松口气，眼下还做不到又难受，却仍顺着轻快过了一会儿，不急着问自己为何非得用力。
- → 轻松退去，眼前的难处还在，他又想起当初不肯再等、先做能做的那一份，也怀疑刚才那股劲是不是真心。
  - ← 唤起：（24–65）「先问值不值得」
- ⟲ 仍在起作用：（24–65）「始终安顿不下来」

### S04｜92–115 小节　（正在面对）

- 轻松退去后，他还记得那一步确实让自己重新动起来，所以仍愿意坚持。
  - ← 唤起：（66–91）「不肯再等」
  - ← 提供理由：（24–65）「越投入越痛快」
- 他真尝过那份亲近带来的快乐，当时的坚定也有他努力撑住自己的成分，可眼下不安没让他认定那一步错了。
- → 他怕停下就得承认那份亲近回不到从前，便硬撑着把自己催得停不住，脑子反复追问过去还能怎样。
- → 可他还想要那种不用防备的亲近，光靠坚持仍没法让他安心。

### S05｜116–147 小节　（正在面对）

- 他知道行动还不够，却舍不得松手，连承认失望都像是在推翻那一步。
  - ← 提供理由：（92–115）「重新动起来」
- 想到那种不必防备的亲近，他心里会软，可又怕自己一软下来就停了步。
  - ← 提供理由：（92–115）「反复追问」
- → 他把难受和想停都当成自己还不够坚定，便逼自己继续撑。
- → 他连累了也不准自己松劲，直到发现自己正逼着一个累了的人硬撑，终于不想再证明自己多坚强。
- → 他有些茫然，撑着的劲松了，却没因此安心，才肯承认自己仍舍不得那种不必防备的亲近。
- ⟲ 仍在起作用：（92–115）「光靠坚持」

### S06｜148–180 小节　（没在想）

- 催逼停下来后，他认出自己舍不得的不是一时舒服，而是曾真心相信过的生活。
  - ← 说明：（116–147）「仍舍不得」
- → 他盼着人与人靠近时不用时时防备，珍惜的东西也不必靠争抢才能留住。
- 他想付出时只是因为喜欢，不必反复证明自己值得被爱和接纳。
- 他确实尝过那种亲近带来的快乐，所以不肯轻易把这份向往说成软弱。
  - ← 提供理由：（92–115）「亲近的快乐」
- → 他不再逼自己维持坚强，也暂时不盘问这份向往有没有用，压住的委屈和思念终于能露出来。
  - ← 改写：（116–147）「不准自己松劲」
- → 他允许自己相信这份向往，满足和柔软慢慢回来，连先前的疲惫也暂时淡了。
- → 这份满足让他一时舍不得把心思拉回现实，可那种生活仍没真正实现。

### S07｜181–205 小节　（正在面对）

- 熟悉的亲近让他觉得生活近在眼前，身体先绷紧，才察觉现实没变；他懊恼怎么又沉进去，忘了还有事要面对。
  - ← 唤起：（148–180）「这份满足」
- → 他当初不肯再等，是怕珍惜的东西继续受损，光在心里想着那种生活也护不住它们。
  - ← 提供理由：（24–65）「珍贵东西」
- → 他想重新投入，却已不能毫无顾忌，怕自己又只顾硬撑，把刚找回的温柔磨掉，连想留住的生活也顾不上。
- → 他原以为想清为何不能再等就能安心，如今还得想怎样争取才不伤温柔，理由更多了，还是定不下来。

### S08｜206–213 小节　（没在想）

- 为难时，那份曾让他满足的亲近又回到心里，他不急着逼自己回答还该不该继续争取。
  - ← 唤起：（148–180）「这份满足」
- → 他愿意多停一会儿，心里松快，也欢喜，可先前的为难还在，安静留不久。
- ⟲ 仍在起作用：（181–205）「理由更多」

### S09｜214–215 小节　（正在面对）

- 他刚才让自己安静了一会儿，可原先的难题还在，他又拿不定主意。
  - ← 唤起：（206–213）「安静留不久」
- → 他这回知道自己为什么迟疑：怕往前又把自己逼得太狠，也舍不得那种不必防备的生活。
  - ← 改写：（148–180）「真心相信过」
- ⟲ 仍在起作用：（181–205）「磨掉温柔」

### S10｜216–225 小节　（正在面对）

- 他知道那种生活仍重要，却累得连自己为什么舍不得都说不清，也提不起劲争取。
  - ← 说明：（181–205）「理由更多」
- → 他舍不得丢开那一步，也舍不得那份安宁。
  - ← 提供理由：（92–115）「重新动起来」
  - ← 提供理由：（148–180）「说成软弱」
- → 他怕再往前又把自己逼得太狠，可那些妨碍那种生活的事仍让他放不下。
  - ← 提供理由：（214–215）「为什么迟疑」
- → 他反复想着自己究竟想护住什么，想歇一歇也不等于要把它丢下。
  - ← 改写：（148–180）「这份满足」
- → 他还不知道往后该怎么过，却不再急着判哪一边错，逼自己立刻选边的劲也松了一点。
- ⟲ 仍在起作用：（148–180）「不必靠争抢」；（181–205）「不肯再等」

### S11｜226–241 小节　（正在面对）

- 他心里仍没底，开始重新想眼前还能承担什么。
  - ← 提供理由：（216–225）「选边的劲也松」
- → 他已经试过，行动带来的力气并不能消掉对那种生活的牵挂。
  - ← 说明：（24–65）「越投入越痛快」
- → 他想到，难处不在自己不够坚定：行动给他力气，那种生活给他安慰，两样都舍不得，却很难不伤到其中一样。
  - ← 改写：（116–147）「还不够坚定」
  - ← 提供理由：（148–180）「说成软弱」
  - ← 限制：（181–205）「磨掉温柔」
- → 想到要付出的代价，他心里还是疼，盼着别失去太多。
- → 他没想出两全办法，也怕争取伤到安宁，可不争取也护不住珍惜的东西，他仍带着怕先去争取。
  - ← 提供理由：（181–205）「不肯再等」
- ⟲ 仍在起作用：（181–205）「磨掉温柔」

### S12｜242–253 小节　（正在面对）

- 他没再等一个不会伤到任何东西的办法，接着做眼前的事，久违的劲头又回来了。
  - ← 提供理由：（226–241）「两样都舍不得」
  - ← 提供理由：（24–65）「越投入越痛快」
- → 他只管把眼前能做的做好，不再逼自己每次努力都得把事情扭转过来。
- → 他舍不得那种生活，也不想放下眼前该做的事，怕顾住这头就伤了那头。
- → 那份担心又冒出来，他心里晃了一下，还是带着不安往前走，不用装作不怕，也不必等犹疑消失才坚定。
- ⟲ 仍在起作用：（226–241）「两样都舍不得」；（226–241）「带着怕先去争取」

### S13｜254–288 小节　（正在面对）

- 从前他总想退回那份安宁，觉得这样才护得住向往的生活；可妨碍它的事还是会照旧。
  - ← 提供理由：（181–205）「磨掉温柔」
  - ← 提供理由：（181–205）「不肯再等」
- → 这回他带着对那种生活的牵挂往前，发现眼前做的事也在替它争取，旧愿反倒近了些。
  - ← 提供理由：（226–241）「带着怕先去争取」
  - ← 改写：（242–253）「舍不得那种生活」
- → 他不再觉得惦记那种生活会拖住自己，反而更有劲往前做事。
- → 他觉得那种生活值得费力争取，却怕一味硬撑会磨掉其中的温柔，便留心自己怎么做。
  - ← 限制：（181–205）「磨掉温柔」
  - ← 提供理由：（226–241）「带着怕先去争取」
- 经历过怀疑和疲惫，他想起那种生活仍会高兴，没能过上它也不等于从前的快乐是假的。
  - ← 提供理由：（148–180）「说成软弱」
- 他不再拿心里的安慰顶替该做的事，也不拿忙着做事压下想念。
  - ← 说明：（226–241）「两样都舍不得」
  - ← 改写：（242–253）「舍不得那种生活」
- 那种生活还没实现，眼前的事能不能改变什么、最后能护住多少，他仍没把握。
  - ← 限制：（242–253）「扭转过来」
- → 真要付出代价，他还是可能累得想退回那份安宁。
  - ← 提供理由：（181–205）「磨掉温柔」
- → 他不再靠拼命证明自己该往前，松下来后仍清楚想护住什么。
  - ← 改写：（116–147）「不准自己松劲」
- ⟲ 仍在起作用：（148–180）「这份满足」；（148–180）「不必靠争抢」
