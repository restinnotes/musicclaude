# Op.60｜关系图（在 v6 上修补，w28）

**Center：**对亲密的投入与自我克制始终相互牵制。

### S01｜1–3 小节　（还说不清）

- 我没想到自己竟然这么想亲近他，这份喜欢来得太突然，连我自己都没料到。
- 可我不敢把这份喜欢说得太明白，怕说破了会改变我们之间的关系；我又舍不得放下，所以现在还不想作出明确的决定。

### S02｜4–16 小节　（没在想）

- 他刚才还想把心里的喜欢多说一点，可又怕说得太明白会改变两人的关系，想说的话还是收了回去。
- → 他不想把喜欢变成非得让对方回应的要求，也不再反复猜对方怎么想；就算不知道对方有没有接住这份心意，他还是能自在地关心对方，觉得这样自然地亲近已经够了。两个人以后的事先留到以后，他不急着决定；可眼前这样亲近未必会一直有，暂时不决定也不能保证它会一直在，他希望这一刻慢些过去。
  - ← 改写：（1–3）「舍不得放下」
- ⟲ 仍在起作用：（1–3）「舍不得放下」

### S03｜17–23 小节　（正在面对）

- 他还是不急着确认两个人以后会怎样。眼下能这样亲近，他已经很满足了，也因此开始盼着这份亲近能长久些。可他能做的只是好好珍惜对方，对方会不会也珍惜他，他说了不算。所以他偶尔会想，自己对对方是不是特别的，只是还不想开口问个明白。
  - ← 提供理由：（4–16）「多说一点」

### S04｜24–34 小节　（正在面对）

- 我先不去想自己在他心里是不是特别了，只想真心盼他好，关心他、把心意给出去，这样我自己也会高兴。我也就暂时不去追问他怎么想了，甚至觉得，只要我不向他要回应，这份亲近就不会失去，所以更敢把心意给出去。可我还是不知道他会不会也珍惜我。我想再深一点地表达心意，把眼前的亲近留住，又怕自己太热切会像是在催他回应，只好收住一点。

### S05｜35–39 小节　（还说不清）

- 欢喜退下去一点，我还是想知道他有没有把我放在心上。我原先以为，只要不向他要回应，就能安心喜欢，也不会失去眼前的亲近；现在这个念头又回来了，我开始怀疑，自己对他好时是不是也盼着他珍惜我。可我知道，先前那些快乐并不是为了换他的回应；我也不敢把这个疑问直接拿去问他，怕一开口就成了索取，把眼前的亲近弄坏。我只能先看看，自己到底在盼什么。
  - ← 限制：（24–34）「盼他好」
- → 我不敢再认定眼前的亲近会一直这样，也不想急着替自己辩白，或再热烈起来把这份难堪盖过去。想让这份亲近一直继续下去的念头，也没那么强了。

### S06｜40–50 小节　（没在想）

- 我自己的快乐说明不了他怎么想，再多对他好也证明不了我什么都不求。我不想再拿慷慨替自己辩白，也不必逼自己把期待压下去。关心他、真心盼他好时，我确实是快乐的。
  - ← 说明：（35–39）「放在心上」
  - ← 提供理由：（35–39）「难堪」
- 我还是盼着他也珍惜我，也想知道他懂不懂我的心事。这些事不是我能决定的。眼下不追问，也没让这份未知消失。
  - ← 唤起：（35–39）「放在心上」

### S07｜51–61 小节　（正在面对）

- 我关心他、盼他过得好时，是真的开心；这份喜欢本身就值得留着，我不想把它收淡。可我越珍惜他，越惦记他，也越盼他能懂我的关心，盼这份亲近能长久。我只能决定自己怎样珍惜他，不能决定他是否也珍惜我，更不能保证眼前的亲近会一直有。我怕开口要回应会搅坏亲近，只好不催，把这些期待留给自己慢慢消化。
  - ← 限制：（24–34）「盼他好」

### S08｜62–71 小节　（没在想）

- 他不用等对方答应什么，靠近对方、真心盼对方好，哪怕只是把喜欢留在心里，也会让他高兴。他舍不得把喜欢收淡，就不想再因为怕受伤时时管住自己，想放开些，好好享受。
  - ← 提供理由：（4–16）「自在地关心」
  - ← 提供理由：（51–61）「不想把它收淡」
- 他还在享受这一刻，心里又想起这样的亲近能留多久不是自己说了算，也盼着对方同样珍惜自己，便想把这一刻留住。
- ⟲ 仍在起作用：（35–39）「放在心上」

### S09｜72–77 小节　（正在面对）

- 欢喜稍退后，他还是觉得眼前这样亲近已经很好，也确实想被对方同样珍惜；这份满足没能让那个愿望消失。他知道自己真心喜欢对方，也不能因此要求对方回应，又怕一直盼着会催到对方。可要他把盼望收回去，又像是在否认自己刚承认的心意；两边都舍不得，他觉得委屈又累，不知道该怎么办。
  - ← 提供理由：（24–34）「盼他好」

### S10｜78–83 小节　（正在面对）

- 我还是想靠近你，也怕催到你；我不必逼自己非得选一边，也不用现在就把这件事解决掉，委屈和想被你珍惜的心思都可以先留着。想靠近时，我不必马上做什么；想守住分寸，也不等于要否认自己还眷恋你。就算还不知道你怎么想，我还是愿意关心你，自然地对你好。

### S11｜84–92 小节　（正在面对）

- 他不想再逼自己先把渴望压下去、把心事理清，或现在就决定两人会怎样；只要不催对方，他还是想继续亲近。他也想被对方珍惜，这不代表他之前对对方的关心是拿来换回应的；他关心对方时确实很快乐，那份心意也是真的。他不想再把这份盼望收回去，可对方会不会也选择他，不是他能决定的。
  - ← 提供理由：（35–39）「放在心上」
  - ← 改写：（35–39）「难堪」
- ⟲ 仍在起作用：（78–83）「不必逼自己选一边」；（72–77）「两边都舍不得」

### S12｜93–102 小节　（没在想）

- 他不再拿想被珍惜来怀疑自己的真心，想靠近、想给予、想被选择都可以是他的心意。他开始想着两个人也许能一起过的日子，不再只顾着自己能不能得到回应。
- 对方还没有给他新的保证，他仍盼着对方选择自己，只是一时顾不上追问答案，只想让眼下的满足多留一会儿。那份期待并没有消失，只是暂时搁在了一边。

### S13｜103–110 小节　（正在面对）

- 他是真的想和对方一起过日子，看看两个人能过出怎样的幸福，可对方没有给新的保证，他不能把眼下的满足当成两个人已经选了彼此。他还是盼对方主动靠近、把他放在心上，却不想拿这份期待逼对方回应，也不肯装作自己已经不在乎，哪一边他都不想放掉。
  - ← 提供理由：（93–102）「想被珍惜」
- ⟲ 仍在起作用：（72–77）「两边都舍不得」

### S14｜111–116 小节　（正在面对）

- 他想起自己以前能安心靠近对方，愿意把心意给出去，也有些心事只能自己体会，还曾经尽情地高兴。那些时候没换来对方的承诺，可快乐都是真的，他也确实很在乎这个人。他还是想被对方选中，也不想催对方，这两件事不必非得舍掉一件；把喜欢收住也好，尽情给出去也好，都不能保证以后不遗憾，他不想再因为怕这份喜欢会改变两人的关系，就把它收回去。

  - ← 说明：（62–71）「这一刻留住」
  - ← 改写：（1–3）「舍不得放下」
- ⟲ 仍在起作用：（78–83）「不必逼自己选一边」
