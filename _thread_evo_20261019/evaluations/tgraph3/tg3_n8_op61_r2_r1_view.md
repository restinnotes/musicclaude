# Op.61｜关系图

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### 1–23　（还说不清）

起初，他说不清自己究竟在等什么。心里有股**不肯任那些事就此过去**的劲，仿佛放任下去就是亲手承认它们理所当然；可想到真的投入，又**怕会丢下什么**，他并未失去勇气，也没只想守着安稳，却分不清这两股牵扯。他想找一个**足以让自己不再犹豫的理由**，刚觉得有把握，舍不得又浮上来，过后甚至觉得刚才的确信陌生；**反复犹豫**让他难堪，他开始怀疑自己是否非要把心里的一切照顾妥当才肯往前。


### 24–65　（正在面对）

他渐渐不愿再用还没想清楚让自己等下去，**先认下能承担的那一份**；没有保证，牵挂也仍在，可开始行动让他切实感到有力量，至少他愿意尽力，这使他为自己没有再被疑虑拦住而骄傲。他投入得热切，付出本身给他快乐，原先无处可去的不满仿佛有了出口；他舍得付出更多，甚至贪恋**倾尽全力的畅快**，也不想时时检视软弱。偶尔在用力时，他仍会触到一小块没有跟着振奋的心事：它暂时不妨碍行动，却隐约提醒他，还有**没有被照顾到的牵挂**。

- ← 提供理由：（1–23）「反复犹豫」
- ← 失效：（1–23）「足以让自己不再犹豫的理由」
- ⟲ 仍在起作用：（1–23）「怕会丢下什么」

### 66–91　（没在想）

那点隐约的心事一时还不足以令他停步。因他已经认真投入，终于能从反复自问里松开一些，发现自己也会因不再畏缩而高兴，并在向前的热情中感到轻盈；偶尔忘了为何如此用力，他暂时也不觉得这是辜负。他顺着**轻盈的快乐**走了一程，没急着解释它；等快乐淡下来，先前作出的决定仍在等他面对。

- ← 提供理由：（24–65）「先认下能承担的那一份」
- ← 唤起：（24–65）「倾尽全力的畅快」
- ⟲ 仍在起作用：（24–65）「没有被照顾到的牵挂」

### 92–115　（正在面对）

快乐退下去后，他重新面对自己的决定，仍愿坚持，因为它的确使他走出了反复犹豫，也带来过实在的轻快；心里还有缺口，他也不愿抹去这些收获。可是如今想**靠坚定让自己安稳**，他反而察觉心里另有一种要求，这份力量顾不到它。他不情愿地承认，**行动值得**，**行动也不够**，却已无法假装不知道。　✦ 办法的限度

- ← 提供理由：（24–65）「先认下能承担的那一份」
- ← 说明：（66–91）「轻盈的快乐」
- ← 限制：（24–65）「没有被照顾到的牵挂」

### 116–147　（正在面对）

明知行动也不够，他仍放不下它，因为它曾帮自己挣脱犹疑；他怕失望说明自己已经变心，于是**逼自己坚持**，把心里的难处当成应当克服的迟疑，连想稍歇都担心是退缩。他知道自己苦，却想不出除了坚持还能怎样对得起最初的决意；曾使他昂扬的要求连脆弱也容不下，渐渐变成苛责，他也像是在勉强一个疲惫的人。终于，他不想再**证明自己有多坚强**，**暂时放下催逼**，虽然还不安心，却让**被压住的依恋**有了回来的余地；他茫然又松了一些，仿佛肯承认自己真有舍不得的东西。　✦ 办法的限度

- ← 失效：（92–115）「靠坚定让自己安稳」
- ⟲ 仍在起作用：（92–115）「行动也不够」；（24–65）「先认下能承担的那一份」

### 148–180　（没在想）

不再催逼自己，那份依恋才慢慢显出模样：他想念一种自己**曾真心相信的生活**，人们可以不用时时防备，珍贵的东西不用争夺才能留下，一个人也不用不断证明自己值得被爱和接纳；付出可以因喜欢，靠近也不用先准备受伤。他想起这样的相信曾给过他**真实的快乐**，也曾让他觉得与人、与生活亲近无需时时费力；因此这份盼望并非眼下为逃避辛苦而编出的安慰，他无法再把它当成软弱。　✦ 分清

他于是肯完整地待在这份盼望里，让爱惜暂时不受责任审问，也不急着问这种生活还能不能得到、同眼前的坚持谁更重要。仅仅允许自己爱和相信，就让他深深满足，仿佛那个一度只知道向前用力的自己又能柔软地活着；他几乎忘了疲惫，暂时不想离开，**这份安宁**确实给了他一直需要的东西。

- ← 提供理由：（116–147）「暂时放下催逼」
- ← 唤起：（116–147）「被压住的依恋」
- ← 改写：（24–65）「没有被照顾到的牵挂」
- ← 改写：（1–23）「怕会丢下什么」

### 181–205　（正在面对）

正因为这份安宁让他满足，他渐渐不甘**只在心里怀念**那种生活：**让它难以存在的事情**仍在，单靠留恋不会改变它们；当初他不肯继续等待，也正因为不愿任珍贵的东西受损。想到这里，他一阵懊恼，几乎怪自己刚才沉浸在满足中，忘了仍有必须面对的事。　✦ 满足照出未满足

他试着重新催自己振作，却没法像先前那样毫无顾忌地投入；在充分感受过温柔的可贵后，他害怕争取的艰难会一点点**耗尽温柔**，最后只留下不肯退让的意志。于是**向前和停留都令他不安**：他曾想靠一个坚定的理由免去为难，如今理由反而更多，心却更难定。　✦ 知道更多反而更尖锐

- ← 唤起：（148–180）「这份安宁」
- ← 提供理由：（148–180）「曾真心相信的生活」
- ← 限制：（148–180）「真实的快乐」
- ← 失效：（1–23）「足以让自己不再犹豫的理由」
- ⟲ 仍在起作用：（1–23）「不肯任那些事就此过去」

### 206–213　（没在想）

为难还在时，温柔又短暂地贴近他。明知自己不能一直停留，他仍不忍立即推开，也不想每次想起它就拿来责问自己；他只愿**再爱惜片刻**，暂时不想那些还没有答案的事。这一点安静仍使他欢喜，只是欢喜里已经有了不舍。

- ← 唤起：（181–205）「向前和停留都令他不安」
- ⟲ 仍在起作用：（148–180）「这份安宁」

### 214–215　（正在面对）

这点安静一退，熟悉的迟疑又回来，仿佛走了很远仍回到原处。只是他如今**知道自己舍不得什么**：那份迟疑里有他不愿失去的生活希望，也有胆怯，他无法再把它全当成软弱。　✦ 分清

- ← 限制：（206–213）「再爱惜片刻」
- ← 改写：（148–180）「曾真心相信的生活」
- ⟲ 仍在起作用：（1–23）「反复犹豫」

### 216–225　（正在面对）

知道自己舍不得什么并没有让他立刻勇敢起来：最初凭决心投入、刚才靠旧愿得到安宁，这**两种办法**都曾给他东西，也都留下不能忽略的难处。他眼下一时没有力气逼自己大改，只剩一个**微弱的心愿**：继续争取时别忘为了什么，爱惜那份安宁时也别放下使它难以存在的事情。他还不知道怎样做到，只是反复想着，心里那种**非得舍弃一边才能继续的逼迫**似乎轻了一点。　✦ 办法的限度

- ← 提供理由：（214–215）「知道自己舍不得什么」
- ← 限制：（24–65）「先认下能承担的那一份」
- ← 限制：（206–213）「再爱惜片刻」
- ⟲ 仍在起作用：（181–205）「让它难以存在的事情」

### 226–241　（正在面对）

他凭着这个还不牢靠的心愿，重新想自己能怎么办：尽力承担曾使他从无力中站起，却不能消除牵挂；心中的美好曾给他安慰，单靠安慰却护不住自己爱惜的生活。**两份收获**他都不想否定，但他渐渐明白，想保有那种不必时时奋力的安宁，争取它时就可能再次失去安宁；过去为这份难受责怪自己，如今他开始接受，所珍视的东西本来就不止一种。　✦ 办法的限度

承认**可能付出代价**，他仍会心疼，也仍盼有条少些艰难的路；可等下去不会让那条路自己出现，只因怕损伤而不争取，珍贵的东西也未必保得住。他便不再逼自己先变得毫不害怕，允许舍不得、没有把握、承担中会受苦，慢慢又聚起力量，决定**带着不舍往前**；真正要承担时，他仍会感到害怕，却不想再由惧怕替自己决定。　✦ 选择的代价

- ← 唤起：（216–225）「微弱的心愿」
- ← 改写：（216–225）「两种办法」
- ← 失效：（181–205）「只在心里怀念」
- ← 说明：（181–205）「耗尽温柔」
- ← 动摇：（216–225）「非得舍弃一边才能继续的逼迫」 —— 这点松动并未给他一条没有代价的路，只让他开始容许自己带着害怕继续。
- ⟲ 仍在起作用：（92–115）「行动值得」；（1–23）「不肯任那些事就此过去」

### 242–253　（正在面对）

不再等一个毫无损失的办法，他重新挺直身来，久违的昂扬也回来了；过去他多少还想借坚定证明自己能改变些什么，如今仍愿尽力，却无需压下脆弱来维持坚定，也不再要求尽力证明自己什么都能做到。他知道自己要承担什么、又为什么舍不得，**把害怕失去和想珍惜的东西一同带着**，愿为它们负起责任；所以这次的决心仍热烈，却比起初踏实，即使还有疑虑，他也准许自己坚定。

- ← 提供理由：（226–241）「带着不舍往前」
- ← 改写：（226–241）「可能付出代价」
- ← 改写：（116–147）「证明自己有多坚强」
- ← 失效：（116–147）「逼自己坚持」
- ⟲ 仍在起作用：（216–225）「微弱的心愿」

### 254–288　（正在面对）

他意外发现，带着牵挂重新站稳以后，过去总使他想退回去的旧愿似乎更亲近了。他仍希望人们不用时时防备就能相爱、珍贵之物不用争夺才能留下，也仍怀念付出不致耗尽自己、信任无须反复受考验的日子；过去一想到这些便想撤出艰难，如今感到它们可贵，便更不愿放任使它们难以存在的事情。他第一次这样清楚地感觉到，温柔也可以使他愿意行动：他要的仍是那种无需拼命也能好好生活的日子，但有时为了珍惜它，他得离开它在心里给他的安宁。他没把付出的多少当作旧愿实现的保证，也不因心愿美好就相信所有付出都值得；他仍怕争取磨掉原本想守住的温柔，因此要留心自己怎样坚持。

两股曾让他为难的心意，此刻能够一同支持他；他感到比先前开阔的喜悦，不再为依恋羞惭，也不因责任厌倦，重新尝到最初相信生活时的快乐，经历疑虑和疲惫后，他也不再觉得这份快乐理所当然。喜悦平静后，他仍清楚自己的努力能改变多少没有保证，那种不用防备的生活也尚未回来；日后他还可能疲惫、为代价动摇，两种渴望也还会牵制。他于是愿意让过去的快乐、失望、疲惫与依恋一同留下，不拿一边的满足遮住另一边的需要，也不因有未满足的部分就抹去已经得到的东西；这些经历让他看清什么值得付出、什么不能在付出中丢掉。他仍向往安宁，也仍愿行动，不知最后能留住多少，却不愿靠忘掉任何一边求安稳；他可以带着不舍继续往前，这次他不再需要为自己的愿意寻找更多证明。　✦ 满足照出未满足

- ← 仍在起作用：（1–23）「不肯任那些事就此过去」 —— 起初还没有具体模样的抗拒，如今有了他不愿任其受损的生活作为所指。
