# Op.61｜线（r54role）

**Center：**维持尊严的行动与对旧日生活及归属的怀念反复拉扯

### S01｜1–23 小节　（还说不清）

- 他已经离开了那段熟悉的生活，因为继续留下去，就意味着一次又一次委屈自己。
- 他仍觉得当初想保住自己的尊严没有错，可这个选择并没有让他马上安定下来。 〔1–23 ①〕
- 想到从前那些熟悉的日子，他心里有些空落，隐约想再靠近那份生活，却还说不清究竟舍不得什么。 〔1–23 ①〕

### S02｜24–65 小节　（正在面对）

- 即使如此，他还是不甘心再用委屈自己来换取从前那份安稳。 〔1–23 ①〕〔24–65 ③〕
