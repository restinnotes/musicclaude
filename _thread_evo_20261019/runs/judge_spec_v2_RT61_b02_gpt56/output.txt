结论先给：**文章B > 文章A > 文章D > 文章C**。

我把“why-now 是否清楚”和“这个 why-now 是否靠编造得到”分开计：所以 C、D 有不少段仍会标“有”，因为它们的因果链本身写得清楚；但由于因果强度建立在未经允许的事实性前史/处境上，最终严格执行你的 **overall ≤ 4** 硬上限。四篇都没有哪一段需要判成“乐”：A 虽在首段拿“开头那些迟疑、试探”来对应人物状态，但人物理由已经先成立，并不是音乐变化导致心理变化。fileciteturn0file0L5-L5

## 1. 文章B

**Center：** 他既真心希望自己和别人还有值得期盼的明天，又害怕把“我希望它会好”偷偷冒充成“我知道它会好”；难点是怎样不背叛悲伤，也不靠虚假保证才敢继续期盼。开头把冲突立住，但没有预告最后会怎样解决。fileciteturn0file1L5-L9

**why-now：**
`弱 / 有 / 有 / 有 / 有 / 有 / 有 / 有 / 弱 / 有 / 有 / 有 / 有`

最好的一处是 **mm.226–241**。这里不是简单地“他决定勇敢”：前面他已经确认，谨慎不可能给未来找到保证；于是此刻才发现，若为了避免失望而拒绝一切好的可能，恐惧其实已经替他作了一次选择。他接受风险，是前面认识积累后的必然结果。尤其“防备尚未发生的失望，反而先放弃确实珍惜的东西”这一层，why-now、机制和代价同时成立。fileciteturn0file1L45-L45

最弱的是 **mm.214–215**。“刚允许自己留下这点真实，最初疑问又回来”说得通，但“为什么偏偏此刻回来”主要靠一个过门式连接，没有邻近几段那么充分。fileciteturn0file1L37-L37

它最大的结构瑕疵反而在很早：首段其实已经相当清楚地知道“盼望只是愿望，危险在于把愿望当事实”；到 mm.148–180 又把“相信未来一定好”和“希望未来能好”写成此刻才第一次分清。也就是说，一个很好的后期认识被开头提前说掉了一部分。fileciteturn0file1L5-L5 fileciteturn0file1L25-L25

不过，B 后面没有只围着上一段转。mm.181–205 会重新检验 mm.148–180 的安定究竟承担什么责任，mm.206–213 再纠正自己刚才对它提出的过量要求；这是货真价实的 Connection，而非单纯“上一段导致下一段”。fileciteturn0file1L29-L33

**判断：四篇里最好。** 它最强的地方不是曲折多，而是每一次理解增加以后，旧问题都会被改写一点。

## 2. 文章A

**Center：** 他希望别人同时明白两件事——这件事对他有不能退让的分量，以及他其实会害怕、会受伤、盼望被珍惜；困难在于他一直觉得表达其中一面会削弱另一面。fileciteturn0file0L5-L9

**why-now：**
`弱 / 有 / 有 / 有 / 有 / 有 / 有 / 有 / 有 / 有 / 有 / 有 / 有`

最好的一组推进在 **mm.148–205**。先是自我体谅真正产生了满足；也正因为满足是真的，他才辨出它没有处理什么——“我不羞于自己会疼”并不能替代“我珍惜的事情本身应被认真对待”。随后 mm.181–205 才有理由重新生出坚持，而且这次坚持的根据已经和早先不同。这里的“满足照出仍未满足之处”非常符合你要求的理解积累。fileciteturn0file0L25-L29

最弱的是 **mm.1–23**。人物的两难本身写得清楚，但还主要是一张静态冲突图；而且一开始就断言“两件事在他心里本来就分不开”，实际上已经替后文“终于允许两者同时存在”泄露了部分答案。fileciteturn0file0L5-L5

A 的 History 和远距离 Connection 很好。例如 mm.206–213 会明确认出自己“正在重犯旧错”，mm.214–215 又把最初的问题带回来，但此时他已经拥有坚定、放松、兼顾、被安慰等多次真实试验，因此旧问题的含义变了。fileciteturn0file0L33-L37

它弱于 B，主要因为后半程有一点**同一结论反复换说法**：脆弱不取消坚定、温柔不等于退让、两者可以共存，这个认识在 mm.214 后连续被重新确认。逻辑都成立，但信息增量开始下降。语言上“既……又……”“不……也不……”“正因为……才……”以及“坚定、温柔、安宁、要求”等抽象词也偏密。

**判断：优秀 Thread，但比 B 稍显“答案先在，后面逐步证明它”。**

## 3. 文章D

**Center：** 身体已经衰弱的人仍想保有自己作决定的权利；困难是他既不能把身体限度一律当成软弱，也不愿让“体谅自己”变成提前放弃自己真正愿意承担的事情。fileciteturn0file3L5-L9

**why-now：**
`有 / 有 / 有 / 有 / 有 / 有 / 有 / 有 / 弱 / 有 / 有 / 有 / 有`

如果只看因果工艺，它甚至非常强。最好是 **mm.226–241**：前面的硬撑确实给过骄傲，放松确实给过轻快，自我体谅也确实给过安宁；这些成功都没有被抹掉，反而共同逼出一个更成熟的问题——不是“怎么选才能证明不软弱”，而是“知道必有损失之后，我仍愿意承担什么”。这是四篇里很好的“合理选择必有代价”范例。fileciteturn0file3L45-L45

最弱的 why-now 是 **mm.214–215**。从“允许几种感受并存”忽然跳到“真正害怕的是自己会允许身体垮下去”，洞察本身有意思，但这一个特定隐藏动机为何恰好从此前认识中推出，解释少了一步。fileciteturn0file3L37-L37

但是它有一个无法绕开的硬伤：**“身体一天比一天虚弱”不是轻微 Outer，而是决定全篇心理变化的重大事实性处境。** 腰背能否支撑、体力耗尽、身体“允许”与否，都被当成一次次心理认识的证据。fileciteturn0file3L5-L13

这尤其值得和珠子区分。参考只是把“腿脚虚浮的人”“整理好衣服、抬起头”等明确作为一种**听法或身体联想**；D 把这种可选联想变成了人物真的处于持续身体衰退中的事实。fileciteturn0file4L17-L23 最后又进一步确定“有些力气确实不会再回来”，等于替人物写出了不可逆的身体预后。fileciteturn0file3L55-L59

所以这是很典型的：**why-now 很强，但强度恰恰来自编造。** 按你的规则只能封顶 4。

## 4. 文章C

**Center：** 他既想守住来自过去共同世界的尊严，又仍渴望那个已经失去的世界继续承认他的归属；难点是前者可以独自坚持，后者却需要现实中的回应。fileciteturn0file2L5-L13

**why-now：**
`有 / 有 / 有 / 有 / 有 / 有 / 有 / 有 / 有 / 有 / 有 / 有 / 有`

它最好的 why-now 是 **mm.66–91**：正因为“尊严”这套办法真的使他重新站起来，它才终于暴露出不能处理的部分——可以证明自己没有倒下，却不能单方面证明自己仍然属于那个世界。“办法先有效，效果本身再照出边界”，机制非常扎实。fileciteturn0file2L13-L13

最差从合法性上说反而是 **mm.1–23**：它解释得很完整，但全部解释依赖一个稿件自行加入的重大前史——他曾属于某个世界，那个世界已经远去，他失去了位置并渴望重新被认出。之后整篇都在花这笔“借来的因果资本”。fileciteturn0file2L5-L5

到 mm.92–147，前史还继续被具体化成“在那里无需解释便被理解、自然拥有位置”“过去确实接住过他”，继而让人物向这个世界请求继续认得自己。这些不是单纯给同一关系安排一个小动作，而是新增的历史事实，而且正是转折理由。fileciteturn0file2L17-L21

它和参考珠子的关系也比 A、B 更危险。珠子只是说某些段落**可以**令人想到故乡、旧日生活或远方家园，而且明确保留其他读法；C 却把“故乡/共同世界/失去归属”固定成整条线的事实世界。fileciteturn0file4L27-L33 fileciteturn0file4L51-L57 这不是逐字照抄，但确有“把可选珠子读法单一化成剧情前史”的问题。

结尾还突然写“当他再次走向人群”，又新加了一个外部行动；即便不是主要转折原因，也没有必要。fileciteturn0file2L53-L53

因此 C 的逻辑网其实不差，但它比 D 又多了一层问题：不仅有重大编造，全文还高度依赖“归属、共同价值、承认、位置、关系”等抽象概念，扫读时实物感较弱。

### 横向判断

**B 胜 A**：B 的每一次认识更经常会改变问题本身；A 后半则较多是在确认“坚定与柔软可以并存”。

**D 胜 C，但只能排第三**：两者都触发编造硬上限；D 至少基本只围绕一个持续的“身体衰弱”设定工作，心理机制更具体。C 为了维持“失去归属”这条故事，不断补充过去怎样被接纳、怎样被理解、如今等谁回应等实质性前史，因此更严重。

**照抄方面**：我没有发现任何一篇达到“大面积逐字照抄/复述珠子”而需要单独触发硬上限的程度。真正需要扣的是 C、D 把珠子的可选意象固化成事实；A、B 更多只是使用了相近的总体心理形状。
