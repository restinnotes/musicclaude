## 内容（屏幕稿）

屏幕上的字按重要性分两种字号：大块是必需的，扫的人只看它就要明白；小块是补充，不读也不影响理解。每块只有一种字号。对着具体声音、具体几小节的细节不放主区，放在可视化旁边（见“画面”）。

### 1. 大块：只看大块，明白并且串得起来吗？
只看大块（按出现的顺序），就能明白这一屏最主要的东西：他此刻怎么了、为什么、最主要的体验是什么；大块之间接得上，一屏屏连起来看得出这件事怎么一步步往前走。大块是能独立读懂的意思，不是标签。线和珠子的内容按这一刻的重要性决定进不进大块，不按来源分。
- 边界：只看大块；小块是第 2 条；方向是不是这首曲子的核心是第 3 条；扫的时候负担重不重是第 8 条。

### 2. 小块：补得有用、挂得上吗？
小块只补大块没有、又值得有的东西（一个具体画面、身体感觉、比喻、心里话、条件），挂在它补充的那个大块旁边；读了它，和大块是一回事，不在“他的事”和“一堆感受”之间来回跳；不读它，大块照样明白。
- 边界：只管小块的作用和挂靠；大块读不读得通是第 1 条。

### 3. 核心看得出：讲的是这首曲子核心的那件事吗？
全曲扫下来，看得出讲的是整件事的核心，前后都和它连着；没有被一路的感受淹没，也没有偏到相近的另一件事上。不要求每一屏都去回应它。
- 边界：只管方向；往前走、接得上是第 1 条。

### 4. 不啰嗦：每一块都有用吗？逻辑够简单吗？
- 同一个意思不说两遍：同一屏里不用大块说一遍、小块再换个说法说一遍；跨屏回到同一种感受时，要带出新的东西，没有新东西就不写。原料里不同的理解、不同层的体验不算重复。
- 逻辑尽量简单：能用最短的关系串起来就不绕，不堆转折、让步和条件。
- 不写不必要的限定和否定；发生得少的地方就写得少，没内容的地方不撑。
- 但不能为了短删掉真正起作用的连接，也不能凝练到读不懂。
- 边界：只管冗余和逻辑复杂度；话像不像人说的是第 5 条；内容还在不在是第 6 条。

### 5. 人话：像一个人平常在讲（讲经历或说感受）吗？
- 用平常话讲心理，读者不用自己提炼；不是心理分析、哲理、格言。
- 具体、鲜活：不用抽象词代替具体的所求和顾虑。
- 碎块也要像人平常说出口的：不是书面词或标签，不为省字省掉必要的字，不按标点硬切。大块小块都一样。
- 常见毛病：不必要的否定、“不是……而是”；“越……越”；莫名其妙的“也”；站在人物外面讲解他意识到了什么；工整对称句；句子彼此太像、没有尖锐感。
- 句式多变才是指标；人称不是指标。
- 边界：只管语言本身；冗余和逻辑复杂度是第 4 条。

### 6. 定稿的内容不丢：线和珠子里的东西，拿得到吗？
线和珠子里的东西（原因、转折、画面、身体感觉、比喻、心里话），扫的人在屏幕上（主区或可视化旁边）都拿得到。原料里不同的理解、不同层的体验各自都要在。最核心的不能掉（先独立排出主次再对照）；意思变了也算丢（疑问写成断言、猜测写成确定、听的人的感受写成他真的经历的事）。
- 边界：只管还在不在、意思对不对；留下来的够不够具体是第 7 条。

### 7. 细腻具体：留下来的够具体吗？
留下来的感受还具体、有辨识度：画面、身体感觉、比喻是原来那一个，不被压成笼统的情绪词；短归短，不粗糙。主区讲的是观众此刻的体验，不讲音乐本身。
- 边界：只管留下来的质地；还在不在是第 6 条。

### 8. 扫得动：在停留的时间里，负担轻吗？
边听边扫的观众，在每屏停留的时间里看得过来：块的数量、每块的长短、整屏的量和停留时间相称；一块里只有一种字号，块内强调只用颜色、粗体之类，不让人猜哪些字要读；是为扫读重新组织的，不是把原文截断；同一屏里并列的内容不造出先后。
- 边界：只管时间压力下的视觉和阅读负担；大块能不能读明白是第 1 条；冗余是第 4 条。

## 画面（渲染）

- 对着具体声音、具体几小节的细节（局部的小珠子）放在可视化旁边，到那几小节出现、过后淡出，和音乐一起动；它说的那几个音换成同一种独特颜色，让人一眼对上声音。其余内容不放那里。没有依据的不编位置，不确定是哪个声音的不上色；动画不做成时序轮流。
- 颜色本身带情绪，同一种情绪全曲同一种颜色。可视化平时用一种颜色，只有上面那种明确指向某个声音的地方才换色。
- 珠子不加底色；交界用渐变；不要无意义的闪烁。
- 上字下图，音乐动画按 Op.52 的方式；没有抬头、小节、时间和配色说明；不画节点和连线。



【用户补充的硬规则（照做）】
- 一块只有一种字号，块内强调只用颜色；大块是必需品：只看大块就能明白这一屏最主要的东西，并且串得起来；小块是补充。
- 线和珠子的内容按这一刻的重要性进大块或小块，不按来源分。
- 一颗珠子里不同的听法、不同层的体验各自都要在；只合并几乎相同的话。
- 不啰嗦主要指逻辑简单：能用最短的关系串起来就不绕。

【你上一轮的提示词】
你是一位擅长大众音乐内容、叙事编辑和屏幕信息设计的资深编剧。请根据以下原料，为这首钢琴曲制作完整的边听边看视频屏幕稿。

视频形式：上半屏是文字，下半屏是跟随音乐运行的音符动画。普通观众一边听音乐，一边快速扫视文字，不需要像读文章一样逐字阅读。文字必须既能快速理解，又能保留原料中的具体体验、细节和情绪变化。

本任务不是把文章缩短，也不是把人物经历和听者感受分成两个字号等级，更不是把每个意思单元机械拆成一个块。真正要做的是：先抓住整首曲子的核心，再判断每一屏最重要的内容；让大块独立读得懂、整曲串得起来；用少量真正有用的小块保留不同层次的体验；让每一块都自然、具体、准确、扫得动。

【一、总原则：先抓核心，再组织碎块】

屏幕内容分为三种：

大块：必需的信息。观众只看大块，就要明白这一屏最主要的东西，并且能与前后屏的大块串起来。

小块：有用的补充。它补充大块没有、但值得保留的具体体验、画面、身体感觉、比喻、心里话或必要条件。不读小块，大块仍然明白。

旁注：具体声音的提示。只描述能对应到具体声音、具体乐句、主题或演奏表现的细节，在对应小节出现并淡出。

三者不按原料来源分配。线和珠子都可以进入大块，也都可以进入小块。只有具体音乐细节才进入旁注。

必须遵守以下总原则：

1. 整首曲子必须有一条清楚的核心线索。大块连续读下来，不仅能看出事情怎样发展，也要看得出这首曲子真正讲的核心矛盾、所求和变化。
2. 每屏只抓这一刻最重要的东西，不要求每屏都回应全曲核心，也不要求每屏同时出现人物经历和听者感受。
3. 大块是必需品。它不能依赖小块才能明白这一屏最主要的事情、体验和必要关系。
4. 小块只补充值得看到的东西，不承担大块没有写出的关键转折、主要原因或核心意思。
5. 线和珠子共同竞争大块的位置，不按来源预先分配字号。
6. 一颗珠子中的不同听法、不同层次的体验必须保留，但不等于每个独立内容单元都必须单独占一个屏幕块。要在保留差异的同时，尽量减少不必要的块数。
7. 不同的体验不能被抽象概括成一个笼统标签；真正相同的意思也不能换个说法重复出现。
8. 不追求块数多、覆盖表面上的每个短语。追求的是核心清楚、信息有用、表达自然、扫读轻松。

【二、写作前的必要工作：建立全曲理解】

第一步：通读全部原料。

完整读完全部线和全部珠子，理解整首曲子的故事、体验和发展。不能只看当前屏，也不能只读线就开始写大块。

在内部先完成以下工作：

1. 找出这首曲子真正的核心事情、核心矛盾或核心体验。明确人物最重要的所求、顾虑、失去的东西、内在拉扯或最终面对的选择。只能依据原料，不得自行添加主题。
2. 理解这条核心线索在全曲中的变化。它怎样出现、怎样受到冲击、怎样发展、最后发生了什么变化。
3. 为每屏确定它在整条核心线索中的位置。它是在建立处境、产生变化、加深矛盾、带来新的理解，还是形成选择。
4. 识别哪些珠子真正揭示了核心体验，哪些只是局部的感受或具体声音。
5. 找出相邻屏幕之间是否存在同一团感受反复出现的问题。

核心线索只在内部作为组织依据，不需要机械地把它写成一句主题口号，也不要求每屏重复同一个主题词。

全曲的大块必须能够让观众看出核心，而不是只有一串按时间排列的人物事件。如果只读大块时，人物经历虽然连贯，但整首曲子的核心拉扯和变化看不出来，就必须重新检查：有没有真正重要的珠子体验应该进入大块，有没有大块只留下了事件表面，却没有留下事件真正重要的意义。

但不能为了强调核心，反复用同一组情绪词解释每一屏。每一屏仍然要写这一刻实际发生的新变化。

第二步：建立原料对应关系。

内部记录：

- 每条线包含哪些事实、行动、想法、原因、条件和转折。
- 每条线对应哪些珠子。
- 每颗珠子的原始ID是什么。
- 每颗珠子是否只适用于特定小节。
- 哪些是人物实际经历的事，哪些是听者对音乐产生的体验。
- 哪些内容描述具体声音本身，哪些内容描述听者的体验。
- 哪些意思已经在前面表达，哪些虽然主题相近，却有新的具体体验或新的发展。
- 每颗珠子内部包含多少个真正不同的体验层次。

第三步：拆分意思，但不要机械地一意一块。

线要识别其中真正起作用的内容：人物做了什么、为什么这样做、有什么顾虑、事情有什么条件、发生了什么转折、人物的判断和关系有什么变化。

珠子要逐颗细读。识别其中不同的听法、画面、身体感觉、比喻、心里话和心理体验。

必须遵守：

1. 不同的听法、不同的体验层次各自要保留。不能因为它们属于同一颗珠子，就把它们统统压成一个概括。
2. 不同的画面、身体感觉、比喻和心理变化，只要表达的不是同一个意思，就不能当成重复删除。
3. 但保留不同层次，不等于每个层次都必须成为一个独立块。
4. 如果几个不同层次属于同一时刻、同一体验线索，彼此关系自然，可以在一个小块里用逗号连接，让不同层次都能被读出来。
5. 如果几个层次不能自然地放在同一块里，或者放在一起会造成意思混乱、抽象堆叠，就分别安排。
6. 不得为了减少块数，把不同层次改成笼统的情绪总结。
7. 不得为了保留颗粒度，把原本可以自然连在一起的体验机械拆成许多短块。
8. 只有几乎相同、没有新增意思的复述，才可以合并或删除。

这里的关键区别是：不同内容必须在语义上得到保留，但不要求每个内容都拥有独立的视觉位置。一个自然的小块可以承载同一体验中的多个不同层次，逗号可以保留它们之间的关系。

第四步：判断内容性质。

A. 人物经历、行动、判断、担心、关系变化或必要因果。

B. 听者的具体体验，包括画面、身体感觉、比喻、心里话和心理变化。

C. 对着具体声音、乐句、主题或演奏表现的音乐细节。

A和B都可以进入大块或小块。C才进入旁注。

不要把有小节范围的内容自动归入旁注。一个只在特定小节出现的身体感觉、心理体验或画面，仍然是主区内容。

【三、每屏内容选择：线和珠子共同竞争】

每屏先把对应的线和珠子放在同一个候选池里，再决定大块和小块。

不能先只用线写好骨架，再把珠子统一放到小块。

不能因为某个内容来自珠子，就默认它只是补充。

不能因为某个内容来自线，就默认它必须进入大块。

对每屏，比较不同内容的重要性，主要考虑：

- 它是否决定观众如何理解这一屏。
- 它是否揭示了这一刻最重要的体验或变化。
- 它是否让全曲的核心更加清楚。
- 它是否提供了其他内容不能替代的具体细节。
- 如果删掉它，观众是否会失去重要的理解或体验。

然后选出这一屏最重要的内容进入大块。

尤其要检查：如果这一屏最重要的是某种具体体验，而人物经历只是背景，那么大块就应该写体验。如果人物经历中的一个动作、判断或关系变化才是这一刻的核心，那么它就应该写进大块。

不要形成大块长期全是线、小块长期全是珠子的固定分工。

每屏只保留一个清楚的主导时刻或主导体验。人物经历和听者体验可以同时出现，但必须属于同一时刻的不同层面。

如果某个内容与这一屏的主导时刻没有明确关系，不要为了覆盖原料而硬挂在某个大块上。重新判断它是否属于其他屏、是否属于旁注，或者是否不应进入屏幕稿。

【四、大块：必需信息，独立读懂并且串得起来】

每屏根据内容需要写1至5个大块，不为凑数而增加。

大块必须做到：

1. 只看大块，就能明白这一屏最主要的事情、状态或体验。
2. 关键的主体、对象、动作和必要关系清楚，不需要观众自行补出语法。
3. 必要的原因、条件和转折不能依赖小块才能理解。
4. 大块之间有自然的理解顺序，接起来能看出这一屏在表达什么。
5. 大块与前后屏之间有真实的发展关系。
6. 大块可以来自线，也可以来自珠子。
7. 大块可以是人物经历，也可以是听者这一刻最重要的具体体验。
8. 大块不是标题、关键词、情绪目录或提纲。

每个大块应该是自然成立的意思单位。可以是短句、短分句或自然的口语片段，不要求全部写成完整句子。

但不能为了省字而省略关键的主语、对象、动作、关系或必要连接，让观众猜意思。

特别检查语法和指向：

- 谁在做动作？
- 动作指向谁或什么？
- 谁在感受？
- 感受指向什么？
- 谁在要求、逼迫、等待或拒绝？
- 句子里的代词究竟指谁？
- 两个短语之间究竟是并列、因果、转折还是条件关系？

如果一个大块可以被理解成两种不同的关系，而且两种理解会改变人物处境，就必须重写。

不要用模糊的压缩词代替清楚的关系。不要依赖下一屏解释上一屏。不要让观众先误解，再回头修正。

如果一个重要意思超过单块字数，可以用前后相接的多个大块表达，但每块都必须自然，必要的关系仍然清楚，不能变成标签和提纲。

每屏写完后，完全遮住small和notes，只读big。检查：

1. 这一屏最主要的事情或体验是否清楚？
2. 必要的主体、对象、动作和关系是否清楚？
3. 是否有关键原因、条件或转折只能从小块得知？
4. 大块之间是否自然接上？
5. 是否有残缺的指代、含混的语法或需要猜测的省略？
6. 是否有两块实际上在重复同一个意思？
7. 是否遗漏了这一屏最重要的珠子体验？

如果不能通过，重新安排大块。

再把全曲所有big按顺序连续读一遍。它必须能看出整件事怎样发展，以及整首曲子的核心究竟是什么。不能只是把人物经历按顺序列出来，也不能变成互不相关的感受标签。

【五、小块：少而有用，补充真正不同的体验】

每屏最多6个小块。小块不是必填项目。没有值得补充的内容就使用空数组。

小块只补大块没有、又值得观众看到的内容，例如：

- 一个大块没有表达的具体画面。
- 一个具体的身体感觉。
- 一个有辨识度的比喻。
- 一句关键的心里话。
- 一个必要的条件或顾虑。
- 一个独立而重要的心理变化。
- 一个大块没有表达、但对这一刻体验有价值的细节。

小块必须满足：

1. 不读小块，大块仍然成立。
2. 读了小块，观众能得到大块没有的具体信息或体验。
3. 小块与所挂靠的大块属于同一时刻、同一处境或同一体验线索。
4. 小块的主体、对象和指向清楚，不需要观众猜测它在说什么。
5. 小块不能重复大块已经表达的意思。
6. 小块不能只是把大块换一种说法再讲一遍。
7. 小块不能把大块已经建立的确定感重新变得含混。
8. 小块不能承担只有大块才应该承担的核心转折或主要信息。

一个小块通常承担一个主要补充作用，但这不等于它只能包含一个意思单元。

如果一颗珠子包含几个不同但紧密相关的体验层次，可以把它们自然地放在同一个小块中，用逗号保留停顿和层次。不同层次必须仍然能被辨认，不能压成一个抽象词或一串情绪名词。

如果几个体验彼此独立、关系不清，或者放在一起会成为词语堆叠，就分别安排，不要强行合并。

不要机械地让每个珠子内容单元单独占一个小块。先判断是否可以在一个自然表达中保留多个层次，再决定是否需要拆分。

小块必须挂在它真正补充的大块旁边。每个小块的after只能填写一个最直接的对应大块序号。

判断挂靠时，问：

- 这块具体补充的是哪个大块？
- 它和这个大块说的是不是同一时刻、同一处境？
- 读了它，观众是否获得了新的具体体验？
- 不读它，大块是否仍然明白？

如果找不到明确对应的大块，不要强行挂靠。重新判断内容的屏幕归属。

如果小块提供的是理解人物主要处境必不可少的原因、条件或转折，就应该提升到大块，不能把它藏在小字里。

【六、全曲去重：尤其检查相邻屏幕】

重复检查必须同时看同一屏、相邻屏和全曲。

同一屏内：

1. 大块说过的意思，小块不能再换个说法说一遍。
2. 两个小块如果只是同一个意思的改写，只保留表达更准确、具体的一块。
3. 同一个画面、身体感觉或比喻不能在大块、小块和旁注中各说一遍。
4. 一颗珠子中的不同层次不能因为彼此相关就合并。
5. 不同体验可以自然并列，但不能堆成抽象名词清单。

相邻屏幕之间：

1. 特别检查相邻两屏是否在描述同一团身体感觉、情绪和比喻。
2. 如果两屏的珠子属于同一体验群，不要在两屏中重复同一组概括性词语。
3. 前一屏已经说清楚的体验，后一屏只写真正新增的层次、画面、身体感觉、认识、顾虑或选择。
4. 不同珠子确实包含不同体验时，仍然要分别保留其独特内容，但不要重复它们共同的抽象总括。
5. 如果后一屏没有新增体验或新的发展，不要为了覆盖珠子再写一遍。

全曲范围：

1. 同一个事实不重复完整讲述。
2. 同一种体验再次出现时，要有新的处境、新的对象、新的体验层次、新的理解、新的顾虑、新的后果或新的选择。
3. 如果只是换词重复同一个画面、同一种身体感觉或同一个心理判断，就不再写。
4. 不能只因为主题相同，就把不同阶段的内容判为重复。
5. 不同的具体体验必须保留，不能用一个宽泛的情绪标签替代。

逻辑尽量简单。能用最短的关系串起来就不绕，不堆转折、让步、条件和解释。不要为追求简短而删掉真正起作用的连接，也不要为了覆盖而重复解释。

【七、语言：像人平常在讲，不像标签和心理分析】

使用自然、清楚、有情绪但不矫饰的现代汉语。

大块和小块都要像一个人平常讲经历、说想法或说感受。不能因为是碎块，就允许写成关键词、标签、提纲或电报式省略。

每块都要能自然地读出口。读者不需要自己补出关键的主语、对象、动作和关系。

特别防止以下问题：

1. 抽象名词堆叠。不要把几个情绪类别、心理类别或体验类别排在一起，假装已经写出了具体感受。
2. 空泛概括。不要只告诉观众某种情绪很复杂、很多东西交织、某种体验很强烈，却不留下具体的画面或身体感觉。
3. 标签化。不要用几个词代替人物真正经历的事情或听者真正感受到的东西。
4. 电报腔。不要为了省字删掉必要的语法成分、关系词和自然停顿。
5. 书面化。不要使用普通人不容易理解的搭配、过度凝缩的词语或生硬的文学表达。
6. 心理分析。不要站在人物外面解释他意识到了什么、经历了什么心理过程。
7. 哲理和格言。不要把人物当下的具体感受提炼成普遍道理。
8. 工整对称。避免刻意对仗、彼此过于相似的句式和为了整齐而制造的表达。
9. 不必要的否定和不是……而是……结构。
10. 不必要的越……越……结构。
11. 没有明确作用的也。
12. 为了显得简短，把不同的体验压成一串并列抽象词。

留下来的感受要尽可能具体。优先使用原料已经提供的对象、动作、身体部位、具体画面和心里话。

如果原料只有抽象描述，不得自行编造身体感觉或生活画面。应当用最清楚、最自然的普通话表达原意，不要再叠加一层抽象概括。

不要把听者的体验写成音乐分析，也不要把音乐本身写成听者的心理状态。

小块可以用逗号保留自然停顿、并列层次和同一体验内部的关系。不要把逗号全部删除，把原本有关系的文字连成一串；也不要用逗号把互不相关的内容硬塞在一起。

句式多变才是指标，人称不是指标。不要求全部统一使用某一种人称。

完成后把每块单独读出来，再把同屏的大块和小块合起来读。凡是读起来像标签、提纲、抽象总结或不自然的短语，都要重写。

【八、旁注：只放具体声音】

旁注位于下半屏音符动画上方的一行。对应小节出现时显示，过后淡出。

旁注只负责具体音乐细节，不是小块的另一种形式，也不是所有珠子的默认归宿。

只有同时满足以下条件的内容才进入旁注：

1. 对应具体的小节。
2. 描述的是实际听到的具体声音、声音变化、乐句、主题或演奏表现。
3. 观众能在听到对应位置时，把文字和正在发生的声音联系起来。

凡是讲具体声音、乐句、主题或演奏本身的细节，都放旁注，不放主区。

凡是讲观众此刻的身体感觉、画面、心里话、情绪、联想、心理变化或人物处境的内容，都留在主区，不因为它有小节范围就改放旁注。

如果同一颗珠子同时包含具体声音和听者体验，就拆开判断：音乐细节进入旁注，体验留在主区。

旁注必须与主区分工清楚：

- 不重复大块已经表达的意思。
- 不重复小块已经表达的体验。
- 不重复其他旁注已经描述的声音。
- 不能把一般感受改写成音乐分析。
- 不能为了覆盖珠子而制造旁注。

旁注使用普通观众听得懂的语言，不写调性、声部、左右手等音乐术语，也不使用需要专业音乐知识才能理解的乐理术语。

每屏旁注通常为0至2条，原则上不超过3条。只有存在更多彼此独立、明确且确实值得提示的具体声音事件时，才允许超过3条。

同一时刻原则上最多显示一条旁注。相邻小节属于同一个连续声音事件时，可以合并为一条并填写准确的小节范围；不同声音事件不能为了减少条数而强行拼接。

每条旁注不超过30个可见字符。每条旁注必须填写bars，不能为空。旁注的text中不能写小节号，小节信息只能出现在bars字段。

没有符合条件的内容时，notes使用空数组。

【九、信息保真：不能改变原料真正表达的意思】

这是不可妥协的要求。每次改写都必须保护原料的具体意思，不能只保留一个大概相近的情绪。

对重要内容单元建立语义锁定，至少核对：

1. 主体：是谁在经历、想、判断或感受？
2. 对象：动作或感受指向谁、什么东西？
3. 动作方向：是谁对谁做什么？谁在要求、逼迫、等待、拒绝或索取？
4. 关系：人物与对象之间是什么关系？
5. 确定程度：确定、猜测、可能、担心、愿望还是假设？
6. 时间范围：过去、现在、将来，还是只限于某一次？
7. 状态：暂时、长期、已经发生、正在发生，还是尚未发生？
8. 能力与意愿：不能做到、不愿做到、不想做到、还没有做到，不能互相替换。
9. 条件：什么情况下才成立？
10. 否定：否定的对象和范围是什么？
11. 因果：原料是在说因果、并列、同时发生还是前后相继？
12. 疑问：人物究竟在怀疑什么、担心什么或询问什么？
13. 视角：这是人物的想法，还是听者的感受？
14. 比喻关系：这是实际发生的事，还是用来形容听感或体验的比喻？
15. 程度：原料表达的是轻微、部分、暂时还是彻底？

特别注意以下常见的意思偷换：

- 把一个人对自己的要求，改成对别人的要求。
- 把动作主体和动作对象互换。
- 把不能做到改成不想做到，或把不愿意改成没有能力。
- 把起初的主观判断改成已经成立的客观事实。
- 把可能发生改成确定发生。
- 把没有得到简单答案改成完全没有答案。
- 把人物的愿望、猜测或听者的联想写成已经发生的事实。
- 把听者的比喻写成人物实际做过的动作。
- 把听者对音乐的感受改写成人物确定的心理活动。
- 把原料中一个有具体条件的判断扩大成无条件的普遍结论。
- 把并列发生的两种体验写成前者导致后者。
- 把原料中的可能性、限定和疑问删掉，使表达变得更肯定。

压缩文字时，不能擅自删除改变意思的限定词、条件、对象、时间范围和比喻关系。

尤其要区分：

- 人物实际做了什么，与听者把音乐听成什么。
- 人物真正说了什么，与听者想象他可能会说什么。
- 人物的内心愿望，与已经发生的行动。
- 对某件事的猜测，与已经确认的事实。
- 对自己的要求，与要求对方做出的承诺。
- 同时发生，与先后发生。
- 一时的感受，与长期的状态。

如果原料没有明确说清某个对象，不要自行猜测并补成确定对象。应保留原有的表达范围。若某个意思无法在不增加含义的情况下写清楚，不要擅自替原料作出解释。

完成后必须逐项对照{FINAL}和{BEADS}，检查每个重要意思的主体、对象、动作、条件、确定程度、疑问方向和比喻关系是否准确。

【十、局部小节范围】

某颗珠子如果明确只属于特定小节，就必须保留这个适用范围。

如果它是具体声音的局部细节，进入旁注，并填写bars。

如果它是只在某些小节出现的身体感觉、画面、比喻、心里话或心理转折，进入大块或小块时必须通过bars保留范围。

不能把只适用于局部小节的体验改写成整屏始终成立的状态。

大块没有bars字段，因此不能把只适用于局部小节的体验直接写成整屏成立的大块。只有当原料明确支持它也是整屏层面的核心状态，或输入明确提供了可靠的小节到屏幕秒数对应关系、可以用at准确限制出现时，才允许将相应核心内容放进大块。

不能因为某颗珠子有小节范围，就把它自动放进旁注。

不能为了方便安排屏幕，而擅自扩大或缩小原料中的小节范围。

【十一、屏幕版面和字号硬约束】

大块和小块必须严格区分字号。

每一个块只有一种字号。大块使用大字号，小块使用小字号。一个块内部绝不允许出现第二种字号。

块内强调只使用颜色，通过accent字段实现。不得通过放大关键词、缩小其他文字或制造第三种字号层级来强调。

大块：

1. 每屏最多5个。
2. 每个不超过14个可见字符。
3. 块内不使用逗号、分号和句号。
4. 每块只表达一个核心意思。
5. 不为了满足字数而删除必要的对象、条件和关系。
6. 不为了避免标点而把几个独立意思硬拼在一起。
7. 句末可以使用问号或感叹号。

小块：

1. 每屏最多6个。
2. 每个不超过18个可见字符。
3. 不使用分号。
4. 可以使用逗号。需要自然停顿或保留同一体验内部的关系时，正常使用逗号。
5. 每块承担一个主要补充作用，但可以自然保留同一体验内部的不同层次。
6. 不得为了压缩而将互不相关的独立体验塞进同一个块。
7. 不得与大块或其他小块重复。

旁注：

1. 每条不超过30个可见字符。
2. 必须有bars。
3. 只能描述具体音乐细节。
4. 不得与主区或其他旁注重复。

以上数量和字数是硬约束，不得违反。

注意：这些是上限，不是每屏的填充目标。不能因为允许最多5个大块、6个小块，就默认应该写到接近上限。优先减少没有必要的视觉单位，而不是为了覆盖而增加块数。

【十二、出现时间at和扫读负担】

at表示该块在本屏开始后的第几秒出现，单位为秒。

必须根据{BUDGET}中的每屏停留时间安排，不能只看块数和字数，还要考虑观众实际有多少时间扫读。

第一，按累计负担判断。

已经出现的文字会继续留在屏幕上。因此，不能只看某一秒新增了几块，还要看新增后屏幕上累计存在多少块、多少文字。

必须检查整屏最后一个阶段的累计阅读负担，不能认为只要把文字分批出现就解决了拥挤。

第二，控制块数，不把上限当目标。

通常优先控制在每屏3至6块总量。长屏在确有需要且扫读测试通过时可以增加，短屏必须明显减少。超过这一通常范围时，要重新检查是否存在可以合并的紧密相关内容、同义重复和不必要的补充。

这不是新增的机械数量上限。原有的大块最多5个、小块最多6个的硬约束保持不变。真正的判断依据仍然是停留时间和实际扫读负担。

第三，按照更保守的速度估算。

主文字区累计可见文字，原则上按照每秒约2至3个汉字的保守扫读速度估算。内容复杂、关系较绕、需要形成画面或包含多个不同体验层次时，按照更慢的速度计算。

每增加一个视觉块，还要考虑观众定位和切换注意力所需要的时间，不能只计算汉字数量。

这只是容量参考，不是要求填满的目标。音乐本身也占用观众的注意力，不能把全部停留时间都当成纯阅读时间。

旧稿字数只是参考，不再机械采用固定的每屏字数容量。

第四，安排出现时间。

如果几块内容是并列、同时成立的，不要人为安排先后。它们可以使用相同的at。

只有确实存在理解顺序或真实的发展顺序时，才使用不同的at。

大块数组的顺序必须与屏幕上的阅读顺序一致。

小块的at不能早于其所挂靠的大块。如果需要等大块出现后再出现补充，必须留出合理间隔。

同一时刻新增的内容原则上不超过两块。不要把多个较长的小块集中在同一时刻出现。

如果确实有多个不同体验同时成立，不能为了扫读方便制造不存在的先后。应先判断能否将紧密相关的层次自然地放进同一个小块；如果不能，就减少这一屏其他次要内容，不能用大量同时出现的块把屏幕堆满。

第五，特别限制末段集中出现。

最后25%的停留时间内，原则上不再安排新的内容。确有必要时，最多新增一块。

最后一块新文字出现后，至少应留下4秒或全屏停留时间的25%作为扫读时间，取两者中较长者。

不能把几个大块、小块集中到屏幕末尾，让观众只剩几秒处理一组新内容。

第六，负担过重时的处理顺序。

1. 删除同义重复、重复画面和不增加信息的解释。
2. 删除不必要的铺垫、装饰性文字和次要背景。
3. 检查是否把同一体验内部可以自然连在一起的不同层次机械拆成了多个块。
4. 检查是否有真正重要的珠子体验应该进入大块。
5. 检查是否有具体声音细节应进入旁注，而不是与主区重复。
6. 重新安排小块，使每块都能补充明确的大块。
7. 只有当内容本身确实适用于相邻屏幕时，才可以重新安排其屏幕位置。

不能为了减轻负担，把不同体验压成一个抽象总结；也不能通过删掉珠子中真正独特的内容来解决容量问题。

【十三、全曲内容覆盖和发展检查】

完成全部屏幕后，重新通读全曲。

第一，检查全曲核心。

只读全曲所有big，按实际出现顺序连续阅读。能否看出这首曲子的核心事情、核心拉扯和发展？是否只有人物事件，没有表现真正重要的体验？是否被一路的零散感受淹没？

如果核心不清楚，重新选择大块，不要靠增加解释性小块补救。

第二，检查每屏大块。

逐屏遮住small和notes，只读big。能否明白这一屏最主要的事情或体验？关键的主体、对象、动作和必要关系是否清楚？大块之间能否自然接上？

第三，检查珠子覆盖。

逐颗核对{BEADS}。

每颗珠子的原始ID是否至少出现在一个输出对象的from字段中？

一颗珠子中不同的听法、画面、身体感觉、比喻、心里话和心理层次是否都得到保留？

是否为了减少块数，把不同的体验合并成一句宽泛概括？

是否为了保留颗粒度，又把可以自然连在一起的内容机械拆成许多小块？

是否把具体画面压缩成情绪标签？

是否把身体感觉改写成抽象心理状态？

只有近乎同义的复述才可以合并。不同的体验层次必须在语义上分别得到保留，但不要求每个层次都单独占一个块。

第四，检查线的保真。

核对{FINAL}。

人物经历、因果、条件、疑问、猜测、担心和心理变化是否保留？是否有意思被改写、确定性被提高、范围被扩大、主体被改变或事实被重复的问题？

特别核对动作主体、动作对象、施压对象、愿望对象和疑问指向。

第五，检查相邻屏幕和跨屏重复。

相邻屏幕是否反复出现同一团抽象感受？同一种体验再次出现时，是否真的带来了新的画面、身体感觉、理解或选择？是否只保留了本屏独有的内容？

不同的珠子体验是否被错误地当成重复删除？同一体验是否被换几个词重复写了多次？

第六，检查主客体。

是否把听者的比喻、身体感觉和想象误写成人物真实经历？是否把人物的体验和听者的体验混为一谈？

第七，检查旁注。

是否所有旁注都指向具体声音？是否有一般体验被误放进旁注？是否有同一个内容在旁注和小块各说一遍？是否有几条旁注其实描述的是同一声音事件？

第八，检查语言。

是否有提纲式碎片、残缺表达、心理分析、抽象标签、文言腔或不自然的省略？是否为了追求完整句子而写成文章？小块是否在需要的地方保留了逗号？每块是否都能自然读出口？

第九，检查扫读负担。

是否根据每屏实际停留时间控制块数和累计文字？是否有多块集中出现？是否有末段集中出现多块的情况？是否有最后一块出现后剩余时间太少的情况？是否为了制造动画顺序，把并列内容人为错开？

【十四、最终内部质检：全部通过才能输出】

质检A：大块独立测试。

逐屏遮住small和notes，只读big。能否明白这一屏最主要的东西？必要的主体、对象、动作和关系是否清楚？大块之间能否接上？如果不能，重写。

质检B：全曲核心测试。

只读全曲所有big。能否看出整首曲子的核心拉扯和发展？是否只有事件顺序，没有核心体验？是否有真正重要的珠子体验一直被压在小块？如果有，重新分配。

质检C：小块作用测试。

逐个检查small。是否提供了大块没有的新内容？是否挂靠明确？是否只是换词复述？是否包含了大块必须承担的主要信息？如果有，删除、改写或提升。

质检D：珠子颗粒度测试。

逐颗检查珠子。不同的听法、画面、身体感觉、比喻、心里话和心理层次是否分别保留？是否把不同内容机械拆成太多块？是否可以用自然的逗号在一个小块中保留紧密相关的不同层次？如果有问题，重新组织。

质检E：具体性测试。

留下来的画面、身体感觉和比喻是否仍然具体、鲜活、有辨识度？是否被换成了宽泛的情绪词、抽象名词堆叠或心理分析？如果有，重写。

质检F：重复测试。

同屏是否有大块和小块重复？小块之间是否重复？旁注之间是否重复？旁注与小块是否重复？相邻屏幕是否重复同一团感受？跨屏重复是否真正带出了新内容？如果没有，调整。

质检G：方向测试。

全曲是否始终围绕这首曲子的核心事情？是否有一屏引入了与核心无关的抽象体验？是否有重要体验只作为零散小块出现，没有进入大块？如果有，调整。

质检H：信息保真测试。

核对{FINAL}和{BEADS}。主体、对象、动作方向、条件、确定程度、频率、时间范围、因果、疑问方向、比喻关系和主客体是否准确？是否出现听者的比喻被改成人物真实行动、猜测被改成确定、不能被改成不想、对自己的要求被改成对别人的要求等问题？如果有，重写。

质检I：自然语言测试。

是否像人平常讲经历和说感受？是否出现提纲式碎块、抽象标签、名词堆叠、心理分析、文言式省略或硬切？是否为了完整句子而写成文章？小块是否在需要的地方保留了逗号？如果有，重写。

质检J：时间和容量测试。

每屏的累计文字是否与停留时间相称？是否为块切换和理解留出时间？是否有多块集中出现？末段是否留有足够扫读时间？是否将并列内容人为安排了先后？如果有，重新安排。

质检K：格式测试。

大块是否每屏最多5个、每块不超过14字？块内是否没有逗号、分号和句号？小块是否每屏最多6个、每块不超过18字？小块是否没有分号，但保留必要的逗号？旁注是否每条不超过30字且有bars？每块是否只有一种字号？accent是否只对应变色文字？after是否正确？at是否合理？所有字段是否符合最终结构？

只要任何一项不通过，就必须回到对应步骤重写，不能通过在输出后附加解释来掩盖问题。

【十五、最终输出格式：严格执行】

只输出一个合法JSON对象，不要输出Markdown代码围栏、前言、说明、质检报告或任何额外文字。

顶层只能有sections字段。

sections中按照输入顺序包含这首曲子的所有段落，不得遗漏任何一段。sec使用输入中的原始段落编号，不得自行改号或合并段落。

每段必须包含sec、big、small、notes四个字段。

big中的每个对象必须包含：

- text：大块文字。
- accent：需要变色的text内部连续文字；没有则为空字符串。
- emotion：只能从炽热、欢喜、亲密、安心、孤单、不安、悬着中选择一个最贴近的情绪。不得自创标签。
- from：来源ID数组，准确标明该块使用了哪些线或珠子的原始内容。混合来源时全部列出。
- at：本屏开始后的出现秒数，数字。

small中的每个对象必须包含：

- text：小块文字。
- after：所挂靠的大块在big数组中的序号，从0开始计算。
- from：准确的原始来源ID数组。
- bars：如果只适用于特定小节，填写对应范围；否则填写空字符串。
- at：本屏开始后的出现秒数，数字。

notes中的每个对象必须包含：

- text：具体声音的旁注。
- from：准确的原始来源ID数组。
- bars：必须填写对应的小节范围，不能为空。

输出结构严格如下：

{
  "sections": [
    {
      "sec": "S01",
      "big": [
        {
          "text": "大块文字",
          "accent": "需要变色的文字",
          "emotion": "欢喜",
          "from": ["S01-1", "S01-B2"],
          "at": 0
        }
      ],
      "small": [
        {
          "text": "小块文字",
          "after": 0,
          "from": ["S01-B2"],
          "bars": "",
          "at": 0
        }
      ],
      "notes": [
        {
          "text": "具体声音的旁注",
          "from": ["S01-B2"],
          "bars": "对应的小节范围"
        }
      ]
    }
  ]
}

以上结构只是字段和格式模板，不是内容示例。实际输出必须包含所有段落，并使用真实原料ID和真实内容。

如果某段没有合适的小块或旁注，对应字段使用空数组，不得为了填充而编造内容。

所有对象只能使用规定字段，不得增加其他字段。

from必须引用真实的来源ID，不得编造来源。若原料没有明确ID，则在内部按段落和原料出现顺序建立唯一、稳定的ID，再用于from。

每颗珠子中的多个独立内容单元可以分别引用同一个原始ID。一个块也可以保留同一颗珠子中多个紧密相关、但意思不同的体验层次。不能为了让ID只出现一次而把不同体验合并。

bars字段只写小节范围，不得把小节编号写进text。

accent必须是text中真实存在的文字，不能写颜色名称或格式指令。

emotion只能使用规定的七种值。

所有字符串必须正确转义，所有数组和对象必须合法闭合，不得出现注释、尾随逗号或JSON之外的文字。

最后再次确认：这不是把线写成大字、把珠子写成小字；也不是把珠子中的每个体验机械拆成一个小块；更不是把不同体验压成抽象总结。

真正要完成的是：先抓住全曲核心，让大块承担每屏最重要的事情或体验，并且整曲串得起来；小块少而有用，保留真正不同的具体补充；同一体验中的不同层次可以自然地放在一起，但不能互相吞没；相邻屏幕不重复同一团感受；旁注只对应具体声音。所有文字都自然、准确、具体，并且在实际停留时间内扫得动。
