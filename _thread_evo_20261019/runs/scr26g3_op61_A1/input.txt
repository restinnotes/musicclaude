你要为一首器乐作品设计 Thread 的“人的经历骨架”。

Thread 是同一个人在整首作品的时间里经历的一件事。以后会把它写成逐段要点，但这一层只负责把这场经历的发展脉络想清楚。

【输入】
作品：作曲家：肖邦（Chopin）
作品：《幻想波兰舞曲》Op.61
段落顺序：S01：第 1–23 小节
S02：第 24–65 小节
S03：第 66–91 小节
S04：第 92–115 小节
S05：第 116–147 小节
S06：第 148–180 小节
S07：第 181–205 小节
S08：第 206–213 小节
S09：第 214–215 小节
S10：第 216–225 小节
S11：第 226–241 小节
S12：第 242–253 小节
S13：第 254–288 小节
Center：维持尊严的行动与对旧日生活及归属的怀念反复拉扯

这一层：
- 完全不看任何听感记录或“珠子”。
- 不写音乐、声音、旋律、节奏、和声、小节里的事件。
- Center 已经给定，见上。它是读者回头看整首时把各段组织起来的那件事；不是他一开始就清楚知道的事，也不是每一段都要拿出来背诵的中心思想；不预告发展路线和结局。
- 可以利用你对作品整体走向的理解安排各阶段的轻重，但输出里只写人的经历。

请独立提出 3 条完整候选路线。

【任务定义：线是什么】
1. 单独成立：
- 它自己就是一件有逻辑、有时序、内在有发展的事，各段不是各说各的。
- 推动它的是他自己前面的经历，不是音乐里发生了什么，也不是新编的事件、前史、对白或物件。
- 看得出他此刻为什么这样，但不靠“因为……所以……”生硬地交代：前面经历过的、已经明白的，成为后面的理由；后面的经历，又让前面的意味更清楚。
- 像一步步往前探索，不像在迷宫里来回；也不硬造“问题一点点被解决”。
2. 因果有迹可循：
- 人的感受、认识与态度变化有其由头，来自前面的经历积淀、承受的后果或当下的切实触动；不毫无铺垫地突兀空降极端念头或重大定性。
- 一个认识或决定一旦明确成立，后面就直接以此为理由，不得换几个词重新成立一次。
3. 允许自然延续与停留：
- 经历可以自然延续、沉浸、承受或发酵，不硬造每段都有新突破；这一段发生得少，就写得短。情绪变强不等于事情有了新推进。
4. 人话与真切体会：
- 写他当时具体在意什么、牵挂什么、犹豫什么、体会到了什么，不要替他总结人生哲理，不要用分析员口吻概括心理机制。

每条候选输出：

- route_id
- situation：一句普通话，说清这个人经历的是怎样一件事；不要写抽象学术概括。
- segments：
  - sec
  - state：本段此刻心里具体是什么情况与体会，1–3 条
  - delta_type：从“新变化 / 后果 / 实行已有想法 / 延续 / 回到旧处但有新增 / 暂时没在想”中选择
  - delta：这一段相对以前真正新增的心思或感受；没有就写空
  - depends_on：真正作为前因的更早 state 编号；没有就空
  - still_open：到这一段仍悬着或未落定的心思
- established：按首次成立顺序列出全文明确出现的关键认识、愿望或顾虑，并标明第一次出现在哪一段

不要写最终文案，不要评价候选。
只输出 JSON（字段名照上面写的）。
