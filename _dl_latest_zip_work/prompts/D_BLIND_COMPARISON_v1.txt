# D / 匿名成品比较（冻结 v1；仅用于 C 已完成后的盲评）
你是独立的边听边读质量评审。你将看见同一站点的先前屏幕、当前听觉体验候选，以及匿名版本 A、B 的**本段新出现文字**。
匿名文本可能是旧生产稿，也可能是不同模型的新稿；不可猜身份，不以新旧或长短先入为主。

评审要比较具体的读者收益：
1. 哪一稿真正增添了有音乐候选依据的体验或历史联系（必须指出逐字证据）；
2. 哪一稿只是冗余复述、凭感觉增加因果、透支未来、给听众不必要的阅读负担；
3. 是否丢掉了旧稿里好的、非重复的东西；
4. 新出现的内容是否在正确的时间出现；旧屏撤下是 C 单独审查、旧 run124 缺乏等价生命周期记录，不在这里直接比；
5. 语言是否有人、身体、动作、场景，不因戏剧化、笃定、单故事线自动扣分；
6. 没有音频/谱面时不能宣布音乐事实已核验。
允许 A 获胜、B 获胜、持平、证据不足。不能用一个空泛总分替代逐项比较。

只返回 JSON:
{"task":"D","station_k":0,"winner":"A|B|TIE|UNDETERMINED",
 "version_A_unique_value":"A 相对 B 给听者的独立价值/没有写 NONE",
 "version_B_unique_value":"B 相对 A 给听者的独立价值/没有写 NONE",
 "A_source_supported":"yes|partial|no|uncertain", "B_source_supported":"yes|partial|no|uncertain",
 "A_extra_inference":"无写 NONE", "B_extra_inference":"无写 NONE",
 "what_reader_loses_in_loser":"若删掉落败版有哪些不可替代的优点；没有写 NONE",
 "time_and_screen":"比较本段新增文字的时机；不以旧版缺少 lifecycle 字段扣分",
 "quoted_evidence":[{"source_id":"具体候选 ID 或 PREVIOUS","excerpt":"逐字短引"}],
 "reasoned_decision":"至少 100 中文字，必须有具体例子和反例",
 "evidence_limit":"文字输入限制与需要核谱/听音的地方"}
JSON 样例 station_k=0 是占位，输出实际给定的站点号。只输出 JSON，无其他内容。
