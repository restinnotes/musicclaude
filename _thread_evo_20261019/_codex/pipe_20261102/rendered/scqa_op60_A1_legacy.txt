你要为一首器乐作品设计 Thread 的“人的经历骨架”。

Thread 是同一个人在整首作品里经历的一件事。以后会把它写成逐段关系图，但这一层只负责把这件事本身想清楚。

【输入】
作品：作曲家：肖邦（Chopin）
作品：《船歌》Op.60
段落顺序：S01：第 1–3 小节
S02：第 4–16 小节
S03：第 17–23 小节
S04：第 24–34 小节
S05：第 35–39 小节
S06：第 40–50 小节
S07：第 51–61 小节
S08：第 62–71 小节
S09：第 72–77 小节
S10：第 78–83 小节
S11：第 84–92 小节
S12：第 93–102 小节
S13：第 103–110 小节
S14：第 111–116 小节

这一层：
- 完全不看任何听感记录或“珠子”。
- 不写音乐、声音、旋律、节奏、和声、小节里的事件。
- 不写正式 Center。Center 会在最终 Thread 写完后再归纳。
- 可以利用你对作品整体走向的理解安排各阶段的轻重，但输出里只写人的经历。

请独立提出 3 条完整候选路线。

每条路线必须从头到尾只是一件事。可以没有具体外部事件；不要新增聚会、书信、物件、对白、地点、职业等情节来推动变化。

最重要的规则：

1. 前面已经发生过、相信过、期待过、得到过、失望过的东西，才可以成为后面此刻这样想或这样感受的根据。

2. 不要默认采用“试一个办法 → 不管用 → 换一个办法”的发展。一个人可以只是经历、等待、沉浸、意识到后果、把以前的事看得更清楚，或者暂时不想这件事。

3. 一个认识、决定或问题一旦已经明确成立，后面不能再次把同一件事写成第一次成立。
如果后来回到类似的地方，必须明确写出这一次新增了什么；没有新增内容，就标成延续，不要制造第二次转折。

4. 不要求每段都有新认识。有些段落可以只是：
- 已经存在的感受继续存在；
- 某件已经知道的事真正落到自己身上；
- 暂时沉浸在别的感受里；
- 前面的某件事产生后果。
不要为了填满段落制造心理动作。

5. 特别区分“情绪变强”和“人物处境发生了新变化”。
情绪更强本身不算新的认识或决定。

6. 不要让人物不停总结自己。优先写他当时具体在意什么、盼什么、犹豫什么、已经知道什么、还不知道什么。

7. 结尾不必解决问题，也不要为了有终点而制造决心、原则或人生结论。

8. 同一路线中要保存一份“已经成立的事实账本”。后面的段落不得违背它，也不得把其中已经完成的变化重新完成一次。

每条候选输出：

- route_id
- situation：一句普通话，说清这个人正在经历的是哪一件事；不要写抽象论文标题。
- segments：
  - sec
  - state：本段此刻实际是什么情况，1–3 条
  - delta_type：从“新变化 / 后果 / 实行已有想法 / 延续 / 回到旧处但有新增 / 暂时没在想”中选择
  - delta：这一段相对以前真正新增了什么；没有就写空
  - depends_on：真正作为前因的更早 state 编号；没有就空
  - still_open：到这一段仍未解决或仍不知道的东西
- established：按首次成立顺序列出全文的重要事实、认识、愿望或选择，并标明第一次成立在哪一段

不要写最终文案，不要写 Center，不要评价候选。
只输出结构化结果。
