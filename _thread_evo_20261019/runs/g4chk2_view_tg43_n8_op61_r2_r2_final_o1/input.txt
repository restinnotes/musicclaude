  - ← 改写：（1–23）「摇摆难堪」
- → 没有保证，牵挂也没消失；可一旦动起来，他真切地觉得自己有了力量。
- → 过去总问值不值得，如今至少能说：“我愿意尽力。”
- → 这让他有些骄傲：心里仍有疑虑，也可以不让疑虑替自己做主。
- → 越投入，他越热切；付出的过程本身就让他快乐，仿佛心里的不满终于有了去处。
- → 他愿意给得更多，甚至有些贪恋把全力用上的畅快。
- → 不再时时审视自己，也不想每遇一点软弱就停下来。
- → 可用力到了深处，心里偶尔有一小块始终没跟着高昂起来。
- → 它没拦住他继续，却提醒他：这份坚决还没顾到所有牵挂。　✦ 满足照出未满足

### 66–91　（没在想）

- 认真投入过一回，反倒让他能从反复自问里松开一点。
  - ← 提供理由：（24–65）「付出带来快乐」
- → 原来除了沉重和责任，他也会因不再畏缩而高兴。
- → 向前的热情让他感到轻盈；偶尔忘了用力的缘由，他也不觉得那是背叛。
- → 他顺着这份自由走了一程，没有急着给它更大的意义。
- → 等快乐淡下去，先前那个决定又回到眼前，等着他重新面对。

### 92–115　（正在面对）

- 他重新看向那个决定，还是愿意坚持；毕竟它曾把自己从动弹不得的犹豫里带出来。
  - ← 唤起：（66–91）「决定重新出现」
  - ← 提供理由：（24–65）「停止等待」
- → 那阵轻快也确实发生过，他不肯因心里有缺口，就把先前一切判成错的。
- → 可曾让他昂起头的坚定，如今安不了心；越想确认自己有力量，越听见心里另一个要求。
- → 他终于得承认这个不情愿的答案：行动值得，却仍然不够。　✦ 满足照出未满足

### 116–147　（正在面对）

- 行动明明还不够，他却不肯撒手——它曾把他从犹疑里救出来。
  - ← 提供理由：（92–115）「决定仍值得坚持」
- → 他怕眼下的失望说明自己变了心，于是把力气用得更狠。
- → 明知自己正受苦，他仍把难处当成必须克服的迟疑；想停一下，又怕辜负最初的决意。
- → 最初让他昂然的要求，渐渐连脆弱也容不下，终于变成苛责。　✦ 办法的限度
- → 越想维持坚定，他越像在逼一个疲惫的人硬撑；终于，他不想再证明自己有多坚强。
- → 放下催逼没有立刻带来安心，却给一直压着的依恋留出回来的空隙。
- → 他有些茫然，也松懈下来，终于肯承认：除了必须做的事，他还有真心舍不得的东西。

### 148–180　（没在想）

- 催逼停下后，那份依恋才显出原样：他想要的，是一种曾真心相信过的生活。
  - ← 说明：（116–147）「承认有所不舍」
- → 在那种生活里，人不必时时防备，珍贵的东西也不必靠争夺才能留下。
- → 他盼着人不必反复证明自己值得被爱、被接纳，付出也可以只是因为喜欢。
- → 靠近珍惜的人和事时，也不必先做好受伤的准备。
- → 这样的相信曾给过他快乐，让他觉得人与生活可以亲近，不必靠时时用力维持。
- → 那些感受确实真实过，所以他没法把这份盼望贬成不切实际的软弱。
- → 这回他终于让爱惜本身留下，不再先拿责任盘问它，也不急着证明它有用。
- → 他暂且不问这种生活能否实现，也不比较它和眼前的坚持孰轻孰重。
- → 只是允许自己这样去爱、去相信，满足便慢慢涌上来，那个只会往前使劲的人仿佛又柔软了。
- → 这份安宁是真的；他几乎忘了先前的疲惫，一时也不想离开。

### 181–205　（正在面对）

- 安宁太真实了，他渐渐不能只把它留在心里；满足反倒照见了心愿仍未实现。　✦ 满足照出未满足
  - ← 提供理由：（148–180）「真实的安宁」
- → 如果那样的生活值得珍惜，使它难以存在的事情又怎能只靠怀念改变？
- → 他想起当初不肯继续等待，也是因为不愿看着重要的东西受损。
- → 懊恼立刻涌上来：怎么才刚沉进满足里，就忘了还有事要面对？
- → 他试着重新振作，却发现自己已无法像从前那样毫无顾忌地投入。
- → 温柔有多可贵，他如今感受得越深，就越怕艰难的争取会一点点耗尽它。
- → 他怕到最后只剩不肯退让的意志，心里却失去让一切值得争取的温柔。
- → 往前走，怕温柔被耗尽；留下来，又放不下它正受着威胁。
- → 他曾以为找到足够坚定的理由就能不再为难；如今理由更多，心反倒更难平静。　✦ 知道更多反而更尖锐
- ⟲ 仍在起作用：（1–23）「两难初现」

### 206–213　（没在想）

- 为难中，那份温柔又短暂地靠近；他明知不能一直停留，却舍不得马上推开它。
- → 既然它确实给过自己那么深的满足，他何必每次想起，都立刻拿它审问自己？
  - ← 提供理由：（148–180）「真实的安宁」
- → 于是他愿意再爱惜片刻，暂时不去想那些还没有答案的事。
- → 这点安静仍让他欢喜，只是欢喜里已经有了不舍。

### 214–215　（正在面对）

- 安静退去，熟悉的迟疑又回来了，仿佛走了很远，最后仍回到原处。
  - ← 唤起：（206–213）「欢喜中已有不舍」
- → 可他已知道自己放不下什么：那份迟疑里有怯懦，也有不愿失去的生活希望。　✦ 分清
  - ← 改写：（148–180）「看清依恋的模样」

### 216–225　（正在面对）

- 知道自己舍不得什么，并没让他立刻勇敢起来。
  - ← 限制：（214–215）「分清怯懦与珍惜」
- → 他已无法只凭最初那股决心向前，也无法安心沉浸在旧愿里。
- → 两种办法都曾帮过他，也各自留下了绕不过去的难处。　✦ 办法的限度
  - ← 说明：（92–115）「决定仍值得坚持」
- → 他一时没力气要求自己作出多大改变，只剩一个很轻的愿望。
- → 如果还要争取，就记得为什么；如果还想爱惜安宁，也别放下威胁它的事。
- → 他仍不知道该怎样做到，只是一遍遍想着这点微弱的意思。
- → 想得久了，那种非得舍弃一边才能继续的逼迫，似乎松了一点。

### 226–241　（正在面对）

- 凭着这点还不牢靠的心意，他重新想自己还能怎么做。
  - ← 提供理由：（216–225）「不再非此即彼」
- → 他亲身试过，尽力承担能让人从无力里重新动起来，却不能抹掉所有牵挂。　✦ 办法的限度
  - ← 说明：（24–65）「行动带来力量」
- → 心里那幅美好生活也能安慰他，却不能只靠安慰护住真正珍惜的东西。　✦ 办法的限度
  - ← 限制：（148–180）「真实的安宁」
- → 这两样收获都是真的，他再也不想简单地否定任何一个。
- → 可要两样东西都毫发无伤地留下，恐怕并不可能。
- → 他想保有那份不用时时奋力的安宁，可一旦为它争取，也可能失去安宁。
- → 过去他常责怪自己，仿佛真正坚定的人就不该如此为难。
- → 如今他渐渐明白，代价未必因为意志不够强，而可能因为珍惜的东西本来就不止一种。　✦ 选择的代价
- → 承认这一点并不轻松；想到要付出的东西，他还是心疼，也盼着有条容易些的路。
- → 他知道，再等下去，那条更容易的路也不会自己出现。
- → 若只因怕珍贵的东西受损就不再争取，自己爱惜的也未必留得住。
- → 他不再要求自己先毫不害怕；带着不舍、没把握，边承担边受苦，也可以向前。
- → 真走近要承担的事，他还是会怕；只是这回不肯再让恐惧替自己决定。

- → 这次的决心依旧热烈，却比从前踏实；不必等犹疑消失，他也允许自己坚定。　✦ 分清
