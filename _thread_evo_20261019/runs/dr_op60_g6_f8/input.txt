下面是肖邦《船歌》Op.60的一条“线”（Thread）的两个版本：原来那一版，和改写后的一版。两版的 Center（贯穿全曲的那个问题）相同：对亲密的投入与自我克制始终相互牵制。

改写只该改写法，不该改 Center 各部分在这条线里指什么。请先读原来那一版，弄清 Center 的每一部分在那里指什么（包括哪几面）；再逐段读改写后的一版，判断：
- 守住：这一段说到 Center 的那部分时，意思和原来一致（可以换说法、可以只说当下相关的一面，但没有让读者以为它就只是那一面）；
- 改窄：把原来一整件事缩成了其中一面，或者用一件更小、更日常的事情顶替了它；
- 换掉：说成了另一件原来没有的事。
不涉及 Center 的段落判“守住”。写一句理由，说出原来指什么、这里变成了什么。最后整体说：改写后的一版，Center 的哪一部分被改得最多。

### S01｜1–3 小节　（还说不清）

- → 想让这份喜欢多停留一会儿，他却又本能地把心收了回去。
- → 眼下还没有非作决定不可的事，他也说不清自己为何这样谨慎。
- → 这点喜欢轻得仿佛随时可以放下，他却偏偏舍不得。

### S02｜4–16 小节　（没在想）

- 还说不清自己怕什么，他先不替喜欢安排去向；两人以后怎样，可以以后再说。
  - ← 提供理由：（1–3）「谨慎的困惑」
- → 也不必因为喜欢就向对方期待什么。这样想着，他才慢慢敢安心靠近。
- → 心里的温柔可以自由给出去，不必时时确认对方有没有接住；认真在乎一个人，原来也未必让人不安。
- → 这份快乐让他渐渐放下对喜欢的提防，也有些满意自己能这样宽和。
- → 若亲近能一直这样自然，不追问、不计较，他当时真觉得已经足够。

### S03｜17–23 小节　（正在面对）

- 正因为这份亲近已经让他尝到幸福，他开始盼它不只属于眼前，还能长久。
- → 一想到长久，他便想到：自己能决定怎样珍惜对方，却决定不了对方是否也珍惜自己。
- → 从前觉得无需确认的事，如今竟开始牵动他的心。
- → 他还没打算索取什么，只是偶尔想知道，自己在对方心里是不是也很特别。
- → 期待只多了一点，原有的安稳就松动了；他意外地发现，已经满足的亲近仍会生出更多盼望。
  - ← 动摇：（4–16）「以为已经足够」

### S04｜24–34 小节　（正在面对）

- 他不愿让新添的紧张毁掉好不容易得来的快乐；对方没答应过什么，他也不想把喜欢变成催促。
  - ← 提供理由：（17–23）「满足照出未满足」
- → 于是他提醒自己：关心、给予、真心替对方高兴，本来就是快乐，不必每次换来表示或保证。
- → 这样想真的让他轻松下来；想确认的紧张渐渐退去，他反而更愿意付出，也不再计算给了多少。
- → 多给一点，也不再让他怕自己显得更在乎；尽情对一个人好，心里反而更丰盈。
- → 那阵子他甚至相信，只要不提出要求，就能尽情去爱，也不会失去什么。

### S05｜35–39 小节　（还说不清）

- 可欢喜稍稍平息，他还是想知道：对方有没有也把他放在心上。
  - ← 动摇：（24–34）「以为无所求就不会受伤」
- → 刚为无所求而高兴，转眼又盼着被看见；他因此难堪，也怀疑体贴里是否藏着未承认的期待。
- → 说自己毫无所求并不诚实，可先前的快乐也确实不是为了换取回应。
- → 他暂且留在这份不自在里，不替自己辩解，也不急着用新的热烈盖过去。

### S06｜40–50 小节　（没在想）

- 这份难堪没让他少喜欢，却让他看见：再靠慷慨证明自己无所求，也解不开矛盾。
  - ← 提供理由：（35–39）「难堪与自我怀疑」
- → 他想让心意自然些：不时时查看对方是否在意，也不逼自己变成全无期待的人。
- → 于是先看眼前：愿意关心，就去关心；他安静惦念，也真心盼对方过得好。
- → 有些喜欢只留在心里，就已经很甜；他暂时忘了为何在意回应，那个问题也不再占满心思。

### S07｜51–61 小节　（正在面对）

- 可这份甜意留得越久，喜欢越不再轻巧，也越来越难收放自如。
  - ← 改写：（40–50）「留在心里的甜」
- → 他原想把喜欢留在自己心里，免得对方为难，也不让期待牵着自己走。
- → 偏偏越珍惜，越常惦念，也越盼自己的关心能被对方领会。
- → 他仍觉得不催促对方才是对的；越不想添负担，那些没着落的盼望就越得自己消化。
- → 这份喜欢并非不值得；正因为尝过那么细的甜，他才舍不得把它减轻。
  - ← 提供理由：（40–50）「专注此刻的关切」

### S08｜62–71 小节　（没在想）

  - ← 提供理由：（51–61）「舍不得减轻深情」
- → 他想起最初安心的亲近、付出时的满足、独自珍藏的甜：这些都不是对方许诺后才有的。
  - ← 说明：（4–16）「安心靠近」
  - ← 说明：（24–34）「慷慨带来丰盈」
  - ← 说明：（40–50）「留在心里的甜」
- → 即使仍有期待，那些快乐也是真的；他不想再因怕受伤，连高兴都小心翼翼。
- → 他想充分喜欢一次，不急着追问结果，也不忙着替未来留退路。
- → 积攒已久的眷恋成了坦然的热情；不再计量给出多少，也不在心意深一点时提醒自己收回。
- → 有一阵，欢喜真的盖过顾虑；明知前面没有保证，他几乎感觉不到那份沉重。

### S09｜72–77 小节　（正在面对）

  - ← 唤起：（62–71）「欢喜暂时盖过顾虑」
- → 喜欢得再深，也不能把自己的真心当作对方理应回应的理由。
- → 退回谨慎，仿佛辜负了刚承认的心；继续盼下去，又怕爱变成要求。
- → 两边都舍不得，他找不到两全的办法，越想越委屈，也厌倦反复为难自己。

### S10｜78–83 小节　（正在面对）

- 他终于不再逼自己马上选一边，决定暂且不替这份感情下结论。
  - ← 提供理由：（72–77）「找不到两全的办法」
- → 想靠近时，可以先不急着往前；想守住分寸，也不必把眷恋藏得看不见。
- → 两种心思仍在，他可以带着盼望喜欢，也坦承自己没有把握。
- → 暂且放过自己，让心里松开一点；为难还在，原本绷紧的温柔却又能自然留在心里。

### S11｜84–92 小节　（正在面对）

- → 可这回，他尝过期待的紧张、无从确认的难堪，也知道深情替不了对方作决定，却还是愿意喜欢。
- → 他不必再用无所求证明体贴，也不因想被珍惜就怀疑真心；犹疑这么久仍能高兴，反让他感动。

### S13｜103–110 小节　（正在面对）

- → 他能尽情拥有自己的深情，却不能凭这份深情换来对方同样的选择。
- → 欢喜越真实，酸楚越难忽略；他已知道自己爱得多深，再也不能说对方怎样回应都无所谓。
  - ← 提供理由：（93–102）「让幸福停在此刻」
