# Op.61｜关系图（在 v6 上修补，w30）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他还没弄清自己眼下的处境，也说不清那股不肯罢休的念头究竟在等什么、舍不得什么。
- 他不愿把眼前这样当成理所当然，可又怕真正投入会让自己失去别的东西，所以他既不肯放弃，也不敢马上继续。
- 熟悉感又让他想继续，可他知道过去不会因此回来，也还找不到继续下去的理由。

### S02｜24–65 小节　（正在面对）

- 他不再等到把事情想透才行动，先承担眼下能做的一份；这份投入让他有了力量、快乐和一点骄傲，却没有消除牵挂。
  - ← 提供理由：（1–23）「真正投入」
- 他知道，那些东西已经不能再按从前的方式拥有。
  - ← 限制：（1–23）「熟悉感」
- → 他怕承认自己仍放不下会让自己又回到非得想透才肯行动的老路，便把注意力转回眼下，反复说服自己能够承受。
- ⟲ 仍在起作用：（1–23）「眼下的处境」

### S03｜66–91 小节　（正在面对）

- 那些珍贵的东西总把他的心思牵回去，让他拿不准该往哪使劲，心里恼火又不甘。
  - ← 限制：（24–65）「按从前的方式拥有」
  - ← 说明：（24–65）「转回眼下」
- → 他想要自在亲近、不必时时防备的生活，想到它便暂时不再追问为何用力，可轻松退去后，眼前的难处仍没答案，他又怀疑刚才那股劲是不是真心。
  - ← 唤起：（24–65）「承担一份」

### S04｜92–115 小节　（正在面对）

- 他知道，先前那份投入没能让自己安定下来，也没能让那份亲近照旧回来。
  - ← 说明：（24–65）「承担一份」
- → 他怕一停下来就得承认那份亲近已经回不到从前，便把继续行动当成暂时不去面对的办法。
- 他想弄清当初没想透就行动时，自己是否还有别的选择。
  - ← 唤起：（66–91）「自在亲近」
- ⟲ 仍在起作用：（66–91）「自在亲近」

### S05｜116–147 小节　（正在面对）

- 他仍觉得当初那一步不能辜负，怕承认失望就是变心，也怕顺着那份依恋便会停下。
  - ← 提供理由：（24–65）「承担一份」
  - ← 改写：（92–115）「继续行动」
- → 他发现自己把行动中得到的力量变成必须一直坚强的要求，连受苦也当成迟疑尚未克服的证据；意识到自己正在逼一个已经疲惫的自己后，他不再想证明坚强。
- → 他发现不再催逼自己也不能消除心里的不确定，直到继续抵抗的意愿耗尽，才暂时松开。
- ⟲ 仍在起作用：（66–91）「自在亲近」

### S06｜148–180 小节　（没在想）

- 他舍不得的不是行动带来的片刻舒服，而是他曾真切尝过快乐、真心相信过的生活：人与人可以亲近，不必防备、争夺，也不必反复证明自己值得被爱和接纳。
  - ← 失效：（116–147）「不能辜负」
  - ← 改写：（116–147）「暂时松开」
- → 他知道这样的生活还没有真正来到，也不知道能不能实现；越肯珍惜它，他越确认自己仍在盼着它，这份愿望也因此变得明确而迫切，却不能当作已经得到。
- ⟲ 仍在起作用：（116–147）「必须一直坚强」

### S07｜181–205 小节　（正在面对）

- 他知道那种生活不是空想，因为他曾真心相信过，也尝过其中的亲近；可心里认定它珍贵，并不等于眼下已经拥有。
- → 他当初不肯再等，是怕珍贵之物继续受损；如今他又怕逼自己去争取会耗掉刚重新珍惜的温柔，停下来也护不住它，便找不到不牺牲它的做法。
  - ← 改写：（66–91）「拿不准该往哪使劲」
  - ← 限制：（116–147）「必须一直坚强」
- ⟲ 仍在起作用：（148–180）「明确而迫切」

### S08｜206–213 小节　（没在想）

- 他不愿只因眼下还做不到，就把那种亲近的向往说成软弱，仍愿意相信并珍惜它。
  - ← 提供理由：（181–205）「不是空想」
- 他知道眼前的问题还没过去，仍得面对。
  - ← 说明：（148–180）「明确而迫切」
  - ← 提供理由：（181–205）「不牺牲它」

### S09｜214–215 小节　（正在面对）

- 他知道，那点安宁没替他找到办法；他还是得想清怎样争取那种生活，才不至于把自己逼得太狠、磨掉刚找回的温柔。
  - ← 说明：（181–205）「不牺牲它」
- ⟲ 仍在起作用：（148–180）「明确而迫切」

### S10｜216–225 小节　（正在面对）

- 他累得想不清自己为什么还放不下那种生活，也提不起劲继续争取。
  - ← 提供理由：（116–147）「必须一直坚强」
- → 他不再逼自己立刻选边。
  - ← 说明：（214–215）「暂时搁开」
- ⟲ 仍在起作用：（148–180）「明确而迫切」

### S11｜226–241 小节　（正在面对）

- 他看清，行动带来的力量和所向往的生活给他的安慰都是真的，却很难保证两者不互相伤害；即使决定承担，也没法让两边的牵挂和代价消失。
  - ← 提供理由：（24–65）「承担一份」
  - ← 说明：（181–205）「不牺牲它」
- → 他愿意带着两边的牵挂先去做眼下能做的事，不再把选清楚当作行动的前提。
- ⟲ 仍在起作用：（148–180）「明确而迫切」

### S12｜242–253 小节　（正在面对）

- 他不再把两边都舍不得、又找不到两全办法，当成自己不够坚定。
  - ← 说明：（116–147）「必须一直坚强」
  - ← 提供理由：（226–241）「两边的牵挂」
- → 他不再要求每次尽力都得改变一切。
- ⟲ 仍在起作用：（148–180）「明确而迫切」

### S13｜254–288 小节　（正在面对）

- 他发现眼下承担的事也在替那种生活争取，便不再觉得责任和依恋互相妨碍；当初相信它时的快乐也因此重新得到确认。
  - ← 提供理由：（226–241）「行动的前提」
- 他知道再使劲也不能保证那种生活回来，还可能耗掉刚找回的温柔，所以他愿意吃苦，也得顾着怎样坚持才不伤到所爱。
  - ← 限制：（226–241）「两边的牵挂」
- → 他承认真要承担代价时自己还是可能想退回安宁，便不再逼自己反复证明非得往前。
- ⟲ 仍在起作用：（148–180）「明确而迫切」
