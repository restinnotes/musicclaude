# Op.61｜关系图（在 v6 上修补，w34）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他怕由着事情照旧就等于认了它们本该如此，便硬撑着不肯倒下；也想停一停，怕真投进去会失去别的东西。
- → 熟悉的感觉一回来，他就下意识想继续，可过去不会因此回来，他还想找个理由才敢往前走。每次刚觉得想通，舍不得又回来，连那点确信也变得陌生，他也为非得想透才肯动而难堪。

### S02｜24–65 小节　（正在面对）

- 他还没想透，结果也没把握，却不让疑虑替他做主，主动接下能做的一份，尽力去做，渐渐有了些力气，也有点骄傲。
  - ← 改写：（1–23）「熟悉的感觉」
- → 他发现投入本身让他快乐，甚至愿意给得更多，贪恋倾尽全力的畅快，也不再时时审视自己或因一点软弱停步。

### S03｜66–91 小节　（正在面对）

- 他认真投入后，第一次能放下反复自问，也发现自己会因不再畏缩而真正高兴。
  - ← 提供理由：（24–65）「投入本身」
- 他想要自在亲近、不必时时防备的生活，却还不知怎样才能过上，因此不甘，想到它时仍会松口气。
- → 快乐淡去后，难处仍在，他想起自己先前决定尽力去做，也怀疑那股劲是否真心。
  - ← 唤起：（24–65）「能做的一份」

### S04｜92–115 小节　（正在面对）

- 他确实尝过那份亲近带来的快乐，所以虽知道当时的坚定也靠努力撑着，眼下虽不安仍愿意坚持。
  - ← 动摇：（66–91）「快乐淡去」
- → 他怕停下就得承认那份亲近回不到从前，便硬撑着不肯停下，反复追问过去还能怎样，却仍无法安心。
  - ← 改写：（1–23）「熟悉的感觉」

### S05｜116–147 小节　（正在面对）

- 行动明明还不够，他却舍不得松手，怕承认失望就是变心。
- → 他怕一软就停步，便不肯放下那份曾让他骄傲的要求，渐渐连脆弱都容不下，一累就怪自己不够坚定。
  - ← 改写：（24–65）「能做的一份」
- → 他发现自己还在逼着一个累了的人硬撑，终于不想再证明自己多坚强。
- → 他终于松了劲，却没因此安心下来，这才肯承认自己舍不得那种不必防备的亲近。
- ⟲ 仍在起作用：（92–115）「回不到从前」

### S06｜148–180 小节　（没在想）

- 催逼停下来后，他发现自己舍不得的不是一时舒服，而是曾真心相信过的生活：他盼着珍惜的东西不用靠争抢才能留住；他想付出时只是因为喜欢，不必反复证明自己值得被爱、被接纳，也不必先想着靠近会受伤。
  - ← 改写：（116–147）「不必防备的亲近」
- → 他不愿把这份向往说成软弱。
- → 他暂时不再担心心里一软就会停步，才肯承认自己也有委屈和思念。
  - ← 提供理由：（116–147）「逼着一个累了的人」
- → 他允许自己去爱、去相信，先珍惜心里向往的生活，不急着求它实现或证明有用，也不拿责任和它比轻重。

### S07｜181–205 小节　（正在面对）

- 熟悉的亲近让他觉得向往的生活近在眼前，可现实并没因此改变，他懊恼自己又沉进去了。
- → 他越真切地感到安宁，越不能只满足于在心里拥有那种生活，因为这份满足反而提醒他愿望还没实现。
  - ← 改写：（148–180）「先珍惜」
- → 他当初不肯再等，是怕珍惜的东西继续受损，光在心里想着那种生活也护不住它们。
- → 他想重新投入，却怕刚找回的温柔被耗尽，也怕顾不上想留住的生活，仍没想定怎样争取才不伤那份温柔。
- ⟲ 仍在起作用：（1–23）「本该如此」

### S08｜206–213 小节　（没在想）

- 安宁曾给过他很深的满足，他不必每次想起都立刻审问自己，仍愿爱惜片刻，欢喜里已有不舍。
  - ← 提供理由：（181–205）「心里安宁」

### S09｜214–215 小节　（正在面对）

- 他这回知道自己为什么迟疑：他有些怯懦，也不愿丢掉过上那种生活的盼头。
- ⟲ 仍在起作用：（148–180）「曾真心相信」

### S10｜216–225 小节　（正在面对）

- 他提不起劲争取，也说不清为何舍不得丢开那一步和那份安宁。
- → 他知道尽力去做确实帮过他，如今也让他难以继续，若还争取就得记得当初为什么不肯再等。
  - ← 提供理由：（181–205）「不肯再等」
- 他知道自己向往的生活确实曾让他安宁，可威胁它的事还在，珍惜它也不能把那些事放下。
  - ← 提供理由：（206–213）「爱惜片刻」
- → 他反复想着自己究竟想护住什么，想歇一歇也不等于要把它丢下。
- → 他还不知道往后该怎么过，却不再急着判哪一边错，逼自己立刻选边的劲也松了一点。

### S11｜226–241 小节　（正在面对）

- 他知道行动给他的力气和那种生活的安宁都是真的，却很难两样都不受损地留住，便重新想还能承担什么。
  - ← 提供理由：（216–225）「尽力去做」
- → 他怕争取会伤到珍惜的东西，心里仍疼，也知道只因害怕而不争取，未必留得住它们，还可能让它们继续受损。
- → 他知道再等也不会等来容易的路，便带着不舍和痛苦继续争取，不再要求自己先不害怕。
- ⟲ 仍在起作用：（181–205）「不肯再等」

### S12｜242–253 小节　（正在面对）

- 他知道该做什么，能做多少先做到多少，不必否认脆弱，也不用等犹疑消失才坚定，久违的昂扬又回来了。
  - ← 改写：（226–241）「带着怕」
- → 他舍不得那种不必证明也能被爱、被接纳的生活，也怕失去它，愿为所爱负责，不再把牵挂当成行动的拖累。
  - ← 提供理由：（148–180）「曾真心相信」

### S13｜254–288 小节　（正在面对）

- 他从前想退回安宁里护住那种生活，如今发现眼前的事也在替它争取。
  - ← 提供理由：（242–253）「真心爱惜」
- → 旧愿近了些，让他重尝当初的快乐，愿望未成也不抹掉这份快乐，却不能代替他真正过上那种生活。
- → 他发现旧愿和眼前的行动虽能一起推着他，却仍可能彼此冲突。
- → 他愿为那种生活吃苦，却知道再多付出也未必更靠近它，不能只因心愿就认定每一分付出都值得。
- → 他得留心别在争取时耗尽所爱，真要付代价时，仍可能累得想退回安宁。
- → 他不再反复找理由证明自己该往前，仍清楚知道那种生活是自己想要的。
- ⟲ 仍在起作用：（181–205）「刚找回的温柔」
