# op60｜Center 候选 1｜关系图（精简视图）

> 比赛用的 Center 句：一个人很想和所爱的人真正听懂彼此，可再亲近也无法替对方说出心里话，连温柔的沉默都可能让人猜错。

**Center｜什么对他重要：**他深爱对方，珍惜曾经得到的体贴和不用时时防备的亲近，想知道对方心里怎样想，也盼望自己的软弱、需要和不同心意能被对方认真听见。

**Center｜什么使它难以安顿：**他舍不得那种不必说尽就能相通的感觉，却怕自己的期待混进了对对方的理解；他想确认彼此真的懂得，又害怕听见不同的答案，也害怕自己把心意交出来后依然得不到回应。

### 1–3

◇ **Center（触及）**：他想让深爱带来不必说尽的相通，又担心自己的盼望冒充了对方的心意。

**此刻：他仍舍不得不言而喻的亲近，却已经不敢完全相信自己的懂得。**
- ← **提供理由**（1–3·恐惧）他怕自己的盼望混进猜测，误把自己想听的意思当成对方的心意。
  　他怕自己的猜测掺入愿望，所以不敢完全依赖原先相信的默契。
- ← **提供理由**（1–3·所求）他舍不得两个人相处时不必时时解释自己的自在。
  　他仍然珍惜不用解释的轻松，所以没有因为怀疑就舍弃那份亲近。
- ← **提供理由**（1–3·代价）他担心自以为已经懂得，会让自己错过对方心里实际存在的想法。
  　他怕自己的懂得反而使他错过对方真实的心，心里便保留着迟疑。
- ✦ 机制：他太盼着两颗心相合，遇到没说清的地方就可能朝自己希望的方向猜。（还模糊）

- ← **提供理由**（4–16·快乐）他曾觉得自己流露需要也不用难堪，可以轻松地待在这份爱里。

- ⟲ 仍在起作用：（1–3）他盼着爱的人不必说明每个念头，两个人就能明白彼此的意思。；（1–3）他舍不得两个人相处时不必时时解释自己的自在。
