话：他心里【空落落的】
感受：像忽然站在刺眼的亮光下，连手脚都不知往哪放 / 像脚下一空漂进浓雾里，刚才攥紧的手也垂了下来 / 像一下沉进冷水里，四周静得发慌，刚才的暖像场梦
话：他忍不住【担心对方会嫌自己太黏】
感受：像中间忽然起了一层白雾，暖意一下就淡了

### S06（屏幕停留 39 秒）
话：这回对方看出他有多在乎，跟他相处却一点没变，他才又能像从前那样【自在地待着】
感受：像从暖金水面滑进古桥阴影，微风贴着皮肤吹过
话：安静时，他还想靠近，【怕要得太多】
感受：像屏着的气轻轻吐出来，手还是忍不住往前探了探 / 像闭眼泡在温水里，热气漫过肩膀，舒服得有些发晕
话：对方不知道他刚才多怕被嫌弃，【他有点孤单】
感受：像热闹过后独自吹着夜风，鼻尖忽然泛起一点酸
话：他又忍不住想，对方既然一直没有退开，会不会也有一点【舍不得结束这份亲近】？

### S07（屏幕停留 41 秒）
话：想起这些日子对方总愿意跟他待在一起，他渐渐觉得，也许对方【有时也需要他陪着】
话：跟他在一起【也能安心些】
话：他【高兴得有点收不住】，想到两个人也许能互相依靠
感受：心口忽然一紧，有些发烫，却舍不得退开 / 像水底的热泉一股股往上涌，推着身体不住往前倾 / 像被温热的气息紧紧裹住，正往旋涡里沉，却不想出来
话：他真盼着，往后对方想找人陪时还会想到自己，自己也能【一直陪在身边】
感受：像手心攥着温热的细沙，抓得再紧，还是往指缝外漏

### S08（屏幕停留 39 秒）
话：上回他无意间露了心意，这回【见对方依然亲近】
话：他想主动些，【大大方方地回应】
感受：像推开窗迎着阳光和风，胸口敞亮，脚步也轻快起来 / 像眨了下眼，脚步轻快得差点跳起来
话：这样想着，他连往后的日子都开始盼了，觉得两个人说不定【还能这么好很久】
话：可眼下两个人都愿意亲近，以后未必还会这样，他【心里没底】
感受：身上还晒着暖阳，眼前的光却已经像傍晚了

### S09（屏幕停留 32 秒）
话：那点没底越来越具体：要是哪天对方【不再需要他陪】，连和他待着都不自在了呢？
话：他一下安静了，刚才还敢盼那么远，现在却【不敢再往下想】
感受：像话说到要紧处忽然顿住，呼吸停了，胸口还紧紧绷着 / 像空气忽然变得闷重，四周的光还在，却隔了一层薄雾 / 像空屋里只剩刚才那声余音，站在原地，不知该往哪迈步
话：他想起对方一直没退开，两人眼下还亲近，【这些都是真的】
感受：又像抬头看见开阔的夜空，心跳还快，呼吸却慢慢顺了 / 像手心忽然碰着一点温热，嘴角忍不住轻轻弯起

### S10（屏幕停留 27 秒）
话：他想着，再猜下去【连今天也过不踏实】
话：便暂时不去管往后怎样，先好好【享受眼前的亲近】
话：先前那阵紧绷慢慢松下去，他心里亮堂得【几乎想笑，也有点想哭】
感受：像耸着的肩膀终于落下来，长舒一口气，眼眶微微发热 / 像窗外雨还没停，却先关上窗，安心陷进温暖的沙发里 / 像急雨里躲进窄窄的屋檐下，能喘口气，却没法久留 / 身体轻得像飘在夏夜微风里，连衣服的重量都感觉不到了

### S11（屏幕停留 37 秒）
话：他忽然想到自己需要对方，对方【有时也需要他】
话：即使对方不需要他，他仍愿意陪着，【不再藏着喜欢】
感受：像一直压低的声音忽然放开了唱，坦坦荡荡，不再闪躲
话：这个念头一上来，他【高兴得连害臊都顾不上了】
感受：像渴极了终于喝饱甜水，胸口滚烫，满脸都是笑
话：可对方以后还愿不愿意让他陪在身边，【不是他能说了算的】
话：想到两人未必总能这样亲近，欢喜就【压得他心口发疼】
感受：像落日沉没前烧得血红金亮，晃眼得叫人直想流泪 / 又像多年后重回老屋，桌椅没变，午后的阳光却沉甸甸的

### S12（屏幕停留 38 秒）
话：他顾不上对方是否也在乎他，只想【把能给的都给对方】，希望对方安心
话：可他明知再用心也没法保证以后还这么好，还是嫌这样的日子不够，想【多陪对方一会儿】
感受：像捧着泉水大口大口地喝，越喝越急，却还是觉得渴
话：那一阵高兴终于整个涌了出来，他不再强迫自己收着，只顾【痛痛快快地喜欢】对方
感受：像耳边的私语化作漫天回响，整个人被声浪托起，轻飘飘的 / 像发高烧似地浑身滚烫，又像重逢时用力抱紧，久久不松手 / 喉咙发紧，眼眶发烫，一时分不清是想笑还是想哭

### S13（屏幕停留 39 秒）
话：高兴过后，他更想听对方说【以后也不变】
话：他越喜欢跟对方待着，【越觉得时间过得快】
感受：像手心捧着温水，明明还暖着，却觉得正一点点变凉 / 像在急流里不敢停桨，刚到浪峰，又有更大的浪推上来 / 像刚坚定地应了一声，尾音还没落，舌根却先泛起一阵苦
话：起初他怕自己的需要给对方添负担，如今【更怕对方哪天不再需要他】，连这样待着都没了
话：可他早不像最初那样能装作不在乎了，真要往回藏，自己【反倒更难受】
感受：像伸出的手想往回缩，一收就扯得胸口疼，掌心却还滚烫 / 像双脚明明钉在原地一步不退，胸口却随叹息一沉再沉

### S14（屏幕停留 34 秒）
话：最初他连喜欢都不敢多露，【如今两人还亲近】
话：心里【又甜又酸，却不后悔】
感受：胸口还温热着，呼吸却慢慢平稳下来 / 也像从美梦里醒来，眼前还留着温润的光
话：他还是会舍不得，也不知道以后怎样，却【不想再逼自己讨】一句永远不变的保证
话：既然喜欢已经让对方看见，【他就不往回藏了】
话：往后会怎样，等真的【到了那时再说】
感受：像一场大风过后，站起身整理好衣服，轻轻关上了门
