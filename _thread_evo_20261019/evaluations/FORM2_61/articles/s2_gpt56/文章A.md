# 文章A

**（1—23）**

**越想确保自己没选错，越容易把刚冒头的愿望审到不敢认。**

**（24—65）**

**刚尝到自己做主的踏实，我又把“不许改口”误当成了果断。**
← 因为我曾一有疑问就推翻自己，所以急着证明自己已经变了。
→ 于是做主变成了自我考核，越怕回头，越不准自己调整。

**（66—91）**

**把心软当成软弱，坚定就会变成逼自己硬撑。**
← 因为我把果断当成不能改口的证明，连怕伤人、怕想得太简单都想压下去。
→ 于是我开始明白，挺直腰杆不等于赶走真实的感受。

**（92—115）**

**被压下去的顾虑，不会因为决定已下就自动消失。**
← 因为我不想再让无休止的思考替我做决定，却仍然在乎那些没解决的问题。
→ 于是我继续往前，也不再把每一次犹豫都判成软弱。

**（116—147）**

**想有人接住自己，不等于不愿为自己负责。**
← 因为我终于承认，自己既想做主，也会累、会想被理解，而过去总把这种需要骂成没出息。
→ 于是我允许两种需要同时存在，却仍得自己摸索怎么选择。

**（148—180）**

**看清自己为什么纠结，不会替你省掉必须失去的东西。**
← 因为我既想顾及别人，又不愿处处让步；既想周全，又不能无限拖延。
→ 于是我明白，不选也有代价，拖延只是暂时把代价藏起来。

**（181—205）**

**真正的坚定不是保证不后悔，而是不再拿可能后悔当作不行动的理由。**
← 因为再怎么周全，也无法让别人和自己心里的每个念头都满意。
→ 于是我愿意承担选择的代价，却又忍不住怀疑自己是否足够坚定。

**（206—213）**

**犹豫可以跟着决定一起存在，但不能自动拥有否决权。**
← 因为我刚决定承担，心里仍会冒出“可是”，仍然在乎别人和可能失去的东西。
→ 于是我不再赶走这部分自己，也不让它次次把我拉回原地。

**（214—215）**

**再次摇摆不一定是回到原点，也可能是终于看清自己在怕什么。**
← 因为我已知道自己想要什么，也知道选择意味着失去什么。
→ 于是问题从“我想要什么”变成“我敢不敢认领这个选择”。

**（216—225）**

**不必等到毫无疑虑，才有资格把一个愿望当成选择。**
← 因为我开始明白，想到另一条路，不等于自己没有资格决定。
→ 于是我不夸大也不抹掉那点心愿，哪怕发抖，也愿意迈步。

**（226—241）**

**坚定不是心里没有别的声音，而是不再让它们替自己无限延期。**
← 因为我不再纠结自己算不算坚定的人，而开始问自己是否愿意负责。
→ 于是即使看得见别的路、仍然怕后悔，我也开始往前走。

**（242—253）**

**真正的选择不是消灭心软，而是不必先证明它错了才能行动。**
← 因为强硬曾让我迈步，也差点让我否认感受；心软让我顾及别人，也曾让我拖延。
→ 于是我能说清自己为什么选，并愿意承担，而不假装以后不会改变。

**（254—288）**

**真正的坚定不是永远不变，而是每次动摇都重新想清代价，再亲自做主。**
← 因为我尝过果断带来的踏实，也见过硬撑与拖延各自的代价。
→ 于是我允许自己心软、怀疑甚至改主意，却不再等到心里毫无矛盾才敢承担决定。
