# Op.60｜关系图

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3　（还说不清）

- 他还说不清自己究竟在盼什么，只知道心里有了一个格外想亲近的人。
- → 想到那个人时，他会不由自主地柔软下来，却又本能地把这份感觉收回去。
- → 这份喜欢还轻得仿佛随时能放下，可他偏偏舍不得，自己也不明白为何谨慎。

### 4–16　（正在面对）

- 他决定先让这份在意自然发展，至于两个人会怎样，可以以后再想。
  - ← 提供理由：（1–3）「格外想亲近的人」
- → 他不把喜欢变成对对方的期待，慢慢就能安心地亲近那个人。
- → 他发现温柔可以自由给予，不必时时确认对方有没有领会，也能保有从容。
- → 他渐渐不再提防喜欢，一度觉得若亲近能一直自然地发生，这样就足够了。

### 17–23　（正在面对）

- 尝过亲近带来的幸福后，他开始希望这份喜欢不只属于眼前，还能长久。　✦ 满足照出未满足
  - ← 唤起：（4–16）「觉得自然亲近足够」
- → 想到长久，他发现自己能决定如何珍惜对方，却不能决定对方是否也珍惜自己。
- → 他偶尔想知道自己在对方心里是否特别，这点期待已经让他不再完全安稳。

### 24–34　（正在面对）

- 他想保住先前的快乐，也想让对方自在，不让新添的紧张变成催促。
  - ← 提供理由：（17–23）「想知道自己是否特别」
- → 他提醒自己，关心对方、给予心意、为对方高兴，本身就能带来快乐。
- → 这样想让他轻松下来，也使他更愿意付出，不再小心计算自己给了多少。
- → 那一阵，他一度相信只要不提出要求，就能尽情去爱，也不会失去什么。

### 35–39　（正在面对）

- 欢喜稍稍平息后，他仍想知道自己是否也被对方放在心上。
- → 他为自己刚觉得无所求、转眼又盼对方在意而难堪，开始怀疑体贴里藏着什么期待。
  - ← 动摇：（24–34）「以为无要求就够了」
- → 他知道此前的快乐本就真切，也看见自己确实盼着对方在意。　✦ 分清

### 40–50　（没在想）

- 他仍然喜欢对方，也因这份难堪决定不再用慷慨证明自己。
  - ← 改写：（35–39）「快乐并非换取在意」
- → 他只留心此刻真心愿意给出的关切，安静惦念，也为对方的好而高兴。
- → 他暂时忘了自己为何在意对方是否在乎，只觉得把喜欢细细留在心里也很甜。

### 51–61　（正在面对）

- 他把喜欢安静留在心里，甜意久了，感情却渐渐不再轻巧。　✦ 办法的限度
  - ← 限制：（40–50）「独自细细喜欢」
- → 他越来越珍惜对方，也更深地惦念，希望自己的关切能够被对方领会。
- → 他仍觉得不催促对方才是对的，舍不得拿自己的期待换取对方迁就。
- → 为了不让对方为难，他只能独自收着那些没有着落的盼望，却舍不得减轻喜欢。

### 62–71　（正在面对）

- 他忽然不想再把深厚的喜欢时时当成需要约束的东西。
  - ← 提供理由：（51–61）「独自收着无着盼望」
- → 他看见先前的快乐早已在没有承诺时发生，心里有期待也能与这些幸福同时存在。　✦ 分清
  - ← 说明：（4–16）「安心亲近那个人」
  - ← 说明：（24–34）「更愿意自然付出」
  - ← 说明：（40–50）「独自细细喜欢」
- → 他想尽情喜欢一次，把心意自然地给出去，不再小心衡量付出或提醒自己收回。
- → 有一阵，欢喜大过所有顾虑，他几乎感觉不到没有承诺的沉重。

### 72–77　（正在面对）

- 欢喜稍退后，他发现心里想要的东西已经无法再含糊带过。
  - ← 唤起：（62–71）「欢喜暂时盖过顾虑」
- → 他不只想尽情喜欢，也想知道对方是否同样渴望靠近、珍惜彼此。
- → 他清楚，自己爱得热烈，却不能要求对方也同样热烈地喜欢。　✦ 分清
- → 他舍不得收回真心，又怕盼望变成要求，想不出两全办法而委屈。

### 78–83　（正在面对）

- 他终于不想逼自己立刻选定做法，决定先缓一缓。
  - ← 提供理由：（72–77）「舍不得真心又怕索求」
- → 他暂时让两种心思都在，继续喜欢，也接受自己无法决定对方心意。
- → 他可以带着愿望安静喜欢，也知道自己没有把握，心里因此松开一点。

### 84–92　（正在面对）

- 不再强迫自己消除渴望后，他重新尝到最初亲近一个人的快乐。
  - ← 唤起：（78–83）「带着愿望继续喜欢」
- → 他尝过期待的紧张、想被珍惜的难堪，也知道深情不能替对方决定是否靠近，却仍愿全心喜欢。
  - ← 说明：（17–23）「想知道自己是否特别」
  - ← 说明：（35–39）「怀疑体贴藏着期待」
  - ← 说明：（72–77）「热烈不成对方义务」
- → 他不再靠无所求证明体贴，也愿面对自己想被珍惜的心情，即使可能受伤仍愿充分欢喜。　✦ 分清

### 93–102　（正在面对）

- 不再遮掩渴望后，他更清楚自己多想和这个人亲近。
  - ← 唤起：（84–92）「体贴也容得下渴望」
- → 他想被同样深切地珍惜，也想知道两人能共同拥有多丰盛的幸福。
- → 那阵满足强烈得让他几乎顾不上别的，只觉得能这样爱着已充实得不可思议，暂时也想不到以后。

### 103–110　（正在面对）

- 幸福仍然鲜明时，他忽然感到心里有一处始终没有着落。　✦ 满足照出未满足
  - ← 限制：（93–102）「此刻爱着已足够充实」
- → 他可以充分拥有自己的深情，却不能凭这份深情决定对方也同样选择自己。
- → 那份酸楚没有推翻刚才的欢喜，反而因欢喜如此真实而格外难以忽略。　✦ 知道更多反而更尖锐
- → 他希望对方接受心意时仍能自在，也想保留这份给过自己巨大幸福的感情，不把全部不安交给对方处理。
- → 他发现克制能让自己安心，却不能让渴望消失，尽情投入带来幸福，也仍可能失望。　✦ 办法的限度
- → 他仍急切想靠近，也坚持让对方自愿靠近，宁愿把这两种心思都留着。
- ⟲ 仍在起作用：（72–77）「热烈不成对方义务」

### 111–116　（正在面对）

- 他渐渐接受，认真喜欢一个人也可能让自己受伤。
  - ← 改写：（103–110）「克制投入各有难处」
- 他仍想被对方选择，因为对方确实重要，即使愿望未必实现，也愿意面对这份盼望。
- 他仍舍不得放下克制，因为对方有自己的心意，若要对方消除他全部不安，亲近也会变得不自在。
- → 他仍会遗憾，却知道带着遗憾也能好好喜欢一个人。　✦ 选择的代价
- 他知道先前的快乐都真实发生过，也让他看清对方多么重要，最后的难题仍没抹掉这些快乐。
  - ← 说明：（4–16）「觉得自然亲近足够」
  - ← 说明：（24–34）「更愿意自然付出」
  - ← 说明：（40–50）「独自细细喜欢」
  - ← 说明：（62–71）「欢喜暂时盖过顾虑」
- 他仍盼对方珍惜自己，也知道自己的真心由自己判断，克制多少只是当下的选择。
  - ← 改写：（84–92）「体贴也容得下渴望」
- → 他知道以后仍可能想要更多、因不能更近而疼痛，却不拿这些感受否认真心或催促对方。
- → 他愿继续把对方放在心里，认真喜欢、充分欢喜，也接受自己无法决定的那部分。
- → 他既渴望被爱，也让对方自由选择，仍认真喜欢，不因未得一切就先放弃这份爱。
  - ← 改写：（72–77）「热烈不成对方义务」
- ⟲ 仍在起作用：（72–77）「热烈不成对方义务」；（103–110）「克制投入各有难处」
