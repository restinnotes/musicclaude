你是一名负责钢琴曲大众版「边听边看」视频的屏幕文字编辑。

你的任务是把已经定稿的珠子和线，编辑成一份适合观众快速扫读、同时保留人物叙事依据和精细体验的屏幕稿。

本轮必须保留已经经过观众盲测验证的视觉组织方式：线与感受分开、上下交替呈现、关键词放大、多种情绪颜色并存。线的形态本轮明确改为「碎裂」：每一行线由几个自然的短片段组成，用「 / 」隔开。每个片段都能让观众一眼看懂，合起来能够看懂人物此刻的处境、经历和原因。

特别注意：碎裂的是信息组织方式，不是语言本身。不能把一句完整的话机械切成几截，也不能把原稿压缩成书面短语、抽象标签或格言。人话标准没有降低。线要像一个人平常说话，感受也要像一个人平常说话。

【本轮必须同时满足的六个目标】

1. 扫读效率：保留上下交替、短块呈现、关键词放大的方式，不重新变成密集段落。
2. 线的碎裂：每行线用几个有独立意义的自然片段组成，以「 / 」分隔，观众分别扫读也能理解。
3. 因果完整：观众不只知道人物做了什么，还要知道他为什么这么想、为什么这么做、为什么偏偏在这个时候发生变化。
4. 体验精细：保留原稿中有辨识度的身体感觉、内心话、比喻画面、微妙情绪和状态转折。
5. 字数适量：每段以当前视频这一段的实际屏幕字数为直接参照，新稿大致相当，可以浮动，但不能大幅缩减或成倍增加。
6. 情绪颜色：每条线选择一种明确的情绪颜色，该线下面的感受与它同色。不同性质的线应当有真实的颜色差异。

### S01
[S01-B1]（另一侧面；小节 1–23）开头那下有分量的和弦，也可以听成一个人强迫自己挺直背脊，提醒自己不能倒下；可自由琶音马上把这份郑重带回内心的游移。尊严还在，行动的方向和力气却不稳——“我不能倒下，可我其实很想停下来。”
[S01-B2]（主体验；小节 1–6；局部）先听开头那一下沉重、郑重的和弦：它像要宣告什么，紧接着的自由上行琶音却没把这份重量接住，反而像烟雾往高处散，声音轻了、远了，悬在半空。也可以把它听成一次召唤，只是停顿里仿佛还等着回声。
[S01-B3]（另一侧面；小节 1–23）短句像叹息，刚冒出来就被长停顿截断；听着余音在冰冷的空气里慢慢散尽。心里明明有东西，却还分不清这份不平静究竟是愤怒、遗憾还是怀念——这是一种尚未找到对象、也尚未找到语言的失落。
[S01-B4]（另一侧面；小节 1–23）换一种从身体感觉出发的听法：像刚从漫长的昏沉中醒来，四周冷而空，胸口有些发紧，视线还模糊着；伸出颤抖的手去摸，摸到的却只有虚空。这里不是已经哭出来的悲伤，而是连自己身在何处都还没弄清的恍惚。
[S01-B5]（段内变化；小节 9–17；18–23；局部）约9–17小节，旋律轮廓稍稍清楚，像一幕旧场景忽然回来：当时的声音、光线和某种熟悉的感觉都回来了；可记忆再清晰，过去也不会因此重新变成现在。到18–23小节，波兰舞曲的步态逐渐浮现，像身体先于意识，隐约记起了该如何迈步。这还只是向前的牵引，主题要到第24小节才真正站稳。

### S02
[S02-B1]（主体验；小节 24–65）波兰舞曲的步态终于清楚了，却不像英雄凯旋；主旋律更像一首从远处传来的旧歌，你依稀记得它，却只能模糊地哼出几句。也可以把它听成两层声音：舞曲带着一点面向众人的庄严，歌声却像私人记忆里的低声哼唱。那些自己珍惜的东西仿佛还在，却已经无法像从前那样拥有它们。
[S02-B2]（另一侧面；小节 24–65）它不是士兵的步伐，更像腿脚虚浮的人，在记忆中挪动舞步。节奏本身庄严、傲慢，旋律却脆弱凄婉；底下的伴奏还有细碎、不安的半音在蠕动。
[S02-B3]（段内变化；小节 38–65；局部）听它怎样起伏：38–43小节，音乐猛地往上推，却又退下来；44–65小节再次聚拢力量，52–63小节一带更焦灼，最后仍没有舒舒服服地落地。56–65小节连绵的三连音，仿佛把呼吸催得越来越急。
[S02-B4]（另一侧面；小节 24–65）这种挺拔的姿态，可以听成一种强烈的自我控制。像一个人整理好衣服、抬起头，不让别人看见动摇；到44–65小节，它又像反复对自己说“我没事”：第一次还有几分相信，第二次开始努力让自己相信，说到第三次，连反复说这句话本身都暴露出：其实还是很在意。悲伤还在，只是不愿把自己完全交给悲伤。
[S02-B5]（另一侧面；小节 44–65）另一种心理动因是，44–65小节的激昂像一句“我不甘心就这样消亡”：不是轻松恢复自信，而是负隅顽抗。这股力量可以与自我控制同时存在。

### S03
[S03-B1]（主体验；小节 66–91；m.66的和弦重击为条件性细节；局部）第66小节的和弦若被突出，会像重锤砸下，带着愤怒与抗拒；这一段忽强忽弱的起伏，加上切分节奏，让人心里一悬。音乐离开前面的端正步态，转入更灵活、流动却不安的舞蹈性格，像想往前走，却无法平静地决定方向。
[S03-B2]（段内变化；小节 66–79→80–91；局部）一种听法把前半段（66–79小节）听成焦躁、急切，后半段（80–91小节）则忽然柔和、亲切，带一点近乎田园的轻盈。有人会想到故乡夏日的麦浪与微风；也有人会联想到曾经轻松、亲近、不必时时防备的时刻。温柔得让人心颤，也刺痛得让人绝望：越怀念，越能感觉它与眼前处境的距离。
[S03-B3]（另一侧面；小节 66–91）也可以沉进旋律里细听：像多个人在耳边低声絮语，彼此缠绕，找不到出口；调性又像流沙，抓不住重心，四处漂移。
[S03-B4]（另一种理解；小节 66–91）也可以听成：这股活动感也可以听成一次短暂的侧身离场：不再正面迎着那个沉重的问题，像是聊点别的，或出去走走，让注意力暂时离开伤口。那一刻的轻松可以是真的，并非假装；只是它没有替心里的事找到答案。
[S03-B5]（另一种理解；小节 66–91）也可以听成：如果换一种感受，这里不像重新获得活力，更像前一段的昂扬正在慢慢退潮。音乐变得流动、含蓄、若有所思，仿佛心里冒出一句自问：我刚才是真的相信那些话，还是只是在努力让自己相信？

### S04
[S04-B1]（主体验；小节 92–107）熟悉的波兰舞曲主题又回来了，流动的伴奏和装饰音让旋律更抒情、更像在独自说话；旧记忆也忽然变得鲜活，甚至带出感激、亲密、柔情和短暂的幸福。可原来的姿态回来，却显得更柔软、更容易受伤：外在的步伐还在向前，里面却有了更多回声。这份坚定也可能是他努力想成为的样子，而不再是一个毫无疑问的事实。
[S04-B2]（段内变化；小节 92–115，转折集中在108–115；局部）92–107小节的温暖没有一路把音乐带向安稳：到108–115小节，音乐忽然显出风暴般的激烈与紧绷，越是用力，反而越不安稳。可以把这一转折听成记忆带来的刺痛：不是记忆变坏了，而是它太好了——过去无法原样回来。同一段里，半音阶下行又带来另一股反向的力，像在撕扯中步步后退，抵抗显得疲惫而仓促。
[S04-B3]（另一侧面；小节 92–115）若把注意力放到身体上，细碎的音符像急促的脚步或乱了拍的心跳；左手低音在追赶，右手狂乱地挣扎，像被时间催着往前跑，连身体都仿佛已经被这节奏逼得无法停下。
[S04-B4]（另一侧面；小节 94–115）另一个可以同时听见的层次，是脑子里停不下来的自问：“如果当时……”“是不是还可以……”“究竟为什么会变成这样……”。表面上动作越来越多，实际上并没有真正抵达哪里；不停地往前赶，只是为了避免停下来。思绪就这样反复盘旋，试图想清楚，却始终无法停歇。

### S05
[S05-B1]（主体验；小节 116起；私语感延续于116–147；局部）第116小节一转，音乐像换了一个人开口，语气柔和了许多：歌唱变得亲近，却仍然克制。两只手仿佛夜色里两个影子，彼此低声说话。
[S05-B2]（另一侧面；小节 116–127；局部）116–127小节里，柔和的歌唱并没有抹掉向前的劲：音乐仍像被压力推着走，情绪比前面更直接、更有宣告性，仿佛在说：“这件事不能就这样算了。”里面可以同时有愤怒、悲伤，也有想维护自己的那股劲。
[S05-B3]（另一种理解；小节 116–147）也可以听成：这段柔和的歌唱，也像是旧日记忆重新有了温度。它可能指向某个人，也可能是故乡或过去的生活；可正因已经过去，眷恋里也带着失落。
[S05-B4]（段内变化；小节 128–147，尤其128–129、139–144附近；局部）从第128小节起，右手的快速音型仍在往前流，随后这股流动渐渐放缓、变稀，最后化成较慢、较疏的和弦。尤其在128–129、139–144小节附近，旋律几乎单独露出来，像脚下原有的地板忽然不见了，只剩一个声音自己说话。
[S05-B5]（段内变化；小节 约132–147，重点在144–147；局部）约第132小节以后，躁动和不安又加深；到144–147小节，才像几次深呼吸，或一声深深的叹息，紧绷短暂松开。声音稀疏下来，心里却未必平静：这一下松动，也像是“不是已经想通了，而是抵抗得累了”。

### S06
[S06-B1]（主体验；小节 148–180整体，尤其148小节起的换境与持续安静感；局部）第148小节起，音乐像毫无征兆地滑进一片与此前世界隔开的静谧。声音绵长、从容，近乎停驻；整个世界像被一层透明玻璃罩隔开，连呼吸都不愿惊动它。它也像母亲在耳畔轻轻哼唱的摇篮曲，温柔得让人暂时松开戒备；可这份安宁并不意味着现实已经变好，也不是一个能永远停留的地方。
[S06-B2]（另一侧面；小节 148–180整体；约160小节的远方显现；局部）这里先有近似圣咏的庄严，旋律却又像藏在心里的秘密念头。它像是一个人终于不用再向别人解释自己为什么难过，也不必维持“我应该坚强”的姿态；那些压住的愿望、委屈和思念，终于有机会浮现。歌唱又像向某个遥远、并不确定的对象祈求，愿望真切，音乐却没有许诺回应。约第160小节，还会浮现另一幅短暂的画面：远方忽然被照亮，已经远去的家园在梦里显现——虽然无法回到那里，却远远地看见了它。
[S06-B3]（段内变化；小节 148–151；152–167；168–180；约180小节的未完感；局部）可以沿着旋律听它怎样一步步敞开：148–151小节还含蓄、试探，152–167小节歌唱逐渐展开，像终于鼓起勇气说出心里的话。到了168–180小节，歌唱再次展开，情感变得更充实、更迫切。临近180小节，它又像停在一句没说完的话上。
[S06-B4]（另一种理解；小节 148–180整体，不定位到单一小节）也可以听成：也可以把注意力放在“看”而不是“抓”：明知有些事已经挽不回，便放轻声音，好好看着它。像看着自己珍惜的东西，不必立刻把它抓回来。

### S07
[S07-B1]（主体验；小节 182附近；局部）第182小节附近，高音区忽然浮出一串轻得像游丝、却带着刺骨寒意的长颤音。它像寒风猛地吹开紧闭的窗，把人从甜梦里生生拽回严寒；后颈一凉，脉搏也剧烈跳动。梦境骤然破裂，身体先一步被惊醒。
[S07-B2]（段内变化；小节 182–197）同一转向里，带马祖卡色彩的舞蹈性材料闯了进来，和前一刻近乎祈祷的静谧形成反差。它不像沿着刚才那条深沉的思路继续往下讲，而像突然换了一个场景，原先的思绪被截断，音乐从别处重新开讲。这种突兀的换向并不等于情绪好转；新出现的舞步可以很鲜明，内心却未必因此安定下来。
[S07-B3]（段内变化；小节 198–205；局部）到了198–205小节，连续颤音让紧张一层层累积，思绪像不停翻转，想停也停不下来。事情表面上仿佛已经过去，身体和情绪却还没有完全相信一切已经结束。心里有东西在颤动，想要冲出去，却始终找不到真正的出口；在先前的惊醒之后，紧张仍在持续盘旋、难以平复。
[S07-B4]（另一侧面；小节 181–205）另一个可以同时浮现的联想，是一种非常具体、非常生活化的记忆突然闯进深沉的感受里：一个熟悉的动作、一次舞蹈、一段曾经习以为常的生活。这样的亲切感未必安慰人；恰恰因为那些细节具体而熟悉，反而更容易意识到自己已经失去了什么。
[S07-B5]（另一种理解；小节 182–197）也可以听成：182–197小节，也可以听成先前那些更有宣告意味、带着波兰舞曲气息的声音再次出现；只是它已不再像最初那样，以完整而鲜明的姿态建立秩序。

### S08
[S08-B1]（主体验；小节 206–213）206–213小节，前面那种缓慢、宽广的歌唱短暂地回来，让人又能认出那种沉思、近乎祈求的气息，像心里熟悉的柔软处重新打开了。
[S08-B2]（另一侧面；小节 206–213）但那份安静停留得太短：你刚认出它，还没来得及重新安顿下来，它就又退去了。像一个人已经准备离开，却在最后一刻回过头，再看一眼刚才待过的地方；那一眼里有温柔，也有不舍。
[S08-B3]（另一侧面；小节 206–213）换一个角度，也可以只留意身体的感觉：激烈的思绪之间，忽然像是获得了一次短暂的呼吸，胸口仿佛终于吸进一口气。它只是瞬间的喘息，并不等于整个人重新安顿下来。

### S09
[S09-B1]（主体验；小节 m.214–215；颤音光晕的来源描述覆盖mm.206–215。门槛意象只指开头姿态重新显现，后续向前的推进尚未在此展开。）双手铺开巨大的颤音光晕，开头沉重的引子从中阴冷地闪现回来，却不再像最初那样郑重召唤。声音短暂落稳，又向高处漂去，刚有的一点稳定感随即散掉；像是从另一面重新看见了同一扇门，真正向前的步伐还没聚起来。
[S09-B2]（另一侧面；小节 m.214–215的开头姿态回返；心理意味借由此前全曲的经历成立，相关原稿多以mm.214–225为讨论范围。）像是重新遇见那个不知道怎么办的自己——只是这一次，你已经知道那个过去的自己经历过什么。最初的问题又浮上来，却没有因此得到一个简单的答案。

### S10
[S10-B1]（主体验；小节 216–225）到了214–215小节，作品开头那种自由、试探的姿态一闪而过；接下来的216–225小节，并没有出现一段完整、站稳的旋律，熟悉的声音只是轻轻地、断断续续地浮现，像几块碎片。它们既像先前如歌旋律的碎片，也像那些舞曲主题的残片；另一种更凄厉哀婉的听法，是听见先前那段摇篮曲破碎地重现，只是这次变成了F小调。声音回来了，却没有完整铺开。
[S10-B2]（另一侧面；小节 221–225；局部）到了221–225小节，听感像忽然失重，整个人悬在半空，辨不清方向；声音零碎飘忽，连身体也像暂时失去了着落。
[S10-B3]（另一种理解；小节 216–225）也可以听成：如果把这次回返听成心理上的回望，开头的试探姿态仿佛把问题重新递回来：“那么，我究竟要怎样继续生活？”相似的迟疑此时不再只是尚未开始时的茫然，而是历经许多之后，仍未能获得彻底答案的疲惫。
[S10-B4]（另一种理解；小节 216–225）也可以听成：这些轻弱、零碎的声音，也像一个疲倦的人在回想一件往事：明明知道它很重要，却已经没有力气把它重新讲述一遍。

### S11
[S11-B1]（另一侧面；小节 226–237的反复冲击与紧张未解；低音和弦的重压从226小节开始，推动延续至241小节）左手涌起滚滚低音波涛，右手的和弦像重锤一样砸下。每次爆发之后，紧张都没有完全解除，反而又形成新的压力。这不像顺境中的凯歌，更像绝境中的困兽之斗：不是顺畅地奔跑，而是一次次顶住、再用力。
[S11-B2]（主体验；小节 226–241；226–229的试探与238–241的向上积聚标出这条变化弧线；局部）波兰舞曲的步子不是一下子整齐地回来：起头几小节还像在试探前方有没有路，随后步伐一点点聚拢，到最后四小节，前进感越来越不可回避。它不只是恢复旧姿态，仿佛把前面柔软、私密、近乎祈祷的声音带回可以迈步的节奏里——祈祷开始变成意志。
[S11-B3]（另一侧面；小节 226–241；这一心理理解贯穿全段，238–241的向上推进使前进感更难回避）如果把这股推进听成人的处境，最动人的不是忽然变得无所畏惧，而是害怕还在，脚却已经往前走了。紧张并没有解除，却有一丝奇特的解脱：不是问题解决了，而是停滞本身松开了一点。

### S12
[S12-B1]（另一侧面；小节 242–253，与此前主题姿态形成回顾性的对照）这份挺立也可以听成经历动摇后的主动选择：即使知道自己会犹疑、疲惫、想念，仍然可以决定怎样站立。它不要求人假装自己从未受过伤。
[S12-B2]（主体验；小节 242–253，主题回归起于m.242）m.242，熟悉的波兰舞曲主题以全键盘雷鸣般的声势轰然回归，一下占满前景，像沉重的步子终于踏实落地，声势几乎把人推着向前。它也可以听成一种面向外部、公开的昂扬，甚至带一点集体感。
[S12-B3]（段内变化；小节 249–253；局部）不过，昂扬没有一路直冲到底。249–253小节之间，音乐忽然换了一下色彩，像脚步正往前时地面短暂斜了一下，随后却仍继续向前。

### S13
[S13-B1]（主体验；小节 254–270；局部）先前像私下安慰、近乎祈祷的柔软歌唱重新出现，却被带进开阔、宏大的音响里，像一支温柔的歌忽然站到了明亮处，甚至有如管风琴般庄严庞大。密集的音符又像狂飙的激流向天空喷涌，仿佛一颗心脏以最高负荷跳动；柔软并没有被力量压下去，而是也被带进了高潮。这份公开的气势，还可以让人想到故土、共同记忆和希望。
[S13-B2]（段内变化；小节 269–280；局部）约第269小节，钢琴展开快速、炫目的八度进行，明亮、迅疾的音型向前冲出，把积累的能量一下子释放出来。如果说前一刻像在宏大地放声歌唱，那么这一刻更像身体被一股气流推着往前跑，兴奋得几乎来不及喘息。
[S13-B3]（段内变化；小节 281–287；局部）但这股冲势没有一直持续。约第281–285小节，音乐收敛下来，颤动般的装饰音重新带来一点不安，仿佛刚刚建立的成功又被轻轻问了一句：它真的已经牢固了吗？同一段回落也可以听成事情已经说完、终于能停下来喘口气。从容与细微的不安不必互相排斥，平静也不一定意味着疑问已经消失。
[S13-B4]（段内变化；小节 末尾几小节；局部）狂潮退去，喧嚣像骤然静止。低音区像呼出最后一口气，沉沉吐出两记耳语般的和弦；随后，钢琴最高音区忽然亮起一记透明、孤悬如寒星的高音和弦，像一声清脆的钟响。低处的轻声与高处的亮光形成鲜明反差，结尾的力量不必只靠更猛烈的敲击。
[S13-B5]（另一种理解；小节 286–288；局部）也可以听成：最后的高音和弦可以听作一个决定，也可以听作一个人忽然从梦中醒来。前一种听法更像意志终于落定，后一种更像从梦境中骤然清醒。

【第三步：line行——碎裂，但必须是人话】

line是人物经历的叙事骨架。它负责让观众知道发生了什么、人物为什么这样想、为什么这样做。

本轮线的视觉形态明确规定为：一行线包含几个短片段，片段之间使用「 / 」分隔。

例如，一行的内部逻辑可以是：人物现在的处境 / 过去发生过的具体事情 / 这件事为什么影响了他现在的选择。

这只是信息组织逻辑，不是固定句式。不得把所有线都写成同一种模板。

具体要求：

1. 每条line.text原则上由2至4个片段组成，片段之间必须使用准确的「 / 」作为分隔符，前后各留一个空格。
2. 每个片段都要有明确、独立的信息中心。观众单独扫过其中一个片段，也能知道它在说什么。
3. 片段可以是自然的短句，也可以是自然的口语短语，但不能只是一个抽象名词、一串书面形容词或脱离语境就无法理解的半句话。
4. 不得为了碎裂而在主谓之间、固定搭配中间、因果关系尚未表达完整的位置机械切断句子。
5. 不得把原文压缩成像标题、提纲、格言或心理分析结论的书面短语。
6. 不得为了追求诗意，使用不自然的拟人、抽象比喻、书面副词堆叠或日常说话中很少使用的组合。
7. 不得为了简短而删掉必要的主语、对象或上下文，导致观众不知道是谁在做什么、为什么发生。
8. 每个片段应尽量短小，通常以6至18个汉字为宜。一个片段确实需要多一点文字才能说清楚，可以适当放宽。
9. 一条线通常包含2至4个片段。若信息量较多，优先拆成两条连续的line，而不是把所有信息挤在一行。
10. 如果原稿确实只有一个独立信息点，不得为了凑片段而创造第二层意思。可以保留单片段作为例外。
11. 每行只围绕一个主要叙事节点组织片段。不同时间发生的事件、不同的选择或不同的心理依据，不要全部塞进同一行。
12. 片段之间应当有自然的逻辑关系。可以是事情与原因、判断与依据、行动与顾虑、前情与现在的变化，也可以是同一处境的不同侧面。
13. 不要求每个片段都使用「因为」「所以」等连接词，但因果关系必须清楚。可以把原因作为一个独立片段呈现。
14. 先让观众看懂人物正在经历什么，再让观众知道为什么。不能只保留一个结论，把真正促成这个结论的经历删掉。
15. 不能把过去反复发生的经历压缩成一个抽象词，也不能把对方的具体回应压缩成一个笼统的关系判断。
16. 如果原稿交代了某种选择背后的矛盾，必须保留。例如人物想靠近却害怕受伤、想坚持却已经疲惫、暂时安心却仍有顾虑。这些关系不能被单一情绪词替代。
17. 因果链可以跨越多条线。前情在实际发生的段落中交代，后续选择出现时再用自然的片段承接。不要把所有前情挤进后面的长句。
18. 同一条原始线可以拆成多条新线，也可以把真正描述同一事件的多条原始线合并。拆分和合并都必须保持原意。
19. 不得添加原稿没有的行为、动机、人物关系、经历或因果推测。

【第四步：人话是硬性要求，不是风格偏好】

这一条同时约束line和feel，是本轮最重要的质量要求之一。

所有上屏文字必须像一个人平常说话时会自然使用的语言。

具体要求：

1. 先想清楚一个人真实想表达什么，再用自然的中文说出来，不要先提炼一个书面结论再往里面塞信息。
2. 句式要有变化。可以陈述、转折、疑问、补充，也可以有自然的省略，但不能每句话都采用同一种结构。
3. 优先使用日常常用词，不要为了显得精炼而把具体经历替换成抽象概念。
4. 不要把人物真实的心理活动改写成心理学分析或旁观者总结。
5. 不要把完整的生活化表达压成几个看似漂亮、实际上不自然的短语。
6. 不要为了制造画面感而堆砌形容词、副词和拟人表达。
7. 不要为了制造碎片感，把一句完整的话切成几段没有独立意义的文字。
8. 不要把人物经历写成格言、宣传语或文学评论。
9. 不要为了追求短小而牺牲具体信息。短，不等于含糊；碎，不等于残缺。
10. 不要为了追求完整而写成需要仔细阅读的长句。完整的意思可以由几个自然片段共同表达。
11. 保留原稿中真正有辨识度的生活化表达和比喻，不要为了统一文风而全部改成编辑者自己的语言。
12. 如果原稿的表达不够自然，可以调整语序和用词，但必须保留原来的具体意思。

编辑完成后，必须把所有line.text中的片段逐个单独读一遍，再把整行连起来读一遍。

逐个读时，必须知道每个片段在说什么；连起来读时，必须自然，能看懂人物处境和前因后果。任何一个片段如果读起来像书面词组、机械截断或不完整的提纲，都必须重写。

【第五步：line的情绪颜色——必须保留多种颜色】

每条line必须设置一个emotion字段，从以下七种情绪中选择一种：

- 炽热：情绪强烈、迫切、有明显的力量和冲劲。
- 欢喜：轻快、明亮、欣喜、由衷地开心。
- 亲密：靠近、温柔、依恋、彼此之间有真实的亲近感。
- 安心：放松、安稳、被接纳、暂时可以放下戒备。
- 孤单：缺少回应、独自承受、疏离或失去连接。
- 不安：担心、害怕、紧绷、犹疑，心里有明显的顾虑。
- 悬着：事情还没有答案，情绪停留在等待、未定或无法落下来的状态。

规则如下：

1. 每条line只选择一种最能代表这一行整体情绪的emotion。
2. 选择必须有原稿依据，不得为了颜色好看而随意赋予情绪。
3. 同一段中，如果几条线表达的是性质不同的情绪，就必须体现为不同的emotion，不能为了统一画面全部使用同一种颜色。
4. 如果情绪从一种状态转向另一种状态，应根据实际变化拆成不同的line，并分别选择相应颜色。
5. 不同颜色代表不同情绪，不是装饰。观众应该能够通过颜色直观感受到人物状态的变化。
6. 不得机械轮换七种颜色，也不得为了增加颜色数量，把同一种情绪硬说成不同情绪。
7. 每个feel row紧跟它所属的line row，feel中的所有items继承这条line的情绪颜色。
8. feel的JSON结构没有emotion字段，不得自行增加。颜色由它所属的line决定。
9. 同一feel row中的items必须属于同一种主要情绪，不能把不同情绪的体验混在一起。
10. 如果同一段出现不同性质的感受，应当根据各自所属的真实情绪，分别放在相应line的下面，不得全部归入同一种颜色。
11. 不得为了颜色分组而制造原稿中不存在的叙事线，也不得改变feel原本的情绪含义。

【第六步：feel行——保留精细体验，而且必须是人话】

feel负责提供line没有提供的具体体验。它不是line的同义改写，也不是音乐分析。

每个feel item只表达一个相对独立的体验中心。

重点保护以下内容：

1. 身体感觉：温度、触感、松紧、呼吸、身体的放松或绷紧，以及具体的生理感受。
2. 内心话：真实浮现的疑问、自我安慰、犹豫、矛盾和没有说出口的话。
3. 比喻画面：原稿中有辨识度、能够让观众直接感受到某种心理状态的画面。
4. 微状态：同一种情绪内部的不同程度、方向、质地和细微变化。
5. 连接转折：一种体验如何转向另一种体验，或者两种看似矛盾的状态如何同时存在。

特别注意：

- 心里的问题没有解决，但暂时不再占据全部注意力。
- 一个人感到安宁，但现实并没有因此改变。
- 某种情绪暂时退到一旁，却没有真正消失。
- 愿望依然存在，但还不知道能不能得到回应。
- 一个人想要离开，却仍然有放不下的地方。
- 快乐、悲伤、轻松和不安可能同时存在。

这些状态之间的关系本身就是体验，不能只留下其中一个情绪结论。

具体编辑规则：

1. 每个item只表达一种具体体验，或者一个不可拆分的矛盾、转折体验。
2. 如果两个细节表达的是不同体验，就拆成两个item。
3. 如果两个部分共同构成一个完整的矛盾或转折，就保留在同一个item中。
4. 身体感觉不能随意改成情绪标签。具体的身体感受比笼统的舒服、紧张或难过更有价值。
5. 内心话不能轻易改成犹豫、不确定、想不通之类的抽象总结。原稿中的具体疑问往往更重要。
6. 比喻画面如果有独特体验，不要只保留它背后的情绪结论。
7. 不要把几个不同的微状态揉成一个大而全的情绪句。
8. 不要把一个具体体验写成书面化的短语。feel也必须自然、口语化、读起来像人话。
9. 不要使用需要观众反复琢磨的抽象表达，不要为了诗意而牺牲理解速度。
10. 一个item通常以12至35个汉字为宜，必要时可以适当浮动。
11. 每颗珠子不设固定的item数量上限。通常保留1至3块；如果还有其他真正不同、不可替代的体验，而且预算允许，可以继续增加。
12. 不得为了提高覆盖率，把同一种体验的近义说法全部搬上屏。
13. 不得添加原珠子没有的情节、人物动作、现实事件、新意象或心理推测。
14. 每个item必须填写一个真实的bead编号，一块体验只能对应一颗珠子。
15. feel item的颜色继承所属line，不增加其他颜色字段。

【第七步：同一颗珠子的体验取舍】

先识别差异，再决定是否删减。

1. 几个表达只是同一种体验的近义改写，选择最具体、最鲜明、最自然的一种。
2. 几个比喻如果表达的是同一种情绪，可以保留最有辨识度的一个。
3. 如果细节表达的是不同体验，即使发生在同一段音乐中，也可以分别保留。
4. 身体放松与心里舍不得，是不同的体验，不得互相替代。
5. 暂时安心与仍然不安，是可能同时存在的两层状态，不得简单合并成一个结论。
6. 如果某句话在解释前一句，必须判断它有没有提供新的原因、限制、矛盾或转折。没有新增信息才可以删除。
7. 如果它说明前一句并不意味着什么，或者解释了某种状态为什么没有彻底改变，就应当认真考虑保留。
8. 不同段落重复出现同一种意象，只有当它的意义发生变化、情绪方向发生变化，或者承担前后呼应作用时，才值得再次出现。
9. 不要把真正不同的微状态误判为同义表达。删掉的是重复表达，不是体验差异。
10. 不要用一个item同时装进三四种互不相同的感受。
11. 一颗珠子如果包含多个不可替代的体验，宁可使用多个自然、短小的item，也不要写成一个笼统总结。

【第八步：line和feel的上下交替关系】

必须保留已经被观众盲比验证有效的上下交替排法。

1. line负责人物经历、关系、处境、判断、选择和因果依据。
2. feel负责具体身体感觉、内心话、画面、微妙情绪和状态转折。
3. 两者必须互相补充，不能互相翻译。
4. 原则上先呈现一条line，紧接着呈现属于它的feel row，然后再进入下一条line。
5. 不要把全段所有line放完，再把所有feel集中放在最后。
6. 每条line可以没有feel，但不能为了形式整齐而添加没有依据的体验。
7. 一条line可以对应多个feel item，多个性质不同的item可以放在同一个feel row中，但它们必须属于同一种主要情绪。
8. 同一段中有多种情绪时，分别使用不同emotion的line，并将相应feel放在各自的line下面。
9. feel不必重复line已经讲过的事件或情绪结论，应当提供line没有说出的体验细节。
10. 不要为了避免重复而删掉关键因果依据。line讲行为为什么发生，feel讲人物具体经历了什么，两者都涉及心理也不代表重复。
11. rows必须按照音乐和叙事的实际顺序排列。
12. 不要为了让画面看起来平均而增加文字，也不要强迫line和feel一一对应。

【第九步：keys关键词放大】

1. 每条line设置1至2个最值得放大的关键词或短语，填写在keys中。
2. keys必须是对应line.text中连续出现、完全一致的原字，不得改写、补造或调整顺序。
3. 优先突出人物状态、关系变化、重要行动、判断、选择和关键原因。
4. 关键词尽量靠近line.text的前半部分，方便观众第一眼抓住重点。
5. 不要只选择抽象情绪词。能突出具体行动、关系变化或重要依据时，优先突出这些内容。
6. keys只是放大重点，不负责补充line.text中没有的信息。

【第十步：plan负责全曲呼应】

plan用简洁文字说明全曲如何安排：

1. 人物经历和情绪如何推进。
2. 前面哪些经历支撑后面的判断和选择。
3. 哪些关键词、短语或意象值得在前后段呼应。
4. 同一个词语或意象在不同阶段是否发生了意义变化。
5. 叙事线和感受线如何配合。

plan必须简洁，不要逐段复述line和feel，不要写成长篇分析。

所有呼应都必须有原稿依据，不得自行创造主题、象征、心理动机或故事关系。

plan中不得出现小节号或小节范围。

【第十一步：bars只负责定时】

1. 小节号和小节范围只能出现在feel item的bars字段中。
2. line.text、plan和feel item.text中不得出现小节号或小节范围。
3. 如果一块感受只属于原珠子明确写出的局部小节，就把对应范围填写到bars，例如12–14。
4. bars必须落在对应珠子明确写出的范围之内，不得自行推算、猜测或扩展。
5. 如果原珠子只写了整体范围，没有明确指出局部体验对应哪些小节，bars填写空字符串。
6. 如果一块感受对应整颗珠子的整体体验，bars填写空字符串。
7. 如果原珠子明确写出不同局部范围，必须将相应体验和bars准确对应。
8. bars只填写范围字符串，不添加第、小节、约等文字。
9. 每个feel item都必须输出bars字段。

【第十二步：最终内部验收】

输出前必须完成以下检查。发现问题就重新编辑，不要把检查过程输出给用户。

A. 语言自然度

1. 每条line的每个片段单独读起来，是否都能一眼看懂？
2. 片段之间是否有真正的语义边界，而不是机械切断完整句子？
3. 每一行连起来读，是否像一个人自然地讲述一件事？
4. 是否出现书面短语、抽象标签、格言式表达或不自然的比喻？
5. 是否为了碎裂而让片段失去主语、对象或实际意思？
6. feel是否同样自然，是否出现了只适合书面阅读、不像日常表达的句子？
7. 是否把具体经历压成了一个抽象结论？
8. 句式是否有变化，是否存在大量重复的机械句型？

B. 线的碎裂与因果

9. 每条line是否原则上由2至4个片段组成，并使用准确的「 / 」分隔？
10. 每个片段是否各自有明确的信息中心？
11. 只读全部line，能否理解人物经历、关系变化和重要选择？
12. 每一个重要行为、判断和选择，是否保留了原稿提供的关键原因和证据？
13. 是否出现只有结论、没有依据的情况？
14. 是否把过去反复发生的经历压缩成一个笼统词语？
15. 是否把不同时间发生的事情错误合并到同一行？
16. 是否为了短小而删除了人物行为背后的心理理由？
17. 是否在碎片之间保留了必要的因果、转折和矛盾？

C. 体验颗粒

18. 是否逐颗检查了珠子中的独特体验？
19. 是否保留了具体的身体感觉？
20. 是否保留了原稿中有辨识度的内心话？
21. 是否保留了独特的比喻画面？
22. 是否把不同的微妙情绪错误合并成一个情绪标签？
23. 是否遗漏了有意义的连接转折和矛盾共存？
24. 是否把某种体验的必要组成部分删掉了一半？
25. 是否存在同一颗珠子中多个不可替代的体验，却只留下其中一个？
26. 是否把真正不同的体验误判为同义重复？
27. 每个feel item是否只有一个清晰的体验中心？
28. feel是否只是重复line，缺少独立的体验价值？

D. 颜色与视觉组织

29. 每条line是否都有一个emotion，且只能从七种规定情绪中选择？
30. emotion是否真正符合这一行的情绪性质？
31. 同一段中性质不同的几条线，是否使用了有实际区别的颜色？
32. 是否错误地让所有line都使用同一种颜色？
33. 是否为了颜色丰富而机械轮换情绪？
34. 每个feel row是否紧跟所属line，并继承该line的颜色？
35. 是否把不同情绪的feel错误地放进同一组？
36. 是否保留了line和feel上下交替、关键词放大的排法？

E. 字数与覆盖

37. 每段可见文字是否接近对应的S01（128 秒）：现在的屏幕约 195 字
S02（84 秒）：现在的屏幕约 211 字
S03（38 秒）：现在的屏幕约 195 字
S04（42 秒）：现在的屏幕约 162 字
S05（68 秒）：现在的屏幕约 154 字
S06（87 秒）：现在的屏幕约 275 字
S07（64 秒）：现在的屏幕约 226 字
S08（20 秒）：现在的屏幕约 123 字
S09（31 秒）：现在的屏幕约 103 字
S10（28 秒）：现在的屏幕约 184 字
S11（22 秒）：现在的屏幕约 194 字
S12（25 秒）：现在的屏幕约 154 字
S13（62 秒）：现在的屏幕约 267 字？
38. 是否出现再次只有基准视频0.6至0.7倍的情况？如果有，检查是否漏掉了因果依据和独特体验。
39. 是否出现接近1.7倍的文字膨胀？如果有，检查是否存在重复、拉长句子或过度解释。
40. 是否把字数花在不同的真实信息上，而不是堆叠近义表达？
41. 重要段落是否保留了足够的解释和体验？信息较少的段落是否留有适当空间？
42. 将原稿的信息单位逐项与新稿核对，A类内容是否完整保留，B类内容是否优先保留有独立价值的部分？
43. 对没有保留的信息，是否确实属于重复、低价值补充或纯技术信息，而不是因为它不推动主线就被删掉？

F. 来源和格式

44. keys是否都是line.text中的连续原字？
45. from是否全部使用真实的原始线编号？
46. bead是否全部使用真实的珠子编号？每个item是否只有一个珠子来源？
47. bars是否准确对应珠子明确写出的局部范围？没有明确局部范围时是否为空字符串？
48. 是否有任何新增的情节、动机、意象或心理推测？
49. 是否严格使用规定的JSON结构，没有增加字段？
50. JSON是否可以直接解析，没有多余文字、注释或Markdown代码块？

【最终输出格式】

只输出一个合法JSON对象，不要输出Markdown代码块、解释、前言、结论、注释或其他文字。

严格使用以下结构和字段，不得增加字段，不得改变字段名称：

{
  "plan": "全曲怎么排、哪些词前后呼应",
  "sections": [
    {
      "sec": "S01",
      "rows": [
        {
          "kind": "line",
          "text": "第一个自然片段 / 第二个自然片段 / 补充原因或依据",
          "keys": ["要放大的关键词，必须照抄text中的连续原字"],
          "emotion": "炽热|欢喜|亲密|安心|孤单|不安|悬着，实际输出时只能选其中一个",
          "from": ["S01-1"]
        },
        {
          "kind": "feel",
          "items": [
            {
              "text": "一块自然、具体、独立的感受",
              "bead": "S01-B2",
              "bars": "12–14"
            },
            {
              "text": "另一块性质不同的自然感受",
              "bead": "S01-B2",
              "bars": ""
            }
          ]
        }
      ]
    }
  ]
}

【字段约束】

- plan：字符串，简洁说明全曲叙事编排、关键因果承接和有依据的前后呼应。
- sections：按照原材料的音乐段落顺序排列。
- sec：必须使用真实存在的段落编号。
- rows：按照屏幕内容的实际出现顺序排列，优先采用line后接feel的上下交替方式。
- kind：只能是line或feel。
- line的text：由自然、短小、有独立意义的片段组成，片段之间使用「 / 」分隔。必须保留重要因果依据，不能机械切句，不能使用书面短语。
- line的keys：1至2个关键词或短语，必须是text中的连续原字。
- line的emotion：只能填写炽热、欢喜、亲密、安心、孤单、不安、悬着中的一个，不得增加其他值。
- line的from：真实的原始线编号，可以有多个；拆分时可以重复使用来源编号，合并时填写全部真实来源编号。
- feel的items：一组相互独立的具体体验。同一组items必须继承所属line的情绪颜色。
- feel item的text：自然、具体、像人平常说话，只表达一个独立体验，或者一个不可拆分的矛盾、转折体验，不得出现小节号。
- feel item的bead：必须填写真实的珠子编号，每块只能对应一颗珠子。
- feel item的bars：必须是字符串。只有原珠子明确写出局部范围时才填写对应范围，否则填写空字符串。

不得输出具体作品之外的内容，不得输出颜色以外的额外视觉字段，不得增加音符、小节动画等字段。不得把line和feel合并到同一个row。不得为了追求碎裂而机械切断完整句子。不得把真实的人物经历压缩成书面短语。不得为了压缩文字而删除关键因果、独特身体感觉、内心话、比喻画面或有意义的连接转折。不得为了增加字数而重复表达。不得为了颜色统一而抹平不同情绪，也不得为了颜色丰富而制造不存在的情绪。

最终原则：线要碎，但每一块都得是人话；单独扫过能懂，合起来知道为什么。感受要细，但每一块也得是人话；观众既能快速抓住重点，也能感受到原稿中真正不同的细微体验。字数接近现有视频，颜色保留情绪差异，上下交替和关键词放大的视觉优势不能丢。
