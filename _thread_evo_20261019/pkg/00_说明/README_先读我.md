# Thread Prompt 自进化交接包（GPT3 CLI / GPT-6 Max）

**任务是优化生成 Thread 的提示词和输入策略，不是修订一篇《船歌》文章。**

## 给本地执行 Agent 的入口

**请先读 `00_说明/AGENT_直接执行任务.md`，随后自行设计并实施实验，必须亲自运行 `gpt3` CLI 调用其中的 GPT-6 Max。**

模型 CLI 的具体命令行选项**尚未在打包环境中验证**，因此不能将任意 CLI 用法冒充真实有效；请用 `gpt3 --help` 及帮助信息查明实际调用方式、模型名称、输入输出方式，再真实调用，记录成功/失败与命令日志。不能用其他模型无声替代 GPT-6 Max。

## 文件布局

- `01_提示词与基准/P0_用户原始提示词_完整.md`：用户在本对话粘贴的原始完整提示词；比前一次的“规范化复写”更接近原文。
- `01_提示词与基准/B0_成功范例_水面从来不答应静止.md`：用户粘贴的 GPT-6 Max 一次生成的**完整文章**，包含它第117小节误读以供评测；禁止用它给候选生成器做直接模仿样本。
- `02_Bead精简输入/D0_零Bead_说明.md`：不传任何 Bead 的对照。
- `02_Bead精简输入/D1_十四段音乐锚点.md`：人工浓缩的音乐事件；不是原材料逐字抽取或经过乐谱校勘的事实库。
- `02_Bead精简输入/D2_十四条主体验.md`：每段以原 STRUCT 的 B1 主体验抽取，**不是“14 reader”的同义词**。
- `02_Bead精简输入/D3_十四段reader.md`：14段正式读者稿；**必须与 D4 对照**。
- `02_Bead精简输入/D4_五十一条完整Bead.md`：51条独立体验的原始文字（去掉审稿、来源和冗余字段）；**必须与 D3 对照**。
- `03_Bead机器可读/14段_STRUCT轻量版.json`：结构化的14段、51条（保留角色、位置、相关重要关系，不带旧数据超长源码、逐句来源）。
- `03_Bead机器可读/S01.json ... S14.json`：上项拆分，便于 Agent 分段读入、探索更小的输入表示。
- `04_历史参考/历史第二轮_短Thread候选.md`：既有 Thread 工作结果，仅作诊断参考，不是默认输入。
- `05_实验记录模板/`：文件与实验日志建议格式，不限制 Agent 自行选择更好的方法。
