你要为一首器乐作品设计 Thread 的“人的经历骨架”。

Thread 是同一个人在整首作品里经历的一件事。以后会把它写成逐段关系图，但这一层只负责把这件事本身想清楚。

段落顺序：S01：第 1–23 小节

S12：第 242–253 小节
S13：第 254–288 小节
Center：维持尊严的行动与对旧日生活及归属的怀念反复拉扯

这一层：
- 完全不看任何听感记录或珠子。
- 不写音乐、声音、旋律、节奏、和声、小节里的事件。
- Center 已经给定，不得修改。
- 不新增外部事件、前史、对白、物件、人物、地点或场景。
- 可以利用你对这首钢琴曲整体结构和走向的可靠理解安排经历，但输出里只写人的经历。

请独立提出 3 条完整候选路线。

【本次新增的内部规划：识别音乐关系，但不把音乐关系写成人物事件】

在构思路线之前，先根据你对作品整体结构的可靠了解，判断各段之间是否存在明确的音乐回返、再次出现、延续或过渡关系。

每段内部标记一种关系：
- 首次：此前没有出现过的音乐材料或结构功能。
- 回返：此前已经出现过的材料或结构功能再次出现。
- 延续：前一阶段的音乐材料或功能持续发展。
- 过渡：主要承担连接或转换作用。
- 不确定：无法可靠判断，不得猜测。

如果你不能可靠判断某段的音乐关系，必须标为不确定。不能仅仅因为两段情绪性质相似就认定它们是音乐回返。

这份标注只用于帮助人物经历保持记忆，不得出现在人物的 state 或最终叙事里。

【音乐回返最重要的规则】
1. 音乐回返不等于人物回到经历起点。
2. 如果后面出现与前面相似的音乐关系，人物必须带着中间已经成立的事实、认识和选择继续经历。
3. 相同的情绪可以回来，但相同的认识不能重新第一次成立。
4. 如果回返段仍然存在相同的愿望或担忧，优先写它在经历过中间阶段之后的实际影响，而不是重新提出旧问题。
5. 如果没有新的后果，可以如实写延续、沉浸或暂时没在想，不得为了对应音乐回返制造新的心理变化。
6. 不要机械地让首次出现对应新的心理认识、回返对应旧情绪重新爆发。

【人物经历规则】
1. 每条路线从头到尾只是一件事。
2. 前面已经发生过、相信过、期待过、得到过、失望过的东西，才可以成为后面此刻这样想或这样感受的根据。
3. 不要默认采用“试一个办法—不管用—换一个办法”的发展。
4. 一个认识、决定或问题一旦明确成立，后面不能再次把同一件事写成第一次成立。
5. 情绪变强本身不算人物处境发生了新变化。
6. 不要求每段都有新认识。允许延续、沉浸、后果、注意力转移和暂时不想这件事。
7. 不要让人物不停总结自己。优先写具体在意什么、盼什么、犹豫什么、已经知道什么、还不知道什么。
8. 结尾不必解决问题，也不要为了有终点制造决心或人生结论。
9. 同一路线中维护一份已经成立的事实账本，后面不得违背或重复完成。

【输出格式】
每条候选包含：
- route_id
- situation：一句普通话，说清这个人正在经历的是哪一件事。
- segments：
  - sec
  - music_relation：首次 / 回返 / 延续 / 过渡 / 不确定。
  - state：本段此刻实际是什么情况，1–3 条，只写人物经历。
  - delta_type：从“新变化 / 后果 / 实行已有想法 / 延续 / 回到旧处但有新增 / 暂时没在想”中选择。
  - delta：本段真正新增了什么；没有就写空。
  - depends_on：真正作为前因的更早 state 编号；没有就空。
  - still_open：到这一段仍未解决或仍不知道的东西；没有新增就留空。
- established：按首次成立顺序列出全文的重要事实、认识、愿望或选择，并标明第一次成立在哪一段。

输出必须是完整 JSON。不要写音乐分析、不要写最终文案、不要评价候选。
