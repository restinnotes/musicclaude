# Op.61｜线（pd3）

**Center：**维持尊严的行动与对旧日生活及归属的怀念反复拉扯

### S01｜1–23 小节　（正在面对）

- 他心里始终放不下那个曾经很亲近的人。
- 如今两人有了隔阂，他心里的委屈还没有被理解，也不愿先向对方靠近。
- → 可他不知道对方如今还在不在意这段关系，只能先把想念留在心里。

### S02｜24–65 小节　（正在面对）

- 他越想起过去那种自然的亲近，就越舍不得这个人。
- → 想到自己到现在还这样想念，他又有些不甘心，好像连自己受过的难受都快被轻轻带过去了。
- → 他想让对方知道自己仍然在乎，却始终不愿先说出口。

### S03｜66–91 小节　（正在面对）

- 他慢慢明白，挡住自己的不只是怕对方不回应。 〔24–65 ③〕
- → 他更怕自己先说了想念，对方却仍不了解他的委屈，就以为那些难受都可以不提了。
- → 他至少希望自己的难受也能被对方认真对待，而不是因为自己还想亲近就变得无足轻重。

### S04｜92–115 小节　（正在面对）

- 他因此还是忍住了想告诉对方的心思，不愿先替两个人把隔阂轻轻揭过去。 〔66–91 ②〕
- → 可这样守着自己的委屈，也没让他少惦记对方。

### S05｜116–147 小节　（没在想）

- 他又想起从前在那个人面前的自在，心里有什么都不用先藏起来。
- → 他想念那种安心的日常，也想念那个在对方面前能够放松的自己。
- 他真想再和那个人这样亲近，不必处处留意自己的心情该不该流露。

### S06｜148–180 小节　（正在面对）

- 他舍不得从前那份安心，却也知道自己没法装作如今的隔阂从来没有存在过。 〔116–147 ②〕〔66–91 ③〕
- → 他开始盼的是将来还能坦诚地亲近，而不只是把两个人的相处恢复成从前的样子。
- → 即使不能完全回到过去，他也希望有一天双方能真正理解彼此的心情。

### S07｜181–205 小节　（正在面对）

- 可他没法凭自己的盼望，就知道对方是否还愿意理解他。 〔148–180 ③〕
- → 想到自己再怎么舍不得也代替不了对方的心意，他又难过起来。
- 他仍想让对方知道自己的委屈和牵挂，却怕那个人根本不愿意听。

### S08｜206–213 小节　（正在面对）

- 他暂时不愿再设想该怎样向对方开口了。 〔181–205 ③〕
- → 那份想念还在，他却宁愿先把它留给自己，不去猜测说出来会怎样。

### S09｜214–215 小节　（没在想）

- 他心里还是放着那个人。
- 这一刻他只是默默想念，没有继续盘算要不要开口。

### S10｜216–225 小节　（正在面对）

- 他不再因为自己还在想念，就急着责怪自己太舍不得。 〔24–65 ②〕
- → 那份委屈没有消失，他也不必为了守住它就否认自己想亲近的心。 〔66–91 ③〕
- → 他开始容许自己想象，有一天或许能把这份牵挂说出来，同时也不隐瞒自己仍在难受。 〔148–180 ②〕

### S11｜226–241 小节　（正在面对）

- 可一想到对方也许并不愿意理解，他还是怕自己说出口之后得不到回应。 〔216–225 ③〕
- → 他仍然不敢真的向对方表达，却不再因为这份害怕，就把已经承认的想念收回去。 〔216–225 ①〕

### S12｜242–253 小节　（正在面对）

- 他又停留在想念那个人的心情里，想念从前那份不用设防的自在。 〔116–147 ②〕
- → 他没有再急着压下这份柔软，哪怕委屈依然留在心里。 〔216–225 ②〕
- 他还是希望有机会和对方自然地说出心里话，却不想为此先假装自己已经不难过。 〔148–180 ②〕

### S13｜254–288 小节　（正在面对）

- 他仍不知道对方是否在意这段关系，更不知道对方是否愿意理解他的委屈。
- 他仍舍不得这个人，也不想为了显得自己没有让步，就硬说那些过去的亲近已经不重要了。 〔216–225 ②〕
- 他愿意继续珍惜这份感情，也愿意让自己的难受留有位置。 〔242–253 ②〕
- 至于是否真的向对方坦露这一切，他还没有决定，也不知道两个人以后能否重新亲近。 〔226–241 ②〕
