# Op.60｜关系图

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3　（还说不清）

- 他还说不清自己究竟在盼什么，只是格外想亲近一个人。
- 想到那个人时，他心里会不由自主地柔软下来。
- 每当想让这份感觉多停留一会儿，他又会本能地往回收。
- 他不知道自己为何谨慎，那点喜欢似乎随时能放下，他却舍不得。

### 4–16　（正在面对）

- 他还不知道自己怕什么，所以暂时不急着决定这份喜欢要走到哪一步。
  - ← 提供理由：（1–3）「说不清盼什么」
- → 他不必现在想清两人会怎样，也不必因为喜欢就向对方期待什么。
- → 这样想着，他慢慢安心地亲近那个人，享受能自由给予温柔的感觉。
- → 他不必时时确认自己的心意有没有被对方领会，也觉得自己似乎比先前更自在。
- → 他渐渐不再提防喜欢，觉得只要亲近一直自然、无需追问计较，当时便已足够。

### 17–23　（正在面对）

- 这份亲近已经让他尝到幸福，他开始希望这份喜欢不只属于眼前。
  - ← 唤起：（4–16）「自然亲近已足够」
- → 想到长久，他便想到自己能珍惜对方，却不能决定对方是否也珍惜自己。
- → 他偶尔盼自己在对方心里也很特别，原先无需确认的事开始牵动他的心。
  - ← 动摇：（4–16）「自然亲近已足够」
- → 他有些意外，一份已经让他满足的亲近，仍会使他盼望得到更多。　✦ 满足照出未满足

### 24–34　（正在面对）

- 他不愿让新添的紧张破坏先前的快乐，也不想让喜欢变成无形的催促。
  - ← 提供理由：（17–23）「满足后仍盼更多」
- → 他提醒自己，珍惜一个人可以关心、给予，也能真心为对方高兴。
- → 他觉得这些快乐本身就很实在，没必要再从中索取一个保证。　✦ 分清
- → 这样想让他轻松下来，他也更愿意付出，不再小心衡量给了多少。
- → 他为毫不勉强地热切喜欢而幸福，仿佛积攒的温柔终于能尽情给出。
- → 那一阵，他甚至相信只要不提出要求，就能尽情地爱而不会失去什么。

### 35–39　（正在面对）

- 欢喜稍稍平息后，他仍想知道自己是否也被对方放在心上。
  - ← 动摇：（24–34）「不提要求就无所失」
- → 这个念头让他难堪，刚为无所求高兴，转眼又盼望被看见。
- → 他怀疑那些体贴里是否一直藏着自己不愿面对的期待。
- → 他说自己毫无所求似乎不够诚实，却知道此前的快乐并非为了换取对方珍惜。　✦ 分清
- → 他暂时不替自己辩解，也不急着用新的热烈盖过这份难堪。

### 40–50　（正在面对）

- 他仍然喜欢，却不愿继续用慷慨证明自己。
  - ← 提供理由：（35–39）「无所求后又盼被看见」
- → 他想保留自己的期待，也不愿时时检查对方是否在意。
- → 他开始只留心此刻真心愿意给予的关切，不再急着想两人以后会怎样。
- → 他可以盼对方好、安静惦念，也能因心里有这个人而生出柔和喜悦。
- → 他发现有些快乐只需留在心里，就已经足够鲜明。
- → 他暂时忘了自己为何那么在意对方是否珍惜，只觉得细细喜欢一个人很甜。
- → 之前的疑问仍没解决，只是不再让它占满心思。

### 51–61　（正在面对）

- 这份不声张的甜意留得久了，他开始觉得喜欢不像起初那样轻巧。
  - ← 改写：（40–50）「暂忘对方是否珍惜」
- 他原想把喜欢留在自己心里，免得对方为难，也让自己少受期待牵动。
- → 他对对方的珍惜渐渐加深，感情也难以收放，更盼自己的关切被领会。
- 他仍觉得不催促对方是对的，也舍不得拿自己的期待换来别人的迁就。
- → 他不愿让对方为自己的期待费心，只能独自想着那些还没有结果的盼望。
- → 对方给过他的甜蜜如此细致，他舍不得把这份喜欢减轻。
- → 他发现从前似乎能轻轻放在心里的喜欢，如今已不容易收放自如。
- ⟲ 仍在起作用：（40–50）「保留期待不查对方」

### 62–71　（正在面对）

- 既然已经这样深地喜欢，他忽然想让自己充分感受它，不再时时提防。
  - ← 提供理由：（51–61）「喜欢难以轻放」
- → 他回想起安心亲近、愿意付出时的满足，以及独自珍藏的细小甜蜜。
- 他发现这些幸福早在没有承诺时就已发生，即使仍有期待也是真的。
  - ← 说明：（4–16）「暂不期待关系结果」
  - ← 说明：（24–34）「温柔终于能尽情给出」
  - ← 说明：（40–50）「惦念本身有甜意」
- → 他想让自己尽情喜欢一次，不再因为怕受伤而连高兴都小心翼翼。
- → 他放下对付出多少的逐一衡量，心意深一些时也不再提醒自己收回。
- → 他为自己竟能这样爱着一个人而高兴，一度觉得欢喜大过所有顾虑。
- → 他知道前面仍没有保证，却几乎感觉不到那份不确定的沉重。

### 72–77　（正在面对）

- 他刚刚毫无保留地面对自己的感情，欢喜稍退后，心里想要的东西反而清楚起来。
  - ← 唤起：（62–71）「暂时感觉不到无保证」
- → 他不只想尽情喜欢，也想知道对方是否同样渴望靠近、愿意珍惜彼此。
  - ← 改写：（17–23）「盼喜欢长久」
- → 他明白自己想要得很深，也知道对方可以没有同样热烈的心意。　✦ 分清
- → 他一时不知道该往哪边走，退回谨慎像辜负刚面对的心意，继续盼又怕变成索取。
- → 他想不出既能继续盼望又不勉强对方的办法，反复思量让他委屈，也有些厌倦自己。

### 78–83　（正在面对）

- 他既放不下喜欢，也决定不了对方的心意，便暂时不作选择。
  - ← 提供理由：（72–77）「找不到两全办法」
- → 他可以暂缓靠近，也可以让眷恋留在心里，不急着把它藏起来。
- → 两种心思仍同时存在，却不再互相催逼，他可以带着愿望安静地喜欢。
- → 他也能接受自己没有把握，心里因此松开了一点。
- → 先前的为难并未消失，只是他终于不必时时和它争执。
- → 那份原本被拉紧的温柔，又能自然地留在他心里。
- ⟲ 仍在起作用：（72–77）「谨慎与期待难两全」

### 84–92　（正在面对）

- 不再强迫自己消除渴望后，他重新感到亲近一个人的快乐。
  - ← 唤起：（78–83）「温柔重新自然留存」
- → 这次的从容不同于最初，他已尝过期待的紧张和无从确认的难堪。
- → 他知道自己再深的喜欢也不能替对方决定，却仍然愿意继续喜欢。
- → 他渐渐明白，体贴和想被珍惜可以同时存在，偶尔期待也不会抹掉真心。　✦ 分清
- → 他愿意全心投入，面对感情的深度，也不再为自己的热切羞怯。
- → 他为经历犹疑后仍能高兴而感动，过去警惕的愿望也可一同存在。
- → 他知道自己仍可能受伤，心里也有顾虑，却仍愿尽情感受幸福。
- ⟲ 仍在起作用：（72–77）「对方可有不同心意」

### 93–102　（正在面对）

- 既然连渴望都不必遮掩，他更清楚地感到自己多想和这个人亲近。
  - ← 提供理由：（84–92）「知道会受伤仍愿喜欢」
- → 他想把积攒的温柔全都给出去，让亲密不只停在自己的愿望里。
- → 他也想被同样深切地珍惜，知道两人能共同拥有怎样的幸福。
- → 这些愿望曾让他紧张难堪，如今暂时不再折磨他。
- → 他觉得自己有很多可以给予的感情，一时甚至觉得已经足够。
- → 他几乎被满足感淹没，想靠近、想被爱、想把自己交给这份亲近。
- → 尽管对方没有给出新的保证，他仍真切觉得能这样爱着，心里已充实得不可思议。
- → 他一时顾不上以后会怎样，只愿让这份幸福完整地属于此刻。
- ⟲ 仍在起作用：（72–77）「想知道是否彼此靠近」

### 103–110　（正在面对）

- 可就在幸福仍很鲜明时，他隐约觉得，自己想要的事还没有全都实现。
  - ← 限制：（93–102）「爱着本身很充实」
- → 他尽情爱着、盼望被爱后，才看清自己还想得到对方同样深切的选择。　✦ 满足照出未满足
  - ← 改写：（93–102）「想被同样深切珍惜」
- → 想到这里他仍会酸楚，刚才的欢喜如此真实，他更难不去想对方是否珍惜自己。
- → 他已知道自己能爱得多深，再也难说服自己对方是否同样珍惜都无所谓。　✦ 知道更多反而更尖锐
- → 他想留住自己心里的安心，也舍不得因怕得不到而削弱这份感情。
- → 他发现克制确实曾让他安心，却没能让渴望消失。　✦ 办法的限度
- 他也发现尽情投入确实让他幸福，却不能保证自己不会失望。　✦ 办法的限度
- → 他心里仍急切想靠近，也仍坚持不勉强对方，两边都不肯退让。
- → 他不愿为了求得轻松就仓促舍弃一边，宁可带着这份不轻松继续。　✦ 选择的代价

### 111–116　（正在面对）

- 带着仍未平息的牵挂，他渐渐不再要求自己找到一种不会受伤的爱法。
  - ← 限制：（103–110）「克制没让渴望消失」
  - ← 限制：（103–110）「投入不能免去失望」
- → 他仍想被对方选择，因为那个人重要，即使愿望未必实现，也不必假装从未盼过。
- 他舍不得放弃克制，因为对方有自己的心意，不必与他相同。　✦ 分清
- → 若要对方负责消除他的全部不安，两人的亲近也会变得不自在。
- → 他仍会遗憾，却已明白带着遗憾也能好好喜欢一个人。
- 他仍珍惜过去的快乐，知道即使问题未解，那些快乐也都是真的。
  - ← 说明：（4–16）「自由给予温柔」
  - ← 说明：（24–34）「温柔终于能尽情给出」
  - ← 说明：（40–50）「暂忘对方是否珍惜」
  - ← 说明：（62–71）「欢喜暂压过顾虑」
- → 这些快乐让他一次次愿意向前，也让他更清楚这个人有多重要。
- → 他仍盼对方也珍惜自己，却不再凭对方是否同样珍惜来判断自己的真心，也不再用保留多少证明清醒。　✦ 分清
- → 他知道以后还会失望，也会因没法再靠近一步而疼痛，却不拿这些催促对方或否认感情。
- → 他愿继续认真喜欢、充分欢喜，也接受自己决定不了的事。
- → 他终于不必在热切与克制之间赶走一个，能渴望被爱，也尊重对方自由。
- → 他不把渴望变成对方的义务，也不因尊重自由收回自己的心。
- → 他没得到想要的一切，却不再为了顾全自己和对方，先放弃最想给予的爱。
- ⟲ 仍在起作用：（72–77）「对方可有不同心意」
