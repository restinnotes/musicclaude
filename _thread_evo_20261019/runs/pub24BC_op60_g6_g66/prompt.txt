- S02-B4-p1：几次柔软的落音，像一根温柔的刺。
- S02-B4-p2：它既像是甜蜜的确认，又带着一点无法排遣的惆怅：眼前的好还在，心里却已经有一点鼻酸。
- S02-B4-p3：因为太喜欢眼前的东西，所以还没有失去，就已经生出一丝舍不得，忍不住希望这一刻再慢一点过去。

### S03
- S03-B1-p1：刚才的歌声渐渐退到后面，剩下一阵阵流动、盘旋，水波般的摇曳托着身体，只感觉自己在摇晃、漂浮，暂时“不去哪里”。
- S03-B1-p2：像说过一句重要的话以后，人还停留在那句话里面，有一点陶醉，有一点走神。
- S03-B1-p3：也可以想成亲密交谈后忽然安静下来：沉默并不尴尬，反而很舒服；
- S03-B1-p4：身体还在这里，心却已经慢慢漂远。
- S03-B2-p1：约在第20–21小节，持续摇曳中忽然冒出几句短促、稍显急切的声音。
- S03-B2-p2：像心里闪过一个急于表达的念头，却很快又沉了回去；
- S03-B2-p3：它只在水面上露了一下头，没有变成一场真正的倾诉。
- S03-B3-p1：水波还在晃，流动却像受了牵绊。
- S03-B3-p2：约在第20–22小节，平稳的“对话”有一种被水下暗流拖住的感觉，音乐绕远、滞留，某些声音像被挂在半途。
- S03-B3-p3：若换一种更纷乱的听法：思绪像被风吹碎的倒影，粼粼闪烁却难以拼凑完整；
- S03-B3-p4：仿佛亲密的谈话触碰到了某些无法解开的结。
- S03-B3-p5：音乐并未走向悲剧，却在那份顺畅之中生出了阻力。

### S04
- S04-B1-p1：第24小节，熟悉的歌声又回来了。
- S04-B1-p2：两道紧贴的声线仍像两个人在耳边低语，呼吸挨得很近；
- S04-B1-p3：但这一遍比第一次更华丽、更迫切。
- S04-B1-p4：细密的花腔仿佛水面折射的光斑，突然晃得人睁不开眼。
- S04-B1-p5：也可以像听一个人谈往事：刚开始还能微笑着讲，讲着讲着语速变了；
- S04-B1-p6：本来一句话已经够了，却忍不住再说一遍，又折回来补上更多细节。
- S04-B2-p1：到第32小节附近，高处的长颤音像夕阳在水面切出的最后一道金光，亮得几乎刺眼，仿佛把情绪一下照到最炽热的地方。
- S04-B2-p2：这又像想把最深的情意说出口，却在喉咙口颤抖、哽咽：右手在高处悬停，左手的水波却仍推着你往前走。
- S04-B2-p3：这股情绪一瞬间像是完整地打开了，可音乐一边奋力向高处攀升，一边又渐渐收弱，并没有稳稳落下。
- S04-B2-p4：到第34小节，摇晃渐渐放慢，仿佛方才吐露的话语还在空气里回荡，人却安静下来。
- S04-B3-p1：还有一种几乎能落到手指上的触感：原本只是轻轻握着另一个人的手，后来不自觉地握得更紧。
- S04-B3-p2：自己也许还没有意识到在害怕什么，动作已经先透露了出来。
- S04-B3-p3：另一幅更晃荡的画面，是想用力抱紧对方、牢牢抓住当下；
- S04-B3-p4：但你越用力，水面的颠簸就越剧烈，船舱内的平衡就越脆弱。
- S04-B4-p1：这里还有一种甜蜜，会让人鼻子发酸。
- S04-B4-p2：明明美好的东西仍在发生，两道声线仍贴得那么近，左手的水波却一直向前流，仿佛每一秒都在倒数。
- S04-B4-p3：还没有失去什么，就已经舍不得了；
- S04-B4-p4：歌声越美，越让人想多留在这一刻。

### S05
- S05-B1-p1：此前还像要用力抱紧对方、牢牢抓住当下；
- S05-B1-p2：到了这里，音乐却仿佛自己松开了手，深吸一口气。
- S05-B1-p3：刚才那阵想攥紧不放的冲动，终于轻轻退了下去。
- S05-B2-p1：原来一直托着你的水波和摇晃，忽然像被抽掉了。
- S05-B2-p2：丰满的声音只剩下一条单薄、孤零零的旋律，在空中漫无目的地游走。
- S05-B2-p3：人仿佛突然失去了脚下的支撑，连时间也松开了；
- S05-B2-p4：像小船漂进一片起雾的水域，前路未卜。
- S05-B3-p1：刚才仿佛还有两个人在贴近耳语，到了这里，交谈却戛然而止。
- S05-B3-p2：一个人从“我与你”的亲密中抽身，转而跌回自己的内心；
- S05-B3-p3：像一句快到嘴边的重要话又悬在了唇边，心里甚至会闪过一个小小的疑问：“这份幸福是真实的吗？
- S05-B3-p4：它能维持多久？”

### S06
- S06-B1-p1：方才悬在空中的音乐，到了第40小节，像重新落在一片陌生的水域。
- S06-B1-p2：熟悉的摇摆回来了，却不再沉甸甸：左手的波浪变薄、碎成细密的小纹。
- S06-B1-p3：光线仿佛从暖金色的水面滑入古桥阴影，空气一下凉了；
- S06-B1-p4：A大调的新旋律清澈、舒展，近乎一支朴素的牧歌。
- S06-B1-p5：那份纯净像清凉、空灵的月光，又让人忽然想起童年，或年少时第一次心动的下午。
- S06-B2-p1：这支清澈的新歌并非全然平静。
- S06-B2-p2：旋律压低声音，旁边另一条声线不时回应、插话，又不断与它纠缠；
- S06-B2-p3：像一个念头好不容易安静下来，却又回来：“算了”“但还是放不下”。
- S06-B2-p4：声音时而靠近，时而退开。
- S06-B2-p5：那份低声也有另一种听法：像一个人说着说着，忘记了自己正被别人看着，不是哭泣或崩溃，只是不再努力显得完整。
- S06-B3-p1：这份安静，也像一个人独自退回了内心深处。
- S06-B3-p2：白天明明和某个人相处得很好，晚上回到家后，心头却泛起一阵酸楚。
- S06-B3-p3：独处把幽微的感受放大了：即使是最亲密的人，也没法陪你走进心里的每一个角落。
- S06-B3-p4：甚至当美好的时光仍在眼前流淌时，恍惚间却像已经成了回忆。
- S06-B4-p1：也可以听成：还有人听到的恰好不是感官欲望退潮，而是一种更贴身的沉醉。
- S06-B4-p2：那份感觉像水波一样，一层一层荡开，像独自回想一段关系：气味、身体感觉、幻想、遗憾、快感混在一起。
- S06-B4-p3：它越舒服，反而越让人失去方向。

### S07
- S07-B1-p1：这段歌声再回来，原先的清澈还没消失，底下却越来越不安分：伴奏音符变密，内声部像水底的暗涌不断攀爬，低音的八度与切分像沉重的脉搏在催促。
- S07-B1-p2：原先压着的感受反而变成了动力，光是安静地享受已经不够，身体仿佛被一股更深的渴望推着往前。
- S07-B1-p3：那热度甚至像情欲、执念与对生的眷恋，从心底一齐翻涌上来。
- S07-B2-p1：这股热度还有一种舍不得抽身的快感。
- S07-B2-p2：像独处时反复回想一段关系，记忆慢慢变成气味、身体感觉、幻想、遗憾和快感，混在一起。
- S07-B2-p3：它有一点情色性的暖意；
- S07-B2-p4：越舒服，越让人失去方向。
- S07-B2-p5：你明知道自己正在被卷进去，却暂时不想出来。
- S07-B3-p1：什么都还很好，可你已经听见时间正在经过。
- S07-B3-p2：音乐并没有彻底变暗，美也没有消失；
- S07-B3-p3：只是这一刻纵然完美，你也没有办法让它停住。

### S08
- S08-B1-p1：旋律忽然变得直接、舒展，近乎意大利歌剧里的咏叹调。
- S08-B1-p2：没有哲学，没有防卫，没有分析。
- S08-B1-p3：歌句越唱越开，情绪一再抬高，连熟悉的摇荡也仿佛在轻轻催促。
- S08-B2-p1：同一阵歌声又明亮、轻盈、透气，像重新接触到阳光和风。
- S08-B2-p2：连身体也像恢复了弹性，甚至带一点玩心；
- S08-B2-p3：这份灵动，也像轻快的调情与回应。
- S08-B3-p1：到了第69–70小节，歌声没有踏踏实实地落定，反而向上散掉、蒸发了。
- S08-B3-p2：约第71小节，正当你以为它还会继续唱下去，它却戛然而止，转入片刻静意。
- S08-B3-p3：快乐的余温尚在，心头却已泛起一阵怀念。

### S09
- S09-B1-p1：前面那股几乎要冲出去的势头，到了这里却突然收住脚步。
- S09-B1-p2：熟悉的摇摆退到一旁，像话说到要紧处一下顿住。
- S09-B1-p3：到第76–77小节，飘渺的颤音和轻柔的和弦悬在半空。
- S09-B1-p4：整段像两个人对视到呼吸都停了：强烈的渴望还在，却引而不发，那股绷紧的劲尚未真正松开。
- S09-B2-p1：像忽然陷进一片低气压里：前面的明朗被收走，声音一层层下沉、变暗，注意力反而越来越集中。
- S09-B2-p2：四周并未彻底暗下去，更像阳光被薄雾柔化——光还在，只是隔了一层朦胧的雾气。
- S09-B3-p1：这阵安静也像一个人在听自己刚才说过的话。
- S09-B3-p2：不急着接下一句，只是听着自己的余响；
- S09-B3-p3：心里还在反复问：“刚才那是真的吗？
- S09-B3-p4：接下来怎么办？”
- S09-B4-p1：也可以听成：也可以想象成一个人在激动地说了很多话之后，忽然抬头看见夜空，意识到眼前的美好其实比自己的愿望大得多。
- S09-B4-p2：心里的不安还没有得到回答，却暂时不再占据全部心思。

### S10
- S10-B1-p1：像一直微微绷着肩膀的人，终于长长呼出一口气，胸腔一下打开。
- S10-B1-p2：前面压着没说的话有了舒展的空间，眼泪也终于不必再忍。
- S10-B1-p3：心事并没有解决，只是这一刻不必再强迫自己控制感受；
- S10-B1-p4：明亮得让人有点想哭。
- S10-B2-p1：原先载着小船不断前行的摇荡，仿佛被一阵突然吹进来的清风拨开。
- S10-B2-p2：时间也松了，旋律像在时间里开出一小块空地，暂时不必跟着水波一直往前走。
- S10-B2-p3：不过它很短，更像一口终于呼出的气，不是能永远躲进去的避风处。
- S10-B3-p1：这一刻，轻的不只是音符。
- S10-B3-p2：连自己的身体也仿佛失去了重量，像灵魂从躯壳里飘出来，悬浮在夏夜的微风中。
- S10-B3-p3：原先压在肉身上的沉重负担，仿佛一下子再也碰不到飘起来的自己了。
- S10-B4-p1：右手在高音区织出极细、极亮的小音符，像晨曦里的银色蛛丝，又像从天上飘下的细雨，几乎没有重量。
- S10-B4-p2：其中一串琶音又仿佛飞瀑从极高处倾泻而下，清亮地落进水里。

### S11
- S11-B1-p1：刚才近乎失重、像在梦里漂着，到了第84小节，同一艘船、同一首歌忽然变得异常直接、异常现实。
- S11-B1-p2：开头旋律刚一唱出便收弱的那份谨慎不见了：厚重的和弦托起歌声，左手温柔的水波翻成横跨几个八度的惊涛骇浪。
- S11-B1-p3：像之前一直压在心底的话终于说出口：「这是我的感情，我不再为它道歉。」
- S11-B2-p1：这次重逢，也像多年后重新走进一间旧房子。
- S11-B2-p2：家具可能没变，可你知道的事情已经太多了。
- S11-B2-p3：原来的温柔再次出现，却有了新的重量；
- S11-B2-p4：而知道它有多珍贵以后，心里反而更容易发疼。
- S11-B3-p1：到第92小节附近，刚才铺开的力量仿佛短暂地悬在半空，像在等待下一股更大的浪潮。
- S11-B3-p2：若还记得第32小节那次差一点抵达、却没能真正落定的高潮，这里又可以听出另一层：前面悬置已久的期待，终于得到了某种满足。
- S11-B3-p3：但这还不是全曲的结束。
- S11-B4-p1：这份灿烂也可能让人不太舒坦。
- S11-B4-p2：像夕阳在沉入地平线前那一两分钟，天空烧得血红金亮，光芒刺眼到让人想流泪；
- S11-B4-p3：胸口非但没有舒展开来，反而被压迫得发痛。
- S11-B4-p4：喜悦已经浓烈到身体几乎承受不住。

### S12
- S12-B1-p1：第62–71小节那支异常温柔、晴朗的歌，在这里被放到了最大尺度：声音明亮、开阔，近乎英雄式，内声部却彼此拉扯，音乐一浪高过一浪。
- S12-B1-p2：前面做梦、走神般的状态忽然聚焦到“此时此地”，内心的私语仿佛放大成天地的共振。
- S12-B1-p3：倒不是“我的感情终于变得比一切都伟大”，反而像整个人被卷进一个比自己更大的世界，连“我”都暂时退到了后面。
- S12-B2-p1：这股声浪却不是一路畅通地冲到顶。
- S12-B2-p2：原本温柔的歌带上近乎恳求的力量，旋律一次次向上伸展，仿佛还想要更多，却始终不能完全满足。
- S12-B2-p3：到第96–100小节附近，乐句末端仍有牵扯、延迟与紧张，那口气一直悬到102–103小节交界，才得到一次重大的释放。
- S12-B3-p1：这份狂喜像高烧。
- S12-B3-p2：它也可以像久别重逢：刚才还能够微笑、寒暄，忽然却抱紧对方，久久不愿松手；
- S12-B3-p3：又可以是喉咙发紧、眼眶湿润，快乐到连自己想笑还是想哭都分不清。

### S13
- S13-B1-p1：第103小节像终于把长久悬着的心愿说出口，音乐却没有就此收住。
- S13-B1-p2：它在反复与渐强中继续往前推，106小节以后越绷越紧，仿佛怕一停下，刚刚得到的东西就会消失。
- S13-B1-p3：像刚抵达一道浪峰，身后又有更大的浪推上来，直逼110–111小节交界处的又一次冲击。
- S13-B2-p1：也可以听成：也可以把这份阴影听成一段突然插进来的苦涩话语：像刚刚最坚定地说了一声「是」，心里马上有个声音反问：「可是呢？」
- S13-B2-p2：那个「可是」并没有证明先前的幸福是假的；
- S13-B2-p3：只有真正相信过，怀疑才会这么疼。
- S13-B3-p1：起初好像仍在坚持、确认刚才那种灿烂；
- S13-B3-p2：到107小节以后，明亮的声音里却渐渐掺进越来越尖锐、暗沉的成分。
- S13-B3-p3：幸福没有消失，悲伤却进入了幸福内部。
- S13-B3-p4：有时真正「得到」也会疼——像终于把珍贵的东西握在手里，才恍然明白这么好的一刻终究无法永远留住。
- S13-B4-p1：下方的脚步仿佛牢牢踩住地面，不肯移动、不肯让步；
- S13-B4-p2：上方的声音却一次次往下落，像叹息，又像有什么还在反复纠缠。
- S13-B4-p3：仿佛人明明站得很稳，胸口却一沉再沉。

### S14
- S14-B1-p1：就在声音渐渐变轻的时候，第113小节左手内声部幽幽地唱出一句，像男中音独自沉思。
- S14-B1-p2：先前熟悉的歌唱与摇荡，仿佛又回来了一次。
- S14-B1-p3：到115小节，右手一道细碎的琶音像水花溅落夜空——低低的一声回望之后，还有最后一闪。
- S14-B2-p1：音乐没有像梦一样慢慢飘走。
- S14-B2-p2：第116小节，最后几下和弦干脆、沉重，低音像铁锚落入水底，把还在摇荡的小船一下定住。
- S14-B2-p3：也可以想成一个人经历了强烈的内心震荡后，站起来，整理衣服，关上门。
- S14-B3-p1：110–111小节交界，最后一股浪头像是又猛推了一下；
- S14-B3-p2：进入终结句，音乐才真正松下来、轻下来。
