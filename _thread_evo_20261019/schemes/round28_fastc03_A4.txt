你要一次写出一首器乐作品最终使用的Thread（线），用于在逐段听感记录旁阅读。线必须是同一个人经历的同一件事；只读线就能跟着他的处境走下去，每段也要与给定TARGETS的体验性质大体接得上。不是对音乐的解说，更不是把珠子的画面变成人物事实。

【段落】
{SECTIONS}

【Center（给定，不修改）】
{CENTER}
Center是回头看时能把全篇组织成一件事的中心，不是人物开头必须知道的结论，也不是每段必须复述的题目。

【已通过宏观评审的路线候选】
{ROUTES}

【珠子的体验性质TARGETS】
{TARGETS}
你不能看见原珠子，也不要猜其用词、画面、人物动作或音乐细节。

【第一步：选能容纳复杂体验的单一路线】
从ROUTES中选一条base_route，不能拼接。先检查人物自己的前因和一件事是否站得住，再考察该路线能否在不编外部事情的情况下自然容纳TARGETS里多种并存的性质。不是选和最多情绪词相似的一条，也不是因为某段TARGETS改变就更换故事主线。

【第二步：先做隐形的逐段体验配置】
对TARGETS的每段，在内部区分：人物正在经历的同一个处境、最显出来的体验、仍在场的另一层体验、如果确实有的话本段内部的先后变化。compatible_bundle代表可以同时成立的侧面，tensions代表可能并存的张力或不同听法；不必二选一，也不能强迫冲突的听法成为两次真实事件。各bead_id的qualities和temporal_shape是匹配线索，不是剧情指令。只在人物已有处境许可时，把多个体验分给不同条目或让一条的单一事情带出复杂感受；不要把多个独立心理动作塞成一条长句。

【第三步：让覆盖在成稿时自然发生】
一次写完整条线；每段的文字首先回答这个人身处什么真实的内在处境，其次让该处境可感地承担TARGETS的力度、方向和并存层次。轻松不必是做出决定，沉重不必是退缩，短促变化不必是新的认知；音乐起落不得直接扮演人的行动。不能只挑一个最容易写的体验而把其余层次压平，也不能每颗珠子配一句相似的情绪释义。书写时留意同段各bead_id是否有一处确实相近的生活感受及前因，遇到兼容性问题优先选择人物已有处境的另一面，而不是编造故事或改写珠子的意义。所有段落连起来仍须保持一件事的自然发展，允许没有新转折的段落与未解决的结尾。

【第四步：从已写正文反查匹配】
只把真正有情境对应的bead_id写入相应items的covers；同一条可对应多颗，多个条目也可共同照应一颗，但不得虚构覆盖。检查每段哪些体验仍无着落；除非再覆盖必然要编出新外部事实，否则不能用“无需覆盖”代替写作时的充分考虑。关系标签、前文引用、delta及established全部从实际正文推出，不能为匹配TARGETS改写人物已成立的事实。

正文按给定段落顺序写，每段2–4条，每条仅一句完整、自然的话，只承担一件有用的事；经历少的段落就用两句短句，不把多个独立心理步骤挤进一条。不同条可以是相继发生、并存的感受、某事的后果或已有状态的延续，不必硬造段内转折。全篇从头到尾一次写成，不逐段分别生成，不在成稿后另设改写或补珠子层。人物不靠新编的事件、道具、场景、对白、他人举动或对他人隐秘心态的断言推进，也不把TARGETS里的意象、想象的情节或音乐的物理动作直接变成现实。语言要像普通人讲自己当时真在乎的事，清楚而不说教；允许适当否定，避免固定口头禅或心理概念反复充当句子的内容。

最后根据实际正文填写元数据：cite只列该条真实提及或依赖的更早条目ID（包括本段前面的条目），仅主题相似不算；covers只列本段该条确有相近情境的bead_id，不为凑覆盖乱标，也不逐颗解释；relation只按正文标“没在想/还说不清/正在面对”，仍在挂念或打量Center不能标“没在想”；delta_type只从接口给定六类选，情绪变强不自动算“新变化”，delta没有真正新增便留空；established只收确实在正文首次成立的重要状态、认识、意愿或选择，并准确指向那一条；uncovered_targets仅记录强行覆盖须虚构外部事实的珠子及原因，没有则为空数组。

【输出】
只输出合法JSON，不要解释、Markdown或额外字段；接口固定为：
{
  "base_route": "route_id",
  "segments": [
    {
      "sec": "S01",
      "relation": "没在想/还说不清/正在面对",
      "items": [
        {"id": "S01-1", "text": "...", "cite": [], "covers": ["bead_id"]}
      ],
      "delta_type": "新变化/后果/实行已有想法/延续/回到旧处但有新增/暂时没在想",
      "delta": "本段真正新增的心理事实；没有则为空字符串"
    }
  ],
  "uncovered_targets": [
    {"bead_id": "...", "reason": "若要覆盖就必须虚构外部事实的原因"}
  ],
  "established": [
    {"claim": "首次成立的重要认识或状态", "first_established": "Sxx-x"}
  ]
}
segments按输入段落顺序完整填列，示例中的值只表示字段形状；不增加字段。
