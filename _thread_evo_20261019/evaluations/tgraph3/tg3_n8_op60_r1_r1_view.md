# Op.60｜关系图

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3　（还说不清）

他**还说不清自己究竟盼什么**，只知道心里多了一个格外愿意亲近的人，想到对方就有些柔软；可当他想让这感觉多留一会儿，又**本能地往回收**。他明明没有什么现在非决定不可的事，也不懂自己为何谨慎。那点喜欢似乎随时可以放下，他偏偏舍不得放下。


### 4–16　（正在面对）

因为还不知道自己在怕什么，他暂时不给喜欢安排去向，不急着知道两个人会怎样，也不因喜欢就向对方有所期待，心里慢慢安稳下来。他发现自己可以自在地关心、给予，**不必时时确认心意是否被领受**，也不必因对方重要就失去从容，有时甚至比先前更自在；这份**真实的快乐**让他逐渐不再提防自己的喜欢，甚至有点满意自己的宽和。那一阵他觉得，只要亲近可以自然地发生，不追问、不计较，**这样已经足够**。　✦ 分清

- ← 提供理由：（1–3）「还说不清自己究竟盼什么」

### 17–23　（正在面对）

正因为这份亲近已经让他尝到幸福，他开始盼它不只属于眼前：从前只须允许自己喜欢，现在还**希望它能长久**。想到长久，他便想到对方有自己的心意；他能决定怎样珍惜，却**不能决定对方是否同样珍惜自己**，原先觉得不必确认的事开始牵动他。他起初只偶尔想，**自己在对方心里是否也有特别的位置**，没有打算索取什么；可这一点轻微的期待已让他不再那么安稳，他意外地发现，原本满足的亲近仍会生出更多盼望。　✦ 满足照出未满足

- ← 唤起：（4–16）「真实的快乐」
- ← 动摇：（4–16）「这样已经足够」 —— 当下觉得足够，并没有替他回答这份亲近能持续多久。
- ← 动摇：（4–16）「不必时时确认心意是否被领受」

### 24–34　（正在面对）

他不愿这点新添的紧张毁掉先前的快乐，也知道对方从没答应什么，**不想让喜欢变成催促**，于是试着放宽自己的心。他提醒自己，关心、给予、为对方高兴本来就能带来快乐，无须为这些心意讨一个保证；这样想让他真的轻松起来，想确认的紧张渐渐退去，他反而更愿意付出，也不再计算给出多少，或担心多给一点就显得自己更在乎。

他为这种毫不勉强的热切感到幸福，仿佛一直小心保存的温柔终于有了足够宽敞的地方。那一阵，他甚至相信只要**不提出要求**，就可以**尽情地爱**，也**不会失去什么**。

- ← 唤起：（17–23）「自己在对方心里是否也有特别的位置」
- ← 限制：（17–23）「不能决定对方是否同样珍惜自己」
- ⟲ 仍在起作用：（4–16）「真实的快乐」

### 35–39　（正在面对）

等这阵充盈的欢喜稍稍平息，他仍然想知道自己是否也被对方放在心上。刚为无所求而高兴，转眼又**盼望被看见**，让他**难堪**，也让他怀疑自己的体贴里是否一直藏着期待。他不能诚实地说自己毫无所求，却也知道之前给予时的快乐确实真实，不能说那都是为了换回回应；他一时答不出来，只好留在不自在里，不辩解，也不再拿热烈来掩盖。　✦ 办法的限度

- ← 限制：（24–34）「不提出要求」
- ← 动摇：（24–34）「不会失去什么」
- ⟲ 仍在起作用：（17–23）「自己在对方心里是否也有特别的位置」

### 40–50　（没在想）

这份难堪没有削弱他的喜欢，却让他不愿再靠慷慨证明自己，也不想不停检查对方的心意或逼自己毫无期待。他改为留意此刻确实愿意给出的关切：希望对方好，安静惦念，因心里有那个人而高兴，不再每次拿心意衡量两个人的关系。这样的喜欢更隐秘，也更贴近他自己；有些快乐**只留在心里**已足够鲜明，他一度沉浸在**细细喜欢的甜意**里，甚至暂时忘了为什么在意回应。先前的疑问并未解决，只是暂时没有占满他的心。

- ← 唤起：（35–39）「难堪」
- ← 改写：（17–23）「希望它能长久」
- ⟲ 仍在起作用：（35–39）「盼望被看见」

### 51–61　（正在面对）

可是这份不声张的甜意停留久了，便不再像起初那么轻巧。他本想把喜欢只放在自己心里，让对方不为难，也免得自己受期待牵动；如今随着珍惜加深，他已不大能随意收住或放开，惦念加重，更希望关切被对方领会，有时并无特别缘由，心里也满是那个人。他仍觉得不催促对方是对的，**舍不得用自己的期待换取迁就**，只能**独自容纳那些没有着落的盼望**。他没有因此觉得喜欢不值；正因独自珍惜曾给他细致的甜蜜，他才**舍不得减轻**，只是这份感情**已经有了重量**。　✦ 办法的限度

- ← 限制：（40–50）「只留在心里」
- ⟲ 仍在起作用：（40–50）「细细喜欢的甜意」；（17–23）「自己在对方心里是否也有特别的位置」

### 62–71　（正在面对）

既然喜欢已有这样的重量，他忽然不愿再时时把它当成要约束的东西。他回想最初安心亲近、后来主动给予的满足，还有独自珍惜时那些细小的甜蜜，知道它们都曾真实地发生，并没有依赖对方给出承诺；即使自己仍有期待，也**无须怀疑那些幸福**。　✦ 分清

他不愿因害怕受伤就连高兴也畏缩，想**充分地喜欢一次**，不急着追问结果，也不替以后准备退路。积攒已久的眷恋因而变成他能够坦然享受的热情：他不再计算付出了多少，心意深一点时也不急着收回；有一阵**欢喜大过顾虑**，他虽知道没有保证，却几乎感觉不到其中的沉重。

- ← 唤起：（51–61）「已经有了重量」
- ← 提供理由：（4–16）「真实的快乐」
- ← 提供理由：（40–50）「细细喜欢的甜意」
- ← 改写：（24–34）「尽情地爱」 —— 他先前把不提要求当成放开去爱的条件，这次即使有期待，也允许自己享受热情。
- ← 动摇：（1–3）「本能地往回收」

### 72–77　（正在面对）

正因为刚刚毫无保留地承认了自己的喜欢，等那阵欢喜稍稍落定，他才发现自己想要的不止是尽情喜欢：他还**盼这份深情能与对方相遇**，想知道对方是否也渴望靠近、愿意彼此看重。他也清楚，自己爱得再热烈，都**不能据此要求对方同样回应**。　✦ 知道更多反而更尖锐

他于是陷入两难：若退回先前的谨慎，仿佛辜负刚刚才肯承认的心意；若继续放任盼望，又怕自己有一天把关心和要求对方满足自己混在一起。两边都有舍不得放弃的东西，他**想不出能同时保全的办法**，心里委屈，也有点厌倦这种反复为难。　✦ 选择的代价

- ← 唤起：（62–71）「充分地喜欢一次」
- ← 改写：（17–23）「自己在对方心里是否也有特别的位置」
- ← 动摇：（62–71）「欢喜大过顾虑」
- ⟲ 仍在起作用：（51–61）「舍不得用自己的期待换取迁就」；（1–3）「本能地往回收」；（24–34）「不想让喜欢变成催促」

### 78–83　（正在面对）

他终于不愿逼自己立刻在两边选一个了。既然此刻减轻不了喜欢，也无法决定对方怎样想，他就**暂时不决定什么**：想靠近也不用马上行动，心里的眷恋仍然可以留着。**两种心思仍然都在**，却暂时不再相互催逼；他能怀着盼望安静地喜欢，也承认自己没有把握。为难没有消失，只是他不再时时同它争执，**心里松开了一点**，原先拉扯得发紧的温柔也重新自然起来。　✦ 分清

- ← 改写：（72–77）「想不出能同时保全的办法」
- ← 提供理由：（17–23）「不能决定对方是否同样珍惜自己」
- ⟲ 仍在起作用：（51–61）「舍不得减轻」

### 84–92　（正在面对）

不再逼自己消除渴望以后，他又感到最初亲近的快乐，但他知道这次的从容不同：先前是还不知道自己会盼望那么多，如今他经历了期待的紧张、得不到确认时的难堪，也知道深情不能替对方作答，仍愿意喜欢。他无需再用无所求证明体贴，也不因偶尔想被珍惜就怀疑整份感情；这让他更坦荡地投入，不躲避心意的深，也不再为热切害羞。他甚至为自己经过这么多犹疑还能这样高兴而感动，心里那些一度使他警惕的愿望此刻仿佛都能与喜欢同在、得到伸展。他**已经知道自己可能受伤**，依旧**愿意充分承认眼前的幸福**。　✦ 分清

- ← 提供理由：（78–83）「暂时不决定什么」
- ← 唤起：（78–83）「心里松开了一点」
- ← 改写：（4–16）「真实的快乐」
- ← 改写：（35–39）「难堪」
- ⟲ 仍在起作用：（62–71）「无须怀疑那些幸福」

### 93–102　（没在想）

既然连想被爱都不必遮掩，他便更真切地感到自己想与对方亲近，盼积攒的温柔能被对方接住，盼自己也**被同样深切地珍惜**，想知道两个人共同的幸福可以有多丰盛。那些愿望曾经令他紧张、难堪，这一阵却暂时不再像缺憾一样折磨他；他只觉得自己有那么多可以给予，甚至一时觉得不必再添什么。想靠近、被爱、把整个自己交给这份亲密的愿望仿佛同时得到了抒发，他**几乎被满足淹没**；虽然**没有得到任何新的保证**，他仍真切觉得能这样爱着已经令自己格外充实，一时顾不上以后，只愿这份幸福完整地留在此刻。

- ← 唤起：（84–92）「愿意充分承认眼前的幸福」
- ← 改写：（35–39）「盼望被看见」
- ⟲ 仍在起作用：（72–77）「盼这份深情能与对方相遇」

### 103–110　（正在面对）

就在幸福还很鲜明时，他也觉出其中仍有一处没有着落。他已让自己尽情喜欢、尽情盼望，所以这时更加清楚：自己能够拥有深情，却无法凭它获得**对方同样深切的选择**；刚才的欢喜真实，想起这份欠缺时的**酸楚**也真实，反倒因此格外难忽略。他知道自己爱得多深，已很难再说服自己，对方怎样回应都无所谓。　✦ 满足照出未满足

他又明白，把安稳全押在对方的回应上，会让对方在接受喜欢时还得负责消除他全部不安；可为躲开失望而减轻自己的心意，他也舍不得，因为那份喜欢确实给过他巨大幸福。**克制曾使他安心**，却没有消除渴望；**尽情投入曾使他幸福**，也不能排除将来的失望。他此刻依旧迫切想靠近，也依旧不愿勉强对方，**两种心思都没有退让**，反倒因为他已舍不得否认任何一边而更冲突；他宁可受着不轻松，也不愿匆忙舍掉任何一边来骗自己平静。　✦ 办法的限度

- ← 改写：（93–102）「几乎被满足淹没」
- ← 失效：（24–34）「不会失去什么」
- ← 限制：（24–34）「尽情地爱」
- ← 说明：（93–102）「没有得到任何新的保证」
- ⟲ 仍在起作用：（93–102）「被同样深切地珍惜」；（51–61）「独自容纳那些没有着落的盼望」；（72–77）「不能据此要求对方同样回应」；（78–83）「两种心思仍然都在」

### 111–116　（正在面对）

带着还没平息的牵挂，他慢慢不再逼自己找一种不会受伤的爱法。他仍然想被选择，因为对方对他很重要，他真心希望两个人彼此亲近；即使愿望可能落空，他也不必装作没有想过。他同样舍不得克制，因为对方有自己的心意，愿不愿亲近都该由对方自己决定；若让对方承担自己所有期待，那份亲近也会变得不自在。他想到这里仍会遗憾，却不再逼自己先消除遗憾才能继续爱。　✦ 分清

回头看，他曾小心亲近，曾不求确认地给予，曾独自珍惜，也曾让热情尽情充满自己；每一次快乐都是真的，并没有因为最后的难题未解就白费，如今他甚至更珍惜它们。它们曾让他一次次愿意向前，使他知道这个人有多重要；而反复收住心意又放开心意，也使他知道两种办法都无法让他避开受伤的可能。他仍盼得到回应，也仍会克制，却不再靠有没有回应判断自己的真心，也不拿收住多少证明自己清醒；他知道以后还会想多靠近、会疼痛，却不再因此否认喜欢或催促对方。他愿继续把那个人放在心里，认真地喜欢、充分地欢喜，也承受自己决定不了的部分：他尚未得到想要的一切，却能让想被爱和不勉强对方的心思一起留下，不必为了守住双方就先收回自己的爱。　✦ 选择的代价
