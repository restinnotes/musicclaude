  - [S09 ③]「他不愿因为没答案就不认相处的开心」——“不认相处的开心”很不像自然汉语。“不认”可以说不认账、不认输，但这里想表达的应该是不愿否定已经得到的快乐。 → 他不愿因为还没有答案，就否认和对方在一起时的快乐
  - [S10 ①]「他不想再压着盼望求平静」——“压着盼望求平静”明显有压缩句子的痕迹。“盼望”被当作一个要按住的东西，“求平静”又显得书面而生硬。 → 他不想再为了让自己安心，就硬把心里的期待压下去
  - [S10 ③]「这样没让对方给答案，但他看清了自己到底盼的是什么。」——“这样没让对方给答案”像是在描述一种办法没有奏效，但他本来就没有向对方要答案，因果关系不够贴切。 → 他仍然不知道对方的心意，却终于看清了自己究竟在期待什么。
  - [S12 ①]「他想把收着的关心都给对方，连以后的琐事和难处都想替对方分担。」——“把收着的关心都给对方”有点生硬；“替对方分担”也不如“帮对方分担”自然。尤其是“以后的琐事和难处”，没有说清是对方将来的生活，还是两人共同的生活。 → 他想不再克制自己的关心，甚至想到将来对方生活中遇到什么琐事和难处，自己都愿意陪着一起分担。
  - [S12 ②]「他顺着这些事想到以后两人一起过日子」——“顺着这些事想到”不够顺口，而且“这些事”指的是上一句里尚未发生的琐事和难处，指代有些虚。 → 想着想着，他甚至开始想象以后和对方一起过日子的情景
  - [S13 ②]「这回连还没来的以后也舍不得」——这里的感情有意思，但“还没来的以后”叠得拗口，“舍不得”后面又缺少明确的动作，读者需要想一下才能明白是舍不得放弃想象中的未来。 → 这一次，他连想象中还没到来的未来都舍不得放手
  - [S13 ④]「他不想把这份难过交给对方解决，也不肯为了省事说自己不想要。」——“把难过交给对方解决”像心理分析术语，不太像人在叙述自己的感受；“为了省事”则把一件痛苦的感情取舍说得过于轻巧，“不想要”也缺少宾语。 → 他不想逼对方来安慰自己、替自己消除难过，却也不愿为了少受点煎熬，就假装自己并不想和对方有那样的未来。
  - [S14 ①]「就算收着心意也还是会难过，给得再多也换不来确定的以后。」——“收着心意”“给得再多”“确定的以后”连续使用抽象而省略的表达，尤其“确定的以后”不太自然，让本来应该清楚有力的领悟显得含混。 → 就算把心意藏起来，他还是会难过；不管为对方付出多少，也无法保证两人将来一定能在一起。
  - [S14 ②]「也想起后来放开去关心的快乐，哪一段都不想抹掉。」——“放开去关心”不太符合汉语习惯；“哪一段都不想抹掉”虽然能懂，但没有说清是不想否定那段经历，还是不想忘记它。 → 也想起后来不再克制、尽情关心对方时的快乐。他不愿否定其中任何一段经历。

### 5.6 第1次：7 分，24 处
- 最主要的问题：最大的毛病不是意思不清，而是心理过程经常被压缩成一串抽象概念和关系词。作者其实很清楚人物每一步在想什么，但落到句子里，常写成“关心、亲近、期待、回应、热情、保证、以后”之间的逻辑运算，像在给情绪做结构说明，而不是一个人真的在经历这些情绪。因此不少句子单独看都能懂，连续读却会有明显的提纲感和分析腔。
- 一再出现：抽象名词反复承担太多内容，如“亲近、关心、回应、期待、热情、以后”，具体感不足，久读容易发木。；为了压短句子，经常省掉宾语、因果或“既然……为什么……”一类连接，造成“只能决定去关心”“开口像要回应”“眼下能永远继续”这种需要回读的表达。；有些动词和宾语搭配得不自然，例如“失去亲近”“收住念头”“痛快地相处”“不认开心”。；频繁使用“收着、给、留住、换来”来处理感情，形成一套反复出现的控制／交换隐喻，后面会显得模式化。；“这样、这些事、那点、这份”一类指代词较多，有时所指不够扎实，使句子像是在接前文论证，而不像自然叙事。；核心意思有几轮相似的重复：怕期待变成催促、怕付出是在换回应、既想继续喜欢又想得到回应。心理递进本身存在，但措辞变化不够，容易让读者觉得在原地反复解释。
  - [S02 ①]「一想到对方就想去关心」——“去关心”有点像在说一项要执行的行动，放在感情里略机械。 → 一想到对方，就忍不住想关心对方。
  - [S03 ②]「自己只能决定去关心」——“决定去关心”太理性、太程序化，而且“只能决定”读起来有点拧。 → 他发现自己能决定的，只有要不要继续关心对方。
  - [S04 ①]「让对方跟他待着没压力」——“跟他待着没压力”很口语，但搭得不太顺，像临时拼出来的说法。 → 让对方和自己相处时没有压力。
  - [S04 ②]「不老怕自己更在乎了」——“不老怕”虽然能懂，但“更在乎了”的时态和前面的持续心理不太贴，读起来会顿一下。 → 也不再总担心自己会越来越在乎。
  - [S04 ③]「他给得越多」——“给”具体指关心、热情还是付出，不够清楚；这里突然抽象成“给”，有点空。 → 他越是对对方上心，越舍不得这份亲近结束。
  - [S05 ①]「越怕失去亲近」——“失去亲近”搭配不自然，一般会说失去“这份亲近”或“不再亲近”。 → 可他越怕失去这份亲近，越明白再怎么热情也换不来保证。
  - [S05 ③]「怎么真心关心，又还是盼着回应？」——句法压得太狠，“怎么”后面缺少完整的提问关系，像把“既然……为什么……”硬缩掉了。 → 既然是真心关心对方，为什么自己还是会盼着回应？
  - [S07 ①]「光靠自己关心对方那点开心已经不够了」——修饰关系不清，“自己关心对方那点开心”要读第二遍才知道“那点开心”指什么。 → 光是关心对方带来的那点开心，已经不够了。
  - [S07 ②]「又怕开口像要回应」——“开口像要回应”搭配不成立，实际意思是怕自己的开口听起来像在向对方索取回应。 → 又怕一开口，就像是在向对方要回应。
  - [S07 ④]「他不指望眼下能永远继续」——“眼下”本身不是能“继续”的东西，省掉的宾语太重。 → 他已经不指望眼下这样的日子能一直继续。
  - [S08 ②]「相处久一点，他慢慢又像起初那样」——“相处久一点”容易被理解成“这一次多待一会儿”，这里实际说的是又过了一段时间。 → 又相处了一阵，他慢慢变得像起初那样。
  - [S08 ③]「只管痛快地和对方相处」——“痛快地相处”不是很自然的搭配；“痛快”更适合修饰做某件具体的事或一种释放感。 → 只管痛痛快快地对对方好，享受两个人相处的日子。
  - [S09 ①]「明白现在开心不代表有了许诺」——“有了许诺”有点书面又生硬，而且“开心”和“许诺”直接对举，关系说得太省。 → 也明白现在相处得开心，并不等于对方已经给过什么承诺。
  - [S09 ②]「想收回来，可一收又觉得是在逼自己别喜欢」——前面的“期待”不是很适合直接说“收回来”，“一收”又太省略，动作感不明确。 → 他想把这份期待压下去，可一压又觉得是在逼自己别再喜欢。
  - [S09 ③]「不认相处的开心」——“不认开心”不太像自然说法，通常会说“不愿否认”或“不想抹掉”。 → 他不愿因为没有答案，就否认两个人相处时是真的开心。
  - [S10 ①]「压着盼望求平静」——几个抽象动作挤在一起，意思能猜到，但很像提纲语言，不像人在自然地叙述心理。 → 他不想再为了让自己平静，就硬把这份盼望压下去。
  - [S10 ③]「这样没让对方给答案」——“这样没让……”关系有点别扭，也容易短暂理解成“没能让对方给答案”。 → 他没有因此逼对方给出答案，却看清了自己到底在盼什么。
  - [S11 ②]「现在想要回应也是真心的」——“想要回应是真心的”语义搭配略怪；真不真通常说的是感情、愿望或感受本身。 → 而现在会盼着对方回应，也同样是真的。
  - [S12 ①]「把收着的关心都给对方」——“收着的关心”稍显造作，前文虽然一直用“收着”，但这里把“关心”当成一包可以存着再交出去的东西，痕迹比较重。 → 他想把以前不敢尽情表达的关心，都给对方。
  - [S12 ②]「他顺着这些事想到以后两人一起过日子」——“顺着这些事想到”比较含混，“这些事”具体指琐事和难处，连接到“一起过日子”时显得像逻辑说明。 → 想到这些琐事和难处，他又自然想到以后两个人一起过日子。
  - [S13 ②]「这回连还没来的以后也舍不得」——有一点刻意的文学化。“以后”尚未发生，却直接说“舍不得”，意思虽能懂，但需要停一下转换成“舍不得那个想象中的未来”。 → 这回，他连那个还没到来的以后都已经舍不得了。
  - [S13 ③]「现在想一起过日子的念头，怎么收也收不住了」——“收住念头”不算很自然，而且连续两个“收”显得用力。 → 可现在，想和对方一起过日子的念头怎么也压不下去了。
  - [S13 ④]「也不肯为了省事说自己不想要」——“为了省事”太日常、太轻，和这里的情感重量不匹配，像嫌麻烦所以放弃，削弱了原本的心理冲突。 → 也不愿为了让自己少难受一点，就骗自己说其实并不想要。
  - [S14 ①]「给得再多也换不来确定的以后」——“给得再多”又一次把具体的关心和付出抽象成“给”；“确定的以后”也稍显概念化。 → 就算再怎么对对方好，也换不来一个确定能共同拥有的以后。

### 5.6 第2次：6.5 分，27 处
- 最主要的问题：最主要的问题是语言经常为了把心理逻辑压进一句话，而把正常汉语会展开说的关系压得太紧。于是出现不少“意思能懂，但第一遍不像人会这么说”的表达，尤其是抽象名词和动作硬搭在一起，例如“决定去关心”“压着盼望求平静”“有了许诺”“不认相处的开心”。整篇的心理线其实很清楚，问题主要不在逻辑，而在句子的自然度和具体度。
- 一再出现：反复把感情和关系写成可以“收、放、给、留住、换来”的东西；单次使用没问题，但密度高了以后会显得机械。；“亲近、关心、回应、期待、以后”几个抽象词出现得非常频繁，而具体动作、场景和感受较少，导致语言有提纲感。；常把主语、宾语或中间关系省掉，例如“眼下能永远继续”“一想可能落空”“说自己不想要”，读者需要自行补全。；为了简短而连续堆动词或心理概念，例如“压着盼望求平静”“光靠自己关心对方那点开心”，容易形成翻译腔或分析笔记腔。；有些句子为了保持前后概念对应，宁可沿用同一个词或反义结构，牺牲了自然口语感，例如反复使用“收着／放开”“给得多／换不来”“想要回应／不给答案”。
  - [S02 ②]「想让这样的日子多些」——“日子多些”搭配有点生硬，像把“日子”当成可直接增减数量的东西，读到这里会稍微顿一下。 → 想多过些这样的日子。
  - [S03 ②]「自己只能决定去关心」——“决定去关心”太抽象、太像在分析行为机制，不太像人在描述自己的感情。 → 他发现自己能做的，只是继续关心对方。
  - [S04 ①]「让对方跟他待着没压力」——“跟他待着没压力”口语结构不完整，通常会说“跟他待在一起时没压力”。 → 让对方跟他待在一起时不用有压力。
  - [S04 ②]「不老怕自己更在乎了」——“不老怕”很口语，但后面的“自己更在乎了”接得不顺；这里实际说的是不再害怕自己越来越在乎。 → 也不再总怕自己会越来越在乎。
  - [S05 ①]「越怕失去亲近」——“失去亲近”搭配不自然。“亲近”在这里是两人的关系状态，通常要说“失去这份亲近”。 → 可越怕失去这份亲近，越明白再热情也换不来保证。
  - [S05 ②]「怀疑自己说不求回报是骗自己」——句法压得太紧，“说不求回报”像少了一层成分，第一眼容易读成“说不求回报这句话”。 → 怀疑自己说自己不求回报，其实是在骗自己。
  - [S05 ③]「怎么真心关心，又还是盼着回应？」——“怎么……又还是……”的结构不顺，而且“真心关心”和“盼着回应”之间的并存关系没有说清楚。 → 怎么会一边真心关心对方，一边又还是盼着得到回应？
  - [S07 ①]「光靠自己关心对方那点开心已经不够了」——定语层层粘在一起，“关心对方那点开心”容易被误读，得回头拆句子。 → 光是关心对方带来的那点开心，已经不够了。
  - [S07 ②]「又怕开口像要回应」——“开口像要回应”不是很自然的说法；真正担心的是一开口就显得像在向对方索取回应。 → 又怕一开口，就像是在向对方讨回应。
  - [S07 ④]「他不指望眼下能永远继续」——“眼下”本身是时间状语，却被当成了“能继续”的东西，省略得过头。 → 他不再指望眼下这样的亲近能永远继续。
  - [S08 ②]「相处久一点，他慢慢又像起初那样」——“相处久一点”像临时条件句，也容易理解成“只要再相处久一点”；这里其实是在叙述又相处了一阵之后的变化。 → 又相处了一阵，他慢慢又像起初那样，不用许诺也很开心。
  - [S08 ③]「只管痛快地和对方相处」——“痛快地相处”搭配比较别扭。“痛快”常形容做事、说话或情绪释放，用来修饰“相处”不太贴。 → 更愿意主动关心对方，只管享受和对方相处的开心。
  - [S09 ①]「现在开心不代表有了许诺」——“有了许诺”略显生硬，也容易让人问是谁给了谁许诺。 → 现在相处得开心，也不等于对方给了什么承诺。
  - [S09 ②]「他怕期待露出来像催对方」——“期待露出来像催对方”压缩得太厉害，主语关系不够清楚，像是“期待”自己在催人。 → 他怕自己的期待一露出来，就显得像是在催对方。
  - [S09 ③]「他不愿因为没答案就不认相处的开心」——“不认相处的开心”很不像自然汉语。“不认”通常接事实、账、错等，这里更自然的是“不否认”或“不抹掉”。 → 他不愿因为没有答案，就否认两人相处时的开心。
  - [S10 ①]「他不想再压着盼望求平静」——“压着盼望求平静”把三个抽象动作硬挤在一起，意思能猜到，但不像人会自然说出来的话。 → 他不想再靠压住自己的盼望来换取平静。
  - [S10 ③]「这样没让对方给答案」——字面上像是“这种做法没有让对方产生给答案的行为”，表达很机械。这里其实是在说他没有逼迫对方。 → 这样做并没有逼对方给出答案，但他看清了自己到底在盼什么。
  - [S11 ②]「现在想要回应也是真心的」——“想要回应”本身不太适合用“是真心的”来判断，语义搭配有些拧。 → 现在他也确实真心盼着得到回应。
  - [S11 ③]「想到这也有点感动」——“感动”由什么引起不够明确：是被自己的坚持感动，还是被这份喜欢本身感动？读者需要自行补。 → 想到自己明知如此还是愿意继续喜欢，他心里也有点触动。
  - [S12 ①]「他想把收着的关心都给对方」——“把关心收着”“把关心都给出去”的隐喻叠在一起，有点刻意，也延续了全文频繁把感情当作可收放之物的写法。 → 他不想再收着自己的关心，想尽可能多地对对方好。

  - [S08-B2]「人变得有弹性」——“有弹性”一般形容材料、身体动作或处理事情的方式，直接说一个人因音乐而“变得有弹性”，稍显机械。 → 整个人也跟着轻快、灵动起来，甚至生出一点玩心。

  - [S11-B2]「天空烧得血红金亮」——“血红金亮”不是自然的颜色组合词，既想写颜色又想写亮度，几个形容词挤成一团。 → 天空被染成刺眼的红金色，像整片天都烧了起来。

  - [S11-B4]「前面长期欠着的期待，终于得到了某种满足」——“欠着的期待”搭配别扭，像有人欠了一笔账；“前面长期”也不顺，后半句“某种满足”则显得过于含糊。 → 此前一直悬而未决的期待，到这里终于像是有了回应。
  - [S12-B1]「第62–71小节那支异常温柔、晴朗的歌，在这里被放到了最大尺度」——“把歌放到最大尺度”很像从外语直译过来的抽象说法，具体是音量更大、气势更宏伟，还是情绪更强，都需要读者自己换算。 → 第62–71小节那支温柔、晴朗的旋律，在这里被大大铺展开来，变得明亮而宏伟。

  - [S12-B3]「才得到一次重大的释放」——“得到一次重大的释放”偏抽象、书面，有点翻译腔，不如直接写那股紧张怎样消散或爆发。 → 那口一直悬着的气，直到102–103小节交界，才终于痛快地释放出来。

  - [S13-B2]「起初好像仍在坚持、确认刚才那种灿烂」——“坚持灿烂”“确认灿烂”都不是自然搭配。这里把两个抽象动词并列，却没有给它们合适的宾语。 → 起初，音乐似乎还在反复确认刚才那份灿烂的喜悦。
  - [S13-B2]「明亮的声音里却渐渐冒出越来越尖锐、暗沉的东西」——“东西”过于笼统，前面的“尖锐、暗沉”又分别指向不同的听觉特征，读起来像作者还没想好自己究竟听到了什么。 → 明亮的声音里却渐渐透出一丝尖锐，音色也开始变得阴沉。
  - [S13-B3]「下方的脚步仿佛牢牢踩住地面，不肯移动、不肯让步」——“下方的脚步”说法含糊，应该是在指低声部；脚步本来意味着移动，紧接着又说不肯移动，比喻有点互相抵触。 → 低音像一双牢牢踩在地上的脚，无论如何也不肯挪动。
  - [S14-B1与S14-B2]「第116小节，最后几下和弦干脆、沉重……110–111小节交界，最后一股浪头像是又猛推了一下」——两段单看都通顺，但先讲116小节结束，再倒回110–111小节，时间顺序突然倒退，而文中没有提示这种倒叙。作为逐段听感记录，会让人读得一顿。 → 建议先放S14-B2，写110–115小节如何渐渐平静，再放S14-B1，写116小节最后几下和弦如何收束全曲。
  - [S14-B3]「右手一道细碎的琶音像水花溅落夜空」——“水花溅落夜空”有空间方向上的别扭：水花通常向上溅起，或向下落入水中，不太会“溅落夜空”。 → 右手一道细碎的琶音，像夜色中突然溅起的一串水花。
  - [S14-B3]「低低的一声回望之后，还有最后一闪」——“一声回望”把听觉量词和视觉动作直接拼在一起，“低低的”也不知道修饰声音还是回望，读起来不顺。 → 像低声回头道别之后，水面上又闪过最后一点光。
  - [S14-B4]「最后那几下向上的和弦动作」——“向上的和弦动作”像在生硬翻译音乐术语，既不如“上行和弦”简洁，也不如“和弦一步步向上”形象。 → 最后那几个向上推进的和弦，又像接住了开头悬着的话，终于把它说完。

### 5.6 第1次：7 分，36 处
- 最主要的问题：主体文字其实有相当多鲜明、可感的比喻，情绪推进也大体清楚；最影响语言质感的是“听感散文”和“资料整理/分析笔记”混在了一起。尤其各段括号里频繁出现“原稿所述”“覆盖某段”“明确定位”“宽述”“不能进一步细定位”之类编校语言，甚至残留来源编号，会把读者一下从音乐经验里拽出来。正文自身的主要问题则是有些地方为了追求细腻和新鲜，把抽象概念、身体感觉和动作比喻叠得过密，于是出现“放弃对重力的控制”“掉进自己”“期待欠着”“往上争取”这类意思能猜到、但不像自然汉语会说的话。

  - [S05 ①]「他怕承认失望就算变心」——少了“一……就……”的关系提示，“承认失望”也略硬。这里需要让人清楚：他害怕的不是失望本身，而是觉得承认失望意味着自己变了心。 → 他怕自己一承认失望，就等于变了心。
  - [S05 ②]「他以前为坚定骄傲，现在这么逼自己太受苦，不想再靠坚持证明自己了。」——“为坚定骄傲”缺少自然的修饰成分；“现在这么逼自己太受苦”尤其不像日常汉语。“证明自己”又没说清究竟证明什么，力度因此减弱。 → 他以前曾为自己的坚定感到骄傲，可如今这样逼自己，实在太苦了。他不想再靠苦撑来证明自己有多在乎。
  - [S05 ③]「不这么催自己以后」——这个时间状语的语序不顺。“不这么催自己”直接接“以后”，读起来需要重新整理句子关系。 → 等他不再这样逼自己，才肯承认，自己一直舍不得那种不用防备的亲近。
  - [S06 标题与①]「（没在想） / 他全心想着真正快乐过的生活」——标题明确说“没在想”，正文开头却是“全心想着”，字面上直接打架。如果“没在想”指不再分析、只是在感受，就需要换一种说法，否则读者会停下来判断是不是前后矛盾。 → （不再追问） / 他沉浸在过去真正快乐过的日子里。
  - [S06 ①]「让喜欢和依恋留着，不急着辩护。」——“让喜欢和依恋留着”是把感情当成东西存放，表达生硬。“辩护”也缺少对象：是在为自己的留恋辩护，还是为过去的生活辩护？ → 他允许自己继续喜欢、继续依恋，不急着为这份感情找理由。
  - [S06 ③]「他能因为喜欢去付出，也能亲近生活，不用处处用力。」——“因为喜欢去付出”虽然能懂，但不如“出于喜欢而付出”自然。“亲近生活”比较空，既不像与人亲近，也不明确是享受生活还是参与生活。 → 他可以单纯因为喜欢而付出，也能好好享受生活，不必事事都那么费力。
  - [S06 ④]「他不管这份向往有没有用，只管爱惜，连压着的委屈和想念也留着，舍不得离开。」——这一句有连续几个悬空的动作：“爱惜”什么？为什么要把委屈“留着”？又是舍不得离开什么？读者虽然能猜到大意，但得替作者补足太多关系。 → 他不再管这份向往有没有用，只想好好珍惜它。连那些一直压在心底的委屈和想念，他也愿意慢慢感受，舍不得从这段回忆里抽身。
  - [S07 ①]「从那份满足里出来」——“从满足里出来”是比较生硬的空间化说法。这里其实是从沉浸或回忆的状态中恢复过来。 → 从那种满足感中回过神来
  - [S07 ③]「他原以为理由够了就能安心，现在既怕失去所爱，也没法光留在回忆里，不敢像第一次那样投入。」——“理由够了”比较含糊。更大的问题是后半句的逻辑衔接：怕失去所爱、不能只留在回忆里，本来都可能促使他行动，为什么得出的结果反而是不敢投入？需要把“怕行动也伤害所爱”这层顾虑明确接上。 → 他原以为只要想清楚为什么要做，就能安心投入。可现在，他既怕失去所爱，又怕自己的行动反而伤害它。他不能只守着回忆，却也不敢像上回那样一头扎进去。
  - [S08 ①]「他又回到那种曾让他满足的亲近里，只想再爱惜一会儿。」——“回到亲近里”不太自然，“爱惜一会儿”也搭配不顺，因为爱惜通常不是用时间长度来描述的动作。这里更像是想多停留在那份感觉中。 → 他又沉浸在那种曾让自己满足的亲近感里，只想再多感受一会儿。
  - [S08 ②]「任由心里的不舍留着。」——“任由”一般接一个自行发生或发展的动作，“留着”却像主动保存东西。两个词放在一起不够协调，也重复了 S06 中保存情绪的表达方式。 → 他依然珍惜这份喜欢，也不急着压下心里的不舍。
  - [S09 ②]「迟疑除了因为害怕，也是真舍不得那种可以相信、亲近的生活。」——“除了因为害怕，也是舍不得”前后结构不平行。“可以相信、亲近的生活”也有歧义，好像“生活”同时是相信和亲近的对象，但实际想说的是人与人之间的信任和亲近。 → 这回他明白，自己迟疑，不只是因为害怕，也是因为真的舍不得那种能信任别人、与人亲近的生活。
  - [S10 ③]「就不用逼自己先丢开安宁。」——“丢开安宁”有些生硬，把一种内心状态说成可以随手丢弃的东西。“先”也不清楚是在什么行动之前。 → 他也就不必逼自己立刻放弃眼前的安宁。
  - [S11 ①]「尽力曾给他力量，只是没顾好全部牵挂」——“尽力曾给他力量”像是把一句较自然的话压缩得过头了。“顾好全部牵挂”则有搭配问题：人能够照顾的是牵挂的人或事，而不是牵挂这种感情。 → 曾经全力以赴，让他找回了力量。只是他没能顾及所有在乎的人和事。
  - [S11 ③]「所以他带着不舍和害怕继续承担。」——“承担”到这里突然结束，缺了宾语。承担责任、承担代价都可以，单说“继续承担”显得话没讲完。 → 所以即使心里仍有不舍和害怕，他还是决定继续承担自己该承担的责任。
  - [S12 ①]「他认下可能的代价，不等完全不怕了，现在就去做能做的事。」——“认下可能的代价”不如“愿意承担代价”自然。“不等完全不怕了”双重否定绕口。“现在就去做能做的事”也有一种把意思硬塞进句子的感觉。 → 为了珍爱的生活，他愿意承担可能的代价。即使心里还有害怕，他也决定从现在开始，做自己力所能及的事。
  - [S12 ②]「但他不嫌自己害怕和不舍了，投入的热切和畅快又回来了。」——“不嫌自己害怕和不舍”很不自然，像是在嫌弃两件物品。“投入的热切和畅快”也堆了几个抽象词，不如直接说他重新有了投入的热情。 → 牵挂还在，但他不再责怪自己会害怕、会舍不得。那股投入时的热情和畅快又回来了。
  - [S13 ①]「可想到退回安宁也护不住它」——“退回安宁”不算自然搭配。“退回”通常接某个地方、状态或立场，这里的“安宁”没有交代成一个可以退回去的处境。 → 可想到就算退回去，只守着眼前的安宁，也保护不了所爱。
  - [S13 ②]「想到争取的就是那种能真心亲近的生活」——“争取的就是生活”可以理解，但“能真心亲近的生活”缺少亲近的对象。“真心亲近”通常指人与人的关系，不能直接修饰生活，读者需要自己转换。 → 想到自己努力争取的，正是那种能真心与人亲近的生活。
  - [S13 ④]「他尽了眼下能尽的力，还愿意爱那种生活」——“尽了眼下能尽的力”意思重复得比较明显。“还愿意爱那种生活”也显得刻意，好像爱这种生活需要重新作出许可或承诺，而前文主要说的是他一直珍惜它。 → 他已经尽了眼下所能，心里依然珍惜那种生活。

### 5.6 第1次：6.5 分，23 处
- 最主要的问题：最大的问题不是单句完全看不懂，而是大量抽象词被当作具体事物来搬动、保存、进入、退出或照料，比如“顾好牵挂”“回到亲近里”“丢开安宁”“退回安宁”“保住决心”。意思大多能猜出来，但汉语搭配不够自然，读者常常需要先把句子在脑中翻译成正常说法，才明白人物到底在想什么。再加上很多对象被省略，语言就容易呈现出“概念关系图”或创作笔记的感觉，而不是一个人在自然地讲述内心经历。
- 一再出现：抽象名词被过度实体化：反复出现“保住、顾好、回到、丢开、退回、护住”等动作去支配“牵挂、亲近、安宁、决心、生活”等抽象概念，容易产生生造搭配。；为了压缩而频繁省略必要的主语、宾语或逻辑成分，如“理由够了”“不急着辩护”“继续承担”“争取的就是”，导致句子虽然短，却更需要读者补全。；“那种生活”“珍爱的东西”“所爱”“牵挂”“安宁”“争取”“投入”“用力”等抽象代称重复很多，而且所指会变化，越往后越容易需要回看才能确定具体指什么。；不少句子使用相似的“他……又怕……所以/但……”结构，心理逻辑交代得很密，却缺少更具体的动作、场景或感受，因此整体有较强的分析稿、提纲稿气息。；个别地方把本来很自然的意思说得过度绕曲，例如“那股劲是不是真心”“舍不得否认”“真心待人的温柔”；这种不寻常搭配在全文中反复出现，是最明显的‘不像人话’来源之一。
  - [S02 ③]「但他一直没顾上另一份牵挂」——“牵挂”通常指心里的挂念，不太能直接说“顾上牵挂”；这里像是把“牵挂的对象”省掉了，读时要补一层意思。 → 但他一直没顾上另一件放不下的事
  - [S03 ②]「想跟人自在亲近、不用防备」——“自在亲近”直接并在一起有点生硬，“自在”更自然地修饰“亲近”；顿号式的连接也让句子略像提纲。 → 想自在地跟人亲近，不用防备
  - [S03 ③]「他开始怀疑当初那股劲是不是真心」——“真心”一般说人的心意或行为动机，“那股劲是真心”搭配不上，意思能猜到，但会顿一下。 → 他开始怀疑当初那股劲到底是不是出于真心
  - [S04 ①]「可他也舍不得否认行动曾帮自己走出犹豫」——“舍不得否认”很别扭。“舍不得”通常针对放弃、离开、伤害某物，这里实际想说的是“不愿否认”或“不能否认”。 → 可他也不愿否认，行动曾帮自己走出犹豫
  - [S04 ③]「为保住决心，他硬撑着反复追问还能怎样做」——“保住决心”“硬撑着追问”都是偏生造的搭配，几个抽象动作叠在一起，读起来不像自然叙述。 → 为了不让自己动摇，他硬逼着自己一遍遍想还能做些什么
  - [S05 ①]「他怕承认失望就算变心」——这里的“就算”容易先被读成“即使”，而实际意思应是“就等于”，会造成瞬间歧义。 → 他怕一承认失望，就等于承认自己变了心
  - [S05 ②]「他以前为坚定骄傲，现在这么逼自己太受苦」——“为坚定骄傲”缺少“自己的”，“这么逼自己太受苦”也不太符合汉语习惯，像把两种句式硬接到了一起。 → 他以前为自己的坚定感到骄傲，可现在这样逼自己，实在太苦了
  - [S05 ③]「不这么催自己以后」——“不这么……以后”的时间结构不够顺，口语里通常会说“不再……之后”。 → 不再这样催逼自己之后
  - [S06 ①]「让喜欢和依恋留着，不急着辩护」——“辩护”缺少对象：替什么辩护、向谁辩护都不明确。前半句是感受，后半句突然出现一个论辩动作，衔接也有些跳。 → 让那份喜欢和依恋留着，不急着替自己的向往找理由
  - [S06 ③]「他能因为喜欢去付出，也能亲近生活」——“亲近生活”很抽象，也不是很常见的自然搭配。前面的“亲近、相信别人”都很具体，到这里忽然变成了概念性的说法。 → 他能因为喜欢而付出，也能安心地投入这样的生活
  - [S06 ④]「连压着的委屈和想念也留着，舍不得离开」——“舍不得离开”的对象不清楚：是舍不得离开这种状态、这份向往，还是舍不得离开什么人？句尾会让人回头找指代。 → 连一直压着的委屈和想念也任它们留着，他舍不得从这份向往里出来
  - [S07 ②]「连那种生活需要的温柔也耗掉」——“生活需要温柔”可以理解，但把“温柔”直接归为“那种生活需要的”略显概念化，像分析术语，不太像人在叙述自己的感受。 → 连过那种生活所需要的温柔也耗掉
  - [S07 ③]「他原以为理由够了就能安心」——“理由够了”过于压缩，像工作笔记里的简称。自然汉语一般会说理由“充分”或“想明白了”。 → 他原以为只要理由足够充分，自己就能安心
  - [S08 ①]「他又回到那种曾让他满足的亲近里」——“回到……亲近里”把“亲近”当成了一个可以进入的空间，搭配很不自然。 → 他又回到那种曾让他满足的亲近状态里
  - [S09 ②]「那种可以相信、亲近的生活」——字面上像是“生活”本身可以被相信、被亲近，而实际意思应该是“在那种生活里可以相信别人、亲近别人”。省略得太多。 → 那种可以相信别人、自在亲近的生活
  - [S10 ①]「他现在提不起劲争」——“争”单独放在这里过于突兀，前文一直使用的是“争取”，这里骤然缩成一个字，不像自然叙述。 → 他现在已经提不起劲再去争取
  - [S10 ③]「就不用逼自己先丢开安宁」——“丢开安宁”搭配生硬。“安宁”不是通常会说“丢开”的东西。 → 就不用逼自己先把那份安宁舍掉
  - [S11 ①]「只是没顾好全部牵挂」——和前面的“没顾上另一份牵挂”是同一个问题：“牵挂”是感情，不是通常可以“顾好”的对象。 → 只是没能顾全所有放不下的东西
  - [S11 ③]「所以他带着不舍和害怕继续承担」——“承担”通常需要宾语，如承担责任、风险、代价。这里句子直接停在“承担”，明显像少了半截。 → 所以他带着不舍和害怕，继续承担自己能承担的事
  - [S12 ①]「他认下可能的代价，不等完全不怕了」——“认下代价”搭配略生硬；“完全不怕了”又用了口语式双重否定感，和整段偏抽象的语体撞在一起。 → 他接受可能要付出的代价，不等到自己完全不害怕，就去做眼下能做的事
  - [S13 ①]「想到退回安宁也护不住它」——“退回安宁”仍然把“安宁”写成一个地点，和前面的“回到亲近里”“丢开安宁”一样，有明显的生造感。 → 想到就算退回原先那份安宁，也还是护不住它
  - [S13 ②]「想到争取的就是那种能真心亲近的生活」——“争取的就是”省掉了主语和宾语关系，略像提纲语；加上“自己”后逻辑会立即清楚很多。 → 想到自己正在争取的，正是那种能真心与人亲近的生活
  - [S13 ③]「免得把真心待人的温柔耗光」——“真心待人的温柔”修饰关系有点拧，像是临时把“真心待人”和“温柔”压成了一个名词短语。 → 免得把真心待人时的那份温柔也耗光

### 5.6 第2次：6 分，25 处
- 最主要的问题：最大的问题不是单句语法错误，而是大量抽象词彼此搭配：如“生活、所爱、牵挂、亲近、安宁、争取、投入、用力、珍贵的东西”等反复出现，却常常不把对象说实。于是动词也容易跟着悬空，形成“顾好牵挂”“退回安宁”“亲近生活”“舍不得否认”这一类能猜到意思、但不是自然汉语习惯的组合。整条心理线其实相当清楚，因果和前后呼应也大体能跟上；真正拖累阅读的是表达过度概念化，读者常要先把抽象词翻译回具体心理动作，才能继续往下读。
- 一再出现：抽象名词过密，同一段里常连续出现“生活、所爱、牵挂、安宁、亲近、决心、真心”等，画面和动作感不足。；动词与抽象名词搭配生硬，反复出现语义能猜到、汉语习惯却不这么说的组合，如“顾好牵挂”“退回安宁”“亲近生活”。；有些关键动词省略对象，如“争、投入、爱惜、承担、舍不得”，导致句子在概念上悬空。；“那种生活”“珍贵的东西”“所爱”“那份亲近”等代称使用频繁，连续读时指向容易变虚，需要读者回想它具体指什么。；为了压缩心理变化，常把两三层因果、转折塞进一句，语法虽然多半成立，但口气容易像心理分析提纲，而不像一个人自然地讲自己的经历。
  - [S01 ②]「以后没法再回头去顾」——“回头去顾”搭配有点生硬，“回头”和“去顾”叠在一起，读到这里会稍微顿一下。 → 以后就没法再回头照顾那些东西了

  - [S04-B4]「它不是身体被追赶的另一种比喻，而是思绪反复盘旋、试图想清楚却无法停歇的心理处境。」——这句话像在替不同版本的解释划清边界。“另一种比喻”“心理处境”都是编辑腔，后半句还重复了前面的“停不下来”。 → 这里的慌乱不只是身体被节奏催着跑，更像脑子里的念头一个接一个冒出来，怎么也理不清。
  - [S05-B1]「声音像换了一个更柔和的人在说话」——“换了一个更柔和的人在说话”结构有点绕，仿佛换掉的是人的性格，而不是说话者或语气。 → 仿佛忽然换了一个人开口，语气比刚才柔和了许多。
  - [S05-B2]「也有想维护自己的那股劲。」——“维护自己”不够地道，通常会说维护尊严、维护权益，或保护自己；“那股劲”前的动作也没有说清楚。 → 也有一股不愿退让、想守住自己尊严的劲。
  - [S05-B3]「随后运动逐渐减弱，落入较慢、较稀疏的和弦。」——“运动”是抽象概念，不能很自然地“落入和弦”；“较慢、较稀疏”也更适合形容音乐的进行，而不是和弦本身。 → 随后，快速的音符渐渐慢下来，声音也变得稀疏，最后只剩下缓缓响起的几个和弦。
  - [S06-B1]「整个世界像被一层透明玻璃罩隔开」——“世界被玻璃罩隔开”没有说清楚玻璃罩把什么和什么隔开，画面略显含混。 → 仿佛周围罩上了一层透明的玻璃，把外面的喧闹都隔绝了。
  - [S06-B2]「歌唱又像向某个遥远、并不确定的对象祈求」——“并不确定的对象”听起来像心理分析或研究报告中的术语，不像人在形容祈求和思念。 → 歌声又像在向远方的某个人祈求，甚至不知道对方能不能听见。
  - [S06-B2]「约160小节，还可以听见另一幅短暂的画面」——“听见一幅画面”虽然可以当作通感，但这里没有特别明确的修辞效果，反而让人停下来想究竟是听见了什么。 → 约第160小节，眼前仿佛又浮现出一幅短暂的画面。
  - [S06-B4]「一层波浪托着另一层波浪：它轻轻托起，又缓缓落下」——“波浪托着波浪”画面不够清楚，后面的“它”也不知道指哪一层波浪；“托着”和“托起”重复。 → 旋律像一层层波浪，轻轻涌起，又慢慢落下。
  - [S06-B4]「不必被推成夸张的戏剧场面。」——“被推成戏剧场面”搭配生硬，也突然从描述声音变成了指导演奏的语气。 → 演奏时不必刻意夸大起伏，把它处理成戏剧性的高潮。
  - [S07-B2]「原先的思绪被截断，音乐从别处重新开讲。」——“从别处重新开讲”不太像自然中文。这里想表达的是音乐换了话题或换了场景。 → 原先的思绪突然被打断，音乐仿佛换了一个话题，重新说起。
  - [S07-B4]「同一段还有另一种材料辨认：一些原稿把182–197听成先前更具宣告性、带有波兰舞曲气质的材料重新出现。」——“另一种材料辨认”不自然；“一些原稿把……听成”也把写作来源和实际听感混在了一起。读者会感觉自己在读整理说明，而不是音乐文字。 → 也有另一种听法：第182–197小节仿佛重新出现了先前那种更具宣告性、带有波兰舞曲气质的音乐。
  - [S07-B4]「这是对音乐材料的另一种理解，不是断言它已经完成了主题回归；更不必把它讲成一个人重新站直、重新找回旧日自我的连续故事。」——连续几层免责声明让一句本来简单的听感判断变得沉重。“完成了主题回归”“连续故事”也很像内部讨论用语。 → 但这种相似还不足以让人觉得主题已经完整回归，也不必急着把它解释成重新振作。
  - [S07-B5]「这不是对舞曲主题身份的判断，也不必和上面的材料辨认拼成一个人的连续经历。」——“主题身份”“材料辨认”“拼成连续经历”都是分析过程中的措辞，与前面生活化的记忆画面格格不入。 → 这种联想不一定说明某个舞曲主题真的回来了。它也可以只是一段熟悉的生活记忆，突然闯进心里。
  - [S08-B1]「沉思、近乎祈求的气息又被认出来，像熟悉的柔软处重新打开了。」——“气息被认出来”是生硬的被动句；“熟悉的柔软处”又没有明确所指，两种抽象表达叠在一起，影响理解。 → 那种沉思、近乎祈求的语气又回来了，像心里某个柔软的角落再次被轻轻触动。
  - [S08-B2]「刚认出那份安静，还来不及重新安顿，就又退开。」——主语在句子中间悄悄变了：谁认出安静，谁来不及安顿，又是谁退开？ → 那份安静刚刚回来，还没来得及让人重新平静下来，就又消失了。
  - [S08-B3]「忽然像是获得了一次短暂的呼吸，胸口仿佛终于吸进一口气。它只是瞬间的喘息」——“获得呼吸”“吸进一口气”“瞬间的喘息”接连说同一件事；“获得了一次短暂的呼吸”尤其不自然。 → 胸口仿佛终于能松一口气。但这短暂的喘息，并不意味着整个人已经安定下来。
  - [S09-B1（标注）]「颤音光晕的来源描述覆盖mm.206–215。门槛意象只指开头姿态重新显现，后续向前的推进尚未在此展开。」——这是明显的编辑备注，不像给读者看的听感文字。“来源描述覆盖”“门槛意象只指”尤其生硬，而且信息密度过高。 → 214–215小节；开头的姿态短暂重现，真正向前推进的力量还没有形成。相关颤音音响可结合206–215小节来听。
  - [S09-B1]「开头沉重的引子又从双手巨大的颤音光晕里阴冷地闪回来」——“引子闪回来”不够自然；“双手巨大的颤音光晕”也堆了太多修饰，反而让具体声音变模糊。 → 开头那种沉重的声音，忽然又在双手铺开的颤音中阴冷地闪现。
  - [S09-B1]「像同一扇门从另一面显出」——“门从另一面显出”很难想象具体画面：是门转过来了，还是人走到了门的另一侧？ → 仿佛又回到了开头那扇门前，只不过这一次，自己站在了门的另一侧。
  - [S09-B2]「像是重新遇见那个不知道怎么办的自己——只是这一次，你已经知道他经历过什么。」——一句话里从“自己”跳到“你”，又跳到“他”，视角不统一。尤其“他”会让人误以为突然出现了另一个人物。 → 像是再次遇见开头时那个不知所措的自己。只是经历了这么多以后，你已经不再是当初的你。
  - [S09-B3]「低声的荒凉被硬生生划开」——“低声的荒凉”搭配不顺。“低声”是声音的状态，“荒凉”是气氛，直接组合显得生造。 → 原本低沉、荒凉的气氛突然被这一下强音划破。
  - [S10-B1]「216–225小节并没有接出一段完整、站稳的旋律」——“接出一段旋律”不太地道，“站稳的旋律”又是一个额外的比喻，组合后比较费解。 → 到了216–225小节，音乐也没有顺势发展出一段完整、稳定的旋律。
  - [S10-B1]「熟悉的声音只是轻轻地、断断续续地浮出几块。」——“声音浮出几块”量词不合适，像是在把声音当作石块或碎片，但这个比喻没有建立清楚。 → 熟悉的旋律只是轻轻地、断断续续地露出几个片段。
  - [S10-B2]「听感像忽然失了重」——通常说“失重”或“失去了重量”，“失了重”有点像把现成词硬拆开。 → 听起来像突然失重了
  - [S11-B1]「到最后四小节，前进感越来越不可回避。」——“前进感不可回避”是抽象概念之间的生硬搭配。想表达的是音乐越来越有非往前走不可的势头。 → 到了最后四小节，那股向前迈步的力量越来越强，几乎无法阻挡。
  - [S11-B1]「仿佛把前面柔软、私密、近乎祈祷的声音带回可以迈步的节奏里」——“把声音带回节奏里”关系不清楚；“可以迈步的节奏”也有点绕。它真正想表达的是情绪从低声倾诉转为行动。 → 仿佛前面那些柔软、私密、近乎祈祷的心声，终于化成了可以迈步向前的力量。
  - [S11-B2]「左手涌起滚滚低音波涛」——“涌起”“滚滚”“波涛”重复制造气势，名词也叠得生硬，像硬压缩过的形容句。 → 左手的低音如波涛般翻涌。
  - [S11-B3]「如果把这股推进听成人的处境」——“把推进听成人的处境”搭配不自然。音乐的推进可以让人联想到某种处境，但不能直接等同于处境。 → 如果把这段音乐想成一个人在困境中咬牙往前走
  - [S11-B3]「不是问题解决了，而是停滞本身松开了一点。」——“停滞本身松开”过于概念化。“停滞”通常说被打破，或者说僵住的状态有所松动。 → 不是问题解决了，而是原本僵住的状态终于有了一点松动。
  - [S12-B1]「它也可以听成一种面向外部、公开的昂扬」——“面向外部、公开的昂扬”很像分析标签，不像自然的听感描述。读者需要先把两个抽象限定词翻译成具体情景。 → 这次昂扬不再像一个人暗自给自己打气，而更像是在众人面前挺起胸膛，甚至有了几分集体前行的气势。
  - [S13-B1]「甚至有如管风琴般庄严庞大。」——“有如……般”句式重复，“庄严庞大”也不如“庄严宏伟”适合形容音响。 → 甚至像管风琴一样庄严、宏伟。
  - [S13-B1]「密集的音符又像狂飙的激流向天空喷涌，仿佛一颗心脏以最高负荷跳动」——一句里同时塞进狂风、激流、天空、心脏和机械负荷，意象过多而且彼此不太协调。“最高负荷”也突然有了技术报告的味道。 → 密集的音符像激流般向上喷涌，听得人心跳加快，几乎喘不过气来。
  - [S13-B1]「柔软并没有被力量压下去，而是也被带进了高潮。」——“而是也”连接得很生硬；“柔软”和“力量”都被当作实体搬来搬去，意思虽能猜到，却不够顺畅。 → 那份柔情没有被强大的声势掩盖，反而随着音乐一起涌向高潮。
  - [S13-B2]「这里的身体感不再只是前一刻的宏大歌唱」——“身体感”不能直接等同于“歌唱”，比较双方不在同一层面。应该直接对比两段音乐带来的感受。 → 比起前面庄严宏大的歌唱，这里更让人觉得身体也被一股力量带着往前冲。
  - [S13-B3]「仿佛刚刚建立的成功又被轻轻问了一句：它真的已经牢固了吗？」——“建立的成功”搭配不当，“成功牢固”也不自然，而且这里究竟成功了什么并没有交代。 → 仿佛刚刚升起的那份坚定又受到了一点动摇：这一切真的已经稳住了吗？
  - [S13-B4]「忽然亮起一记清脆、透明、孤悬如寒星的高音和弦，像一声清脆的钟响。」——“清脆”重复；“透明”“孤悬如寒星”“钟响”连续堆叠，反而冲淡了结尾那一下声音本来的鲜明。 → 随后，钢琴最高处忽然响起一记清亮的和弦，像寒夜里孤独的一声钟响。

### 5.6 第1次：7 分，28 处
- 最主要的问题：最大的语言问题不是意象太多本身，而是感性的听感描写、音乐分析术语和整理原稿时的编辑说明经常混在同一层文字里。前一句还在写“寒风”“旧歌”“脚步”，后一句突然出现“材料辨认”“原稿支持”“心理解释范围”“采用哪种认定”，语气会一下从人的听觉经验跳成资料库或校注说明，因此有些地方明显带着加工、拼接感。除此之外，少数句子为了追求形象，把抽象名词强行动词化或把多个比喻叠在一起，也会让读者停一下才能解码。总体上仍然是可读而且相当有画面的，只是离非常自然、松弛的人写法还有一段距离。
- 一再出现：编辑性、免责声明式语言反复闯入正文，如“原稿支持”“材料辨认”“不是唯一确定的故事”“不必拼成……剧情”，容易显得像整理模型输出而不是人在写听感。；抽象名词和分析术语偏多，如“姿态”“回返”“换向”“运动”“认定”“心理处境”等，有时把本来很直接的感觉说复杂了。；偶尔出现不自然的搭配或抽象名词拟人化，如“旋律站稳”“步伐聚起来”“停滞本身松开”“成功牢固”。；有些比喻一次叠得太多，视觉、身体、机械等不同系统同时进入一句话，单个意象都能懂，合在一起却稍显用力。；“也可以听成……”“另一种理解……”“不必把……”“不是……而是……”这一类校正和分流句式出现很频繁，长期累积会让文章带上固定模板感。
  - [S01-B4 结尾]「这只是往前的牵引，还不是第24小节起的主题已经站稳。」——“还不是……已经……”这个句式拧巴，读到这里需要倒回去判断逻辑关系。 → 这只是往前的牵引，还没到第24小节起主题真正站稳的时候。
  - [S01-B5 结尾]「“我不能倒下，以及我其实很想停下来。”」——“以及”是书面并列词，放进人物内心独白里很不像人会这样想或这样说。 → “我不能倒下，可我其实很想停下来。”
  - [S02-B4]「说到第三次，连这句话本身都暴露出其实很在意。」——“暴露出其实很在意”少了一个明确的承受者，语法虽能猜懂，但有一点悬空。 → 说到第三次，连反复说这句话本身，都暴露出他其实很在意。
  - [S02-B5]「但不必把两种原稿的说法拼成同一个人的确定剧情。」——“两种原稿的说法”突然从听感语言跳到编辑、整理材料的口吻；“确定剧情”也比较生硬。 → 但不必硬把这两种理解拼成同一个人的一条完整剧情。
  - [S03-B1]「这一段强弱跳动、切分让人心口悬起。」——“强弱跳动、切分”直接并排作主语不太顺，像笔记还没整理成句子。 → 这一段强弱的跳动和切分，让人心口一直悬着。
  - [S03-B3]「也可以把耳朵收进旋律里」——“把耳朵收进……”这个动作很难形成直观经验，修辞刻意感较重。 → 也可以把注意力收进旋律里
  - [S04-B1 结尾]「这份坚定也可能是他努力想成为的样子，而不再是一个毫无疑问的事实。」——前面一直没有明确的“他”，这里突然出现第三人称；同时“坚定是一个事实”搭配也略显抽象。 → 这份坚定也可能只是一个人努力想维持的样子，而不再是理所当然、毫不动摇的状态。
  - [S04-B4 结尾]「它不是身体被追赶的另一种比喻，而是思绪反复盘旋、试图想清楚却无法停歇的心理处境。」——“它不是身体被追赶的另一种比喻”指代不够清楚，而且像在解释写作分类，不像听感本身。 → 这里说的不是身体被追赶，而是另一种停不下来的感觉：思绪反复盘旋，越想弄清楚，越无法停歇。
  - [S05-B1]「声音像换了一个更柔和的人在说话」——“声音换了一个人”在句法上有点别扭，实际想说的是“说话的人变了”。 → 像忽然换成了一个更柔和的人在说话
  - [S05-B3]「随后运动逐渐减弱」——“运动”在这里过于抽象、偏分析术语，和前后的听觉描写不在一个语域里。 → 随后这种流动感逐渐减弱
  - [S06-B1]「整个世界像被一层透明玻璃罩隔开」——“被玻璃罩隔开”没有交代是和什么隔开，空间关系有些模糊。 → 整个世界像隔在一层透明玻璃罩后面，连呼吸都不愿惊动它。
  - [S06-B2]「那些压住的愿望、委屈和思念」——按这里的意思，是愿望等“被压住”，原句少了一个“被”，读起来像是这些愿望主动去压住了别的东西。 → 那些被压住的愿望、委屈和思念

  - [S01-B5]「“我不能倒下，以及我其实很想停下来。”」——内心独白中使用书面连词“以及”，极不符合人类真实的心理语言习惯，带有生硬的书面翻译腔。 → “我不能倒下，可我其实多想停下来。”
  - [S02-B4]「这份挺直可以听成一种强烈的自我控制。」——“挺直”通常是动词或动补短语（如“挺直腰板”），强行名词化为“这份挺直”显得生硬晦涩。 → 这种强撑挺拔的姿态，可以听成一种强烈的自我控制。
  - [S02-B5]「但这股力量可以与自我控制同时存在，但不必把两种原稿的说法拼成同一个人的确定剧情。」——“原稿的说法”“确定剧情”属于乐评编辑或文献校勘的元语言（meta-language），突然打破听感沉浸，让读者出戏且困惑。 → 这股力量完全可以与自我控制并存，而不必非要把不同的感受强行拼凑成一段连贯的情节故事。
  - [S03-B4]「这股活动感也可以听成一次短暂的侧身离场」——“活动感”是生硬的直译/造词（似对应 activity 或 movement），在中文音乐描摹中极为别扭生涩。 → 这种跃动感（或：这种活跃流动的气氛）也可以听成一次短暂的侧身离场
  - [S04-B2]「越用力却没有越安稳。把这一转折听成记忆带来的刺痛，是一种有原稿支持的听法」——前半句“越……却没有越……”搭配别扭；后半句“有原稿支持的听法”再次漏出研究札记般的行话，行文割裂。 → 越是用力，反而越难心安。这一转折正如记忆骤然带来的刺痛：
  - [S05-B4]「这一下松动也可以听成“不是他想通了，而是他抵抗累了”。」——“抵抗累了”属于生造的口语拼凑，不符合中文书面动补搭配习惯。 → 这一下松动也可以听成：“并不是他想通了，而是他已经无力再抗争。”
  - [S07-B4]「同一段还有另一种材料辨认：一些原稿把182–197听成先前更具宣告性、带有波兰舞曲气质的材料重新出现。」——“材料辨认”“一些原稿把……”完全是音乐学考证或学术批注的口吻，放在通感描摹中极为违和。 → 这一段还有另一种听法：有人在这里辨认出先前那段更具宣告性、带有波兰舞曲气质的主题。
  - [S10-B1]「熟悉的声音只是轻轻地、断断续续地浮出几块……摇篮曲以F小调残破地回来」——“声音浮出几块”量词错位，有如浮冰碎块；“残破地回来”则是欧化结构，搭配松散别扭。 → 熟悉的声音只是断断续续地浮现出零星碎片……摇篮曲在F小调上残缺地重现
  - [S10-B3]「而是走过许多之后，仍未能获得彻底答案的疲惫。」——“走过许多之后”缺少宾语中心词，是典型的英文代词（after going through so much）直译腔，在中文里语义悬空。 → 而是历经诸多起伏之后，仍未寻得终极答案的疲惫。
  - [S11-B1]「波兰舞曲的步子不是一下子整齐地回来……前进感越来越不可回避。」——“步子……整齐地回来”语言偏俚俗散漫；“前进感越来越不可回避”是明显的翻译腔（inescapable sense of forward motion）。 → 波兰舞曲的步伐并非骤然齐整归来……向前的势头越来越不可阻挡。
  - [S12-B3]「像脚步正往前时地面短暂斜了一下，随后却仍继续向前。」——“地面短暂斜了一下”意象平瘪笨拙，既缺少通感美感，也显得像低幼口语描述。 → 就像步子正迈开时脚下忽然一晃（或：身体重心微微倾侧），但随即又稳步向前。
  - [S13-B3]「仿佛刚刚建立的成功又被轻轻问了一句：它真的已经牢固了吗？」——“建立的成功”搭配生硬，“成功”一词用于此处乐境过于功利且具象化，不够贴切音乐的情绪特质。 → 仿佛刚刚确立的笃定与辉煌又被轻轻质问了一句：这一切真的牢不可破了吗？
