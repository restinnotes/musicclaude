### S10（屏幕停留 28 秒）
左：他慢慢觉得自己最舍不得的，还是从前有人把他当作自己人的日子；可就算真的回去，还能像从前那样吗？
  右：声音回来却没完整铺开 / 开头的试探一闪而过 / 摇篮曲破碎地响起
左：何况当初那些让他难受的事也不能当作没发生过，光凭舍不得，他还是没法放心回去。
  右：
左：他翻来覆去想得很累，还是没个答案，连眼下的日子都过得不踏实。
  右：走了这么久还是没答案 / 累得不想再讲一遍 / 整个人悬在半空 / 我以后该怎么过？ / 未能获得答案的疲惫

### S11（屏幕停留 22 秒）
左：明知道回去未必找得回那份亲近，他却还是忍不住想：万一能呢？
  右：
左：他再心动，也不愿只凭这点指望，就回去过从前那种忍让的日子。
  右：一次次顶住再用力 / 每次爆发 压力又叠上来
左：他想，回不回去可以以后再定，先试着把眼下的日子过稳些，兴许比急着回去踏实。
  右：祈祷变成意志 / 前方有没有路？ / 步伐一点点聚拢
左：他还是怕以后遇上难处只能自己扛，心里也没多少底，可这回不想因为害怕就把刚才的打算收回去。
  右：害怕还在 脚已经往前 / 停滞终于松开

### S12（屏幕停留 25 秒）
左：他想，当初那些气确实不该忍，和那些人在一起时也确实开心过，自己可以都记着。
  右：犹豫也自己作决定 / 不必假装没受过伤 / 疲惫想念也能决定
左：想起那些好时候，他还是会心软，也怕往后一个人熬，可他不再怪自己当初离开，更不愿只为有人陪着就回头；他愿意带着想念继续过日子。
  右：脚下一晃 仍继续向前 / 沉重的步子踏实落地 / 声势推着人向前 / 公开的昂扬

### S13（屏幕停留 62 秒）
左：想起从前那些自然亲近的日子，他心里又热了起来，也盼着以后还能有那样的相处。
  右：柔软的歌也唱进高潮 / 想起故土 / 心跳到了最高负荷 / 温柔的歌忽然热烈
左：这么想着，他倒真有了劲头，想把往后的日子好好过起来，不再整天跟从前的事较劲。
  右：兴奋得顾不上喘气 / 一股气流推着往前跑
左：劲头稍缓，他想到往后还会孤单，也不知何时再有人亲近，心里渐渐静了下来。
  右：它真的已经牢固了吗？ / 终于能停下来喘口气 / 平静里仍有疑问
左：将来要是再有人愿意把他当自己人，他会好好珍惜；即使一直没有，他也愿意自己好好过下去，不再为了留住谁把那些委屈咽下去。
  右：终于下定决心 / 喧嚣骤然静止 / 呼出最后一口气 / 从梦境中骤然清醒
