<WritingBlock id="58321" variant="document">**（第1—3小节）**

**我想被完整接纳，又怕交出自己；连我都分不清，是想要亲密，还是只想找个安心处。**

**（第4—16小节）**

**跟一个人亲近确实让我放松，我愿意再往前试一点。**
← 因为前面我想被接纳，却一直担心亲密会拿走自己的选择。
→ 于是我暂时享受这份温柔，却不敢许诺长久；旋律缓缓下行、摇摆。

**（第17—23小节）**

**我开始怕这份快乐会突然消失，连开心都要反复确认。**
← 因为上一段我刚敢靠近，却还没相信亲密能一直持续。
→ 于是我又想回到熟悉的温柔里，说服自己再信一次；主题退开，和声变动。

**（第24—34小节）**

**我又回到熟悉的亲密里，可心里总在问：这样真的够了吗？**
← 因为前面我怕幸福突然消失，便想靠熟悉的安慰压住不安。
→ 于是我开始追问自己为什么还需要保证，熟悉的主题重现，却多了急切。

**（第35—39小节）**

**我想让别人爱我，也想借这份爱证明自己值得被爱、以后会没事。**
← 因为前面我一直检查亲密够不够，连自我价值和未来也交给了它。
→ 于是我承认感情没法替我弄清自己，原本连贯的旋律也散开了。

**（第40—50小节）**

**我还是需要亲密，却不想再让对方的反应决定我值不值得被爱。**
← 因为前面我发现，自己把自我价值和未来都压在一段感情上了。
→ 于是我开始辨认自己的需要和界限，新的旋律也向上展开。

**（第51—61小节）**

**自己做主让我轻松些，可我也可能为了不受伤，把感情全收起来。**
← 因为前面我开始靠自己的判断生活，不再急着向别人讨保证。
→ 于是我发现，若只求不受伤，我可能什么都不敢要；旋律明亮，心里仍不安。

**（第62—71小节）**

**我开始试着和一个人亲近，也保留自己的判断和选择。**
← 因为前面我看见，只顾防备受伤，会让我连喜欢的关系也慢慢收起来。
→ 于是我不再急着在亲密和自由里选一个，音乐也重新有了活力。

**（第72—77小节）**

**我知道自己两样都想要，也得接受选择之后会有代价。**
← 因为前面我决定继续靠近别人，不再把自己的选择全交出去。
→ 于是我明白，道理不能替我承担风险；音乐放慢了，和声仍悬着。

**（第78—83小节）**

**我开始怀疑自己那套规矩：幸福为什么非得让我永远安心？**
← 因为前面我看清亲密和独立都有代价，却还想找个万无一失的答案。
→ 于是我不再把每次犹豫都当失败，也允许自己暂时没答案；音乐挣脱规整节奏。

**（第84—92小节）**

**不再逼自己立刻想通后，我才慢慢接受亲密和独立各有边界。**
← 因为前面我松开了“幸福必须让我永远安心”的苛刻要求。
→ 于是我敢继续靠近，不再要求自己消灭依恋；主旋律回来，像终于有地方可停。

**（第93—102小节）**

**我还是想被爱，只是不再拿别人的回应给自己打分。**
← 因为前面我接受了亲密有局限，也允许自己带着不确定生活。
→ 于是我敢承认自己想要幸福，并愿意为这个选择负责；第二主题变得开阔有力。

**（第103—110小节）**

**我主动选择亲密时，也承认自己需要回应，还可能失去对方。**
← 因为前面我终于敢承认自己的渴望，不再逼别人替我证明价值。
→ 于是我不再把矛盾当成选错；高潮退去后，低音仍在，像心里还有不同声音。

**（第111—116小节）**

**我终于能相信，那些快乐是真的，即使感情不能保证未来。**
← 因为前面的怀疑让我看清，有些需要不能互相替代，有些代价得自己承担。
→ 于是我愿意认真爱人，也接受失去的可能，不再让没答案的问题控制生活；尾声向上收束。

音乐段落的划分参考 PTNA 对《船歌》各小节的分析，以及 David Kopp 对主题、过渡段和尾声的解读。</WritingBlock>
