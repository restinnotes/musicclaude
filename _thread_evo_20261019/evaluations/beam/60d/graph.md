# Op.60｜关系图（逐段综合 60d）

**Center：**亲近本身的满足与对这份亲近能否长久的忧虑彼此交织。

### 1–3　（还说不清）

- 他心里生出想靠近某个人的愿望，却说不清自己究竟在期待什么。

### 4–16　（正在面对）

- 亲近的可能越显珍贵，他越不忍它转瞬即逝；期待也渐渐成了盼这份亲近长久。
  - ← 改写：（1–3）「说不清的靠近」

### 17–23　（正在面对）

- 亲近带来的留恋让他静静沉浸在期待里，心意舒展而满足。
  - ← 提供理由：（4–16）「甜意里的留恋」

### 24–34　（正在面对）

- 先前的满足让他更珍惜这份亲近；越享受其中，他越舍不得它结束，欢喜里也添了急切。
  - ← 提供理由：（17–23）「满足中的留恋」
  - ← 提供理由：（4–16）「甜意里的留恋」

### 35–39　（正在面对）

- 不愿这一刻过去，他便愈发在意眼前的满足能否延续到以后，心里因此有些没底。
  - ← 提供理由：（4–16）「甜意里的留恋」
  - ← 提供理由：（24–34）「舍不得结束」

### 40–50　（正在面对）

- 亲近会不会继续仍让他不安，已得到的满足却让他心里能喘息片刻。
  - ← 提供理由：（17–23）「满足中的留恋」
  - ← 限制：（35–39）「满足难保延续」

### 51–61　（正在面对）

- 尝到亲近的真切满足后，他更想靠近那个人，心底的依恋也化成更直接的渴望。
  - ← 提供理由：（40–50）「片刻松快」
  - ← 改写：（24–34）「舍不得结束」

### 62–71　（正在面对）

- 眼前的亲近让他心里舒畅，靠近的念头也添了玩心，享受当下便已满足。
  - ← 提供理由：（40–50）「片刻松快」
  - ← 改写：（51–61）「渴望更直接」
  - ← 限制：（35–39）「满足难保延续」
- → 这份轻松难得，他刚体会到，便盼着亲近能多持续一会儿。
  - ← 提供理由：（24–34）「舍不得结束」
  - ← 提供理由：（35–39）「满足难保延续」

### 72–77　（正在面对）

- 从眼前的亲近中，他感到满足不只是如愿以偿，相遇本身也值得他珍惜。
  - ← 提供理由：（62–71）「渴望带上玩心」
  - ← 改写：（62–71）「珍惜片刻轻松」

### 78–83　（正在面对）

- 亲近本身让他觉得从容，心里的急切也暂时缓了下来。
  - ← 唤起：（40–50）「片刻松快」
  - ← 提供理由：（72–77）「珍惜相遇本身」
  - ← 限制：（35–39）「满足难保延续」

### 84–92　（正在面对）

- 这份自在让他的热切显得坦荡而饱满。
  - ← 提供理由：（72–77）「珍惜相遇本身」
  - ← 提供理由：（78–83）「因亲近而从容」

### 93–102　（正在面对）

- 这份亲近已显得格外可贵，他在热切中感到充实，几乎忘我。
  - ← 提供理由：（72–77）「珍惜相遇本身」
  - ← 提供理由：（84–92）「坦荡的热切」

### 103–110　（正在面对）

- 他在亲近中近乎忘我，这份亲近能否长久难说，珍惜中添了惆怅。
  - ← 改写：（35–39）「满足难保延续」
  - ← 提供理由：（72–77）「珍惜相遇本身」
  - ← 提供理由：（93–102）「近乎忘我」

### 111–116　（正在面对）

- 满足已使亲近成为珍贵经历；它能否延续难说，他温柔而惆怅地眷恋它。
  - ← 提供理由：（72–77）「珍惜相遇本身」
  - ← 提供理由：（93–102）「近乎忘我」
  - ← 提供理由：（103–110）「珍惜中的惆怅」
