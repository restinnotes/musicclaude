  - [S01 第2条]「他才肯让对方看见需要，舍不得这轻松。」——“看见需要”缺少明确的归属，读者要停顿一下才能确定是他自己的需要。“这轻松”也不如“这份轻松”自然。整句话压缩得过紧。 → 他这才肯让对方知道，自己也有需要对方的时候，也舍不得这份轻松。
  - [S04 第1条]「他更放得开去爱，安心接受温柔。」——“放得开去爱”搭配不够自然。“放得开”通常直接描述人的状态，用在“去爱”前面时，最好交代他放开的是自己。 → 他更敢放开自己去爱，也能安心接受对方的温柔。
  - [S04 第2条]「他不再猜自己是否值得被爱，喜欢敞开的自己。」——“猜自己是否值得被爱”不太符合日常用词习惯，通常会说“怀疑自己值不值得被爱”。“敞开的自己”也有些抽象，缺少“敞开心”这一层意思，读起来不够顺口。 → 他不再怀疑自己值不值得被爱，也开始喜欢这个愿意敞开心的自己。
  - [S06 第3条]「他偶尔退回心底，心疼又舍不得如今不用防备的自己，这层心绪再亲密也无法分享。」——这里有几处表达叠在一起，让句子难以顺着读下去。“退回心底”不容易形成明确的动作或心理状态；“心疼又舍不得如今不用防备的自己”需要反复辨认两个情绪的对象；“这层心绪”也不像日常说法。整句想表达的心理很细，但句法过于浓缩。 → 他偶尔会独自想着心事，心疼如今终于不用防备的自己，也舍不得失去这样的自己。哪怕和对方再亲密，这份心情他也没法说出来。
  - [S07 第3条]「怕这份好留不住，他不肯少爱，哪怕更痛。」——“这份好”可能指他对对方的好，也可能指眼前美好的关系，所指略有摇摆。“不肯少爱”尤其显得生硬，像是为了缩短句子而把正常说法压掉了。“哪怕更痛”也需要读者自行补出以后可能更痛的意思。 → 他怕眼前这份好留不住，却还是不愿因此少爱一点，哪怕以后会更痛。
  - [S09 第2条]「他想幸福时不惦记它会过去，却留不住最好的时候。」——“想幸福时不惦记”不如“想在幸福的时候不去想”顺畅。另外，前半句说的是他想控制自己的担忧，后半句说的是客观上无法留住美好，两者用“却”直接连接，关系略显跳跃。 → 他想在幸福的时候只管享受，不去惦记它会过去，可心里也知道，最好的时候终究留不住。
  - [S10 第1条]「怪不了对方，他更疼惜，不让对方担他的不安。」——“他更疼惜”缺少对象，虽然可以推断，但单独读不够自然。“担他的不安”也不是常见搭配，通常会说“承受他的不安”或“替他分担不安”。 → 他知道不能怪对方，反而更心疼对方，不愿让对方替他承受这份不安。
  - [S10 第2条]「他珍惜不施压的自在，不用依恋束缚对方。」——“不施压的自在”把一种相处方式压成了抽象名词，不像平常说话。“不用依恋束缚对方”也容易产生歧义：到底是“不需要靠依恋束缚对方”，还是“不拿自己的依恋去束缚对方”？结合前后文，后者更符合这里的心理。 → 他珍惜这种不用给对方压力的自在，也不想让自己的依恋束缚对方。
  - [S11 第1条]「重回熟悉的亲近，先前久久悬着的期盼终于落定，补上了未尽的欢喜。」——这是较明显的一处搭配问题。“期盼终于落定”不够自然，通常是“心落了地”或“期盼终于实现”。“补上了未尽的欢喜”也有些刻意，好像欢喜是一件能补齐的东西。几个抽象说法连续出现，让原本应该很有情绪的时刻读起来反而费劲。 → 又回到那种熟悉的亲近里，他一直悬着的心终于落了地，先前没能尽兴的欢喜也回来了。
  - [S12 第3条]「欢喜混着怕留不住，他快乐得发疼也不愿收回。」——“欢喜”是名词，“怕留不住”是一个尚未说完整的心理判断，两者直接用“混着”连接不够协调。“不愿收回”也没有明确对象，读者不容易确定他不愿收回的是爱、快乐，还是投入感。 → 他很欢喜，也怕留不住这样的日子。就算这份快乐让他心里发疼，他也不愿退缩。
  - [S14 第1条]「欢喜平缓后，他仍依恋，很难再像起初只顾眼前轻松。」——“很难再像起初只顾眼前轻松”省略得过多。“像起初”后面缺少自然的衔接，“只顾眼前轻松”也不太像日常表达。意思能看懂，但收尾处读起来有些磕绊。 → 欢喜慢慢平复后，他还是很依恋对方，已经很难像一开始那样，只顾着享受眼前的轻松。
- 累积（中等）：抽象的心理总结持续出现，使整篇逐渐接近情绪分析提纲，而不太像一个人在讲自己当时的感受｜影响：这些句子单独看大多是通顺的，有些还准确表达了细微的心理区别。问题出在它们连续出现时，读者经常直接得到一个心理判断，例如安心接受、自在享受、喜欢自己的爱、珍惜美好、全心去爱，却较少听见这个人当时心里具体怎样想。于是各段虽然在道理上有区别，阅读时却容易形成一种整齐的分析口吻。读者理解他处于什么心理状态，却不总能自然地感到他正在经历这种状态。这是整篇距离“平平常常讲自己的经历”最明显的差距之一。｜边界：这不意味着必须补充人物、动作、对话或具体场景。以音乐为线索的短条目，本来就需要概括内心变化。像S12“美好比自己的得失重要得多”，承担着重要的价值转变，保留这样的心理判断完全合理。真正需要调整的是许多相邻条目都采用类似的抽象总结口吻，尤其在已有一条说明心理状态之后，下一条仍然只是换一种概念给这种状态命名的时候。｜建议：保留抽象层面的心理区别，但挑选少数关键位置，把结论式表述改成更贴近当时心里话的表达，不必增加任何具体事件。例如S02第3条可以改成“对方给他的温柔，他也能安心接受了，不再觉得自己欠了什么。想对对方好，就自然地去做。”S12第4条可以改成“他忽然觉得，比起自己最后会得到什么、失去什么，眼前这份好更重要。”这样仍然含蓄，却少了一点分析者替人物下定义的感觉。

    - [S03 第3条]「他喜欢这样需要对方，也有温柔想给。」
    - [S06 第2条]「心意不必说尽，他自在享受亲近。」

- 累积（中等）：“怕美好留不住—舍不得—继续珍惜或去爱”的心理反复占据多个段落，部分段落的推进感因此减弱｜影响：这些表达并不是简单重复一句话，确实有一条可以辨认的发展线：最初预感到无法长久，随后心酸，接着决定不因害怕而少爱，最后不再追问。这个发展成立。但连续阅读时，关于“终有一天会失去”的判断出现得相当密集，许多段落都在重新说明同一个矛盾。尤其到了后半部分，读者已经充分知道他舍不得、怕改变，遇到新的同类表述时，就不太容易立刻感受到这一段比上一段多了什么。情绪在逻辑上不断加深，语言上却有时像在原地绕圈。这会使本来应有的音乐性回旋部分变成阅读上的重复感。｜边界：这里不能简单删去所有“舍不得”或“留不住”。S04第一次产生担忧是必要的；S05把担忧发展成心酸；S07强调他不愿因此减少付出；S13表现念头越来越难摆脱；S14则落到不再追问，这些都是有作用的变化。只有当后续表述没有带来新的感受、选择或认识，只是再一次强调“美好可能会过去”时，才值得减轻重复。音乐中的情绪反复本身不是语言毛病。｜建议：不需要减少整条线上的不舍，而是让每次返回这个念头时，语言重点更明确地落在这一次新增的心理上。例如S12第2条可以改成“越是满足，他越觉得眼前这一刻难得，也就越想好好珍惜。”如果这一段必须保留对改变的担忧，则可写成“他越满足，越怕以后再没有这样的时刻，眼前的一点好也因此格外珍贵。”S13第2条可以改成“他正幸福着，却发现那个‘终究会变’的念头已经怎么也甩不开了。”重点从再次陈述道理转到念头难以摆脱的体验。

    - [S07 第3条]「怕这份好留不住，他不肯少爱，哪怕更痛。」
    - [S09 第2条]「他想幸福时不惦记它会过去，却留不住最好的时候。」
    - [S12 第2条]「越满足，他越舍不得这一切改变，更珍惜眼前。」
    - [S13 第2条]「正这么幸福，“终究会变”的念头却越来越缠人。」
    - [S14 第3条]「他更爱对方，仍不知美好能留多久。他不再追问，全心去爱。」
- 累积（轻微）：相邻段落重复使用“快乐得发疼”这一较醒目的强烈感受，削弱了表达的新鲜度和阶段差别｜影响：“欢喜浓烈得发疼”和“快乐得发疼”单独出现都能成立，尤其适合描述快乐与痛苦交织的体验。但它们紧挨着出现在两个段落中，强度几乎一样，又使用相同的身体化比喻。读者刚刚接受了一次“快乐到疼”的高峰，下一段又听到同样的表达，第二次的冲击就会变弱。同时，S11侧重快乐太强、几乎无法承受，S12侧重明知可能失去也不愿退缩，这两种心理本来可以有更清楚的区别。｜边界：这种快乐与疼痛并存的写法本身自然，也不是不能重复感受。若音乐确实在两个连续阶段维持高强度，保留这种感受是合理的。真正略显多余的是两处使用了几乎相同、又比较醒目的比喻，没有让第二次表达承担明显不同的作用。｜建议：建议保留S11的“欢喜又浓烈得发疼”，因为它与后面的“几乎承受不住”连贯。S12则突出害怕与继续投入的选择，例如改成“他一边欢喜，一边又怕这一切留不住。可即使心里不安，他也不愿因此收起自己的爱。”这样不必降低S12的情绪强度，也能避免相邻两段用同一种说法表达高潮。

### 5.6 第1次：7 分，6 处
- 最主要的问题：整体是能顺畅读完的，心理线也基本清楚：从放松、敢于依赖和接受爱，到意识到亲近未必长久，再到一面不舍、一面仍愿意全心去爱。多数单句其实自然，真正明显的局部硬伤不多，说明基础语言质量不错。最影响连续阅读体验的不是某一个词或某一种语病，而是中后段大量使用同一批核心情绪词，并反复以“他怎样，但/仍/又不怎样”的方式整理心理，使原本细腻的阶段变化在语言表面上渐渐趋同，读起来有一些心理提纲式的整齐感。其次是抽象心理词密度偏高，偶尔让口吻离“一个人在平常讲自己的经历”远了一点。好的一面是，这些问题都没有严重到破坏理解，而且“亲近”“舍不得”等反复本身也承担了主题回声，不能机械消除。若只松动若干重复句式、减少少数不必要的抽象命名，并修正几处压缩过头的表达，全文会明显更自然，也更能显出各段心理推进的差别。
- 一再出现：中后段反复直接使用“亲近、欢喜、舍不得、自在、温柔、依恋”等同一组核心词，造成不同阶段的语言辨识度下降。；多处使用相近的“他＋心理状态＋转折或否定＋另一心理状态”结构，累积后使叙述节奏偏齐，略像心理梗概。；抽象心理名词连续密集出现，少数段落因此显得经过概念整理，日常讲述感稍弱。
  - [S01 第2条]「他才肯让对方看见需要，舍不得这轻松。」——“看见需要”缺少明确的领属或对象，普通中文里通常会说“看见他的需要”或“看见自己也有需要”。这里省略后，读者会短暂停一下判断“需要”是谁的、是什么意义上的需要。“舍不得这轻松”也略显压缩，但结合前一句尚能顺着读。 → 他才肯让对方看见自己也有需要，也舍不得这样的轻松。
  - [S06 第3条]「他偶尔退回心底，心疼又舍不得如今不用防备的自己，这层心绪再亲密也无法分享。」——“这层心绪再亲密也无法分享”中，“再亲密”的逻辑主语没有落出来，字面上像是“这层心绪再亲密”。实际想说的是两个人无论多亲密，这部分心绪仍只能由他自己体会，因此句法关系稍显悬空。 → 他偶尔退回心底，心疼又舍不得如今不用防备的自己；这层心绪，两个人再亲密也无法真正分享。
  - [S09 第1条]「满足过仍难受，再多温柔也不够。」——“满足过仍难受”压缩得过头。“满足过”通常描述曾经得到满足这一事实，直接接“仍难受”虽然能猜懂，却不像自然口语或一般叙述，会让人停一下重新组织两者的关系。 → 明明已经满足过，他还是难受，再多温柔也觉得不够。
  - [S09 第2条]「他想幸福时不惦记它会过去，却留不住最好的时候。」——“想幸福时不惦记”容易先被读成“想要幸福的时候”，而实际意思应是“在幸福的时候，他想不去惦记……”。“幸福时”与“想”连在一起产生了短暂的歧义。 → 他想在幸福的时候不去惦记它会过去，却还是留不住最好的时候。
  - [S10 第1条]「怪不了对方，他更疼惜，不让对方担他的不安。」——“担他的不安”不是很自然的搭配。“担”通常接“责任”“风险”“担子”，或者说“替他担心”；这里想表达的是不让对方承受、分担自己的不安，但现有说法略生硬。 → 怪不了对方，他反而更疼惜，不愿让对方承受自己的不安。

  - [S04 第3条]「他还是怕承认美好会伤尊严，却不觉得温柔丢脸。」——“承认美好会伤尊严”容易产生短暂的理解歧义：究竟是承认过去很美好会伤到尊严，还是承认美好本身会伤害尊严？结合上下文能判断是前一种，但句子本身压缩得太厉害。后半句的心理区别是清楚且有价值的，值得保留。 → 他还是怕，一旦承认过去那么美好，自己就像丢了尊严；可他并不觉得当时的温柔有什么可丢脸的。
  - [S05 第2条]「那时他有个位置，能放心信人、热切付出，也安心接受亲近。」——“放心信人”不太符合自然口语，像是为了缩短字数，把“放心相信别人”硬压成四个字。后面“热切付出”“安心接受亲近”都能理解，因此主要问题集中在这个短语。 → 那时他觉得自己有个位置，能放心相信别人，热切地付出，也能安心接受别人的亲近。
  - [S05 第4条]「他开始心疼从前不用证明自己的自己，安心一退，又只剩一个人。」——“从前不用证明自己的自己”连续出现两个“自己”，虽然意思能够理解，却有明显的绕口感。后半句“安心一退”也略显压缩，两个本来可以自然连接的心理变化因此显得有些生硬。 → 他开始心疼从前的自己：那时他不用向谁证明什么。可那点安心一退，他又觉得只剩下自己一个人。
  - [S06 第3条]「他先小心承认渴望，后来更迫切，却说不尽。」——“后来更迫切”省略了究竟是什么变得迫切；“却说不尽”又没有明确承接的内容。读者大致知道是在说渴望越来越强，但这三个短句之间的关系不够自然，像是把完整的心理描述抽掉了太多连接部分。 → 他起初只是小心地承认自己还渴望亲近，后来那份渴望越来越强烈，怎么说也说不尽。
  - [S06 第4条]「过去回不来，他只沉浸在开阔和快乐里，暂时忘了不甘和失去。」——“沉浸在开阔和快乐里”的搭配不太自然。“快乐”可以直接说沉浸其中，但“开阔”通常需要依附于心境或感受，直接当作沉浸的对象有些别扭。 → 过去回不来，但他暂时只顾着感受那份舒展和快乐，忘了不甘和失去。
  - [S07 第1条]「回到眼下，他还想亲近，却不知能向谁放心交出心意。」——“向谁放心交出心意”的动词搭配不够自然。平常更容易说“放心把心意交给谁”。原句的意思明确，主要是词序和搭配让表达显得刻意。 → 回到眼下，他还是想亲近别人，却不知道还能放心把心意交给谁。
  - [S10 第3条]「每次强硬，他反倒想起旧日的好，虽然还能往前，却更痛更不舍。」——“每次强硬”不像一个完整、自然的时间状语。强硬是一种态度，不太适合直接说成一次次发生的动作。这里实际表达的是他每次试图让自己强硬起来时，都会出现相反的心理反应。 → 每次逼自己强硬起来，他反而会想起旧日的好。虽然还能往前走，心里却更痛，也更舍不得。
  - [S11 第3条]「从前他能热切对人好、坦然接受而不伤骄傲，如今没法再那样了。」——“坦然接受”后面没有明确对象，虽然可以从前文推知是接受别人的亲近，但与前面的“对人好”并列起来不够顺。“不伤骄傲”也不是很自然的搭配，通常会说“不伤自尊”或者“不觉得有损骄傲”。 → 从前他能热切地对人好，也能坦然接受别人的亲近，还不觉得有损自己的骄傲。如今却没法再那样了。
  - [S13 第1条]「发现自己还愿意信赖、深爱和付出，也盼着安心接受亲近，他一阵兴奋。」——“他一阵兴奋”不太自然。“一阵”通常接某种感受的发生，如“感到一阵兴奋”，或者说“他一下子兴奋起来”。这里的问题主要在句尾，不是前面列出的心理内容。 → 发现自己还愿意信赖、深爱和付出，也盼着能安心接受亲近，他一下子兴奋起来。
  - [S13 第3条]「他带着从前的温暖和骄傲向前，还是难过，无处放心交出心意。」——后半句“还是难过，无处放心交出心意”衔接偏硬。“无处放心交出心意”也延续了S07中不够自然的动词搭配。这里想写的是他仍能往前走，但仍感到难过，而且找不到可以放心亲近的人；原句把这些关系压得过紧。 → 他还记着从前的温暖，也留着那份骄傲，继续往前走。只是心里依然难过，不知道还能放心把心意交给谁。
- 累积（中等）：后半篇多次重新陈述“想亲近，却不愿为亲近受辱”的同一个两难，部分段落之间缺少足够明显的新变化。｜影响：这些句子单独看，大多自然，而且确实表达了人物的核心矛盾。连续阅读时，问题在于S10以后，读者已经明白他既舍不得亲近，又不能接受受辱，但接下来的几节仍不断以不同措辞重申这两个立场。S11增加了“舍掉哪一边都不像自己”的自我认识，这是新变化；相比之下，S12和S13有些句子主要还是在重新确认他不会为了亲近而低头。结果是音乐中的情绪可能还在发展，文字给人的感觉却有时停留在同一个结论上，削弱了后半篇的推进感。这是全文最明显的累积性问题。｜边界：这种两难本身必须反复出现，因为它就是人物经历的核心。S08写的是他受到一点回应后的急切与戒备，S11写的是他终于接受自己同时需要亲近和尊严，S13写的是短暂兴奋之后的清醒；这些都是有实际区别的，不能简单删除。真正需要留意的是那些已经没有增加新心理区别、只是再次宣布“不肯受辱”的句子，尤其是相邻几个段落连续出现时。｜建议：保留关键节点上的两难表述，让其余句子更多承担具体心理变化，而不是每次都完整重说两种立场。例如S12第2条可以和第1条合并成：“他记得那时的暖意，也记得亲近原本不必靠低声下气来换。”S13第2条可以简化为：“孤单和不舍还在，他也没有因此放低自己。”这样仍保留人物不愿受屈的态度，但不必再次使用完整的“为了被接纳而受辱”结构。

- 累积（轻微）：多处用抽象心理概念直接概括人物的变化，使普通讲述的口吻偶尔变成对心理状态的分析。｜影响：这些句子并非本身不通顺。问题在于连续读下来，“付出、接受、骄傲、强硬、受辱、受屈、坚持、接纳”等概念轮流出现，很多心理变化直接以结论的形式告诉读者。读者能够理解他的处境，却偶尔会感觉是旁人在整理他的心理，而不是一个人在平常地讲自己经历了什么。尤其当这类句子相邻出现时，叙述的情绪显得较为理性、整齐，少了一点犹豫、迟疑或不由自主的感觉。｜边界：这篇文字本来就以心理经历为主，又需要配合音乐分段，因此使用抽象词是合理的，也完全不需要为了改善语言而补造具体事件、人物或场景。“不让别人决定自己的分量”能体现人物重建尊严的决心；“舍掉哪一边都不像自己”能准确说出复杂的自我认识，都是有效的概括。只有当几个段落连续用概念解释概念，而没有穿插人物当下的直接感受时，才会形成距离感。文中“越劝越不安”“这次想了很久”“累得连旧事都无力细想”等句子就比较贴近日常感受，可以作为参照。｜建议：不必增加故事细节，也不必全面减少抽象词。只需要在少数位置把高度概括的判断改成更贴近人物当时想法的说法。例如S05第3条：“那时他想对人好就对人好，不怕被人看轻，心软也不觉得低人一等。如今他不肯受委屈，却已经撑得很累。”这保留了过去付出时的自在和骄傲，以及如今坚持尊严带来的疲惫，但说起来更像人在回想自己的感受。

### 5.6 第1次：8 分，6 处
- 最主要的问题：整体语言质量较好。连续读下来，人物从不安、强撑，到回忆、松动，再到承认自己既需要亲近又不肯受屈，心理线是清楚的；大部分句子克制、易懂，也没有为了煽情而补造场景。真正影响阅读体验的不是大量单句病句，而是后半篇对同一个核心冲突反复作近义重申，尤其S10以后几次重新落到“想亲近但不肯受辱／受屈”，使本来存在的细微推进有时被重复结论盖住。其次是转折和平衡句式使用得较密，让全文略带心理分析稿的整齐感。局部只有少数压缩过度或搭配稍硬的表达，修改成本很低。总体已经自然、完整，主要需要做的是减掉少量重复确认，让每一次回到核心矛盾时都更能显出这一次与上一次的区别。
- 一再出现：后半篇反复用近义表达重新确认“仍想亲近，但绝不因此受屈”，局部虽自然，累积后略有原地打转感；心理变化频繁写成两面相对的转折句，连续阅读后句式稍显整齐、分析化
  - [S01 第3条]「那份笃定没了，他仍在等，想起从前有次自然地靠近人，又忍不住想那样靠近。」——“有次自然地靠近人”组合得比较生硬。“有次”很口语，但后面的“自然地靠近人”又偏概括，接在一起不像平常叙述；末尾“那样靠近”还需要读者回头确认“那样”具体指什么。 → 那份笃定没了，他仍在等。想起从前有一次自然而然地靠近过别人，又忍不住想像那时一样靠近。
  - [S02 第2条]「他不再因牵挂去求，要靠自己往前，不让别人决定自己的分量。」——“因牵挂去求”压缩得过头，正常口语里通常会说“因为牵挂而去求谁”或“因为放不下就去求”。现在的说法意思能懂，但有一点提纲式。 → 他不想再因为牵挂去求谁，要靠自己往前，不让别人决定自己的分量。
  - [S03 第4条]「振奋渐渐退了，他怀疑自己是真信，还是硬逼自己相信。」——“是真信”略显生硬，像为了压短字数而省掉了“真的相信”。前后本来是在很细地分辨心理状态，这里的省略反而让语气突然变硬。 → 振奋渐渐退了，他怀疑自己是真的相信，还是硬逼自己相信。
  - [S05 第4条]「他开始心疼从前不用证明自己的自己，安心一退，又只剩一个人。」——“不用证明自己的自己”连续两个“自己”读起来明显绊一下。后半句“安心一退”也稍显概念化，像在给心理状态做标记，而不是自然地讲经历。 → 他开始心疼从前那个不用证明自己的自己。那点安心一退，又只剩他一个人。
  - [S06 第3条]「他先小心承认渴望，后来更迫切，却说不尽。」——“后来更迫切”省略了究竟是什么变得迫切，“却说不尽”也缺少清楚的落点。连续两个省略叠在一起后，读者需要自己补全句意。 → 他先小心承认自己的渴望，后来那渴望越来越迫切，却还是说不清。
  - [S13 第1条]「发现自己还愿意信赖、深爱和付出，也盼着安心接受亲近，他一阵兴奋。」——句首的“发现……”直接接“他一阵兴奋”，少了“时”或“以后”，略有书面压缩感；同时“信赖、深爱和付出”三个词并列时，“深爱”悬空得最明显，普通叙述里不太会这样并列。 → 发现自己还愿意信赖、去爱、去付出，也还盼着能安心接受亲近时，他一阵兴奋。
- 累积（中等）：后半篇多次重新陈述“想亲近，但不肯因此受屈”这一核心冲突，新增的信息有时不足以抵消重复感｜影响：这些句子单独看大多自然，而且核心矛盾本来就需要反复出现。但连续读到后半篇时，同一个心理结论被用“低声下气、看轻自己、受辱、受屈、受人轻慢”等近义方式不断重新确认，几次段落推进最后又落回几乎相同的位置。这样会削弱本来很细的心理变化：读者越来越容易先看到“又一次重申原则”，而不是注意这一次重申和上一次究竟有什么不同。尤其S10到S13之间，叙述有一点原地打转。｜边界：反复本身不是问题。S08中“越急切越抗拒”写的是欲望突然变强后的即时冲突，S11的“舍掉哪一边都不像自己”又明确推进到两难，这些重复都有新的作用。真正显得多余的是一些只再次确认“不肯受屈”、但没有明显增加新心理层次的句子，例如S12第2条，以及S13已经写过“受人轻慢”以后，结尾再落到“仍不肯受屈”。｜建议：保留几个真正承担转折作用的重申，其余位置可以把重点让给这一段新发生的变化，而不是再次完整复述原则。例如S12第2条可弱化为“从前的亲近不需要这样委屈自己，如今更不能了。”；S13末句则可以不再重复“不肯受屈”，改成“兴奋一下子退了，他看清：过去并没有因此回来。”这样仍保留失落，却把结尾的重点放在这一段真正新增的认识上。
