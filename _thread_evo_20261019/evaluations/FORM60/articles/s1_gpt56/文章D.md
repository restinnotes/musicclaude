# 文章D

**1–3**

**越分不清自己要的是靠近、回应还是保有自己，就越不敢把希望押在一个答案上。**

**4–16**

**真正让他敢靠近的，不是被拥有，而是不用为亲密交出自己。**
← 因为他逐渐发现，两个人可以彼此照应，却不必失去各自的声音。
→ 于是他相信靠近与自我或许能并存，却还不敢把眼前的相应当作长久的保证。

**17–23**

**一旦亲近真的发生，人就会开始追问它凭什么成立。**
← 因为他刚尝到靠近而不失去自己的可能，便不再满足于只证明亲近曾经发生。
→ 于是他开始分辨真实理解与暂时合拍，保留信任，却不再让信任替未来作证。

**24–34**

**一种满足有边界，不等于它从来不是真的。**
← 因为他发现亲密未必能持续，却也没有理由否认它曾经真实地给予过自己。
→ 于是他重新珍惜这份亲近，同时承认它不是最终答案，并开始看见其他尚未满足的需要。

**35–39**

**只有不再逼安稳包办一切，人才看得见安稳之外的自己。**
← 因为他承认亲密真实却有限，不再要求它替所有愿望作答。
→ 于是他看见自己还需要向前生长，宁可承受不确定，也不愿为了保住安稳而压下新需要。

**40–50**

**当成长也成了需要，关系稳不稳就不再是唯一标准。**
← 因为他不只想被接住，还想让自己的力量向外伸展。
→ 于是前进带来活力，也让他担心成长会改变原本令人安心的关系平衡。

**51–61**

**两种需要都是真的，难题就不是选谁，而是不再用谁抹掉谁。**
← 因为他反复确认向外生长不是一时冲动，却发现活力本身解决不了它与亲密的冲突。
→ 于是他开始寻找能同时容纳靠近与自由的方式，而不是让其中一方为另一方付出全部代价。

**62–71**

**如果每次得到都只算下一次追求的起点，满足就永远不算数。**
← 因为他已确认成长值得追求，却也看见一味向前会让已经得到的亲密失去位置。
→ 于是他试着停留在所得之中，分辨自己是真的还有重要需要，还是不习惯承认已经得到的价值。

**72–77**

**几种满足都是真的，冲突就不能再靠“多一点”解决。**
← 因为亲密、成长和享受所得各有价值，却没有因此自动相容。
→ 于是他不再只问自己还要去哪里，而开始追问怎样让这些需要同时属于自己。

**78–83**

**看清冲突不等于能解开它，急着选边只会把活问题变成死结。**
← 因为他知道亲密与自我伸展不能互相替代，却还没有找到让两者共存的做法。
→ 于是他允许自己暂时没有答案，不再为了摆脱不确定而仓促下结论。

**84–92**

**回到旧的亲密，不是回到旧答案，而是检验它能否容下新的自己。**
← 因为他已承认两种需要都真实，却还没有学会怎样同时承受它们。
→ 于是他重新靠近，却开始追问这份关系是否只有在自己不再变化时才能维持安稳。

**93–102**

**向外生长未必是在离开亲密，也可能让亲密变得更完整。**
← 因为重新检验后，他没有否认亲密，也不再把成长当成背离原路的冒险。
→ 于是他尝试把两种满足带回同一生活，不再把前进等同于离开、靠近等同于退让。

**103–110**

**此刻能同时满足，不代表以后永远不会冲突。**
← 因为亲密与成长开始能够并存，但一时的充盈仍不是永久保证。
→ 于是他回头检验自己的成长需要，分清哪些已无需反复证明，哪些即使满足过仍不能放弃。

**111–116**

**不必让一个答案消灭所有矛盾，才能承认每份满足都是真的。**
← 因为他终于看清，亲密有限不等于虚假，成长带来不安也不等于错误，得到与未得可以同时存在。
→ 于是他能珍惜已有、承认欠缺，继续追求或暂时安顿，不再逼不同需要挤成一个答案。
