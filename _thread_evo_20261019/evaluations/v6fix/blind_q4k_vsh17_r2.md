| S01 | 新版：X把“尚未说清的失落”落在已经失去却仍温暖的旧生活、被接纳感和勉强挺住的尊严上，能同时解释珠子里的恍惚、旧景闪回和“不能倒下却想停”的两股力。 | 新版：X四条虽然稍多，但每条分别承担失去、旧日体验、回忆的风险和不愿被失去支配的作用，Y反而额外造出“投入一边就会丢掉另一边”的前提，起点上没有来历。 | 新版：X说的是“不用证明自己值得留下”“怕以后只能靠回忆确认幸福过”这类具体心事，Y的“珍惜的东西”“别的珍贵东西”明显更泛。 |
| S02 | 新版：X把庄严步态解释成从失去中转向自持、坚持价值和不肯为接纳降低要求，因此能说明为什么私人旧歌仍在，外面却开始出现挺直和不甘。 | 新版：X从“不能停在过去”到“开始做事”再到“守住要求而生出骄傲”因果很直，Y同时塞进行动快感、发泄不满、怕白费和没顾上另一牵挂，动机略显过多。 | 新版：“想重新被接纳也不肯放低对自己的要求”比Y的“接下能做的事”“另一份牵挂”更像一个人在讲自己具体为什么硬撑。 |
| S03 | 新版：X清楚写出上一段的骄傲怎样一度变成“只要不退让就不会受伤”，又怎样被旧日亲近和旧日曾给予自己的勇气动摇，较完整地解释了从躁动自持转向温柔怀念和自我怀疑。 | 新版：X的转折都围绕“坚持是否足够”推进，Y则先说已经可以安心歇下，随后又突然怀疑先前的劲是否出于真心，中间的心理台阶略跳。 | 新版：X的“被理解、不用独自支撑、能坦然生活”比Y反复说“没顾上的事”“那种自在”更具体。 |
| S04 | h17：Y不仅保留了旧生活带来的快乐，还解释了为什么温暖会在段末转成越做越多、越想越停不下来的紧绷：他怕一停就得承认自己仍过不上向往的生活。 | h17：Y三条围绕“停下来意味着什么”形成单一压力链，X前半对怀念写得很细，却几乎没有解释108–115那股突然加剧的强迫性运动。 | 新版：X直接说亲近、理解、被爱、被留下，Y虽然因果更好，却仍用“那种生活”“行动”“决心”这些较概括的词。 |
| S05 | 新版：X同时交代了“亲近已经失去”带来的委屈和恼火、继续维护自己的劲，以及压住怀念直到疲惫的过程，比较完整地覆盖了这一段柔和私语之下仍有压力、愤怒，最后又松下来的弧线。 | h17：Y把硬撑压缩成一条清楚的误会——承认失望就像变心——再写到不愿靠受苦证明自己和终于承认眷恋，比X来回试过两头都不行更利落。 | 新版：“不肯为了重新被接纳委屈自己，可也不想以后都独自撑着”非常像真实的人话，也比Y的“变了心”“证明自己”更有生活对象。 |
| S06 | h17：Y从上一段终于承认眷恋，顺势让他暂时不再解决问题、只待在曾经的亲近与信任里，尤其能解释珠子里那种与现实隔开、无需证明、只看不抓的安静。 | 差不多：X的“旧日亲近给勇气”和“旧日坦然仍影响现在”略有重叠，Y的“沉进去”“不争抢”“不急着出来”也有相近意思，两边都有一点铺陈但都承担了有效内容。 | h17：Y写“不用防着受伤，也不用证明自己值得被爱、被接纳”“不用处处用力”，比X较总结性的“照着那时的心意认真生活”更贴近人在回忆里会说的话。 |
| S07 | 新版：X让刚得到的安宁被眼下的失落突然刺破，又写熟悉小事反而使失去更具体，并让他试着拿旧日留下的力量稳住自己却仍久久不安，很贴合惊醒、生活细节闯入和随后持续颤动三层体验。 | 新版：X三条就是“惊醒—具体回忆加痛—试图稳住却失败”，Y则在这一刻另建“争取会耗掉温柔”的新矛盾，解释力有但结构更绕。 | 新版：“想起熟悉的小事反倒更难受”“总惦着那份失去”比Y的“珍爱的东西还会受损”“理由够了就能安心”更具体自然。 |
| S08 | h17：Y直接把它写成前面那片亲近感短暂重新打开、本人只想再多待一下，而它已经开始消退，最能解释这里为什么是一次短暂回头和喘息而不是问题真的解决。 | h17：Y两条就完成“回来—想留—正在退去”，X三条主要是在说明快乐没有解决现实问题，信息有用但对这八小节稍显解释过量。 | 新版：X明确说“身边还缺少亲近和理解”，比Y的“那种曾让他满足的亲近感”“守着这份喜欢”更有现实落点。 |
| S09 | h17：Y明确让短暂亲近散去后最初的“我该怎么办”重新回来，同时又说明这次的迟疑已经被前面的经历改写，因此特别贴合珠子里“同一扇门从另一面再出现”。 | h17：Y两条分别说明问题复现和问题为何已经不同，X则只写舍不得安宁和现实仍要面对，少了一层回返后的新认识。 | h17：“这回他明白，自己迟疑不只因为害怕，也是真舍不得……”既具体又像人会对自己说的话，没有Y其他段常见的抽象负担。 |
| S10 | h17：Y把这一段解释成前面用力过狠后的疲倦、两种满足都舍不得、仍不知道接下来怎么走，并用“歇一歇不等于放弃”给零碎和悬空感一个很好的经历性理由。 | h17：Y只处理疲惫、未解决和允许休息三件事，X却在声音仍零碎未站稳时已经推进到“决定继续守住要求”，结论略早。 | h17：“之前用力太狠，他提不起劲再争取了”“歇一歇不算放弃”很口语也很身体化，虽仍有“那种生活”这类泛称，整体比X的决断性表述更像当下心声。 |
| S11 | h17：Y让他在害怕仍然存在时重新衡量能承担什么，并因为“停下也保护不了在乎的东西”而开始往前走，正好解释珠子里步伐从试探到不可回避、压力未解却开始前进。 | h17：Y三条依次总结两种旧办法都不够、重新衡量、带怕行动，变化清晰；X三条仍主要停在悲愤和两难，没有把这一段的推进真正推出去。 | 新版：X的“怎么既不委屈自己，又有亲近的人可以依靠”比Y的“在乎的一切”“承担什么”更具体、更像一个人的现实困境。 |
| S12 | 差不多：两版都能说明“经历动摇后仍主动站起来”：X强调受伤、想念仍在却继续守价值，Y强调不等害怕消失就先行动并允许结果未必如愿；Y更贴近声势复起，X的心理整合则更扎实。 | 新版：X四条虽多却分别完成来源改写、承认眷恋、价值选择和承受后果，Y第三条把“争取也可能伤到在乎的一切”再次重复S11的限制，第二条“接受害怕于是畅快回来”的连接也略快。 | 新版：X说“想要那样的亲近”“看重的事照样值得守”“不知道能走多远”，对象和处境都比Y的“珍爱的那种生活”“可能的代价”清楚。 |
| S13 | h17：Y把最后的大推进解释成“退回安宁也守不住，所以愿意出力”，又让行动明确服务于真心亲近的生活，并在高潮后写到会歇、会限量、仍不知道能守住多少，较完整地对应力量与柔软合流、冲刺、回落和余下疑问。 | 差不多：X的四条围绕怀念、骄傲和未来收束得很整齐，Y的四条围绕行动、快乐、节制和结果收束也各有功能，两边都没有明显多余环节。 | 新版：X最后仍说“亲近和理解”“不用证明自己就能安心生活”，Y虽然动作更准确，却继续大量使用“珍爱的东西”“那种生活”这类代称。 |
