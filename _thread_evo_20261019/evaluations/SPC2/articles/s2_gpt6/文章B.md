# 文章B

**1–23小节**

**我不知道接下来往哪走，只能先撑住，怕他们不再认我，也不敢想自己可能已经没了位置。**

**24–65小节**

**我先把自己管住，照熟悉的规矩做事，至少别让人看出我垮了。**
← 因为我怕失去归属，又不知道还能往哪走，只好抓住过去大家认可的做法。
→ 于是我能继续守住在乎的事，心里好受些，可他们还是没把我当自己人。

**66–91小节**

**我终于看清，光靠撑住自己，回答不了他们还认不认我。**
← 因为我把情绪和行为都管住了，却还是没等到他们接纳我。
→ 于是我承认，自己最怕的是那扇门再也不开。

**92–115小节**

**想起以前不用解释就有人知道我该站哪，我心里暖了一下，也更难受了。**
← 因为我看清自己怕的是失去归属，过去那些被自然接纳的时刻又浮上来。
→ 于是我知道那份亲近确实存在过，也更难面对眼下的空缺。

**116–147小节**

**我终于承认，我想听他们亲口说还认我，也盼着他们主动向我伸手。**
← 因为那份亲近曾经真实存在，如今的空缺让我想要一个明确回应。
→ 于是我说清了自己的愿望，却没法替他们答应。

**148–180小节**

**我先不追着要答案，试着安静地想想那些被理解、被欢迎的日子。**
← 因为回应只能由他们给，我暂时只能照看自己记得的那些日子。
→ 于是我心里稍微安稳些，可现实里的门还是没开。

**181–205小节**

**我知道自己没失去一切，可我现在还是想有人回应我。**
← 因为安静回想让我看见过去留下了什么，也让我看清记忆填不上眼前的空缺。
→ 于是我开始面对当下的需要，知道回忆没法替现在的人点头。

**206–213小节**

**我还在等有人认出我、愿意把我当自己人，也知道这可能落空。**
← 因为过去留给我的东西没法替现在的人回应，我仍然想要现实里的接纳。
→ 于是我说清楚自己在等什么，也承认结果不由我决定。

**214–215小节**

**想到他们可能不回应，我就想装回那副硬样子，骗自己不求人也能行。**
← 因为我说出了自己想要什么，也看见这件事可能没结果。
→ 于是我又想靠硬撑躲开被拒绝的感觉，可我还是想回去。

**216–225小节**

**我承认自己还是很在乎他们，想到曾被接纳的日子就会心软。**
← 因为装作不求人没能让我放下想念，我开始不再责怪自己的心软。
→ 于是我不再因想念他们自责，也不用为了显得坚强而装冷淡。

**226–241小节**

**我不想再装作谁都不需要，可我也怕只顾着等他们回头，会错过眼前的生活。**
← 因为我已经承认自己舍不得，也看见等着回到旧位置会耽误眼前的日子。
→ 于是我得找条新路，能带着这份想念继续过日子。

**242–253小节**

**我重新按自己相信的规矩做事，知道伤口还在，也可能等不到回应。**
← 因为我不想再装作谁都不需要，也不愿把日子全押在等他们回头上。
→ 于是我继续担起能做的事，不再逼自己表现得像没受过伤。

**254–288小节**

**我又回到人群里，还是盼着有人认出我，想到那段重要的日子也会难过。**
← 因为我决定过好眼前的日子，不再把未来全押在他们会不会回应上。
→ 于是我带着想念继续生活，不逼过去回来，也把那段经历教会我的东西用在往后的日子里。
