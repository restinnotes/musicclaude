# 最终输入协议（Thread 生成）

所有模型推理都经本机 `gpt3`（GPT-6 Thinking / max，Temporary + Unpersonalized）。每一步都是一个新会话、从零生成，不在旧稿上局部修改段落。

## 0. 分段（上游）

`works/<作品>/segmentation.json`（见 `SEGMENTATION.md`）。提示词里的分段句由 `seg.clause(d, "note")` 渲染：

> 按照小节数1, 4, 17, …, 117 来分段（最后一个数117只是全曲结束的边界，不是一个小节；全曲共116小节）

不要改成逐段区间列表（`ranges`）：它修掉了 117 误读，却在 6 个样本、3 位评委下都明显降低质量。

## 1. 第一遍：自己找主线（不给 Bead）

消息 = `FINAL_PROMPT_TEMPLATE.txt`（R2 版）填入 `{SEG}`（上面的分段句）和 `{WORK_SHORT}`（`segmentation.json` 的 `short_name`）。不附任何材料。
命令：`gpt3 ask --file <消息文件> --json`（脚本：`python gen.py R2 <work> note D0 <n>`）。

## 2. 第二遍：从头重写全文

消息 = 同一份第一遍提示词 + `---` + 下面二选一：

- **默认，不给 Bead**（推荐；两首作品都验证过）：`FINAL_REDRAFT_PROMPT.txt`，把第一遍全文填入 `{DRAFT}`。
  脚本：`python late.py R2 <work> note D0 <draft_run_ids>`
- **可选，给 Bead**（只在 Op.60 上测过，总体与不给持平，“鲜活”略高）：`FINAL_REDRAFT_WITH_BEADS_PROMPT.txt`，`{DRAFT}` 填第一遍全文，`{MATERIAL}` 填 14 段 reader（D3）。
  脚本：`python late.py R2 <work> note D3 <draft_run_ids>`

第二遍要求“检验初稿而不是装饰它”、“以能让整篇更真实的一边为准”、“从头写出完整新文章，不提初稿和材料”。

## 3. Bead 的组织规格（如果用）

- **入口在第二遍，不在第一遍。** 先给 Bead（D3/D4 直接附在提示词后）在 P0 和 Q1 下都没有净增益，而且会把 Bead 里的音乐事实错误照搬进文章（4 篇 9 处错误，其中 5 处高严重度；不给 Bead 的样本几乎为 0）。
- **用 14 段 reader（D3），不用 51 条（D4）。** 先给时 D4 全面最差（F5 音响描写合集、F3 抽象注水最多）；后给时 D3 与 D4 持平，D3 更短。
- 包装统一：材料前写明“不是剧情提纲、同段内可能有互不相容的听法、不能串成一个人接连发生的事”。
- **Bead 的作用边界**：在第二遍里，有 Bead 与无 Bead 的总体分数基本相同（J3：8.63 vs 8.64；J4：9.37 vs 9.25；J6：8.15 vs 8.48），Bead 的稳定贡献是“鲜活”一项更高、结论先行更少。因此 Bead 是加分项，不是必要条件；没有 Bead 的新作品照样走第 2 步的无 Bead 版本。
- **上游待修**：Bead/D1 中至少三处音乐事实需要按谱校正后再用于任何“先给”的场合：第72–77小节“颤音悬在半空”（颤音在第71小节、第82小节附近）；第115小节“细碎的琶音”（实为跨约六个八度、渐强冲向第116小节的高速音群）；第51–61小节“低音八度与切分”（八度加厚主要在右手旋律）。另有第1小节“两下和弦”而首拍实为左手低音八度的说法。

## 4. 输出的机器可读化

`python segcheck.py --export <run_id> thread.json` 会把文章里各种写法的段标题（`### 第1—3小节｜…`、`**（1—23小节）**`、`### 小节1—3`）解析出来，要求它们与 `segmentation.json` 的段落逐一相同且顺序一致，然后导出 `{work, boundaries, segments:[{id, start, end, text}]}`。最终方案 24/24 篇通过。不通过的文章（如先给 Bead 时整篇不分段）应重新生成，不要人工切分。

## 5. 不建议的做法（都实测过）

| 做法 | 结果 |
|---|---|
| 在提示词里再追加“节奏/不必每段领悟”的段落（Q2 = Q1 + P1 段落） | 变差（J5 7.17 vs Q1 8.19）：领悟句少了，音响描写和抽象词多了 |
| 先让模型比较多个候选困扰再写（P2） | 变差（J2 6.60 vs P0 8.41），更像论证 |
| 要求每段先从可听事件说起（P3） | 变差（J2 7.34） |
| 只加“只输出文章正文”（P0o） | 变差（J4 6.14 vs P0 7.10） |
| 先给 51 条 Bead（D4） | 三轮里一直最差的输入之一，并引入音乐错误 |
| 用 P0 做两遍 | Op.61 上变差（6.16 vs P0 单次 6.49）：出现评改式前言、说理更多；两遍机制要配 R2/Q1 |
