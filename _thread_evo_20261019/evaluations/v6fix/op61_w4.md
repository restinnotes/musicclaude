# Op.61｜关系图（A2 整首修补 w4）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他心里有股不肯停的劲，却说不清在等什么，熟悉感先牵动身体，念头还认不出方向。
- → 他怕再拖下去，会把珍惜之物继续受损当成没办法的事，也怕真投进去会失去别的东西。
- → 他想找个能说服自己的理由，可每次刚以为想通，不舍又回来，连那点确信也变得陌生。
- → 他为自己非得想透才肯动而难堪。

### S02｜24–65 小节　（正在面对）

- 他怕再拖下去会慢慢认下眼前的样子，也不愿看着珍惜的东西继续受损，便先接下能做的一份。
  - ← 提供理由：（1–23）「没办法的事」
- → 接下这一步后，他有了些力气，也有点骄傲，心里仍犯嘀咕却已经能继续做。
  - ← 改写：（1–23）「想透才肯动」
- 他仍惦记从前熟悉的亲近，那些珍惜的东西如今不能像过去那样自然地拥有。
- → 他一感到失落，就把心思压回眼前，越逼自己稳住，越显出他仍很在意。
- → 他刚聚起力气，又担心自己会垮，只好再逼自己用力，始终安顿不下来。

### S03｜66–91 小节　（没在想）

- 他因自己不再缩着而短暂高兴，少了些反复自问，可愤怒、不甘和失落仍让他定不下方向。
  - ← 提供理由：（24–65）「仍犯嘀咕」
- → 那种不用时时防备的亲近让他松了口气，可越觉得它可贵，越清楚眼下离它很远。
- → 轻松退去时，先前那份决定又占回他的心思，他开始怀疑刚才的昂扬有几分真心。
- ⟲ 仍在起作用：（24–65）「熟悉的亲近」

### S04｜92–115 小节　（正在面对）

- 短暂松开后，他记得接下那一步确实让自己重新动起来，所以仍愿意坚持。
  - ← 唤起：（66–91）「昂扬有几分真心」
  - ← 提供理由：（24–65）「仍犯嘀咕」
- 那阵亲近的温暖确实发生过，他当时看似坚定，也是在努力撑住自己。
  - ← 说明：（66–91）「不用时时防备」
- → 他越想追问过去还能怎样，越被眼前的事催着往前，反复盘问却始终换不来安心。
- → 他知道那一步有用，却不能把那种亲近带回来，光靠坚持还是安不下心。
  - ← 限制：（24–65）「熟悉的亲近」

### S05｜116–147 小节　（正在面对）

- 那次决定曾把他从犹疑里带出来，他舍不得松手，也怕一失望就说明自己变了心。
  - ← 提供理由：（92–115）「重新动起来」
- 他仍想要那种不用时时防备的亲近，想到它会心软，却怕这点软让自己停下来。
- → 他把受苦当成自己还不够坚定，越难受越逼自己继续撑。
- → 他把坚持变成不能示弱的硬规矩，连疲惫都不准承认，最后发现自己正逼着一个累了的人硬撑。
- → 他先有些茫然，撑着的劲也松了，不安没散，他才承认舍不得那种不必防备的生活。
- ⟲ 仍在起作用：（92–115）「努力撑住自己」

### S06｜148–180 小节　（没在想）

- 催逼停下来后，他认出自己舍不得的不是一时舒服，而是曾真心相信过的生活。
  - ← 说明：（116–147）「不必防备的生活」
- → 他盼着人与人靠近时不用时时防备，珍惜的东西也不必靠争抢才能留住。
- 他想付出时只是因为喜欢，不必反复证明自己值得被爱和接纳。
- 他确实尝过那种亲近带来的快乐，所以不肯轻易把这份向往说成软弱。
  - ← 提供理由：（92–115）「努力撑住自己」
- → 他不再逼自己维持坚强，也暂时不盘问这份向往有没有用，压住的委屈和思念终于能露出来。
  - ← 改写：（116–147）「不能示弱」
- → 他允许自己相信这份向往，满足和柔软慢慢回来，连先前的疲惫也暂时淡了。
- → 这份满足让他一时舍不得把心思拉回现实，可那种生活仍没真正实现。

### S07｜181–205 小节　（正在面对）

- 他刚认出自己想要的亲近，熟悉的生活感便清晰起来，现实仍缺着它，身体先绷紧。
  - ← 提供理由：（148–180）「这份满足」
- → 他当初不肯再等，是不愿看着重要的东西继续受损，如今妨碍那种生活的事还在。
  - ← 提供理由：（24–65）「接下能做的一份」
  - ← 说明：（148–180）「这份满足」
- → 他想重新投入，却怕自己又把疲惫当软弱，硬撑到最后把想保护的温柔也磨掉。
  - ← 提供理由：（116–147）「不能示弱」
- → 他原以为理由想明白就能安心，如今既怕珍惜之物受损，又怕争取磨掉温柔，反倒更难定心。
  - ← 改写：（1–23）「连那点确信」

### S08｜206–213 小节　（没在想）

- 为难时，那份曾让他满足的柔软又短暂浮现，他认得它，舍不得马上压下去。
- → 他记得那份满足曾真实地安慰过自己，这次不想一出现就把它变成必须解决的问题。
  - ← 提供理由：（148–180）「说成软弱」
- → 他终于喘过一口气，心里短暂安静下来，却已知道这份安静不会久留。
- ⟲ 仍在起作用：（148–180）「疲惫也暂时淡了」

### S09｜214–215 小节　（正在面对）

- 安静退去，熟悉的迟疑又浮上来，刚要站稳的心意随即散开。
  - ← 唤起：（206–213）「不会久留」
- → 他怕再把自己逼垮，也舍不得那种不必防备的生活，这次迟疑已牵着他认出的愿望。
  - ← 提供理由：（116–147）「不能示弱」
  - ← 说明：（181–205）「更难定心」
- ⟲ 仍在起作用：（148–180）「不必靠争抢」

### S10｜216–225 小节　（正在面对）

- 他知道自己舍不得那种生活，却想不出怎样护住它，光是知道仍提不起劲去争取。
  - ← 限制：（214–215）「认出的愿望」
- 那一步曾让他从无力里动起来，那份安宁也确实让他缓过来。
  - ← 说明：（24–65）「仍犯嘀咕」
  - ← 说明：（148–180）「疲惫也暂时淡了」
- → 可妨碍那种生活的事还在，光靠行动或怀念都不能替他把它护住。
  - ← 限制：（181–205）「继续受损」
- → 他不想一争取就忘了最初要护住什么，也不想一安宁下来就把眼前的威胁抛开。
  - ← 提供理由：（181–205）「继续受损」
- → 他还不知道怎么兼顾，却发现不必先把其中一边说成错，逼自己立刻选边的劲才松了一点。

### S11｜226–241 小节　（正在面对）

- 选边的压力松了一点，他仍没底，开始重新想眼前还能承担什么。
  - ← 提供理由：（216–225）「选边的劲」
- → 他亲自试过，接下眼前的事能让自己从无力里动起来，却不能把牵挂消掉。
  - ← 说明：（24–65）「仍犯嘀咕」
  - ← 限制：（92–115）「安不下心」
- 那份安宁也确实安慰过他，可妨碍那种生活的事仍在，光靠怀念挡不住。
  - ← 说明：（148–180）「疲惫也暂时淡了」
  - ← 限制：（181–205）「继续受损」
- → 他过去总怪自己不够坚定，如今才看见自己想护住的东西不止一件，硬逼自己只顾一边会伤到另一边。
- → 他还想退回安宁，盼着有条少伤一点的路，却心疼付出的代价，也知道眼前的损害不会因等待停下。
  - ← 提供理由：（181–205）「继续受损」
- → 他仍怕付出会磨损那份温柔，却没等自己先不怕，就接下眼前该做的事。
  - ← 提供理由：（181–205）「继续受损」
  - ← 限制：（181–205）「磨掉温柔」
- ⟲ 仍在起作用：（181–205）「磨掉温柔」

### S12｜242–253 小节　（正在面对）

- 他想到仍有代价，心里一晃，却没撤回眼前这一步，久违的昂扬重新回来。
  - ← 提供理由：（226–241）「没等自己先不怕」
- → 他仍想把能做的做好，却不再要求每次努力都得换来局面好转的证据。
  - ← 限制：（226–241）「从无力里动起来」
- → 他把那种不必时时防备的生活也算进自己要护住的东西里，愿意为它继续做事。
  - ← 改写：（226–241）「不止一件」

### S13｜254–288 小节　（正在面对）

- 带着对那种不必防备的生活的牵挂重新向前，他反而觉得旧愿近了些，心里也生出更开阔的喜悦。
  - ← 改写：（242–253）「要护住的东西」
- 从前一想到争取会磨掉温柔，他就想退回安宁，仿佛只要不动手就能保住它。
  - ← 说明：（226–241）「少伤一点的路」
- → 他不想再只在心里怀念那种生活，因为妨碍它的事仍会继续，他愿意为它承担眼前的事。
  - ← 改写：（148–180）「不必靠争抢」
  - ← 提供理由：（181–205）「继续受损」
  - ← 限制：（226–241）「光靠怀念挡不住」
- → 他知道再拼命也不保证那种生活能实现，硬撑还可能磨掉温柔，他不能为了向前把自己想护住的东西也压掉。
  - ← 限制：（226–241）「从无力里动起来」
  - ← 提供理由：（226–241）「少伤一点的路」
  - ← 限制：（116–147）「不能示弱」
- → 他曾把疲惫当成软弱，也怕舍不得会拖住自己，如今肯承认自己仍想要那种亲近。
  - ← 改写：（116–147）「不能示弱」
- → 想到那种亲近，他又尝到最初相信生活时的快乐，现实没变也不代表这份快乐或那次行动是白费。
  - ← 唤起：（148–180）「说成软弱」
  - ← 改写：（92–115）「安不下心」
- → 妨碍那种生活的事还没解决，他仍不知道尽力能改变多少，往后也可能因代价而动摇。
  - ← 限制：（226–241）「少伤一点的路」
- → 他不再反复找理由证明自己该向前，只继续做眼前能做的事。
  - ← 改写：（1–23）「连那点确信」
  - ← 说明：（226–241）「没等自己先不怕」
- ⟲ 仍在起作用：（181–205）「磨掉温柔」；（181–205）「继续受损」
