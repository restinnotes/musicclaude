《船歌》Op.60
Center：他在乎那份真切的亲近：它让他深深喜欢，也让他总想确认自己能不能安心待在其中。

### S01 ｜ 1–3 小节

• 一阵强烈的心动突然涌上来，兴奋而郑重，也带着一点紧张。
→ 想靠近的心意来得太直接，身体先有了反应。他还没来得及安顿，就已经感到这件事对自己很重要，不能轻轻带过。
• 激动渐渐变得柔和、谨慎，期待仍然悬着，不能完全放心。
→ 他已经清楚自己想靠近，却还没有任何根据相信这份亲近真的成立。越是珍惜这种可能，越不敢把强烈的心愿当成已经拥有的幸福，只能带着期待小心地等待。

### S02 ｜ 4–16 小节

• 先前绷着的心慢慢松开，他愿意被温柔托着，不急于落定。
→ 上一段他已经发现，单靠想靠近换不来确定；此刻一种持续的安适先让身体放松，他暂时不再逼自己掌控结果。即使一切还在向前，他也愿意安心待在其中。
• 他仿佛与人贴得很近，觉得亲昵、自在，沉默也甜蜜。
→ 刚才不再急着抓住保证，他才有余地体会亲近本身：不必努力证明什么，就能感到仿佛有人相伴的温暖。先前只能向往的好，如今第一次成为可以慢慢享受的感觉。
• 越觉得这一刻好，他越微微鼻酸，想让它慢一点过去。
→ 此前他只为亲近能否成立悬心；如今已经尝到其中的快乐，才开始舍不得它流走。眼前的好仍在，但他已经知道心意再强也不能保证留住它，所以这份甜开始带上一点酸。
• 他的喜欢忽然涌得更热切，随后柔和下来，仍有余恋。
→ 刚才的快乐已经珍贵到让他舍不得，他一度想更充分地靠近，让这份心意得到更多。可热切并不能替亲近换来保证，所以激动退下后，他仍留在这份温柔里，没有急着把心事说尽。

### S03 ｜ 17–23 小节

• 他还沉在刚才的幸福里，舒服地走着神，暂时什么也不想做。
→ 先前他已发现，即使亲近还没有保证，那份感觉本身也能让他安心。如今他舍不得这份快乐过去，便只想顺着它的余温停留，暂时不急着追求更多。
• 安静中忽然生出一点急切，想抓住什么，却很快又沉回温柔里。
→ 前面的快乐已经让他盼着这份亲近能多停留一会儿，所以心里偶尔会忍不住想把它抓得更稳。但满足感仍在，他还没有真的失去安心，这点急切便没有变成持续的追问。
• 温柔仍在，他却渐渐有些放不下，心思绕来绕去，难以安稳。
→ 正因为刚才曾不费力地享受幸福，如今又舍不得它过去，他才察觉，想让这份好一直持续，并不能让自己始终同样自在。越想留住刚才的安稳，心里反而越有一点牵挂。

### S04 ｜ 24–34 小节

• 熟悉的亲近又回来了，他欢喜，也松了口气。
→ 先前他已尝过亲近的快乐，也发现越想留住它，安心越难自然。如今同一种温柔仍能让他高兴，便多了一层庆幸，而不是多了任何保证。
• 欢喜越涨越满，甜得发酸，他不自觉地抓紧。
→ 上次幸福让他舍不得，后来想留住又使心里绷紧。这次越觉得美好仍在，越想再多感受一点；用力不是因为已经失去，而是怕此刻不够长。
• 他几乎想把心意全倾出来，却激动得发颤。
→ 他早知道心意再强也不能保证亲近，如今又带着想留住幸福的紧张。越想把感情表达得彻底，越觉倾尽自己也不能把这一刻定住，最热烈处反而有了哽咽。
• 热切渐渐退下，他安静了，却仍恋恋不舍。
→ 刚才他已经把欢喜推得很满，再用力也不能让它停得更久。身体终于慢慢松开，心里的舍不得却还在；这份安静并不意味着原来的疑问有了答案。

### S05 ｜ 35–39 小节

• 刚才攥紧的心忽然松开，轻了一点，却也失了重心。
→ 上一段他把喜悦和心意推到极致，仍没能让幸福长久有保证。再用力也无法留住这一刻，那股一直想抓紧的劲便先退了下去，反而让他一时无所依凭。
• 他忽然有些孤单、茫然，像从亲近里退回了自己。
→ 此前他能从亲近本身得到安心，刚才也确实那么幸福；如今那阵热烈已成了刚刚过去的事，他才清楚地感到自己与它有了距离。快乐并非不真实，却不能一直替他托住此刻。
• 空落渐渐变得柔软，他仍舍不得，却不再急着抓回刚才。
→ 此前越想留住幸福，安心反而越难自然；刚才又已经知道，再强烈的喜悦也换不来保证。如今那股用力终于退去，他开始能够安静地想念刚才的亲近，让留下的温暖陪着自己。

### S06 ｜ 40–50 小节

• 浓烈退去后，心里浮出一种清凉、安静而亲切的温柔。
→ 上一段让他发现，不重新抓住幸福，留下的温暖也仍然是真的。于是此刻他能停在余温里，尝到一种比先前更轻、更私密的满足。
• 这份温柔并不全然平静，安定里总有一点酸楚和反复的牵挂。
→ 上一段让舍不得不必再靠挽留来表达；不再急着做什么以后，那份仍未消失的眷恋反而更容易被直接感觉到，所以温暖和牵挂会一起回来。
• 亲切里开始有一点孤单，像幸福尚温暖，却已经带上回忆的距离。
→ 既然他已经能独自带着余温想念，就不必把它立刻拉回原来的当下；于是他第一次更清楚地感觉到，留下来的温暖与正在发生的幸福并不是同一种在场。

### S07 ｜ 51–61 小节

• 先前安静的想念渐渐变得滚烫，连身体都被更深的渴望推着向前。
→ 他已经能够不靠用力挽留，带着余温独自想念。正因为不必急着求一个结果，他反而能更深地沉进这份感受；原本安静的温暖渐渐变成了想要更深亲近的冲动。
• 这份回味又甜又烫，他明知自己越陷越深，却舍不得抽身。
→ 他已经尝到不必得到新的回应，也能独自享受想念的温暖。如今这份感受越来越浓，连身体都跟着陶醉；他不再只是温柔地记着那份幸福，也开始贪恋回味本身带来的快感。
• 甜蜜仍在，他却更清楚自己只能回味，不能重回那一刻。
→ 他已经知道最浓的幸福虽已过去，却仍真实，留下的温暖也带着距离。如今回味越鲜明，越像重新感到亲近，他反而越清楚：眼下的甜蜜是真的，却不等于过去那一刻重新成为现在。

### S08 ｜ 62–71 小节

• 他忽然不再纠结那份距离，心里敞亮起来，只想尽情高兴。
→ 先前他已发现，回味唤不回过去，却能让喜欢在身体里重新热起来。如今他不再只把这股热意当成求而不得，而是直接为自己还能这样深深地喜欢而欢喜。
• 欢喜越来越轻盈、活泼，甚至有点想把快乐分享出去的玩心。
→ 他已学会不靠用力挽留来表达舍不得，而刚才的想念又唤起了充沛的热情。此刻不急着追回过去的亲近，这股热情便能变成自在、活泼的表达，而不只是让自己心里发紧。
• 高兴还在往上涌，就忽然没了下文；他已经开始舍不得。
→ 这回他几乎忘了检查幸福能留多久，整个人都投在欢喜里；可他早已知道，再真切的快乐也不能被留住。正因为毫无防备地尽兴，快乐还没来得及落稳，想念就抢先到了。

### S09 ｜ 72–77 小节

• 刚才的欢喜突然收住，他一时空落，强烈的渴望却还在。
→ 他在尽情高兴时就已开始舍不得，却没能让快乐慢一点过去。如今那阵忘我真的停下，即使早有预感，身体仍突然失去着力点，暂时不知道怎样接住这一刻。
• 安静越深，他越感到余温还在，心却悬着，没有着落。
→ 他已经知道，过去的幸福依然真实，回味却不能让它回来。刚才的欢喜还那么清楚，却不能替他填满眼前的安静；他没有怀疑那份快乐，只是越来越想知道接下来还能有什么。
• 他几乎屏住呼吸地期待，紧张中又有一种出神的温柔。
→ 先前的忘我让他发现，不盘算得失也能被这份喜欢深深打动。此刻虽然不安仍在，他却不再追赶刚才的快乐，而是静静感受那份美好还留在心里；越不急着做什么，牵挂反而越集中。

### S10 ｜ 78–83 小节

• 他忽然松开紧绷，像终于能长长呼出一口气。
→ 上一刻他还带着温柔屏息等待，却没有新的快乐立刻接住他；等这阵空落真的被他承受下来，他也没有失去先前的温暖。绷紧已不能改变什么，身体便先于念头松开。
• 他明亮、柔软得几乎想哭，心里却不急着求什么。
→ 先前他已知道快乐过去也仍然真实，但刚才失去着落时，还是难以安心。如今不必马上拿下一份快乐来接续，曾有过的亲近与欢喜反而能不受牵挂打扰地涌上心头，让他深深感动。
• 空落忽然变得开阔，他轻得像暂时脱离了自己。
→ 此前的忘我是被当下欢喜带走；刚才却是快乐已过、下一刻尚未接住他。如今连寻找着落的劲也松了，那片空处竟能暂时让他舒展，而不是只让他悬着。但他并没有因此得到保证。

### S11 ｜ 84–92 小节

• 刚才轻飘的自在猛地变成沉甸甸、毫不遮掩的欢喜。
→ 刚才他发现，没有新的幸福接住自己也能松开；更早他已尝过只因喜欢本身而忘我的快乐。如今熟悉的亲近感再次鲜明，他不必先求一个保证，就敢把心意全放出来。
• 熟悉的温柔比从前沉重，越高兴越觉得心疼。
→ 他已经经历过幸福过去后仍温暖却有距离，也经历过还在欢乐中就开始舍不得。如今同样的亲近感回来，连先前的想念和失落也被一同唤起，所以不能再像最初那样轻轻享受。
• 欢喜越来越盛，盛得胸口发紧，几乎有点疼。
→ 他曾发现想念会唤起强烈的身体渴望，也曾在快乐里提前感到不舍。如今他又能不靠抓紧来安放自己，于是渴望、珍惜和喜悦一起涌上来，强得身体都难以承受。
• 他仿佛终于尽兴，却在最高处短暂悬住。
→ 从前把欢喜推到极致，也无法得到长久的保证；刚才他又学会在没有着落时松开。如今这份充实终于不必拿来换确定感，他可以尽情承受；但稍稍停住，下一刻仍未有答案。

### S12 ｜ 93–102 小节

• 欢喜忽然大得把他整个卷进去，连自己的得失都退远了。
→ S08让他尝过因喜欢本身而忘我的快乐，S11又让亲近承载此前所有甜蜜与不舍。如今两者一起涌来，他不只是为自己得到的幸福高兴，而像被一份比自己更大的喜悦整个淹没。
• 他快乐得发烫，几乎想哭，越充实越觉得心疼。
→ S09使他亲身知道，最满的快乐过去后仍会失去着落；S11又使这份幸福带上全部牵挂的重量。所以此刻越尽兴，越切身感到它珍贵而不能久留，喜悦和酸楚一同冲上来。
• 热烈中透出急切的恳求，到了末尾那口气仍悬着。
→ S11已经让他能毫无保留地接受这份幸福，却没让他安心；S09则使他知道，再充实的当下也不能替下一刻提供着落。于是眼前的狂喜与舍不得同时绷得很紧，直到末尾仍未真正松开。

### S13 ｜ 103–110 小节

• 他像终于站稳，痛快而毫不迟疑地认定这份喜欢。
→ 刚才他连留不住的心疼都带进了忘我的欢喜；如今那股激动凝成清楚的肯定，他发现自己依然如此喜欢，无需再用更大的快乐替它作证。
• 明明已经站稳，他却越发用力，怎么也松不下来。
→ 刚才他还能带着全部不舍忘我地投入；如今那阵忘我变成坚定的肯定，先前积下的温柔、失落和眷恋却没有随之消散。他不再需要更多证明，却仍要承受它们的全部分量，越坚持越吃力。
• 欢喜里渐渐浮出苦涩，心口像一次次往下沉。
→ 他曾在快乐尚未结束时就开始怀念，也经历过快乐过去后的无着落。此刻越肯定幸福真实，越明白它仍会过去；心里的那个「可是」不推翻刚才的肯定，却让这份坚定越来越疼。

### S14 ｜ 111–116 小节

• 那股越撑越疼的劲终于松了，疲倦里透出轻轻的释然。
→ 刚才他已经把幸福真实却终究留不住的疼，清醒地承受到了极处。再绷紧也不能让幸福多停留一刻，身体先松下来，心里那份必须继续撑住的急迫才渐渐退去。
• 熟悉的温柔又悄悄回来，亲切，却像隔着一点距离回望。
→ 他早已发现，幸福过去后仍能留下真实的温暖；如今强烈的不舍不再占满自己，最初那份亲近便重新浮起。只是经过后来的一切，它已不再是等待答案的期待，而是带着全部快乐与心疼的回忆。
• 快要安静时，心里又亮了一下，欢喜和舍不得一起涌上来。
→ 回望让那些已经过去的亲近再次变得鲜明，他仍会因为如此珍惜而突然心动。但他已经知道，坚定的喜欢消不掉不舍，也不必靠再次激动挽回什么；这一下既有留恋，也有单纯的欢喜。
• 最后他郑重而干脆地停住，心里仍热，却不再悬着追问。
→ 最初他想要一份能长久依靠的保证，后来却已经充分经历、也清楚肯定了这份幸福。如今连最后的留恋都走到了尽头；保证仍未得到，但经历不能因此作废。他不必再用力留住什么，也能让这一切真正结束。
