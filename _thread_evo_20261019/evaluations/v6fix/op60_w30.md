# Op.60｜关系图（在 v6 上修补，w30）

**Center：**对亲密的投入与自我克制始终相互牵制。

### S01｜1–3 小节　（还说不清）

- 他还不愿把这份喜欢推进到明确的决定里。

### S02｜4–16 小节　（没在想）

- 他不想让对方非得回应这份喜欢，也不再反复猜对方的反应，觉得能这样自然地关心对方就够了。
  - ← 改写：（1–3）「明确的决定」
- 他开始怕眼前的亲近不会一直持续，便希望这一刻慢些过去。
  - ← 限制：（1–3）「明确的决定」
- 他有过多表达一些心意的念头，热切过后还是把分寸收了回来。
  - ← 限制：（1–3）「明确的决定」

### S03｜17–23 小节　（正在面对）

- 他开始盼这份亲近能长久。
  - ← 提供理由：（4–16）「自然地关心」
- → 想到长久，他发现自己能决定怎样珍惜对方，却不能决定对方是否也珍惜自己。
- → 他偶尔想知道自己在对方心里是不是特别，却还不打算向对方索取答复。
  - ← 动摇：（4–16）「自然地关心」
- ⟲ 仍在起作用：（4–16）「慢些过去」

### S04｜24–34 小节　（正在面对）

- 他发现真心盼对方好、关心和给予本身也能让自己快乐，便暂时不再惦记自己是否特别。
  - ← 改写：（17–23）「是不是特别」
- → 他把不索取回应带来的轻松误当成亲近不会失去的保证，因此更敢把心意给出去。
- 他想更深地表达心意，却怕热切会变成催促，便收住了表达。
  - ← 提供理由：（17–23）「盼它长久」
  - ← 限制：（17–23）「不能决定」

### S05｜35–39 小节　（还说不清）

- 欢喜稍退，他又想知道对方是否把自己放在心上，先前那份确信便站不住了。
  - ← 动摇：（24–34）「轻松误当成保证」
  - ← 唤起：（17–23）「是不是特别」
- → 他开始怀疑自己对对方好时也盼着被珍惜，却知道先前的快乐不是为了换回应，怕追问会损坏亲近，便先想想自己到底盼什么。
  - ← 说明：（24–34）「关心和给予」
- → 他不敢再认定这份亲近会一直持续，也不急着替自己辩白或用新的热烈掩盖难堪，想让它继续下去的愿望便弱了。

### S06｜40–50 小节　（没在想）

- 他不再拿慷慨替自己辩白，也不再逼自己消除想被珍惜的期待。
  - ← 改写：（35–39）「被珍惜」
- 他暂时不再追问，却知道对方是否珍惜他、懂不懂他的心事仍没有答案。
  - ← 提供理由：（35–39）「放在心上」
- ⟲ 仍在起作用：（24–34）「关心和给予」

### S07｜51–61 小节　（正在面对）

- 他觉得这份喜欢本身值得珍惜，便想把它留在心里、不让它淡下去，也更常惦念对方。
  - ← 提供理由：（24–34）「关心和给予」
- → 他因此更盼自己的关心能被理解，却怕索取回应会搅坏亲近，便不催，把期待留给自己消化。
  - ← 限制：（35–39）「被珍惜」
- ⟲ 仍在起作用：（40–50）「没有答案」

### S08｜62–71 小节　（没在想）

- 他不再时时管住自己，愿意放开去喜欢、尽情享受。
  - ← 提供理由：（51–61）「留在心里」
- 他一边享受这份喜欢，一边想把眼前这一刻留住。
  - ← 提供理由：（4–16）「慢些过去」
  - ← 唤起：（35–39）「放在心上」

### S09｜72–77 小节　（正在面对）

- 欢喜稍退，他发现自己享受着眼前的亲近，还是盼着对方也把他放在心上。
  - ← 提供理由：（62–71）「留住这一刻」
- → 他知道不能拿自己的真心要求对方回应，也怕继续盼着会催到对方；可要他把盼望收回去，又像是否认自己的心意，他觉得委屈、疲惫，不知道该怎么办。
  - ← 说明：（17–23）「不能决定」
- ⟲ 仍在起作用：（51–61）「期待留给自己」

### S10｜78–83 小节　（正在面对）

- 他不再逼自己在想靠近和顾及对方之间作出取舍，也暂时不催自己把这份两难想明白，允许委屈和渴望都留着。
  - ← 改写：（72–77）「收回盼望」
- → 他还是愿意自然地关心对方，就算还不知道对方怎么想，也可以先不急着靠近，不必因此把眷恋压下去。
  - ← 提供理由：（72–77）「放在心上」
- ⟲ 仍在起作用：（51–61）「期待留给自己」

### S11｜84–92 小节　（正在面对）

- 他不再要求自己先把心事理清或决定这份关系的去留，愿意带着渴望继续亲近对方。
  - ← 改写：（78–83）「委屈和渴望」
- → 他承认自己也盼着被对方珍惜，不再因此怀疑先前的关心是不是出于真心。
  - ← 改写：（35–39）「被珍惜」
- ⟲ 仍在起作用：（72–77）「收回盼望」

### S12｜93–102 小节　（没在想）

- 他开始把心思放到两人可能共同拥有的日子上。
  - ← 提供理由：（84–92）「被对方珍惜」
  - ← 提供理由：（84–92）「继续亲近」
- 他只想让眼下的满足多留一会儿，便暂时把想被选择的期待搁在一旁。
  - ← 提供理由：（62–71）「留住这一刻」

### S13｜103–110 小节　（正在面对）

- 他想和对方一起过日子，可对方没有给出新的保证，他不能把眼下的满足当成两个人已经选定彼此。
  - ← 提供理由：（93–102）「共同拥有的日子」
- 他还盼对方主动靠近、把他放在心上，却不愿拿这份盼望逼对方回应，也不肯假装自己已经不在乎。
  - ← 限制：（72–77）「收回盼望」
- ⟲ 仍在起作用：（40–50）「没有答案」

### S14｜111–116 小节　（正在面对）

- 他不再把想被对方选择和不催对方当成只能二选一，也不再指望收住喜欢或尽情投入就能免去遗憾，因此不再因怕改变关系而收回喜欢。
  - ← 改写：（103–110）「逼对方回应」
- 他回想起自己曾安心靠近、真心给予、把喜欢留在心里、尽情享受的日子，知道这些经历虽没换来承诺，却都真切地让他快乐，也让他看清对方对自己有多重要。
  - ← 提供理由：（24–34）「关心和给予」
- ⟲ 仍在起作用：（40–50）「没有答案」
