<WritingBlock id="48216" variant="document">**1–3**

**我想靠近、想被回应，又怕一靠近就把自己弄丢，只能先借音乐安放这份说不清的渴望。**

**4–16**

**我发现自己想要的是彼此理解、彼此靠近，也各自保有自己。**
← 因为起初那团说不清的渴望，慢慢显出了我对亲密关系的期待。
→ 于是我愿意相信这份幸福，却还不敢认定它能长久；两条贴近的旋律向下展开。

**17–23**

**我开始怀疑，我们是真的懂彼此，还是只在某一刻合得来。**
← 因为这份亲密让我很快乐，却还没让我确定我们能一直互相理解。
→ 于是我追问这份信任能走多远，音乐也暂时离开原来的歌唱。

**24–34**

**我承认那份亲近是真的，可它回答不了我所有的问题。**
← 因为怀疑让我看见关系的局限，却没能抹掉曾经的幸福。
→ 于是我珍惜这份感情，也开始问自己还想要什么；原主题再次响起，两条旋律更加饱满。

**35–39**

**我开始看见，自己还想成长，也想试试生活里的其他可能。**
← 因为亲密没法满足所有需要，我终于有余力注意到安稳之外的愿望。
→ 于是我不再只顾着确认关系，音乐也慢慢转向陌生的色彩。

**40–50**

**我想主动往前走，却怕一改变，原本的安稳也会跟着改变。**
← 因为成长的愿望变得具体，我也看见它可能触动这段关系。
→ 于是我既期待未来，又担心失去现在；旋律转为上行，在A大调与升F小调之间游移。

**51–61**

**我确定自己想成长，可还没找到让亲密与自由都留下的办法。**
← 因为反复确认后，我发现成长带来充实，却无法自动化解被爱与自我发展的冲突。
→ 于是我不再逼自己二选一；上行旋律再次出现，我知道方向，却还走得不踏实。

**62–71**

**我开始想，能不能先好好享受已经拥有的幸福。**
← 因为总盯着还缺什么，我很难感受到眼前的满足。
→ 于是我试着体会已有的一切；琶音舒展开来，心里却还留着迟疑。

**72–77**

**亲密、成长和享受当下都让我满足，可我还不知道怎么让它们一起留下。**
← 因为我已经看见这些需要各有价值，没法只靠追逐下一步来安排它们。
→ 于是我停下来，不急着作答；音乐也暂时松开原有的节奏。

**78–83**

**我知道自己为什么卡住，却还没想出能让几种需要共存的办法。**
← 因为否认其中一种只会让我暂时轻松，反复分析又可能让我一直不去生活。
→ 于是我先承认自己暂时做不到两全；短促流动的旋律里，几股力量仍没找到合适的位置。

**84–92**

**我又回头看这段感情，想知道它能不能容得下改变后的我。**
← 因为我已经看见亲密有它的限度，成长也无法替我解决关系里的疑问。
→ 于是我不再回避这个问题；熟悉的旋律再次出现，带着紧张停在结尾。

**93–102**

**我开始相信，自己成长起来，也许能给这段关系添进更多东西。**
← 因为我亲自体验过被理解和自我成长各自带来的满足，知道两者都很重要。
→ 于是我可以继续向前，也继续靠近别人；主题回到主调，听起来更加热烈有力。

**103–110**

**我提醒自己，某一刻很圆满，也不能保证以后不再不安。**
← 因为眼下两种需要都得到满足，未来仍可能出现新的冲突。
→ 于是我重新分清哪些已经得到回应、哪些仍要坚持；音乐缩短上行主题，留下小调的阴影。

**111–116**

**我不再指望一个答案解决所有矛盾，也不再因为某种满足有局限就否定它。**
← 因为亲密有它做不到的事，成长也会带来不安，已有的满足仍可能伴随未实现的愿望。
→ 于是我开始分清每种需要给了我什么、又做不到什么，不再急着追求一个完美答案。

**我的烦恼还在，却不再逼着我不停追求、反复确认。**
← 因为我终于看见，几种需要都很重要，却没有一种能替其他需要作主。
→ 于是我可以珍惜已有的，也继续寻找尚未实现的；音乐最终收拢旧主题，安静落回升F大调，我也不再逼所有需要给出同一个答案。</WritingBlock>
