# Op.61｜关系图

**Center：**维持尊严的行动与对旧日生活及归属的怀念反复拉扯

### 1–23　（还说不清）

- 起初，他没觉得自己在怀念什么。
- 他心里总有一处落不下来。
- 过去，他不必费力解释自己。
- 过去，他不必小心衡量每一分心意。
- 那时，他自然相信自己有一个位置。
- 如今，那份确信消失了。
- 他仍不由自主地期待亲近。
- 期待落空时，他先感到难堪。
- 他不愿正视自己的失落。
- 他仿佛觉得，承认还在等就很可怜。
- 他羞于承认，期待却没有消失。
- 他既不能安心等，也不能真正不等。
- 他心里始终躁动。

### 24–65　（正在面对）

- 他受不了自己还需要那份回应。
  - ← 提供理由：（1–23）「期待亲近」
- 曾经自然得到的，如今似乎得伸手去求。
  - ← 改写：（1–23）「有一个位置」
- 只要想象伸手去求，他就感到受辱。
- 难堪逐渐变成不甘。
  - ← 改写：（1–23）「先感到难堪」
- 他不愿让安宁取决于别人的接纳。
- 他不愿为挽回亲近让别人决定自己的分量。
  - ← 提供理由：（1–23）「承认还在等」
- 他不再继续等候，转而向前。
  - ← 提供理由：（1–23）「不能真正不等」
- 起初，这样做使他感到畅快。
- 他发现自己能不再围着缺少的东西打转。
- 他喜欢上靠自己的力量撑住自己。
- 他喜欢不必向谁讨取准许的强硬。
- 旧日的牵挂仍在。
- 他不再顺着牵挂伸手。
- 先前的屈辱仿佛减轻了。
- 他第一次觉得，失去亲近至少还能保住自己。　✦ 分清
- ⟲ 仍在起作用：（1–23）「期待亲近」

### 66–91　（正在面对）

- 尝过畅快，他更舍不得放开向前的劲头。
  - ← 提供理由：（24–65）「感到畅快」
- 先前的委屈使如今的强硬格外扬眉吐气。
- 他仿佛觉得，精神昂扬就能甩开旧日期待。
  - ← 提供理由：（24–65）「讨取准许」
- 这种畅快渐渐带上不肯停歇的急切。
- 他其实并没有真的不在乎。
- 旧日亲近稍一浮现，他就立刻抵住。
- 连一瞬间的柔软都使他觉得危险。
- 他仿佛怕自己又回到等待和乞求。
  - ← 唤起：（24–65）「感到受辱」
- 他需要时时守着强硬的样子。
  - ← 限制：（24–65）「仿佛减轻了」 —— 屈辱的减轻仍要靠持续抵住牵挂。
- 那份强盛仍令他振奋，却已无法轻松。　✦ 办法的限度
- ⟲ 仍在起作用：（1–23）「先感到难堪」；（24–65）「牵挂仍在」

### 92–115　（正在面对）

- 他疲惫于连想念都不能安心想。　✦ 办法的限度
  - ← 提供理由：（66–91）「时时守着」
- 旧日的亲近也曾给他真切的快乐。
  - ← 唤起：（1–23）「有一个位置」
- 那份快乐曾使他愿意信赖和靠近。
- 想到这些，他似乎觉得自己不该留恋。
  - ← 提供理由：（66–91）「觉得危险」
- 他仿佛怕承认那份美好就保不住尊严。
  - ← 提供理由：（24–65）「讨取准许」
- 如今他连自己珍惜过什么都不敢承认。
  - ← 改写：（24–65）「转而向前」 —— 原本为免受辱而采取的强硬开始压住珍惜。
- 他仍没有放下倔强。
- 那股一直抵住想念的力气有些疲惫了。
- 被压住的温柔渐渐没那么可耻。
  - ← 唤起：（24–65）「牵挂仍在」

### 116–147　（正在面对）

- 旧日美好重现，先使他感到久违的亲切。
  - ← 唤起：（92–115）「没那么可耻」
- 他没有先感到自己曾惧怕的软弱。
  - ← 动摇：（66–91）「觉得危险」
- 他想念曾被接纳的安心。
  - ← 唤起：（1–23）「有一个位置」
- 他更珍惜那时能自然信赖别人的自己。　✦ 分清
- 那时，他能不吝惜地付出心意。
  - ← 说明：（1–23）「衡量每一分心意」
- 他不必每次付出都先怕被轻慢。
- 他无须时时证明自己值得被爱。
- 他无须用强硬遮住自己的需要。
- 那时，他可以柔软、热切、毫无防备。
- 他不觉得这样就低人一等。
  - ← 动摇：（92–115）「保不住尊严」
- 他心里的紧绷渐渐淡了些。
  - ← 动摇：（66–91）「无法轻松」
- 他开始疼爱曾那样生活的自己。
  - ← 唤起：（92–115）「真切的快乐」

### 148–180　（没在想）

- 他记起旧日生活里一直有的安稳。
  - ← 唤起：（116–147）「自然信赖别人」
- 那时，他的心意有地方可以去。
  - ← 说明：（116–147）「付出心意」
- 他能安心接受别人的亲近。
  - ← 唤起：（116–147）「被接纳的安心」
- 付出时，他不必计算得失。
- 接受时，他也不觉得亏欠。
- 那时，他也有骄傲，却无须时时防备。
  - ← 说明：（116–147）「证明自己值得被爱」
- 他从前不必在尊严和亲近之间选择。
  - ← 说明：（116–147）「低人一等」
- 那种自在如今显得格外美好。
- 他仿佛又感到从前那份宽阔。
  - ← 唤起：（116–147）「那样生活的自己」
- 当年拥有它的喜悦也重新鲜明。
- 失去的事实暂时退远了。
- 他没有急着比较过去和现在。
- 他没有追问那样的生活还能否回来。
- 他只想让那份温暖多停留一会儿。
- 他一时几乎忘了自己为何愤怒。
  - ← 动摇：（24–65）「变成不甘」 —— 曾推动他抗拒的怒气暂时退到心后。
