# 主研究者直接阅读笔记

记录于 2026-10-17。以下判断来自原稿与上一版实际正文，不以模型分数为依据；模型对照结果另记。

## 已确认的损失，不等于已确认的模型成因

1. **S02 的具体动作在统合时被淡化。** `SRC-gflash-int-1-U04` 写“两个人紧挨”的同时，还有“他们的肩膀贴着肩膀，声音放得极低”。旧读者稿保留了耳语，却去掉肩膀这一触觉细节。`SRC-gflash-int-3-U05` 的风“裹在皮肤上甚至有些黏稠”，旧稿变成“几乎轻轻贴在皮肤上”：温度还在，微妙的不舒适感和感官浓度减少了。原稿中的病情和临终解释并不能因这些句子好而一并接受。
2. **S02 内部稿先建了抽象主旨，再让读者稿反复证明。** 内部起句是“一种终于能够安心依恋的幸福，却因为太珍贵，反而不敢毫无保留地享受”。读者稿后面又写“太珍贵”“格外敏感”“不敢把幸福说得太满”“太喜欢眼前这一刻”。原料确实包含这一判断，问题是它多次挤占了其他可听、可感的内容。
3. **旧提示词不是完全没有质量要求。** 它已经明确“优先继承 A 原文自然、有力的表达”“不能以信息覆盖率堆砌同义句”。所以不能把失败描述成上一轮根本没要求保留好句。另一个同时存在的要求是先输出“内部完整珠子（核心体验、独特侧面、竞争解释、真实段内变化、来源ID、风险和保留/舍弃账本）”，再输出“中文完整珠子”；还要为未进入读者稿的有价值内容说明原因。这可能鼓励铺满解释，但它是否是主因要靠同Pool复跑验证。
4. **S13 的错误已经发生在上游，也在最终稿中被保住。** 旧内部稿把“表面出现了退潮的迹象”作为核心命题，且说退潮读法“不能因它较安静就将其删除”。读者稿因此先写“浪花退下去”“哭过后的清明”，再写“另一种却是听见不肯退场”。是否退潮是本段的事实位置问题，不能靠拥有多个A来源而豁免核查。
5. **S07 的语言漂亮，并不保证它属于 S07。** `SRC-gflash-int-3-U07` 将 *dolce sfogato* 定在 m.51；其“悬浮在无垠的星空”“时间停摆”进入旧稿的“奇异的失重”“时间也像停住了”。本地 Kopp 原文 [22] 明确将该段开始置于 m.78。因此不应为了保留优美语言把这组体验继续写进 S07，也不应在没有独立正确定位的A支持时机械搬到S10。
6. **原始A也有解释过度与概括偏好。** 主研究者完整读过的 Gemini int 三轮，都含“幸福太满/无法留住”及以病情解释音乐的框架；Muse int-1 反复写“想留住—焦虑—放下”，int-2 甚至自称全曲138小节、6/8。写作模型并非第一次引入这些问题。需要同时筛掉事实错误和抽象重复，不能只要求最终模型模仿Gemini。

- 新Pool不做摘要、不新增研究，只恢复相同来源相关单元的完整正文。每个单元检查为原始文件中的连续子串。
