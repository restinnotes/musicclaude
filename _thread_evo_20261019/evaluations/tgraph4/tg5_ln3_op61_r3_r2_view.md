# Op.61｜关系图

**Center：**维持尊严的行动与对旧日生活及归属的怀念反复拉扯

### 1–23　（还说不清）

- 他心里空了一处，却说不出少了什么。
- 过去的亲近曾让他不怕稍有疏忽便失去依靠。
- 想起旧日，他仍先感到安稳。
- 他甚至有一瞬间随熟悉感松弛下来。
- 那份安稳里似乎藏着让他不自在的东西。
- 他不明白自己的戒备，也不敢完全沉进去。
- 他舍不得把温存推远。
- 连怀念都不再自然，让他怅惘。

### 24–65　（正在面对）

- 曾为保住亲近而忍下的不满重新浮现。
  - ← 唤起：（1–23）「不自在的东西」
- 那些委屈使他确信自己有理由不退让。
  - ← 改写：（1–23）「不敢完全沉进去」
- 他终于不愿为了留住别人先让自己难受。
  - ← 改写：（1–23）「温存推远」
- 这种自由带来的畅快远超预想。
- 他喜欢自己此刻不再处处顾忌的硬气。
- 他甚至为过去的难堪感到一丝骄傲。
- 他感到积压已久的力量终于能伸展。
- 先前的迟疑暂时被冲淡。

### 66–91　（正在面对）

- 他愈发珍惜不必依赖别人认可的安稳。
- 痛快平息后，他感到另一种安静。
  - ← 限制：（24–65）「远超预想」
- 许多事情如今可由他自己承担。
- 他却少了一个能够放心依赖的所在。
  - ← 唤起：（1–23）「失去依靠」
- 保护自己的分量仍换不回被自然接纳的感觉。　✦ 办法的限度
  - ← 限制：（24–65）「留住别人」
- 这份欠缺暂未动摇他，却添了轻轻的孤单。
- ⟲ 仍在起作用：（24–65）「不再处处顾忌」

### 92–115　（正在面对）

- 孤单让旧日温存更难割舍。
  - ← 提供理由：（66–91）「轻轻的孤单」
- 他恼怒自己仍如此需要从前的生活。
- 他仿佛仍被旧日委屈借着依恋牵住。
- 怀念因此变得带刺。
- 原先畅快的坚定此刻也紧绷起来。
  - ← 改写：（24–65）「不再处处顾忌」
- 一想到失去的亲近，他便愤懑难平。
  - ← 唤起：（66–91）「放心依赖」
- ⟲ 仍在起作用：（24–65）「忍下的不满」

### 116–147　（正在面对）

- 持续的愤懑让他疲惫。
  - ← 提供理由：（92–115）「愤懑难平」
- 他不愿再只凭委屈回想过去。
- 他承认过去确实给过自己快乐。
  - ← 唤起：（1–23）「失去依靠」
- 他开始觉得当年的珍惜不全因软弱或怕失去。　✦ 分清
  - ← 改写：（92–115）「恼怒自己」
- 他不甘心：为何无法安稳地留在那份幸福里？
- 愤怒已无法替他把事情说清。　✦ 办法的限度
  - ← 限制：（92–115）「愤懑难平」
- 失去那些好，忽然难以只是解脱。
- 怀念让他的心柔软了些。
- ⟲ 仍在起作用：（92–115）「更难割舍」

### 148–180　（没在想）

- 他终于能少带怨气地感受过去的好。
  - ← 提供理由：（116–147）「给过自己快乐」
- 他记起那时不必时时证明自己值得被爱。
- 他怀念喜欢别人时可以只是喜欢。
- 他怀念依赖别人时不必觉得难堪。
- 旧日的快乐仍真实，并非失去后才显得美好。
  - ← 说明：（116–147）「不全因软弱」
- 此刻他暂时无心追究那些委屈。
  - ← 提供理由：（116–147）「柔软了些」
- 他只想在那份温柔里多停留一会儿。
- 重新感到无需防备，他甚至有些幸福。
  - ← 唤起：（1–23）「失去依靠」

### 181–205　（正在面对）

- 回忆里的幸福渐渐变得充实。
- 他几乎能像从前那样毫无顾忌地依恋。
- 需要别人照顾的自己也不再令他不安。
  - ← 唤起：（148–180）「不必觉得难堪」
- 他仍渴望把心完全交给值得信赖的感情。
- 先前的骄傲给不了他被温柔包容的满足。　✦ 满足照出未满足
  - ← 说明：（66–91）「自然接纳」
- 那些亲近在回忆里鲜明得仿佛从未远去。
- 这份满足又让他更舍不得。
- 他还想念那个能坦然爱人、放心示弱的自己。
  - ← 唤起：（148–180）「值得被爱」
- 往日的自在如今竟显得难得。
- ⟲ 仍在起作用：（148–180）「有些幸福」

### 206–213　（正在面对）

- 他忽然记起那时也有不敢表露的真实感受。
  - ← 动摇：（181–205）「放心示弱」
- 他曾怕认真提出要求会伤害感情。
- 刚才的幸福仍在，却忽然添了令人心疼的一面。
  - ← 改写：（181–205）「变得充实」
- 那份爱确实存在，他也曾为保住它而受苦。
  - ← 说明：（148–180）「仍真实」
- ⟲ 仍在起作用：（24–65）「忍下的不满」

### 214–215　（正在面对）

- 最舍不得的温暖竟也让他收起部分自己。
  - ← 说明：（206–213）「不敢表露」
  - ← 改写：（206–213）「为保住它而受苦」
- 他仍舍不得那份爱，却再也受不了委屈。
- ⟲ 仍在起作用：（181–205）「值得信赖」；（24–65）「理由不退让」

### 216–225　（正在面对）

- 旧日屈辱重新灼痛了他。
  - ← 唤起：（214–215）「收起部分自己」
- 这次的愤怒几乎没有畅快。
  - ← 改写：（24–65）「远超预想」
- 正因珍贵的好都是真的，他更痛恨当年的退让。　✦ 知道更多反而更尖锐
  - ← 提供理由：（148–180）「仍真实」
- 他不明白珍贵的亲近为何容不下完整的自己。
- 他仍想要温暖，却已不肯再靠忍委屈换取它。
- 他比起初更迫切地想保护当年受苦的自己。
  - ← 提供理由：（206–213）「为保住它而受苦」
- ⟲ 仍在起作用：（214–215）「再也受不了委屈」

### 226–241　（正在面对）

- 不退让的力量如今使他感到更沉重。
  - ← 改写：（216–225）「受苦的自己」
- 他终于看清失去的亲密与幸福有多珍贵。
  - ← 提供理由：（181–205）「显得难得」
- 他为失去那些感情而心疼。
  - ← 唤起：（181–205）「放心示弱」
- 他终于体会到守住自己也要付出代价。　✦ 选择的代价
  - ← 改写：（24–65）「留住别人」
- 他不愿再牺牲自己的需要。
  - ← 提供理由：（216–225）「受苦的自己」
- 他也不愿为表面的安稳藏起痛苦。
- 他仍为坚持骄傲，却不再觉得无所不能。
  - ← 限制：（181–205）「温柔包容」
- ⟲ 仍在起作用：（206–213）「伤害感情」

### 242–253　（正在面对）

- 这次怀念出现时，他不再恼怒自己。
  - ← 改写：（92–115）「恼怒自己」
- 他觉得仍爱旧日幸福并不可耻。
  - ← 提供理由：（116–147）「不全因软弱」
- 他尤其想念亲近中毫无隔阂的时刻。
  - ← 唤起：（148–180）「值得被爱」
- 再想起那份温柔，总带着一点疼。
- 他无法再毫无保留地沉入怀念。
  - ← 限制：（216–225）「忍委屈换取它」
- 他也不愿为守住尊严而否定曾经的幸福。
  - ← 提供理由：（148–180）「仍真实」
- ⟲ 仍在起作用：（214–215）「收起部分自己」

### 254–288　（正在面对）

- 只顾怀念，会让他觉得辜负当年受过的委屈。
- 只顾骄傲，他又会觉得辜负曾有的幸福。
- 怀念再也不会使他怀疑是否该回去。
  - ← 改写：（1–23）「温存推远」
- 他也不必否定过去，才能确信不该再忍耐。
  - ← 提供理由：（116–147）「给过自己快乐」
- 他如今能同时承认失去的难过与坚持的珍贵。　✦ 分清
  - ← 提供理由：（242–253）「否定曾经的幸福」
- 同时承认这些仍换不回失去的亲近。　✦ 办法的限度
  - ← 限制：（66–91）「放心依赖」
- 他仍没有既能放心依赖别人又不必收起自己的生活。
- 有时，失去的亲近仍令他难过得厉害。
  - ← 唤起：（214–215）「收起部分自己」
- 他格外盼望将来亲近时不必再忍委屈。
  - ← 唤起：（181–205）「放心示弱」
- 他带着思念继续向前。
- 他的怀念里也有了不愿再委屈自己的要求。
- 他虽更能承受这两份感情，渴望却未减。
- 他仍想在别人身边安心，也能对自己坦然。
  - ← 限制：（216–225）「受苦的自己」
- ⟲ 仍在起作用：（24–65）「忍下的不满」；（148–180）「有些幸福」；（66–91）「自然接纳」；（216–225）「忍委屈换取它」；（242–253）「并不可耻」；（181–205）「值得信赖」
