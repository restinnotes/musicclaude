# Op.61｜线（round28_crossc01）

### S01｜1–23 小节　（还说不清）

- 一开始，他想守住一点自己认可的体面，可这份郑重刚有形状，就被说不清的空落冲散。
- 那种空落又带着隐约的熟悉，他想到旧日生活曾给过的归属感，心里一暖，随即更觉无所依凭。 〔1–23 ①〕
- 他模模糊糊地盼着还能再次靠近那种感觉，却暂时看不出自己该怎样做。 〔1–23 ②〕
