  - [S06 第2条]「他想爱得更充分，便特意去细细体会那些原先自然感到的点滴幸福。」——这是比较明显的一处拗口表达。“爱得更充分”不太符合日常说话习惯；“那些原先自然感到的点滴幸福”也不顺，主要是“原先自然感到的”这个修饰语显得生硬。句子想表达的心理区别其实很好理解：过去不必刻意留心就能感到幸福，现在却开始有意识地体会它。 → 他想更尽情地爱，便特意留心那些从前不用刻意体会就能感到的小小幸福。
  - [S07 第3条]「他一次次确认没有失去什么，反倒难以像从前那样不必求证就享受亲密。」——“难以像从前那样不必求证就享受亲密”中，否定和修饰关系叠在一起，读起来要稍微回头整理。这里的意思并不复杂：越确认，反而越无法自然地享受亲密。原句把这个简单的变化说得有些绕。 → 他一遍遍确认自己什么也没失去，反而越来越难像从前那样，不用求证就能享受两人的亲近。
  - [S08 第2条]「他努力不再要求每一刻都比上一刻好，起初不容易，少了盘问确实轻松些。」——这里有一个容易使读者迟疑的细小偏差。S07主要写他反复检查幸福是否还和刚才一样、有没有减少；这里却变成“要求每一刻都比上一刻好”，从害怕变差变成要求不断变好，心理要求忽然提高了一级。此外，“少了盘问”没有明确对象，容易让人想到他在盘问对方，而前面主要写的是内心反复求证。 → 他试着不再时时比较，追问现在是不是还和刚才一样好。起初并不容易，可少了这样的自我追问，心里确实轻松了一些。
  - [S09 第4条]「他先前再用心珍惜，也安排不了将来；承认这一点，心里还是疼。」——“安排不了将来”能猜出意思，但不够准确自然。“安排将来”通常指规划未来的生活，而这里说的是无法决定两人的感情以后会怎样。用“左右不了以后会怎样”更符合这段心理。 → 他先前再怎么用心珍惜，也左右不了以后会怎样。承认这一点，他心里还是疼。
  - [S10 第1条]「明知眼前的幸福保不住往后也这样，他仍盼着长久，也怕会变，没法装作无所谓。」——“眼前的幸福保不住往后也这样”搭配不顺。“保不住”后面直接接“往后也这样”，不像自然的汉语表达。读者需要自己把它转换成“眼下幸福不能保证以后一直幸福”。 → 他明知眼下再幸福，也不能保证以后一直如此，却仍盼着长久，也怕这一切会变，没法装作无所谓。
  - [S13 第1条]「那股急切让他感到无力：就算尽情去爱，也保不住以后还像现在这样。」——这里再次出现“保不住”直接连接“以后还像现在这样”的搭配问题。“保不住以后还像现在这样”不如“不能保证以后还像现在这样”自然。这是句子本身的问题，不只是因为前面出现过相似表达。 → 那股急切让他感到无力：就算尽情去爱，也不能保证将来仍像现在这样。
  - [S14 第1条]「那些快乐他舍不得抹去，也不再为盼着长久而羞愧；只是他知道，盼望不能变成要对方永远不变。」——“盼望不能变成要对方永远不变”比较别扭。“盼望”是名词，“要对方永远不变”是一个动作性的说法，两者直接用“变成”连接，显得不够顺畅。这里其实是在区分两件很重要的事：可以希望爱情长久，但不能因此要求对方永远不变。 → 那些快乐他舍不得抹去，也不再为自己盼着长久而羞愧；但他知道，再想长久，也不能因此要求对方永远不变。
  - [S14 第2条]「从前非要对方交出心意，已经搅乱过他珍惜的亲密；他不想再提这种要求，妨碍自己自由地爱。」——“交出心意”本身就有些生硬，更值得注意的是“非要对方交出”和“再提这种要求”容易让人理解成他曾明确向对方提出过要求。前文虽然写过索取和要求保证，但也特别写了“暗中要求”，主要呈现的是内心的强求和反复求证。这里的措辞容易让读者以为发生过一次没有交代的正面要求。若本意仍是暗中的心理要求，最好说清楚。 → 从前他总在心里要对方不断证明心意，这种念头已经搅乱了他珍惜的亲密。他不想再抱着这样的要求，免得妨碍自己自由地爱。
  - [S14 第4条]「他不愿为少疼就克制快乐或收回心意，仍想靠近对方。他也舍不得如今这个自己：正因真心爱过，他才如此留恋，不想退回从前。」——“为少疼”省略得不自然，通常会说“为了少难受一点”。“克制快乐”也不如“压住快乐”或“不敢尽情快乐”贴近日常说法。另外，故事中的爱仍在继续，“真心爱过”容易带出爱情已经结束的感觉；这里如果强调的是一路以来的真心投入，使用持续性的表达会更准确。 → 他不愿为了让自己少难受一点，就压住眼下的快乐或收回心意。他还是想靠近对方，也舍不得如今这个自己：正因为一直真心去爱，他才这么留恋，不想退回从前。
- 累积（中等）：后半篇多次重新说明“眼下的幸福无法保证将来”，部分段落因此显得在原地反复确认同一个认识。｜影响：连续阅读时，这个主题的反复最为明显。S05第一次产生舍不得的感觉，S09真正承认将来无法保证，都是清楚的心理进展。S12又把问题推进到两个人终究有各自的心意，因而不能完全掌握彼此，这也有新的意义。但S10开头几乎立刻重复S09已经得出的认识，S13开头又重新说了一遍S12刚刚说明的限制，S14再一次明确未来无法掌控。虽然每段随后都有细微变化，但读者需要不断重读同一个基本判断，后半篇的推进感就会减弱。尤其S12本应是一次强烈的情绪高点，紧接着S13再次解释为什么留不住幸福，会稍微削弱那股情绪直接延续下去的力量。这并不使故事难懂，却使它有时像在反复论证同一个道理。｜边界：这不是说同一忧虑不能反复出现。人物从初次不安，到反复求证，到接受不确定，再到幸福极深时重新感到疼痛，本来就需要回到相同主题。S05的第一次舍不得、S09对未来无法保证的明确认识、S12对两个人独立心意的触及，以及S14不再因舍不得而责怪自己，都有各自的作用。真正值得精简的是那些刚刚讲明一件事，下一段又用相近的抽象判断重新讲一遍、却没有立刻带出新感受的地方。｜建议：保留主题的回返，但让重复出现的段落尽快落到这一回与上一回有什么不同，而不是每次重新陈述未来无法保证。比如S10开头可以改为：“他还是想和对方长久地在一起，也没法不怕失去。但这回，他不想让害怕替自己做决定。”这样直接进入从担忧到主动选择的变化。S13开头可以改为：“爱得越急，他越觉得无力。想把眼下的一切留住，却不知道自己还能做什么。”这样保留无力感，而不必又一次完整解释将来无法保证。

- 最主要的问题：连续读下来，整篇的心理发展是清楚的：从靠近、被接纳，到投入、舍不得、求证，再到承认无法保证长久却仍愿意去爱，前后转折基本都能顺着读下去。大多数句子也属于正常中文，并不存在大面积生硬或难懂的问题。最影响阅读体验的不是个别病句，而是中后段逐渐变浓的“心理分析感”：抽象词承担了太多叙事功能，同时人物的矛盾又经常被明确整理成让步、转折和因果关系。这样写很精确，却使全文有时不像一个人在平常地讲自己的经历，而像已经替自己的每一层心理关系做过解释和归纳。其次是少数小节句式过齐，以及几处压缩过头或搭配不自然的局部表达。值得修改的方向不是增加具体事件，也不是大量替换“心意、幸福、舍不得”等核心词，而是让其中一部分句子少解释一层、少堆一个抽象概念，并适当打散同小节的句式。整体基础较好，情绪脉络和人物心理区别大多保得住，问题主要集中在语言过度整理之后产生的距离感。

  - [S11 第2条]「他坦然需要对方」——“需要”在这里是心理状态，“坦然”直接修饰它略显生硬。自然的说法通常是坦然面对、承认或接受自己的这种需要。 → 他能坦然面对自己对对方的需要，也热切盼对方幸福，两份心愿不再彼此拉扯。
  - [S13 第4条]「不可能盼着一切从未发生」——“盼着”通常指向尚未发生的事，用来表达“希望过去根本没有发生过”稍显别扭。这里换成能够表示反事实愿望的“希望”更自然。 → 也不可能希望这一切从未发生过
- 累积（中等）：抽象的心理词和关系词长期承担主要叙事动作，读到中后段时容易产生“在整理心理机制”多于“在讲自己的经历”的感觉。｜影响：“心意、幸福、亲近、付出、眷恋、满足、舍不得”等词本身都正常，而且正是这篇文字需要追踪的核心内容。问题在于许多句子同时用两三个这类抽象词来说明另一个抽象心理变化，具体的感受常被概念之间的关系代替。连续读十四段后，读者需要不断记住“心意被接住—付出带来满足—满足变成舍不得—舍不得引出求证”等关系，文本因而逐渐接近心理分析提纲，离“一个人平平常常地讲自己的经历”稍远了一点。｜边界：核心词的回环并不是问题。“接住心意”在前段建立关系，到后文重新出现，能形成很清楚的照应；“幸福”“舍不得”也是故事真正围绕的东西，不能为了避重复全部换掉。真正影响阅读的是某些段落连续让多个抽象概念互相解释，尤其一句里同时堆入“心意、付出、满足、亲近、幸福”等词时。这里也不需要补造人物、事件或场景，只要偶尔改成更直接的状态描述即可。｜建议：保留少数作为主线标记的关键词，其他位置适当改成较直接的说法。例如 S04 可写成：“心意被接住，付出本身也让他满足，他渐渐不再顾虑，也不再总想两个人是不是一样热切。”下一句再写：“他不太计较自己给了多少、得了多少，也不用每次亲近都去求证。”这样心理关系没有改变，但读者不必一次处理太多概念。S12 的“把所有眷恋都倾注给对方，恨不得两人的心意完全相融”也可以稍放松为：“他想再靠近一些，恨不得把满心的眷恋都给对方，两个人的心再没有一点距离。”

- 累积（中等）：让步、转折和自我校正式的句法在中后段持续出现，使很多段落都呈现“A是真的，但B也是真的”的论证节奏。｜影响：这些转折单独看大多很自然，而且人物的核心处境本来就是两种真实感受同时存在，所以需要大量让步和对照。累积的问题是，到了 S09–S14，几乎每一步心理变化都被显式整理成“虽然如此，却仍如此”“不是前者，而是后者”。读者因此不断被提醒前后命题之间的逻辑关系，叙述节奏显得很会解释自己，稍有一种作者在替人物做心理辨析的感觉。情绪本身反而少了一点自然流动。｜边界：真正的转折点不能删。例如“他知道对方爱他，可还是忍不住比较”准确写出了问题所在；“不愿收回爱，也不想要求对方永不改变”也是后期人物选择的核心。需要减的是已经由上下文充分说明、又再次用“却、可、仍、反而、只是、没因此”等词明确标注的次级转折，而不是把矛盾心理改成单一心理。｜建议：有些地方可以让两个事实并排存在，不必每次都用连接词替读者说明它们相反。例如 S09 第2条可改成：“两人如今确实幸福。正因为这样，他才这么舍不得；这份苦恼也不能全算作贪心。”S13 第4条也可稍松开：“有一瞬间，他怪自己爱得太深。可先前那些快乐是真的，付出的爱也没有错。想到这里，他反而更难放下，也无法希望这一切从没发生过。”保留真正重要的“可”，其余关系交给句序表达。

### 5.6 第2次：8 分，7 处
- 最主要的问题：整体语言质量较高。连续读下来，人物从靠近、被接纳，到因舍不得而求证，再到承认无法控制将来、重新选择自由去爱的变化是清楚而连贯的；不少细微区别也写得准确，例如“不安心”与“重新坦然”并存，并没有被简单处理成一个圆满结论。真正影响阅读体验的主要不是病句，而是中后段逐渐增加的分析感：抽象心理词较密，同时大量依靠转折、让步和自我修正把每层心理区别说明完整，使部分段落不像人在顺着经历讲，而像在给自己的感情作精确解释。这个问题属于中等程度，并未破坏整体流畅和情绪推进。局部另有少数搭配或句法确实生硬，其中“眼前的幸福保不住往后也这样”最明显；连续以“他”起句造成的节奏单一则只是次要问题。
- 一再出现：中后段抽象心理概念较密，连续出现时会增强分析感，削弱平常叙述的自然感。；后半篇多层转折、让步和自我修正较集中，累积后略有心理论证式的节奏。；若干小节连续使用“他＋心理或意愿动词”的起句方式，造成轻微的节奏单调。
  - [S03 第3条]「他急着把得到的好也给出去，对方幸福他就满足，付出反而让他更丰足。」——前半句很自然，但“让他更丰足”略显书面和抽象。“丰足”通常更容易修饰生活、内心或某种状态，直接说一个人“更丰足”，放在这篇偏平常叙述的文字里稍微突兀。 → 他急着把得到的好也给出去，对方幸福他就满足，付出反而让他心里更充实。
  - [S06 第2条]「他想爱得更充分，便特意去细细体会那些原先自然感到的点滴幸福。」——“爱得更充分”不太像日常中文里会自然说出的搭配，“原先自然感到”也略显分析式。两个偏概念化的说法叠在一起，使这句话比上下文生硬。 → 他想更尽心地去爱，便特意细细体会那些原本自然而然就能感到的点滴幸福。
  - [S06 第3条]「他相信此刻的幸福抹不掉，盼着以后不那么满足时，回想起来还能给他力量。」——“幸福抹不掉”能理解，但搭配略悬空，通常会说某段记忆、痕迹“抹不掉”，或说幸福“不会被抹去”。这里读到“抹不掉”时会短暂停一下。 → 他相信此刻的幸福不会被轻易抹去，盼着以后不那么满足时，回想起来还能给他力量。
  - [S07 第3条]「他一次次确认没有失去什么，反倒难以像从前那样不必求证就享受亲密。」——“难以像从前那样不必求证就……”里面套了否定和比较关系，意思没有问题，但句法稍绕，需要重新理一下“难以”的范围。 → 他一次次确认自己并没有失去什么，反倒越来越难像从前那样，不求证就安心享受亲密。
  - [S09 第4条]「他先前再用心珍惜，也安排不了将来；承认这一点，心里还是疼。」——“安排不了将来”容易让人先想到计划、筹划未来，而这里实际说的是无法决定或控制以后会怎样，搭配不够贴切。 → 他先前再怎么用心珍惜，也决定不了将来会怎样；承认这一点，心里还是疼。
  - [S10 第1条]「明知眼前的幸福保不住往后也这样，他仍盼着长久，也怕会变，没法装作无所谓。」——“幸福保不住往后也这样”这一段结构不顺。“保不住”通常接具体对象或状态，这里实际要说的是眼前的幸福不能保证未来仍旧如此。 → 明知眼前的幸福不能保证往后还会这样，他仍盼着长久，也怕会变，没法装作无所谓。
  - [S14 第2条]「从前非要对方交出心意，已经搅乱过他珍惜的亲密；他不想再提这种要求，妨碍自己自由地爱。」——后半句两个分句之间的关系不够明确。按意思，“妨碍自己自由地爱”是他不想再提要求的原因或要避免的结果，但现在直接用逗号连接，容易读成两个并列动作。 → 从前非要对方交出心意，已经搅乱过他珍惜的亲密；他不想再提这种要求，免得妨碍自己自由地爱。
- 累积（中等）：抽象的心理概念在中后段持续密集出现，使叙述逐渐有一点像在分析感情，而不是平常地讲自己经历了什么。｜影响：“心意、幸福、付出、亲近、满足、要求、舍不得、坦然”这些词本身大都自然，而且正是全文需要反复追踪的心理线索。问题不在重复本身，而在于不少段落连续用这些概念彼此解释：一种心理状态再由另一种心理状态说明，具体动作越来越少。连续读到中后段时，读者需要不断分辨相近概念之间的细小差别，叙述因此稍微从“一个人在说自己的事”滑向“把自己的心理机制说明白”。｜边界：核心词如“幸福”“舍不得”“心意”完全没有必要刻意回避，它们承担了全文的主题和前后照应；在关键转折处准确说出“求证”“要求”“坦然”也很有效。真正显得多余的是一句里同时堆进数个抽象概念，或者前一句已经让读者感受到变化，下一句又把同一变化重新概念化说明。｜建议：不必补造人物、场景或事件，只需在部分位置少解释一层，多用简单动词承接前文。例如S06第2条可改为“他想更尽心地去爱，便开始特意留心那些原本自然而然就能感到的快乐。”S14第3条则可以稍收束为“不再这样要求，他仍管不了以后怎样。想到这一切可能会变，他还是会疼，也有点不甘心，只是不再为自己的舍不得难为情。”

- 累积（中等）：后半篇连续使用多层转折、让步和自我修正，心理区别虽然准确，但累积后使句子显得较强的论证性。｜影响：这些转折单独看大多很好，尤其全文真正要写的正是“明知如此，却仍然如此”“没有安心，却重新坦然”这种细微区别。但从S07往后，很多条目都采用“先确认一层—再转折—再补一个例外或修正”的结构，读者会越来越像在跟随一套严密的心理推理。人物的矛盾因此解释得非常完整，却也少了一点自然流动感；到S13、S14时尤其容易产生“每个可能的误解都被提前澄清”的感觉。｜边界：像“他没因此安心，心里却重新坦然起来”这种转折不能简单删掉，因为“安心”和“坦然”的区别正是人物变化的关键。问题主要出现在相邻条目连续采用类似的辩证结构，或者一句已经完成主要转折后又继续补第二、第三层限定。｜建议：保留真正决定人物变化的那一层转折，部分次要限定可以让上下文自行承担。例如S13第4条可略收为“他一瞬间怪自己爱得太深。可那些快乐是真的，付出的爱也没有错，所以他反而更难放下。”这样仍保留原来的心理区别，但读起来少一层论证。S14第3条也可以把“不再怪自己舍不得”直接说成“不再为这份舍不得羞愧”，减少一次绕行。

- 累积（中等）：大量用“不、没、不再、不愿、不肯、不必”配合“也、却、仍、可”来界定心理状态，久读后形成较强的辩证式、论证式节奏。｜影响：这种写法很适合表现人物不断给自己划界线、修正上一阶段想法的过程，所以单句往往自然；但连续使用后，人物几乎每进一步都通过“不是这个、也不是那个”“虽然如此、却仍如何”来定义。结果是心理逻辑非常严密，语气却略显时时在自我辩论。全文本来希望像平常讲经历，这种高频的否定和转折会让声音稍显经过整理和论证。｜边界：在真正存在两难和转折的地方，这种结构是必要而且有效的，例如 S05“他不肯委屈自己换取接纳，也不愿永远独自撑着”准确地写出了两头都不能接受的处境，不应为了变化而改掉。问题主要出现在已经可以正面陈述新状态时，仍继续用两三层否定来说明它。｜建议：在已经完成转变的段落里，可以多用正面陈述，让节奏松开。例如 S06 第1条可改成：“他暂且让自尊和怀念一起留着。想起过去时，他愿意多待一会儿；看着现在，也不再要求它一定像从前。”这样保留原来的心理区别，但少了一层层否定。
