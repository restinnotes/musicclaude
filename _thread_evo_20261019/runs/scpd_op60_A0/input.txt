任务：为一首器乐作品独立构思三条候选 Thread 经历。

Thread 是一个人在作品对应的时间进程中经历的一件事。
它最终要写成按段排列的线：只读线，不看听感记录
（珠子），也能读到一件有前因、有发展、属于这个人的事。

本阶段只构思经历，不写成品条目，不写散文。
本阶段不能看到珠子、A稿或从珠子提炼出的任何资料，
也不能猜测珠子具体写了什么。

【作品及固定 Center】
作曲家：肖邦（Chopin）
作品：《船歌》Op.60
Center（上游已定，不改）：亲密的幸福与留不住它的痛楚难以分开

【段落及边界】
S01：第 1–3 小节
S02：第 4–16 小节
S03：第 17–23 小节
S04：第 24–34 小节
S05：第 35–39 小节
S06：第 40–50 小节
S07：第 51–61 小节
S08：第 62–71 小节
S09：第 72–77 小节
S10：第 78–83 小节
S11：第 84–92 小节
S12：第 93–102 小节
S13：第 103–110 小节
S14：第 111–116 小节

【可选：独立于珠子的作品资料】
（没有另外提供；可以用你对这首作品的了解，也可以联网查。）

一、固定起点

Center 来自上游 N04，已经确定。
围绕给定 Center 构思，不重新定义或替换它。

同一条候选从头到尾都是同一个人经历的同一件事。
作品段落的顺序，就是这件事在他心里经历的时间顺序。

可以依据对作品的了解、独立音乐资料或联网查到的
可靠作品信息，判断不同段落适合承载什么感受，
以及经历在时间上适合怎样展开。

但音乐里的变化不能成为人物心理变化的原因。
人物为什么这样想、为什么改变，要从他自己的处境、
愿望和此前已经经历的内容中找到根据。

不掌握精确音乐细节时，不伪称掌握。
也不以精确到小节的对应代替人物经历本身的成立。

二、构思一个真正在意事情的人

每条候选都要说清：

- 他现在实际处在什么事情里；
- 什么对他重要，他具体希望得到或保住什么；
- 他有什么顾虑，为什么不能轻易随心所欲；
- 他此前的感受或态度，会怎样影响后来的自己。

具体性主要放在人物的所求、顾虑、舍不得和感受上。
不能只给人物安排一个抽象议题，再让他逐段思考它。

也不能只说他在意某个对象，却没有交代这种在意
对他本人有什么切身意义。

不虚构具体职业、年龄、地点、物件、对白、外部事件，
或为解释人物而新增一段具体前史。

允许开头存在一个轻量、持续的基本处境。
它可以包含人物关系的基本状态和当下的心理倾向，
但不能靠后续新增事实推动故事。

不要为了让人物具体，就替他编造外部动作和他人的回应。
也不要因禁止外部情节，就把所有具体的人际顾虑、
愿望和个人感受删成抽象概念。

三、保留真正发生过的心理历史

构思时区分：

- 开头已经成立的基本事实和处境；
- 他在这首作品的进程中实际经历过的感受、犹豫和回应；
- 只是猜测、担心或希望，并没有成为事实的事情；
- 已经形成、后来可以继续起作用的认识或选择；
- 到结尾仍未得到答案的事情。

后面的感受应能从此前的经历中生长出来。

已经形成的认识不能在后面重新写成第一次发现。
但知道一件事，不等于以后不会再为它难受，
也不等于已经能够在所有时候照着它去做。

同样的愿望或顾虑可以再次出现。
再次出现时，检查此前的经历有没有改变它的意味。
如果有，记录真实的区别；如果没有，就承认它在延续。

不要把每次情绪增强都写成新认识。
不要让人物反复证明同一结论。
也不要为了制造发展，安排固定的尝试、失败、领悟、
决定或解决过程。

四、设计自然的时间进程

先想整件事，再判断每个段落实际承载什么。

重要变化要有前因。
前因可以来自很早的段落，但必须是真实成立的内容，
不能仅仅因为两段谈论同一个主题就算有因果。

不要求每段都有新变化。
一段可以是在延续先前的心情，也可以是暂时没在想
整件事，或在一种已经形成的感受中停留。

段落短、实际发生得少，就不要硬塞新的心理动作。
较长段落也不因长度较长，就必须获得某种认识。

整条经历要能一直往前读。
它可以有反复和迟疑，但不应像不断回到起点；
也不应把所有问题都整理成逐步获得解决的过程。

结尾只需写人物实际走到了哪里。
不要求外部结果，不要求彻底解决，也不预先规定
必须作出一个坚定决定。

五、三条候选的区别

独立构思三条有实质差异的候选经历。

差异应体现在人物为什么在意、在意什么、
顾虑什么，或这些经历怎样逐渐改变他。

不要只把同一条经历换一种说法。
不要故意套用三种固定的故事类型。
不要把几种不同的心理问题堆在一起，
以制造表面上的丰富。

每条候选都必须是有可能独立写成一条完整线的经历。

六、表达和内部检查

使用自然、准确的中文。

可以构思复杂的心理关系，但必须能够说明
这些感受具体属于这个人，来自他的什么经历，
又对他以后产生了什么实际影响。

不要用心理学标签、哲理概括、价值判断
代替人物自己的所求和感受。

turns 是内部历史账本，不是以后逐条写进正文的提纲。
只记录真正重要的变化。
basis 记录它在此前经历中的根据。
change 记录已经成立、以后不能重新当作未知的内容。

没有新变化的段落，应在 segment_sketch 中如实标明，
不要为填 turns 而制造转折。

initial_facts 只列开头已成立的轻量处境和心理事实，
不能加入一段具体的、未经给定材料支持的前史。

weaknesses 应指出这条路线可能存在的实际缺点，
例如人物所求不清、前因不足、内容重复、
后段缺乏新的实际经历或过于抽象。
不要为了使路线看起来完善而隐瞒弱点。

七、输出

输出 JSON：

{
  "candidates": [
    {
      "id": "C1",
      "situation": "他实际处在什么事情里",
      "what_matters": "什么对他重要",
      "initial_facts": [
        "开头已经成立的事实或处境"
      ],
      "turns": [
        {
          "sec": "段号",
          "now": "这里真正新出现或改变了什么",
          "basis": "由此前哪一份经历产生",
          "change": "这以后有什么已经不能当作未知"
        }
      ],
      "segment_sketch": [
        {
          "sec": "段号",
          "role": "此段承载的经历或感受",
          "new_or_continuing": "新变化/延续/暂时没在想",
          "uncertainty": "尚无依据的部分，没有则留空"
        }
      ],
      "unresolved": [
        "到结尾仍然没有得到的东西或答案"
      ],
      "weaknesses": [
        "这条路线最可能出现的具体问题"
      ]
    }
  ]
}

必须输出 C1、C2、C3 三条候选。
每条候选的 segment_sketch 覆盖全部段落。
turns 只记录重要变化，不要求每段都有。
不输出正式线，不输出珠子分析。

只输出 JSON。
