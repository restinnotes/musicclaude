# st2_n7_op61_IA_c4_r1_r2

**这件事：**一个总因迟疑而不敢承认自己意愿的人，逐渐学会带着真实的顾虑和柔软作出选择，并在日后的动摇中继续承担自己的选择。

**走向：**他起初一认出愿望就被合理顾虑拉回自我审查，后来尝到主动决定的力量，却把坚定变成必须证明自己不会再变的要求。承认心软、渴望支持之后，他发现各个需要仍会冲突，理解自己也免不了取舍，于是开始带着不安承担选择。结尾，开头的摇摆和早先昂扬的舞步再次汇合；他把坚定看成每次怀疑回来时重新看清愿望、认领并承担决定的能力。

### 1–23

**他刚认出自己想要什么，就先把自己审了一遍**
→ 于是弄清自己是没想透，还是不敢承认意愿

### 24–65

**他终于敢认领愿望，却开始怕自己又变回那个反复的人**
← 因为（1–23）长期自我审查让他急着停止旁观，开始主动认领意愿
↺ 原以为想透才能选，现在发现认领意愿有力量，却又把坚定当成身份证明
→ 于是把坚定变成必须守住的自我证明

### 66–91

**他怕自己一强硬，就把心软和顾虑也一起压没了**
← 因为（24–65）坚定成了自我证明，其他感受便像在威胁它
↺ 原以为迟疑只是软弱，现在发现有些顾虑守着他在乎的东西
→ 于是找一种能容纳心软的坚定

### 92–115

**他舍不得第一次决断带来的踏实，却压不住旧顾虑**
← 因为（66–91）他已承认心软和顾虑有价值，没法再全算作软弱
↺ 原以为加重决心就能恢复踏实，现在知道冲突不会自行消失
→ 于是追问那些顾虑究竟在保护什么

### 116–147

**他终于承认，自己也想有人懂，累了能靠一下**
← 因为（66–91）他已发现心软有真实价值，开始辨认其中具体的需要
↺ 原以为想依靠就不够独立，现在知道求支持也能负责
→ 于是从责备自己转向看清需要

### 148–180

**他发现每种需要都有道理，可它们没法全顾上**
← 因为（116–147）承认想被理解和支持后，他看见这些诉求也会冲突
↺ 原以为接纳自己就能平静，现在明白理解也免不了取舍
→ 于是接受选择必然留下损失

### 181–205

**他想保留早先决断的力量，却又怀疑这样费劲算不算坚定**
← 因为（148–180）他已看见各种需要无法兼顾，拖延也要付出代价
↺ 原以为要确信无悔才配行动，现在愿带着舍不得承担
→ 于是把坚定从完美确信转向承担

### 206–213

**刚下决心，他心里又冒出一句“可是”**
← 因为（66–91）他早已知道心软有真实价值，不能为了坚定把它赶走
↺ 原以为下决心就能压住冲突，现在让心软留下，也不让它取消决定
→ 于是让坚定和柔软同时在场

### 214–215

**开头的摇摆回来了；他知道所求和所怕，还敢认领吗**

### 216–225

**他不再等到毫无保留，才承认自己还想试试**
← 因为（1–23）起初他一有疑问就把意愿全盘撤回，如今开始松动这个习惯
↺ 原以为只要还有反对声音，决定就不算数，现在承认微弱意愿也真实
→ 于是让不完整的意愿成为行动起点

### 226–241

**他开始问自己肯不肯负责，不再纠结够不够坚定**
← 因为（148–180）他已知道各种需要难以兼顾，等待完美一致也有代价
↺ 原以为得先压住疑问、成为坚定的人才配选，现在改问自己愿不愿负责
→ 于是把当下意愿落实成行动

### 242–253

**他终于说出自己的选择，也没要求心里只剩一个声音**
← 因为（66–91）早先他发现强硬会压掉心软，这次不再要求顾虑先消失
↺ 原以为明确就得压下其他感受，现在能带着顾虑认领决定
→ 于是把不完整的意愿认领为决定

### 254–288

**他不再把未来的动摇，当成过去努力都白费了**
← 因为（24–65）早先他把坚定当成永不改口的身份考验，未来动摇便像失败
↺ 原以为坚定就得永不动摇，现在知道柔软与承担能共存，动摇后仍可重想并负责
→ 于是在下一次怀疑里重新认领选择
