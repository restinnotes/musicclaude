# 所以我现在认为真正正确的链路只有 4 步

1. **PDF Thesis Pack**

   不只是 seed ID。

   应该保留文章原来的：
   - 宏观判断；
   - 行业判断；
   - 选股理由；
   - 排除理由；
   - 入场逻辑；
   - 反面情形；
   - 时间周期。

   加上我们此前已经发现的 correction。

2. **Expansion + Verifier**

   它的职责是：

   > **把 PDF 变成一份“数据更完整、逻辑更完整、截至今天更新过”的研究报告。**

   每条原 thesis 都做：

   ```text
   原观点
   → 原证据
   → 核查
   → 修正
   → 新证据
   → 修正后的因果链
   → 当前市场是否验证
   → 当前个股/ETF表现
   → 当前价格和估值
   ```

   注意：**这一步可以主动扩充 PDF 没有写完整的东西。**

   例如原文只说：

   > 银行息差可能筑底。

   Verifier 应该补：

   > 为什么？存款成本、贷款收益率、信用成本、非息、资产质量分别发生什么。

   原文太保没做完整估值。

   那就把 EV / PEV / NBV / sensitivity 补完。

   这才叫“扩充 PDF”。

3. **Independent Attacker**

   它拿同一份原 PDF、历史修正和当前事实。

   核心任务：

   > **如果这篇更新版研究最后导致亏钱，最可能错在哪里？**

   攻击四件事就够：

   ```text
   事实有没有错
   因果有没有错
   市场验证是不是被误读
   当前价格/证券表达是不是错
   ```

   Blind 不 Blind 其实只是实现细节。

   我倾向于**不要先给它 Verifier 的结论**，因为那样更独立；但这不是系统成败的核心。

   核心是它真的独立调查，而不是机械唱反调。

4. **Judge / Investment Conclusion**

   Judge 不需要再研究一遍。

   它只需要把：

   ```text
   原文
   +
   扩充验证结果
   +
   Attacker
   +
   当前市场/价格
   ```

   裁成最终报告。

   而且最终必须逐条回答：

   ```text
   ① 赚钱因果链：
   成立 / 部分成立 / 已破坏

   ② 市场验证：
   已验证 / 部分验证 / 尚未验证 / 反向验证

   ③ 当前价格：
   昂贵 / 合理 / 出现赔率 / 极佳赔率但高风险

   ④ Instrument：
   这个股票是不是最好的表达

   ⑤ 当前动作：
   不做 / 观察 / 等价格 / 可准备参与 /
   已达到入场条件 / 持有 / 降低 / 退出

   ⑥ 最大反证：
   什么最可能让我们错

   ⑦ 下一次什么变化会改变判断
   ```
