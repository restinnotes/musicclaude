# 文章C

### 1–23
- 因为每当愿望刚刚形成，他都能立刻找到并非虚假的反面理由，所以他无法干脆舍弃这些理由，自己的意愿总是迟迟得不到承认。
- 因为长期把愿望交给反复审查，使他始终不能真正站在自己的选择之中，所以他意识到最难受的不是没有答案，而是自己仿佛一直在生活之外旁观自己。
- 因为他已经厌倦了这种不断旁观、不断撤回的状态，所以他开始想把已经形成的意愿当真，不再要求绝不犯错，也不再一有疑问就退回尚未决定的状态。
- 因为承认自己的意愿对他而言仍是一件生疏的事，所以他无法确定自己真正缺少的是更充分的理解，还是理解之后敢于承认和选择的勇气。

### 24–65
- 因为他不愿再永远停留在审看自己的位置，所以他第一次主动尝试让意愿先于反驳站出来。
- 因为他尝试不再同时替每一种相反的可能性辩护，所以他发现明确选择不只是失去其他可能，也能带来充实，使他从旁观者变成对所求负责的人。
- 因为这次明确表达意愿确实给了他力量和充实感，所以他希望保持这种状态，并开始把坚定看成一种值得练成的能力。
- 因为他已经体验到不必解决所有疑问也能够作出选择，所以他开始相信自己未必缺少更多理由，而是需要承认已有理由足以支持选择，不再允许每个新疑问推翻一切。
- 因为他越来越珍惜坚定带来的充实，希望以后不再反复争取同样的东西，所以他从满足于偶尔站定，转而希望通过坚定证明自己已经成为一个坚定的人。
- 因为他让一次明确选择承担起证明自己已经改变的任务，所以继续保持坚定变成了对自身的考验，而不再只是帮助自己作出选择的方式。

### 66–91
- 因为坚定已经被他当成证明自身品质的依据，所以一切与坚定姿态不相符的感受都开始显得像是威胁。
- 因为他原先把迟疑归结为意志不够强，却发现自己仍有一些不愿舍弃的顾虑，所以他认识到这些顾虑不全是恐惧，也包含对他人的体恤、对复杂性的尊重和不愿失去的诚实。
- 因为他发现那些妨碍决断的柔软部分也具有真实价值，所以他意识到如果必须否认它们才能获得清楚，那种清楚就可能只属于一个被削薄的自己。
- 因为他既不愿重新陷入无所作为，也不愿通过排除真实的自我来维持强硬，所以他开始怀疑强硬能否代表完整，并希望获得一种能够容纳真实自我的坚定。
- 因为先前坚定带来的充实仍然真实，而柔软的价值也已经无法否认，所以他既不能把坚定全盘判为错误，也不能再把不利于决断的感受一概判为软弱，因而陷入新的内在冲突。

### 92–115
- 因为他仍然知道完全不作选择会让愿望陷入无休止的辩论，而且坚定曾经使他能够行动，所以即使已经产生怀疑，他仍尝试重新站回先前认可的坚定立场。
- 因为他已经认识到被压下去的感受并不会因此失去真实性，所以他不再把重新坚定误认成冲突已经结束，同样的决定变得更加费力，必须一边前进一边承认尚未满足的自己。
- 因为坚定曾使他获得行动能力，也曾使他忽略自己其他真实的需要，所以他既不能轻易放弃坚定，也不能再毫无保留地信任坚定。
- 因为他发现单靠增强决心无法使内在要求自动一致，所以他不再能够用意志薄弱的旧解释理解自己的反复，意识到眼下的不安并不只是退步。

### 116–147
- 因为重新坚定仍未解决冲突，原先责备自己不够坚决的解释已经失效，所以他转而更深入地审视自己的内在需要，不再只是要求自己增强意志。
- 因为他开始认真倾听过去被坚定姿态压住的部分，所以他发现自己不仅想拥有选择的权利，也想被理解，并希望在承担责任时仍能有所依靠。
- 因为他认识到渴望理解和依靠也是自己的真实需要，所以他开始允许脆弱存在，并明白需要支持不等于缺乏主见，能够承担也不意味着必须否认对支持的渴望。
- 因为承认柔软使他获得宽慰，也让他理解了过去反复退缩的原因，所以他发现理解自身需要并不等于知道如何处理它们，知道为何退缩也不等于已有能力停止退缩，因而仍不知道怎样让柔软与承担相容。

### 148–180
- 因为被压抑的需要终于获得承认，他原本期待内在争执会因此缓和，所以他反而发现这些真实需要彼此也会冲突，保有柔软和避免退让、尊重复杂性和及时决定并不能自动兼得。
- 因为不同的真实需要之间存在无法同时满足的要求，所以他明白困难不能再简单归结为缺少勇气，因为即使足够勇敢，选择仍然会让某些重要的东西暂时得不到满足。
- 因为他曾期待更充分地理解自己就能逐渐消除冲突，如今却看见各方都有不能轻易舍弃的价值，所以他认识到理解并不保证和解，有时反而会使取舍更艰难，使简单答案更难成立。
- 因为他已经看见选择的代价，却也发现拖延和反复同样会造成只是较不显眼的损失，所以他不能因为选择无法兼顾一切，就干脆放弃选择。

### 181–205
- 因为他已经知道理解本身不能化解真实需要之间的冲突，而不选择同样有代价，所以他再次渴望明确，但这次希望明确能够终止无限延期，而不再指望意志消灭矛盾。
- 因为他知道退缩有时有正当理由，但如果每一种顾虑都能撤销决定，他就永远无法承担责任，所以他决定尝试在无法满足所有需要的情况下仍作出选择，并承担由此留下的缺口。
- 因为他已经承认选择不可能保证完全正确、没有局限或绝不后悔，所以他开始尝试一种不以彻底正确为行动前提的坚定，在预见可能的失去之后仍认领自己的意愿。
- 因为新的坚定仍然要求他反复说服自己，每次站出来都要经历挣扎，所以他产生新的疑问：如果坚定始终如此费力，自己究竟算不算一个坚定的人。

### 206–213
- 因为重新凝聚的决心仍无法驱除柔软，而排除柔软会重演先前削损自我的代价，所以他不能把这次坚定当成最终答案，而必须再次倾听内心不肯完全服从的部分。
- 因为重新倾听柔软，使他看见体恤、眷恋理解和感受另一面的能力都是自己的一部分，所以他认识到自己要守住的不只是某个决定，也包括那个作出决定、仍会被触动的人。
- 因为彻底排除柔软会损失真实的自己，而任由柔软随时撤销决定又会使他失去行动能力，所以他暂时允许坚定与柔软同时存在，承认它们尚未形成稳定平衡，并接受这种共存带来的不安。

### 214–215
- 因为柔软重新进入他的内心，原本的矛盾并没有被解决，所以熟悉的不确定再次出现，但他已经能够分辨自己想要什么、为何想要，以及自己会因何退缩，不再像最初那样茫然。
- 因为他已经看见选择的代价，也知道强烈的意愿不保证永远不变，无法再靠无知或完美自我的幻想回避困难，所以真正悬而未决的问题转变为：即使内心仍有裂缝，他是否依然能够把选择认作自己的。

### 216–225
- 因为他逐渐看清过去总要求所有部分毫无保留地赞同，才肯承认立场，而这种状态几乎不可能出现，所以他不再要求自己先达到完整、绝不动摇的决心，才有资格承认意愿。
- 因为他已经放弃把完全一致当成意愿成立的唯一条件，所以他开始承认零碎而带着迟疑的意愿也可能是真实选择，并把动摇后仍不肯撤回的那一点所求看成决心的萌芽。
- 因为这点意愿虽然真实，却还没有强大到足以保证他始终坚定，所以他拒绝把它夸大成已经获得胜利，以免重新迫使自己维持不可能始终如一的状态。
- 因为他既承认微弱意愿存在，也不再要求它立即成为完整的宣言，所以他第一次允许自己在尚未完全站稳时，就承认自己确实想要站出来。

### 226–241
- 因为已经得到承认的微弱意愿仍不足以使他安心，但继续等待完美的内在一致只会重演拖延，所以他开始面对是否主动聚拢这些意愿、据此作出选择的问题。
- 因为他已经发现用一次决定证明自己是坚定的人，会带来无法维持的自我要求，所以他把问题从是否已经具有坚定的品质，转向即使未来仍会改变，自己是否愿意承担眼下的选择。
- 因为他把承担当前选择看得比证明内心已经统一更重要，也知道怀疑、其他可能性和未来后悔无法预先消除，所以他不再允许自我分析、预期后悔或未解决的顾虑代替回应，开始接受自己可以在不确定中行动并负责。

### 242–253
- 因为他已经接受选择不必等待所有需要消失、所有内在矛盾解决，所以他终于能够更清楚地表达眼下的意愿，承认这是自己愿意作出的决定，而不是一个永不动摇的保证。
- 因为此前的坚定既给过他力量也暴露了强硬的代价，柔软既帮助他理解自己也曾成为拖延的理由，所以他开始把这些经验整合成承担选择的共同根据，而不再让它们仅仅互相抵消。
- 因为他已经能够让坚定与柔软的经验共同支持自己的决定，所以他对明确的理解从排除异议转为收回选择的责任，不必证明迟疑全错或否认柔软，仍可以坚持。
- 因为他知道自己未来仍可能改变，也不再把永远不变当成选择有效的条件，所以他终于愿意站出来，不再把当下决定的权力完全交给未来可能发生的动摇。

### 254–288
- 因为他已经作出了明确选择，却知道柔软、迟疑和新的需要不会因此永久消失，所以他意识到这次选择并没有给他一份永久有效的坚定证明，未来仍可能重新怀疑今天的立场。
- 因为如果仍把坚定定义为永远不变，那么未来每一次动摇都会被解释成对过去努力的否定，所以他认识到不能再用是否始终不变来判定自己是否真正坚定。
- 因为他已经亲身了解明确的力量、强硬的损失、柔软的价值以及拖延的代价，所以他开始把过去那些显得反复无常的经历视为认识自身所求和取舍边界的依据，而不仅是缺乏决断的证据。
- 因为他不再要求一次选择永久解决内在矛盾，也发现过去的反复能够积累新的认识，所以他开始把坚定理解为持续承担的能力，而不是一次获得便永远拥有的品质。
- 因为坚定已经被重新理解为可以反复实行的承担，而非绝不动摇的状态，所以他认识到以后的犹豫不会自动证明先前的坚定是假的，每一次重新争取都能帮助他更清楚地理解自己为何迟疑、又为何仍想选择。
- 因为他已经接受自己会改变、所求会冲突、明确选择也可能再次变得困难，而这些都不必取消此前的承担，所以他最终不再要求先消除所有迟疑才允许自己站出来，而是愿意在每次选择重新变得困难时再次面对它，不把责任交还给犹豫，并继续认领自己的选择。
