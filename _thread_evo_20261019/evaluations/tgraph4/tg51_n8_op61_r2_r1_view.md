# Op.61｜关系图

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### 1–23　（还说不清）

- 起初他不知道自己究竟在等什么，心里却不肯就此算了，仿佛放任事情照旧就是默认它们本该如此。
- → 真要投入，他又怕会丢下什么；他有勇气，却也舍不得一些还说不清的东西。
- → 他试着找个足以让自己不再犹豫的理由，刚觉得想通，另一番舍不得就浮上来。
- → 他为自己的反复摇摆难堪，甚至怀疑自己得先想清心里一切才肯向前。

### 24–65　（正在面对）

- 他受不了再拿没想清楚当作等待理由，决定先把自己能做的一份认下来。
  - ← 提供理由：（1–23）「投入时怕失去」
  - ← 改写：（1–23）「摇摆让他难堪」
- → 即使没有任何保证，心里的牵挂也没消失，他却真切地感到自己有了力量。
- → 他从追问值不值得转为愿意尽力，也有些骄傲，觉得心里有疑虑也不必听它的。
- → 他投入得很热切，付出的过程本身让他快乐，心里的不满也似乎有了去处。
- → 他愿意给出更多，甚至有些贪恋全力以赴时那种畅快。
- → 他不再时时审视自己，也不愿因一点软弱就停下来。
- → 用力到深处，他仍觉心里一小块没跟着昂扬，隐约知道坚决也没照顾到所有牵挂。

### 66–91　（没在想）

- 这点不安还没逼他停下；认真投入过后，他反而能从反复自问里松开一点。
- → 他发现自己也会因不再畏缩而高兴，向前的热情还让他感到轻盈。
  - ← 提供理由：（24–65）「付出带来快乐」
- → 偶尔忘了自己为何如此用力时，他觉得那不算背叛，反而像久违的自由。
- → 他顺着自由走了一程，没有急着解释它；快乐淡下去后，先前的决定仍等着他。
- ⟲ 仍在起作用：（24–65）「牵挂没有消失」

### 92–115　（正在面对）

- 他仍愿意坚持先前的决定，因为那曾把他从动弹不得的犹豫里带出来。
  - ← 唤起：（66–91）「旧决定仍等着」
- → 他不愿因心里仍有未满足的地方就认定先前全错，可坚定已不能让他安心。
- → 他想确认自己仍有力量，却发现心里还有一种要求无法由力量替代；行动值得，也仍不够。　✦ 办法的限度

### 116–147　（正在面对）

- 明知行动还不够，他仍不肯放手，怕此刻的失望意味着自己已经变了心。
  - ← 提供理由：（92–115）「坚持原先决定」
  - ← 限制：（92–115）「行动值得却不够」
- → 他把心里的难处当作能克服的迟疑，想停一停时又怕那就是退缩。
- → 他知道自己正在受苦，却想不出除了坚持，还有什么办法对得起最初的决定。
- → 原先让他昂然的要求，慢慢变成连脆弱也容不下的苛责。
- → 他发现自己像在勉强一个已经疲惫的人，终于不想再证明自己坚强。
- → 他暂时放下催逼，虽未安心，却有些松懈；被压住的依恋回来，他也发现自己真舍不得一些东西。

### 148–180　（没在想）

- 放下催逼后，他才看清自己舍不得的生活：人与人不用时时防备。
  - ← 唤起：（116–147）「依恋重新回来」
- → 他曾自然相信，珍贵的东西不用争夺也能留下，付出出于喜欢，靠近无需先防着受伤。
- → 这份盼望确实给过他快乐，让他觉得自己不只是凡事都得扛着、必须坚强的人。
- → 他终于肯沉浸在这份盼望里，不急着问能否得到；仅仅去爱、去相信，就让他深深满足。

### 181–205　（正在面对）

- 这份安宁如此真实，他不满足只在心里拥有它，也开始追问单靠怀念怎能改变威胁它的事。　✦ 满足照出未满足
  - ← 动摇：（148–180）「沉浸旧愿满足」
- → 他想起最初不肯被动等待，也是因为有些重要的东西不能任由它们受损。
  - ← 提供理由：（1–23）「投入时怕失去」
- → 他一阵懊恼，几乎责怪自己刚沉浸满足，就忘了还有必须面对的事。
- → 他试着重新振作，却怕再次投入艰难的争取，会一点点耗尽刚尝到的温柔。
  - ← 限制：（148–180）「旧愿曾给快乐」
- → 想到安宁他舍不得，想到它受威胁又放不下；理由更多了，他心里反而更难平静。　✦ 知道更多反而更尖锐

### 206–213　（没在想）

- 他明知不能久留，仍愿再爱惜温柔片刻，不拿它审问自己；欢喜里也已有不舍。
  - ← 唤起：（181–205）「前进停留都不安」

### 214–215　（正在面对）

- 安静退去后，熟悉的迟疑又回来；他如今知道，迟疑里也有不愿失去的生活希望。　✦ 分清
  - ← 唤起：（206–213）「再爱惜温柔片刻」
  - ← 改写：（148–180）「不靠争夺保有」

### 216–225　（正在面对）

- 知道自己舍不得什么，并没让他立刻勇敢；决心和沉浸旧愿这两种办法都有难处。　✦ 办法的限度
  - ← 限制：（214–215）「迟疑里有旧愿」
- → 他一时只盼着，继续争取时记得为何出发，爱惜安宁时也肯面对威胁它的事。
  - ← 提供理由：（148–180）「不靠争夺保有」
- → 他还不知道怎样做到，只觉得反复想着这点心愿，似乎稍减了非得舍弃一边的逼迫。

### 226–241　（正在面对）

- 凭着这点还不牢靠的心意，他重新想自己还能怎么做。
  - ← 提供理由：（216–225）「舍弃一边的逼迫」
- → 他亲身体会到，尽力做事能让人从无力里缓过来，却不能消除所有牵挂。　✦ 办法的限度
- 他也尝过，心里的美好能安慰自己，却不能单靠安慰保护所爱的生活。　✦ 办法的限度
- → 这两样收获都是真的，所以他不愿再简单否定其中任何一样。
- → 他想保有那份无需时时奋力的安宁，却知道为它争取也可能失去安宁。
  - ← 限制：（148–180）「沉浸旧愿满足」
- → 他渐渐明白，难受未必说明意志不够；他珍视的东西确实不止一种。　✦ 选择的代价
- → 他仍心疼可能失去的东西，也盼着有条轻松的路，却知道继续等不会让它出现。
- → 他允许自己害怕、没把握，也带着不舍继续往前，不再让惧怕替自己决定。
- ⟲ 仍在起作用：（24–65）「疑虑不再作主」；（148–180）「沉浸旧愿满足」

### 242–253　（正在面对）

- 既然不再等一个毫无损失的办法，他重新感到昂扬，也能带着脆弱继续。
  - ← 提供理由：（226–241）「带着不舍前进」
- → 他仍愿尽力，却不再要求行动证明自己无所不能；他知道自己要做什么，也知道为何舍不得。
  - ← 改写：（226–241）「珍视的不止一种」
- → 他愿为真心爱惜的一切负责，不再把它们当作行动的拖累；即使仍犹疑，也允许自己坚定。
- ⟲ 仍在起作用：（226–241）「带着不舍前进」

### 254–288　（正在面对）

- 他重新向前时，旧愿似乎没有变远，反而比从前更亲近了。
  - ← 改写：（242–253）「为珍惜之物负责」
- → 过去他以为退回争取之外才能保住旧愿；如今因知道它珍贵，他更不愿任由威胁它的事存在。
  - ← 提供理由：（148–180）「不靠争夺保有」
- → 他觉得温柔也能成为不肯袖手旁观的理由；若争取时丢掉这份向往，坚强又有什么用？
- → 他仍想过不必拼命的日子，却愿为珍惜它而离开眼前的安宁。
  - ← 改写：（148–180）「沉浸旧愿满足」
- → 他知道尽力未必能实现旧梦，心怀美好也得看清付出会不会伤到所爱。　✦ 办法的限度
  - ← 限制：（226–241）「尽力不能消除牵挂」
- → 这些顾虑也提醒他该带着怎样的心继续坚持。
  - ← 改写：（226–241）「珍视的不止一种」
- → 两种心意终于一起帮他向前，他能珍惜依恋，也能继续做该做的事；历经怀疑和疲惫后，他尝到更深的快乐。
  - ← 改写：（242–253）「为珍惜之物负责」
- → 喜悦平静后，他仍无答案：行动未必改变什么，安宁也没回来；他往后仍会疲惫动摇，两种渴望仍会相互牵制。
  - ← 限制：（226–241）「尽力不能消除牵挂」
  - ← 限制：（226–241）「安慰不能保护生活」
- → 他愿意同时顾及两种需要，也珍惜已经得到的东西，即使其中一种仍未满足。
- → 过去的快乐、失望、疲惫和依恋，让他知道什么值得付出，什么不能轻易牺牲。
- → 他仍向往安宁，也愿继续行动；虽不知最终能留下多少，他仍带着不舍向前，不再寻找更多证明。
- ⟲ 仍在起作用：（242–253）「为珍惜之物负责」
