下面是肖邦《船歌》Op.60的一条 Thread（关系图，叫 v6）。我们在 v6 的基础上逐段修补，前面的段已经修好，现在修 S14（第 111–116 小节）。

Thread 是什么：一个人在这首曲子里经历的一件事。每一段要让人看见他此刻为什么会这样，理由来自他前面真实经历过、相信过、发现过的东西，而不是音乐忽然发生了什么。珠子是另一批人听这段音乐写下的听感，写的是此刻听到、感到的具体样子，会和线并排展示；线不用把珠子再描写一遍，而是给这些感受一个“为什么偏偏此刻会这样”的理由。
关系图的写法：每段先标他和 Center 的关系（还说不清 / 正在面对 / 没在想）；条目前的 → 表示由上一条引出；← 是跨段箭头，指回前面某段的某一条（提供理由、说明、限制、动摇、唤起、改写、失效）；⟲ 是前面仍在起作用的东西。

这次修补只解决三个问题：
1. 覆盖不足：这一段珠子里的感受（主体验、段内变化，以及和它们同时成立的另一侧面），线要给出他此刻为什么会这样；理由和珠子对不上的要改。
2. 啰嗦废话：一个意思拆成几条、翻来覆去说同一件事、没有必要的心理环节、不成立的因果。
3. 不说人话：抽象、像哲理总结、工整对照、作者替他宣布领悟、只说他没做什么。
v6 已经成立的好内容不能丢：整体走向、已经说清的心理事实和前后关系都要留下，可以改写、合并，但意思不能丢、不能变弱；只有换成更有解释力的说法时才可以去掉，并在 changes 里说明。和珠子对不上的解释不算好内容，要改。

要求：
- 覆盖：主体验、段内变化里的每一种感受，都要能从这一段的条目里看出他此刻为什么会这样。线的作用不是把感受写得更细——细节由珠子并排展示，线只给原因；所以不要把珠子的描写搬进线里。一条原因常常能同时解释好几颗珠子，不要为每颗珠子各加一条。同时存在的几种感受可以写在同一条里，不要硬排成先后发生的几件事。真正解释不了的写进 gaps，不要硬补。另一种理解（和主体验不能同时成立的听法）不必解释。
- 精简：一条只说一个别的条目没说过的意思，包括前面各段已经说过的——前面说过的原因不要再说一遍，此刻还在起作用就用 ← 指回去；几条其实是同一个念头就合成一条；删掉也不损失意思的就删。条数跟这一段真正发生了多少相称，没多少事就写一两条；修补后的条数一般不多于 v6 这一段，除非 v6 确实漏掉了这一段的主体验。不强求每段都有新的领悟、办法或转折，不写“试一个办法—不管用—换一个办法”。全曲一直成立的背景（他在乎、对方心意未知、时间在走之类）不能单独当此刻的原因，要说出它此刻因为前面哪一步变了才起了新作用。关键转折写出具体前因，不用“越……越……”“更……了”顶替。
- 人话：直接写他具体在想什么、怕什么、想要什么。不把心情说成一样东西（“这份……”“一种……”），不写听着深刻的总结句，不写整整齐齐的“前半句；后半句”对照，不由作者替他宣布“他终于明白”“他才看清”；只说他没做什么的空否定，改成说他在做什么（说出变化的“不再……”可以留）。一条只放一个意思，不用分号把两三件事串在一起；每条一般不超过 45 字，但不要为了字数把一个意思拆成几条。
- 边界：不新增前史、往事、身份、外部事件、对白、具体的人物关系或场景；珠子里的比喻——地点、人物、往事画面，以及处境、动作、对白（例如“像要对很亲近的人说一件想了很久的事”“握紧另一个人的手”“像一幕旧场景回来”）——只说明感受像什么，不能写成他真的在做、真的要做或真的想起的事；可以取其中的心理，不取那件事本身；不把音乐本身的变化当成心理原因。可以补一座接在前面已确立内容上的局部心理过程（身体先于念头、刚才的什么让此刻变了）。正文不写小节号、编号、音乐术语，也不写对修改的说明。
- 形式同 v6：relation 是这一段他和 Center 的关系（还说不清 / 正在面对 / 没在想），一般沿用 v6；follows: true 表示由这一段上一条引出（画成 →）；because 是跨段箭头，from 只能写【前面已经修好的段】里的条目编号，rel 取 提供理由、说明、限制、动摇、唤起、改写、失效、仍在起作用，只连真正的前因，主题相近不算。key 是两到八个字，取自这一条的原文，后面的箭头用它指代这一条。explains 写这一条给出原因的珠子编号。Center 不改。

【Center】对亲密的投入与自我克制始终相互牵制。

- B2［段内变化］（111–115（承接110–111小节交界的最后冲击））110–111小节交界，最后一股浪头像是又猛推了一下；进入终结句，音乐才真正松下来、轻下来。心里仍然温热，身体却慢慢恢复了平静。也像从一场美梦里醒来，还记得梦里的光。

评审甲：
- 值得保留 R65、R68：保留他不再寻找一种绝不会受伤的爱法，因为此前的经历已经证明，克制和尽情投入都不能保证没有遗憾。结尾不是找到无风险的办法，而是接受风险仍在。
- 值得保留 R66、R67：保留他仍然想被这个人选择，同时承认对方可以有自己的心意，不必满足他的全部期待。这是他继续喜欢而不把渴望变成对方义务的必要边界。
- 值得保留 R69、R70：保留结尾对先前几种亲近方式的回看：安心靠近、慷慨给予、独自珍藏、尽情欢喜都曾经给他真实的快乐，因此没有一种经历只是白费。这一回看使最后的继续喜欢不是空泛的乐观。
- 值得保留 R71、R72、R73：保留未来仍无保证、他仍会想要更多并感到疼，却不把对方的选择当作自己真心的判决，也不以克制来证明自己清醒，最后仍愿意认真喜欢。B2-B4支持温热仍在、经历之后的回望，以及结尾对开头悬而未决感的回应。
- 珠子 B1：偏弱。R65-R73给出了较稳定的内心立场，但没有充分解释最后的声音为什么会如此干脆、沉重、像把船一下定住；继续认真喜欢更像情感上的选择，不等于外在的彻底收束。
- 珠子 B2：说清。R65-R73说明他已经不再寻找无风险的办法，也不必靠否定渴望换取平静，因此最后可以温热仍在、身体慢慢安定，而不需要把问题写成已经解决。
- 珠子 B3：说清。R69-R70让结尾熟悉的歌唱成为对过去经历的回望：他再次看见那些不同的喜欢方式都曾给过自己真实的快乐，所以回来的不是原封不动的开头，而是经历之后的重新理解。
- 珠子 B4：偏弱。从R3的谨慎到R68-R73的风险意识和继续喜欢，可以形成开头与结尾的呼应；但v6没有明确把开头未说出口、未理解的谨慎接到结尾的回应上，而且他最后仍是在心里作出选择，并没有真的对对方说出那句话。
- 啰嗦 R65、R68：两条都在说不再寻找绝不会受伤的爱法。R65适合作为承接前段的转向，R68适合作为把两种办法都无法免险说清的结论，但可合并重复部分，避免先宣布不找办法、再宣布办法都无效。
- 啰嗦 R66、R71：两条都说仍然想被对方选择、仍会想要更多。R71新增了未来无保证和不能更近时会疼，应该保留这些具体代价，而不是两次单独宣布渴望仍在。
- 啰嗦 R67、R72：R67说对方有自己的心意、不必满足全部期待，R72说不把疼痛变成催促对方的理由，两条都在维护对方的自由。R72还新增了不拿选择判定真心、不拿克制证明清醒的内容，可以把共同的边界合并起来。
- 啰嗦 R69、R70：R69列举过去的快乐，R70宣布它们没有白费并让他更愿意向前，存在明显的总结重复。但R69提供具体经验，R70解释这些经验对最终选择的意义，两者不宜全部删除，应缩短清单或减少结论式语言。
- 啰嗦 R71、R73：两条都保留了渴望、风险和继续喜欢。R71强调疼痛和无保证，R73强调不强迫对方、不因自保而先放弃；可以让R73真正成为行动方向，不必再次完整列出愿望和风险。
- 啰嗦 R69、R70、R73：结尾的回顾、价值判断和继续喜欢构成合理的收束，但三条连续给出经验总结、经验意义和最终原则，容易让故事连续三次宣布结论。保留经验如何促成最后的选择，比保留三层总结更重要。
- 不说人话 R65「他不再逼自己找一种绝不会受伤的爱法。」：这是抽象地宣布放弃某种办法，却没有说明他究竟放下了什么具体幻想；而且后面的R68又会重复这项认识。
- 不说人话 R67「他知道对方有自己的心意，不必和他一样；若为求安心就要对方接住全部期待，亲近反会失去自在。」：这是关于亲密关系边界的完整道理，像在替读者讲解健康的相处原则。应保留他为什么不愿把全部期待交给对方承担，但不必把原则说得如此周全。
- 不说人话 R68「他终于明白，遗憾不必先消失才能好好喜欢；收住和尽情投入，也都不能替他免去风险。」：终于明白直接替他宣布领悟，后半句又是工整的两种方法对照。它的意义很重要，但需要与他经历过的具体失望、快乐和选择连起来。
- 不说人话 R70「它们没解开最后的问题，却没白费。」：这是一句概括性的价值判决，而且它们和最后的问题都比较抽象；更有解释力的是这些经历究竟让他获得了什么、为什么仍值得继续。
- 不说人话 R72「他不拿对方的选择判定真心，也不拿克制证明清醒；更不让这些疼痛成为否认感情或催促对方的理由。」：三重否定组成了整齐的原则清单，几乎像替人物写出一套最终信条。可以保留他不再把渴望、克制和疼痛当作判决的事实，但应避免把结尾变成道德宣言。
- 不说人话 R73「他愿继续认真喜欢、充分欢喜；想被爱，却不把渴望变成对方的义务，也不为保护彼此先放弃爱。」：这句话把前文所有主题完整地排成对照，像一个过于圆满的最终答案。它容易让人物显得已经彻底解决了矛盾，而R71仍明确说他会失望、会疼，结尾应保留这种未解决的真实。

评审乙：
- 值得保留 R65、R68：他不再把找到一种绝不受伤的爱法当作前提，并承认克制和尽情投入都不能替他免去风险。这是从S13冲突得出的真实限制，而不是突然获得了无所畏惧的答案。
