### S06（屏幕停留 39 秒）
话：这回对方看出他有多在乎，【跟他相处却一点没变】，他才又能像从前那样【自在地待着】。
感受：熟悉的摇摆回来，左手波浪却变薄、碎成细纹；光线像从暖金水面滑入古桥阴影，新旋律清澈得像月光 / 忽然想起年少时第一次心动的下午
话：安静时，他【还想靠近】，却怕要得太多；对方不知道他刚才多怕被嫌弃，【他有点孤单】。
感受：旋律压低声音，另一条声线不时回应、插话，又纠缠回来，像一个念头刚安静下去又浮上来 / 心里刚说算了 又忍不住放不下 / 白天和某个人相处得很好，独处时心头却泛酸
话：他又忍不住想，对方既然【一直没有退开】，会不会也有一点【舍不得结束这份亲近】？

### S07（屏幕停留 41 秒）
话：想起这些日子对方总愿意跟他待在一起，他渐渐觉得，【也许对方有时也需要他】，跟他在一起也能【安心些】。
感受：歌声再回来，清澈底下却越来越不安分：伴奏变密，低音像沉重的脉搏催促，身体仿佛被更深的渴望推着往前 / 独自回想一段关系，气味、身体感觉、幻想、遗憾和快感混在一起；明知正被卷进去，却暂时不想出来
话：他高兴得有点收不住，想到两个人也许能【互相依靠】，心里忽然一紧，却还想这样待着；他真盼着往后对方想找人陪时还会想到自己，自己也能【一直陪在身边】。
感受：美也没有消失；可你已经听见时间正在经过，这一刻纵然完美，也没有办法让它停住

### S08（屏幕停留 39 秒）
话：上回他无意间露了心意，这回见对方【依然亲近】，他想主动些，【大大方方地回应】。
感受：熟悉的摇荡也轻轻催着人往前 / 身体恢复弹性，带一点玩心和调情般的回应
话：这样想着，他连【往后的日子都开始盼了】，觉得两个人说不定还能【这么好很久】。
感受：歌声没有落定，反而向上散开；后来忽然戛然而止，快乐余温尚在，心头却泛起怀念
话：可眼下两个人都愿意亲近，【以后未必还会这样】，他【心里没底】。

### S09（屏幕停留 32 秒）
话：那点没底越来越具体：要是哪天对方【不再需要他陪】，连和他待着【都不自在了呢】？
感受：前面那股几乎要冲出去的势头突然收住；飘渺的颤音和轻柔和弦悬在半空，像对视到呼吸都停了 / 那股想靠近的劲还绷着 没有真正松开 / 明朗像被薄雾柔化，声音一层层下沉、变暗，光还在，只是隔了一层
话：他【一下安静了】，刚才还敢盼那么远，现在却【不敢再往下想】。
感受：又像激动地说了很多话后抬头看见夜空，眼前的美好比自己的愿望更大；不安还没回答，却暂时不占满心思
话：他想起对方一直没退开，两人眼下还亲近，【这些都是真的】；也许对方也喜欢他在身边，他【有点高兴】。

### S10（屏幕停留 27 秒）
话：他想着，再猜下去连今天也过不踏实，便暂时不去管往后怎样，【先好好享受眼前的亲近】；紧绷的肩膀终于松开，胸腔打开，心里亮堂得几乎想笑，也【有点想哭】。
感受：身体也像失去重量，短暂悬在夏夜微风里，只是一口气，不是能久留的避风处 / 右手高音区织出极细、极亮的小音符，像晨曦里的银色蛛丝 / 一串琶音仿佛飞瀑从极高处倾泻，清亮地落进水里 / 眼泪终于不用憋着了

### S11（屏幕停留 37 秒）
话：轻松过后，他忽然想到自己需要对方，对方有时也需要他；即使对方不需要他，他仍愿意陪着，【不再藏着喜欢】，像终于能说：这是我的感情，【我不再为它道歉】。
话：这个念头一上来，他高兴得【连害臊都顾不上了】，觉得自己这么在乎对方也【没什么不好】。
感受：前面悬置的期待似乎终于得到满足，但还不是结束 / 灿烂像夕阳沉下前血红金亮的天空，刺眼到让人想流泪，胸口反而被压得发痛 / 像多年后重新走进旧房子：熟悉的温柔还在，可知道它有多珍贵后，心里反而更容易发疼 / 像刚从梦里漂着 忽然一下落回现实
话：可对方以后还愿不愿意让他陪在身边，【不是他能说了算的】；想到两人未必总能这样亲近，【欢喜就压得他心口发疼】。

### S12（屏幕停留 38 秒）
话：他顾不上对方是否也在乎他，只想【把能给的都给对方】，【希望对方安心】。
感受：那支温柔晴朗的歌在这里被放到开阔的尺度，内声部彼此拉扯，一浪高过一浪；像整个人被卷进比自己更大的世界 / 这份狂喜像高烧，也像久别重逢：忽然抱紧对方，久久不愿松手 / 喉咙发紧 眼眶一下湿了
话：可他明知再用心也【没法保证以后还这么好】，还是嫌这样的日子不够，【想多陪对方一会儿】。
感受：歌声带上近乎恳求的力量，一次次向上伸展，却始终不能完全满足
话：那一阵【高兴终于整个涌了出来】，他不再强迫自己收着，只顾【痛痛快快地喜欢对方】。

### S13（屏幕停留 39 秒）
话：高兴过后，他更想听对方说【以后也不变】；可就算听到了，越喜欢跟他待着，越觉得时间过得快，【真能一直这样吗】？
感受：明亮里渐渐掺进尖锐、暗沉的成分，幸福没有消失，悲伤却进了幸福里面 / 刚握到手里 才发现它留不住 / 像刚坚定地说了一声「是」，心里马上又追问：「可是呢？」 / 下方的脚步仿佛牢牢踩住地面，不肯移动；上方声音却一次次往下落，像叹息，胸口一沉再沉
话：起初他怕自己的需要给对方添负担，如今更怕对方哪天不再需要他，连这样待着都没了；【少露些心意，会不会少疼些？】可他早不像最初那样能装作不在乎，刚才想对对方好也是真心的，真要往回藏，【自己反倒更难受】。

### S14（屏幕停留 34 秒）
话：最初他连喜欢都不敢多露，如今两人还亲近，心里【又甜又酸】，【却不后悔】。
感受：进入终结句才真正松下来、轻下来，心里仍温热，身体慢慢平静 / 左手内声部幽幽唱出一句，像男中音独自沉思；接着，右手细碎琶音像水花溅落夜空
话：他还是【会舍不得】，也不知道以后怎样，却不想再逼自己讨一句【永远不变的保证】。
感受：尾声像隔着很远回应开头；最后几下向上抬起的和弦，像接住开头悬着的话 / 低音像铁锚落入水底，把摇荡的小船定住 / 像从一场美梦里醒来 还记得梦里的光
话：既然喜欢已经让对方看见，他就【不往回藏】了；往后会怎样，【等真的到了那时再说】。
