《幻想波兰舞曲》Op.61
Center：他在乎那份亲切，既想让它有可靠的着落，又不愿自己的珍惜只能靠抓紧和逼迫来维持。

### S01 ｜ 1–23 小节

• 猛地郑重地绷紧，随即又悬空，茫然得不知该往哪里着力。
→ 他还没弄清是什么触动了自己，身体已经先觉得不能倒下，想用力挺住。可这份郑重并不能告诉他究竟该抓住什么，刚提起的劲便落了空。
• 紧绷慢慢变成失神和孤单，心里难过，却说不清在难过什么。
→ 最初的惊动过去后，他本以为停一停就能缓过来，可那份空落并没有散去。越是安静地待着，越觉得心里确实少了什么，却连自己在惦念什么都还不知道。
• 恍惚中渐渐感到亲切和温暖，随之又生出难以言说的惆怅。
→ 他一直没有离开这份惦念，渐渐从茫然中摸到一种仿佛早已熟悉的感觉。可越觉得它亲近，越发现这份亲近只能在心里感到，不能就此变成眼前能够握住的东西。
• 仍有失落和迟疑，却慢慢有了一点想向前的劲，还不敢说站稳了。
→ 刚才短暂的亲切虽然留不住，却让他知道自己确实还想靠近。几次悬着、停住以后，他不再只是等着心情平复，身体先有了一点迈步的准备，尽管心里仍没有把握。

### S02 ｜ 24–65 小节

• 他终于有了庄严和底气，心里却仍有柔软的伤感。
→ 先前那份亲切虽不能当成已经拥有的东西，却让他真切地想靠近。如今他不再只顾着弄清它，而是郑重地承认自己的珍惜，因此能挺直起来；但这份力量并没有消除亲切背后的失落。
• 他越来越激昂，也越来越急切，甚至有些不甘心。
→ 刚才的郑重确实让他站住，也让他更清楚这份亲切有多值得珍惜。可越投入，他越感觉到，能够挺住并不等于能够安心；他开始不甘心总要靠用力承受才能守住这份珍惜。
• 他一次次把自己稳住，坚定里渐渐透出紧张。
→ 刚才他已经尝到郑重承认心意所带来的力量，于是更想保持这份挺直。但每次重新收束自己，都让他察觉不安其实还在；越要维持镇定，越显出这件事对他有多重。
• 高涨渐渐收敛，他仍舍不得放下，也没有安心。
→ 几次重新振作都确实让他站住了一阵，却始终没能让那份亲切变得可以把握。等强烈的自持渐渐收住，原先没有解决的牵挂仍在那里；他还愿意坚持，却已知道坚持不能代替安心。

### S03 ｜ 66–91 小节

• 刚才的笃定一松，他反而焦躁、抗拒，急着往前却找不到方向。
→ 前面他靠郑重坚持站稳了，却仍不安心；如今更不想一直硬撑。旧办法刚松，新的着力点又没有，他便急着找路，也忍不住怀疑刚才的笃定有几分是自己撑出来的。
• 他暂时把心思移开，确实轻松了一些，却仍游移不定，难以安静。
→ 先前一直用力守住自己的珍惜，已经让他疲惫；此刻不再紧盯那个问题，便有了喘息的余地。轻松是真的，可原先压在一旁的疑问并没有散，少了那股坚持压着，反倒纷纷冒了出来。
• 忽然有一阵熟悉的温柔，让他觉得轻盈、亲近，却又心酸。
→ 暂时不再费力证明自己站得住，早先触动过他的那份亲切反而自然浮现。他发现，不必硬撑也能从珍惜中得到快乐；可越是这样自然地感到亲近，越让他难过于这份温柔仍不是自己能留住的。

### S04 ｜ 92–115 小节

• 熟悉的郑重让他重新踏实，却也有了柔软的欣喜和感激。
→ 前面他已知道，认真珍惜能让自己站稳，却不能换来安心；又尝过不必硬撑的亲切。如今重新认真起来，他不再急着证明自己够坚定，反而更清楚自己珍惜的东西有多好。
• 越觉得亲切幸福，他越心酸，越舍不得它再过去。
→ 刚才那份不用勉强的快乐是真的，却没能让温柔留下。现在这份亲近再次出现，他已不能只为它回来而高兴，也会想到它可能仍是短暂的；不安就贴在了眷恋里。
• 他突然焦急得浑身紧绷，像被催着追赶，越冲越无力。
→ 他想让这份真切的好不要再溜走，于是下意识地一再加力；可他已经知道，靠坚定并不能保住温柔。越追越没有把握，身体却停不下来，渐渐只剩一种仿佛步步后退的疲惫。
• 脑子也反复追问还能怎样做，越想越乱，始终没个着落。
→ 前面他已经发现，不硬撑也不会自然有方向；此刻再感到亲近的脆弱，他便急着替它找个办法。每个设想都不能给出把握，他又立刻换一个问题，忙着想反倒成了不敢停下。

### S05 ｜ 116–147 小节

• 忽然柔软、亲近，却仍带着郑重的不甘。
→ 上一段让他看见，拼命追赶有时只是避开无能为力；一松开，那份仿佛来自过去的亲切又直接触到他。可他也知道，珍惜不能保证留住它，所以柔软里仍有不肯退让。
• 恳切渐渐变得赤裸，像只剩自己悬在那里。
→ 先前他已尝过不费力的亲近，也知道那不等于真正留住。如今不再忙着证明自己多坚定，他才更直接地碰到所求：希望那份温柔有个可靠的着落；愿望清楚了，却仍无处着力。
• 委屈转成紧迫的抗拒，越挣越慌。
→ 前面已证明越急着留住，越不能安心；但此刻他连自己所求是什么都已无法含糊带过，便更难甘心没有答案。他试着把盼望变成更用力的要求，反而越来越慌。
• 急迫慢慢冷下去，只剩疲惫而沉重的难过。
→ 他已察觉忙碌不等于有路，这次又亲自尝到：连不肯退让地要求也换不来安稳。绷得太久，身体先卸了力，心里的舍不得却仍在。

### S06 ｜ 148–180 小节

• 从耗尽后的空落里，忽然进入小心而郑重的安静。
→ 上一段已经证明，再加重要求也逼不出答案；当这股用力终于停下，仍未消失的愿望第一次可以不靠追问而留在心里。
• 安静渐渐变成更深的温柔、亲近和真切的幸福。
→ 愿望没有因无解而消失，也不必再立刻承担求得保证的任务；于是他能暂时只体会所珍惜之物的分量，既宽慰又郑重。
• 原先压住的愿望渐渐完整浮现，牵挂也变得更深。
→ 上一段已让他认清愿望仍在；此刻不再逼它立刻换来答案，愿望反而能更完整地被感到。靠近因此更深，却仍不等于得到回应。
• 越到后面越舍不得，温柔里渐渐有了伤感和空落。
→ 正因为他刚刚发现未解决也能安静地珍惜，才不再急着抓住这一刻；可不抓以后，它不能被强留这件事反而更清楚，于是幸福与不舍一起加深。

### S07 ｜ 181–205 小节

• 安宁骤然断开，他先浑身一凉、心头猛跳，随后才感到失落。
→ 上一段他刚能在没有答案时放下逼迫，安心待在那份温柔里，因此也少了防备。一旦那份安稳突然维持不住，身体先被惊慌攫住，随后才意识到自己有多舍不得。
• 一股熟悉而鲜活的亲切忽然闯进来，却没能安慰他，反而更心酸。
→ 他早已尝过不必硬撑也能自然感到亲切的快乐，刚才又能安静地珍惜。如今熟悉感再次变得鲜明，却带不回那份安稳，反而让刚才能够拥有、此刻却留不住的落差格外刺人。
• 惊慌渐渐变成停不下来的焦灼，最后只剩绷紧的等待。
→ 他早已知道追赶不能带来方向，却因为刚才真的安宁过，惊慌中仍忍不住反复确认那份亲切能否回来。越想找回，越得不到把握；最初还想有所作为的急切，渐渐困成了无法松开的紧张。

### S08 ｜ 206–213 小节

• 紧绷的心忽然松了一点，重新感到熟悉的亲切和短暂的安慰。
→ 他早已体验过，不必逼迫自己，珍惜也能自然带来亲切；刚才惊慌中的反复确认并没有抹去这份可能。如今那份熟悉的温柔重新被感到，身体也随之有了片刻喘息。
• 他为重新感到安宁而温暖、欣慰，却又因刚才的失落而心酸。
→ 他曾在愿望没有得到回答时真正安宁过，随后又亲身感到那份安宁中断后的刺痛。如今同样的温柔回来，既让他重新得到安慰，也让他更清楚地感到它曾经失去，所以高兴和心疼同时存在。
• 温暖渐渐变轻，他还来不及重新安心，就已经感到深深的不舍。
→ 他已经经历过安宁中断后的难受，也知道惊慌中的反复确认不能使它留下。因此这次温柔虽然真实，却不再让他觉得能够久留；随着它渐渐退去，刚才的失落又使这短暂的亲切格外令人舍不得。

### S09 ｜ 214–215 小节

• 刚才的温柔忽然被熟悉的寒意打断；他一怔，刚站稳一点，又悬了起来。
→ 刚重新感到的亲切已经不足以使他安心，此刻一失去那点依托，先前安宁中断时留下的紧张便比念头更快地回来。他短暂想稳住自己，却还找不到向前的方向。
• 他像忽然认出最初那个不知怎么办的自己，熟悉中带着更深的酸楚。
→ 最初他连自己究竟在面对什么都说不清；如今已经知道自己想让那份亲切有可靠的着落，也知道温柔重现仍不能保证它留下。所以旧的无措再次出现，不是因为不明白自己想要什么，而是不知道明白了这一切以后还能怎样往前走。

### S10 ｜ 216–225 小节

• 从刚才的茫然里缩回来，只剩低低的难过和小心。
→ S09已让他知道自己要什么，却仍不知道怎样继续；而S07–S08又留下了安宁会中断、确认会重新绷紧的经验，所以身体先收住，不敢马上再用力。
• 那份所求还是轻轻回来，亲近、舍不得，却不敢把它变成期待。
→ S05已把模糊的不满足认成明确愿望，S06又证明不逼迫时它也不会消失；但S08说明片刻温柔已不足以安顿他，因此它回来时只能被承认，不能再当作希望的根据。
• 偶尔还想往前一点，却很快收住，克制里带着不安。
→ 牵挂没有消失，稍有力气便会自然向前；可S07–S08已经让身体记住，急着确认只会重新紧起来。于是冲动一冒头，身体便先把它压低。
• 到后来忽然失了着落：仍然想要，却连下一步往哪里去都抓不住。
→ 这次轻轻靠近既没有变成新的期待，也没有给出方向；S09那种“知道要什么却不知道怎么走”的无措因此变得更切身，连克制地守着愿望也不能提供着力处。

### S11 ｜ 226–241 小节

• 他不再只敢轻轻珍惜，心里发紧，试探着想往前走。
→ 刚才他已经发现，把盼望收得很轻也找不到方向；可从前硬逼又换不来答案。所以那份想靠近的心虽开始催他往前，他起初仍不敢一下放开。
• 几次发力都落不稳，他越来越急，甚至有些恼怒。
→ 每次试着往前，都没让那份没有着落的需要变轻；上一阵留下的紧张便压到下一次。努力没有换来踏实，反而使他更不甘心继续停着。
• 害怕、舍不得和不甘搅在一起，他越来越难收住冲劲。
→ 他既知道拼命用力会把自己耗尽，也发现克制不能替珍惜找到着落。几次想重新稳住都没能缓下紧张，他渐渐顾不上分辨这些感受，只剩一股越来越强的向前冲力。
• 最后他仍然害怕，却越来越停不住脚步，甚至有一点松快。
→ 连续的冲撞没有带来答案，却使他渐渐顾不上反复检查自己敢不敢。害怕还在，身体却已经带着那份珍惜往前走；停滞终于松开一点，虽然所求仍没有着落。

### S12 ｜ 242–253 小节

• 一种堂堂正正、很有分量的昂扬，像终于真正站稳了。
→ 刚才他已经亲自走过害怕和没把握，却仍能往前；因此此刻不必先等安心，整个人就能更完整地站出来。
• 这份骄傲很强，却少了早先那种必须靠强来撑住自己的紧张。
→ 他已知道用力不能换来安顿，也知道未满足时仍能继续珍惜；如今坚定只是在回答自己愿意怎样站，不再替结果作保证。
• 临近末尾忽然心里一软，昂扬中掠过一点心酸和失重。
→ 当“我能站住”终于不必再证明，先前留下的脆弱便有余地重新露出来；但刚得到的力量没有消失，所以他没有因此缩回去。

### S13 ｜ 254–288 小节

• 曾经只能安静感受的温柔，此刻变得开阔而庄重，令他欢喜得几乎想哭。
→ 上一段他已能带着脆弱堂堂站住，不必再靠力量压住柔软。于是，原先只能在安静中享有、又曾因害怕失去而拼命追赶的温柔，如今可以成为他毫不遮掩、热烈欢喜的对象。
• 欢欣越积越满，忽然化成止不住的冲劲，兴奋得几乎忘我。
→ 以前一激动，他就容易忙着追赶、确认，越用力越紧。如今他已经能带着不安站住，温柔也能在力量里充分展开；那股劲不再忙着防止失去，便可以痛快地向外奔涌。
• 激动渐渐退去，他终于松了口气，满足里又浮起一点不舍和不放心。
→ 刚才他已经尽情经历了那份珍惜，不必再靠持续激动来证明它。但他也经历过温柔重新到来却仍无法安心；如今热烈退去，原先没有着落的担忧便又露出来，只是刚刚真实的快乐也还留着。
• 热潮退尽，他像吐出最后一口气，又忽然清醒地感到自己仍然深深珍惜。
→ 他已经不再追着刚才的欢欣跑，也不必把重新露出的疑问立刻压下去。几乎静下来时，留下的珍惜反而格外清楚；那一下既像醒悟，也像决意，却不是终于有了结果的保证。
