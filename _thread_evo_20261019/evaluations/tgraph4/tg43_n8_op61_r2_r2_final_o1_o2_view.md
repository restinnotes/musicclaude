# Op.61｜关系图

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### 1–23　（还说不清）

- 起初，他连自己在等什么都说不清，只知道心里有股劲，不肯就此算了。
- → 任由事情照旧，仿佛就是承认它们理当如此；真投进去，他又怕会丢下什么。
- → 他找一个足够有力的理由；刚觉得想通了，另一份舍不得又冒出来，连确信都变得陌生。
- → 摇摆久了，他越来越为自己难堪：难道非得先理清心里的一切，才肯迈步？

### 24–65　（正在面对）

- “还没想清楚”终于不能再让他等下去，他先认下自己能做的那一份。
  - ← 改写：（1–23）「摇摆久了，他越来越为」
- → 没有保证，牵挂也没消失；可从等待转为动手后，他第一次真切觉得自己有了力量。
- → 从前总问值不值得，如今至少能说：“我愿意尽力。”这让他有些骄傲，疑虑也不必替他做主。
- → 越投进去越热切，付出的过程本身就让他快乐，心里的不满仿佛终于有了去处。
- → 他愿意给得更多，甚至贪恋倾尽全力的畅快；心思更多放在投入上，软弱时也接着做。
- → 可用力到深处，心里仍有一小块没跟着昂扬；他继续向前，也察觉坚决还没顾到所有牵挂。　✦ 满足照出未满足

### 66–91　（没在想）

- 认真投入过一回，他反倒能从反复自问里松开些，也发现自己会因不再畏缩而高兴。
  - ← 提供理由：（24–65）「越投进去越热切，付出」
- → 向前的热情让他感到轻盈；偶尔忘了为何用力，他也不觉得那是背叛。
- → 他顺着自由走了一程，不急着赋予它更大意义；快乐淡下去，先前的决定又回到眼前。

### 92–115　（正在面对）

- 他仍愿坚持那项决定：它曾把他从犹豫里带出来；那阵轻快是真的，心有缺口也不代表全错。
  - ← 唤起：（66–91）「他顺着自由走了一程，」
  - ← 提供理由：（24–65）「“还没想清楚”终于不」
- → 可从前让他昂起头的坚定，如今已安不了心；越想确认自己有力量，越听见心里另一个要求。
- → 他只得承认这个不情愿的答案：行动值得，却仍然不够。　✦ 满足照出未满足

### 116–147　（正在面对）

- 行动明明还不够，他却不肯撒手：这条路曾救他脱离犹疑，他怕失望就是变心，便更狠地催自己。
  - ← 提供理由：（92–115）「他仍愿坚持那项决定：」
- → 明知自己正受苦，他仍把难处当成必须克服的迟疑；想停一停，又怕辜负最初的决意。
- → 最初那股让他昂然的要求，渐渐连脆弱也容不下，终于成了苛责。　✦ 办法的限度
- → 越想维持坚定，他越像在逼一个疲惫的人硬撑；到头来，他不想再证明自己有多坚强。
- → 他暂时放下对自己的催逼，心里还没安心，却给压住的依恋留出了回来的空隙。
- → 茫然与松懈间，他终于承认：除了必须做的事，还有真心舍不得的东西。

### 148–180　（没在想）

- 催逼停下，依恋才露出原样：他想要的生活里，人不必时时防备，珍贵之物也不必靠争夺留下。
  - ← 说明：（116–147）「茫然与松懈间，他终于」
- → 人不必反复证明自己值得被爱、被接纳；付出可以只是喜欢，靠近谁也不用先准备好受伤。
- → 那样的信任、亲近和自由付出，曾真切地给过他快乐；人与生活原来可以不靠时时用力维持。
- → 这些感受确实发生过，他便确认这份盼望不是逃避时临时编的安慰，也不该被贬成软弱。
- → 这回，他让爱惜先留下，让爱本身先存在，不急着向责任证明它有何用。
- → 他暂且不问这种生活能否实现，也不拿它和眼前的坚持比较轻重。
- → 只让自己去爱、去相信，满足与安宁便涌上来；他柔软下来，几乎忘了疲惫，一时不想离开。

### 181–205　（正在面对）

- 安宁越真实，他越不能只把它留在心里；让那种生活难以存在的事，怎能只靠怀念改变？　✦ 满足照出未满足
  - ← 提供理由：（148–180）「只让自己去爱、去相信」
- → 当初不肯再被动等待，正因为他不愿看着重要的东西受损。
- → 才刚沉进满足里，他便懊恼自己忘了还有事要面对，几乎想责怪自己。
- → 他试着振作，却再难像从前那样投入；正因尝过温柔的可贵，他怕争取会一点点耗尽它。
- → 他怕只剩不肯退让的意志，失去让一切值得争取的温柔；停下来，又放不下它正受威胁。
- → 他曾以为理由足够坚定，便不会再为难；如今理由更多，心反而更难平静，最初的两难又回来。　✦ 知道更多反而更尖锐
- ⟲ 仍在起作用：（1–23）「任由事情照旧，仿佛就」

### 206–213　（没在想）

- 为难时，那份温柔又短暂靠近；他知道不能一直停留，却舍不得马上推开它。
- → 既然它确实给过他深深的满足，何必每次想起都立刻拿它审问自己？
  - ← 提供理由：（148–180）「只让自己去爱、去相信」
- → 他愿再爱惜片刻，暂且放下还无答案的事；安静仍让他欢喜，只是这回欢喜里已有不舍。

### 214–215　（正在面对）

- 安静一退，迟疑又像把他带回原处；但他已分清，其中既有怯懦，也有不愿失去的生活希望。　✦ 分清
  - ← 唤起：（206–213）「他愿再爱惜片刻，暂且」
  - ← 改写：（148–180）「催逼停下，依恋才露出」

### 216–225　（正在面对）

- 知道舍不得什么，也没让他立刻勇敢：最初的决心推不动他，旧日盼望也无法让他安心停留。
  - ← 限制：（214–215）「安静一退，迟疑又像把」
- → 行动曾把他从犹疑里带出来，旧愿也给过安宁；可两条路各有缺口，谁都解不了所有难处。　✦ 办法的限度
  - ← 说明：（92–115）「他仍愿坚持那项决定：」
- → 眼下他没力气要求自己作出多大改变，只剩一个很轻的愿望。
- → 若还要争取，就记得为何出发；若想爱惜安宁，也得面对威胁它的事。
- → 他还不知如何做到，只反复想着这点愿望；非得舍弃一边才能继续的逼迫，似乎松了些。

### 226–241　（正在面对）

- 凭着这点还不牢靠的心意，他重新想自己还能怎么做。
  - ← 提供理由：（216–225）「他还不知如何做到，只」
- → 他亲身试过，尽力行动能让人重新有力气，却不能抹掉所有牵挂。　✦ 办法的限度
  - ← 说明：（24–65）「没有保证，牵挂也没消」
- → 那种不必时时防备、可以自由去爱的生活，曾给他真切安慰，却不能单靠安慰护住所爱。　✦ 办法的限度
  - ← 限制：（148–180）「只让自己去爱、去相信」
- → 行动带来的力量和旧愿给的安慰都是真的，他不想再简单否定任何一边。
- → 可要两样都毫发无伤地留下，恐怕不可能。
- → 他想保住那份无需时时用力的安宁；偏偏为它争取，也可能失去它。
- → 从前他总因此责怪自己，仿佛真正坚定的人就不该如此为难。
- → 他渐渐明白，代价未必说明意志不够强，而是珍惜的东西本来就不止一种。　✦ 选择的代价
- → 承认这点仍让他心疼，也盼着有条容易些的路；可再等下去，那条路不会自己出现。
- → 若只因怕珍贵的东西受损就不再争取，自己爱惜的也未必留得住。
- → 他不再等自己毫不害怕；即使不舍、没把握、会受苦，也继续向前，不让恐惧替他决定。

### 242–253　（正在面对）

- 不再等一个毫无损失的办法，他重新愿意向前；昂扬回来了，也不必靠否认脆弱维持。
  - ← 提供理由：（226–241）「他不再等自己毫不害怕」
- → 他仍愿尽力，却不再要求这份尽力证明自己能改变一切。
- → 他知道自己要承担什么，也明白为何舍不得；牵挂不再被当成行动的拖累，他愿为所爱负责。
- → 这次的决心仍热烈，却比从前踏实；犹疑还在，他也允许自己坚定向前。　✦ 分清
- ⟲ 仍在起作用：（226–241）「他渐渐明白，代价未必」

### 254–288　（正在面对）

- 带着全部牵挂向前，他意外发现旧愿反而更近；过去总想退出争取，以为这样才能保住它。
  - ← 改写：（242–253）「他知道自己要承担什么」
- → 正因盼着不必拼命也能好好生活，他才不肯任由伤害它的事继续；为守住这份盼望，有时得离开安宁。
- → 投入更多不保证旧梦成真，美好愿望也不能替每一份付出辩护。　✦ 办法的限度
  - ← 限制：（226–241）「他亲身试过，尽力行动」
  - ← 限制：（226–241）「那种不必时时防备、可」
- → 他仍得留心，争取时会不会耗掉自己珍惜的东西；这份顾虑也提醒他该怎样坚持。
  - ← 改写：（181–205）「他试着振作，却再难像」
- → 承认珍惜之物会彼此牵制后，他重新看懂这份希望：两股曾拉扯他的心意，竟能一起推他向前。
  - ← 改写：（226–241）「他渐渐明白，代价未必」
- → 依恋不再令他羞愧，肩上的责任也不再让他厌倦那些真心想珍惜的东西。
- → 最初相信生活时的快乐又回来了；经历怀疑与疲惫后，这份快乐已不再理所当然。
- → 喜悦平静后，他仍知道许多事没有答案：尽力未必改变现实，他也没回到无需防备的生活。
- → 往后他仍可能疲惫，也会因要付出的代价动摇；两种渴望同行，并不意味着它们从此不再冲突。
- → 他不再拿一种满足遮住另一种需要，也不因某个愿望未实现，就否定已经得到的东西。
  - ← 改写：（92–115）「他只得承认这个不情愿」
  - ← 改写：（148–180）「只让自己去爱、去相信」
- → 一路走来，他更清楚哪些东西值得付出，哪些不能在争取中轻易牺牲。
  - ← 提供理由：（24–65）「越投进去越热切，付出」
  - ← 限制：（116–147）「最初那股让他昂然的要」
  - ← 提供理由：（148–180）「只让自己去爱、去相信」
  - ← 限制：（181–205）「他试着振作，却再难像」
- → 他仍盼安宁，也愿带着不舍向前；能留下多少尚未知，他不再靠遗忘一边或证明自己求安稳。
- ⟲ 仍在起作用：（148–180）「催逼停下，依恋才露出」；（181–205）「当初不肯再被动等待，」
