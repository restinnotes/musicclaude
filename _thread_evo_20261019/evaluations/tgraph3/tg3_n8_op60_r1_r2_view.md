# Op.60｜关系图

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3　（还说不清）

他**还说不清自己究竟盼什么**，只是想到那个格外想亲近的人，心里便有一点不由自主的柔软。每当想让这份喜欢多停留一会儿，他又**本能地往回收**；眼下明明没有必须决定的事，他也**说不清自己为何谨慎**。喜欢还很轻，似乎随时能放下，他却舍不得放下。


### 4–16　（正在面对）

因为还不知道自己怕什么，他先不替这份在意安排去向，也不预想两个人以后会怎样，更不因喜欢就期待对方什么，于是慢慢能**安心亲近**。能够自由地给予温柔，**不用时时确认**对方有没有领受，他既在乎，又保有从容，有时甚至觉得比先前自在。这样的快乐使他不再提防自己的喜欢，还有点满意于自己的宽和；他当时盼亲近能一直自然发生，不追问、不计较，**觉得已经足够**。

- ← 提供理由：（1–3）「说不清自己为何谨慎」
- ← 改写：（1–3）「本能地往回收」

### 17–23　（正在面对）

正因为这份安心的亲近已经让他幸福，他开始**希望这种喜欢能够长久**。一想到长久，他便明白自己可以决定怎样珍惜对方，却决定不了对方是否同样珍惜自己；原先不用确认的事开始牵动他。他起初并不想索取什么，只是偶尔想知道自己在对方心里是否也有**特别的位置**；这点还不强烈的期待已经让他**失去一部分安稳**，他意外地发现，眼前的满足还会带来更多盼望。　✦ 满足照出未满足

- ← 唤起：（4–16）「安心亲近」
- ← 动摇：（4–16）「不用时时确认」
- ← 动摇：（4–16）「觉得已经足够」

### 24–34　（正在面对）

他不愿新添的紧张破坏先前得来的快乐，也记得对方没有答应过什么，怕自己的喜欢变成催促，于是试着把心放宽：关心、给予、为对方高兴，本来就能让他快乐，不必非要对方有相应的表示。他因此真的轻松起来，想确认的紧张慢慢退去，**付出也更自在**，不再衡量给了多少或担心自己显得更在乎；心里仿佛有了足够宽敞的地方容纳温柔。那一阵他甚至相信，**只要不提出要求**，就能尽情地爱，也不会失去什么。

- ← 唤起：（17–23）「失去一部分安稳」
- ← 改写：（4–16）「不用时时确认」 —— 先前不用确认很自然，如今已有期待，他需要主动劝自己别追讨回应。

### 35–39　（还说不清）

等那阵充盈的欢喜稍稍平息，他仍然想知道自己是否也**被对方放在心上**；想到刚才还为自己的无所求高兴，他有些**难堪**，也怀疑体贴里是否一直藏着期待。他**一时没法回答**：说自己毫无所求，似乎不够诚实；可此前给予的快乐确实真切，他也知道那并非只为换取回应。他只能暂时待在这份不自在里，不替自己辩解，也不再找热烈的感觉盖过去。　✦ 办法的限度

- ← 失效：（24–34）「只要不提出要求」
- ⟲ 仍在起作用：（17–23）「特别的位置」

### 40–50　（没在想）

这份难堪没有让他少喜欢，却让他不愿继续用慷慨证明自己；他既不想盯着对方的回应，也不想逼自己全无期待。于是他把心思放在此刻确实**愿意给出的关切**上，安静惦念，希望对方好，因心里有这个人而高兴，不再每次都拿这些心意衡量关系。喜欢变得隐秘而贴近自己，**只留在心里的快乐**也鲜明得很；他甚至暂时忘了自己为何那么在意回应，觉得这样细细喜欢很甜，先前的疑问仍未解决。

- ← 唤起：（35–39）「难堪」
- ← 改写：（17–23）「希望这种喜欢能够长久」
- ⟲ 仍在起作用：（35–39）「一时没法回答」

### 51–61　（正在面对）

这份不声张的甜意留得久了，渐渐不像起初那样轻巧。他原想把喜欢留在自己心里，让对方免于为难，也让自己少受期待牵动，可珍惜加深后，他惦念得更深，更希望关切被领会，有时并无特别缘由，心里就满是对方。他仍觉得**不催促对方**是对的，宁愿独自承受**没有着落的盼望**；细致的甜蜜又使他舍不得减轻喜欢，只是先前以为能轻轻收放的心意如今**有了重量**。　✦ 办法的限度

- ← 限制：（40–50）「愿意给出的关切」
- ⟲ 仍在起作用：（40–50）「只留在心里的快乐」；（35–39）「被对方放在心上」

### 62–71　（没在想）

既然心意已经有了重量，他忽然不愿再时时约束它。他想到最初安心亲近、后来付出时的满足，以及独自珍惜的细致甜蜜，知道这些快乐在没有承诺时也真实发生过；即使仍有期待，他也无须怀疑那份幸福。于是他不愿因怕受伤而连高兴都小心翼翼，想**尽情地喜欢**，不急着问结果或安排退路；积攒的眷恋变成坦然的热情，他不再计量付出，也不再时时提醒自己收回。那一阵**欢喜确实压过顾虑**，他知道**仍没有保证**，却几乎感觉不到这份无把握的沉重。　✦ 分清

- ← 唤起：（51–61）「有了重量」
- ← 提供理由：（4–16）「安心亲近」
- ← 提供理由：（24–34）「付出也更自在」
- ← 提供理由：（40–50）「只留在心里的快乐」

### 72–77　（正在面对）

正因为他刚刚毫无保留地承认了自己的感情，欢喜稍落，他就无法再含糊自己想要什么：他**想让这份深情有所相遇**，想知道对方是否也想靠近、愿意彼此看得那样重要。他同时明白，**自己的热烈不能替对方作决定**，也不能要求对方同样热烈地回应。于是他一时**进退两难**：退回先前的谨慎，仿佛辜负刚敢承认的喜欢；继续盼望，又**怕自己会把爱变成要求**；两边都舍不得，他找不到兼顾的办法，委屈得甚至有些厌倦这样反复为难自己。　✦ 知道更多反而更尖锐

- ← 唤起：（62–71）「尽情地喜欢」
- ← 唤起：（62–71）「欢喜确实压过顾虑」
- ← 改写：（1–3）「还说不清自己究竟盼什么」
- ← 限制：（51–61）「不催促对方」
- ⟲ 仍在起作用：（17–23）「特别的位置」；（1–3）「本能地往回收」

### 78–83　（正在面对）

他终于不想再逼自己立刻选一边：现在减不轻喜欢，也无法决定对方的心意，于是**暂时不决定什么**。他不用因为想靠近就立即向前，也不用为了守住分寸便把眷恋压住；**愿望和没把握的感觉依旧同在**，只是暂时不再互相催逼。这让他**心里松开一点**，先前的为难并未消失，但紧绷的温柔又能自然地留在心中。　✦ 分清

- ← 唤起：（72–77）「进退两难」
- ← 限制：（72–77）「自己的热烈不能替对方作决定」
- ⟲ 仍在起作用：（51–61）「没有着落的盼望」

### 84–92　（正在面对）

不再逼自己消除渴望之后，他又感到最初亲近的快乐，但这次他已尝过期待的紧张、无从确认的难堪，以及深情不能替对方作答的无奈，仍愿意喜欢。他因此**不必靠毫无所求证明体贴**，也不会因为偶尔盼被珍惜就怀疑自己的真心；他不再躲避热切或因此羞怯，仿佛先前挤在一起的心思都有了伸展的地方。他甚至为经历许多犹疑后仍能这样高兴而感动，**愿望此刻可以与喜欢同在**。他**清楚自己可能受伤**，却仍愿意充分承认这份幸福。　✦ 分清

- ← 提供理由：（78–83）「暂时不决定什么」
- ← 唤起：（78–83）「心里松开一点」
- ← 改写：（4–16）「安心亲近」
- ← 改写：（35–39）「一时没法回答」
- ← 改写：（24–34）「只要不提出要求」

### 93–102　（没在想）

既然已经让愿望与喜欢同在，他更清楚自己多想亲近那个人：想让积攒的温柔有所回应，**想被同样深切地珍惜**，也想知道两个人若能共同拥有亲密，会有多丰盛。那些曾令他紧张、难堪的愿望，此时暂时没有以缺憾折磨他；他只觉得有许多可以给予和珍惜，甚至觉得已经不需要再增加什么。**那一阵满足**强烈得几乎难以承受，想靠近、想被爱、想把自己都交给这份亲近的心愿仿佛一同得到抒发；他**没有得到新保证**，却真切觉得能够这样爱着已让生命格外充实，一时顾不上以后。

- ← 唤起：（84–92）「愿望此刻可以与喜欢同在」
- ⟲ 仍在起作用：（72–77）「想让这份深情有所相遇」；（62–71）「尽情地喜欢」

### 103–110　（正在面对）

幸福仍这么鲜明，他却感到其中有一块始终没有着落。刚才他让自己尽情地爱，也尽情盼望被爱，因此此刻格外清楚：自己的深情可以充分拥有，对方是否同样选择他却仍**由对方决定**。他因此**酸楚**；那酸楚没有推翻刚才的欢喜，恰因欢喜真实、他已知道自己爱得多深，他再难说服自己对回应无所谓。　✦ 满足照出未满足

他知道把自己的安稳全交给对方，会使对方在接受心意时还要负责消除他的不安；可为了避开得不到的疼痛而削弱喜欢，又会失去这份感情给过他的幸福。他终于看清，**克制曾让他安心，却留不住渴望**；**尽情投入让他幸福，也挡不住可能的失望**。想靠近的迫切和不肯勉强对方的坚持仍然冲突，此刻甚至更强烈，因为两边他都舍不得否认；他**宁肯承受不轻松**，也不想靠舍掉其中一边换取表面的平静。　✦ 办法的限度

- ⟲ 仍在起作用：（93–102）「想被同样深切地珍惜」；（62–71）「仍没有保证」；（72–77）「怕自己会把爱变成要求」；（51–61）「不催促对方」；（84–92）「清楚自己可能受伤」

### 111–116　（正在面对）

带着这份仍未平息的牵挂，他渐渐不再要求自己找到一种不会受伤的爱法。他承认自己还想被对方选择，因为对方对他确实重要，他真切地盼两个人彼此亲近；即使这愿望未必得到满足，他也不用假装它不存在。他也明白自己为何舍不得克制：对方有自己的心意，有选择不同的自由；要是为求安心让对方承担他的全部期待，连他盼的亲近也会变得不自在。他想到这里仍有遗憾，却不再逼自己先消除遗憾才敢喜欢。　✦ 分清

他回看先前的快乐，知道小心地亲近、不求确认地付出、独自珍藏的甜蜜，以及后来尽情投入的欢喜都是真的；正因为这些经历让他一再愿意继续，他才明白这个人对他有多重要，也看见收住心意和放开去爱都不能免除风险。他仍希望得到回应，也仍会有所保留，但对方怎样回应已不再被他拿来判断自己的真心，他也不再靠收得多紧证明自己清醒；以后或许还会想要更多，因无法再靠近而疼痛，却不用为此否认喜欢或催促对方。他愿意认真地喜欢这个人，充分欢喜，也承受自己不能决定的部分；他想被爱，也尊重对方可以有不同心意的自由，虽没有得到想要的一切，仍不愿先放弃最想给予的爱。　✦ 选择的代价
