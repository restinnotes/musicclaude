# Op.60｜关系图

**Center：**亲密的幸福与留不住它的痛楚难以分开

### 1–3　（还说不清）

- 起初他还不知道自己盼望什么。
- 独自过得安稳的他如今觉得少了些什么。
- 他想靠近对方。
- 他不敢确信心意会被接住。
- 这份没把握并未让他退缩。
- 想到也许能在对方面前不必小心，他就有些欢喜。

### 4–16　（没在想）

- 他慢慢把心敞开一些。
  - ← 提供理由：（1–3）「想靠近」
  - ← 唤起：（1–3）「有些欢喜」
- 对方真的接住了他。
- 他原以为被理解前得先把自己讲明白。
- 他原以为被喜欢就得藏起不讨喜的部分。
- 他发现不够好也能被亲近。
- 他发现柔软和迟疑没有令自己难堪。
- 他觉得先前的冒险值得。
  - ← 改写：（1–3）「不敢确信」
- 他愿意再多敞开一些。
- 每次不收住心意，他都更放松。
- 他享受自然做自己的舒畅。

### 17–23　（没在想）

- 他开始有余力关心对方的快乐。
  - ← 提供理由：（4–16）「不够好」
- 他也想知道自己在对方心里多重要。
- 他希望对方在自己面前同样自在。
  - ← 唤起：（4–16）「自然做自己」
- 他发现让对方幸福也使自己满足。
- 他急着把得到的好也给对方。
  - ← 唤起：（4–16）「接住了他」
- 付出没有令他委屈，反而使他丰足。
- 他终于不必总守着自己的需要。

### 24–34　（没在想）

- 他渐渐忘了最初的顾虑。
  - ← 提供理由：（4–16）「接住了他」
- 他不再查看彼此是否同样热切。
  - ← 提供理由：（17–23）「自己满足」
- 他不再计算付出与得到的多少。
  - ← 提供理由：（17–23）「使他丰足」
- 有时他甚至没觉得自己在追求幸福。
- 他能尽情喜欢，也坦然接受对方的喜欢。
- 他不再从每份亲近里寻找证明。
- 他开始喜欢亲近时不必刻意用力。
  - ← 说明：（4–16）「更放松」
- 他喜欢心意自然流向对方的自己。
- 他喜欢彼此不必费力的信任。
- ⟲ 仍在起作用：（17–23）「同样自在」

### 35–39　（还说不清）

- 他忽然有一点舍不得。
  - ← 唤起：（24–34）「追求幸福」
- 那时他并没有失去什么。
- 他也没有怀疑对方。
  - ← 提供理由：（4–16）「接住了他」
- 快乐时他忽然想一直这样下去。　✦ 满足照出未满足
  - ← 唤起：（24–34）「不必费力」
- 这个念头让他短暂地发紧。
- 眼前的幸福随即安抚了他。
  - ← 提供理由：（24–34）「坦然接受」
- 他还没把这点不安当成问题。
- 他以为舍不得只是因为太喜欢这一切。

### 40–50　（还说不清）

- 他不愿让舍不得搅扰快乐。
  - ← 提供理由：（35–39）「短暂地发紧」
- 他转而更用心珍惜眼前的亲近。
  - ← 唤起：（35–39）「一直这样」
- 他觉得该爱得更充分。
- 他想把这一刻感受得更深。
- 他开始主动体会每点细微的好。
  - ← 改写：（24–34）「不必刻意」 —— 原先自然感到的好，如今被他主动留意。
- 他盼望以后想起时仍能获得力量。
- 他想到将来未必总这样满足。
- 他确信此刻得到的幸福谁也抹不掉。
- 他觉得这种爱比从前更郑重。
- 他没意识到自己也想靠认真留住些什么。
- ⟲ 仍在起作用：（35–39）「舍不得」

### 51–61　（正在面对）

- 他开始检查此刻是否还像刚才那样好。
  - ← 改写：（40–50）「细微的好」 —— 体会细微的好变成了检查好是否还在。
- 他开始检查自己的心是否仍然饱满。
- 他想确认对方的亲近是否仍足够。
- 那份细心反倒使他难以安宁。　✦ 办法的限度
- 即使什么没变，他也忍不住比较。
- 他仍感到被爱，却想知道能否一直如此。
  - ← 唤起：（40–50）「留住些什么」
- 细微的好成了他反复辨认的凭据。
- 他并不真的怀疑对方爱他。
- 他难过自己已无法毫无顾虑地享受亲密。
  - ← 失效：（24–34）「寻找证明」 —— 原先无须证明的轻松已经难以维持。
- 反复确认没有失去，反让他仿佛失去了什么。
- 他为自己的委屈感到羞愧。
- 他不明白得到了真实的好为何仍不满足。
  - ← 限制：（40–50）「谁也抹不掉」 —— 确信得到过幸福，仍不能消除眼前的不满足。
- ⟲ 仍在起作用：（35–39）「没有怀疑」

### 62–71　（正在面对）

- 他开始厌烦自己反复追索。
  - ← 唤起：（51–61）「感到羞愧」
- 他发现自己把对方心意当成必须交出的东西。　✦ 办法的限度
  - ← 说明：（51–61）「反复辨认」
- 他觉得这种索取改变了原先喜欢的亲密。
  - ← 改写：（24–34）「同样热切」 —— 彼此曾经不必时时察看，如今却被索取打扰。
- 他试着收住比较的念头。
  - ← 唤起：（4–16）「接住了他」 —— 他记起最初的快乐来自敞开后的回应。
- 他不再要求每一刻胜过上一刻。
- 起初这样做并不容易。
- 少了盘问，他确实又轻松一些。
- 他记起自己喜欢的还有对方这个人。
  - ← 唤起：（17–23）「自己满足」
- 他仍会担忧，却不再催对方立刻消除。
  - ← 改写：（51–61）「能否一直如此」 —— 他仍想安心，但不再把消除担忧交给对方。

### 72–77　（正在面对）

- 不再索要保证后，他仍想长久相爱。
  - ← 限制：（62–71）「轻松一些」 —— 盘问减少了，长久的愿望却还在。
- 他发现苦恼不能全怪自己计较。　✦ 分清
  - ← 限制：（62–71）「必须交出」 —— 索取保证确实有问题，却不能解释全部苦恼。
- 即使不再比较，他仍怕幸福终有变化。
- 他盼望往后还能与对方相伴。
- 他不愿轻易责备自己贪心。
- 真实得到的快乐让他更渴望长久。
  - ← 提供理由：（17–23）「自己满足」
- 他开始分清眼前被爱与往后永不改变。　✦ 分清
  - ← 提供理由：（4–16）「接住了他」 —— 他确实得到过对方愿意爱他的回应。
- 他知道此刻被爱也无法保证往后永远如此。
- 他知道自己的珍惜无法保证以后。　✦ 办法的限度
  - ← 失效：（40–50）「留住些什么」 —— 认真珍惜不能换来以后不变。
- 他接受这个分别，心里仍旧疼。
- ⟲ 仍在起作用：（35–39）「短暂地发紧」

### 78–83　（正在面对）

- 他不再勉强自己装作无所谓。
  - ← 提供理由：（72–77）「仍旧疼」
- 他仍盼幸福长久。
- 他仍怕有一天不再如此。
- 他不愿为了防备那天先收回眼下的爱。
  - ← 唤起：（72–77）「幸福终有变化」
- 他珍惜对方自由给予的亲近。
  - ← 提供理由：（4–16）「接住了他」
- 他也想自由地给予自己的爱。
- 他不愿暗中要求对方永不改变。
  - ← 改写：（62–71）「必须交出」 —— 他不想再把对方的心意变成必须交出的东西。
- 即使不能保证以后，他仍愿把心交出去。
  - ← 限制：（72–77）「无法保证」 —— 他只能决定此刻仍愿意爱。
- 这个选择没有让他安心。　✦ 选择的代价
- 他却重新感到坦然。

### 84–92　（没在想）

- 少了暗中计较，他又能尽情欢喜。
  - ← 提供理由：（78–83）「永不改变」
- 他没有忘记亲密可能带来痛楚。
  - ← 仍在起作用：（78–83）「把心交出去」 —— 他是在知道可能受伤的情况下继续亲近。
- 他不再为自己的热切羞愧。
  - ← 改写：（51–61）「感到羞愧」
- 他不再为显得清醒而克制喜爱。
- 他能够坦然感到自己需要对方。
- 他也能热切地盼对方幸福。
- 这两种心愿不再互相争夺。　✦ 分清
- 他喜欢在爱里变得柔软的自己。
- 他喜欢自己能够慷慨地给予。
- 犹疑后仍愿相信，使他的满足更深。
- 他还没有想通所有问题。
- 有一阵子他幸福得不再追问。
  - ← 提供理由：（62–71）「立刻消除」 —— 他暂时不必让每份担忧都得到解答。
- ⟲ 仍在起作用：（17–23）「同样自在」；（17–23）「使他丰足」

### 93–102　（正在面对）

- 他难以忍受如此圆满也留不住。　✦ 满足照出未满足
  - ← 唤起：（84–92）「满足更深」 —— 犹疑之后得到的满足，使他格外舍不得。
  - ← 唤起：（84–92）「有一阵子」
- 他想再靠近对方一点。
  - ← 唤起：（72–77）「与对方相伴」
- 他恨不得彼此心意完全相融。
- 他想消除一切可能使两人分离的距离。
- 他明白亲近再深，两人仍是两个人。
  - ← 说明：（72–77）「永远如此」 —— 对方的心意无法完全由他决定。
- 他明白此刻圆满也无法阻止以后变化。
- 明白这些后，他的渴望反而更炽烈。　✦ 知道更多反而更尖锐
- 他不肯因此减少自己的爱。
- 他想倾注所有眷恋。
- 这样爱着令他幸福得近乎无法承受。
- 想到幸福换不来永远，他又感到剧痛。
- 他分不清急切来自太快乐还是无法留住。
  - ← 仍在起作用：（35–39）「一直这样」 —— 最初盼望一直这样下去的心愿没有消失。
- 他舍不得到几乎不能安静地幸福。
- ⟲ 仍在起作用：（72–77）「无法保证」；（78–83）「把心交出去」

### 103–110　（正在面对）

- 这种急切终于使他感到无力。
  - ← 提供理由：（93–102）「不能安静」
- 他发觉尽情爱仍不能替未来保证。　✦ 办法的限度
  - ← 限制：（93–102）「减少自己的爱」 —— 不减少爱，也无法令以后按他的愿望发展。
- 他甚至希望自己不要懂这么多。
- 他想若像最初只知靠近，也许不必这样疼。
  - ← 唤起：（1–3）「不知道」 —— 他一度怀念最初还不懂得这些的自己。
- 他想至少把一切牢牢记住。
  - ← 唤起：（40–50）「获得力量」
- 记忆能证明他曾得到幸福。
- 记忆无法使他重新拥有那份幸福。　✦ 办法的限度
  - ← 限制：（40–50）「谁也抹不掉」 —— 幸福确实存在过，也无法靠记忆留在眼前。
- 他不觉得先前的快乐是假的。
- 他也不觉得自己的投入是错的。
- 确信那些快乐真实，让他更难放下。　✦ 知道更多反而更尖锐
- 他有一瞬间埋怨自己爱得太深。
  - ← 唤起：（93–102）「换不来永远」
- 他无法真心希望幸福从未发生。
- ⟲ 仍在起作用：（4–16）「接住了他」；（93–102）「近乎无法承受」

### 111–116　（正在面对）

- 他分清希望长久与要求永不改变。　✦ 分清
  - ← 改写：（72–77）「开始分清」 —— 他进一步分清长久的心愿与永不改变的要求。
- 他希望长久是因为真心爱对方。
- 他看见要求永不变会让自己难以自由地爱。
  - ← 提供理由：（62–71）「必须交出」
- 他不再为希望长久感到羞愧。
- 他不愿再用永不变的要求束缚彼此。
- 想明白这些，他依然感到疼。
- 无法确定以后，仍令他心口发紧。
- 他不再急着责备自己的舍不得。
  - ← 改写：（51–61）「感到羞愧」 —— 原先的羞愧不再要求他立刻压下舍不得。
- 他不再用舍不得否定得到过的快乐。
  - ← 提供理由：（103–110）「更难放下」
- 他知道自己确实幸福，所以如此留恋。
  - ← 提供理由：（84–92）「满足更深」
- 他知道幸福留不住，因此幸福时也疼。
  - ← 提供理由：（103–110）「不能替未来保证」
- 快乐无法消除他的痛楚。
- 他不愿为了不疼而减少快乐。
- 他依旧想靠近，也愿意爱。
- 他还有一点不甘心。
- 他无法安排往后的变化。
- 他不愿因此收回已经付出的心意。
- 他舍不得那个因爱过而舍不得的自己。
  - ← 提供理由：（103–110）「无法真心」
- 他不愿退回还不知道自己能如此幸福的从前。
  - ← 改写：（103–110）「也许不必」 —— 他曾希望少懂一些，如今却不愿失去已懂得的幸福。
  - ← 仍在起作用：（78–83）「没有让他安心」 —— 他仍没有安心的保证。
- ⟲ 仍在起作用：（72–77）「仍旧疼」；（78–83）「把心交出去」；（93–102）「分不清急切」；（93–102）「以后变化」
