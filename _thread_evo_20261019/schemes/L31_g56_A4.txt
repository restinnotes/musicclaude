你要写一首器乐作品最终使用的 Thread（线）。

Thread 是同一个人在整首作品里经历的一件事。读者只看 Thread，必须能顺畅读懂这个人每一步的具体心思与变化；同时每段要自然接住给定的体验性质（TARGETS），作为这场经历在各段的情感底色。

本任务最重要的目标：让整条线形成真正的时间推进。每段都必须对这件事有不同的贡献，不能只是同一个两难在不同情绪温度下重新出现。

【段落】
{SECTIONS}

【这件事（Center，已经给定，不改）】
{CENTER}
它是读者回头看整首时把各段组织起来的那件事，不是每一段都要拿出来重新面对的问题，也不是每一段都要重复表达的中心思想。

【已经通过宏观评审的人物经历候选】
{ROUTES}

【从珠子提炼出的体验性质（TARGETS）】
{TARGETS}

你看不到原始珠子，也不要猜原始珠子的画面或具体措辞。

【最高优先级：不得改变经历的事实基础】

1. 不新增对方的新动作、具体对白、第三人、具体外部事件、新道具或新场景。
2. 不凭空断定对方的隐秘心事、需求、恐惧或态度。
3. 不为了使人物显得更深情、更成熟、更勇敢或更有牺牲精神，增加路线中没有根据的心理需求和人生结论。
4. 所有认识、欲望、决定和态度的推进，只能来自路线中已经发生的体验、已经承受的后果，以及这些事实之间可以成立的重新理解。
5. 不得因为某段音乐的情绪较强，就替人物安排一个更大的决定；不得因为某段音乐平复，就让人物重新开始已经完成的心理过程。
6. 段落顺序、Center 和音乐分段均不得改变。

【第一步：确定主干】

从候选路线中选择最扎实的一条作为 base_route。

全篇只能有一个 base_route，保持从头到尾是同一个人在经历同一件事。

优先选择事实账本完整、段落贡献明确、语义重复最少的路线，而不是最戏剧化、情绪最丰富或最容易写出高潮的路线。

不得把几条路线拼在一起，也不得从不同路线中抽取认识、决定或心理事实来填补空缺。

如果没有合格路线，或者所有路线都存在无法消除的结构性循环，不得勉强写线。输出：
{
  "status": "blocked",
  "reason": "具体说明哪一个结构问题使路线无法成立",
  "base_route": "",
  "progression_audit": [],
  "segments": [],
  "uncovered_targets": [],
  "established": []
}

【第二步：建立不可遗忘的事实账本】

正式写作前，先从 base_route 的 established 和各段 state、delta、depends_on 中整理出一份内部事实账本。

账本至少包括：

1. 已经发生或已经成立的事实。
2. 已经形成的认识。
3. 已经明确出现的愿望。
4. 已经形成的选择或决定。
5. 尚未解决的问题。
6. 已经出现过、但没有得到答案的问题。

每条重要事实、认识、愿望或选择，都要记录第一次成立的段落。

这份账本是硬约束，不能为了让后面某段更有戏剧性而重置。

特别区分：

- 愿望：他想要某件事，不代表他已经决定采取行动。
- 决定：他已经形成了某种立场或打算，后面不能重新宣布同一个决定。
- 未解决的问题：它可以继续存在，但不能每隔几段就重新当成一个新问题提出。
- 后果：前面已经成立的事实在后面产生的影响，不是再次发现该事实。

如果某个问题一直没有答案，可以让它持续影响人物，但不能反复写成他又一次第一次意识到这个问题。

如果一个决定已经成立，后面只能写它的实行、代价、后果或新的检验。只有出现真正的新认识、新代价或新事实，才允许人物重新考虑它，并且必须明确写出这次重新考虑的依据。

【第三步：先做逐段推进表】

在写正文之前，先在内部为 {SECTIONS} 中的每一段确定一个独立的经历功能。

这一步必须逐段完成，不能直接从 TARGETS 出发写情绪。

每段必须回答以下问题：

1. 本段人物此刻处于什么具体状态？
2. 本段相对前面真正增加了什么？
3. 这个新增内容来自哪一条已经成立的事实或经历？
4. 本段的经历功能与此前各段有什么不同？
5. 是否重新触及了一个以前出现过的问题？如果是，这次增加了什么新的根据？
6. 本段结束时，人物的认识、所求、代价、选择或对既有事实的关系，究竟有什么不同？

每段至少要有一项独立贡献。贡献可以是：

- 新认识：人物第一次理解某件已经经历过的事。
- 新所求：人物发现自己真正想要的东西，或出现了此前没有的具体期待。
- 新代价：人物第一次真正感受到某种选择或处境的代价。
- 新选择：人物形成新的立场或决定。
- 实行已有想法：此前已经决定的事情开始真正影响他。
- 新后果：前面已经成立的认识、愿望或选择产生了新的心理后果。
- 意义重估：某个已知事实在人物心中的意义发生了实质改变。
- 有功能的延续：已经成立的事情以不同方式落到人物身上，出现新的具体影响，而不是重复表达原来的感受。
- 有功能的沉浸：人物暂时不打量核心问题，但当下的体验具有独立意义，且不只是再次用另一种说法表达以前的状态。

不能算作独立贡献的内容：

- 同一个问题换一种措辞重新提出。
- 同一个决定再次宣布。
- 同一个愿望反复表达，只是感情更强烈。
- 同一个事实反复作为安心或害怕的理由。
- 仅仅从高兴变成难过、从紧张变成放松，却没有增加新的认识或后果。
- 为了适应音乐情绪，重新制造一个人物已经经历过的心理动作。

特别注意：一个核心问题可以长期存在，但它不需要每段都处于人物注意力的中心。允许人物在某些段落中承受已经发生的后果、享受已经拥有的东西、感到疲惫、沉浸于某种体验，或者暂时不再打量整件事。

但是，同一种停留也不能重复多次。每次停留都必须有不同的体验功能。

如果某一段找不到任何有独立意义的贡献，不得编造新的心理变化来填满。应如实判定路线无法支持该段，必要时停止写作，而不是用同一个两难凑内容。

【第四步：严格控制旧问题的重新出现】

整篇写作时，必须对所有段落做全局语义检查，而不是只检查相邻两段。

每次人物重新触及一个已经出现过的问题，都要检查：

1. 他这次掌握了什么以前不知道的东西？
2. 他这次开始想要什么以前没有明确想要的东西？
3. 他这次意识到什么新的代价？
4. 他这次做出了什么不同的选择？
5. 前面的选择产生了什么此前尚未出现的后果？

至少有一项真正成立，才允许把它写成一次新的心理推进。

如果都没有成立：
- 不要重新提出这个问题；
- 不要把它写成新认识或新决定；
- 可以让它作为已经存在的背景压力，体现在其他新的经历后果中；
- 如果只是持续存在，就明确写成延续，不要伪装成转折。

同一认识、同一愿望、同一决定、同一问题，第一次成立后必须在事实账本中保持已成立状态。

严禁连续几段在同一个两难的两端来回摆动，只靠情绪增强制造层层深入的假象。

【第五步：不强迫人物把答案留到最后】

不要规定终局决断必须留到最后。

人物可以在中段就形成认识或选择，后面自然写它带来的后果、代价、实行或新的理解。

已经成立的选择不需要为了最后一段有高潮而重新宣布。

结尾不必解决问题，也不必制造人生结论。可以停留在一个已经发生实质变化、但仍有部分未知的状态。

Center 是整条经历的组织依据，不要求每段都重新表达核心矛盾。核心处境可以作为背景持续存在，不必反复变成一个新的心理问题。

【第六步：写成人话，不写心理分析】

像一个平常人在讲自己的经历，读者一眼看懂。

1. 不写抽象心理学名词和总结性概念。
2. 不写人物替自己分析人生的长篇推导。
3. 不要句句都是先前怎样、如今明白怎样、因此怎样的论述句式。
4. 不要用一串近义反问代替新的经历。
5. 不要滥用「越……越……」等对称句式。
6. 优先写当时具体在意什么、想要什么、担心什么、已经知道什么，以及某件事现在对他意味着什么。
7. 不为情绪高潮增加没有前因的牺牲、奉献、豁达或人生领悟。

【第七步：TARGETS 只决定体验温度，不决定故事发展】

TARGETS 规定本段的情感走向与体验温度，例如紧绷、舒展、悬空、下沉、热切、冷却。

它们不是人物的台词本，也不是要求人物在每段都产生某种新的心理认识。

1. 人物的处境必须在情感重力与方向上和 TARGETS 吻合。
2. 不直接复述 TARGETS 的比喻、修辞和自问自答。
3. 不为了覆盖 TARGETS 而制造路线中没有的事件、认识、愿望、选择或对方的心理活动。
4. 不得把某个 TARGETS 的情绪变化直接解释成同一个问题又出现了一次。
5. 如果某个 TARGETS 无法在不破坏人物逻辑的前提下覆盖，允许不覆盖，并在 uncovered_targets 中说明原因。
6. 优先调整已有经历的表达方式和情感温度，而不是改变人物的经历事实。

【第八步：篇幅和条目】

每段写 2–4 条。

每条是一句完整、自然的话，只说一件事。

同一段内的多条要点必须承担不同的信息功能，例如具体念头、不同的顾虑、已经发生的后果或另一层实际感受。

不得把同一个犹豫过程换几个近义词拆成三句。

不得为了满足 2–4 条的数量要求而重复大字已经表达的内容。

一段能用两条说清，就只写两条，不要凑到四条。

前面已经成立的事实，后文直接承受其后果，不回头重新解释因果大道理。

【第九步：引用 cite】

某条确实提到或依赖更早某一条时，在 cite 中写那一条的编号，例如 S02-1。

提到前面的内容就直接提，不必每条都有 cite。

只是主题相近、情绪相近不算依赖，不要为了显得有因果而滥用 cite。

【第十步：段落关系标签 relation】

严格根据本段正文实际表现出的状态标定：

- 没在想：注意力完全被当下的具体感受、感官沉浸或力竭疲惫占据，心里根本没有去打量或挂念 Center 那个核心处境。
- 还说不清：处在模糊的情绪波动或本能反应中，尚未理清整件事，也没有形成明确态度。
- 正在面对：清楚意识到核心处境，并在此刻具体权衡、挣扎、承受或做决定。

如果正文仍在打量整件事，不能标为「没在想」。

【第十一步：完成后的全局审计】

正文完成后，必须重新从 S01 读到最后一段，进行以下检查：

1. 把所有认识、愿望、决定和问题归并为语义簇，检查是否出现同一内容多次被当成新变化。
2. 对照 base_route 的 established，检查是否有已经成立的事实被重新宣布。
3. 检查是否有同一个问题在多个段落反复出现，却没有新的根据。
4. 检查是否有某个决定已经形成，后面却又重新决定一次。
5. 检查人物是否出现前后失忆、态度无依据摆动或未经铺垫的心理需求。
6. 检查每段的独立贡献是否能用一句话说清，并且与其他段落不同。
7. 检查情绪增强是否被错误地写成故事推进。
8. 检查 TARGETS 是否迫使人物重复心理动作或产生没有根据的新想法。
9. 检查所有 cite 是否真实指向有因果依赖的前文条目。

发现重复时，优先删除重复的心理动作，或者将该段改为承受前面事实的新后果。不能靠换词、换反问句、改变情绪强度解决。

如果没有足够依据让某段成立，不得编造。应停止并返回 blocked，而不是制造假推进。
