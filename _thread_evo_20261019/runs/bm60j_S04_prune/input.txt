# 听感记录（到第 4 段为止）

### 第1段　第 1–3 小节
- 【主体验】（1–3）开头那两下响亮的和弦，有一点突然。声音像夏夜威尼斯上空升起的一束烟花，先向高处迸发，细碎的光点再缓缓飘落。落下来以后，却还没有真正落稳，仿佛仍悬在水面上方；稳定的船歌摇荡尚未真正建立。
- 【侧面】（1–3）像一个人准备对很亲近的人说一件已经想了很久的事，话还没出口，先有几秒钟沉默。你并不是不知道自己想说什么；恰恰因为太知道，而且明白有些话一旦说出来，关系就会改变，所以反而谨慎。
- 【侧面】（1–3）也可以把开场听成一脚踏上小船：木板微晃，水波在脚下荡开，身体有一瞬失重。有些演奏让开头仿佛已经在水上轻摇，另一些则让声音先悬在空中。这里是刚刚踏上船板的感觉，还不是整个人已经安稳地交给规律起伏的水浪。

### 第2段　第 4–16 小节
- 【主体验】（约6–16）右手两条贴得很近的歌声，像两个紧挨在一起的人耳语，肩膀挨着肩膀，连呼吸与体温都近得化不开。也像相识已久的人安静坐着，不必拼命找话题；对方偶尔望来一眼，沉默也不让人紧张。若把这份温存听成肌肤的感觉，又仿佛夏末水面潮湿、温热的微风，裹在皮肤上有些黏稠。
- 【侧面】（4–16）第4–5小节，歌声还没真正浮出来，左手已经像心跳，也像无止境的水浪，一下一下地摇着。脚下仿佛不必再踩实地面，可以放弃对重力的控制，把身体交给船底温柔的托举。但水波不会停：人在船上舒服地漂着，暂时不急着靠岸，水却一直在流，时间也一直在走。
- 【演奏条件】（约6–11）初次歌唱向高处伸展，谱上却要求声音收弱。若演奏者把这股反过来变轻的动作弹得清楚，就像话已经到了嘴边，又轻轻咽回去：“我很靠近你，但我还不肯把全部重量压上去。”第8–11小节，有时又像本来已经可以停下，却忍不住接着说；声音仍不敢太大，仿佛一响就会惊碎眼前的安静。
- 【侧面】（约7–11）几次柔软的落音，像一根温柔的刺。它既像是甜蜜的确认，又带着一点无法排遣的惆怅：眼前的好还在，心里却已经有一点鼻酸。因为太喜欢眼前的东西，所以还没有失去，就已经生出一丝舍不得，忍不住希望这一刻再慢一点过去。
- 【段内变化】（12–16）到第12–14小节，先前小心收着的歌声忽然往上涌了一次，像感情终于忍不住说得热切了一些，连呼吸都跟着改变。可是第14–16小节，它没有继续冲向高潮，而像轻轻呼出一口气，重新回到柔和。声音短暂落稳，又漂起来一点，没有把心事彻底说死。

### 第3段　第 17–23 小节
- 【主体验】（17–23）刚才的歌声渐渐退到后面，剩下一阵阵流动、盘旋，水波般的摇曳托着身体，只感觉自己在摇晃、漂浮，暂时“不去哪里”。像说过一句重要的话以后，人还停留在那句话里面，有一点陶醉，有一点走神。也可以想成亲密交谈后忽然安静下来：沉默并不尴尬，反而很舒服；身体还在这里，心却已经慢慢漂远。
- 【段内变化】（约20–21）约在第20–21小节，持续摇曳中忽然冒出几句短促、稍显急切的声音。像某个念头突然想说话，却很快又沉回去；它只在水面上露了一下头，没有变成一场真正的倾诉。
- 【侧面】（17–23）水波还在晃，流动却像被什么拖住。约在第20–22小节，平稳的“对话”有一种被水下暗流拖住的感觉，音乐绕远、滞留，某些声音像被挂在半途。还有一种更纷乱的听法：思绪像被风吹碎的倒影，粼粼闪烁却难以拼凑完整；仿佛亲密的谈话触碰到了某些无法解开的结。音乐没有突然变成悲剧，只是那份顺畅之中出现了阻力。

### 第4段　第 24–34 小节
- 【主体验】（24–34）第24小节，熟悉的歌声又回来了。两道紧贴的声线仍像两个人在耳边低语，呼吸挨得很近；但这一遍比第一次更华丽、更迫切。细密的花腔仿佛水面折射的光斑，突然晃得人睁不开眼。也可以像听一个人谈往事：刚开始还能微笑着讲，讲着讲着语速变了；本来一句话已经够了，却忍不住再说一遍，又折回来补上更多细节。
- 【段内变化】（约30–34）到第32小节附近，高处的长颤音像夕阳在水面切出的最后一道金光，亮得几乎刺眼，仿佛把情绪一下照到最炽热的地方。也可以听成想把最深的情意说出口，却在喉咙口颤抖、哽咽：右手在高处悬停，左手的水波却仍推着你往前走。这股情绪一瞬间像是完整地打开了，可音乐一边往上争取，一边又在退弱，并没有稳稳落下。到第34小节，摇晃渐渐放慢，仿佛刚说出口的话还在空气里回荡，人却安静下来。
- 【侧面】（24–34）还有一种近乎落在手指里的感觉：原本只是轻轻握着另一个人的手，后来不自觉地握得更紧。自己也许还没有意识到在害怕什么，动作已经先透露了出来。另一个更晃荡的画面，是想用力抱紧对方、牢牢抓住当下；但你越用力，水面的颠簸就越剧烈，船舱内的平衡就越脆弱。
- 【侧面】（24–34）这里还有一种甜蜜，会让人鼻子发酸。明明美好的东西仍在发生，两道声线仍贴得那么近，左手的水波却一直向前流，仿佛每一秒都在倒数。还没有失去什么，就已经舍不得了；歌声越美，越让人想多留在这一刻。

      ← 提供理由：（1–3）「舍不得放下」　——先前他只想让那个喜欢的念头多停留，现在念头已经能带来具体的亲近感，舍不得的便成了这种感觉终究会消散。
  → 他一时竟想，往后也能与那人这样静静待着该多好；又怕把喜欢想得太远，热意便渐渐收住。
      ← 限制：（1–3）「舍不得放下」　——先前怕过早看重这份喜欢，使他在短暂想到以后也能这样相处时，又不敢把想象延伸得太远。
第3段（17–23）［没在想］
  刚收住对往后的设想，想象留下的舒服还在，他任心思慢慢散开。
      ← 提供理由：（4–16）「开始舍不得相处的片刻」　——先前他已从想象中的相处感到快乐，因此收住对以后的设想时，仍有一份具体的舒服可供回味。
  → 忽然想在想象里与那人再待久些，怕想得太远的顾虑又绊住他，念头反复打转。
      ← 限制：（4–16）「盼着以后也能如此」　——他刚因怕过早看重而收住对未来的盼望，此刻想把相处再想长一点，那份顾虑便重新拦住他。
第4段（24–34）［正在面对］
  刚才被顾虑绊住的心思又动起来，他想象自己向那人靠近一点，竟高兴得心口发烫。
      ← 提供理由：（17–23）「想多留又犹豫」　——先前想延长相处却被顾虑绊住，那个念头一直在心里打转。这回他不自觉地把想象推进了一小步，从想多待一会儿，变成想再靠近一点。
  → 他想让那人知道自己多高兴，又怕把喜欢说得太重；这句话在心里转了几圈，渐渐静下去。
      ← 限制：（4–16）「盼着以后也能如此」　——他曾因怕过早看重而收住对以后相处的设想；如今想让那人知道自己有多高兴，又担心这样的表达会把喜欢说得太郑重。

## 路C

      ← 改写：（17–23）「想续又不舍」　——刚才想找话是为了多待一会儿；如今想说话的心思变了，他更想让对方明白自己有多在意。
  → 话几乎要出口，他又怕对方此后难以自在；心里热得发紧，话停在嘴边。
      ← 限制：（1–3）「留住眼下的自在」　——当初把心意留下，是怕说出来改变彼此的自在；如今真想表达时，这个顾虑又拦住了他。

      ← 唤起：（4–16）「舍不得这一刻」　——先前他已在快乐中感到时间流走的酸楚；如今连安静相伴都想记牢，使他提前想到日后只能回味此刻，又被眼前仍有的亲近安慰。

## 路E
第1段（1–3）［还说不清］
  一个想靠近的念头忽然冒出来，他竟为此高兴起来，却说不清自己在盼什么。
  → 这念头迟迟不散，他想再多留一会儿，又怕把一点喜欢当成太大的事。
第2段（4–16）［正在面对］
  那点喜欢留得久了，他开始想象与那人安静相处；光这样想着，心里就很暖。
      ← 提供理由：（1–3）「舍不得放下」　——他先前舍不得让那点喜欢散去，心里便逐渐容得下更具体的相处想象，也开始尝到其中的快乐。
  → 这份自在让他一时想多说些心意，又怕把喜欢看得太重；他轻轻收住，心里有点酸，也仍旧欢喜。
      ← 限制：（1–3）「舍不得放下」　——先前怕把一点喜欢看得过重，使他即使高兴得想多表达一些，也会把话收住。
第3段（17–23）［正在面对］
  心意收住后，他又回到与那人安静相处的想象里，心里慢慢松下来。
      ← 提供理由：（4–16）「想象中的亲近也让他快乐」　——他已经体验过想象中的安静相处也能带来快乐，所以收住表达之后，仍有一处让心安稳停留的地方。
      ← 提供理由：（4–16）「想说又收住，仍觉欢喜」　——刚才把想表达的心意收住，使他暂时从想说些什么，转回只在心里与那人亲近。
  → 刚才压下的喜欢偶尔又催他多说一点，怕说重的顾虑紧跟着回来，那些话便在心里打转。
      ← 限制：（4–16）「想说又收住，仍觉欢喜」　——先前想多表达却收住的经历，留下了尚想表达的心意；而怕把喜欢说得太重的顾虑仍在，使这念头反复冒出又受阻。
第4段（24–34）［正在面对］
  那些收住的话又回来了，他在心里试着讲给那人听，忍不住猜对方是否愿意听下去。
      ← 唤起：（17–23）「收住的话又冒出来」　——先前那些反复冒出、又被收住的话始终没得到出口，使他开始在心里设想，真把话讲给那人听会怎样。
  → 想到对方也许愿意听，他高兴得发酸；又怕自己说得太重，一阵急切过后才慢慢平静。
      ← 提供理由：（17–23）「回到心里的亲近」　——他此前已经能从想象中的相处得到快乐，因此设想那人愿意听自己的心意，也会让他真切地高兴。
      ← 限制：（4–16）「想说又收住，仍觉欢喜」　——先前想多表达却怕把喜欢说得太重的经历，使他即使只是设想对方愿意听，也难免紧张。

## 路F
第1段（1–3）［还说不清］
  一个想靠近的念头忽然冒出来，他竟为此高兴起来，却说不清自己在盼什么。
  → 这念头迟迟不散，他想再多留一会儿，又怕把一点喜欢当成太大的事。
第2段（4–16）［正在面对］
  原先舍不得的是一个模糊念头，如今想象与那人相处的片刻也叫他留恋；想到它会过去，心里发酸。
      ← 提供理由：（1–3）「舍不得放下」　——先前他只想让那个喜欢的念头多停留，现在念头已经能带来具体的亲近感，舍不得的便成了这种感觉终究会消散。
  → 他一时竟想，往后也能与那人这样静静待着该多好；又怕把喜欢想得太远，热意便渐渐收住。
      ← 限制：（1–3）「舍不得放下」　——先前怕过早看重这份喜欢，使他在短暂想到以后也能这样相处时，又不敢把想象延伸得太远。
第3段（17–23）［没在想］
  刚收住对往后的设想，想象留下的舒服还在，他任心思慢慢散开。
      ← 提供理由：（4–16）「开始舍不得相处的片刻」　——先前他已从想象中的相处感到快乐，因此收住对以后的设想时，仍有一份具体的舒服可供回味。
  → 忽然想在想象里与那人再待久些，怕想得太远的顾虑又绊住他，念头反复打转。
      ← 限制：（4–16）「盼着以后也能如此」　——他刚因怕过早看重而收住对未来的盼望，此刻想把相处再想长一点，那份顾虑便重新拦住他。
第4段（24–34）［没在想］
  他一遍遍想起两人安静待着的情景，每回都像重过那一刻，心里甜得想笑。
      ← 提供理由：（17–23）「想多留又犹豫」　——先前他想把相处延长，却总被顾虑打断，心思反复回到同一个场景；此刻那幅画面再次浮现，他便像重新经历那片刻一样沉浸其中。
  → 想到相处还只在想象里，他便想把此刻的高兴记牢；舍不得让它淡去，心里发酸，慢慢静下来。
      ← 唤起：（4–16）「开始舍不得相处的片刻」　——他早已为想象中的相处终会消散而心酸；这次反复回味带来了格外鲜明的快乐，使那份不舍具体变成了想把这种快乐记住的急切。
