| S01 | 新版：X把开头的恍惚落在“在乎的东西受伤—不管等于认了—真去管又怕顾不上别的”这组尚未理清的牵扯上，比Y的“珍贵、投入、回头余地”更能解释为什么此刻既想动又悬着。 | 差不多：两版都是三步冲突，没有明显多出的心理环节，Y稍整齐而X稍直接，压缩程度基本相当。 | 新版：“看着在乎的东西继续受伤害”“顾不上别的重要事”“以后再也补不回来”更像人在说自己的具体顾虑，Y的“珍惜、投入、珍贵东西、回头余地”更书面。 |
| S02 | 新版：X用“出力做事就让他高兴”“不满有了地方使”“怕忙到最后白费就催自己”把昂扬、焦灼和自我驱赶接成了一条具体原因链，更能给珠子里的挺直和负隅顽抗提供来路。 | 新版：Y连续用“投入”统摄不同心理动作，反而把接事、出力、忙得顾不上和自催压成同一个抽象词，X区分得更清楚而没有多绕一步。 | 新版：“心里的不满有了地方使”“直催自己别退”比“付出本身”“另一份牵挂”“一再催自己”更口语、更像当事人在讲自己。 |
| S03 | 差不多：两版都完整保留了做过以后可以暂歇、仍惦记另一种生活、又开始怀疑此前干劲这三层，因此对珠子里短暂松动、温柔向往和自问的解释力相近。 | 差不多：两版几乎是一一对应的改写，都没有明显多余的拆分或新增因果。 | 新版：“放心歇口气”“跟人放心来往、不用互相防着”比Y的“背弃决定”“自在亲近、不必防备”更接近日常自述。 |
| S04 | b0：Y的“舍不得否认行动曾让自己走出犹豫”接住了S03已经出现的怀疑，同时“反复追问还能怎样做”也更准确地解释珠子里温暖之后忽然停不下来的自问。 | b0：Y把这一段收成“舍不得否认—不敢停—反复追问”三步，较少X里“做得不够、怕劲散、还能做什么”之间略显重复的自我加码。 | 新版：X的“怕一停手，就得承认自己还是过不上想要的日子”和“那股劲散了”比Y的“面对自己”“留住那份决心”更像一个人的原话。 |
| S05 | b0：Y把先前曾带来骄傲的坚定写成如今反过来苛责自己的东西，更清楚说明为什么这一段会从继续硬撑转向柔下来承认真正舍不得的亲近。 | b0：Y用“坚定成了苛责”一次交代旧力量的变质，比X的“逼自己硬撑、越撑越苦”少一层同义重复。 | 新版：X的“觉得做得还不够”“拿当初不肯退的劲头逼自己”“跟人放心来往”都比Y的“行动还不够”“坚定成了苛责”“不必防备的亲近”更具体自然。 |
| S06 | b0：Y除了承接“不必防备”的旧梦，还写出“不急着辩护”“不用处处用力”“舍不得离开”，更能解释珠子里暂时卸下坚强姿态、让愿望和委屈自行浮现的安静。 | 差不多：X较直白但四条都在展开同一种好日子的不同面向，Y也有“喜欢、依恋、亲近、爱惜、不舍”的多次回环，二者都没有明显可以整块删掉的环节。 | 新版：“真正快活的日子”“痛痛快快去喜欢、去惦记”“跟人跟事都能踏实相处”比Y的“任由依恋留着”“亲近生活”“爱惜”更像具体生活经验。 |
| S07 | 新版：X把重新争取的危险具体落到“会不会把真心待人和体谅人的心意磨没”，因此既解释了突然被现实拽回，也解释了随后为什么会持续紧张而不敢像第一次那样猛干。 | b0：Y用“那种生活需要的温柔”压缩了X较长的“真心待人和体谅人的心意”，并把第三条收得更紧，结构上更省。 | 新版：“光靠心里想念根本保不住”“只顾硬拼”“把体谅人的心意磨没”都比Y的“失去所爱”“温柔耗掉”更像人在说实际担心。 |
| S08 | b0：Y把这次短暂回返写成“曾让他满足的亲近正在消退而他舍不得推开”，更贴近珠子里刚重新认出柔软处就又要离开的短促不舍。 | 新版：X两句已经交代回去、消散和舍不得，Y第二句又用“舍不得、只管喜欢、任由不舍”连续复述同一依恋动作。 | 新版：“只想多留恋一会儿”“怎么也舍不得放手，心里全是惦记”比Y的“沉在满足的亲近里”“任由不舍留在心里”更口语。 |
| S09 | 新版：X既保留开头问题原样回来，又让这次回返多出一个明确的新认识——难下决心正因为想保住能信人、亲近人的日子——最能解释珠子所说的“同一个自己，但已经知道他经历过什么”。 | 新版：Y额外加入“怕担责任”这一此前没有铺垫的动机，不但多了一环，还把本来已经清楚的原因变成两个并列原因。 | 新版：“拿不准该怎么做事”“真心想保住那种能信人、亲近人的日子”比Y的“回到起初的迟疑”“不只是怕担责任”更直接。 |
| S10 | 新版：X把此刻的疲惫明确追到前面“逼自己逼得太狠”，同时保留行动的痛快和心里踏实两样都舍不得，因此更能解释珠子里走过很多以后仍悬着、又无力完整重来的状态。 | 差不多：两版都是疲惫、现实未解、允许暂歇三步，长度和心理环节基本一致。 | 新版：“之前逼太狠”“没劲去争”“干事的痛快和心里的踏实”比Y的“尽力得太狠”“昂扬和安宁”具体得多。 |
| S11 | 新版：X很清楚地把两个已经亲自试过的失败摆在一起——闷头干会漏掉牵挂、只求踏实又护不住东西——所以“害怕还在但继续做”不是突然振作，而是前面经验逼出的选择。 | 新版：X用两个具体失败直接推出“重新盘算能做什么”，Y改成“力量、全部牵挂、安宁、承担”等概念后并没有减少步骤，反而需要读者再翻译一遍。 | 新版：“只顾闷头干”“漏掉惦记的事”“重新盘算自己能做点什么”“接着做事”明显比Y的“尽力、安宁、承担”更像日常叙述。 |
| S12 | 新版：X既让他接受做事会有损失和害怕，又保留“心软”与“出力不一定能改变多少”这两项具体认识，因此能同时解释主题昂扬回来和249–253仍会短暂斜一下的迟疑。 | 新版：Y把有限的现实判断改成“不要求每一分努力都能改变一切”，无端引入了一个更极端的旧要求，反而多造出一层没有铺垫的心理前提。 | 新版：“不嫌自己害怕心软”“能做多少就先做多少”“出力不一定能改变多少”都比Y的“脆弱当成阻碍”“没有代价的路”“改变一切”更朴素。 |
| S13 | 新版：X把高潮后的整合写成“继续做、可以歇、别把体谅心磨掉、最后仍不知道能保住多少”，既给强大的前进感理由，也保住珠子末尾那一点没有被胜利抹平的不确定。 | b0：Y把“吃苦但不拼命证明—做一程肯歇—免得耗尽温柔”收得更紧，末条也少了X连续出现的“也、还、那种好日子、在乎的”等重复。 | 新版：“干一阵就歇口气”“把待人的体谅心磨没了”“不知道在乎的最后能保住多少”比Y的“耗尽温柔”“愿意去爱那种生活”“能留下多少”更具体。 |
