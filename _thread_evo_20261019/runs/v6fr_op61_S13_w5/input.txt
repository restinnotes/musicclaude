下面是肖邦《幻想波兰舞曲》Op.61的一条 Thread（关系图，叫 v6）。我们在 v6 的基础上逐段修补，前面的段已经修好，现在修 S13（第 254–288 小节）。

Thread 是什么：一个人在这首曲子里经历的一件事。每一段要让人看见他此刻为什么会这样，理由来自他前面真实经历过、相信过、发现过的东西，而不是音乐忽然发生了什么。珠子是另一批人听这段音乐写下的听感，写的是此刻听到、感到的具体样子，会和线并排展示；线不用把珠子再描写一遍，而是给这些感受一个“为什么偏偏此刻会这样”的理由。
关系图的写法：每段先标他和 Center 的关系（还说不清 / 正在面对 / 没在想）；条目前的 → 表示由上一条引出；← 是跨段箭头，指回前面某段的某一条（提供理由、说明、限制、动摇、唤起、改写、失效）；⟲ 是前面仍在起作用的东西。

这次修补只解决三个问题：
1. 覆盖不足：这一段珠子里的感受（主体验、段内变化，以及和它们同时成立的另一侧面），线要给出他此刻为什么会这样；理由和珠子对不上的要改。
2. 啰嗦废话：一个意思拆成几条、翻来覆去说同一件事、没有必要的心理环节、不成立的因果。
3. 不说人话：抽象、像哲理总结、工整对照、作者替他宣布领悟、只说他没做什么。
v6 已经成立的好内容不能丢：整体走向、已经说清的心理事实和前后关系都要留下，可以改写、合并，但意思不能丢、不能变弱；只有换成更有解释力的说法时才可以去掉，并在 changes 里说明。和珠子对不上的解释不算好内容，要改。

要求：
- 覆盖：主体验、段内变化里的每一种感受，都要能从这一段的条目里看出他此刻为什么会这样。线的作用不是把感受写得更细——细节由珠子并排展示，线只给原因；所以不要把珠子的描写搬进线里。一条原因常常能同时解释好几颗珠子，不要为每颗珠子各加一条。同时存在的几种感受可以写在同一条里，不要硬排成先后发生的几件事。真正解释不了的写进 gaps，不要硬补。另一种理解（和主体验不能同时成立的听法）不必解释。
- 精简：一条只说一个别的条目没说过的意思，包括前面各段已经说过的——前面说过的原因不要再说一遍，此刻还在起作用就用 ← 指回去；几条其实是同一个念头就合成一条；删掉也不损失意思的就删。条数跟这一段真正发生了多少相称，没多少事就写一两条；修补后的条数一般不多于 v6 这一段，除非 v6 确实漏掉了这一段的主体验。不强求每段都有新的领悟、办法或转折，不写“试一个办法—不管用—换一个办法”。全曲一直成立的背景（他在乎、对方心意未知、时间在走之类）不能单独当此刻的原因，要说出它此刻因为前面哪一步变了才起了新作用。关键转折写出具体前因，不用“越……越……”“更……了”顶替。
- 人话：直接写他具体在想什么、怕什么、想要什么。不把心情说成一样东西（“这份……”“一种……”），不写听着深刻的总结句，不写整整齐齐的“前半句；后半句”对照，不由作者替他宣布“他终于明白”“他才看清”；但他想明白的东西本身（分清了两件事、发现某个办法管不了什么、对自己的新认识）是内容，不能因此删掉：保留这个认识，用他自己的平常话说出来，并让人看出是前面哪段经历让他想到的；前文没有经历撑着的，不要把无奈写成高尚、坚定的选择。只说他没做什么的空否定，改成说他在做什么（说出变化的“不再……”可以留）。一条只放一个意思，不用分号把两三件事串在一起；每条一般不超过 45 字，但不要为了字数把一个意思拆成几条。
- 边界：不新增前史、往事、身份、外部事件、对白、具体的人物关系或场景；珠子里的比喻——地点、人物、往事画面，以及处境、动作、对白（例如“像要对很亲近的人说一件想了很久的事”“握紧另一个人的手”“像一幕旧场景回来”）——只说明感受像什么，不能写成他真的在做、真的要做或真的想起的事；可以取其中的心理，不取那件事本身；不把音乐本身的变化当成心理原因。可以补一座接在前面已确立内容上的局部心理过程（身体先于念头、刚才的什么让此刻变了）。正文不写小节号、编号、音乐术语，也不写对修改的说明。
- 形式同 v6：relation 是这一段他和 Center 的关系（还说不清 / 正在面对 / 没在想），一般沿用 v6；follows: true 表示由这一段上一条引出（画成 →）；because 是跨段箭头，from 只能写【前面已经修好的段】里的条目编号，rel 取 提供理由、说明、限制、动摇、唤起、改写、失效、仍在起作用，只连真正的前因，主题相近不算。key 是两到八个字，取自这一条的原文，后面的箭头用它指代这一条。explains 写这一条给出原因的珠子编号。Center 不改。

【Center】向外行动与旧梦都要求投入，却彼此牵制。

【这一段的珠子】
- B1［主体验］（254–270（主题回归主要在254–268，密集音符的喷涌延续至约270））先前像私下安慰、近乎祈祷的柔软歌唱重新出现，却被带进开阔、宏大的音响里，像一支温柔的歌忽然站到了明亮处，甚至有如管风琴般庄严庞大。密集的音符又像狂飙的激流向天空喷涌，仿佛一颗心脏以最高负荷跳动；柔软并没有被力量压下去，而是也被带进了高潮。这份公开的气势，还可以让人想到故土、共同记忆和希望，但不必把它听成某个具体胜利的宣告。
- B2［段内变化］（269–280）约第269小节，钢琴展开快速、炫目的八度进行，明亮、迅疾的音型向前冲出，把积累的能量一下子释放出来。这里的身体感不再只是前一刻的宏大歌唱，更像被一股气流推着往前跑，兴奋得几乎来不及喘息。
- B3［段内变化］（281–287（颤动带来的不安主要在281–285））但这股冲势没有一直持续。约第281–285小节，音乐收敛下来，颤动般的装饰音重新带来一点不安，仿佛刚刚建立的成功又被轻轻问了一句：它真的已经牢固了吗？同一段回落也可以听成事情已经说完、终于能停下来喘口气。从容与细微的不安不必互相排斥，平静也不一定意味着疑问已经消失。
- B4［段内变化］（末尾几小节（低音和弦至第288小节的最后高音和弦））狂潮退去，喧嚣像骤然静止。低音区像呼出最后一口气，沉沉吐出两记耳语般的和弦；随后，钢琴最顶端忽然亮起一记清脆、透明、孤悬如寒星的高音和弦，像一声清脆的钟响。低处的轻声与高处的亮光形成鲜明反差，结尾的力量不必只靠更猛烈的敲击。
- B5［另一种理解］（286–288）最后的高音和弦可以听作一个决定，也可以听作一个人忽然从梦中醒来。前一种听法更像意志终于落定，后一种更像从梦境中骤然清醒；它们是对同一记声音的两种理解，不是先后发生的两件事。
珠子之间：B1 与 B2：段内先后；B2 与 B3：段内先后；B3 与 B4：段内先后；B4 与 B5：可同时成立

评审甲：
- 值得保留 R65：带着全部牵挂重新向前后，旧日愿望反而变得更亲近；这说明愿望不再只是行动的对立面，而可能成为行动的理由。
- 值得保留 R66、R67、R68：他以前以为退回安宁才能保护旧愿，如今发现任由威胁它的事继续存在，也可能失去它；因此珍惜有时要求他离开安宁去行动，这是全曲最关键的关系改写。
- 值得保留 R69：他不再把投入更多当成必然接近愿望的保证，也不再把愿望本身当作努力必然值得的证明；珍惜之物可能被行动耗损，因此需要考虑如何坚持，而不只是坚持多少。
- 值得保留 R70、R71：行动与旧愿开始能够共同推动他，而不是必须互相压制；他也不必因为承担责任就羞愧于自己的依恋，这是从两难走向有限整合的实质变化。
- 值得保留 R72、R73、R74：最初的生活向往重新带来快乐，但行动是否有效、能否回到无须防备的生活都没有保证，未来仍可能因代价而动摇；整合不是冲突彻底消失。
- 值得保留 R75、R76：他不再用一种满足遮住另一种需要，也不再因愿望未成而否定已经得到的东西；由此形成更具体的衡量方式，知道什么值得付出、什么不应在付出时轻易丢掉。
- 值得保留 R77、R78：他仍不知道最终能保住多少珍贵的东西，但不愿靠遗忘任一边来换取安稳，也不再要求自己先找出更多证明才向前；结尾保留了真实的不确定性。
- 珠子 B1：说清。R65至R72把旧日愿望重新带进向前行动的高潮，解释了柔软与宏大为何可以同时出现，也保留了这份昂扬不是某个具体胜利宣告的可能。
- 珠子 B2：说清。R68和R70说明珍惜之物本身能够推动他向前，能解释高潮中能量释放、向前冲出的心理动力，而不是只把它写成盲目的亢奋。
- 珠子 B3：说清。R73和R74明确保留了愿望未必实现、行动仍可能付出代价以及未来仍会动摇的事实，能解释昂扬之后细微的不安为何没有被彻底消除。
- 珠子 B4：没有。R73至R78虽然保留了结局的不确定性，却没有对应末尾低音区轻声退去、最后高音和弦孤悬显现的具体心理变化，因此无法解释这一声音反差。
- 啰嗦 R70、R72：两条都写喜悦重新出现，R70强调两种心意共同推动行动，R72强调旧日相信生活的快乐重新变得可感；可以合并重复的喜悦措辞，但应保留动力整合与情感回返的区别。
- 啰嗦 R73、R74：两条都限制了整合的完满程度，但R73说的是现实尚未改变，R74说的是未来仍有代价和冲突；二者不能互相替代，只需避免都以抽象的反向总结收尾。
- 啰嗦 R75、R76：R75说不再用一种满足否定另一种需要，R76把这个认识转化成哪些值得付出、哪些不能轻易丢掉的衡量方式；可以合并重复的价值判断，保留从态度到实际取舍的推进。
