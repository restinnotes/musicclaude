# Op.61｜关系图（v6 修补 r3）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他心里有股劲催着自己别停，却说不清自己在等什么、为何不安，念头还没跟上身体的反应。
- → 他想保住自尊，可真投进去又怕会失去别的东西，心里也想停下来喘口气。
- → 他忽然觉得熟悉，便本能地想往前，身体仿佛还记得怎么走，却回不到从前。
- → 他想找个让自己敢走的理由，可每回快要说服自己，舍不得又冒出来，连刚才还觉得已经想通的事也忽然变得陌生，他又为非得想清才肯走而难堪。

### S02｜24–65 小节　（正在面对）

- 他还是没想明白，却不愿再把日子耗在等答案上，先接下眼前能做的事。
  - ← 改写：（1–23）「变得陌生」
- → 他不甘心被失落压垮，动起来后有了些底气，也为自己还能往前而骄傲，却仍不知道最后会怎样。
- 他仍惦记着那些珍惜的东西，却已不能像从前那样拥有，眼下承担的事也顾不上它们。
  - ← 说明：（1–23）「身体记得怎么走」
- → 他怕一承认难过就撑不住，只好一遍遍压住难过，越压越难说服自己还能撑住，越逼自己往前越喘不过气。

### S03｜66–91 小节　（没在想）

- 他不甘心停下，却放不下那些珍惜的东西，连该往哪边使劲都定不下来。
  - ← 提供理由：（24–65）「不能像从前那样」
- → 他惦记的那些东西，连着他想亲近、安心过日子的愿望。
- → 他暂时只顾眼前能做的事，松快了一会儿。可向往的日子还没过上，当初那个决定又压回心头，他得重新面对它。

### S04｜92–115 小节　（正在面对）

- 他仍愿意坚持那个决定，因为它确实让他从犹豫里动了起来。
  - ← 唤起：（66–91）「压回心头」
  - ← 提供理由：（24–65）「接下眼前能做的事」
- 他确实感到过亲近和欢喜，不愿说那只是自己安慰自己。
- → 那阵温暖让他舍不得放下亲近安稳的盼望，却也怕自己终究得不到。
- → 他反复追问还能怎么补，好像只要脑子不停，就不必承认自己有多难受。
- → 他还逼自己继续往前，却发现光靠行动过不上想要的亲近、安稳日子。
- ⟲ 仍在起作用：（24–65）「不能像从前那样」；（24–65）「越难说服自己」

### S05｜116–147 小节　（正在面对）

- 他还拿那个决定逼自己向前，怕一停又退回等待，可曾尝到的亲近与欢喜让他舍不得放下。
  - ← 提供理由：（92–115）「从犹豫里动了起来」
- → 一难受，他就认定是自己又在退缩，非得把这股难受压过去才肯停。
- → 他拿当初的决心逼自己不许示弱，连疲惫都当成不争气。
- → 他看见自己已经累得撑不住，还在逼自己硬撑，终于不愿再证明自己能扛。
- → 他松开对自己的逼迫，心里仍没踏实，却终于肯承认自己舍不得。
- → 他一时也不知道该怎么办，只知道自己想过上亲近、安心的日子。

### S06｜148–180 小节　（没在想）

- 他舍不得的，是曾经真心相信过的那种生活。
  - ← 提供理由：（92–115）「亲近和欢喜」
- → 他想和人亲近时不用提防，珍惜的东西也不用靠争抢才能留住。
- 他盼着被爱、被接纳时不用证明自己够好，付出只因喜欢。
- 他不再因仍盼着这样的生活而羞愧。
- → 他暂时不再追着自己问个明白。
  - ← 提供理由：（116–147）「承认舍不得」
- → 他压了很久的渴望渐渐涌上来，心里满足起来，也没那么绷着了。
- → 他心里安稳下来，先前的疲惫暂时退远。

### S07｜181–205 小节　（正在面对）

- 他刚尝到亲近安稳的满足，向往的日子忽然显得熟悉而具体。眼下却过不上，落差猛地撞来，身体先绷紧了。
  - ← 唤起：（148–180）「渴望渐渐涌上来」
- → 他这才想到自己刚把还没解决的事搁到脑后，心里有些懊恼。
- → 他当初不肯再等，是不想看着珍惜的东西继续受损，光在心里怀念也护不住它们。
  - ← 唤起：（24–65）「接下眼前能做的事」
  - ← 提供理由：（24–65）「不能像从前那样」
- → 他想重新振作，却已不能像从前那样毫无顾忌地投入。
  - ← 限制：（116–147）「不许示弱」
- → 他怕自己一急着争取，就又只顾硬撑，最后连向往的亲近日子也留不住。
  - ← 改写：（1–23）「想保住自尊」
  - ← 提供理由：（148–180）「不用提防」
- → 光凭不能再等已催不动他。他想再找个足够有力的理由，可一想到争取的代价，还是定不下来。
  - ← 失效：（24–65）「接下眼前能做的事」
  - ← 失效：（1–23）「变得陌生」
