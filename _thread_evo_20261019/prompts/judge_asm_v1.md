你是一位独立评审。附件里有 {N} 篇匿名文章（{LABELS}），都是为 {WORK}（全曲{TOTAL}小节，按 {RANGES} 共{NSEG}段）写的讲解视频旁白稿，篇幅相近。另有一份参考材料「{BEADFILE}」：这首曲子每一段的“当下体验”记录（下称“珠子”）。

## 这些稿子是怎么来的

每篇都由两种原句组成，都只删不改：
- **线**：每段开头那一段正文。它讲一件属于人的、难以安顿的事怎样一步步发生，每段说清此刻为什么会这样。线写作时没有看过珠子。
- **珠子**：以“> 【珠子】”标出的句子，逐字摘自参考材料，提供此刻可感的体验。

各篇的差别只在于**删掉了哪些句子**。请评的是：删减后组合起来的成品好不好。

## 评什么

1. **线仍是主干，而且自己推动自己（最重要）**：只读线的部分，它是否仍是一条有先后、有因果、一步推一步的过程？每段的转折是否由前面已发生的经历推出，而不是“此时音乐忽然……于是……”？压缩是否删掉了关键的因果环节，让某一段的变化变得没头没脑？
2. **相合**：同一段里，珠子写的体验和线说的状态是否相合？如果线说他此刻在怀疑，珠子写的却是安然的舒展，读者会困惑——这是矛盾，要扣分。请列出矛盾的段落。
3. **连贯**：整篇从头读到尾，是否像一篇文章，而不是线和珠子两套东西轮流出现？珠子句是否像这一段此刻的感受，而不是插进来的另一种声音？
4. **鲜活**：读者能否感到这件事正在一个人身上发生，而不只是被告知？对乐谱细节写得多精确与此无关。
5. **取舍**：在相近篇幅里，留下的是不是关键的句子；有没有明显的重复或空话。

**不要因为这些扣分**：语气戏剧化、笃定；解释和说理本身；线不写音乐。

## 怎么读

先只读文章，各篇整篇读完；对每篇写出：
- 一句话说出它的 Center；
- 逐段判断线的转折由什么推动：“内”（前文的经历或认识）、“乐”（此刻的音乐事件）、“无”（没有交代理由）；
- 有无线与珠子的矛盾（带小节）；
- 一处读起来最顺的地方、一处最断裂或最突兀的地方。

## 输出

先写上面的逐篇读后，最后给一个 ```json 代码块：

```json
{
 "ranking": ["文章X", "..."],
 "articles": {
  "文章A": {
   "center": {"present": 0, "statement": "一句话，或‘没有’"},
   "self_driven": 1,
   "segment_drivers": ["内", "乐", "无"],
   "fit": 1,
   "conflicts": ["mm.xx–yy: 简述"],
   "flow": 1,
   "alive": 1,
   "selection": 1,
   "overall": 1,
   "verdict": "一句话"
  }
 }
}
```

- self_driven、fit、flow、alive、selection、overall：1–10 分。
- segment_drivers：按段落顺序，每段一个“内”“乐”或“无”，个数必须等于段数（{NSEG}）。
- center.present：0 = 没有属于人的 Center；1 = 模糊；2 = 清楚；3 = 清楚且在全篇真正发展。
- overall 是对成品的总体判断：线失去主干地位或因果断裂、线与珠子矛盾、读起来像两套东西轮流出现，都应明显拉低 overall。
- ranking 必须包含全部 {N} 篇，从最好到最差，不许并列。
