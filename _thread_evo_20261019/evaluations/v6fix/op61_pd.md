# Op.61｜线（pd）

**Center：**维持尊严的行动与对旧日生活及归属的怀念反复拉扯

### S01｜1–23 小节　（还说不清）

- 想到与家人相处，他仍习惯先顾及他们会不会难过，把自己的想法往后放。
- → 他想保住那份熟悉的亲近，却越来越难忽略退让时心里的委屈。

### S02｜24–65 小节　（正在面对）

- 家人对他太重要了，他很想在他们面前仍像从前那样自在，不必担心自己是否被接纳。
- → 可一想到不再事事附和，他就怕家人失望，连原本自然的亲密也会变得拘谨。 〔1–23 ①〕
- → 他想让家人明白自己也有不同的感受，却又舍不得让这份亲情承担可能的失望。

### S03｜66–91 小节　（正在面对）

- 他渐渐肯承认，过去有些退让并不是自己真心愿意，而是害怕家人不再像从前那样亲近他。 〔24–65 ②〕
- → 想到自己那么珍惜的亲情，也会让他不敢说出心里的话，他感到一阵心酸。
- → 他依旧想体谅家人，却没法再把每一次勉强自己都当成心甘情愿的体贴。

### S04｜92–115 小节　（正在面对）

- 他没有因此埋怨家人，因为他们究竟会怎样面对他的不同，他还不知道。 〔66–91 ①〕
- 他只是觉得累，连爱着家人时都要小心自己的想法会不会使他们失望。
- → 他多希望一家人能好好亲近，不用分出谁赢谁输，也不用总由一个人退让。

### S05｜116–147 小节　（没在想）

- 他想起过去与家人相处的日子，那时的亲近似乎不需要这样小心地维持。
- → 他沉浸在那份熟悉的暖意里，只希望还能像以前一样，安心地待在家人中间。

### S06｜148–180 小节　（正在面对）

- 为了再拥有那样的日子，他一度想照旧退让，把自己的真实想法重新压下去。 〔116–147 ②〕
- → 可他已经尝过勉强自己的难受，即使这样能换来和气，他也不会觉得自己被完整地接纳。 〔66–91 ①〕〔66–91 ②〕
- → 他仍然渴望与家人亲近，但他想要的是不用藏起真实感受也能拥有的安心。

### S07｜181–205 小节　（正在面对）

- 他还是舍不得过去的亲密，想到那份温暖已经很难像从前那样自然地感受，心里便难过。 〔116–147 ①〕
- → 但一想到又要靠委屈自己来维持熟悉的相处，他便无法再毫无顾虑地盼着回到原来的样子。 〔148–180 ②〕
- → 他仍深深爱着家人，只是这份爱如今也带着一份没法轻易放下的难受。

### S08｜206–213 小节　（正在面对）

- 一想到家人也许会因为他的不同而伤心，他又忍不住心软。
- → 他仍想尽量顾全他们的感受，可一想到重新压下自己会有多难受，他也没法就这样劝自己退回去。 〔148–180 ②〕

### S09｜214–215 小节　（正在面对）

- 他实在不愿让自己珍惜的家人失望。
- → 可他也不愿再一次把自己的难受轻轻带过，一时只能这样犹豫着。

### S10｜216–225 小节　（正在面对）

- 他忽然想到，自己一直怕家人不接受，可他们面对一个不再事事附和的他究竟会怎样，其实还没有答案。 〔24–65 ②〕
- → 他不想再因为担心可能的疏远，就提前把自己真正想表达的话咽回去。 〔148–180 ②〕
- → 他仍然害怕家人会失望，却开始容许自己想一想，也许他们能接受他有不同的想法。

### S11｜226–241 小节　（正在面对）

- 想到有一天真的让家人知道自己并不总是赞同他们，他心里还是紧张。
- → 他甚至有点想照旧顺着他们，至少那样暂时不用面对可能出现的失望。
- → 只是这一次，他能分清自己的害怕和家人真正的态度，不再把可能的疏远当成必然的结果。 〔216–225 ①〕〔216–225 ③〕

### S12｜242–253 小节　（正在面对）

- 他对家人的牵挂依旧很深，想起他们时，心里还是有许多温柔和舍不得。
- → 他暂时不想逼自己决定以后该顺从还是坚持，只想让这份亲近与尚未消散的委屈都先留在心里。

### S13｜254–288 小节　（正在面对）

- 他仍盼着家人能像从前那样自然地爱他，也依然害怕自己的不同会让彼此生分。
- → 可即使再想留住那份暖意，他也不愿继续靠一直压下自己来换取表面的和气。 〔148–180 ②〕〔148–180 ③〕
- → 他愿意继续珍惜这份亲情，也开始允许那些尚未说出口的真实想法在自己心里占有位置。 〔216–225 ②〕〔216–225 ③〕
- → 家人究竟能不能接受他，自己又能不能承受可能的不理解，他现在仍不知道。
