# 文章B

**Center｜什么对他重要：**他想与人亲近，得到回应，同时保有自己的想法和声音；他也在意自己能继续成长，并能好好享受已经得到的东西。
**Center｜什么使它难以安顿：**这些需要各自重要，却会向他的生活提出不同要求。亲密让他安心，也可能让他害怕变化；向前发展使他充实，也可能动摇原有的安心；已经得到的满足很真实，却无法照顾所有愿望。他怕为了保住一样重要的东西，逐渐失去另一样。

### 1–3

  ← 说明：［处境｜1–3］他心里有一股想要靠近的牵引，却还找不到能把这份愿望说清楚的话。　—— 他说不清最初的牵引，因此还只能守着模糊的期待。
  ← 提供理由：［恐惧｜1–3］他隐约怕自己太早把希望全押在一个答案上，却还说不清问题会出在哪里。　—— 他隐约担心过早确定答案，所以无法完全放心。

  ← 限制：［困难｜4–16］他得到的这份亲密还没有经历双方难以自然回应的时候，眼前的顺畅给不了他以后一直顺畅的保证。　—— 亲密尚未经历变化的检验，使他的信任暂时无法成为长期保证。

- ［办法］他愿意相信这种双方都能表达的亲密，允许自己从中得到安心。
- ［困难］他得到的这份亲密还没有经历双方难以自然回应的时候，眼前的顺畅给不了他以后一直顺畅的保证。
- ［问题］他不知道双方无法这样自然回应时，亲密还能不能维持。
- History：［所求｜1–3］他想在靠近别人时得到回应，知道自己的靠近有人接住。；［所求｜1–3］他想在得到回应的时候，仍然保有自己的想法和声音。；［机制｜1–3］他暂时把靠近、得到回应和保有自己挤在同一个希望里，觉得满足其中一项或许就能照顾其他几项。；［恐惧｜1–3］他隐约怕自己太早把希望全押在一个答案上，却还说不清问题会出在哪里。
- Outer：他体验到两个人都能够表达自己，也能够彼此照应。

### 17–23

◇ Center（加深）：他已经尝到亲近的快乐，开始追问这份相应能说明多少理解，又能在什么情况下继续成立。

**此刻｜他仍然信任已经发生的亲密，却开始怀疑自己是否已经充分理解它。**
  ← 提供理由：［理由｜4–16］眼前确实发生的相互回应，让他有理由相信这种亲密值得信任。　—— 此前的信任有真实回应作根据，所以他仍愿意保留它。
  ← 动摇：［困难｜17–23］他已有的经历足以证明亲近发生过，却还不足以让他确定双方一直能够理解彼此。　—— 他发现现有经验无法保证一直相互理解，因此无法再毫无保留地相信。
  ← 说明：［恐惧｜17–23］他担心未经检验的信任会让自己过早放心，以为两个人已经拥有可靠的长久理解。　—— 他害怕误把短暂相应当成长期根据，使保留下来的信任也带着审视。
- ［机制］因为那份靠近确实发生过，他开始在意它究竟证明了多少东西。
- ［问题］他想知道双方能够相应，是因为彼此确实理解了对方，还是因为当时恰好能够贴近。
- ［问题］他不知道这份相应换了处境、遇到困难以后还能持续到什么程度。
- ［发现｜满足照出未满足］他已经感受过真实的亲近，却发现自己还想理解这份亲近为什么能够成立。
- ［需要］他需要知道双方的相互回应可以依靠什么，又可能在什么情况下失去根据。
- ［困难］他已有的经历足以证明亲近发生过，却还不足以让他确定双方一直能够理解彼此。
- ［机制］他舍不得抹去亲密已经给过的好处，也怕让那一次满足替以后的关系担保。
- ［恐惧］他担心未经检验的信任会让自己过早放心，以为两个人已经拥有可靠的长久理解。
- History：［恐惧｜1–3］他隐约怕自己太早把希望全押在一个答案上，却还说不清问题会出在哪里。；［快乐｜4–16］他在彼此回应时感到亲近，也没有觉得自己的声音被对方盖住。；［回报｜4–16］他一直想靠近别人又保有自己的愿望，在这份亲密里暂时同时得到了满足。；［发现｜4–16］他亲身发现，两个人可以靠得很近，同时各自保留表达自己的空间。

- ［发现｜办法的限度］他也知道每一种满足都有照顾不到的地方，无法让其中一种替其余需要负责。
- ［发现｜其他］他能够珍惜亲密给过自己的好处，不再因为它有限就怀疑那段经历是否真实。
- ［发现｜其他］他能够看见成长带来的不安，同时继续重视成长已经给过自己的充实。
- ［发现｜满足照出未满足］他知道自己确实有过充分满足的时刻，后来仍有欠缺也无需抹掉那些时刻。
- ［办法］他愿意好好珍惜已经得到的东西，也给尚未满足的需要留下继续辨认的空间。
- ［办法］他不再因为不安重新出现就逼自己立刻追求更多，也不逼自己宣布所有问题已经结束。
- ［发现｜分清］他已经能够分清自己确实还有重要东西没有得到，以及自己只是习惯继续追求。
- ［需要］他以后仍需要留意这些愿望怎样随生活变化重新发生拉扯，再判断自己该怎样回应。
- ［发现｜其他］他已经能够允许自己暂时享受所得，也允许自己以后继续追问尚未解决的需要。
- ［困难］他知道几种需要以后仍可能互相拉扯，自己没有一种能够永久免除冲突的办法。
- History：［机制｜1–3］他暂时把靠近、得到回应和保有自己挤在同一个希望里，觉得满足其中一项或许就能照顾其他几项。；［快乐｜4–16］他在彼此回应时感到亲近，也没有觉得自己的声音被对方盖住。；［发现｜24–34］他开始分开看待亲密曾经真实和亲密能否照顾自己全部愿望这两件事。；［状态｜24–34］他重新肯定曾经得到的亲密，同时愿意留下一个还没说清的缺口。
