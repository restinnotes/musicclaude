# Op.61｜关系图

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### 1–23　（还说不清）

- 他心里有股不肯就此算了的劲，仿佛任事情继续就是承认它们理所当然。
- 可一想到真要把自己投进去，他又觉得会丢下什么，却还不知道那是什么。
- 他试着找到足以让自己不再犹豫的理由，刚觉得有把握，另一份舍不得又浮上来。
- 他有时几乎相信自己已经想通，过一会儿却连刚才的确信都觉得陌生。
- 长久的摇摆令他难堪，他怀疑是否非得把心里的一切想妥才肯向前。

### 24–65　（正在面对）

- 他渐渐受不了再拿还没想清楚当等候的理由，决定先承担自己能够承担的那一份。
  - ← 提供理由：（1–23）「摇摆」
- 即使没有保证，牵挂也没有消失，一旦开始行动，他便真切地感到有了力量。
- 从前他总问值不值得，现在愿意尽力，也为自己不再受疑虑支配而骄傲。
  - ← 改写：（1–23）「舍不得」
- 投入让他热切而快乐，仿佛不满终于有了去处，他甚至贪恋倾尽全力的畅快。
- 他不再需要时时审视自己，也不想为了偶尔的软弱停下来。
- 偶尔触到心里一处未随之昂扬的地方时，他隐约知道仍有牵挂没有被顾及。
- ⟲ 仍在起作用：（1–23）「会丢下什么」

### 66–91　（没在想）

- 那一点不安尚未逼他停下，认真投入过之后，他反而能暂时松开反复自问。
  - ← 提供理由：（24–65）「有了力量」
- 他发现自己也会因不再畏缩而高兴，在向前的热情里感到轻盈。
  - ← 唤起：（24–65）「倾尽全力」
- 偶尔忘记为何如此用力，他也不觉得是背叛，反而尝到久违的自由。
- 他顺着这份自由走了一程，没有忙着替这份快乐寻找更大的意义。
- 当快乐不再那么满，先前作出的决定又开始等着他面对。

### 92–115　（正在面对）

- 他重新面对自己的决定，仍愿坚持，因为它确实帮他走出了难以行动的犹豫。
  - ← 唤起：（66–91）「决定」
  - ← 提供理由：（24–65）「有了力量」
- 先前那阵轻快也是实在的收获，他不肯因仍有缺口就否定付出过的一切。
  - ← 提供理由：（66–91）「不再畏缩」
- 他试着从坚定中再次确认力量，却发现心里还有一种要求，力量替代不了。
  - ← 唤起：（24–65）「隐约知道」
- 他不愿承认这两件事，却已无法装作不知道：行动值得，行动也不够。　✦ 办法的限度

### 116–147　（正在面对）

- 失望令他格外怕自己变了心，因此在知道行动不够时仍更用力地催逼自己。
  - ← 提供理由：（92–115）「仍愿坚持」
  - ← 唤起：（92–115）「行动也不够」
- 他把心里的难处都当成应克服的迟疑，想停一停又担心是在退缩。
- 他知道自己在受苦，却想不出除了坚持，还能怎样对得起最初的决意。
- 曾使他昂扬的要求渐渐容不下脆弱，他开始觉得自己像在勉强一个疲惫的人。　✦ 办法的限度
- 他终于不想再证明自己多坚强，暂时放下催逼，却没能立刻安心。
- 被压住的依恋随之回来了，他有些茫然，仿佛终于肯承认自己真舍不得一些东西。
  - ← 唤起：（24–65）「隐约知道」

### 148–180　（没在想）

- 停止催逼后，他心里的依恋才渐渐清楚，指向一种曾真心相信能过上的生活。
  - ← 提供理由：（116–147）「催逼」
  - ← 改写：（1–23）「会丢下什么」
- 他想要人与人不必时时防备，珍视的东西也不用靠争夺才能留下。
- 他盼望被爱和接纳无须反复证明，付出能出于喜欢，亲近时也不必先防备受伤。
- 那份盼望确实给过他快乐和亲近感，因此他无法再把它看作逃避的软弱。
- 他终于肯让被压下的爱惜回来，不再一想到它就用责任审问自己。
  - ← 改写：（116–147）「脆弱」
- 他暂时不急着问这样的生活还能否得到，也不急着比较它和眼前的坚持。
- 单是允许自己去爱、去相信就给他深深的满足，他几乎忘记疲惫，也暂时不想离开。

### 181–205　（正在面对）

- 那份安宁确实满足过他，他因此渐渐不甘心只能在心里拥有它。　✦ 满足照出未满足
  - ← 提供理由：（148–180）「深深的满足」
- 想到有些事仍让那种生活难以存在，他明白单靠怀念改变不了这些事。　✦ 办法的限度
- 因为再次体会到这种生活多值得爱惜，他又想为它有所争取，不甘只留恋。
  - ← 提供理由：（148–180）「时时防备」
- 他几乎责怪自己刚才沉浸在满足里，忘了还有必须面对的事，便想再催自己振作。
  - ← 唤起：（116–147）「变了心」
- 可一想到重新争取，他就怕温柔被耗尽，最后只剩不肯退让的意志。
  - ← 提供理由：（148–180）「给过他快乐」
- 他曾盼找到坚定的理由就不再为难，如今两边都有理由，反而更难作出选择。　✦ 知道更多反而更尖锐
- ⟲ 仍在起作用：（1–23）「不肯就此算了」

### 206–213　（没在想）

- 为难之中，那份温柔又短暂贴近他，他明知不能久留，仍不忍立刻推开。
  - ← 唤起：（148–180）「深深的满足」
- 既然它给过他深深的满足，他不想每次想起都急着拿它审问自己。
- 他愿再爱惜片刻，暂时不想那些没有答案的事，这份欢喜里已经有了不舍。
  - ← 限制：（181–205）「温柔」
- ⟲ 仍在起作用：（148–180）「爱惜」

### 214–215　（正在面对）

- 安静退去后，熟悉的迟疑又回来，他仿佛绕了很远仍回到原处。
- 可他现在能认出迟疑里还有真不愿失去的生活希望，已经无法全当成怯懦。　✦ 分清
  - ← 改写：（1–23）「会丢下什么」
  - ← 说明：（148–180）「真心相信」
- ⟲ 仍在起作用：（181–205）「坚定的理由」

### 216–225　（正在面对）

- 知道舍不得什么仍未使他勇敢起来，过去只凭一股决心向前的办法也难以照用。
  - ← 限制：（92–115）「行动也不够」
- 他也无法再安心沉浸在旧愿里，虽然这两种办法都给过他一些东西。　✦ 办法的限度
  - ← 限制：（181–205）「怀念」
- 他无力作大改变，只盼争取时记得为什么争取，爱惜安宁时也肯面对妨碍它的事。
  - ← 提供理由：（214–215）「生活希望」
  - ← 唤起：（181–205）「坚定的理由」
- 他还不知道怎样才能做到，只是反复想这点愿望，非得舍弃一边的逼迫似乎稍稍减轻了。

### 226–241　（正在面对）

- 他凭这点还不牢靠的心意，重新想能怎么办，也不愿简单否定曾得到的两份收获。
  - ← 提供理由：（216–225）「舍弃一边」
- 他想到，为了留住不必时时奋力的安宁去争取，就可能再次失去安宁。　✦ 选择的代价
  - ← 唤起：（181–205）「温柔」
- 他渐渐肯承认，即使意志并不软弱，珍视着不止一种东西也会让人难受。　✦ 分清
  - ← 改写：（116–147）「变了心」
- 这种承认没有使他轻松，他仍心疼，也仍盼有条不用如此艰难的路。
- 可他也明白，再等下去不会让那条路自然出现，怕受损就不争取，所爱也未必留得下。
  - ← 提供理由：（181–205）「怀念」
- 他不再要求自己先成为毫不害怕的人，舍不得、没有把握、受苦都不足以让他停下。
- 他一点点重新聚起力量，愿意带着不舍向前，不再逼自己压倒犹豫。
- 接近真正的承担，他反而更清楚自己仍会害怕，却已不愿让惧怕替他决定。
- ⟲ 仍在起作用：（24–65）「有了力量」；（148–180）「深深的满足」

### 242–253　（正在面对）

- 他不再等一个毫无损失的办法，久违的昂扬终于回来，也无须否认自己的脆弱。
  - ← 提供理由：（226–241）「失去安宁」
  - ← 提供理由：（226–241）「惧怕」
- 他仍愿尽力改变事情，却不再借这份尽力证明自己无所不能。　✦ 分清
  - ← 改写：（116–147）「脆弱」
- 他明白自己要承担什么，也肯让那些怕失去、想珍惜的感受被自己看见。
- 他愿为真心爱惜的一切负起责任，不再把牵挂看成行动的拖累。
  - ← 改写：（216–225）「为什么争取」
- 他仍会犹疑，却已经允许自己不等它消失就重新下决心。
- ⟲ 仍在起作用：（214–215）「生活希望」

### 254–288　（正在面对）

- 重新选择向前后，连他都有些意外，旧愿没有变远，似乎反而比从前更亲近。
- 他第一次真切感到，那份温柔也能成为不肯袖手旁观的理由。
  - ← 提供理由：（148–180）「时时防备」
  - ← 改写：（1–23）「不肯就此算了」
- 他想到，如果争取中丢掉那份向往，哪怕证明坚强，也会失去行动的缘由。
- 他知道为珍惜那种无需拼命的生活，有时仍须离开它带来的安宁去争取。　✦ 选择的代价
  - ← 改写：（226–241）「失去安宁」
- 他仍知道，投入更多未必离旧梦更近，怀着美好的愿望也无法保证付出值得。
- 他得留意会不会在争取中失去所爱，这种顾虑如今也提醒他怎样坚持。
  - ← 改写：（216–225）「为什么争取」
- 他发现两股心意竟能共同支持他，因而喜悦，也不必羞于依恋或厌倦责任。
- 完整投入又让他尝到最初相信生活时的快乐，经历怀疑和疲惫后，他已不觉得这理所当然。
  - ← 唤起：（148–180）「给过他快乐」
- 喜悦平静后，他仍不能保证承担能改变什么，也没有真的回到不用防备的生活。
- 他知道自己以后还可能疲惫、为代价动摇，两份心愿也仍可能相互牵制。
  - ← 说明：（181–205）「坚定的理由」
- 他不再急着用一种满足盖住另一种需要，也不愿因还有缺憾就否定已有的收获。　✦ 分清
  - ← 改写：（92–115）「行动也不够」
- 他不知道最终能留下多少珍贵的东西，仍愿带着不舍向前，也不再为自己的愿意找证明。
  - ← 提供理由：（242–253）「无所不能」
- ⟲ 仍在起作用：（148–180）「真心相信」；（181–205）「温柔」
