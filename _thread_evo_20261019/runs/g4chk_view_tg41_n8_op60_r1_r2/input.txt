# Op.60｜关系图

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3　（还说不清）

- 他还说不清究竟在盼什么，只知道心里有个格外想亲近的人，想到对方便会柔软。
- 他想让这份感觉多留一会儿，却本能地往回收，明明眼下无须决定，也不明白为何谨慎。
- 那点喜欢还很轻，似乎随时可以放下，他却偏偏舍不得放下。

### 4–16　（正在面对）

- 他不知道自己怕什么，便不急着决定两人以后会怎样，也不因喜欢就向对方期待什么。
  - ← 提供理由：（1–3）「本能地往回收」
- 这样想后，他渐渐能够安心亲近，把温柔自由地给予对方，无须时时确认有没有被领受。
  - ← 唤起：（1–3）「说不清」
- 他有时甚至觉得比先前自在，发现自己可以认真在乎对方，又不必因在乎而抓住什么。
- 他渐渐不再提防喜欢，甚至有点满意于自己的宽和，那时觉得不追问也不计较就已足够。

### 17–23　（正在面对）

- 先前的亲近已让他尝到幸福，他便开始希望这份喜欢能够长久，不只属于眼前。
  - ← 唤起：（4–16）「安心亲近」
- 一想到长久，他就意识到自己只能决定怎样珍惜对方，无法决定对方会否同样珍惜自己。
- 他原先觉得无须确认的事开始牵动心绪，偶尔想知道自己在对方心里是否也特别。
  - ← 改写：（4–16）「不急着决定」
- 这愿望起初不强，他也没打算索取，却已不像刚才安稳，意外于满足之后仍想要更多。　✦ 满足照出未满足
  - ← 改写：（4–16）「就已足够」

### 24–34　（正在面对）

- 他不愿新添的紧张破坏先前的快乐，也记得对方从未答应什么，不想让喜欢变成催促。
  - ← 唤起：（17–23）「仍想要更多」
  - ← 提供理由：（17–23）「无法决定」
- 他试着放宽心，提醒自己珍惜对方时，不必事事都得到相应表示。
- 他从关心、给予和为对方高兴中得到快乐，想确认回应的紧张也真的渐渐退去。
- 他因此更愿意付出，不再衡量心意的多少，也不再担心多给一些就显得自己更在乎。
- 他为这份毫不勉强的热切感到幸福，仿佛一直收着的温柔终于可以尽情给出去。
- 那一阵，他甚至相信，只要不向对方提出要求，就能尽情地爱，也不会失去什么。
- ⟲ 仍在起作用：（4–16）「比先前自在」

### 35–39　（正在面对）

- 等那阵充盈的欢喜稍稍平息，他仍想知道自己是否也被对方这样放在心上。　✦ 办法的限度
  - ← 限制：（24–34）「不会失去什么」
- 这让他难堪，明明刚为无所求而高兴，却又盼着被看见，怀疑体贴里是否藏着期待。
  - ← 唤起：（24–34）「毫不勉强」
- 他没法轻易回答，说毫无所求似乎不诚实，可他也知道先前的快乐并非为换回应。
- 他暂且停在不自在里，不替自己辩解，也不急着再用热烈的感觉把疑问盖过去。
- ⟲ 仍在起作用：（17–23）「是否也特别」

### 40–50　（没在想）

- 那份难堪没有减轻喜欢，却让他不再用慷慨证明自己，也不想逼自己变得毫无期待。
  - ← 唤起：（35–39）「盼着被看见」
- 他也不愿时时查看对方是否在意，于是改为留心自己此刻确实愿意给予的关切。
  - ← 改写：（35–39）「仍想知道」
- 他照样惦念对方、盼对方好，也会因心里有这个人高兴，却不再拿每份心意衡量关系。
- 他发现有些快乐留在心里就足够鲜明，甚至暂时忘了为何在意回应，只觉得细细喜欢很甜。
- ⟲ 仍在起作用：（4–16）「安心亲近」

### 51–61　（正在面对）

- 不声张的甜意留得久了，这份喜欢也渐渐深到难以像起初那样收放自如。　✦ 办法的限度
  - ← 改写：（40–50）「暂时忘了」
- 他仍想把心意留在自己这里，不让对方为难，却更加惦念，也盼自己的关切能被领会。
  - ← 限制：（40–50）「愿意给予」
- 他依然觉得不该让对方迁就自己的期待，于是那些没有着落的盼望只能自己承受。　✦ 选择的代价
- 这份喜欢仍让他觉得值得，正因尝过细致的甜蜜，他才舍不得把它减轻。
  - ← 提供理由：（40–50）「惦念对方」
- ⟲ 仍在起作用：（24–34）「变成催促」

### 62–71　（没在想）

- 喜欢已深到这个地步，他忽然不想再时时把它当作需要约束的东西。
  - ← 提供理由：（51–61）「舍不得把它减轻」
- 他明白那些快乐并非靠对方的承诺才发生，即使仍有期待，也无须怀疑自己感到的幸福。　✦ 分清
  - ← 改写：（35–39）「没法轻易回答」
  - ← 提供理由：（4–16）「安心亲近」
  - ← 提供理由：（24–34）「毫不勉强」
  - ← 提供理由：（40–50）「暂时忘了」
- 他不想再因害怕受伤，连高兴都小心翼翼，决定充分喜欢一次，不急着追问结果。
- 他开始坦然享受积攒已久的眷恋，不再每多付出一点就提醒自己收回一点。
- 有一阵欢喜真的盖过顾虑，他知道前面没有保证，却几乎感觉不到那份沉重。

### 72–77　（正在面对）

- 欢喜稍稍落定后，正因为刚才毫无保留地承认喜欢，他再也没法含糊心里的愿望。
  - ← 唤起：（62–71）「几乎感觉不到」
- 他想让这份深情与对方相遇，想知道对方是否也渴望靠近，愿意在彼此心里占重要位置。　✦ 满足照出未满足
- 他明白自己的盼望有多深，却也知道自己的热烈不能成为对方必须同样回应的理由。　✦ 分清
- 他一时进退两难，退回谨慎仿佛辜负真心，继续盼望又怕将来分不清喜欢和索取。　✦ 选择的代价
  - ← 限制：（62–71）「充分喜欢一次」
- 他想不出能同时顾全两边的办法，心里委屈，甚至有点厌倦反复为难自己。
- ⟲ 仍在起作用：（17–23）「是否也特别」；（51–61）「自己承受」

### 78–83　（正在面对）

- 他终于不愿再逼自己立刻选择，因为他减不轻喜欢，也决定不了对方的心意。
  - ← 提供理由：（72–77）「厌倦」
- 他明白想靠近无须立即向前，想守住分寸也不用把眷恋压没，于是暂时不决定什么。　✦ 分清
  - ← 限制：（72–77）「同样回应」
- 两种心思仍在，他允许自己带着愿望安静喜欢，也承认对方的回应没有把握。
  - ← 改写：（72–77）「进退两难」
- 先前的为难没有消失，他却不必时时与它争执，心里的温柔因此又能自然留下。
- ⟲ 仍在起作用：（62–71）「需要约束」

### 84–92　（正在面对）

- 他不再强迫自己消除渴望，便重新感受到亲近对方的快乐，尽管现在知道自己可能受伤。
  - ← 提供理由：（78–83）「无须立即向前」
- 他不再用无所求证明体贴，也不因偶尔盼被珍惜就怀疑整份喜欢是否真诚。　✦ 分清
  - ← 改写：（35–39）「没法轻易回答」
  - ← 改写：（24–34）「不会失去什么」
- 他比先前敢全心投入，不再躲避喜欢得深的事实，也不再为自己的热切羞怯。
- 他甚至为经历犹疑后还能如此高兴而感动，曾让他警惕的愿望此刻也能随喜欢一同存在。
  - ← 提供理由：（78–83）「不必时时与它争执」
- ⟲ 仍在起作用：（62–71）「充分喜欢一次」

### 93–102　（没在想）

- 他更清楚自己多想靠近对方，盼积攒的温柔能得到回应，不只停留在愿望里。
- 他想被对方同样深切地珍惜，也想知道两个人能够共同拥有的幸福究竟有多丰盛。
- 曾令他紧张的愿望此刻暂时不再折磨他，他甚至一度觉得已没有什么需要增加。
  - ← 提供理由：（84–92）「一同存在」
- 那是一阵几乎无法承受的满足，想靠近、想被爱、想尽情投入的心愿仿佛同时得到抒发。
  - ← 唤起：（84–92）「敢全心投入」
- 他没有得到任何新保证，却真切感到这样爱着已经无比充实，一时顾不上以后会怎样。
- ⟲ 仍在起作用：（72–77）「深情与对方相遇」

### 103–110　（正在面对）

- 他刚才尽情爱过，也尽情盼过被爱，此刻更清楚，深情无法决定对方是否同样选择自己。　✦ 满足照出未满足
  - ← 动摇：（93–102）「没有什么需要增加」
- 想到这里他仍会酸楚，刚才的欢喜让酸楚格外难忽略，他也难再说服自己不在乎回应。　✦ 知道更多反而更尖锐
  - ← 唤起：（93–102）「仿佛同时得到抒发」
- 他怕把安心全交给对方，就让对方负责消除所有不安，又不愿因怕落空而减轻喜欢。
- 他发现克制曾让他安心，却没让渴望消失，尽情投入曾让他幸福，也不能保证不失望。　✦ 办法的限度
  - ← 限制：（4–16）「就已足够」
  - ← 限制：（62–71）「坦然享受」
- 想靠近的迫切和不愿勉强对方的坚持都没退，因为哪一边都舍不得否认，冲突显得更尖锐。
- 他宁愿承受这种不轻松，也不想为了轻松就匆忙舍弃其中一边，或靠欺骗自己得到平静。
- ⟲ 仍在起作用：（17–23）「无法决定」；（51–61）「自己承受」；（78–83）「无须立即向前」

### 111–116　（正在面对）

- 带着仍没平息的牵挂，他渐渐不再要求自己找出一种不会受伤的爱法。
  - ← 提供理由：（103–110）「不能保证不失望」
- 他仍想被对方选择，因为真的希望两人彼此亲近，即使未必如愿，也不再假装没有这愿望。
- 他仍想克制，因为对方可以有不同心意，若让对方为他的安心迁就，亲近就难再自在。
- 想到这里他仍有遗憾，但不再觉得必须先消除遗憾，才能好好喜欢。
  - ← 提供理由：（103–110）「宁愿承受」
- 那些快乐没解开最后的疑问，他也不觉徒劳，反而更明白这个人有多重要。
  - ← 提供理由：（4–16）「安心亲近」
  - ← 提供理由：（24–34）「毫不勉强」
  - ← 提供理由：（40–50）「暂时忘了」
  - ← 提供理由：（93–102）「仿佛同时得到抒发」
- 他仍盼回应，却不再借对方有没有回应，判断自己是否真心。
  - ← 改写：（35–39）「没法轻易回答」
- 他也仍会有所保留，却不再拿自己收住多少喜欢来证明清醒。
- 他知道以后可能失望，也可能因不能靠近而疼，但不再以此否认感情或催促对方。
- 他愿继续认真地喜欢、充分地欢喜，也肯承受自己无法决定对方会怎样回应。
- 他未得到想要的一切，仍盼被爱，却不催对方回应，也不为了尊重对方而收回想给予的爱。
- ⟲ 仍在起作用：（103–110）「酸楚格外难忽略」；（72–77）「同样回应」；（78–83）「无须立即向前」
