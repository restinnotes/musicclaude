# 第二轮顾问：怎样提覆盖

## g6

我建议下一轮先不要改写稿骨架，也不要增加任何事后修补层。最值得动的是 A4 的综合写线方式，其次才是 A3 对珠子的提取方式。

我的核心判断是：

Q1 已经找到了一条有希望的路，但还没有真正把“人的经历”和“逐段体验”结合起来。 它让人的经历保持了连贯，珠子也不再直接变成情节，可是综合时仍然偏向于忠实执行一条预先想好的路线。珠子的体验性质只是被拿来对照，而没有充分参与决定：这段经历的哪一面，应该在这个时刻显现出来。

更具体地说，有三个不同的问题：

1. 真缺失： 有些段落的心理方向与珠子相反，或者把本应在这一段出现的重要体验挪到了别处。这是实质性的覆盖损失。
2. 路线偏窄： 一件原本可以包含多层体验的事，被写成了围绕少数心理顾虑反复调整的过程。路线本身未必不成立，但会限制它能够容纳的体验。
3. 评委偏严： 有些判定把珠子里的比喻、情节、极端强度乃至必须彻底解决的结尾，当成了线必须实现的东西。这部分不应该靠修改线来迎合。

这三者不能混在一起。尤其不能为了追求 90% 的数字，把第三类也塞回线里。

下面先把判定拆开，再给两套可以直接替换的提示词。两套都保留 Q1 的输入占位符和 JSON 输出结构，不增加事后改写层。

## 一、这些没接上的珠子，真正缺了什么？

### 1. 首先是体验的方向和出现时机，不是形容得不够强烈

我认为，最值得重视的是以下几组判定。

| 判定        | 我怎么看   | 真正暴露的问题                              |
| --------- | ------ | ------------------------------------ |
| S04 B4    | 明显缺失   | 线有热切和担心，但担心的对象、时间指向与珠子不同             |
| S09 B3    | 明确相反   | 珠子中的疑问仍在持续，线却直接说人物暂时不再追问             |
| S11 B1    | 实质性失配  | 珠子要求的一种坦然、向前的状态没有被写出来，线却把害怕放到了中心     |
| S13 B1    | 明确相反   | 珠子指向继续向前，线把往回收作为本段的主要反应              |
| S09 B1、B2 | 有实质缺口  | 线写成了平静、满足，少了表面安静之下仍然存在的压力            |
| S12 B1    | 部分实质缺口 | 若去掉宏大画面，珠子仍有个人得失暂时退到后面的体验；线没有充分承载这一层 |

这里有一个容易被忽略的区别：情绪不同，不一定相反；人物此刻采取的姿态不同，才更可能真正相反。

比如，一个人可以同时坦然承认自己的感情，又担心将来失去它。这两种感觉不矛盾。问题不是一段里出现了害怕，而是线把害怕写成主要方向，挤掉了本来可以同时存在的另一面。

这也解释了为什么现有 A4 的“允许一段有多种体验”还不够。模型知道这个原则，却没有在整篇写作之前，认真安排不同体验怎样在同一处境里成立。

### 2. 其次是把复杂体验写得过于单一

S06 的 B3、B4，S07 B3，以及 S11 B4 都有这个倾向。

线其实已经提供了可以连接珠子的处境，但往往只写出其中最顺的一面：满足就是满足，放松就是放松，担忧就是担忧。

读者可能在同一时刻既觉得亲近，又感到某种距离；已经得到了想要的东西，却正因得到而更加舍不得。这样的并存不需要新的情节，也未必需要新认识。

我怀疑 Q1 在这一点上受到了 established ledger 的间接影响：账本原本是防止同一认识反复成立的好工具，但生成时可能让模型过分追求每段都有一个清楚、统一的心理状态。

账本应该限制人物事实和真正的变化，不应该限制一个已经成立的处境在当下能有多少种感受。

这和之前 P1 的问题也不一样。P1 是把心理层次讲解得太多；这里要做的是让处境本身更有层次，而不是增加心理分析。

### 3. 有些判定确实超出了标准

这几项我不会为了覆盖而补：

| 判定        | 为什么不宜照单全收                                 |
| --------- | ----------------------------------------- |
| S06 B1    | 要求童年、初恋等具体回忆，已经越过了珠子比喻不得变成人物事实的界线         |
| S03 B3    | 要求出现谈话中难解的心结，过于贴近珠子想象的情节；真正可要求的是心理上的滞涩和纠缠 |
| S06 B4    | 可以要求沉浸与复杂感受，但不能仅因缺少“失去方向”的极端程度就必然判不接      |
| S11 B4    | 不应该要求已经得到的满足再作为一次全新的获得成立                  |
| S12 B1    | 可以要求暂时忘记个人得失，但不能要求人物真的进入某个更广大的世界          |
| S14 B1、B4 | 音乐有明确的结束感，不等于人物必须彻底想通、解决未来；标准明确允许保留未知     |

最后一项尤其重要。一次经历可以在当下告一段落，而它涉及的人生问题仍然没有答案。 评委可以要求读者感觉到本次经历已经走到这里，却不能因此要求一个永久性的答案。

### 4. 路线确实偏窄，但不是 Center 偏窄

从 Q1 可以观察到一个结构性倾向：多次变化都围绕“表达多少、收住多少、担心失去多少”展开。这样的路线有连续性，却容易把别的体验都吸收到同一个心理机制里。

而且有些转折依赖后来才出现的对方态度或需要。这也值得警惕：它虽然不像编造具体生活场景那么显眼，却仍然可能用新添加的关系事实驱动人物。

不过，Q3 已经证明：简单增加“不许把 Center 缩窄”“不许靠对方新举动”“不许靠心理动作推动”等规定，并不能解决问题，反而可能产生更加机械的心理算账。

所以这次不应该继续叠加禁止条款。

我更想改变的是综合时怎样使用已经有的人的经历：让同一个处境在不同段落自然显出不同的面，而不是不停制造一次认识、一次决定、一次心理操作。

## 二、先做一个很小的溯源检查，才能知道究竟该改哪层

现在只有原始珠子的覆盖判定，没有看到 Q1 实际生成的 `TARGETS` 和 A1 候选路线全文。因此还不能肯定，到底是 A3 丢了信息，还是 A4 看到了却没有用。

这个问题可以用现有运行记录检查，不需要重新生成：

### 每颗未接住的珠子，沿三个位置往前查

① A3 提取时保住了吗？

检查关键的感受方向、同时存在的不同感受、时间指向或段内变化，是否已经存在于 `TARGETS`。

如果没有，问题首先在 A3。

② 候选路线本来能容纳吗？

若 A3 保住了，再看 A1 产生的候选中，是否有一条无需添加人物事实，就能让它在相应段落自然成立。

- 有别的候选能容纳，选中的不能：A4 选路问题。
- 所有候选都不能：A1 候选空间问题。
- 选中的路线本来就能容纳：进入下一项。

③ 最终文字写出来了吗？

若体验已经提取，路线也能容纳，最终文字却没有写出来，才可以认定是 A4 综合写线的问题。

另外标出评委额外要求具体比喻、情节或永久性结论的情况，不把它们当作生成层的失败。

这个检查很有价值，因为它能阻止下一轮继续凭印象增加提示词。

## 三、方案一（首推）：把 A4 从“先选路线，再照顾珠子”改成“先比较整条路线的承载能力，再一次写线”

建议优先试验

只替换 `Q1_A4.txt`。A1、A2、A3 不动。

这不是增加一轮覆盖诊断，也不是要求模型在写完后逐段补齐。改变的是写线之前的内部构思顺序。

原 A4 的实际倾向是：

选一条路线

沿路线写

尽量接体验

新 A4 要求先完成一次全篇范围的可行性判断：比较候选路线在各段到底能自然承载多少体验、会不会与关键体验冲突，然后才决定以哪条路线为基础。选定后先想完整体的处境分布，最后一次写成全部要点。

### 可直接替换的 A4 提示词

你要为一首器乐作品写最终使用的 Thread。

Thread 是同一个人在整首作品里经历的一件事。只读 Thread，它必须是一件有前因后果、随时间自然发展的事。它还会逐段与独立写成的听感记录排列在一起，因此每段需要自然接住相近的体验。

这是一次整体构思、一次成稿的任务。不能先写成一条线，再逐段按照未覆盖的珠子修改。

【输入】

段落：\
{SECTIONS}

Center：\
{CENTER}

它是回头看整首时把各段组织起来的那件事，不是人物一开始就知道的结论，也不是每段必须回答的问题。

已经通过宏观评审的人物经历候选：\
{ROUTES}

从珠子提取的体验性质：\
{TARGETS}

你看不到原始珠子。不要猜测其中的画面、比喻或情节。

【一、先选择能够承载整首体验的路线，不输出分析】

不要只按路线本身是否完整、是否容易讲清楚来选。

对每条候选，通读它的全部前因和已成立事实，再对照整首的 TARGETS，判断：

1. 各段已经具备的处境，能自然容纳哪些体验？有些体验是否只需从既有处境的另一面来看，就能够成立？
2. 哪些体验需要凭空增加人物前史、对方行为、关系事实、心理认识或决定，才能成立？这些不能算作可覆盖。
3. 哪些体验与候选在对应段落的实际状态直接冲突？
4. 候选是否把整件事收窄成反复处理同一种顾虑或实行同一种心理办法，以至于其他体验难以进入？
5. 它能否在不破坏前因后果、不重复成立同一认识的前提下，容纳一段里不同甚至相互牵扯的感受？

选择一个 base_route。

在路线本身能够独立成立的前提下，优先选择与全篇体验更相容、需要额外编造更少、直接冲突更少的路线，而不是仅仅选择最整齐或转折最多的路线。

只能有一个 base_route。不能拼接几条路线互不兼容的人物前提。

如果所有路线都有无法承载的体验，保留缺口，不要为覆盖强行改造人物。

【二、在写出任何最终要点之前，想清整篇的处境】

选中的路线提供这件事的基础：人物原本在意什么、已经经历什么、哪些事实已经成立，以及它们之间的先后关系。

保留这些基础，不得为了某段体验而改写已有前因。

但候选路线中的逐段 state 不是必须照抄的句子。你要从同一件经历中，决定每个时刻哪一面值得写出来。

整体安排时，逐段想清：

- 他此刻的处境是什么？它怎样接着前面？
- 此刻最切身的所求、顾虑或感受是什么？
- 同一处境有没有另外一面，能够与它同时存在，而不需要新增事实？
- 与此前相比，是真有事情发生了变化，还是已有事情继续存在、变得切身、带来后果，或者暂时退到心思之外？
- 本段有哪些关键体验必须有处境相近的内容支撑？有没有体验会被某个不必要的判断或决定直接排除？

这一步看整篇，不逐颗安排句子。

不要把 TARGETS 排列成一连串人物必须依次完成的心理动作。

一段的丰富，可以来自同一处境中同时存在的几种感受，不一定来自多次转折。

两种感受表面不同，不等于互相矛盾；但也不能把真正互斥的感受硬说成同时成立。

体验的强弱、持续、反复和段内起伏可以改变人物当下的感受，不必因此产生新的认识或选择。

如果一个重要体验需要某种前面的铺垫，检查已有经历中是否真的有这种前因；没有就不能直接写出那个结果。

【三、一次写出完整的线】

从头到尾写同一个人的经历。

推动后面的，是前面已经经历、相信、期待、得到、失望或选择的东西，以及这些事情自然带来的后果。

不得靠临时编造的新事件、对方的新举动、关系事实、前史、对白、物件或场景来制造转折。

也不要用连续的心理操作替代经历。人物不必不断试办法、检验结果、修正办法、总结道理。

已经成立的认识、愿望和决定，只能真正成立一次。后面可以延续、实行、承受后果，或者发现此前还不知道的一面，不能把同一变化重新写成第一次发生。

一段里可以有不同的感受。只要来自同一个真实处境，就让它们自然并存，不必分析它们之间的心理机制。

不要为了顺畅而把复杂感受统一成一种，也不要为了覆盖而硬造复杂。

每段写 2–4 条，每条一句完整、自然的话：

- 每句话说一件有用的事。
- 连着读能自然接下去。
- 一句说得清的不拆开，也不把几件事挤进一句。
- 本段发生得少，就写得短。
- 不重说前面已经成立的内容。

语言像一个人平常讲自己的经历。写他当时想要什么、舍不得什么、顾虑什么、正承受什么。

不替人物分析心理结构，不创造抽象概念反复解释，不写哲理、格言或工整总结。

不要刻意追求每段转折，也不要求结尾彻底解决什么。

【四、与珠子的关系】

TARGETS 是体验上的参照，不是待翻译的文字，也不是要求逐条写出的事项。

同一个处境可以覆盖多颗珠子。只有确实相近的体验才记为覆盖。

不要把 TARGETS 中的体验变成人物已经发生的具体事实。

不要为了覆盖某种体验，而强迫人物在这一段产生新的认识、愿望、决定或行为。

不同体验可以分属同一处境的不同侧面，但不能忽略它们各自的方向、时间指向以及是否仍有顾虑。

尤其不要为了让叙述显得平稳、干净、连贯，就写出会无端排除本段其他真实体验的判断。

如果某种体验必须损害人物前因后果、增加无依据的事实或翻译珠子才能成立，就留下不覆盖。

以整篇自然成立为前提，争取尽量多的真实覆盖，不追求逐颗解释或表面上的全覆盖。

【五、引用、标签与内部校验】

先确定正文，再标注内部信息。

cite 只标真正使本条成立的更早要点编号。主题相近、情绪相近不算前因。不强制每段有引用。

covers 只列正文实际能够承载的 bead_id。一条可以对应多颗，但不能为了覆盖率虚报。

全文维护 established 账本，记录重要事实、认识、愿望和选择第一次成立的位置。正文不得与账本矛盾，也不得重复完成同一变化。

delta_type 和 delta 记录真实新增的内容；没有新变化就如实记录延续，不制造推进。

每段 relation 根据已经写出的正文标记：

- 没在想
- 还说不清
- 正在面对

不得为了符合预设标签改变正文。

【输出】

只输出 JSON，不输出构思或说明。保持以下结构：

{\
"base_route": "...",\
"segments": [\
{\
"sec": "S01",\
"relation": "没在想/还说不清/正在面对",\
"items": [\
{\
"id": "S01-1",\
"text": "...",\
"cite": [],\
"covers": ["..."]\
}\
],\
"delta_type": "...",\
"delta": "..."\
}\
],\
"uncovered_targets": [\
{\
"bead_id": "...",\
"reason": "为什么没有自然覆盖"\
}\
],\
"established": [\
{\
"claim": "...",\
"first_established": "Sxx-x"\
}\
]\
}

covers、delta、established 是内部校验信息，最终展示时删除。

### 为什么这有可能比 Q1 好？

关键不在于增加了多少限制，而在于重新分配了综合时的注意力。

Q1 的 A4 很会保护人的经历，却可能在选定路线之后，把每段预想成一个相对单一的心理状态。新版明确要求模型在落笔之前，查看同一处境里还能成立哪些不同感受。

它也把覆盖的成本纳入选路：一条路线即使逻辑非常漂亮，如果需要大量新增事实才能适应逐段体验，就不应该轻易胜出。

最重要的是，这没有恢复原来那种“局部补珠子”的层。所有变化发生在最终文字产生之前；一旦写完，就不再修改。

这个方案的主要风险是模型开始过度优化体验匹配，让每段又显得像一串人为安排的心理起伏。检验时要特别看：每条新出现的顾虑或认识，究竟来自前文，还是仅仅来自该段的 TARGETS。

## 四、方案二：让 A3 保留“体验怎样发生”，不只留下“这是什么感受”

只替换 `Q1_A3.txt`，其他层先不动。

这个方案针对另一种可能：A3 虽然正确剥掉了比喻和临时情节，却在抽象化的同时，损失了综合写线真正需要的信息。

比如，“热切”“不安”“满足”“惋惜”都是体验性质，但它们无法充分告诉 A4：

- 这种感受是向前的，还是往回收的？
- 人物此刻是相信、怀疑、期待，还是已经得到了什么？
- 两种感受是先后发生，还是同时存在？
- 这种感受是突然出现、持续着，还是在段内有变化？

这些区别不要求人物多做什么，也不需要任何新情节，却可能决定一颗珠子是否真的能接上线。

我想把 A3 的任务从抽取感受名词，稍微推向保留体验本身的结构。

特别注意：不是让 A3 构思人物的经历，更不是让它编出一组心理动作。它仍只提取体验性质，只是别把体验中真正重要的方向和关系抽掉。

### 可直接替换的 A3 提示词

下面是某首器乐作品逐段的听感记录（珠子）。

你只负责提取每颗珠子的体验性质，供后续写 Thread 时使用。

你不构思人物经历，不决定人物关系，不安排故事路线，也不写 Thread。

目标不是把每颗珠子概括成几个情绪词，而是在去掉音乐、比喻和想象情节之后，尽量保留它作为一种真实的人生体验时，最重要的感受及其内部关系。

【一、去掉不能进入 Thread 的东西】

去掉：

- 音乐术语和具体声音事件；
- 画面、物件、天气、地点等比喻；
- 为了描写听感而想象的人物动作、对白、关系情节；
- 从这些比喻或情节中推断出的新人物事实。

珠子写了某种事情，不代表 Thread 中真的发生了那件事。

但不要因为去掉比喻，就把比喻所表达的体验也一并丢掉。

特别区分：

- 一种感受具有某种性质；
- 一个人真的经历了能够产生这种感受的具体事件。

这里只保留前者。

【二、保留体验中真正重要的区别】

逐颗阅读，先判断：这颗珠子最不可替代的体验是什么？

提取时留意以下方面，但只保留珠子实际包含的内容，不要机械填满：

1. 此刻的感受是什么，具有什么方向？是趋近、退开、停留、展开、收束，还是其他方向？
2. 此刻对所经历的东西是什么态度？其中有没有确定、怀疑、盼望、顾虑、舍不得等区别？
3. 感受指向的是已经经历的、正在经历的，还是尚未到来的东西？这种时间指向是否真的构成了体验的重要部分？
4. 几种感受是同时存在、互相牵扯，还是先后变化？不要把同时存在的不同感受概括成一种，也不要把并存误写成先后发生的故事。
5. 突然、持续、反复、短暂、强烈、逐渐变化等性质，哪些是真正重要的？不要只留下情绪名称，丢掉它发生的方式。
6. 珠子有没有明确留下悬念、未定之感，或者明确的收束感？保留这种体验性质，但不推断人物必须作出什么决定。

某个方面没有明显依据，就不提取。不要为了完整而推断。

【三、不要把体验结构变成心理动作】

提取的是感受本身的形状，不是人物应该采取的一连串行动。

不得擅自添加：

- 一次新的认识；
- 一个新的决定；
- 一种新的应对办法；
- 对过去经历的具体回忆；
- 其他人物的行为或态度；
- 一件尚未在珠子中明确出现的人生事实。

即使珠子使用了这些内容作比喻，也不能让它们成为 Thread 必须拥有的情节。

不要推断“人物为了获得这种体验，一定先做了什么”。

【四、每颗珠子的输出】

保留以下字段：

- bead_id
- qualities：1–3 条简短的体验性质。优先保留最关键的感受及其方向；确实有不同层次时，再分别保留。不用抽象词堆砌。
- temporal_shape：只有本段内部确实包含重要变化或先后关系时才填写，说明变化的性质；如果主要是几种感受同时存在，不要把它们编成先后步骤；没有明显变化就留空。
- forbidden_imports：绝不能直接搬进 Thread 的人物事实、动作、情节或具体比喻。
- confidence：高 / 中 / 低。表示对提取是否忠实于原珠子的把握，不表示体验的重要程度。

【五、每段的综合】

对同一段的所有珠子，输出：

- compatible_bundle
- tensions

compatible_bundle：

寻找能够容纳本段多种体验的共同处境性质，但不编造实际的人物经历。

如果本段有几种不相同却能够并存的体验，应当分别保留它们，而不是求出一个平均情绪。

不要为了让一段显得统一，把它概括成单一的感受。

tensions：

记录确实不能简单合并的体验差异。

区分：

- 几种感受虽然不同，却可以同时存在；
- 它们具有不同的时间指向或对象，因此并不真正矛盾；
- 它们在同一时刻、同一方面确实互相冲突。

只指出体验间的关系，不决定未来的 Thread 应当如何解决。

不要强行统一珠子之间不同的听法。

【六、最后检查】

提取后的每颗珠子，应当仍能看出它与其他珠子的不同，尤其是关键的感受方向、时间指向和段内变化。

但这些区别都必须有原始珠子的支持，不能推断出新的情节。

宁可保留少量准确而有区分度的体验，也不要生成许多空泛的情绪词。

只输出 JSON。保留原来的 bead_id、qualities、temporal_shape、forbidden_imports、confidence、compatible_bundle、tensions 字段及原有结构。不增加字段，不合并或遗漏珠子。

### 为什么不把这和方案一直接合并？

因为目前有一个重要的不确定性：A3 原来到底丢没丢这些信息？

如果原来的 TARGETS 已经完整保留了体验的方向与变化，问题在 A4，那么改 A3 未必有用，反而可能增加字数，让 A4 更想逐项解释。

如果原来的 TARGETS 大量丢掉了这些东西，只改 A4 也无法恢复它看不到的信息。

所以建议先单独试两个改动，再看要不要合并。这比同时改 A3、A4 更容易知道为什么好、为什么坏。

## 五、怎样试，才不会又得到一个难以解释的盲比结果？

我建议固定 Q1 的 A1、A2 路线候选，做一个小型的对照：

| 实验    | A3 | A4 | 要回答的问题        |
| ----- | -- | -- | ------------- |
| Q1 基线 | 原版 | 原版 | 当前表现          |
| A     | 原版 | 新版 | 综合方式本身能改善多少   |
| B     | 新版 | 原版 | 体验结构提取本身能改善多少 |
| C     | 新版 | 新版 | 两种改动是否互相加强    |

C 可以在 A、B 显示出价值之后再跑。先固定上游候选，是为了排除抽到不同经历路线造成的波动；如果有候选胜出，再用完整 DAG 重新运行确认。

这里最好把 覆盖数量 和 覆盖质量 分开检查。

## 六、另外三个值得一试的方向

### 1. Best-of-N：独立写几条完整的线，只选择，不修改

这是我认为最值得排在上述两项之后的办法，而且之前尚未被实验否定。

保持同一套 A4 提示词和相同输入，独立生成例如 3 条完整线，不要求它们相互讨论，也不给它们看其他版本。

然后进行整篇选择：既看能否独立成立、是否人话，也看与珠子的真实相容程度，特别检查有没有凭空编造事实、翻译珠子或者出现明显相反的地方。

只选择完整成品，绝不对落选稿取局部优点拼接。

这与此前失败的“事后改写”有本质区别：它不要求一个模型面对既有文字改变结构。好的结构在第一次生成时就已经形成了。

潜在问题是评审噪声，所以选择不能只靠一次覆盖计数。可以先做硬伤检查，再用同一路由下的重复整体盲比确认。

### 2. 如果发现三条候选都窄，先扩大候选的差异，而不是放松写线限制

这项要等前面的溯源检查之后再动 A1。

一个可能的问题是：A1 虽然独立生成了三条路线，但它们可能只是在同一个心理机制上换了不同做法。这样 A4 实际没有多少可选择的空间。

可以尝试让 A1 的多条候选在人物最初的处境、真正想得到的东西，以及经历持续带来的后果上有实质差异，而不是只在同一种顾虑的应对方法上有差异。

但不要规定具体的差异类型，不要列固定的故事模板。也不要再靠增加“不许心理动作”等已经试过的限制来推动这件事。

如果候选空间本来足够丰富，就不值得改 A1。

### 3. 把“线与珠子的排列”作为独立试验，而不是再修改文字

这项不负责补救真正缺失的体验，但可能改善边听边读时的连续感。

在每段文字和珠子都冻结之后，自动选择每颗珠子更适合跟在哪条要点后面，依据实际的处境相关性，不改任何一个字。线和珠子的段落顺序不变，段内尽量保持原本的聆听顺序。

可以比较两种呈现：

当前：一条线后跟它配到的珠子

线 · 要点 1

珠 A

珠 B

线 · 要点 2

珠 C

可试：按处境匹配调整要点后的珠子归属

线 · 要点 1

珠 A

线 · 要点 2

珠 B

珠 C

示意：内容完全不变，只比较自动归属。不能把排列上的接近冒充为语义上的覆盖。

如果有些段落本来就存在比较好的相互照应，只是配对位置不理想，这可能改善实际阅读。但无法把真正相反的心理状态变成相容，所以应当作为呈现实验，和生成质量分开评估。

## 七、我的最终判断：真正值得争取的不是更多“心理内容”

我认为最重要的发现，可能是下面这一点：

一条线能够承载的体验数量，不等于它包含的心理变化数量。

以前提覆盖的方法，是发现一颗珠子不够贴，就往线里添加一个心理事实。它提高了局部覆盖，但不可避免地让人物经历被珠子牵着走。

Q1 则走到了另一个方向：先保证人物经历成立，再让珠子尽量附着于它。这样保住了整体，却有时将一段的人物处境写得过于确定、单一。

下一步可以尝试的中间道路是：

先让整件人的经历成立，再让这件经历在各段显出不同的切身感受；不必每出现一种新的感受，就让人物多经历一件事、多理解一个道理。

这应该是 A4 首先需要学会的东西。它不要求更长的线，不要求更多虚构，不要求音乐引发人物的心理转折，也不要求丢掉 established ledger。

它要求模型更准确地区分两件事：什么是人物处境中真正发生的变化，什么只是他在这个时刻切身感受到的东西。

所以我的试验优先级是：

第一步，溯源检查未覆盖珠子；第二步，只换 A4；第三步，依据溯源结果判断是否值得换 A3；第四步，才考虑 Best-of-N 或扩大候选空间。

如果这个方向成功，理想的进步不应该表现为成品突然增加大量解释，而应该是：字数和人物事实没有明显增加，但同一段原本单薄的处境，能自然接住更多不同的体验。

这才是我会把它判断为真正超越 Q1、也比旧流水线更好的依据。

## g56

我会把这批判定看成一个很明确的信号：**Q1 已经证明“综合写线时看去情节后的珠子”是对的；现在缺的不是再加一层补覆盖，而是让珠子在 A4 里更早参与“这一段到底处在什么方向”的决定。**

### 1. 这些没接上的珠子，真正缺的是什么？

我把两位评委重复指出的问题合起来看，大致有四类。

| 类型 | 典型判定 | 我的判断 |
|---|---|---|
| **方向直接相反** | S09 B3、S11 B1、S13 B1 | 最严重。不是措辞问题，A4 已经把本段人物状态定到了珠子的反方向，之后再“提高覆盖”只能打补丁。 |
| **方向没错，但状态写窄了** | S02 B5、S03 B3、S04 B4、S05 B2、S07 B3、S09 B1/B2、S11 B4、S01 B1/B3 | 数量最多。已有前因其实足够，但 A4 只取了其中一种自然后果，没有把同一处境里可以同时成立的另一层写出来。 |
| **珠子的时间形状丢了** | “冲破一点又收回来”“安静以后仍继续怀疑”“害怕之后反而向前”这类 | A3 有 `temporal_shape`，但 A4 没把“方向和落点”当硬信息使用。于是“都有紧张/都有安静”就被误认为接上了。 |
| **不值得追回的覆盖** | 要靠具体回忆、具体人生事实才能成立；或要求结尾彻底解决整件事 | 这是应该留在 `uncovered_targets` 里的那 10% 左右。强追只会重新走回 mb。 |

所以四个候选解释里，我会这样排：

**第一是路线/段内状态被选窄了；第二是写线时没有把体验性质当作“结构约束”真正用起来；“一段容纳不下”不是主要问题；评委过严只占小部分。**

尤其值得注意的是，很多“偏弱”根本不需要新增事件。一个人完全可以在同一个既有处境里同时有“舒服”和“提前舍不得”，或者“安静下来”和“疑问仍在”。标准本来也明确说“一段里的几种听感不压成一种”。现在 A4 实际上常常做了相反的事：**先从 route 选一个主心理动作，再让其他体验围着它排队。**

更深一层的问题是：A4 目前把 `base_route` 理解得太像“已经写死的剧情”。但 A1 的 route 最应该锁死的其实只有三样东西：**发生过什么、已经成立了什么、什么依赖什么**。某一段到底是更往前、往回缩、悬着、沉进去，很多时候还只是候选的实现方式。现在 TARGETS 到场太晚，能改措辞，不能真正参与“实现方式”的选择。

这也解释了为什么 Q2/P2 会崩：完全冻结线以后再见珠子，当然没空间；而 Q1 比它们好，是因为 A4 还剩一点空间。下一步应该扩大的是这块**合法的实现空间**，不是恢复逐珠补丁。

## 2. 我最建议先试的做法：只改 A4

核心改动只有一句话：

**先根据 ROUTES + TARGETS 决定“这条路线在每段怎样实现最合适”，再一次写完整线；route 的已成立事实不能改，但 route 里尚未成为 established 的局部心理写法不是圣旨。**

这和事后补覆盖有本质区别：珠子参与的是**成文前的整篇定型**。

还有一个重要变化：A4 选 `base_route` 时，不再只隐含地看哪个故事顺，而要先检查每条候选与 TARGETS 有没有大量**方向冲突**。如果一条路线天然让很多段落走到珠子的反方向，就不要选它。不是选“覆盖率最高的故事”，而是排掉“需要经常逆着自己才能覆盖”的故事。

下面是我会直接替换的 A4。占位符和输出结构都不动。

你要写一首器乐作品最终使用的 Thread。

Thread 是一个人在整首作品里经历的一件事。读者只看 Thread，也必须能从头到尾明白这个人为什么此刻会这样；之后它会和独立写成的听感记录放在一起，所以每段还要能自然接住若干体验性质。

你看到这些材料：

【段落】
{SECTIONS}

【这件事（Center，已经给定，不改）】
{CENTER}
它是回头看整首时把各段组织起来的那件事，不是每一段都要回应的题目。

【已经通过宏观评审的人物经历候选】
{ROUTES}

【从珠子去掉音乐、比喻和临时人物情节后得到的体验性质】
{TARGETS}

你看不到原始珠子。不要猜原始珠子的画面或措辞。

先完成整篇的内部定型，再从头到尾一次写完正文。不要先写出一条线，再逐段补 TARGETS。

【一、先判断候选路线能怎样实现】

ROUTES 是人物经历的骨架，不是已经写死的最终文案。

必须保持不变的是：
- situation 所规定的同一件事；
- 前面已经发生并被后文依赖的事实；
- established 中已经成立的认识、愿望、选择或问题；
- 真正的前因后果。

候选路线某段 state 中尚未成为 established、也没有被后文当作必要前因的局部心理写法，不必逐字照搬。
在不新增人物事实、不破坏前因后果的前提下，可以从同一批既有事实中选择另一种自然后果，也可以让几种本来能够同时成立的感受同时存在。

不能为了 TARGETS 改变已经发生的事实，也不能把人物带到与整条路线相反的另一件事里。

选择 base_route 前，先在内部逐段检查每条候选与 TARGETS 的兼容性。

特别检查三件事：

1. 方向
不要只看两边是不是都有“紧张、安静、高兴、难过”。
要看人物此刻实际是在：
- 更愿意靠近，还是更想退开；
- 更愿意承认，还是更想遮住；
- 仍在追问，还是暂时不再追问；
- 更确定，还是更怀疑；
- 想抓住，还是准备放开。

这里只是检查方向，不要把这些词机械写进正文。

如果某个 TARGET 与候选路线在这一段要求相反的方向，算作真实冲突，不能靠换措辞假装覆盖。

2. 同一段内部的变化
TARGETS 中如果有 temporal_shape，要保留它的先后和最终落点。
“先松开又重新收住”和“从头到尾都克制”不是一回事；
“安静下来以后疑问仍在”和“安静下来以后不再追问”也不是一回事。

不要只保留共同的情绪名词而丢掉变化方向。

3. 可以共存的不同感受
同一批既有事实有时能够自然产生几种不同但不矛盾的体验。
不要过早把一段压成唯一一种心理状态。

只要它们来自同一处境，并且彼此能够同时成立，就可以分别写出来。
但不能为了多覆盖而罗列互不相干的感受。

优先选择：
- 自身逻辑完整；
- 已成立事实最少发生冲突；
- 多数 TARGETS 能由既有事实或其自然后果产生；
- 不需要频繁新增心理机制才能接珠子

的候选作为 base_route。

不要为了多接几颗珠子选择本身较差的路线。
如果某颗珠子只有靠新增人物事实、破坏已经成立的状态或把人物推向相反方向才能覆盖，就允许不覆盖。

【二、线自己先成立】

每段此刻为什么这样，只能来自：
- 更早已经发生在他身上的事情；
- 更早已经成立但现在产生后果的认识、愿望或选择；
- 上一状态自然延续到现在。

不能因为某个体验目标需要一种情绪，就临时给他新增一段前史、关系事实、对方行为、回忆、决定或人生观。

尤其不能用“对方这时又做了什么”来发动本来没有根据的转折。

某个体验目标如果只有靠编新事实才能覆盖，宁可把它留下不覆盖。

【三、人物状态只能真正变化一次】

全文维护 established ledger。

某个认识、决定、愿望、问题一旦已经明确成立：
- 后面可以实行它；
- 可以承受它带来的后果；
- 可以发现它还有以前不知道的一面；
- 可以明确改变它；
但不能把同一件事重新写成第一次明白、第一次接受、第一次决定。

如果再次回到类似问题，必须有具体新增内容；否则只写延续。

不要用人物反复采取心理动作来制造推进。
“忍住、放开、说服自己、决定不想、试着收住、又决定不收住”如果只是同一个问题来回操作，不算新的经历。

【四、不要把强度当推进】

情绪变得更强、快乐更满、痛苦更深，可以是本段的重要体验，但不自动等于人物获得了新认识。

已有事情在这一刻真正落到他身上，也可以构成充分变化。

同样，不要因为某一段需要较强的体验，就强迫人物在这里作决定或得出结论。

【五、覆盖 TARGETS 的方法】

TARGETS 不是待翻译的文本，也不是逐项完成的任务单。

先让人物处境成立，再判断同一处境自然能承载哪些体验。

覆盖一颗珠子时，正文中必须真的存在与它相近的处境、方向或变化过程；不能只因为出现了同类情绪词就算覆盖。

特别注意：
- 如果 TARGETS 的关键在方向，正文方向必须相符；
- 如果关键在 temporal_shape，正文必须有相近的先后变化；
- 如果同一段几颗珠子可以共存，不要把它们压成一个平均感受；
- 如果 tensions 中是确实不能同时成立的不同听法，不必硬把两边都写成事实。

严禁因为 TARGETS 而新增：
- 对方做了什么；
- 两人发生了什么新事件；
- 过去曾具体发生什么；
- 新对白；
- 新场景；
- TARGETS 暗示出来、但人物路线原本没有的关系事实。

允许 TARGETS 影响的是：
在已经成立的人物事实之下，这一段具体突出哪一种自然后果、哪几种可以共存的感受，以及这些感受在本段内部怎样变化。

不要求 100% 覆盖。
真实冲突、必须靠新事实才能成立、或者只有把珠子的画面当真人经历才能成立的 TARGETS，应留在 uncovered_targets。

【六、每段内容】

每段写 2–4 条。
一条是一句完整、自然的人话。

一件事一句能说清，就不要拆成几条。
每条必须有独立作用，不得重说本段或前文已经说完的认识。

一段里如果同时存在几种不同感受，可以分条写，但每一种都必须来自同一个已经成立的处境；不要写成情绪清单。

事情少的段落就保持最短的合法长度。

语言像一个人平常讲自己的经历，不像心理分析、论文、总结或提纲。
优先写他此刻具体在意什么、盼什么、舍不得什么、担心什么、还拿不准什么。
少用抽象名词替代这些东西。

不要写格言、人生原则或作者替人物作总结。

【七、引用】

某条之所以成立，确实依赖更早某一条具体经历时，在 cite 中写前文条目编号。

不强制每段一定有 cite。
只是主题相近、情绪相近，不算前因。

不要在正文里写“提供理由”“限制”“说明”等关系标签。

【八、与整件事的关系】

正文全部写完后，再根据这一段实际写出的内容，标：
- 没在想
- 还说不清
- 正在面对

标签必须从正文推出来，不能为了保持预设标签而改正文。

【九、结尾】

不要为了像结尾而制造最终决心、彻底想通、人生结论。

但“没有彻底解决整件事”和“这一刻什么也没有落定”不是一回事。
如果前面的经历自然使人物此刻有一个明确的站法、选择或感受，可以明确写出来；不要为了保留开放性又把已经能够落定的东西故意写悬。

走到哪里就写到哪里。
真正还不知道的，才保留不知道。

## 第二个做法：如果 A4' 还不够，再改 A1，但不是把路线写宽泛

我不建议直接让 A1 “多考虑各种可能感受”。那很容易产出一堆模糊状态。

更值得试的是：**A1 不要过早把每段收束成一个心理操作；保留那些由同一批事实自然产生、以后仍可能往不同方向落的“活的矛盾”。**

这和你准备给 R 加的“不靠心理动作推动”同方向，但再往前一步：不只是禁止“试办法”，还要防止 A1 **过早解决 still_open**。否则 A4 即便看见 TARGETS，也只能推翻路线才能接。

A1 的字段完全可以不改；让 `state` 的 1–3 条承担这件事。

你要为一首器乐作品设计 Thread 的“人的经历骨架”。

Thread 是同一个人在整首作品里经历的一件事。以后会把它写成逐段关系图，但这一层只负责把这件事本身想清楚。

【输入】
作品：{NAME}
段落顺序：{SECTIONS}
Center：{CENTER}

这一层：
- 完全不看任何听感记录或“珠子”。
- 不写音乐、声音、旋律、节奏、和声、小节里的事件。
- Center 已经给定，见下。它是读者回头看整首时把各段组织起来的那件事；不是他一开始就清楚知道的事，也不是每一段都要回应的题目；不预告发展路线和结局。
- 可以利用你对作品整体走向的理解安排各阶段的轻重，但输出里只写人的经历。

请独立提出 {K} 条完整候选路线。

每条路线必须从头到尾只是一件事。可以没有具体外部事件；不要新增聚会、书信、物件、对白、地点、职业等情节来推动变化。

最重要的规则：

1. 前面已经发生过、相信过、期待过、得到过、失望过的东西，才可以成为后面此刻这样想或这样感受的根据。

2. 不要把 Center 缩成一个人物反复操作的心理问题。
一件事不等于一个机制。

如果一条路线的大部分推进都靠人物反复：
- 忍住或放开；
- 试着想开；
- 决定不想；
- 收住又重新放开；
- 找一种办法保护自己；
那么这条路线通常过窄。

人物的经历可以往前走，是因为先前发生的东西继续产生后果，他对同一件事看见了以前不知道的一面，或者原本悬着的东西在新的处境里真正落到自己身上；不必靠他不断管理自己的心理状态。

3. 不要靠新出现的对方行为或外部事件发动转折。
如果后面的变化只有在“对方这时又做了什么”以后才能成立，说明前面的经历本身没有把它推到这里。

4. 一个认识、决定或问题一旦已经明确成立，后面不能再次把同一件事写成第一次成立。
如果后来回到类似的地方，必须明确写出这一次新增了什么；没有新增内容，就标成延续，不要制造第二次转折。

5. 不要求每段都有新认识。有些段落可以只是：
- 已经存在的感受继续存在；
- 某件已经知道的事真正落到自己身上；
- 暂时沉浸在别的感受里；
- 前面的某件事产生后果。

不要为了填满段落制造心理动作。

6. 特别区分“情绪变强”和“人物处境发生了新变化”。
情绪更强本身不算新的认识或决定。

7. 不要过早把仍然能够同时成立的东西处理成单一态度。

如果前面的事实使人物既有一种愿望，又有一种真实顾虑，而且两者并没有真正解决，那么后面的 state 可以让它们继续同时存在。
不要为了让路线显得干净，提前替人物选边。

只有前面的经历真的使其中一边改变、失效或被重新理解时，才把这种变化记进 delta 和 established。

state 的 1–3 条应该写这一段此刻实际同时成立的重要情况，而不是把同一件事拆成几个近义句。

8. still_open 不是必须尽快解决的任务。
它的作用是保存到这一段仍然没有答案、以后仍可能产生后果的东西。

不要因为连续几段都保留同一个 still_open 就强行安排人物处理它。
只有当人物的处境真的变了，答案才应改变。

9. 不要让人物不停总结自己。
优先写他当时具体在意什么、盼什么、犹豫什么、已经知道什么、还不知道什么。

不要用自造的抽象概念替人物反复命名自己的处境。

10. 结尾不必解决问题，也不要为了有终点而制造决心、原则或人生结论。
但前文已经自然形成的明确变化，也不要为了保持开放而重新写模糊。

11. 同一路线中要保存一份“已经成立的事实账本”。
后面的段落不得违背它，也不得把其中已经完成的变化重新完成一次。

12. 检查整条路线的“实现空间”。

在不改变任何已成立事实的情况下，后续写线的人应该仍然能够把一个真实处境写得有层次，而不是每一段都已经被锁成唯一一个心理动作。

实现空间不等于含糊。
人物已经知道什么、发生过什么、什么依赖什么必须清楚；
可以保留余地的是：同一批事实在这一刻具体哪种感受更突出、几种能够共存的感受怎样一起落到他身上。

如果一条候选只有按照你现在写下的唯一心理方向才能成立，把它改得更依赖事实和后果，而不是依赖心理操作。

每条候选输出：

- route_id
- situation：一句普通话，说清这个人正在经历的是哪一件事；不要写抽象论文标题。
- segments：
  - sec
  - state：本段此刻实际是什么情况，1–3 条
  - delta_type：从“新变化 / 后果 / 实行已有想法 / 延续 / 回到旧处但有新增 / 暂时没在想”中选择
  - delta：这一段相对以前真正新增了什么；没有就写空
  - depends_on：真正作为前因的更早 state 编号；没有就空
  - still_open：到这一段仍未解决或仍不知道的东西
- established：按首次成立顺序列出全文的重要事实、认识、愿望或选择，并标明第一次成立在哪一段

不要写最终文案，不要评价候选。
只输出 JSON（字段名照上面写的）。

如果只能先跑一个，我选 **A4'，不是 A1'**。Q1 已经有明显的单独成立优势，先别动它最成功的那一头。A4' 是最小但结构性的改动。

## 3. 还有三件很值得试，但我不会把它们同时塞进主 DAG

第一，**检查 A3 有没有把真正重要的“方向”抽掉**。你现在只给了评委判定，没有给这里对应的 A3 输出，所以我不能确定这一刀到底损失多少。但可以做一个很便宜的离线诊断：拿所有判为“相反/没有/偏弱”的珠子，看 A3 的 `qualities + temporal_shape` 里是否还保留了评委指出的核心区别。如果原珠子是“安静以后仍追问”，A3 只剩“安静、不确定”，那 A4 再聪明也不可能稳定接准。若这个比例高，再改 A3；若大多数信息都还在，就不要碰 A3。

第二，**最终完整生成做 Best-of-N，只挑不改**。这是现在特别适合试的一条。相同的 ROUTES、TARGETS 和 A4'，并行生成 3–4 条完整 Thread；随后让比较评委同时看几条，只选一条，绝不修改。它和已经失败的“事后改写”完全不是一回事：每条候选从一开始就是完整生成，选择不会把结构重新揉坏。你现在的单次路线选择和局部实现有明显随机性，Best-of-N 很可能能吃掉一部分覆盖尾差，而且不会制造“补珠子腔”。

第三，**把覆盖评委拆出一个“不应计入缺失”的出口**，但不要借它美化数字。现在至少有些理由已经越过了标准边界：如果评委认为只有引入珠子里的具体回忆、具体情节才能算接上，那它实际在奖励“翻译珠子”。另一些结尾判定则容易把“明确收束感”误成“人物必须彻底解决 Center”。建议最终仍报两个数：`合法可覆盖中的覆盖率` 和 `全部珠子的覆盖率`；前者用来判断线写得好不好，后者保留观察，不要直接把所有缺口都倒逼给生成器。

### 我会怎么排下一轮实验

不需要铺很多分支。先在同一路由下跑 **Q1 + A4'**，其余完全不变；重点不只看总覆盖，还单独数三个指标：**“相反”还有多少、偏弱里有多少是方向/temporal_shape 没落进去、字数有没有重新膨胀。**

我期待的好信号不是一下从 35/50 变成 50/50，而是：**“相反”接近清零，偏弱明显减少，同时字数和人话基本守住。** 如果做到这一点，再用 Best-of-N 或 A1' 去拿最后那一截，比重新引入任何“逐段补覆盖”安全得多。

### 一、没接上的珠子，真正缺的是什么？

对照评委给出的具体失分理由，覆盖率掉到 35–38/50 的原因既不是“评委太严”，也不是“缺少外部具体情节”，而是由以下 **三个致命结构性偏差** 造成的：

#### 1. 核心问题：“向性相反”（Emotional Vector Inversion）
这是失分最严重、也是盲比中极度刺眼的问题（如 S09 B3、S11 B1、S13 B1）：
- **珠子的情感矢量**：S09 是“退潮后的反复怀疑与不安”，S11 是“坦然承认、不再防卫的笃定与敞开”，S13 是“加压、抓紧、绝不放手”。
- **线里的情感矢量**：S09 成了“满足、体贴、不想追问”，S11 成了“退缩、更加害怕失去”，S13 成了“想往回缩、重新藏起”。
- **成因**：我们在写稿规则里为了防止“廉价顿悟”和“打转解决问题”，施加了极强的抑制定势（“不制造决心”“不解决问题”）。模型把这一条机械地理解成了**“只能永远退缩、被动、往回缩”**。结果当音乐进入高潮推进或明朗确认时，人物心理却在背向撤退，导致评委直接判“相反”。

#### 2. “处境选窄”与“心理单色调”（Monolithic Timidity）
- 观察 Op.60 的 Q1 全文，人物从 S01 到 S14 几乎全在同一套极窄的微型机制里打转：**“想露多一点 ↔ 怕露多了受伤/对方为难 ↔ 对方接住了 ↔ 又想缩回去”**。
- 真实的器乐高潮和深层体验往往具有多种**伴随性心理质感**（Undertones）：
  - 幸福正盛时的“留不住、提前舍不得的时间流逝感”（S04 B4, S07 B3）；
  - 极度亲密之中的“不可替代的深层孤独或如梦感”（S06 B3, S06 B4）；
  - 强烈奉献中“自我退居次席、整个人被浩大感情淹没的开阔感”（S12 B1）。
- 这些并不是新编的外在事件，而是一个人在面对同一件极度在意的事时，**天然会伴随产生的心境波澜**。因为当前的 A4 提示词只允许人物死守选中的单一路线，模型不敢调动这些伴随心境，导致大量这类珠子完全无处着落。

#### 3. A4 提示词给了模型过大的“逃生门”（Opt-out Leak）
- A4 中写道：*“某个体验目标如果只有靠编新事实才能覆盖，宁可把它留下不覆盖。”* 并要求输出 `uncovered_targets`。
- 这本意是防止幻觉编情节，但语言模型是极其“趋利避害”的：**只要写一个丰富的心境稍微有点费劲，它就立刻选择丢进 `uncovered_targets` 放弃覆盖**。它放弃并不是因为“必须编外部情节才能接”，而是因为只要少写一层心理底色，它就能偷懒交差。

#### 4. 评委尺度判定的辨析
- 评委提到的少数点，如 S06 B1 的“童年、初恋回忆”，确实带有珠子自身的意象残留，线**绝对不能**为了迎合评委去凭空捏造童年经历（坚守标准）。
- 但评委抓出的“方向相反”、“没有写出时间流逝的留恋”、“在高潮处格局太小依然在算小账”，全部是完全成立、且在人物纯心理范畴内完全可以也应该做到的。

### 二、怎样把覆盖提到 90% 并保住人话与独立成立？

**核心思路：不改 DAG 结构（保持 A1 骨架 → A2 宏观选 → A3 体验性质 → A4 综合写线），把 A4 从“被动过滤器”改造成“具有向性约束和复调层次的发生器”。**

要实现 90% 覆盖，A4 必须建立两项新机制：
1. **向性矢量对齐（Vector Alignment）**：禁止与本段 TARGETS 的动态趋势（升腾/下沉、敞开/封闭、前推/收束）背道而驰。高潮段人物可以产生更广阔的交付或强烈的确认，平复段可以产生悬置或余波，绝不能在高光推进行段写退缩保底。
2. **前景动作与心境底色（Foreground & Undertone）**：每段 2–4 条，不得把同一个念头翻来覆去换词说。一条写他此刻**最直接的动作或计较**（前景），另一条写**伴随而来的心境、知觉或时空感**（底色，如提前的不舍、强烈的虚幻感、无所保留的冲动等）。

以下是全面升级后的 **A4 提示词**（完全兼容现有 pipeline 占位符与 JSON 输出结构）：

```text
===== Q1_A4_v2.txt =====
你要写一首器乐作品最终使用的 Thread。

Thread 是同一个人在整首作品里经历的一件事。读者只看 Thread，必须能从头到尾明白这个人为什么此刻会这样；同时每段要自然接住给定的体验性质（TARGETS），作为这场经历在各段的情感底色。

【段落】
{SECTIONS}

【这件事（Center，已经给定，不改）】
{CENTER}
它是读者回头看整首时把各段组织起来的那件事，不是每一段都要回应的题目。

【已经通过宏观评审的人物经历候选】
{ROUTES}

【从珠子提炼出的体验性质（TARGETS）】
{TARGETS}

你看不到原始珠子，也不要猜原始珠子的画面或具体措辞。

【第一步：确定主干】
从候选路线中挑出最扎实的一条作为 base_route。全篇只能有一个 base_route，保持从头到尾是同一个人在经历同一件事。

【第二步：一次写完整条线，严格遵循以下规则】

一、线自己先成立
每段此刻为什么这样，只能来自：
1. 更早发生在他身上的体验与处境；
2. 已经成立并在此刻产生后果的认识、愿望或顾虑；
3. 上一段状态的自然延续或反动。
严禁为了满足 TARGETS 而凭空新增：对方的新动作、具体对白、第三人、具体外部事件、新道具或新场景。一切变化都发生在他自己的心理与知觉之内。

二、向性对齐：绝不能方向相反
TARGETS 规定了本段音乐的情感动态方向（是冲动向前还是克制退守、是坦然面对还是犹疑自保、是沉醉开阔还是局促算计）。
- 人物的经历必须在“情感动态矢量”上与本段 TARGETS 呼应。
- 严禁向性相反：当 TARGETS 显示出坦然承认、强烈推进、毫无保留或决定性收束时，人物绝不能在此时写成缩回防卫、回避追问或退回原地。
- 人物的处境是同一件，但处境里的人是有血有肉的：他会因为极度幸福而生出“留不住”的提前心疼；他会因为长久压抑而在某一刻彻底抛开顾虑；他会在狂喜中感受到自我退居其后的浩大与眩晕。调动这些伴随心境去接住 TARGETS，而不是段段重复同一种小心翼翼。

三、前景与底色：一段之内的层次感
每段写 2–4 条，每条是一句完整、自然、平实的人话。
绝不要把同一个念头拆成两句车轱辘话说。段内的多条要形成“前景”与“底色”的互补：
- 前景：他此刻直接面对的所求、迟疑、决定或具体触动；
- 底色：伴随这个状态产生的情感质感（如对时间流逝的敏感、深沉的沉醉、突然袭来的空茫、或某种难以言喻的宽释）。
这样每句话都有独立用处，多颗珠子所代表的复杂体验也能自然融入，不显拥挤。

四、状态不可重复成立（维护 established 账本）
一个认识、决定或心理转折一旦成立：
- 后面可以加深承受其后果，可以在行动中印证，可以因新触动而动摇；
- 但绝对不能把“同一件事”在后文重新当成“第一次意识到”或“第一次做决定”。
- 情绪变强不等于认识改变。没有新变化就写沉浸、延续或伴随感受，不要硬造假转折。

五、人话要求
- 像一个人平平常常讲自己的经历，读者一眼看懂，不用费力提炼。
- 绝不用心理学或分析腔调（如“机制”、“确立边界”、“补偿策略”）。
- 不写格言、警句、对称工整句，不站在外面替人物总结人生哲理。

六、关于未覆盖项
TARGETS 描述的是人的纯粹体验性质。只有当某颗珠子的体验性质【必须依赖虚构外部事实（如有人背叛、有人离世、具体器物破坏）】才能成立时，才允许放入 uncovered_targets。凡是在纯粹心境、情绪波澜、知觉体验范围内能够接住的，必须在线中为其提供合理的心理处境。

七、段落关系标签
写完正文后，按本段实际写出的内容标：
- 没在想
- 还说不清
- 正在面对
标签必须从写出的正文推导出来。

八、结尾
不要硬造彻底解脱或宏大人生总结，但如果音乐与 TARGETS 走向了决定性的平复或落定，人物的内心也应当完成对整件事的某种“收束与安放”，而不是无休止地悬空在犹豫之中。

【输出格式】
只输出 JSON：
{

  "segments": [
```

### 三、还有哪些大胆且值得一试的做法？

如果上述 A4 调整还想进一步稳固胜率，以下两套做法在不违背硬约束的前提下，具有极高的探索价值：

#### 方案 A：在 A3 抽取层显式产出“向性动态锚”（Vector Anchor）（轻量且极稳）
**假设**：A4 模型有时看不清一堆文本属性背后的“动态趋势”，导致写出相反的情感。
**做法**：在 A3 提取体验性质时，强制给每段的 `compatible_bundle` 打一个纯抽象的**动力学向性标签（Affective Vector）**，供 A4 作为硬边界：
- `affective_vector` 只能从以下几组纯心理向性中选 1–2 个：
  - `[扩张/推向极点]`（如全心投入、加压、炽热）
  - `[沉浸/舒展]`（如安宁、沉醉、释怀）
  - `[收缩/退守/迟疑]`（如紧绷、收敛、防御）
  - `[失重/悬置/怀疑]`（如不确定、落空、追问）
  - `[沉降/落定/终局]`（如平息、看透、不再挣扎）
- **检验标准**：换任何曲子这几个动力词都通用；不引入任何情节；但 A4 看到 `[扩张/推向极点]` 时，就有了不可逾越的规则——**这一段的人物绝对不许往后缩**。直接斩断“相反”失分的根源。

#### 方案 B：A1 人物骨架层的“情感起伏容量预留”（Enriched Emotional Palette）
**假设**：Q1 的 Op.60 骨架从一开始就把人设写成了一个“从头到尾只有自保意识的小心翼翼者”，导致后半段无论怎么写都撑不开音乐的气势。
**做法**：在 A1（写经历骨架）时，不给珠子，但给一条**人性常识的硬约束**：
- *“整首作品代表一个人生命中一段剧烈而完整的内心起伏。同一个人在这一件事中，不能只有单一维度的计较。他的经历中应当自然包含沉醉的时刻、毫无保留的时刻、被时间与宿命感触动的时刻、以及最终承受后果的时刻。不要把整条经历写成同一种犹豫状态的反复推演。”*
- 这能让 A1 出来的 3 条候选从骨子里就具备更大的情感动态范围（Dynamic Range），A4 综合时自然就能接纳不同段落高潮与低谷的珠子。

#### 方案 C：A4 单层 Best-of-3 快筛（轻量自动化过滤）
**假设**：一次生成中，模型可能在某一两段出现偶发性“向性滑脱”。
**做法**：
- A4 并行生成 3 个独立版本（$T=0.7$）。
- 用一个轻量规则函数（或单次无外部记忆的模型判定）快速扫描：
  1. `uncovered_targets` 数量是否 $\le 4$ 颗？
  2. 是否出现 established 账本内的违规重说？
- 直接挑选覆盖数最高且无逻辑重复的那一版作为最终输出。试验记录已证明，事后修改（Rewrite/Compress）必败，但在**生成阶段 Best-of-N 挑选**则是保证高质量最稳妥的工程手段。
