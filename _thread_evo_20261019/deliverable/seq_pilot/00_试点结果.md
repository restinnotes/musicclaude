# 逐段构建线：Op.60 第 1–39 小节试点结果（10-23）

计划见 `PLAN_逐段构建线_20261023.md`。先读本文，再读 `Op60_1-39_对照稿.md`（同一段落的几个版本并排，标明来源）。

## 做了什么

1. **修正写稿提示词，新写一批稿**（仍不看珠子），共两种写法：
   - d9L 边听边写：每段先一句“感受”，再写“为什么”；
   - d9S 先写主线：保留 N8 的两步，只去掉诱导编剧情的规则。

   每种 3 篇，两首曲子都写了。
2. **候选池**：每段 13 篇，其中 N8 稿 7 篇、修正稿 6 篇。
3. **逐段综合**：从第 1 段做到第 4 段，每段先“挑解释并说明理由、更新历史”，再“说成人话”。
   - B 组：综合时不看珠子；
   - C 组：综合时看这一段的珠子原文。

   每组用两个模型（gpt6、gpt5.6），各跑 2 遍。
4. 综合提示词做了两版：第一版读下来问题很多，改成第二版后重跑。
5. **人话 2×2**：内容固定，只改说法，看上下文长短、提示词长短各自有没有影响。

## 结果

**评委**：gpt6 和 gpt5.6，每版各 4 次，用新标准（见 `prompts/judge_seq_v1.md`）。

**评委是否可信**：它给现行线（A）24–34 小节的四颗珠子全部判“没解释”，判为“万能故事”，并列出了一长串编出来的心理动作。这和你、ChatGPT 的判断一致，所以这个评委可以用。

| | 总分 | 珠子被解释的比例 | 多余心理动作（分高=少） | 人话 | “万能故事”的段 |
|---|---|---|---|---|---|
| A 现行线（N8） | 3.5–3.8 | 36–42% | 2.0–2.2 | 4.8–5.0 | 38% |
| B 不看珠子（第一版 / 第二版） | 2.8 / 3.2 | 35% / 35% | 6.9 / 8.1 | 7.5 / 8.5 | 69% / 88% |
| C 看珠子（第一版 / 第二版） | 6.2 / 6.0 | 60% / 65% | 7.8 / 6.8 | 7.5 / 7.5 | 56% / **19%** |

- 8 次评审里，C 组 8 次都排第一。
- B 组多数时候排在 A 之后。

## 我的结论

1. **修正后的写稿提示词确实更好用。**综合时选中 N8 稿 9–15 次，选中修正稿 33–42 次。按每篇算，修正稿被选的次数约是 N8 稿的 3 倍。N8 稿只在第一段常被选中。
2. **不看珠子的逐段综合不行。**它把编出来的心理剧情去掉了，可也没留下别的内容，四段只剩“温柔里带点不安”，换到哪首曲子都说得通。线如果只从自己的候选里挑，就不知道这一段到底要解释什么。
3. **看珠子的逐段综合明显最好，但还不到可以交付的水平**（总分 6）。
   - **好在哪**：24–34 小节真的解释了“更迫切”：“已经感受过亲近的快乐，这份温柔变得更珍贵，所以更想靠近、更舍不得。”这正是 ChatGPT 说的那种简单解释，第二版又把“万能故事”从 56% 降到了 19%。
   - **问题一**：它会把珠子里音乐的起伏（涌上来、又退下去）翻译成“他一度热切，又收住”。这等于用心理语言把珠子复述一遍，评委也指出了这一点。
   - **问题二**：第一版曾把第一段某颗珠子里的比喻（“准备对亲近的人说一件想了很久的事”）当成了全曲情节；第二版加了说明，这种情况少了，但没有完全消失。
   - **问题三**：句子偏长，“越……越……”多。
4. **人话问题主要不在上下文、也不在提示词长短。**同一内容在四种条件下改写，结果几乎一样，读起来都已经是人话。只有加长规则时，否定句略少（47–53% 对 63%）。所以：
   - N8 散文原稿逐句来看其实不难懂，难懂的是它的心理剧情；
   - 后来那些抽象说法（“满足照出未满足”、名词化），主要是把散文压成 45 字一条的关系图时产生的。

## 和规则的关系

- 写稿仍然完全不看珠子，这一点没变。
- 但结果说明，在**综合这一步**引入珠子很关键。这正是你说的“可能看珠子，效果不好就不用”，现在的效果是好的。

## 下一步建议

1. **改 C 组的综合提示词（第三版）**，针对上面三个问题：
   - 珠子里的“起伏”本身不用解释成心理上的起伏，只解释这一段整体为什么是这种感受；
   - 再强调一遍：比喻不是情节；
   - 句子短一些。
2. **改完后跑完 Op.60 全部 14 段**，加上全曲一致性检查，再在 Op.61 上检验（Op.61 的修正稿已经写好了）。
3. **再决定线的最终形态**：每段几句人话，还是稀疏的关系图。
