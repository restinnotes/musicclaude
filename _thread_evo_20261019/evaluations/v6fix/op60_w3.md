# Op.60｜关系图（A2 整首修补 w3）

**Center：**对亲密的投入与自我克制始终相互牵制。

### S01｜1–3 小节　（还说不清）

- 他一想到这个人就柔软起来，很想亲近。
- → 他怕心意露得太明白会改变两人的关系，便在想亲近时收住一点。
- 眼下还没到非得决定关系去向的时候。
- 这点喜欢看着还轻，他却舍不得随手放下。

### S02｜4–16 小节　（没在想）

- 他暂且不替这份喜欢安排去向，只想先让眼前的亲近自然发生。
  - ← 提供理由：（1–3）「关系会变」
  - ← 提供理由：（1–3）「非得决定」
- → 他觉得喜欢不必带着期待，也不用总确认对方有没有接住，仍能安心地关心对方。
- → 那时他真觉得眼前这样相处已经够了。
- → 他很享受这份亲近，想到时间还在走，明明还没失去就已盼它慢一点。
- → 那阵喜欢忽然热切起来，他任自己高兴了一阵，随后又把心意收住，没敢全交出去。
- ⟲ 仍在起作用：（1–3）「关系会变」

### S03｜17–23 小节　（正在面对）

- 安静下来后，他仍能舒服地待着，心思一时飘远。
  - ← 提供理由：（4–16）「安心地关心」
- → 想到这份亲近若要长久，他能做的就是好好珍惜对方，至于对方会不会也这样，得由对方自己决定。
  - ← 提供理由：（4–16）「时间还在走」
- → 他还没想向对方要答复，只是偶尔想知道自己在对方心里是不是特别。
- → 这个念头一冒出来，他就没法像刚才那样自在，心里也被它绊住。
  - ← 动摇：（4–16）「已经够了」

### S04｜24–34 小节　（正在面对）

- 发现自己开始在意是不是特别，他怕这点期待毁掉眼前的亲近，也不愿催对方给答案。
  - ← 提供理由：（17–23）「是不是特别」
- → 他把心思放回能给的关心和真心替对方高兴上，提醒自己这些本身就有快乐，不必每次换来回应。
- → 这样想确实让他轻松下来，也让他更愿意付出，不再盘算给了多少，连显得更在乎都没那么可怕。
- → 想到时间还在走，他舍不得这份亲近过去，热情一下涌上来，又怕太急会压到对方，便收住心意。
- → 他把这次轻松当成了保证，以为只要不提要求，就不会失去什么。
- ⟲ 仍在起作用：（4–16）「时间还在走」

### S05｜35–39 小节　（还说不清）

- 热情退下去后，刚才的满足帮不了他确认：对方有没有把他放在心上。
  - ← 失效：（24–34）「不会失去什么」
  - ← 唤起：（17–23）「是不是特别」
- → 他想到自己体贴时也许盼着被珍惜，便觉得难堪。
- → 他知道那时的快乐不是为了换回应，不能因为自己想被珍惜就把它说成交换。
- → 他先把抓紧当下的劲头松开，让难堪留一会儿，不急着替自己开脱或重新热烈起来。

### S06｜40–50 小节　（没在想）

- 他多给一些，还是会盼回应，便不再拿慷慨证明自己无所求。
  - ← 提供理由：（35–39）「盼着被珍惜」
- → 他把心思放回眼前愿意做的关心，真心盼对方过得好，也不再时时查看对方是否在意。
- → 专心想着怎样关心对方时，他偶尔会忘了自己为什么那么在意回应，那个念头暂时退到后面。
- → 独自惦念的甜还在，渴望和遗憾也搅在一起，有些心事连亲近也不能替他分担。

### S07｜51–61 小节　（正在面对）

- 独自惦念的甜让他舍不得把喜欢减轻，渴望和遗憾也混在其中。
  - ← 提供理由：（40–50）「独自惦念的甜」
- → 这份亲近如今对他很重要，相处正好时他也会想到时间不会停，怕眼前的好留不住。
- 他原想把喜欢留在心里，不让期待牵着自己走，也觉得不催对方才是对的。
- → 他仍盼对方能领会自己的关心，又不想给对方添负担，只能自己消化想被回应的心思。
- ⟲ 仍在起作用：（24–34）「不愿催对方」

### S08｜62–71 小节　（没在想）

- 靠近时的安心、给予时的满足、独自惦念的甜，都不是等对方许诺后才有的，他不想再因怕受伤压住欢喜。
  - ← 说明：（4–16）「安心地关心」
  - ← 说明：（24–34）「本身就有快乐」
  - ← 说明：（40–50）「独自惦念的甜」
  - ← 提供理由：（51–61）「喜欢减轻」
- → 他顺着想亲近的兴致高兴起来，心里有了点玩心，给出去的心意不再一笔笔算，喜欢深了也不急着把自己往回拽。
- → 欢喜还没过去，他已经舍不得它结束，想被对方同样珍惜的愿望也冒了出来。
- ⟲ 仍在起作用：（51–61）「自己消化」

### S09｜72–77 小节　（正在面对）

- 欢喜稍落下来，他才承认自己不只想把喜欢给出去，也想让对方主动靠近、把他放在心上。
  - ← 唤起：（62–71）「欢喜还没过去」
- → 他不敢把自己喜欢得深当成对方该回应的理由，可真要把盼望压回去，又像在否认刚承认的心。
- → 他反复想两边怎么兼顾，让他越发委屈、疲惫，偶尔也能把回应放在一旁，觉得眼前的亲近本身很好。

### S10｜78–83 小节　（正在面对）

- 他先不逼自己马上选边，仍盼对方靠近，也承认自己不知道对方会不会同样靠近。
  - ← 提供理由：（72–77）「越发委屈」
  - ← 提供理由：（72–77）「主动靠近」
- → 他想靠近时先慢一点，也允许自己仍然眷恋，不必硬把心意藏起来。
- → 那一刻他能喘口气，委屈和渴望松开些，身体也轻了，对方的心意仍没答案。

### S11｜84–92 小节　（正在面对）

- 不再逼自己选边后，他又尝到熟悉的亲近之乐，犹疑这么久还能高兴，竟让他有些感动。
  - ← 提供理由：（78–83）「喘口气」
- → 他曾因想被珍惜而怀疑自己是不是把体贴当成交换，如今不必先证明自己毫无所求，也能承认自己是真心在乎对方。
  - ← 改写：（35–39）「盼着被珍惜」
- → 他仍不知道对方会不会同样选择自己，却还是愿意把这阵欢喜感受到底，浓烈得胸口发疼。
  - ← 限制：（72–77）「该回应的理由」
- ⟲ 仍在起作用：（17–23）「是不是特别」

### S12｜93–102 小节　（没在想）

- 他想靠近这个人，也开始盼对方同样深切地珍惜自己。
  - ← 提供理由：（84–92）「不必先证明」
- → 他被欢喜整个卷进去，一时顾不上以后会怎样，连自己的得失都暂时退到后面。
- → 他觉得心里有好多爱，终于能尽情给出去，满足得几乎招架不住，却仍不知道对方会不会同样选择自己。
  - ← 限制：（84–92）「胸口发疼」
- → 他只想让这阵欢喜多留一会儿，等它稍退，没回答的愿望又回到心里。

### S13｜103–110 小节　（正在面对）

- 欢喜还在，他却怕一停下来就失去它，也再不能说对方怎么回应都无所谓，最想要的还是对方也选择自己。
  - ← 动摇：（93–102）「好多爱」
- → 他以前收住心意、少问回应时确实安稳过，可想被珍惜的念头还是会回来。
  - ← 提供理由：（4–16）「安心地关心」
  - ← 提供理由：（24–34）「不再盘算」
- 他后来也尽情喜欢过，确实很幸福，却不能替对方决定要不要靠近。
  - ← 说明：（84–92）「胸口发疼」
- → 他不想让对方替自己消除所有不安，也不肯为了好受假装没那么在乎。
- → 收住心意没让渴望消失，尽情投入也不能保证回应，两头都放不下，他越想越难受。

### S14｜111–116 小节　（正在面对）

- 他不再等到完全安心才肯继续喜欢，因为收住心意和尽情投入都没能替他保证结果。
  - ← 改写：（103–110）「两头都放不下」
- → 他仍想被这个人选择，也知道对方未必和自己一样在意，得让对方自己决定要不要靠近。
- → 靠近时的安心、给予时的满足、独自惦念的甜和尽情欢喜都曾让他真切高兴，他舍不得把这份喜欢收回。
  - ← 说明：（4–16）「安心地关心」
  - ← 说明：（24–34）「本身就有快乐」
  - ← 说明：（40–50）「独自惦念的甜」
  - ← 说明：（62–71）「一笔笔算」
- → 以后他还会想要更多，不能更近时也会疼，但他不想因此否认自己确实喜欢这个人。
  - ← 限制：（72–77）「该回应的理由」
- → 他仍没把心意说出口，却不再因怕关系改变就把喜欢从心里撤回。
  - ← 改写：（103–110）「两头都放不下」
- → 他仍愿意认真喜欢，也肯让自己尽情高兴，心里还热，身体却慢慢安静下来。
- ⟲ 仍在起作用：（72–77）「该回应的理由」
