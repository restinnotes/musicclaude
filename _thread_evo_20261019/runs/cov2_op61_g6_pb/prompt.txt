下面是肖邦《幻想波兰舞曲》Op.61的一条线，以及另一批人听这首曲子每一段写下的听感记录（珠子）。请逐颗珠子判断：读者在线的同一段里，能不能找到和这颗珠子的感受情境相近的处境或原因。

线是什么：一个人在这首曲子里经历的一件事，作用是把逐段的听感记录（珠子）串成一个整体。只读线也要成立：有逻辑、有时序、内在有发展，看得出他此刻为什么这样，但不靠“因为……所以……”交代；推动它的是他自己前面的经历，不是音乐里发生了什么，也不是新编的事件。珠子是另一批人听这段音乐写下的听感，会和线排在一起给读者看；线不用把珠子再写一遍，只要在同一段里有情境相近的处境或原因，相关就行。线不能把珠子里的画面、比喻或想象出的情节变成他真的经历的事。
线的写法：按音乐段落分段，每段几条要点；段首括号是他此刻和整件事的关系（没在想 / 还说不清 / 正在面对）；〔〕是这句接着前面哪一段的哪一条。

每颗珠子判一项：
- 说清：线这一段的处境或原因，让人能感到这颗珠子的感受为什么会出现在这里。相关、情境相近就算，不要求逐项解释；
- 偏弱：只照应了一部分，或者只是把感受换个说法；
- 相反：线在这一段写的感受和这颗珠子对不上；
- 没有：线没有涉及。
只看珠子里人的感受那一层：珠子里纯粹的声音、画面、比喻本身，不要求线去对应。线把珠子里的画面或想象出的情节搬进来当成他真的经历的事，不算说清。
“另一种理解”（和主体验不能同时成立的听法）也照样判断。戏剧化、主观、只讲一个故事都不算缺点。
每颗写一句理由，并写出起作用的条目（引几个字即可）。不要漏掉任何一颗。

【线】
**Center：**维持尊严的行动与对旧日生活及归属的怀念反复拉扯

### S01｜1–23 小节　（还说不清）

- 他记得从前与熟悉的人相处时，不必时时留意自己是否失态，就能自然地感到安心。那样的生活如今不再继续，他一想到这点，就觉得眼下的自己没有了从前的着落。
- → 他仍想像从前一样镇定，可现在光是压住不安就要费不少力气。他还分不清，最让自己难受的是失去那份安稳，还是自己竟变得这样容易动摇。
- → 过去的自在偶尔在记忆里显得很近，让他生出一点还能重新站稳的盼望；可他既不能凭回忆回到那种生活，也不知道现在该怎样保住原有的从容。

### S02｜24–65 小节　（正在面对）

- 他不愿一直被眼下的不安牵着走，于是要求自己尽量像从前那样镇定。他觉得即使熟悉的生活已经不在，也不该让自己失去原来的体面。 〔1–23 ②〕〔1–23 ③〕
- → 这样约束自己时，他偶尔觉得还有力量守住原来的自己。可一想到从前根本不必如此费力，心里又难免酸楚，那份勉强得来的坚定并不能使他真正安心。 〔1–23 ①〕
- → 他不甘心承认自己已不像过去那样从容，便反复催促自己收起依恋与不安。可越是这样要求自己，他越清楚那些感受仍在，甚至开始担心自己再也做不到从前的样子。

### S03｜66–91 小节　（正在面对）

- 他对自己有些恼火：明明一直努力保持镇定，心里却还是放不下过去。他一时既想继续约束自己，又想摆脱这种处处防备自身感受的日子。 〔24–65 ③〕
- → 他又想起从前与熟悉的人相处时那种亲切和轻松。记得自己曾经那么自在，他感到真实的欢喜，暂时顾不上继续跟自己较劲；只是越觉得那些日子可亲，也越舍不得它们已经不在。 〔1–23 ①〕
- → 他渐渐明白，从前的从容并不全靠自己坚强。那时有熟悉的人可以信任，不必总担心自己会不会显得软弱，所以他才容易放松。这使他开始怀疑，单凭如今的自我约束是否真能找回过去的样子。 〔24–65 ①〕

### S04｜92–115 小节　（正在面对）

- 他仍想把自己维持得端正、沉着。虽然已经知道旧日的轻松有熟悉关系的支持，他还是不愿因为那些关系不再继续，就允许现在的自己显得比从前脆弱。 〔24–65 ①〕〔66–91 ③〕
- → 他越想恢复旧日的镇定，越会记起那时根本无须如此勉强。那份记忆本来令他温暖，现在却也让他难受：过去曾经自然拥有的东西，如今连在自己心里维持都这么困难。 〔66–91 ②〕
- → 他反复问自己，为什么连平常地安心都做不到，为什么明知道过去与现在不同，还是不能把自己安顿好。每次追问都让他更着急，却没有让他获得新的安稳。 〔66–91 ③〕

### S05｜116–147 小节　（正在面对）

- 他已经被一再勉强自己弄得疲倦，不再有多少力气维持那种强硬的要求。少了这层约束，他更直接地感到失落，也感到无人能够替他承担眼下的不安。 〔92–115 ③〕
- → 他开始觉得自己或许太苛刻了。既然从前的从容离不开那些熟悉、可信赖的关系，而如今的生活已经不同，为什么还非要自己像从前一样毫不费力地镇定？想到这里，他对自己生出一点委屈。 〔66–91 ③〕〔92–115 ②〕
- → 他仍舍不得从前那种轻松，也不愿因现在的难过便轻视自己。可是明白自己的要求可能过分，并没有让责备自己的习惯立刻停下来；他只能暂时不再逼得那么紧。 〔66–91 ②〕〔24–65 ③〕

### S06｜148–180 小节　（没在想）

- 他暂时顾不上继续责备自己，只沉浸在对往日的怀念里。那时与熟悉的人相处，他可以自然地信任别人，不必随时担心自己的感情是否合宜。想到那份安心，他心里慢慢柔和下来。 〔116–147 ①〕〔66–91 ③〕
- → 他为自己曾拥有过这样的生活感到温暖，甚至有一点欢喜。他深深舍不得那种不必处处防备、也不必证明自己足够坚强的亲近，越是安静地想着，想再拥有它的愿望就越真切。 〔66–91 ②〕
- → 他很想再有那样的日子，却知道现在并没有重新得到它。这份怀念不能使过去回来，但此刻他并不急着寻找办法，只愿让曾有过的温暖在心里多停留一会儿。 〔1–23 ①〕

### S07｜181–205 小节　（正在面对）

- 那份温柔的安宁没能一直留住他。当他想到自己如今仍没有过去那种熟悉的支持时，突然又为眼下的脆弱感到难堪：从前那么容易安心的自己，为什么现在连镇定下来都如此困难？ 〔148–180 ②〕〔148–180 ③〕
- → 他明明已经怀疑过这种自我要求是否公平，却还是忍不住拿从前的自己衡量现在。知道不该这样苛责，并不能阻止那股责备涌上来，这使他更加烦躁，也有些害怕自己始终摆脱不了它。 〔116–147 ②〕
- → 他仍然向往那种熟悉、自在的生活，甚至越是想念，就越想重新变得和当时一样轻松。可他又清楚，旧日的从容不是独自用力就能恢复的。他在渴望与自责之间久久不能平静。 〔66–91 ③〕〔148–180 ②〕

### S08｜206–213 小节　（没在想）

- 他有片刻不再追究自己为什么不够从容，只让旧日相处的温暖重新留在心里。那种曾经被熟悉的人自然接纳的感觉，仍使他眷恋。 〔148–180 ①〕〔181–205 ②〕
- → 他舍不得这片刻的亲切就此过去，却也知道自己只是想起了从前，并没有重新回到那样的生活。

### S09｜214–215 小节　（正在面对）

- 短暂的温柔过去后，他又几乎想命令自己别再眷恋，立刻恢复从前那样的镇定。 〔24–65 ①〕〔206–213 ②〕
- → 可他已经知道，旧日的安心不是靠强迫自己得来的，也怀疑过这种要求是否过分。那股强硬刚刚出现，就失去了说服自己的力量；他一时更不知道还能怎样站稳。 〔66–91 ③〕〔116–147 ②〕

### S10｜216–225 小节　（正在面对）

- 他依然想念过去，也依然希望自己能稳得住，可先前那种逼自己镇定的办法已经很难令他信服。经过反复的自责和挣扎，他感到疲惫，既回不到旧日的轻松，也不知道该怎样对待现在的自己。 〔116–147 ①〕〔181–205 ②〕〔214–215 ②〕
- → 他开始试着不再把毫不动摇当作值得尊重自己的条件。他仍会难过、仍会怀念，或许可以先允许这些感受存在，而不是等它们消失以后，才肯觉得自己还算体面。 〔116–147 ②〕〔181–205 ②〕
- → 这个念头让他稍稍松了口气，却没有使他一下子安稳下来。他还不习惯这样看待自己，旧日的生活也没有回来；他不知道下次又为自己的脆弱难堪时，还能不能这样宽待自己。 〔181–205 ②〕

### S11｜226–241 小节　（正在面对）

- 他仍没有完全安心，但开始愿意在这样的不安中维持自己的分寸。他试着不等到心里毫无波动才相信自己，而是在想念和难过仍然存在时，也给现在的自己一点尊重。 〔216–225 ②〕〔216–225 ③〕
- → 责备自己的冲动并没有走远，他仍会想恢复过去的从容，也仍为做不到而感到压力。不过这次，他开始尝试承受那份难堪，而不是每逢动摇便马上命令自己把它压下去。 〔181–205 ②〕〔181–205 ③〕
- → 这样坚持并不轻松。他有时仍怀疑自己是不是只在勉强支撑，却没有因此急着重新变得强硬。他想看看，即使这份迟疑一时消不掉，自己是否也能够继续好好对待自己。 〔214–215 ②〕

### S12｜242–253 小节　（正在面对）

- 他再次想起从前的自己。那时的他确实比较从容，却也是一个生活在熟悉关系中、可以自然信任别人的人。如今再想到这一点，他没有立刻追问自己为什么不能恢复原样。 〔66–91 ③〕〔226–241 ②〕
- → 他开始从这段记忆里感到支撑，而不只是感到自己有所不及。想到曾经有人使他安心、曾经可以那样自在地生活，他对那时的自己生出珍惜，也觉得现在的自己仍有理由保持尊严。 〔216–225 ②〕〔148–180 ②〕
- → 这种底气还会动摇，他偶尔仍觉得如今的自己不够好。但他已能让那份怀疑暂时留着，不急于用更严厉的要求把它压下去。过去的自在依然令他向往，却不再只是责备自己的理由。 〔226–241 ③〕

### S13｜254–288 小节　（正在面对）

- 他依然深深怀念从前那种自然的安心和亲近。可现在想到那些日子，他不仅会为失去它们而难过，也能为自己确实拥有过这样的生活感到欢喜。过去的温暖不必再成为今天责备自己的理由。 〔148–180 ②〕〔242–253 ②〕
- → 他感到长久以来一直压着自己的那股紧劲松开了许多。自己仍会脆弱，仍然盼望重新拥有安稳的关系，可他此刻不再因为这些愿望而轻视自己。那份原本需要费力维护的尊严，现在可以和怀念一起留在心里，使他感到一种真切的充实与力量。 〔216–225 ②〕〔226–241 ②〕〔242–253 ③〕
- → 这份力量没有使旧日生活重新开始。他仍不知道将来能否再次拥有那种不必时时证明自己的归属，也仍然舍不得已经失去的相处。想到这些，他心里还有遗憾，却不再急着要求自己把遗憾消除。 〔1–23 ①〕〔148–180 ③〕
- → 那阵强烈的充实感渐渐平静下来，他能够比较安静地面对今天的自己：虽然还不够从容，也不必因此把自己看低。他不知道以后再次难过时能否始终做到这一点，但此刻已经不需要靠恢复旧日模样，才能觉得自己值得尊重。 〔181–205 ②〕〔216–225 ③〕〔242–253 ③〕

【珠子】
### S01｜1–23 小节
- B1［主体验］（1–6）先听开头那一下沉重、郑重的和弦：它像要宣告什么，紧接着的自由上行琶音却没把这份重量接住，反而像烟雾往高处散，声音轻了、远了，悬在半空。也可以把它听成一次召唤，只是停顿里仿佛还等着回声。
- B2［另一侧面］（1–23）短句像叹息，刚冒出来就被长停顿截断；听着余音在冰冷的空气里慢慢散尽。心里明明有东西，却还分不清这份不平静究竟是愤怒、遗憾还是怀念——这是一种尚未找到对象、也尚未找到语言的失落。
- B3［另一侧面］（1–23）换一种更身体化的听法：像刚从漫长的昏沉中醒来，四周冷而空，胸口有些发紧，视线还模糊着；伸出颤抖的手去摸，摸到的却只有虚空。这里不是已经哭出来的悲伤，而是连自己身在何处都还没弄清的恍惚。
- B4［段内变化］（9–17；18–23）约9–17小节，旋律轮廓稍稍清楚，像一幕旧场景忽然回来：当时的声音、光线和某种熟悉的感觉都回来了；可记忆再清晰，过去也不会因此重新变成现在。到18–23小节，波兰舞曲的步态逐渐浮现，像身体先于意识，隐约记起了该如何迈步。这只是往前的牵引，还不是第24小节起的主题已经站稳。
- B5［另一侧面］（1–23）另一个听法是：开头那下有分量的和弦，像一个人强迫自己挺直背脊，提醒自己不能倒下；可自由琶音马上把这份郑重带回内心的游移。尊严还在，行动的方向和力气却不稳——“我不能倒下，以及我其实很想停下来。”

### S02｜24–65 小节
- B1［主体验］（24–65（旧歌质地主要在24–43））波兰舞曲的步态终于清楚了，却不像英雄凯旋；主旋律更像一首从远处传来的旧歌，你依稀记得它，却只能模糊地哼出几句。也可以把它听成两层声音：舞曲带着一点面向众人的庄严，歌声却像私人记忆里的低声哼唱。那些珍惜的东西仿佛还在，却已不能像从前那样拥有。
- B2［另一侧面］（24–65）它不是士兵的步伐，更像腿脚虚浮的人，在记忆中挪动舞步。节奏本身庄严、傲慢，旋律却脆弱凄婉；底下的伴奏还有细碎、不安的半音在蠕动。
- B3［段内变化］（38–65（38–43、52–63、56–65为局部标记））听它怎样起伏：38–43小节，音乐猛地往上推，却又退下来；44–65小节再次聚拢力量，52–63小节一带更焦灼，最后仍没有舒舒服服地落地。56–65小节连绵的三连音，仿佛把呼吸催得越来越急。
- B4［另一侧面］（24–65（24–43的姿态；44–65的自我说服））这份挺直可以听成一种强烈的自我控制。像一个人整理好衣服、抬起头，不让别人看见动摇；到44–65小节，它又像反复对自己说“我没事”：第一次还有几分相信，第二次开始努力让自己相信，说到第三次，连这句话本身都暴露出其实很在意。悲伤还在，只是不愿把自己完全交给悲伤。
- B5［另一侧面］（44–65）另一种心理动因是，44–65小节的激昂像一句“我不甘心就这样消亡”：不是轻松恢复自信，而是负隅顽抗。这股力量可以与自我控制同时存在，但不必把两种原稿的说法拼成同一个人的确定剧情。

### S03｜66–91 小节
- B1［主体验］（66–91；m.66的和弦重击为条件性细节）第66小节的和弦若被突出，会像重锤砸下，带着愤怒与抗拒；这一段强弱跳动、切分让人心口悬起。音乐离开前面的端正步态，转入更灵活、流动却不安的舞蹈性格，像想往前走，却无法平静地决定方向。
- B2［段内变化］（66–79 → 80–91）一种听法把前半（66–79）听成焦躁、急切，后半（80–91）则忽然柔和、亲切，带一点近乎田园的轻盈。有人会想到故乡夏日的麦浪与微风；另一种相近的联想，是曾经轻松、亲近、不必时时防备的时刻。温柔得让人心颤，也刺痛得让人绝望：越怀念，越能感觉它与眼前处境的距离。
- B3［另一侧面］（66–91）也可以把耳朵收进旋律里：像多个人在耳边低声絮语，彼此缠绕，找不到出口；调性又像流沙，抓不住重心，四处漂移。
- B4［另一种理解］（66–91）这股活动感也可以听成一次短暂的侧身离场：不再正面迎着那个沉重的问题，像是聊点别的，或出去走走，让注意力暂时离开伤口。那一刻的轻松可以是真的，并非假装；只是它没有替心里的事找到答案。
- B5［另一种理解］（66–91）另一个听法不是把这里听成重新获得活力，而是前一段的昂扬慢慢退潮。音乐变得流动、含蓄、若有所思，仿佛心里冒出一句自问：我刚才是真的相信那些话，还是只是在努力让自己相信？

### S04｜92–115 小节
