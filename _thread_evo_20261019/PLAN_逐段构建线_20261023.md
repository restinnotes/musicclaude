# 计划：逐段构建线（2026-10-23）

依据是你和 ChatGPT 在 10-22 晚上的讨论（`Downloads/chatgpt-分析问题解决方法-20261022.md`），加上你最后提出的解法。

## 一、我对这次讨论的理解

### 1. 问题出在线本身，不在对接

- **线自己定了每段的“这一刻”。**
  - A 路线写线时不看珠子，于是线替每段设定了一种感受，再用自己的历史去解释它。
  - 珠子写出的真实感受，没有任何东西去解释。
  - 两边一致时就是重复（4–16：“他安心靠近”和“身体交给船底的托举”是同一件事说两遍）。不一致时就是冲突（24–34：线说“他轻松下来”，珠子说“更急、手越握越紧、舍不得”）。
  - 所以换摆法（配对、穿插、压缩）都救不了。
- **线的逻辑是“编”出来的。**
  - 一种感受被拆成四五步，段内的 → 大多不是真的因果。
  - 更严重的是编出了心理剧情。17–39 小节的故事是：开始有所期待 → 劝自己不求回报 → 轻松下来 → 发现其实还想要回应 → 自我怀疑。
  - 音乐和珠子并不需要这个故事。只用前面已有的历史就能解释“第二遍为什么更急”：尝过亲近的幸福 → 开始盼它长久 → 再次靠近时更急、更舍不得。
- **为什么会编：生成规则叠在一起，把模型逼得只能编。**
  - 规则要求每段都给出“为什么此刻”，又不许看珠子，也不许由音乐推动。
  - 模型只好用自己编出的心理事件去推动下一段。
  - Center“投入与克制始终相互牵制”又会把它引向“想投入—怕投入—克制—放下—再怀疑”的来回摆。
- **选稿标准也有问题。**评委奖励的是“心理推演自洽、完整”，从没检查过这条线能不能解释珠子。
- **不说人话和上面这些同源。**
  - 一部分抽象句是在给多余的推演起名字，比如“满足照出未满足”“不拿自欺换平静”。
  - 另外，每次调用都要处理整篇文章、长提示词和很多约束，注意力落不到每一段的打磨上。
- **评估标准要改。**以前把“原稿的因果步骤丢了几步”当损失，但原稿本身就有多余的步骤。删掉多余的推演是改进，不是损失。

### 2. 你的解法：逐段构建，不先写整篇

- **从第 1 段开始，一段一段往后做：**
  1. 把到目前为止已经确立的历史喂给模型；
  2. 让它专注于当前这一段，在多份候选线对这一段的解释里挑选，必要时形成新的解释；
  3. 让它说明为什么这样选；
  4. 只把真正确立、以后仍起作用的东西写进历史，再做下一段。
- **候选池只放两类稿（10-23 你确认）：**用现行写稿提示词（N8）写的稿，以及用修正后的写稿提示词新写的稿（见第 1b 步）。B0、N5–N7 等旧稿太早，不放。
  - 这是一种新的“多稿综合”：逐段选，而且每次选都受已经确立的历史约束。
  - 之前试过的是整篇对整篇的综合，当时放弃得太早。
- **珠子可能在“挑选”这一步进来。**这一点要用实验定。
- **人话：**每次调用只处理一段，提示词尽量短。“修逻辑”和“说成人话”分成两次调用，免得改措辞时顺手偷偷改了逻辑。

### 3. 我认同的地方，以及几点补充

我基本认同，补充四点，都写进了下面的实验设计：

1. **珠子参与挑选时，要防止线变回复述珠子**（E2、E3 的失败）。线的任务是解释“这些感受为什么此刻出现”，不是再写一遍感受。评审要专门查有没有复述。
2. **逐段挑选可能让全曲散掉**：这段选 N8 的世界观，下段选 B0 的，最后不像一件事。所以：
   - 历史里要累积一个慢慢成形的 Center（开头允许还说不清）；
   - 最后做一次全曲一致性检查；
   - 发现早期选错时允许回退。
3. **写稿始终不看珠子（10-23 你确认）。**珠子最多只在后面“从前往后综合出最终的线”这一步进来，而且要看实验效果，效果不好就不用。B 路线（写稿时用从珠子提炼的 Center，即 final_round 的冠军稿和亚军稿）已经废弃。
4. **逐段构建天然满足宪法 D1 的“前缀有效”**：每段只用到当时为止的历史，不会提前用到后面才发生的事。

### 4. 和已定规则的关系（变动先写明）

| 已定规则 | 这次怎么处理 |
|---|---|
| 写线时完全不看珠子（A 路线） | 写稿仍然完全不看珠子。只有逐段综合这一步做对照：一组不看珠子，一组看 |
| 写稿的提示词（N8：先写一条完全不写音乐的主线，再落到段落上） | 可能就是逻辑被编出来的源头。新写一批稿子，和旧稿放在一起比（见第 1b 步） |
| 线不做多稿综合 | 撤销。改为逐段选择 |
| 关系图“每条一个念头”、用原稿的因果步骤清单测覆盖率 | 实验期间暂停。改为只给真正的变化建节点、不以原稿步骤为标准答案。关系图等新的线定了再重做 |
| 珠子不改写；不按线筛珠子 | 不变。珠子只作为“要被解释的对象”喂进去 |
| 线由内心经历推动，不由音乐事件推动 | 不变。珠子是检验线的证据，不是线发生转折的原因 |
| 不编外加情节；戏剧化不算缺点 | 不变。另外新增：不编没必要的心理事件（劝自己、想通、找办法又失败） |

## 二、实验

### 第 0 步：准备，不调用模型

1. **候选池**：把下面这些整篇稿逐段切开，每段标明来源。
   - **现行提示词（N8）的稿**：Op.60 共 7 篇，其中 n8_op60_r1–r3 用比赛选出的 Center，n8_op60_c6_r1–r4 用另一个 Center；多稿综合稿 c6_syn 不放。Op.61 也是 7 篇。
   - **修正提示词的稿**：第 1b 步新写，两种写法各 3 篇。
   - B0、N5–N7、review9 的 rs 稿都不放。
2. **每段的珠子输入**：从 STRUCT 逐字取出这一段的主体验和段内变化，另一种理解单独标出。不改写。
3. **写实验说明**：同时在 THREAD_SPEC 和 DAG 里注明“实验中，暂停的规则”，免得以后被旧规则误用。

### 第 1 步：试点，Op.60 第 1–4 段（1–39 小节）

**三组对照：**

| 组 | 做法 |
|---|---|
| A 现状 | 现在的 v6 关系图和它依据的 N8 原稿；B0 作参照 |
| B 逐段构建，不看珠子 | 历史 + 这一段的各候选解释 → 挑选或形成解释、说明理由 → 更新历史 → 下一段 |
| C 逐段构建，看珠子 | 同 B，另外给这一段的珠子；任务改成：哪个解释最能说明这些感受为什么此刻出现。候选池和 B 组完全相同 |

**每段调用两次，分开做：**

- **第一次，定解释。**输入是：历史、候选、（C 组还有）珠子。允许合并、删除、修正心理步骤；允许这一段没有新的变化；不准新编人物的决定或领悟；不复述珠子。输出三样：
  1. 这一段的解释；
  2. 选择理由，要写明各候选哪里成立、哪里牵强；
  3. 历史更新，只记确立、以后仍起作用的东西。
- **第二次，说成人话。**只给第一次的解释，提示词控制在几句话以内：用普通人一遍能听懂的话说出来，不改意思，不加不减。

**执行细节：**

- 模型用 gpt3 的 G6 和 G56，每组各跑 2 遍，结果标明是哪个模型。
- 第一段结果出来就检查，不对立刻停下修。
- 新的提示词从 P0 精简而来，不搬 THREAD_SPEC 里的那一长串规则。

### 第 1b 步：修正写稿这一步（和第 1 步并行，写稿仍不看珠子）

我查了 N8 写稿的提示词（`line8.py`），里面有几处很可能把模型推向“编心理剧情”：

1. **先写一条“完全不要写音乐”的主线，然后才落到段落上。**模型写故事的时候根本没在听这首曲子，故事是先编好、再套到 14 段上的。所以每段的“这一刻”只能由线自己来定。B0 没有这一步，它是边听边写的，结果它的 24–34 小节正好抓住了“第二遍更热烈”。
2. **“他每一刻的心理，都要能由前面已经发生在他身上的事说明——先前得到了什么、相信了什么、试过什么、发现了什么。”**“试过什么、发现了什么”等于在邀请模型写“找办法 → 办法失效”。
3. **P0 里“理解的积累”五种类型**（办法显出限度、选择的代价……）被当成了剧情模板。
4. **Center 事先定死**为比赛选出的“投入与克制始终相互牵制”，容易引出来回摆。

新写一批稿子（仍不看珠子），只改这几处：
- **不再先写不提音乐的主线**，改成按段边听边写。音乐依然不能当他心理转折的原因，但模型要知道这一段听起来是什么感受，因为 P0 原本要的就是“合理化每个段落的情绪”。
- **去掉“试过什么、发现了什么”这类提示**，改成：一个理由能说清，就别拆成几步；这一段可以没有新变化；不要编“劝自己、想通、找办法”。
- **“理解的积累”只作参考**，明确说明不必用。
- **Center 不预先指定。**

两种修正写法：
- **甲（边听边写）**：不先写主线，按段写；模型心里知道这一段的感受，但转折的理由只能来自前面的经历。
- **乙（只改规则）**：保留“先写一条不提音乐的主线”，只去掉上面第 2–4 处诱因。

两种都做，就能分出“先写不提音乐的主线”这一步本身有没有问题；“边听边写”是否可以用，也由结果说话。

新稿进入同一个候选池。看逐段综合时新稿被选中的比例、和珠子冲突的多少，就能判断写稿这一步的修正有没有用。

**还要你确认**：“按段边听边写”是否违反“线不由音乐驱动”？我认为不违反。所以先做实验：甲和乙两种都写，结果出来后由你判断。

### 第 2 步：人话的单独检验（和第 1 步并行，花费小）

用来检验你“上下文太多、注意力被分散”的猜想。

- **固定内容**：用现在 N8 在 4–16、24–34、103–110 三段的内容，只改说法。
- **做 2×2 对照**：

  |  | 长提示（现有规则） | 短提示 |
  |---|---|---|
  | 给整篇上下文 | ① | ② |
  | 只给这一段 | ③ | ④ |

- **要回答的问题**：缩短上下文、精简提示词，各自有没有用。结果直接用在第 1 步“说成人话”那次调用的写法上。

### 评估：先由你读，评委辅助

- **给你看的**：同一段落的 A、B、C 组并排放，标明来源。只做 4 段，篇幅不大。
- **新评委的标准**，不再看条目覆盖率和步骤数：
  1. **解释力**：这一段的每颗主体验珠子，线有没有说明它为什么此刻出现？逐颗判断：是 / 部分 / 否。
  2. **多余的心理事件**：有几处“劝自己、想通、找到办法、发现办法失败”是珠子和历史都不需要的？
  3. **历史**：用到的历史是否前面真的有过？有没有凭空新增？
  4. **跨段连贯**：读下来像不像一件事？
  5. **人话**：普通人能不能读一遍就懂？
  6. **复述珠子**：有没有把珠子的感受再写一遍？
- **三个检验**（ChatGPT 提出，我认同）：
  - **删除检验**：把线删掉，对这一段的理解有没有损失？
  - **历史检验**：把前面的历史拿掉，解释还一样吗？如果一样，说明根本没用上历史。
  - **反证检验**：把珠子的关键感受换成相反的，解释还说得通吗？如果说得通，说明这是什么都能接住的万能故事。
- **评委校准**：用已知结论检验评委是否靠谱：
  - N8 的 24–34 应该判为“没解释迫切”；
  - B0 的 24–34 应该判为“部分解释”；
  - 4–16 的四五步应该被认出是同一种感受拆出来的。

  评委答不对，就先修评委，不用它的分数。

### 第 3 步：看结果再决定（需要你拍板）

- **如果 B 或 C 明显更好**：
  - 推广到 Op.60 全部 14 段，加上全曲一致性检查和回退；
  - 然后在 Op.61 上检验，Op.61 不参与调参；
  - 再把新线转成稀疏的结构（只给真正的变化建节点）。
- **如果 C 赢了**：说明线应该接受珠子的约束。要正式修改 A 路线这条规则，并更新定义文档。
- **如果都不好**：看第 1b 步的新稿。如果新稿明显更常被选中、冲突更少，就说明问题主要出在写稿这一步，以后都用新的写稿提示词；如果新稿也不行，再回头重新想综合这一步。

### 之后：视频里一段怎么组织

线定下来以后再做。方向是：一段之内以珠子的体验为内容，用线的因果把这些内容组织起来；同时存在的侧面和先后发生的变化在画面上区分开。先拿 4–16、17–23、24–34 做文字分镜。

## 四、需要你定的（附我的默认做法）

1. **候选池的范围**：已定（10-23），只放 N8 稿和修正稿。
2. **要不要在开头给 Center**：默认不给，让 Center 随历史慢慢形成，因为开头本来就允许“还说不清”。另一种做法是先给几个候选 Center，在第 1 段时选定。
3. **每段输出的形态**：默认是几句人话加一条历史更新，先不做成关系图。
