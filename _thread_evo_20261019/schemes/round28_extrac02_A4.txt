你要一次写出一首器乐作品最终使用的Thread（线），用于在逐段听感记录旁阅读。线必须是同一个人经历的同一件事；只读线就能从一段自然走到下一段，每段也要与给定TARGETS的体验性质大体接得上。不是对音乐的解说，也不能把TARGETS中的画面、想象情节或音乐动作变成人物事实。

【段落】
{SECTIONS}

【Center（给定，不修改）】
{CENTER}
Center是回头看时能把全篇组织成一件事的中心，不是人物开头必须知道的结论，也不是每段必须复述的题目。

【已通过宏观评审的路线候选】
{ROUTES}

【珠子的体验性质TARGETS】
{TARGETS}
你看不到原珠子，也不要猜其用词、画面、人物动作或音乐细节。

【第一步：选一条适合连续交接的主干】
从ROUTES中只选一条作为base_route，不拼接路线。选择时先看这条经历能否从开头一路接到结尾，而不需要A4临时补一个外部事件、人物举动、对白、物件、场景或未建立的他人心态来跨越段落。不要把“每段都有明显转折”当作优点，也不要为了让段落相邻就改写Center。

【第二步：只在内部建立“段界接缝图”】
不要先给每段安排一个必须新增的叙事任务。先看相邻SECTION之间的每一道边界，并在内部为每一道边界记两件事：上一段结束后有什么仍然留在人物身上；下一段开始时，人物最先从这份残留中接住什么。这里记的是交接条件，不是要输出的句子，也不是新的剧情。

接缝不要求平滑。如果下一段的体验确实像被打断、突然转冷、忽然松开或注意力换了方向，可以让表面感受发生明显跳变；但跳变之后仍要看得出同一个人刚从哪里过来，旧问题是暂时被压到背后、被另一种感受盖住，还是以新的作用继续存在。反过来，如果两段本来就是同一种状态的延续，接缝可以只保留一条很薄的连续线，不必制造新认识来证明段落有区别。

TARGETS从接缝图形成时就参与，帮助判断下一段需要接住怎样的体验方向与分量，但不能成为“为什么人物突然改变”的原因，也不建立音乐强弱与人物反应的一一对应。compatible_bundle、tensions和temporal_shape只能告诉你本段可能怎样被感到，不能替接缝添加人物事实。

【第三步：让每段同时接住左边、交给右边】
按全部段落一次写完整条线。每段的文字同时满足两个方向：开头能从上一道接缝自然接进来，结尾又留下足够的东西让下一道接缝成立；但正文不要把接缝解释出来，也不要句句写“因为前面怎样所以现在怎样”。真正好的交接应藏在人物连续的心思、余波、犹豫、愿望和承受里，读者顺着读就能明白。

每段2–4条，每条只写一句完整、自然的话，只承担一件有用的事；事情少的段落用两句短句，不把一个心理过程拆成几句近义复述。允许相邻几段仍围着同一件事，只要每次接手后的作用不同或只是诚实地延续；不要求每段都新增认识，也不为了“推进”硬改人物。全篇仍只能依赖人物已经写出的经历，不新增外部事实，不断言他人未建立的隐秘心态，不把TARGETS里的意象、想象情节或音乐物理动作写成现实。

语言像普通人讲自己当时怎么过来的：具体、清楚，不用心理学式总结替代心思本身，也不为追求口语去加无关细节。TARGETS在写作时参与，使每颗珠子尽量能在本段找到情境相近的原因或处境；一段里有几种不同体验时，可以让它们落在不同条目或同一处境的不同瞬间，不必强行合成一种。若某段的听感突然变化，人物可以只是被某种感受占住、暂时顾不上原来的问题，也可以被旧问题重新撞到；不要把任何一种变化固定解释成同一种人物反应。结尾可以保持未解决。

【第四步：用“去掉段标题也能接上”作最后核对并输出】
在内部把所有text连续读一遍，暂时忽略SECTION标题和元数据。重点只查段界：上一段最后留下的东西，下一段是否真的接到了；如果下一段故意突变，读者是否仍知道这是同一件事里的突变，而不是换了故事；如果一段删掉后接缝完全不受影响，检查它是否只是重复，但真正的停留和余波不因“没有新信息”而自动删除。不要把这一步变成逐段语义差分，也不要为了修接缝新增事实。

cite只列该条真实提及或依赖的更早条目ID，包括本段前面的条目；仅主题或情绪相似不算。covers只列本段该条确有相近情境的bead_id，不为凑覆盖乱标。relation只按正文标“没在想/还说不清/正在面对”，仍在挂念或打量Center不能标“没在想”。delta_type只从接口给定六类选，情绪变强不自动算“新变化”；delta没有真正新增便留空。established只收正文中确实首次成立的重要状态、认识、意愿或选择，并准确指向那一条。uncovered_targets仅记录强行覆盖必须虚构外部事实的珠子及原因。元数据不得制造正文里不存在的交接关系。

【输出】
只输出合法JSON，不要解释、Markdown或额外字段；接口固定为：
{
  "base_route": "route_id",
  "segments": [
    {
      "sec": "S01",
      "relation": "没在想/还说不清/正在面对",
      "items": [
        {"id": "S01-1", "text": "...", "cite": [], "covers": ["bead_id"]}
      ],
      "delta_type": "新变化/后果/实行已有想法/延续/回到旧处但有新增/暂时没在想",
      "delta": "本段真正新增的心理事实；没有则为空字符串"
    }
  ],
  "uncovered_targets": [
    {"bead_id": "...", "reason": "若要覆盖就必须虚构外部事实的原因"}
  ],
  "established": [
    {"claim": "首次成立的重要认识或状态", "first_established": "Sxx-x"}
  ]
}
segments按输入段落顺序完整填列，示例中的值只表示字段形状；不增加字段。
