# Op.60｜关系图（在 v6 上修补，w27）

**Center：**对亲密的投入与自我克制始终相互牵制。

### S01｜1–3 小节　（还说不清）

- 他一想到这个人就柔软起来，很想亲近，自己也被这份心意来得突然吓了一下。
- → 他想让这份喜欢多留一会儿。
- → 眼下还没非得决定关系去向，他却舍不得就这样放下这份喜欢。

### S02｜4–16 小节　（没在想）

- 他没有躲开眼前的亲近，因为自己还不想放下这份喜欢。
  - ← 提供理由：（1–3）「舍不得放下」
- 他提醒自己不必向对方要回应，也不必总揣摩对方的反应；他也喜欢自己能不计较地关心对方。
- → 他觉得眼下两人的关系已经足够，不必急着再向对方要求什么。
- 他不敢认定这样的亲近会一直持续。
  - ← 提供理由：（1–3）「舍不得放下」
- 因为喜欢对方，他一度很想多关心对方一些；但又怕心意露得太明白会改变关系，便把分寸收了回来。
  - ← 提供理由：（1–3）「柔软起来」
  - ← 限制：（1–3）「多留一会儿」

### S03｜17–23 小节　（正在面对）

- 正因为眼前的亲近已经让他满足，他开始盼它能长久。
  - ← 提供理由：（4–16）「不敢认定」
- → 想到长久，他才发现自己能决定怎样珍惜对方，却不能决定对方是否也珍惜自己。
- → 他还没打算向对方索取答复，只是偶尔想知道自己在对方心里是不是特别，连自己也没想到竟会在意这件事。
- → 他开始在意自己在对方心里的位置，没法再像先前那样只想着怎样关心对方。

### S04｜24–34 小节　（正在面对）

- 他怕追着要回应会搅坏眼前的亲近，对方也没答应过他什么。
  - ← 提供理由：（17–23）「在意位置」
  - ← 限制：（17–23）「不能决定」
- → 他把心思转去替对方高兴，告诉自己，真心盼对方好，自己也会开心。
- → 他暂时没那么担心自己在对方心里是否特别，也不计较给了多少、不怕显得更在乎，觉得还有许多心意可给。
- → 他放开些去喜欢，也因此更珍惜两人之间的亲近；但不想让自己的心意变成催促对方回应的事，便仍给自己留着分寸。
- → 他甚至把这阵轻松当成保证，以为只要不向对方要回应，就能尽情喜欢，也不会失去眼前的亲近。
- ⟲ 仍在起作用：（4–16）「不必向对方要回应」；（4–16）「不敢认定」

### S05｜35–39 小节　（正在面对）

- 他又想知道对方是否也把他放在心上，自己的快乐终究说明不了对方的心意。
  - ← 失效：（24–34）「不会失去」
- → 他难堪地想，自己对对方好时或许也盼着被珍惜，再说自己什么都不求，就是骗自己。
- → 可他关心对方、享受亲近时确实很快乐，那时并没想着要换回什么。
  - ← 说明：（24–34）「替对方高兴」
- → 想到自己关心对方时并没想着要换回什么，他不急着替自己辩白，也不拿热情盖住难堪。

### S06｜40–50 小节　（没在想）

- 难堪没让他少喜欢，可再多给一点，也证明不了自己什么都不求。
  - ← 提供理由：（35–39）「盼着被珍惜」
- → 他仍盼被珍惜，只是不再反复琢磨对方在不在意，也不逼自己什么都不求，愿意关心时就真心盼对方过得好。
  - ← 说明：（35–39）「换回什么」
- → 他真心盼对方过得好时，暂时顾不上自己也想被珍惜；可想到自己在对方心里的位置，他还是会在意对方是否回应。
- → 他珍惜和对方的亲近，却记得对方从未答应过什么，不能因此认定对方也同样珍惜他。
  - ← 限制：（24–34）「追着要回应」
- ⟲ 仍在起作用：（35–39）「放在心上」

### S07｜51–61 小节　（正在面对）

- 他觉得这份喜欢值得留着，不舍得主动把它淡下去。
  - ← 提供理由：（40–50）「心里的位置」
- → 他知道自己愿意珍惜这份亲近，可对方愿不愿意继续，不是他能决定的。
  - ← 提供理由：（17–23）「不能决定」
- 他想把喜欢留在心里，免得对方为难，不想被期待牵着走。可他渐渐盼对方懂他的关心，只好自己消化期待，不催。

### S08｜62–71 小节　（没在想）

- 安心靠近、真心给予、独自惦念的甜，都不是等对方许诺才有，他不想再因怕受伤压住欢喜。
  - ← 说明：（4–16）「不必向对方要回应」
  - ← 说明：（24–34）「许多心意可给」
  - ← 提供理由：（51–61）「值得留着」
- → 他不再压着想亲近的心，也不再一笔笔算自己给了多少。
- → 他知道对方没给保证，却仍觉得这份喜欢值得留着。
  - ← 提供理由：（51–61）「值得留着」
- → 他也盼着对方能同样珍惜自己。

### S09｜72–77 小节　（正在面对）

- 欢喜稍落下来，他才承认自己不只想尽情喜欢，也盼对方同样渴望靠近、愿把彼此放在心上。
  - ← 唤起：（62–71）「同样珍惜」
- → 他想被对方同样珍惜，也知道不能拿真心逼对方回应，怕自己的期待成了催促。
- → 他一再想把盼望收回，却总觉得是在否认刚承认的心意，委屈之余也厌烦自己反复为难。
- 他记得，关心对方、享受亲近本身就能让他快乐，不必先等对方给出保证。
  - ← 提供理由：（62–71）「安心靠近」

### S10｜78–83 小节　（正在面对）

- 两边都舍不得，他先不替这份感情下结论，也不逼自己立刻选边。
  - ← 提供理由：（72–77）「反复为难」
- → 他怕催得对方为难，所以不要求对方回应，也不装作自己不在乎。
- → 他仍摸不准对方心意，但记得自己关心对方时本来就没想着换回什么，所以仍能温柔相待。
  - ← 提供理由：（35–39）「换回什么」
- → 他发现，反复收回盼望只会让自己否认刚承认的心意，便不再逼自己把委屈和渴望压下去。
  - ← 提供理由：（72–77）「反复为难」
- ⟲ 仍在起作用：（72–77）「同样珍惜」

### S11｜84–92 小节　（正在面对）

- 他不再逼自己压下渴望，也不急着决定去留；犹疑了这么久，他仍能为这份亲近感到高兴，这让他很感动。
  - ← 提供理由：（78–83）「两边都舍不得」
  - ← 提供理由：（78–83）「不装作自己不在乎」
- → 他曾因想被珍惜而怀疑自己的关心是不是交换，如今能承认自己也想被珍惜，仍是真心关心对方。
  - ← 改写：（35–39）「盼着被珍惜」
  - ← 说明：（35–39）「换回什么」
- → 他仍不知道对方会不会同样选择自己，却不想因为没有答案就放弃眼前的欢喜。
  - ← 限制：（72–77）「同样珍惜」

### S12｜93–102 小节　（正在面对）

- 他不只想靠近、被同样珍惜，也想把积攒的关心给对方，看看两个人能过上怎样的日子。
  - ← 提供理由：（84–92）「想被珍惜」
- → 他不再为想被珍惜自责。
  - ← 提供理由：（84–92）「想被珍惜」
- → 他觉得有许多爱可给，许多真情值得珍惜，一时像是想要的都已经有了。可对方没给新保证，他仍盼对方选择自己。
- → 他一时顾不上以后；等欢喜稍退，尚未得到回应的期待又回到心里。

### S13｜103–110 小节　（正在面对）

- 他真想和对方共享幸福，可对方没给新保证，他怕幸福只属于自己，没法不在意对方会不会选他。
  - ← 提供理由：（93–102）「想要的都已经有了」
  - ← 动摇：（93–102）「尚未得到回应」
- → 他发现，少去确认对方的心意，自己就能安心地关心对方，可还是想被对方珍惜。
  - ← 说明：（4–16）「不必向对方要回应」
  - ← 失效：（40–50）「心里的位置」
- → 他不想把所有不安都交给对方解决，也不愿因怕落空就故意把喜欢压淡。
  - ← 限制：（72–77）「同样珍惜」
- → 他仍盼对方主动靠近、把他放在心上，心里再难受，也不拿这份难受催对方，更不装作自己不在乎。

### S14｜111–116 小节　（正在面对）

- 他不再反复盘算该收住还是放开，仿佛选对了就能不受伤。
  - ← 提供理由：（103–110）「还想被珍惜」
- → 他想让对方按自己的心意靠近，不愿为了缓解难受就把期待全压给对方，催他回应。
  - ← 提供理由：（17–23）「不能决定」
- → 小心靠近、不求确认地付出、独自珍藏、尽情欢喜都曾让他真切地快乐。它们没替他等来答案，却一次次让他愿意继续靠近，也让他舍不得放下这个人。
  - ← 说明：（4–16）「不必向对方要回应」
  - ← 说明：（24–34）「许多心意可给」
  - ← 说明：（40–50）「心里的位置」
  - ← 说明：（62–71）「没给保证」
- → 以后若等不到对方主动靠近，他仍会疼，却不会因此认定先前的喜欢是假的。
- → 他仍想被这个人选择，也愿继续喜欢、尽情享受欢喜。他只是在心里不再因怕改变关系就把它收回，也不靠克制证明自己清醒。
  - ← 提供理由：（84–92）「同样选择」
  - ← 改写：（84–92）「想被珍惜」
