# 一、你们的诊断与我上一轮一致吗？

去掉小节号后，K3M2 可能更清爽、更好看，因此盲比获胜。

# 二、你们提出的灰区规则，有哪些问题？

我逐条看。

## 1. 覆盖 0.03、人话 0.25：目前还不能作为正式门槛

<badge color="warning">建议暂不定稿</badge>

你们想把灰区定为：

- 覆盖率：0.03
- 人话：0.25

方向可以，但这两个数值目前缺乏足够的校准依据。

先看已有数据。

**覆盖率：**

同内容复测差异：

| 内容 | 两次平均差异 |
|---|---:|
| w23 船歌 | 0.013 |
| w23 幻想 | 0.062 |
| K3A 船歌 | 0.013 |
| K3A 幻想 | 0.023 |
| K3M2 船歌 | 约 0.000 |
| K3M2 幻想 | 约 0.003 |

其中 w23 幻想两次差了 0.062。

这意味着：

如果你们把 0.03 设为灰区边界，某个版本即使内容完全没变，也有可能因为一次复测波动超过 0.03 而被直接判失败。

这正是你们想消除的问题。

**人话：**

同内容复测的差异：

- 0
- 0
- 0.125
- 0.167
- 0.167
- 0.583

其中 0.583 那组第二次只有三位评委，所以不能直接当作严格的四对四复测差异。但它至少说明现有评分体系存在明显的尺度波动。

0.25 也不能说已经覆盖了目前的测量误差。

还有一个值得考虑的数字问题：

覆盖率 0.03 意味着什么？

每首有 150–170 条珠子：

\[
0.03\times(150\sim170)=4.5\sim5.1
\]

也就是说，0.03 相当于约 5 条完整珠子的分值。

如果它是你们允许的真实质量退步幅度，那就意味着可以容忍约 5 条珠子的等效损失。

这个幅度究竟合理不合理，应该由内容质量要求决定，而不是由模型波动决定。

**这里有一个非常重要的概念需要拆开：**

- 测量误差：评委反复测同一内容，结果会波动多少。
- 可接受退步幅度：真实质量下降多少，业务上仍然可以接受。

这两者不是一个数。

我建议你们分别定义：

\[
\delta=\text{可接受的真实质量退步幅度}
\]

\[
\sigma=\text{评委测量误差}
\]

前者由质量要求决定，后者由复测数据估计。

不要用复测误差直接决定可以接受多少质量退步。

## 2. 灰区外直接判失败：我明确反对

你们现在的规则是：

> 候选平均比 w23 低，差距在灰区内就复测；差距超过灰区直接判没过。

这个规则的问题是：

**即使差距超过灰区，也可能只是一次不走运的测量。**

例如：

某个版本真实质量完全没变。

但本轮：
- GPT-6 两次都比较严格；
- GPT-5.6 也刚好有一次比较严格；
- 最终平均比 w23 低 0.04。

如果灰区是 0.03，就直接淘汰。

但你们已经观察到 w23 幻想同内容复测都能产生 0.062 的差异。

所以，0.03 不能同时承担两个职责：

- 决定是否需要复测；
- 决定是否已经证明质量退步。

我建议：

**灰区外可以触发更强的复核，不能仅凭一次点估计直接判定质量失败。**

除非已经有充分的历史数据证明首轮测量的误差很小，而且首轮结果满足预先规定的失败证据标准。

目前你们还没有这样的证据。

## 3. 复测后把灰区减半：这个设计不合理

<badge color="danger">建议删除</badge>

你们提出：

- 首轮灰区：0.03、0.25。
- 两轮合并后：0.015、0.125。

我理解你们的想法：

测量次数增加，结果更可靠，所以应该要求更严格。

但这里混淆了两个东西。

假设 0.03 是可接受的真实质量退步幅度。

那么复测后，它仍然是 0.03。

不能因为多测了一轮，就把业务上允许的质量退步幅度改成 0.015。

如果 0.03 是测量误差范围，那么增加测量次数确实可以缩小不确定性，但也不是简单减半。

在理想的独立测量条件下，标准误差大致按照：

\[
SE\propto\frac{1}{\sqrt n}
\]

变化。

样本量翻倍，标准误差约缩小到原来的 0.707 倍，而不是 0.5 倍。

更重要的是，你们的评委并不完全独立。

所以我建议彻底取消「复测后灰区减半」。

**同一个指标的质量底线应该始终固定。增加评审次数，改变的是我们对真实差异的确定程度，而不是底线本身。**

# 三、我建议怎么设计：固定底线、配对复测、三态判定

这是我认为最适合你们当前项目的结构。

## 1. 先把门槛分成两个概念

每项指标单独设置一个可接受退步幅度。

例如：

| 指标 | 可接受退步幅度 |
|---|---:|
| 整屏珠子覆盖 | 待校准 |
| 原稿覆盖 | 单独校准 |
| 精细 | 单独校准 |
| 整屏人话 | 待校准 |

这些数值不需要现在马上确定。

但要在看候选版本的结果之前确定，不能为了让某个版本通过而调整。

同时，根据重复评审确定各指标的测量误差。

这样才有两把尺子：

- 质量底线：到底能接受多少真实退步？
- 测量精度：目前的评委有多大能力识别这种退步？

## 2. 使用非劣效判断，而不是直接比平均数

定义：

\[
\Delta=\text{候选版本平均分}-\text{w23平均分}
\]

设允许的最大退步幅度为 \(\delta\)。

真正需要回答的是：

> 有没有足够证据证明候选版本的真实退步超过了允许幅度？

统计上可以使用配对差值的置信区间。

假设差值区间是：

\[
[L,U]
\]

那么：

| 判定 | 条件 | 解释 |
|---|---|---|
| 通过 | \(L>-\delta\) | 有足够证据表明没有超过允许的退步 |
| 不通过 | \(U<-\delta\) | 有足够证据表明退步超过允许幅度 |
| 待复核 | 区间跨过 \(-\delta\) | 目前无法判断 |

这就是非劣效判断。

这里最重要的变化是：

**不再因为点估计低于 w23 就判失败，而是看真实差异可能落在哪个范围。**

如果你们希望证明纯格式修改前后完全等效，而不只是没有明显退步，还可以采用双侧等效性判断：

\[
-\delta_{\mathrm{eq}}<\Delta<+\delta_{\mathrm{eq}}
\]

要求整个置信区间都落在这个范围内。

否则配对也会变成一种挑结果的工具。

# 四、要不要固定只许重测一次？

我的建议是：**是的，固定最多一次追加复测。但必须允许复测后仍然无法判定。**

这点非常重要。

我建议你们采用两阶段机制。

<box border radius="lg" padding={3} gap={3}>
  **第一阶段：初测**

  四位评委，候选和 w23 同区组配对评审。

  <divider color="subtle"/>
  **第二阶段：确认复测**

  如果首轮结果不足以明确判断，追加一次。

  - 更换调用编号。
  - 两个版本都重新评。
  - 四个席位保持一致。
  - 不改变提示词、模型配置、评分口径。
  - 保留首轮全部有效数据。

  <divider color="subtle"/>
  **最终决策**

  <row align="center" gap={2}>
    <badge color="success">通过</badge>
    有充分证据满足非劣效要求
  </row>
  <row align="center" gap={2}>
    <badge color="danger">不通过</badge>
    有充分证据证明质量退步超过底线
  </row>

    <badge color="warning">待复核</badge>
    两轮结束仍然无法确定
  </row>

这里我想特别强调：

**待复核不是通过，也不等于质量不合格。**

如果你们的发布流程要求必须有证据证明达到底线，那么待复核状态就暂时不能放行。

但内部迭代记录应该把它和「已证实质量退步」分开。

否则你们虽然修正了测量问题，最后还是会通过另一种方式把不确定性当成失败。

### 为什么不允许第三次、第四次？

因为会出现统计上的选择性停止问题。

例如：

- 第一次平均低了 0.02。
- 第二次平均低了 0.01。
- 第三次变成高了 0.01。
- 第四次又变成低了 0.005。

如果一直测到过线才停止，最终分数会系统性偏高。

这就是一种「测到满意为止」的偏差。

所以：

- 同一内容、同一版本，最多两轮。
- 如果还不确定，进入人工复核或正式扩大样本的研究。
- 不允许继续换调用编号，直到平均分好看为止。

还有一种情况需要区分：

如果复测后真的修改了内容，那是一个新版本，不是同一版本的第三次测量。新版本必须重新走完整评测，不能把前一版本的有利结果拼进来。

# 五、你们的校准计划是否足够？

你们提出：

> 用 3–4 个同内容版本各测 3 次补校准。

我认为可以作为初步试验，但还不足以建立正式的误差范围。

原因是目前有两个层次的差异：

1. 同一个模型家族不同调用之间的波动。
2. 不同模型家族之间的系统性尺度差异。

而且不同歌曲、不同内容复杂度，波动可能不同。

例如目前船歌和幻想的覆盖率复测稳定程度就不一样。

我建议这样做：

| 项目 | 建议 |
|---|---|
| 样本内容 | 6–10 份不同屏幕稿，覆盖不同歌曲和内容复杂度 |
| 每份重复次数 | 先做 4–6 个完整评审区组 |
| 每个区组 | 四个评委席位完整评审 |
| 提示词 | 全程固定 |
| 模型 | 尽量固定具体模型版本 |
| 记录 | 保存每位评委的逐条判断和整屏分数 |

这里的 6–10 份、4–6 轮是我建议的校准试验规模，不是保证统计精度的硬性定律。

资源不足时，3–4 份、3 轮也可以先跑，但应标记为探索性结果。

另外，不要只统计最终平均分。

覆盖率建议统计：

- 同一珠子多次评审的标签一致率；
- 留住、部分、没有各自的一致情况；
- GPT-6 与 GPT-5.6 的分歧；
- 哪些类型的珠子最容易产生分歧。

人话建议统计：

- 同一内容的重复评分差异；
- 两个模型家族的评分差异；
- 7、7.5、8 三档的使用情况；
- 与人工评分的差异。

这样才能判断你们究竟是在测量一个不稳定的指标，还是在测量一个定义本身就不清楚的指标。

# 六、我建议直接写进迭代准则的文字

下面这版是我建议你们采用的正式规则。它保留你们的灰区思想、一次复测机制和配对评估，但去掉了不合理的减半规则。

<WritingBlock id="58321" variant="document">## 绝对质量指标的门槛与复测规则

### 一、基本原则

绝对质量指标不得仅凭单次评审的平均分与 w23 历史平均分直接比较，判定候选版本通过或失败。

评审结果存在测量误差。必须区分真实质量差异与评委测量波动。

每项指标分别设定可接受的质量退步幅度和测量误差范围。两者不得混为一谈。

可接受退步幅度应根据实际质量要求预先确定，不得根据某个候选版本的测量结果临时调整。

### 二、配对评审

候选版本与 w23 应在同一评审区组内接受评审。

每个区组使用相同的评委席位、提示词、模型配置和评分口径。

每位评委分别在独立的新对话中评审两个版本，随机安排评审顺序，隐藏版本名称及新旧身份。

对每个匹配席位计算：

候选版本得分 - w23 得分。

分别统计 GPT-6 和 GPT-5.6 两个模型家族的平均配对差值，并在模型家族等权的基础上计算总体差值。

所有预先安排且有效的评审结果均须纳入，不得因结果不利而选择性删除或补测。

### 三、灰区与复测

初测结果用于判断是否需要进一步确认。

当结果的不确定性可能影响门槛判定时，追加一次确认性评审。

确认性评审必须同时重新评估候选版本与 w23，保持相同的评审配置，并使用新的调用编号。

首轮与复测结果应合并分析，不能只选择其中较有利的一轮。

### 四、最终判定

设候选版本相对于 w23 的真实质量差异为 Δ，可接受的最大退步幅度为 δ。

根据配对差值及其不确定性进行判定：

1. **通过：** 有充分证据表明候选版本的质量退步没有超过允许幅度。
2. **不通过：** 有充分证据表明候选版本的质量退步超过允许幅度。
3. **待复核：** 经过规定的评审次数，仍无法区分真实质量差异与测量误差。

如果采用置信区间进行判定：

- 置信区间下界高于 -δ：通过。
- 置信区间上界低于 -δ：不通过。
- 置信区间包含 -δ：待复核。

各指标独立判定，不允许某项指标的高分抵消另一项指标的质量退步。

### 五、复测次数限制

同一内容、同一版本、同一评分口径，最多进行一次追加确认性评审。

两轮结束后仍无法明确判定的，进入待复核状态。

不得通过反复更换调用编号、增加评审次数或选择性保留结果，直到候选版本达到门槛。

如需进一步研究，应启动预先确定扩大样本规模的评审方案，或进行人工仲裁，不得将其作为原版本的常规补测。

### 六、特殊情况：不涉及内容的修改

对于只涉及编号、格式等不改变实际内容的修改：

- 珠子覆盖、原稿覆盖等内容指标应保持等效。
- 整屏人话不得出现有实际意义的退步；如果指标包含视觉扫读体验，也允许出现合理的改善。
- 应优先使用同一评审区组的配对差值判断，而不是将不同批次的历史平均分直接比较。

如果评审提示词、模型版本、评分定义或统计口径发生变化，应重新评审 w23，建立与新口径一致的基线。

### 七、测量规则校准

灰区和可接受退步幅度应分别校准。

通过多个同内容样本的重复评审估计测量误差，通过人工质量评审和实际内容影响确定可接受退步幅度。

在完成校准之前，灰区数值只作为复测触发的临时参考，不作为直接淘汰候选版本的唯一依据。</WritingBlock>

# 七、还有四种新偏差需要防范

你们现在的改法已经开始涉及统计决策，因此有一些以前不明显的问题会变得重要。

## 1. 灰区可能变成「特殊版本的保护伞」

例如 K3M2 失败，于是给它一次复测机会。

下一版失败，也给一次。

再下一版失败，也给一次。

如果其他版本没有同样待遇，最后会出现选择性宽容。

解决方法：

- 所有候选版本执行同一规则。
- 不能因为某个版本已经投入大量制作成本，就给它额外复测。
- 不能因为某个版本是新方案，就放宽它的底线。

## 2. 配对比较可能产生顺序和记忆偏差

如果每次都让模型先看 w23，再看候选版本，可能产生锚定。

解决方法：

- 独立对话。
- 随机顺序。
- 隐藏版本身份。
- 不向评委透露历史评分。

尤其不能让模型知道：

「上次 K3M2 只比 w23 低了 0.004，这次请认真复核。」

这种信息会直接污染测量。

## 3. 两个模型家族可能存在共同偏差

即使你们做了两轮，GPT-6 和 GPT-5.6 仍可能共享某种中文表达偏好。

所以，重复调用次数增加，不等于独立判断来源同比增加。

我建议至少保留模型家族级别的结果。

如果以后资源允许，增加一个独立的人类评审组，或者一个不同模型家族，比单纯把 GPT-6 多调用十次更有价值。

## 4. 门槛可能被历史数据绑架

这是我认为最容易被忽视的一点。

如果你们以后修改了评委提示词，例如增加覆盖率的语义定义，或者给人话评分增加新的锚点：

**旧的 w23 平均分就不再是完全可比的基线。**

必须重新测 w23。

否则你们可能出现：

- 新版评委打分尺度变了；
- 候选版本使用新提示词；
- w23 仍然使用旧提示词；
- 最终把评分尺度变化当成版本质量变化。

这是另一种测量偏差。

- 盲比继续体现对无小节号版本的偏好。

如果连这个对照组都出现明显的内容指标差异，就说明评委系统仍然容易受到非内容因素干扰，不能急着用它淘汰其他版本。

# 最终结论

我认为你们已经找对方向，但还差一个关键的观念转变：

**灰区不是让不好的版本获得一次宽容，而是承认测量系统本身有分辨率限制。**

我最终推荐：

1. 保留灰区触发复测。
2. 取消灰区外凭首轮点估计直接失败。
3. 取消复测后灰区减半。
4. 每个版本最多一次追加复测。
5. 采用同区组、同席位的配对差值，两个模型家族分别报告。
6. 两轮之后仍不确定，就标记待复核，不允许无限重测。
7. 重新校准灰区和质量底线，不能直接把 0.03、0.25 当成已验证标准。

**如果只能优先改一件事，我会优先改「不确定性处理规则」，而不是继续打磨评委提示词。**

因为你们现在最严重的问题不是评委完全不会评价，而是决策系统把一个只有几千分之几的测量差异，当成了确定的质量退步。

这套问题如果不解决，即使换成更好的模型、更多的评委，也仍然可能在迭代过程中误杀真正有价值的版本。
