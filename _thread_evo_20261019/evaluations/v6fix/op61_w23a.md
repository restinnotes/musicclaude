# Op.61｜关系图（在 w20 上逐段聚焦重修 w23a）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他心里有股不肯停的劲，却说不清在等什么、舍不得什么，整个人还没缓过神来。
- → 他怕由着事情照旧就等于认了它们本该如此，便硬撑着不肯倒下，也想停一停，怕真投进去会失去别的东西。
- → 熟悉的感觉一回来，他就下意识想继续，可过去不会因此回来，他还想找个理由才敢往前走。
- → 每次刚觉得想通，舍不得又回来，连那点确信也变得陌生，他也为非得想透才肯动而难堪。

### S02｜24–65 小节　（正在面对）

- 他不想再等到心里全明白，先把自己能做的一份接下来。
  - ← 改写：（1–23）「非得想透才肯动」
- → 没把握时，他仍带着疑虑尽力，不再反复问值不值，越投入越有力量，也越觉得痛快，多少有些骄傲。
- → 心里的不满总算有了去处，他想把能给的都给出去，暂时顾不上反复琢磨自己，也不因一点软弱停下。
- → 他仍惦记着那些珍惜的东西，如今却不能像过去那样自然地拥有。
- → 他努力让自己显得没事，越是强撑，越显出他其实很在意。
- → 可一想到仍放不下的事，刚撑起的劲又泄了，他越发焦急，始终安顿不下来。
  - ← 限制：（1–23）「怕真投进去」

### S03｜66–91 小节　（正在面对）

- 他真往前走了，少问自己该不该走，也庆幸没退，可他还是拿不准该往哪使劲，心里恼火又不甘。
  - ← 提供理由：（24–65）「珍惜的东西」
- → 他想要自在亲近、不必时时防备的生活，想到它便松口气，眼下还做不到又难受，却仍顺着轻快过了一会儿，不急着问自己为何非得用力。
- → 轻松退去，眼前的难处还在，他又想起当初不肯再等、先做能做的那一份，也怀疑刚才那股劲是不是真心。
  - ← 唤起：（24–65）「能做的一份」
- ⟲ 仍在起作用：（24–65）「刚撑起的劲」

### S04｜92–115 小节　（正在面对）

- 轻松退去后，他还记得那一步确实让自己重新动起来，所以仍愿意坚持。
  - ← 唤起：（66–91）「不肯再等」
  - ← 提供理由：（24–65）「带着疑虑尽力」
- 他真尝过那份亲近带来的快乐，当时的坚定也有他努力撑住自己的成分，可眼下不安没让他认定那一步错了。
- → 他怕停下就得承认那份亲近回不到从前，便硬撑着把自己催得停不住，脑子反复追问过去还能怎样。
- → 可他还想要那种不用防备的亲近，光靠坚持仍没法让他安心。

### S05｜116–147 小节　（正在面对）

- 那一步曾救他脱离犹豫，行动明明还不够，他却舍不得松手，怕承认失望就是变心，便逼得更紧。
  - ← 提供理由：（92–115）「重新动起来」
- 他想到那种不必防备的亲近，心里便软下来，却怕自己一软就停步。
  - ← 唤起：（92–115）「光靠坚持」
  - ← 说明：（92–115）「反复追问」
- → 他明明受苦、也想停一下，却把难处当成还没克服的迟疑，仍逼自己往前。
- → 他曾在行动中感到有力量，便要求自己一直撑住，一累就怪自己不够坚定，连歇一下都觉得不该。
  - ← 提供理由：（24–65）「带着疑虑尽力」
- → 他发现自己明明已经累了，还在逼着一个累了的人硬撑，终于不想再证明自己多坚强。
- → 他有些茫然，终于松了劲，却没因此安心下来，这才肯承认自己舍不得那种不必防备的亲近。
- ⟲ 仍在起作用：（92–115）「光靠坚持」

### S06｜148–180 小节　（没在想）

- 他不再逼自己硬撑后，发现自己舍不得的不是一时舒服，而是曾真心相信过的生活。
  - ← 说明：（116–147）「不必防备的亲近」
- → 他盼着人与人亲近时不必时时防着受伤，珍惜的东西也不必靠争抢才能留住。
  - ← 提供理由：（24–65）「珍惜的东西」
- 难过不用向别人解释，付出只因喜欢，也不用反复证明自己值得被爱和接纳。
- 他不想把这份向往说成软弱。
  - ← 提供理由：（92–115）「亲近的快乐」
- → 他只想先珍惜这份向往，不急着问能不能实现，也不拿责任来衡量它有没有用。
- → 他刚肯承认这份向往时还有些迟疑，后来不再逼自己装坚强，委屈和思念渐渐浮上来，渴望也越发迫切。
- → 他重新感到满足，心也柔软下来，疲惫暂时淡去，一时不想把心思拉回现实，可那种生活仍没来到。

### S07｜181–205 小节　（正在面对）

- 熟悉的亲近忽然变真切，他身体先绷紧，才想起那种生活没回来，懊恼自己刚沉进满足就忘了还有事要面对。
  - ← 提供理由：（148–180）「不想拉回现实」
- → 他不甘心只在心里怀念那种生活，因为当初不肯再等，就是怕珍惜的东西继续受损，光怀念护不住它们。
  - ← 唤起：（66–91）「不肯再等」
  - ← 提供理由：（24–65）「珍惜的东西」
- → 他想重新投入，却不敢毫无顾忌，怕自己又只顾硬撑，把刚找回的温柔磨掉，连想争取的心也没了。
  - ← 提供理由：（148–180）「渴望也越发迫切」
  - ← 改写：（1–23）「怕真投进去」
- → 他知道再等下去会失去珍惜的东西，也怕争取时磨掉温柔，心里反而更难定下来。

### S08｜206–213 小节　（没在想）

- 为难时，先前那份柔软又浮上来，他舍不得马上把它压下去。
- → 他愿意再爱惜片刻，把没答案的事先搁一边。
  - ← 提供理由：（148–180）「不想拉回现实」
- → 他心里暂时松下来，知道这点安静留不久，仍觉得欢喜，也舍不得它退去。

### S09｜214–215 小节　（正在面对）

- 安静过去，他又像当初那样不知道该怎么办，觉得自己走了这么远，心里很挫败。
  - ← 唤起：（206–213）「安静留不久」
- → 他舍不得那种不必防备的生活，也承认自己有些胆怯，怕一往前又把自己逼得太狠。
  - ← 改写：（148–180）「不必时时防着受伤」
- ⟲ 仍在起作用：（181–205）「磨掉温柔」

### S10｜216–225 小节　（正在面对）

- 他知道自己舍不得什么，可先前硬撑的疲惫还在，眼下提不起劲。
- → 他记得行动曾让自己重新有了力气，那种安宁也确实安慰过他。
  - ← 提供理由：（24–65）「带着疑虑尽力」
  - ← 提供理由：（148–180）「渴望也越发迫切」
- → 他想往前护住那种安宁，却怕又只顾硬撑，歇下来又放不下那些妨碍它的事。
  - ← 提供理由：（181–205）「光怀念护不住」
- → 他想着自己要护住的还是那种安宁，歇一歇也不等于把它丢下。
- → 他还想不出怎么两边都顾到，却不愿把任何一边说成错的，也没那么觉得非得舍掉一边才能往下走了。
- ⟲ 仍在起作用：（116–147）「逼着硬撑」；（214–215）「不必防备」

### S11｜226–241 小节　（正在面对）

- 他心里仍没底，开始重新想眼前还能承担什么。
  - ← 提供理由：（216–225）「非得舍掉一边」
- → 他已经试过，行动带来的力气并不能消掉对那种生活的牵挂。
  - ← 说明：（24–65）「带着疑虑尽力」
- → 他想到，难处不在自己不够坚定：行动给他力气，那种生活给他安慰，两样都舍不得，却很难不伤到其中一样。
  - ← 改写：（116–147）「把难处当成迟疑」
  - ← 提供理由：（148–180）「说成软弱」
  - ← 限制：（181–205）「磨掉温柔」
- → 想到要付出的代价，他心里还是疼，盼着别失去太多。
- → 他没想出两全办法，也怕争取伤到安宁，可不争取也护不住珍惜的东西，他仍带着怕先去争取。
  - ← 提供理由：（181–205）「光怀念护不住」
- ⟲ 仍在起作用：（181–205）「磨掉温柔」

### S12｜242–253 小节　（正在面对）

- 他接着做眼前该做的事，久违的昂扬又回来了。
  - ← 提供理由：（226–241）「带着怕先去争取」
- → 他不再逼自己每次尽力都得改变一切，能做多少就先做到多少。
  - ← 限制：（226–241）「两样都舍不得」
- → 他舍不得那种不必时时防备的生活，也愿为真心爱惜的一切负责，不再把这份牵挂当成行动的拖累。
  - ← 改写：（226–241）「两样都舍不得」
- → 想到争取仍可能伤到那种生活，他心里又晃了一下，还是带着不安按自己的决定往前做。
- ⟲ 仍在起作用：（226–241）「带着怕先去争取」

### S13｜254–288 小节　（正在面对）

- 从前他怕一往前做就会把刚找回的温柔磨掉，便想退回安宁里护住那种生活。
  - ← 提供理由：（181–205）「磨掉温柔」
- → 他带着对那种生活的牵挂继续往前做，发现眼前的事也在替它争取，旧愿反而近了些。
  - ← 提供理由：（181–205）「光怀念护不住」
  - ← 提供理由：（226–241）「带着怕先去争取」
- → 他不再嫌自己肩上有事还惦记那种生活，发现这份惦记和眼前该做的事都推着他向前，心里很高兴。
  - ← 改写：（226–241）「两样都舍不得」
  - ← 提供理由：（226–241）「带着怕先去争取」
- → 他又尝到当初相信那种生活时的快乐，知道这份快乐是真的，却还没真正过上那样的日子。
  - ← 唤起：（148–180）「渴望也越发迫切」
  - ← 说明：（148–180）「不想拉回现实」
- → 他知道再使劲也未必能让那种生活回来。
  - ← 限制：（226–241）「两样都舍不得」
- → 他愿意为那种生活吃苦，也会想想再使劲会不会把刚找回的温柔搭进去。
  - ← 改写：（181–205）「磨掉温柔」
  - ← 限制：（226–241）「两样都舍不得」
  - ← 提供理由：（226–241）「心里还是疼」
- → 真到了要承受代价的时候，他还是可能累得想退回安宁。
  - ← 提供理由：（226–241）「心里还是疼」
- → 他松了口气，不再反复找理由证明自己该往前，仍清楚知道那种生活是自己想要的。
- ⟲ 仍在起作用：（148–180）「不必时时防着受伤」；（242–253）「带着不安」
