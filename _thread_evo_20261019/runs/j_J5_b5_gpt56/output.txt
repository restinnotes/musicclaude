总体排序：**D > E > B > C > A**。前两篇真正让“先前发生过的事”改变了后面的人怎么问、怎么说、怎么承受；B 的音乐—心理转换很细，但人的处境较少具体抓手；C 有清楚的线，却更接近观念化模型；A 的音乐知识不少，但最明显地中了“答案先写好，再逐段证明”的问题。

### 文章A

**什么在变 / 为什么 / 留下什么：**
在变的是主人公对幸福的要求：最初要的是“能够反复回来、因此可以信赖”的安稳，后来逐渐改成允许美好变化、允许另一种自由，并最终愿意主动投入而不索取永久保证。这个变化主要由第一主题的再现、A大调中段、78小节的 *dolce sfogato*、以及最后两次强力落点推动；结尾保留了未来仍会变化、仍可能担心和失去的事实。

问题是，这条变化在文章真正开始以前已经被完整宣布了——“美好不能靠留住来获得”“不能要求它永远不变”，后面很大程度是在执行这份提纲，而不是让读者自己经历到它。fileciteturn0file0L3-L19 所以我明确判 **F2**；而35—71小节连续出现“可靠之外还要自在→变化也能带来回应→幸福给予活力”这种逐段升格，也有明显 **F3/F7**，并靠近预制的“航行—安稳—松手” **F6**。fileciteturn0file0L101-L123 fileciteturn0file0L153-L209

**最好的一处：72—83小节。** 这里先真正承认“重来并不能保存原来那个时刻”，再让78小节的轻盈成为“不急着证明”的具体经验；这不是简单的由忧到喜，而是前面的多次回归已经改变了“再次得到”的含义。fileciteturn0file0L211-L237 fileciteturn0file0L239-L275

**最差的一处：35—71小节。** 各段虽然逻辑连贯，却太像一架概念阶梯：每一段负责发现一种更高级的需要，几乎没有哪一刻被允许只是停留。读者能理解，但很难忘记作者正在解释“这一段应该意味着什么”。

音乐方面反而相当可靠：A♮带来的转向、A大调中段、78小节、84和93的再现关系、103以后不立即收束以及111后的平息，都抓到了真正特殊的位置。额外写一个自称不存在的“117小节”不是音乐事实造假，但作为文章编辑结构很多余。

### 文章B

**什么在变 / 为什么 / 留下什么：**
在变的是“要不要把真正的感情说出来”。开头他怕一句话太响而保持沉默；熟悉主题让沉默显得安全，中段陌生而自由的歌声却使他越来越不能满足于只是旁观，到84小节以后，旧主题已经必须用更大的声音唱出来。最后仍未解决的是：对方究竟如何回应，以及这份亲近以后能否持续；文章只让他伸出手，而且不再缩回。fileciteturn0file1L345-L359

这篇的优势是，同一个动作——**声音太响 / 是否开口**——确实被整曲改变了。84—92小节尤其好：最初的轻声不是被否定，而是已经“容纳不下现在想说的全部东西”，所以强奏有了人的理由，而不仅是“音乐变强，所以感情变强”。fileciteturn0file1L223-L251 93—102小节又让原来轻快的新歌进入主调后变得有风险，前面的快乐因此成为后面害怕失去的原因。fileciteturn0file1L253-L279

**最好的一处：84—102小节。** 回归不是复读，而是旧的“不要惊动”已经不够用了；第二主题回归时也因主人公已投入得更深而产生新的危险感。这正是好的 accumulation。

**最差的一处：40—50小节。** “想起刚认识时”的回忆比较泛用，略像为了给A大调贴上“陌生、新鲜、对方有独立面貌”的标签而临时补出的背景。fileciteturn0file1L97-L121 不过51小节以后它确实发生了作用，所以我不判F4，也不判F5；大量水光比喻虽然很多，还没有淹没主线。

音乐描述整体很可信，尤其对A♯长期悬留、78小节开头跳进的回声、100附近A♯—E的紧张、103落点与111后的真正缓解都写得具体。

### 文章C

**什么在变 / 为什么 / 留下什么：**
主人公最初把亲近理解成“另一条声音继续回应我”，后来逐渐能够把对方不跟随自己、唱出另一种旋律，也理解成亲近；最终所谓安稳不再意味着把运动停住，而是能够在运动中坐稳。推动它的是A大调材料从“陌生声音”到62小节仿佛对方主动开口，再到93小节两种材料真正同处主调。结尾依然没有保证两个人会始终一致，只改变了主人公对“不一致”的解释。

**最好的一处：62—83小节。** 把62小节理解为“此前主要回应、倾听的人终于自己唱起来”，随后72—77小节主人公想去抓住，却因为明白这种快乐来自对方能自由唱自己的旋律而停手，这两步是真正的因果，而不是情绪标签。78小节因此才有“不再追问”的资格。fileciteturn0file2L33-L42

**最差的一处：51—61小节。** 这一段主要是亮音、水波、倒影、再次盼望亮音的描摹，人物所求几乎没有被进一步具体化。fileciteturn0file2L29-L30 单独作为停留并非错误，但放在这篇本来就较抽象的文章里，会让主线一度接近“音响描写接力”。

我判 **F3、F6**：不是因为它没有线，而是因为这条线相当接近“从需要安稳，到承认他者独立，再到学会不固定”的现成哲学模型；人物本身缺乏足够具体的生活阻力，所以不少句子只能由“回声、方向、落脚、安稳”这些抽象关系承担。

音乐可信度仍然不错。唯一我不愿硬判的是35—39小节直接称为“升F小调的阴影”：A♮及向A大调的转接当然可信，但把整个过渡明确钉成F♯小调，我对此**不确定**。fileciteturn0file2L21-L22

### 文章D

**什么在变 / 为什么 / 留下什么：**
真正变化的不是“她终于接受他要走”，而是**她要求这段关系替她保证什么**。最初她想让他延期；后来发现这个机会本来也是自己曾经真心希望他得到的，于是开始听他究竟为什么想去；再后来，十天异地经历让她意识到“每天通电话、每次都说挺好”可以同时是安慰和遮蔽，于是她最终放弃的是一个完美保证，换成“困难也可以告诉我”的更难实行的亲密。fileciteturn0file3L93-L105 fileciteturn0file3L129-L149

结尾完全没有解决距离：他第二天照样走，他们仍可能忙、逞强、误解，刚学会的坦白还需要以后反复练习。fileciteturn0file3L229-L247 最后的“第三阶滑”又把开头日常照顾的旧意义带回来，却没有假装两人从此同步。fileciteturn0file3L255-L271

**最好的一处：51—83小节。** 尤其是“两个独自难受的人，在电话里互相讲了一个愉快的晚上”。这不是一句观点，而是一段已经发生过的失败；正因为那个办法曾经真的安慰过他们，72小节以后她才有理由放弃“每天都打”的保证。随后78小节，她先交出自己当年没有说的停电夜，音乐的轻盈于是对应一种新的、实际付出过代价的亲密。fileciteturn0file3L95-L105 fileciteturn0file3L151-L173

**最差的一处：103—110小节，且只是相对而言。** “已经站稳主调，但真正费力的部分没有结束”略接近常见的抽象解释；不过车票、明早送行、衣袋等动作仍把它牢牢钉在人物处境中，所以没有滑成F3。fileciteturn0file3L223-L247

这篇我不判任何F1—F7。它每段都有事件，但不是“每段配额”，因为后段的决定经常由前面具体失败造成，而不是由作者规定下一段该升级。

音乐方面有一个明确硬伤：4—16小节写成了“**六八拍**”，而此曲记谱是 **12/8**。fileciteturn0file3L11-L17 除此之外，对35小节转向、78的特殊质地、84与93的回归、103后仍维持强烈推进和111后的收束都很可信。

### 文章E

**什么在变 / 为什么 / 留下什么：**
在变的是主人公对“她离开”这件事的理解：起初他把她的迟疑当成两人关系出现裂缝，后来听见她对新生活既兴奋又害怕，才明白她要走不是因为旧生活虚假，而是她确实有一个不完全包含他的愿望。最后他不再试图问“那我呢？”来迫使她二选一，而是提出一个更有限、也更可承担的要求——让他知道她在那里真实、琐碎的生活。

结尾保留得很好：她会不会喜欢那里、两人能不能经得起久别、信会不会一直写，都没有答案；甚至“她此刻真的想写”与“以后怎样由以后的日子承担”被明确分开。fileciteturn0file4L239-L267

**最好的一处：93—110小节。** “我也舍不得。可是我还是想去。”使两个真相同时成立，而且没有用一个取消另一个；随后他差点问“那我呢”，最后改成“愿意写信告诉我吗？不用有什么特别的事”。这是真正的回应改变：他仍然有同样的害怕，但开始把要求从“选择我”变成“让我认识你在那里怎样生活”。fileciteturn0file4L187-L209 fileciteturn0file4L213-L235

**最差的一处：24—34小节。** 用共同旧事来确认“最重要的东西没有变”，随后马上在35小节收到离城消息，结构略显刻意，像特意先把“旧日保证”垫高再打破。fileciteturn0file4L39-L53 但这个确认后来确实被重新解释，并非无效铺垫。

这篇没有明显F1—F7。它表面上同样涉及“放手”，但关键不是学习一句“爱就是放手”的结论，而是一步步改变他实际会问什么：先不敢问、想让她留下、差点问“那我呢”、最终问“告诉我你在那里过得怎么样”。因此我不判F6。

音乐事件整体位置可靠；尤其62小节把“熟悉的姿态落在不同调性”与她熟悉的热情投向另一种生活联系起来，93小节两种世界在主调中相碰，103以后又拒绝假装问题已经解决，都是较有辨识度的写法。
