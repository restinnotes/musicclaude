## 一、那次讨论的结论，和用户追加的想法

**讨论结论**（你当时的诊断）：
- 线（A 路线，写稿不看珠子）自己定了每段的“这一刻”，所以和珠子要么重复、要么冲突；
- 线的逻辑被编出来了，例如 N8 在 17–39 小节写的“劝自己 → 轻松 → 发现仍想要 → 自我怀疑”；
- N8 写稿提示词里有诱导编戏的规则；
- 选稿标准奖励的是心理推演完整，没考察能不能解释珠子；
- 不说人话，可能和上下文太多、任务太杂有关。

**用户的解法**：逐段从前往后写。把到当前为止的历史喂进去，让模型专注当前这一段，在多种候选解释里挑，并说明理由。珠子可能在这一步进来，要做实验看效果。

**之后用户陆续确定的**（见 `01_规划与定义/THREAD_SPEC.md` §十）：
1. 写稿始终不看珠子；珠子只在“从前往后综合”时进来；B 路线（写稿时借珠子定 Center）废弃。
2. 候选池只用现行（N8）稿和修正稿，不用 B0 这类旧稿。后来又决定连 N8 也去掉，见下文。
3. 输出要简洁，参考你那次讨论里的示例句。
4. 写稿阶段只评宏观视野，不按珠子评、不被珠子困住；珠子在综合时结合进来。评委每个判断都要写理由。中间产物不给用户读，只给成品。
5. 线的最终形态就是关系图（10-21 定稿的 v4.3 形态），而且在综合时直接写成关系图，省掉“散文 → 关系图”这一步。
6. 对接（线和珠子怎样在屏幕上一起出现）也由我来做。
7. 尽量多做迭代：评委、GPT 顾问、我自己三方都评，改了再跑。
8. 降智用水杯题测，每个账号测一次就够。
9. 不要并发上限，也不要自动停用标记。

## 四、现在没解决、要讨论的问题

1. **“多路保留”和用户本来的意思不一样。**
   - 用户原话：“每一段给出很多理解然后放到 pool 里然后按照说服力排序……然后之后可以从前面挑”。
   - 我实际做成的是：每段的理解接在某一条路的历史后面写；只留 3 条路；由评委按“到目前为止的整条路”剪枝；被剪掉的不能回头再挑。
   - 我当时担心各段独立排序再拼起来会前后接不上，但这样改掉了用户要的三样东西：大池子、按说服力排序、能回头挑。
   - 我建议的池子做法：每段同时写 6–8 种理解，每种写清楚“需要前面发生过什么”（前提）和说服力（附理由）；由另一个模型排序；再从前往后挑，选前提和已选内容接得上、说服力最高的那种，必要时回头换。
2. **抽象和啰嗦来回摆。**
   - v8 很短，但抽象（“那份模糊的盼望在亲近中初次有了方向，因此他尝到温柔的满足”），看不出为什么会这样发展。
   - 第 6 轮具体了，但一条里塞了两三个分句，读着啰嗦。
   - 目标是“具体又简洁”，怎么同时做到还没解决。
3. **候选的形态：用户提议先把修正稿整理成关系图，再拿去当候选。**
   - 现在喂给综合的是散文按段切开，每段几百字，模型会照着散文的口气写。
   - 以前 N8 也是先整理成关系图再用的。
   - 风险：以前散文转关系图时出现过一个感受拆成多步、抽象标签变多。
4. **N8 是否完全不用。**
   - 用户认为修正稿已经证明比 N8 好，N8 不该再用。我已经从候选池去掉了 N8（第 6 轮是在这之前启动的）。
   - 但准确地说，只有 d9S 在宏观评审上稳定胜过 N8；N8 的洞见评委仍认为很强，说它“适合提供洞见，不如 d9S 适合作底稿”。
   - 待定：候选池只留 d9S 三篇，还是 9 篇修正稿都用。
5. **珠子里的比喻能不能变成他的动作。**
   - 第 6 轮 Op.60 的开头是“有句话忽然快到嘴边……”，取自珠子里的比喻“像一个人准备对很亲近的人说一件想了很久的事”。
   - 这样写更具体，但越过了“珠子里的画面是听者对音乐的形容，不是他身上发生的事”这条规则。用户还没表态。
6. **评委可靠性。**
   - 用户一眼看出的问题，评委常常漏掉：v7 开头说死，两位评委都给了 8 分；v8 很抽象，评委给“人话”打 7–8 分。
   - 评委逐段判“是 / 部分 / 否”时几乎全给“部分”，噪声很大；整体排名比较稳定。
   - 同一提示词重跑一遍、用来估计噪声的那次（60i），评审调用全都失败了，所以还没测出噪声有多大。
7. **Center。**
   - 曾经是在润色那一步里顺手写的，结果是一句罗列（“未明的期待、亲近中的欲望与深切喜欢，都和彼此心意未必相通的疑问交织在一起”）。
   - 已经改成单独一步，还没跑出结果。
8. **账号。**
   - gpt3 在十几个调用同时跑的时候返回了 `UPSTREAM_UNUSUAL_ACTIVITY`。之后改用 gpt4：水杯题答对（8），长输入也能正常处理。
   - 用户要求不设并发上限，也不要自动停用标记。
