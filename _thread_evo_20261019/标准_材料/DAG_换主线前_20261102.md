# DAG：一首新作品 → 最终的珠子 + 线

地位：和 `THREAD_SPEC.md` 同等。所有迭代都是在改这个 DAG；流程、提示词、模型、节点有任何改动，先改这里，并在文末“修订记录”里记一笔。

模型路由：所有 GPT 调用默认走 gpt3（GPT-6 Thinking max / GPT-5.6 Thinking max），gpt3 一报错（用量上限、保护信号或连续失败）就由 `evo.call` 自动切回 MimicGate（GPT-6 / 5.6-sol High），标记文件 `runs/gpt3_down.txt`；Argon、Gemini 的节点不受影响。

每个节点链接到提示词快照：“模板”是脚本里的原样，“实发”是一次真实运行发出去的完整提示词（Op.61）。改了提示词就跑 `python dag_export.py` 重新导出到 `DAG/prompts/`。

图例：✅ 能直接套用到新作品　⚠️ 有已知问题，见“状态”一栏　🧪 试验中，还没定为生产节点　🗄 已被替代，留作记录

```mermaid
flowchart TD
  W[新作品：曲名 + 小节数] --> N01[N01 分段<br/>查公开曲式表]
  W --> N02[N02 A 稿 ×24<br/>4 模型 × 不联网/联网 × 3]
  N01 --> N03[N03 珠子<br/>pool→gen→rev1→rev2→final→piece→fix]
  N02 --> N03
  N03 --> N03h[N03h 珠子去编辑句]
  N03h --> N03i[N03i 珠子语言：开放评审→只改语言→逐颗核对听感内容]
  N02 --> N04a[N04a Center：读 24 份 A 稿]
  N04a --> N04b[N04b Center：写关系句]
  N04b --> N04c[N04c/d Center：测专属性、解释力，挑一句]
  N04c --> N05[N05 写稿：主线→成文 ×3，盲读挑一篇]
  N01 --> N05
  N05 --> N06[N06 转关系图]
  N06 --> N07[N07 抽词义]
  N06 --> N08[N08 通用改写：不标关系、句中引用、压缩]
  N07 --> N08
  N08 --> N09b[N09b 人话改写：整条用说话口气重说]
  N07 --> N09b
  N09b --> N09[N09 开放评审：不给分类，问通不通顺、是不是人话]
  N09 --> N09c[N09c 按评审改]
  N09c -->|下一轮评审| N09
  N09c --> N09w[N09w 逐字精读：脚本按原文替换字词]
  N09w --> N10[N10 测量：覆盖 / 单独读 / 清单 / 盲评]
  N10 --> N10c[N10c 提覆盖：带接不上的珠子重写弱段，只留变好的段，可多轮]
  N10c --> N10g[N10g 守覆盖：逐段不得低于上一版]
  N10g --> N11
  N03h --> N10
  N11[N11 补漏：被≥2份盲评点名的段重写]
  N11 -->|再测| N10
  N11 --> N12[N12 合写：线和珠子逐字排列，只显示小节号]
  N03i --> N12
  N12 --> OUT[最终：珠子 + 线]
```
