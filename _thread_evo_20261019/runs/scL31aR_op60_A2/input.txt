下面是同一首钢琴曲的几条 Thread 人物经历候选。候选路线会附在本提示词末尾。

你完全看不到珠子，也不要根据音乐细节评判。

你的任务是筛选出真正能够写成一条独立成立、简洁、像真人经历、并且持续向前发展的 Thread 的路线。

不要优先选择最戏剧化、最完整、最主题鲜明或情绪变化最多的一篇。优先选择每一段都有独立推进贡献、前后不能互换、不会重新经历同一个两难的路线。

【第一步：逐条进行结构硬检查】

以下检查不是普通评分项，而是进入下一步的必要条件。

1. 单一事件：从头到尾是否确实是同一个人在经历同一件事，而不是多个心理主题串在一起。

2. 段落贡献：逐段检查每个段落的 `payload_type` 和 `delta`。每段是否真的增加了一个此前没有成立的认识、所求、代价、选择、实行结果或新后果？

如果某段只有情绪变化、同义反问、重复担忧、重复回忆、重复宣布选择，或者只是把前一段换一种说法，判定该段没有独立推进贡献。

3. 语义重复：不要只比较文字是否相同。将语义相同或非常接近的认识、问题、愿望、代价、选择归为同一类。

特别检查：
- 同一个两难是否被改写成多个不同的反问句。
- 同一个认识是否先成立，后来又被当成新发现。
- 同一个选择是否已经作出，后来又被重新宣布。
- 同一个事实是否被反复拿来证明同一个结论。
- 同一个担忧是否只改变了强度或措辞。

4. 新问题的真实性：后面再次出现一个旧问题时，是否真的有新的事实、新认识、新代价、新所求或新选择改变了问题的性质？如果没有，就算重复，不得因为表达方式不同而判定为新问题。

5. 因果依据：每一次真正的变化，是否有前面已经发生的事实作为根据？特别检查突然出现的羞愧、委屈、害怕、自尊、价值判断、新欲望和作者直接宣布的人物成长。

6. 事实账本：人物是否记得自己已经知道、已经选择、已经承认或已经放弃的东西？后文是否重新把已成立的事实写成未知？

7. 选择状态：已经成立的选择是否被后文直接承受？如果人物改变选择，是否有新的内部依据？不能只因为音乐情绪发生变化，就让人物重新犹豫。

8. 单段必要性：删除某一段，是否会失去一个独立的新认识、新所求、新代价、新选择或后果？如果删除后故事的发展基本没有损失，该段很可能只是重复填充。

9. 人物可信度：人物是否像一个人在经历事情，而不是作者不断替他分析心理结构、制造新的领悟或为了音乐制造高潮？

10. 外部事实约束：是否偷偷使用了没有建立的对方动作、隐秘心事、第三人、外部事件或其他新情节？

【第二步：硬性淘汰规则】

符合以下任一情况的路线，不得进入 A4：

- 有任何段落没有独立推进贡献。
- 同一个核心问题反复出现，却没有新的事实、代价、认识或选择改变其性质。
- 同一个认识、愿望或选择被两次以上当作新变化。
- 已经成立的选择在后文无依据地重新变成未决定状态。
- 主要靠情绪加强、反问换词、反复回忆来制造段落数量。
- 路线容量不足，无法支撑全部音乐段落。
- 重要变化没有前因，或者必须编造外部事实才能成立。

核心矛盾可以始终没有解决，但不能因此在每段重复提出同一个问题。

【第三步：评分和排序】

只有通过硬检查的路线才进入评分。

分别给每条路线：
- coherence：1–10
- forward_motion：1–10
- prerequisite_integrity：1–10
- non_repetition：1–10
- human_plausibility：1–10
- arc_capacity：1–10
- 主要问题
- 重复内容聚类：注明首次成立位置和后续重复位置。
- 逐段贡献检查：注明每段新增的内容及其依据。

排序时优先比较 `non_repetition` 和 `forward_motion`，然后比较因果完整性、人物可信度和整体连贯性。其他分数再高，也不能抵消结构硬检查失败。

【第四步：选择】

最多选择 3 条进入下一步，按照优先顺序排列。

只选择通过全部硬检查的路线，不得为了让 A4 有路线可写而降低标准。

如果没有任何路线通过，`selected_routes` 必须为空，并明确要求重新生成 A1 候选，指出需要解决的结构问题。不得将最不差的失败路线伪装成合格路线。

不得改写候选，只能选择和诊断。通过的候选路线必须完整原样复制到 `selected_routes`，供 A4 使用。

【输出格式】

只输出 JSON：

{

      "section_audit": [],
      "主要问题": []
    }
  ],

  "rerun_guidance": []
}
