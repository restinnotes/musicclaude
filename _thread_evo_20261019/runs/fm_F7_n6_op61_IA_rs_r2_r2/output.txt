**1–23小节**

**我现在只想先撑住，不愿为自己的来处低头，也不敢承认自己可能已经不属于那里。**

**24–65小节**

**我先把自己管住，至少别让人看见我垮了。**
← 因为我怕失去原来的位置，只能抓住从前大家认可的规矩，让自己站稳。
→ 于是我守住了自尊和在乎的事，却还是换不回“自己人”的身份。

**66–91小节**

**我开始明白，自己撑得住，并不能回答他们还认不认我。**
← 因为守规矩只能让我站稳，不能替他们重新接纳我。
→ 于是我看清自己怕的是那扇门彻底关上，而这件事我一个人决定不了。

**92–115小节**

**想起从前不用解释就有自己的位置，我心里会暖，也会更难受。**
← 因为我无法独自确认他们还认不认我，才开始回想曾经被接纳的日子。
→ 于是回忆让我知道那份亲近确实存在过，也让眼下的空缺更加明显。

**116–147小节**

**我想听他们亲口说还记得我，也盼着他们主动向我伸手。**
← 因为回忆让我知道那份亲近曾经是真的，却填不上今天的空缺。
→ 于是我终于说出想被认回的心愿，却没法替他们作出回应。

**148–180小节**

**我先不逼自己要答案了，只想把那些被理解、被欢迎的日子留在心里。**
← 因为我能说出自己的愿望，却控制不了他们是否回应。
→ 于是我暂时安稳了些，也接受回忆还在，旧门仍然没开。

**181–205小节**

**我没把来处全弄丢，可我还是想知道，今天还有没有人愿意接纳我。**
← 因为安静下来后，我看见那些教我做人的东西还在，也看清回忆不能替别人点头。
→ 于是我开始面对当下的难题：现在还有没有人愿意回应我。

**206–213小节**

**我还在等他们认出我、继续把我当自己人，也知道这件事可能没有结果。**
← 因为我已经明白，留下来的回忆不能代替今天的回应。
→ 于是我能说清自己想要什么，却只能把他们是否回应交给他们。

**214–215小节**

**一想到可能等不到，我就想装成谁也不需要，免得再被拒绝。**
← 因为我知道自己想要的回应可能落空，却不想承受那份失望。
→ 于是我试着用硬撑压下渴望，可心里还是想回去。

**216–225小节**

**我嘴上说不在乎，想起那些真心接纳过我的人，心还是会软。**
← 因为装得强硬，并没有让那段关系变得不重要。
→ 于是我不再骂自己软弱，承认自己舍不得，也依然可以站稳。

**226–241小节**

**我不能一辈子靠回忆过日子，也不想继续假装自己不需要任何人。**
← 因为我承认自己仍在乎他们，硬说不需要只会让我继续演下去。
→ 于是我得另找一条路，不能把眼前的生活全押在等旧位置恢复上。

**242–253小节**

**我重新照自己相信的规矩做事，也肯担责任，但不再假装一切都好了。**
← 因为我不想再靠否认渴望或死等旧位置来骗自己。
→ 于是我明知未必有人回应，仍决定带着伤口往前走。

**254–288小节**

**我还盼着被认出来，也会难过；我承认曾属于那里，却不再把日子全押在等回应上。**
← 因为我已决定，即使得不到回应，也要带着伤口继续生活。
→ 于是我重新走进人群，带着想念过日子，让那些经历继续影响我，却不替我决定下一步。
