# 逐字精读：h22k → h23

- [op60 S03-1]「他还以为」→「他以为」（argon: 副词“还”在此处无实际表意作用，删去更干净。）
- [op60 S03-3]「待在一起时也老惦记」→「待在一起时老惦记」（gem: 删去多余的“也”，避免与前句的“也”重复，语气更利落。）
- [op60 S04-2]「也愿多关心些」→「也愿意多关心些」（gem: “愿”单字偏书面，改为“愿意”更符合平实口吻。）
- [op60 S04-2]「自己会越来越」→「自己越来越」（argon: “担心”后直接接“越来越在乎”意思已完整，“会”字多余。）
- [op60 S04-3]「显得像在催」→「像在催」（argon: “显得”与“像”语意重叠，删去“显得”更自然，也与后文“像在讨回应”“像在催促”一致。）
- [op60 S04-4]「把热情稍收一点」→「把热情稍微收一点」（gem: “稍收一点”搭配生硬，改为“稍微收一点”更符合平常说话的习惯。）
- [op60 S06-1]「也照样关心」→「照样关心」（argon: “照样”已含承接上文之意，且全篇“也”字偏密，删去更利落。）
- [op60 S07-1]「就越盼」→「越盼」（argon: “越……越……”句式中的“就”字多余，删去后节奏更紧凑。）
- [op60 S07-3]「也老惦记」→「也总惦记」（argon: “也老惦记”与 [S03-3] 用词完全重复，改“老”为“总”可避免连读单调。）
- [op60 S07-4]「去勉强留住」→「勉强留住」（argon: 状语与动词之间修饰成分堆叠，删去多余的“去”字更顺畅。）
- [op60 S08-2]「像起初那样」→「像最初那样」（gem: 与上一条的“起初”撞词且所指阶段不同，改为“最初”更准确清晰。）
- [op60 S08-3]「更愿主动关心」→「更愿意主动关心」（gem: “愿”单用偏书面化，改为“更愿意”更自然通顺。）
- [op60 S10-2]「它们便一个」→「便一个」（argon: 承接前句的“念头”无需再用代词“它们”，删去后更符合自然口语习惯。）
- [op60 S10-2]「眼下仍照常」→「眼下照常」（argon: “仍”与“照常”语意重复，且前后文多次出现“仍”，删去更简洁。）
- [op60 S11-1]「他终于不再」→「他不再」（argon: 紧接的下一条开头即用“他终于明白”，删去此处的“终于”可避免连读重复。）
- [op60 S11-2]「他终于明白」→「他这才明白」（gem: 与上一条末尾的“终于”紧邻重复，改为“这才”承接更顺，消除套话感。）
- [op60 S11-3]「已拥有的幸福」→「已有的幸福」（argon: “已拥有的”略显生硬书面，改为“已有的”更平实自然。）
- [op60 S12-1]「心事，眼下更想」→「心事，更想」（argon: “不光……更……”本身衔接紧密，且“眼下”在相邻多条中反复出现，删去更流畅。）
- [op60 S12-2]「越想越幸福、越急切」→「越想越幸福，心里也越急切」（gem: 顿号连接心理状态显得生硬板滞，改为顺承表述更符合口语叙述。）
- [op60 S13-1]「越细想以后怎么一起过日子，他越想问」→「一细想以后怎么一起过日子，他就想问」（gem: 前后多条频繁出现“越……越……”，换用“一……就……”更自然，消除单调套话感。）
- [op60 S13-2]「如今越觉得」→「如今觉得」（argon: 后文接“他又把……”，并无对应的“越”字呼应，且前两条刚连用“越……越……”，删去“越”字既理顺句式又避免单调。）
- [op60 S14-1]「也不能保证一定能走到那一步」→「也不能保证能走到那一步」（gem: “保证”已含确定之意，删去多余的“一定”，句子更干净。）
- [op60 S14-1]「也还是难过」→「还是难过」（argon: “也”与“还是”叠用略赘，且后半句已有“也不能”，删去此处的“也”更干净。）
- [op60 S14-3]「他也照样关心」→「他照样关心」（argon: “照样”已足以衔接上下文，删去多余的“也”字以减少全篇虚词重复。）
- [op61 S01-3]「越想越难开始」→「更难开始了」（argon: 全篇多处出现“越想越……”，此处改为“更难开始了”可避免句式重复，承接上文也更自然。）
- [op61 S02-1]「也觉得骄傲」→「觉得骄傲」（gem: 同一句前已有“也先接下”，删去多余且重复的副词“也”，读来更干净。）
- [op61 S02-2]「他还想」→「还想」（argon: 主语“他”已在句首出现，此处删去更干净连贯。）
- [op61 S02-2]「有所」→「」（argon: “有所”偏书面，删去后更符合平白自然的日常口吻。）
- [op61 S02-3]「他难过，」→「他很难过，」（argon: 单用“他难过”作分句在现代汉语叙述中偏生硬，补“很”字后语流更自然。）
- [op61 S02-3]「怕投入白费」→「怕努力白费」（gem: “投入白费”搭配略显生硬，换成日常更自然的“努力白费”。）
- [op61 S03-3]「也容许」→「允许」（argon: 删去多余的虚词“也”，并将偏书面的“容许”改为更日常的“允许”。）
- [op61 S03-3]「是不是真心」→「是不是真的」（argon: “那股劲”与“真心”搭配不贴切，改为“真的”更准确自然。）
- [op61 S04-1]「可他也不愿」→「可他不愿」（gem: 此处“也”为多余垫字，删去后转折更利落直接。；argon: 已有转折词“可”连接，“也”字多余，删去更利落。）
- [op61 S04-2]「面对自己还过不上」→「面对还过不上」（gem: 删去单句内重复出现的代词“自己”，语流更轻快顺畅。）
- [op61 S05-1]「一旦」→「」（argon: “一旦”与后文表示等同的“等于”搭配不自然，删去后语义更顺畅。）
- [op61 S05-3]「才肯承认，自己一直舍不得」→「才肯承认，一直舍不得」（gem: 主语承前省略，删去紧邻重复的“自己”，句子更利落。）
- [op61 S05-3]「等他不再」→「他不再」（argon: “等”字使主语“他”包在介词结构里导致主句缺主语，删去“等”字更通顺。）
- [op61 S06-2]「越想越动心」→「想想就动心」（gem: 避免全篇一再出现“越想越……”句式，换用平实的口语说法。）
- [op61 S06-3]「他越发盼着」→「更盼着」（gem: 避免与紧随其后的“越发真切”连续撞车，换用更地道的“一心盼着”。；argon: 删去重复的主语“他”，并将与下条重复且偏书面的“越发”改为“更”。）
- [op61 S07-2]「也磨没了」→「磨没了」（argon: 前文并未提及其他被磨没的事物，“也”字无所呼应，删去更准确。）
- [op61 S07-2]「自己」→「」（argon: “自己”多余，删去后意思不变且更简练。）
- [op61 S08-1]「亲近感里」→「亲近里」（argon: 删去“感”字可避免与后半句“这份感觉里”重复，也与上下文的“那份亲近”一致。）
- [op61 S08-2]「也不催自己」→「不催自己」（argon: 前后分句是从正反两面说同一件事而非递进补充，删去多余的“也”字更干净。）
- [op61 S10-1]「用力太狠」→「用力太猛」（argon: “用力”与“猛”搭配比“狠”更自然准确。）
- [op61 S10-2]「已经」→「」（argon: “已经”多余，删去后表达更干净利落。）
- [op61 S10-3]「并非」→「不是」（argon: “并非”偏书面，改为“不是”更贴合平实自然的叙述口吻。）
- [op61 S11-3]「因害怕就停下」→「因为害怕就停下」（gem: 单音节的“因”略显书面文气，改成双音节连词“因为”更合口语习惯。）
- [op61 S12-1]「就先做」→「先做」（argon: 前文“不等……”并非条件句，删去“就”字前后关联更准确。）
- [op61 S12-1]「那种」→「」（argon: “珍爱的那种生活”略显累赘，删去“那种”更自然，也与后文一致。）
- [op61 S12-3]「争取也可能」→「争取可能」（argon: 此处并非同类并列，“也”字多余且易生歧义，删去更准确。）
- [op61 S13-1]「他便更想」→「他更想」（gem: “便”字略带文气，换成更自然的口语关联词“就”。；argon: “便”字偏书面，与全篇平实的日常口吻不合，删去更自然。）
- [op61 S13-4]「心里却很清楚」→「却很清楚」（gem: 避免与前句的“心里空落落的”紧邻重复，删去多余的“心里”。；argon: 前文刚出现“心里空落落的”，此处删去重复的“心里”更干净。）
- [op61 S13-4]「想到这一点」→「想到这儿」（argon: “想到这儿”更自然日常，且能避免与后文“有了点盼头”的“点”字重复。）
