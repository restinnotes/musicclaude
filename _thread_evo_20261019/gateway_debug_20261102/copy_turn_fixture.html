下面是肖邦《船歌》Op.60同一条线的两个版本 X 和 Y，以及另一批人听这首曲子每一段写下的听感记录（珠子）。两个版本的顺序是随机的。 线是什么：一个人在这首曲子里经历的一件事，作用是把逐段的听感记录（珠子）串成一个整体。只读线也要成立：有逻辑、有时序、内在有发展，看得出他此刻为什么这样，但不靠“因为……所以……”交代；推动它的是他自己前面的经历，不是音乐里发生了什么，也不是新编的事件。珠子是另一批人听这段音乐写下的听感，会和线排在一起给读者看；线不用把珠子再写一遍，只要在同一段里有情境相近的处境或原因，相关就行。线不能把珠子里的画面、比喻或想象出的情节变成他真的经历的事。 线的写法：按音乐段落分段，每段几条要点；段首括号是他此刻和整件事的关系（没在想 / 还说不清 / 正在面对）；〔〕是这句接着前面哪一段的哪一条。 请逐段比较 X 和 Y，每个判断写一句理由： 1. alone（单独成立）：只看线、不看珠子，哪一版这一段更像从前面自然长出来的——看得出他此刻为什么这样，又不是生硬的“因为……所以……”，也没有把前面已经得出的东西当成新的再说一遍？填 X / Y / 差不多。 2. lean（不啰嗦、读得顺）：哪一版这一段每句都有用、没有重复、连着读更顺？ 3. plain（人话）：哪一版更像一个人平平常常讲自己的经历，具体、不抽象，不像心理分析或哲理总结？ 4. cover（接得上珠子）：哪一版这一段更能让人感到珠子里那些感受为什么会出现在这里？相关、情境相近就算；把珠子的画面或情节搬进线当真的不算。 5. lost：X 里有、Y 里丢了又没有用更好的说法取代的实质内容（具体心理事实，或前后之间有解释力的联系），写进 lost_in_Y；反过来写进 lost_in_X。删掉的重复和空话不算丢。没有就留空。 最后整体判断：哪一版更好；如果用 Y 取代 X，算不算实质退步；用 X 取代 Y 呢。 戏剧化、主观、只讲一个故事都不算缺点。 【X】 **Center：**亲密的幸福与留不住它的痛楚难以分开 ### S01｜1–3 小节　（还说不清） -
