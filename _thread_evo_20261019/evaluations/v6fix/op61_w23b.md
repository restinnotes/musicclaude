# Op.61｜关系图（在 w20 上逐段聚焦重修 w23b）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他心里有股不肯停的劲，像是有事等着回应，却说不清等什么、为何不安，熟悉感又回来，过去也回不来了。
- → 他还没缓过神，身体似乎先记得怎么往前，脑子却说不清该往哪走。
- → 他不甘心任由事情照旧，怕那样就等于承认眼下的一切本来就该如此，也怕真投进去会失去别的东西，想停又逼自己撑住。
- → 他想找理由往前走，每次快要想通，舍不得又回来，连刚有的确信也陌生了，他仍说不清舍不得什么。
- → 他为自己总要先想透才肯动而难堪。

### S02｜24–65 小节　（正在面对）

- 他不想再等到心里全明白，便先承担起自己能做的那部分。
  - ← 改写：（1–23）「想透才肯动」
- → 结果没把握，他不再反复追问值不值得，心里仍有疑虑也肯尽力，行动让他有力气，也有些骄傲。
- → 他愿意再多给些，尽力本身就让他痛快，心里的不满也总算有了去处。
- → 他不再时时审视自己，偶尔发软也照样往前。
- 他仍惦记着从前珍惜的东西，如今只能记在心里，不能像过去那样自然拥有。
- → 他努力把失落压下去，反而显出他其实很在意。
- → 他不甘心就这样垮下去，一再把自己撑起来，可想到放不下的事，劲头又泄了，焦急得安顿不下来。

### S03｜66–91 小节　（正在面对）

- 他真往前走了，少问自己该不该走，也庆幸没退，可他还是拿不准该往哪使劲，心里恼火又不甘。
  - ← 提供理由：（24–65）「自然拥有」
- → 他想要自在亲近、不必时时防备的生活，想到它便松口气，眼下还做不到又难受，却仍顺着轻快过了一会儿，不急着问自己为何非得用力。
- → 轻松退去，眼前的难处还在，他又想起当初不肯再等、先做能做的那一份，也怀疑刚才那股劲是不是真心。
  - ← 唤起：（24–65）「承担起自己」
- ⟲ 仍在起作用：（24–65）「劲头又泄了」

### S04｜92–115 小节　（正在面对）

- 轻松退去后，他还记得那一步确实让自己重新动起来，所以仍愿意坚持。
  - ← 唤起：（66–91）「不肯再等」
  - ← 提供理由：（24–65）「行动让他有力气」
- 他真尝过那份亲近带来的快乐，当时的坚定也有他努力撑住自己的成分，可眼下不安没让他认定那一步错了。
- → 他怕停下就得承认那份亲近回不到从前，便硬撑着把自己催得停不住，脑子反复追问过去还能怎样。
- → 可他还想要那种不用防备的亲近，光靠坚持仍没法让他安心。

### S05｜116–147 小节　（正在面对）

- 他知道行动还不够，却舍不得松手，那一步曾救他走出犹豫，承认失望仿佛就要推翻它。
  - ← 提供理由：（92–115）「重新动起来」
- 想到那种不必防备的亲近，他心里会软，却怕一松劲又停了步。
  - ← 提供理由：（92–115）「亲近的快乐」
  - ← 限制：（92–115）「反复追问」
- → 他把难受和想停都当成自己还不够坚定，便逼自己继续撑。
- → 这股劲曾撑起他，如今他一累就怪自己。他发现自己正逼着一个累了的人硬撑，不想再证明自己多坚强。
  - ← 提供理由：（24–65）「行动让他有力气」
- → 他有些茫然，逼自己硬撑的劲松了，心里却没安心，才肯承认自己舍不得那种不必防备的亲近。
- ⟲ 仍在起作用：（92–115）「光靠坚持」

### S06｜148–180 小节　（没在想）

- 催逼停下来后，他发现自己舍不得的不是一时舒服，而是曾真心相信过的生活。
  - ← 提供理由：（116–147）「一累就怪自己」
  - ← 说明：（116–147）「不必防备的亲近」
- → 他盼着和人亲近时不必时时防备，也盼着珍惜的东西不用靠争抢才能留住。
- → 他想付出时只是因为喜欢，不必反复证明自己值得被爱、被接纳，也不必先想着靠近会受伤。
- → 他确实尝过那种亲近带来的快乐，不愿只因眼下做不到，就把这份向往说成软弱。
  - ← 提供理由：（92–115）「亲近的快乐」
- → 他暂时不再担心心里一软就会停步，才肯承认自己也有委屈和思念。
  - ← 提供理由：（116–147）「一累就怪自己」
- → 他允许自己去爱、去相信，先珍惜心里向往的生活，不急着求它实现或证明有用，也不拿责任和它比轻重。
- → 他终于能安心地想那种生活，心里满足、柔软起来，也更盼着有一天能过上那样的日子，先前的疲惫暂时淡了。
- → 这份安宁让他一时不愿把心思拉回眼前的难处，可他盼着的生活还没有真正来到。
- ⟲ 仍在起作用：（66–91）「自在亲近」

### S07｜181–205 小节　（正在面对）

- 安宁让他又感到那种亲近；身体先绷紧，他才发现威胁仍在，懊恼自己沉进去，忘了还有事要面对。
  - ← 说明：（148–180）「亲近带来的快乐」
  - ← 提供理由：（148–180）「盼着的生活」
- → 他想起当初不肯再等，是不愿看着珍惜的东西继续受损；光在心里怀念，护不住它们。
  - ← 提供理由：（24–65）「自然拥有」
  - ← 唤起：（66–91）「不肯再等」
- → 他想重新投入，却不敢像从前那样不顾一切，怕争取到最后只剩硬撑，把想留住的温柔也耗尽。
  - ← 改写：（1–23）「本来就该如此」
  - ← 说明：（116–147）「一累就怪自己」
  - ← 提供理由：（148–180）「满足、柔软」
- → 他原以为想清当初为何不能再等，就能安心往前；如今他发现自己的顾虑也不是没道理，反而更难决定。
  - ← 改写：（1–23）「舍不得又回来」

### S08｜206–213 小节　（没在想）

- 为难时，他心里又软了下来。
- → 那种安宁确实让他满足过，这回他不再因自己沉进去就责怪自己。
  - ← 提供理由：（148–180）「盼着的生活」
- → 他愿把没答案的事放一放，好好珍惜片刻安静，心里也有欢喜。
- → 他知道这份安静留不久，仍舍不得它退去。

### S11｜226–241 小节　（正在面对）

  - ← 提供理由：（181–205）「不肯再等」

  - ← 限制：（226–241）「消不掉牵挂」
  - ← 限制：（226–241）「两样都舍不得」

- → 他不再逼自己找更多理由才肯往前，心里仍清楚，愿意把眼前的事做好。
  - ← 改写：（1–23）「想透才肯动」
