# Op.60｜关系图

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3　（还说不清）

- 他还说不清自己究竟在盼什么。
- 他心里有个格外愿意亲近的人。
- 他想到对方便不由自主地柔软。
- 他想让这份感觉多停留一会儿。
- 他又本能地把感觉往回收。
- 眼下无需作决定，他却不知为何谨慎。
- 他觉得那点喜欢似乎随时可以放下。
- 他偏偏舍不得放下。

### 4–16　（正在面对）

- 他暂不追问这份喜欢以后会怎样。
  - ← 提供理由：（1–3）「说不清」
- 他不因喜欢就期待对方做什么。
- 他慢慢能够安心亲近对方。
  - ← 唤起：（1–3）「舍不得放下」
- 他喜欢自由地给予温柔。
- 他不必时时确认心意有没有被领受。
- 他发现认真在乎也可以保有从容。　✦ 分清
  - ← 改写：（1–3）「往回收」
- 有时他甚至觉得比先前更自在。
- 他渐渐不再提防自己的喜欢。
- 他甚至对自己的宽和感到满意。
- 他盼着亲近一直自然发生。
- 他当时觉得这样已经足够。
