# Op.60｜关系图

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3　（还说不清）

- 他还说不清自己究竟在盼什么。
- 他心里有了一个格外愿意亲近的人。
- 想到对方，他便不由自主地心软。
- 他想让这份柔软多停留一会儿。
- 他又本能地把心往回收。
- 眼下并没有事催他作决定。
- 他也不知自己为何这样谨慎。
- 他觉得那点喜欢似乎随时可以放下。
- 他偏偏舍不得放下。

### 4–16　（正在面对）

- 他不急着为这份在意决定去向。
  - ← 提供理由：（1–3）「这样谨慎」
- 他允许自己暂时不知道两人会怎样。
- 他不因喜欢就向对方期待什么。
- 他慢慢可以安心亲近对方。
  - ← 唤起：（1–3）「舍不得放下」
- 他喜欢自由地给予那份温柔。
- 他不必时时确认心意有没有被领受。
- 他发现重视对方也能保持从容。
- 他有时甚至觉得比先前更自在。
- 他渐渐不再提防自己的喜欢。
- 他有一点满意于自己如此宽和。
- 他希望亲近能一直自然地发生，不必追问计较。
- 他当时觉得这样已经足够。

### 17–23　（正在面对）

- 他开始盼望这份喜欢能够长久。
  - ← 唤起：（4–16）「自然地发生」
- 想到长久，他便想到对方的心意。
- 他能决定自己怎样珍惜对方。
- 他无法决定对方是否同样珍惜自己。
- 对方的回应开始牵动他。
  - ← 动摇：（4–16）「有没有被领受」
- 这愿望起初并不强烈。
- 他并没打算向对方索取什么。
- 他偶尔想知道自己在对方心里是否特别。
- 仅多了一点期待，他便不再完全安稳。
  - ← 动摇：（4–16）「已经足够」
- 他意外发现，已经幸福仍会盼望更多。　✦ 满足照出未满足

### 24–34　（正在面对）

- 他不愿新添的紧张破坏先前的快乐。
  - ← 提供理由：（17–23）「不再完全安稳」
- 他知道对方并未答应过什么。
- 他不想让喜欢变成无形的催促。
- 他试着把心放得更宽。
- 他提醒自己珍惜对方无须事事得到表示。
- 他从关心、给予和为对方高兴中获得快乐。
- 他真的轻松起来，想求确认的紧张渐渐消退。
  - ← 改写：（17–23）「是否特别」
- 他发现自己反而更愿意付出。
- 他不再衡量心意付出了多少。
- 他不再怕多给会显得自己更在乎。
- 他为毫不勉强的热切感到幸福。
- 他仿佛终于能尽情给出小心保存的温柔。
- 那一阵，他甚至相信不提要求就能尽情去爱，也不会伤人。
- 他那时还相信自己不会失去什么。
- ⟲ 仍在起作用：（17–23）「索取什么」；（4–16）「自由地给予」

### 35–39　（还说不清）

- 欢喜稍稍平息，他仍想知道自己是否同样被珍惜。　✦ 办法的限度
  - ← 动摇：（24–34）「不会失去什么」
- 他为又盼望被看见感到难堪。
- 他怀疑此前的体贴藏着不肯承认的期待。
  - ← 唤起：（24–34）「更愿意付出」
- 他没法轻易回答这个怀疑。
- 他觉得说自己毫无所求似乎已不够诚实。
- 他又知道此前的快乐并非为了换回应。
  - ← 提供理由：（24–34）「为对方高兴」
- 他暂时留在这份不自在里。
- 他不急着替自己辩解。
- 他也不再找热烈的感觉来遮盖它。
- ⟲ 仍在起作用：（17–23）「是否特别」

### 40–50　（没在想）

- 难堪没有减轻他的喜欢。
- 他不愿继续用慷慨证明自己。
  - ← 提供理由：（35–39）「盼望被看见」
- 他不想时时检查对方是否在意。
  - ← 改写：（35–39）「同样被珍惜」
- 他也不想强迫自己毫无期待。
  - ← 提供理由：（35–39）「不够诚实」
- 他不再忙着猜两个人以后如何。
- 他只留心此刻愿意给予的关切。
  - ← 提供理由：（35–39）「并非为了换回应」
- 他可以安静地惦念对方。
- 他因希望对方过得好而高兴。
- 他不再用每份心意衡量两人的关系。
- 他发现有些快乐留在心里就很鲜明。
- 他甚至暂时忘了为何那么在意回应。
- 他只觉得细细地喜欢对方很甜。

### 51–61　（正在面对）

- 他发觉不声张的甜意已有重量。
  - ← 改写：（40–50）「留在心里」
- 他渐渐难以把喜欢收放自如。　✦ 办法的限度
  - ← 限制：（40–50）「此刻愿意给予」
- 他更深地惦念对方。
- 他更希望自己的关切能被领会。
- 有时毫无特别缘由，他心里也满是对方。
- 他仍认为不催促对方是对的。
- 他舍不得用期待换取对方迁就。
- 他只得独自容纳没有着落的盼望。
- 他仍觉得这样喜欢值得。
- 他舍不得减轻给过自己甜蜜的感情。
  - ← 提供理由：（40–50）「喜欢对方很甜」
- ⟲ 仍在起作用：（40–50）「安静地惦念」；（17–23）「是否特别」；（24–34）「无形的催促」

### 62–71　（正在面对）

- 他忽然不愿再时时约束这份深情。
  - ← 唤起：（51–61）「收放自如」
- 他明白那些快乐并不靠对方的承诺。
  - ← 提供理由：（24–34）「毫不勉强」
- 他觉得心里仍有期待，也不必怀疑幸福的真切。　✦ 分清
  - ← 提供理由：（40–50）「留在心里」
- 他不愿再因为怕受伤，连高兴都克制。
- 他想让自己充分地喜欢一次。
  - ← 唤起：（51–61）「舍不得减轻」
- 他暂时不急着追问结果。
- 他也不急着替以后安排退路。
- 他开始坦然享受积攒许久的眷恋。
- 他不再计较心意给出了多少。
- 他不再提醒自己心意深了就该收回。
- 他只为自己能这样爱对方而高兴。

- 他知道还没有保证，却几乎感觉不到它的沉重。

### 72–77　（正在面对）

- 欢喜稍稍落定，他已无法含糊自己的愿望。
  - ← 唤起：（62–71）「爱对方而高兴」

  - ← 唤起：（51–61）「关切能被领会」
- 他想知道对方是否同样渴望靠近。
- 他想知道对方是否也把他看得特别重要。

  - ← 改写：（1–3）「往回收」
