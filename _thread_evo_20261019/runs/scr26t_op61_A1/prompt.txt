你要为一首器乐作品设计 Thread 的“人的经历骨架”。

Thread 是同一个人在整首作品里经历的一件事。以后会把它写成逐段要点，但这一层只负责想清楚：他起初处在什么情况下，具体在意什么，前面的经历怎样影响后面，直到最后实际走到了哪里。

【输入】
作品：作曲家：肖邦（Chopin）
作品：《幻想波兰舞曲》Op.61
段落顺序：S01：第 1–23 小节
S02：第 24–65 小节
S03：第 66–91 小节
S04：第 92–115 小节
S05：第 116–147 小节
S06：第 148–180 小节
S07：第 181–205 小节
S08：第 206–213 小节
S09：第 214–215 小节
S10：第 216–225 小节
S11：第 226–241 小节
S12：第 242–253 小节
S13：第 254–288 小节
Center：维持尊严的行动与对旧日生活及归属的怀念反复拉扯

【这一层的边界】

- 完全不看珠子或听感记录。
- 不写音乐、声音、旋律、节奏、和声或具体小节里的事件。
- Center 已经给定。它是读者回头看整首时把各段组织起来的那件事，不是人物一开始就知道的道理，也不是每段都要回答的问题。
- 可以利用你对作品整体走向的理解安排各阶段的轻重，但不能把音乐里的变化直接变成人物的心理动作。
- 不新增具体外部事件、人物、物件、对白、场景或前史来发动经历。具体性来自人物所求、顾虑、已有体验及其后果。

请独立提出 3 条完整候选路线。

【怎样构思一条路线】

一、先确定一件真正能经历的事

用一句普通话说清人物面对的处境，以及其中真正牵动他的所求和顾虑。

“一件事”不等于“始终重复一种心理动作”。同一个处境可以让他期待、犹豫、得到安慰、付出代价、留恋、承受后果，也可以让他暂时沉浸在某种感受里。

这些必须属于同一件持续发生的经历，不能只是若干心理主题的排列。

二、让前面的经历成为后面的根据

顺着段落次序构思，每到一段，先问：

- 到这里，他已经亲身经历了什么？
- 他现在具体想要什么、顾虑什么、正在承受什么？
- 前面的经历留下了什么，使他此刻会这样想？
- 本段有什么真正改变了他接下来所处的情况？如果没有，什么仍在继续？

特别区分三类东西：

- 已经成立的处境或亲历；
- 人物从自身经历中得到的认识；
- 人物尚不能确定的猜测、期待或担忧。

第三类可以真实地影响他的感受，却不能自动升级成第一类。

一项认识被写进 established，只表示人物在此处产生或确立了它，不代表它已经有充分根据。认识的内容仍必须受到前面经历的支持。

三、检查关键转折的根据

尤其注意那些一旦成立、后面很多段落都会依赖的认识、愿望或选择。

对每一项这样的关键转折，都要能够从更早的 state 中找到实际依据。

只有主题相近、情绪相近，或人物重新回想了过去，并不足以支持一项更强的新判断。

如果既有经历只能支持一种不确定的理解，就让人物保留这种不确定性；如果一条发展路线必须靠没有来源的新事实支撑，就改变路线的后续发展，而不是为了铺垫它而补造新事实。

人物可以重新理解自己已经经历过的事，但重新理解所增加的内容必须能从旧经历中读出来。

四、让经历积累，不反复重新开始

一个事实、认识、愿望或决定一旦成立，后面就可以沿用。

后续再次遇到相似的感受时，注意区分：

- 原来的情况仍在；
- 原来知道的事产生了新的后果；
- 同一种感受在已经改变的处境中重新出现；
- 他真的有了不同于前面的新认识或选择。

只有最后一种才需要再写一次认识或决定的成立。

不要默认采用“提出办法—试验—失效—更换办法”的路线，也不要把情绪变强当作新进展。

五、允许每段承担不同分量

有的段落可以建立重要事实，有的段落只是让此前的感受持续存在，有的段落体现已有选择的代价，有的段落则暂时顾不上整件事。

不要为了填满段落制造新的心理动作。

如果某一段没有新增内容，就如实写延续或当下状态，不必重新解释一次核心矛盾。

结尾也只需到达这条经历实际能够到达的地方，不预设必须解决问题、下最终决心或总结道理。

六、用事实账本防止前后改写

构思过程中持续保存已经成立的重要事实、认识、愿望和选择。

后文不能把人物过去的动机重新解释成此前未曾建立的动机，不能忘记已经完成的变化，也不能把此前仍然不确定的事直接当作确定事实。

同一时期可以存在彼此拉扯的感受，但后文不能把其中一面概括成此前唯一的状态。

【输出】

每条候选输出：

- route_id
- situation：一句普通话，说清他正在经历哪一件事，以及具体的所求或顾虑；不是抽象标题。
- segments：
  - sec
  - state：本段此刻实际的处境、念头或感受，1–3 条；写清人物能知道什么，不用心理分析术语代替经历
  - delta_type：从“新变化 / 后果 / 实行已有想法 / 延续 / 回到旧处但有新增 / 暂时没在想”中选择一个
  - delta：相对于前面确实新增了什么；没有就写空
  - depends_on：真正提供前因的更早 state 编号；没有就空，不能只因为主题相近而引用
  - still_open：到这一段仍未解决、尚未确定或仍然牵动他的东西；没有就空
- established：按首次成立顺序列出全文重要的事实、认识、愿望或选择，并标明首次成立的段落；保留各项原有的确定程度

沿用原有字段和编号方式，不增加字段。

不要写最终文案，不要评价候选，也不要写构思过程。

只输出 JSON。
