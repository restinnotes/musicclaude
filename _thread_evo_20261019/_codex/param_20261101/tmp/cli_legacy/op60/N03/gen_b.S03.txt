## 目标

不是覆盖率越高越好。目标是：让听这一段的人，在有限的时间和注意力里，获得足够丰富、鲜活、独特、确实值得感受的体验。一段可能只需要一个很好的侧面，也可能需要好几个；没有规定数量，也没有上限。一种体验即使成立，也不一定值得额外占用一次听者的注意力。

## 任务：按边际价值排序的侧面阶梯

1. 第 1 个侧面：如果听者只能接收一种体验，最值得给的那一个。
2. 第 k 个侧面：在前 k−1 个已经给出之后，新增价值最大的那一个。新增价值指新的具体体验——新的身体感觉、感官质地、人物动作或关系、心理处境、本段内部真实发生的变化，或真正不同的理解角度——而不是同一种体验换一个比喻。
3. 一直排到剩下的材料都没有明显新增价值为止；然后再额外列出最多 3 个"停止点之后"的候选（如果还有材料），用来展示收益为什么衰减。
4. 给出你建议的停止点 `stop_after`（保留前几个），结合本段时长和听者注意力说明理由。

### 每个侧面怎么写

- `text`：给普通听者读的自然中文，一般 1–4 句。尽量保留原稿中最鲜活的具体画面、动作、触感和说法；允许小幅组织、把相容的原话接得更自然，但不要全面重写，不要洗成心理学概念或抽象结论。如果几个场景在你看来共同指向某个道理（例如"因为太在乎，所以动作变轻"），这个道理写进 `internal_note` 帮助理解即可，不要用它替代最动人的那个画面。
- 不要把不同原稿各自的人物、动因拼成同一个人的连续经历或因果链。来自不同原稿的话放进同一个侧面，前提是它们确实在说同一件事。
- `sources`：支持此侧面的原稿逐字原话（每条不超过 60 字，逐字照抄），注明来源 ID 和 Pool id（Pool 里没有的写 null）。
- `measures` 与 `placement`：这个体验在本段哪里成立。`stated`＝原稿明说，`inferred`＝按音乐事件推定，`segment_wide`＝整段性的。不能比证据更精确。原稿定位可疑、或实际属于邻段的，不要为了增益而选入。
- `relation`：与前面侧面的关系，可以有多项，每项写明针对哪个侧面：
  - `新体验`：与前面基本不重叠；
  - `重叠但新增`：与前面某个侧面大量重叠，但新增了独特的身体感觉、心理动因或关系角度（在 adds 里说清新增的是什么）；
  - `可同时成立`：与某侧面不同，但可以在同一时刻同时被感到——不是二选一；
  - `替代理解`：与某侧面是不同的理解角度，听者通常择一而听；
  - `段内先后`：音乐内部真实发生的先后变化（写清从哪里到哪里）；
  - `演奏条件`：只在某种演奏处理下成立（写清条件，不当作作品此处无条件的事实）。
- `adds`：一句话说清它相对前面侧面新增了什么（第 1 个写它本身提供了什么）。
- `also_expressed_by`：其他原稿对同一体验的不同鲜活说法（逐字原话＋来源 ID），它们并入这个侧面，不另立条目。只是换了个比喻的变体放在这里。
- `gain`：你判断的边际价值：`高` / `中` / `低` / `几乎无`。

### 另外

- `set_aside`：Pool 中你明确不采用的内容，按理由分组：`位置错误或属于邻段` / `原稿缺乏依据` / `只是重复已选体验` / `过于抽象或空泛` / `其他`。每组列 Pool id 和一句理由。已并入某个侧面的条目不必再列。
- `internal_note`（可选）：比较材料时发现的共同点、差别或隐含关系，只供内部参考，不上屏。没有就留空，不要硬造洞见。

### 写作提醒

戏剧性、肯定、单一故事的写法本身不是缺点；问题只在于把没有证据的关系拼起来，或用抽象概括替代具体体验。不要套用一个全曲通用的人物故事（例如反复的"倾诉、珍惜、害怕失去、等待回答"）；只写本段原稿真正支持、本段音乐真正有的东西。
