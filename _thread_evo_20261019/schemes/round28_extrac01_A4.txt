你要一次写出一首器乐作品最终使用的Thread（线），用于在逐段听感记录旁阅读。线必须是同一个人经历的同一件事；只读线就能跟着他的处境走下去，每段也要与给定TARGETS的体验性质大体接得上。不是对音乐的解说，也不能把TARGETS中的画面、想象情节或音乐动作变成人物事实。

【段落】
{SECTIONS}

【Center（给定，不修改）】
{CENTER}
Center是回头看时能把全篇组织成一件事的中心，不是人物开头必须知道的结论，也不是每段必须复述的题目。

【已通过宏观评审的路线候选】
{ROUTES}

【珠子的体验性质TARGETS】
{TARGETS}
你看不到原珠子，也不要猜其用词、画面、人物动作或音乐细节。

【第一步：选定一条主干】
从ROUTES中只选一条作为base_route，不拼接路线。优先选择能在不增添外部事实的前提下形成一条完整经历、并允许有些段落只是停留或余波的路线；不要因为某个候选转折多、每段都像有新变化，就默认它更好。Center保持原样，路线中的内容只是这条线可用的经历设计，不能借A4补写新的事件、对白、道具、场景、他人举动或他人隐秘心态。

【第二步：先建立“叙事时钟”，不要让它和段落时钟同步】
在内部把这件事看成一条独立于SECTIONS的叙事时钟。只在人物的处境、理解、愿望、承担或选择真正改变了后文条件时，才在叙事时钟上跨过一个新位置；两个位置之间可以停留很久，也可以跨过得很快。不要预先规定叙事位置的数量，更不要要求一段对应一个变化：连续几段可以处在同一位置，一次真正的变化也可以跨越几段才完成。

然后把每个SECTION放到这条叙事时钟上的实际位置：它可能正停留在两个变化之间，可能正在跨过一个变化，也可能只是让此前已经发生的事更真切地落到人物身上。TARGETS从这里开始参与，但只决定这个叙事位置在本段以怎样的轻重、舒紧、迟疑、热切、空落或其他相容体验被感到；TARGETS不能凭空制造新的叙事位置，也不建立“某种音乐强度必然对应某种人物反应”的固定映射。若TARGETS在相邻段明显变化，而人物的处境没有足够理由变化，就让同一叙事位置呈现不同侧面，而不是强造转折。

【第三步：按双时钟一次写完整条线】
按给定段落顺序一次写完整条线，但写作时始终以叙事时钟为主、SECTION只负责告诉你当前要呈现哪一段时间。处在同一叙事位置的几段，不要重新宣布同一个认识；可以写余波、等待、注意力短暂移开、同一事实此刻变得更难承受或更容易承受，也可以只让已有感受继续存在。真正跨过叙事位置时，变化要从这条线已经写出的经历里自然长出来，不能靠新增现实事实，也不能把TARGETS当成变化发生的原因。

每段2–4条，每条只写一句完整、自然的话，只承担一件有用的事；事情少的段落就用两句短句，不为凑数拆同义句。全篇连起来要像普通人讲自己一路经历了什么，读者不需要替他提炼心理理论；允许直接、朴素地写犹豫、愿望、害怕、放松、舍不得或说不清的感觉，但不让抽象心理概念反复替代实际心思。TARGETS必须在写作时参与，使本段各bead_id尽量都能在线中找到情境相近的落点；同一处境可以接住多颗珠子，也允许某些段落只是同一叙事位置的不同感受。不能复制TARGETS的修辞、人物想象或物理音乐动作来取得覆盖。结尾可以没有最终答案，也不因为叙事时钟走到最后就硬造终局决定。

【第四步：按成稿的真实状态输出】
输出前检查叙事时钟和段落时钟有没有被偷偷重新绑定：不能因为换了SECTION就自动出现新认识，也不能把一个真正变化拆成几次“第一次”。同时检查每段的TARGETS是否在人物现有处境中得到自然照应；只有强行覆盖必然需要虚构外部事实时，才进入uncovered_targets。

cite只列该条真实提及或依赖的更早条目ID，包括本段前面的条目；仅主题或情绪相似不算。covers只列该条确有相近情境的bead_id，不为凑覆盖乱标。relation只按正文标“没在想/还说不清/正在面对”，仍在挂念或打量Center不能标“没在想”。delta_type只从接口给定六类选，情绪变强不自动算“新变化”；delta没有真正新增便留空。established只收正文中确实首次成立的重要状态、认识、意愿或选择，并准确指向那一条。元数据只能描述已经写出的线，不能反过来补造因果。

【输出】
只输出合法JSON，不要解释、Markdown或额外字段；接口固定为：
{
  "base_route": "route_id",
  "segments": [
    {
      "sec": "S01",
      "relation": "没在想/还说不清/正在面对",
      "items": [
        {"id": "S01-1", "text": "...", "cite": [], "covers": ["bead_id"]}
      ],
      "delta_type": "新变化/后果/实行已有想法/延续/回到旧处但有新增/暂时没在想",
      "delta": "本段真正新增的心理事实；没有则为空字符串"
    }
  ],
  "uncovered_targets": [
    {"bead_id": "...", "reason": "若要覆盖就必须虚构外部事实的原因"}
  ],
  "established": [
    {"claim": "首次成立的重要认识或状态", "first_established": "Sxx-x"}
  ]
}
segments按输入段落顺序完整填列，示例中的值只表示字段形状；不增加字段。
