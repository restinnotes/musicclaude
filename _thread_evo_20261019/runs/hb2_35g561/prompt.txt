在内部先构思一条完整、连贯的经历，不要按音乐段落逐段发明心理状态。

先回答：
1. 人物一开始实际处在什么处境中？
2. 这件事真正改变过他什么？
3. 哪些认识、选择或事实确实只在某个时刻首次成立？
4. 这些变化分别有什么已经发生的前因？
5. 最后人物处在什么位置？他对这件事的承担方式发生了什么变化？

经历必须有方向。方向不等于人物必须越来越积极、越来越消极或最终解决问题。方向是指人物已经走过的认识和选择不会在后面被重新当成尚未发生的事。

Center 的两极可以从头到尾同时存在。人物可以始终感受到两方面的力量，但不能因此每隔一段就重新作出同一个判断。需要区分：两种感受仍然存在，与人物重新开始解决同一个问题，是两回事。

整条经历只保留真正必要的心理变化节点。节点必须满足至少一个条件：
- 人物获得了此前没有的新认识，而且有实际经历作为依据；
- 人物作出了此前没有作出的选择；
- 已经发生的事情产生了此前尚未呈现的实际后果；
- 人物对一件已经知道的事，开始采取一种真正不同的承担方式。

单纯情绪变强、同一个问题换一种问法、同一个决定重新宣布，都不是节点。

每个节点必须有自己的前因，并改变后面人物能够知道、能够选择或实际承受的东西。节点成立以后，后面的经历必须承受它的结果，不能把人物退回到节点成立以前的心理位置。

没有新节点的时间不需要制造心理变化。可以只是继续经历、沉浸、感受某种身体状态、承受先前决定的后果，或暂时没有在想这件事。

不要为了让整条弧线显得完整而增加成长、顿悟、决心、原谅、释怀或人生结论。结尾可以仍然有未解决的部分，但人物不能无缘无故回到起点。

【第二步：映射到音乐段落】
完整经历弧确定以后，再把它映射到 {SECTIONS}。

每个真正的心理变化节点只能在最适合的段落首次成立一次。其他段落可以呈现节点发生前的持续处境、节点发生后的具体后果、体验的延续或沉浸。

不能因为某段音乐情绪回到前面的方向，就让人物回到前面已经走过的心理位置。
不能因为某段有明显的情绪变化，就强行给人物增加一个认识或决定。
同一个节点可以在后续段落中产生不同的实际体验，但不能再次被宣布成立。

每段都必须有 state，但 state 不等于新变化。没有新变化时，如实写这一段人物正在经历什么，并将 delta_type 标为延续、后果或暂时没在想。

【第三步：不增加外部情节】
每条路线从头到尾只能是一件事。
不新增聚会、书信、物件、对白、地点、职业、第三人、具体外部事件或场景。
不新增对方的动作和未经检验的隐秘心事。
允许一个从头到尾不变的轻处境和小动作，但不能用它制造新的事件。
所有变化必须来自人物已有经历、已有事实及其实际后果。

【第四步：人物语言】
用普通人平常会说的话写状态。写具体在意什么、想要什么、怕什么、正在承受什么。不要写心理分析、人生道理或抽象概念。不要把每个节点都写成一次总结。

【输出格式】
请独立提出 {K} 条完整候选路线。
每条路线严格使用以下字段，不得增加字段：
- route_id
- situation：一句普通话，说清整件经历。
- segments：按照 {SECTIONS} 原顺序，每段包含：
  - sec
  - state：本段此刻实际是什么情况，1–3条；可以是延续、体验或后果，不要求新认识。
  - delta_type：从新变化、后果、实行已有想法、延续、回到旧处但有新增、暂时没在想中选择。
  - delta：只有真正新增的事实或认识才填写，没有就留空。
  - depends_on：真正作为前因的更早 state 编号；没有就空。
  - still_open：到这一段仍未解决或仍不知道的东西；不要反复写同一个已经处理过的问题。
- established：按首次成立顺序列出全文的重要事实、认识、愿望或选择，并标明第一次成立在哪一段。

established 只登记真正成立的心理事实，不把情绪强弱、同一体验的不同质地当成新的认识。

每条路线都必须先作为一件完整经历成立，再映射段落。不得为了填充某一段而创造新的心理节点。

不要写最终文案，不要评价候选。只输出 JSON。

【A2】
下面是同一首作品的几条 Thread 人物经历候选。你完全看不到珠子，也不要根据音乐细节评判。

你的任务是选择一条真正能从头到尾成立的单向经历，而不是选择心理活动最多、情绪最丰富、最贴近 Center 字面措辞的路线。

请先把每条路线当成一件完整的经历来读。不要把每段看成一个独立的心理任务。

【逐条检查】
1. 是否从头到尾确实是同一件事？人物的起点、经历过程和结尾能否连起来？
2. Center 是否作为整件事的恒定核心存在，而不是每段都被重新提出一次？
3. 是否有明确的经历方向？人物已经获得的认识、作出的选择、承受过的后果，后面是否真的被继续承受？
4. 每个真正的新变化是否有前面已经发生的事情作为根据？
5. 是否把情绪增强误写成新认识？是否把同一个决定换一种说法重新宣布？
6. 是否出现已经走过一个心理节点，后来又回到节点之前重新挣扎的情况？如果有，后面是否真的出现了新的前提或后果？
7. 没有新节点的段落是否允许只是延续、体验、沉浸或承受后果？是否为了填满音乐段落而制造心理变化？
8. 结尾是否符合整条经历自然能够到达的位置？是否为了制造圆满而突然成长、顿悟或作出决定？
9. 人物是否像一个普通人在经历事情，而不是作者在不断解释他的心理结构？

【特别重要：怎样判断往前走】
往前走不是每段都必须有新认识。
往前走是：一旦某个事实成立，人物后面就带着它生活；一旦某个问题已经得到某种处理，后面不能无新增前提地重新处理；一旦某个决定已经作出，后面不能把同一决定再写成一次转折。

可以有相近的情绪，可以有新的身体体验，也可以再次感受到同一矛盾，但这些不能伪装成新的心理变化。

不要因为某条路线的 established 比较长就认为它更完整。真正重要的是少数节点之间是否有真实因果，以及非节点段落能否自然存在。

【评分】
逐条给出：
- coherence：1–10
- forward_motion：1–10
- prerequisite_integrity：1–10
- non_repetition：1–10
- human_plausibility：1–10
- 主要问题

评分时，forward_motion 看经历方向是否成立，不看心理变化的数量。non_repetition 看人物是否反复重新处理已经处理过的问题，不要求不同段落的情绪必须不同。

然后选出最多 3 条进入下一步，按优先顺序排列。

不得改写候选，不得替候选增加新事件，不得因为某段没有新认识而扣分。

候选路线将在本提示词末尾附上。

只输出 JSON，保持原有输出格式。

【A4】
你要为一首钢琴曲写最终使用的 Thread（线）。

Thread 是同一个人在整首作品里经历的一件事。最终成品应当是一条方向明确、因果自然、像普通人讲述真实经历的线。

【段落】
{SECTIONS}

【Center（已经给定，不得修改）】
{CENTER}

【已经通过 A2 的人物经历候选】
{ROUTES}

【从珠子提炼出的体验性质（TARGETS）】
{TARGETS}

你看不到原始珠子，也不得猜测珠子的具体画面或措辞。

【第一步：选定唯一经历弧】
从 ROUTES 中选一条最自然、因果最完整、人物经历方向最明确的路线。

不要选择心理活动最多的路线。优先选择真正的心理变化少而清楚、其余时间可以自然呈现体验和后果的路线。

选定后，在内部把这条经历整理为：
- 起点：人物最初的实际处境。
- 节点：真正改变人物认识、选择或承担方式的事实。
- 后果：节点成立以后，人物实际怎样继续经历这件事。
- 落点：全曲结束时人物处在什么位置。

这份整理只供写作使用，不增加输出字段。

【第二步：给段落分配不同权限】
每段只能承担以下一种或两种功能：
1. 节点：一个真正的新认识、新选择或新的实际后果首次成立。
2. 后果：已经成立的节点在此刻对人物造成的实际影响。
3. 体验：人物仍处于已有处境中，此刻的身体感受、注意力、情绪质地或沉浸状态。
4. 延续：人物带着前面的事实继续经历这件事，没有新认识。

先确定哪些段落是真正的节点段。节点不需要很多，不能为了音乐段落数量增加节点。

节点一旦成立，后续所有段落都必须承受它。不能重新把人物放回节点成立以前的状态。

非节点段没有创造新认识、新决定、新问题、新判断的权限。它们只能呈现已经成立的经历在此刻的体验、后果和延续。

这不是要求非节点段落都写成暂时不想。可以写他正在享受什么、身体怎样、注意力在哪里、某个已经存在的念头怎样影响此刻。只要不重新讨论已经成立的两难，就是有效内容。

【第三步：Center 的使用】
Center 是整条经历的恒定核心，不是逐段重复的题目。

两极可以同时存在，也可以始终无法完全分开。人物不需要通过不断重新选择其中一极来证明 Center 贯穿全曲。

同一个两难只在真正需要人物面对它时呈现。后续如果仍然受到它影响，写具体后果，不重新问一遍，不重新宣布一遍，不把相同问题拆成几个不同问句。

人物最后可以没有解决问题，但必须处在已经经历过这一切之后的位置，不能回到最初的心理状态。

【第四步：TARGETS】
TARGETS 只决定这一段体验的情感底色和质地，不产生新的心理事实。

如果某个 TARGET 的体验性质与人物当前的经历相符，可以自然呈现。
如果它只是一种情绪强弱变化，就让它留在体验层，不要据此增加新的认识或决定。
如果它与人物的经历不相容，不要编造事实去迎合；可以放入 uncovered_targets。珠子本身仍然可以在屏幕稿中承担这项体验。

【第五步：人物经历必须自己成立】
不新增外部事件、前史、对白、物件、第三人、地点或场景。
不新增对方的动作，不推断对方未经检验的隐秘心事。
允许一个从头到尾不变的轻处境和小动作。
所有变化都必须来自已有经历、已经成立的事实和人物实际承受的东西。

必须像普通人平常想事、说话。写具体念头、所求、顾虑、实际感受。不要写心理分析报告、人生道理或抽象总结。不要用不同说法反复解释同一个认识。

【第六步：条目数量】
每段必须有条目，不得空段。
每段以一条为基础，需要两个彼此独立的内容时才写第二条。真正的节点段可以有更多条，但不能为了达到固定数量而拆分同一个念头。
体验条目不是新的心理变化。一个段落可以只有一条体验或延续。

每条是一句完整、自然的话，只表达一个主要意思。相邻段落之间的承接必须自然，整条线连续读下来必须像一个人讲述同一件经历。

前面已经成立的事实，后面直接承受其后果，不重新解释因果。

【第七步：最终检查】
只读正文，检查：
1. 能否清楚指出整条经历的起点、真正的节点和结尾？
2. 每个节点是否只首次成立一次？
3. 有没有在节点成立以后重新回到节点以前的犹豫？
4. 有没有同一个决定、认识或问题换一种说法重新出现？
5. 非节点段是否在写体验、后果和延续，而不是伪造心理变化？
6. 有没有为了对应音乐情绪而增加人物没有经历过的心理事实？
7. 有没有外部加戏？
8. 全文是否仍然具体、有人话、有真实所求，而不是为了不重复变成空泛的短句？

发现重复，优先检查节点安排和段落功能，不要只替换词语。

【输出格式】
只输出 JSON，保持以下结构，不增加字段：
{
  "status": "complete",
  "base_route": "route_id",
  "segments": [
    {
      "sec": "S01",
      "relation": "没在想/还说不清/正在面对",
      "items": [
        {
          "id": "S01-1",
          "text": "...",
          "cite": [],
          "covers": ["bead_id"]
        }
      ]
    }
  ],
  "uncovered_targets": [],
  "blocked_sections": []
}

每段严格按照 {SECTIONS} 顺序出现，必须有条目。relation 只作元数据。cite 只在直接依赖前面某条内容时填写编号。covers 只填写实际覆盖的 bead_id。

不得输出 blocked，不得空段。blocked_sections 固定为空数组。status 固定为 complete。
