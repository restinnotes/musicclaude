你要写一首器乐作品最终使用的 Thread（线）。

Thread 是同一个人在整首作品里经历的一件事。读者只看 Thread，必须能顺畅读懂这个人具体在意什么、顾虑什么、前面的经历怎样留到后面；同时每段要自然接住给定的体验性质（TARGETS）。

【段落】
{SECTIONS}

【这件事（Center，已经给定，不改）】
{CENTER}

【已经通过宏观评审的人物经历候选】
{ROUTES}

【从珠子提炼出的体验性质（TARGETS）】
{TARGETS}

你看不到原始珠子，也不要猜原始珠子的画面或具体措辞。

【第一步：选主干】
从候选中选一条最扎实的路线作为 base_route。全篇只能有一个 base_route。

base_route 锁住的是：
- 这件事从一开始已经存在的处境；
- 人物具体的所求、顾虑和已知限制；
- 少量真正的阶段变化以及这些变化为什么能从前面长出来。

不要改写这些事实，也不要为了更贴音乐增加新的事实。

【第二步：一次写完整条线】

一、把同一个具体处境写到底，不要把它逐渐抽成情绪题
人物开头具体在意什么，后面仍应看得出他在意的是这件具体的事。可以随着经历改变轻重、看法或选择，但不要把具体所求和顾虑逐渐替换成泛泛的幸福、痛苦、安心、不安、有没有保证、能不能想开之类的心理问题。

如果几种东西从一开始就同时成立，而且前面的经历没有真正改变其中任何一边，就让它们继续并存；不必为了让段落显得有进展而替人物选边。

二、真正的变化只发生在 base_route 已经安排好的少量阶段上
不要把每个音乐段落都写成一次心理转折。

在同一个 phase 里的不同段落，可以只是：
- 同一处境的另一面暂时更突出；
- 前面已经发生的东西继续产生感受或后果；
- 人物暂时沉在某种感受里，没有形成新认识；
- 已经存在的愿望和顾虑同时压在身上，只是这一刻轻重不同；
- 前面已经作出的选择真正落到自己身上。

这些都可以是完整、有效的经历，不需要再补一个“因此他想通了什么”。

只有 base_route 的 phase 确实发生变化时，才让人物形成新的看法、选择或处境变化；而且必须能从前面的 Thread 正文直接读出根据。

三、TARGETS 是局部镜头，不是人物发展的方向盘
TARGETS 告诉你这一段适合呈现怎样的体验性质。它可以决定：在已经存在的处境里，这一刻哪一面更明显、哪一种感受更靠前、同一矛盾中的哪一边更有重量。

TARGETS 不得自动制造新的愿望、新的顾虑、新的关系事实、新的判断或新的决定。
不要因为 TARGETS 从紧到松、从热到冷、从悬着到落下，就让人物机械地完成同样方向的心理动作。

同一段有几种能够共存的 TARGETS，可以让它们在同一处境里并存；不必强行压成一种，也不必为了容纳多种性质而编出连续几步心理时序。

四、不通过补事件获得因果
可以使用 base_route 已经建立的真实人际或生活处境；不要因为怕“新编事件”而把这些具体处境抽掉。

但不得新增：
- 后来突然发生的外部事件；
- 对方新的动作或具体回应；
- 对方未经建立的心思、态度或需要；
- 新对白、新物件、新场景；
- 为了给后面转折找依据而临时补写的更早往事。

如果某个重要变化只有补入这种事实才能成立，就不要写这个变化。

五、让前面的经历留下后果，而不是反复重新解释它
后面的内容必须由前面已经写出的经历支撑，但不要求每次推进都表现成“重新想了一遍以前的事”。

已经存在的愿望可以越来越难忽略；已经承担的选择可以后来显出代价；一个没有答案的问题可以继续存在；前面形成的感受可以在后来真正落到自己身上。这些都可以推动经历，而不需要再得出一个新的心理结论。

同一个所求或顾虑可以多次回来，但不要每次都重新完整说明它为什么存在。若它再次出现，这一次应当承担当前阶段自己的作用；如果没有新的后果，只需写得短，不要把旧问题重新讨论一遍。

六、写人话，不写人物分析报告
写他此刻真正会在意、会盼、会怕、会舍不得、会犹豫的东西。

少替人物命名心理机制，少用抽象词把两边精确总结成一套理论，也不要每到一个段落就宣布“他意识到”“他终于明白”“他更加确定”。真正有新认识时可以直接写出来，但不要把普通的情绪起伏包装成认识升级。

不需要强行口语化，不机械禁词，不增加无关生活细节。

七、每段2–4条，每条只说一件事
- 每条必须是一句完整、自然的话。
- 一句能说清的不拆成几条，也不把两三句塞进一条。
- 小段或这一段实际发生得少时，写2条即可，宁短勿凑。
- 同段多条可以有真实的先后，也可以写同一时刻能够并存的不同侧面；不要为了满足条数强造“先这样、再那样”的心理过程。
- 连着读时，每一句都应接着前一句往下走，不重说已经说清的内容。

八、引用 cite
某条真正依赖更早某一条已经写出的经历时，在 cite 中写那一条的编号，如 S02-1。
只是主题相近、情绪相近，不算依赖，不必引用。

九、关系标签 relation
写完本段正文后，只根据正文实际表现标定：
- 没在想：人物这一段确实没有去想 Center 所指的整件事，注意力完全被当下别的具体体验占住。
- 还说不清：人物仍在这件事里，但只是感到、盼望、犹豫或承受，还没有形成清楚的态度。
- 正在面对：人物清楚意识到这件事，并在具体权衡、承受、选择或作决定。

不要为了让标签多样而改正文；正文仍在想这件事时，不能标“没在想”。

十、覆盖 TARGETS
每颗 TARGET 的体验性质，应尽量在同段的真实处境中找到相近的承载点。相关即可，不逐句翻译，也不把珠子的比喻、画面或临时情节变成人物事实。

一条正文可以覆盖多颗相容的 TARGET；一段里几种体验确实有张力时，可以分在不同条目里同时保留。

只有当覆盖某颗 TARGET 必须新增 base_route 中不存在的外部事实、关系事实或人物事实时，才放进 uncovered_targets，并说明原因。不要为了追求全覆盖破坏人物逻辑。

【输出格式】
只输出 JSON：
{
  "base_route": "route_id",
  "segments": [
    {
      "sec": "S01",
      "relation": "没在想/还说不清/正在面对",
      "items": [
        {
          "id": "S01-1",
          "text": "...",
          "cite": [],
          "covers": ["bead_id"]
        }
      ]
    }
  ],
  "uncovered_targets": [
    {
      "bead_id": "...",
      "reason": "若强行覆盖，必须新增哪类 base_route 中不存在的事实"
    }
  ]
}
