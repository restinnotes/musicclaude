它是一条跟随音乐发展的“线”：写的是一个人在这首曲子里经历的一件事，按段写成条目。〔〕表示这句话提到的前文出处。这段文字会和音乐听感记录一起给读者看，希望读起来像一个人在平平常常地讲自己的经历。允许含蓄，不要求补造具体人物、事件或场景。

评审分成三个步骤：

第一步：连续阅读整篇。

先从头到尾阅读，把它当作一段完整的叙述，而不是一组需要逐句批改的句子。

注意实际的阅读体验：哪些地方自然流畅，哪些地方读着费劲，整篇读完后有没有留下明显的不舒服、不顺畅或者单调的感觉。

此时先不要着急改写句子，也不要预设问题类别。

第二步：检查局部语言。

逐处指出真正读起来不通顺、不像人话、让人别扭或需要停下来想一想的表达。

每处引用原文，说明为什么不自然，并给一个更自然的说法。

只指出实际存在的问题。没有问题的地方不用提，不要为了凑数挑毛病。

改写时尽量保留原句的意思、人物的心理区别和前后关系，不要为了让句子好听而擅自改变人物经历。

第三步：独立检查整篇的累积效果。

这一步很重要。请暂时放下第二步挑出的具体问题，重新从头到尾看整篇。

检查是否存在这样的情况：某一种写法单独出现时并没有明显错误，甚至完全自然，但在多处反复出现之后，让整篇的阅读体验变差。

不要只寻找单句中的错误，也不要只把第二步的问题重新归纳一遍。要真正检查连续阅读时产生的效果。

对于发现的每一种累积性问题：

1. 引用多处原文作为证据。如果问题跨越全文，尽量选取不同段落的例子；如果问题集中在同一小节，可以引用几句相邻的原文。
2. 解释为什么这些表达连起来会造成问题。不能仅仅因为某种写法出现次数多，就认定它不好。
3. 区分这种写法在哪些情况下本来是自然、必要或有效的，哪些地方才是真正多余或影响阅读的。不要把所有相似表达一律判错。
4. 说明这种累积问题的实际影响有多大，是轻微、中等还是严重。
5. 如果值得修改，提出具体的改进方向，并选择一两个代表性位置示范改写。不必机械地修改所有同类表达。

不要预设必须找到多少种累积性问题。某一种写法反复出现也可能完全合理，甚至是叙述所需要的。如果没有充分证据，就不要把它列为问题。

最后作出整体判断。

给语言质量打 1–10 分。

说清楚最影响阅读体验的是什么，哪些是次要问题。不要因为某类问题比较容易统计、比较容易举例，就高估它的重要性。

请特别注意：局部语言问题与全文累积问题是两种不同的判断。前者需要证明那句话本身不自然；后者需要证明多处表达连起来产生了不理想的效果。一种表达即使单独没有问题，也可以成为累积问题的证据，但必须讲清楚累积影响。

### S10（屏幕停留 28 秒）
话：他舍不得被当自己人的日子，回去还能如旧？
感受：214–215小节，开头自由试探的姿态一闪而过。 / 216–225小节，没有完整而站稳的旋律。 / 熟悉的声音只是轻轻、断断续续地浮现。 / 那些声音像先前如歌旋律的碎片。
感受：它们也像先前舞曲主题的残片。 / 另一种更凄厉哀婉的听法，是摇篮曲破碎重现。 / 这一次，摇篮曲变成了F小调。 / 声音回来了，却没有完整铺开。
感受：221–225小节，听感忽然失重。 / 整个人像悬在半空，辨不清方向。 / 零碎声音飘忽不定，身体也像失去着落。
话：受过的气还在，他不敢只凭想念回去
感受：开头的试探姿态，仿佛重新递来一个问题。 / “那么，我究竟要怎样继续生活？” / 这一次的迟疑，不再只是开始前的茫然。 / 经历了许多之后，仍没有彻底答案，只剩疲惫。
话：他想得筋疲力尽，眼下日子也不踏实
感受：轻弱零碎的声音，像疲倦的人在回想往事。 / 那件往事明明重要，他却已没有力气重讲一遍。

### S11（屏幕停留 22 秒）
话：未必找回亲近，他仍忍不住想：万一呢？
感受：左手涌起滚滚低音波涛，右手和弦像重锤砸下。 / 每次爆发之后，紧张都没有完全解除。 / 新的压力反而接着形成。 / 这不像顺境中的凯歌，更像绝境里的困兽之斗。
感受：不是顺畅奔跑，而是一次次顶住、再用力。 / 低音和弦的重压从226小节起，一直推动到241小节。
话：他不肯只凭这点指望，回去继续忍让
感受：波兰舞曲的步子没有一下子整齐地回来。 / 226–229小节，起头几步还在试探前方有没有路。 / 随后，步伐一点点聚拢。 / 238–241小节，前进感越来越不可回避。
感受：这不只是恢复旧姿态，也把柔软私密的声音带回可迈步的节奏。 / 祈祷仿佛开始变成意志。
话：他仍怕独自扛事，却先把眼下过稳
感受：他并没有忽然变得无所畏惧。 / 害怕还在，脚却已经往前走了。 / 紧张没有解除，心里却有一丝奇特的解脱。 / 问题还没解决，只是停滞本身松开了一点。

### S12（屏幕停留 25 秒）
话：他知道受过的气不该忍，也曾经开心
感受：经历动摇后，挺立也可以是主动选择。 / 即使知道自己会犹疑、疲惫、想念，仍能决定怎样站立。 / 这不要求人假装自己从未受过伤。
话：他仍会心软，也怕往后一个人熬
感受：242小节，熟悉的波兰舞曲主题以雷鸣般声势回归。 / 全键盘的声势一下占满前景。 / 沉重的步子终于踏实落地，声势几乎推着人向前。 / 这也像面向外部的公开昂扬，甚至带着集体感。
话：他不怪自己离开，不为求陪伴回头，带着想念生活
感受：249–253小节，音乐忽然换了一下色彩。 / 脚步正向前时，地面像短暂斜了一下，却仍继续向前。

### S13（屏幕停留 62 秒）
话：想起从前的亲近，他又盼未来还能如此
感受：私下安慰、近乎祈祷的柔软歌唱重新出现。 / 这份歌唱被带进开阔、宏大的音响里。 / 温柔的歌像忽然站到了明亮处。 / 音响甚至有如管风琴般庄严庞大。
感受：密集音符像狂飙激流，向天空喷涌。 / 仿佛一颗心脏以最高负荷跳动。 / 柔软没有被力量压下去，反而也进入高潮。 / 这份公开气势，还让人想到故土、共同记忆和希望。
话：他真有了劲，想好好过日子，不再较劲
感受：269–280小节，钢琴展开快速、炫目的八度进行。 / 明亮迅疾的音型向前冲出，释放积累的能量。 / 身体仿佛被气流推着往前跑，兴奋得几乎来不及喘息。
话：劲头缓了，他想到孤单，心也渐渐静了
感受：这股冲势没有一直持续。 / 281–285小节，音乐收敛下来，颤动装饰音又带来不安。 / 刚建立的成功仿佛被轻轻问了一句：“真的牢固了吗？”
感受：同一段回落，也可以听成事情已经说完，终于能停下来喘口气。 / 从容和细微不安可以同时存在。 / 平静不一定意味着疑问已经消失。
话：若有人再把他当自己人，他会好好珍惜
感受：狂潮退去，喧嚣像骤然静止。 / 低音区仿佛呼出最后一口气。 / 低处沉沉吐出两记耳语般的和弦。 / 钢琴最高音区忽然亮起一记透明的高音和弦。
感受：那记和弦孤悬如寒星，也像清脆钟响。 / 低处轻声与高处亮光形成鲜明反差。 / 结尾的力量不必只靠更猛烈的敲击。
话：即使再无人亲近，他也好好过，不为留人咽委屈
感受：最后的高音和弦，既像意志终于落定的决定，也像从梦中骤然醒来。
