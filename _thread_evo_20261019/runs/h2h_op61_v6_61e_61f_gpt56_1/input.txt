# 听感记录

### 第1段　第 1–23 小节
- 【主体验】（1–6）先听开头那一下沉重、郑重的和弦：它像要宣告什么，紧接着的自由上行琶音却没把这份重量接住，反而像烟雾往高处散，声音轻了、远了，悬在半空。也可以把它听成一次召唤，只是停顿里仿佛还等着回声。
- 【侧面】（1–23）短句像叹息，刚冒出来就被长停顿截断；听着余音在冰冷的空气里慢慢散尽。心里明明有东西，却还分不清这份不平静究竟是愤怒、遗憾还是怀念——这是一种尚未找到对象、也尚未找到语言的失落。
- 【侧面】（1–23）换一种更身体化的听法：像刚从漫长的昏沉中醒来，四周冷而空，胸口有些发紧，视线还模糊着；伸出颤抖的手去摸，摸到的却只有虚空。这里不是已经哭出来的悲伤，而是连自己身在何处都还没弄清的恍惚。
- 【段内变化】（9–17；18–23）约9–17小节，旋律轮廓稍稍清楚，像一幕旧场景忽然回来：当时的声音、光线和某种熟悉的感觉都回来了；可记忆再清晰，过去也不会因此重新变成现在。到18–23小节，波兰舞曲的步态逐渐浮现，像身体先于意识，隐约记起了该如何迈步。这只是往前的牵引，还不是第24小节起的主题已经站稳。
- 【侧面】（1–23）另一个听法是：开头那下有分量的和弦，像一个人强迫自己挺直背脊，提醒自己不能倒下；可自由琶音马上把这份郑重带回内心的游移。尊严还在，行动的方向和力气却不稳——“我不能倒下，以及我其实很想停下来。”

### 第2段　第 24–65 小节
- 【主体验】（24–65）波兰舞曲的步态终于清楚了，却不像英雄凯旋；主旋律更像一首从远处传来的旧歌，你依稀记得它，却只能模糊地哼出几句。也可以把它听成两层声音：舞曲带着一点面向众人的庄严，歌声却像私人记忆里的低声哼唱。那些珍惜的东西仿佛还在，却已不能像从前那样拥有。
- 【侧面】（24–65）它不是士兵的步伐，更像腿脚虚浮的人，在记忆中挪动舞步。节奏本身庄严、傲慢，旋律却脆弱凄婉；底下的伴奏还有细碎、不安的半音在蠕动。
- 【段内变化】（38–65）听它怎样起伏：38–43小节，音乐猛地往上推，却又退下来；44–65小节再次聚拢力量，52–63小节一带更焦灼，最后仍没有舒舒服服地落地。56–65小节连绵的三连音，仿佛把呼吸催得越来越急。
- 【侧面】（24–65）这份挺直可以听成一种强烈的自我控制。像一个人整理好衣服、抬起头，不让别人看见动摇；到44–65小节，它又像反复对自己说“我没事”：第一次还有几分相信，第二次开始努力让自己相信，说到第三次，连这句话本身都暴露出其实很在意。悲伤还在，只是不愿把自己完全交给悲伤。
- 【侧面】（44–65）另一种心理动因是，44–65小节的激昂像一句“我不甘心就这样消亡”：不是轻松恢复自信，而是负隅顽抗。这股力量可以与自我控制同时存在，但不必把两种原稿的说法拼成同一个人的确定剧情。

### 第3段　第 66–91 小节
- 【主体验】（66–91；m.66的和弦重击为条件性细节）第66小节的和弦若被突出，会像重锤砸下，带着愤怒与抗拒；这一段强弱跳动、切分让人心口悬起。音乐离开前面的端正步态，转入更灵活、流动却不安的舞蹈性格，像想往前走，却无法平静地决定方向。
- 【段内变化】（66–79 → 80–91）一种听法把前半（66–79）听成焦躁、急切，后半（80–91）则忽然柔和、亲切，带一点近乎田园的轻盈。有人会想到故乡夏日的麦浪与微风；另一种相近的联想，是曾经轻松、亲近、不必时时防备的时刻。温柔得让人心颤，也刺痛得让人绝望：越怀念，越能感觉它与眼前处境的距离。
- 【侧面】（66–91）也可以把耳朵收进旋律里：像多个人在耳边低声絮语，彼此缠绕，找不到出口；调性又像流沙，抓不住重心，四处漂移。
- 【另一种听法（和本段某一颗不能同时成立）】（66–91）这股活动感也可以听成一次短暂的侧身离场：不再正面迎着那个沉重的问题，像是聊点别的，或出去走走，让注意力暂时离开伤口。那一刻的轻松可以是真的，并非假装；只是它没有替心里的事找到答案。
- 【另一种听法（和本段某一颗不能同时成立）】（66–91）另一个听法不是把这里听成重新获得活力，而是前一段的昂扬慢慢退潮。音乐变得流动、含蓄、若有所思，仿佛心里冒出一句自问：我刚才是真的相信那些话，还是只是在努力让自己相信？

### 第4段　第 92–115 小节
- 【主体验】（92–107）熟悉的波兰舞曲主题又回来了，流动的伴奏和装饰音让旋律更抒情、更像在独自说话；旧记忆也忽然变得鲜活，甚至带出感激、亲密、柔情和短暂的幸福。可原来的姿态回来，却显得更柔软、更容易受伤：外在的步伐还在向前，里面却有了更多回声。这份坚定也可能是他努力想成为的样子，而不再是一个毫无疑问的事实。
- 【段内变化】（92–115，转折集中在108–115）92–107 的温暖没有一路把音乐带向安稳：到108–115，音乐忽然显出风暴般的激烈与紧绷，越用力却没有越安稳。把这一转折听成记忆带来的刺痛，是一种有原稿支持的听法：不是记忆变坏了，而是它太好了——过去无法原样回来。同一段的半音阶下行又带来另一股反向的力，像在撕扯中步步后退，抵抗显得疲惫而仓促。
- 【侧面】（92–115）若把注意力放到身体，细碎的音符像急促的脚步或乱了拍的心跳；左手低音在追赶，右手狂乱地挣扎，像被时间催着往前跑。紧张不只是一个情绪词，而是身体仿佛已经被节奏逼得无法停下。
- 【侧面】（94–115）另一个可以同时听见的层面，是脑子里停不下来的自问：“如果当时……”“是不是还可以……”“究竟为什么会变成这样……”表面上动作越来越多，实际上并没有真正抵达哪里；运动本身只是为了避免停下来。它不是身体被追赶的另一种比喻，而是思绪反复盘旋、试图想清楚却无法停歇的心理处境。

### 第5段　第 116–147 小节
- 【主体验】（116起；私语感延续于116–147）116小节一转，声音像换了一个更柔和的人在说话：歌唱变得亲近，却仍然克制。两只手仿佛夜色里两个影子，彼此低声说话。
- 【侧面】（116–127）116–127小节里，柔和的歌唱并没有抹掉向前的劲：音乐仍像被压力推着走，情绪比前面更直接、更有宣告性，仿佛在说：“这件事不能就这样算了。”里面可以同时有愤怒、悲伤，也有想维护自己的那股劲。
- 【段内变化】（128–147，尤其128–129、139–144附近）从128小节起，右手的快速音型仍在往前流，随后运动逐渐减弱，落入较慢、较稀疏的和弦。尤其在128–129、139–144小节附近，旋律几乎单独露出来，像脚下原有的地板忽然不见了，只剩一个声音自己说话。
- 【段内变化】（约132–147，重点在144–147）约132小节以后，躁动和不安又加深；到144–147小节，才像几次深呼吸，或一声深深的叹息，紧绷短暂松开。声音变稀疏并不等于心里平静：这一下松动也可以听成“不是他想通了，而是他抵抗累了”。
- 【另一种听法（和本段某一颗不能同时成立）】（116–147）另一个听法是把这段柔和的歌唱听成旧日记忆重新有了温度。它可能指向某个人，也可能是故乡或过去的生活；可正因已经过去，眷恋里也带着失落。

### 第6段　第 148–180 小节
- 【主体验】（148–180整体，尤其148小节起的换境与持续安静感）148小节起，音乐像毫无征兆地滑进一片与此前世界隔开的静谧。声音绵长、从容，近乎停驻；整个世界像被一层透明玻璃罩隔开，连呼吸都不愿惊动它。它也像母亲在耳畔轻轻哼唱的摇篮曲，温柔得让人暂时松开戒备；可这份安宁不是现实已经变好，也不是能永远停留的地方。
- 【侧面】（148–180整体；约160小节的远方显现）这里先有近似圣咏的庄严，旋律却又像藏在心里的秘密念头。它可以像一个人终于不用再向别人解释自己为什么难过，也不必维持“我应该坚强”的姿态；那些压住的愿望、委屈和思念，终于有机会浮现。歌唱又像向某个遥远、并不确定的对象祈求，愿望是真的，音乐却没有保证回应。约160小节，还可以听见另一幅短暂的画面：远方忽然被照亮，已经远去的家园在梦里显现——那不是回到那里，只是看见它。
- 【段内变化】（148–151；152–167；168–180；约180小节的未完感）可以沿着旋律听它怎样一步步敞开：148–151小节还含蓄、试探，152–167小节歌唱逐渐展开，像终于鼓起勇气说出心里的话。到了168–180小节，歌唱再次展开，情感变得更充实、更迫切。临近180小节，它又像停在一句没说完的话上。
- 【演奏条件】（148–180整体）如果这次演奏把旋律线条处理得柔和、连贯，可以留意一层波浪托着另一层波浪：它轻轻托起，又缓缓落下，不必被推成夸张的戏剧场面。
- 【另一种听法（和本段某一颗不能同时成立）】（148–180整体，不定位到单一小节）也可以把注意力放在“看”而不是“抓”：明知有些事已经挽不回，便放轻声音，好好看着它。像看着自己珍惜的东西，不必立刻把它抓回来。

### 第7段　第 181–205 小节
- 【主体验】（182附近）m.182附近，高音区忽然浮出一串轻得像游丝、却带着刺骨寒意的长颤音。它像寒风猛地吹开紧闭的窗，把人从甜梦里生生拽回严寒；后颈一凉，脉搏也剧烈跳动。梦境不是慢慢淡去，而像突然破裂，身体先被惊醒。这一瞬间的寒意和惊悸，是这次转向最鲜明的身体感受。
- 【段内变化】（182–197）同一转向里，带马祖卡色彩的舞蹈性材料闯了进来，和前一刻近乎祈祷的静谧形成反差。它不像沿着刚才那条深沉的思路继续往下讲，而像突然换了一个场景，原先的思绪被截断，音乐从别处重新开讲。这种突兀的换向并不等于情绪好转；新出现的舞步可以很鲜明，内心却未必因此安定下来。
- 【段内变化】（198–205）到了198–205，连续颤音让紧张一层层累积，思绪像不停翻转，想停也停不下来。事情表面上仿佛已经过去，身体和情绪却还没有完全相信一切结束。心里有东西在颤动，想要冲出去，却始终找不到真正的出口。这不是前一刻的惊醒本身，而是随后持续盘旋、难以平复的紧张。
- 【另一种听法（和本段某一颗不能同时成立）】（182–197）同一段还有另一种材料辨认：一些原稿把182–197听成先前更具宣告性、带有波兰舞曲气质的材料重新出现。但即使采用这一听法，它也不再像最初那样，以完整而鲜明的姿态建立秩序。这是对音乐材料的另一种理解，不是断言它已经完成了主题回归；更不必把它讲成一个人重新站直、重新找回旧日自我的连续故事。
- 【侧面】（181–205）另一个可以同时浮现的联想，是一种非常具体、非常生活化的记忆突然闯进深沉的感受里：一个熟悉的动作、一次舞蹈、一段曾经习以为常的生活。这不是对舞曲主题身份的判断，也不必和上面的材料辨认拼成一个人的连续经历。这样的亲切感未必安慰人；恰恰因为那些细节具体而熟悉，反而更容易意识到自己已经失去了什么。

### 第8段　第 206–213 小节
- 【主体验】（206–213）206–213小节，前面那种缓慢、宽广的歌唱短暂地回来，沉思、近乎祈求的气息又被认出来，像熟悉的柔软处重新打开了。
- 【侧面】（206–213）但它停留得太短，刚认出那份安静，还来不及重新安顿，就又退开。像一个人已经准备离开，却在最后一刻回过头，再看一眼刚才待过的地方；那一眼里有温柔，也有不舍。
- 【侧面】（206–213）换一个角度，也可以只留意身体的感觉：激烈的思绪之间，忽然像是获得了一次短暂的呼吸，胸口仿佛终于吸进一口气。它只是瞬间的喘息，并不等于整个人重新安顿下来。

### 第9段　第 214–215 小节
- 【主体验】（m.214–215；颤音光晕的来源描述覆盖mm.206–215。门槛意象只指开头姿态重新显现，后续向前的推进尚未在此展开。）开头沉重的引子又从双手巨大的颤音光晕里阴冷地闪回来，却不再像最初那样郑重召唤。声音短暂落稳，又向高处漂去，刚有的稳定感随即散掉；像同一扇门从另一面显出，真正向前的步伐还没聚起来。
- 【侧面】（m.214–215的开头姿态回返；心理意味借由此前全曲的经历成立，相关原稿多以mm.214–225为讨论范围。）像是重新遇见那个不知道怎么办的自己——只是这一次，你已经知道他经历过什么。最初的问题又浮上来，却没有因此得到一个简单答案。
- 【演奏条件】（m.215；低声荒凉的背景描述覆盖mm.208–220。）如果你听到的版本把m.215的强声突然凸显出来，这里会像一记短促的惊跳：低声的荒凉被硬生生划开，力量又很快退去。

### 第10段　第 216–225 小节
- 【主体验】（216–225）214–215小节开头那种自由、试探的姿态一闪而过后，216–225小节并没有接出一段完整、站稳的旋律；熟悉的声音只是轻轻地、断断续续地浮出几块。它可以被听成先前歌唱材料的碎片，也可以被认作舞蹈性主题的残片；另一种更凄厉哀婉的听法，是先前那段摇篮曲以F小调残破地回来。无论采用哪种认定，较稳妥的共同感受是：声音回来了，却没有完整铺开。
- 【侧面】（221–225）到了221–225小节，听感像忽然失了重，整个人悬在半空，辨不清方向。这不只是一种声音零碎的感觉，也像身体暂时失去了着落。
- 【另一种听法（和本段某一颗不能同时成立）】（216–225）如果把这次回返听成心理上的回望，开头的试探姿态仿佛把问题重新递回来：“那么，我究竟要怎样继续生活？”相似的迟疑此时不再只是尚未开始时的茫然，而是走过许多之后，仍未能获得彻底答案的疲惫。这是对回返的一种理解，不是音乐唯一确定的故事。
- 【另一种听法（和本段某一颗不能同时成立）】（216–225）换一种听法，这些轻弱、零碎的声音像一个疲倦的人回想一件往事：明明知道它很重要，却已经没有力气把它重新讲述一遍。

### 第11段　第 226–241 小节
- 【主体验】（226–241；226–229的试探与238–241的向上积聚标出这条变化弧线）波兰舞曲的步子不是一下子整齐地回来：起头几小节还像在试探前方有没有路，随后步伐一点点聚拢，到最后四小节，前进感越来越不可回避。它不只是恢复旧姿态，仿佛把前面柔软、私密、近乎祈祷的声音带回可以迈步的节奏里——祈祷开始变成意志。
- 【侧面】（226–237的反复冲击与紧张未解；低音和弦的重压从226小节开始，推动延续至241小节）左手涌起滚滚低音波涛，右手的和弦像重锤一样砸下。每次爆发之后，紧张都没有完全解除，反而又形成新的压力。这不像顺境中的凯歌，更像绝境中的困兽之斗：不是顺畅地奔跑，而是一次次顶住、再用力。
- 【侧面】（226–241；这一心理理解贯穿全段，238–241的向上推进使前进感更难回避）如果把这股推进听成人的处境，最动人的不是忽然变得无所畏惧，而是害怕还在，脚却已经往前走了。紧张并没有解除，却有一丝奇特的解脱：不是问题解决了，而是停滞本身松开了一点。

### 第12段　第 242–253 小节
- 【主体验】（242–253，主题回归起于m.242）m.242，熟悉的波兰舞曲主题以全键盘雷鸣般的声势轰然回归，一下占满前景，像沉重的步子终于踏实落地，声势几乎把人推着向前。它也可以听成一种面向外部、公开的昂扬，甚至带一点集体感。
- 【侧面】（242–253，与此前主题姿态形成回顾性的对照）这份挺立也可以听成经历动摇后的主动选择：即使知道自己会犹疑、疲惫、想念，仍然可以决定怎样站立。它不要求人假装自己从未受过伤。
- 【段内变化】（249–253）不过，昂扬没有一路直冲到底。249–253间，音乐忽然换了一下色彩，像脚步正往前时地面短暂斜了一下，随后却仍继续向前。

### 第13段　第 254–288 小节
- 【主体验】（254–270）先前像私下安慰、近乎祈祷的柔软歌唱重新出现，却被带进开阔、宏大的音响里，像一支温柔的歌忽然站到了明亮处，甚至有如管风琴般庄严庞大。密集的音符又像狂飙的激流向天空喷涌，仿佛一颗心脏以最高负荷跳动；柔软并没有被力量压下去，而是也被带进了高潮。这份公开的气势，还可以让人想到故土、共同记忆和希望，但不必把它听成某个具体胜利的宣告。
- 【段内变化】（269–280）约第269小节，钢琴展开快速、炫目的八度进行，明亮、迅疾的音型向前冲出，把积累的能量一下子释放出来。这里的身体感不再只是前一刻的宏大歌唱，更像被一股气流推着往前跑，兴奋得几乎来不及喘息。
- 【段内变化】（281–287）但这股冲势没有一直持续。约第281–285小节，音乐收敛下来，颤动般的装饰音重新带来一点不安，仿佛刚刚建立的成功又被轻轻问了一句：它真的已经牢固了吗？同一段回落也可以听成事情已经说完、终于能停下来喘口气。从容与细微的不安不必互相排斥，平静也不一定意味着疑问已经消失。
- 【段内变化】（末尾几小节）狂潮退去，喧嚣像骤然静止。低音区像呼出最后一口气，沉沉吐出两记耳语般的和弦；随后，钢琴最顶端忽然亮起一记清脆、透明、孤悬如寒星的高音和弦，像一声清脆的钟响。低处的轻声与高处的亮光形成鲜明反差，结尾的力量不必只靠更猛烈的敲击。
- 【另一种听法（和本段某一颗不能同时成立）】（286–288）最后的高音和弦可以听作一个决定，也可以听作一个人忽然从梦中醒来。前一种听法更像意志终于落定，后一种更像从梦境中骤然清醒；它们是对同一记声音的两种理解，不是先后发生的两件事。

# 各条线

## 线A
第1段（1–23）［还说不清］
  起初他连自己在等什么都说不清，只知道心里有股劲，不肯就此算了。
  → 任由事情照旧，仿佛就是承认它们本该如此；真投进去，又怕会丢下什么。
  → 他于是寻找一个够有力的理由，盼着自己终于不再犹豫。
  → 每次快信自己想通了，舍不得又冒出来，确信也变陌生；他开始难堪：非得理清一切才肯走吗？
第2段（24–65）［正在面对］
  “还没想清楚”再也不能成为等下去的理由，他先认下自己能做的那一份。
      ← 改写：（1–23）「质疑非想清才行动」
  → 没有保证，牵挂也没消失；可一行动，他便感到有力量。从前总问值不值，如今只说愿尽力。
  → 这让他有些骄傲：心里仍有疑虑，也可以不让疑虑替自己做主。
  → 越投入越热切，付出的过程本身就让他快乐，仿佛心里的不满终于有了去处。
  → 他愿意给得更多，也贪恋倾尽全力的畅快，不再时时审视自己或为一点软弱停步。
  → 可用力深处，仍有一小块心没跟着高昂；它没拦住他，却提醒他还有牵挂未被照顾。
第3段（66–91）［没在想］
  认真投入过一回，他反倒从反复自问里松开些，也发现自己会因不再畏缩而高兴。
      ← 提供理由：（24–65）「投入本身带来快乐」
  → 向前的热情让他轻盈；偶尔忘了为何用力不算背叛，他便顺着自由走了一程，也没急着解释它。
  → 快乐渐渐淡下去，先前那个决定又回到眼前，等着他重新面对。
第4段（92–115）［正在面对］
  他仍愿坚持那个决定：它确实把自己从动弹不得的犹豫里带了出来。
      ← 唤起：（66–91）「快乐淡去决定重现」
      ← 提供理由：（24–65）「不再拿未想清作借口」
  → 那阵轻快也是真的；心里尚有缺口，不等于先前一切都错。
  → 可曾让他昂起头的坚定，如今安不了心；越想确认自己有力量，越听见心底另一个要求。
  → 他只能承认这个不情愿的答案：行动值得，却仍然不够。
第5段（116–147）［正在面对］
  行动明明还不够，他却舍不得撒手：它曾救他脱离犹疑；怕失望说明变心，他便逼得更紧。
      ← 提供理由：（92–115）「坚持带自己走出犹豫」
  → 明知自己在受苦，他仍把难处当成该克服的迟疑；想停一下，又怕辜负最初的决意。
  → 那份曾让他昂然的要求，渐渐连脆弱也容不下，终于变成苛责。
  → 越想显得坚定，他越像在逼一个疲惫的人硬撑；终于不想再证明自己有多坚强。
  → 放下催逼并没立刻让他安心，却给一直压住的依恋留了空隙。
  → 他有些茫然，也松懈下来，终于承认：除了该做的事，还有真心舍不得的东西。
第6段（148–180）［没在想］
  催逼一停，那份依恋才显出原样：他想要的是曾真心相信过的一种生活。
      ← 说明：（116–147）「承认心中有所不舍」
  → 他盼着人与人不必时时防备，珍贵的东西也不必靠争夺才能留下。
  → 他盼着不必反复证明自己值得被爱、被接纳；付出可以只因喜欢，靠近也不必先做好受伤的准备。
  → 这样的相信曾给过他快乐，让他觉得人与生活可以亲近，不必时时用力维系。
  → 那些感受确实发生过，所以他无法把这份盼望贬成不切实际的软弱。
  → 这回他让爱惜本身留下，不拿责任盘问，也不急着证明它有用或追问能否实现、孰轻孰重。
  → 只是准许自己去爱、去相信，满足便涌上来；那个只会使劲向前的人仿佛又柔软了。
  → 这份安宁是真的，他几乎忘了先前的疲惫，一时也不想离开。
第7段（181–205）［正在面对］
  安宁太真实，他渐渐不满足于只在心里拥有；这份满足反而照见心愿还没实现。
      ← 提供理由：（148–180）「沉浸真实安宁不愿离开」
  → 既然那种生活值得珍惜，使它难以存在的事情，怎能只靠怀念改变？
  → 他想起当初不肯再等，正是不愿看着重要的东西继续受损。
      ← 仍在起作用：（1–23）「害怕投入后失去」
  → 他懊恼地问自己：怎么才刚沉进满足，就忘了还有事要面对？
  → 他试着重新振作，却发现自己已无法像从前那样毫无顾忌地投入。
  → 如今越懂温柔可贵，他越怕争取会耗尽它，最后只剩意志，失去一切值得争取的心。
  → 向前怕温柔被耗尽，留下又放不下它正受威胁。
  → 他曾以为理由足够坚定便不再为难；如今理由更多，心反而更难平静。
第8段（206–213）［没在想］
  为难时，那份温柔又短暂地靠近；他明知不能久留，却舍不得立刻推开。
  → 既然它真给过自己那么深的满足，何必每次想起都立刻拿来审问自己？
      ← 提供理由：（148–180）「沉浸真实安宁不愿离开」
  → 他愿再爱惜片刻，暂不去想没答案的事；这点安静仍让他欢喜，只是欢喜里已有不舍。
第9段（214–215）［正在面对］
  安静退去，熟悉的迟疑又回来，仿佛走了很远，最后仍回到原处。
      ← 唤起：（206–213）「珍惜片刻安静与欢喜」
  → 但他已知道自己放不下什么：迟疑里有怯懦，也有不愿失去的生活希望。
      ← 改写：（148–180）「依恋显出向往的生活」
第10段（216–225）［正在面对］
  看清自己舍不得什么，并没让他立刻勇敢起来。
      ← 限制：（214–215）「迟疑中藏着生活希望」
  → 他已不能只凭最初的决心向前，也无法安心沉浸旧愿；两条路都帮过他，也各有难处。
      ← 说明：（92–115）「坚持带自己走出犹豫」
  → 他暂时没力气要求自己大变，只盼若还要争取就记得缘由，若珍惜安宁也别放下威胁它的事。
  → 他还不知道怎么做到，只一遍遍想着这点微弱的愿望。
  → 想得久了，那种非得舍弃一边才能继续的逼迫，似乎松开了一点。
第11段（226–241）［正在面对］
  凭着这点还不牢靠的心意，他重新琢磨自己还能怎么做。
      ← 提供理由：（216–225）「非此即彼的逼迫松动」
  → 他亲身体会过，尽力承担能让人从无力中重新动起来，却消不掉所有牵挂。
      ← 说明：（24–65）「行动中感到有力量」
  → 心里的美好生活也能安慰他，却不能只靠安慰护住真正珍惜的东西。
      ← 限制：（148–180）「沉浸真实安宁不愿离开」
  → 两样收获都是真的，他不愿简单否定任何一个；可要它们毫发无伤地并存，恐怕不可能。
  → 他想留住不用时时奋力的安宁，可为它争取也可能失去它；过去他总怪自己不够坚定。
  → 如今他渐渐明白，难处未必是意志不够强，而是自己珍惜的东西确实不止一种。
  → 想到要付出的东西，他仍心疼，也盼着有条容易些的路；可再等下去，那条路不会自己出现。
  → 若只因怕珍贵之物受损就不再争取，自己爱惜的也未必留得住。
  → 他不再要求自己先毫不害怕；带着不舍、没把握，也能边承担边受苦，继续向前。
  → 走近真正要承担的事，他还是会怕，只是不肯再让恐惧替自己决定。
第12段（242–253）［正在面对］
  不再等毫无损失的办法，他终于重新向前；久违的昂扬回来，也不必靠否认脆弱维持。
      ← 提供理由：（226–241）「不让恐惧替自己决定」
  → 他仍愿尽力，却不再要求每一分努力都证明自己能改变一切。
  → 他知道要做什么，也明白为何舍不得；怕失去的、想珍惜的，都能摆在明处。
      ← 仍在起作用：（226–241）「难处在于珍惜不止一种」
  → 他愿为真心爱惜的一切负责，不再把牵挂当作行动的拖累。
  → 这次决心仍热烈，却比从前踏实；他不必等犹疑消失，才准自己坚定。
第13段（254–288）［正在面对］
  带着全部牵挂重新向前，他意外发现：旧日的愿望没有远去，反而更亲近了。
      ← 改写：（242–253）「明白该做也不掩不舍」
      ← 仍在起作用：（148–180）「盼人与人不必防备」
  → 从前一想到那种生活，他就想退出艰难的争取，仿佛退回来才能完整保住它。
  → 如今正因知道它多么可贵，他更不愿任由那些使它难以实现的事继续存在。
      ← 仍在起作用：（181–205）「想起当初不肯再等」
  → 正因仍向往那种不必拼命的生活，他不肯袖手旁观；要珍惜它，有时反而得离开安宁去行动。
  → 投入更多不保证靠近旧梦，愿望也不能让付出自动值得；留心别耗掉所爱，才知道怎样坚持。
      ← 限制：（226–241）「尽力承担使人重新行动」
      ← 限制：（226–241）「安慰无法护住珍爱之物」
      ← 改写：（181–205）「害怕争取耗尽温柔」
  → 重新看懂这份希望后，他感到更宽的喜悦：两股曾拉扯他的心意，如今能一起推他向前。
      ← 改写：（226–241）「难处在于珍惜不止一种」
  → 他不必为依恋羞愧，也不必因肩上有责任，就厌倦自己想珍惜的东西。
  → 最初相信生活时的快乐又回来；经历怀疑与疲惫，他知道这快乐并非理所当然。
  → 喜悦平静后，他仍无法保证尽力会改变什么，也没真正回到无需防备的生活。
  → 往后仍会疲惫，也可能因代价动摇；两种渴望同行，不代表它们不再冲突。
  → 他不再拿一种满足遮住另一种需要，也不因心愿未成，就否定已经得到的东西。
      ← 改写：（92–115）「承认行动值得却不够」
      ← 改写：（148–180）「沉浸真实安宁不愿离开」
  → 这一切让他更清楚：哪些值得付出，哪些不能在付出时轻易丢掉。
      ← 提供理由：（24–65）「投入本身带来快乐」
      ← 限制：（116–147）「坚定要求渐成苛责」
      ← 提供理由：（148–180）「沉浸真实安宁不愿离开」
      ← 限制：（181–205）「害怕争取耗尽温柔」
  → 他仍向往安宁，也愿意行动，却不知道最后能留下多少珍贵的东西。
  → 他不愿靠忘掉任何一边换取安稳，也不再需要为自己愿意向前找更多证明。
