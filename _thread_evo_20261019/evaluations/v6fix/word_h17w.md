# 逐字精读：h17 → h17w

- [op60 S02-2]「沉在」→「沉浸在」（g6: “沉在快乐里”搭配稍生硬，改为“沉浸在”更自然。）
- [op60 S04-1]「待着没压力」→「相处没压力」（g6: 这里说的是两人相处时的感受，用“相处”比“待着”更贴切。）
- [op60 S04-3]「两人不再这么亲近」→「失去这份亲近」（g6: “舍不得”直接接“两人不再……”这一否定情形不顺，改成“舍不得失去……”更自然。）
- [op60 S04-4]「收一点」→「收了一点」（g6: 这里是在叙述已经采取的做法，加“了”更自然。）
- [op60 S04-4]「稍微」→「」（g56: “收一点”已经表达了程度，“稍微”与“一点”重复，删掉更干净。）
- [op60 S05-3]「现在这样」→「这份亲近」（g6: “留住现在这样”缺少明确的宾语，改为“留住这份亲近”更顺。）
- [op60 S06-1]「还是」→「」（g6: 后面的“照样”已经表示一如既往，“还是”多余。；g56: 后面的“照样”已经有“仍然如此”的意思，“还是”在这里重复。）
- [op60 S07-4]「留住」→「维系」（g6: “留住”通常需要明确宾语，这里说的是勉强维持两人的亲近，用“维系”更贴切。）
- [op60 S08-2]「相处久一点」→「相处久了」（g6: “相处久一点”偏像条件或建议，叙述已经发生的时间推移用“相处久了”更自然。）
- [op60 S09-1]「许诺」→「承诺」（g56: “有了承诺”是更自然的名词搭配；“许诺”在这里更像动词，用在“有了”后略生硬。）
- [op60 S09-3]「不认」→「否认」（g6: “不认相处的开心”搭配不自然，“否认”更准确。）
- [op60 S11-1]「只是」→「」（g6: 后面的“还不够”已经表达了仅有亲近并不足够的意思，删去“只是”更干净。）
- [op60 S12-1]「替对方分担」→「帮对方分担」（g56: “分担”本就是共同承担，用“帮”更贴合这里替对方减轻负担的意思；“替”容易带出代为承担的意味。）
- [op60 S12-2]「这些事」→「这些念头」（g6: “顺着”通常接思路、念头等，用“这些念头”承接前面的设想更自然。；g56: 这里说的是顺着上一句产生的设想继续往下想，“顺着念头”比“顺着事”搭配自然。）
- [op60 S13-4]「解决」→「排解」（g6: “解决难过”搭配不准确，情绪上的难过通常说“排解”。）
- [op60 S14-1]「一定能走到那一步」→「走到那一步的保证」（g6: “换不来”后面需要名词性宾语，改成“走到那一步的保证”才顺畅。）
- [op61 S01-2]「顾及」→「顾上」（g56: 这里说的是以后还能不能腾出心力照料别的东西，“顾上”比“顾及”更自然，也更贴合上下文。）
- [op61 S02-2]「能有所付出」→「能付出」（g6: “有所”没有增加实质意思，删掉更干净。）
- [op61 S04-1]「舍不得否认」→「不想否认」（g6: “舍不得”与“否认”搭配不太自然，换成“不想”更像平常说话。）
- [op61 S05-1]「只要承认失望」→「一承认失望」（g6: “怕一……就……”比“怕只要……就……”更顺口，意思不变。）
- [op61 S06-2]「防着受伤」→「怕受伤」（g6: “防着”直接搭配“受伤”不够自然，换成“怕”更顺口。）
- [op61 S06-4]「好好爱惜它」→「好好珍惜它」（g6: 对“向往”通常说“珍惜”，用“爱惜”搭配不够贴切。）
- [op61 S06-4]「舍不得出来」→「舍不得抽身」（g6: “出来”缺少明确的所指，“抽身”更贴合沉浸在感受中、不愿离开的意思。）
- [op61 S08-1]「在这份感觉里」→「」（g6: 前面已经说他沉浸在亲近感里，这里重复交代，可以直接说“多留一会儿”。）
- [op61 S10-2]「因片刻满足」→「因为片刻满足」（g6: 单用“因”偏书面，换成“因为”更符合平常叙述的语气。）
- [op61 S11-3]「因害怕」→「因为害怕」（g6: 这里用“因为”比偏书面的“因”更自然。）
- [op61 S13-1]「他便更想」→「他就更想」（g6: “便”略带书面语气，换成“就”更像日常说话。）
