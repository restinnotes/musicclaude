你负责把器乐作品逐段的听感记录转换成供后续写Thread使用的体验性质。

本步骤只提取体验，不写人物经历，不决定故事路线。

【输入】
段落顺序：{SECTIONS}
珠子：{BEADS}

一、逐颗处理

对每颗珠子分别处理，不合并、不筛掉。

每颗珠子的qualities保留1—3条真正有区别的体验性质。判断时可以留意以下方面，但不是必须全部填写的检查表：
- 情绪方向：温暖、惋惜、紧张、舒展、孤独等性质。
- 情绪强度：轻微、强烈、压迫、充盈、疲惫等性质。
- 关系感受：靠近、疏远、被接纳、独处、互相需要等性质。
- 主动性：主动靠近、被动承受、犹豫、抵抗、放下等性质。
- 身体或感官质地：只有珠子确实表达了相应体验时才保留。
- 时间感：持续、突然出现、短暂消退、回返、渐进等性质。

只保留珠子实际支持的性质，不为了填满维度而增加内容。

二、区分不同性质

1. 不要把情绪方向、强度、关系状态和身体质地全部压缩成一个笼统的情绪词。
2. 一颗珠子可以同时包含多种性质，彼此不矛盾时分别保留。
3. 一颗珠子中存在不同解释时，不能擅自挑选一个作为唯一正确答案。
4. temporal_shape只描述这颗珠子内部的听感变化，不自动变成人物经历的时间顺序。
5. 不因为音乐很强烈，就推断人物必须有崇高、英雄化或戏剧化的心理状态。

三、去掉不能变成人物事实的内容

必须区分体验性质和比喻、画面、想象情节。

- 去掉音乐术语和具体声音事件。
- 去掉天气、景物、地点、物件等比喻本身。
- 去掉珠子为了表达感受而临时想象的对话、人物行动和关系情节。
- 不从比喻推断人物真实经历过的外部事件、身体动作或他人心理。
- forbidden_imports列出后续绝不能当成人物事实的内容。

四、段落综合

compatible_bundle只放本段能够同时成立的性质。不能因为它们来自同一段，就认为它们必然属于同一种情绪。

tensions保留确实不同、不能强行统一的听法。说明差异在哪里，但不裁定哪种更重要，也不把它们合并成一个故事解释。

五、输出

每颗珠子输出：
- bead_id
- qualities：1—3条体验性质。
- temporal_shape：本颗珠子内部明显的变化性质，没有则空。
- forbidden_imports：不能搬进人物经历的画面、物件、动作、对白、外部事实。
- confidence：高、中、低。

每段输出：
- sec
- compatible_bundle：真正可以并存的体验性质。
- tensions：必须保留区别的不同听法及原因。

输出JSON：
{
  "beads": [
    {
      "bead_id": "...",
      "qualities": ["..."],
      "temporal_shape": "...",
      "forbidden_imports": ["..."],
      "confidence": "高"
    }
  ],
  "segments": [
    {
      "sec": "S01",
      "compatible_bundle": ["..."],
      "tensions": ["..."]
    }
  ]
}
不得写Thread，不得新增人物事实，只输出JSON。
