  - [S07 第4条]「他不敢指望两人能一直这样下去，心里虽然不安，却不再靠热情去勉强留住了。」——“靠热情去勉强留住了”收尾不顺。“留住”缺少宾语，“勉强留住”也不够明确：究竟是勉强自己，还是硬要维持两人的关系？结合前文可以理解，但这句话本身说得不够顺。 → 他不敢指望两人能一直这样下去，心里虽然不安，却也不再想靠热情硬把这份亲近留住。
  - [S09 第1条]「他明白眼下开心，不代表就有了许诺。」——“眼下开心”省略得有些生硬，“有了许诺”也不太自然。这里要表达的是，两人相处得开心，并不意味着对方已经作出承诺。原句把两层意思压缩在一起，读起来稍有障碍。 → 他也明白，两人现在相处得开心，并不代表对方许诺了什么。
  - [S09 第3条]「他不愿因为没答案就不认相处的开心，可光有这开心不够，他还是盼着回应。」——“不认相处的开心”是比较明显的不自然搭配。“不认”可以说“不认账”“不认这个理”，但用来表示不愿否认一段相处曾经带来的快乐，就显得生硬。后面的“光有这开心不够”也稍微压缩过头。 → 他不想因为没答案，就觉得两人在一起时的开心不算数；可光有这份开心还不够，他还是盼着回应。
  - [S11 第1条]「原来，只是能和对方亲近还不够，他还想成为对方心里特别珍惜的人。」——“只是能和对方亲近”不如“光是能和对方亲近”顺口。“对方心里特别珍惜的人”也稍有搭配不当的感觉，“心里特别”与“特别珍惜”两种说法挤在了一起。 → 原来，光是能和对方亲近还不够，他还希望自己也是对方特别珍惜的人。
  - [S12 第2条]「顺着这些事，他又想到以后两人一起过日子，越想越觉得幸福。」——“顺着这些事”用来连接心理联想，不太符合日常说话习惯。这里不是沿着某些事情行动，而是想到以后愿意分担的琐事和难处，自然而然地想象起共同生活。 → 想着这些，他又想到了两人以后一起过日子的样子，越想越觉得幸福。
  - [S13 第4条]「他不想让对方替自己解决这份难过，也不肯为了好受一点，就假装自己不想要这样的日子。」——“解决这份难过”搭配有点生硬。“解决”通常用于问题、困难，而“难过”是一种感受。原句要表达的并不是对方具体应该解决什么问题，而是他不愿让对方承担消除自己难过的责任。 → 他不想把自己的难过变成对方必须解决的事，也不肯为了让自己好受一点，就假装自己不想要这样的日子。
  - [S14 第1条]「他现在很清楚，就算收着心意也还是会难过，给得再多，也换不来一定能走到那一步。」——“换不来一定能走到那一步”不符合自然的动宾搭配。“换来”后面通常接某种结果或保证，而“一定能走到那一步”是一个判断，不能直接这样承接。这是全文比较明显的一处拗口表达。 → 他现在很清楚：就算收着心意也还是会难过；再怎么付出，也不能保证两人一定能走到那一步。
- 累积（中等）：心理变化经常被明确整理成道理或结论，部分已经交代过的前提又被完整解释，连续阅读时有一点反复总结的感觉。｜影响：这些句子并不因为写了“明白”“看清”就有问题。人物不断认识自己的感情，本来就是这条叙述线的核心。但连续读下来，作者有时像是在不断替人物归纳心理规律：关系能否继续不由自己决定；热情换不来保证；开心不等于许诺；期待不等于索取。每个判断都成立，部分判断也确实对应不同的心理阶段，但相近的前提被多次完整讲出，会使人物经历偶尔显得像心理分析的逐项说明。S10刚宣布“已经看清自己到底盼的是什么”，S11接着又用“原来”“终于明白”引出新的认识，也让连续两段的总结感稍强。实际影响不是读不懂，而是有些本来可以直接感受到的变化，被解释得过于周全。｜边界：S03第一次意识到关系不能由自己决定，是重要转折；S05从这个事实走向对自己是否真心的怀疑，也有独立意义；S11区分当初不图回报与现在想要回应，是人物心理真正向前走的一步；S14再次认识付出不能保证结果，则具有收束作用。这些都不应简单删掉。值得精简的是没有带来足够新认识的重复提醒，以及紧邻的两次总结，而不是人物每一次重新面对不确定性。｜建议：保留几个真正改变人物认识的结论，其余位置尽量让当下的念头和感受直接出现。例如，S09第1条可以收紧为：“相处还是很开心，可那个问题又冒出来：对方想不想主动靠近？”前文已经建立了开心不等于许诺的前提，此处不一定需要再次完整解释。S10第3条可改为：“他没有向对方要答案，那份盼望在心里却越来越清楚。”再让S11明确说出他想成为对方特别珍惜的人。这样既保留阶段差别，也减少连续宣布领悟的感觉。

- 累积（轻微）：叙述反复采用“他＋心理活动或态度”的句式，人物称呼又高度依赖“他”和“对方”，使部分段落的语气显得过于齐整。｜影响：这些句子单独看基本自然，而且人物没有名字，反复使用“他”和“对方”有实际作用。但四十多条连续读下来，相当多的句子都从“他想”“他怕”“他知道”“他不想”“他还是”进入，再陈述另一方或两人的关系。这样的表达很清楚，却让句子的节奏和观看人物的角度变化较少。尤其当一句里两次出现“对方”，或者接连几条都在报告他的想法时，阅读感受会略偏向剧情梗概，而不是一个人自然地讲述经历。这是一种轻度的整体单调，不意味着这些句子各自存在语法错误。｜边界：这篇采用匿名第三人称，而且情节几乎全部发生在人物心里，明确使用“他”和“对方”是合理的。涉及谁主动关心、谁给予回应、谁作出选择时，保留称呼尤其必要。条目开头交代人物也是正常写法。真正值得调整的是相邻句子机械地重复同一种起笔方式，以及读者已经知道对象是谁时仍多次明说“对方”。不能为了变化而随意省略到指代不清，也不必强行给人物起名。｜建议：只在部分位置转换句子的起点，让感受、关系状态或已经提到的事情偶尔成为句子的开头。例如，S02第1条可以改为：“两人还是照常相处。他一想到对方，就想多关心一点，也越来越喜欢这样待在一起。”S07第2条可以改为：“心意是想让对方知道的，可他怕说出口像在催回应，只好先把期待放在心里。”这样不需要补造任何场景，也能让长篇条目的语气稍有变化。

### 5.6 第1次：8 分，8 处
- 最主要的问题：整体语言质量较好。完整读下来，人物心理发展的主线清楚，从最初被喜欢吓到、克制自己，到逐渐承认期待回应，再到明确自己真正想要的是共同生活，前后能够接得上；多数句子也保持了平常、克制的口吻，没有明显故作文学化。最影响连续阅读体验的不是某几个病句，而是S03到S10之间围绕“想要回应又怕给对方压力”的矛盾解释得较密，几轮意思非常接近，使中段推进感稍弱。其次是“这样、眼下、照常、还是、亲近、相处、关心”等词承担了大量衔接工作，全文连读时略显同质。局部另有少数搭配或成分不够自然，如“舍不得两人不再这么亲近”“不认相处的开心”“换不来一定能走到那一步”等，但数量不多，也没有破坏整体理解。总体上已经是清楚、可信、基本自然的中文，主要需要的是适度收紧重复解释和修正少数搭配，而不是大幅重写。

  - [S04 第3条]「关心得越多，他就越舍不得两人不再这么亲近」——“舍不得”和“不再这么亲近”直接接在一起有些拧。“舍不得”的对象通常是现有的人、事或状态，这里却直接接一个否定后的未来状态，读者需要转一下才能明白是“舍不得失去这种亲近”。 → 关心得越多，他就越舍不得失去两人现在这种亲近
  - [S05 第3条]「他不想再靠多付出来留住现在这样」——“留住现在这样”搭配不太完整。“现在这样”可以说“保持现在这样”，但放在“留住”后面时，通常还需要一个较明确的对象，如“这种亲近”“这样的关系”或“这样的日子”。 → 他不想再靠多付出来留住现在这种亲近
  - [S06 第1条]「也还是照样关心对方」——“还是”和“照样”都在表示事情没有改变，叠在一起略显赘余，口语里虽然能听懂，但这里读起来有一点拖。 → 也照样关心对方
  - [S07 第4条]「却不再靠热情去勉强留住了」——“留住”在这里缺少明确的宾语，句子收在“留住了”上会有悬空感。前文虽然能让人推知是想留住两人的亲近，但读到句尾仍会觉得少了一个成分。 → 却不再靠热情去勉强维持这种亲近了
  - [S08 第2条]「相处久一点，他慢慢又像起初那样」——“相处久一点”更像比较或条件说法，例如“再相处久一点就会知道”；这里实际想表达的是又经过了一段时间，因此单独放在句首稍显生硬。 → 又相处了一阵，他慢慢又像起初那样
  - [S09 第3条]「他不愿因为没答案就不认相处的开心」——“不认相处的开心”不是很自然的搭配。“认”通常不这样直接支配“开心”；这里实际是说，他不愿因为没有答案，就否定已经有过的开心。 → 他不愿因为没答案，就把相处时的开心也当作不算数
  - [S12 第2条]「顺着这些事，他又想到以后两人一起过日子」——“顺着这些事”比较含混，也不像很自然的日常说法。这里的逻辑其实很清楚：从前一句想到以后要分担的琐事和难处，于是进一步想到共同生活。 → 想着这些琐事和难处，他又想到以后两人一起过日子
  - [S14 第1条]「给得再多，也换不来一定能走到那一步」——“换不来”后面直接接“一定能走到那一步”这样的完整判断，语法关系不够顺。真正能被“换来”的应当是“保证”或“结果”。 → 给得再多，也换不来一定能走到那一步的保证

  - [S04 第1条]「那种生活确实让他高兴，可他也舍不得否认，行动曾帮自己走出了犹豫。」——“舍不得否认”不是很自然的搭配。“舍不得”通常接放弃、丢掉、离开之类的行为，接“否认”显得别扭。后半句“行动曾帮自己走出了犹豫”也比较抽象，像在总结一种心理机制，而不是平常讲自己的经历。这里要表达的是：他珍惜那种生活，但也不愿抹掉以前靠实际行动摆脱犹豫的经历。 → 那种生活确实让他高兴，可他也不愿否认，自己当初确实是靠做事才走出了犹豫。
  - [S04 第3条]「为保住决心，他硬撑着反复追问自己还能怎么做，停不下来也安不下心。」——“保住决心”略显生硬。决心可以维持、守住，也可以说不让自己动摇，但“保住决心”不太像日常口语。整句话的心理状态是清楚的，主要是开头这几个字不够自然。 → 为了不让自己动摇，他硬撑着，一遍遍问自己还能做什么，停不下来，也安不下心。
  - [S06 标题与第1条]「（没在想）……他一心想着真正让自己快乐过的生活」——标题写“没在想”，紧接着却说“一心想着”，普通读者容易先感到表面上的矛盾。结合后文可以理解，这里的“没在想”应该是不再盘算、不再追问理由，而不是脑中没有任何念头。把“一心想着”换成强调回味或沉浸的说法，能更准确地传达这种区别。 → 他只顾回味那种真正让自己快乐过的生活，让喜欢和依恋留在心里，不急着替它们找理由。
  - [S11 第1条]「只是没顾上所有牵挂」——“顾上”通常接具体的人、事或者某方面的需要。“牵挂”本身是心理上的惦念，直接说“顾上牵挂”不够顺口。读者需要把它理解成“顾上自己牵挂的人或事”。 → 只是还有一些牵挂的事没顾上
  - [S11 第3条]「真要因害怕就停下，在乎的一切照样可能受损，他决定继续承担。」——“因害怕”偏书面，放在这段比较口语化的叙述里显得突兀。另外，“他决定继续承担”收得有点悬空：承担什么？虽然前一条提过“能承担什么”，读者能够补出意思，但单独读到这里，还是会觉得少了一个落点。 → 可要是因为害怕就停下，自己在乎的东西照样可能受损。他还是决定担起自己能担的那一份。
  - [S12 第1条]「不等完全不怕了，就先做眼下能做的事。」——“不等完全不怕了”连续叠加否定，意思虽然明确，但读起来稍微绕口。日常说话通常会改成“不用等到一点都不怕”或“不必等到不害怕了”。 → 不用等到一点都不怕，他就先做眼下能做的事。
- 累积（中等）：重要的牵挂和目标反复用宽泛的称呼代指，读到后面，不同对象之间的界限逐渐模糊。｜影响：这些表达单独看大多自然，含蓄本身也不是问题。连续阅读时，困难在于它们之间的关系不够稳定。开头能看出，他想保护一些珍惜的东西，又怕因此放下另一些牵挂。后来出现了向往的生活、亲近与信任、心里的安宁，以及需要保护的东西。这些概念显然有关，却不完全相同。随着“珍爱的东西”“在乎的一切”“那种生活”等说法反复交替，读者有时需要重新判断：他现在怕失去的，是原本想保护的东西，是另一份牵挂，还是亲近、信任的生活本身？尤其到后半段，同样的“受损”“守住”“留住”不断接到不同的对象上，心理冲突的具体方向便不如开头鲜明。这不至于让整篇读不懂，但会削弱情感的落点。｜边界：并不是所有泛称都应修改。S01 的“别的珍贵东西”用“别的”明确指出另一组牵挂，是有效的；S09 的“那种能相信别人、跟人亲近的生活”也很好，因为它把之前的向往重新说清楚了。反复说“那种生活”有助于维持主题，完全没有必要每次重新解释。真正需要注意的是：当叙述在不同的牵挂、生活理想和行动目标之间转换时，不能始终只靠宽泛而相近的称呼，让读者自行辨别。不需要添加具体人物、事件或场景，只需要使已有的几个心理对象更容易区分。｜建议：建议保留几个相对稳定的说法，分别指向他想保护的东西、暂时没顾上的牵挂，以及他向往的亲近生活。在发生转换或重新作出选择的地方，适度补明所指，不必每条都解释。例如，S11 第1条可以改成：“之前尽力做事让他找回了力量，可还有些牵挂的事没顾上；而只守着心里的安宁，也护不住原本想守住的东西。”S13 第4条可以改成：“他尽了眼下能尽的力，心里仍爱着那种能信任人、跟人亲近的生活，只是不知道，自己一直想守住的那些东西，最后能留住多少。”这样仍然含蓄，但“向往的生活”和“想守住的东西”不容易混成一个概念。

- 累积（中等）：人物的犹豫与选择经常被完整地解释成一套心理推论，后半段又多次重新论证同一组矛盾，使叙述渐渐带上反复总结心理的口吻。｜影响：整篇有一条清楚的心理主线：不行动怕失去珍爱的东西，行动又怕伤到其他牵挂；安宁值得珍惜，却不能代替实际争取。这组矛盾本身是有力量的，而且人物确实在发生变化。问题主要出现在反复解释的密度上。S07 已经说了不能只留在回忆里，却不敢重新投入；S09 再次写拿不定主意；S10 重新指出片刻满足不代表守住生活；S11 用不行动也会受损来支持继续承担；S12 又回到争取可能伤害所爱；S13 再一次用安宁护不住生活来说明为什么要争取。这些段落各自都有新的心理细节，不能简单判作内容重复。但连续读下来，人物仿佛不断把自己已经想过的道理重新解释一遍，新变化反而被反复的论证包住了。同时，“歇下不等于反悔”“承认失望等于变心”“歇一歇不算放弃”等判断不断出现，容易让叙述听起来像事后整理出的心理分析，而不是一个人比较自然地讲述自己怎样反复挣扎、慢慢改变。实际影响是节奏稍显拖沓，情绪的直接感受到了一定削弱。｜边界：这里不能把心理反复本身当作毛病。人物经历的是难以两全的选择，重新迟疑十分合理，也可能正符合音乐的回旋发展。S03 的“歇下不觉得就是反悔”是一次重要松动；S05 的“承认失望等于变心”揭示了他为什么逼迫自己；S09 明确意识到舍不得亲近的生活；S11 决定继续承担；S13 学会努力之后也肯歇下，这些都是实质性的心理变化，应该保留。需要精简的不是这些变化，而是已经交代过的理由再次被完整说出、却没有带来多少新认识的地方。相同的心理矛盾可以反复出现，但不必每次都重新证明它为什么成立。｜建议：后半段可以更明确地分配叙述重点：S07 重在不敢重新投入，S09 重在认清自己的不舍，S10 重在暂时允许自己安宁，S11 重在决定承担，S12 重在带着害怕恢复行动，S13 重在学会有分寸地付出。每段保留真正新增的心理变化，适当省去已经充分说明的理由。例如，S10 第3条可改成：“接下来怎么过，他还不知道。他想先歇一歇，也不急着推开这份安宁。”前文已经建立休息不等于放弃，这里不必再次说明。S13 第1条可改成：“他还是担心争取会伤到所爱，可心里想为那种生活做点事的念头又起来了。”这样保留害怕与愿意行动并存的状态，把已经多次解释的“安宁也护不住它”留给前文，让后续实际投入和懂得歇息的变化更突出。

### 5.6 第1次：7.5 分，5 处
- 最主要的问题：整篇连续读下来是通的，心理发展的主线也能跟住：从不敢开始，到投入后的畅快与自我逼迫，再到承认对亲近生活的留恋，最后尝试在争取与保留温柔之间重新找到做法。多数句子本身自然，真正需要单独修改的局部并不多。最影响阅读体验的不是明显语病，而是全文较高程度的抽象化：几个不同的牵挂和目标经常换用近义的宽泛代称，再加上大量完整写出的心理转折、因果和自我判断，使连续阅读时偶尔像在看一份整理得很细的心理过程说明，而不是一个人在平平常常地讲自己的经历。其次才是少数搭配或省略造成的局部生硬。另一方面，“那种生活”“不用防备”“争取与安宁之间的拉扯”等反复出现，大体都有前后推进，并不是因为出现次数多就构成毛病；不宜为了减少重复而机械换词或删掉。
- 一再出现：不同心理对象反复换用“珍爱的东西、珍贵的东西、牵挂、在乎的一切、所爱”等宽泛近义称呼，偶尔造成指代边界不稳；多处句子连续交代感受、反面顾虑、推论和决定，累积后使叙述偏向心理分析式的推演语气
  - [S04 第1条]「那种生活确实让他高兴，可他也舍不得否认，行动曾帮自己走出了犹豫。」——“舍不得否认”这个搭配有些拧。“舍不得”通常指不忍放弃、离开或做某件会造成失去的事，直接接“否认”虽然能猜到意思，却不像平常说话。后面的“行动曾帮自己走出了犹豫”意思清楚，但和前面的特殊搭配连在一起，整句显得稍微刻意。 → 那种生活确实让他高兴，可他也不愿否认，行动确实曾帮他走出了犹豫。
  - [S05 第1条]「他怕只要承认失望，就等于变了心，明知光靠行动不够，也不准自己停下。」——“怕只要……就……”叠了两层条件关系，读到“怕只要”时会略微卡一下。这里实际表达的是“一承认失望，就会被自己理解成变心”，用“一……就……”更顺。 → 他怕一承认失望，就等于变了心，明知光靠行动不够，也不准自己停下。
  - [S05 第3条]「等他不再这么催自己，才肯承认，自己一直舍不得那种不用防备的亲近。」——“等他……，才……”容易让人先按“等他做完某事，另一个人才……”来解析，因为前半句已经明说了“他”，后半句却把同一个主语省掉了。实际意思能看懂，但句法上会让人短暂停顿。 → 等到不再这么催自己，他才肯承认，自己一直舍不得那种不用防备的亲近。
  - [S06 第4条]「他不管这份向往有没有用，只想好好爱惜它，连压着的委屈和想念也不急着放下，舍不得出来。」——句末“舍不得出来”缺少明确的出处。由于紧挨着“委屈和想念”，第一眼甚至可能误读成“委屈和想念舍不得出来”；即使知道主语仍是“他”，也要回头判断他究竟是舍不得从什么里面出来。 → 他不管这份向往有没有用，只想好好爱惜它，连压着的委屈和想念也不急着放下，也舍不得从这份感觉里出来。
