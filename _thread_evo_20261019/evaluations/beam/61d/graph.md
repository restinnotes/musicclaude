# Op.61｜关系图（逐段综合 61d）

**Center：**对珍爱之物的旧日亲近与眼下疏远，始终牵动着失去的不甘、重获亲近的渴望和清醒的孤单。

### 1–23　（没在想）

- 他心里一阵慌乱，却不知怕什么，连此刻的感受也说不清。

### 24–65　（正在面对）

- 那阵慌意渐渐变成怅惘：他隐约觉得，自己和最在意的东西疏远了。
  - ← 改写：（1–23）「无由的慌乱」

### 66–91　（正在面对）

- 疏远已让他尝到失落，心里随之生出不甘与抗拒。
  - ← 改写：（24–65）「在意之物带来的失落」

### 92–115　（正在面对）

- 往日的亲近让他稍感宽慰，也让他再次觉得它珍贵。
  - ← 唤起：（24–65）「在意之物带来的失落」
- → 可那份亲近越显珍贵，眼下的疏远越叫他难受。
  - ← 提供理由：（24–65）「在意之物带来的失落」
- → 他更急着挡住失去，抵抗已显疲惫而仓促。
  - ← 改写：（66–91）「不甘与抗拒」

### 116–147　（正在面对）

- 不甘失去仍推着他反抗，可持续抵挡已让他疲惫，紧绷才短暂松开。
  - ← 提供理由：（92–115）「珍惜刺痛」
  - ← 改写：（92–115）「急切抵抗」

### 148–180　（正在面对）

- 抗拒稍歇，曾有的亲近又让他盼着再次贴近珍爱之物。
  - ← 改写：（66–91）「不甘与抗拒」
  - ← 提供理由：（92–115）「珍惜刺痛」
  - ← 提供理由：（116–147）「疲惫的抗拒」

### 181–205　（正在面对）

- 那段亲近越显真切，他就越想靠近；眼前的疏离也更叫他难熬，盼望愈发迫切。
  - ← 唤起：（92–115）「旧日慰藉」
  - ← 提供理由：（92–115）「珍惜刺痛」
  - ← 改写：（148–180）「柔软的盼望」

### 206–213　（正在面对）

- 旧时的温柔仍让他心软；如今盼望已急，因而更难割舍。
  - ← 唤起：（92–115）「旧日慰藉」
  - ← 提供理由：（92–115）「珍惜刺痛」
  - ← 提供理由：（181–205）「盼望变得急切」

### 214–215　（正在面对）

- 心里又慌得没底：他已知道自己想把亲近找回来，此刻的疏离仍叫他难安。
  - ← 唤起：（1–23）「无由的慌乱」
  - ← 提供理由：（181–205）「盼望变得急切」
  - ← 改写：（206–213）「温柔里的不舍」

### 216–225　（正在面对）

- 他已明白自己盼着重获亲近，疏远仍令他茫然；慌乱中还混着急切盼望后的倦意。
  - ← 唤起：（1–23）「无由的慌乱」
  - ← 提供理由：（116–147）「疲惫的抗拒」
  - ← 改写：（214–215）「知道所求仍无着落」

### 226–241　（正在面对）

- 心慌与倦意仍在，恢复亲近的念头却开始化为主动靠近的决心。
  - ← 改写：（148–180）「柔软的盼望」
  - ← 提供理由：（181–205）「盼望变得急切」
  - ← 限制：（216–225）「盼望后的无着」

### 242–253　（正在面对）

- 失去的不甘又化成一股坚定的劲，他开始自己决定该往哪走。
  - ← 提供理由：（66–91）「不甘与抗拒」
  - ← 改写：（92–115）「急切抵抗」
  - ← 改写：（226–241）「盼望转成意志」
- → 慌乱与倦意仍在，这股力量也带着先前消耗留下的沉重。
  - ← 提供理由：（116–147）「疲惫的抗拒」
  - ← 限制：（216–225）「盼望后的无着」

### 254–288　（正在面对）

  - ← 提供理由：（216–225）「盼望后的无着」
  - ← 改写：（242–253）「不甘化为挺立」
  - ← 限制：（242–253）「带着消耗站稳」
