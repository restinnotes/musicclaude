你要为一首器乐作品写出最终使用的 Thread（线）。

Thread 是同一个人在整首作品里经历的一件事。

遮住珠子，只读 Thread，读者应能看见一个人具体牵挂什么、为什么难以两全、此前经历怎样影响后来，以及最后实际走到了什么地方。

同时，每段应自然接住 TARGETS 提供的多种体验性质。

【段落】
{SECTIONS}

【Center】
{CENTER}

Center 是整件经历的中心，不是人物必须逐段解答的问题，也不要求结尾解决。

【人物经历候选】
{ROUTES}

【体验性质 TARGETS】
{TARGETS}

TARGETS 来自珠子，但你看不到原始珠子。它们提供体验性质，不提供故事事实。

【本次写作任务】

从候选中选一条能够独立成立的人物经历，把它一次写成完整的逐段要点。

写的是一个人持续经历同一件有切身利害的事，而不是逐段描述他的心情，也不是讲他如何不断调整自己的心理办法。

这件事应有具体可懂的所求、顾虑、珍惜、代价或尚未解决的取舍。它们在后面要继续产生作用，而不是开头交代完就退化成笼统情绪。

ROUTES 提供处境、已成立内容和发展依据；TARGETS 帮助呈现各段体验的轻重、方向和并存关系。

任何一方都不能成为补造外部事实的理由。

一次写出完整的线，不逐段分别生成，也不在写成后另外改写。

以下工作在内部完成，最终只输出 JSON。

## 一、选取有真实利害与发展的路线

从 ROUTES 选择一个 base_route，全篇只用这一条。

选择时先遮住 TARGETS，连读路线的 situation 和 state。

优先检查：

- 人物真正想要什么、顾虑什么，为什么这件事不能轻易两全；
- 这些所求和顾虑在后面是否有具体作用，而不是逐渐消失；
- 前面已经经历的东西，是否让后面的愿望、担心、犹豫、选择或理解变得不同；
- 中间阶段是否具有真实作用，而不是可以互换的情绪描述；
- 关键变化是否有依据，有没有依赖无来源的事件、他人反应或现实结果；
- 是否避免把自我管理和反复评估办法当作主要故事发动机。

再考虑 TARGETS 的不同体验性质能否在这条已有经历中自然成立。

不要因为某条路线情绪种类多、容易匹配 TARGETS，就优先选择它；也不要因为某条路线有更多转折，就认定它更好。

保留所选路线的基本处境、真实依据、具体利害和主要发展方向。

路线不是需要逐段照抄的剧本，但不能把它最重要的所求、顾虑和发展关系删去，只保留总体情绪。

如果某个关键判断缺少根据，不能通过补造事实把它变真；优先选择其他成立的路线。

## 二、先确定整件事的内在连续性

在写各段正文前，先把人物整段经历连起来想。

读者应当能理解：

- 他起初身处什么处境，具体想要或保留什么；
- 他为什么有所顾虑，或者面临什么不能轻易兼得的东西；
- 前面的亲身体验、愿望和选择如何留在后面；
- 到了后来，他所想要、害怕、舍不得或愿意承担的东西发生了什么真正的变化；
- 结尾承接了什么，留下了什么，而不是重说什么。

让后面的心理经历由前面已经存在的内容自然产生。

人物可以有新的念头、愿望、犹豫、理解和内心选择。它们不必由新的外部事件来证明，但必须具有可理解的前因。

重要变化不是必须解决问题，也不必比前一段更坚定。

同一愿望可以持续存在，同一种顾虑可以再次出现；但如果它们在后面仍是完全相同的意思，就不要重新包装成新进展。

一个真正有发展的阶段，应当使读者读到后面时，更清楚人物为什么走到这里。

不要为了维持前进感，让人物反复提出办法、实行、检查效果和改变办法。选择若发生，应当来自他面对的真实利害，而不是为了给每段安排一次心理动作。

## 三、事实与人物内心必须分开

严格区分：

- 输入中已经确立的客观处境；
- 人物在其中实际产生的感受、愿望、认识、犹豫和决定；
- 他对尚未发生之事的期待、想象与担忧；
- 真正已经发生且有输入依据的行动和现实结果。

不新增未经输入建立的事件、前史、他人反应、物件、对白或外部场景。

不能把人物期待的变化写成已经发生，也不能把决定写成已经实行并取得结果。

不得通过含糊措辞暗示某件尚无依据的事情已经做完、经过验证或积累成经验。

新的内心认识必须由已有经历支持；即使说得很自然，也不能凭空建立会支撑后文的关键前提。

人物可以改变准备怎样面对某件事，却不能因为改变了心意，就认定现实已经配合改变。

如果某个发展必须依赖未经建立的事实，那不是可以靠换词解决的措辞问题；应当回到已有处境，选择另一种真正有依据的心理发展。

不能为了让后半篇丰富而编造新的事实，同样不能因为没有外部新事实，就把后半篇全部削成抽象情绪。

## 四、让不同段落具有各自的实际内容

把整条线当成一个人从头到尾在经历的事，再按输入分段。

每段写人物此刻真实在意、正在经历或暂时顾不上什么。

相邻阶段不必都有重大转折，但它们应当自然相接。前面内容已经成立，就直接使用；不要重新交代或宣布第一次明白。

不同阶段可以分别呈现：

- 既有所求和顾虑在此刻产生的不同影响；
- 前面经历留下的后果；
- 原有愿望或担忧在新的内心处境下具有的不同意义；
- 人物在一个尚未解决的取舍中实际产生的念头或选择；
- 暂时沉浸、安静、松开注意力，或没有继续考虑整件事的时刻。

这些只是可能存在的经历，不是需要按顺序套用的步骤。

如果一段没有新的事实或认识，不必制造转折；但不能把一句已经说清的感受展开成几次同义反复。

写到后半篇时，检查具体所求与顾虑是否仍然存在于因果关系中。它们可以改变，也可以被新的关切取代，但不能无缘无故只剩关于情绪本身的描述。

不要让情绪强度、安静与激动的交替承担整个故事的发展。

不要因为结尾需要收住，就重新确认人物早已明确的愿望或态度。结尾可以有选择，也可以没有；应当停在实际有根据的地方。

## 五、让 TARGETS 参与体验呈现，但不接管经历

写正文时同时考虑各段 TARGETS 的 qualities、temporal_shape、compatible_bundle 和 tensions。

TARGETS 告诉你这一段的体验可能具有怎样的性质，而不是要求人物在此刻发生什么事件、认识或决定。

先确保这一段在人物自己的经历中有位置，再让 TARGETS 影响他如何亲身感到这件事。

同段可以有几种同时成立或相互牵制的感受。它们应当来自已有处境，不必给每颗珠子安排独立事件或心理转折。

如果 TARGETS 存在段内变化，可以让人物已有的不同感受在注意力中有先后，也可以呈现此前经历在这一刻留下的不同影响；但不能把体验变化直接转换成新事实。

TARGETS 可以影响情绪轻重、感受亲近或疏离的程度、注意力的所在，以及不同感受怎样并存。

TARGETS 不能决定人物新增了什么关键经历、对方作出了什么反应、某项行动已经完成，或未来已经得到了什么保证。

不要搬用 TARGETS 中的比喻、场景、拟人化情节或想象动作，也不要把其中的心理过程当成已经发生的人物事实。

尽量让每颗珠子的体验性质在同一段找到情境相近的内容；相关即可，不需要逐颗解释。

同一段的不同听感无需压成一种。

如果一种体验只能靠增添未经支持的事实、破坏人物的主要取舍或改变已有经历才能覆盖，就在 uncovered_targets 如实记录。

不要为了覆盖数量牺牲人物经历的独立真实性。

## 六、一次写出连贯、简洁的人话

采用第三人称分段要点，写成可以直接使用的最终文案。

正文要像一个人在平常地讲自己经历的事，而不是心理分析、抽象情绪记录或哲理总结。

直接写人物具体想要什么、顾虑什么、舍不得什么，以及这些东西为什么在此刻牵动他。

不要用抽象名称替代有实际对象的所求与顾虑，也不要每次都替人物解释一套心理机制。

让前后因果自然显出，不必不断使用解释性连接词。

形态要求：

- 严格按输入段落顺序。
- 每段 2–4 条要点。
- 每条恰好一句完整、自然的话，只说一个主要意思。
- 连起来读仍是一段流畅的经历。
- 内容较少的段落用两条即可，不为了凑数制造心理变化。
- 不把一个意思拆成几条重说，也不把几件事塞进散文式长句。
- 前面已成立的内容直接承接，不重复宣布旧认识或旧决定。
- 有根据的犹豫、反复和持续感受可以存在，不为了显得一直前进而删去它们。
- 不写心理分析术语、格言式总结、刻意对称句或不必要的限定与否定。
- 不强行口语化，不加无关细节，不把人物真实的复杂处境削成简单态度。

每条要点都应有自己的用处。它可以推进经历，也可以交代必要的当前处境、心理后果、悬而未决之处或一次自然停留。

## 七、正文完成后再填写元数据

元数据必须以已经写出的正文为准。不能为了填写字段而增添正文内容。

### cite

某条明确回指或直接依赖更早的要点时，填写相应 id。

只引用真正提供依据的前因，不因为主题相似而引用。不必每条都有 cite，不标关系类型。

### covers

填写该要点确实能够接住的 bead_id。

一条可以覆盖多颗，同一颗也可以由同段多条共同承接。只在体验性质相近时填写，不虚标覆盖。

### relation

按该段正文实际内容选择：

- 没在想：当下注意力完全在别的具体体验或处境上，没有打量或挂念整件事。
- 还说不清：人物已有相关感受或反应，但此刻尚未形成明确理解或态度。
- 正在面对：人物清楚意识到整件事，正在具体考虑、承受、权衡或作出选择。

标签以正文为准，不因 Center 存在而默认正在面对。

### delta_type 与 delta

选择：新变化 / 后果 / 实行已有想法 / 延续 / 回到旧处但有新增 / 暂时没在想。

delta 只记录正文中确实新增且有根据的内容，没有则为空字符串。

不要为得到新变化标签而把持续感受写成新认识，也不要把尚未实行的想法写成实行结果。

### established

只记录正文中确实首次成立的重要事实、认识、愿望或选择，标明首次出现的要点 id。

保持确定程度，不记录只存在于构思中、正文无法支持的内容。再次出现的同一内容不重复记录。

### uncovered_targets

记录在已有经历中确实无法自然容纳，强行覆盖会要求新增无依据事实或破坏人物逻辑的体验性质。

先充分考虑同一处境的不同侧面，不轻易放弃，也不虚构覆盖。

## 八、最终通读

第一遍完全遮住 TARGETS 和元数据，只读正文。

检查：

- 是否能读成一个人持续经历的一件事？
- 他的具体所求、顾虑和不能轻易两全之处，是否贯穿并影响后面的内容？
- 前面的经历是否真实改变了后面在意的事、面对的取舍、内心态度或选择？
- 如果删去中间多个阶段，后半篇是否仍几乎原样成立？如果是，检查是否只有情绪连续、缺少经历发展。
- 有没有把抽象感受的增强、减弱和重返冒充为发展？
- 有没有反复重新完成同一心理动作、同一认识或同一决定？
- 有没有依赖无来源的外部事件、他人反应、已完成行动或现实结果？
- 有没有把猜测升级为事实，把决定升级为结果？
- 有没有把人物面对的真实利害缩成反复调整心理办法的程序？
- 结尾是否承接实际发展，而不是再次宣告早已明确的心意？
- 是否像普通人能讲出来的话，而不是心理提纲？

第二遍再看 TARGETS 和元数据。

检查：

- 各段多种体验性质是否大体有着落？
- 有没有为了覆盖而翻译体验、编造情节或改变人物经历？
- relation 是否符合正文？
- cite、covers、delta、established 是否都有实际依据？
- 每段是否有 2–4 条，每条是否恰好一句？
- 编号、顺序、字段及 JSON 结构是否正确？

发现问题时，在本次成篇过程中确保正文成立，不另起一次事后改写步骤。

若发生冲突，首先保证人物经历的独立真实性与具体发展，再尽量覆盖 TARGETS。不能通过新增事实来填补缺口，也不能用抽象重复来掩盖缺口。

【输出格式】

只输出 JSON，保持以下结构，不增删字段：

{
  "base_route": "route_id",
  "segments": [
    {
      "sec": "S01",
      "relation": "没在想/还说不清/正在面对",
      "items": [
        {
          "id": "S01-1",
          "text": "...",
          "cite": [],
          "covers": ["bead_id"]
        }
      ],
      "delta_type": "新变化/后果/实行已有想法/延续/回到旧处但有新增/暂时没在想",
      "delta": "本段确实新增的内容，无则留空"
    }
  ],
  "uncovered_targets": [
    {
      "bead_id": "...",
      "reason": "不能自然覆盖的原因"
    }
  ],
  "established": [
    {
      "claim": "首次成立的重要事实、认识、愿望或选择",
      "first_established": "Sxx-x"
    }
  ]
}
