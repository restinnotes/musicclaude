你是一位独立评审。附件里有 8 篇匿名文章（文章A、文章B、文章C、文章D、文章E、文章F、文章G、文章H），都是为 Frédéric Chopin, Barcarolle in F-sharp major, Op. 60 写的同一条「线」的不同版本，按同样的段落分段。另有一份参考材料「原文.md」：这条线最初的完整版本。各篇中可能有的就是原文本身，也可能是改写或压缩过的版本。

## 这条线是做什么的

它沿着既定段落，讲一件属于人的、难以安顿的事怎样一步一步发生：每一段的感受，由前面已经发生在这个人身上的经历、已经成立的认识推出来；读者读完每段，能说出“为什么此刻是这样”。它最后会和另一份“当下体验”的记录穿插起来，做成讲解视频的旁白，所以它不必自己描写音乐或体验。

## 评什么

1. **不损失内容（最重要）**：对照「原文.md」，原文里每一步因果——前面得到了什么、相信了什么、发现了什么，所以此刻怎样——是否都还在？逐条列出丢掉或被说错的步骤。只是删掉重复、铺陈和泛泛的话，不算损失。
2. **人话**：是否像一个人在把事情讲清楚，读者一遍能跟上？抽象名词堆叠、绕来绕去的长句、同一个意思反复换说法，都要扣分。
3. **自己推动自己**：每段的转折是否由前面的经历推出，而不是“此时音乐忽然……于是……”，也不是各段各说各的。
4. **具体（同样重要）**：读完每一句，读者能否说出这个人此刻具体在想什么、怕什么、想要什么、在做什么？“站稳、安顿、承受、归属、边界、限度、代价、空缺、回应、姿态、位置”这类词堆起来的句子，听着有意思，其实说不出内容，要明显扣分；把这类词换成同义的抽象说法不算具体。具体也不等于另编情节：不需要新的人物、事件、物件。
5. **鲜活**：读者能否感到这件事正在一个人身上发生，而不只是被告知。

**不要因为这些扣分**：篇幅长短本身；语气戏剧化、笃定；解释和说理本身；不写音乐。

## 输出

先对每篇写几句读后（要写出丢掉了原文的哪些步骤），最后给一个 ```json 代码块：

```json
{
 "ranking": ["文章X", "..."],
 "articles": {
  "文章A": {
   "fidelity": 1,
   "lost_steps": ["S03: 简述丢掉的那一步"],
   "plain": 1,
   "concrete": 1,
   "self_driven": 1,
   "segment_drivers": ["内", "乐", "无"],
   "alive": 1,
   "overall": 1,
   "verdict": "一句话"
  }
 }
}
```

- fidelity、plain、concrete、self_driven、alive、overall：1–10 分。
- segment_drivers：按段落顺序，每段一个“内”“乐”或“无”，个数等于段数（14）。
- overall：这条线作为旁白的“线”好不好。丢掉关键因果步骤、抽象空洞说不出具体内容、读不懂、转折靠音乐，都应明显拉低 overall。
- ranking 必须包含全部 8 篇，从最好到最差，不许并列。
