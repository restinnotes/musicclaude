请阅读下面这段中文。

它是一条跟随音乐发展的“线”：写的是一个人在这首曲子里经历的一件事，按段写成条目。〔〕表示这句话提到的前文出处。这段文字会和音乐听感记录一起给读者看，希望读起来像一个人在平平常常地讲自己的经历。允许含蓄，不要求补造具体人物、事件或场景。

请作为第一次读到它的普通中文读者，独立评审它的语言质量。你不知道作者此前修改过什么，也不要预先假定它有哪些毛病。

评审分成三个步骤：

第一步：连续阅读整篇。

先从头到尾阅读，把它当作一段完整的叙述，而不是一组需要逐句批改的句子。

注意实际的阅读体验：哪些地方自然流畅，哪些地方读着费劲，整篇读完后有没有留下明显的不舒服、不顺畅或者单调的感觉。

此时先不要着急改写句子，也不要预设问题类别。

第二步：检查局部语言。

逐处指出真正读起来不通顺、不像人话、让人别扭或需要停下来想一想的表达。

每处引用原文，说明为什么不自然，并给一个更自然的说法。

只指出实际存在的问题。没有问题的地方不用提，不要为了凑数挑毛病。

改写时尽量保留原句的意思、人物的心理区别和前后关系，不要为了让句子好听而擅自改变人物经历。

第三步：独立检查整篇的累积效果。

这一步很重要。请暂时放下第二步挑出的具体问题，重新从头到尾看整篇。

检查是否存在这样的情况：某一种写法单独出现时并没有明显错误，甚至完全自然，但在多处反复出现之后，让整篇的阅读体验变差。

不要只寻找单句中的错误，也不要只把第二步的问题重新归纳一遍。要真正检查连续阅读时产生的效果。

对于发现的每一种累积性问题：

1. 引用多处原文作为证据。如果问题跨越全文，尽量选取不同段落的例子；如果问题集中在同一小节，可以引用几句相邻的原文。
2. 解释为什么这些表达连起来会造成问题。不能仅仅因为某种写法出现次数多，就认定它不好。
3. 区分这种写法在哪些情况下本来是自然、必要或有效的，哪些地方才是真正多余或影响阅读的。不要把所有相似表达一律判错。
4. 说明这种累积问题的实际影响有多大，是轻微、中等还是严重。
5. 如果值得修改，提出具体的改进方向，并选择一两个代表性位置示范改写。不必机械地修改所有同类表达。

不要预设必须找到多少种累积性问题。某一种写法反复出现也可能完全合理，甚至是叙述所需要的。如果没有充分证据，就不要把它列为问题。

最后作出整体判断。

给语言质量打 1–10 分。

说清楚最影响阅读体验的是什么，哪些是次要问题。不要因为某类问题比较容易统计、比较容易举例，就高估它的重要性。

请特别注意：局部语言问题与全文累积问题是两种不同的判断。前者需要证明那句话本身不自然；后者需要证明多处表达连起来产生了不理想的效果。一种表达即使单独没有问题，也可以成为累积问题的证据，但必须讲清楚累积影响。

感受：脚下像突然失重，整个人悬在半空。 / 连方向也分不清，身体一时找不到着落。 / 心里又响起那句：我究竟要怎样继续生活？ / 这次的迟疑不是刚开始的茫然，而是历经许多后的疲惫。
话：翻来覆去还是没答案，他连眼下的日子都过不踏实。
感受：像知道一段往事很重要，却累得没力气再讲一遍。

### S11（屏幕停留 22 秒）
话：他还是会想回去：明知未必找得回亲近，却忍不住想，万一呢？
感受：低处像波涛滚来，沉重的声音一次次砸下。 / 每次爆发都没消掉压力，像被困住还得再顶一次。
话：可再心动，他也不愿只凭这点盼头回去继续忍让。
话：他决定先把眼下的日子过稳，回不回去以后再定。
感受：一开始还在探路，像不知道脚下有没有路。 / 步子终于聚拢，往前的力量越来越不可回避。 / 之前那些轻声祈求，这回像终于变成迈步的意志。
话：他还是怕一个人扛不住，却不想因害怕就收回打算。
感受：不是不害怕了，而是脚已经往前走。 / 问题还没解决，困在原地的感觉却松开一点。

### S12（屏幕停留 25 秒）
话：他终于肯把两件事都记着：当初受的气，确实不该忍。
话：可和那些人在一起时的快乐，也是真的有过。
感受：这次挺直背脊，是明知受过伤也要自己作出的选择。 / 会犹疑、会想念，也不必假装从没受过伤。 / 熟悉的步子猛地落稳，响声像一下铺满眼前。 / 像终于能面向外面大声说，不再只是心里暗暗坚持。 / 这股昂扬甚至像许多人一同往前。
话：他还会心软、怕往后独自熬，但不再怪自己当初离开。
话：他不想只为有人陪就回头，愿意带着想念继续过。
感受：脚下像突然斜了一下，晃过之后却还是继续走。

### S13（屏幕停留 62 秒）
话：再想起那些自然而亲近的日子，他心里又热了起来。
话：他还盼着将来某一天，能跟人那样自然亲近地相处。
感受：原来像私下安慰的歌，忽然唱到了宽阔明亮的地方。 / 声音大得像管风琴，带着宽广庄严的分量。 / 密密的声音像激流往天上喷涌。 / 心脏仿佛被推到极限，跳得快要承受不住。 / 可那一点柔软的心事，没有被大声响压下去。 / 那份昂扬里，也像有故乡、共同记忆和盼望。
话：这么想着，他真有了劲，想把往后的日子好好过起来。
话：这股劲也让他不想再整天跟从前那些事较劲。
感受：明亮的声音飞快冲出去，像积攒的劲终于释放。 / 整个人像被一股气流推着跑，兴奋得来不及喘息。
话：等劲头稍缓，他想到以后还会孤单，也不知何时再有人亲近。
感受：热闹收住后，一点细细的颤动又回来了。 / 心里仿佛被轻问：刚才的成功真的站稳了吗？ / 也像终于可以从容喘气，平静里却仍留着一点疑问。
话：心慢慢静下来，他想：若再有人把他当自己人，一定珍惜。
感受：喧闹像潮水退去，四周忽然静了。 / 低处响起两声轻轻的和弦，像吐出最后一口气。 / 最高处突然亮起一声，透明得像一颗孤悬的寒星。 / 低处的耳语与极高处的亮光，竟相隔那么远。 / 声音不必再更猛烈，也能把最后的话说完。 / 那声高音也像一个终于落定的决定。 / 换一种听法，却像一个人猛然从梦中醒来。
话：即使一直没人再亲近，他也愿意好好过，不再为留住谁咽下委屈。
