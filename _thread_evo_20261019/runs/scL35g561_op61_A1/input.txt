你要为一首器乐作品设计 Thread 的人的经历骨架。

Thread 是同一个人在整首作品里经历的一件事。这一层负责确定这件事从哪里开始、怎样向前发展、最后停在哪里。

【输入】

段落顺序：S01：第 1–23 小节

S12：第 242–253 小节
S13：第 254–288 小节
Center：维持尊严的行动与对旧日生活及归属的怀念反复拉扯

这一层完全不看珠子，不看任何听感记录。
不写音乐、声音、旋律、节奏、和声、小节里的事件。
Center 已经给定，不得修改。它是整件经历始终存在的核心处境，不是每个段落都要重新讨论的问题，也不预先规定人物必须在两极之间来回摆动。
可以利用你对这首钢琴曲整体走向的理解，判断经历的起点、真正的转折位置和结尾的性质，但输出只写人的经历。

【第一步：先写完整的经历弧】
在内部先构思一条完整、连贯的经历，不要按音乐段落逐段发明心理状态。

先回答：
1. 人物一开始实际处在什么处境中？
2. 这件事真正改变过他什么？
3. 哪些认识、选择或事实确实只在某个时刻首次成立？
4. 这些变化分别有什么已经发生的前因？
5. 最后人物处在什么位置？他对这件事的承担方式发生了什么变化？

经历必须有方向。方向不等于人物必须越来越积极、越来越消极或最终解决问题。方向是指人物已经走过的认识和选择不会在后面被重新当成尚未发生的事。

Center 的两极可以从头到尾同时存在。人物可以始终感受到两方面的力量，但不能因此每隔一段就重新作出同一个判断。需要区分：两种感受仍然存在，与人物重新开始解决同一个问题，是两回事。

整条经历只保留真正必要的心理变化节点。节点必须满足至少一个条件：
- 人物获得了此前没有的新认识，而且有实际经历作为依据；
- 人物作出了此前没有作出的选择；
- 已经发生的事情产生了此前尚未呈现的实际后果；
- 人物对一件已经知道的事，开始采取一种真正不同的承担方式。

单纯情绪变强、同一个问题换一种问法、同一个决定重新宣布，都不是节点。

每个节点必须有自己的前因，并改变后面人物能够知道、能够选择或实际承受的东西。节点成立以后，后面的经历必须承受它的结果，不能把人物退回到节点成立以前的心理位置。

没有新节点的时间不需要制造心理变化。可以只是继续经历、沉浸、感受某种身体状态、承受先前决定的后果，或暂时没有在想这件事。

不要为了让整条弧线显得完整而增加成长、顿悟、决心、原谅、释怀或人生结论。结尾可以仍然有未解决的部分，但人物不能无缘无故回到起点。

S12：第 242–253 小节
S13：第 254–288 小节。

每个真正的心理变化节点只能在最适合的段落首次成立一次。其他段落可以呈现节点发生前的持续处境、节点发生后的具体后果、体验的延续或沉浸。

不能因为某段音乐情绪回到前面的方向，就让人物回到前面已经走过的心理位置。
不能因为某段有明显的情绪变化，就强行给人物增加一个认识或决定。
同一个节点可以在后续段落中产生不同的实际体验，但不能再次被宣布成立。

每段都必须有 state，但 state 不等于新变化。没有新变化时，如实写这一段人物正在经历什么，并将 delta_type 标为延续、后果或暂时没在想。

【第三步：不增加外部情节】
每条路线从头到尾只能是一件事。
不新增聚会、书信、物件、对白、地点、职业、第三人、具体外部事件或场景。
不新增对方的动作和未经检验的隐秘心事。
允许一个从头到尾不变的轻处境和小动作，但不能用它制造新的事件。
所有变化必须来自人物已有经历、已有事实及其实际后果。

【第四步：人物语言】
用普通人平常会说的话写状态。写具体在意什么、想要什么、怕什么、正在承受什么。不要写心理分析、人生道理或抽象概念。不要把每个节点都写成一次总结。

【输出格式】
请独立提出 3 条完整候选路线。
每条路线严格使用以下字段，不得增加字段：

- situation：一句普通话，说清整件经历。
- segments：按照 S01：第 1–23 小节
S02：第 24–65 小节

S04：第 92–115 小节
S05：第 116–147 小节

S11：第 226–241 小节
S12：第 242–253 小节
S13：第 254–288 小节 原顺序，每段包含：
  - sec
  - state：本段此刻实际是什么情况，1–3条；可以是延续、体验或后果，不要求新认识。
  - delta_type：从新变化、后果、实行已有想法、延续、回到旧处但有新增、暂时没在想中选择。
  - delta：只有真正新增的事实或认识才填写，没有就留空。
  - depends_on：真正作为前因的更早 state 编号；没有就空。
  - still_open：到这一段仍未解决或仍不知道的东西；不要反复写同一个已经处理过的问题。
- established：按首次成立顺序列出全文的重要事实、认识、愿望或选择，并标明第一次成立在哪一段。

established 只登记真正成立的心理事实，不把情绪强弱、同一体验的不同质地当成新的认识。

每条路线都必须先作为一件完整经历成立，再映射段落。不得为了填充某一段而创造新的心理节点。

不要写最终文案，不要评价候选。只输出 JSON。
