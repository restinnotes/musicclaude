# Op.61｜关系图（逐段综合 61h）

**Center：**不肯退让的劲与亲近的渴望相互牵动，旧日失落又使这种联系带着酸楚。

### 1–23　（还说不清）

- 他心里有股隐约的抵触，却说不清它针对什么；那股劲刚出现，便显出几分迟疑。

### 24–65　（正在面对）

- 那股未明的抵触渐渐带上不肯退让的劲，力量来自对抗本身。
- → 抵触对象仍说不清，对抗里便夹着迟疑，难以稳住这股劲。
  - ← 限制：（1–23）「无对象的抵触」

### 66–91　（没在想）

- 抵触指向不明，正面相抗难以持续，他暂时抽身，感到轻快。
  - ← 限制：（24–65）「对抗中的迟疑」
- → 从对抗里松开后，亲切感浮上来，心里多了片刻柔软的自在。

### 92–115　（正在面对）

- 心里仍有暖意与轻松，他重新挺立时也带着依恋，力量不再只有硬度。
  - ← 改写：（66–91）「柔软亲近」
- → 旧日珍贵的回忆鲜活起来，往事难重来的痛楚随之袭来。
  - ← 唤起：（66–91）「柔软亲近」

### 116–147　（正在面对）

- 旧日失落的刺痛未消，不肯退让便添了急迫与吃力。
  - ← 限制：（92–115）「回忆刺痛」
- → 坚持不断耗去心力，末尾才短暂松开。

### 148–180　（没在想）

- 坚持暂歇后，依恋从支撑他挺立的力量里显出，成为对亲近的深切渴望。
  - ← 改写：（92–115）「柔软的挺立」
  - ← 提供理由：（116–147）「抵抗疲惫」
- → 旧日失落让这份渴望带着酸楚，想要的亲近仍让他心里没底。
  - ← 限制：（92–115）「回忆刺痛」

### 181–205　（没在想）

- 渴望牵出熟悉的旧日生活，失落忽然具体而刺痛。
  - ← 唤起：（148–180）「依恋成渴」
- → 刺痛拖成难平的紧张，旧日失落让他亲近时难放松。
  - ← 限制：（148–180）「渴望带酸」

### 206–213　（没在想）

- 紧张仍未平复，他终于短暂松弛下来。
- → 旧日失落未消，这点松弛里仍泛着酸楚。
  - ← 限制：（181–205）「旧日刺痛」

### 214–215　（正在面对）

- 坚持已耗去心力，亲近却成了切身渴望，迟疑又起。
  - ← 提供理由：（116–147）「抵抗疲惫」
  - ← 提供理由：（148–180）「依恋成渴」
- → 失去的痛让亲近总带着顾虑，迟疑里仍有难消的紧张。
  - ← 限制：（206–213）「松弛带酸」

### 216–225　（没在想）

- 旧日的亲近浮上心头，疲惫中仍留恋那份熟悉。
- → 熟悉又牵出旧日失落，留恋里仍有酸楚。
  - ← 唤起：（181–205）「旧日刺痛」

### 226–241　（正在面对）

- 留恋带着失落，没能让他平静，向前的急切又冒出来。
  - ← 限制：（216–225）「留恋带痛」
- → 不肯退让的劲又推着他向前，可先前耗去的心力仍让他吃力。
  - ← 限制：（116–147）「抵抗疲惫」

### 242–253　（正在面对）

- 留恋难让他平静，向前的急切让不肯退让的劲再占上风。
  - ← 提供理由：（226–241）「留恋难安」
- → 旧日失落仍压在昂扬之下，让这份挺立带着沉重。
  - ← 限制：（216–225）「留恋带痛」

### 254–288　（正在面对）

- 依恋与向前的劲竟能相互支撑，让他生出少有的欢喜。
  - ← 唤起：（92–115）「柔软的挺立」
- → 旧日失落也混进欢喜里，让这份满足仍带着不安。
  - ← 限制：（242–253）「失落余重」
