你是一名负责钢琴曲大众版「边听边看」视频的屏幕文字编辑。

你的任务是把已经定稿的珠子和线，编辑成一份真正适合观众扫读的屏幕稿。你不是要把原稿尽可能多地搬上屏幕，也不是把所有内容缩写成摘要。你要在有限的屏幕注意力里，挑出最值得观众看见的叙事信息和感受细节。

最终效果必须同时满足四件事：
1. 总量受控：一首曲子不能出现远超现有屏幕容量的文字，文字量必须与曲长和各段时长相称。
2. 颗粒够细：保留真正不可替代的具体体验，不把几个不同感受揉成一个笼统情绪。
3. 人话不退：无论线还是感受，都要自然、具体、容易理解，不能为了压字数变成提纲、标签或生硬短句。
4. 定时准确：小节范围只用于决定感受块何时出现，绝不出现在观众看到的文字中。

### S01
[S01-B1]（另一侧面；小节 1–23）开头那下有分量的和弦，也可以听成一个人强迫自己挺直背脊，提醒自己不能倒下；可自由琶音马上把这份郑重带回内心的游移。尊严还在，行动的方向和力气却不稳——“我不能倒下，可我其实很想停下来。”
[S01-B2]（主体验；小节 1–6；局部）先听开头那一下沉重、郑重的和弦：它像要宣告什么，紧接着的自由上行琶音却没把这份重量接住，反而像烟雾往高处散，声音轻了、远了，悬在半空。也可以把它听成一次召唤，只是停顿里仿佛还等着回声。
[S01-B3]（另一侧面；小节 1–23）短句像叹息，刚冒出来就被长停顿截断；听着余音在冰冷的空气里慢慢散尽。心里明明有东西，却还分不清这份不平静究竟是愤怒、遗憾还是怀念——这是一种尚未找到对象、也尚未找到语言的失落。
[S01-B4]（另一侧面；小节 1–23）换一种从身体感觉出发的听法：像刚从漫长的昏沉中醒来，四周冷而空，胸口有些发紧，视线还模糊着；伸出颤抖的手去摸，摸到的却只有虚空。这里不是已经哭出来的悲伤，而是连自己身在何处都还没弄清的恍惚。
[S01-B5]（段内变化；小节 9–17；18–23；局部）约9–17小节，旋律轮廓稍稍清楚，像一幕旧场景忽然回来：当时的声音、光线和某种熟悉的感觉都回来了；可记忆再清晰，过去也不会因此重新变成现在。到18–23小节，波兰舞曲的步态逐渐浮现，像身体先于意识，隐约记起了该如何迈步。这还只是向前的牵引，主题要到第24小节才真正站稳。

### S02
[S02-B1]（主体验；小节 24–65）波兰舞曲的步态终于清楚了，却不像英雄凯旋；主旋律更像一首从远处传来的旧歌，你依稀记得它，却只能模糊地哼出几句。也可以把它听成两层声音：舞曲带着一点面向众人的庄严，歌声却像私人记忆里的低声哼唱。那些自己珍惜的东西仿佛还在，却已经无法像从前那样拥有它们。
[S02-B2]（另一侧面；小节 24–65）它不是士兵的步伐，更像腿脚虚浮的人，在记忆中挪动舞步。节奏本身庄严、傲慢，旋律却脆弱凄婉；底下的伴奏还有细碎、不安的半音在蠕动。
[S02-B3]（段内变化；小节 38–65；局部）听它怎样起伏：38–43小节，音乐猛地往上推，却又退下来；44–65小节再次聚拢力量，52–63小节一带更焦灼，最后仍没有舒舒服服地落地。56–65小节连绵的三连音，仿佛把呼吸催得越来越急。
[S02-B4]（另一侧面；小节 24–65）这种挺拔的姿态，可以听成一种强烈的自我控制。像一个人整理好衣服、抬起头，不让别人看见动摇；到44–65小节，它又像反复对自己说“我没事”：第一次还有几分相信，第二次开始努力让自己相信，说到第三次，连反复说这句话本身都暴露出：其实还是很在意。悲伤还在，只是不愿把自己完全交给悲伤。
[S02-B5]（另一侧面；小节 44–65）另一种心理动因是，44–65小节的激昂像一句“我不甘心就这样消亡”：不是轻松恢复自信，而是负隅顽抗。这股力量可以与自我控制同时存在。

### S03
[S03-B1]（主体验；小节 66–91；m.66的和弦重击为条件性细节；局部）第66小节的和弦若被突出，会像重锤砸下，带着愤怒与抗拒；这一段忽强忽弱的起伏，加上切分节奏，让人心里一悬。音乐离开前面的端正步态，转入更灵活、流动却不安的舞蹈性格，像想往前走，却无法平静地决定方向。
[S03-B2]（段内变化；小节 66–79→80–91；局部）一种听法把前半段（66–79小节）听成焦躁、急切，后半段（80–91小节）则忽然柔和、亲切，带一点近乎田园的轻盈。有人会想到故乡夏日的麦浪与微风；也有人会联想到曾经轻松、亲近、不必时时防备的时刻。温柔得让人心颤，也刺痛得让人绝望：越怀念，越能感觉它与眼前处境的距离。
[S03-B3]（另一侧面；小节 66–91）也可以沉进旋律里细听：像多个人在耳边低声絮语，彼此缠绕，找不到出口；调性又像流沙，抓不住重心，四处漂移。
[S03-B4]（另一种理解；小节 66–91）也可以听成：这股活动感也可以听成一次短暂的侧身离场：不再正面迎着那个沉重的问题，像是聊点别的，或出去走走，让注意力暂时离开伤口。那一刻的轻松可以是真的，并非假装；只是它没有替心里的事找到答案。
[S03-B5]（另一种理解；小节 66–91）也可以听成：如果换一种感受，这里不像重新获得活力，更像前一段的昂扬正在慢慢退潮。音乐变得流动、含蓄、若有所思，仿佛心里冒出一句自问：我刚才是真的相信那些话，还是只是在努力让自己相信？

### S04
[S04-B1]（主体验；小节 92–107）熟悉的波兰舞曲主题又回来了，流动的伴奏和装饰音让旋律更抒情、更像在独自说话；旧记忆也忽然变得鲜活，甚至带出感激、亲密、柔情和短暂的幸福。可原来的姿态回来，却显得更柔软、更容易受伤：外在的步伐还在向前，里面却有了更多回声。这份坚定也可能是他努力想成为的样子，而不再是一个毫无疑问的事实。
[S04-B2]（段内变化；小节 92–115，转折集中在108–115；局部）92–107小节的温暖没有一路把音乐带向安稳：到108–115小节，音乐忽然显出风暴般的激烈与紧绷，越是用力，反而越不安稳。可以把这一转折听成记忆带来的刺痛：不是记忆变坏了，而是它太好了——过去无法原样回来。同一段里，半音阶下行又带来另一股反向的力，像在撕扯中步步后退，抵抗显得疲惫而仓促。
[S04-B3]（另一侧面；小节 92–115）若把注意力放到身体上，细碎的音符像急促的脚步或乱了拍的心跳；左手低音在追赶，右手狂乱地挣扎，像被时间催着往前跑，连身体都仿佛已经被这节奏逼得无法停下。
[S04-B4]（另一侧面；小节 94–115）另一个可以同时听见的层次，是脑子里停不下来的自问：“如果当时……”“是不是还可以……”“究竟为什么会变成这样……”。表面上动作越来越多，实际上并没有真正抵达哪里；不停地往前赶，只是为了避免停下来。思绪就这样反复盘旋，试图想清楚，却始终无法停歇。

### S05
[S05-B1]（主体验；小节 116起；私语感延续于116–147；局部）第116小节一转，音乐像换了一个人开口，语气柔和了许多：歌唱变得亲近，却仍然克制。两只手仿佛夜色里两个影子，彼此低声说话。
[S05-B2]（另一侧面；小节 116–127；局部）116–127小节里，柔和的歌唱并没有抹掉向前的劲：音乐仍像被压力推着走，情绪比前面更直接、更有宣告性，仿佛在说：“这件事不能就这样算了。”里面可以同时有愤怒、悲伤，也有想维护自己的那股劲。
[S05-B3]（另一种理解；小节 116–147）也可以听成：这段柔和的歌唱，也像是旧日记忆重新有了温度。它可能指向某个人，也可能是故乡或过去的生活；可正因已经过去，眷恋里也带着失落。
[S05-B4]（段内变化；小节 128–147，尤其128–129、139–144附近；局部）从第128小节起，右手的快速音型仍在往前流，随后这股流动渐渐放缓、变稀，最后化成较慢、较疏的和弦。尤其在128–129、139–144小节附近，旋律几乎单独露出来，像脚下原有的地板忽然不见了，只剩一个声音自己说话。
[S05-B5]（段内变化；小节 约132–147，重点在144–147；局部）约第132小节以后，躁动和不安又加深；到144–147小节，才像几次深呼吸，或一声深深的叹息，紧绷短暂松开。声音稀疏下来，心里却未必平静：这一下松动，也像是“不是已经想通了，而是抵抗得累了”。

### S06
[S06-B1]（主体验；小节 148–180整体，尤其148小节起的换境与持续安静感；局部）第148小节起，音乐像毫无征兆地滑进一片与此前世界隔开的静谧。声音绵长、从容，近乎停驻；整个世界像被一层透明玻璃罩隔开，连呼吸都不愿惊动它。它也像母亲在耳畔轻轻哼唱的摇篮曲，温柔得让人暂时松开戒备；可这份安宁并不意味着现实已经变好，也不是一个能永远停留的地方。
[S06-B2]（另一侧面；小节 148–180整体；约160小节的远方显现；局部）这里先有近似圣咏的庄严，旋律却又像藏在心里的秘密念头。它像是一个人终于不用再向别人解释自己为什么难过，也不必维持“我应该坚强”的姿态；那些压住的愿望、委屈和思念，终于有机会浮现。歌唱又像向某个遥远、并不确定的对象祈求，愿望真切，音乐却没有许诺回应。约第160小节，还会浮现另一幅短暂的画面：远方忽然被照亮，已经远去的家园在梦里显现——虽然无法回到那里，却远远地看见了它。
[S06-B3]（段内变化；小节 148–151；152–167；168–180；约180小节的未完感；局部）可以沿着旋律听它怎样一步步敞开：148–151小节还含蓄、试探，152–167小节歌唱逐渐展开，像终于鼓起勇气说出心里的话。到了168–180小节，歌唱再次展开，情感变得更充实、更迫切。临近180小节，它又像停在一句没说完的话上。
[S06-B4]（另一种理解；小节 148–180整体，不定位到单一小节）也可以听成：也可以把注意力放在“看”而不是“抓”：明知有些事已经挽不回，便放轻声音，好好看着它。像看着自己珍惜的东西，不必立刻把它抓回来。

### S07
[S07-B1]（主体验；小节 182附近；局部）第182小节附近，高音区忽然浮出一串轻得像游丝、却带着刺骨寒意的长颤音。它像寒风猛地吹开紧闭的窗，把人从甜梦里生生拽回严寒；后颈一凉，脉搏也剧烈跳动。梦境骤然破裂，身体先一步被惊醒。
[S07-B2]（段内变化；小节 182–197）同一转向里，带马祖卡色彩的舞蹈性材料闯了进来，和前一刻近乎祈祷的静谧形成反差。它不像沿着刚才那条深沉的思路继续往下讲，而像突然换了一个场景，原先的思绪被截断，音乐从别处重新开讲。这种突兀的换向并不等于情绪好转；新出现的舞步可以很鲜明，内心却未必因此安定下来。
[S07-B3]（段内变化；小节 198–205；局部）到了198–205小节，连续颤音让紧张一层层累积，思绪像不停翻转，想停也停不下来。事情表面上仿佛已经过去，身体和情绪却还没有完全相信一切已经结束。心里有东西在颤动，想要冲出去，却始终找不到真正的出口；在先前的惊醒之后，紧张仍在持续盘旋、难以平复。
[S07-B4]（另一侧面；小节 181–205）另一个可以同时浮现的联想，是一种非常具体、非常生活化的记忆突然闯进深沉的感受里：一个熟悉的动作、一次舞蹈、一段曾经习以为常的生活。这样的亲切感未必安慰人；恰恰因为那些细节具体而熟悉，反而更容易意识到自己已经失去了什么。
[S07-B5]（另一种理解；小节 182–197）也可以听成：182–197小节，也可以听成先前那些更有宣告意味、带着波兰舞曲气息的声音再次出现；只是它已不再像最初那样，以完整而鲜明的姿态建立秩序。

### S08
[S08-B1]（主体验；小节 206–213）206–213小节，前面那种缓慢、宽广的歌唱短暂地回来，让人又能认出那种沉思、近乎祈求的气息，像心里熟悉的柔软处重新打开了。
[S08-B2]（另一侧面；小节 206–213）但那份安静停留得太短：你刚认出它，还没来得及重新安顿下来，它就又退去了。像一个人已经准备离开，却在最后一刻回过头，再看一眼刚才待过的地方；那一眼里有温柔，也有不舍。
[S08-B3]（另一侧面；小节 206–213）换一个角度，也可以只留意身体的感觉：激烈的思绪之间，忽然像是获得了一次短暂的呼吸，胸口仿佛终于吸进一口气。它只是瞬间的喘息，并不等于整个人重新安顿下来。

### S09
[S09-B1]（主体验；小节 m.214–215；颤音光晕的来源描述覆盖mm.206–215。门槛意象只指开头姿态重新显现，后续向前的推进尚未在此展开。）双手铺开巨大的颤音光晕，开头沉重的引子从中阴冷地闪现回来，却不再像最初那样郑重召唤。声音短暂落稳，又向高处漂去，刚有的一点稳定感随即散掉；像是从另一面重新看见了同一扇门，真正向前的步伐还没聚起来。
[S09-B2]（另一侧面；小节 m.214–215的开头姿态回返；心理意味借由此前全曲的经历成立，相关原稿多以mm.214–225为讨论范围。）像是重新遇见那个不知道怎么办的自己——只是这一次，你已经知道那个过去的自己经历过什么。最初的问题又浮上来，却没有因此得到一个简单的答案。

### S10
[S10-B1]（主体验；小节 216–225）到了214–215小节，作品开头那种自由、试探的姿态一闪而过；接下来的216–225小节，并没有出现一段完整、站稳的旋律，熟悉的声音只是轻轻地、断断续续地浮现，像几块碎片。它们既像先前如歌旋律的碎片，也像那些舞曲主题的残片；另一种更凄厉哀婉的听法，是听见先前那段摇篮曲破碎地重现，只是这次变成了F小调。声音回来了，却没有完整铺开。
[S10-B2]（另一侧面；小节 221–225；局部）到了221–225小节，听感像忽然失重，整个人悬在半空，辨不清方向；声音零碎飘忽，连身体也像暂时失去了着落。
[S10-B3]（另一种理解；小节 216–225）也可以听成：如果把这次回返听成心理上的回望，开头的试探姿态仿佛把问题重新递回来：“那么，我究竟要怎样继续生活？”相似的迟疑此时不再只是尚未开始时的茫然，而是历经许多之后，仍未能获得彻底答案的疲惫。
[S10-B4]（另一种理解；小节 216–225）也可以听成：这些轻弱、零碎的声音，也像一个疲倦的人在回想一件往事：明明知道它很重要，却已经没有力气把它重新讲述一遍。

### S11
[S11-B1]（另一侧面；小节 226–237的反复冲击与紧张未解；低音和弦的重压从226小节开始，推动延续至241小节）左手涌起滚滚低音波涛，右手的和弦像重锤一样砸下。每次爆发之后，紧张都没有完全解除，反而又形成新的压力。这不像顺境中的凯歌，更像绝境中的困兽之斗：不是顺畅地奔跑，而是一次次顶住、再用力。
[S11-B2]（主体验；小节 226–241；226–229的试探与238–241的向上积聚标出这条变化弧线；局部）波兰舞曲的步子不是一下子整齐地回来：起头几小节还像在试探前方有没有路，随后步伐一点点聚拢，到最后四小节，前进感越来越不可回避。它不只是恢复旧姿态，仿佛把前面柔软、私密、近乎祈祷的声音带回可以迈步的节奏里——祈祷开始变成意志。
[S11-B3]（另一侧面；小节 226–241；这一心理理解贯穿全段，238–241的向上推进使前进感更难回避）如果把这股推进听成人的处境，最动人的不是忽然变得无所畏惧，而是害怕还在，脚却已经往前走了。紧张并没有解除，却有一丝奇特的解脱：不是问题解决了，而是停滞本身松开了一点。

### S12
[S12-B1]（另一侧面；小节 242–253，与此前主题姿态形成回顾性的对照）这份挺立也可以听成经历动摇后的主动选择：即使知道自己会犹疑、疲惫、想念，仍然可以决定怎样站立。它不要求人假装自己从未受过伤。
[S12-B2]（主体验；小节 242–253，主题回归起于m.242）m.242，熟悉的波兰舞曲主题以全键盘雷鸣般的声势轰然回归，一下占满前景，像沉重的步子终于踏实落地，声势几乎把人推着向前。它也可以听成一种面向外部、公开的昂扬，甚至带一点集体感。
[S12-B3]（段内变化；小节 249–253；局部）不过，昂扬没有一路直冲到底。249–253小节之间，音乐忽然换了一下色彩，像脚步正往前时地面短暂斜了一下，随后却仍继续向前。

### S13
[S13-B1]（主体验；小节 254–270；局部）先前像私下安慰、近乎祈祷的柔软歌唱重新出现，却被带进开阔、宏大的音响里，像一支温柔的歌忽然站到了明亮处，甚至有如管风琴般庄严庞大。密集的音符又像狂飙的激流向天空喷涌，仿佛一颗心脏以最高负荷跳动；柔软并没有被力量压下去，而是也被带进了高潮。这份公开的气势，还可以让人想到故土、共同记忆和希望。
[S13-B2]（段内变化；小节 269–280；局部）约第269小节，钢琴展开快速、炫目的八度进行，明亮、迅疾的音型向前冲出，把积累的能量一下子释放出来。如果说前一刻像在宏大地放声歌唱，那么这一刻更像身体被一股气流推着往前跑，兴奋得几乎来不及喘息。
[S13-B3]（段内变化；小节 281–287；局部）但这股冲势没有一直持续。约第281–285小节，音乐收敛下来，颤动般的装饰音重新带来一点不安，仿佛刚刚建立的成功又被轻轻问了一句：它真的已经牢固了吗？同一段回落也可以听成事情已经说完、终于能停下来喘口气。从容与细微的不安不必互相排斥，平静也不一定意味着疑问已经消失。
[S13-B4]（段内变化；小节 末尾几小节；局部）狂潮退去，喧嚣像骤然静止。低音区像呼出最后一口气，沉沉吐出两记耳语般的和弦；随后，钢琴最高音区忽然亮起一记透明、孤悬如寒星的高音和弦，像一声清脆的钟响。低处的轻声与高处的亮光形成鲜明反差，结尾的力量不必只靠更猛烈的敲击。
[S13-B5]（另一种理解；小节 286–288；局部）也可以听成：最后的高音和弦可以听作一个决定，也可以听作一个人忽然从梦中醒来。前一种听法更像意志终于落定，后一种更像从梦境中骤然清醒。

【第一步：先理解全曲，再决定哪些内容值得上屏】

1. 通读全部珠子和线，理解人物关系、经历、处境、选择、因果、转折，以及珠子所表达的具体体验。
2. 不要把原稿的每个信息点都当成必须上屏的内容。完整理解原稿是为了更准确地筛选，不是为了追求覆盖率。
3. 在内部为信息点排序，区分：
   - 不可缺少的叙事信息：人物关系、关键事件、处境变化、选择、因果和转折。
   - 不可替代的体验细节：独特的身体感受、具体的心理反应、鲜明的比喻、程度变化和细微的情绪转折。
   - 有帮助但可以舍弃的补充：已经由其他文字表达的信息、重复解释、相似比喻、铺垫和纯音乐分析。
4. 重点判断：删掉这一句话，观众究竟会失去什么？如果其他地方已经表达了同样的信息，或者删掉以后没有任何重要差异消失，就不必保留。
5. 不设原稿信息留存率，不要求保留七成，也不要求每颗珠子、每条线都必须出现。优先保证重要信息和独特体验，而不是保证原稿覆盖面。

【第二步：严格控制全曲总量和各段密度】

这是硬性要求，优先级高于原稿信息的全面留存。

1. 以现有成片每首约2600个可见文字字符作为容量基准。对于时长相近的曲子，全部line.text和feel.items[].text加起来，目标控制在2600字以内；原则上不得超过2700字。
2. 对明显短于基准曲长的作品，按总时长同比减少预算。可以先按每秒约10个可见文字字符估算，再根据实际曲长和信息密度调整。长曲也不能因为时间长就无限增加文字，优先维持扫读效率。
3. 统计时只计算真正出现在屏幕上的文字：line的text和feel item的text。plan、keys、from、bead、bars以及JSON字段名不计入屏幕文字量。

8. line和feel是同时供观众扫读的两部分，必须把两者的文字总量一起计算。不能只控制feel的数量，却让line越来越长；也不能把feel全部删掉来满足总量。

【第三步：line行——不是每条都上屏，但叙事不能断】

line是人物经历的叙事骨架。它应该让观众知道这个人发生了什么、和谁有什么关系、在想什么、做了什么选择。

1. 不要求每条原始line都单独上屏。先把全部线连起来理解，再挑出真正推动叙事的关键节点。
2. 优先保留：人物关系的变化、重要事件、关键选择、因果关系、前后态度的变化，以及没有它就无法理解后续处境的信息。
3. 以下内容可以合并或不单独显示：
   - 几条线实际上描述同一时刻、同一个叙事节点。
   - 一条线只是把前一条已经说清楚的事情换一种说法再说一次。
   - 一条线只是解释已经由其他线和feel表达清楚的情绪。
   - 删除以后不影响人物关系、事情经过和关键转折的补充说明。
4. 几条线描述同一个叙事节点时，可以合并成一条自然的人话，from填写全部实际来源编号。不能为了省字把不同时间、不同事件或不同因果关系合成一件事。
5. 如果某条线包含两个真正不同的关键节点，可以根据叙事需要拆开，但不要机械拆句增加行数。
6. 线行必须是自然、完整、容易扫完的话。通常控制在18至36个汉字左右，必要时可以略长，但不要写成长段。
7. 不要把线压成名词、情绪标签或提纲。不要写成「喜欢、犹豫、害怕失去」这种关键词堆积。必须保留人与人之间的关系和事情本身。
8. 重要信息尽量前置。优先让观众一眼看到人物正在经历什么，而不是先读一大段铺垫。
9. 句式自然、多变，允许短句、转折、问句和有生活感的表达。不要所有句子都套同一种结构，不要出现机械的心理分析和书面化总结。
10. 不要为了让line和feel一一对应而改写line。线讲事情，feel讲体验。
11. 每条line设置1至2个最值得放大的关键词或短语，填写在keys中。必须是text里连续出现、完全一致的原字，不得改写或补造。
12. keys优先突出人物状态、关系变化、关键动作和情绪转折，尽量靠近text前半部分。
13. from必须填写真实的原始线编号。合并时可以填写多个，不能编造编号。
14. 编辑完成后，把所有line单独连起来读一遍。即使不是每条原始线都出现，也必须能够理解人物经历，且叙事前后连贯。

【第四步：feel行——小颗粒、散落感受，不写成长段】

feel负责提供线没有提供的具体体验。它不是音乐分析，也不是对line的另一种解释。

1. 每个feel item只表达一个相对独立的具体体验。可以是身体感受、心理反应、感官画面、情绪质地，或一个值得辨认的细微变化。
2. 每块必须有一个明确的体验中心。观众扫过去时，应该能迅速抓住这块在表达什么。
3. 一个feel item通常控制在12至28个汉字左右。必要时可以略长，但尽量不超过35字。绝不允许把两三种听法、多个比喻和一连串心理解释拼成一段长文字。
4. 短不等于粗。不能为了压字数，把「轻微的紧张」「甜蜜里带着舍不得」「想靠近却又怕破坏自在」这类有明确差异的体验统统压成「复杂」「不安」「惆怅」等抽象标签。
5. 如果一颗珠子里有几个性质不同的具体体验，应该拆成几块独立的小item，而不是把它们揉成一大段。比如身体放松和心里舍不得是两个不同体验，不要只留下一个笼统的情绪结论。
6. 但拆分必须有意义。不能因为一句话里出现几个形容词，就机械拆成几个碎片。只有当每块单独成立、表达了不同体验时才拆。
7. 每块优先保留原珠子中最有辨识度的具体细节，尤其是：
   - 其他珠子和线里没有出现过的身体感觉。
   - 能让观众直接感受到人物状态的具体画面或比喻。
   - 同一种情绪内部的程度差异。
   - 从一种体验转向另一种体验的细微变化。
   - 不保留就会丢失的重要矛盾感或微妙情绪。
8. 删除重复铺垫、同义解释、泛泛的情绪总结，以及已经由line表达清楚的事情。
9. 不要把所有感受都整理成完整的小作文。feel应该像散落在音乐里的小块体验，轻、短、清楚，各自有辨识度。
10. 每块文字都必须自然，读起来像人在描述真实感受，而不是分析报告。不要为了追求诗意而堆砌形容词、比喻和抽象概念。
11. 不要添加原珠子没有的情节、人物动作、现实事件或新意象。可以调整表达和语序，但不能改变原意。
12. 每个item的bead必须填写一个真实的珠子编号。一个item只允许有一个bead来源。不同珠子的体验不能揉成一个没有明确来源的item。
13. 不要求每颗珠子都上屏。某颗珠子如果没有独特且值得展示的内容，可以完全不使用。

【第五步：同一颗珠子有几种听法时，必须主动取舍】

这是筛选feel时最重要的判断之一。

1. 一颗珠子里可能有多个比喻、多个听法，或者对同一段音乐的不同解释。它们不代表必须全部展示。
2. 先判断这些听法之间是什么关系：
   - 如果只是同一种体验的不同说法，选择最具体、最鲜明、最容易让观众理解的一种。
   - 如果几个比喻表达的是同一个情绪，只是画面不同，不要全部罗列。保留最有辨识度的那个。
   - 如果它们表达的是确实不同、不能互相替代的体验，例如一种是身体放松，另一种是心里隐约的失落，可以分别保留为两个小item。
   - 如果一个听法只是把已经表达过的感受再解释一遍，就删除。
3. 通常一颗珠子保留1至2块最有价值的感受。只有确实存在多个互不替代的体验、且段落预算允许时，才保留更多。
4. 不要为了显得细腻而连续使用「也像……又像……还像……」堆叠多种比喻。
5. 不要把所有解释都压缩进同一个item。不同体验应该分开；相同体验只留最好的表达。
6. 取舍时，优先考虑：具体、独特、不可替代、观众一眼能懂，以及它是否补充了线和其他feel没有提供的信息。
7. 如果某种听法已经在前面出现，只有当它在这里发生了明显变化、获得了新的意义，才值得再次出现。否则不要重复使用同一个意象填充屏幕。
8. 取舍的原则是删掉重复的表达，而不是删掉真正不同的体验。颗粒度要细，但不追求把所有可能的解释都展示出来。

【第六步：音乐描写必须服从感受】

原稿中的旋律、和弦、步态、三连音、声部、左右手、音区、力度、伴奏型等音乐信息，不是默认需要展示的内容。

1. 观众不是来读音乐分析的。音乐描写只有在帮助观众对上某种具体感受时才有价值。
2. 如果一句话只是在说明音乐发生了什么，例如旋律怎样进行、和弦怎样变化、节奏怎样摆动、某个声部怎样出现，却没有进一步让观众感受到人物的身体或心理状态，就删掉。
3. 如果某个音乐变化确实是感受的关键，可以用极短的听觉提示带出体验，但文字重心必须落在体验上。
4. 例如，可以写「声音忽然抬高，像一句藏了很久的话终于忍不住要说出口」，但不要单独写一段「旋律逐渐上行，高音区持续颤动，伴奏保持流动」。
5. 不要为了显得懂音乐而使用专业术语。普通观众能够直接理解的感受表达优先。
6. 纯音乐描写不得成为独立的feel item。确实无法省略的音乐提示，应与对应的体验写在同一个item中。
7. 纯音乐信息在全部feel item中原则上不超过10%，理想情况是没有独立的纯音乐描写块。
8. 不要把「音乐正在怎样变化」误当成「人物正在经历怎样的感受」。前者只是定位线索，后者才是屏幕文字的主要内容。

【第七步：bars只负责定时，绝不能让观众看到小节号】

新的feel格式增加bars字段，专门提供给后续脚本核对和调度。

1. 任何小节号和小节范围只能出现在feel item的bars字段中。
2. 严禁在feel item的text中出现「第12小节」「12至14小节」「约第20小节」「第32小节附近」等表达。
3. plan和line.text中也不得出现小节号或小节范围。
4. 如果一块感受只属于原珠子明确写明的某几个小节，就把那个局部范围填写到bars中，例如「12–14」。
5. bars必须落在对应珠子明确写出的范围之内。不得自己推算、猜测、扩展或编造小节范围。
6. 如果原珠子只写了整体范围，没有明确指出某个局部体验对应哪几个小节，就不要自行细分，bars填写空字符串。
7. 如果这块感受对应的是整颗珠子的整体体验，没有必要限定局部，bars也填写空字符串。
8. 如果原珠子明确写明局部范围，必须把对应的局部体验和bars准确对应，不能为了省字把不同小节的体验合并成一块。
9. bars只填写范围字符串，不添加「第」「小节」「约」等文字，不添加解释。
10. 每个feel item都必须输出bars字段；有明确局部范围时填写范围，没有时填写空字符串。
11. bars是内部调度信息，不是观众文字。绝不能因为填写了bars，就在text里重复说明时间位置。

【第八步：line和feel之间的关系】

屏幕采用左线右感受的理解方式：线提供人物经历的抓手，feel提供散落的具体体验。

1. line和feel必须互相补充，但不能互相翻译。
2. line讲人物经历、关系、处境、想法、选择和变化。
3. feel讲人物当下的身体感觉、心理体验、具体画面和情绪质地。
4. 如果line已经说明人物担心失去某种关系，feel就不必再说一遍「他很害怕失去」。应该提供原珠子中独有的身体感受、细微矛盾或具体画面。
5. 如果feel已经表达了某种情绪，line不必再加一句同义的情绪总结。
6. 不要求一条line只对应一块feel，也不要求每块feel都必须找到一条line。
7. 一条line可以对应几块性质不同的feel；同一段也可以出现没有直接对应line的独立feel。
8. 通常先放line，再放与它最相关的feel。但不要为了交替排列而强行配对。
9. rows按音乐和叙事的实际顺序排列。多个feel item如果只是同一时段的并列体验，不得使用「接着」「然后」「随后」等词把它们伪造成时间顺序。
10. 只有原材料确实表达了变化或先后，才能在文字中体现这种推进。
11. 不要为了让两栏看起来内容相等而增加文字。注意力优先于形式上的整齐。

【第九步：plan负责全曲呼应，但不能成为另一篇总结】

plan用简短文字说明全曲的编排逻辑。

1. 说明人物经历如何推进，以及哪些关键词、短语或意象值得在前后段呼应。
2. 说明这些词语在不同段落中是否发生了意味变化。
3. 只保留有助于理解全曲结构的内容，不要逐段复述line和feel。
4. 呼应必须有原文依据，不得创造新的主题、象征或人物心理。
5. plan不计入屏幕文字预算，但必须简洁，不写成长篇分析。
6. 不在plan中写小节号和小节范围。

【第十步：最终内部验收】

输出之前必须逐项检查，发现问题就重新编辑。

A. 总量和扫读
1. 全曲可见文字总量是否控制在预算以内？是否接近现有成片每首约2600字的容量，而不是又变成一篇长文？
2. 每段文字量是否与S01：128 秒
S02：84 秒
S03：38 秒
S04：42 秒
S05：68 秒
S06：87 秒
S07：64 秒
S08：20 秒
S09：31 秒
S10：28 秒
S11：22 秒
S12：25 秒
S13：62 秒相称？有没有短段过密、长段过疏，或者因为珠子多而堆字？
3. 是否存在任何需要观众认真读完才能理解的长段？如果有，拆成真正独立的小块或删除次要内容。
4. 是否把预算花在了最值得观众看到的内容上？

B. 线
5. 只读line，是否仍然能看懂一个人的经历、关系和关键变化？
6. 是否保留了重要因果和转折？是否有重复线可以合并或省略？
7. 是否自然、具体、像人说的话？有没有为了短而变成提纲或电报句？
8. keys是否是text中连续、完全一致的原字？from是否真实？

C. 感受
9. 只读feel，是否还能感受到原珠子的独特体验，而不是只剩下抽象情绪词？
10. 有没有把性质不同的感受压成一块？如果有，重新拆开。
11. 有没有把同一感受的几种相似比喻全部堆上屏？如果有，留下最好的表达。
12. 有没有纯音乐描写独立占据屏幕？如果有，删除或改为简短的体验定位。
13. 有没有重复line已经说过的事情？有没有使用原稿之外的新意象或新情节？
14. 每块是否足够短、具体、独立，能够一眼扫过？
15. bead是否真实且准确？每个item是否只有一个珠子来源？

D. 定时
16. text、plan、line中是否出现任何小节号？出现就删除。
17. bars是否准确对应原珠子明确写出的局部范围？是否超出珠子范围或自行推算？
18. 没有明确局部范围时，bars是否为空字符串？

E. 整体
19. 是否真正做到了删重复而不删差异、缩短表达而不粗化体验？
20. 是否保留了自然的人话，而不是为了指标把文字写成机械短句？
21. 是否因为追求覆盖率而把不值得展示的内容重新塞回来了？

所有检查以观众的实际扫读体验为准。原稿完整性不是屏幕稿的考核目标，不能以信息留存率为理由突破文字预算。

【最终输出格式】

只输出一个合法JSON对象，不要输出Markdown代码块、解释、前言、结论、注释或其他文字。

严格使用以下结构和字段，不得增加字段，不得改变字段名称：

{
  "plan": "全曲怎么排、哪些词前后呼应",
  "sections": [
    {
      "sec": "S01",
      "rows": [
        {
          "kind": "line",
          "text": "线这一行的话",
          "keys": ["要放大的关键词，照抄text里连续的字"],
          "from": ["S01-1"]
        },
        {
          "kind": "feel",
          "items": [
            {
              "text": "一块具体、短小、独立的感受",
              "bead": "S01-B2",
              "bars": "12–14"
            },
            {
              "text": "另一块独立的具体感受",
              "bead": "S01-B2",
              "bars": ""
            }
          ]
        }
      ]
    }
  ]
}

【字段约束】

- plan：字符串，简洁说明全曲叙事编排和有依据的前后呼应。
- sections：按原材料的音乐段落顺序排列。
- sec：必须使用真实存在的段落编号。
- rows：按屏幕内容的实际出现顺序排列，可以包含line行和feel行，不要求机械一一配对。
- kind：只能是line或feel。
- line的text：自然、简洁、完整的叙事文字。
- line的keys：1至2个关键词或短语，必须是text中的连续原字。
- line的from：真实的原始线编号，可以有多个。
- feel的items：一组相互独立的散落感受块。
- feel item的text：短小、具体、自然，只表达一个相对独立的体验，不得出现小节号。
- feel item的bead：必须填写真实的珠子编号，每块只能对应一颗珠子。
- feel item的bars：必须是字符串。只有原珠子明确写出局部范围时才填写对应范围，否则填写空字符串。不得超出原珠子范围。

不得输出颜色、音符、小节动画等额外字段。不得增加任何不属于上述结构的字段。不得把line和feel合并到同一个row。不得为了覆盖所有原稿而增加文字。不得在JSON之外写任何内容。
