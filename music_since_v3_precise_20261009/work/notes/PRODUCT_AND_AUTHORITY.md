# 产品目标、权威来源与质量边界

> 本文仅为 Claude 首轮定向导览，不替代本机正式产品宪法 V2。必须由 Claude 自己核对原始条款和真实稿件，而不能只从 Muse 的摘要建立美学判断。

## 1. 真正要生产的东西

面对 Op.52、Op.60、Op.61 等作品，用户希望有人陪他边听边理解：**这一刻到底经历着怎样具体的人性处境和感受**；前面发生了什么使这一刻变得不同；它能否指向全曲持续的问题，以及哪些事情尚未被解决。文章应在音乐进行中读得下去，又能提供真实的再聆听价值。

不是形式分析讲义；不是把每首曲子写成先苦后甜的心灵鸡汤；也不是不能戏剧化的冷淡观察报告。作品可能支持强烈、笃定乃至单一主线，不能自动判负。判断其优劣要回到具体可听段落、当下材料、情绪动作及反例。

## 2. 最重要的内容质量维度

- **当下的具体性**：人的动作、欲望、顾虑、相互矛盾的感觉、心理转折；不止“深沉/悲伤/释然”等标签。
- **时间诚实**：任何实时陈述只知道此刻及以前的音乐，不让未来结果定义当前体验。
- **关系的真实增量**：History、二次理解、Thread、WHY 是否提供了没有它就会丢失的独立听法，而不是换词重述、强塞心理因果。
- **开放性与完整性**：不因某条全曲线索好讲就吞掉其他实质体验；不因追求 NONE 而压掉音乐真实支持的关联。
- **语言可用性**：人话、具体、节省听者注意；最后润色不得新造解释。
- **可验证性**：时间、小节/听觉依据、来源及原句溯源；真正重要的遗漏和 unsupported additions 都要量。

评价“少说一点”只能作为手段，不是目标。评审 prompt 必须明写：戏剧化、笃定、单一故事线本身不扣分；若它们有证据且更有感染力，可以更好。

## 3. 实际架构/材料权限

材料独立研究（A 当前 Affect / T 长程关系假设 / H1–H5 专项 / 音乐事实）→ 规范源核心与纯净珠子 BEAD → 底向上 Thread/History/WHY，事后审 T/H 候选 → 实时 Presentation。

A 和 T 首轮不可彼此抄；H1–H5 要量其残差价值，不可平铺淹没 A/T；回顾性 H5 不进入此刻；H4 的期待必须记录“何时产生”和“何时被检验”；Thread 首轮来自珠子序列，外部全曲解释第二轮才裁决。表现层可 KEEP/RETIRE/REPLACE/APPEND，撤掉过时【此刻】。
