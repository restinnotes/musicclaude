你要写一首器乐作品最终使用的 Thread（线）。

Thread 是同一个人在整首作品里经历的一件事。

只读 Thread，不看珠子，读者应当能够顺着读懂他每一步具体在意什么、为什么会这样，以及前面的经历怎样影响后面。

同时，各段的处境和感受要自然接住 TARGETS。TARGETS 提供听感上的方向和层次，不提供人物故事。

【段落】
{SECTIONS}

【这件事（Center，已经给定，不改）】
{CENTER}

Center 是读者回头看整首时能够辨认出的整件事，不是人物每段都要面对的命题，也不要求最后解决。

【已经通过宏观评审的人物经历候选】
{ROUTES}

【从珠子提炼出的体验性质（TARGETS）】
{TARGETS}

你看不到原始珠子，不要猜测其画面、比喻或原句。

【工作方式】

一次写出完整条线，不逐段分别生成，也不在成品后另做改写。

在形成正文时，同时把握完整经历和 TARGETS；但两者各有不同作用。

先确定人物的经历，再让这份经历在各段自然呈现与 TARGETS 相近的感受，而不是按照 TARGETS 一段段编造心理变化。

以下构思和检查只在内部进行，最终只输出指定 JSON。

## 第一步：选择一条能够独立成立的经历

从候选中选择一条作为 base_route。

全篇只有一个 base_route，保持同一个人经历同一件事。

选择时同时考虑：

- 路线是否有明确且具体的人的处境；
- 前后的关键认识和变化是否有根据；
- 各段是否能自然容纳 TARGETS 中不同的体验性质；
- 这件事是否有足够的生活切面，不必靠反复解决同一个心理问题来延续。

因果成立优先于局部贴合听感。

ROUTES 是经历的骨架，不是必须逐字兑现的剧情。

保留所选路线的基本处境、已成立的事实和主要发展方向。路线里的猜测仍然只是猜测；如果某项推断超出了前文经历能支持的范围，正文只能写到人物能够知道或合理怀疑的程度。

不能通过补造更早的事实，让原本缺少根据的关键转折看起来成立。

如果某条路线的主要发展依赖无法成立的前提，优先选另一条有充分依据的候选。

## 第二步：安排整件事在各段的实际进程

从头到尾想清楚他经历了什么。

每一段都承接此前已经存在的处境。人物当前的念头可以来自：

- 他亲身经历过的感受；
- 他已经知道、相信、期待或害怕的事；
- 以前的愿望、选择和顾虑留下的后果；
- 已有处境在此刻继续产生的影响。

人物可以重新理解旧经历，但新认识必须能从旧经历里读出来。回想本身不是新认识的证据。

特别留意那些会成为后面许多段落共同前提的变化。必须先有足够根据，后面的发展才能建立在它上面。

不要为了让经历前进而不断安排人物想通什么。

经历可以通过不同方式发展：

- 原有的愿望变得更加切身；
- 前面的事情开始产生后果；
- 某种顾虑使眼前已有的好变得难以安心享受；
- 人物真正承受了以前已经知道的事；
- 已有感受暂时占据全部注意力；
- 同一份经历在后来显出不同的一面；
- 人物在尚未解决的问题中继续生活。

这些不是每段必须填写的步骤，只是可供经历自然发展的方式。

一段若只有某种状态在继续，就写它正在怎样继续，不要另外制造认识或决定。

同一种感受可以多次出现。再次出现时，若只是延续，就不要重新讲一遍道理；若此前的经历改变了它的意味，就让读者从具体处境中看见区别。

不必使每段都在两种相反念头之间重新权衡。整件事的影响可以始终存在，而人物此刻只顾着其中一面。

结尾按经历实际发展来写。可以有选择、承受、留恋、继续或尚未解决的事情，不强求最终答案。

## 第三步：让 TARGETS 参与各段，但不替人物决定发生什么

TARGETS 描述的是体验性质，不是人物的台词，也不是必须照演的心理过程。

构思每段时，同时考虑该段所有珠子的 qualities、temporal_shape、compatible_bundle 和 tensions。

把这些体验性质放进人物已有的处境里，寻找能够自然产生相近感受的原因。

注意：

1. 先有人物自己的所求和顾虑，再有情感表现。不能只因为 TARGETS 有某种情绪，就让人物突然发生一次没有前因的心理转折。
2. 同一段可以有几种并存的感受，不必压成一种。它们可以属于同一处境的不同侧面，也不必逐颗单独解释。
3. TARGETS 若包含段内变化，应考虑这种变化能否从人物当前经历中自然产生。不能直接把听觉上的起落、停顿、回返转换成他的新行动、新决定或新认识。
4. 体验性质可以影响本段的情感轻重、紧迫程度和感受方向，但不能提供未经建立的事实、人物动机或别人内心的确定结论。
5. 对于 TARGETS 中不同但可以共存的理解，尽量用同一段里不同的感受层次容纳，不要为了覆盖而另编一套情节。
6. 不搬用 TARGETS 里的比喻、拟人化情节、心理句式或想象中的动作。读者读到的应当是人物自己的经历。

尽量让每颗珠子在同段找到情境相近的内容；相关即可，不要求逐颗解释，也不要求每颗珠子对应独立的一条。

确实无法自然容纳时，不为了覆盖而破坏人物逻辑。

## 第四步：一次写出连贯、简洁的人话

把整条线当成一个人在讲自己经历的事来写。

虽然采用第三人称分段要点，连起来仍要像一段自然的经历，而不是对心理变化的逐段分析。

正文直接写他此刻在意的事，不把构思时的心理分类搬进句子。

优先写：

- 他具体想要什么、舍不得什么、怕什么；
- 此刻什么让他高兴、难过、安心或犹豫；
- 他已经经历过的事怎样影响眼前的感受；
- 他此刻实际愿意怎么做，或尚且不知道怎么办。

因果要能读得出，但不必每句都解释一遍因果。

前面已经交代过的事，后面可以直接承接；读者不需要每次重新听一遍背景说明。

让人物的念头自然出现，不必总由叙述者宣布他获得了新的认识、完成了某种心理转变。

避免让概括性心理词代替具体所求，也不要反复使用同一套转折句式、工整对称、哲理总结或不必要的否定。

否定、回顾和解释在确有用处时可以正常使用，不机械避开。

不增加未经建立的外部事件、具体场景、物件、对白或他人行动来推动变化。人物对他人的推测可以写成推测，不能冒充已获证实的事实。

### 分段要点的形态

- 严格按输入段落顺序输出。
- 每段 2–4 条。
- 每条恰好一句完整、自然的话，只承担一个主要意思。
- 连着读时，前一句能自然接到后一句。
- 不把一个意思换词拆成多条，也不把几件事压进一句散文式长句。
- 一段内的要点应各有作用，但不要求每条都发生新的认识或时序转折。
- 内容少的段落写两条即可，宁可简短，不凑心理动作。
- 全篇已经成立的认识和决定不要重复首次成立；已有的感受可以继续存在。
- 不让人物过早用终局式的话语宣布一个其实尚未完成的变化。

正文应当是完整的最终文字，不输出草稿或解释。

## 第五步：根据已经写出的正文填写元数据

元数据是对正文的记录，不能反过来强迫正文产生新内容。

### cite

某条明确提到或直接依赖更早的一条时，在 cite 中填写前面那条的 id。

引用的是实际前因或明确回指，不是主题相似。

不必每条都有 cite；不标关系类型。

### covers

填写本条确实能够接住的 bead_id。

一条可以覆盖同段多颗珠子，一颗珠子也可以由同段几条共同承接。

只有体验性质确实相近才填写，不为凑覆盖数量虚标。

### relation

根据本段正文实际呈现的人物状态，从以下三种选择一个：

- 没在想：此刻的注意力完全在别的具体感受或处境上，没有打量、挂念整件事。
- 还说不清：已有与整件事有关的感受或反应，但人物此刻还没有形成明确理解或态度。
- 正在面对：人物此刻清楚意识到整件事，并在具体考虑、承受、权衡或作出选择。

不要根据 Center 本身的存在来决定标签。

如果正文实际上正在想着整件事，不能标“没在想”。

### delta_type 与 delta

根据本段正文实际发生的内容选择：

- 新变化
- 后果
- 实行已有想法
- 延续
- 回到旧处但有新增
- 暂时没在想

delta 只记录本段确实新成立的心理事实或处境变化。

没有新增就写空字符串。不要为了让 delta 不为空而制造转折。

### established

只记录最终正文确实首次成立的重要事实、认识、愿望或选择，并填写第一次出现的要点 id。

不要收录构思中出现、但正文没有成立的东西。

后面再次提到同一项，不另记首次成立。

### uncovered_targets

仅当某颗珠子的体验性质无法在现有经历中自然容纳、强行覆盖必须增加未经支持的事实或破坏人物逻辑时列出。

先尽量利用人物已有处境的不同感受侧面完成覆盖，不能轻易放弃。

【最终检查】

输出前通读整条正文，确认：

- 把珠子和元数据全部遮住，仍然是一件有时序、有来由的人的经历。
- 后半篇依赖的重要认识，在前面确实有足够根据。
- 没有把猜测写成已确认的事实，也没有在后面改变前面已经建立的动机。
- 相邻段的相似感受不是无意义的重复陈述；没有新增时能够自然延续。
- 没有反复宣布问题已经解决，又以同样方式重新解决。
- 语言是具体、自然的人话，而不是心理分析提纲。
- 每段多种 TARGETS 体验大体有着落，未把珠子的想象写成真实经历。
- 每段 2–4 条，每条严格一句，所有引用、编号、标签和字段有效。

如有冲突，优先保证人物经历独立成立，不靠编造事实满足覆盖；在此基础上尽量兼顾各段体验性质。

【输出格式】

只输出 JSON，沿用以下结构，不增删字段：

{
  "base_route": "route_id",
  "segments": [
    {
      "sec": "S01",
      "relation": "没在想/还说不清/正在面对",
      "items": [
        {
          "id": "S01-1",
          "text": "...",
          "cite": [],
          "covers": ["bead_id"]
        }
      ],
      "delta_type": "新变化/后果/实行已有想法/延续/回到旧处但有新增/暂时没在想",
      "delta": "本段真正新增的心理事实，无则留空"
    }
  ],
  "uncovered_targets": [
    {
      "bead_id": "...",
      "reason": "为什么若强行覆盖会伤害人物逻辑（仅限必须编外部事实的情况）"
    }
  ],
  "established": [
    {
      "claim": "首次成立的重要认识或状态",
      "first_established": "Sxx-x"
    }
  ]
}
