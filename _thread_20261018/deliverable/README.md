# 《船歌》Op.60 · Thread / Inner / Outer（2026‑10‑18）

## 整首音乐里一直在发生什么（研究负责人的概括；原文见 C）

三件事同时在发生，同一段音乐可以同时在三条线上：

1. **把自己交给一个会动的承托。** 第 4–5 小节，左手的摇荡先托住身体，歌声才浮上来。这份承托在第 35 小节忽然撤去，身体这才发觉自己早已把重量交了出去。第 40 小节它以更薄的波纹回来，第 51 小节变得催急，第 78 小节短暂松开、让人失重。第 84 小节，当初温柔的水波翻成巨浪，歌声敢在上面放开。第 116 小节，一记果断的和弦截住了这阵长久的运动。
2. **说过的话再被说起时，旧的一遍仍在耳中。** 第 24 小节的重说添了更多细节；第 84 小节同一支歌用巨大声量再唱，耳根却还留着当初很轻的声音。第二主题再现时次序倒转：明亮的后半先回来，较内向的前半到第 103 小节才接上，带着暗色继续增压。这个倒转要走到第 103 小节才能听出来。
3. **亲近，却不能替对方唱完他自己的歌。** 第 6 小节起是两条贴得很近的歌声，第 40–71 小节是另一片有自己清凉、热度和玩心的歌唱，它们各自完整地发生。辉煌之后，较私人的那支歌仍有沉重的话要说；第 113 小节，低处还容得下一句独唱。

三条线都没有走"幸福—失去—接受"。也有一些段落，例如开场、第 17–23 小节的漂浮、第 72–83 小节的屏息与失重，由各条线明确说明为什么让它们保持独立。
