# 交给本地 Agent 后，直接执行

**先读 `00_说明/AGENT_直接执行任务.md`，然后自己开始调用 `gpt3` CLI 中的 GPT-6 Max 做 Prompt 自进化实验。**

本包含：

1. `01_提示词与基准/`：原提示词 P0（完整版本及可直接输入版）、GPT-6 Max 一次生成的完整优秀示范 B0（还有一份只含14段的盲评用阅读版）。
2. `02_Bead精简输入/`：D0 零 Bead，D1 音乐锚点，D2 14 条主体验，**D3 14 段正式 reader**，**D4 全部 51 条独立 Bead**。D3 和 D4 **必须两路都实测**，不要事先确定胜出者。
3. `03_Bead机器可读/`：正式原始材料抽取的14段、51条，含小节位置、原文及原段内关系。
4. `04_历史参考/`：旧版方案，只作为诊断对照，不许混进固定 P0 实验。
5. `05_实验记录模板/`：可自由修改的日志/清单。
6. `tools/`：可选本地工具。`python tools/verify_bundle.py` 检验材料完整；`python tools/assemble_input.py --condition D3 --output work/P0_D3.txt` 组装一致格式的测试输入，**不会调用模型**。

你必须在自己的终端发现 `gpt3` 的实际正确用法并调用 GPT-6 Max；此包未测试 CLI 选项，不编造调用语法。目标是进化**可迁移的提示词和输入机制**，而不是修当前这篇文章。所有真实运行记录保存到独立的 `work/` 目录。
