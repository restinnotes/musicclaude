【第一步：选择路线并检查其推进能力】

从通过 A2 的候选路线中选择一条最扎实的路线作为 `base_route`。全篇只能有一个 base_route，不能把不同路线拼在一起。

必须优先选择逐段推进贡献完整、事实账本自洽、语义重复最少的路线，而不是情绪变化最多的路线。

如果 ROUTES 中没有通过 A2 的合格路线，或者所有路线都无法支撑现有段落，不得勉强写线。输出 `status` 为 `blocked`，说明原因，不得通过新增外部事件或反复制造心理动作填满段落。

【第二步：先建立全篇推进计划，再写正文】

在写任何正文之前，先为 S01：第 1–23 小节
S02：第 24–65 小节
S03：第 66–91 小节
S04：第 92–115 小节
S05：第 116–147 小节
S06：第 148–180 小节
S07：第 181–205 小节
S08：第 206–213 小节
S09：第 214–215 小节
S10：第 216–225 小节
S11：第 226–241 小节
S12：第 242–253 小节
S13：第 254–288 小节 中的每一个段落建立一份推进计划。

每段必须明确：

1. 本段承接了此前哪一项已经成立的事实、认识、愿望、代价或选择。
2. 本段独有的新贡献是什么。
3. 新贡献属于哪一类：新认识、新所求、新代价、新选择、实行已有选择、已有选择产生的新后果。
4. 为什么这个新贡献在前面尚未成立。
5. 它会怎样改变后续人物的认识、所求、代价、选择或处境。
6. 本段的 TARGETS 需要怎样的情感底色，但不能因此改变人物事实。

逐段检查推进计划：

- 每段必须有一个独立的主要推进贡献。
- 不同段落的主要贡献不能只是同义改写。
- 同一个问题可以持续悬而未决，但不能在每段重新成为人物正在解决的题目。
- 一个认识一旦成立，后面不能重新发现。
- 一个选择一旦作出，后面不能重新宣布；可以承受它的新代价、执行它或在新依据下调整它。
- 一个愿望一旦成立，后面不能只通过加强情绪把它重新包装成新愿望。
- 同一个事实不能被反复使用来制造相同的安心、担忧或结论。
- 如果某段只有情绪变强、情绪变弱、重新回忆、重新反问或暂时不想，都没有独立推进贡献，必须重新设计。

如果某个段落在不编造事实的情况下无法增加真正的新内容，不能为了完成段落而重复其他段落。应改选路线；仍然无法成立时，输出 `blocked`。

【第三步：线自己先成立，因果从自身经历长出来】

1. 严禁外部加戏与凭空代度：不新增对方的新动作、具体对白、第三人、具体外部事件、新道具或新场景；同样，严禁凭空断定对方有了什么隐秘心事，或突然对对方的心态做出未经相处检验的新判断。
2. 允许一个从头到尾不变的轻处境和小动作。人物可以在已有处境中改变认识、所求、代价和选择，不需要外部事件来推动。
3. 所有认识的推进，只能来自人物对自己已有经历、已经知道的事实和已经承受的后果的重新打量。
4. 每一次变化都必须能追溯到前面的事实或状态。不得为了对应音乐高潮，突然让人物成长、释怀、放弃或产生伟大的感情。
5. 不模仿音乐物理动作。情绪的停顿、沉落、转折，必须由人物当时的心思或实际体验引出。
6. 不要求结尾必须有决断。决断可以在前面已经成立，后续段落负责呈现其后果；如果始终没有明确答案，也可以如实保留。

【第四步：核心矛盾可以贯穿，但不能反复上演】

整件事的核心矛盾可以始终存在，但它只能作为整条线的背景重力，不能成为每一段重新表演的固定心理动作。

特别禁止以下结构：

- 想靠近 → 害怕 → 安心 → 再次害怕，反复出现而没有新认识或新代价。
- 想念 → 想起委屈 → 怀疑选择 → 害怕孤单，再次回到想念。
- 已经决定 → 再次犹豫 → 再次决定，实际上没有任何新依据。
- 已经认识到某件事 → 后面换一种措辞，再次把它当作发现。
- 已经形成一种相处态度 → 后面连续几段重新宣布同一种态度。
- 每段都围绕同一个问题进行新的反问，只有问法发生变化。

如果旧问题再次出现，必须在正文中让读者看见这一次究竟多了什么：新的认识、新的所求、新的代价、新的选择或新的后果。不能只在 `delta` 字段里声称有新增，正文却仍然在重复旧问题。

情绪变强不算推进。回忆更鲜明不算推进。人物更痛苦、更安心、更害怕，也不自动算推进。

【第五步：TARGETS 是情感底色，不是人物事实】

1. TARGETS 规定本段的情感重力与方向，是紧绷还是舒展、悬空还是下沉、热切还是冷却。
2. 人物处境必须在情感重力与方向上与 TARGETS 吻合，但不得为了吻合而重新制造一个已经出现过的心理过程。
3. 不得把 TARGETS 里的心理比喻、修辞性描写或自问自答直接套写成人物的自白。
4. 不得把每个 TARGETS 都解释成一个新的心理事件。多个段落可以有相近的情绪底色，但它们必须在经历本身上承担不同功能。
5. 同一个认识可以在不同情绪底色下继续产生不同后果，但必须写清后果，而不是重新宣布认识。
6. 如果某项体验性质只有通过编造外部事实才能覆盖，才可以放入 `uncovered_targets`，说明原因。

【第六步：真正的人话】

1. 像一个平常人在讲自己的经历，读者一眼看懂。
2. 严禁抽象心理学名词和总结性的心理概念。
3. 不要每句都带推导脚手架，不要句句使用先前怎样、如今明白怎样、这让他怎样的分析句式。
4. 不要反复总结自己，不要替人物讲人生道理。
5. 杜绝套路对称句式，特别是反复使用越……越……。
6. 优先写具体在意什么、盼什么、怕失去什么、已经知道什么、现在愿意承担什么。
7. 不得为了写出不同的段落而人为制造人物态度的摆动。

【第七步：篇幅和条目】

1. 每段写 2–4 条要点，每条是一句完整、自然的话，只说一件事。
2. 一段内的多条要点必须是不同时序的具体念头推进，或不同但相互关联的实际内容，不能把一个犹豫过程换几个词拆成三句同义反复。
3. 每段至少有一条清楚承载该段独有的推进贡献。
4. 其他条目可以交代前因、具体心思或后果，但不得重复本段主要贡献，也不得重复前段已经说过的内容。
5. 小段落可以写 2 条，宁短勿凑。不得为了达到 2–4 条的数量而拆分同义句。
6. 前面已经成立的事实，后文直接承受其后果，不回头重新解释因果大道理。

【第八步：引用 cite】

某条提到或依赖更早某一条时，在 cite 里写那一条的编号，例如 S02-1。提到前面的内容就直接提，不必每条都有。只是主题相近、情绪相近不算引用。

【第九步：段落关系标签 relation】

写完正文后，严格根据本段正文实际表现出的状态标定：

- 没在想：注意力完全被当下的具体感受、感官沉浸或力竭疲惫占据，心里根本没有去打量或挂念 Center 那个核心矛盾。
- 还说不清：处在模糊的情绪波动或本能反应中，尚未理清整件事，也没有形成明确态度。
- 正在面对：清楚意识到核心矛盾，并在此刻具体权衡、挣扎、承受或做决定。

如果正文仍在打量整件事，不能标为没在想。

relation 只是本段心理状态标签，不代表本段已经完成故事推进。不能用没在想来掩盖本段没有独立新贡献的问题。

【第十步：最终全篇语义审计】

写完初稿后，不要直接输出。必须从头到尾进行一次独立的语义审计：

1. 把所有重要认识、愿望、代价、问题和选择归类，标记首次成立的位置。
2. 找出语义相同但表达不同的句子，尤其是重复的反问、重复的决定和重复使用的关系证据。
3. 检查每段的 `delta` 是否确实存在于正文，是否是相对前文的新内容。
4. 检查是否出现前面已经知道、后面又不知道的情况。
5. 检查人物已经作出的选择是否被无依据地重新打开。
6. 检查每段的主要贡献是否能被一句话独立概括，且不能被相邻段落的贡献替代。
7. 检查人物是否在几个相同状态之间循环，只是情绪温度不同。
8. 发现重复后，优先改变段落的叙事功能和推进内容，而不是替换形容词、调整句式或增加心理解释。
9. 如果不可能在现有事实和约束下消除重复，输出 `blocked`，不能保留一个明知打转的完整成品。
