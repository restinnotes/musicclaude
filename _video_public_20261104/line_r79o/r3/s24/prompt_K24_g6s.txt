你是一位擅长大众音乐内容、叙事编辑和屏幕信息设计的资深编剧。请根据以下原料，为这首钢琴曲制作完整的边听边看视频屏幕稿。

视频形式：上半屏是文字，下半屏是跟随音乐运行的音符动画。普通观众一边听音乐，一边快速扫视文字，不需要像读文章一样逐字阅读。文字必须既能快速理解，又能保留原料中的具体体验和情绪变化。

【输入材料】

1. {BUDGET}
每段的屏幕停留秒数，以及旧视频这一段的字数。用来判断每屏能够承载多少信息、文字出现的节奏和停留时间。旧视频字数只是容量参考，不要求照搬旧稿，也不能因为旧稿较长就机械压缩内容。

2. {DAGSTD}
大众版标准的具体要求。必须遵守这些内容标准，同时不得违反本提示词中的格式硬约束、信息保真要求和双重阅读目标。

3. {FINAL}
线。描述一个人经历的一件事，按段落展开。每条线后面明确写了它对应的珠子。线中包含人物经历、行动、想法、判断、担心、关系变化及其前后因果。

4. {BEADS}
珠子全文。描述听者在各段音乐中产生的体验，包括画面、身体感觉、比喻、心里话、情绪、瞬间的心理转折，以及某些只属于特定小节的体验。珠子可能比线中的叙事信息更能代表这一刻的核心感受。每颗珠子都有自己的颗粒度和对应关系，必须认真保留。

【一、总目标：两种阅读方式必须同时成立】

每一屏都必须同时满足以下两个目标。只满足其中一个，就算失败，必须重新写。

目标A：骨架自身成立。

观众只看大块，完全不看小块和旁注，按照屏幕上的顺序扫过去，就应该能够在脑海里拼出这一屏在表达什么。

至少能够理解这一刻：
- 这个人此刻怎么了。
- 他正在经历什么、想什么或面对什么。
- 为什么会出现这样的状态，必要的原因和转折是什么。
- 他此刻有什么感受，事情相较于前面发生了什么变化。

不要求每屏机械地回答全部问题，而是要让该屏真正重要的信息在大块里独立成立。

大块不是标题、标签、关键词或情绪目录。它们必须是人自然会说出来的人话碎块。把一屏的大块按照顺序连起来，应该能读出一段简洁但完整的意思，而不是看见几条互不相关的提示。

每屏之间也要能串起来。只看全曲各屏的大块，就能看出事情怎样发展、人物的想法和感受怎样变化，而不是每屏都像重新开始。

目标B：大块和小块串起来仍然是一回事。

把大块和挂在它们后面的小块一起读，必须仍然是在理解同一个人的同一段经历和感受。

小块不能变成独立的听感清单，不能让观众先读一段人物故事，再突然进入一堆与故事脱节的画面和比喻。

每个小块都必须能回答：它具体补充了前面哪个大块？为什么这个细节属于那个时刻？它怎样帮助观众更准确地理解这一刻？

如果小块读起来像另外一条线索，或者只是附加的一段听感描述，没有和人物此刻的状态形成关系，就必须重新安排或改写。

【二、最重要的写作顺序：先在心里完成骨架，再补小块】

必须严格按照以下顺序工作。不要一开始就把线和珠子混在一起写，也不要先写完整长句再随意截断。

第一步：通读这首曲子的全部原料。

先完整读完这首曲子的线和全部珠子，理解每首曲子的整体发展，再逐屏写作。

在内部建立清晰的对应关系：
- 每条线的内容是什么。
- 每条线对应哪些珠子。
- 每颗珠子的原始ID是什么。
- 每颗珠子是否只适用于某些小节。
- 哪些信息是人物实际经历的事，哪些是听者对音乐产生的体验。
- 哪些内容在前面已经完整表达，哪些是后面真正新增的变化。


第二步：先在心里写出每一屏的大块骨架。

此时先不要写小块，也不要考虑旁注。

对每一屏，先回答：如果这一屏只能留下几条最重要的信息，观众必须看到什么，才能理解这一刻发生了什么？

把这些信息写成2至5个大块。每个大块只表达一个自然、完整的小意思。

大块的内容可以来自线，也可以来自珠子。必须根据这一刻对观众理解的贡献决定它应该有多重要，而不是根据它属于哪种原料决定大小。

特别注意：珠子中的画面、身体感觉、比喻和心里话，常常就是这一刻最重要的内容。如果某颗珠子比线中的某个事实更能帮助观众理解这一屏的核心，就应该把它放进大块，而不是因为它来自珠子就降级成小字。

反过来，线中的某个事实如果只是补充背景、条件或细节，也可以放进小块。不能形成线是大字、珠子是小字的固定分工。

第三步：进行严格的骨架独立阅读测试。

大块写好后，先在内部把所有小块和旁注完全遮住，只读大块。

必须按照大块的实际显示顺序连续读，不允许在脑海中自行补入原料中有、但大块没有写出的内容。

逐屏检查：
1. 只看这些大块，是否能知道这一屏在说什么？
2. 是否能理解人物此刻的状态，而不是只看到几个情绪标签？
3. 必要的原因、条件和转折是否已经在骨架里？
4. 大块之间是否自然承接？有没有两块之间缺少关键关系，导致读者无法拼起来？
5. 连续看相邻几屏的大块，能否看出整件事的推进？
6. 是否有一块看起来重要，但实际上只是重复上一块，没有提供新的信息？

如果读者必须依赖小块才能知道人物为什么这样想、正在经历什么，说明骨架没有成立，必须重新安排大块。

如果大块只是几个抽象词、标签或没有谓语和关系的残缺表达，也必须重写。

如果大块看起来像几条独立的短标题，而不是可以拼成一段人话，也必须重写。

只有当只读大块已经能独立理解这一屏，才允许进入下一步。

第四步：骨架通过后，再补小块。

重新查看这一屏对应的全部线和珠子，判断还有哪些信息虽然不是骨架的必需部分，但如果完全不写，观众就会失去某个重要的具体体验、理解依据或情绪层次。

这些内容才可以进入小块。

小块只补充骨架拼不出来、但又必须保留的内容，主要包括：
- 一个具体的画面。
- 一个具体的身体感觉。
- 一个有辨识度的比喻。
- 一句关键的心里话。
- 一个骨架尚未交代、但对理解人物状态有必要的条件。
- 一个不能被大块替代的瞬间转折。
- 一个能够让人物经历和听者体验真正连起来的细节。

不写只是换一种说法重复大块的内容。

不写没有增加理解的装饰性描述。

不因为原料中有某颗珠子，就必须把它塞进小块。应当判断它是否其实比某个现有大块更重要，可以替换或提升为大块。

不因为某条线比较长，就把它全部塞进大块。背景、补充条件和非核心细节可以进入小块。

小块必须挂在具体的大块后面。它不是独立段落，也不是与人物故事平行的第二套叙述。

第五步：进行合读测试。

将大块和小块按照实际阅读关系连起来读一遍。

检查观众能否自然地从人物经历读到具体体验，再回到人物此刻的感受，而不会感觉在两套内容之间来回切换。

每个小块都要有明确的归属。它补充的画面、身体感觉、比喻或心里话，必须能帮助理解挂靠的大块。

如果某个小块离开其他内容后像一条孤立的听感记录，就要重新判断它是否真的有必要，或者是否应该改变它的归属和表达方式。

合读通过后，再进行最终的来源覆盖检查、字数检查和格式检查。

【三、内容来源与信息分层规则】

1. 大块和小块都不按来源分类。

线和珠子都可以进入大块，也都可以进入小块。

决定大小的唯一依据是：这一刻对观众理解整件事和感受有多重要。

禁止形成以下固定结构：人物经历永远是大字，听者感受永远是小字；线永远是骨架，珠子永远是补充。

珠子可以成为骨架的核心。线也可以成为细节补充。

2. 珠子的颗粒度必须保留。

珠子是独立的体验单位。每颗珠子可能有自己独特的画面、身体感觉、比喻、心里话或心理转折。

必须逐颗处理，不能因为几颗珠子都与某种情绪有关，就把它们合并成一句宽泛的情绪概括。

不能把具体画面压缩成抽象情绪。

不能把具体身体感觉改写成笼统的心理状态。

不能把不同的比喻合并成一个泛化的意象。

不能把有先后变化的几颗珠子压成一个静态结论。

不能为了控制字数而删除珠子中的独特信息。

可以删掉珠子中纯粹重复的铺垫、无新增信息的解释和多余连接语，但必须保留它真正独特的体验内容。

每颗珠子都必须有明确去处：大块、小块或符合条件的旁注。不得因为它难以压缩、比较细微或不是音乐描述而直接丢弃。

珠子全文中的每个原始ID，至少必须在输出中某个对象的from字段里出现一次。一个珠子包含多个不同的重要体验时，可以拆开表达，并在相应对象中重复引用同一个来源ID，但不得把不同珠子压成一条笼统的信息。

3. 线的内容也要保真。

不能只留下人物做了什么，而删掉为什么这样做、有什么顾虑、发生了什么心理变化。

不能只留下结论，而删掉让结论成立的必要条件。

不能擅自添加原料没有提供的动机、事件、关系或结果。

疑问仍然写成疑问，猜测仍然是猜测，担心不能写成已经发生的事实，可能性不能写成确定结论。

人物的愿望不能改写成已经实现的事情，人物对别人的推测不能改写成对方已经明确表达的事实。

4. 听者体验不能冒充人物实际经历。

珠子中的比喻、身体感觉和听觉联想，属于听者的体验，不等于人物在故事中真的经历了这些事。

如果把听者体验写进大块或小块，必须保留它的主观性质。

根据内容使用像……、听起来……这样的表达，或者使用不带人物主语的画面、感觉描述。

不得把听者想象的身体动作、环境画面或比喻，直接写成人物实际做过的动作或遭遇。

不得把听者的感受强行解释成人物确定的心理活动。

5. 线的重复必须去重，但珠子的独特体验不能被去重掉。

同一个事实在全曲中只完整表达一次。

后面再次出现同一个事实时，只表达它带来的新想法、新顾虑、新感受、新后果或新的理解，不要把原来的事实重新讲一遍。

如果后面没有新东西，就合并处理，不要为了填满屏幕而重复。

但如果后面出现的是一颗新的、独立的珠子，即使它与前面的体验相近，也要判断它有没有独特细节或情绪变化。不能把不同珠子仅仅因为主题相似就合并。

6. 处理局部小节限定。

某颗珠子如果明确只属于特定小节，就必须保留这个适用范围。

如果它是具体声音的局部细节，可以进入旁注，并写明bars。

如果它是只在某些小节出现的身体感觉、画面、比喻或心里话，应优先放进带有bars的小块，而不是把它改写成整屏始终成立的体验。

大块结构没有bars字段，因此不能把只适用于局部小节的体验直接写成整屏持续成立的事实。只有当原料明确支持它同时也是整屏层面的核心状态，或输入明确提供了可靠的小节到屏幕秒数对应关系、可以用at准确限制出现时，才允许将相应核心内容放进大块。

不能为了让某颗珠子成为大块，就抹掉它原本的局部适用范围。

【四、大块的文字和版面规则】

1. 每屏最多5个大块。
2. 每个大块不超过14个可见字符。
3. 每个大块只有一种字号。大块统一使用较大的字号，不允许在同一个大块内部再把某几个字放大。
4. 块内需要强调的字，只能通过accent字段改变颜色，不能改变字号。
5. accent必须是text中真实存在的连续文字。没有必要强调时填写空字符串。
6. 大块内部不能用逗号、分号、句号把几件不同的事串在一起。句末可以使用问号或感叹号。
7. 每个大块只表达一个核心判断、动作、状态、感受或必要关系。
8. 大块之间可以通过自然的语义顺序形成连贯表达，不要把一整句话全部塞进一个大块，也不要为了拆块而机械地按照原句的逗号切断。
9. 每块必须是人自然说出来的完整小意思。允许必要的主语、谓语、语气词和连接词，不能为了追求短而压成文言式省略句、电报腔或不完整的标签。
10. 不要使用心理学术语、抽象标签、概念标题或作者替人物做的分析。要写具体的人正在怎样想、怎样做、怎样感受。
11. 大块的先后顺序按照观众理解事情的自然顺序安排，不必机械遵守原料句子的先后顺序，但不得改变事实发生的真实先后关系。

【五、小块的文字和版面规则】

1. 每屏最多6个小块。
2. 每个小块不超过18个可见字符。
3. 每个小块只有一种字号。所有小块统一使用比大块更小的字号。
4. 小块挂在某一个大块后面，after填写该大块在big数组中的序号，从0开始计算。
5. 小块只补充骨架不能独立表达、但又必须保留的必要细节。
6. 小块可以来自线，也可以来自珠子。不能因为来自珠子就默认放小字。
7. 小块不能成为另一个独立叙事段落，也不能堆成一份听感清单。
8. 每个小块只承担一个主要补充作用。不要在一个小块里用多个并列信息拼成小作文。
9. 小块不使用分号。尽量避免通过标点把多个不同意思塞在同一个块里。
10. 小块不重复解释大块已经清楚表达的内容。
11. 小块的at不能早于其所挂靠的大块；如果与大块同时出现，可以使用相同的at。
12. 如果小块不受特定小节限制，bars填写空字符串。如果只适用于特定小节，bars必须填写原料中对应的小节范围。

【六、旁注区规则】

旁注位于下半屏音符动画上方的一行。对应小节出现时显示，过后淡出。

旁注不是小块的另一种形式，也不是所有珠子的默认归宿。

只有同时满足以下条件的内容才进入旁注：
- 对应具体的小节。
- 指向这一处实际听得到的具体声音、声音变化或声音表现。
- 能够让观众在听到这一处时，把文字和正在听到的声音联系起来。

每条旁注不超过30个可见字符。

每条旁注必须填写bars，不能为空。

旁注的text中不能写小节号。小节信息只能出现在bars字段。

不能把一般的心理感受、人物经历、与具体声音无关的比喻都塞进旁注。

珠子中如果包含的是体验而不是具体声音描述，通常仍然应当放进大块或小块，即使它有小节范围，也不因此自动进入旁注。

珠子重体验，不重音乐描述。不要为了把珠子变成旁注而把它们全部改写成对音乐的分析。

旁注用普通观众听得懂的语言，不写调性、声部、左右手等音乐术语，也不使用需要专业音乐知识才能理解的乐理术语。描述可直接听见的变化和感受，不写技术分析。

旁注不得重复上半屏已经表达的完整意思。它应当为正在发生的声音提供具体、短暂、准确的提示。

没有符合条件的内容时，notes使用空数组，不要为了让每屏都有旁注而制造内容。

【七、出现时间at的规则】

at表示该块在本屏开始后的第几秒出现，单位为秒。

根据{BUDGET}中的屏幕停留时间安排。

如果一屏的文字可以同时出现，at填写0。

如果大块需要按照理解顺序依次出现，可以给它们安排不同的at，让观众逐步拼出骨架。

只有确实存在理解顺序时才安排先后。并列的信息、同时成立的状态，不要为了制造动画节奏而人为安排时间差。

大块数组的顺序必须与屏幕上的阅读顺序一致。

小块的出现时间要与所挂靠的大块协调，不得在观众还没看到对应大块时先出现补充内容。

at必须是数字，表示相对本屏开始的秒数，不能超出本屏的停留时间。没有必要错开出现时间时，统一填0。

不能用at制造原料中不存在的事件顺序或心理转变。

【八、整体语言要求】

使用自然、清楚、有情绪但不矫饰的现代汉语。

要像一个人在平常说话，不像论文、心理分析、文学评论或提纲。

不要为了短而牺牲人话。

不要为了保留完整句子而让文字变成长段落。

真正的做法是把意思拆成自然的小块，保留信息密度，去掉铺垫、重复和不必要的连接语。

保留必要的语气、条件、转折和因果。不要把这些内容当作可以随意删除的虚字。

不写小节号。正文和旁注的text都不出现小节编号，小节信息只写在bars字段。

不写调性、声部、左右手等音乐术语。

不要使用长篇的音乐描述替代珠子的体验内容。

不要擅自解释音乐或人物，也不要把不确定的东西写成确定。

不要让语言为了追求精炼而变得生硬、文言化或像机器生成的标签。

【九、每屏容量与节奏】

主文字区约1370×650像素。大块约40号字，一行约30个字符。

每屏大块和小块合计，通常以约120至180个可见字符作为舒适容量参考。这个范围不是必须填满的目标，停留时间较短的屏幕应当更少。内容本身不足时，不得为了凑字数增加重复或无用信息。

大块最多5个，小块最多6个。各块的字数上限优先于总容量参考。

根据{BUDGET}中的每屏停留秒数判断观众是否来得及扫读。停留较短时优先保留最能建立骨架的信息，减少非必要补充；停留较长时也不能把屏幕写成清单。

不能通过删除大量珠子来满足容量。应该先删除铺垫、重复和没有新增信息的解释，再重新判断哪些信息进入大块、哪些进入小块、哪些属于局部旁注。

不能把一屏拆成十几条碎片。大块最多5条、小块最多6条，所有内容都必须形成有关系的阅读结构。

【十、最终内部质检：全部通过才能输出】

质检A：骨架测试。

逐屏遮住small和notes，只读big。是否能够独立理解这一屏的主要事情、人物状态和必要原因？如果不能，重写。

质检B：合读测试。

逐屏把big和small连起来读。是否仍然是同一件事？每颗小块是否挂靠正确？是否出现故事与听感分离？如果有，重写。

质检C：全曲推进测试。

连续只读这首曲子的全部big。是否能看出每首曲子的事情如何发展、人物的想法和感受如何变化？是否有重复讲述同一事实的情况？如果有，调整。

质检D：珠子覆盖测试。

逐颗核对{BEADS}。每颗珠子是否至少在big、small或notes中有对应内容？它的独特画面、身体感觉、比喻、心里话和转折是否被保留？是否把几颗不同珠子压成了一个抽象总结？如果有，补回或拆开。

质检E：线的保真测试。

核对{FINAL}。人物经历、因果、条件、疑问、猜测、担心和心理变化是否保留？是否有意思被改写、确定性被提高或事实被重复的问题？

质检F：主客体区分测试。

是否把听者的比喻、身体感觉和想象误写成人物真实经历？是否保留了听者体验的主观性质？

质检G：小节范围测试。

所有有局部小节限制的内容是否保留了准确的bars？是否有局部体验被写成整屏成立的状态？旁注是否每条都有bars？

质检H：语言测试。

是否有标签、文言腔、电报腔、残缺的句子、心理分析或不自然的省略？是否为了短而删掉了必要的关系词和语气？

质检I：容量和格式测试。

每屏大块是否不超过5个、每块不超过14字？小块是否不超过6个、每块不超过18字？旁注是否每条不超过30字？各块是否只有一种字号？accent是否只对应变色文字？after是否正确？at是否合理？所有字段是否符合最终结构？

只要任何一项不通过，就必须回到对应步骤重写，不能通过在输出后附加解释来掩盖问题。

【十一、最终输出格式：严格执行】

只输出一个合法JSON对象，不要输出Markdown代码围栏、前言、说明、质检报告或任何额外文字。

顶层只能有sections字段。

sections中按照输入顺序包含这首曲子的所有段落，不得遗漏任何一段。sec使用输入中的原始段落编号，不得自行改号或合并段落。

每段必须包含sec、big、small、notes四个字段。

big中的每个对象必须包含：
- text：大块文字。
- accent：需要变色的text内部连续文字；没有则为空字符串。
- emotion：只能从炽热、欢喜、亲密、安心、孤单、不安、悬着中选择一个最贴近的情绪。不得自创标签。
- from：来源ID数组，准确标明该块使用了哪些线或珠子的原始内容。混合来源时全部列出。
- at：本屏开始后的出现秒数，数字。

small中的每个对象必须包含：
- text：小块文字。
- after：所挂靠的大块在big数组中的序号，从0开始。
- from：准确的原始来源ID数组。
- bars：如果只适用于特定小节，填写对应范围；否则填写空字符串。
- at：本屏开始后的出现秒数，数字。

notes中的每个对象必须包含：
- text：旁注文字。
- from：准确的原始来源ID数组。
- bars：必须填写对应的小节范围，不能为空。

输出结构严格如下：

{
  "sections": [
    {
      "sec": "S01",
      "big": [
        {
          "text": "大块文字",
          "accent": "需要变色的文字",
          "emotion": "欢喜",
          "from": ["S01-1", "S01-B2"],
          "at": 0
        }
      ],
      "small": [
        {
          "text": "小块文字",
          "after": 0,
          "from": ["S01-B2"],
          "bars": "",
          "at": 0
        }
      ],
      "notes": [
        {
          "text": "具体声音的旁注",
          "from": ["S01-B2"],
          "bars": "对应的小节范围"
        }
      ]
    }
  ]
}

以上结构只是字段和格式模板，不是内容示例。实际输出必须包含所有段落，并使用真实原料ID和真实内容。

如果某段没有合适的小块或旁注，对应字段使用空数组，不得为了填充而编造内容。

所有对象只能使用规定字段，不得增加其他字段。

from必须引用真实的来源ID，不得编造来源。若原料没有明确ID，则在内部按段落和原料出现顺序建立唯一、稳定的ID，再用于from。

bars字段只写小节范围，不得把小节编号写进text。

accent必须是text中真实存在的文字，不能写颜色名称或格式指令。

emotion只能使用规定的七种值。

所有字符串必须正确转义，所有数组和对象必须合法闭合，不得出现注释、尾随逗号或JSON之外的文字。

最后再次确认：这不是把长文章缩短，也不是把线和珠子分别放大字和小字。真正要完成的是一套双层阅读结构：只读大块，骨架就能独立讲清楚；大块加小块一起读，所有具体经历和体验又能自然地串成同一件事。两者必须同时成立，且不能以牺牲任何一颗珠子的独特颗粒度为代价。
【用户补充的硬规则（写完提示词后用户又明确的，照做）】
一颗珠子里如果有几种不同的听法、不同的画面、不同层的体验，它们是不同的内容，各自都要在屏幕上有自己的块，不能只留一种；只有几乎是同一句话换个词的重复才合并。颗粒度不能变粗：具体的画面、身体感觉、比喻不能换成笼统的情绪词。
