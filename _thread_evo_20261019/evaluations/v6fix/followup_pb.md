# 一、对这次实测的判断

我的判断是：候选经历先行、重视人物自身历史的方向有价值，但这次实现存在一个必须纠正的结构性错误，而且成品暴露出系统性的语言问题。不能直接取代主线，也不应该只给现有 A2 加几条润色规则就重跑。

我倾向于保留独立构思经历的核心思路，调整 DAG 中生成与覆盖检查的先后关系，再试一次。下面先说明证据与归因，最后给出完整的改版提示词。

## 1. 实测究竟证明了什么

把两首作品、两位评委放在一起：

| 指标     | op60                 | op61              |
| ------ | -------------------- | ----------------- |
| 珠子覆盖   | 新版低 4–6 颗            | 新版高 1–5 颗         |
| 单独成立   | 新版 14/14，主线 11–12/14 | 新版 13/13，主线 11/13 |
| 重说段数   | 新版 3–4，主线 3–7        | 新版 3–6，主线 2–3     |
| 标签不符   | 新版 0，主线 2            | 新版 0–2，主线 1       |
| 逐段人话盲比 | 主线均以 13:1 胜出         | 主线以 13:0、12:1 胜出  |
| 整体盲比   | 两位均选新版               | 两位各选一个            |

这里最值得相信的，不是单次整体胜负，而是跨作品、跨评委重复出现的现象。

### 明确的进步：单独成立

这次方案确实改善了线的历史连续性。

op60 的新版，不只是依次产生亲近、快乐、不安、痛楚，而是建立了一个持续起作用的经历：先前的保留影响后来的投入，投入后的空落改变他对自己愿望的理解，长久愿望又改变了他面对未来不确定性的方式。

op61 的新版也有类似优点：先前为何要求自己镇定，后来为何怀疑这种要求，以及最后怎样改变对待自己的方式，都有可以追溯的前因。

两首作品的单独成立结果都提高到全部段落成立，而且两位评委一致。这说明 A0 的独立构思，以及对已经获得的认识和历史事实进行区分，是有效的。

这部分应该保留。

### 明确的退步：人话

这不是几个词没有润色好。

四组逐段盲比中，主线在人话上几乎全胜。新版经常把人物正在经历的事情写成对其心理机制的说明。

例如 op60：

> “以前他只是担心幸福会失去，如今他更清楚地分出了自己多么想留住它，与它实际上能否长久，是两件不同的事。”

这句话说的区别有意义，但人物不像在经历它，而像在写一份对自己的分析报告。

op61 也是：

> “他开始试着不再把毫不动摇当作值得尊重自己的条件。”

这里的问题并非“尊重”不能说，而是人物的变化被表达为一套抽象条件的修改。

因此，人话的退步是方案产生的系统性副作用，不是局部措辞问题。

### 没有得到稳定改善：覆盖、重说、标签

覆盖方面，op60 退步，op61 进步。不能说 A1 的珠子诊断已经有效提高了泛化覆盖。

重说方面，op60 没有一致的明显优势，op61 反而往往更多。这尤其值得注意：新方案本来比主线更强调不重复认识，却依然产生大量重复。

标签方面，op60 明显改善，op61 的评委意见并不一致，因此不能宣布问题已经解决。

整篇盲比也不能简单理解为新版三胜一负：op61 的 GPT-6 还明确判断替换构成实质退步，而另一位评委认为新版较好。这意味着两条路线各有不可忽略的损失。

另外，复述珠子的统计摘要和所列实例数量存在不一致，例如 op61 的一项写成 `None`，后面却列出了多处实例。我不会把这个数字当作可靠的精确计数。不过，两位评委反复指出的具体重合现象，仍然值得认真处理。

综合起来：新方案证明了自己能造出更连贯的心理历史，却没有证明自己能稳定写出更好的成品。

## 2. 问题出在哪一层

## P1_A0：加强了历史，却把人物构思得过于概念化

原提示词这段是对的：

> “已经成立的认识可以在后来继续影响他，但不能反复写成刚刚才明白。”

它直接针对线中非常重要的问题：前面经历过的事，在后面必须真实存在，不能随时重置。

`turns` 中的 `now / basis / change` 也有价值，可以检查转折是不是凭空发生。

但有两处设计造成了副作用。

第一处：

> “明确他在意的是什么、为什么在意。说到这个程度就够：可以是‘一个人’‘一段关系’‘从前的生活’这样说得出性质的对象。”

这把“人物具体”主要理解为“对象明确”，却没有充分要求人的所求和顾虑本身具体。

结果，A0 可以交出逻辑非常完整、但缺乏个人切身感的路线。比如“想恢复从容—意识到要求过苛—重新尊重自己”，逻辑清楚，却容易只剩自我分析。

主线在人话评审中领先的许多内容，不是因为它有更多外部事件，而是因为人物有直接的顾虑、舍不得、想争取的东西，以及自己不愿怎样对待别人或被别人对待。

这些具体性完全可以存在于心理经历中，不必虚构事情。

第二处是整个输出结构的使用方式：

> `now`：“这里真正新出现或改变了什么”\
> `basis`：“由此前哪一份经历产生”\
> `change`：“这以后有什么已经不能当作未知”

这适合做内部核对，却容易使下游把每段写成“变化—依据—认识”的说明文字。

处理方式：保留 A0 的历史账本，但明确它是内部构思，不是成品的表达模板。同时要求人物有切身的所求和顾虑，而不只是清楚的心理议题。

原来禁止编造外部事件、前史、对白和物件的约束不应放松。

## P1_A1：有必要的诊断思想，但放错了位置

这是本次最严重的结构问题。

现有 DAG 实际上是：

A0：不看珠子，生成三条候选经历

A1：读取珠子，提炼体验性质和历史要求

此时珠子已经影响准备写成品的材料

A2：读取 A1 的结果，写正式的线

A1 原文：

> “提供每段值得保留的几种体验性质，以及覆盖缺口需要怎样的历史条件。”

A2 随后要求：

> “覆盖诊断中的体验性质是适配要求。”

以及：

> “尽可能让同段的人物处境自然具有这些性质。”

这实际上是在让 A2 按照珠子导出的心理内容构造人物经历。

没有直接看珠子原文，不等于没有看珠子。`human_quality`、`segment_guidance.qualities`、`historical_requirements` 都是珠子衍生的信息。

因此，现有 DAG 不满足“写线的经历时不看珠子；珠子到后面结合时才进来”这一硬约束。

这不是某句提示词提醒得不够清楚，而是信息流顺序本身有问题。

而且它有可观察的后果：op60 中若干条目把珠子中的情绪升降、短促念头和回落过程，几乎同步变成了人物的心理过程；op61 也有把珠子中的反复自问、强撑和疲倦解释转成真实经历的现象。

这里需要区分两件事：

- 允许的相接：珠子表达舍不得，线里也有舍不得，而且由人物自己的处境说明为什么舍不得。这不是天然的复述错误。
- 有风险的翻译：珠子想象一种特定的心理动作或完整变化次序，线就让人物照着经历一次，尤其人物的历史中并没有独立理由产生这个动作。

开放评审中有些“复述”指控把正常的情境相近也算了进去，不应全部采纳。但后一种情况确实出现，而 A1→A2 的信息流为它创造了条件。

处理方式：A1 不能继续在写成品之前提供珠子导出的写作要求。必须改成成品已经写好之后的检查、选择和结合。

## P1_A2：直接导致解释过多、重复认识以及部分段落失去新意

A2 有三处特别需要修改。

第一处：

> “一份经历可以在后来产生不同作用，但必须交代人物此刻比上一次多经历了什么、知道了什么，或对同一件事产生了怎样不同的感受。”

用来核查因果，这句话基本正确；用来要求每条正文“交代”，就过了。

它鼓励人物不断回顾自己获得了什么认识，解释为什么这次与上次不同。于是本来可以直接写的感受，经常先被说明一遍。

应该改为：\*\*写作者内部检查有无区别，正文只写此刻真正需要读者知道的内容。\*\*没有新变化时，允许真实地延续，而不是靠解释制造变化。

第二处：

> “全图完成后，才回头概括 Center。”

这与当前迭代的边界不符。

N04 的 Center 已经确定，不属于这次迭代范围。A2 不应该自己总结出一个新 Center，再让它反过来统领线。

正确做法是把 N04 的 Center 原样传给生成层，作为固定输入；成品 `center` 原样输出，不由 A2 改写。

而且 A0 的原提示词提到“上面给定的 Center”，实际占位符却没有单独的 `{CENTER}`。若运行时的 `{WORK_INFO}` 也没有包含 N04 Center，那就连构思的共同起点都没有可靠落实。

第三处：

> “可以吸收其他候选中相容且有根据的内容。”

这允许 A2 在已经选定路线后，继续拼入其他路线的心理内容。即使每一部分单独看来都合理，合起来仍可能让人物有太多需要交代的分支。

既然 A0 已经产生了不同候选，我认为更合适的是每条候选各写成一条完整的线，最后选择，而不是先按覆盖拼合，再要求人物把它们解释圆满。

另外，原提示词写“每段通常写 2–4 条”，而标准明确要求每段 2–4 条；实际结果也有一条要点内部连写两三句的情况。这应直接按标准纠正。

## 3. 不应从开放评审照搬的修改

开放评审提出的有些具体方案，对眼前作品很有说服力，但不能原样写进通用提示词。

例如，把连续三个高潮固定为“放开—忘我—承受代价”，或者规定结尾必须有一次坚定选择，都会把这两首作品的特点变成以后所有作品的写作程式。

真正可以泛化的是：

再次经历相似感受时，要考虑此前的经历是否改变了它的意味；如果没有真实变化，就写延续，不要制造新认识。结尾按照人物实际走到的地方结束，不强行下决定，也不靠反复总结制造完成感。

这同样适用于完全不同的作品。

还需要强调：主线的人话优势值得学习，但不能把主线里缺乏依据的回应、关系进展或愿望实现照搬回来。提高具体性，应当具体在人的心愿、顾虑、感受和已有处境上，而不是给故事补事件。

# 二、下一步应该怎样改

我不建议在现有顺序上修补 A1、A2，让 A1 继续提供更谨慎的覆盖指导。那样仍然没有解决信息流的问题。

建议改成：

N04 固定 Center + N01 分段 + 独立音乐资料

P1_A0：构思三条候选经历

完全不接触珠子

C1

P1_A2

独立写完

C2

P1_A2

独立写完

C3

P1_A2

独立写完

P1_A1：此时才读取珠子

比较三条已完成的线，选择并建立珠子映射，不修改线

程序结合：原文线 + 原文珠子

按条目 ID 排列，不改写任何内容

这不是只换提示词内容，而是必须调整这三层的调用顺序。三层文件名可以保持不变。

具体接口如下。

1\. A0 运行一次，仍输出 C1、C2、C3 三条候选草图。`{WORK_INFO}` 中必须明确包含 N04 原样输出的固定 Center，不能让 A0 或 A2 自己另立 Center。

2\. A2 对每条候选分别运行一次。每次 `{CANDIDATES_JSON}` 只放对应的一条候选，保留 `candidates` 数组包装；`{COVERAGE_PLAN_JSON}` 固定传入空对象 `{}`，不能放任何珠子或珠子导出的资料。这个占位符仅为兼容现有接口保留。

3\. A1 最后运行。此时 `{CANDIDATES_JSON}` 不再是 A0 的草图，而是三份已完成的线，每份外层附上 C1、C2、C3 的 `id`。A1 才第一次得到 `{BEADS_JSON}`，用标准的四个维度比较已完成的线，并给出珠子与条目 ID 的对应。A1 可以选整条成品，不能建议把某段换成另一候选，也不能修改任何条目。

4\. 结合由程序机械完成。A1 原有的 `segment_guidance[].qualities` 和 `source_ids` 足以承载“条目 ID → 珠子 ID”的映射，无需更改输出 JSON 的字段结构。程序把珠子原文接在选中条目后面，不改写两者。如果无自然对应，应记录缺口，而不是强行挂上；如果整条线不达标，就不能冒充合格成品。

这种改法保留了原方案有效的部分：独立构思、保留人物历史、候选比较和覆盖检查。但把覆盖检查从引导写作改成了成品选择与结合。

它也有明确代价：需要写出三条完整的线，而不是只扩写一条；并且成品写完后不能用珠子做定向补救。因此，覆盖率是否足够仍是下一轮实验要验证的问题，不能预先假定三选一就一定解决。

如果 A1 判断都不合格，可以由流水线重新独立生成一批候选，但不能把 A1 从珠子得出的缺口、原因或修改建议喂回 A0/A2；否则只是把违规信息流搬到下一轮。

## 3. 为什么还要改 A0 和 A2，而不只调整顺序

单纯调整顺序可以解决珠子提前进入的问题，却不能解决实测中最明显的人话退步。

所以三个提示词都需要修改，但分工不同。

A0 负责让经历真正有人的切身内容。 具体应体现在所求、舍不得、顾虑和真实的心理前因上，不靠新增情节。保留 `turns` 历史检查，但不把它当作需要逐段完成的认知任务。

A2 负责把已经设计好的经历写成自然的成品。 不再靠复盘前因和解释认识证明连贯性；不把“前面经历过什么”写成一段又一段心理总结；每条一句，控制重说，让必要的历史在人物此刻的念头和反应里起作用。固定使用 N04 Center。

A1 负责事后诊断、选择和配对。 不提供新的角色事实、心理转折或者写作要求，严格区分真正的处境相近和照着珠子重演心理动作。

这里不增加一套新的故事阶段，也不改变四维标准。提示词只规定如何独立构思、如何自然写、如何验收和结合。

## 4. 下一轮怎样判断要不要替换主线

仍然两首同跑、同一套提示词，沿用已有的覆盖、单独读、四维开放评审和新旧全文盲比。

我尤其看三个结果：单独成立的优势能否保留；人话是否不再像这次一样被主线压倒性胜出；在不提前读取珠子的情况下，覆盖是否仍然足够，而且不会让任一首作品出现整体实质退步。

不能因为单独成立满分就接受人话严重退步，也不能因为人话变好就接受新增人物经历或改写珠子。两首作品都应按完整标准判断，不能用一首的胜出来抵消另一首的严重退步。

在下一轮证据出来前，主线保持不变。这次方案不直接上线替换。

结论：改了再试

# 三、改版提示词

下面三个文件都需要改。文件名、原有占位符和各自输出 JSON 的字段结构保持不变；改变的是调用顺序、输入内容的装配方式，以及各层的职责。

```

=====FILE: P1_A0.txt=====
任务：为一首器乐作品独立构思三条候选 Thread 经历。

Thread 是一个人在作品对应的时间进程中经历的一件事。
它最终要写成按段排列的线：只读线，不看听感记录
（珠子），也能读到一件有前因、有发展、属于这个人的事。

本阶段只构思经历，不写成品条目，不写散文。
本阶段不能看到珠子、A稿或从珠子提炼出的任何资料，
也不能猜测珠子具体写了什么。

【作品及固定 Center】
{WORK_INFO}

【段落及边界】
{SEGMENTS}

【可选：独立于珠子的作品资料】
{INDEPENDENT_MUSIC_CONTEXT}

一、固定起点

Center 来自上游 N04，已经确定。
围绕给定 Center 构思，不重新定义或替换它。

同一条候选从头到尾都是同一个人经历的同一件事。
作品段落的顺序，就是这件事在他心里经历的时间顺序。

可以依据对作品的了解、独立音乐资料或联网查到的
可靠作品信息，判断不同段落适合承载什么感受，
以及经历在时间上适合怎样展开。

但音乐里的变化不能成为人物心理变化的原因。
人物为什么这样想、为什么改变，要从他自己的处境、
愿望和此前已经经历的内容中找到根据。

不掌握精确音乐细节时，不伪称掌握。
也不以精确到小节的对应代替人物经历本身的成立。

二、构思一个真正在意事情的人

每条候选都要说清：

- 他现在实际处在什么事情里；
- 什么对他重要，他具体希望得到或保住什么；
- 他有什么顾虑，为什么不能轻易随心所欲；
- 他此前的感受或态度，会怎样影响后来的自己。

具体性主要放在人物的所求、顾虑、舍不得和感受上。
不能只给人物安排一个抽象议题，再让他逐段思考它。

也不能只说他在意某个对象，却没有交代这种在意
对他本人有什么切身意义。

不虚构具体职业、年龄、地点、物件、对白、外部事件，
或为解释人物而新增一段具体前史。

允许开头存在一个轻量、持续的基本处境。
它可以包含人物关系的基本状态和当下的心理倾向，
但不能靠后续新增事实推动故事。

不要为了让人物具体，就替他编造外部动作和他人的回应。
也不要因禁止外部情节，就把所有具体的人际顾虑、
愿望和个人感受删成抽象概念。

三、保留真正发生过的心理历史

构思时区分：

- 开头已经成立的基本事实和处境；
- 他在这首作品的进程中实际经历过的感受、犹豫和回应；
- 只是猜测、担心或希望，并没有成为事实的事情；
- 已经形成、后来可以继续起作用的认识或选择；
- 到结尾仍未得到答案的事情。

后面的感受应能从此前的经历中生长出来。

已经形成的认识不能在后面重新写成第一次发现。
但知道一件事，不等于以后不会再为它难受，
也不等于已经能够在所有时候照着它去做。

同样的愿望或顾虑可以再次出现。
再次出现时，检查此前的经历有没有改变它的意味。
如果有，记录真实的区别；如果没有，就承认它在延续。

不要把每次情绪增强都写成新认识。
不要让人物反复证明同一结论。
也不要为了制造发展，安排固定的尝试、失败、领悟、
决定或解决过程。

四、设计自然的时间进程

先想整件事，再判断每个段落实际承载什么。

重要变化要有前因。
前因可以来自很早的段落，但必须是真实成立的内容，
不能仅仅因为两段谈论同一个主题就算有因果。

不要求每段都有新变化。
一段可以是在延续先前的心情，也可以是暂时没在想
整件事，或在一种已经形成的感受中停留。

段落短、实际发生得少，就不要硬塞新的心理动作。
较长段落也不因长度较长，就必须获得某种认识。

整条经历要能一直往前读。
它可以有反复和迟疑，但不应像不断回到起点；
也不应把所有问题都整理成逐步获得解决的过程。

结尾只需写人物实际走到了哪里。
不要求外部结果，不要求彻底解决，也不预先规定
必须作出一个坚定决定。

五、三条候选的区别

独立构思三条有实质差异的候选经历。

差异应体现在人物为什么在意、在意什么、
顾虑什么，或这些经历怎样逐渐改变他。

不要只把同一条经历换一种说法。
不要故意套用三种固定的故事类型。
不要把几种不同的心理问题堆在一起，
以制造表面上的丰富。

每条候选都必须是有可能独立写成一条完整线的经历。

六、表达和内部检查

使用自然、准确的中文。

可以构思复杂的心理关系，但必须能够说明
这些感受具体属于这个人，来自他的什么经历，
又对他以后产生了什么实际影响。

不要用心理学标签、哲理概括、价值判断
代替人物自己的所求和感受。

turns 是内部历史账本，不是以后逐条写进正文的提纲。
只记录真正重要的变化。
basis 记录它在此前经历中的根据。
change 记录已经成立、以后不能重新当作未知的内容。

没有新变化的段落，应在 segment_sketch 中如实标明，

initial_facts 只列开头已成立的轻量处境和心理事实，

不要为了使路线看起来完善而隐瞒弱点。
```

```
有没有用心理分析、抽象概括、哲理总结
代替真正发生的心理内容。
有没有句式过于相似或不必要的限定、否定。

不机械禁止任何词或句式。

4. 接得上珠子

每段是否有足够的具体人物处境，
自然承载同段珠子的不同体验。
有没有把珠子的画面、比喻、想象情节
变成人物真实发生的事。
有没有为了对应而造成不自然的心理动作。

六、选择整条成品

综合四个维度，选择最适合成为最终成品的整条线。

不得只按覆盖数量排名。
也不能因为某条线结构最完整，
就忽略它在自然语言、重说或珠子相接上的
严重缺陷。

不能以局部的漂亮句子代替整件事的成立。
不能以某段特别贴珠子为理由，
接受整条经历缺乏根据的重大问题。

对于候选间的真实取舍，应说明：
哪条线整体更有前因、更自然，
哪些方面更能接珠子，
以及选择它会保留哪些缺陷。

只能选择完整的 C1、C2 或 C3。
不能把另一候选的条目搬进被选中的线。

如果三条都有重大缺陷，不能硬选一条合格成品。
可以 preferred 为空，并标记 rethink_upstream。

诊断结果只供验收记录和后续独立实验分析。
不能作为对已写成品的修改指令，
也不能作为下一次写线的珠子衍生输入。

七、给选中成品分配珠子位置

在不修改任何内容的前提下，
为选中的线建立“条目 id—珠子 id”对应。

同一颗珠子应优先放在本段自然承载其
主要体验性质的那个条目后面。

如果多个条目都能相接，选择最贴切的一条。
同一颗珠子在最终排列中只能出现一次。

一条线的条目可以接多颗珠子。
但不能因为条目与珠子处于同一段，
就自动认定它们的体验性质已经对应。

如果珠子中几种听法不能被同一个人物处境
同时容纳，不得硬把它们压成一种解释。
应区分能够相接的部分和真实缺口。

不要求把声音本身翻译为人物经历。
纯声音内容在不改变原文的情况下，
可与本段适合的条目相邻排列，
但不能虚报人物情境已经解释了它。

如果某颗珠子确实无法自然分配到本段任何条目，
记录缺口，不虚构条目或修改文字来补救。

八、在原有 JSON 结构中表示分配结果

使用 segment_guidance 中已有的 qualities 和 source_ids。

对选中线的每一段：

qualities 中的每项对应一个实际存在的条目。

quality 必须以该条目的完整 id 开头，
紧跟一个全角竖线“｜”，再简要说明
该条目为什么能承载这些珠子的体验。

source_ids 放分配给这条目的原始珠子编号。

若一条目承载多种体验性质，
可以有多个 qualities 项，但同一珠子
不能重复分配到不同条目。

没有分配珠子的条目，不必建立 qualities 项。

只记录现有条目与珠子的对应，
不能在 quality 中写新的人物经历，
也不能把这一字段当作修改正文的建议。

historical_requirements 仅记录尚未满足的
历史条件或覆盖缺口，作为事后诊断。
不能用它补造人物历史。

avoid 记录结合时必须避免的错误对应，
而不是指导重新写线。

这一映射供后续程序机械排列使用：
程序按条目 id 找到 source_ids，
将对应珠子原文放到该条目之后。
线的 text 和珠子的原始内容均不得修改。
```
