# 文章C

**1—23**

起初，他只是觉得心里有一处始终安静不下来。想到往后的日子，他会着急，觉得自己不能再这样停留，不能把全部心力都花在反复思量自己的难处上。明明还有值得去做、值得承担的事，他不愿让自己辜负它们。可每当真想把自己完全交出去，心里又会生出一种说不清的舍不得，仿佛这样一来，就有什么珍贵的东西要被留在身后。他不知道该怎样对待这份牵挂。过去确有一种盼望使他活得很真切，想起来仍能使他动心，可它如今又不能告诉他明天该怎样过。他越想弄明白自己究竟要什么，越觉得哪一种回答都不妥当。倒是想到自己还可以有所作为，心里才稍微有了着落。既然暂时想不通，他愿意先把力气用在自身以外的事情上，看看这样活下去，是否真能使自己踏实一些。

**24—65**

带着这点尚不牢靠的心意，他开始认真要求自己向外投入。起初仍有迟疑，怕自己不过是在逃避那个没有答案的问题；可当他不再时时顾着内心的纷乱，肯把心力交给眼前值得承担的事时，竟真的感到了一种久违的昂扬。他渐渐相信，人不必先把心里的所有牵挂都解释清楚，才能活得有力量。原来只要自己还肯投入，还肯承担，就不是只能被那些无法挽回、无法决定的事情困住。这样的获得使他振奋，也使他愈发珍惜眼前的可能。他开始急切地催促自己：既然向前确实能使人振作，那就更不该迟疑，更不能轻易退回去。可他越想凭坚决保住这种力量，就越不容许自己软弱；本来使他觉得自由的事情，渐渐也成了必须不断向自己证明的要求。他仍然愿意向前，只是这份昂扬里，已经悄悄混进了一些勉强。

**66—91**

然而当他不再时时检查自己够不够坚定，只是全心享受能够投入的快乐时，那份勉强竟暂时不见了。他忽然觉得，人活着原来还可以这样轻快，不必每时每刻都为自己的选择寻找理由。能够真心愿意做些什么，本身就足以使他欢喜。他甚至忘了先前为什么那么着急，觉得那些反复纠缠的问题似乎也没有那么紧要。此刻他并没有想通什么，只是高兴，毫无负担地高兴。他愿意相信往后的日子还会有许多这样的时刻，也愿意暂时不去想那些尚未得到照顾的心事。

**92—115**

可正因为这份快乐如此真实，当它稍稍过去，他反而更不能满足于先前那种靠逼迫自己维持的坚决。他已经知道向外投入并不只是责任，它确实能带来自由和喜悦；那么，为什么自己仍有一份挥之不去的缺憾？如果那是他真心愿意的生活，他又为什么总得费力说服自己？他不甘心轻易放弃已经得到的力量，便仍旧鼓起劲来，想让自己更加坚定。只是这一次，越努力向前，那种似乎亏欠了什么的感觉便越鲜明。他不再能像最初那样，把心中的不安都归于自己不够勇敢。先前暂且搁下的牵挂并没有因为他快乐过就失去分量。他开始觉得，也许自己不该只顾着向前，还得给从前那份舍不得一个交代。可究竟怎样才算没有亏欠，他依然不知道。

**116—147**

因为不愿舍掉已经找到的快乐，又不忍让过去变得无足轻重，他试着把两边都照顾周全。愿意投入眼前的事时，他提醒自己不要因此渐渐淡忘从前；想要好好珍惜过去时，他又怕自己沉溺其中，失去向前的勇气。他原以为只要足够用心，便能两边都不辜负，可后来连用心本身都变得沉重。稍有松懈，他就觉得自己不够尽责；稍有忘怀，又觉得自己对不起曾经那么真切的盼望。更令他难受的是，原本出于喜欢和珍惜的两种心意，都渐渐变成了对自己的责备。想要向外投入，先得证明自己不是在逃避过去；想要安心怀念，又得证明自己不是在逃避未来。他越来越分不清自己究竟是出于热爱，还是出于害怕亏欠，才这样费力地坚持。到后来，他已经没有多少心力继续争辩，只觉得不能再这样逼着自己了。

**148—180**

既然怎样权衡都不能让自己安心，他终于肯暂时放下那些要求，让过去所珍爱的东西完整地留在心里。这一次，他不急着问它对将来有什么用，也不急着判断自己是不是太留恋。他只是重新体会到，那份幸福确实存在过。它曾给他安慰，使他觉得自己所珍爱的值得珍爱；也曾让他感到一种不必向谁证明的满足。那并不是他因为眼前艰难，才把从前想象得如此美好。恰恰因为它曾真实地滋养过自己，他如今才仍然舍不得。

他终于可以不带愧疚地珍惜它了。过去的好并不会因为无法重来就变成虚假，也不必因为不能替他决定未来，就被迫交出自己的价值。他甚至不想再为它辩护，只觉得能够这样爱过、信过，已经是一件值得感激的事。遗憾当然还在，可这份遗憾并没有压倒他的幸福；反而使他更温柔地体会到，自己曾得到过多么珍贵的东西。他不必急着显得坚强，也不必立刻作出什么回应，只想安安静静地守着这份满足。先前费尽心力都无法平息的挣扎，此刻竟像是可以暂时不必理会了。他真希望自己能在这样的安宁里多停留一些时候。

**181—205**

可是，他越是舍不得离开这份安宁，就越害怕它只能靠回想来维持。过去的幸福并没有消失，但若往后所有的热情都投向别处，它会不会渐渐变成一段虽然珍贵、却不再真正参与自己生活的记忆？他不甘心让如此重要的东西只剩下被怀念的份儿。可一想到要为它保留更多心力，他又想起自己向外投入时得到的快乐。那种自由同样不是虚假的，他也不愿失去。

他于是重新陷入犹疑。有时他觉得，既然过去曾给予自己那么多，就该允许自己多留恋一些，不必总逼着自己往前走；可转念又怕，这份体谅会不会慢慢变成纵容，使自己只愿守着已经拥有过的幸福，不肯再为往后的生活付出。他也试着说服自己，或许可以一边行动，一边好好保存那份旧梦，但先前拼命兼顾两边的疲惫又使他不敢轻信。现在他更加舍不得仓促决定了，因为无论怎样选择，他都知道自己要失去的不是一件无足轻重的东西。想得越细，便越难心安；他仍然爱着两边，却不知道该怎样让这种爱真正成为生活。

**206—213**

这样反复思量之后，那份旧梦仍能使他温柔下来。他没有因为它带来难题，就不再为它动心。只是这一次，他在珍惜中也渐渐觉出，它能使自己明白曾经为什么幸福、为什么舍不得，却不能替自己回答以后该怎样活。它的美好没有因此减少；正因为那么美好，他才更不愿拿它去勉强回答它本来无法回答的事。他仍想多留恋片刻，心里却已知道，自己不能永远只靠这份安慰过下去。

**214—215**

想到这里，他又接近了最初那种不知如何是好的感觉。可现在，他至少知道自己为什么为难了：那份不肯割舍的眷恋是真的，向外投入所带来的快乐也是真的。他不是还没找到值得相信的东西，而是已经有了两份值得相信的东西。

**216—225**

他没有急着让自己振作。经历过先前的强求，他知道，再催促自己作出一个毫无遗憾的选择，只会重新陷入那种两边都不敢亏欠的疲惫。他愿意暂且承认，自己就是无法把两份重要的东西都照顾得妥妥当当。想到过去，仍会舍不得；想到未来，也仍有想要投入的热情。至少此刻，他不必因为一份心意还没有得到满足，就怀疑另一份心意的真诚。这样的承认并没有解决难题，却使他稍微能够体谅自己，不再急于用一次决断结束所有不安。

**226—241**

也正因为不再逼迫自己否认任何一边，他终于能够重新想起，向外投入曾怎样真切地使他快乐。过去他总怕，自己一旦全心向前，就意味着那份旧梦不再重要；可如今想来，自己能够为往后的生活动心，并不等于过去所珍爱的东西失去了价值。他曾经那样热切地盼望过、相信过，难道这份热切只能永远留在回忆里吗？他开始愿意相信，自己仍可以把同样真诚的心力交给未来，而不必把这看成对过去的背弃。

这样的念头使他重新聚拢起决心。只是现在的决心不再像起初那样轻易。他已经知道，投入并不会自动消除想念，也不可能让两边时时都得到满足。每多愿意向前一些，他就越清楚自己要让出多少原本舍不得的安宁。有时这使他害怕，几乎想退回那份无须选择的温柔里；但他也记得，一味守住温柔，会使自己错过什么。他仍然迟疑，却不再把迟疑当作应该立刻克服的软弱。他想再试着向前，这一次不是因为不肯承认代价，而是因为知道了代价，依然觉得有些事情值得自己投入。

**242—253**

终于，他能够坦然肯定自己想有所作为的愿望。他不必再急着证明自己足够坚强，也不必为了向前而故意看轻过去。他承认自己仍会留恋，也承认许多想念往后不可能时时得到周全照顾；可这并不使他想要投入的心意变得不真诚。曾经的幸福值得珍惜，眼前值得去做的事也不能因此被辜负。他不再要求自己先解决所有矛盾，才有资格作出选择。既然向外生活确实能使他感到充实而自由，他愿意再把心力交出去。这回的昂扬里仍有不舍，却少了先前那种非得压倒什么才能站稳的急切。他知道自己要什么，也知道自己不能因此得到什么；即便如此，他仍然愿意。

**254—288**

而当他真正容许自己带着这份不舍向前时，一种意想不到的快乐又渐渐充满了他。他原先一直担心，只要把热情交给未来，过去给予他的温柔便会慢慢远去；可现在，他竟发现那份温柔并不一定要靠停留在回忆里才能保存。曾经使他感到幸福的东西，已经留在他怎样热爱、怎样相信、怎样愿意付出之中。他不必时时回想过去，才能证明那份幸福仍然重要；也不必在行动时把自己的眷恋藏起来，才能显得果决。

这使他的心一下子敞亮起来。原来自己曾经得到的，并不只是一些只能舍不得的幸福，还有一种愿意真诚投入的能力。他没有重新得到过去，也仍然无法让所有期待都得到满足，可当他想到自己可以把过去给予他的好用在往后的生活里，便感到一种近乎感恩的欢欣。原先两份心意总在争夺他的全部心力，现在竟有那么一刻，他能同时为它们感到骄傲：他珍惜自己曾有过的幸福，也愿意让自己继续活得热切。他不再觉得必须站在哪一边，才能对得起另一边。这份快乐比先前单纯向外投入时更加饱满，因为他终于不需要把心里最舍不得的部分留在快乐之外。他甚至近乎相信，自己已经能够让两种渴望永远这样相伴。

可当这股欢欣渐渐平下来，他并没有忘记先前的艰难。他知道，往后的日子仍会有顾此失彼的时候。真正投入眼前的事，便不可能时时守着旧梦；而当想念深深打动自己时，也依然会舍不得离开那份安宁。它们不会因为这一刻能够共同使他快乐，就从此不再彼此牵制。

只是如今，他已不必要求自己通过否认一方来证明另一方。向外行动时，他可以承认自己仍然想念；被旧梦打动时，他也不必因此怀疑自己向前的决心。他仍会害怕自己忘得太多，也仍会怕自己留恋得太久，但他终于能够让这份害怕留在心里，而不由它决定自己是否行动。

他并没有得到一种从此毫无遗憾的生活。相反，他比起初更加清楚，每一种真心的投入，都有自己无法同时照顾周全的部分。然而也正因为他已经尝过两边真实的快乐，他不愿再轻易放弃其中任何一种。他愿意有所作为，也愿意一直珍惜那份旧梦；不再指望每一次都能使它们两全，却肯承受它们同时存在所带来的不安。

从前使他舍不得离开的，如今也使他懂得有什么值得珍惜；而他正是带着这份珍惜，仍愿把自己交给尚未到来的生活。
