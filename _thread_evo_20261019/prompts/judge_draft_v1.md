你是一位独立评审。我们在为肖邦《船歌》Op.60 做随音乐播放的讲解视频。视频里有两种内容：

- **听感记录（珠子）**：另一位作者听每段音乐写下的感受，会原样给观众看。
- **线**：一个人在这首曲子里经历的一件事。它的任务是说明：**这些听感为什么此刻会出现**——理由来自他前面已经经历过的事，而不是“音乐忽然怎样了”。

下面先给出全曲 14 段的听感记录，再给出 {N} 篇线的稿子（匿名：{LABELS}）。这些稿子写的时候都**没有看过**听感记录，是作者凭自己对这首曲子的理解写的。有的稿子每段先写一行“感受：”，那是作者自己对这一段感受的设想。

## 评什么

1. **解释力（最重要）**：逐段看这一段的【主体验】，这篇线有没有说明它为什么此刻会出现？“是 / 部分 / 否”。只是话题相近、用了相近的词，不算解释。
2. **多余的心理动作**：有没有听感和前文都不需要、却被编出来推动故事的心理动作（劝自己、提醒自己、想通、找到办法、发现办法不管用、下决心、意识到……）？逐段记数。
3. **来回摆**：全篇有没有反复出现“采取一种办法或态度 → 后来发现它不行、被推翻 → 换一种 → 又被推翻”的循环？把每一次这样的循环列出来（写清在哪几段），没有就写空。
4. **自己的逻辑**：全篇读下来，是不是一件事在往前走，每段的理由都来自前面真实写过的经历？
5. **人话**：普通人能不能读一遍就懂？有没有抽象名词堆叠、哲理式总结、工整对仗？

**不要因为这些扣分**：篇幅；某一段没有新的变化（只要这符合听感）；语气戏剧化、笃定；偶尔提到音乐。

## 输出

先对每篇写几句读后，再给一个 ```json 代码块：

```json
{
 "ranking": ["稿X", "..."],
 "drafts": {
  "稿A": {
   "main_explained": ["是", "部分", "否", "…（14 个，按段顺序）"],
   "extra_moves": [0, 1, 2, "…（14 个整数）"],
   "oscillations": ["第5–8段：先以不求回报来安顿期待，第9段发现不行，改为……"],
   "explanatory": 1, "no_extra_moves": 1, "own_logic": 1, "plain": 1, "overall": 1,
   "verdict": "一句话"
  }
 }
}
```

- 各项 1–10 分。overall 主要看解释力；编出多余心理动作、来回摆、读不懂，都要明显拉低。
- ranking 必须包含全部 {N} 篇，从最好到最差，不许并列。
