# st_n6_op60_IB_own_r1_r1

**这件事：**一个人怎样从渴望亲密、又害怕失去自己，慢慢分清亲密、自我成长和享受所得带来的不同满足，并学着让它们共同属于自己的生活，即使这些需要无法永远协调。

**走向：**他先在相互回应的亲密中发现，靠近别人时也能保有自己；后来又看见这份满足有边界，无法照顾所有愿望。成长和享受已有所得也逐渐显出各自的价值，他的烦恼随之从追求更多转向怎样安顿几种真实需要之间的冲突。最后，他尝试把成长带回亲密，也放下了要求所有需要永久融合的念头，学会珍惜已经得到的、承认尚未满足的，同时允许自己继续寻找。

### 1–3

**他想有人回应自己，又怕一靠近就把自己弄丢**
→ 于是他开始寻找一种能同时容纳亲近、被回应和保有自我的关系，但眼下还说不清该怎么做到。

### 4–16

**他终于遇到一种亲密：彼此靠近时，还能各自做自己**
← 因为（1–3）他原本同时渴望回应和自我边界，所以双方都能表达、也愿意理解彼此的关系，第一次让这几种愿望同时得到满足。
↺ 原先拿不准亲近和保有自己能否兼得，现在亲身发现，它们至少能在一段关系里暂时并存。
→ 于是这份经验让他愿意信任关系，也把问题推向下一步：这种相互回应能经得起时间和变化吗？

### 17–23

**这份幸福让他开始不放心：我们是真的懂彼此，还是刚好合拍？**
← 因为（4–16）正因为相互回应确实发生过，他才开始追问这份相应意味着什么，以及它能维持到什么程度。
← 因为（1–3）他从一开始就隐约知道，几种愿望未必能由同一个答案安顿，所以不肯让一次幸福结束所有疑问。
↺ 原先把真实回应当作信任关系的根据，现在开始分清相应发生过、彼此真正理解、关系能否持续，是几件不同的事。
→ 于是他继续保留对这段关系的信任，同时检查它成立的条件和可能的边界，为重新肯定这份亲密找到依据。

### 24–34

**他不想把曾经的亲密说成假的，也不再要求它包办人生**
← 因为（4–16）双方曾经真切回应彼此，并能保有各自的声音，这段经验有自己的价值。
← 因为（17–23）他已经发现这份亲近缺少长久成立的保证，但心里的疑问不能抹去曾经发生的满足；最初混在一起的几种愿望，也需要被分别看待。
↺ 原先担心缺少长久保证会让亲密站不住脚，现在承认它可以真实且有限，也无需成为人生的最终答案。
→ 于是既然亲密无法照顾所有愿望，他开始留意自己还有哪些需要没有被看见，并准备走出只顾确认关系的阶段。

### 35–39

**他守住了安稳，才发现自己还想把生活往外过一过**
← 因为（1–3）他最初就有好几种尚未分清的愿望，亲密得到满足后，其他需要仍然可能留在心里。
← 因为（24–34）他已经承认亲密是真实却有限的满足，因此有余地寻找它尚未照顾到的需要，而不必先否定这段关系。
↺ 原先主要想确认亲密并把它守住，现在发现亲密带来的安稳没有取消继续成长的需要。
→ 于是他开始准备主动向外发展，也必须面对变化可能扰动现有关系的担心。

### 40–50

**他想主动去做想做的事，又怕自己一变，熟悉的关系也跟着变**
← 因为（35–39）他已经认出成长是一项独立需要，也不愿为了守住安稳而压下它。
← 因为（4–16）早先相互回应的关系曾让他安心，所以一想到改变现有状态，他就担心会失去这份亲近。
↺ 原先主要用自己有没有得到回应来判断满足，现在还得考虑自己能否继续发展，以及愿意承担哪些变化。
→ 于是他继续向前尝试，也开始认真衡量成长可能带来的代价，并寻找不轻易牺牲已有亲密的办法。

### 51–61

**他确认自己确实想成长，可不愿为了向前就把亲密丢在后面**
← 因为（40–50）向外发展让他感到充实，也引出关系会不会改变的忧虑，所以他需要反复检验这份愿望。
← 因为（4–16、24–34）亲密曾经真实地满足过他，而他也已经学会承认一种满足有边界仍有价值，不能因为成长变得重要就贬低原有关系。
↺ 原先还怀疑向前的冲劲会不会只是暂时兴奋，现在确认成长经得起反复思量，同时明白它无法替亲密解决所有问题。
→ 于是他不再逼自己选边，开始寻找让亲密与成长都能保留下来的生活安排，但还没有找到让自己安心的方法。

### 62–71

**他试着停下来享受已经得到的，不再把每份充实都变成下一个目标**
← 因为（40–50）他已经实际体验过主动成长带来的充实，因此手里有值得停留和享受的所得。
← 因为（51–61、24–34、35–39）成长已经被确认是重要需要，亲密也已被确认有独立价值。他不必靠不断增加目标来证明成长的意义，也需要留意自己是否把追求新满足变成了新的惯性。
↺ 原先觉得充实主要来自继续向前，现在发现停留、充分体验并承认已有所得，也能带来满足。
→ 于是他开始分辨自己究竟还缺少重要的东西，还是不习惯承认眼前的幸福已经有价值。

### 72–77

**几种好东西都在手里了，他却发现自己还是没法安顿下来**
← 因为（1–3）最初混在一起的亲近、回应和保有自我的愿望，经过一路体验，已经逐渐显出不同的内容。
← 因为（4–16、40–50、51–61、62–71）亲密、主动成长和享受所得都已给过他真实满足；他也确认亲密与成长不能轻易互相取消。可是，三种满足分别有价值，并没有自动变成一种协调的生活。
↺ 原先把持续寻找看作还有东西没得到，现在发现即使亲密、成长和享受所得都各有价值，它们也未必能自然地放在一起。
→ 于是问题从还要得到什么，转向怎样让几种满足共同属于自己的生活。他需要面对这些需要之间的拉扯，而不能指望增加其中任何一种就让其他问题消失。

### 78–83

**他已经看清自己卡在哪儿，却还没想出能走通的办法**
← 因为（72–77）他已辨认出困难在几种满足如何共处，单纯增加满足并不能自动解决它。
← 因为（51–61、17–23、62–71）他早已知道二选一会损失一项需要，也曾从已经发生的幸福中继续追问成立的根据；学会享受已有所得后，他开始允许问题暂时悬着，不再急着用新的追求赶走不安。
↺ 原先还想靠继续分析找到足以消除冲突的答案，现在承认看清矛盾和找到解法是两步，暂时无解也可以继续生活。
→ 于是他先不靠否定某种需要来求得轻松，接下来回到亲密关系里检验它能不能容纳变化。

### 84–92

**他重新审视那段关系：它能容纳一个继续变化的我吗？**
← 因为（4–16）最初双方相互回应的亲密给过他真实的信任，所以这份关系值得重新面对。
← 因为（35–39、40–50、78–83）他已经认出成长是不能轻易压下的需要，也知道向前发展可能改变原有的关系平衡。既然暂时还找不到让所有需要协调的办法，他就得在具体关系中检验亲密能否容纳变化。
↺ 原先只要双方能自然回应，他就愿意信任这段亲密；现在还要看关系能否接纳他的成长，而不要求他停在原处。
→ 于是他不再假装这个问题不存在，但也暂时拿不到保证。亲密需要接受更严格的检验，而他仍愿意寻找它与成长共存的可能。

### 93–102

**他开始把成长带回亲密里，发现向前走也可能让关系更有内容**
← 因为（4–16、40–50）早先的亲密让他知道，靠近别人时可以保有自己的声音；后来的成长经验又让他确认，自主发展能够带来充实。这两段实际经历给了他尝试结合两种满足的基础。
← 因为（51–61、62–71、72–77、84–92）他已经确认亲密和成长都值得保留，也练习过享受已有所得，并把困难认作几种满足如何共同生活。重新审视关系后，他开始尝试让已经发生的自我变化进入亲密。
↺ 原先常担心继续成长会让亲密被甩在身后，现在发现自我展开也可能成为关系内容的一部分，主动靠近别人也仍能保有自己。
→ 于是他得到了一种实际可行的相容感，但还需要看看它在热烈退去、条件改变后能否继续成立。

### 103–110

**两种需要刚能放在一起，他就提醒自己别急着当成永久答案**
← 因为（17–23、24–34）他早已知道，一次真实的亲近无法保证关系永远成立，而缺少永久保证也不能抹去已有的价值。这次面对亲密与成长的新融合，他沿用了同样的检验标准。
← 因为（35–39、40–50、51–61、62–71、84–92、93–102）成长从最初被辨认出来，经过反复确认、实际体验，再被带回亲密，终于出现了初步的融合。现在他要重新检查，强烈的满足退去后，哪些愿望仍然重要，哪些需要已经得到回应。
↺ 原先刚看到亲密和成长能够相容，现在明白某一刻的融合无法保证以后永远协调；需要的价值也不必靠持续强烈的感觉来证明。
→ 于是他开始从兴奋和不安里分辨哪些满足已经发生、哪些愿望仍需照顾。他为最后的转变做准备：不再要求某一种幸福证明自己已经选对了全部人生。

### 111–116

**他终于不逼所有需要给出同一个答案，也能带着缺憾往下生活**
← 因为（1–3、24–34、35–39）最初混在一起、似乎需要由同一个答案安顿的愿望，如今已经逐渐分清。他也知道，亲密即使有限仍然值得珍惜，已有的安稳不能成为压低成长需要的理由。
← 因为（51–61、62–71、72–77、78–83、93–102、103–110）他确认亲密和成长各有价值，学会享受已有所得，认出几种满足之间的共存困难，也允许问题暂时没有答案。他还亲身体验过亲密与成长能够彼此容纳，并进一步明白这种相容无法保证未来永远没有冲突。
↺ 原先想靠反复确认或继续追求找到能安顿一切的答案，现在能承认不同需要同时真实、各有边界，不必由一种满足替全部愿望负责。
→ 于是他可以珍惜已经得到的，继续照顾尚未实现的愿望，也允许未来再有拉扯。他不再把彻底消除矛盾当成生活的前提，暂时停下来和继续寻找都可以成为自己的选择。
