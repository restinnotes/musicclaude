# Op.60｜关系图（在 v6 上修补，w38）

**Center：**对亲密的投入与自我克制始终相互牵制。

### S01｜1–3 小节　（还说不清）

- 他一想到这个人就柔软起来，很想亲近，也被这份突然到来的心意吓了一下。
- → 他觉得这份喜欢轻得随时可以放下，却偏偏舍不得。
- → 他怕说出心意会改变关系，眼下不用决定去向，便想让喜欢多留一会儿，靠近时收住一点。

### S02｜4–16 小节　（没在想）

- 他不再揣摩对方反应，也不索要回应，便能自在关心对方，也喜欢自己不计较。
- → 他觉得只要能这样亲近下去，眼下就已经够了，便把两个人以后的事留给以后再说。
- 他不敢认定这样的亲近会一直有，便只盼眼下这一刻慢些过去。
- 他想把心意多给一点，却想到还得顾着分寸，便还是收了回来。
  - ← 限制：（1–3）「改变关系」
- ⟲ 仍在起作用：（1–3）「改变关系」

### S03｜17–23 小节　（正在面对）

- 他已从眼前的亲近里得到满足，暂时不再惦记还要什么，心思便不必总围着对方转。
  - ← 提供理由：（4–16）「眼下已经够了」
- → 他仍盼这份亲近长久，原先不必多想的安稳因此松动。
- → 想到长久，他才发现自己能决定怎样珍惜对方，却不能决定对方是否也珍惜自己。
- → 他从前觉得自己在对方心里是否特别无需确认，如今却偶尔在意，不打算求证，亲近也因此被绊住，没法完全走神。
- ⟲ 仍在起作用：（4–16）「慢些过去」

### S04｜24–34 小节　（正在面对）

- 他知道，对方也没答应过他什么。
  - ← 说明：（17–23）「不能决定」
- → 他把心思转去替对方高兴，觉得真心盼对方好，自己也会开心。
- → 他暂时不太担心自己是否特别，觉得还有许多心意可以给，也不怕显得比对方更在乎，便放开些去喜欢。
  - ← 动摇：（17–23）「无需确认」
- → 他越放开些去喜欢，越舍不得这一刻过去，热切时又怕成了催促，只好收住一点。
- → 他甚至把这阵轻松当成保证，以为自己能尽情喜欢，也不会失去眼前的亲近。

### S05｜35–39 小节　（还说不清）

- 他发现自己尽情喜欢时的快乐，终究说明不了对方是否也珍惜这份亲近。
  - ← 动摇：（24–34）「当成保证」
- → 他难堪地想，或许盼着被珍惜，说不求回报是在骗自己，可那时关心对方、享受亲近，确实没想过换回什么。
- → 他不急着替自己辩白或用热情盖住难堪，想把亲近留住的劲头便松了些。

### S06｜40–50 小节　（没在想）

- 他不愿因自己也盼回应就否定这份喜欢，仍愿意真心关心对方，也不再假装什么都不求。
  - ← 提供理由：（35–39）「盼着被珍惜」
- → 他关心对方时把喜欢留在心里独自珍藏，不急着求回应，便暂时忘了为何还盼回应，过会儿那份期待又回来。
- → 他发现，再多对对方好，也不能证明自己什么都不求，偏偏他想被珍惜又不愿开口索取。
- ⟲ 仍在起作用：（17–23）「无需确认」

### S07｜51–61 小节　（正在面对）

- 他记得关心对方时那份细细的欢喜，便越来越常惦念对方，喜欢渐渐收不住，舍不得减轻。
- → 眼前的亲近明明还好，他不想让期待牵着自己走，便不愿开口多求一点亲近，只把喜欢留在心里。
- → 他渐渐盼对方懂他的关心，却不愿催促对方，怕给对方添负担，只能自己消化没有着落的盼望。
- 他不再以为只凭自己的热情就能留住眼前的亲近，便不再盼这一刻停下来。
  - ← 动摇：（35–39）「自己的快乐」
- ⟲ 仍在起作用：（40–50）「不愿开口索取」

### S08｜62–71 小节　（没在想）

- 他记得亲近的安心、慷慨付出的满足和独自珍藏的甜意，都不是等对方许诺才有的，便不必为未来留退路，也不再因怕受伤压住欢喜，玩心冒出来。
  - ← 改写：（24–34）「答应过他什么」
- → 他欢喜起来便给得更多，不再一笔笔算自己付出多少，也暂时顾不上盼回应的沉重。
- 他又盼对方也珍惜自己，知道眼前的亲近仍证明不了对方心意，便重新在意起来。
- 他想到眼前这一刻终究留不住，便想把这份欢喜留在心里。
- ⟲ 仍在起作用：（35–39）「自己的快乐」

### S09｜72–77 小节　（正在面对）

- 他也盼对方想靠近、把彼此放在心上，却知道喜欢再深也不能觉得对方该回应，怕盼得太紧会催到对方。
- → 他一再想收回盼望，却觉得这样是在否认刚承认的心意，委屈之余也厌烦自己反复为难。
- 他不肯因对方心意未明就轻看这段亲近，因为他确实从相处中得到过安心和满足。
  - ← 提供理由：（62–71）「亲近的安心」
- ⟲ 仍在起作用：（62–71）「重新在意」

### S10｜78–83 小节　（正在面对）

- 他不再逼自己立刻理清感情或下结论，想靠近也不急着往前，便能把喜欢温柔自然地留在心里，心里轻松些。
  - ← 改写：（72–77）「反复为难」
- → 他不把对方温柔当成更进一步的信号，也不拿回应衡量关心，仍能照常关心。
- → 他承认想被珍惜不等于催对方回应，也不必为守分寸藏起眷恋，委屈和渴望便不用再压着。
  - ← 改写：（72–77）「盼得太紧」

### S11｜84–92 小节　（正在面对）

- 他记得亲近曾使他满足，之后仍盼被特别珍惜，便敢承认渴望。
  - ← 提供理由：（17–23）「盼这份亲近」
- → 他仍真心关心，不再拿无所求证明体贴，也知对方没有回应义务。
  - ← 改写：（35–39）「盼着被珍惜」
- → 他知道深情不能替对方作决定，也可能伤己，仍带着渴望去喜欢。
- → 无新保证，他仍信真心，久疑后仍能高兴，完整接纳幸福，也被自己打动。

### S12｜93–102 小节　（没在想）

- 他不再为想被珍惜自责，便想把积攒的关心给对方，也想看看两人能过上怎样的日子。
  - ← 提供理由：（84–92）「可能伤己」
- → 他觉得许多真情都值得珍惜，便想靠近、想被爱，也想把心全交给对方，仿佛已拥有所求，满足得招架不住。
- → 他连日后与相爱无关的琐事和难处也愿和对方一起操心，因为他想过的是两个人的日子。
- → 他仍盼对方愿与他过日子，曾为此紧张难堪，暂时顾不上未来和未获回应，只想让已充分展开的幸福完整停留。
- ⟲ 仍在起作用：（72–77）「盼得太紧」

### S13｜103–110 小节　（正在面对）

- 他真想和对方共享幸福，也记得尽情投入的快乐，却知道对方未必同样珍惜，投入再深仍可能失望。
- → 他不因怀疑就否认曾经的幸福，正因真心相信、真切幸福过，忽然想到未必如愿才格外难受。
- 他把喜欢收在心里确实能暂时安心，却不能让想被珍惜的愿望消失。
  - ← 改写：（40–50）「独自珍藏」
- → 他不想把不安都交给对方，也不肯为怕落空压淡喜欢，舍不得收回曾让他幸福的投入。
- → 他不愿逼对方回应，也不肯假装自己不想被珍惜，宁可继续难受，不拿无所求换平静。
- ⟲ 仍在起作用：（78–83）「想被珍惜」

### S14｜111–116 小节　（正在面对）

- 他不再盘算该收住还是放开，也不靠克制证明清醒，因为两种做法都不能保证不受伤。
- 他想被爱、想要更多，也知对方自有心意，不必和他一样，不要求对方接住全部期待，免得亲近失去自在。
- 他回看小心靠近、慷慨付出、独自珍藏和尽情欢喜，确认它们都曾带来真切快乐，并没有白费。
  - ← 说明：（62–71）「亲近的安心」
- → 这些经历让他一次次愿意向前，也让他看清对方有多重要，明知会疼仍愿继续认真喜欢、尽情欢喜。
  - ← 提供理由：（93–102）「真情值得珍惜」
- → 对方是否选择他仍无答案，他不拿结果判真心，因为那些快乐和在意都是真的。
- → 他知道等不到对方主动靠近会疼，却不必等遗憾消失才在心里好好喜欢，也不催对方回应。
- → 他发现若总等对方主动靠近，日子便只剩猜测，不能再把心里的喜欢全押在这个答案上。
