  - [S07 第1条]「他越在乎，越盼着对方也主动靠近，光靠自己关心对方那点开心已经不够了。」——“光靠自己关心对方那点开心”结构挤得太紧。“靠”与“那点开心”的关系不清晰，读者需要自己补出“关心对方时获得的开心”。 → 他越在乎，越盼着对方也主动靠近。只是关心对方带来的那点开心，已经不够了。
  - [S07 第2条]「他想让对方懂自己的心意，又怕开口像要回应，只好把期待留在心里。」——“开口像要回应”省略得过多。“开口”是说出心意，“要回应”是向对方提出要求，两个动作直接连在一起，表达不够顺畅。 → 他想让对方懂自己的心意，又怕一说出来，就像是在催对方回应，只好把期待留在心里。
  - [S08 第3条]「他有了点玩心，更愿意主动关心对方，只管痛快地和对方相处。」——“有了点玩心”本身可以成立，也能表现心情重新轻快起来。但“痛快地和对方相处”搭配不太自然。“痛快”通常修饰较明确的行动或情绪释放，放在笼统的“相处”前面，读起来有些别扭。 → 他有了点玩心，更愿意主动关心对方，和对方待在一起时也只管开心。
  - [S09 第3条]「他不愿因为没答案就不认相处的开心，可光有这开心，他还是盼着回应。」——“不认相处的开心”不是很自然的搭配。“不认”通常用于不承认某件事实、责任或关系，这里要说的是不愿否定已经感受到的快乐，用“否认”更准确。 → 他不愿因为没有答案，就否认两人相处时的开心；可光有这份开心，他还是盼着回应。
  - [S10 第1条]「他不想再压着盼望求平静，心里想：我想被珍惜，又不是逼对方马上回应。」——“压着盼望求平静”把几个意思压缩得太紧，像是在概括心理状态，而不是日常叙述。“为了心安而压住期待”会更顺口。后面的内心独白本身自然，可以保留。 → 他不想再为了求个心安，硬把期待压下去。心里想：我想被珍惜，又不是逼对方马上回应。
  - [S10 第3条]「这样没让对方给答案，但他看清了自己到底盼的是什么。」——“这样没让对方给答案”不太自然，仿佛前面的做法本来是一种让对方给答案的办法。实际意思是他没有要求对方表态，却更清楚了自己的心愿。把这层关系直接说出来更准确。 → 他没有因此向对方要答案，却更清楚自己到底在盼什么。
- 累积（中等）：不同阶段反复使用同一组抽象词语描述亲近、关心和开心，使一些本来不同的心理变化在语言上显得相似。｜影响：这些句子单独看大多没有明显问题，而且各自承担着不同作用：S02是满足于当下，S06是经历难堪之后仍然喜欢，S08是重新轻松起来，S09是快乐之外又生出期待，S14则是在接受不确定之后继续相处。这些心理区别确实存在，并不是情节原地踏步。问题在于，表达这些区别时反复依靠“相处、关心、亲近、开心”等词，部分句子还采用非常接近的表述，如两次“他沉在……里”。连起来读，容易先感到“他又在说相处很开心”，然后才从后半句辨认这一次究竟有什么不同。音乐所对应的情绪回归本来可以有效，但语言上的回归过于接近时，各阶段的独特感受就会被削弱。｜边界：这些词都是叙述的核心词，不能因为重复就全部换掉。尤其S09的“相处还是很开心”必须保留当下的快乐，才能体现他并非因为相处不好才想得到回应；S14重申仍能亲近和关心，也有收束全文的作用。真正值得调整的是几次回到开心状态时，开头和叙述重点都过于接近，没有足够突出这一次开心与上一次的不同。｜建议：不需要增加具体事件，也不必寻找大量同义词。更有效的做法是让句子的重心跟着心理阶段变化：第一次写满足，后来写难堪没有冲淡喜欢，再后来写暂时放下期待后的轻松。比如S06第1条可改成：“那阵难堪并没让他少喜欢对方。他还是照样关心，一想到对方，心里仍然高兴。”S08第2条可改成：“跟对方待得久了，他又找回起初那份轻松：即使没有许诺，相处时也很开心。”这样保留必要的重复，却让每次返回的意义更突出。

### 5.6 第1次：8 分，6 处
- 最主要的问题：整体语言质量较好。连续读下来，人物的心理变化基本清楚，前后照应也能成立，而且大多数句子确实像普通人在用朴素的话解释自己怎么一步步走到这里，并没有普遍性的生硬、矫饰或故作文学感。真正影响阅读体验的主要不是单句错误，而是全文后半段的累积效果：同一批抽象关系词反复高密度出现，同时很多心理变化又采用“想要／又怕”“承认一边／又保留另一边”的对照句式，因此S07到S11一带偶尔会出现一种概念在原地反复调位置的感觉，细微的心理推进没有内容本身那么鲜明。其次才是少数局部搭配，如“压着盼望求平静”“不认相处的开心”“光靠自己关心对方那点开心”，会让读者短暂停一下。整体并不需要大改；如果只处理这些局部生硬处，并在少数段落里疏开抽象词和对照句式，文本会更像自然讲述，同时仍能保住现在很重要的心理区分。
- 一再出现：抽象的关系词和心理词在后半篇较密集地重复，部分段落因此显得概念化、说明感偏强。；“想要／又怕”“不想／但仍然想”等双面心理结构多次以相近句法出现，使若干阶段的节奏和语气趋同。；条目长期以“他＋心理动作”起句，和前两项叠加后产生轻微的记录式、均匀感。

  - [S04 第1条]「对方没许诺什么，但一直和他好好相处，他宁可先不追问，让对方跟他待着没压力。」——“让对方跟他待着没压力”意思能懂，但“跟他待着”和“没压力”接得有点硬，读到这里会轻微顿一下。 → 对方没许诺什么，但一直和他好好相处，他宁可先不追问，让对方跟他待在一起时没什么压力。

  - [S02 第3条]「但他一直没顾上另一份牵挂，又怕投入到最后白费，就老催自己别后退。」——“投入到最后白费”搭配有些生硬。“投入”在这里既像动作又像投入进去的东西，“到最后白费”接上去不够顺，读者会稍微停一下才能确定意思是“怕最后这一番投入白费”。 → 但他一直没顾上另一份牵挂，又怕到最后这一番投入都白费，就老催自己别后退。
  - [S04 第1条]「那种生活确实让他高兴，可他也舍不得否认行动曾帮自己走出犹豫。」——“舍不得否认”不太像日常中文里自然形成的搭配。“舍不得”通常指不忍放开、失去或停止某样东西，放在“否认”前面会让意思拐一下；这里实际要表达的是他不愿抹掉行动曾有过的作用。 → 那种生活确实让他高兴，可他也不愿否认，行动曾帮自己走出犹豫。
  - [S05 第2条]「他以前为坚定骄傲，现在这么逼自己太受苦，不想再靠坚持证明自己了。」——“这么逼自己太受苦”句法黏得较紧，口语里通常会把“这么逼自己”和“太受苦”分开说，否则“太受苦”像直接充当“逼自己”的补语，读起来略别扭。 → 他以前为自己的坚定骄傲，可现在这样逼自己实在太苦，不想再靠坚持证明自己了。
  - [S05 第3条]「不这么催自己以后，他才肯承认，自己一直舍不得那种不用防备的亲近。」——“不这么催自己以后”不够自然。“以后”通常接在一个已经成立的时间节点后，而“不这么催自己”本身像临时状态；这里更自然的是明确说“不再这么催自己之后”。 → 不再这么催自己之后，他才肯承认，自己一直舍不得那种不用防备的亲近。
  - [S06 第4条]「他不管这份向往有没有用，只管爱惜，连压着的委屈和想念也留着，舍不得离开。」——末尾“舍不得离开”的对象不够清楚。前面刚说“委屈和想念也留着”，读到这里会短暂出现两种挂接方式：是他舍不得离开这种状态，还是那些委屈和想念“舍不得离开”。句意能够推出来，但需要回读。 → 他不管这份向往有没有用，只管爱惜，连压着的委屈和想念也留着，自己也舍不得从这份向往里出来。
  - [S10 第1条]「之前用力太狠，他现在提不起劲争，可做事的痛快和那份安宁他都舍不得。」——“提不起劲争”略显生硬。“争”单独放在这里过于突然，前文一直使用的是“争取”，缩成一个“争”以后口气反而不像前后这种平常叙述。 → 之前用力太狠，他现在提不起劲再去争取，可做事的痛快和那份安宁他都舍不得。
  - [S11 第1条]「尽力曾给他力量，只是没顾好全部牵挂，心里的安宁再真实也护不住所爱。」——“顾好全部牵挂”搭配不自然。“顾好”通常接人、事情或具体对象，而“牵挂”是心理上的挂念；这里想说的其实是没有把各方面都顾全。 → 尽力曾给他力量，只是没顾全所有牵挂，心里的安宁再真实也护不住所爱。
  - [S12 第1条]「为了珍爱的生活，他认下可能的代价，不等完全不怕了，现在就去做能做的事。」——这一句有两处压缩叠在一起：“认下可能的代价”不如“接受可能的代价”自然；“不等完全不怕了”又连续使用否定，意思能懂，但口语感不够顺。 → 为了珍爱的生活，他接受可能的代价，不等到自己完全不怕，现在就去做能做的事。
  - [S13 第2条]「他做着能做的事，想到争取的就是那种能真心亲近的生活，心里又快乐起来。」——“想到争取的就是……”省掉了“自己”，使“争取的”第一眼容易被看成定语结构，读到后面才知道是“自己正在争取的东西”。补出主语后会顺很多。 → 他做着能做的事，想到自己争取的正是那种能真心亲近的生活，心里又快乐起来。
- 累积（中等）：大量条目采用相近的“他……，又/但/可/还是……，于是……”式转折结构，连续阅读时形成过于整齐的心理摆动节奏｜影响：这些句子各自都能成立，而且人物本来就在反复权衡，因此转折是必要的。问题出在它们连续出现以后，许多条目都呈现同一种“先说一股力量，再用另一股力量顶回来”的句法轮廓。人物的心理变化其实在推进，但语言层面的起伏比较单一，读久了容易产生“每一段又在重新做一次权衡”的感觉，也削弱了不同阶段本来应有的差异。｜边界：人物真正处在两难、心理发生转向时，用“又怕”“但”“可”“还是”非常自然，S07、S13 这样的关键冲突尤其需要保留。真正值得减的是那些转折关系已经由上下文十分清楚、仍然继续用同样句式完整摆出两端的地方。并不是所有转折词或两面心理都应删掉。｜建议：可以保留关键节点的正面冲突，而在部分过渡条目里换成顺承、结果或较短的落点，让不同阶段有不同的句法重心。例如 S03 第3条可改成“想到那种自在，他还是高兴。只是难处并没有消失，他也开始怀疑当初那股劲是不是真心。”；S10 第1条可改成“之前用力太狠，他现在已经提不起劲再去争取。可做事时的痛快和那份安宁，他又都舍不得。”这样心理内容不变，但连续阅读时不再每句都压进同一个转折骨架。

- 累积（中等）：“既想 A，又怕 B，因而陷入 C”的二元心理天平对峙句式密集贯穿全文｜影响：人物的内心几乎每一段都处于极其工整的“两头称重”状态。单看每一句都在精准刻画心理矛盾，但连起来读时，句式的语法节奏（想……又怕……只好……）高度同质化，人物显得一直在原地进行精密的心理算计与自我拉扯，情绪起伏被这种工整的思辨结构抹平了，缺乏呼吸感与行进感。｜边界：表现犹豫、反思与妥协时，转折与权衡结构不可或缺。但叙述不能只有“算盘式”的心理对比，在音乐推进过程中，某些段落应专注于纯粹的行动冲动、纯粹的疲倦，或者纯粹的沉浸，不需要每句话都必须把“正反两面”平衡完整地交代一遍。｜建议：打破部分句子的“对冲平衡”句式，减少成套出现的“想……又怕……”，让部分句子直接落地在动作或单向情绪上。
