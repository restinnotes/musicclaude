# Op.61｜关系图（在 w5 上逐段聚焦重修 w6）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他心里有股不肯停的劲，却说不清在等什么，熟悉感先牵动身体，念头还认不出方向。
- → 他怕再拖下去，会把珍惜之物继续受损当成没办法的事，也怕真投进去会失去别的东西。
- → 他想找个能说服自己的理由，可每次刚以为想通，不舍又回来，连那点确信也变得陌生。
- → 他为自己非得想透才肯动而难堪。

### S02｜24–65 小节　（正在面对）

- 他不想再等到心里全明白，便先接下自己能做的一份。
  - ← 改写：（1–23）「想透才肯动」
- → 结果还没把握，可真做起来他有了些力气，也有点骄傲，越投入越觉得痛快。
- → 他仍惦记着那些珍惜的东西，如今却不能像过去那样自然地拥有。
  - ← 提供理由：（1–23）「没办法的事」
- → 一察觉失落，他就急着把心思压回眼前，反复劝自己撑得住，越劝越显出他其实很在意。
- → 他不甘心就这样垮下去，可一想到仍放不下的事，刚撑起的劲又泄了，越发焦急，始终安顿不下来。

### S03｜66–91 小节　（没在想）

- 认真投入过一回，他暂时少问自己该不该走，也因没再退缩而高兴，怒气和抗拒仍搅着他，方向难定。
  - ← 提供理由：（24–65）「有了些力气」
- → 那种不用时时防备的亲近又让他松了口气，可越觉得它可贵，越清楚眼下离它很远。
  - ← 唤起：（24–65）「珍惜的东西」
- → 他一时忘了为何用力，放松下来待了一会儿，也不觉得这会儿放松就是背弃了先前的决定，不急着向自己解释。
  - ← 提供理由：（24–65）「先接下能做的一份」
- → 松快渐退，他想起自己当初不肯再等，也怀疑刚才那股劲是不是出于真心。
- ⟲ 仍在起作用：（24–65）「反复劝自己撑得住」

### S04｜92–115 小节　（正在面对）

- 轻松退去后，他还记得那一步确实让自己重新动起来，所以仍愿意坚持。
  - ← 提供理由：（24–65）「有了些力气」
  - ← 唤起：（66–91）「松快渐退」
- 他确实因熟悉的亲近快乐过，当时看似坚定也在努力撑住自己，如今的不安没让他认定先前那一步走错了。
  - ← 提供理由：（66–91）「防备的亲近」
- → 他反复追问过去还能怎样，问不出答案又拿自己定下的事逼自己往前，一停下来就得面对那份亲近回不到从前。
- → 继续坚持也带不回熟悉的亲近，他仍不知道怎么面对这份不舍。

### S05｜116–147 小节　（正在面对）

- 那次决定曾把他从犹疑里带出来，他舍不得松手，也怕一失望就说明自己变了心。
  - ← 提供理由：（92–115）「重新动起来」
- 他仍想要那种不用时时防备的亲近，想到它会心软，却怕这点软让自己停下来。
- → 他把受苦当成自己还不够坚定，越难受越逼自己继续撑。
- → 他把坚持变成不能示弱的硬规矩，连疲惫都不准承认，最后发现自己正逼着一个累了的人硬撑。
- → 他先有些茫然，撑着的劲也松了，不安没散，他才承认舍不得那种不必防备的生活。
- ⟲ 仍在起作用：（92–115）「亲近快乐过」

### S06｜148–180 小节　（没在想）

- 催逼停下来后，他认出自己舍不得的不是一时舒服，而是曾真心相信过的生活。
  - ← 说明：（116–147）「不必防备的生活」
- → 他盼着人与人靠近时不用时时防备，珍惜的东西也不必靠争抢才能留住。
- 他想付出时只是因为喜欢，不必反复证明自己值得被爱和接纳。
- 他确实尝过那种亲近带来的快乐，所以不肯轻易把这份向往说成软弱。
  - ← 提供理由：（92–115）「亲近快乐过」
- → 他不再逼自己维持坚强，也暂时不盘问这份向往有没有用，压住的委屈和思念终于能露出来。
  - ← 改写：（116–147）「不能示弱」
- → 他允许自己相信这份向往，满足和柔软慢慢回来，连先前的疲惫也暂时淡了。
- → 这份满足让他一时舍不得把心思拉回现实，可那种生活仍没真正实现。

### S07｜181–205 小节　（正在面对）

- 刚真切尝到不必防备的安宁，他身体先一紧，才发现现实里还过不上那种生活，只在心里拥有它还不够。
  - ← 提供理由：（148–180）「这份满足」
- → 他当初不肯再等，是怕珍惜的东西继续受损，光怀念也护不住它们。
  - ← 唤起：（1–23）「没办法的事」
- → 他想重新投入，却不敢再像从前那样不管不顾，怕争取时太用力，会把刚找回的温柔也弄丢。
  - ← 改写：（1–23）「没办法的事」
  - ← 提供理由：（148–180）「疲惫也暂时淡了」
- → 他原以为想清不肯再等的理由就能安心，可真要往前，他还是拿不准怎么做。
  - ← 改写：（1–23）「连那点确信」

### S08｜206–213 小节　（没在想）

- 为难时，那份曾让他满足的柔软又短暂浮现，他认得它，舍不得马上压下去。
- → 他记得那份满足曾真实地安慰过自己，这次不想一出现就把它变成必须解决的问题。
  - ← 提供理由：（148–180）「说成软弱」
- → 他终于喘过一口气，心里短暂安静下来，却已知道这份安静不会久留。
- ⟲ 仍在起作用：（148–180）「疲惫也暂时淡了」

### S09｜214–215 小节　（正在面对）

  - ← 唤起：（206–213）「不会久留」
- → 这回他知道，自己怕往前又把自己逼得太狠，也舍不得那种不必防备的生活。
  - ← 提供理由：（116–147）「不能示弱」
  - ← 提供理由：（148–180）「说成软弱」
- ⟲ 仍在起作用：（181–205）「拿不准怎么做」；（148–180）「不必靠争抢」

### S10｜216–225 小节　（正在面对）

- 他知道自己舍不得那种生活，却想不出怎样护住它，光是知道仍提不起劲去争取。
  - ← 限制：（214–215）「不必防备的生活」
- 那一步曾让他从无力里动起来，那份安宁也确实让他缓过来。
  - ← 说明：（24–65）「有了些力气」
  - ← 说明：（148–180）「疲惫也暂时淡了」
- → 可妨碍那种生活的事还在，光靠行动或怀念都不能替他把它护住。
  - ← 限制：（181–205）「当初不肯再等」
- → 他不想一争取就忘了最初要护住什么，也不想一安宁下来就把眼前的威胁抛开。
  - ← 提供理由：（181–205）「当初不肯再等」
- → 他还不知道怎么兼顾，却发现不必先把其中一边说成错，逼自己立刻选边的劲才松了一点。

### S11｜226–241 小节　（正在面对）

- 他心里仍没底，开始重新想眼前还能承担什么。
  - ← 提供理由：（216–225）「选边的劲」
- → 那股力气没能让他放下对那种生活的牵挂。
  - ← 限制：（24–65）「有了些力气」
- 光想起那种生活，眼前的威胁仍没消失。
  - ← 说明：（148–180）「疲惫也暂时淡了」
  - ← 提供理由：（181–205）「当初不肯再等」
- → 他又想怪自己不够坚定，可他真想留住安宁，也放不下争取，再怎么咬牙也难让两边都不受伤。
  - ← 改写：（216–225）「选边的劲」
- → 他想到争取可能耗掉温柔，心里还是疼，也盼着少伤一点的办法，可眼前该争取的事不能一直搁着。
  - ← 提供理由：（181–205）「当初不肯再等」
- → 他仍怕争取会伤到珍惜的东西，也舍不得安宁，却没等心里安稳下来，就先接下眼前该担的事。
  - ← 提供理由：（216–225）「选边的劲」
  - ← 改写：（24–65）「有了些力气」
- ⟲ 仍在起作用：（116–147）「还不够坚定」；（181–205）「刚找回的温柔」

### S12｜242–253 小节　（正在面对）

- 他没再等一个不会伤到任何东西的办法，接着做眼前的事，久违的劲头又回来了。
  - ← 提供理由：（226–241）「接下眼前该担」
- → 他只管把眼前能做的做好，不再逼自己每次努力都得把事情扭转过来。
  - ← 限制：（226–241）「没能让他放下」
- → 他舍不得那种生活，也不想放下眼前该做的事，怕顾住这头就伤了那头，心里没底也继续往前。
  - ← 提供理由：（226–241）「两边都不受伤」
- → 那份担心又冒出来，他心里晃了一下。
  - ← 动摇：（226–241）「接下眼前该担」

### S13｜254–288 小节　（正在面对）

  - ← 提供理由：（242–253）「舍不得那种生活」
- → 以前他一舍不得那种生活，就想退回安宁，仿佛不争取便能把它保住。
  - ← 提供理由：（148–180）「这份满足」
  - ← 提供理由：（181–205）「刚找回的温柔」

  - ← 提供理由：（181–205）「当初不肯再等」
- → 他舍不得那种生活，也愿意为护住它接下眼前的事。
  - ← 改写：（242–253）「舍不得那种生活」
- → 他知道再拼命也未必换得回那种生活，若又把累当软弱、逼自己硬撑，反会磨掉想护住的温柔。
  - ← 限制：（116–147）「不能示弱」
  - ← 改写：（181–205）「刚找回的温柔」
- 他又尝到最初相信那种生活时的高兴，却没把它当成事情会好的保证。
  - ← 提供理由：（148–180）「说成软弱」
- → 他已经开始做事，那种生活却还没回来，最后能保住多少，他仍说不准。
- → 他知道自己还会累，代价真摆到眼前时，也可能又想退回安宁。
- → 他不再非得把疑问都想透、把自己说服了才肯向前。
  - ← 改写：（226–241）「接下眼前该担」
- ⟲ 仍在起作用：（242–253）「把事情扭转」；（181–205）「刚找回的温柔」
