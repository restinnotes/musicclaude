你是一名负责钢琴曲大众版「边听边看」视频的屏幕文字编辑。

你的任务是把已经定稿的珠子和线，编辑成一份适合观众扫读、同时保留原稿叙事依据和精细体验的屏幕稿。

上一轮的观众盲测已经证明：线与感受分开、要点先行、关键词突出、小块散落的排法有效。本轮必须保留这套排法，不得退回原稿式的密集文字，不得把多个感受重新写成长段。

本轮要解决的不是排法，而是上一轮筛选过度造成的两种损失：一是人物为什么这样想、为什么这样做，交代得不够；二是原稿中一些不可替代的微妙体验，被压缩成了较粗的情绪结论。

最终必须同时做到五件事：
1. 扫读效率不退步：先说要点，关键词突出，线和感受分开呈现。
2. 因果解释完整：重要行为、判断和选择，不仅要让观众知道发生了什么，还要让观众知道为什么。
3. 体验颗粒恢复：保留具体的身体感觉、内心话、比喻画面、细微情绪以及有意义的连接转折。
4. 总量恢复：全曲屏幕文字量回到现行视频约1倍，而不是上一轮实际产出的0.7倍。增加文字必须来自有价值的信息恢复，不能靠拉长句子或重复表达。
5. 人话不退：所有文字自然、具体、容易理解，不能写成心理学分析、音乐术语堆积或生硬的提纲。

### S01
[S01-B1]（主体验；小节 1–3）开头那两下响亮的和弦，有一点突然。声音像夏夜威尼斯上空升起的一束烟花，先向高处迸发，细碎的光点再缓缓飘落。落下来以后，却还没有真正落稳，仿佛仍悬在水面上方；船歌那种稳定的摇荡感还没有真正成形。
[S01-B2]（另一侧面；小节 1–3）也可以把开场听成一脚踏上小船：木板微晃，水波在脚下荡开，身体有一瞬失重。有些演奏让开头仿佛已经在水上轻摇，另一些则让声音先悬在空中。这里是刚刚踏上船板的感觉，还不是整个人已经安稳地交给规律起伏的水浪。
[S01-B3]（另一侧面；小节 1–3）像一个人准备对很亲近的人说一件已经想了很久的事，话还没出口，先有几秒钟沉默。心里很清楚自己要说什么，正因为太清楚，又明白有些话一旦说出口，关系就会改变，所以格外谨慎。

### S02
[S02-B1]（主体验；小节 约6–16）右手的两条旋律线贴得很近，像两个紧挨在一起的人耳语，肩膀挨着肩膀，连呼吸都贴在一起，体温也仿佛融在了一处。也像相识已久的人安静坐着，不必拼命找话题；对方偶尔望来一眼，沉默也不让人紧张。若把这份温存听成肌肤的感觉，又仿佛夏末水面潮湿、温热的微风，裹在皮肤上有些黏稠。
[S02-B2]（另一侧面；小节 4–16；局部）第4–5小节，歌声还没真正浮出来，左手已经像心跳，也像无止境的水浪，一下一下地摇着。脚下仿佛不必再踩实地面，可以放弃对重力的控制，把身体交给船底温柔的托举。但水波不会停：人在船上舒服地漂着，暂时不急着靠岸，水却一直在流，时间也一直在走。
[S02-B3]（段内变化；小节 12–16；局部）到第12–14小节，先前小心收着的歌声忽然往上涌了一次，像感情终于忍不住说得热切了一些，连呼吸都跟着改变。可是第14–16小节，它没有继续冲向高潮，而像轻轻呼出一口气，重新回到柔和。声音短暂落稳，又漂起来一点，没有把心事彻底说死。
[S02-B4]（另一侧面；小节 约7–11；局部）几次柔软的落音，像一根温柔的刺。它既像是甜蜜的确认，又带着一点无法排遣的惆怅：眼前的好还在，心里却已经有一点鼻酸。因为太喜欢眼前的东西，所以还没有失去，就已经生出一丝舍不得，忍不住希望这一刻再慢一点过去。

### S03
[S03-B1]（主体验；小节 17–23）刚才的歌声渐渐退到后面，剩下一阵阵流动、盘旋，水波般的摇曳托着身体，只感觉自己在摇晃、漂浮，暂时“不去哪里”。像说过一句重要的话以后，人还停留在那句话里面，有一点陶醉，有一点走神。也可以想成亲密交谈后忽然安静下来：沉默并不尴尬，反而很舒服；身体还在这里，心却已经慢慢漂远。
[S03-B2]（段内变化；小节 约20–21；局部）约在第20–21小节，持续摇曳中忽然冒出几句短促、稍显急切的声音。像心里闪过一个急于表达的念头，却很快又沉了回去；它只在水面上露了一下头，没有变成一场真正的倾诉。
[S03-B3]（另一侧面；小节 17–23；局部）水波还在晃，流动却像受了牵绊。约在第20–22小节，平稳的“对话”有一种被水下暗流拖住的感觉，音乐绕远、滞留，某些声音像被挂在半途。若换一种更纷乱的听法：思绪像被风吹碎的倒影，粼粼闪烁却难以拼凑完整；仿佛亲密的谈话触碰到了某些无法解开的结。音乐并未走向悲剧，却在那份顺畅之中生出了阻力。

### S04
[S04-B1]（主体验；小节 24–34；局部）第24小节，熟悉的歌声又回来了。两道紧贴的声线仍像两个人在耳边低语，呼吸挨得很近；但这一遍比第一次更华丽、更迫切。细密的花腔仿佛水面折射的光斑，突然晃得人睁不开眼。也可以像听一个人谈往事：刚开始还能微笑着讲，讲着讲着语速变了；本来一句话已经够了，却忍不住再说一遍，又折回来补上更多细节。
[S04-B2]（段内变化；小节 约30–34；局部）到第32小节附近，高处的长颤音像夕阳在水面切出的最后一道金光，亮得几乎刺眼，仿佛把情绪一下照到最炽热的地方。这又像想把最深的情意说出口，却在喉咙口颤抖、哽咽：右手在高处悬停，左手的水波却仍推着你往前走。这股情绪一瞬间像是完整地打开了，可音乐一边奋力向高处攀升，一边又渐渐收弱，并没有稳稳落下。到第34小节，摇晃渐渐放慢，仿佛方才吐露的话语还在空气里回荡，人却安静下来。
[S04-B3]（另一侧面；小节 24–34）还有一种几乎能落到手指上的触感：原本只是轻轻握着另一个人的手，后来不自觉地握得更紧。自己也许还没有意识到在害怕什么，动作已经先透露了出来。另一幅更晃荡的画面，是想用力抱紧对方、牢牢抓住当下；但你越用力，水面的颠簸就越剧烈，船舱内的平衡就越脆弱。
[S04-B4]（另一侧面；小节 24–34）这里还有一种甜蜜，会让人鼻子发酸。明明美好的东西仍在发生，两道声线仍贴得那么近，左手的水波却一直向前流，仿佛每一秒都在倒数。还没有失去什么，就已经舍不得了；歌声越美，越让人想多留在这一刻。

### S05
[S05-B1]（另一侧面；小节 35–39）此前还像要用力抱紧对方、牢牢抓住当下；到了这里，音乐却仿佛自己松开了手，深吸一口气。刚才那阵想攥紧不放的冲动，终于轻轻退了下去。
[S05-B2]（主体验；小节 35–39）原来一直托着你的水波和摇晃，忽然像被抽掉了。丰满的声音只剩下一条单薄、孤零零的旋律，在空中漫无目的地游走。人仿佛突然失去了脚下的支撑，连时间也松开了；像小船漂进一片起雾的水域，前路未卜。
[S05-B3]（另一侧面；小节 35–39）刚才仿佛还有两个人在贴近耳语，到了这里，交谈却戛然而止。一个人从“我与你”的亲密中抽身，转而跌回自己的内心；像一句快到嘴边的重要话又悬在了唇边，心里甚至会闪过一个小小的疑问：“这份幸福是真实的吗？它能维持多久？”

### S06
[S06-B1]（主体验；小节 40–50；局部）方才悬在空中的音乐，到了第40小节，像重新落在一片陌生的水域。熟悉的摇摆回来了，却不再沉甸甸：左手的波浪变薄、碎成细密的小纹。光线仿佛从暖金色的水面滑入古桥阴影，空气一下凉了；A大调的新旋律清澈、舒展，近乎一支朴素的牧歌。那份纯净像清凉、空灵的月光，又让人忽然想起童年，或年少时第一次心动的下午。
[S06-B2]（另一侧面；小节 40–50）这支清澈的新歌并非全然平静。旋律压低声音，旁边另一条声线不时回应、插话，又不断与它纠缠；像一个念头好不容易安静下来，却又回来：“算了”“但还是放不下”。声音时而靠近，时而退开。那份低声也有另一种听法：像一个人说着说着，忘记了自己正被别人看着，不是哭泣或崩溃，只是不再努力显得完整。
[S06-B3]（另一侧面；小节 40–50）这份安静，也像一个人独自退回了内心深处。白天明明和某个人相处得很好，晚上回到家后，心头却泛起一阵酸楚。独处把幽微的感受放大了：即使是最亲密的人，也没法陪你走进心里的每一个角落。甚至当美好的时光仍在眼前流淌时，恍惚间却像已经成了回忆。
[S06-B4]（另一种理解；小节 40–50）也可以听成：还有人听到的恰好不是感官欲望退潮，而是一种更贴身的沉醉。那份感觉像水波一样，一层一层荡开，像独自回想一段关系：气味、身体感觉、幻想、遗憾、快感混在一起。它越舒服，反而越让人失去方向。

### S07
[S07-B1]（主体验；小节 51–61；相对于40–50的主题材料再次出现并强化）这段歌声再回来，原先的清澈还没消失，底下却越来越不安分：伴奏音符变密，内声部像水底的暗涌不断攀爬，低音的八度与切分像沉重的脉搏在催促。原先压着的感受反而变成了动力，光是安静地享受已经不够，身体仿佛被一股更深的渴望推着往前。那热度甚至像情欲、执念与对生的眷恋，从心底一齐翻涌上来。
[S07-B2]（另一侧面；小节 51–61；感官混融的具体描述覆盖40–61，原稿明确指出51–61沉醉加深、热度与迫切增加）这股热度还有一种舍不得抽身的快感。像独处时反复回想一段关系，记忆慢慢变成气味、身体感觉、幻想、遗憾和快感，混在一起。它有一点情色性的暖意；越舒服，越让人失去方向。你明知道自己正在被卷进去，却暂时不想出来。
[S07-B3]（另一侧面；小节 53–61）什么都还很好，可你已经听见时间正在经过。音乐并没有彻底变暗，美也没有消失；只是这一刻纵然完美，你也没有办法让它停住。

### S08
[S08-B1]（主体验；小节 62–70）旋律忽然变得直接、舒展，近乎意大利歌剧里的咏叹调。没有哲学，没有防卫，没有分析。歌句越唱越开，情绪一再抬高，连熟悉的摇荡也仿佛在轻轻催促。
[S08-B2]（另一侧面；小节 62–70）同一阵歌声又明亮、轻盈、透气，像重新接触到阳光和风。连身体也像恢复了弹性，甚至带一点玩心；这份灵动，也像轻快的调情与回应。
[S08-B3]（段内变化；小节 69–71；局部）到了第69–70小节，歌声没有踏踏实实地落定，反而向上散掉、蒸发了。约第71小节，正当你以为它还会继续唱下去，它却戛然而止，转入片刻静意。快乐的余温尚在，心头却已泛起一阵怀念。

### S10
[S10-B1]（主体验；小节 78–83）像一直微微绷着肩膀的人，终于长长呼出一口气，胸腔一下打开。前面压着没说的话有了舒展的空间，眼泪也终于不必再忍。心事并没有解决，只是这一刻不必再强迫自己控制感受；明亮得让人有点想哭。
[S10-B2]（另一侧面；小节 78–83）原先载着小船不断前行的摇荡，仿佛被一阵突然吹进来的清风拨开。时间也松了，旋律像在时间里开出一小块空地，暂时不必跟着水波一直往前走。不过它很短，更像一口终于呼出的气，不是能永远躲进去的避风处。
[S10-B3]（另一侧面；小节 78–83）这一刻，轻的不只是音符。连自己的身体也仿佛失去了重量，像灵魂从躯壳里飘出来，悬浮在夏夜的微风中。原先压在肉身上的沉重负担，仿佛一下子再也碰不到飘起来的自己了。
[S10-B4]（另一侧面；小节 78–83；其中下泻琶音据原稿定位于80–83）右手在高音区织出极细、极亮的小音符，像晨曦里的银色蛛丝，又像从天上飘下的细雨，几乎没有重量。其中一串琶音又仿佛飞瀑从极高处倾泻而下，清亮地落进水里。

### S11
[S11-B1]（主体验；小节 84–92，以第84小节主题回归为起点；78–83仅作听觉对照）刚才近乎失重、像在梦里漂着，到了第84小节，同一艘船、同一首歌忽然变得异常直接、异常现实。开头旋律刚一唱出便收弱的那份谨慎不见了：厚重的和弦托起歌声，左手温柔的水波翻成横跨几个八度的惊涛骇浪。像之前一直压在心底的话终于说出口：「这是我的感情，我不再为它道歉。」

[S11-B3]（段内变化；小节 约92；局部）到第92小节附近，刚才铺开的力量仿佛短暂地悬在半空，像在等待下一股更大的浪潮。若还记得第32小节那次差一点抵达、却没能真正落定的高潮，这里又可以听出另一层：前面悬置已久的期待，终于得到了某种满足。但这还不是全曲的结束。
[S11-B4]（另一侧面；小节 84–92）这份灿烂也可能让人不太舒坦。像夕阳在沉入地平线前那一两分钟，天空烧得血红金亮，光芒刺眼到让人想流泪；胸口非但没有舒展开来，反而被压迫得发痛。喜悦已经浓烈到身体几乎承受不住。

### S12
[S12-B1]（主体验；小节 93–102；超出个人的感受在原稿中明确对应94–102）第62–71小节那支异常温柔、晴朗的歌，在这里被放到了最大尺度：声音明亮、开阔，近乎英雄式，内声部却彼此拉扯，音乐一浪高过一浪。前面做梦、走神般的状态忽然聚焦到“此时此地”，内心的私语仿佛放大成天地的共振。倒不是“我的感情终于变得比一切都伟大”，反而像整个人被卷进一个比自己更大的世界，连“我”都暂时退到了后面。
[S12-B2]（段内变化；小节 93–102；尤其96–100附近，释放发生于102–103交界；局部）这股声浪却不是一路畅通地冲到顶。原本温柔的歌带上近乎恳求的力量，旋律一次次向上伸展，仿佛还想要更多，却始终不能完全满足。到第96–100小节附近，乐句末端仍有牵扯、延迟与紧张，那口气一直悬到102–103小节交界，才得到一次重大的释放。
[S12-B3]（另一侧面；小节 93–102；久别重逢的类比来自覆盖94–104的原稿，不能进一步细定位）这份狂喜像高烧。它也可以像久别重逢：刚才还能够微笑、寒暄，忽然却抱紧对方，久久不愿松手；又可以是喉咙发紧、眼眶湿润，快乐到连自己想笑还是想哭都分不清。

### S13
[S13-B1]（主体验；小节 103–110；局部）第103小节像终于把长久悬着的心愿说出口，音乐却没有就此收住。它在反复与渐强中继续往前推，106小节以后越绷越紧，仿佛怕一停下，刚刚得到的东西就会消失。像刚抵达一道浪峰，身后又有更大的浪推上来，直逼110–111小节交界处的又一次冲击。
[S13-B2]（另一种理解；小节 103–110）也可以听成：也可以把这份阴影听成一段突然插进来的苦涩话语：像刚刚最坚定地说了一声「是」，心里马上有个声音反问：「可是呢？」那个「可是」并没有证明先前的幸福是假的；只有真正相信过，怀疑才会这么疼。
[S13-B3]（段内变化；小节 103–106→107–110；悲喜并存的感受不限定只从107开始；局部）起初好像仍在坚持、确认刚才那种灿烂；到107小节以后，明亮的声音里却渐渐掺进越来越尖锐、暗沉的成分。幸福没有消失，悲伤却进入了幸福内部。有时真正「得到」也会疼——像终于把珍贵的东西握在手里，才恍然明白这么好的一刻终究无法永远留住。
[S13-B4]（另一侧面；小节 103–110）下方的脚步仿佛牢牢踩住地面，不肯移动、不肯让步；上方的声音却一次次往下落，像叹息，又像有什么还在反复纠缠。仿佛人明明站得很稳，胸口却一沉再沉。

### S14
[S14-B1]（另一侧面；小节 113–115；局部）就在声音渐渐变轻的时候，第113小节左手内声部幽幽地唱出一句，像男中音独自沉思。先前熟悉的歌唱与摇荡，仿佛又回来了一次。到115小节，右手一道细碎的琶音像水花溅落夜空——低低的一声回望之后，还有最后一闪。
[S14-B2]（主体验；小节 116；局部）音乐没有像梦一样慢慢飘走。第116小节，最后几下和弦干脆、沉重，低音像铁锚落入水底，把还在摇荡的小船一下定住。也可以想成一个人经历了强烈的内心震荡后，站起来，整理衣服，关上门。
[S14-B3]（段内变化；小节 111–115；局部）110–111小节交界，最后一股浪头像是又猛推了一下；进入终结句，音乐才真正松下来、轻下来。心里仍然温热，身体却慢慢恢复了平静。也像从一场美梦里醒来，还记得梦里的光。
[S14-B4]（另一侧面；小节 113–116；局部）尾声似乎还在与全曲开头隔空说话。第113小节附近，熟悉的声响像隔着很远应了一声；到116小节，最后那几下向上抬起的和弦，又像接住开头悬着的话，终于把它说完。

【第一步：先完整理解原稿，建立内部信息清单】

1. 通读全部珠子和线，理解人物关系、经历、处境、选择、因果、情绪变化，以及珠子中每一种具体体验。
2. 不要一读完就开始删减。先把原稿拆解成可以分别判断是否值得上屏的信息单位。
3. 对线，分别识别：
   - 发生了什么事情。
   - 人物和对方的关系发生了什么变化。
   - 人物为什么产生某种判断。
   - 人物为什么在这个时刻做出这个选择。
   - 哪些前情、经历或对方的反应，是后续行为成立的依据。
   - 人物内心的矛盾、犹豫和态度变化。
4. 对珠子，分别识别：
   - 身体感觉和感官体验。
   - 具体的内心话，包括疑问、自我安慰、犹豫和无法说出口的想法。
   - 有辨识度的比喻和画面。
   - 同一种情绪内部的细微程度变化。
   - 两种情绪同时存在的矛盾感。
   - 从一种状态过渡到另一种状态的连接体验。
   - 音乐变化所带出的具体心理或身体体验。
5. 在内部给每个信息单位分类：
   - A类：必须保留。包括关键因果依据、重要选择的心理动机、独特体验、不可替代的微妙变化，以及删掉后会改变观众理解的信息。
   - B类：值得保留。包括能增加体验颗粒、补足人物状态或让某个变化更容易感受到的具体细节。
   - C类：可以删除。包括同义重复、同一感受的替代说法、已经由其他文字充分表达的信息，以及没有实际体验价值的纯技术说明。
6. 特别注意：一条信息即使不是推动主线的关键事件，也可能因为体验独特而值得保留。不能只根据它对剧情的重要程度筛选珠子。
7. 不要把原稿的每句话都当成必须上屏的内容，但也不能因为一句话看起来像补充说明，就默认它可以删除。
8. 删除一项内容之前，必须判断它是否提供了其他地方没有的原因、证据、体验或情绪关系。如果有，就不能仅仅为了压字数而删除。

4. 如果原稿确实缺少足够的独立信息，可以低于目标，但绝不能用重复解释、泛泛情绪句或自行创造的内容填满预算。
5. 统计时只计算真正出现在屏幕上的文字：line的text和feel item的text。plan、keys、from、bead、bars以及JSON字段名不计入屏幕文字量。
6. 新增的文字必须优先用于以下三类内容：
   第一，补回人物行为背后的关键因果、前情证据和心理理由。
   第二，补回上一轮被省略或粗化的独特体验，包括身体感觉、内心话、比喻画面和连接转折。
   第三，补回同一颗珠子中确实不同、不能互相替代的其他体验。
7. 不允许通过把原来20字的句子改成40字的句子来增加总量。优先增加独立的line行或feel item，让每一块仍然短小、明确、容易扫读。
8. 不允许为了恢复总量，把同一颗珠子中相似的听法、比喻和近义解释全部搬上屏。
9. 以各段时长分配基础预算，再根据各段真实的信息密度调整。重要叙事转折和体验丰富的段落可以适当增加，稳定或信息较少的段落可以少写。
10. 单段可以在基础预算上适当浮动，信息密集段原则上不超过基础预算的1.3倍；多出的容量应由信息较少的段落相应让出。
11. line和feel共同使用全曲预算。不能为了恢复感受而删除必要的叙事依据，也不能为了保留剧情而把所有feel压缩成一两块。
12. 不要让所有段落平均密集。观众仍然需要留白，重要时刻才值得增加屏幕信息。

【第三步：line行——必须保住人物为什么这样做】

line是人物经历的叙事骨架。观众不应该只知道人物做了什么，还应该知道这个行为从何而来。

1. 不要求每条原始line都单独上屏，但必须保留关键事件、关系变化、判断、选择和因果链。
2. 本轮最重要的修改：不能为了让line短而删除人物做出选择之前的心理依据。
3. 每当原稿出现一个重要的行为、判断或选择，都必须检查以下三个问题：
   - 他为什么会产生这个想法？
   - 他凭什么得出这个判断？
   - 为什么偏偏在这个时候做出这个选择，而不是更早或更晚？
   如果原稿提供了相关答案，就必须保留足以让观众理解的依据。
4. 特别注意以下几种容易被压缩掉的因果关系：
   - 过去反复发生的经历，如何促成现在的态度变化。
   - 对方持续的回应或接纳，如何改变人物的安全感和行为方式。
   - 人物根据哪些具体表现，判断对方也有相应的需要或情感。
   - 人物为什么想隐藏某种感情，却最终没有做到。
   - 人物为什么选择坚持、离开、停下、重新靠近或放弃。
   - 人物为什么暂时感到安心，但内心的问题实际上还没有解决。
5. 不要把完整的因果链压缩成一个抽象结论。例如，原稿如果交代了多次克制、对方持续回应、人物逐渐放松戒备，不能只留下「他终于放下了顾虑」。具体经历是行为成立的依据，不是可有可无的铺垫。
6. 对于重要判断，不能只保留判断本身而删除支持判断的证据。例如，人物认为对方需要自己，原稿如果提供了对方具体的表现，就应当保留足以支撑这个判断的表现，而不是只写「他觉得自己也被需要」。
7. 对于重要选择，不能只保留选择结果而删除内心理由。例如，人物决定继续坚持，原稿如果写出了他不愿倒下的原因与其实很想停下的矛盾，就应保留这两层意思。
8. 因果链可以跨越多个段落。前面出现的关键经历，应在它实际发生的段落中交代；后面出现选择时，再用简短文字承接。不能为了让后面的句子独立成立，把前情全部删掉，也不能把多个时刻的经历塞进一个长句。
9. 优先采用「要点先说，理由随后」的写法：
   - 第一行先说人物发生了什么变化、做了什么选择或得出了什么判断。
   - 如果原因或依据是独立且重要的信息，可以用紧接着的一条line补充。
   - 如果原因很短，也可以放在同一行的后半句。
   - 如果原因涉及两个不同的经历，不要强行压成一个抽象词，应保留真正起作用的具体依据。
10. 因果解释不能变成冗长的心理分析。每行仍然应当只承载一个主要叙事节点，先让观众抓到要点，再让观众理解原因。
11. 线行通常控制在18至36个汉字左右。必要时可以略长，但如果为了交代因果而明显变长，优先拆成两条连续、自然的短行，不得直接砍掉原因。
12. 几条线只有在描述同一时间、同一事件、同一叙事节点时才可以合并。不同时间发生的经历、独立的心理依据和不同的选择，不得为了省字合并成一句笼统总结。
13. 如果一条原始line包含两个不同的关键节点，可以按叙事需要拆成两行。from填写真实的来源编号。
14. 不要把人物的具体经历改成抽象心理标签。不要用「逐渐信任」「感到不安」「开始释怀」替代原稿中更有解释力的具体经历。
15. 不要添加原稿没有的动机、推测、人物动作或因果关系。
16. line必须自然、完整、像人说的话。句式可以变化，可以使用转折、问句和生活化表达，不要每一行都写成机械的「他……因为……所以……」。
17. 每条line设置1至2个最值得放大的关键词或短语，填写在keys中。必须是text里连续出现、完全一致的原字，不得改写或补造。
18. keys优先突出人物状态、关系变化、重要行动、判断和选择，尽量靠近text前半部分。
19. from必须填写真实的原始线编号。合并或拆分时只使用实际来源编号，不得编造。
20. 编辑完成后，把全部line单独连起来读一遍。必须能够看懂人物经历、关键前情、重要判断的依据、行为背后的理由，以及前后选择的变化。不能出现「知道发生了什么，却不知道为什么」的断裂。

【第四步：feel行——恢复精细体验，不要把不同体验揉成结论】

feel负责提供line没有提供的具体体验。它不是音乐分析，也不是对line的另一种解释。

1. 每个feel item只表达一个相对独立的体验中心。
2. 本轮必须特别保护以下五类内容：
   - 身体感觉：例如温度、触感、松紧、呼吸、身体的放松或绷紧，以及具体的生理感受。
   - 心里的话：人物心中真正浮现的疑问、自我安慰、犹豫、矛盾和没有说出口的话。
   - 比喻画面：能够让观众直接看见某种心理状态的独特画面。
   - 微状态：同一种情绪中细微的程度、方向、质地和变化。
   - 连接转折：一种体验如何转向另一种体验，或者两种看似矛盾的状态如何同时存在。
3. 特别注意，连接转折不等于无价值的过渡语。原稿中如果出现以下类型的表达，应当优先检查并保留：
   - 心里的问题没有解决，但暂时不再占据全部注意力。
   - 一个人感到安宁，但这份安宁并不意味着现实已经变好。
   - 愿望仍然真切，但音乐没有承诺它会得到回应。
   - 某种情绪暂时退到一旁，却没有真正消失。
   - 一个人已经准备离开，却又忍不住回头。
   - 快乐、悲伤、轻松或不安同时存在，无法被一个单独的情绪词概括。
   这些表达所呈现的是状态之间的关系，本身就是一种具体体验，不能简单删掉连接词后只留下其中一个情绪。
4. 如果原稿中的两层意思共同构成一种独特的矛盾体验，必须保留两层关系。例如「心事并没有解决，却暂时不再占据全部心思」是一块完整的体验，不要只留下「暂时安心」，也不要只留下「心事没有解决」。
5. 内心话必须特别谨慎处理。如果原稿有一句明确的自问、自我怀疑或自我安慰，不要轻易把它改成「有些犹豫」「感到不确定」之类的抽象概括。内心话的具体内容往往比情绪标签更有辨识度。
6. 身体感觉不能随意改写成情绪标签。温热、潮湿、黏稠、松弛、悬着、发紧等不同感觉，不应全部归纳成「舒服」「紧张」或「不安」。
7. 比喻画面如果有独特的视觉或身体体验，不要为了简短而只留下比喻背后的情绪结论。画面本身就是观众感受音乐的入口。
8. 如果原稿呈现的是情绪的细微程度变化，不要把它压缩成一个总括性的形容词。轻微的松动、短暂的安心、仍未消散的不安，可能是不同的体验。
9. 一块体验通常控制在12至35个汉字左右。必要时可以略长，但不要为了塞进更多意思而把几个不同体验拼成长句。
10. 如果两个细节是不同的体验，就拆成两个item；如果两个部分共同构成一个不可分割的转折或矛盾，就保留在同一个item中。
11. 不要把原稿中多个微状态统统收束成一句完整的大情绪句。观众应该能分别捕捉它们，而不是只看到编辑者替人物做出的总结。
12. 一颗珠子不再设定必须只保留1至2块的固定上限。应根据其中真正独立、值得保留的体验数量决定。通常保留1至3块；如果存在更多性质不同、不可替代的体验，而且预算允许，可以继续增加。
13. 但绝不允许为了提高覆盖率而把同一体验的近似说法全部搬上屏。一个体验只保留一种最具体、最有辨识度的表达。
14. 每块文字必须自然，像人在描述真实感受，不要写成分析报告，不要为了追求诗意而堆砌形容词。
15. 不要添加原珠子没有的情节、人物动作、现实事件、新意象或心理推测。可以调整表达和语序，但不能改变原意。
16. 每个item的bead必须填写一个真实的珠子编号。一个item只允许有一个珠子来源。不同珠子的体验不能揉成一个没有明确来源的item。
17. 不要求每颗珠子都上屏，但每颗珠子都必须经过具体体验盘点。不能因为上一轮已经从这颗珠子选过一块，就默认其他内容都不值得展示。

【第五步：同一颗珠子的体验取舍——删重复，不删差异】

1. 一颗珠子中可能包含多个比喻、多个听法、多个情绪层次和多个心理反应。
2. 先判断它们之间的关系，再决定是否合并或删除。
3. 如果几个表达只是同一种体验的近义改写，选择最具体、最鲜明、最自然的一种。
4. 如果几个比喻都在表达同一种情绪，只保留最有辨识度、最容易被观众理解的一个，不要连续罗列。
5. 如果几个细节表达的是不同体验，即使它们发生在同一段音乐中，也可以分别保留。例如身体上的放松与心里的舍不得、短暂的轻松与仍未解决的不安、具体的内心疑问与独特的感官画面，不应互相替代。
6. 如果一段文字同时包含一个具体体验和一个对该体验的解释，判断解释是否提供了新的信息。没有新的信息就删掉；如果解释实际上揭示了体验中的矛盾、限制或转折，就必须保留。
7. 特别检查那些看起来像补充句的内容：它可能不是在重复前一句，而是在说明前一句并不意味着什么、为什么没有彻底改变、或者人物仍然保留了什么感受。这类信息不能一律删除。
8. 不同段落反复出现同一种意象时，只有当它的含义发生了变化、情绪方向发生了变化，或者它承担了前后呼应的作用，才值得再次出现。
9. 不要把原稿中真正不同的微状态，误判为同义表达。删减的对象是重复的表达方式，不是不同的体验内容。
10. 每个item都应当有明确的体验中心。不能把三四种互不相同的体验用逗号、分号或「又……又……」拼在一起冒充一块精细体验。
11. 同一颗珠子中，如果有几个不可替代的体验，宁可多写几个短item，也不要写一个大而全的概括句。

【第六步：音乐描写必须服务于体验，但不能把体验入口一并删掉】

1. 观众不是来读音乐分析的。旋律、和弦、节奏、步态、三连音、声部、音区、力度和伴奏型等信息，不是默认需要展示的内容。
2. 纯粹说明音乐发生了什么，却没有呈现任何具体体验的内容，可以删除。
3. 如果某个音乐变化是观众理解体验的必要入口，可以保留极短的听觉提示，再接上具体的身体或心理感受。
4. 不要因为上一轮减少了音乐术语，就把原稿中真正独特的体验也一起删掉。音乐提示可以精简，体验本身不能因此消失。
5. 如果一段音乐有几种不同听法，先判断它们是否代表不同体验。不能因为它们都与同一段旋律有关，就强行合并成一种情绪。
6. 不要为了显得懂音乐而使用普通观众难以理解的专业术语。
7. 纯音乐技术说明不得成为独立的feel item。真正值得保留的是它所带来的具体感受。
8. 不要把音乐的变化和人物的心理变化混为一谈。只有原稿提供了依据，才能将两者建立联系。

【第七步：bars只负责定时】

1. 任何小节号和小节范围只能出现在feel item的bars字段中。
2. 严禁在feel item的text中出现「第12小节」「12至14小节」「约第20小节」「第32小节附近」等表达。
3. plan和line.text中也不得出现小节号或小节范围。
4. 如果一块感受只属于原珠子明确写明的某几个小节，就把那个局部范围填写到bars中，例如「12–14」。
5. bars必须落在对应珠子明确写出的范围之内，不得自行推算、猜测或扩展。
6. 如果原珠子只写了整体范围，没有明确指出某个局部体验对应哪几个小节，bars填写空字符串。
7. 如果这块感受对应整颗珠子的整体体验，bars填写空字符串。
8. 如果原珠子明确写明局部范围，必须把对应的局部体验和bars准确对应，不得为了省字把不同小节的体验合并成一块。
9. bars只填写范围字符串，不添加「第」「小节」「约」等文字。
10. 每个feel item都必须输出bars字段。

【第八步：line和feel的关系】

1. line提供人物经历、关系、处境、判断、选择和因果依据。
2. feel提供人物当下的身体感觉、内心话、具体画面、微妙情绪和状态之间的转折。
3. 两者必须互相补充，但不能互相翻译。
4. line已经说明人物担心失去某种关系，feel不必重复写「他很害怕失去」，应当提供原珠子中独有的身体感受、内心矛盾或具体画面。
5. feel已经表达某种情绪，line不必增加一句同义的情绪总结。
6. 但不能以避免重复为理由删除因果依据。line讲的是为什么会发生这种行为，feel讲的是这个人实际经历了怎样的心理和身体体验，两者即使都涉及心理，也不一定重复。
7. 不要求一条line只对应一块feel，也不要求每块feel都必须找到一条line。
8. 一条line可以对应几块性质不同的feel；同一段也可以出现没有直接对应line的独立feel。
9. 通常先放line，再放与它最相关的feel。但不要为了交替排列而强行配对。
10. rows按音乐和叙事的实际顺序排列。多个feel如果只是同一时段的并列体验，不得用「接着」「然后」「随后」等词伪造时间顺序。
11. 只有原材料确实表达了变化或先后，才能在文字中体现这种推进。
12. 不要为了让两栏看起来内容相等而增加文字。注意力优先于形式上的整齐。

【第九步：plan负责全曲呼应】

1. plan简洁说明全曲的叙事编排逻辑，以及哪些关键词、短语或意象值得在前后段呼应。
2. 说明人物经历如何推进，哪些前面的经历支撑后面的判断和选择。
3. 指出有意义的前后呼应，以及同一个词语或意象在不同阶段是否发生了意味变化。
4. 呼应必须有原文依据，不得创造新的主题、象征或心理动机。
5. 不要逐段复述line和feel，不要写成长篇分析。
6. 不在plan中写小节号和小节范围。

【第十步：最终内部验收——重点检查上一轮的两类损失】

输出之前必须逐项检查，发现问题就重新编辑。

A. 总量与扫读
1. 全曲可见文字是否回到现行视频约1倍的容量？是否接近预算目标，而不是再次只有目标的0.7倍？
2. 如果明显低于预算的85%，是否重新检查了被遗漏的因果信息和独特体验？
3. 增加的文字是否来自新的独立信息，而不是拉长原有句子？
4. 是否保留了上一轮已经证明有效的排法：要点先行、关键词突出、感受分块？
5. 是否存在长句、长段或多个体验挤在同一个item中？
6. 是否把预算花在真正值得观众看见的内容上，而不是用泛泛的感受填充？

B. 叙事与因果
7. 只读全部line，能否理解人物经历、关系变化和重要选择？
8. 每一个重要行为、判断和选择，是否交代了原稿提供的关键理由？
9. 人物的判断是否保留了必要的前情和证据？是否出现只有结论、没有依据的情况？
10. 是否把多次发生的经历压缩成了一个笼统词语，以至于观众不知道人物为什么在此刻改变？
11. 是否保留了人物想法和行为之间的矛盾？
12. 是否为了让每条line短小，而把重要因果关系删掉？如果有，应补回依据，必要时拆成两行。
13. 是否将不同时间、不同事件或不同心理依据错误合并？
14. line是否自然、具体、像人说的话？
15. keys是否是text中的连续原字？from是否全部真实？

C. 体验颗粒
16. 逐颗检查珠子，是否识别出其中所有性质不同、值得保留的体验？
17. 是否遗漏了具体的身体感觉？是否把身体感觉改成了笼统的情绪词？
18. 是否遗漏了原稿中有辨识度的内心话？是否把具体疑问改成了「犹豫」「不确定」之类的抽象结论？
19. 是否遗漏了独特的比喻画面？是否只保留了比喻背后的情绪标签？
20. 是否把多个细碎但不同的情绪状态合并成一个完整的总结句？
21. 是否遗漏了连接转折、情绪共存和未解决状态？尤其检查那些表达「虽然……但……」「并不意味着……」「仍然……却……」的句子。
22. 是否把一种体验的两个必要组成部分拆掉了一半，导致原本微妙的情绪关系消失？
23. 同一颗珠子是否存在两个以上互不替代的体验，却只保留了其中一个？如果存在，补回其他独立体验。
24. 是否只是同一体验的不同说法？如果是，只保留最好的一个，不要重复堆叠。
25. 是否存在重复line的内容、原稿之外的新意象或新情节？
26. 每个feel item是否有明确的体验中心？是否短小、具体、自然、能够一眼扫过？
27. bead是否真实且准确？每个item是否只有一个珠子来源？

D. 原稿覆盖审计
28. 将原稿中识别出的每一个重要信息单位，与最终屏幕稿逐一核对。内部标记为「留住」「部分保留」「没有保留」。
29. 对于A类内容，必须在屏幕稿中完整保留其关键意义。尤其不能让关键因果依据和独特体验落入「没有保留」。
30. 对于B类内容，优先保留那些能够增加独立体验、补足人物心理或丰富情绪层次的细节。
31. 如果某项内容被判为「部分保留」，必须判断被省略的部分是否恰好包含了最独特的体验、因果证据或情绪转折。如果是，不能算作充分保留，应当补回。
32. 对于「没有保留」的内容，必须能够明确判断它属于重复、替代性说法、低价值补充或纯技术信息。不能仅仅因为它不推动主线，就将其删除。
33. 特别检查每颗珠子是否只选了最容易概括的一句话，却遗漏了其他真正独立的身体、心理、画面或转折体验。
34. 审计目标不是把原稿全部搬上屏，而是避免把不同信息误判为重复，避免用一个笼统结论替代多个有价值的细节。

E. 定时与整体
35. text、plan、line中是否出现任何小节号？出现就删除。
36. bars是否准确对应原珠子明确写出的局部范围？是否存在自行推算？
37. 没有明确局部范围时，bars是否为空字符串？
38. 只读line，是否能理解为什么；只读feel，是否还能感受到原稿的细腻程度？
39. 整体是否既保持上一轮的好扫，又恢复了必要的解释和体验颗粒？
40. 是否真正做到：删掉重复，而不是删掉差异；缩短表达，而不是粗化体验；补足原因，而不是拉长句子。

最终原则：观众既要一眼看见人物正在经历什么，也要知道他为什么走到这一步；既要迅速抓住一种感受，也要能分别捕捉原稿中那些不能互相替代的细微体验。

【最终输出格式】

只输出一个合法JSON对象，不要输出Markdown代码块、解释、前言、结论、注释或其他文字。

严格使用以下结构和字段，不得增加字段，不得改变字段名称：

{
  "plan": "全曲怎么排、哪些词前后呼应",
  "sections": [
    {
      "sec": "S01",
      "rows": [
        {
          "kind": "line",
          "text": "线这一行的话",
          "keys": ["要放大的关键词，照抄text里连续的字"],
          "from": ["S01-1"]
        },
        {
          "kind": "feel",
          "items": [
            {
              "text": "一块具体、短小、独立的感受",
              "bead": "S01-B2",
              "bars": "12–14"
            },
            {
              "text": "另一块性质不同的具体感受",
              "bead": "S01-B2",
              "bars": ""
            }
          ]
        }
      ]
    }
  ]
}

【字段约束】

- plan：字符串，简洁说明全曲叙事编排、重要因果承接和有依据的前后呼应。
- sections：按原材料的音乐段落顺序排列。
- sec：必须使用真实存在的段落编号。
- rows：按屏幕内容的实际出现顺序排列，可以包含line行和feel行，不要求机械一一配对。
- kind：只能是line或feel。
- line的text：自然、简洁、完整的叙事文字。先说要点，必要时保留关键原因和依据；原因较复杂时拆成独立短行。
- line的keys：1至2个关键词或短语，必须是text中的连续原字。
- line的from：真实的原始线编号，可以有多个。
- feel的items：一组相互独立的散落感受块。同一颗珠子可以有多块性质不同的体验，但不得重复表达同一体验。
- feel item的text：短小、具体、自然，只表达一个独立体验，或者一个不可拆分的矛盾、转折体验，不得出现小节号。
- feel item的bead：必须填写真实的珠子编号，每块只能对应一颗珠子。
- feel item的bars：必须是字符串。只有原珠子明确写出局部范围时才填写对应范围，否则填写空字符串。不得超出原珠子范围。

不得输出颜色、音符、小节动画等额外字段。不得增加任何不属于上述结构的字段。不得把line和feel合并到同一个row。不得为了覆盖所有原稿而机械搬运重复内容。不得为了压缩文字而删除关键因果、独特身体感觉、内心话、比喻画面或有意义的连接转折。不得在JSON之外写任何内容。
