# Op.61｜线与珠子对接（时间线）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

每段按小节排：**线**（他此刻怎样、为什么）和 珠子（此刻听到、感到什么）交错出现。线条目下的 ⇢ 是配给它的珠子：呈现 = 可感形态；对照 = 感受不同但同时成立。最后列出没配上线的珠子（照样保留）。

### 1–23　（还说不清）

- **〔1–6〕起初他连自己在等什么都说不清，只知道心里有股劲，不肯就此算了。**
  - ⇢ 呈现｜B1.1·主体验·意象（1–6）开头那一下沉重、郑重的和弦：它像要宣告什么。
  - ⇢ 呈现｜B1.3·主体验·意象（1–6）一次召唤，只是停顿里仿佛还等着回声。
  - ⇢ 呈现｜B2.3·另一侧面·心理（1–23）这是一种尚未找到对象、也尚未找到语言的失落。
  - ⇢ 呈现｜B3.1·另一侧面·意象（1–23）像刚从漫长的昏沉中醒来。
- **〔1–8〕任由事情照旧，仿佛就是承认它们本该如此；真投进去，又怕会丢下什么。**
  - ⇢ 呈现｜B1.2·主体验·意象（1–6）紧接着的自由上行琶音却没把这份重量接住，反而像烟雾往高处散，声音轻了、远了，悬在半空。
  - ⇢ 呈现｜B2.2·另一侧面·心理（1–23）心里明明有东西，却还分不清这份不平静究竟是愤怒、遗憾还是怀念
  - ⇢ 呈现｜B3.2·另一侧面·身体（1–23）四周冷而空，胸口有些发紧，视线还模糊着。
  - ⇢ 对照｜B5.1·另一侧面·意象（1–23）开头那下有分量的和弦，像一个人强迫自己挺直背脊，提醒自己不能倒下。
  - ⇢ 呈现｜B5.2·另一侧面·心理（1–23）可自由琶音马上把这份郑重带回内心的游移。
  - ⇢ 呈现｜B5.3·另一侧面·心理（1–23）尊严还在，行动的方向和力气却不稳——“我不能倒下，以及我其实很想停下来。”
- **〔8–15〕他于是寻找一个够有力的理由，盼着自己终于不再犹豫。**
  - ⇢ 对照｜B2.1·另一侧面·意象（1–23）短句像叹息，刚冒出来就被长停顿截断；听着余音在冰冷的空气里慢慢散尽。
  - ⇢ 对照｜B3.3·另一侧面·意象（1–23）伸出颤抖的手去摸，摸到的却只有虚空。
- **〔9–23〕每次快信自己想通了，舍不得又冒出来，确信也变陌生；他开始难堪：非得理清一切才肯走吗？**
  - ⇢ 对照｜B3.4·另一侧面·心理（1–23）这里不是已经哭出来的悲伤，而是连自己身在何处都还没弄清的恍惚。
  - ⇢ 呈现｜B4.1·段内变化·意象（9–17）旋律轮廓稍稍清楚，像一幕旧场景忽然回来：当时的声音、光线和某种熟悉的感觉都回来了。
  - ⇢ 对照｜B4.2·段内变化·心理（9–17）可记忆再清晰，过去也不会因此重新变成现在。
  - ⇢ 呈现｜B4.3·段内变化·意象（18–23）波兰舞曲的步态逐渐浮现，像身体先于意识，隐约记起了该如何迈步。
  - ⇢ 呈现｜B4.4·段内变化·声音（18–23）这只是往前的牵引，还不是第24小节起的主题已经站稳。

### 24–65　（正在面对）

  - ⇢ 呈现｜B4.2·另一侧面·意象（24–65）像一个人整理好衣服、抬起头，不让别人看见动摇。
- **〔31–38〕没有保证，牵挂也没消失；可一行动，他便感到有力量。从前总问值不值，如今只说愿尽力。**
  - ⇢ 呈现｜B1.1·主体验·意象（24–65）波兰舞曲的步态终于清楚了，却不像英雄凯旋。

  - ⇢ 对照｜B2.1·另一侧面·意象（24–65）它不是士兵的步伐，更像腿脚虚浮的人，在记忆中挪动舞步。
  - ⇢ 对照｜B2.3·另一侧面·意象（24–65）底下的伴奏还有细碎、不安的半音在蠕动。
- **〔39–43〕这让他有些骄傲：心里仍有疑虑，也可以不让疑虑替自己做主。**
  - ⇢ 呈现｜B3.1·段内变化·声音（38–43）38–43小节，音乐猛地往上推，却又退下来。
  - ⇢ 对照｜B2.2·另一侧面·声音（24–65）节奏本身庄严、傲慢，旋律却脆弱凄婉。
- **〔44–51〕越投入越热切，付出的过程本身就让他快乐，仿佛心里的不满终于有了去处。**
  - ⇢ 对照｜B3.2·段内变化·声音（44–65）44–65小节再次聚拢力量，52–63小节一带更焦灼，最后仍没有舒舒服服地落地。
- **〔52–60〕他愿意给得更多，也贪恋倾尽全力的畅快，不再时时审视自己或为一点软弱停步。**
  - ⇢ 呈现｜B3.3·段内变化·意象（56–65）56–65小节连绵的三连音，仿佛把呼吸催得越来越急。
  - ⇢ 对照｜B4.3·另一侧面·意象（44–65）到44–65小节，它又像反复对自己说“我没事”。
  - ⇢ 对照｜B4.4·另一侧面·心理（44–65）第一次还有几分相信，第二次开始努力让自己相信。
  - ⇢ 对照｜B5.1·另一侧面·意象（44–65）44–65小节的激昂像一句“我不甘心就这样消亡”。
  - ⇢ 对照｜B5.2·另一侧面·心理（44–65）不是轻松恢复自信，而是负隅顽抗。
  - ⇢ 对照｜B5.3·另一侧面·心理（44–65）这股力量可以与自我控制同时存在，但不必把两种原稿的说法拼成同一个人的确定剧情。
- **〔61–65〕可用力深处，仍有一小块心没跟着高昂；它没拦住他，却提醒他还有牵挂未被照顾。**
  - ⇢ 呈现｜B1.3·主体验·意象（24–65）舞曲带着一点面向众人的庄严，歌声却像私人记忆里的低声哼唱。
  - ⇢ 呈现｜B1.4·主体验·心理（24–65）那些珍惜的东西仿佛还在，却已不能像从前那样拥有。
  - ⇢ 呈现｜B4.5·另一侧面·心理（44–65）说到第三次，连这句话本身都暴露出其实很在意。
  - ⇢ 呈现｜B4.6·另一侧面·心理（24–65）悲伤还在，只是不愿把自己完全交给悲伤。

  - ⇢ 呈现｜B1.3·主体验·意象（66–91）音乐离开前面的端正步态，转入更灵活、流动却不安的舞蹈性格。

  - ⇢ 对照｜B3.1·另一侧面·意象（66–91）像多个人在耳边低声絮语，彼此缠绕，找不到出口。
