# Op.61｜关系图

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### 1–23　（还说不清）

- 起初他不知道自己究竟在等什么，心里却有股不肯就此算了的劲。
- → 他仿佛觉得，任由一些事继续下去，就像亲手承认它们本来就该如此。
- 真要把自己投进去时，他又怕会丢下什么；他试着找个不再犹豫的理由，却总有另一份舍不得浮上来。
- → 他有时以为自己想通，转眼又被舍不得拉回；最令他难堪的是摇摆，甚至怀疑非得想好一切才肯向前。

### 24–65　（正在面对）

- 他渐渐受不了再拿“还没想清楚”当作等候理由，先认下自己能做的那一份。
  - ← 改写：（1–23）「摇摆让他难堪」
- → 没有保证，心里的牵挂也没消失；过去他反复问值不值得，如今至少愿意尽力。
- → 他为这种变化感到骄傲，发现自己仍可有疑虑，却不让疑虑支配行动。　✦ 分清
- → 投入的过程本身使他快乐，好像心里那些不满终于有了去处。
- → 他舍得给出更多，甚至有点贪恋倾尽全力时的畅快。
- → 他不再需要时时审视自己，也不想为一点软弱就停下来。
- → 可用力到深处，他仍感到心里有一小块没有跟着昂扬；他知道决心没照顾到所有牵挂。　✦ 满足照出未满足

### 66–91　（没在想）

- 这点隐约的不安还没逼他停下；认真投入过，反而让他能从反复自问里松开一点。
  - ← 提供理由：（24–65）「贪恋全力投入」
- → 他发现自己不只感到沉重和责任，也会因不再畏缩而高兴，在向前的热情里感到轻盈。
- → 偶尔忘了自己为何用力，他觉得那不算背叛；那像久违的自由，他顺着这份自由走了一程。
- → 快乐没那么满时，先前作过的决定仍在等他。
- ⟲ 仍在起作用：（24–65）「心里仍有牵挂」

### 92–115　（正在面对）

- 他仍愿坚持原来的决定，因为它曾把他从动弹不得的犹豫里带出来；他不愿因心里有缺口就说此前全错。
- → 可曾让他昂头的坚定，此时已不能让他安心。
- → 他想确认自己仍有力量，却发现心里另有要求无法靠力量满足；他不愿接受这个答案，却不能装作不知。　✦ 知道更多反而更尖锐
- ⟲ 仍在起作用：（66–91）「决定仍在等他」

### 116–147　（正在面对）

- 明知行动还不够，他仍不肯撒手；他怕此刻的失望意味着自己变了心，因为行动曾救他脱离犹疑。
  - ← 限制：（92–115）「力量满足不了」
- → 因而他更用力催逼自己，把心里的难处当作能克服的迟疑；想停一停，又怕那就是退缩。
- → 他不知道除了继续坚持，还能怎样对得起最初的决定。
- → 原先使他昂扬的要求慢慢变成苛责，因为它连他的脆弱也容不下，他像在勉强疲惫的自己。　✦ 办法的限度
- → 他终于不想再证明自己有多坚强了。
- → 暂时放下催逼没让他安心，却让压住的依恋回来；他仿佛承认，自己还舍不得必须做的事以外的东西。
- ⟲ 仍在起作用：（92–115）「坚持原来决定」

### 148–180　（正在面对）

- 他想要人与人不用时时防备，珍惜的东西不用争抢，也不必反复证明自己值得被爱。
  - ← 唤起：（116–147）「依恋重新回来」
- → 他盼付出出于喜欢而非责任，靠近别人时也不用先做好受伤的准备。
- → 这份盼望不是临时为逃避编出的安慰；它曾给他快乐，让他感到人与生活可以亲近。
- → 他终于肯只管去爱、去相信，不急着问能否得到或比较轻重；这份满足让他仿佛又能柔软地活着。

### 181–205　（正在面对）

- 这份安宁如此真实，他渐渐不能只在心里拥有它；他想知道阻碍那种生活的事情如何改变。
  - ← 提供理由：（148–180）「允许自己柔软」
- → 他懊恼自己刚沉浸在满足里就忘了必须面对的事，试着重新催自己振作。
- → 可他已充分尝过温柔的可贵，再想到艰难争取，就怕这份温柔会一点点耗尽。
- → 他怕最后只剩不肯退让的意志，却失去原本让一切值得争取的心。
- → 他舍不得那份安宁，想到它受威胁又放不下；理由更多了，向前和停留都让他不安。
- ⟲ 仍在起作用：（1–23）「任由事情如此」

### 206–213　（没在想）

- 它曾给他深深满足，他不必每次想起都立刻责问自己；明知不能久留，他仍愿再爱惜片刻。
  - ← 改写：（181–205）「懊恼忘了要面对」
- ⟲ 仍在起作用：（148–180）「允许自己柔软」

### 214–215　（正在面对）

- 安静退去后，迟疑又回来，仿佛走远仍回原处；他如今知道，迟疑里也有对旧愿的珍惜。
  - ← 改写：（206–213）「再爱惜片刻」

### 216–225　（正在面对）

- 他知道自己舍不得什么，却没立刻勇敢起来；只靠决心向前和沉浸旧愿都不再够用。　✦ 办法的限度
  - ← 限制：（214–215）「迟疑里有珍惜」
- → 他一时没力气要求自己大变，只盼争取时记得为何争取，爱惜安宁时也别躲开威胁它的事。
- → 他还不知道怎样做到，只反复想着这点微弱心愿，非得舍弃一边才能继续的逼迫似乎轻了些。
- ⟲ 仍在起作用：（1–23）「任由事情如此」；（148–180）「允许自己柔软」

### 226–241　（正在面对）

- 他凭着那点尚不牢靠的心意，重新想自己还能怎么办。
  - ← 唤起：（216–225）「两种办法都不够」
- → 两样收获都是真的，他不愿再简单否定其中任何一个。
- → 可要它们都完好留下，恐怕不可能；争取那份安宁，也可能失去安宁。　✦ 选择的代价
- → 过去他会为这种难受责怪自己，如今渐渐承认，是因为自己珍视的东西不止一种。　✦ 分清
- → 他仍心疼将要付出的东西，也盼有条轻松些的路，却知道再等也不会让它自己出现。
- → 若只因怕珍贵之物受损就不再争取，它们也未必能留下。
- → 他不再要求自己先毫不害怕；可以舍不得、没把握、受苦，也愿带着这些往前。　✦ 分清
- → 他一点点聚起力量，不为压倒犹豫，而愿连同不舍往前；惧怕还在，却不再替他决定。
- ⟲ 仍在起作用：（148–180）「允许自己柔软」；（181–205）「不只心里拥有」

### 242–253　（正在面对）

- 他不再等一个毫无损失的办法，久违的昂扬回来了，也不必靠否认脆弱来维持。
  - ← 提供理由：（226–241）「惧怕不替他决定」
- → 他知道自己要做什么，也知道舍不得什么；那些害怕与珍惜不必藏起，反而让他愿为所爱之物尽力。
- → 这次决心仍热烈，却不再要证明自己无所不能；他愿带着犹疑行动，不必等它消失。　✦ 分清
  - ← 改写：（226–241）「惧怕不替他决定」
- ⟲ 仍在起作用：（226–241）「珍惜的不止一种」

### 254–288　（正在面对）

- 当他带着全部牵挂重新向前，意外发现旧愿没有因此变远，仿佛反而更亲近了。
  - ← 改写：（242–253）「不等犹疑消失」
- → 过去他想撤回来保住旧愿，如今却不愿让阻碍它的事继续，温柔也能催他行动。　✦ 分清
  - ← 提供理由：（148–180）「无需防备相处」
- → 若不是仍向往那种生活，他何必如此尽力；若在争取中丢了向往，即使坚强又得到什么？
  - ← 提供理由：（148–180）「无需防备相处」
- → 他仍想过不用拼命也能好好活的日子，却愿承认，为珍惜它有时不能停在它给予的安宁里。　✦ 分清
- → 他知道尽力不保证更接近旧梦，美好愿望也不能让每份付出都值得；他得留心别丢掉所爱。
  - ← 限制：（226–241）「两边难以无损」
- → 这些顾虑不只使他退缩，也提醒他该以怎样的心继续争取。
  - ← 改写：（226–241）「惧怕不替他决定」
- → 两种心意如今能一起支持他；历经怀疑疲惫，他重尝久违的快乐，不再羞于依恋或厌倦责任。
  - ← 改写：（242–253）「不等犹疑消失」
- → 喜悦平静后，他知道答案仍未到来；他没回到无需防备的生活，尽力也未必改变什么。
- → 往后他仍会疲惫，也可能因付出的损失动摇；两种渴望同行，仍可能彼此牵制。
- → 他不再拿满足遮住别的需要，也不因未满足否定所得；过去的快乐、失望、疲惫和依恋仍属于他。　✦ 分清
  - ← 改写：（24–65）「心里仍有牵挂」
- → 这些经历让他知道什么值得付出，什么不能轻易牺牲。
- → 他仍向往安宁，也仍愿行动；不知能留下多少，仍不忘任何一边，带着不舍继续，不再需要更多证明。
- ⟲ 仍在起作用：（226–241）「两边难以无损」；（148–180）「无需防备相处」；（226–241）「珍惜的不止一种」；（148–180）「允许自己柔软」；（242–253）「不等犹疑消失」
