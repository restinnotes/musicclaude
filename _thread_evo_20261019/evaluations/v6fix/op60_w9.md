# Op.60｜关系图（在 w8 上逐段聚焦重修 w9）

**Center：**对亲密的投入与自我克制始终相互牵制。

### S01｜1–3 小节　（还说不清）

- 他一想到这个人就柔软起来，很想亲近，连自己都没料到心意来得这么快。
- → 他舍不得退开，喜欢来得轻，似乎随时能放下，又怕太显在意会让相处拘谨，靠近时仍有说不清的犹豫。
- → 他还没摸准怎样靠近才自在，眼下也没有非得作决定的事。

### S02｜4–16 小节　（没在想）

- 他先不急着想两人以后会怎样，只想先享受眼前的亲近。
  - ← 提供理由：（1–3）「怎样靠近才自在」
- 他挺喜欢自己能真心对对方好，不求回应。
- → 那时他真觉得，只要能这样自然地亲近对方，眼下已经够了。
- 他没把握以后还能一直这样亲近。
- 他想把心意多给一点，最后还是留了余地。
- ⟲ 仍在起作用：（1–3）「说不清的犹豫」

### S03｜17–23 小节　（正在面对）

- 安静下来后，他仍沉浸在刚才的亲近里，心思飘远，暂时不急着去哪里。
  - ← 提供理由：（4–16）「不求回应」
- → 正因为眼前的亲近已经让他满足，他开始盼它能长久。
  - ← 改写：（4–16）「眼下已经够了」
  - ← 提供理由：（4–16）「没把握以后」
- → 想到长久，他才发现自己能决定怎样珍惜对方，却不能决定对方是否也珍惜自己。
- → 他还没打算向对方索取答复，只是偶尔想知道自己在对方心里是不是特别。
- → 这念头一冒出来，原先顺畅的亲近就被绊住，他仍陶醉，却没法完全走神。

### S04｜24–34 小节　（正在面对）

- 他怕追着要回应会搅坏眼前的亲近，对方也没答应过他什么。
  - ← 提供理由：（4–16）「眼下已经够了」
  - ← 提供理由：（17–23）「被绊住」
- → 他把心思转去替对方高兴，提醒自己，真心盼对方好这件事本身就让他开心。
- → 想确认自己是否特别的紧张暂时退了，他不再计较给了多少，也不怕显得更在乎，觉得自己还有许多心意可给。
- → 他放开些去喜欢，反倒更舍不得这一刻过去，又怕给对方压力，热情便收了回来。
- → 他还是把这阵轻松当成保证，以为只要不向对方要回应，就能尽情喜欢，也不会失去眼前的亲近。

### S05｜35–39 小节　（还说不清）

- 欢喜稍退，他又想知道对方是否也把他放在心上，自己的快乐终究说明不了对方的心意。
  - ← 失效：（24–34）「不会失去」
- → 他难堪地想，自己对对方好时或许也盼着被珍惜，再说自己什么都不求，就是骗自己。
- → 可他关心对方、享受亲近时确实很快乐，那时并没想着要换回什么。
  - ← 说明：（24–34）「替对方高兴」
- → 他也不敢认定亲近会一直如此，不急着替自己辩白或用热情盖住难堪，想把亲近留住的劲头便松了些。

### S06｜40–50 小节　（没在想）

- 难堪没让他少喜欢，可再多给一点，也证明不了自己什么都不求。
  - ← 提供理由：（35–39）「盼着被珍惜」
  - ← 说明：（35–39）「换回什么」
- → 他仍盼被珍惜，也把心思放回眼前愿意做的关心，不再反复查验对方心意。
  - ← 提供理由：（35–39）「换回什么」
- → 关心对方时，他觉得喜欢本身就很甜，暂时忘了自己为什么那么在意回应，可那念头过一会儿又会回来。
- → 留在心里的甜是真的，可对方是否也珍惜他，他仍无从确定，甜里也有一点酸楚。
- ⟲ 仍在起作用：（17–23）「不能决定」

### S07｜51–61 小节　（正在面对）

- 他觉得这份喜欢值得留着，不舍得收淡，于是越来越常惦念对方，喜欢渐渐不是想收就能收住的。
  - ← 提供理由：（40–50）「那么在意回应」
- → 眼前的亲近明明还好，他却不能决定它能留多久，已经有点怕它留不住。
  - ← 提供理由：（40–50）「留在心里的甜」
- 他还是想把喜欢留在心里。
- → 他越来越盼对方能懂自己的关心，可还是觉得不该催对方，只好自己消化这份期待。
  - ← 限制：（24–34）「搅坏眼前的亲近」

### S08｜62–71 小节　（没在想）

- 安心靠近、真心给予、独自惦念的甜，都不是等对方许诺才有，他不想再因怕受伤压住欢喜。
  - ← 说明：（4–16）「不求回应」
  - ← 说明：（24–34）「心意可给」
  - ← 说明：（40–50）「留在心里的甜」
  - ← 提供理由：（51–61）「不舍得收淡」
- → 他不再压着想亲近的心，任自己高兴，连玩心也冒出来，给得多了也不再一笔笔算。
- → 他明知对方没给保证，却高兴得一时顾不上那份沉重，也不急着替未来留退路。
  - ← 说明：（35–39）「放在心上」
- → 欢喜还没散，他已经舍不得它结束，想被对方同样珍惜的愿望也跟着冒出来。
  - ← 唤起：（51–61）「消化这份期待」

### S09｜72–77 小节　（正在面对）

- 欢喜稍落，他才承认自己不只想把喜欢给出去，也觉得眼前的亲近很好，还盼对方主动靠近、把他放在心上。
  - ← 提供理由：（62–71）「舍不得它结束」
- → 他不敢因为自己真心就认定对方该回应，继续盼下去又怕是在催对方。
- → 他两边都舍不得，也想不出怎么才能两边都顾上，越想越委屈，也厌倦了反复这样为难自己。

### S10｜78–83 小节　（正在面对）

- 他不再逼自己马上选边，也不急着认定这份感情该怎么走。
  - ← 提供理由：（72–77）「怕是在催对方」
- → 他让眷恋先留在心里，照样顾着分寸，不急着付诸行动。
  - ← 提供理由：（72–77）「两边都舍不得」
- → 他终于能喘口气，委屈和渴望松了些，身上也松了劲，原本绷紧的温柔又能自然地留在心里，他还摸不准对方心意。

### S11｜84–92 小节　（正在面对）

- 他不再逼自己压下渴望或立刻决定去留，熟悉的亲近之乐又回来，犹疑这么久还能高兴，竟让他感动。
  - ← 提供理由：（78–83）「自然地留在心里」
- → 他曾因想被珍惜而怀疑自己的关心是不是交换，如今能承认自己也想被珍惜，仍是真心关心对方。
  - ← 改写：（35–39）「盼着被珍惜」
  - ← 说明：（35–39）「换回什么」
- → 他仍不知道对方会不会同样选择自己，却愿意把这阵欢喜感受到底，浓烈得胸口发疼。
  - ← 限制：（72–77）「怕是在催对方」

### S12｜93–102 小节　（没在想）

- 不再为想被珍惜自责后，他更清楚自己多想靠近，也盼对方同样珍惜自己，想看看两人能一起过怎样的日子。
  - ← 提供理由：（84–92）「不是交换」
- → 他觉得自己有许多爱可以给，心里的这些感情也都值得珍惜，欢喜一涌上来，他连自己的得失都顾不上。
  - ← 说明：（84–92）「不是交换」
- → 他仍盼对方也选择自己，可对方没给新保证，想要的回应还没有着落。
  - ← 限制：（84–92）「胸口发疼」
- → 他只想让眼前的欢喜多留一会儿，暂时顾不上以后能不能如愿，等欢喜退下，想被珍惜的心还会回来。

### S13｜103–110 小节　（正在面对）

- 他真想和对方共享幸福，可对方仍没给保证，他怕这份幸福只属于自己，没法不在意对方会不会选他。
  - ← 限制：（93–102）「回应还没有着落」
  - ← 唤起：（93–102）「欢喜多留一会儿」
- → 他曾不再查看对方是否在意，只管关心，安稳过一阵，可想被珍惜的心还是会回来。
  - ← 说明：（40–50）「眼前愿意做的关心」
- → 尽情喜欢确实让他幸福，可他先前试过不盯回应，也没法靠这两种做法保证对方会选他。
  - ← 失效：（24–34）「不会失去」
  - ← 说明：（62–71）「玩心也冒出来」
- → 他不想让对方负责消除自己所有的不安，也不愿因怕落空就故意把喜欢压淡。
- → 他仍盼对方主动靠近、把他放在心上，却不愿催对方回应，也没法假装自己不在乎，心里很难受。
- ⟲ 仍在起作用：（93–102）「多想靠近」；（35–39）「放在心上」；（17–23）「不能决定」；（62–71）「独自惦念」；（72–77）「怕是在催对方」；（72–77）「主动靠近」

### S14｜111–116 小节　（正在面对）

- 他不再反复盘算该收住还是放开，试过后知道哪种都不能保证不受伤，也不再拿收住证明自己清醒。
  - ← 提供理由：（103–110）「两种做法」
- → 他不再逼自己先放下遗憾才继续喜欢，绷紧的劲慢慢松下来，对这个人的喜欢还热着。
- 安心靠近、真心给予、独自惦念、尽情欢喜，都曾让他真切快乐，也让他舍不得放下这个人。
  - ← 说明：（4–16）「不求回应」
  - ← 说明：（24–34）「心意可给」
  - ← 说明：（40–50）「那么在意回应」
  - ← 说明：（62–71）「留退路」
- → 他仍盼对方主动靠近，可对方愿不愿意，只能由对方自己拿主意。
- → 对方若没选他，他会疼，却不把自己的喜欢说成假的，也不拿疼去催对方。
  - ← 说明：（84–92）「不是交换」
- → 他不再因怕关系改变，就先把喜欢收回。
  - ← 改写：（1–3）「说不清的犹豫」
- ⟲ 仍在起作用：（72–77）「主动靠近」；（17–23）「不能决定」；（72–77）「怕是在催对方」
