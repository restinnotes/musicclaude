========== 甲 版 ==========
### S01 ｜ 1–3 小节

• 他很清楚自己在乎这个人，也知道对方怎样回应，对自己意义重大。
• 但对方究竟对他抱着怎样的心意，他目前还没有把握。
→ 正因在乎又没有把握，刚升起的期待虽然深深触动他，却还不能变成安心的快乐。

### S02 ｜ 4–16 小节

• 眼下真切的相伴，让他感到亲近不再只是一个未落实的愿望。
→ 两人可以安静待在一起，不必急着确认什么，先前的谨慎才暂时松开。
→ 正因为尝到这份自在，他又舍不得相伴的时间就这样过去。
• 他越来越愿意亲近，热切一时难以收住，心意也更愿意显露。
• 但他珍惜的也有安静相处的自在，所以心意显露后仍不急着索取答案。

### S03 ｜ 17–23 小节

• 相伴带来的安慰仍在，他还可以安静沉浸在眼前，不急着再求别的。
→ 但正因为已经得到满足，他开始想让亲近延续，不再只要眼前这一刻。
→ 一想到要让亲近延续，他就碰到一个限制：这件事不能只凭自己的喜欢决定。
→ 于是急切会短暂冒出来，却找不到能真正落下去的地方。
• 他想回到单纯享受，又放不下已经生出的需要，所以舒服之中一直有股力量拖住他。

### S04 ｜ 24–34 小节

• 熟悉的亲近又让他舒服，但已经生出的延续愿望并没有随之消失。
• 先前即使已想延续，眼前亲近仍能暂时安定；如今越充分，延续需要越真切，反而难安住眼前。
→ 因此这次的欢喜不再只是满足，未获着落的需要也使它添了迫切与酸楚。
• 即使投入得再充分，也不能因此让相伴的以后更有保证。
→ 越想靠此刻的好抓牢亲近，增加的只有自己的牵动，而非延续的把握。
→ 因此最明亮、最热切的时候，他仍会失衡、哽住，甚至退缩。

### S05 ｜ 35–39 小节

• 刚才的热切曾让他整个人沉在相伴的充盈里。
• 一从那份充盈中露出来，他便独自面对那个仍没有着落的愿望：想让亲近继续。
• 现在仅靠眼前的好，已无法承托想要延续的需要，再加大热切也补不上。
→ 原先，眼前的亲近还足以让他暂时安定；如今却已不够，空落只能由自己承受。
• 强烈沉浸时的用力退了下来，身体终于可以缓一口气。
• 用力退下带来松动，未解的牵挂留下孤单；轻下来的并不是已经想通的心。

### S06 ｜ 40–50 小节

• 失去的只是被眼前温柔包围的安稳，已经经历的美好仍留在心里。
• 眼前的亲近暂时不能像先前那样安慰他，留下的余温却仍能让他快乐。
→ 他现在可以独自细细体会那份清澈的好，这种快乐不再全靠眼前的相伴来托住。
→ 这种快乐成了他自己的感受，也带着别人无法完全陪同的孤单。
• 热切不再填满他时，他反而更清楚温柔如何留在自己身上。
• 热切退下后，他更清楚自己仍想亲近对方；能独自快乐，并没有消除安静里的拉扯。

### S07 ｜ 51–61 小节

• 独自感到的温柔并没使他远离对方，快乐反而让相伴的满足更鲜明。
→ 身体越记得那份满足，再次靠近对方的愿望就越直接。
→ 先前可以安静回味的温柔，如今变成舍不得抽身的热度。
• 沉浸本身也有快感，使他难以只停留在独自回味里。
• 他既知道相伴能让人安稳，也体验过独自回味仍能快乐。
• 可无论哪一种快乐，都不能让眼前的时间停住；美好还在，他已经舍不得它正在过去。

========== 乙 版 ==========
### S01 ｜ 1–3 小节

• 一阵强烈的欣喜突然涌上来，心也跟着绷紧。
→ 他忽然真切地感到，自己多么想与对方亲近。那份可能带来的高兴一下子冲了上来，身体先激动起来，心却还没来得及在这份高兴里站稳。
• 激动渐渐柔和下来，他却更加小心，满怀期待又不敢安心。
→ 刚才那阵激动让他更清楚自己想要什么，却没有让他知道对方是否也愿意。他明白自己的心动不能算作对方的答应，便收住急切，不敢贸然把可能的亲近当成已经拥有的幸福。

### S02 ｜ 4–16 小节

• 他还带着一点悬念，却渐渐放松，敢安心待在这份亲近里。
→ 上一段他确认了想靠近的心意，却只能收住冲动等待。如今这份亲近持续着，并没有因为他不再急着争取就消失，身体便先于念头松下来，暂时不必追问结果。
• 他觉得两人近得令人安心，连安静待着都甜蜜。
→ 先前他太在意能否靠近，不得不把自己的急切收住。现在亲近已经持续了一阵，他的注意力渐渐不再围着自己的等待转，而是落到那个人身上；即使还不知道对方的心意，光是感到这样近，就已经让他高兴。
• 他忽然有点鼻酸，明明还在快乐，却已经舍不得。
→ 刚才他终于能放下紧张，真切享受这份亲近，才发现自己已经在幸福里度过了一段时间。那些美好的瞬间还没来得及留住就过去了；眼前的好并没有减少，他却因为太喜欢，第一次这样具体地心疼时间的流逝。
• 他的喜欢一时热切得藏不住，随后又柔和下来，仍有眷恋。
→ 原先收着的喜欢，经过这阵真实的快乐和刚生出的不舍，渐渐积得太满，他忍不住想让对方更明白自己的心意。可再热切也不能替对方决定心意，于是他重新收住，不把这一刻的幸福当作已经有了结果。

### S03 ｜ 17–23 小节

• 刚才的热切渐渐退下，他仍沉浸在亲近的快乐里，舒服得有些走神。
→ 先前他已发现，即使没有对方心意的保证，也能安心享受亲近；又因为舍不得刚才的快乐，心还留在那份余味里。此刻不急着表达或求证，只想任自己在其中多待一会儿。
• 舒服之中忽然有点心急，像有话想说，却很快又安静下来。
→ 前一段他已开始想让对方知道自己有多喜欢。刚才的陶醉稍稍退开，这个愿望便突然冒出来；可他也知道自己的热切不能替对方回答，心里一时没有把话继续说下去的把握，于是又收住了。
• 温柔还在，心却渐渐绕住了，带着一点说不清的牵挂和迟疑。
→ 先前他已经能够不求答案地享受亲近，如今却又想把自己的喜欢传给对方。刚才想说的念头起了又落，愿望仍留在心里；他越想继续舒服地沉浸其中，越察觉有一部分心思放不下来，却还没有什么能够解决。

### S04 ｜ 24–34 小节

• 悬着的心忽然松开，熟悉的亲近让他惊喜又庆幸。
→ 上一段里，连舒服的安静都被没说出口的喜欢牵住，他没法完全放松。如今那份温柔仍能让他真切地快乐，身体先松下来，才格外感到它的可贵。
• 喜悦越来越满，他想抓紧这份亲近，也更想让对方知道自己的喜欢。
→ 他已经尝过亲近的快乐，也尝过它退去后的不舍；上一段又让藏着的喜欢自己浮起来。此刻重新尽情高兴，他便不满足于只是安静享受，越投入越想把这份好留住、把心意表达出来。
• 最激动时，他几乎想把喜欢全说出来，却又心颤得没底。
→ 上一段已让他发现，没说出口的喜欢不会因亲近而安静；如今欢喜越强，那份心意就越难藏。可亲近仍不能替对方回答，他越想毫无保留地交出去，越感觉到自己没有把握。
• 热烈渐渐退去，他仍甜得心酸，安静下来却越发舍不得。
→ 先前他已经尝过快乐过去后的不舍，这一次却比先前高兴得更满。他还在享受亲近，就已心疼它终究留不住；越想抓紧，越觉得自己无力让它停下，激动退去后便留下温柔的眷恋。

### S05 ｜ 35–39 小节

• 刚才的热烈忽然退下，他一时空落、陌生，像失去了着力点。
→ 前面他已经在幸福正浓时为它终将过去而心疼；如今那阵强烈的快乐真的退远，心却还习惯着刚才的亲近，一时不知该怎样安放自己。
• 他从刚才的亲近里退开，感到孤单，也更清楚地意识到自己的牵挂。
→ 前面他已经发现，越幸福越想说出心意，却仍不能替对方回答；当自己刚才的欢喜退远，没说出口的喜欢便独自浮出来。他没有认定亲近是假的，却忍不住想，它究竟能持续多久。
• 他不再急着抓住刚才的快乐，孤单里慢慢有了轻松和温柔。
→ 前面他越快乐越舍不得松手，如今那阵热烈已经过去，继续用力也留不住它；而曾经得到的幸福依然真实。他渐渐不必急着找回原来的感觉，能够带着余温安静地想念，也重新生出一点想靠近的期待。

### S06 ｜ 40–50 小节

• 空落之后，他重新温柔起来，像在回味刚过去的亲近，甜里带酸。
→ 刚才他已经不再急着把过去的快乐抓回来，于是回味本身第一次能成为安慰；越觉得那一刻真实珍贵，也越能尝到它已经过去的酸楚。
• 他越安静地想着对方，越显得柔软袒露，偶尔又会突然心紧。
→ 不再忙着追回快乐以后，没说出口的喜欢反而更无遮掩；而先前已经浮出的不确定，此刻失去热烈快乐的包裹，便显得更孤单、更容易刺他一下。
• 那阵心紧过去后，他仍愿意停在想念里，亲切慢慢重新占上风。
→ 他已经学会让喜欢与不确定同时存在，也能承受快乐留下的空落，所以短暂的不安不再逼他退出；缓下来后，对方留在心里的温暖仍然成立。

### S07 ｜ 51–61 小节

• 回味里的甜蜜越来越热，连身体都渴望更深地亲近。
→ 上一段他已发现，亲近虽然过去，独自回味仍能给自己温暖。如今这份温暖没有停在安静的怀念里，反而把心里积蓄的喜欢一点点推成难以按捺的渴望。
• 他越沉醉越舍不得抽身，快乐里有近乎失控的迷恋。
→ 他已经能够不急着追回过去，也不必等到对方回应，便享受心里的喜欢。此刻越允许自己沉浸，回味就越像重新亲身尝到那份快乐，连渴望与遗憾也混进快感里，使他明知越陷越深，仍不愿停下。
• 明明还陶醉着，他却心疼这份快乐也正在过去。
→ 他先前已切身感到美好成为过去，随后又学会从回味里重新得到温暖。现在他发现，回味虽然能让快乐再次发生，却不能留住这一次的快乐；越是舍不得抽身，越清楚此刻也在流逝。
• 热切渐渐缓下，心里仍温暖，却更加难舍。
→ 刚才他已经任自己尽情沉醉，原来温柔的牵挂也变得格外强烈。等这阵激动稍稍退下，他仍无法留住美好，也没有得到对方更多的确定；但刚才的快乐确实属于自己，所以心疼之余仍愿温柔地珍惜。


========== 丙 版 ==========
### S01 ｜ 1–3 小节

• 一阵强烈的心动突然涌上来，兴奋而郑重，也带着一点紧张。
→ 想靠近的心意来得太直接，身体先有了反应。他还没来得及安顿，就已经感到这件事对自己很重要，不能轻轻带过。
• 激动渐渐变得柔和、谨慎，期待仍然悬着，不能完全放心。
→ 他已经清楚自己想靠近，却还没有任何根据相信这份亲近真的成立。越是珍惜这种可能，越不敢把强烈的心愿当成已经拥有的幸福，只能带着期待小心地等待。

### S02 ｜ 4–16 小节

• 先前绷着的心慢慢松开，他愿意被温柔托着，不急于落定。
→ 上一段他已经发现，单靠想靠近换不来确定；此刻一种持续的安适先让身体放松，他暂时不再逼自己掌控结果。即使一切还在向前，他也愿意安心待在其中。
• 他仿佛与人贴得很近，觉得亲昵、自在，沉默也甜蜜。
→ 刚才不再急着抓住保证，他才有余地体会亲近本身：不必努力证明什么，就能感到仿佛有人相伴的温暖。先前只能向往的好，如今第一次成为可以慢慢享受的感觉。
• 越觉得这一刻好，他越微微鼻酸，想让它慢一点过去。
→ 此前他只为亲近能否成立悬心；如今已经尝到其中的快乐，才开始舍不得它流走。眼前的好仍在，但他已经知道心意再强也不能保证留住它，所以这份甜开始带上一点酸。
• 他的喜欢忽然涌得更热切，随后柔和下来，仍有余恋。
→ 刚才的快乐已经珍贵到让他舍不得，他一度想更充分地靠近，让这份心意得到更多。可热切并不能替亲近换来保证，所以激动退下后，他仍留在这份温柔里，没有急着把心事说尽。

### S03 ｜ 17–23 小节

• 他还沉在刚才的幸福里，舒服地走着神，暂时什么也不想做。
→ 先前他已发现，即使亲近还没有保证，那份感觉本身也能让他安心。如今他舍不得这份快乐过去，便只想顺着它的余温停留，暂时不急着追求更多。
• 安静中忽然生出一点急切，想抓住什么，却很快又沉回温柔里。
→ 前面的快乐已经让他盼着这份亲近能多停留一会儿，所以心里偶尔会忍不住想把它抓得更稳。但满足感仍在，他还没有真的失去安心，这点急切便没有变成持续的追问。
• 温柔仍在，他却渐渐有些放不下，心思绕来绕去，难以安稳。
→ 正因为刚才曾不费力地享受幸福，如今又舍不得它过去，他才察觉，想让这份好一直持续，并不能让自己始终同样自在。越想留住刚才的安稳，心里反而越有一点牵挂。

### S04 ｜ 24–34 小节

• 熟悉的亲近又回来了，他欢喜，也松了口气。
→ 先前他已尝过亲近的快乐，也发现越想留住它，安心越难自然。如今同一种温柔仍能让他高兴，便多了一层庆幸，而不是多了任何保证。
• 欢喜越涨越满，甜得发酸，他不自觉地抓紧。
→ 上次幸福让他舍不得，后来想留住又使心里绷紧。这次越觉得美好仍在，越想再多感受一点；用力不是因为已经失去，而是怕此刻不够长。
• 他几乎想把心意全倾出来，却激动得发颤。
→ 他早知道心意再强也不能保证亲近，如今又带着想留住幸福的紧张。越想把感情表达得彻底，越觉倾尽自己也不能把这一刻定住，最热烈处反而有了哽咽。
• 热切渐渐退下，他安静了，却仍恋恋不舍。
→ 刚才他已经把欢喜推得很满，再用力也不能让它停得更久。身体终于慢慢松开，心里的舍不得却还在；这份安静并不意味着原来的疑问有了答案。

### S05 ｜ 35–39 小节

• 刚才攥紧的心忽然松开，轻了一点，却也失了重心。
→ 上一段他把喜悦和心意推到极致，仍没能让幸福长久有保证。再用力也无法留住这一刻，那股一直想抓紧的劲便先退了下去，反而让他一时无所依凭。
• 他忽然有些孤单、茫然，像从亲近里退回了自己。
→ 此前他能从亲近本身得到安心，刚才也确实那么幸福；如今那阵热烈已成了刚刚过去的事，他才清楚地感到自己与它有了距离。快乐并非不真实，却不能一直替他托住此刻。
