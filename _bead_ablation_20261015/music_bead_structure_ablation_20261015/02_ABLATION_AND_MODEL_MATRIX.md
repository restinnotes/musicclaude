# Bead 质量实验：逐分支 × 逐模型，不预设什么必然有用

## 实验变量必须拆开

**独立变量 S：分段来源。** S0 = run102 历史宏观时间轴（只作对照）；S1 = 使用包内通用提示词独立做出的音乐结构段落。S1 必须先独立完成、冻结、存 hash，再揭示 S0 作比较。另记次级边界，但 Bead 不再自行切。

**独立变量 R：研究素材分支。** 以下条件都使用相同结构段落、A-only 基线、相同合成模型与输出预算（建议主要候选长度误差不超过约 10–15%，内容库存可额外完整保存）：

| 条件 | 给珠子生成器的材料 | 验证什么 |
|---|---|---|
| R0 | 仅 A（int+web） | 当前体验能有多好；必做 |
| R1 | R0 + T（明确隔离“本段目前可用”与“仅历史候选”） | T 是否真的改善 Bead，而不是只让它提前成为 Thread |
| R2 | R0 + 通过来源检查的 H1 | 听觉引导是否改善体验，而非增加技术描述 |
| R3 | R0 + 通过来源检查的 H2 | 持续体验尺度/局部侧面是否改善，不只数新增句 |
| R4 | R0 + 通过来源检查的 H3 | 有无独立有效的本段读法，还是提前泄漏全曲叙事 |
| R5 | R0 + 通过来源检查的 H4 | 当时已经可成立的期待是否形成新感受 |
| R6 | R0 + 通过来源检查的 H5 | 有无极少数本段合法内容；大多只留回听，不必硬上 |
| R7 | R0 + 经过 R1–R6 检查后胜出的各条 | 只有证实增益才综合，没胜出可仍采用 R0 |

**不需在一开始做大规模 R 全排列。** 先查已有残差和原文，三个代表乐段逐个变量测试；发现实际有增益才扩展。H3/H5 若没有本段前缀有效的材料，标“此段无可测候选”是有效结论，而非要求模型硬写。

**独立变量 M1：原料来源模型。** 按 `A/T/H × model × int/web × sample` 列出原文、单位、独有贡献、质量风险。来源模型逐家留一/加回：

1. 固定 A 基线 pool，在一个段里删除某模型的 A 内容，看是否失去具体、可感、独有的感受；再加入该模型原文是否恢复，不能拿被其他模型重复的内容冒称独有。
2. 用同样方法检查各来源模型 T 里的局部增量；大部分历史话语未必能成为 Bead，但研究者可提供新且真实的当前局部事实。
3. H1–H5 既审分支的独特任务，也审同分支不同模型/联网是否有互补。每份需要记录 useful / duplicate / misaligned / inaccurate / hindsight / vague。
4. 当文档长短差异明显，不直接以“更长所以更多条”为胜；要同时报告绝对新内容和单位篇幅内真正独有的听者价值。
5. **来源层与合成层分开评价**：不能把某模型作为 Reviewer 很强，推导它作为素材研究者一定好；也不能因为 GPT-5.6 做 BEAD 好，就认为它生成的 A 原料更好。

历史 run126 Op.60 的原始模型家族包括：gflash、muse、luna、opus、sonnet、grok、sol，以及各自可能的 web/int 变体；H 又有 GPT-5.6 的补样。每首作品可能不同，模型目录必须从 `manifest` 实际生成，禁止将这串名字硬编码为所有作品的清单。

**独立变量 M2：珠子统合写手。** 至少用历史 GPT-5.6 可用版本作基线，按当前环境的真实可用性与 Gemini、Muse、Opus 等候选作同题对照。相同 S1、相同 R0、相同温度/数量预算/输入，输出匿名后由独立模型与用户审阅。旧 run129 的 Opus 重复问题只能作为风险提示，不可代替本轮实验。

## 对每个分支/模型怎么认定“有贡献”

对每条候选 `source_id/unit_id`，记录：

- 在固定段落与其当前听觉事实下，它究竟是什么独特的体验、事实、关系、解释？
- A-only 珠子有没有已经包含？若已包含，算支持/更鲜活的表达，不算新发现。
- 它对**当前 Bead**的增益还是对以后 Thread、曲终回顾的增益？要分开。
- 是否存在实际音乐/外部来源支撑？无法核对的明显标注，不得伪造。
- 是否把后面才发生的事写进当前？例如“以后才知道……”不能随意进入首听珠子。
- 保留它是否导致 A 内容损失、重复、篇幅膨胀、单一叙事污染？
- 一个模型新产出的内容，即使只多一条，但具有很强的特殊感受，也可能比十条同义改写重要。

分类建议 `CORE / ADDS_LOCAL / ADDS_LISTENING_CUE / CONTEXT_ONLY / SUPPORT / ALTERNATIVE / DUPLICATE / RETROSPECTIVE_ONLY / UNSUPPORTED / TRACE_GAP`。每个标签要有真实文本/来源，不机械计分；不能只靠自动模型自评。

## 明确要看的实验位置与完整性

Op.60 先至少选三个不同特征的宏观段：早期一个、中心变化一个、后段一个。历史 mm.4–16 可作为其中一个；真正的测试段以独立结构输出为准。若研究表明某个位置没有 H5 当前可用内容，应记录为零并停止该条件。审核三段的质量和成本，确认改善再扩展至 Op.60 全段。

**质量检查：**
- 当前感受真实、鲜活、异质，是否有音乐事实支撑；
- 跨乐段引用的材料是否保留完整意思和时间定位；
- 对同一段中持续、先后、竞争解释是否分清；
- 读者拿到一颗珠子能否体验一段完整音乐，而非 23 个碎标签；
- 不预设文学风格、人生主题，也不为赢盲比写得越来越长；
- 每条有价值的内容去了哪里，是否可找回原始来源。

## 正式验收门

**Gate S：** 结构候选经过至少两种独立证据源/独立研究任务（若只有一种，必须标低置信度），与既有宏观切点盲后比较；没有偷读 A/T/H 或强迫固定段数。

**Gate P：** 选定段落的 A/T/H 来源对应关系全可追、跨段素材无无声删除；争议项显式列出。

**Gate B：** A-only 与各消融的真正文字可以并排读，用户可以指认原文中的增益和损失；定稿的一颗 Bead 不强制具有 T/H 的条数配额。

**Gate U：** 用户本人认可至少一些完整段落 Bead 的实文后，才讨论是否开展后面的 Thread。没有此项，阶段未完成。

不得用“跑完全部调用”“覆盖率更高”“模型打分更高”代替 Gate B/U。
