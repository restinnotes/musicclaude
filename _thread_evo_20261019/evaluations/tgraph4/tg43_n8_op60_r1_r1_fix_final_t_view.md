# Op.60｜关系图

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3　（还说不清）

- 他还说不清自己究竟在盼什么，只因心里有了格外愿意亲近的人，一想到对方便不由自主地柔软。
- → 每当他想让这份喜欢多停留一会儿，又会本能地往回收。
- → 眼下并没有什么要求他决定的事，他也说不清自己为何谨慎。
- 这点喜欢轻得似乎随时可以放下，他却偏偏舍不得。

### 4–16　（没在想）

- 他还说不清自己怕什么，便不急着决定两人以后会怎样，也不因喜欢向对方期待什么。
  - ← 提供理由：（1–3）「无事待决仍谨慎」
- → 这样想着，他慢慢能够安心地亲近那个人。
- → 他发现认真在乎一个人，也能自由给予温柔，不必确认对方是否领受。
- → 这份快乐让他渐渐不再提防自己的喜欢，也满意自己能够宽和。
- → 那时他觉得，只要亲近始终自然、不追问不计较，这样已经足够。

### 17–23　（正在面对）

- 尝到亲近的幸福后，他开始希望这份喜欢不只属于眼前。
- → 一想到长久，他便想到自己能决定怎样珍惜对方，却不能决定对方是否也珍惜自己。
- → 他偶尔忍不住想，自己在对方心里是否也很特别，却没打算索取什么。
- → 一点期待让原本无需确认的事开始牵动他，也打破了先前的安稳。
- → 他有些意外，原来已经令人满足的亲近仍会让人盼望更多。　✦ 满足照出未满足
  - ← 动摇：（4–16）「自然亲近便已足够」

### 24–34　（正在面对）

- 他不想让喜欢变成对对方的无形催促。
  - ← 提供理由：（17–23）「期待打破原有安稳」
- → 他发现关心、给予和为对方高兴本身就是快乐，不必换来保证，这让他渐渐轻松。
- → 他不再衡量谁更在乎，开始毫不勉强地多给一点，心里也越发丰盈。
- → 不计较回报让他感到充实自由，他以为不提要求便能尽情爱而不失去什么。

### 35–39　（还说不清）

- 欢喜稍平后，他仍想知道自己是否也被对方放在心上。
  - ← 动摇：（24–34）「以为不索求就不会失去」
- → 他刚刚还为自己的无所求而高兴，如今却又盼望被看见，因此感到难堪。
- → 他因此怀疑，那些体贴里是否一直藏着不愿承认的期待。
- → 他没法说自己毫无所求，也知道此前的快乐并非为了换取对方的珍惜。
- → 他只能暂时停在这份不自在里，不替自己辩解，也不急着用新的热烈盖过去。

### 40–50　（没在想）

- 这份难堪没有让他不再喜欢，却使他不愿再用慷慨证明自己。
  - ← 提供理由：（35–39）「盼被看见而感难堪」
- → 因此他转而只留心当下确实愿意给予的关切，不再忙着想两人以后会怎样。
- → 他可以盼对方好、安静惦念，也因心里有这个人而生出柔和喜悦。
- → 这种细细的喜欢让他暂时忘了自己为何盼被珍惜，只觉得它很甜。

### 51–61　（正在面对）

- 从前以为能轻轻放在心里的喜欢，如今渐渐有了重量。
  - ← 改写：（40–50）「细细喜欢带来甜意」
- 他原想把喜欢留在自己这里，不让对方为难，也不让期待牵动自己。
- → 珍惜对方的心更深后，他常常惦念，也希望自己的关切能被领会。
- → 他仍不催促对方，却常独自想着对方是否也会靠近。
- → 喜欢渐渐变重，他仍珍惜其中细致的甜蜜。
  - ← 提供理由：（40–50）「盼对方好并安静惦念」

### 62–71　（没在想）

- 这份心意已经很深，他忽然不想再时时把它当作需要约束的东西。
  - ← 提供理由：（51–61）「变重仍珍惜细致甜蜜」
- → 他想起安心亲近、付出和独自珍藏的甜蜜，不靠承诺也真实，即使仍有期待。
  - ← 说明：（4–16）「安心地慢慢亲近」
  - ← 说明：（24–34）「不再衡量并慷慨给予」
  - ← 说明：（40–50）「细细喜欢带来甜意」
- → 他想充分享受积攒许久的眷恋，不再因怕受伤而小心高兴，也不急着追问结果或安排退路。
- → 有一阵，欢喜大过所有顾虑，他几乎感觉不到没有保证的沉重。

### 72–77　（正在面对）

- 欢喜稍平后，他发现自己不只想尽情喜欢，也想知道对方是否同样渴望靠近。
  - ← 唤起：（62–71）「欢喜一时盖过顾虑」
- → 他明白自己想要得很深，却不能把真心当作对方理应同样喜欢的理由。　✦ 分清
- → 他怕退回先前的谨慎会辜负刚承认的心意，也怕继续盼望会变成要求。
- → 两边都有他舍不得放弃的东西，他想不出办法兼顾，感到委屈又厌倦。

### 78–83　（正在面对）

- 他终于不再逼自己立刻选择，暂时不决定如何处理这份感情。
  - ← 提供理由：（72–77）「两难委屈又厌倦」
- → 他不必急着靠近或压下眷恋，可以带着愿望安静喜欢，也承认自己没有把握。
- → 他暂时放过自己，心里松开一点，温柔又自然地留在心里，先前的为难仍在。

### 84–92　（正在面对）

- 他不再强迫自己消除渴望，也不再时时纠结于未解决的矛盾，因此重新感到最初亲近一个人的快乐。
- → 他尝过期待的紧张、无从确认的难堪，也知道深情不能替对方作答，却仍愿意喜欢。
- → 他不再躲避感情的深度，也不为热切羞怯，并因犹疑后仍能高兴而感动。
- → 他不再用无所求证明体贴，也允许想被珍惜的愿望与喜欢同在，虽可能受伤仍承认幸福。
- ⟲ 仍在起作用：（17–23）「期待打破原有安稳」；（35–39）「盼被看见而感难堪」；（72–77）「不把真心当作对方必须同样喜欢的理由」

### 93–102　（没在想）

- 他不再遮掩渴望后，更清楚地感到自己多么想亲近这个人。
  - ← 提供理由：（84–92）「允许被珍惜的愿望与喜欢同在」
- → 他想把积攒的温柔给对方，也想让两人的亲密真正发生。
- → 他想被同样深切地珍惜，也想知道两人共同的幸福能有多丰盛。
- → 那一刻，他仿佛觉得所有心愿都已得到抒发，尽管没有任何新的保证。
- → 他一时顾不上以后，只想尽情享受眼前的幸福。

### 103–110　（正在面对）

- 幸福还很鲜明时，他忽然察觉自己仍有一个愿望没有实现。
  - ← 动摇：（93–102）「只想享受眼前幸福」
- → 他能决定自己爱得多深，却不能替对方决定要不要同样爱他。
- → 刚才的欢喜越真实，他越难再说自己不在乎对方是否珍惜他，酸楚也更难忽略。　✦ 满足照出未满足
  - ← 提供理由：（93–102）「只想享受眼前幸福」
- → 他不愿把自己的安稳全交给对方，也不想让对方负责消除全部不安。
- → 他也不愿因害怕得不到，就故意削弱那些曾给他巨大幸福的感情。
- → 他曾靠克制得到安心，却没能因此让渴望消失。　✦ 克制未消渴望
- → 尽情投入曾让他幸福，却没能让失望从此不再可能。　✦ 投入仍有风险
- → 如今他已舍不得否认想靠近和不勉强对方这两种心思，冲突反而更强烈。　✦ 知道更多反而更尖锐
- → 他不愿为了轻松就匆忙放弃靠近的愿望或克制的坚持。

### 111–116　（正在面对）

- 带着这份仍未平息的牵挂，他渐渐不再要求自己找到一种不会受伤的爱法。
  - ← 改写：（103–110）「不为轻松而放弃一边」
- → 他喜欢得很深，也坦承盼被选择，却仍收住心意，因为对方未必同样想要。
- → 若为求安心把全部期待都交给对方，他盼望的亲近也会失去自在。
  - ← 提供理由：（103–110）「不让对方负责全部不安」
- → 他仍会遗憾，却不再觉得必须消灭遗憾才能好好爱一个人。
- → 小心亲近、不求确认地付出、独自珍藏和尽情欢欣，都曾给他真实的幸福。
  - ← 说明：（4–16）「安心地慢慢亲近」
  - ← 说明：（24–34）「不再衡量并慷慨给予」
  - ← 说明：（40–50）「细细喜欢带来甜意」
  - ← 说明：（62–71）「欢喜一时盖过顾虑」
- → 他曾努力收住，也曾尽情投入，因此知道两种办法都不能免去爱人的风险。
  - ← 说明：（103–110）「克制安心却未消渴望」
  - ← 说明：（103–110）「尽情投入仍可能失望」
- → 他知道未来仍可能失望、想要更多或因无法更近而疼痛，却不因此否认感情、催促对方或放弃爱。
- ⟲ 仍在起作用：（72–77）「不把真心当作对方必须同样喜欢的理由」
