# 这一轮是什么

- 01：v6 原线关系图（10-21 用户整体认可方向的版本；✦ 是当时的内部标签）。
- 02：在 v6 上逐段修补后的新线。形式同 v6：Center 不改；每段标他和 Center 的关系；→ 段内由上一条引出；← 指回前面某段的某一条；⟲ 前面仍在起作用的。新线不再显示 ✦ 标签。
- 03：珠子关系图（逐字原文，未改动）。
- 04：新线和珠子结合：每屏是线的条目和它说明的珠子条目。
- 05：新线和 v6 的匿名盲评（gpt-6、5.6，随机顺序），逐段比 覆盖 / 啰嗦 / 人话，并列出两个方向各丢了什么。
- 06：回退检查的固定清单：两位诊断评审列出的 v6 实质好内容合并成一份清单，两位评委逐条判 保留 / 更好地取代 / 丢失。
- 07 / 07b：珠子覆盖的绝对数：评委只看一版线和全部珠子，逐颗判 说清 / 偏弱 / 相反 / 没有；07b 是 v6 用同一把尺子的结果。

新线是怎么来的（底稿始终是 v6，Center 不改）：
1. w2：v6 整首一次修补。输入 v6 全曲、两首珠子、两位评审对 v6 的逐段诊断（P1 覆盖 / P2 啰嗦 / P3 人话 / 值得保留的内容）；之后逐段核对（越界、箭头前因、不看珠子能否读懂、有没有丢 v6 的实质内容），再整首退改一次。
2. w3、w4：在上一轮基础上，按“和 v6 匿名盲评”列出的“新版丢了 v6 的内容”整首再修。
3. w5 起：只对仍丢着内容的段落逐段聚焦重修（每段一次调用，看 v6 全曲、前面各段、这一段 v6 原样和珠子、要找回的内容），其余段沿用上一轮；w6 按上一次交付前评定的意见再逐段重修。
所以文件标题里的“在 w4/w5 上重修”指的是上一轮新线，它们本身都是从 v6 修来的。
