## 三、覆盖怎么判

- 对象：Op.60 的 51 颗珠子、Op.61 的 55 颗珠子，“演奏条件”类跳过。
- 逐颗判断某篇稿子有没有解释这颗珠子的感受，也就是有没有给出理由，说明“经历过前面那些之后，此刻为什么会这样感受”。分四档：

| 标签 | 意思 |
|---|---|
| 解释了 | 写到了相符的感受，并且给出了说得通的理由。一个理由可以同时解释几颗珠子；不要求写到珠子里的声音或比喻 |
| 只提到 | 有相近的感受，但没有理由；或者理由放到哪一段都成立；或者只解释了这颗珠子里不重要的那一部分 |
| 没有 | 这一段没有涉及这种感受 |
| 相反 | 稿子写的感受和这颗珠子相反，比如 d9S 的 35–39 |

- 规则：
  - 角色标签不代表重要性。“侧面”没被解释，就算没有。
  - “另一种理解”类的珠子，只要解释了其中一种听法就算解释了。
  - 每颗都要写一句理由，并引用稿子里的关键几个字。
  - 解释依赖编出来的设定时，照常打标签，另外把设定单独列出来。
- **池子的覆盖率：** 合起来看所有稿子，每颗珠子只要有一篇稿子“解释了”就算覆盖。
  - 严格口径：两位评委（gpt6、gpt56）都判“解释了”。
  - 宽松口径：任意一位判“解释了”。
- **校准：** 拿已知的例子检验评委判得对不对。
  - d9S 的 35–39 应判“相反”，d9L 的 35–39 应判“解释了”。
  - 60e 式的写法没有涉及暗流，应判“没有”。
  - 另外，评委意见不一致的地方，以及列为缺口的珠子，我自己逐颗抽查。

## 四、新稿：P0+

- **原则：** 保留 P0 原文，也就是你最初那段提示词，再加 P0+ 规则。不给珠子，不给 Center，音乐材料仍然只有小节分段。
  - 先理解这一段的感受：和前面有什么不同，哪些感受同时成立。不必只挑最主要的一种。
  - 再从已经确立的历史出发找理由：一个理由能解释几种感受，就不拆成几步；几个相容的理由可以并存；这一段也可以只是前面的延续。
  - 不先编好一套故事再让音乐去配合。一个理由如果放到别的段也成立，就说明它还没说出这一段的原因。
  - 不编自我劝说、突然想通、下决心、外部事件；不把音乐的变化当作心理变化的原因。可以大胆提出自己的理解，但前提是解释这一段确实需要它。
  - 开头不交代过去、性格，不提前点出主题，也不预告后面的发展。
  - 用人话写，不描写声音和意象。
  - 每段写五项：感受、Thread、用到的历史、新增的历史、仍未解释的部分。
- **两种写法 × 两个模型 × 3 次，每首 12 篇：**
  - 逐段串行：每段单独一次调用，带上前面各段的内容，用来测“局部专注”这个假说。
  - 一次写完：整首在一次调用里写完，格式相同。
- 用同一套覆盖评审评这 24 篇新稿，和旧的修正稿、N8、B0 比。

## 五、覆盖关

- **过关标准：** 新稿池在严格口径下的覆盖不低于旧稿池。没覆盖的珠子要逐颗归类：
  - **池子太窄**：这种感受本可以由历史解释，只是没有一篇稿子写到。这类算缺口。
  - **可以独立保留**：和本段的解释相容，本身不需要另立理由。
  - **替代听法**：和本段的心理故事互斥。
  - **珠子本身存疑**：比如 S03 主体验的排序。

  后三类要写明为什么不算缺口。如果某一段最重要的体验落在后三类里，这一段就不过关。重点看已知的缺口：Op.60 的 17–23 暗流、35–39、93–102、103–110，Op.61 的 24–65、254–288。
- **没过关时：** 看缺口是哪一类。
  - 写反方向：说明音乐读错了。这时考虑给一份只列乐谱事实、不写情绪的材料，这一步先问你。
  - 理由空泛：改提示词。
  - 整体视野窄：加入不同的写法，提高多样性。
- 改了就重写一批再评，直到过关。修改的必须是通用规则，不能针对某颗珠子写，因为写稿时看不到珠子。
- 如果最后仍有个别缺口补不上，就在综合阶段为它们定向补候选，并标“新增”。

## 六、过关之后的对接（逐段综合），具体做法

### 1. 建池
- 每篇稿子用一次调用抽成“每段的解释”。每条写四项：
  - 理由：经历过前面那些，为什么此刻会这样；
  - 前提：需要前面已经发生过什么；
  - 能解释本段哪几颗珠子（沿用覆盖评审的判定）；
  - 来源。
- 不拆成步骤。被判“相反”的解释不进这一段的池子。
- 同一段里理由相同的合并，并记下有几篇独立提出过。
- **按机制去重，不按句子去重**：只有前提不同、后果也不同的才算两种。例如“希望长久所以舍不得”和“珍惜当下所以想留住”算同一种；“担心过失去，所以重新得到时更热烈”和“尝过幸福，所以对以后有了更多期待”算两种。
- 每段的数量不设上限，有几种就留几种。挑选时只把相关的给模型看，以减轻它的注意力负担。
- 24 篇新稿不等于 24 种思路，要报告每段实际有几种不同的机制。
- 池子从头到尾保留，任何一条都不会因为某次没被选上而删掉。

### 2. 逐段挑选（每一段 k 都走一遍）
- **输入只有三样：**
  - 已选定的历史（前面各段选中的条目，带编号）；
  - 本段珠子原文（带编号；角色标签注明“只是归类，不代表重要性”）；
  - 本段的池子。
- 提示词要短。字数、箭头、措辞这些格式要求都留到后面的步骤。
- **A 挑选（模型甲）**，逐条评池子里的候选，五项分开写：
  - 解释了本段哪几颗珠子，没解释哪几颗；
  - 前提在已选历史里有没有，有就写出历史条目的编号，没有就写“缺”；
  - 加了什么编出来的设定；
  - 这个理由放到别的段是否也成立，成立就算空话；
  - 是在讲原因，还是只宣布结果（比如“更想投入”）。
- **A 挑选**，然后选出本段用哪几条：
  - 理由相同的合并；
  - 解释不同侧面、又能同时成立的，并存；
  - 互相排斥的，只留一条，其余记为备选。
  - **逐颗核查，不是逐颗都要因果。** 本段每颗珠子都要判一个去处：
    - 被选中的某条解释覆盖（一条解释可以同时覆盖好几颗）；
    - 和选中的解释相容，作为独立的感受保留，并说明为什么不需要另立理由；
    - 替代听法，和本段的故事互斥，留在珠子里；
    - 当前没有解释，交给 D。
  - 不能为了覆盖而给每颗珠子各补一个心理步骤。一段如果只需要一个理由，就只写一个。
  - 不能用“只是侧面”放过。如果本段最重要的体验只能判成“独立保留”，就判这一段解释力不足。
- **B 检查（模型乙，用校准过的评委）**：先给绝对判断，可以判“本轮所有候选都不合格”。不及格时退回 A 重挑，最多一次；仍不合格就进入 C 或 D，不无限重挑。理由和结论对不上的评审作废重评。
  - **前提要查真假，不只查编号。** 历史条目有编号，不等于这件事成立。每条历史都记下它当初解释了哪几颗珠子。只靠设定撑着、没有解释过任何珠子的条目（例如“他过去一直压抑感情”）要标出来；后面引用它的解释，按“编造设定”处理。
- **C 回头，按依赖关系，不按距离。**
  - 有好候选只是因为前提“缺”而用不上时，先在附近的段落找，找不到可以一直往前找，比如 93–102 可能要回到 40–61。要找的是另一条同样成立、又能提供这个前提的解释。
  - 换上以后，所有依赖被换条目的下游段落都重新检查，全部通过才算数，否则保持原样。
- **D 补缺，允许失败。** 模型乙先判断解释不了的原因属于哪一种：

| 原因 | 怎么处理 |
|---|---|
| 池子太窄，但历史足够 | 只依据已选历史，定向写 2 条局部候选，标“新增”，加进池子后回到 A |
| 当前历史缺少必要的前提 | 进入 C，看要不要回头重选前面的段落 |
| 珠子本身的角色或情绪判断有疑点 | 回到来源稿和音乐证据复核，不改珠子原文 |

  补出来的候选同样要接受“编造设定”的检查。补不出有说服力的，就如实记为“在当前历史下暂时找不到足够有说服力的解释”，不硬凑一个说得通的心理故事。
- **本段产出：** 选中的解释、各自依赖的历史编号、新增的历史条目，以及每颗珠子的去处。

### 2.5 全局连贯检查（跑到中途就开始做，全曲写完再做一次）
- **检查时间点：**
  - Op.60：写完 S05（1–39）、S08（62–71）、S11（84–92）后各一次，全曲写完再一次。
  - Op.61：写完 S03、S07、S11 后各一次，全曲写完再一次。
- **不预设 Center，只问三件事：**
  - 到目前为止，形成了哪些真正有价值的历史关系？
  - 后面的理解有没有真的利用、发展或改变这些历史，而不只是引用前面的情绪？
  - 这些局部解释是否还属于同一件持续发展的事？
- 不合格时，指出是哪一段把线写散了，回到那一段走 C。

- Center 的正式措辞仍然最后才写。但线成不成立，不能留到最后才查。

### 3. 出成品
- **E 写关系图**：直接用选中的结果拼，不加新内容。
  - 每条不同的理由写成一个条目。
  - 跨段箭头只连“依赖的历史编号”，关系类型从“提供理由 / 动摇 / 限制 / 改写 / 唤起”五种里选。
  - 每段标一个状态：还说不清 / 正在面对 / 没在想。
- **F 人话化**：每段单独一次调用，只给本段和相邻两段的条目。只许改说法，不许增删理由；改完由评委核对原因有没有丢、有没有加。
- **G Center**：全曲写完后，根据关系图写成一句最小的关系句。先出 3 个候选，两个模型各挑一次；不能写成列表，要说人话。
- **H 评成品**：用校准过的评委比较新成品和 v8，逐个关键位置写理由。另请 GPT 顾问提改法，然后迭代。只给你看成品。
- **I 不得回退验收**：对每个关键段，先从过去所有版本（N8、B0、60d–60g、61d–61g、旧修正稿）里找出这一段曾经得到过的最好解释。然后问新成品：保住了它的价值，还是用更好的理解取代了它？不要求照搬旧答案，但回退了必须明确判出来，不能因为新成品整体更顺就放过。

| 测试段落 | 必须通过的检验 |
|---|---|
| Op.60 17–23 | 漂浮、急切和暗流都得到恰当对待，不能只解释舒服 |
| Op.60 24–34 | 说明第二次亲近为什么更迫切，不能只说“更投入” |
| Op.60 35–39 | 解释突然失去支撑，不能沿用前一段的欢悦 |
| Op.60 93–102 | 不只是情绪增强，还要有前面的经历带来的新意义 |
| Op.60 103–110 | 区分“已经得到释放”和“情绪仍停不下来” |
| Op.61 24–65 | 庄严和脆弱都要理解到，不能只剩尊严和力量 |

### 4. 试跑顺序
- **先跑 Op.60 的 1–39**，再接着跑到 93–110，用来检验离得很远的历史能不能接上。这两步过了，再跑全曲和 Op.61。
- **试跑时重点看五件事：**
  - 多个候选合在一起，是否真的比单篇解释得更多；
  - 有没有为了覆盖而让心理逻辑重新膨胀；
  - 有没有保住旧版本已经得到的有效理解；
  - 跨段因果是否自然，还是一堆各自独立的情绪原因；
  - 选出来的东西能不能用普通人的话说清，而不靠抽象标签。
- 这五点成立之后，再做 E、F、G。

### 5. 讨论里的问题分别怎么解决

| 问题 | 解决办法 |
|---|---|
| 整路剪枝丢掉局部好解释（60d、60f 的 24–34） | 池子永不删；逐段挑；C 回头 |
| 评委以“侧面”放过漏掉的内容（60e 的 17–23 暗流） | A 要求每颗珠子都有着落；角色标签不代表重要性 |
| 只宣布结果、没有机制（“更想把心意放深”） | A 单独判“讲原因还是宣布结果”；校准负例 |
| 同一个理由包办全曲（“珍惜所以怕失去”） | A 判“放到别段也成立吗”；理由相同就合并，不重复写 |
| 编人物前史和设定（v7 开头、共同体与责任） | 前提必须能在已选历史里找到编号；“编造设定”单列；开头不交代过去 |
| 把珠子里的比喻写成他的事（“那句话”） | 线不复述珠子的意象；校准负例；不再要求“写他具体在做什么” |
| 好解释接不上历史（d9L 的 24–34 需要前面的“不安”） | 解释好坏和历史接不接得上分开评；C 回头 |
| 相容的解释能不能并存 | A 区分理由相同、可以并存、互相排斥三种情况；成品仍是一条线 |
| 上下文长、规则多，影响解释成形 | 挑选只看三样输入，提示词短；格式要求放到 E、F |
| 字数压力逼出抽象（45 字/100 字） | 挑选阶段不限字数，只在 F 控制长度，而且不许丢原因 |
| 强制每段两条、强制每段有新转折 | 条数由解释决定；允许“只是延续” |
| 评委只给相对排名、理由和结论对不上 | 先给绝对判断；用校准样例测过关；对不上的作废；我自己抽查 |
| 所有稿子都解释不了某颗珠子 | 先过覆盖关；还有剩下的就用 D 定向补，标“新增” |
| 音乐方向读反（d9S 的 35–39） | 覆盖评审判“相反”的不进池 |
| Center 写成重叠的列表、不说人话 | G 放到最后，写成一句关系句 |
| 箭头硬连 | 箭头只来自挑选时记下的“依赖的历史编号” |
| gpt6 和 gpt56 谁更适合做挑选 | 同样的输入各跑一遍，对比结果 |
| 屏幕排法 | 暂停 |
| 为了覆盖珠子，重新制造心理步骤 | 逐颗核查：可以被同一条解释覆盖，也可以作为相容的感受独立保留，不要求每颗都有因果 |
| 局部都说得通，但连不成一条线 | 中途和写完后各做全局连贯检查 |
| 好解释需要的前提在很久以前 | 按依赖关系回头，不限 3 段；回头后重查所有下游 |
| 补缺变成硬凑理由 | 允许补缺失败，先分清三种原因 |
