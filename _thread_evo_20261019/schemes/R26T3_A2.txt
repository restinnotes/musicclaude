下面是同一首器乐作品的几条 Thread 人物经历候选。

你完全看不到珠子，不依据音乐局部细节选择路线。

你的任务是选出最有可能写成一条独立成立、有具体利害、自然发展、简洁且像真实人物经历的 Thread 的候选。

【先把每条路线连起来读】

暂时忽略 delta_type、depends_on 和 established，按顺序只读 situation 与各段 state。

先问这究竟是一个人在经历什么，而不是一组什么样的感受。

一、检查整件事是否有可理解的利害

- 人物实际想要、珍惜或不愿失去的是什么？
- 他具体顾虑什么，为什么不能轻易顺着自己的愿望走？
- 愿望与顾虑之间有没有真正相互牵制的地方，而不是只被并列列出？
- 这些内容是否来自 Center 和已有处境，还是需要凭空增添事实才能成立？
- 后半篇是否仍然受到这些具体利害的牵动，而不是逐渐只剩情绪名称和笼统态度？

具体不等于有更多生活细节。不要为了得到清楚的故事而奖励未经输入建立的外部事件、前史或他人反应。

也不要因为候选没有这些事实就自动认定它缺乏发展；有前因、有后果的内心经历本身可以成立。

二、检查前面的经历怎样使后面不同

连续读完后，回答：

- 哪些早先成立的感受、愿望、顾虑、判断或选择，使后面的内容成为可能？
- 人物后来想要的、害怕的、愿意承担的或无法再轻易接受的东西，究竟有什么不同？
- 后面的变化是由之前经历引出来的，还是只因作者需要另一个情绪阶段？
- 同一种感受再次出现，是否真的具有前文造成的不同意义？
- 后半篇是否多次重新确认已经成立的愿望、认识或决定？

做一次删除检验：设想拿掉中间几个阶段，后面主要的处境、想法与结尾还能不能原样成立？

如果大部分阶段删去或互换后影响很小，说明路线可能只有主题持续，没有足够的经历积累。

这不是要求每段都有新发展。必要的停留、沉浸和延续可以存在；要检查的是整篇而不是强迫每一段交出转折。

三、检查是否落入两种相反的失败

第一种：用心理办法循环推进。

如果整条线的主要发动机是人物提出自我管理办法、实行、检查效果、换办法，即使步骤严密，也要检查它是否把真实的利害缩成心理程序。

第二种：为了回避无依据的事件与办法循环，把经历削成不同强度和组合的情绪。

如果人物始终只是珍惜、失落、紧张、放松、再次珍惜，具体所求和顾虑没有进一步发生作用，就不能因为它没有虚构事实、也没有明显重复句子而认定它是一条好的线。

真正的发展不等于情绪变强或变弱，也不等于转折多、决定多或认识多。

人物可以反复犹豫，可以一直不能解决问题；关键是他经历了什么，使后来这一阶段不同于最初。

【核对事实来源和内心变化的前因】

找出支撑后续多个阶段的关键事实、认识、愿望与选择。

逐项检查：

1. 这项内容最初如何成立？输入是否真的支持它？
2. 如果它是人物新的心理认识，前面是否有足够的亲身体验使它自然出现？
3. 有没有把尚未证实的期待、推测或担忧当成事实？
4. 有没有把意向、决定或尝试写成已经取得的现实结果？
5. 有没有靠含糊描述暗示某项行动已经发生或得到验证？
6. 有没有突然增加他人的态度、反应、既往经历或新的现实关系？
7. 如果抽掉这一关键内容，后面的因果是否随之失效？

established、delta 和 depends_on 只是记录，不是证明。必须回到 state 实际内容核查。

不要把‘人物想到新的可能’等同于‘新的事实已经发生’；也不要因为不允许虚构事实，就否定有根据的内心变化。

【比较路线质量】

从以下五个维度评价：

- coherence：1–10。是否独立读得懂同一个人持续经历的一件事；具体所求、顾虑及其相互牵制的地方是否清楚？
- forward_motion：1–10。前面经历是否真正改变后面在意的事、面对的取舍、内心态度或实际处境；中间阶段是否不可随意删除、互换？不按转折次数打分。
- prerequisite_integrity：1–10。重要事实、认识、愿望、选择及后续结果是否有真实依据；有无无来源的重要支点？
- non_repetition：1–10。不同阶段是否各有作用，是否避免重新完成同一心理变化、重新解释同一矛盾，或仅调整情绪强度？
- human_plausibility：1–10。是否像一个真实的人在经历有切身利害的事，所求、顾虑和感受能否用普通话理解，而不是抽象心理说明？

不要让某一维的高分替代另一维的实质缺陷。

覆盖事实边界良好，却失去具体所求和后续发展，不是优秀路线。

故事发展鲜明，却依赖新增外部事实或凭空验证的结果，也不是优秀路线。

【选路】

对每条路线输出原有的五项分数和主要问题。

主要问题必须指出整条经历真正的薄弱处：它究竟是缺少具体利害、后半段失去这些利害、阶段发展可以任意互换、依靠心理办法循环，还是依靠无来源事实。

选出最多 3 条进入下一步，按优先顺序排列。可以少选，不必凑满。

优先选择在不补造事实的前提下，既能保留可辨别的所求与顾虑，又能让早先经历持续影响后面的路线。

不要修改候选，不补写前因，不设计最终文案。

沿用原有 JSON 输出字段和结构。

只输出 JSON。
