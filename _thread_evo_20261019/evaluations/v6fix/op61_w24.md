# Op.61｜关系图（在 v6 上修补，w24）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他心里有股不肯停的劲，却说不清在等什么、舍不得什么，整个人还没缓过神来。
- → 他怕由着事情照旧就等于认了它们本该如此，便硬撑着不肯倒下，也想停一停，怕真投进去会失去别的东西。
- → 熟悉的感觉一回来，他就下意识想继续，可过去不会因此回来，他还想找个理由才敢往前走。
- → 每次刚觉得想通，舍不得又回来，连那点确信也变得陌生，他也为非得想透才肯动而难堪。

### S02｜24–65 小节　（正在面对）

- 从前他总要先问值不值得，如今还没想透，也先接下自己能做的一份，尽力去做。
  - ← 改写：（1–23）「非得想透才肯动」
- → 结果还没把握，疑虑和牵挂也还在，可他做着做着有了些力气，也有点骄傲，越投入越痛快。
- → 他还是舍不得那些说不清的珍贵东西，它们仿佛还在，却已不能像从前那样拥有。
- → 一察觉失落，他就急着把心思拉回眼前，反复劝自己撑得住，越劝越显出他其实很在意。
- → 他不甘心就这样垮下去，可一想到仍放不下的事，刚撑起的劲又泄了，只好重新提起劲，心里始终安顿不下来。

### S03｜66–91 小节　（正在面对）

- 他真往前走了，少问自己该不该走，也庆幸没退，可他还是拿不准该往哪使劲，心里恼火又不甘。
  - ← 提供理由：（24–65）「珍贵东西」
- → 他想要自在亲近、不必时时防备的生活，想到它便松口气，眼下还做不到又难受，却仍顺着轻快过了一会儿，不急着问自己为何非得用力。
- → 轻松退去，眼前的难处还在，他又想起当初不肯再等、先做能做的那一份，也怀疑刚才那股劲是不是真心。
  - ← 唤起：（24–65）「先问值不值得」
- ⟲ 仍在起作用：（24–65）「始终安顿不下来」

### S04｜92–115 小节　（正在面对）

- 轻松退去后，他还记得那一步确实让自己重新动起来，所以仍愿意坚持。
  - ← 唤起：（66–91）「不肯再等」
  - ← 提供理由：（24–65）「越投入越痛快」
- 他真尝过那份亲近带来的快乐，当时的坚定也有他努力撑住自己的成分，可眼下不安没让他认定那一步错了。
- → 他怕停下就得承认那份亲近回不到从前，便硬撑着把自己催得停不住，脑子反复追问过去还能怎样。
- → 可他还想要那种不用防备的亲近，光靠坚持仍没法让他安心。

### S05｜116–147 小节　（正在面对）

- 那一步曾救他脱离犹豫，行动明明还不够，他却舍不得松手，怕承认失望就是变心，便逼得更紧。
  - ← 提供理由：（92–115）「重新动起来」
- 他想到那种不必防备的亲近，心里便软下来，却怕自己一软就停步。
  - ← 唤起：（92–115）「光靠坚持」
  - ← 说明：（92–115）「反复追问」
- → 他明明受苦、也想停一下，却把难处当成还没克服的迟疑，仍逼自己往前。
- → 他曾在行动中感到有力量，便要求自己一直撑住，一累就怪自己不够坚定，连歇一下都觉得不该。
  - ← 提供理由：（24–65）「越投入越痛快」
- → 他发现自己明明已经累了，还在逼着一个累了的人硬撑，终于不想再证明自己多坚强。
- → 他有些茫然，终于松了劲，却没因此安心下来，这才肯承认自己舍不得那种不必防备的亲近。
- ⟲ 仍在起作用：（92–115）「光靠坚持」

### S06｜148–180 小节　（没在想）

- 催逼停下来后，他发现自己舍不得的不是一时舒服，而是曾真心相信过的生活。
  - ← 提供理由：（116–147）「逼着硬撑」
  - ← 说明：（116–147）「不必防备的亲近」
- → 他盼着和人亲近时不必时时防备，也盼着珍惜的东西不用靠争抢才能留住。
- → 他想付出时只是因为喜欢，不必反复证明自己值得被爱、被接纳，也不必先想着靠近会受伤。
- → 他确实尝过那种亲近带来的快乐，不愿只因眼下做不到，就把这份向往说成软弱。
  - ← 提供理由：（92–115）「亲近的快乐」
- → 他暂时不再担心心里一软就会停步，才肯承认自己也有委屈和思念。
  - ← 提供理由：（116–147）「逼着硬撑」
- → 他允许自己去爱、去相信，先珍惜心里向往的生活，不急着求它实现或证明有用，也不拿责任和它比轻重。
- → 他终于能安心地想那种生活，心里满足、柔软起来，也更盼着有一天能过上那样的日子，先前的疲惫暂时淡了。
- → 这份安宁让他一时不愿把心思拉回眼前的难处，可他盼着的生活还没有真正来到。
- ⟲ 仍在起作用：（66–91）「自在亲近」

### S07｜181–205 小节　（正在面对）

- 熟悉的亲近让他觉得生活近在眼前，身体先绷紧，才察觉现实没变；他懊恼怎么又沉进去，忘了还有事要面对。
  - ← 唤起：（148–180）「盼着的生活」
- → 他当初不肯再等，是怕珍惜的东西继续受损，光在心里想着那种生活也护不住它们。
  - ← 提供理由：（24–65）「珍贵东西」
- → 他想重新投入，却已不能毫无顾忌，怕自己又只顾硬撑，把刚找回的温柔磨掉，连想留住的生活也顾不上。
- → 他原以为想清为何不能再等就能安心，如今还得想怎样争取才不伤温柔，理由更多了，还是定不下来。

### S08｜206–213 小节　（没在想）

  - ← 提供理由：（148–180）「盼着的生活」
- → 他心里暂时松下来，知道这点安静留不久，仍觉得欢喜，也舍不得它退去。

### S10｜216–225 小节　（正在面对）

  - ← 提供理由：（148–180）「亲近带来的快乐」

### S11｜226–241 小节　（正在面对）

- 他心里仍没底，开始重新想眼前还能承担什么。
  - ← 提供理由：（216–225）「选边的劲也松」
- → 他已经试过，行动带来的力气并不能消掉对那种生活的牵挂。
  - ← 说明：（24–65）「越投入越痛快」
- → 他想到，难处不在自己不够坚定：行动给他力气，那种生活给他安慰，两样都舍不得，却很难不伤到其中一样。
  - ← 改写：（116–147）「把难处当成迟疑」
  - ← 提供理由：（148–180）「亲近带来的快乐」
  - ← 限制：（181–205）「磨掉温柔」
- → 想到要付出的代价，他心里还是疼，盼着别失去太多。
- → 他没想出两全办法，也怕争取伤到安宁，可不争取也护不住珍惜的东西，他仍带着怕先去争取。
  - ← 提供理由：（181–205）「不肯再等」
- ⟲ 仍在起作用：（181–205）「磨掉温柔」
