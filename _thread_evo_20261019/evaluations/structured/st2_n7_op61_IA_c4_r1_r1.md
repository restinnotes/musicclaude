# st2_n7_op61_IA_c4_r1_r1

**这件事：**一个总因迟疑而不敢承认自己意愿的人，逐渐学会带着真实的顾虑和柔软作出选择，并在日后的动摇中继续承担自己的选择。

**走向：**他起初一有疑问就撤回意愿，后来尝到果断带来的力量，却把坚定变成了必须证明自己永不动摇的要求。接着，他看见柔软、求支持和顾及他人都是真实需要，而这些需要未必能同时满足，理解也无法替他免去取舍。最后，他开始在不确定仍在时认领当下的选择，并把坚定理解成动摇时仍愿重审、决定和承担的能力。

### 1–23

**他明明知道自己想要什么，却一有疑问就把自己审回原点。**
→ 于是追问他缺理解还是行动的勇气

### 24–65

**他终于敢说“我就要这个”，舞步昂扬起来，他却急着证明自己不会改口。**
← 因为（1–23）长期自我审查让他急着结束旁观，试着认领已有意愿
↺ 原以为要想得更周全才敢选；果断带来力量，他却把它变成不许反复的考验。
→ 于是把坚定推成身份考验

### 66–91

**他开始怕，为了站稳，连心软和对复杂的诚实也被自己压下去。**
← 因为（24–65）他把坚定当成自我证明，其他感受因此像成了威胁
↺ 原以为犹豫只是胆小，现在看见顾虑里也有不愿舍弃的价值。
→ 于是寻找能容纳柔软的坚定

### 92–115

**他重申原来的决定，却发现被压下的顾虑仍在旁边流动。**
← 因为（66–91）他已承认柔软和顾虑有真实价值，不能再全当软弱
↺ 原以为再把决心拧紧就能找回早先的踏实，现在知道冲突仍在。
→ 于是从压住顾虑转向辨认它们

### 116–147

**他终于承认也想有人懂、有人扶一把，轻声旋律像肯听他把话说完。**
← 因为（66–91）他已承认柔软有真实价值，开始追问它藏着哪些需要
↺ 原以为渴望依靠说明自己没出息，现在知道求支持和承担责任可以并存。
→ 于是把羞耻转成具体需求

### 148–180

**音乐柔下来，他反而更难选：每个愿望都重要，却没法全顾上。**
← 因为（116–147）被压住的需求得到承认，也显出彼此冲突的地方
↺ 原以为理解并接纳自己会让心安定，现在发现取舍仍有损失。
→ 于是接受选择必然有代价

### 181–205

**他愿承担遗憾，却又怀疑这么挣扎算不算坚定，旧旋律又来催他。**
← 因为（148–180）他已看清每种选择都有损失，拖延也在付代价
↺ 原以为坚定要证明自己不会反复，现在尝试在知道代价后仍然选择。
→ 于是从求确定转向承担代价

### 206–213

**刚下决心，“可是”又来了；慢主题提醒他带着心软往前走。**
← 因为（116–147）他已承认想被理解、获得支持也是自己的真实需要
↺ 原以为重申决心就能压住冲突，现在让柔软留下，也不让它独占决定权。
→ 于是练习让两边同时在场

### 214–215

**开头那种摇摆又回来了，但他已知道自己想要什么、怕失去什么。**
← 因为（206–213）决心与柔软仍同时存在，旧日的拉扯便再次浮现
↺ 原以为摇摆说明自己根本不清楚，现在发现愿望和代价都清楚，冲突仍在。
→ 于是把旧日茫然变成清醒的拉扯

### 216–225

**断续的旋律回来，他还发抖，却肯承认自己心里仍想试试。**
← 因为（214–215）他已分清愿望与顾虑，知道摇摆时自己仍有明确所求
↺ 原以为只要还有一部分反对，整个意愿就不算数；现在肯承认它仍真实。
→ 于是从承认愿望走向实际选择

### 226–241

**他不再考核自己够不够坚定，舞步重新聚拢，他开始为选择负责。**
← 因为（92–115）他已发现加大决心也压不平内心冲突，不能再等它消失
↺ 原以为要先等内心一致才有资格决定，现在愿在仍有疑问时负责。
→ 于是把理解落实为行动

### 242–253

**他终于认领这个选择，心软和害怕都还在，昂扬的主旋律也回来了。**
← 因为（226–241）他已把焦点转向愿不愿为眼下的选择负责
↺ 原以为明确就得压下其他感受、保证以后不变，现在能带着它们负责。
→ 于是明确作出并认领决定

### 254–288

**他知道还会动摇，却不再抹掉旧努力；抒情和昂扬终于汇在一起。**
← 因为（242–253）他已经在保留顾虑时认领过选择，知道矛盾仍在也能行动
↺ 原以为坚定就是永不改口，现在允许柔软和冲突重来，仍肯重审并负责。
→ 于是在每次动摇中重新认领选择
