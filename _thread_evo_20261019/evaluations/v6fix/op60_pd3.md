# Op.60｜线（pd3）

**Center：**亲密的幸福与留不住它的痛楚难以分开

### S01｜1–3 小节　（正在面对）

- 那段亲密关系已经结束，他却依然舍不得曾经与对方亲近的感觉。
- → 每当想起那时的幸福，他就怕紧跟着想起如今再也不能那样亲近，于是常常让自己别再往下想。

### S02｜4–16 小节　（正在面对）

- 这一次，他没有像往常那样避开，而是任自己重新想起那份亲近。 〔1–3 ②〕
- → 熟悉的温暖仍能让他高兴，他没想到自己还能这样真切地感到曾经的幸福。

### S03｜17–23 小节　（没在想）

- 他愿意在这份温暖里多待一会儿，不急着把回忆收起来。 〔4–16 ②〕
- → 这时他只想念那种能够靠近对方的感觉，暂时不去计较回想之后会不会更难过。

### S04｜24–34 小节　（正在面对）

- 想得越亲切，他越觉得只在心里记得还远远不够。 〔17–23 ①〕
- → 他真想重新拥有那种亲近，像从前一样因为靠近对方而感到安心。
- → 明知已经回不去，他还是忍不住盼着这份记忆能继续给自己从前那样的依靠。

### S05｜35–39 小节　（正在面对）

- 他还想沉在那份亲近里，可一想到现在已经失去，心里就难受得厉害。 〔24–34 ②〕
- 他知道盼望不会让关系重新开始，却仍舍不得放下刚刚生出的愿望。 〔24–34 ③〕

### S06｜40–50 小节　（正在面对）

- 他开始一遍遍在心里追寻过去的感觉，想把那份亲近牢牢留住。 〔24–34 ③〕〔35–39 ②〕
- → 他越怕记忆变淡，就越逼着自己把幸福想得和当时一样真切。
- → 这样想下去，他越来越难感到先前那种自然的温暖，反而被疲惫和难过缠住。 〔4–16 ②〕

### S07｜51–61 小节　（正在面对）

- 即使回想已经让他这么累，他还是很想回到曾经与对方亲近的时候。 〔40–50 ③〕
- → 他为自己再怎么舍不得也改变不了现在而难过，一时连放松回忆都做不到。

### S08｜62–71 小节　（正在面对）

- 渐渐地，他不再逼着自己把过去的幸福想得那么完整。 〔40–50 ③〕〔51–61 ②〕
- → 他仍舍不得那份温暖，又不想再把自己弄得疲惫，只能先这样带着失落停一会儿。

### S09｜72–77 小节　（正在面对）

- 他又想起曾经的幸福，这一次只让自己为拥有过它而高兴片刻。 〔62–71 ①〕〔4–16 ②〕
- → 他知道那份亲近不会因此回来，心里也仍有痛，但这次没有急着压住那点高兴。 〔24–34 ③〕

### S10｜78–83 小节　（没在想）

- 他继续留在回忆里，心里有了一点久违的安稳。 〔72–77 ②〕
- → 那份亲近依然令他眷恋，他暂时只顾着怀念，没有再去想怎样把它留在现在。

### S11｜84–92 小节　（正在面对）

- 曾经的幸福又变得十分鲜明，他愈发舍不得那段能够依恋对方的日子。 〔78–83 ②〕
- → 想到如今不能再那样亲近，他又疼得厉害，刚才的安稳也守不住了。 〔78–83 ①〕
- → 他虽然难受，仍没有像最初那样马上打断回想。 〔1–3 ②〕〔72–77 ②〕

### S12｜93–102 小节　（正在面对）

- 他一度想躲开这阵疼痛，可又舍不得连那份幸福也一起推远。 〔84–92 ②〕
- → 这一次，他没有逼自己在怀念和放下之间立刻选一个，就让幸福和失落同时留在心里。 〔72–77 ②〕〔84–92 ③〕
- → 即使想起那段亲近仍会痛，他也愿意承认自己曾经因此十分幸福。

### S13｜103–110 小节　（正在面对）

- 他再想起那份温暖时，心里仍会疼，却没有急着把回忆赶走。 〔93–102 ③〕
- 他也不再像先前那样，非得把每一点亲近都牢牢记住。 〔40–50 ②〕〔93–102 ②〕

### S14｜111–116 小节　（正在面对）

- 他仍然舍不得那份亲近，却没有再逼自己把它从过去带回现在。 〔24–34 ③〕〔93–102 ②〕
- → 此刻他愿意让曾经的幸福继续留在心里，哪怕想起它时仍有失落。 〔93–102 ③〕
- → 以后再想起那段关系时，他能不能仍然这样承受，他还不知道。
