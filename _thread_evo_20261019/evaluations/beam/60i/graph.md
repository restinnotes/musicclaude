# Op.60｜关系图（逐段综合 60i）

**Center：**亲近的欢喜与感情的分量彼此牵连，脆弱与酸楚也伴随其间。

### 1–3　（还说不清）

- 他对自己的反应感到意外：这份感受竟显得很有分量，让他一时拘谨。

### 4–16　（没在想）

- 亲近让他暂且放松，他愿在这份温柔里多待一会儿。

### 17–23　（没在想）

- 亲近后的舒适让他一时出神，心思从有意多留转为自然沉浸。
  - ← 改写：（4–16）「亲近带来安适」
- → 早先那份令他意外的分量偶尔牵动心绪，闲适间掠过一瞬急切。

### 24–34　（还说不清）

- 亲近时的舒心让他察觉自己被触动得更深，脆弱中还夹着羞怯。

### 35–39　（还说不清）

- 亲近带来的轻松暂时退去，他独自觉出自己受影响之深，羞怯也显露无遗。
  - ← 改写：（24–34）「亲近里的脆弱」

### 40–50　（还说不清）

- 脆弱独自显露后，他心头稍稍一松，尝到短暂而陌生的自在。
  - ← 改写：（35–39）「脆弱显露」

### 51–61　（没在想）

- 那点自在让亲近的欢喜舒展开来，也生出主动靠近的渴望。
  - ← 改写：（40–50）「自己的余地」
  - ← 提供理由：（4–16）「亲近带来安适」
- → 满心热切，他沉浸在亲近时鲜活的感受里。

### 62–71　（没在想）

- 那份欢喜让他一时心满意足，轻快地沉浸其中。
- → 欢喜稍退，一丝怅然浮上心头，他仍眷恋那份亲近。
  - ← 唤起：（4–16）「亲近带来安适」

### 72–77　（正在面对）

- 热切退去，他仍想靠近；这份心意显出他对亲近格外敏感，让他一时迟疑。
  - ← 提供理由：（62–71）「欢喜后的怅然」

### 78–83　（正在面对）

- 他对亲近的敏感暂时柔和下来，眷恋自然流露，心里也松快片刻。

### 84–92　（正在面对）

- 刚才那阵舒畅让他更坦然地感受亲近的喜悦，心底那份感情也显出分量。
  - ← 改写：（78–83）「敏感舒展」

### 93–102　（没在想）

- 亲近带来的喜悦充满心头，他全然沉入其中，连自我意识也暂时淡去。
  - ← 改写：（84–92）「欢喜坦然展开」

### 103–110　（正在面对）

- 他仍沉在欢喜里，先前欢喜稍退后才有的怅然却提前浮现，酸楚渗入此刻。
  - ← 唤起：（62–71）「欢喜后的怅然」

### 111–116　（正在面对）

- 他再次感到亲近的分量，心里带着郑重，也很清醒。
  - ← 改写：（1–3）「意外的分量」
  - ← 提供理由：（103–110）「欢喜里的酸楚」
