# Op.60｜关系图

**Center：**亲密的幸福与留不住它的痛楚难以分开

### 1–3　（还说不清）

- 感到自己被珍惜，便想再靠近一点。
- 热意刚起便害羞，仿佛高兴得太早、想要得太多。
- 他不怀疑对方心意，却不习惯依恋被坦然接受。
- 因太珍惜，不敢一下投入全部感情。

### 4–16　（没在想）

- 他的拘谨没让对方的温柔减少。
- 他发现流露依恋没有成为对方的负担。
  - ← 动摇：（1–3）「坦然接受」
- 后来渐渐不再为欢喜太明显而害羞。
  - ← 改写：（1–3）「高兴得太早」
- 在对方面前，不必装得更加独立从容。
  - ← 动摇：（1–3）「投入全部感情」
- 平日藏着的柔软，如今也能自然显露。
- 他开始愿意长久停留在这份安稳里。
  - ← 改写：（1–3）「投入全部感情」

### 17–23　（没在想）

- 眼前已很好，他仍盼彼此了解得更深。　✦ 满足照出未满足
  - ← 唤起：（4–16）「长久停留」
- 更深、更难说清的心意，会不会也被懂得？
  - ← 提供理由：（4–16）「对方的负担」
- 他甚至喜欢尚未抵达的期待，已不再为它不安。
  - ← 改写：（1–3）「投入全部感情」
  - ← 提供理由：（4–16）「欢喜太明显」
- 想到还有许多可以亲近的地方，心又热起来。

### 24–34　（没在想）

- 他越来越愿意相信，双方能不断敞开心意。
  - ← 唤起：（17–23）「难说清的心意」
- 也相信自己的热切会被同样珍重地接住。
  - ← 提供理由：（4–16）「对方的负担」
- 如今连自己的热情也觉得可爱。
  - ← 改写：（1–3）「高兴得太早」
- 他急着把柔软与欢喜全给对方，让对方也幸福。
  - ← 唤起：（17–23）「可以亲近」
- 仿佛爱意用不完，给出一点便更充盈。

### 35–39　（还说不清）

- 没有失去什么，也未受冷落，他却忽然紧涩。
  - ← 唤起：（24–34）「更充盈」
- 投入已深，他开始舍不得亲近有一点改变。　✦ 满足照出未满足
  - ← 改写：（4–16）「长久停留」
  - ← 唤起：（24–34）「让对方也幸福」
- 想到无法时时这样相待，便有一点难过。
- 难过仍轻，尚未妨碍欢喜，却隐隐感到无可奈何。

### 40–50　（正在面对）

- 他发现不必时时浓烈，也不必不断得到回应。
  - ← 唤起：（35–39）「亲近有一点改变」
- 只要彼此仍能不费力地懂得，他便幸福。　✦ 分清
  - ← 提供理由：（4–16）「不必装得」
- 如今只想安静亲近，感受信任仍然真实。
  - ← 改写：（24–34）「让对方也幸福」
  - ← 改写：（35–39）「忽然紧涩」
- 想到能如此相待，他生出近乎感激的温柔。

### 51–61　（没在想）

- 温柔持续，他更不急着索取什么。
  - ← 提供理由：（40–50）「安静亲近」
- 即使少了激动的满足，相互珍惜也已丰厚。
  - ← 提供理由：（40–50）「不费力地懂得」
- 他有时因对方这样好而生出疼惜。
  - ← 唤起：（40–50）「感激的温柔」
- 他开始觉得对方本身就值得深深珍惜。
  - ← 改写：（4–16）「对方的负担」
- 连高兴本身也让他有些动容，仿佛太深。
  - ← 改写：（24–34）「更充盈」

### 62–71　（正在面对）

- 开始希望对方往后也能自由、完整地快乐。
  - ← 唤起：（51–61）「对方本身」
- 他开始在意自己无法决定的那些喜忧。
  - ← 唤起：（51–61）「生出疼惜」
- 尽力给予也无法替对方承受所有难处。　✦ 办法的限度
  - ← 限制：（24–34）「让对方也幸福」
- 也无法保证以后永远这样美好。
  - ← 动摇：（4–16）「长久停留」
  - ← 改写：（35–39）「亲近有一点改变」
- 第一次清楚感到，对方有自己顾不到的一生。
- 他没有怀疑亲密，心里却添了牵挂与隐痛。

### 72–77　（正在面对）

- 因无法保证往后，更想把眼前的爱给足。
  - ← 唤起：（62–71）「无法保证」
  - ← 改写：（24–34）「让对方也幸福」
- 此刻的温柔和相通的快乐至少都是真实的。
- 他已不相信多给爱就能消除全部牵挂。　✦ 办法的限度
  - ← 提供理由：（62–71）「承受所有难处」
  - ← 改写：（24–34）「让对方也幸福」
- 每次感到对方亲近，他都格外动容。
- 他知道相通无法凭自己热切就得到。
  - ← 提供理由：（4–16）「对方的负担」
- 无力保护的难过未消失，只是暂时不刺人。
- ⟲ 仍在起作用：（62–71）「牵挂与隐痛」

### 78–83　（正在面对）

- 他渴望彼此完全懂得，再无抵达不了的地方。
  - ← 改写：（17–23）「难说清的心意」
- 这份渴望使他激动，也令他疲惫。
  - ← 唤起：（72–77）「都是真实的」
- 即使相爱，各自仍有不能由对方代受的感受。　✦ 办法的限度
  - ← 改写：（62–71）「承受所有难处」
- 他不责怪这点距离，却忍不住难过。
  - ← 唤起：（62–71）「无法决定」

### 84–92　（没在想）

- 仍有抵达不了的地方，他却觉得彼此很近。
  - ← 改写：（78–83）「忍不住难过」
- 先前的渴望此刻仿佛都融进欢喜。
  - ← 改写：（78–83）「完全懂得」
- 他不再急求彻底保证，甚至无暇担忧以后。
  - ← 改写：（78–83）「令他疲惫」
- 此刻只觉得自己的爱得到最热切的回应。
  - ← 唤起：（72–77）「格外动容」
- ⟲ 仍在起作用：（4–16）「对方的负担」

### 93–102　（正在面对）

- 对方未有改变，他还在幸福里，却已怀念方才的充盈。
  - ← 唤起：（84–92）「最热切的回应」
  - ← 改写：（84–92）「无暇担忧以后」
- 他连自己也无法让那份圆满原样停住。　✦ 知道更多反而更尖锐
  - ← 改写：（35–39）「亲近有一点改变」
  - ← 提供理由：（84–92）「最热切的回应」
- 他开始舍不得幸福本身的流动。
  - ← 改写：（35–39）「亲近有一点改变」
- 他懂得每一刻亲密都有不可重复的美好。
- 仍感到被爱，眼前温柔却因不舍更动人。
- 那一点酸楚也融进更强烈的眷恋。

### 103–110　（正在面对）

- 此刻他仍不想少爱一点。
- 尝过深深的幸福，留不住才格外疼痛。　✦ 知道更多反而更尖锐
  - ← 提供理由：（93–102）「原样停住」
  - ← 提供理由：（84–92）「最热切的回应」
- 因为舍不得，更急着给出欢喜与疼惜。
  - ← 改写：（24–34）「让对方也幸福」
- 欢欣和疼痛此刻已难清楚分开。
  - ← 改写：（93–102）「更强烈的眷恋」
- 每次感到相通，都怕美好消逝一点。
- 这份热烈几乎让他喘不过气。
- ⟲ 仍在起作用：（62–71）「完整地快乐」；（78–83）「完全懂得」；（35–39）「亲近有一点改变」；（93–102）「幸福本身的流动」

### 111–116　（正在面对）

- 明知眷恋无法全满足，他仍爱得更加坦然。
  - ← 改写：（1–3）「高兴得太早」
- 那些不能长留的时刻，依然十分美好。　✦ 分清
  - ← 改写：（93–102）「原样停住」
  - ← 提供理由：（93–102）「不可重复的美好」
- 幸福里始终含着一丝酸楚。
- 曾如此亲密，使他生出一点骄傲。
  - ← 提供理由：（84–92）「最热切的回应」
- 他无意挽回什么，仍情不自禁倾注全部爱意。
- 幸福没能停住，却仍深深留在他心里。
  - ← 改写：（93–102）「原样停住」
- 想到它曾真实充满自己，又欢喜得几乎心痛。
  - ← 改写：（93–102）「更强烈的眷恋」
- ⟲ 仍在起作用：（103–110）「难清楚分开」；（103–110）「欢喜与疼惜」；（103–110）「留不住」
