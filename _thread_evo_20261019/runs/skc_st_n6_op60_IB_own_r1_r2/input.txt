← 因为（72–77）几种满足都已经被证实有价值，难题也已从感觉不足转为它们难以共同安顿；51–61早已说明，选择一边、压下另一边会带来损失。
← 因为（17–23）他过去就经历过从真实的亲密继续追问其根据，却无法因此获得长久保证的处境。如今他再次知道问题在哪里，却没有现成答案；62–71对停留和享受所得的尝试，也让他开始允许自己暂时不把不安转化成新的追逐。
↺ 原先他总希望继续分析就能找到足以消除冲突的答案，现在承认，看清问题和解决问题之间还有距离，暂时无解也不必逼自己马上选边。
→ 于是他只能带着尚未解决的矛盾回到具体生活中，尤其是重新面对那段曾经给过自己安全感的亲密，检验它能否容纳变化。

### 84–92

**他重新看这段曾经让自己安心的关系，想知道它能不能容得下一个不断变化的自己。**
← 因为（4–16）最初双方相互回应的亲密给过他真实的信任；24–34又让他确认这份关系有价值却有边界，因此现在需要检验它能否接纳新的需要，而不能继续要求它包办所有满足。
← 因为（40–50）主动成长曾让他感到充实，也让他担心原有关系平衡会被打破。78–83已经说明，看清亲密和成长之间的冲突还不够，他现在必须在具体关系里面对这个问题。
↺ 原先他因双方能够自然相互回应而信任亲密，现在还要看这份关系能否接纳他的成长，而不要求他停在原处。亲密是否能够容纳变化，成为一项尚未得到保证的事情。
→ 于是他开始尝试把成长带回关系，看看向前发展能否成为亲密的一部分，而不是每次都让他觉得自己正在离开重要的人。

### 93–102

**他开始发现，自己往前走也许能给亲密带来新内容，靠近别人也仍能保有自己。**
← 因为（84–92）他重新检验关系能否接纳变化，开始看到一种可能：早在4–16就成立过的亲密与自我保有，或许也能容纳40–50所经历的成长，而不必要求他回到原来的状态。
← 因为（62–71）他已经实际体验过成长带来的充实，也学会承认享受所得的价值；72–77进一步指出多种满足需要共同进入生活。现在，他可以把已经获得的自我充实带回亲密，而非只把它当成继续向外追逐的理由。
↺ 原先他容易把成长看成离开，把亲密看成退让，现在发现自我发展也可能成为关系的一部分。亲近别人不必自动要求自己缩小，主动成长也可能为双方带来新的内容。
→ 于是这份新的相容给了他希望，但还需要接受时间和情绪变化的检验。他接下来要看，热烈的满足退去后，这种共处是否仍有根据。

### 103–110

**他没有急着把这次靠近当成永久答案，开始看看热烈退去后，哪些愿望仍然重要。**
← 因为（17–23）他早已知道，真实发生过的亲近不能直接证明关系会永远成立。如今亲密与成长刚出现融合，他仍沿用同样的判断标准，不把一次成功的共处当成永久保证。
← 因为（93–102）亲密和成长刚刚出现相互容纳的可能，但这仍是一段需要继续检验的经验。它呼应35–39发现成长不可压低、40–50面对变化代价、51–61确认成长并非一时兴奋的过程，也接续62–71区分真实欠缺与追逐惯性的尝试。
↺ 原先他刚看到亲密和成长可以相容，现在知道一时的融合仍不能保证未来永远协调；需要也不必靠强烈的感受来证明。即使不安重新出现，也不能据此否定此前已经得到的满足。
→ 于是他开始进一步分辨哪些需要已经得到回应，哪些愿望仍然重要。最终，他要把这种判断带到所有满足之中，允许已有所得和未完成的愿望同时存在。

### 111–116

**他终于能让几种需要各自有分量：珍惜已经得到的，也允许自己仍有缺憾。**
← 因为（1–3）最初挤在一起、仿佛需要由同一个答案安顿的亲密、回应与自我保有的愿望，经过整段经历终于能够被分别辨认。他不再要求一种满足替其他愿望全部作答。
← 因为（103–110）他已经知道暂时的融合不能保证永久协调，而这一路的经历也让他确认：24–34说明有限的亲密仍值得珍惜，35–39与51–61说明成长不能被轻易压低，62–71让他学会承认所得的价值，72–77让他看见多种满足之间的共存难题，78–83允许他暂时没有答案，93–102则让他体验到亲密与成长可以相互容纳。
↺ 原先他想靠反复确认或继续追求找到足以安顿一切的满足，现在能承认每种需要都真实、各有边界，任何一种都不用替全部愿望负责。亲密有限仍值得珍惜，成长伴随不安仍然重要，已经满足过也不会因为后来还有缺憾就失去价值。
→ 于是往后仍会有新的拉扯，但他已经能够辨认自己需要什么、每种满足能带来什么，也知道它们各自做不到什么。他可以继续追求尚未实现的愿望，也可以停下来享受已有的生活，不必先把所有矛盾解决，才允许自己安心地活下去。
