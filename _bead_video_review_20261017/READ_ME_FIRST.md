# 这轮结论：保住好读的母稿，补清差异，再做随乐呈现

现版有不少鲜活内容，但它是一份有取舍的选编，尚不能称为“大部分原稿异质性都完整保留”的合并稿。上一轮检查了采用内容能否回到来源；那不等于检查了来源中的每一种不同意思有没有进入成稿。这一轮补做了反向核查。

## 覆盖究竟怎样

正式30份A对应353个原始单位。十四段局部Pool里有297个不同单位、559次出现；这些不是异质性分母。本次从局部Pool逐段人工归并了213条登记：

| 登记状态 | 数量 | 它说明什么 |
|---|---:|---|
| 完整保留 | 28 | 该意义族登记的关键差异在母稿中有表达 |
| 部分保留 | 85 | 主干或共同底色在，但仍缺少改变理解的差异 |
| 遗漏 | 64 | 母稿没有承载该听法，含尚需按演奏选择的条件候选 |
| 待核／隔离 | 22 | 事实、定位、绝对化断言或传记因果有问题 |
| 本段范围外 | 14 | 跨段全文里的具体事件不属于当前段 |

前三项合计177个按段意义族。若只在这份清单内计算，完整保留为28/177（约16%），至少触及为113/177（约64%）。**后一个数不能叫完整异质性覆盖率；前一个数也不是作品质量分。** 意义族划分很严格，一个主体或时间方向没保住，就可能从完整降为部分；不同族的价值和篇幅并不相等，跨段也可能登记相似意思。

这不是全体原A的精确覆盖率：51个GLOBAL单位未纳入局部审计，另有5个标题或错误范围单元单独说明，且人工归并不能证明字句级穷尽。因此，不能把这些数字包装成“所有原稿的意义已经量完”。详情见 [SCOPE_AND_EXCLUSIONS.md](SCOPE_AND_EXCLUSIONS.md)。

394处原A证据引句均经脚本核验，是相应原单位的连续片段。这支持追溯，不会自动证明每个审美判断正确。登记中的遗漏也不等于64处必须改写的错误：有的适合主片，有的适合另一版听法，有的值得留作候选，有的仍需核对音乐位置。

## 合并到底丢了什么

| 位置 | 现稿保留了 | 仍不能互相代替的意思 |
|---|---|---|
| S02 | 亲近、易碎、安慰中的微痛 | 眼前这一刻怕它消失；回忆过去，知道回不去也不要求回去。两者的时间位置与态度不同 |
| S02 | 两个人肩膀贴着低语 | 一个人内心的两种声音相互安慰。双人场景没有覆盖独处主体 |
| S04 | 越说越细、亲昵流连 | 因为更怕结束而越抓越紧，甚至喘不过气。不是同一个动因 |
| S07 | 夜里反复想谈话、沉迷感觉 | 深谈以后静下来，语言跟不上感受。这是心理安静，不能因错置sfogato的其他原文被一并删除 |
| S13 | 上方叹息、下方不让步、热烈中有刺 | 局部换气，以及特定演奏中逐渐收退的另一条路。不能宣布所有收退都错误 |
| S14 | 握手、余温、明确结束 | 握手是在告别；结束发生了，与“我愿意让它结束”也不同 |

有些合并确实成立，例如 S12 的重逢、拥抱、笑哭难分、身体先于语言，可以形成一个相容场景。但不能由这一处成功推出其他地方都已无损合并。

## 面向视频，我的判断

母稿约3048个字符，单段约155–290个字符。它适合停下来读；直接把整段铺在随音乐播放的视频上，会让观众同时寻找重点、理解比喻、追踪音乐。把文章逐句加圆点，仍未解决这一问题。

应保留自然语言，把画面按意义关系组织起来：一句场景、两件同时发生的事、相似乐句中的变化、确实发生的前后转变、一个微小动作，以及另一路听法。模式重复出现时，观众可以熟悉布局；文字仍然是“笑着笑着，表情忽然有一点僵”，而不是“反讽／张力／复杂性”。

这轮已经找回旧STRUCT、ATTN和render尝试。旧版有正确原则：音乐进新段不等于必须换屏，内部完整与实时显示应分开。但一个实际render样本将“终于被托住”的意思在同屏重复，又不断累积长条目。本次因此明确：保留仍有效的句子，只更新新增差异，撤下已经过时的内容。详见 [HISTORY_AND_DISPLAY_RULES.md](HISTORY_AND_DISPLAY_RULES.md)。

也不能为了宣称覆盖高，把所有不同读法快速轮播。主片、另一版本、片后附录、只留在研究材料，必须分别登记。普通导出视频没有“展开”按钮；网页展开里的内容不算观众已经在视频看过。

本次分镜已做桌面与手机排版、切换、筛选及引句核验。尚未做实际音频对齐或观众阅读实验，不能宣称已经提高了阅读速度或注意力。最终秒点应跟选定演奏的乐句校准，不用固定BPM猜测。
