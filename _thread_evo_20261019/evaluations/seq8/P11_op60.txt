《船歌》Op.60
Center：他珍惜对那个人的喜欢，这份心意给他温暖，也让他牵挂对方是否知晓、回应。

### S01 ｜ 1–3 小节

• 他忽然被一阵强烈的期待牵住，兴奋里夹着一点不安。
→ 他已经很想靠近，却还不知道这份亲近会不会得到回应。
→ 最初的激动渐渐柔下来，期待仍悬着，没能真正安定。
→ 他不能把自己的心动当成对方也愿意靠近，于是热切转成小心等待。

### S02 ｜ 4–16 小节

• 想到对方时，他渐渐安稳下来，心里有了温柔而持续的快乐。
→ S01让他不再用自己的心动替对方作答；眼下能确认的只有自己的喜欢，暖意便先属于他自己。
→ 他开始舍不得这份快乐很快过去，温柔里也浮出一点心酸。
→ S01让他开始等待对方回应；如今自己已尝到快乐，却仍不知对方是否同样心动，留恋便带着酸楚。
→ 心意忽然变得热切，随后缓和下来，留下想让对方知道的愿望。
→ S01让他不再把心动当成对方已回应；自己的快乐虽真实，却不能替对方表态，于是他想让对方知道。

### S03 ｜ 17–23 小节

• 那份温暖仍托着他，他暂时沉在其中，心像随水波轻轻漂着。
→ S02让他知道，未获回应的喜欢也能带来真实的快乐，所以他暂时沉在其中。
→ 沉浸里，他忽然想把心意递给对方，冲动刚冒头便又沉了回去。
→ S02让他想让对方知道心意；S01却使他不把自己的心动当成对方已靠近，冲动便停住。
→ 冲动退下后，他仍被对方是否知道、是否同样在意牵住，温柔里生出滞涩。
→ 他想让心意抵达对方，却不能从自己的快乐知道对方怎么想，思绪只得绕回这个未答的问题。

### S04 ｜ 24–34 小节

• 他再次清楚感到，喜欢对方本身能带来温暖，喜悦比先前更饱满。
→ 他早已发现，即使对方尚未回应，自己的喜欢也能持续带来真实快乐。
→ 喜悦渐渐急切，情意涨到几乎收不住；他想让对方知道心意。
→ 他知道，想让对方明白心意，并不等于对方已经明白。
→ 热烈渐渐退下，留下温柔的不舍；他不愿这份快乐就此过去。
→ 这份快乐确实存在，而对方是否知晓仍不确定；他舍不得它就此过去。

### S05 ｜ 35–39 小节

• 前一刻的饱满忽然退开，他心里空了一下，像暂时失去原先的着力点。
→ S02让他尝到喜欢本身的快乐；S04的表达急切却不能靠这份快乐直接完成。
→ 他从想着怎样把心意送到对方那里抽开，转而独自感受自己心里的那份心意。
→ S03已说明想让对方知道不等于心意抵达；S04一松，他才转回自己的心意。
→ 他不再紧紧攥住这一刻，表达的冲动轻轻退下，陌生感里渐渐有了一点轻松。
→ S04那股急着表达的愿望暂时不再催他往前，对方的心意仍未知，他却可以先停在这里。

### S06 ｜ 40–50 小节

• 他开始尝到一种更私密的满足：不急着表达，也能温柔地惦念对方。
→ S02让他知道喜欢本身能带来温暖；S05又让表达的急切暂退，他得以留心这种柔情。
→ 这份温柔里仍浮起一点酸楚，他不知道对方是否也这样想着自己。
→ S03让他明白，想让对方知道心意不等于对方收到；独自体会仍不能确认对方的心意。
→ 到后半，安静的惦念又牵出想与对方更亲近的愿望。
→ S04已确立他想让对方知道心意；S05让表达的急切暂退，而喜欢仍在。

### S07 ｜ 51–61 小节

• 清澈的柔情仍在，底下却涌出更直接、近乎身体性的渴望。
→ 他已发现柔情能安慰自己，却仍牵着他想靠近对方；沉进去后，愿望便有了身体热度。
→ 这股热度让他舍不得抽身；快感里混着遗憾，他明知被卷进去却暂时不想停。
→ 他能停留在私密柔情里，却不能凭自己的感受知道对方是否也靠近；快感因此未能抹去遗憾。
→ 沉醉仍是甜的，他却开始感觉这一刻正流过去，美好不能因此停住。
→ 他已不必急着推进下一步，能真正享受柔情；因此开始舍不得眼前的时刻过去。

### S08 ｜ 62–71 小节

• 他忽然从细密的眷恋转入明亮、直接的欢喜，暂时顾不上反复审视自己的心意。
→ S05让他能暂不推进下一步，S06的柔情又能安慰他，S07的身体渴望便有余地化成欢喜。
→ 欢喜一阵阵抬高，他又几乎忍不住想让对方也知道此刻有多快乐。
→ S02让他盼对方知道心意，S04又把愿望推成急切；这阵外放的欢喜重新点燃了它。
→ 快乐还在涌动时，他已感到它开始散开，心里先一步生出舍不得。
→ S07已让他难以忽略时刻流逝；这次快乐一松动，时间感便变成了对刚才的怀念。

### S09 ｜ 72–77 小节

• 刚才明亮外放的欢喜忽然收住，他一下安静下来，心里空了一块。
→ 那阵欢喜曾让他暂时忘了自己；它一退，身体才显出疲乏和落差。
→ 安静延续后，他开始舍不得刚才那一刻，失落渐渐浮出来。
→ 他先前已察觉欢喜将散；如今它真的退下，预感成了眼前的空隙。
→ 他仍想靠近，心里的渴望却悬着，没有立刻催他表达。
→ 他先前已体会到，私密柔情能安慰自己，不必立刻表达。

### S10 ｜ 78–83 小节

• 他感到一种柔软而开阔的释然：刚才的欢喜回不来，却仍然真实。
→ 因为他已承认回想不能使那一刻重现，而那份快乐曾真实地温暖过自己。
→ 他的注意暂时从已过去的欢喜移开，转向让自己如此欢喜的那个人。
→ 因为回想不能把那一刻带回，而私密柔情仍牵着他想靠近那个人。
→ 想到那个人本身，他感到深切的感激；对方是否也喜欢自己仍未知。
→ 他已知道自己的喜欢能带来真实温暖，所以此刻的感动不必先等对方回应。

### S11 ｜ 84–92 小节

• 静静的感动忽然涌成直接、坦荡的欢喜，他不再把爱意收得很轻。
→ 他刚能不等对方回应就感激那个人本身，感动因此不必停在安静里。
→ 熟悉的亲近感重新涌上来，他又想让那个人知道自己有多在乎。
→ 先前他已试过让表达的急切暂时退下、独自感受心意；所以想让她知道不等于必须立刻说出口。
→ 自己的欢喜终于充分涌出，却强到近乎发疼；对方是否也愿意靠近仍悬着。
→ 他知道欢喜会在仍真实时散去、过去不能追回；表达心意也不等于对方收到。

### S12 ｜ 93–102 小节

• 他被一阵明亮而巨大的欢喜卷住，暂时顾不上自己。
→ 先前的欢喜已能外放，对那个人的感激又把它系到那个人身上；亲近感重新唤起了分享心意的愿望。
→ 想让对方知道心意的冲动近乎恳求，快乐里也出现难以舒展的疼。
→ 他知道想传达不等于对方已收到；这次亲近只重燃愿望，没有替他完成传达。
• 他也舍不得眼前这一刻过去，欢喜里浮出快要来不及的心疼。
→ 他知道旧时刻不能重来，而此刻的欢喜又连着对那个人的感激。

### S13 ｜ 103–110 小节

• 他先感到一阵明亮的畅快，仿佛心愿终于被完整说出。
→ S12已让他发现，光是想让对方知道心意，就能带来忘我的欢喜。
→ 畅快没有让他停下，他仍想把这份欢喜留在眼前，反复确认。
→ 他已知道欢喜会在尚未结束时就开始散去，回想也不能复原此刻。
→ 明亮里浮出“可是呢”：欢喜仍真，酸楚与疑问却也进入其中。
→ S12带来的内在到达仍没让对方听见心意，S01、S03的等待与未抵达便重现。

### S14 ｜ 111–116 小节

• 临到收束，他仍忽然涌起一阵舍不得，珍惜和一点心疼又变得鲜明。
→ S08让他在欢喜未散时先尝到留恋；S13让未获回答的疑问仍留在幸福里。
→ 这阵激动过去后，他自己的情绪终于退下，身体才慢慢松开，先觉疲惫和空白。
→ S12把他卷进忘我欢喜，S13又让他知道，继续加力也不能替对方作答。
→ 空白退去，他重新感到对那个人的温柔；临到最后，珍惜又短暂地亮了一下。
→ S13的疑问仍未由对方回答；但S10让他能感激这个人，S09让他承认此刻已过去。
