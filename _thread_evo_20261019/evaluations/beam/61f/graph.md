# Op.61｜关系图（逐段综合 61f）

**Center：**旧日亲近的温暖与难以留住它时的失落，始终影响着继续生活的打算。

### 1–23　（没在想）

- 他看待周遭和自身都带着一层陌生感，连情绪也难以贴近；此刻最突出的是恍惚。

### 24–65　（没在想）

- 一丝熟悉的眷恋浮现，先前的疏离让它带着怅惘。
  - ← 限制：（1–23）「陌生与恍惚」

### 66–91　（没在想）

- 对旧日的想念愈发鲜明，他也更渴望感到亲近。
  - ← 改写：（24–65）「隔远的眷恋」
- → 安慰短暂浮现，心里仍隔着一层，想亲近也带着失落。
  - ← 限制：（1–23）「陌生与恍惚」

### 92–115　（没在想）

- 熟悉的亲切感涌上心头，他短暂尝到亲近的温暖。
- → 可回忆里的亲近难以原样重现，心里那层隔阂更让人难受。
  - ← 限制：（66–91）「安慰带失落」

### 116–147　（没在想）

- 亲近既曾真切温暖过他，他便不甘心让它只剩回忆。
  - ← 提供理由：（92–115）「亲近成为真实感受」
- → 不甘化作急切抗拒，心里仍隔着一层；力尽后抵抗才暂缓。
  - ← 限制：（92–115）「温暖照出失落」

### 148–180　（正在面对）

- 抵抗松动后，他更直接地感到自己仍想靠近，却不知能否如愿。
  - ← 提供理由：（116–147）「不甘只成回忆」
  - ← 改写：（116–147）「抵抗耗尽」

### 181–205　（没在想）

- 沉入熟悉的日常回忆，往日亲近反衬出眼下的疏远，失落久久不散。
  - ← 唤起：（92–115）「亲近成为真实感受」
  - ← 提供理由：（92–115）「温暖照出失落」

### 206–213　（没在想）

- 熟悉的日常片段再度带来亲近的暖意，失落暂时减轻。
  - ← 唤起：（181–205）「亲切显出缺席」
- → 往日亲近难以重现，暖意一来，便也泛起挽留不住的酸楚。
  - ← 限制：（181–205）「亲切显出缺席」

### 214–215　（正在面对）

- 那份亲近确实重现过，却仍转眼难留，他心里又没底。
  - ← 改写：（206–213）「暖意里的不舍」

### 216–225　（正在面对）

- 曾真切感到的亲近难以延续，往后的日子该怎么过又成了难题。
  - ← 改写：（214–215）「亲近难留」

### 226–241　（正在面对）

- 心里仍有不安，他开始愿意继续过日子。
  - ← 改写：（216–225）「往后难行」
- → 亲近仍难长久，这份心意因此显得试探而脆弱。
  - ← 限制：（214–215）「亲近难留」

### 242–253　（正在面对）

- 心里虽仍不安，继续生活的念头却渐渐清楚，往后该怎么过也有了头绪。
  - ← 改写：（226–241）「带着不安继续」
- → 亲近难以留住，让他短暂难过，随后仍照样过日子。
  - ← 限制：（226–241）「试探着迈步」

### 254–288　（正在面对）

- 旧日亲近让他更有劲儿过下去，他一时畅快地投入其中。
- → 亲近终究难以长留，失落又一次袭来，他最终决定继续往前。
  - ← 改写：（242–253）「明确生活方向」
