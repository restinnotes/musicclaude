# Op.61｜线（pd1）

**Center：**维持尊严的行动与对旧日生活及归属的怀念反复拉扯

### S01｜1–23 小节　（正在面对）

- 他与那群人如今已经有了距离，从前待在他们之中的自在却总让他惦记。
- 他不知道他们现在还愿不愿意亲近自己，便先守着分寸。
- 他怕自己的留恋一旦显出来，就像是在等别人赏给他一个位置。

### S02｜24–65 小节　（正在面对）

- 想着想着，他发现自己并不满足于只记得从前的日子。 〔1–23 ①〕
- → 他仍想以现在的自己回到他们中间，像过去那样被自然地当作一员。
- → 他盼的是彼此平等的亲近，而不是别人出于怜悯留一个位置给他。

### S03｜66–91 小节　（正在面对）

- 这个愿望越清楚，他越觉得自己好像在向那些人有所求。 〔24–65 ②〕
- → 这种念头使他难堪，他于是更用力地把想靠近的心收起来。

### S04｜92–115 小节　（正在面对）

- 收住心思之后，他至少觉得自己没有失去体面。 〔66–91 ②〕
- → 可那份没能亲近他们的失落依旧留在心里。
- → 他渐渐明白，守住距离并不能让自己不再需要那份归属。

### S05｜116–147 小节　（没在想）

- 他想起从前与他们相处时，根本不必猜自己受不受欢迎。
- 那时待在他们之中是很平常的事，他可以安心做自己。
- → 他舍不得那样的日子，暂时只想留在这份怀念里。

### S06｜148–180 小节　（正在面对）

- 那份安心越清晰，他越希望它并没有真的离自己远去。 〔116–147 ②〕
- → 可他知道，从前的亲近是真的，并不代表他们如今也还愿意一样亲近。
- → 他没有因此不想回去，只是不再把回忆当成现在得到的答复。

### S07｜181–205 小节　（正在面对）

- 少了这个可以依靠的想法，他更难受于如今的疏远。 〔148–180 ③〕
- 他仍舍不得那些人，却不能放心地相信自己在他们之中还有原来的位置。 〔148–180 ②〕
- → 他让这份难过继续留着，暂时没有再替他们猜一个答案。

### S08｜206–213 小节　（没在想）

- 他暂时把该靠近还是继续疏远的问题搁在一边。 〔181–205 ③〕
- 只是心里那点不安还在，他没法真的把那些人抛开。

### S09｜214–215 小节　（没在想）

- 他仍想回到从前那样自在的相处里。
- → 想到这个愿望还悬着，他心里酸了一下。

### S10｜216–225 小节　（正在面对）

- 想起自己越是克制越难过，他不愿再一味责怪自己的盼望。 〔92–115 ②〕〔92–115 ③〕
- → 他开始觉得，想让他们自然地接纳自己，并不等于低声下气地讨一个位置。 〔148–180 ③〕
- → 他仍不想讨好谁，却愿意让这份想靠近的心留着。

### S11｜226–241 小节　（正在面对）

- 可这样想过以后，他还是怕这一切终究只是自己的一厢情愿。 〔216–225 ③〕
- → 这个不确定仍让他不安，甚至有时又觉得难堪。
- → 不过这次他没有因为难堪就认定自己不该想靠近。 〔66–91 ②〕〔216–225 ②〕

### S12｜242–253 小节　（没在想）

- 他安静地想念过去那种不必小心证明自己的生活。
- → 现在的距离一旦浮上心头，那份温暖又叫他觉得寂寞。

### S13｜254–288 小节　（正在面对）

- 他依然愿意盼着与他们平等亲近，而不打算为此讨好谁。 〔216–225 ③〕〔226–241 ③〕
- 如今的他们是否还愿意接纳他，他仍不知道。 〔148–180 ②〕
- 他也还没有决定，自己会不会真的尝试靠近。
- → 他就带着这份没有着落的期待，守着眼下的距离。
