  词：92–107小节，熟悉的主题又回来，流动的伴奏和装饰音让它更像独自说话；旧记忆里的亲密、感激和短暂幸福都鲜活起来
线：可那份亲近越鲜活，当初那些委屈也跟着翻上来：那一步走得对不对，后不后悔？没走的话，如今又会怎样？
  词：92–107小节的温暖没有一路带来安稳；108–115小节忽然风暴般激烈、紧绷，半音阶下行像在撕扯中步步后退 / 不是记忆变坏了 是它太好了 / 细碎音符像急促的脚步、乱了拍的心跳；低音追赶，右手挣扎，身体像被节奏逼着往前跑 / 脑子里停不下来的“如果当时……”“是不是还可以……”越往前赶，思绪越盘旋，始终停不下来

### S05
线：他仍不服气，觉得当初那些气不该忍，可连过去开心的事都不敢多想，也太为难自己了。
  词：116小节起，音乐像换了一个人开口，歌唱柔和而克制；两只手仿佛夜色里两个影子，彼此低声说话 / 116–127小节，柔和的歌唱仍像被压力推着走，仿佛在说：“这件事不能就这样算了。” / 委屈和火气都在 还想替自己争口气 / 旧日记忆像重新有了温度，可能指向某个人，也可能是故乡或过去的生活；眷恋里仍带着失落
线：跟自己争得没了力气，那股不服气也渐渐淡了，想到自己如今已不在那些人身边，只觉得难受。
  词：128–147小节，快速音型渐渐放缓、变稀，最后化成较慢、较疏的和弦；旋律像忽然失去依托，只剩一个声音自己说话 / 132小节以后躁动和不安又加深；144–147小节像几次深呼吸，紧绷短暂松开，却更像抵抗得累了

### S06
线：心里那阵难受慢慢缓下来，他又想起以前和人在一起、不必时时防备的时候，这回没急着拿受过的气压住这份想念。
  词：148小节起，音乐滑进与此前隔开的静谧，像透明玻璃罩，也像耳边轻哼的摇篮曲；温柔得让人暂时松开戒备 / 近似圣咏的庄严里藏着秘密念头；像终于不用解释难过，也不用维持坚强，心里的愿望向远方发出，却没有回应的许诺 / 压在心底的委屈和想念终于冒了头
线：离开以后，遇上难熬的事，他常常只能自己挺过去，这才知道从前有人在身边能让自己轻松多少。
  词：约160小节，远方忽然被照亮，已经远去的家园在梦里显现；看得见，却回不去
线：他很想再过上那种不用多说也知道彼此亲近的日子，又怕以后再也没有了。
  词：148–151小节还含蓄试探；152–167小节歌唱逐渐展开；168–180小节更加充实、迫切，临近180却像停在一句没说完的话上 / 像终于鼓起勇气 把心里的话说出来
线：不过，那样的日子自己毕竟真真切切过过，光是这么想着，他心里也暖和了一点。
  词：像是放轻声音，好好看着珍惜的东西；明知有些事已经挽不回，也不必立刻把它抓回来

### S07
线：刚有点安心，他却猛然想到：以后再遇上难事，要还是只能一个人顶着，他真的撑得住吗？
  词：182小节附近，高音长颤音像寒风猛地吹开窗，后颈一凉，脉搏也剧烈跳动 / 甜梦一下碎了 身体先被惊醒 / 182–197小节，带马祖卡色彩的舞步突然闯入，截断先前祈祷般的静谧；换了场景，不等于心情好转
线：当初走时他只想着别再受那些气，没料到会这么孤单；早知道这样，自己还会走吗？
  词：熟悉的动作、一次舞蹈或一段习以为常的生活忽然闯进深沉的感受；越具体亲切，越看清自己失去了什么 / 198–205小节，连续颤音让紧张层层累积；思绪不停翻转，身体和情绪还没相信事情已经结束 / 心里直想冲出去 却找不到出口
线：他想找回从前那份亲近，又不甘心回去再受那些气，可连当初走时那股决心也找不着了。
  词：182–197小节，先前带宣告意味的波兰舞曲气息再次出现，却已不再以完整、鲜明的姿态建立秩序

### S08
线：他先把回去的事放一边，想起曾被当作自己人，心里暖了一会儿，却没因此想回头。
  词：缓慢、宽广的歌唱短暂回来，熟悉的柔软处重新打开 / 安静停留得太短，像已经准备离开的人最后回头看一眼：温柔，也不舍
线：可那点暖意很快就淡了，想到以后真遇上难事，回忆没法陪着他，心又悬了起来。
  词：激烈思绪之间，胸口仿佛终于吸进一口气；只是短暂喘息，并不是重新安顿

### S09
线：他忽然说不清，想回去是舍不得被当作自己人的日子，还是怕孤单到连那些气也肯再受。
  词：214–215小节，双手铺开巨大的颤音光晕，开头沉重的引子从中阴冷地闪现；声音短暂落稳，又向高处漂去，真正向前的步伐还没聚起来 / 那扇门又出现了 却不再像最初那样召唤 / 像重新遇见那个不知道怎么办的自己；只是这一次，已经知道那个过去的自己经历过什么，问题仍没有简单答案
线：这念头让他一阵心慌，连往下想都不敢了。

### S10
线：他慢慢觉得自己最舍不得的，还是从前有人把他当作自己人的日子；可就算真的回去，还能像从前那样吗？
  词：熟悉的歌唱与舞曲只剩轻弱、断续的碎片；摇篮曲也像在F小调里破碎重现，声音回来了，却没能完整铺开 / 221–225小节，零碎的声音让人忽然失重，整个人悬在半空，辨不清方向 / 明明很重要 却连从头讲一遍的力气都没了
线：当初那些让他难受的事也不能当作没发生过，光凭舍不得，他还是没法放心回去。翻来覆去想得很累，仍没个答案，连眼下的日子都过得不踏实。
  词：开头的试探又把问题递回来：我究竟要怎样继续生活

### S11
线：明知道回去未必找得回那份亲近，他却还是忍不住想：万一能呢？
  词：左手低音波涛般涌起，右手和弦像重锤砸下；每次爆发之后，紧张仍没有解除，反而又形成新的压力
线：他不愿只凭这点指望回去忍让；回不回以后再说，先把眼下日子过稳些。以后若还得独自扛事，他仍怕、仍没底，却不想因为害怕就把刚才的打算收回去。
  词：226–229小节，步子还在试探前方有没有路；随后一点点聚拢，到238–241小节，前进感越来越不可回避。害怕还在，脚却已经往前走了 / 像终于把心里的祈求变成往前迈的劲儿

### S12
线：他想，当初那些气不该忍，和那些人在一起也确实开心过，这回他不逼自己选边了。
  词：熟悉的波兰舞曲主题以雷鸣般的声势回归，沉重的步子终于踏实落地 / 像一个人终于站出来 也像一群人一起抬头 / 这份挺立像经历动摇后的主动选择：知道自己会犹疑、疲惫、想念，仍然决定怎样站立，不必假装从未受过伤
线：想起那些好时候，他还是会心软，也怕往后一个人熬；但他不再怪自己当初离开，更不愿只为有人陪着就回头，愿意带着想念继续过日子。
  词：249–253小节，脚步正往前时，音乐忽然换了一下色彩，像地面短暂斜了一下，随后仍继续向前

### S13
线：想起从前那些自然亲近的日子，他心里又热了起来，也盼着以后还能有那样的相处。
  词：柔软的、近乎祈祷的歌唱被带进开阔宏大的音响，像温柔的歌忽然站到了明亮处；温柔与力量一起涌起，也让人想到故土、共同记忆和希望
线：这么想着，他倒真有了劲头，想把往后的日子好好过起来，不再整天跟从前的事较劲。
  词：269–280小节，快速八度明亮、迅疾地向前冲，像被一股气流推着跑，兴奋得几乎来不及喘息 / 心跳像一下子被推到最高处
线：劲头稍缓，他又怕还要等很久，才能再遇上那样亲近的人，心里渐渐静了下来。
  词：281–287小节，冲势收敛，颤动般的装饰音又带来一点不安；刚建立的成功仿佛被轻轻问了一句：真的牢固了吗？回落也像终于能停下来喘口气
线：将来要是再有人愿意把他当自己人，他会好好珍惜；即使一直没有，他也愿意自己好好过下去，不再为了留住谁把那些委屈咽下去。
  词：狂潮退去，低音像呼出最后一口气，沉沉吐出两记耳语般的和弦；随后，高音区亮起透明、孤悬如寒星的一记和弦 / 286–288小节，最后的高音和弦可以听作一个决定，也可以听作从梦中骤然醒来
