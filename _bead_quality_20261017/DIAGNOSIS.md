# 质量损失：已经证实的部分与仍不能归因的部分

这次的主要问题是**好原料和坏原料一起进入了偏向解释的统合任务**。A本身有重复和错位，Pool有局部传输缺口，旧Bead把身体细节磨成了通用心理结论。现有实测不足以把主要责任归给GPT-6w的固定能力缺陷。

以下判断均可回到原文、实际提示词和独立响应。没有将更短、UID更多或模型自评视为更好。

## 1. A原文：有值得直接留下的句子，也自带问题

S02 的 Gemini 原文写：

> 他们的肩膀贴着肩膀，声音放得极低，仿佛任何大声喧哗都会惊碎眼前的幻觉。

> 就像夏末傍晚威尼斯水面上潮湿、温热的微风，裹在皮肤上甚至有些黏稠。

分别来自 [gflash-int-1 U04](sources/SRC-gflash-int-1.md) 与 [gflash-int-3 U05](sources/SRC-gflash-int-3.md)。它们让亲密有距离、温度和稍微不舒服的质地。旧稿已有“耳语”，却删掉肩膀相贴，把后一句变成“几乎轻轻贴在皮肤上”。可直接确认触觉浓度下降，不必先假设模型动机。

Muse 的另一个句子也很好：

> 像靠在船舷上，眼睛看着远处，不敢看太用力，怕把这片刻看碎了。

见 [muse-int-1 U03](sources/SRC-muse-int-1.md)。旧Pool已提供这段正文，旧Bead没有提及该UID。因此这是本可使用的独特表达没有进入结果；不能仅凭相近意思，断言旧稿的“怕动作大一点就惊醒”一定是由此改写。本轮正文也没有把所有好意象塞进S02：选了肩膀／皮肤／手掌，船舷与视线留在内部备选。

与此同时，原A多次自发解释“幸福太满所以怕失去”。部分Gemini原稿以病情、生命将尽解释音乐；Muse-int-2写成138小节、6/8；gflash-int-3把dolce sfogato放到m.51。**这些问题并非最终统合模型首次创造。** 本轮保留有原料支持的想象，排除错段依据及未经支持的传记因果。没有因为一句话漂亮，就认证整篇研究可靠。

## 2. Pool：没有发现全面语义压缩，确有上下文传输缺口

旧名义30份的354个unit，在统一换行后全部是原稿连续子串；连同继承标题对回全文，未覆盖的非空白字符为0。没有证据说明unitize已把好句普遍总结成情绪标签。不能为证明优化而重写一个“语义清洗层”。

可确认的损失发生在后续传递：

| 项目 | 实际情况 | 本轮处理 |
|---|---|---|
| WIDE跨段正文 | 旧S02有6个仅头行项，S07有7个；部分是后来排除的来源，但仍有合格原A正文被隐藏 | 只对正式来源恢复完整相关原文，保留跨段原范围 |
| 继承标题 | 正文并未丢失，但一些上级标题没有随FULL Pool发出 | 另建production_context恢复23次继承标题出现，不回写已发实验输入 |
| GLOBAL | 旧map只有索引，真正全文在units；旧55条没有随各段发送 | 正式30份对应51条全局原文单独归档，明确不在局部试写输入里 |
| UID“引用” | 旧脚本把保留、舍弃、不可用、风险中的UID都算入提及 | 最终账本单列正文采用，备选与排除不算采用 |
| 来源身份 | 名义5.6w的两份实为Sol | 排除，使用已存在、真实标签有证据的两份5.6 Thinking旧稿；不新增A采样 |

详细证据见 [来源／Pool审计](audits/SOURCE_POOL_AUDIT.md)。这支持修复传输完整性，**不等于已用写作消融实验证明每一项恢复都会提升文采**。本轮没有花额外调用去证明“发全文比只发标题好”；对可读内容的缺失先作机械修复，写作实验集中在同一个完整Pool上。

## 3. 旧任务：并非没说保留好句，而是输出负担与取材重点互相牵制

[旧提示词](prompts/METHOD_OLD.txt)已经明确：

> 优先继承 A 原文自然、有力的表达，不要只取不同模型的语义交集，不能为了活泼而虚构人类剧情。

同时要求先写“内部完整珠子”，包含核心体验、独特侧面、竞争解释、段内变化、来源、风险及保留／舍弃账本；再写“中文完整珠子”，并为未进入正文的有价值内容说明原因。它没有直接命令重复，却使写作者先铺开一套解释，再在读者稿里重复组织。

旧S02内部起点是“终于能够安心依恋的幸福，却因为太珍贵，反而不敢毫无保留地享受”；读者稿随后多次说太珍贵、怕时间流逝、不能把幸福说满、太喜欢眼前这一刻。旧S05把单线撤空进一步解释成“你可以无限靠近某个人，却终究不能把自己的全部感受交给他”；S06、S07再次展开类似结论。原料的不同细节被同一个人生判断占据。

本轮第一版新提示词也失败了：过重的“必须增加听觉信息”导向，使GPT-6和Flash都变成声音导览。GPT稿写双音、相同尾音、底下和声；Flash甚至把未选的恋人比喻解释为偏离“纯粹听觉形态”。**这不是用户要求。** 第一轮稿保留为实验，不进入产品。

第二版把原料已有的身体、关系、感官和情绪边缘放回优先位置，正文先写，证据后置。相同S02 Pool下，GPT-6重新保住肩膀、皮肤黏稠和手掌托物；S07也保住气味、身体感觉、幻想与快感的混合。它证明任务定义可以改善GPT-6的实际输出；不能由此断言只改一句提示词就保证全部段落自动成功。

## 4. S07和S13：不能把所有矛盾都当成“丰富性”

S07的错误链是“m.51 = dolce sfogato → 星空悬浮／时间停摆”。实际dolce sfogato在m.78，poco più mosso在m.62。旧S07却写出“奇异的失重”“时间也像停住了”。本轮排除错误事实链，同时承认独立A中的心理失重可以是另一种主观体验，不用谱面去审判所有比喻。最终选择的是：回放谈话、沉入感觉本身、局部收轻又推起。见 [S07事实审计](audits/S07_DOLCE_SFOGATO_AUDIT.md)。

旧S13先说“浪花退下去”“哭过后的清明”，再并列“不肯退场”；没有明确限定哪些是谱面事件、哪些是特定演奏读法。这个混合不能因为两边都有UID就自动成立。

本轮采用持续张力的正文主线：103的抵达不等于全段松弛，106以后再次聚紧，110的花饰尚未替111完成解决。局部收轻与细腻触键仍然允许。Kopp讨论的收势传统，包括Rubinstein 1962例子，留在有条件的另一条听法中；**并未宣判所有退潮体验都错误**。本轮没有亲听指定录音，所以不声称核实了某录音的实际音量轨迹。见 [S13事实审计](audits/S13_FACT_AUDIT.md) 与 [最终有限事实复核](audits/FINAL_FACT_REVIEW.md)。

最后完成的受控复跑还表明：**旧方法＋同一事实提示也能正确区分两种演奏条件**，并在正文中写明“若演奏让声音渐渐收远”。所以S13事实关系的修复不能全部归给新写作方法。旧方法仍反复解释幸福、保证与怀疑；A2及最终编辑主要改变的是取材和正文组织。完整原文对照保留，不因这条反证削弱新方法的宣传而将它隐藏。

## 5. 目前不能给出的结论

- 不能说GPT-6普遍不适合统合，也不能说Flash天生更会保留人味。同输入的S02与S07已经显示模型之间的优劣并非稳定单向；完整三段与方法对照见 [实测报告](MODEL_METHOD_COMPARISON.md)。
- 不能声称30份是严格的5×2×3同条件研究。Luna-int-3实际有web_search，部分int提示不同；模型路由证据也有强弱。它们是本轮可用材料集，不是严整能力基准。
- 不能把最终编辑稿的收益全部记到某个提示词或模型头上。十四段由主编辑重选、组织、删改，外部模型原稿单独保存。
- 不能因检查通过就保证艺术效果。事实复核只拦错误，来源复核只拦无据补写；读者是否觉得这些段落具体、自然、有区别，仍须直接读正文判断。

## 6. 最小可行方案

保持冻结分段与原A；Pool只作忠实收纳和必要的标题恢复；短事实提示拦错段；A2优先保留好表达；读者正文先写，随后给可核对原句和简短取舍；主编辑逐段删去重复推论、无据动作和不必要的场景。无需新增中间研究层、投票层或长篇内部解释。

代码与完整提示词均已保存，后续调用从 [复用说明](REPRODUCE.md)进入。本轮停止在Bead。
