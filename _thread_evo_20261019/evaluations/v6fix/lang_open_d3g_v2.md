  - [S04 第2条]「尽情喜欢，也坦然接受喜欢，不再从亲近里找被爱的证明。」——“尽情喜欢”和“坦然接受喜欢”都省去了对象，但后者尤其不顺口。“接受喜欢”像把一种感情当成抽象物品来接受，普通叙述中说“接受对方的喜欢”更自然。 → 他尽情喜欢对方，也坦然接受对方的喜欢，不再从亲近里找被爱的证明。
  - [S06 第2条]「以前自然而然感到的好，他现在会特意留心，盼着以后还想得起来。」——“自然而然感到的好”意思可以理解，但“感到的好”不太像自然的口头表达。这里要说的是过去不经意间感受到的美好，如今开始有意识地留意，原句把这层意思压得有些生硬。 → 以前不经意间感受到的那些好，他现在会特意留心，盼着以后还能想起来。
  - [S06 第3条]「盼着记忆能给自己力量，却没察觉自己也想靠用心记住一切，把幸福留住。」——“靠用心记住一切”搭配生硬，“靠”和“用心”挤在一起，使表达变得绕口。真正重要的心理区别是：他以为自己只是想留下能支撑自己的回忆，实际上还隐隐希望通过记牢一切来留住幸福。这个区别值得保留，但可以说得更自然。 → 他盼着以后能从这些回忆里得到力量，却没察觉自己还想把一切都记牢，好像这样就能留住幸福。
  - [S07 第1条]「他渐渐拿特意留心的细节去比对，总要看现在是不是还像刚才一样好。」——“拿特意留心的细节去比对”缺少明确的比较对象，而且“拿……去比对”比较笼统，读者要到后半句才知道是在把过去与现在进行比较。“特意留心的细节”本身也稍显累赘。 → 他渐渐会拿自己记下的细节和眼下比较，总想知道现在是不是还像刚才一样好。
  - [S10 第1条]「就算以后没法确定，他也不想装作无所谓，更不想提前收回自己的爱。」——“以后没法确定”不太顺口。“以后”是一个时间范围，而这里真正不能确定的是将来会发生什么、两人能否一直相伴。“提前收回自己的爱”则表达清楚，没有必要改动其含义。 → 就算不知道以后会怎样，他也不想装作无所谓，更不想提前收回自己的爱。
  - [S10 第2条]「珍惜对方自愿给的亲近，也愿意自由地把自己的心交出去。」——“自愿给的亲近”搭配不自然。亲近通常是两个人之间的关系或行为，说成对方“给”的东西，显得生硬。“自由地把自己的心交出去”也有些概念化，普通叙述中更可能说“出于自己的心意”或者“心甘情愿”。原句想强调两个人都是自愿的，这一点可以保留。 → 他珍惜对方愿意与自己亲近，也愿意出于自己的心意，继续把心交给对方。
  - [S12 第2条]「想靠得更近，把眷恋全交出去，甚至盼着两人的心意完全相融。」——“把眷恋全交出去”不太符合日常语言习惯。人可以把心交给对方，也可以表达、流露眷恋，但“交出眷恋”让人不太容易理解具体指什么。后面的“心意完全相融”虽然带有诗意，却能明确表达他想消除两人之间距离的愿望，不属于同样的问题。 → 他想靠得更近，毫无保留地向对方流露眷恋，甚至盼着两个人的心意完全相融。
  - [S12 第4条]「他幸福得几乎承受不住，可想到再怎么爱也换不来永远相伴，心里又疼，急切得分不清是欢喜还是舍不得。」——这一句连续挤进了幸福、想到无法永远相伴、心疼、急切以及两种感情难以分辨，读起来需要重新整理情绪之间的关系。尤其“急切得分不清是欢喜还是舍不得”，容易让人疑惑究竟是急切让他无法分辨，还是欢喜和舍不得共同构成了这份急切。 → 他幸福得几乎承受不住，可一想到再怎么爱也换不来永远相伴，心里又疼。欢喜和舍不得搅在一起，他自己也分不清这股急切究竟从哪儿来。
  - [S14 第4条]「他还愿意亲近，不想为了少受点疼，就少享受眼下的快乐，或收回自己的爱。」——“少享受眼下的快乐”不够自然。“享受快乐”通常不直接用“少”来修饰，这里真正要表达的是他不愿因为害怕受伤，就刻意压抑眼前的快乐、减少投入。 → 他还愿意亲近，不想为了少受点疼，就压住眼下的快乐，或收回自己的爱。
- 累积（中等）：对“未来无法保证”的认识在中后段反复得到近似表述，部分段落的情绪推进因此显得迟缓｜影响：连续阅读时，读者会多次得到同一个核心认识：眼下再幸福、自己再努力，也无法保证将来永远如此。这是整篇叙述的重要矛盾，反复出现本身合理。问题是到了S12至S14，这一认识已经非常明确，却又几次被完整说出。读者能够理解人物仍然难过，但某些句子没有显著增加新的感受或心理变化，而是在重新说明已经理解的道理。结果是后半部分偶尔像在原地反复思考，削弱了音乐段落之间本来可以具有的递进感。｜边界：S05第一次出现未来可能变化的担忧，是必要的。S09进一步意识到自己不能安排未来，也有明确的推进。S12强调两人终究是独立的人，补充了新的痛苦来源，也应该保留。S13关于记忆无法留住幸福的认识，与单纯担心未来不同。真正值得压缩的是这些认识已被充分表达之后，又用接近的完整句式重新说明“以后没法一直这样”的地方，尤其S13与S14的衔接。不应该为了避免重复而删除人物反复经历的舍不得。｜建议：保留每次情绪回返，但尽量让新的段落侧重这一次与前一次的区别，而不是再次完整论证未来的不确定。比如S14第1条可以改为：“他仍盼着长久，只是不想再拿这份盼望要求对方永远不变。”前一段已经说明记忆留不住幸福，这里就可以直接进入他如何对待自己的盼望。

### 5.6 第1次：8 分，4 处
- 最主要的问题：整体语言质量较好。全文的心理线很清楚，从靠近、放松、珍惜，到因害怕失去而反复确认，再到放弃索取保证、仍然接受自己想长久相伴的愿望，前后基本能顺着读下来。多数句子是朴素、可理解的，没有明显堆砌修辞，也没有为了含蓄而故意写得玄。真正影响连续阅读体验的主要不是单句病句，而是中后段在同一个核心矛盾上反复使用“以后、一直这样、保证、不变”以及大量“不再、不想、不能、没法”的自我修正式表达，使S09以后几个本来有细微区别的阶段在语言上稍显相似，偶尔有在同一认识附近来回说明的感觉。其次是条目句式比较整齐，“他”字起句很多，略有剧情梗概式的机械感。局部真正需要改的地方不多，主要是少数搭配或并列关系略生硬。总体上已经自然、完整、可读；若把后半篇各阶段的语言落点再拉开一些，并减少少量重复的论证式句法，阅读体验会更松弛，也更像一个人在讲亲身经历，而不是在逐层解释自己的心理结论。
- 一再出现：后半篇用相近的“以后／一直这样／保证／不变”反复概括不同阶段，造成一定的语义和措辞同质化。；中后段“不再／不想／不能／没法”等否定和自我修正式结构偏密，累积后略有分析、论证口吻。；大量条目以“他＋心理动作”起句，全文节奏稍显齐整和机械。

### 5.6 第2次：8 分，8 处
- 最主要的问题：整体语言质量较高。叙述线清楚，人物从试着敞开、享受亲近，到因害怕失去而反复确认，再到接受未来无法保证却仍愿意去爱的变化，连续读下来基本能自然跟上；多数句子也确实像人在平静地讲自己的内心经历，而不是刻意追求文采。真正影响阅读体验的主要不是单句病句，而是后半段S09至S14对“以后能不能一直这样”这一矛盾解释得较密，又频繁借助“保证、证明、留住、交出去”等抽象关系词和让步句式来整理心理，因此有几处产生轻微的原地盘旋和心理分析摘要感。局部另有少数搭配或并列结构不够自然，但数量不多，也不妨碍理解。整体已经顺畅、完整，进一步修改最值得做的是减掉若干重复解释，让每次同一恐惧重新出现时更突出这一阶段真正新增的感受或选择，而不是全面改写口吻。
- 一再出现：后半段对“未来是否还能一直这样”的近义重述偏密，削弱了部分段落之间的推进感；抽象关系词及概念化比喻连续出现，使部分文字略显心理分析式；后半段让步、转折句式偏密，句法节奏偶尔显得过于论证化
  - [S02 第3条]「他不够好的地方，还有柔软和迟疑的时候，都没妨碍两人亲近，他越来越敢做自己。」——“不够好的地方”和“柔软和迟疑的时候”一个是“地方”，一个是“时候”，并列得不太齐，读到“都没妨碍”时需要回头理一下两项各自是什么。后半句本身自然。 → 他那些不够好的地方，连同柔软、迟疑的时刻，都没妨碍两人亲近，他越来越敢做自己。

  - [S07 第1条]「他渐渐拿特意留心的细节去比对，总要看现在是不是还像刚才一样好。」——“拿……细节去比对”没有很清楚地说是在和什么比，动词搭配也稍显生硬。后面的“看现在是不是还像刚才一样好”才补出了比较对象，因此前半句读起来会短暂停顿。 → 他渐渐会拿这些特意留心的细节作比较，总要看现在是不是还像刚才一样好。
  - [S08 第2条]「不再总去比较，也不催对方立刻让自己安心，他慢慢轻松了一些。」——“催对方立刻让自己安心”不太像自然说法，像是把“催对方给出某种回应”和“让自己安心”压成了一个结构。 → 不再总去比较，也不再催着对方马上给出能让自己安心的回应，他慢慢轻松了一些。
  - [S09 第1条]「不追着要保证，他还是盼着以后相伴，不想把这盼望当贪心。」——“把盼望当贪心”在意义类别上有一点错位：一种“盼望”可以被认为“贪心”，但通常不会直接“当成贪心”。意思很清楚，只是说法略硬。 → 不追着要保证，他还是盼着以后相伴，也不想觉得这样的盼望就是贪心。

  - [S02 第3条]「他守住了自己认准的事，重新肯定了自己，觉得自己还有力量，也很骄傲。」——“守住了自己认准的事”搭配略显生硬。“守住”通常接原则、底线、信念等，而这里的“事”承接前一句“继续做自己看重的事”，重点是没有放弃正在坚持的事情，用“没有放弃”更贴近普通人的说法。 → 他没有放弃自己认准的事，也重新肯定了自己，觉得自己还有力量，为此很骄傲。
  - [S05 第2条]「他不觉得自己的要求过分，可坚持能给他力量，却换不回原来的亲近，心里又委屈又恼怒。」——“可”和“却”连续出现，分别牵出不同的转折关系，使句子的重心不够清楚。读者得稍微整理一下，才能分清他认为自己想要亲近并不过分，以及坚持虽然能带来力量、却不能换回亲近这两层意思。 → 他不觉得自己想要亲近有什么过分。坚持自己看重的事确实让他有力量，却换不回原来的亲近，他心里又委屈又恼怒。
  - [S09 第1条]「他舍不得刚才那种不用左右为难的满足，还想多体会一会儿。」——“不用左右为难”说的是人的处境，直接用来修饰“满足”，读起来稍有些拧。这里真正想表达的是，他刚才感到满足，而且暂时不用在两种心愿之间为难。把这两层意思稍微分开，会更像平常说话。 → 他舍不得刚才那份满足。那会儿他不用左右为难，还想让这种感觉多留一会儿。
  - [S11 第2条]「他既想重新有人亲近，又不肯委屈自己去换接纳，找不到两全的办法，越想越悲愤。」——“想重新有人亲近”不太符合自然的汉语搭配，容易让人短暂停顿，判断究竟是他想亲近别人，还是希望重新有人亲近他。结合前文，后一层意思更明确。“换接纳”也稍显压缩，不过尚能理解。 → 他既盼着再有人亲近自己，又不肯委屈自己去换取接纳，怎么也想不出两全的办法，越想越悲愤。
  - [S13 第3条]「自己看重的事始终没有放弃，这让他很自豪，也想在往后的日子里留住从前给他的宽厚和勇气。」——前半句把“自己看重的事”放在开头，却省略了实际执行“没有放弃”这一动作的“他”，读起来不如直接说“他始终没有放弃……”顺畅。后半句从“这让他很自豪”接到“也想……”，主语又暗中从“这”转回“他”，使整句略有牵绊。 → 他始终没有放弃自己看重的事，为此很自豪。他也想在往后的日子里留住从前给他的宽厚和勇气。
- 累积（中等）：相邻段落反复确认同一个现实困境，使后半篇的叙述推进变慢｜影响：这些句子单独看基本都自然，彼此也没有明显矛盾。真正的问题出现在连续阅读时：从S08到S11，读者不断被告知同一件已经明白的事——心里的变化不能让过去的亲近回来。虽然每段分别带有清醒、留恋、承担、不甘等情绪，但相同的现实前提被完整解释了太多次。尤其S08、S09和S10连续三段，读者容易觉得叙述在同一个地方反复确认，而不是每段都带来了新的心理变化。这样会削弱S10作出选择、S11情绪加重本来应有的分量。｜边界：失去无法挽回是全篇的核心处境，必须反复出现；而且伴随音乐段落变化，同一个事实在不同情绪下重新浮现也完全合理。S08从喜悦回到现实、S10开始考虑以后怎么生活、S11产生更强的不甘，这些区别值得保留。真正多余的不是再次想到失去，而是每次想到时，都几乎重新交代一遍“现实没有改变”。｜建议：保留每段真正不同的心理动作，减少已经交代过的现实前提。比如S10第1条可以直接改为：“他得想清楚，以后要怎么带着这份遗憾过日子。”这样接在S08、S09之后，读者已经知道遗憾是什么，不必再听一遍“现实里的缺口没有补上”。S11第4条也可以把重心放在情绪的新变化上，例如：“他还是希望往后的日子能带着从前给的勇气，只是越这样盼着，越觉得眼下的日子难熬。”不需要把所有类似句子都删掉，只要让相邻段落各自承担不同的叙述任务。

### 5.6 第1次：7.3 分，9 处
- 最主要的问题：整篇的心理脉络是清楚的，从舍不得过去、靠坚持抵抗失去，到允许怀念与坚持同时存在，再到承认现实缺口仍然没有解决，前后关系基本能顺着读下来。大部分句子也确实有普通人平静讲自己经历的底色，并没有普遍性的生硬或故作深沉。最明显的问题不在某一句特别差，而在后半段的累积效果：S08—S11 连续用非常接近的语言重新确认“亲近回不来、现实缺口还在”，使本来细微的心理推进显得有些原地盘旋。其次是“这份／那份＋抽象名词”和“不再／还是／依然”一类状态标记使用较密，使文字偶尔像在整理心理逻辑，而不是一个人在自然回忆。局部另有少数明确的搭配和句法问题，尤以“比较过去和现在哪边更要紧”“羡慕……日子”“自己看重的事始终没有放弃”等较明显。总体已经可读、逻辑细致，主要需要减少重复确认和概念化表达，而不是大幅重写人物心理。
- 一再出现：相邻段落反复用近似措辞确认“现实中的亲近没有回来、失去仍然存在”，使局部推进感变弱。；“这份／那份＋安心、亲近、怀念、失去、遗憾”等抽象回指较密，连续阅读时略显概念化。；后半段多次用“不再／还是／依然”等词校正人物心理状态，句法节奏逐渐趋同。
  - [S01 ③]「想起那份安心他还是会高兴，但怕往后只能靠回忆，才觉得自己曾经过得很好。」——后半句“怕……才觉得……”的因果关系接得有些生硬。“才觉得”像是在说直到害怕未来只能回忆，他才第一次意识到过去过得好；如果只是说这种担心让他更强烈地意识到过去的可贵，现有说法不够顺。 → 想起那份安心他还是会高兴，可一想到往后也许只能靠回忆，他才更觉得自己从前确实过得很好。
  - [S03 ③]「可从前那份安心也曾给过他勇气、让他活得坦然，光靠逼自己硬撑，真的够吗？」——“给过他勇气”和“让他活得坦然”是两个谓语结构，用顿号硬接在一起，读起来会轻微卡顿，也不像前后文字的自然口吻。 → 可从前那份安心也曾给过他勇气，也让他活得坦然，光靠逼自己硬撑，真的够吗？
  - [S06 ①]「他发现逼自己没用，就先不急着比较过去和现在哪边更要紧，心里反倒慢慢静下来。」——“比较过去和现在哪边更要紧”搭配不自然。“哪边”通常用于较具体的两方，“过去和现在”又不是很适合用“更要紧”直接衡量，因此读到这里需要稍微转换一下意思。 → 他发现逼自己没用，就先不急着非要在过去和现在之间分出轻重，心里反倒慢慢静下来。
  - [S08 ①]「他满足了一阵才意识到，就算心里能一边怀念一边坚持，现实里那份亲近也还是回不来。」——“满足了一阵”不是很自然的说法。“满足”在这里是心理状态，通常会说“感到满足”“沉浸在满足里”或“这份满足持续了一阵”。 → 他沉浸在这份满足里一阵后才意识到，就算心里能一边怀念一边坚持，现实里那份亲近也还是回不来。
  - [S09 ①]「他舍不得刚才那种不用左右为难的满足，还想多体会一会儿。」——“不用左右为难”直接修饰“满足”稍显拧巴，因为“不左右为难”描述的是人的处境或心境，不是“满足”本身的性质。 → 他舍不得刚才那种不必左右为难、心里很满足的感觉，还想多体会一会儿。
  - [S12 ③]「哪怕得不到安慰，他也愿意坚持自己看重的事，只是一旦不再压住怀念，反而更觉得这份失去沉重。」——“觉得这份失去沉重”搭配略硬。“沉重”可以形容心情、负担或某种感受，但直接说一项“失去”很沉重，在这种平常叙述中显得偏书面。 → 哪怕得不到安慰，他也愿意坚持自己看重的事，只是一旦不再压住怀念，反而更觉得这份失去难以承受。
  - [S13 ①]「他不再逼自己忘记过去，还是羡慕那时不用证明自己就能安心生活的日子。」——“羡慕……日子”搭配不太自然。人通常羡慕某个人、某种处境或那时的自己；对一段已经经历过的生活，更常说“怀念”或“向往”。 → 他不再逼自己忘记过去，还是很向往那时不用证明自己就能安心生活的日子。
