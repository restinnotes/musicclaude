### S06

### S07
[S07-B1]（主体验；小节 182附近；局部）第182小节附近，高音区忽然浮出一串轻得像游丝、却带着刺骨寒意的长颤音。它像寒风猛地吹开紧闭的窗，把人从甜梦里生生拽回严寒；后颈一凉，脉搏也剧烈跳动。梦境骤然破裂，身体先一步被惊醒。
[S07-B2]（段内变化；小节 182–197）同一转向里，带马祖卡色彩的舞蹈性材料闯了进来，和前一刻近乎祈祷的静谧形成反差。它不像沿着刚才那条深沉的思路继续往下讲，而像突然换了一个场景，原先的思绪被截断，音乐从别处重新开讲。这种突兀的换向并不等于情绪好转；新出现的舞步可以很鲜明，内心却未必因此安定下来。
[S07-B3]（段内变化；小节 198–205；局部）到了198–205小节，连续颤音让紧张一层层累积，思绪像不停翻转，想停也停不下来。事情表面上仿佛已经过去，身体和情绪却还没有完全相信一切已经结束。心里有东西在颤动，想要冲出去，却始终找不到真正的出口；在先前的惊醒之后，紧张仍在持续盘旋、难以平复。
[S07-B4]（另一侧面；小节 181–205）另一个可以同时浮现的联想，是一种非常具体、非常生活化的记忆突然闯进深沉的感受里：一个熟悉的动作、一次舞蹈、一段曾经习以为常的生活。这样的亲切感未必安慰人；恰恰因为那些细节具体而熟悉，反而更容易意识到自己已经失去了什么。
[S07-B5]（另一种理解；小节 182–197）也可以听成：182–197小节，也可以听成先前那些更有宣告意味、带着波兰舞曲气息的声音再次出现；只是它已不再像最初那样，以完整而鲜明的姿态建立秩序。

### S10
[S10-B1]（主体验；小节 216–225）到了214–215小节，作品开头那种自由、试探的姿态一闪而过；接下来的216–225小节，并没有出现一段完整、站稳的旋律，熟悉的声音只是轻轻地、断断续续地浮现，像几块碎片。它们既像先前如歌旋律的碎片，也像那些舞曲主题的残片；另一种更凄厉哀婉的听法，是听见先前那段摇篮曲破碎地重现，只是这次变成了F小调。声音回来了，却没有完整铺开。
[S10-B2]（另一侧面；小节 221–225；局部）到了221–225小节，听感像忽然失重，整个人悬在半空，辨不清方向；声音零碎飘忽，连身体也像暂时失去了着落。
[S10-B3]（另一种理解；小节 216–225）也可以听成：如果把这次回返听成心理上的回望，开头的试探姿态仿佛把问题重新递回来：“那么，我究竟要怎样继续生活？”相似的迟疑此时不再只是尚未开始时的茫然，而是历经许多之后，仍未能获得彻底答案的疲惫。
[S10-B4]（另一种理解；小节 216–225）也可以听成：这些轻弱、零碎的声音，也像一个疲倦的人在回想一件往事：明明知道它很重要，却已经没有力气把它重新讲述一遍。

### S11
[S11-B1]（另一侧面；小节 226–237的反复冲击与紧张未解；低音和弦的重压从226小节开始，推动延续至241小节）左手涌起滚滚低音波涛，右手的和弦像重锤一样砸下。每次爆发之后，紧张都没有完全解除，反而又形成新的压力。这不像顺境中的凯歌，更像绝境中的困兽之斗：不是顺畅地奔跑，而是一次次顶住、再用力。
[S11-B2]（主体验；小节 226–241；226–229的试探与238–241的向上积聚标出这条变化弧线；局部）波兰舞曲的步子不是一下子整齐地回来：起头几小节还像在试探前方有没有路，随后步伐一点点聚拢，到最后四小节，前进感越来越不可回避。它不只是恢复旧姿态，仿佛把前面柔软、私密、近乎祈祷的声音带回可以迈步的节奏里——祈祷开始变成意志。
[S11-B3]（另一侧面；小节 226–241；这一心理理解贯穿全段，238–241的向上推进使前进感更难回避）如果把这股推进听成人的处境，最动人的不是忽然变得无所畏惧，而是害怕还在，脚却已经往前走了。紧张并没有解除，却有一丝奇特的解脱：不是问题解决了，而是停滞本身松开了一点。

### S12
[S12-B1]（另一侧面；小节 242–253，与此前主题姿态形成回顾性的对照）这份挺立也可以听成经历动摇后的主动选择：即使知道自己会犹疑、疲惫、想念，仍然可以决定怎样站立。它不要求人假装自己从未受过伤。

### S13
[S13-B1]（主体验；小节 254–270；局部）先前像私下安慰、近乎祈祷的柔软歌唱重新出现，却被带进开阔、宏大的音响里，像一支温柔的歌忽然站到了明亮处，甚至有如管风琴般庄严庞大。密集的音符又像狂飙的激流向天空喷涌，仿佛一颗心脏以最高负荷跳动；柔软并没有被力量压下去，而是也被带进了高潮。这份公开的气势，还可以让人想到故土、共同记忆和希望。
[S13-B2]（段内变化；小节 269–280；局部）约第269小节，钢琴展开快速、炫目的八度进行，明亮、迅疾的音型向前冲出，把积累的能量一下子释放出来。如果说前一刻像在宏大地放声歌唱，那么这一刻更像身体被一股气流推着往前跑，兴奋得几乎来不及喘息。
[S13-B3]（段内变化；小节 281–287；局部）但这股冲势没有一直持续。约第281–285小节，音乐收敛下来，颤动般的装饰音重新带来一点不安，仿佛刚刚建立的成功又被轻轻问了一句：它真的已经牢固了吗？同一段回落也可以听成事情已经说完、终于能停下来喘口气。从容与细微的不安不必互相排斥，平静也不一定意味着疑问已经消失。
[S13-B4]（段内变化；小节 末尾几小节；局部）狂潮退去，喧嚣像骤然静止。低音区像呼出最后一口气，沉沉吐出两记耳语般的和弦；随后，钢琴最高音区忽然亮起一记透明、孤悬如寒星的高音和弦，像一声清脆的钟响。低处的轻声与高处的亮光形成鲜明反差，结尾的力量不必只靠更猛烈的敲击。
[S13-B5]（另一种理解；小节 286–288；局部）也可以听成：最后的高音和弦可以听作一个决定，也可以听作一个人忽然从梦中醒来。前一种听法更像意志终于落定，后一种更像从梦境中骤然清醒。

【本轮四条硬原则】

一、珠子覆盖优先于凑字数：对原稿珠子中彼此不同的具体体验，以此前较完整版本的严格覆盖水平（约90%–98%）为参照；不能用保留了大意、主线或情绪标签冒充保留具体体验。

二、「碎」指每个感受小块只承载一个体验、在屏幕上分散呈现，绝不指把一句话生硬切成两块。每块离开相邻文字也必须是一句完整自然的话，或一个自足、顺口、读得懂的短语。

三、线要减重：线是放大的昂贵注意力位，明显缩短、减少行数，突出关键词；删重复解释、合并同一节点，而不是删掉人物判断和选择成立的必要依据。

四、保留多种情绪色：每条line设置emotion，情绪不同的相邻组应有看得出的颜色区别；不为了变色编造原稿没有的情绪。

【先在内部盘点，不能直接按字数裁剪】

1. 把所有原始line拆成：人物/事件、关系变化、关键前情、可验证的判断依据、行动动机、决定及其转折。标记哪些因果不说就会看不懂，哪些只是重复说明。同一时刻同一节点的线先尝试合并。
2. 逐颗盘点珠子里的独立体验单位：具体身体或感官感觉；说得出内容的心里话/疑问；独特的比喻或画面；同一情绪的微小差别；同时存在的矛盾；未解决却暂时松开的状态；从一种状态转到另一种的关键连接。每一种不可替代的体验单独登记，即使不推动主线也算重要。
3. 对每个体验判断「独特」还是「同一体验的另一说法」。只删真正同义重复、没有体验价值的纯音乐说明、原稿已被另一条完整表达的信息；不得把具体画面删成抽象情绪，也不得把身体感觉和心里话互相替代。
4. 先确定全曲真实的叙事推进、各段节点和词语呼应，再编排屏幕顺序；不要预先给各颗珠子固定名额。

【线：少量大字，短句+关键词】

1. 通常每条line写10–18个汉字，整体平均争取不超过18字；超过22字先改写，确实有不可拆的关键因果时才偶尔放宽到24字。禁止回到平均26–28字的解释型长句。
2. 每段尽量只保留1–3条独立叙事节点；信息密集时可多，但每新增一条必须回答：少了它，观众是否会不知道是谁、发生了什么、凭什么判断或为何选择？如果不会，合并或删去。不要机械地为每条原始线生成一条屏幕线。
3. 要点、人物关系变化或关键行动尽量放前面；只保留支撑它的最短、最具体依据。因果可以由相邻线跨时承接，不要求每行重复前情，也不要把不同时间的关键经历错并为一个笼统结论。
4. 优先用一条顺口的人话同时讲清节点与必要理由，能并的并。确有两个独立时间/原因/转折才另起line；不能把「因为……」「但后来……」截成悬空半句，也不能写成「信任加深」「情绪转向」这类没人说的话。
5. 每条line的keys选1–2个最值得放大的连续原字，最好落在前半行，聚焦人物、变化、选择或关键缘由；keys不得包含text里不存在的字。from必须准确列出实际来源编号，可一条line对应多个原始编号。
6. 只把必须承担叙事职责的内容放line。具体触感、内心原话、画面和状态质地优先留给feel，避免大字线复述小字感受。单独连读所有line，仍要能明白关键事件、判断依据和决定的原因。

【珠子：多些、碎些，但每块必须是人话】

1. 每个feel item只承载一种独立的具体体验；通常8–22字。不可分开的矛盾、限制或转折可以稍长，必要时至约30字；不能用长段容纳三四种体验。
2. 逐块做「遮住上下文」测试：不看前一块、后一块，单看这块是否仍有完整意思？有无缺主语或关键对象、只剩状语/补语、句子后半截、悬空代词或不知指什么的「它」「这样」？不合格就重写成自足短句；如果本来只有一个完整体验，就合成一个短块，不为求碎硬切。
3. 不要求每块都是主谓宾齐全的书面句；「胸口像被轻轻拽住」这样自然的短句或自足短语可以。禁止机械标题、心理学标签、硬造诗句、讲解式长句。观众一扫就能理解，不能靠上一块帮它补全语法。
4. 同一珠子有几种不可替代的体验，就给几块；没有每颗只能1–2块的限制。身体感觉、独特画面、心里话、情绪细微层次、矛盾两面、限制性转折都要争取原样保留其具体性。尤其不能把「并未解决，却暂时不再压在心上」缩成「安心」。
5. 一块若含不可分割的「虽……却……」「还……但……」，保留两者关系，不要断成前后依赖的两个item。两种真正不同的体验则各写成能独立读懂的一块。同一体验无论来自几种近义听法、几种相似比喻，只留最准确、鲜明、自然的一种；跨珠子也检查无价值重复。
6. 原稿有明确的自问、身体触感或画面，优先保留其辨识度，不用概括性情绪词覆盖。纯音乐技术描写不单独上屏；只有音乐的一个可听见的变化确实帮助观众对上具体感受，才保留极短听觉提示，并与真实体验相连，不能杜撰心理因果。
7. 允许比现行视频更多的小字feel，因为它们是分散的小块，而不是一大段。按原稿实际时间与叙事顺序分散排布；一个feel row建议放1–4个可独立阅读的items，更多则拆成相邻的不同feel rows，不能把全部体验同时挤成满屏长墙。
8. 每个item必须标真实bead编号且只标一颗；不能拼接不同珠子的细节来造一种新感受。允许同一bead在多条item中出现，但这些item必须表达不同的独立体验。

【情绪色与组】

1. 每条line都必须有emotion，值只能是「炽热」「欢喜」「亲密」「安心」「孤单」「不安」「悬着」之一，不得写十六进制色值或另加color字段。
2. 一条line及其后与之相连的feel构成一个观看组；该line的emotion是这组的视觉用色依据。不同组若原稿确有不同情绪，应选不同emotion，让画面保持多色区分；不要把整曲写成一个色，也不要为轮换颜色强行误判情绪。相同情绪、同一节点的相邻线优先合并。
3. feel没有emotion字段；不要为了给某块feel着色而制造无叙事作用的line。必要时让feel自然接在最相关的line后；仍以真实音乐顺序优先。

【bars定时与顺序】

1. 局部小节范围只允许放在feel item的bars字段。如果原珠子明确指出这项具体体验只在某几小节发生，照抄相应局部范围（如「12–14」）；如果只给珠子的整体范围，或未把这项体验指向明确局部，bars必须是空字符串。不得猜算、延伸、越界。
2. 每个feel item都必须输出bars，即使为空。line.text、feel.text、plan不写小节号。sections按原段顺序；rows按体验和叙事发生的顺序，通常先line后相关feel，但不强求机械一一配对，不伪造先后。
3. plan只简洁写全曲编排、真实的因果承接和词语/意象的前后呼应，不增加原稿没有的主题。

【输出前在内部进行两次独立验收】

A. 严格珠子覆盖：逐颗、逐项把前面登记的每一种非重复具体体验对照屏幕稿，标记「完整留住／只剩大意／遗漏」。只剩情绪标签、只剩音乐描述、失去特殊画面或失去「虽……却……」关系，都不能算完整留住。以此前90%–98%的严格覆盖水平为努力目标；发现有独特体验漏掉，先补一块独立自然的feel，不是加长line。对于删除项必须能指出是同义重复或确无体验价值，不得以S01（128 秒）：现在的屏幕约 195 字

B. 人话与注意力：单独看每一个feel item，不能成为被硬切下来的半句话；每块都要通顺、自足、一眼能懂。单独连读line，关键「谁、怎么了、为什么」不能断；逐段检查line是否明显比旧的26–28字短、行数是否因归并而减少、keys是否真正突出。检查同一体验有没有在line与feel、同珠不同item间重复。

C. 色彩与溯源：每条line有且只有一个合法emotion，真实不同的组有区别；keys为text连续原字，from与bead均真实，bars合法且准确，没有无依据的新意象、情节、因果或小节号。

未通过就只重写有问题的部分，不能以牺牲另一条轨道的质量换取一项达标。

【最终输出】

只输出一个合法JSON对象，不要Markdown、说明、注释或任何额外字段。固定结构如下：
{
  "plan": "全曲怎么排、哪些词前后呼应",
  "sections": [
    {
      "sec": "S01",
      "rows": [
        {
          "kind": "line",
          "text": "线这一行的话",
          "keys": ["这一行"],
          "emotion": "安心",
          "from": ["S01-1"]
        },
        {
          "kind": "feel",
          "items": [
            {"text": "一块自足的具体感受", "bead": "S01-B2", "bars": ""}
          ]
        }
      ]
    }
  ]
}
示例中的sec、from、bead只说明字段位置，实际必须使用输入中的真实编号；bars只有符合原珠子明确局部范围时才填写。line只能有kind、text、keys、emotion、from；feel只能有kind、items；item只能有text、bead、bars。
