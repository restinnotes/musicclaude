  - [S12 第2条]「顺着这些事，他又想到以后两人一起过日子，越想越觉得幸福。」——“顺着这些事”比较含混。上一句讲的是他想象中愿意替对方分担的琐事和难处，不是已经发生的事情。用“顺着这些事”衔接，像是略过了从想象分担生活到想象共同生活的心理过程，口语中也不太常这样说。 → 想到以后能替对方分担生活里的琐事和难处，他又忍不住想象两人一起过日子，越想越觉得幸福。
  - [S13 第3条]「以前收着热情还能照常相处，现在想一起过日子的念头，却怎么压也压不住了。」——“现在想一起过日子的念头”读起来不够顺，容易让人短暂地把“现在想”连成一个动作，再发现后面真正的主语是“念头”。“念头”和“压也压不住”之间的逗号也让句子的衔接有些别扭。 → 以前收着热情还能照常相处，可如今想和对方一起过日子的念头，却怎么也压不住了。
  - [S13 第4条]「他不想让对方替自己解决这份难过」——“解决这份难过”的搭配有些生硬，像是在把一种感受当成需要处理的问题。“替自己解决”又进一步增加了这种分析性的语气，不太像平常讲述心情时会自然说出的话。 → 他不想指望对方来消除自己的难过。
  - [S14 第1条]「给得再多，也换不来一定能走到那一步。」——“换不来”后面直接接“一定能走到那一步”，语法上显得有些悬空。这里真正换不来的是一种保证，而不只是那个结果本身。补出“保证”，句意就顺畅得多。 → 给得再多，也换不来两人一定能走到那一步的保证。
  - [S14 第2条]「他想起最初小心地靠近，也想起后来放开去关心的快乐，哪一段都不想抹掉。」——“放开去关心”搭配不太自然。“放开”可以形容不再拘束、不再压抑自己，但直接接“去关心”，动作关系有些别扭。这里要表达的是他后来不再那么压着自己的热情，主动关心对方时感到快乐。 → 他想起最初小心地靠近，也想起后来不再那么收着热情、主动关心对方时的快乐，哪一段都不想抹掉。
- 累积（中等）：关于期待回应、害怕给对方压力的同一层顾虑，反复得到比较完整的解释｜影响：这些话单独看都自然，心理上也能够成立。连起来读，却会反复遇到同一套解释：他有期待，又怕期待变成对对方的催促，因此把它收起来。虽然每一次的心理位置并不完全相同，但相似的担忧总是被重新说得很明白，读者容易产生一种已经理解了这一点、却又在听它被解释一遍的感觉。特别是S07和S09相隔不远，都直接使用了“怕……像在催对方”的表达，使后一次原本重要的心理转折稍微失去新鲜感。整篇并没有因此难懂，但心理进展有时显得缓慢。｜边界：这些顾虑并非无意义的重复。S04担心的是自己的热情会给对方压力；S07担心的是表达心意会被理解为索要回应；S09开始意识到压抑期待也是在为难自己；S10则确认想被珍惜不等于逼迫对方。四处各有作用，不能全部合并或删除。真正影响阅读的是几处连续使用十分相近的理由和措辞，导致已经建立的顾虑再次得到详细解释。S10的辨别尤其值得保留，因为它是前面矛盾的一次实质性化解。｜建议：保留不同阶段的心理变化，但不必每次都重新交代为什么害怕被看成催促。前文已经说明过的顾虑，后文可以简短带过，把篇幅留给这一次真正新增的心理反应。例如S09第2条可以改成：“他又想把期待藏起来，可刚这么想，就觉得连自己的喜欢也要被压住了。”这样承接S07已经交代过的担心，同时让读者更直接地注意到S09新增的自我冲突。

- 累积（中等）：大量心理变化采用相近的解释性句式，连续阅读时有些像在整理心理过程｜影响：整篇几乎所有变化都由他对自己的心理作出判断来呈现，常见的推进方式是先交代感受，再讲清顾虑，最后得出认识。这样写的优点是逻辑明白，读者能分辨人物每个阶段不同的想法。但连续十四段都采用相近的心理分析方式，会形成一种始终在解释自己为什么这么想的语气。人物经历里的犹豫、难堪、开心和释然都存在，却经常很快被一句道理概括掉，少了一点人在回想经历时自然的停顿和轻重变化。它不像明显的病句，更多是整篇叙述的口吻略偏理性、整齐。｜边界：这是一篇以内心变化为中心的文字，明确写出“他明白”“他发现”“他想通”完全合理，也不需要为了避免抽象而添加具体场景。尤其S05对不求回报的怀疑、S11对此的重新理解，是心理发展的关键，解释清楚很有必要。真正值得调整的是：并非每一个过渡段都需要把心理原因和所得结论讲到同样完整的程度。重要的认识可以明说，较小的变化则可以让犹豫、反应或一句心里的话自己呈现。｜建议：给心理叙述增加一点句式和语气的变化，不改变故事事实，也不需要补造事件。例如S03第2条可以改成：“可一想到以后，他又没那么踏实了。自己能决定的，只有还要不要继续对对方好；以后还能不能这么亲近，不是他一个人说了算。”这样仍然清楚，但不是单纯宣告他明白了一条道理。S14的重要总结则可以保留，因为它承担了全文收束的作用。

### 5.6 第1次：8 分，5 处
- 最主要的问题：整篇的心理线很清楚，而且大多数句子都属于自然、朴素的现代口语书面表达。连续读下来，人物从害怕喜欢、享受亲近，到承认期待、再到明确想被珍惜并想一起生活，层次能够跟得上；末尾重新落回“还不知道答案，但仍愿意喜欢和相处”，收束也稳。真正影响阅读体验的并不是大量单句病句，而是中段以后逐渐显出的提纲感：同一组抽象关系词反复组合，同时人物经常用正反两面给自己的感情作辨析，因此一些本来细微不同的阶段在语言表面显得相似。其次是“眼下、照常、还是、这样”等维持现状的表述多次复位，稍微削弱了推进感。局部只有少数搭配或指代需要调整，整体不存在明显的不通顺，也没有严重的机械重复。若目标是像一个人平平常常讲自己的经历，最值得改的不是增加细节，而是减少重复性的状态说明和自我解释，让已经说清楚的心理区别不必每一段都重新证明。
- 一再出现：“亲近、相处、关心、在乎、期待、回应”等抽象关系词密集反复，连续阅读时略显提纲化；人物频繁用转折和否定来区分自己的不同心理，局部都合理，但中段累积后自我分析感偏强；“眼下、现在、这样、照常、还是”等维持现状的表达多次复现，轻微削弱段落之间的推进感
  - [S07 第1条]「他越在乎，就越盼着对方也主动靠近。光是主动对对方好，那种开心已经不够了。」——“那种开心”指代得有些悬。前半句说的是“主动对对方好”这个行为，后半句忽然把它概括成“那种开心”，读者需要自己补出“主动付出时得到的开心”这一层，句子因此略有拐折。 → 他越在乎，就越盼着对方也主动靠近。光是主动对对方好带来的那点开心，已经不够了。
  - [S08 第2条]「相处久一点，他慢慢又像起初那样，不用许诺也很开心。」——“相处久一点”放在叙述已经发生的事情里，稍微像条件句或劝说语气，例如“再相处久一点就知道了”，不太像在交代时间经过。 → 又相处了一阵，他慢慢又像起初那样，不用许诺也很开心。
  - [S12 第2条]「顺着这些事，他又想到以后两人一起过日子，越想越觉得幸福。」——“顺着这些事”搭配比较生硬。“这些事”指的是前一句里的琐事和难处，而这里实际表达的是思路由此继续展开，用“想到这些”或“顺着这个念头”会更自然。 → 想到这些，他又想到以后两人一起过日子，越想越觉得幸福。
  - [S13 第4条]「他不想让对方替自己解决这份难过，也不肯为了好受一点，就假装自己不想要这样的日子。」——“解决这份难过”把一种情绪说成了可以直接“解决”的问题，搭配略显生硬。这里真正要说的更像是不要求对方负责消除、承担他的难过。 → 他不想让对方负责消解自己的这份难过，也不肯为了好受一点，就假装自己不想要这样的日子。

### 5.6 第2次：7.5 分，3 处
- 最主要的问题：整体语言是可读的，人物的心理变化也基本能顺着 S01 到 S13 连续跟下来。多数句子本身没有明显病句，口气也没有刻意华丽；真正妨碍阅读的并不是大量局部错误，而是全文层面的抽象化和解释性偏强。最主要的问题是，同一核心愿望和行动不断换用若干近义的抽象名称，读者到后半篇需要额外辨认“那种生活”“珍爱的东西”“安宁”“温柔”“投入”“争取”“承担”等词彼此是什么关系；其次是很多条目都把心理原因、顾虑、转折和结论解释得很完整，长时间维持同一种理性复盘口气，使文字比“一个人平平常常讲自己的经历”更像经过整理的心理轨迹说明。否定式表达偏多也会稍微加强这种感觉，但它和人物从防备、自我逼迫中松开的主题高度相关，影响明显小于前两项。局部真正需要修的地方不多，其中 S06 的“舍不得出来”指向最不清楚，S04 的“舍不得否认”和 S07 的多重连接则属于轻度到中度的不自然。整体已有较好的连贯性和情绪线，如果主要稳定几个核心称呼，并让一部分心理关系少解释一层，语言会明显更自然，也更像人在讲经历。

  - [S04]「那种生活确实让他高兴，可他也舍不得否认，行动曾帮自己走出了犹豫。」——“舍不得否认”语感扭捏、生硬。在平实自然的叙述中，人不会“舍不得”去否认一个事实，通常只会说“但他心里清楚”、“他没法否认”或“他也不想抹煞过去的努力”。 → 那种生活确实让他高兴，但他心里也清楚，之前的行动确实帮自己走出了犹豫。
  - [S06]「连压着的委屈和想念也不急着放下，舍不得出来。」——句尾的“舍不得出来”缺少明确的前承对象。前面罗列的是情绪（委屈和想念），读者读到这里需要停顿一下，靠猜测去补全“从什么里面出来”（是从沉浸的心境里、还是回忆里出来），句末显得突兀脱节。 → 连压着的委屈和想念也不急着放下，舍不得从这种感觉里退出来。
  - [S10]「可他向往的那种能跟人亲近的生活还在受损，不能因片刻满足，就以为已经守住了它。」——“生活还在受损”属于不自然的词语搭配。“生活”一般可以说被打破、被破坏或难以为继；“受损”通常用于具体事物、利益、关系或身心健康。直接说“生活在受损”，读起来像生硬拼凑的书面语。 → 可他向往的那种能跟人亲近的日子还在被人打破，不能因为片刻满足，就以为已经守住了它。
