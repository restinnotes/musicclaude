我会把这批判定看成一个很明确的信号：**Q1 已经证明“综合写线时看去情节后的珠子”是对的；现在缺的不是再加一层补覆盖，而是让珠子在 A4 里更早参与“这一段到底处在什么方向”的决定。**

### 1. 这些没接上的珠子，真正缺的是什么？

我把两位评委重复指出的问题合起来看，大致有四类。

| 类型 | 典型判定 | 我的判断 |
|---|---|---|
| **方向直接相反** | S09 B3、S11 B1、S13 B1 | 最严重。不是措辞问题，A4 已经把本段人物状态定到了珠子的反方向，之后再“提高覆盖”只能打补丁。 |
| **方向没错，但状态写窄了** | S02 B5、S03 B3、S04 B4、S05 B2、S07 B3、S09 B1/B2、S11 B4、S01 B1/B3 | 数量最多。已有前因其实足够，但 A4 只取了其中一种自然后果，没有把同一处境里可以同时成立的另一层写出来。 |
| **珠子的时间形状丢了** | “冲破一点又收回来”“安静以后仍继续怀疑”“害怕之后反而向前”这类 | A3 有 `temporal_shape`，但 A4 没把“方向和落点”当硬信息使用。于是“都有紧张/都有安静”就被误认为接上了。 |
| **不值得追回的覆盖** | 要靠具体回忆、具体人生事实才能成立；或要求结尾彻底解决整件事 | 这是应该留在 `uncovered_targets` 里的那 10% 左右。强追只会重新走回 mb。 |

所以四个候选解释里，我会这样排：

**第一是路线/段内状态被选窄了；第二是写线时没有把体验性质当作“结构约束”真正用起来；“一段容纳不下”不是主要问题；评委过严只占小部分。**

尤其值得注意的是，很多“偏弱”根本不需要新增事件。一个人完全可以在同一个既有处境里同时有“舒服”和“提前舍不得”，或者“安静下来”和“疑问仍在”。标准本来也明确说“一段里的几种听感不压成一种”。现在 A4 实际上常常做了相反的事：**先从 route 选一个主心理动作，再让其他体验围着它排队。**

更深一层的问题是：A4 目前把 `base_route` 理解得太像“已经写死的剧情”。但 A1 的 route 最应该锁死的其实只有三样东西：**发生过什么、已经成立了什么、什么依赖什么**。某一段到底是更往前、往回缩、悬着、沉进去，很多时候还只是候选的实现方式。现在 TARGETS 到场太晚，能改措辞，不能真正参与“实现方式”的选择。

这也解释了为什么 Q2/P2 会崩：完全冻结线以后再见珠子，当然没空间；而 Q1 比它们好，是因为 A4 还剩一点空间。下一步应该扩大的是这块**合法的实现空间**，不是恢复逐珠补丁。

## 2. 我最建议先试的做法：只改 A4

核心改动只有一句话：

**先根据 ROUTES + TARGETS 决定“这条路线在每段怎样实现最合适”，再一次写完整线；route 的已成立事实不能改，但 route 里尚未成为 established 的局部心理写法不是圣旨。**

这和事后补覆盖有本质区别：珠子参与的是**成文前的整篇定型**。

还有一个重要变化：A4 选 `base_route` 时，不再只隐含地看哪个故事顺，而要先检查每条候选与 TARGETS 有没有大量**方向冲突**。如果一条路线天然让很多段落走到珠子的反方向，就不要选它。不是选“覆盖率最高的故事”，而是排掉“需要经常逆着自己才能覆盖”的故事。

下面是我会直接替换的 A4。占位符和输出结构都不动。

你要写一首器乐作品最终使用的 Thread。

Thread 是一个人在整首作品里经历的一件事。读者只看 Thread，也必须能从头到尾明白这个人为什么此刻会这样；之后它会和独立写成的听感记录放在一起，所以每段还要能自然接住若干体验性质。

你看到这些材料：

【段落】
{SECTIONS}

【这件事（Center，已经给定，不改）】
{CENTER}
它是回头看整首时把各段组织起来的那件事，不是每一段都要回应的题目。

【已经通过宏观评审的人物经历候选】
{ROUTES}

【从珠子去掉音乐、比喻和临时人物情节后得到的体验性质】
{TARGETS}

你看不到原始珠子。不要猜原始珠子的画面或措辞。

先完成整篇的内部定型，再从头到尾一次写完正文。不要先写出一条线，再逐段补 TARGETS。

【一、先判断候选路线能怎样实现】

ROUTES 是人物经历的骨架，不是已经写死的最终文案。

必须保持不变的是：
- situation 所规定的同一件事；
- 前面已经发生并被后文依赖的事实；
- established 中已经成立的认识、愿望、选择或问题；
- 真正的前因后果。

候选路线某段 state 中尚未成为 established、也没有被后文当作必要前因的局部心理写法，不必逐字照搬。
在不新增人物事实、不破坏前因后果的前提下，可以从同一批既有事实中选择另一种自然后果，也可以让几种本来能够同时成立的感受同时存在。

不能为了 TARGETS 改变已经发生的事实，也不能把人物带到与整条路线相反的另一件事里。

选择 base_route 前，先在内部逐段检查每条候选与 TARGETS 的兼容性。

特别检查三件事：

1. 方向
不要只看两边是不是都有“紧张、安静、高兴、难过”。
要看人物此刻实际是在：
- 更愿意靠近，还是更想退开；
- 更愿意承认，还是更想遮住；
- 仍在追问，还是暂时不再追问；
- 更确定，还是更怀疑；
- 想抓住，还是准备放开。

这里只是检查方向，不要把这些词机械写进正文。

如果某个 TARGET 与候选路线在这一段要求相反的方向，算作真实冲突，不能靠换措辞假装覆盖。

2. 同一段内部的变化
TARGETS 中如果有 temporal_shape，要保留它的先后和最终落点。
“先松开又重新收住”和“从头到尾都克制”不是一回事；
“安静下来以后疑问仍在”和“安静下来以后不再追问”也不是一回事。

不要只保留共同的情绪名词而丢掉变化方向。

3. 可以共存的不同感受
同一批既有事实有时能够自然产生几种不同但不矛盾的体验。
不要过早把一段压成唯一一种心理状态。

只要它们来自同一处境，并且彼此能够同时成立，就可以分别写出来。
但不能为了多覆盖而罗列互不相干的感受。

优先选择：
- 自身逻辑完整；
- 已成立事实最少发生冲突；
- 多数 TARGETS 能由既有事实或其自然后果产生；
- 不需要频繁新增心理机制才能接珠子

的候选作为 base_route。

不要为了多接几颗珠子选择本身较差的路线。
如果某颗珠子只有靠新增人物事实、破坏已经成立的状态或把人物推向相反方向才能覆盖，就允许不覆盖。

【二、线自己先成立】

每段此刻为什么这样，只能来自：
- 更早已经发生在他身上的事情；
- 更早已经成立但现在产生后果的认识、愿望或选择；
- 上一状态自然延续到现在。

不能因为某个体验目标需要一种情绪，就临时给他新增一段前史、关系事实、对方行为、回忆、决定或人生观。

尤其不能用“对方这时又做了什么”来发动本来没有根据的转折。

某个体验目标如果只有靠编新事实才能覆盖，宁可把它留下不覆盖。

【三、人物状态只能真正变化一次】

全文维护 established ledger。

某个认识、决定、愿望、问题一旦已经明确成立：
- 后面可以实行它；
- 可以承受它带来的后果；
- 可以发现它还有以前不知道的一面；
- 可以明确改变它；
但不能把同一件事重新写成第一次明白、第一次接受、第一次决定。

如果再次回到类似问题，必须有具体新增内容；否则只写延续。

不要用人物反复采取心理动作来制造推进。
“忍住、放开、说服自己、决定不想、试着收住、又决定不收住”如果只是同一个问题来回操作，不算新的经历。

【四、不要把强度当推进】

情绪变得更强、快乐更满、痛苦更深，可以是本段的重要体验，但不自动等于人物获得了新认识。

已有事情在这一刻真正落到他身上，也可以构成充分变化。

同样，不要因为某一段需要较强的体验，就强迫人物在这里作决定或得出结论。

【五、覆盖 TARGETS 的方法】

TARGETS 不是待翻译的文本，也不是逐项完成的任务单。

先让人物处境成立，再判断同一处境自然能承载哪些体验。

覆盖一颗珠子时，正文中必须真的存在与它相近的处境、方向或变化过程；不能只因为出现了同类情绪词就算覆盖。

特别注意：
- 如果 TARGETS 的关键在方向，正文方向必须相符；
- 如果关键在 temporal_shape，正文必须有相近的先后变化；
- 如果同一段几颗珠子可以共存，不要把它们压成一个平均感受；
- 如果 tensions 中是确实不能同时成立的不同听法，不必硬把两边都写成事实。

严禁因为 TARGETS 而新增：
- 对方做了什么；
- 两人发生了什么新事件；
- 过去曾具体发生什么；
- 新对白；
- 新场景；
- TARGETS 暗示出来、但人物路线原本没有的关系事实。

允许 TARGETS 影响的是：
在已经成立的人物事实之下，这一段具体突出哪一种自然后果、哪几种可以共存的感受，以及这些感受在本段内部怎样变化。

不要求 100% 覆盖。
真实冲突、必须靠新事实才能成立、或者只有把珠子的画面当真人经历才能成立的 TARGETS，应留在 uncovered_targets。

【六、每段内容】

每段写 2–4 条。
一条是一句完整、自然的人话。

一件事一句能说清，就不要拆成几条。
每条必须有独立作用，不得重说本段或前文已经说完的认识。

一段里如果同时存在几种不同感受，可以分条写，但每一种都必须来自同一个已经成立的处境；不要写成情绪清单。

事情少的段落就保持最短的合法长度。

语言像一个人平常讲自己的经历，不像心理分析、论文、总结或提纲。
优先写他此刻具体在意什么、盼什么、舍不得什么、担心什么、还拿不准什么。
少用抽象名词替代这些东西。

不要写格言、人生原则或作者替人物作总结。

【七、引用】

某条之所以成立，确实依赖更早某一条具体经历时，在 cite 中写前文条目编号。

不强制每段一定有 cite。
只是主题相近、情绪相近，不算前因。

不要在正文里写“提供理由”“限制”“说明”等关系标签。

【八、与整件事的关系】

正文全部写完后，再根据这一段实际写出的内容，标：
- 没在想
- 还说不清
- 正在面对

标签必须从正文推出来，不能为了保持预设标签而改正文。

【九、结尾】

不要为了像结尾而制造最终决心、彻底想通、人生结论。

但“没有彻底解决整件事”和“这一刻什么也没有落定”不是一回事。
如果前面的经历自然使人物此刻有一个明确的站法、选择或感受，可以明确写出来；不要为了保留开放性又把已经能够落定的东西故意写悬。

走到哪里就写到哪里。
真正还不知道的，才保留不知道。

【输出】

{
  "base_route": "...",
  "segments": [
    {
      "sec": "S01",
      "relation": "没在想/还说不清/正在面对",
      "items": [
        {
          "id": "S01-1",
          "text": "...",
          "cite": [],
          "covers": ["..."]
        }
      ],
      "delta_type": "...",
      "delta": "..."
    }
  ],
  "uncovered_targets": [
    {
      "bead_id": "...",
      "reason": "为什么若强行覆盖会伤害人物逻辑"
    }
  ],
  "established": [
    {
      "claim": "...",
      "first_established": "Sxx-x"
    }
  ]
}

covers、delta、established 是内部校验信息；最终展示时删除。

我会**先只跑这个改动**。因为它正对着你现在的断点，而且不增加 DAG 层数。

我预期它主要修的是两类失分：一类是目前“差一点”的珠子，另一类是由于 A4 自己选错局部方向造成的“相反”。如果它有效，覆盖应该上升，同时字数不需要明显增加——因为不是往已有句子里塞东西，而是**一开始就选另一种更兼容的写法**。

## 第二个做法：如果 A4' 还不够，再改 A1，但不是把路线写宽泛

我不建议直接让 A1 “多考虑各种可能感受”。那很容易产出一堆模糊状态。

更值得试的是：**A1 不要过早把每段收束成一个心理操作；保留那些由同一批事实自然产生、以后仍可能往不同方向落的“活的矛盾”。**

这和你准备给 R 加的“不靠心理动作推动”同方向，但再往前一步：不只是禁止“试办法”，还要防止 A1 **过早解决 still_open**。否则 A4 即便看见 TARGETS，也只能推翻路线才能接。

A1 的字段完全可以不改；让 `state` 的 1–3 条承担这件事。

你要为一首器乐作品设计 Thread 的“人的经历骨架”。

Thread 是同一个人在整首作品里经历的一件事。以后会把它写成逐段关系图，但这一层只负责把这件事本身想清楚。

【输入】
作品：{NAME}
段落顺序：{SECTIONS}
Center：{CENTER}

这一层：
- 完全不看任何听感记录或“珠子”。
- 不写音乐、声音、旋律、节奏、和声、小节里的事件。
- Center 已经给定，见下。它是读者回头看整首时把各段组织起来的那件事；不是他一开始就清楚知道的事，也不是每一段都要回应的题目；不预告发展路线和结局。
- 可以利用你对作品整体走向的理解安排各阶段的轻重，但输出里只写人的经历。

请独立提出 {K} 条完整候选路线。

每条路线必须从头到尾只是一件事。可以没有具体外部事件；不要新增聚会、书信、物件、对白、地点、职业等情节来推动变化。

最重要的规则：

1. 前面已经发生过、相信过、期待过、得到过、失望过的东西，才可以成为后面此刻这样想或这样感受的根据。

2. 不要把 Center 缩成一个人物反复操作的心理问题。
一件事不等于一个机制。

如果一条路线的大部分推进都靠人物反复：
- 忍住或放开；
- 试着想开；
- 决定不想；
- 收住又重新放开；
- 找一种办法保护自己；
那么这条路线通常过窄。

人物的经历可以往前走，是因为先前发生的东西继续产生后果，他对同一件事看见了以前不知道的一面，或者原本悬着的东西在新的处境里真正落到自己身上；不必靠他不断管理自己的心理状态。

3. 不要靠新出现的对方行为或外部事件发动转折。
如果后面的变化只有在“对方这时又做了什么”以后才能成立，说明前面的经历本身没有把它推到这里。

4. 一个认识、决定或问题一旦已经明确成立，后面不能再次把同一件事写成第一次成立。
如果后来回到类似的地方，必须明确写出这一次新增了什么；没有新增内容，就标成延续，不要制造第二次转折。

5. 不要求每段都有新认识。有些段落可以只是：
- 已经存在的感受继续存在；
- 某件已经知道的事真正落到自己身上；
- 暂时沉浸在别的感受里；
- 前面的某件事产生后果。

不要为了填满段落制造心理动作。

6. 特别区分“情绪变强”和“人物处境发生了新变化”。
情绪更强本身不算新的认识或决定。

7. 不要过早把仍然能够同时成立的东西处理成单一态度。

如果前面的事实使人物既有一种愿望，又有一种真实顾虑，而且两者并没有真正解决，那么后面的 state 可以让它们继续同时存在。
不要为了让路线显得干净，提前替人物选边。

只有前面的经历真的使其中一边改变、失效或被重新理解时，才把这种变化记进 delta 和 established。

state 的 1–3 条应该写这一段此刻实际同时成立的重要情况，而不是把同一件事拆成几个近义句。

8. still_open 不是必须尽快解决的任务。
它的作用是保存到这一段仍然没有答案、以后仍可能产生后果的东西。

不要因为连续几段都保留同一个 still_open 就强行安排人物处理它。
只有当人物的处境真的变了，答案才应改变。

9. 不要让人物不停总结自己。
优先写他当时具体在意什么、盼什么、犹豫什么、已经知道什么、还不知道什么。

不要用自造的抽象概念替人物反复命名自己的处境。

10. 结尾不必解决问题，也不要为了有终点而制造决心、原则或人生结论。
但前文已经自然形成的明确变化，也不要为了保持开放而重新写模糊。

11. 同一路线中要保存一份“已经成立的事实账本”。
后面的段落不得违背它，也不得把其中已经完成的变化重新完成一次。

12. 检查整条路线的“实现空间”。

在不改变任何已成立事实的情况下，后续写线的人应该仍然能够把一个真实处境写得有层次，而不是每一段都已经被锁成唯一一个心理动作。

实现空间不等于含糊。
人物已经知道什么、发生过什么、什么依赖什么必须清楚；
可以保留余地的是：同一批事实在这一刻具体哪种感受更突出、几种能够共存的感受怎样一起落到他身上。

如果一条候选只有按照你现在写下的唯一心理方向才能成立，把它改得更依赖事实和后果，而不是依赖心理操作。

每条候选输出：

- route_id
- situation：一句普通话，说清这个人正在经历的是哪一件事；不要写抽象论文标题。
- segments：
  - sec
  - state：本段此刻实际是什么情况，1–3 条
  - delta_type：从“新变化 / 后果 / 实行已有想法 / 延续 / 回到旧处但有新增 / 暂时没在想”中选择
  - delta：这一段相对以前真正新增了什么；没有就写空
  - depends_on：真正作为前因的更早 state 编号；没有就空
  - still_open：到这一段仍未解决或仍不知道的东西
- established：按首次成立顺序列出全文的重要事实、认识、愿望或选择，并标明第一次成立在哪一段

不要写最终文案，不要评价候选。
只输出 JSON（字段名照上面写的）。

如果只能先跑一个，我选 **A4'，不是 A1'**。Q1 已经有明显的单独成立优势，先别动它最成功的那一头。A4' 是最小但结构性的改动。

## 3. 还有三件很值得试，但我不会把它们同时塞进主 DAG

第一，**检查 A3 有没有把真正重要的“方向”抽掉**。你现在只给了评委判定，没有给这里对应的 A3 输出，所以我不能确定这一刀到底损失多少。但可以做一个很便宜的离线诊断：拿所有判为“相反/没有/偏弱”的珠子，看 A3 的 `qualities + temporal_shape` 里是否还保留了评委指出的核心区别。如果原珠子是“安静以后仍追问”，A3 只剩“安静、不确定”，那 A4 再聪明也不可能稳定接准。若这个比例高，再改 A3；若大多数信息都还在，就不要碰 A3。

第二，**最终完整生成做 Best-of-N，只挑不改**。这是现在特别适合试的一条。相同的 ROUTES、TARGETS 和 A4'，并行生成 3–4 条完整 Thread；随后让比较评委同时看几条，只选一条，绝不修改。它和已经失败的“事后改写”完全不是一回事：每条候选从一开始就是完整生成，选择不会把结构重新揉坏。你现在的单次路线选择和局部实现有明显随机性，Best-of-N 很可能能吃掉一部分覆盖尾差，而且不会制造“补珠子腔”。

第三，**把覆盖评委拆出一个“不应计入缺失”的出口**，但不要借它美化数字。现在至少有些理由已经越过了标准边界：如果评委认为只有引入珠子里的具体回忆、具体情节才能算接上，那它实际在奖励“翻译珠子”。另一些结尾判定则容易把“明确收束感”误成“人物必须彻底解决 Center”。建议最终仍报两个数：`合法可覆盖中的覆盖率` 和 `全部珠子的覆盖率`；前者用来判断线写得好不好，后者保留观察，不要直接把所有缺口都倒逼给生成器。

### 我会怎么排下一轮实验

不需要铺很多分支。先在同一路由下跑 **Q1 + A4'**，其余完全不变；重点不只看总覆盖，还单独数三个指标：**“相反”还有多少、偏弱里有多少是方向/temporal_shape 没落进去、字数有没有重新膨胀。**

我期待的好信号不是一下从 35/50 变成 50/50，而是：**“相反”接近清零，偏弱明显减少，同时字数和人话基本守住。** 如果做到这一点，再用 Best-of-N 或 A1' 去拿最后那一截，比重新引入任何“逐段补覆盖”安全得多。
