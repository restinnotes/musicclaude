感受：182小节附近，高音区忽然浮出一串轻如游丝、却带着刺骨寒意的长颤音，像寒风吹开紧闭的窗；后颈一凉，脉搏也剧烈跳动，梦境骤然破裂（到时出现） / 祈祷般的静谧忽然被带着马祖卡色彩的舞蹈材料截断，像突然换了一个场景；这种突兀的转向并不等于情绪好转 / 先前带着波兰舞曲气息的声音再次出现，却已不再像最初那样，以完整鲜明的姿态建立秩序（到时出现） / 熟悉的动作、一次舞蹈，或一段曾经习以为常的生活突然闯进深沉的感受；这种亲切反而让人更容易意识到失去了什么（到时出现） / 198-205小节，连续颤音让紧张一层层累积，思绪不停翻转，想冲出去却始终找不到出口；身体和情绪都还没能平复（到时出现）

### S08（屏幕停留 20 秒）
话：他先把回去的事放一边；想起曾被当作自己人，心里暖了一会儿，却【没因此想回头】。可那点暖意很快淡了：以后真遇上难事，【回忆没法陪着他】，心又悬起来。
感受：缓慢、宽广的歌唱短暂回来，熟悉的柔软、近乎祈求的气息重新打开；胸口仿佛终于吸进一口气，可安静停留得太短，很快又退去，像离开前回头再看一眼

### S09（屏幕停留 31 秒）
话：他忽然说不清，想回去是舍不得被【当作自己人的日子】，还是怕孤单到【连那些气也肯再受】；这念头让他一阵心慌，连往下想都不敢了。
感受：双手铺开巨大的颤音光晕（到时出现） / 开头沉重的引子从光晕中阴冷地闪现，不再像最初那样郑重召唤；声音短暂落稳又向高处漂去，像从另一面重新看见同一扇门，向前的步伐还没聚起来（到时出现） / 像重新遇见那个不知道怎么办的自己，只是这一次，已经知道他经历过什么；最初的问题又浮上来，却仍没有简单的答案（到时出现）

### S10（屏幕停留 28 秒）
话：他慢慢觉得【最舍不得的】，还是曾被当作自己人的日子；可真回去还能像从前吗？当初那些难受不能当没发生，光凭想念仍让他放心不下，反复想得很累，连眼下也【过得不踏实】，心里又浮起一句：我究竟要怎样继续生活？
感受：熟悉的如歌旋律和舞曲只剩几块断断续续的碎片；也像摇篮曲破碎地重现，却变成了F小调的凄厉哀婉 / 221-225小节忽然像失重，整个人悬在半空，辨不清方向，连身体也暂时失去了着落（到时出现） / 像一个疲倦的人回想一件重要的往事，却已经没有力气把它重新讲述一遍

### S11（屏幕停留 22 秒）
话：他明知道回去未必找得回那份亲近，却还是会想万一能呢；可不愿只凭这点指望回去忍让，决定【先把眼下过稳】。以后仍怕独自扛难处，心里也没多少底，却不想因害怕收回打算——【害怕还在，脚已经往前】。
感受：左手涌起滚滚低音波涛，右手和弦像重锤砸下；每次爆发后紧张都没有完全解除，反而又形成新的压力，像困兽一次次顶住、再用力 / 波兰舞曲的步子起初还在试探，随后一点点聚拢，到最后四小节，前进感越来越不可回避；祈祷般柔软的声音仿佛开始变成意志（到时出现）

### S12（屏幕停留 25 秒）
话：他终于【不再逼自己选边】：当初那些气不该忍，和那些人在一起也确实开心过；他不怪自己离开，也不愿只为有人陪就回头，愿意【带着想念继续过日子】，不必假装自己从未受过伤。
感受：熟悉的波兰舞曲主题以雷鸣般的声势轰然回归，像沉重的步子终于踏实落地，也带着面向外部、近乎集体的昂扬 / 249-253小节之间，音乐忽然换了一下色彩，像脚步正往前时地面短暂斜了一下，随后却仍继续向前（到时出现）

### S13（屏幕停留 62 秒）
话：想起从前自然亲近的日子，他【心里又热起来】，也盼着以后还能有那样的相处；这么想着，他倒真有了劲头，想把往后的日子【好好过起来】，不再整天跟从前较劲。
感受：先前像私下安慰、近乎祈祷的柔软歌唱，忽然被带进开阔、宏大的声响里，像一支温柔的歌站到了明亮处；密集音符如心脏以最高负荷跳动，也让人想到故土、共同记忆和希望（到时出现） / 快速、炫目的八度向前冲出，像一股气流推着身体往前跑，兴奋得几乎来不及喘息（到时出现） / 冲势慢慢收敛，颤动般的装饰音又带来一点不安，像在问刚刚建立的成功是否真的牢固；也像事情终于说完，可以停下来喘口气，平静里仍留着细微的疑问（到时出现）
话：劲头稍缓，他又怕还要等很久才能遇上那样亲近的人，【心里渐渐静下来】；将来若有人愿意把他当自己人，他会好好珍惜；即使一直没有，也愿意自己好好过，【不再为了留住谁把委屈咽下去】。
感受：狂潮退去，低音像呼出最后一口气，沉沉吐出两记耳语般的和弦；随后高处亮起一记透明、孤悬如寒星的和弦，像清脆的钟响。它可以听作一个决定，也可以听作一个人忽然从梦中醒来（到时出现）
