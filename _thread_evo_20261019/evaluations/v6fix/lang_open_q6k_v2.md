  - [S06 第2条前半]「独自回想，他像初懂喜欢般单纯，也觉未来陌生、酸楚难说」——“像初懂喜欢般单纯”偏压缩、偏书面；“也觉未来陌生、酸楚难说”又把对未来的陌生感和说不出的酸楚挤在一起，读着需要稍微停顿，才能分清两种感觉。这里不是心理矛盾有问题，而是表达过于紧缩。 → 一个人回想这些时，他又像刚懂得喜欢一个人那样单纯；可一想到未来，又觉得陌生，心里酸楚，却说不清楚。
  - [S06 第2条后半]「盼以后没了这份满足，回忆还能给他力量。」——“盼以后没了这份满足”容易在第一遍阅读时被理解成“盼望以后失去这份满足”。实际意思应当是：希望即使将来失去这种满足，回忆仍能支撑自己。条件关系没有交代清楚。 → 他盼着，就算以后不再有这份满足，回忆也还能给他力量。
  - [S09 第3条]「他当初那么用心珍惜，也决定不了以后，仍疼；但两人能这样相爱，比他自己的愿望更值得珍惜。」——“仍疼”收得太急，像是把“他心里还是会疼”压缩成了两个字。在前面接着“也决定不了以后”时，语气有点突然，不太像平常讲述经历。后半句表达的价值转变是清楚的，不需要改变。 → 想到自己当初那么用心珍惜，却仍决定不了以后的事，他心里还是会疼；但两人能这样相爱，比他自己的愿望更值得珍惜。
  - [S10 第2条]「欢喜得轻快、几乎收不住」——“欢喜得轻快”搭配不太顺。通常是欢喜得“整个人轻快起来”，或者欢喜“几乎收不住”。这里把两种不同的表达并列在一个“得”字后面，读起来不够自然。 → 欢喜得整个人都轻快起来，几乎压不住那股喜悦
  - [S11 第3条]「他比以前更满足，久盼的自在亲近像得了回应，却仍想尽情爱；更觉亲近珍贵，也喜欢如今柔软、慷慨的自己。」——“久盼的自在亲近像得了回应”不太顺畅。通常是一个人的盼望得到回应，或者终于得到盼望已久的亲近；这里却把“自在亲近”本身写成了得到回应的对象。后面“更觉亲近珍贵”也略显压缩，使整条偏像心理概念的连续排列。 → 他比以前更满足，仿佛终于得到了盼了很久的那种自在亲近，却还想尽情去爱；他越发觉得这样的亲近珍贵，也喜欢如今柔软、慷慨的自己。
  - [S13 第3条]「他想至少牢牢记住这一切，可记得再牢，也只是真有过这份幸福，没法把它留在眼前。」——“可记得再牢，也只是真有过这份幸福”在语法和意思的衔接上都有点卡。记忆再牢固，也只能记住幸福曾经真实存在过，而不能使幸福一直停留在眼前。原句把“记住”和“真有过”直接接在一起，省略了关键关系。 → 他想至少把这一切牢牢记住，可再怎么记，也只能记住自己确实有过这份幸福，没法让它一直留在眼前。
- 累积（中等）：对未来无法保证的担忧，在中后段多次以相近的话重新说明，部分位置削弱了心理发展的推进感。｜影响：这条线的核心矛盾本来就与“眼下幸福，却无法保证未来”有关，因此担忧反复出现是合理的。问题不在于反复担忧，而在于某些相邻阶段重新交代的内容几乎相同。尤其S09已经明确说他现在幸福、仍怕以后会变，S10又说虽怕以后变；S12刚说幸福换不来永远，S13又说以后没法都如他所愿。连续读下来，有时感觉叙述正在重新说明已经理解的前提，而不是让人更直接地感受到这一阶段新出现的心理反应。这样会让后半篇的推进稍显迟缓，也削弱了几次转折的鲜明程度。｜边界：S04到S05是担忧开始形成，值得写；S07的患得患失、S08的停止催问、S12的急切与无力、S14的接受不确定，都是不同的发展阶段，不能因为都涉及未来就视为重复。S14再次承认仍会疼也很必要，因为它说明结局不是消除担忧，而是带着担忧继续爱。真正可以减少的是相邻段落中没有带来新认识、新行动或新心理后果的同义提醒。｜建议：保留关键阶段对未来的担忧，但在已经说清楚这一前提之后，下一条优先写担忧如何改变了他，而不是再次说明他担心什么。例如S10第2条可以写成：“他顺着心意去爱，也珍惜对方自愿给的爱；那份欢喜重新涌上来，他终于又能放松些了。”前一句已经说明他不再要求保证，此处不必再次说怕以后变。S13第1条则可以突出无力感：“那股急切过后，他刚感到满足，又忍不住想把爱全给出去；可越是用力，越觉得往后的事由不得自己，终于感到无力。”

### 5.6 第1次：7 分，11 处
- 最主要的问题：整篇作为一条连续叙述是成立的：从最初想靠近、得到回应，到因珍惜而害怕失去，再到追问、松手、接受不能保证长久，最后决定“不要求保证，也不收回爱”，心理线索完整，而且多数地方读者不需要猜发生了什么。真正影响连续阅读的首要问题，不是某几个病句，而是中后段反复用“幸福／满足—舍不得—怕以后—想留住／珍惜”的相近抽象词汇解释心理，使本来有层次的变化偶尔听起来像同一件事的几种改述；再加上很多条目把数层转折压在一个复句里，全文会比“平平常常讲自己的经历”更像一份细致的心理梳理。局部还有若干明显的压缩式表达，如“盼以后没了这份满足”“只当珍惜”“决定不了以后”“也只是真有过这份幸福”，这些会让人短暂停顿，但属于次要问题。总体仍然清楚、有连贯的感情推进，也有一些很自然有力的句子；如果减少中段同义重述，并把少数过度压缩的复句放松一些，语言会明显更自然。
- 一再出现：核心情绪反复使用“舍不得、怕以后、珍惜、留住、幸福”等相近措辞重述，削弱了中后段各阶段之间的语言差异。；复句中频繁叠加“却、又、仍、可、只是、但”等转折和限定，使部分段落显得像在逐层分析心理，而不是自然讲述。；“对方”在若干位置连续重复，累积后略显抽象和疏离。
  - [S01 第2条]「他想走出独处去靠近对方，又拿不准心意会不会被接住。」——“走出独处去靠近”搭配得有些硬。“走出独处”不是很自然的日常说法，而且“走出”和“去靠近”直接连在一起，读到这里会稍微停一下。 → 他想从独处里走出来，去靠近对方，又拿不准自己的心意会不会被接住。
  - [S02 第3条]「喜欢就热切表达，不必说尽也能自然做自己」——“不必说尽”省略得稍过头，一时不清楚是“不必把什么说尽”；“自然做自己”也不如“自在地做自己”顺口。两个压缩表达连在一起，句子显得有些加工感。 → 喜欢就热切表达，话不用说尽，也能自在地做自己
  - [S05 第1条]「想到以后谁也不能保证」——“保证”后面缺少明确内容。上下文能猜出是“以后会怎样谁也不能保证”，但原句本身收得太早，读者需要自己补齐。 → 想到以后的事谁也不能保证
  - [S06 第2条]「他像初懂喜欢般单纯，也觉未来陌生、酸楚难说」——“像初懂喜欢般单纯”略带生硬的书面压缩；后面的“未来陌生、酸楚难说”又把两个不同的判断并排压在一起，关系不够清楚。整段意思可以懂，但不像平常说话。 → 他像刚懂得喜欢时那样单纯，也觉得未来陌生，那点酸楚说不清
  - [S06 第2条]「盼以后没了这份满足，回忆还能给他力量。」——“盼以后没了这份满足”容易先被读成“盼着以后失去这份满足”，与实际意思相反。真正想表达的是：如果以后失去了，希望回忆还能支撑他。 → 他只盼着，如果以后没了这份满足，回忆还能给他力量。
  - [S06 第3条]「只当珍惜，没察觉还想用心留住幸福。」——“只当珍惜”成分不完整，不太像自然汉语。这里实际是“只以为自己是在珍惜”的意思。 → 只以为自己是在珍惜，没察觉自己其实还想用心留住幸福。
  - [S09 第2条]「刚才那样幸福却仍令他恍惚」——“那样幸福”通常是描述人的状态，直接拿来作“令他恍惚”的主语略显别扭。这里实际指的是“刚才那种幸福”或“刚才那段幸福的感觉”。 → 刚才那样的幸福却仍让他恍惚
  - [S09 第3条]「他当初那么用心珍惜，也决定不了以后，仍疼」——“决定不了以后”缺少“以后会怎样”这一层，搭配比较硬；“仍疼”又压缩得过短。几个省略连在一起，使本来很清楚的心理意思变得像提纲。 → 他当初那么用心珍惜，也决定不了以后会怎样，想到这里还是会疼
  - [S10 第2条]「欢喜得轻快、几乎收不住」——“得”后面并列的“轻快”和“几乎收不住”不是同一种补语结构，因此读起来不太稳；“收不住”具体收不住什么也稍显悬空。 → 欢喜得几乎收不住，整个人也轻快起来
  - [S11 第3条]「久盼的自在亲近像得了回应」——真正“得到回应”的应当是他的盼望，而不是“自在亲近”本身。现在把“久盼的自在亲近”直接当作“得了回应”的主体，语义关系有些拧。 → 长久盼着的那种自在亲近，仿佛终于真的有了

- 累积（中等）：同一组抽象关键词在全文反复回环，使一些本来有细微变化的心理阶段读起来像在重新陈述同一份结论｜影响：「从前」「安心」「亲近」「理解」「坚持」「看重的事」这些词本身都很平常，也确实是这条心理线的核心，所以单独看并没有问题。连续读下来，问题在于这些词经常以相近的组合再次出现：从前有亲近和安心，现在靠坚持守住看重的事，但亲近仍然缺失。人物其实在不断改变对这些东西的理解，可语言常常先把同一套概念完整复述一遍，再补上一点新的变化，于是中后段容易产生原地绕圈的感觉。读者能理解每一步，却需要额外分辨这一段和上一段到底新增了什么。｜边界：核心词不应该全部换掉。像「坚持」「从前」「亲近」本来就承担着贯穿全曲的主题作用，在人物真正重新评价它们时重复反而有力量。真正影响阅读的是：上下文已经很清楚时，仍把「亲近、理解、安心」或「坚持、看重的事、肯定自己」整组重新说全；以及新的心理变化被包在大段旧信息里。可以保留关键回声，但省掉读者已经知道的那一半。｜建议：优先保留每一段真正新增的心理变化，把已经建立过的概念适当省称、压缩或改成动作表达。例如 S08 第2条可改为：「过去的好和自己一路的坚持，他现在都不愿否定，只是眼下仍少了亲近和理解。」S13 第3条可改为：「他为自己没有把看重的事丢掉而自豪，也更明白，这股劲儿里一直有从前那种亲近和信任留下的东西；他还是愿意善待别人。」这样仍保留主题词，但重点更落在这一阶段的新认识上。

- 累积（中等）：转折、让步和自我修正的句式过于密集，连续阅读时容易形成几乎每句话都在「前一句之后再加一个但是」的节奏｜影响：人物的核心状态本来就是两头拉扯，因此「可、却、仍、还是、又、只是、就算」大量出现有充分的内容理由。问题是它们密集到一定程度后，叙述的节拍会变得高度同构：先承认一种感受，再立即补上另一面，再说明两面都没有消失。尤其 S05、S12 一类段落，几乎每一条都在做这种修正。连续听下来更像在精确整理心理逻辑，而不像一个人自然地讲自己怎么一路走过来，情绪的起伏也因此略显规整。｜边界：真正发生心理反转或两种愿望正面冲突时，转折词非常必要，例如「他不再逼自己非得坚强」之后重新允许怀念，或「仍选择坚持」同时承认害怕，这些地方不宜为了变化而删。可以减的是那些上下句内容本身已经足以体现反差、却又额外使用一层「还是／可／又／却」的地方。｜建议：让一部分矛盾直接并列，或让前后内容自然产生反差，不必每次都显式标出转折。例如 S05 第2条可以从「他还是不肯为了重新被接纳委屈自己，可也不想以后都独自撑着」改为「他不肯为了重新被接纳委屈自己，也不想以后一直独自撑着。」两种愿望的冲突仍在，但句子不再重复做一次逻辑提示。S12 第4条也可稍微拆开：「不再压着怀念后，难过反而更明显。有时他也不知道自己能走多远，但至少没有因此否定自己。」
