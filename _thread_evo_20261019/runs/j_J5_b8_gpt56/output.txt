我把 Thread 质量放在首位，音乐可信度单独评分；拿不准的音乐细节不据此重扣。

### 文章A

**什么在变 / 为什么 / 留下什么：** 她一开始把他的照顾理解成一种可以向未来索取保证的东西；得知他真心想远行以后，她逐步分清“他爱我”“他会留下”“我也有自己的生活”并不是同一件事。变化之所以成立，是因为早先具体建立的东西后来真的被重新使用：铺子、他的照顾、那只暂时离开的手、她自己的钥匙、他谈海时的兴奋；结尾仍没有解决他究竟去不去、去多久、分别会怎样，只解决了两个人怎样诚实地站在这个未决问题前。

**最好：103–110小节。** 靠岸不是比喻性总结，而是一次真正的失败、疼痛和协作：她第一次抛绳没套住，他又无法腾手替她完成；最早“等他扶我”的关系在这里被身体事实重新检验，而且没有滑成“独立就是不需要别人”。这是五篇里最强的累积之一。fileciteturn0file0L183-L199

**最差：93–102小节。** “信里别只写平安—难事也告诉我—你也要告诉我”的互惠约定稍微太整齐，像成熟关系原则被及时写进高潮；前后的人物细节救回了它，但这里比全文其他地方更能看到作者在安排答案。fileciteturn0file0L151-L173

不判 F6：虽然真的用了“船”，但铺子、远航、信件和靠岸都在改变人物选择，不只是给“航行—放手”模板换皮。

### 文章B

**什么在变 / 为什么 / 留下什么：** 主体从“亲近应当满足我全部生命”变成承认自己与伴侣各有独立生长的需要，再变成理解“两种愿望共存会彼此改造，而不是简单并排”。结尾保留了争执、让步、无法满足的愿望；问题在于这些变化大多由论述解释出来，而不是让一个具体人的经历迫使他改变。

**最好：103–110小节。** 它抓住了一个很重要的结构事实：103附近已经有明确的主音到达，上方却仍继续以先前较躁动的材料、强奏和尖锐和声活动；因此“知道落在哪里”和“真正承受住落在那里”被区分开。这是文章最有说服力的音乐—Thread连接。fileciteturn0file1L582-L604

**最差：35–39小节，连同正文前的提纲。** 文件开头已经直接宣布“真正接纳两种幸福意味着改变理解幸福的方式”，还预先交代各关键段应怎样理解；正文于是很容易变成逐段举证。fileciteturn0file1L3-L7 到35–39又迅速把稀薄织体解释成“尚未被使用的生命”，哲学命题先于可进入的处境。fileciteturn0file1L176-L216

这里明确判 **F2、F3、F7**。它不是 F1：其逻辑远比“越来越激动”复杂；问题恰恰是逻辑太完整、太先行。

### 文章C

**什么在变 / 为什么 / 留下什么：** “我”从需要被托住、被带回，逐渐发现自己也可以拥有方向，最后重新回到亲近，却不再把回归当作唯一安全选项。结尾留下的是冲突仍会存在，但某种关系可以承受改变；这个变化可辨认，不过“为什么在人生里此刻会这样”经常只有抽象心理解释，没有真正事件。

**最好：84–92小节。** “因为已经在A大调尝过另一种可能，所以第一主题回来时不再只是依赖，而成了主动选择”——这是同一音乐因经历改变而改义，完全击中 Thread 的核心要求。fileciteturn0file2L127-L139

**最差：40–61小节。** “受过温柔照顾，所以才有勇气离开庇护”“沿自己的步子再走一段”等句子逻辑上通顺，却没有发生足以迫使人物如此认识的事情；“自由、方向、庇护”承担了过多人类处境本应承担的工作。fileciteturn0file2L61-L83

判 **F3、F7**。音乐方面有一个明确问题：文章两次按“六八拍”理解节拍；我对此曲的记忆是原作 **12/8**。fileciteturn0file2L5-L7

### 文章D

**什么在变 / 为什么 / 留下什么：** 他起初真正想要的是“下一次见面也能预先确定”；她要去另一座城市以后，他先试图靠交通安排消除不确定，再因为亲眼看见她对新生活的热情，逐渐学会把“我舍不得你”与“所以你不该走”拆开。结尾并没有解决何时再见、关系能否维持，甚至“别走”的冲动还会回来；改变的是他已经能让自己的难过和她的愿望同时是真的。

**最好：51–77小节。** 用查车次、计算周末往返这样非常普通的行动，把“我其实想要的是保证，不只是见面的可能”做了出来；随后62–71让他真心分享她的兴奋，于是“要求她留下会损伤我所喜欢的那部分她”不是道理，而是前一刻刚亲自看见的事实。fileciteturn0file3L29-L38

另一个尤其好的地方是103–110：理解过这么多以后，他仍“几乎想再说一次不要走”；文章没有为了证明成长而取消旧欲望。fileciteturn0file3L53-L54

**最差：78–83小节。** 倒影“被分成两半、后来又靠近”的景象稍显写得太合题，象征设计比人物行动先露出来；不过它没有被强行解释成和解，所以损伤有限。fileciteturn0file3L41-L42

不判 F6/F7：船景虽多，但真正推动 Thread 的是工作、周末、车次、分别这些不可互换的具体事实。

### 文章E

**什么在变 / 为什么 / 留下什么：** 人从想把美好稳定保存下来，逐步转向允许美好变化、允许自己充分投入而不要求永久保证。结尾仍承认未来会改变、仍可能担心；但核心困难其实在文章开头已经被定义，并且结尾基本按原定义得到答案，所以“变化”更像哲学论证完成了，而不像人物被经历改造了。

**最好：103–116小节。** 对“103已经到达，却还不能结束；111以后才真正卸下高潮重量”的处理很好，它拒绝把调性抵达误写成心理问题自动解决。fileciteturn0file4L335-L383

**最差：62–71小节。** 音乐刚获得充分快乐，文章便立即提炼出“一个时刻不能因为美好就不再成为过去”；这几乎就是开头预设的“美好不能靠留住来获得”再次被证明。fileciteturn0file4L179-L209 文件开篇本身也把中心答案直接写明。fileciteturn0file4L3-L7

判 **F2、F3、F6、F7**。其中 F6 尤其明确：这正接近题目要求警惕的“幸福不能停留/航行—安稳—放手”模板。另立“第117小节”也很伤独立成文感：它虽然明确承认乐曲实际没有第117小节，因此不是虚构音乐事实，但题目本来已经给定止于111–116的14段，文章却虚构了“你指定的第117个节点”。fileciteturn0file4L417-L445
