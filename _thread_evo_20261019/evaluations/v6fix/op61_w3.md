# Op.61｜关系图（A2 整首修补 w3）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他心里有股不肯停的劲，却说不清在等什么，连不安从哪来都辨不明。一点熟悉感牵着他想靠近，却没让他认出方向。
- → 他不想任由事情照旧，怕自己慢慢认下眼前这样，便逼自己撑住，可心里也想停下来喘口气。
- → 真把心力投进去，他又怕会失去别的珍惜之物。
- → 他想找个能说服自己的理由，可每次刚要信，不舍又回来，连确信也留不住，他为非得想透才肯动而难堪。

### S02｜24–65 小节　（正在面对）

- 他想到再等下去，珍惜的东西还会继续受损，便先接下眼前能承担的一份。
- → 他不甘心被失落压垮，接下这一步后有了些力气，也有点骄傲。心里仍犯嘀咕，他手上照样能继续做。
- 他把该承担的事摆在前面，心里仍挂着那些珍惜的东西，知道如今不能像从前那样拥有。
- → 失落一冒头，他就把它压回去，再逼自己聚起力气。可他反复想让自己相信没事，恰好说明他仍很在意。
- → 失落压不下去，他只好一遍遍重新聚力。刚撑起一点，他又担心自己会垮，始终安顿不下来。

### S03｜66–91 小节　（没在想）

- 他还在逼自己撑住，失落、不甘和想停下的念头缠在一起，让他想往前却定不下方向。
- → 他暂时顾不上眼前的难题，心里向往的亲近让他松了口气。
- → 可这会儿的轻松没能改变眼前处境，先前那份要承担的事又回到他心里。

### S04｜92–115 小节　（正在面对）

- 短暂松开后，他记得接下那一步确实让自己重新动起来，所以还愿意坚持。
- 他舍不得抹掉那种亲近带来的温暖。如今得不到同样的安稳，他反而更难受。
- → 他想证明坚持有用，却总发现自己仍想要那种亲近。追问当时还能怎样，也始终换不来安心。
- → 行动确实让他重新动起来，可那种亲近仍没有回来，他开始承认单靠坚持安不下心。

### S05｜116–147 小节　（正在面对）

- 他知道行动还不够，却舍不得放手。那次决定曾把他从犹疑里带出来，他怕失望会辜负当初的认真。
- 他仍向往人与人不必时时防备的亲近，想到它心里会软下来，可眼前的事让他觉得不能停。
- → 他把自己的难受也看成还不够坚定，便压下疲惫，逼自己继续撑。
- → 他把不能软弱当成硬规矩，连疲惫都不准自己承认，最后发现这要求已经变成对自己的苛责。
- → 他停下逼自己，却仍没安心。压住的想念这才浮出来，他承认自己舍不得那种不必防备的生活。

### S06｜148–180 小节　（没在想）

- 催逼停下来后，他认出自己舍不得的是曾真心相信过的生活，不只是眼前一时的轻松。
- 他盼着亲近时不用时时提防，喜欢的东西也不用靠争抢才能留住。
- 他想付出时只是因为喜欢，不必反复证明自己值得被爱和接纳。
- → 他确实尝过这种亲近带来的快乐，才不肯轻易把愿望说成软弱或不切实际。
- → 他知道过去不能原样回来，仍准自己相信那种生活，暂不拿责任衡量它值不值得、能不能成。
- → 他把愿望想得更深，才发现自己还有许多舍不得的地方，心里渐渐满足也渐渐迫切。一时舍不得离开，现实却没因此改变。

### S07｜181–205 小节　（正在面对）

- 刚才的安宁让他想要的亲近一下变得具体，眼前仍缺着它。身体先绷紧，他才重新顾上现实。
- → 他有些懊恼，刚才只顾着沉进满足，竟一时忘了眼前的事还在。
- → 他当初不肯再等，是怕珍惜的东西继续受损。如今只在心里怀念，妨碍它的事还在。
- → 他想重新投入，却怕一味硬撑会耗尽自己想保护的温柔。想到这些代价和当初不肯再等的理由，他反而更难平静。

### S08｜206–213 小节　（没在想）

- 为难时，那种熟悉的柔软又靠近，他认得它曾给过自己满足，舍不得立刻推开。
- → 他忽然想，自己为什么每次一想起它，就非要马上审问自己？
- → 他让自己再停一会儿，终于喘过一口气，也知道这份安静不会久留。

### S09｜214–215 小节　（正在面对）

- 安静退去，熟悉的迟疑又浮上来，刚要站稳的心意随即散开，他仍迈不出步。
- → 他迈不出去，是怕争取又把自己逼得疲惫。那种不必防备的生活又是他真想要的，他舍不得放下。

### S10｜216–225 小节　（正在面对）

- 他已经知道自己舍不得什么，却想不出怎么护住它，也提不起力气立刻去争取。
- → 行动曾让他重新动起来，安宁也让他缓过来。可妨碍那种生活的事还在，单靠哪一样都护不住它。
- → 他还记得当初为什么不能再等，也舍不得那份安宁，知道妨碍它的事仍在。眼下想不出兼顾的办法，他便先不逼自己选边。

### S11｜226–241 小节　（正在面对）

- 选边的压力松了一点，他心里仍没底，但开始重新想眼前还能承担什么。
- → 他知道接下眼前的事确实能让自己动起来，可心里想要的亲近并不会因此消失。
- → 那种安宁确实让他缓过来，但他已经看见妨碍它的事仍在。光想念挡不住它们。
- → 他过去总怪自己不够坚定。如今他发现自己要保住的东西不止一件，硬靠意志也难免伤到其中一边。
- → 想到争取会磨损温柔，他仍心疼，也盼着有条容易些的路。
- → 他想到不动也挡不住那些威胁，还是怕付出代价，却把眼前该承担的事接过来做。

### S12｜242–253 小节　（正在面对）

- 他心里仍没底，却不再等疑虑全消失，带着没算清的代价重新向前，久违的昂扬也回来了。
- → 他愿意尽力，却不再逼每一次付出都得证明事情能被扭转。
- → 他把那种不必防备的生活也算进自己愿意承担的事里，准备为它继续做事。
- → 想到代价，他还是有些发虚，脚下短暂没了把握，却没有撤回决定。

### S13｜254–288 小节　（正在面对）

- 他带着对安宁生活的牵挂重新向前，旧愿不再只把他往回拉，也让他心里生出更开阔的喜悦。
- → 从前一想到争取要付出的代价，他就想缩回去，怕自己把那份温柔磨掉。
- → 他也记得只留在安宁里，妨碍那种生活的事还会继续。他不愿再看着珍惜的东西受损。
- → 他知道再怎么使劲也不保证能过上想要的生活。光是想要它，也不能让每次付出都变得值得。
- → 想起自己曾把疲惫当软弱，他不再把舍不得看成丢脸。妨碍那种生活的事得承担，温柔却不能再被压掉。
- → 想到那种亲近生活，他又尝到最初的快乐。经历过怀疑和疲惫，他这回愿意珍惜它，不把它当成现实一定会好转的保证。
- → 现实还没变，他没有因此把那段安宁当成白费，也没忘记行动曾让自己重新动起来。
- → 他一时缓过气来，却又担心争取会磨损温柔，心里仍有不安。
- → 妨碍那种生活的事还没解决，他仍说不准尽力能改变多少、能留下多少珍贵的东西。往后付出的代价也可能让他动摇。
- → 经历了这些来回，他不再靠把自己逼得更紧证明决心，仍愿承担眼前能做的事，也不必再替这份决定找更多理由。
