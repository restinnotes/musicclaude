# Op61 候选 Center 一览

1. 他为故乡和同胞曾有的骄傲而珍惜他们，可身在异乡、眼见太多失去，连想起那些光荣的时刻也会感到心痛。
2. 他很想和亲近的人彼此信任、彼此照顾，可越需要对方，就越担心自己的脆弱会让两个人都受伤。
3. 他很在乎自己还能挺直腰、靠自己的力量做决定，可身体越来越虚弱，越想表现得坚定，越清楚地感觉到自己有多吃力。
4. 他舍不得那些曾让自己幸福的日子，可每次认真回想，都会更清楚地发现眼前已经不同，记忆越美好，心里反而越疼。
5. 他很想让别人听见自己真正要说的事，可庄严地说会漏掉脆弱，轻轻地说又无法表达内心那股不肯低头的劲，怎么说都像少了一半。
6. 他很想相信自己和别人还有值得期盼的明天，可眼前的悲伤太真实，每当心里重新亮起来，他都害怕那只是自己为了好受而编出的安慰。
7. （行动与做梦）他想站起来，对外面的世界有所行动、守住自己的尊严，却一次次被拉回梦、记忆和自己的内心；他分不清哪一边才是真的自己，也不知道两边能不能同时成立。
