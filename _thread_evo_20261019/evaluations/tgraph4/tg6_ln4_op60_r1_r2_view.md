# Op.60｜关系图

**Center：**亲密的幸福与留不住它的痛楚难以分开

### 1–3　（没在想）

- 想到那个人，他心里惯常绷紧的地方就松了一点。
- 那点松动还不足以让他相信什么。
- 他已经舍不得离开这点轻松。
- 他暂时不急着表现得更好。
- 他也不急着藏起自己的需要。

### 4–16　（没在想）

- 他起初仍不敢明显表现欢喜。
- 他依恋时仍习惯留几分余地。
- 他怕显露需要会成为对方的负担。
- 他渐渐更愿意向那个人敞开。
  - ← 提供理由：（1–3）「藏起自己的需要」
- 他喜欢自己的欢喜有了去处。
- 脆弱时，他不必急着独自承受一切。
- 他不再觉得亲近使自己欠下什么。
- 他可以自然地喜欢、需要和给予。
- 他开始喜欢上曾羞于承认的依恋。
  - ← 改写：（1–3）「舍不得离开」
- ⟲ 仍在起作用：（1–3）「不足以相信」；（1–3）「不急着表现」

### 17–23　（没在想）

- 他开始盼望更多亲近。
  - ← 提供理由：（4–16）「愿意向那个人敞开」
- 他想把尚未说清的感受交给对方。
  - ← 提供理由：（4–16）「欢喜有了去处」
- 他想慢慢熟悉彼此未触及的部分。
- 他仿佛觉得往后还能更好。
- 他从前总怕自己想要太多。
- 如今他为心里有这么多爱意而高兴。
  - ← 改写：（4–16）「自然地喜欢」
- 对未来的期待让眼前的幸福更鲜亮。
- ⟲ 仍在起作用：（4–16）「羞于承认的依恋」

### 24–34　（正在面对）

- 他能毫无保留地享受亲近。
- 对方的亲近使他喜欢敞开着的自己。
  - ← 提供理由：（4–16）「自然地喜欢」
- 他不用时时猜测自己值不值得被爱。
  - ← 提供理由：（4–16）「不必急着独自承受」
- 他仿佛还有无数温柔可以给予。
- 每一次给予都让他觉得更加幸福。
- 有一瞬间，快乐太满反使他舍不得。
- 当时并无缺憾，他的心口却收紧了一下。
- 他开始担心这样的好能否一直持续。
  - ← 动摇：（17–23）「未来的期待」
  - ← 改写：（17–23）「往后还能更好」
- 那念头很快散去，他仍沉浸在满足中。
- 他隐约觉得自己比原先以为的更在乎这份亲密。
- ⟲ 仍在起作用：（17–23）「这么多爱意」

### 35–39　（正在面对）

- 那点不舍还没有完全散去。
- 他想到可能无法长久亲近，就感到难受。
  - ← 唤起：（24–34）「能否一直持续」
  - ← 提供理由：（24–34）「毫无保留」
- 从前不曾拥有，他也不用这样牵挂。
- 他还谈不上害怕，只是格外珍惜。
  - ← 提供理由：（24–34）「更在乎这份亲密」
- 他的温柔带上一点不愿松开的意味。
- ⟲ 仍在起作用：（24–34）「快乐太满」

### 40–50　（正在面对）

- 那份酸楚没有妨碍他安心亲近。
  - ← 限制：（35–39）「无法长久亲近」
- 真切得到的温暖使他不怀疑眼前的幸福。
- 他不用反复确认亲近，也不用说尽心意。
  - ← 提供理由：（4–16）「欠下什么」
- 他依然感到被对方放在心上。
- 这比频繁的热烈回应更令他舒服。
- 他也舍不得亲近中那个不必防备的自己。
- 有时一切很好，他心里仍会轻轻疼一下。
- ⟲ 仍在起作用：（1–3）「松了一点」；（24–34）「敞开着的自己」；（35–39）「没有完全散去」

### 51–61　（正在面对）

- 这份自在使他更想亲近得深些。
  - ← 提供理由：（40–50）「更令他舒服」
- 他已不满足于只是感到被爱。
- 他想让对方领受自己最难表达的情意。
- 他想把更多爱意给出去。
- 他也想完整地接住对方的温柔。
- 他因心里还有没交出去的爱而着急。
- 对失去的担忧反而使他想更尽情地爱。
  - ← 改写：（35–39）「无法长久亲近」
- 他不愿因未来可能难受而在眼下少爱。
- 平常那些迟疑暂时显得很小。
- ⟲ 仍在起作用：（17–23）「尚未说清的感受」；（24–34）「无数温柔」；（35–39）「不愿松开」

### 62–71　（还说不清）

- 更深的亲近确实给了他想要的快乐。
  - ← 提供理由：（51–61）「亲近得深些」
  - ← 提供理由：（51–61）「完整地接住」
- 有一阵，他几乎顾不上别的。
- 他觉得自己从未这么满足过。
- 那股欢喜稍平缓，他心里却空落了一块。
  - ← 限制：（51–61）「眼下少爱」
- 他不愿承认自己得了这么多还觉得不够。
  - ← 改写：（51–61）「只是感到被爱」
- 他为不满足感到委屈。
- 他又羞愧，仿佛辜负了这份幸福。
- 他仍相信刚才的亲密真切。
- 他尝过深深的满足，反而更难忍受它无法持续。　✦ 满足照出未满足
- 幸福之外，他仍有一股说不清的渴。
- ⟲ 仍在起作用：（24–34）「能否一直持续」

### 72–77　（正在面对）

- 那股说不清的渴开始让他难受。
- 他似乎已不再想靠更多温柔或亲近消除不安。
  - ← 唤起：（62–71）「还觉得不够」
- 他想在幸福时不必想到它终究会过去。　✦ 分清
  - ← 提供理由：（62–71）「更难忍受」
- 他明白对方多爱他也留不住幸福时刻。　✦ 办法的限度
  - ← 限制：（51–61）「更尽情地爱」
- 他知道仅凭自己的在乎留不住最好的时候。
- 想到这里，他有些无措。
- 他没有理由责怪谁。
- 那股舍不得比先前更清晰。
  - ← 改写：（24–34）「能否一直持续」
- ⟲ 仍在起作用：（62–71）「说不清的渴」；（35–39）「无法长久亲近」

### 78–83　（正在面对）

- 他因这份无措而格外心疼对方。
  - ← 唤起：（72–77）「有些无措」
- 他不愿让对方承受自己全部的不安。
  - ← 提供理由：（72–77）「对方多爱他」
- 他喜欢对方有自己的心意。
- 他舍不得把依恋变成束缚。
  - ← 提供理由：（40–50）「不用反复确认」
- 他仍觉得亲近甜美，心里却也有酸楚。
- 他也喜欢自己能够这样爱人。
- 他甚至不知道这份疼惜该落向哪里。
  - ← 唤起：（72–77）「仅凭自己的在乎」
- ⟲ 仍在起作用：（4–16）「欠下什么」；（72–77）「比先前更清晰」

### 84–92　（没在想）

- 再次沉浸在亲近里，他又满心欢喜。
- 难受并没减弱他对幸福的向往。
- 他如今知道这个人确实能使自己这样快乐。
  - ← 提供理由：（62–71）「从未这么满足」
- 先前的疼惜仍在他心里。
- 他更想把自己整个交给对方。
  - ← 提供理由：（78–83）「这样爱人」
- 他连最易受伤的地方也不愿再藏。
  - ← 改写：（78–83）「全部的不安」
- ⟲ 仍在起作用：（62–71）「想要的快乐」；（78–83）「格外心疼对方」

### 93–102　（还说不清）

- 从前的顾虑一时抵不过亲近的快乐。
  - ← 失效：（17–23）「想要太多」
  - ← 失效：（62–71）「仿佛辜负」
- 他惊讶于自己竟喜欢得这么深。
- 平日难以放下的计较也轻了许多。
- 他恨不得把爱意全部给出去。
- 他也恨不得接住对方全部的温柔。
- 尽情相爱时，他却更舍不得。
- 那点不安让眼前的幸福显得更珍贵。
- 他几乎分不清胸口的热是快乐还是怕失去。
- 这份近乎疼痛的欢喜仍让他不愿退开。
  - ← 提供理由：（84–92）「又满心欢喜」
- ⟲ 仍在起作用：（84–92）「整个交给对方」；（51–61）「完整地接住」；（72–77）「比先前更清晰」；（72–77）「仅凭自己的在乎」

### 103–110　（正在面对）

- 他仍盼望幸福继续加深。
- 他已经觉得这份幸福深得有些承受不住。
  - ← 说明：（93–102）「不愿退开」
- 他如今格外舍不得自己能这样全心爱人。
- 他清楚地感到，再丰盛的爱也留不住美好时刻。　✦ 知道更多反而更尖锐
- 他无法轻轻带过失去它的可能。
  - ← 唤起：（93–102）「几乎分不清」
- 那份痛楚也没使幸福变得虚假。
  - ← 提供理由：（84–92）「确实能使自己这样快乐」
- 他无法希望欢喜或不舍中的任何一种消失。
  - ← 说明：（93–102）「几乎分不清」
- 他舍不得的恰是使自己这样快乐的东西。
  - ← 提供理由：（93–102）「更珍贵」
- ⟲ 仍在起作用：（78–83）「这样爱人」；（72–77）「对方多爱他」

### 111–116　（正在面对）

- 那股强烈的情绪渐渐平缓。
- 他的依恋并未因此减轻。
- 他仍会在最温柔时感到一点疼。
- 他再无法像最初那样只因想到对方就轻松。
  - ← 改写：（1–3）「松了一点」
- 真切得过的快乐使他无法后悔敞开。
  - ← 提供理由：（103–110）「没使幸福变得虚假」
- 他不愿少爱一点来减少牵挂。　✦ 选择的代价
  - ← 提供理由：（103–110）「使自己这样快乐」
- 他不愿因终究留不住而轻看眼前的幸福。
  - ← 限制：（103–110）「留不住美好时刻」
- 他甚至比先前更喜欢对方。
- 哪怕好时刻不能停留，他仍想完整地爱着。
  - ← 提供理由：（103–110）「任何一种消失」
- ⟲ 仍在起作用：（93–102）「不愿退开」；（51–61）「眼下少爱」；（103–110）「全心爱人」；（103–110）「继续加深」
