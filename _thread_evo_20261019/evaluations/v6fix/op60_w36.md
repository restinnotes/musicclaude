# Op.60｜关系图（在 v6 上修补，w36）

**Center：**对亲密的投入与自我克制始终相互牵制。

### S01｜1–3 小节　（还说不清）

- 他一想到这个人就柔软起来，很想亲近，也被这份突然到来的心意吓了一下。
- → 他觉得这份喜欢轻得随时可以放下，却偏偏舍不得。
- → 他怕说出心意会改变关系，眼下不用决定去向，便想让喜欢多留一会儿，靠近时收住一点。

### S02｜4–16 小节　（没在想）

- 他让眼前的亲近自然发生，不再揣摩对方反应，也不索要回应，便能自在关心对方，也喜欢自己不计较。
- → 他那时真觉得，只要能这样亲近下去，眼下已经够了。
- 他不敢认定这样的亲近会一直有，便只盼眼下这一刻慢些过去。
- 他一度很想把心意多给一点，热切了一阵，想到还得顾着分寸，便又收了回来。
- 他决定先不替这份喜欢安排去向，觉得两个人以后怎样，等以后再说就好。
  - ← 改写：（1–3）「改变关系」

### S03｜17–23 小节　（正在面对）

- 他已从眼前的亲近里得到满足，暂时不再惦记还要什么，心思便不必总围着对方转。
  - ← 提供理由：（4–16）「眼下已经够了」
- → 他仍盼这份亲近长久，原先不必多想的安稳因此松动。
- → 想到长久，他才发现自己能决定怎样珍惜对方，却不能决定对方是否也珍惜自己。
- → 他从前觉得自己在对方心里是否特别无需确认，如今却偶尔在意，不打算求证，亲近也因此被绊住，没法完全走神。
- ⟲ 仍在起作用：（4–16）「不敢认定」

### S04｜24–34 小节　（正在面对）

- 他知道，对方也没答应过他什么。
  - ← 说明：（17–23）「不能决定」
- → 他把心思转去替对方高兴，觉得真心盼对方好，自己也会开心。
- → 他暂时不太担心自己是否特别，觉得还有许多心意可以给，也不怕显得比对方更在乎，便放开些去喜欢。
  - ← 动摇：（17–23）「无需确认」
- → 他越放开些去喜欢，越舍不得这一刻过去，热切时又怕成了催促，只好收住一点。
- → 他甚至把这阵轻松当成保证，以为自己能尽情喜欢，也不会失去眼前的亲近。

### S05｜35–39 小节　（还说不清）

- 他发现自己尽情喜欢时的快乐，终究说明不了对方是否也珍惜这份亲近。
  - ← 动摇：（24–34）「当成保证」
- → 他难堪地想，或许盼着被珍惜，说不求回报是在骗自己，可那时关心对方、享受亲近，确实没想过换回什么。
- → 他不急着替自己辩白或用热情盖住难堪，想把亲近留住的劲头便松了些。

### S06｜40–50 小节　（没在想）

- 他不愿因自己也盼回应就否定这份喜欢，仍愿意真心关心对方，也不再假装什么都不求。
  - ← 提供理由：（35–39）「盼着被珍惜」
- → 他关心对方时把喜欢留在心里独自珍藏，不急着求回应，便暂时忘了为何还盼回应，过会儿那份期待又回来。
- → 他发现，再多对对方好，也不能证明自己什么都不求，偏偏他想被珍惜又不愿开口索取。
- ⟲ 仍在起作用：（17–23）「无需确认」

### S07｜51–61 小节　（正在面对）

- 他尝过关心对方时那份细细的甜，便越来越常惦念对方，喜欢也渐渐收不住，舍不得把它减轻。
- → 他不愿开口索取亲近，便回想两人相处时的亲近，也想象彼此身体上更亲密的情形，独自得到欢愉。
  - ← 提供理由：（40–50）「不愿开口索取」
- → 眼前的亲近明明还好，他不想让期待牵着自己走，便想把喜欢留在心里。
- → 他渐渐盼对方懂他的关心，却相信不该催对方，越不愿给对方添负担，越只能自己消化没有着落的盼望。
- 他不再以为只凭自己的热情就能留住眼前的亲近，便不再盼这一刻停下来。
- ⟲ 仍在起作用：（35–39）「盖住难堪」

### S08｜62–71 小节　（没在想）

- 他记得亲近时的安心、不计较地关心对方的满足和独自珍藏喜欢的甜意，虽没许诺却都是真的。
- → 他记得亲近时的安心和独自珍藏的快乐都是真的，便不再因怕受伤压住欢喜，连玩心也冒出来。
- → 他放开欢喜后，给得多了也不再一笔笔算，一时顾不上那份沉重，也不急着替未来留退路。
- → 他又盼对方也珍惜自己，却知道眼前的亲近证明不了对方的心意，便重新在意起来。
- 他曾把喜欢独自珍藏，想到这一刻终究留不住，便也想把这份欢喜留在心里。
  - ← 提供理由：（40–50）「独自珍藏」
- ⟲ 仍在起作用：（40–50）「不愿开口索取」

### S09｜72–77 小节　（正在面对）

- 他也盼对方想靠近、把彼此放在心上，却知道喜欢再深也不能觉得对方该回应，怕盼得太紧会催到对方。
- → 他一再想收回盼望，却觉得这样是在否认刚承认的心意，委屈之余也厌烦自己反复为难。
- 他不肯因对方心意未明就轻看这段亲近，因为他确实从相处中得到过安心和满足。
  - ← 提供理由：（62–71）「独自珍藏」
- ⟲ 仍在起作用：（62–71）「证明不了」

### S10｜78–83 小节　（正在面对）

- 他不再逼自己立刻理清感情或下结论，温柔又自然地留在心里，心里轻松了些。
  - ← 改写：（72–77）「反复为难」
- → 他不把对方温柔当成更进一步的信号，也不拿回应衡量关心，仍能照常关心。
  - ← 提供理由：（72–77）「盼得太紧」
- → 他承认想被珍惜不等于催对方回应，不再压住委屈和渴望。

### S11｜84–92 小节　（正在面对）

- 他盼被珍惜却无从确认，曾紧张难堪，仍真心关心，不再拿无所求证明体贴。
  - ← 提供理由：（78–83）「想被珍惜」
- → 他知道深情不能替对方作决定，也可能伤己，仍愿意喜欢。
- → 没有新保证，他也不疑真心，久疑后仍能高兴，竟被自己打动。
- ⟲ 仍在起作用：（72–77）「盼得太紧」

### S12｜93–102 小节　（没在想）

- 他不再为想被珍惜自责，便想把积攒的关心给对方，也想看看两人能过上怎样的日子。
  - ← 提供理由：（84–92）「深情不能替」
- → 他觉得许多真情都值得珍惜，便想靠近、想被爱，也想把心全交给对方，仿佛已拥有所求，满足得招架不住。
- → 他连日后与相爱无关的琐事和难处也愿和对方一起操心，因为他想过的是两个人的日子。
- → 他仍盼对方愿与他过日子，曾为此紧张难堪，暂时顾不上未来和未获回应，只想让已充分展开的幸福完整停留。
- ⟲ 仍在起作用：（72–77）「盼得太紧」

### S13｜103–110 小节　（正在面对）

- 他真想和对方共享幸福，也记得尽情投入的快乐，却知道对方未必同样珍惜这份亲近，自己仍可能失望。
  - ← 提供理由：（93–102）「未获回应」
- 他越珍惜此刻的幸福，越知道它不能永远留住，心里便有了失落。
- 他把喜欢收在心里确实安心些，却发现想被珍惜的愿望并没有因此消失。
- → 他不想把所有不安都交给对方解决，也不愿因怕落空就故意把喜欢压淡。
- → 他不愿为了暂时轻松就只把喜欢收在心里，也舍不得收回曾让自己幸福的投入。
- → 他舍不得否认自己想被珍惜，又不愿逼对方回应，心里便越来越难受。
- → 他宁可继续不舒服，也不愿假装自己不想被珍惜，换来一时平静。
- ⟲ 仍在起作用：（62–71）「终究留不住」

### S14｜111–116 小节　（正在面对）

- 他不再盘算该收住还是放开，也不靠克制证明清醒，因为两种做法都不能保证不受伤。
  - ← 改写：（103–110）「不愿假装不想」
- 他仍想被爱、想要更多，却不要求对方接住全部期待，怕眼前的亲近因此失去自在。
  - ← 说明：（103–110）「越来越难受」
- 他记得小心靠近、慷慨付出、独自珍藏的快乐，明知会疼仍愿继续认真喜欢、尽情欢喜，不先退开。
- → 对方会不会选择他仍无答案，他却更知对方重要，不拿结果判真心，因为快乐和在意都是真的。
- → 他接受遗憾留在心里，也仍愿喜欢，等不到对方主动靠近会疼，却不否认感情或催回应。
- → 他发现若总等对方主动靠近，日子便只剩猜测，不能再把喜欢全押在这个答案上。
