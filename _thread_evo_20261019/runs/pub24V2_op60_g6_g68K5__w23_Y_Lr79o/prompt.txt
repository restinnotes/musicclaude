感受：原先清澈的歌声底下越来越不安分，密集的音符和沉重的脉搏把压着的渴望往前推；安静地享受已经不够，连对生命的眷恋也一齐翻涌上来 / 回想一段关系时，气味、身体感觉、幻想、遗憾和快感混在一起；越舒服越失去方向，明知自己正在被卷进去，却暂时不想出来 / 什么都还很好，美也没有消失，可已经听见时间正在经过；再完美的一刻，也没有办法让它停住
话：他真盼着，往后对方【想找人陪时还会想到自己】，自己也能【一直陪在身边】。

### S08（屏幕停留 39 秒）
话：上回无意间露了心意，这回见对方依然亲近，他想主动些，【大大方方地回应】；往后的日子也开始让他期待，觉得两个人说不定还能【这么好很久】。
感受：歌句越唱越开，直接而舒展，没有防卫，也不再分析，像只想把心意痛快地唱出来 / 明亮、轻盈、透气，像重新碰到阳光和风，身体也恢复了弹性，带一点玩心和调情般的回应
话：可眼下两个人都愿意亲近，【以后未必还会这样】，他【心里没底】。
感受：歌声没有踏实落定，反而向上散开、蒸发；正以为它还会继续唱下去，却忽然停住，只剩快乐的余温和一点怀念（到时出现）

### S09（屏幕停留 32 秒）
话：那点没底越来越具体：要是哪天对方【不再需要他陪】，连和他待着都不自在了呢？他一下安静下来，刚才还敢盼那么远，现在却【不敢再往下想】。
感受：前面几乎要冲出去的势头突然收住，像话到要紧处一下顿住；第76–77小节的颤音和轻柔和弦悬在半空，强烈的渴望还在，却引而不发（到时出现） / 像忽然陷进低气压里：明朗被收走，声音一层层下沉、变暗；光还在，只是隔着一层薄雾 / 像听着自己刚才说过的话的余响，停下来问：“刚才那是真的吗？接下来怎么办？”又像激动地说了很多话后抬头看夜空，忽然觉得眼前的美好比自己的愿望更大；不安还没有答案，却暂时不再占满心思
话：可他想起对方【一直没退开】，两人眼下还亲近，这些都是真的；也许对方【也喜欢他在身边】，他又有点高兴。

### S10（屏幕停留 27 秒）
话：他想着，再猜下去连今天也过不踏实，便暂时不管往后怎样，先【好好享受眼前的亲近】。绷紧的肩膀终于松开，胸腔一下打开，心里亮堂得几乎【想笑，也有点想哭】。
感受：水波像被一阵清风拨开，时间也松了，旋律开出一小块空地；只是一口终于呼出的气，不是能永远躲进去的避风处 / 身体仿佛失去了重量，像灵魂从躯壳里飘出来，悬浮在夏夜微风中，暂时碰不到原先压在身上的沉重 / 高音区细亮的小音符，像晨曦里的银色蛛丝，又像从天上飘下的细雨，几乎没有重量 / 一串琶音又像飞瀑从极高处倾泻而下，清亮地落进水里（到时出现）

### S11（屏幕停留 37 秒）
话：轻松过后，他忽然想到：自己需要对方，【对方有时也需要他】；就算对方不需要，他仍愿意陪着，【不再藏着喜欢】。
感受：第84小节，同一首歌忽然变得直接而现实；厚重的和弦托起歌声，温柔的水波翻成横跨几个八度的惊涛骇浪，像终于能直说：“这是我的感情，我不再为它道歉。”
话：这个念头让他高兴得连害臊都【顾不上】，觉得自己这么在乎对方也【没什么不好】。
话：可对方以后还愿不愿意让他陪在身边，【不是他能说了算】的；想到两人未必总能这样亲近，欢喜就压得他【心口发疼】。
感受：第92小节附近，刚才铺开的力量短暂悬在半空，像在等待下一股更大的浪潮；若想起第32小节那次未能真正落定的高潮，这里又像终于得到了某种满足，但还不是结束（到时出现） / 像夕阳沉下地平线前的一两分钟，天空烧得血红金亮，刺眼得让人想流泪；胸口非但没有舒展开来，反而被压得发痛 / 像多年后重新走进一间旧房子，家具也许没变，可经历过太多之后，原来的温柔再次出现，已经有了新的重量

### S12（屏幕停留 38 秒）
话：他顾不上对方是否也在乎自己，只想【把能给的都给对方】，让对方安心。可他明知再用心也没法保证以后还这么好，还是嫌相处的日子不够，【想多陪对方一会儿】。
感受：那支温柔晴朗的歌被放大到近乎英雄式，声音明亮、开阔，内声部却彼此拉扯；像整个人被卷进一个比自己更大的世界，连“我”都暂时退到了后面 / 这份狂喜像高烧，也像久别重逢：从微笑寒暄忽然变成紧紧抱住对方，久久不愿松手，快乐得连自己想笑还是想哭都分不清 / 原本温柔的歌带上近乎恳求的力量，一次次向上伸展，像还想要更多；96–100小节附近仍有牵扯、延迟和紧张，那口气一直悬到102–103小节交界，才得到一次重大的释放（到时出现）
话：那阵【高兴终于整个涌了出来】，他不再强迫自己收着，只顾【痛痛快快地喜欢对方】。

### S13（屏幕停留 39 秒）
话：高兴过后，他更想听对方说【以后也不变】；可越喜欢跟对方待着，越觉得时间过得快，【真能一直这样吗】？
感受：第103小节像终于把长久悬着的心愿说出口，音乐却没有就此收住，反而反复、渐强地往前推；106小节以后越绷越紧，像刚抵达一道浪峰，又被更大的一浪推向前（到时出现） / 起初还在坚持、确认那份灿烂，到107小节以后，明亮里渐渐掺进尖锐、暗沉的成分；幸福没有消失，悲伤却进入了幸福里面，真正得到珍贵的东西也会因为无法永远留住而疼（到时出现）
话：他如今更怕对方哪天不再需要他，连这样待着都没了；【少露些心意，会不会少疼些】？可他早不像最初那样能装作不在乎了，刚才想对对方好也是真心的，真要【往回藏，自己反倒更难受】。
感受：像刚刚最坚定地说了一声“是”，心里马上又有个声音追问：“可是呢？”这个疑问并没有证明先前的幸福是假的 / 下方的脚步牢牢踩住地面，不肯移动；上方的声音却一次次往下落，像叹息，又像有什么反复纠缠，胸口一沉再沉

### S14（屏幕停留 34 秒）
话：最初他连喜欢都不敢多露，如今两人还亲近，心里【又甜又酸】，【却不后悔】。他还是会舍不得，也不知道以后怎样，却不想再逼自己讨一句永远不变的保证。
感受：最后一股浪头像是又猛推了一下，进入终结句才真正松下来、轻下来；心里仍然温热，身体却慢慢恢复平静，像从一场美梦里醒来，还记得梦里的光（到时出现） / 第113小节左手内声部幽幽唱出一句，像男中音独自沉思；熟悉的歌声与摇荡仿佛又回来了一次，到115小节，右手细碎的琶音像水花溅落夜空（到时出现） / 尾声像隔着很远回应开头悬着的话；最后向上抬起的和弦，仿佛终于把那句话接住、说完（到时出现） / 第116小节最后几下和弦干脆而沉重，低音像铁锚落入水底，把还在摇荡的小船一下定住；也像经历强烈震荡后站起来，整理衣服，关上门（到时出现）
话：既然喜欢已经让对方看见，他就【不往回藏】了；往后会怎样，【等真的到了那时再说】。
