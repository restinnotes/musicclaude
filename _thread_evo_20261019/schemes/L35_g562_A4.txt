你要为一首钢琴曲写最终使用的 Thread（线）。

这一次最重要的任务是：先写完整条经历，再将已经完成的叙述分配到音乐段落。段落分配过程中不得重新创作心理内容。

【段落】
{SECTIONS}

【Center（已经给定，不得修改）】
{CENTER}

【已经通过 A2 的人物经历候选】
{ROUTES}

【从珠子提炼出的体验性质（TARGETS）】
{TARGETS}

你看不到原始珠子，也不得猜测珠子的具体画面或措辞。

【第一步：选择路线】
从 ROUTES 中选择一条完整叙述最自然、因果最可靠、时间框架最稳定的路线。

不要因为某条路线每段内容较多就认为它更好。优先选择能够不依靠段落填充而独立成立的经历。

【第二步：写完整条线】
在内部暂时不看段落编号，也不看 TARGETS。

先根据所选路线写出一条从头到尾连续的完整叙述。它应当像一个普通人在讲述自己经历的一件事。

这一版叙述必须先独立成立，不能依靠音乐段落的存在才显得有变化。

写作时：
1. 保留人物真实的所求、顾虑、犹豫、感受和实际变化。
2. 只有真正发生的新认识、新选择、新后果，才写成新的心理变化。
3. 已经成立的认识后面直接承受后果，不重新宣布。
4. 一件事可以持续很久，不必每隔一段出现一个新的心理动作。
5. 可以写不同时间里的身体体验、注意力、沉浸、感受质地和已经存在的心思。
6. 不允许为了显得丰富，把同一个问题拆成多个问题。
7. 不允许为了显得有进展，把情绪增强写成新的认识。

【第三步：冻结叙述，映射段落】
完整叙述写完并通过检查以后，视为已经冻结。

现在才查看 {SECTIONS}，把已经存在的句子分配到相应段落。

映射时不得新增句子来满足某一段的情绪要求。不得为了补足某一段而制造新认识、新决定或新问题。

每段必须有条目，但条目可以是完整叙述中已有的体验、后果和延续。没有新心理变化的段落，只需呈现人物带着前面的事情继续经历这一刻。

一条叙述可以在连续的音乐时间中自然延续，但不同段落不能把同一个命题重复写一遍。应当根据已经完成的经历选择这一段真正值得呈现的内容。

每段默认一条。只有完整叙述中确实有两个不同且都值得呈现的内容，才分成两条。不要为了段落均匀而增加条目。

映射完成后，把所有 items 按原顺序重新连续读一遍。它们必须仍然是第一步那条完整叙述，不能因为分段而变成一组彼此独立的心理结论。

【第四步：TARGETS】
现在才检查 TARGETS。

TARGETS 只帮助判断已有叙述在各段的体验质地是否自然，不是新内容来源。

不得为了覆盖某个体验性质而修改已经冻结的叙述，尤其不能增加新的心理问题或决定。

如果 TARGETS 可以由当前经历自然承载，就在 covers 中填写对应 bead_id。
如果无法自然承载，可以放入 uncovered_targets。珠子仍然可以在屏幕稿中独立呈现，不需要全部转化为线的内容。

【第五步：人物经历约束】
不新增外部事件、前史、对白、物件、第三人、地点或场景。
不新增对方的动作，不推断对方没有依据的隐秘心事。
允许一个从头到尾不变的轻处境和小动作。
所有变化必须来自已有经历和实际后果。

用普通人的语言讲述，不写心理分析、人生道理、格言或抽象总结。不要让每句话都解释人物为什么这样想。

【第六步：最终检查】
1. 不看段落编号，完整叙述是否独立成立？
2. 分配段落以后，是否仍然能连续读成原来那条经历？
3. 是否在段落映射阶段偷偷增加了新心理事实？
4. 是否有一个命题在不同段落重新成立？
5. 是否为了让每段内容不同而制造了虚假的心理变化？
6. 是否保留了人物具体的所求、顾虑和感受？
7. 是否有外部加戏？

发现问题时，先回到完整叙述修正，不能只在某一个段落局部补一句。

【输出格式】
只输出 JSON，保持以下结构，不增加字段：
{
  "status": "complete",
  "base_route": "route_id",
  "segments": [
    {
      "sec": "S01",
      "relation": "没在想/还说不清/正在面对",
      "items": [
        {
          "id": "S01-1",
          "text": "...",
          "cite": [],
          "covers": ["bead_id"]
        }
      ]
    }
  ],
  "uncovered_targets": [],
  "blocked_sections": []
}

所有段落严格按 {SECTIONS} 原顺序出现。每段至少一条。不得输出 blocked，不得空段。blocked_sections 固定为空数组，status 固定为 complete。

cite 只在直接依赖前面某条内容时填写编号。covers 只填写实际覆盖的 bead_id。relation 只作元数据，不写进正文。
