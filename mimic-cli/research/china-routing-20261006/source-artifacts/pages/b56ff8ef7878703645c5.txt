12、搜索商品
三、搜索商品
1.接口描述
根据搜索条件查询符合要求的商品列表。
2.URL
https://api-iop.jd.com/api/search/search
3.参数格式
访问方式："Content-Type", "application/x-www-form-urlencoded"
4.HTTPS请求方式
POST
5.请求参数
参数名称
类型
是否必填
描述
token
String
是
授权时获取的access token
keyword
String
否
搜索关键字，需要编码
catId
String
否
分类Id,只支持三级类目Id
pageIndex
Integer
否
当前第几页
pageSize
Integer
否
当前页显示
min
String
否
价格区间搜索，低价
max
String
否
价格区间搜索，高价
brands
String
否
品牌搜索 多个品牌以逗号分隔，需要编码
cid1
String
否
一级分类
cid2
String
否
二级分类
sortType
String
否
销量降序="sale_desc";价格升序="price_asc";价格降序="price_desc";上架时间降序="winsdate_desc";按销量排序_15天销售额="sort_totalsales15_desc";按15日销量排序="sort_days_15_qtty_desc";按30日销量排序="sort_days_30_qtty_desc";按15日销售额排序="sort_days_15_gmv_desc";按30日销售额排序="sort_days_30_gmv_desc";
priceCol
String
否
价格汇总 priceCol=”yes”
extAttrCol
String
否
扩展属性汇总extAttrCol=”yes”
mergeSku
boolean
否
true:合并同一产品不同规格sku;false:不合并同一产品不同规格sku
6.请求示例
以Post形式提交
1.关键字搜索
url : https://api-iop.jd.com/api/search/search?token=xxx&keyword=iphone
\2. 分类Id搜索
url : https://api-iop.jd.com/api/search/search?token=xxx&catId=898873
\3. 品牌搜索
url : https://api-iop.jd.com/api/search/search?token=xxx&brands=华为,苹果
4.带价格的组合搜索(价格区间，低价和高价为必须)
url:
https://api-iop.jd.com/api/search/search?token=xxx&catId=898873&keyword= iphone&min=0&max=10000
5．带库存有货
https://api-iop.jd.com/api/search/search?token=PFVCtR72Ao2ZqLuJnA7xPlXSY&keyword=鼠标&pageIndex=1&pageSize=100&brands=小米&areaIds=1,2810,51081&redisStore=true&catId=693
