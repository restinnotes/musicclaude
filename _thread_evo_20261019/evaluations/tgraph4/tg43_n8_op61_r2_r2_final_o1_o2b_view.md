# Op.61｜关系图

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### 1–23　（还说不清）

- 起初他连自己在等什么都说不清，只知道心里有股劲，不肯就此算了。
- → 任由事情照旧，仿佛就是承认它们本该如此；真投进去，又怕会丢下什么。
- → 他于是寻找一个够有力的理由，盼着自己终于不再犹豫。
- → 每次快信自己想通了，舍不得又冒出来，确信也变陌生；他开始难堪：非得理清一切才肯走吗？

### 24–65　（正在面对）

- “还没想清楚”再也不能成为等下去的理由，他先认下自己能做的那一份。
  - ← 改写：（1–23）「每次快信自己想通了，」
- → 没有保证，牵挂也没消失；可一行动，他便感到有力量。从前总问值不值，如今只说愿尽力。
- → 这让他有些骄傲：心里仍有疑虑，也可以不让疑虑替自己做主。
- → 越投入越热切，付出的过程本身就让他快乐，仿佛心里的不满终于有了去处。
- → 他愿意给得更多，也贪恋倾尽全力的畅快，不再时时审视自己或为一点软弱停步。
- → 可用力深处，仍有一小块心没跟着高昂；它没拦住他，却提醒他还有牵挂未被照顾。　✦ 满足照出未满足

### 66–91　（没在想）

- 认真投入过一回，他反倒从反复自问里松开些，也发现自己会因不再畏缩而高兴。
  - ← 提供理由：（24–65）「越投入越热切，付出的」
- → 向前的热情让他轻盈；偶尔忘了为何用力不算背叛，他便顺着自由走了一程，也没急着解释它。
- → 快乐渐渐淡下去，先前那个决定又回到眼前，等着他重新面对。

### 92–115　（正在面对）

- 他仍愿坚持那个决定：它确实把自己从动弹不得的犹豫里带了出来。
  - ← 唤起：（66–91）「快乐渐渐淡下去，先前」
  - ← 提供理由：（24–65）「“还没想清楚”再也不」
- → 那阵轻快也是真的；心里尚有缺口，不等于先前一切都错。
- → 可曾让他昂起头的坚定，如今安不了心；越想确认自己有力量，越听见心底另一个要求。
- → 他只能承认这个不情愿的答案：行动值得，却仍然不够。　✦ 满足照出未满足

### 116–147　（正在面对）

- 行动明明还不够，他却舍不得撒手：它曾救他脱离犹疑；怕失望说明变心，他便逼得更紧。
  - ← 提供理由：（92–115）「他仍愿坚持那个决定：」
- → 明知自己在受苦，他仍把难处当成该克服的迟疑；想停一下，又怕辜负最初的决意。
- → 那份曾让他昂然的要求，渐渐连脆弱也容不下，终于变成苛责。　✦ 办法的限度
- → 越想显得坚定，他越像在逼一个疲惫的人硬撑；终于不想再证明自己有多坚强。
- → 放下催逼并没立刻让他安心，却给一直压住的依恋留了空隙。
- → 他有些茫然，也松懈下来，终于承认：除了该做的事，还有真心舍不得的东西。

### 148–180　（没在想）

- 催逼一停，那份依恋才显出原样：他想要的是曾真心相信过的一种生活。
  - ← 说明：（116–147）「他有些茫然，也松懈下」
- → 他盼着人与人不必时时防备，珍贵的东西也不必靠争夺才能留下。
- → 他盼着不必反复证明自己值得被爱、被接纳；付出可以只因喜欢，靠近也不必先做好受伤的准备。
- → 这样的相信曾给过他快乐，让他觉得人与生活可以亲近，不必时时用力维系。
- → 那些感受确实发生过，所以他无法把这份盼望贬成不切实际的软弱。
- → 这回他让爱惜本身留下，不拿责任盘问，也不急着证明它有用或追问能否实现、孰轻孰重。
- → 只是准许自己去爱、去相信，满足便涌上来；那个只会使劲向前的人仿佛又柔软了。
- → 这份安宁是真的，他几乎忘了先前的疲惫，一时也不想离开。

### 181–205　（正在面对）

- 安宁太真实，他渐渐不满足于只在心里拥有；这份满足反而照见心愿还没实现。　✦ 满足照出未满足
  - ← 提供理由：（148–180）「这份安宁是真的，他几」
- → 既然那种生活值得珍惜，使它难以存在的事情，怎能只靠怀念改变？
- → 他想起当初不肯再等，正是不愿看着重要的东西继续受损。
- → 他懊恼地问自己：怎么才刚沉进满足，就忘了还有事要面对？
- → 他试着重新振作，却发现自己已无法像从前那样毫无顾忌地投入。
- → 如今越懂温柔可贵，他越怕争取会耗尽它，最后只剩意志，失去一切值得争取的心。
- → 向前怕温柔被耗尽，留下又放不下它正受威胁。
- → 他曾以为理由足够坚定便不再为难；如今理由更多，心反而更难平静。　✦ 知道更多反而更尖锐
- ⟲ 仍在起作用：（1–23）「任由事情照旧，仿佛就」

### 206–213　（没在想）

- 为难时，那份温柔又短暂地靠近；他明知不能久留，却舍不得立刻推开。
- → 既然它真给过自己那么深的满足，何必每次想起都立刻拿来审问自己？
  - ← 提供理由：（148–180）「这份安宁是真的，他几」
- → 他愿再爱惜片刻，暂不去想没答案的事；这点安静仍让他欢喜，只是欢喜里已有不舍。

### 214–215　（正在面对）

- 安静退去，熟悉的迟疑又回来，仿佛走了很远，最后仍回到原处。
  - ← 唤起：（206–213）「他愿再爱惜片刻，暂不」
- → 但他已知道自己放不下什么：迟疑里有怯懦，也有不愿失去的生活希望。　✦ 分清
  - ← 改写：（148–180）「催逼一停，那份依恋才」

### 216–225　（正在面对）

- 看清自己舍不得什么，并没让他立刻勇敢起来。
  - ← 限制：（214–215）「但他已知道自己放不下」
- → 他已不能只凭最初的决心向前，也无法安心沉浸旧愿；两条路都帮过他，也各有难处。　✦ 办法的限度
  - ← 说明：（92–115）「他仍愿坚持那个决定：」
- → 他暂时没力气要求自己大变，只盼若还要争取就记得缘由，若珍惜安宁也别放下威胁它的事。
- → 他还不知道怎么做到，只一遍遍想着这点微弱的愿望。
- → 想得久了，那种非得舍弃一边才能继续的逼迫，似乎松开了一点。

### 226–241　（正在面对）

- 凭着这点还不牢靠的心意，他重新琢磨自己还能怎么做。
  - ← 提供理由：（216–225）「想得久了，那种非得舍」
- → 他亲身体会过，尽力承担能让人从无力中重新动起来，却消不掉所有牵挂。　✦ 办法的限度
  - ← 说明：（24–65）「没有保证，牵挂也没消」
- → 心里的美好生活也能安慰他，却不能只靠安慰护住真正珍惜的东西。　✦ 办法的限度
  - ← 限制：（148–180）「这份安宁是真的，他几」
- → 两样收获都是真的，他不愿简单否定任何一个；可要它们毫发无伤地并存，恐怕不可能。
- → 他想留住不用时时奋力的安宁，可为它争取也可能失去它；过去他总怪自己不够坚定。
- → 如今他渐渐明白，难处未必是意志不够强，而是自己珍惜的东西确实不止一种。　✦ 选择的代价
- → 想到要付出的东西，他仍心疼，也盼着有条容易些的路；可再等下去，那条路不会自己出现。
- → 若只因怕珍贵之物受损就不再争取，自己爱惜的也未必留得住。
- → 他不再要求自己先毫不害怕；带着不舍、没把握，也能边承担边受苦，继续向前。
- → 走近真正要承担的事，他还是会怕，只是不肯再让恐惧替自己决定。

### 242–253　（正在面对）

- 不再等毫无损失的办法，他终于重新向前；久违的昂扬回来，也不必靠否认脆弱维持。
  - ← 提供理由：（226–241）「走近真正要承担的事，」
- → 他仍愿尽力，却不再要求每一分努力都证明自己能改变一切。
- → 他知道要做什么，也明白为何舍不得；怕失去的、想珍惜的，都能摆在明处。
- → 他愿为真心爱惜的一切负责，不再把牵挂当作行动的拖累。
- → 这次决心仍热烈，却比从前踏实；他不必等犹疑消失，才准自己坚定。　✦ 分清
- ⟲ 仍在起作用：（226–241）「如今他渐渐明白，难处」

### 254–288　（正在面对）

- 带着全部牵挂重新向前，他意外发现：旧日的愿望没有远去，反而更亲近了。
  - ← 改写：（242–253）「他知道要做什么，也明」
- → 从前一想到那种生活，他就想退出艰难的争取，仿佛退回来才能完整保住它。
- → 如今正因知道它多么可贵，他更不愿任由那些使它难以实现的事继续存在。
- → 正因仍向往那种不必拼命的生活，他不肯袖手旁观；要珍惜它，有时反而得离开安宁去行动。
- → 投入更多不保证靠近旧梦，愿望也不能让付出自动值得；留心别耗掉所爱，才知道怎样坚持。　✦ 办法的限度
  - ← 限制：（226–241）「他亲身体会过，尽力承」
  - ← 限制：（226–241）「心里的美好生活也能安」
  - ← 改写：（181–205）「如今越懂温柔可贵，他」
- → 重新看懂这份希望后，他感到更宽的喜悦：两股曾拉扯他的心意，如今能一起推他向前。
  - ← 改写：（226–241）「如今他渐渐明白，难处」
- → 他不必为依恋羞愧，也不必因肩上有责任，就厌倦自己想珍惜的东西。
- → 最初相信生活时的快乐又回来；经历怀疑与疲惫，他知道这快乐并非理所当然。
- → 喜悦平静后，他仍无法保证尽力会改变什么，也没真正回到无需防备的生活。
- → 往后仍会疲惫，也可能因代价动摇；两种渴望同行，不代表它们不再冲突。
- → 他不再拿一种满足遮住另一种需要，也不因心愿未成，就否定已经得到的东西。
  - ← 改写：（92–115）「他只能承认这个不情愿」
  - ← 改写：（148–180）「这份安宁是真的，他几」
- → 这一切让他更清楚：哪些值得付出，哪些不能在付出时轻易丢掉。
  - ← 提供理由：（24–65）「越投入越热切，付出的」
  - ← 限制：（116–147）「那份曾让他昂然的要求」
  - ← 提供理由：（148–180）「这份安宁是真的，他几」
  - ← 限制：（181–205）「如今越懂温柔可贵，他」
- → 他仍向往安宁，也愿意行动，却不知道最后能留下多少珍贵的东西。
- → 他不愿靠忘掉任何一边换取安稳，也不再需要为自己愿意向前找更多证明。
- ⟲ 仍在起作用：（148–180）「他盼着人与人不必时时」；（181–205）「他想起当初不肯再等，」
