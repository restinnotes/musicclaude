# 为什么旧版的五段选择不能被当成“现成来源直接给了五段”

在前一轮 Op.60 实验里，同样参看 Kopp 与 PTNA 及乐谱：一路整理为 `1–34 / 35–71 / 72–83 / 84–102 / 103–116` 五段；另一路为九段。旧裁决把“短引子不值得独立”“短过渡只是大段入口”等理解加入了**自己的换气判断**。这超出了本轮要求的“忠实采用已有文献分段”。

此次应直接展示 PTNA/Kopp 文献中明确列出的每一级结构与对应起点；如果某位作者确实明确把多个部分归为一个父级，也显示那个父级。**不能用自己合并的五段声称“文献已经证明是五段”。**

Op.60 的历史 run102 九段可以放在文献提取结束后的对照表中供用户查看，但不得作为文献提取模型的提示词示例，也不因用户喜欢九段就自动修改论文中的边界。
