# 逐字精读：mb5k → mb6w

- [op60 S01-1]「随之缓缓」→「缓缓」（argon: “随之”偏书面且多余，删去后语感更自然干净。）
- [op60 S01-2]「持续牵动」→「牵动」（argon: “持续”有报告腔，且后文“着”已表持续，删去更自然。）
- [op60 S02-3]「，也自在」→「，自在」（argon: 全篇“也”字过多，此处顺承不必用“也”，删去更利落。）
- [op60 S03-2]「却仍盼着」→「却盼着」（argon: “却”“仍”同表转折，叠用累赘，删去“仍”更干净。）
- [op60 S04-1]「，也安心」→「，安心」（argon: 前后分句顺承自然，“也”字多余且在全篇反复出现，宜删。）
- [op60 S05-2]「温柔也带着」→「温柔却带着」（argon: 前后是转折关系，用“也”不准，改为“却”语义更贴切。）
- [op60 S06-2]「他也能安心」→「他能安心」（argon: 此处并无递进或类同对象，“也”字多余，删去可减少全篇重复。）
- [op60 S08-2]「充盈感」→「充盈」（argon: “充盈感”带心理学术语味，删去“感”字更合乎平实的叙述语调。）
- [op60 S09-2]「更多温柔」→「多少温柔」（argon: “更多”与“也留不住”搭配不当，改为“多少”才合乎自然口语。）
- [op60 S09-2]「最好时候」→「最好的时候」（argon: 缺少助词“的”，读起来生硬拗口。）
- [op60 S10-3]「他也喜欢」→「他还是喜欢」（argon: 前有“虽”，后接“也”搭配不顺，改为“还是”更自然，并减少“也”的重复。）
- [op60 S10-4]「欢喜也随着」→「欢喜随着」（argon: 与前句无并列关系，“也”字凭空多出，删去更干净。）
- [op60 S11-1]「有了满足」→「满足了」（argon: “期待有了满足”搭配生硬，改为“满足了”更自然。）
- [op60 S11-2]「，也安心」→「，安心」（argon: 三个分句一气呵成，且与S04-1句式雷同，删去“也”避免套话感。）
- [op60 S11-3]「，也没想」→「，却没想」（argon: “欢喜得发疼”与“没想停下”是转折关系，改“也”为“却”更准确。）
- [op60 S12-4]「自己的得失」→「得失」（argon: “得失”本就指自己的，“自己的”属于赘词。）
- [op60 S14-1]「想起起初」→「想起当初」（argon: “起起”二字相连拗口，追忆往事用“当初”更自然。）
- [op61 S02-1]「竟像得伸手」→「竟像要伸手」（argon: “像得”易误读为“像+得（de）”，显得拗口，改为“像要”更自然顺口。）
- [op61 S02-3]「似乎也能」→「也能」（argon: 前文已有“他觉得”表主观揣测，“似乎”语意重复。）
- [op61 S03-1]「越来越急着」→「更急着」（argon: 附近几条密集出现四个“越来越”，此处改为“更”可避免单调并紧承前句。）
- [op61 S03-3]「已越来越」→「越来越」（argon: 表已然的“已”与表递进过程的“越来越”语义冲突，删去“已”更利落。）
- [op61 S04-4]「面对那种生活」→「接受那种生活」（argon: “面对”后直接跟主谓小句“那种生活再也回不来”搭配不自然，改为“接受”更贴切。）
- [op61 S05-2]「竟像得乞求」→「竟要乞求」（argon: 避免与[S02-1]重复“如今竟像得……”的生硬句式，且“乞求”本身已含低姿态，不必叠用“像得”。）
- [op61 S05-3]「忽然又孤单」→「忽然孤单」（argon: 前文并未提过“孤单”，“又”字落空，且与上一条末尾“他又气愤起来”连用“又……起来”显得重复。）
- [op61 S05-4]「疼爱当年」→「心疼当年」（argon: “疼爱”多用于长辈对晚辈或伴侣之间，对自己过往的隐忍与不易应说“心疼”。）
- [op61 S06-3]「也暂时退远」→「暂时退远」（argon: 前文并无同类事物退远可供并列，此处“也”字多余，且与前后条的“也”连读显腻。）
- [op61 S08-1]「孤单使他」→「孤单让他」（argon: “使”字偏书面生硬，改为“让”更符合全文平实自然的叙述口吻。）
- [op61 S08-3]「他已打算」→「他打算」（argon: “打算”本是当下的起意，前加“已”字赘余生硬。）
- [op61 S09-1]「差一点不再」→「差一点就不再」（argon: “差一点”后接否定谓语时，自然口语需有“就”字衔接才顺畅。）
- [op61 S11-1]「痛到这里」→「痛到这一步」（argon: “到这里”偏指空间位置，表程度或境地时用“痛到这一步”更自然准确。）
- [op61 S12-3]「为想念而羞耻」→「为想念羞耻」（argon: “为……而……”偏书面套语，删去“而”字更干净平实。）
- [op61 S13-2]「为了被人接纳」→「为了被接纳」（argon: 删去“人”字意思不变，且能避免与后半句“由着别人”的“人”字重复。）
