# Op.60｜关系图（在 w10 上逐段聚焦重修 w11）

**Center：**对亲密的投入与自我克制始终相互牵制。

### S01｜1–3 小节　（还说不清）

- 他一想到这个人就柔软起来，很想亲近，自己也被这份心意来得突然吓了一下。
- → 他想让这份喜欢多留一会儿，却怕心意露得太明白会改变关系，靠近时便收住一点。
- → 眼下还没非得决定关系去向，喜欢也轻得不稳，他却舍不得就这样放下。

### S02｜4–16 小节　（没在想）

- 他先让眼前的亲近自然发生，不急着想两人以后会怎样。
  - ← 提供理由：（1–3）「轻得不稳」
- 他提醒自己不必向对方要回应，也不必总揣摩对方的反应，便能安心靠近、自在地关心对方，也喜欢自己不计较。
- → 那时他真觉得，能这样亲近下去，眼下已经够了。
- 他不敢认定这样的亲近会一直有，眼下就盼这一刻慢些。
- 他一度很想把心意多给一点，热切了一阵，又把分寸收回来。

### S03｜17–23 小节　（正在面对）

- 安静下来后，他仍沉浸在刚才的亲近里，心思飘远，暂时不急着去哪里。
  - ← 提供理由：（4–16）「不必向对方要回应」
- → 正因为眼前的亲近已经让他满足，他开始盼它能长久。
  - ← 改写：（4–16）「眼下已经够了」
  - ← 提供理由：（4–16）「盼这一刻慢些」
- → 想到长久，他才发现自己能决定怎样珍惜对方，却不能决定对方是否也珍惜自己。
- → 他还没打算向对方索取答复，只是偶尔想知道自己在对方心里是不是特别。
- → 这念头一冒出来，原先顺畅的亲近就被绊住，他仍陶醉，却没法完全走神。

### S04｜24–34 小节　（正在面对）

- 他怕追着要回应会搅坏眼前的亲近，对方也没答应过他什么。
  - ← 提供理由：（4–16）「眼下已经够了」
  - ← 提供理由：（17–23）「被绊住」
- → 他把心思转去替对方高兴，提醒自己，真心盼对方好这件事本身就让他开心。
- → 想确认自己是否特别的紧张暂时退了，他不再计较给了多少，也不怕显得更在乎，觉得自己还有许多心意可给。
- → 他放开些去喜欢，反倒更舍不得这一刻过去，又怕给对方压力，热情便收了回来。
- → 他还是把这阵轻松当成保证，以为只要不向对方要回应，就能尽情喜欢，也不会失去眼前的亲近。

### S05｜35–39 小节　（还说不清）

- 欢喜稍退，他又想知道对方是否也把他放在心上，自己的快乐终究说明不了对方的心意。
  - ← 失效：（24–34）「不会失去」
- → 他难堪地想，自己对对方好时或许也盼着被珍惜，再说自己什么都不求，就是骗自己。
- → 可他关心对方、享受亲近时确实很快乐，那时并没想着要换回什么。
  - ← 说明：（24–34）「替对方高兴」
- → 他也不敢认定亲近会一直如此，不急着替自己辩白或用热情盖住难堪，想把亲近留住的劲头便松了些。

### S06｜40–50 小节　（没在想）

- 难堪没让他少喜欢，可再多给一点，也证明不了自己什么都不求。
  - ← 提供理由：（35–39）「盼着被珍惜」
- → 他仍盼被珍惜，却先把心思放回当下，真心关心对方，也盼对方过得好。
- → 关心对方时，他觉得这份喜欢留在心里也很甜，暂时忘了自己为何盼回应，可那念头过会儿又回来。
  - ← 提供理由：（35–39）「放在心上」
- → 他舍不得眼前的亲近就这样过去，却怕它留不住，心里便泛起酸楚。

### S07｜51–61 小节　（正在面对）

- 他觉得这份喜欢值得留着，不舍得收淡，于是越来越常惦念对方，喜欢渐渐不是想收就能收住的。
  - ← 提供理由：（40–50）「留在心里也很甜」
- → 眼前的亲近明明还好，他却不能决定它能留多久，已经有点怕它留不住。
  - ← 提供理由：（40–50）「亲近留不住」
- 他还是想把喜欢留在心里。
- → 他越来越盼对方能懂自己的关心，可还是觉得不该催对方，只好自己消化这份期待。
  - ← 限制：（24–34）「搅坏眼前的亲近」

### S08｜62–71 小节　（没在想）

- 安心靠近、真心给予、独自惦念的甜，都不是等对方许诺才有，他不想再因怕受伤压住欢喜。
  - ← 说明：（4–16）「不必向对方要回应」
  - ← 说明：（24–34）「心意可给」
  - ← 说明：（40–50）「亲近留不住」
  - ← 提供理由：（51–61）「不舍得收淡」
- → 他不再压着想亲近的心，任自己高兴，连玩心也冒出来，给得多了也不再一笔笔算。
- → 他明知对方没给保证，却高兴得一时顾不上那份沉重，也不急着替未来留退路。
  - ← 说明：（35–39）「放在心上」
- → 欢喜还没散，他已经舍不得它结束，想被对方同样珍惜的愿望也跟着冒出来。
  - ← 唤起：（51–61）「消化这份期待」

### S09｜72–77 小节　（正在面对）

- 欢喜稍落下来，他才承认自己不只想尽情喜欢，也盼对方同样渴望靠近、愿把彼此放在心上。
  - ← 唤起：（62–71）「舍不得它结束」
- → 他很想被对方同样珍惜，也知道不能拿真心逼对方回应，怕继续盼下去会催到对方。
- → 他一再想把盼望收回，却总觉得是在否认刚承认的心意，委屈之余也厌烦自己反复为难。
- 他仍肯为眼前的亲近高兴，即使对方的心意还没着落。
  - ← 说明：（62–71）「独自惦念」
- ⟲ 仍在起作用：（51–61）「消化这份期待」

### S10｜78–83 小节　（正在面对）

- 他不再逼自己马上选边，也不急着认定这份感情该怎么走。
  - ← 提供理由：（72–77）「怕催到对方」
- → 他让眷恋先留在心里，照样顾着分寸，不急着付诸行动。
  - ← 提供理由：（72–77）「反复为难」
- → 他终于能喘口气，委屈和渴望松了些，身上也松了劲，原本绷紧的温柔又能自然地留在心里，他还摸不准对方心意。

### S11｜84–92 小节　（正在面对）

- 他不再逼自己压下渴望或立刻决定去留，熟悉的亲近之乐又回来，犹疑这么久还能高兴，竟让他感动。
  - ← 提供理由：（78–83）「自然地留在心里」
- → 他曾因想被珍惜而怀疑自己的关心是不是交换，如今能承认自己也想被珍惜，仍是真心关心对方。
  - ← 改写：（35–39）「盼着被珍惜」
  - ← 说明：（35–39）「换回什么」
- → 他仍不知道对方会不会同样选择自己，却愿意把这阵欢喜感受到底，浓烈得胸口发疼。
  - ← 限制：（72–77）「怕催到对方」

### S12｜93–102 小节　（没在想）

- 他不只想靠近、被同样珍惜，也想把积攒的关心给对方，看看两个人能过上怎样的日子。
  - ← 提供理由：（84–92）「不是交换」
- → 他不再为想被珍惜自责，欢喜把他整个卷进去，旧日难堪暂时退下，连自己的得失也顾不上。
  - ← 提供理由：（84–92）「竟让他感动」
  - ← 提供理由：（84–92）「不是交换」
- → 他真想把积攒的关心都给出去，欢喜浓得难以承受，可对方仍没给新保证，他还盼同样的选择。
  - ← 限制：（84–92）「胸口发疼」
- → 他一时顾不上以后，只想让这阵欢喜多留一会儿，等它稍退，尚未得到回应的期待又回到心里。

### S13｜103–110 小节　（正在面对）

- 他真想和对方共享幸福，可对方仍没给保证，他怕这份幸福只属于自己，没法不在意对方会不会选他。
  - ← 限制：（93–102）「新保证」
  - ← 唤起：（93–102）「期待又回到心里」
- → 他曾不再查看对方是否在意，只管关心，安稳过一阵，可想被珍惜的心还是会回来。
  - ← 说明：（40–50）「放回当下」
- → 尽情喜欢确实让他幸福，可他先前试过不盯回应，也没法靠这两种做法保证对方会选他。
  - ← 失效：（24–34）「不会失去」
  - ← 说明：（62–71）「玩心也冒出来」
- → 他不想让对方负责消除自己所有的不安，也不愿因怕落空就故意把喜欢压淡。
- → 他仍盼对方主动靠近、把他放在心上，却不愿催对方回应，也没法假装自己不在乎，心里很难受。
- ⟲ 仍在起作用：（93–102）「怎样的日子」；（35–39）「放在心上」；（17–23）「不能决定」；（62–71）「独自惦念」；（72–77）「怕催到对方」；（72–77）「同样渴望靠近」

### S14｜111–116 小节　（正在面对）

- 他不再逼自己找出怎样喜欢才不会受伤，先停下反复盘算该收住还是放开。
  - ← 提供理由：（103–110）「两种做法」
- → 他想让对方按自己的心意靠近，不愿为了让自己安心，把所有期待都压给对方，弄得两人不自在。
  - ← 限制：（72–77）「怕催到对方」
- → 虽仍没有答案，安心靠近、真心给予、独自珍藏、尽情欢喜都曾让他快乐，让他知道这个人有多重要，也让他愿意继续向前。
  - ← 说明：（4–16）「不必向对方要回应」
  - ← 说明：（24–34）「心意可给」
  - ← 说明：（40–50）「亲近留不住」
  - ← 说明：（62–71）「留退路」
- → 以后若等不到对方主动靠近，他还是会疼，这不等于他先前的喜欢是假的。
- → 他仍想被这个人选择，也愿继续喜欢，不再因怕改变关系就把心意收回去。
  - ← 改写：（1–3）「多留一会儿」
