## 配对与防降级
- 每一份 `jobs/gpt6w/<ID>.txt` 与 `jobs/gpt56w/<ID>.txt` 必须完全一样；真实路由/实际档位与调用时间分别记录。
- 统计时只比较两边都真实成功、可验证为目标模型的同一 JOB；有一边失败就标 unpaired，不算模型质量胜负。
- 成功率本身单列工程可靠性，不把排队失败/held 当模型语义能力差。
- 可以检查异常短耗时、输出极短和不遵守指令；但这些只是嫌疑，不能直接宣告降智。

## 解释结果时的边界
此轮测的是*文本材料上的能力*，不测模型真正听音或读谱能力；不证明作品唯一正确解释。评审要分开：准确性、真洞见、前缀、表达、上屏实际效用以及输入证据不足。
