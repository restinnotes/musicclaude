我把五篇都按整篇连续经验来判断；音乐项只按我对这首曲子的知识判断，拿不准的地方明确标“不确定”，不把它当错误硬扣分。

### 文章A

**什么在变 / 为什么 / 留下什么：** 她从“希望这种自然的亲近不断重来”，逐渐变成承认：对方可以望向别处、自己甚至可以真正喜欢对方喜欢的新世界，但这并不取消她希望继续相伴的愿望。变化来自她真的经历了“不同方向也能带来快乐”，而不是单靠一句尊重自由的道理；结尾仍没有解决两人以后是否继续同行，只解决了她怎样表达眷恋而不把它自动变成要求。

**最好的一处：93—102小节。** 她想到对方第一次转头看另一条水路时真正高兴的神情，于是“希望继续相伴”和“不愿抹掉他的那种目光”第一次发生实质冲突；这让第二主题回到主调不只是形式上的“融合”，而是过去经验真正改变了现在所求。fileciteturn0file0L155-L169

**最差的一处：103—110小节。** 音乐这里极有压力，文章却主要用回顾和总结来完成高潮：“不能把经历收回去”“不否认愿望，也不把它变成束缚”。这些话逻辑正确，却没有新的双方事件来逼出它，人物在最需要遭遇对方的时候变成了自己给自己作结论。fileciteturn0file0L173-L191

因此我会点 **F6、F7**：并非整篇失败，但“航行—不同方向—学会不抓紧”的模板感仍比较明显，而且多数段落末尾都要结算一次新认识。

### 文章B

**什么在变 / 为什么 / 留下什么：** 她最初珍惜的是两个人不用商量就能配合的生活；后来真正看见他为什么想去船厂，自己又亲手体验陌生水域的吸引，于是问题从“怎样让他留下”变成“我怎样既不否认他的向往，也不把自己的损失假装成没关系”。结尾保留了远行、信件可能延迟、关系可能争执等风险；改变的是他们开始用说出来、调整、重新配合代替“默契就该自动成立”。

**最好的一处：103—110小节。** 前面建立的是“不费力的同步”，这里货船余波逼得两个人必须互相提醒、临时改变动作；所以同一种“共同划船”回来时，意义已经彻底不同——成熟不是恢复无摩擦，而是发生摩擦时仍能协调。这个回收非常强。fileciteturn0file1L403-L419

**最差的一处：78—83小节。** 指节旧伤、轻轻触碰和 *dolce sfogato* 很漂亮，也有前史，但安排得稍显“恰好”：几乎把这一特殊音乐时刻完整兑换成一个完美的温柔镜头。好在后面立刻重新产生说话的压力，所以没有沦为纯音响插图。fileciteturn0file1L271-L309

我不判任何明显假阳性。它虽然大量使用船、桨、船厂，但这些不是换皮比喻，而是已经构成人物工作、愿望和关系史的具体世界。

### 文章C

**什么在变 / 为什么 / 留下什么：** 他最初只是想把最后一晚拖长，后来却发现一个更难看的事实：自己不只怕她吃苦，甚至会因为她可能过得很好、可能不再需要自己而难受。变化之所以成立，是因为她的车票、工作欲望、害怕、想念，以及他自己那一瞬间“不该有的轻松”逐步逼他把“关心她”与“希望她留下”拆开；结尾仍保留离别、嫉妒、新的人际关系、通信失败等真正的问题，没有用成熟人格把它们消灭。

**最好的一处：51—61小节。** 这是五篇里我认为最强的局部之一。他不断询问住处、工作、冬天、照应，自以为是在担心；等她说“也许会不顺利”，他却先感到了一瞬轻松，于是不得不发现自己正在等一个可以名正言顺劝她留下的麻烦。人物获得的不是漂亮道理，而是一个让自己羞愧的新事实，后面的每一步都因此被改写。fileciteturn0file2L221-L251

**最差的一处：17—23小节。** 故事上的“再绕一圈”非常好，但这一段前半先被写成相当舒服的沉默，到约20小节才让牵引感出现；就我对音乐的记忆，这稍微把该段的过渡性不安推迟了。问题不大，反而是全篇少数我会在“local moment”上犹豫的地方。fileciteturn0file2L49-L79

没有明显 F1–F7。尤其结尾还让他承认自己并没有因为谈通了就不再嫉妒，这一点成功避免了“顿悟之后人格升级”的假解决。

### 文章D

**什么在变 / 为什么 / 留下什么：** 可以回答出“什么在变”，但主要变的是一套概念：从索取安稳，到接受变化与自由，再到主动投入，最后允许一个美好时刻结束。为什么变，文章大多用音乐本身和作者预设的哲学推导来回答，而不是让人物遭遇足够具体的新事实；结尾留下的仍是时间会流动、关系不能保证，只是这一答案其实在正文开始以前就已经宣布了。fileciteturn0file3L3-L19

**最好的一处：103—110小节。** 它准确抓住了“103处已经强烈抵达，但音乐偏偏还不能结束”这个特殊经验，而且没有简单解释成又一轮焦虑，而是“已经知道自己珍惜什么，仍需要让感情充分存在”。这是全文少数音乐结构本身真正反过来抵抗哲学捷径的地方。fileciteturn0file3L335-L371

**最差的一处：正文开始之前。** “真实美好不能靠留住获得”“既不能……也不能……”已经把中心论证和最终立场完整交代；随后大量段落实际上是在替这套答案寻找音乐例证。再加上“承托、安稳、自由、重量、充分回应”等概念不断自我繁殖，读者很难感觉一个人真的经历了什么。

这里我明确判 **F2、F3、F6、F7**。另外它额外建立“第117小节｜音乐之外”一节；作者确实明确说明实际不存在第117小节，因此我不判“虚构音乐事实”，但它仍超出了题设的14段结构。fileciteturn0file3L417-L427

### 文章E

**什么在变 / 为什么 / 留下什么：** 正文中的“我”从害怕最后一晚太好，逐渐能同时承认两件互不抵消的事：我真想让你留下，也真希望你去；后来两人又从抽象的“愿意”走到地图、见面、通信、疲惫、怨恨和无法及时回应这些具体代价。结尾仍保留远距离生活是否真的撑得住、双方会不会自私疲倦乃至争吵；得到的不是保证，而是一套目前愿意实行、以后还可能失败的回应方式。

**最好的一处：103—110小节。** 93—102刚刚把“我们仍可以共同创造生活”推到近乎狂喜，下一段却没有顺势收束，而是马上追问假期被打乱、消息不能及时回复、甚至将来真的可能怨对方怎么办。这很好地利用了103之后“已抵达却继续增强”的反常感，使前一段的愿意接受现实压力测试，而不是成为结局。fileciteturn0file4L573-L645

**最差的一处：正文前的元评。** 文件一开始已经直接告诉读者“主线成立”“需要加深”“两个人发现彼此都有不能放弃的愿望”，甚至先告诉我们103—110应该怎样理解。fileciteturn0file4L3-L7 这明显削弱了第一次阅读正文时逐渐辨认的权利。若只从 `#《船歌》：把这一夜真正过完` 开始算，文章会明显更强。

因此我判 **F2、F7**：F2主要来自这个前置说明；F7则较轻，正文的分段标题和段尾仍经常提前替读者把“这一段的新认识”结算出来。不过因为每次认识背后都有橘子、草图、工作、家人、地图、实际交流限制等具体事实，远没有D那么严重。
