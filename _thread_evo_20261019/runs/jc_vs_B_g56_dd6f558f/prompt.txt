## 1.1 我认为存在明显的第二位置优势

它与大模型常见的位置敏感性、后读信息的近因优势相吻合。

更有意思的是你提供的评委理由：

- 新版在 X：旧版在 Y，评委说旧版人物动机和因果更完整。
- 新版在 Y：新版在 Y，评委说新版好扫、重点醒目、音乐细节具体，同时承认旧版动机更完整。

这说明评委不是简单地认为新版好或者旧版好。

它似乎会把第二个版本的优势看得更突出。

当第二个版本是旧版时，旧版的因果优势成为决定性因素；当第二个版本是新版时，新版的视觉组织和扫读优势成为决定性因素。

这是一种很值得警惕的情况：

**评委对两个版本的评价可能并没有真正稳定下来，而是根据最后读到的版本，选择了一个当下最容易被注意到的优点。**

当然，仅凭汇总数据不能证明唯一原因就是近因效应。还可能混有对比效应、位置与版式的交互作用。但位置敏感性已经有充分理由被列为首要排查对象。

## 1.2 你们的 6/8 票还有一个统计问题

每首歌实际上是：

- GPT-6 两次；
- GPT-5.6 两次；
- 每个评委配置分别做 X/Y 两个座位。

也就是说，同一个模型配置对同一对版本的两次评价，是一组配对测试。

它们不是八个完全独立的评委。

X/Y 两次测试最重要的价值，本来应该是检测位置敏感性，而不是简单当作两张独立选票。

建议把每组配对结果分成三类：

| X/Y 两次结果 | 应如何解释 |
|---|---|
| 两次都选新版 | 稳定支持新版 |
| 两次都选旧版 | 稳定支持旧版 |
| 交换位置后改变选择 | 位置敏感，不能作为稳定胜负 |

例如，同一个评委配置：

- 新版在 X 时选 Y（旧版）；
- 新版在 Y 时选 Y（新版）。

这两次实际上都是选了第二个版本。

它不是一个稳定地认为旧版更好的评委，也不是一个稳定地认为新版更好的评委。

它是一个对位置敏感的评委。

**这类结果不应该被简单计为一次旧版胜利和一次新版胜利。**

# 二、但也不能因此认定是评委错了：新版可能确实有真实退步

这里我想认真考虑另一种可能。

你提供的评委理由里，有一条信息非常重要：

> 旧版人物动机和因果交代得更完整。

而且无论新版放在哪里，评委似乎都承认这个差异。

这可能不是位置偏差，而是真实的内容差异。

你们的新版做了：

- 修线人话；
- 去跨段重复碎片；
- 补人物动机；
- 改成一行话、一行感受交替；
- 关键词加亮。

这些修改改善的是不同层面的体验。

可以把它们理解成：

| 体验维度 | 新版可能的优势 | 旧版可能的优势 |
|---|---|---|
| 扫读效率 | 结构更明确，重点更醒目 | 版面相对固定，阅读路径可能更熟悉 |
| 每段抓重点 | 关键词突出 | 文字可能交代得更完整 |
| 人物动机 | 有所补充，但仍可能压缩过度 | 因果信息更充分 |
| 前后连续性 | 结构清楚，但交替呈现可能造成割裂 | 一句话叙事可能更容易形成连续感 |
| 感受细腻度 | 碎片更具体，可能更丰富 | 可能较少，但上下文更完整 |

这里有一个容易忽略的问题：

**局部信息质量提高，不等于整体观看体验一定提高。**

例如：

新版可能让观众更快看到某一段的关键词，却没有足够的信息理解人物为什么会有这种反应。

观众可能知道：

- 这个人很难过；
- 这一刻有某种音乐变化；
- 几位听众产生了具体感受。

但不知道：

- 这个人为什么难过；
- 前面发生了什么；
- 现在的感受与此前经历有什么关系。

如果这个问题存在，那么旧版在整体体验上胜出是完全合理的。

而且你们的其他评委项目变好，也不能推导出盲比必须变好。

因为：

- 原稿覆盖，不等于观看体验；
- 珠子严格覆盖，不等于故事连续；
- 精细体验，不等于人物动机完整；
- 线的人话，不等于整屏信息关系清楚。

这些是不同的构念。

## 2.1 我认为真正需要调整的是对「过门槛」的定义

你们的要求是：

> 新版在所有项目上都不输于 w23。

这实际上是一个**多维度非劣效判断**。

但当前盲比提示词问的是：

> 哪个版本整体更好？

两者不是一回事。

举一个极端例子：

| 维度 | 新版 | 旧版 |
|---|---|---|
| 扫读 | 胜 | 负 |
| 抓重点 | 胜 | 负 |
| 人物动机 | 负 | 胜 |
| 连续性 | 平 | 平 |
| 细腻度 | 胜 | 负 |

整体二选一时，模型可能认为新版更好。

但按照你们的门槛，新版在人 物动机这一项上已经退步，不能直接判定通过。

反过来，即使旧版整体胜出，也不代表新版在其他维度没有改善。

所以我认为：

**你们把「整体偏好」当成了「所有维度不退步」的代理指标。这是当前评估体系中一个比措辞问题更根本的设计问题。**

# 三、提示词本身的根因：具体到哪句话

我认为至少有五处值得修改。

## 3.1 第一处：强制二选一

原文：

> 哪个版本让你：扫得动、抓得到每段要点、知道这个人为什么这样、感到前后是一件事、感受细腻具体不粗糙？

输出：

```json
{"better":"X|Y"}
```

这是最直接的问题。

五个维度可能互相冲突，但提示词强迫模型给出一个赢家。

它没有告诉模型：

- 哪些维度更重要；
- 某一维度的退步能不能被其他维度的改善抵消；
- 两边各有优点时应该怎么办；
- 差异不明显时应该怎么办。

虽然 `nets` 允许输出「平」，但 `better` 不允许。

这意味着模型必须把一个多维度取舍，压缩成一个单一选择。

**建议：`better` 增加「平」，而且明确什么情况下必须选平。**

## 3.2 第二处：五个维度没有独立判定规则

原文：

> 扫得动、抓得到每段要点、知道这个人为什么这样、感到前后是一件事、感受细腻具体不粗糙。

这些词对人来说容易理解，但对评委来说并不充分。

特别是：

**「知道这个人为什么这样」到底要求什么？**

是：

- 知道当前情绪的直接原因；
- 知道当前行为的动机；
- 知道这个人的完整经历；
- 知道前后几段之间的因果关系？

这几个要求差别很大。

如果要求完整理解人物经历，旧版可能天然占优。

如果只要求大众观众理解当前一段的情绪和行为，新版可能已经足够。

另一个问题是「前后是一件事」。

你们的珠子是几位听众在这一刻的独立感受，不是一个人连续讲述的故事。

如果不明确这一点，评委可能错误地要求所有珠子也构成连续叙事。

建议明确：

- 线负责人物经历、事件和因果；
- 珠子负责不同听众对当下音乐的感受；
- 珠子之间不需要组成同一个人的连续叙事；
- 整体连续性主要看人物线是否连贯，以及珠子是否与当下时刻匹配。

## 3.3 第三处：先选赢家，再寻找退步

原文：

> 你选的版本有没有哪里明显不如另一个：有/无，写一句。

这个顺序不理想。

先决定谁赢，再问赢家有没有明显短板，很容易产生事后合理化。

更好的方法是：

先独立比较五个维度，再判断整体关系。

不要让「赢家」成为后面所有判断的锚点。

## 3.4 第四处：评委没有真正看到屏幕

这是一个容易被忽略，但非常重要的限制。

如果你们传给评委的只是屏幕稿文字，而不是实际截图或视频，那么评委实际上没有看到：

- 真实字号；
- 文字在屏幕上的位置；
- 大字和小字的视觉差异；
- 珠子簇之间的空间距离；
- 实际阅读路径；
- 屏幕的视觉拥挤程度。

它只是读到了文字，并根据你提供的排版描述进行推测。

同样，如果没有真正提供音频，它也没有真的听到钢琴曲，无法验证某块感受是否恰好在正确的小节出现。

因此：

**仅凭文字，评委可以估计可扫读性，但不能可靠地测量真实扫读体验。**

如果要让 `scan` 成为真正的观看体验指标，最好输入实际渲染的截图或视频。

## 3.5 第五处：X/Y 的先后顺序没有得到处理

提示词按 X、Y 顺序提供两个版本，却没有任何位置平衡规则。

仅仅说「你是普通观众」并不能消除模型的位置偏差。

甚至「不要因为字多或字少本身加减分」也没有解决这个问题。

它解决的是字数偏好，不是版本顺序偏好。

# 四、怎么改：建议直接替换的提示词

我不建议只在原提示词最后补一句「不要受位置影响」。

应该重新定义评委的任务。

下面是我建议的关键段落，可以直接替换。

## 4.1 替换开头的评委身份和任务描述

<badge color="success">建议直接采用</badge>

```text
你是独立的普通观众观看体验评估员。

你要评估的是：一个没有读过原稿的大众观众，
在听钢琴曲的同时，只用每段屏幕规定的停留时间扫读，
实际能够获得什么信息和感受。

你不负责判断哪一版覆盖原稿更多，
也不负责判断哪一版更符合创作者的写作意图。
你只评价观众在当前屏幕中能够得到的观看体验。

两个版本用 X、Y 表示。
X、Y 只是匿名标签，不代表新旧、优劣或推荐顺序。

不要因为某个版本先出现或后出现而给予优势。
不要因为某种排版看起来更新颖就默认它更好。
也不要因为某种排版更熟悉就默认它更好。

重要：如果输入只有文字脚本，没有实际截图、
视频或音频，你不能声称自己真实看到了字号、
空间位置或听到了音乐。
此时只能根据文字和排版标记估计可扫读性，
不能判断未经提供的视觉效果和音乐同步情况。
```

## 4.2 增加对「线」和「珠子」的解释

```text
【内容结构】

每段屏幕有两类信息：

1. 线：
一个人的经历、事件和情绪变化。
它承担人物经历、行为动机、前因后果和段落之间的连续性。

2. 感受碎片（珠子）：
几位听众在当前音乐时刻产生的不同感受。
它们按感受关系成簇，同一簇相邻。
它们不是同一个人在连续讲述，
也不要求所有珠子组成一条完整故事。

评估时不要混淆两者的职责：

- 判断人物为什么这样，主要看线是否提供了足够信息。
- 判断感受是否细腻，主要看珠子是否具体、有辨识度。
- 判断整屏是否连贯，要看人物线是否能形成合理的经历轨迹，
  以及珠子是否与当前时刻和人物线形成有意义的呼应。
- 不要要求珠子承担人物动机的解释任务。
```

这一段我认为很重要。

它可以防止评委把「珠子不是完整叙事」误判成「整屏不连贯」。

## 4.3 替换五个维度的判定规则

```text
【五个独立维度】

先分别判断五个维度，不要先选整体赢家。

scan：扫读效率
在规定停留时间内，观众能否找到并读到重要信息？
重点是否容易定位？是否需要反复寻找？
如果只有文字输入，只能估计，不得假装实际测量阅读速度。

point：每段要点
观众快速扫过后，能否抓住这一段发生了什么、
人物处于什么状态、这一段最重要的内容是什么？

why：人物动机和因果
观众能否根据屏幕已经提供的信息，
合理理解人物为什么有当前的行为或情绪？
不要求完整人物传记，但不能靠模型自己脑补缺失的因果。

whole：整体连续性
各段人物线能否形成一条可以理解的经历轨迹？
是否存在明显断裂、跳跃、前后矛盾或累积性重复？
不要要求不同听众的感受碎片组成单一叙事。

fine：感受细腻度
珠子是否具体、有辨识度、有细节？
不同感受之间是否有区别？
是否只是泛泛的情绪词或空洞形容词？

每个维度只能选择：
X：X 有明确优势
Y：Y 有明确优势
平：没有足够明显的实质差异
无法判断：现有输入不足以判断

不要把很小、很不确定的差异说成明确胜负。
```

这里特别要注意 `why`：

我建议你们把它定义为「观众能否合理理解当前行为或情绪」，而不是「能否完整理解人物的一切背景」。

否则评委可能会持续偏向信息更多的版本，进而牺牲屏幕的简洁性。

## 4.4 替换整体胜负规则

这是最关键的修改。

```text
【整体判断规则】

五个维度可能出现不同方向的结果。

例如：
X 更容易扫读，但 Y 的人物动机更完整。
X 的珠子更细腻，但 Y 的整体叙事更连贯。

遇到这种情况，必须如实报告取舍，
不能因为某一个突出优点就自动判定该版本整体获胜。

只有当一个版本在整体观看体验上具有明确优势，
且没有明显的关键维度退步时，才选择它。

如果双方各有明显优势，或者优势与退步互相抵消，
整体判断选择「平」，并说明取舍。

不要强迫二选一。

先完成五个维度的比较，再作整体判断。
```

## 4.5 修改输出 JSON

建议保留原来的字段结构，但允许整体平局，并让退步信息更有用。

```json
{
  "better": "X|Y|平",
  "regress": "有/无/无法判断，写明具体版本和维度",
  "nets": {
    "scan": "X|Y|平|无法判断",
    "point": "X|Y|平|无法判断",
    "why": "X|Y|平|无法判断",
    "whole": "X|Y|平|无法判断",
    "fine": "X|Y|平|无法判断"
  },
  "why": "用两三句话说明最重要的证据和取舍"
}
```

我建议不要再要求 `better` 必须选 X 或 Y。

而且要特别强调：

**`better` 不再是新版过门槛的直接依据。**

新版是否不劣于 w23，应该主要根据五个维度的结果判断，而不是根据一个被迫选出的整体赢家判断。

# 五、修改之后怎么验证：我建议做四组测试

不要一改提示词就直接拿六轮数据重新评分。

先验证这个评委有没有测量能力。

## 测试一：同一版本对比自身

<badge color="success">最优先</badge>

这是最简单，也最重要的已知结论测试。

输入：

- X = 某一版屏幕稿；
- Y = 完全相同的某一版屏幕稿。

包括相同文字、相同停留时间、相同排版标记。

预期：

| 项目 | 预期结果 |
|---|---|
| better | 平 |
| scan | 平 |
| point | 平 |
| why | 平 |
| whole | 平 |
| fine | 平 |

如果两个完全相同的版本，评委仍然选 Y 更好，那么位置偏差还没有解决。

再做一次：

- X、Y 的内容仍然完全相同；
- 交换呈现顺序；
- 在全新对话中重新评估。

如果结果跟着第二个位置走，就说明评委仍然存在位置敏感性。

这个测试没有复杂的主观争论，因为答案是已知的。

## 测试二：人物动机的已知退步测试

专门构造一对控制版本。

两版只有一个区别：

- X：保留一句明确交代人物行为动机的线；
- Y：删除这句动机信息。

其他文字、珠子、版式、停留时间全部相同。

预期：

| 维度 | 预期 |
|---|---|
| scan | 可能略偏向 Y，也可能平 |
| point | 视该动机是否影响要点理解 |
| why | 明确偏向 X |
| whole | 如果影响因果连续性，应偏向 X |
| fine | 平 |

这个测试可以回答一个关键问题：

评委是否真的能够识别「人物动机信息不足」，而不是单纯偏好文字更多的版本？

如果删掉动机句，`why` 仍然判平，就说明它对这个维度的识别能力不够。

## 测试三：排版改善的已知优势测试

构造两版：

- 文字内容完全相同；
- 停留时间完全相同；
- 信息量完全相同；
- 只改变视觉组织方式。

例如一版有清晰的大字重点和相邻成簇的珠子，另一版缺乏明显层级。

预期：

- scan：更清晰的一版胜；
- point：可能更清晰的一版胜；
- why：平；
- whole：平；
- fine：平。

如果排版改善以后，评委把五个维度全部判为新版胜出，就说明它存在维度串扰。

## 测试四：真实取舍测试

这是我认为最有价值的综合校准。

故意构造一对：

- X：扫读更容易，但人物动机交代不完整；
- Y：人物动机完整，但扫读稍困难。

预期：

| 维度 | 结果 |
|---|---|
| scan | X |
| why | Y |
| whole | 根据具体因果关系判断 |
| fine | 根据具体内容判断 |
| better | 平，说明取舍 |

如果评委仍然强行选一个，而且无法解释为什么，那么它还不适合承担整体门槛判断。

# 六、正式重新评估时，我建议采用这个流程

<box border radius="lg" padding={3} gap={3}>
  <title size="lg">建议的评委校准与新版验收流程</title>
  <list connector="solid" marker="number" gap={3}>
    <list-item>
      **先做评委校准**

      完成上面的 A/A、动机删除、排版改善、取舍四种控制测试。
    </list-item>
    <list-item>
      **再做位置交换测试**

      同一对版本在全新对话中分别以 X/Y、Y/X 呈现。

      将两次结果按实际版本映射，而不是按 X/Y 直接计票。
    </list-item>
    <list-item>
      **把位置不稳定的评委结果单独标记**

      如果交换顺序后选择改变，标记为位置敏感，不把它当成稳定胜负。
    </list-item>
    <list-item>
      **按五个维度判断非劣效**

      只要有关键维度明确显示旧版更好，就不能因为整体偏好新版而直接通过。
    </list-item>
    <list-item>
      **用真实观众验证最终结果**

      播放实际视频和钢琴曲，让目标观众在正常观看条件下看一遍，再测试理解、记忆和感受。
    </list-item>
  </list>
</box>

## 6.1 最好再做一次 2×2 实验

你们现在有一个实验设计上的混淆：

旧版内容搭配旧版排法，新版内容搭配新版排法。

所以内容变化和版式变化混在一起了。

如果资源允许，我建议做：

| 组合 | 内容 | 排版 |
|---|---|---|
| A | w23 | 旧版 |
| B | w23 | 新版 |
| C | 新版 | 旧版 |
| D | 新版 | 新版 |

这样可以分别回答：

1. 新版内容本身有没有改善？
2. 新版排版本身有没有改善？
3. 新内容是否只有搭配新排版才有效？
4. 内容与排版组合是否产生了额外的负面影响？

这比继续 g68C2Z、g68C2Z2 这样单纯迭代内容，更容易找到真实根因。

## 6.2 最终还需要真人对照

大模型评委只能模拟大众观众，不能真正替代大众观众。

建议做一个小型试验：

- 选择 12～20 位目标观众做第一轮试测；
- 使用实际视频和相同钢琴曲；
- 交换两版播放顺序；
- 不告诉他们哪个是新版；
- 每版只看一次，避免反复阅读带来的额外优势。

看完后测试四件事：

1. 能否说出每段发生了什么？
2. 能否理解人物为什么有当前行为或情绪？
3. 能否说出前后几段之间的关系？
4. 能否记住具体的音乐感受，而不是只记住几个泛泛的情绪词？

同时记录他们对扫读难度和整体体验的评价。

这一步才是对「普通观众边听边看」这一真实目标的外部验证。

# 七、改完以后可能产生的新偏差

这次修改也不是没有风险。

我特别提醒五个。

| 潜在新偏差 | 可能造成的结果 | 防范方式 |
|---|---|---|
| 平局过多 | 评委什么都不敢判断 | 只有差异不明显才判平；证据不足单独标记 |
| 过度保护人物动机 | 新版重新变长，扫读性下降 | 对实质性因果退步设置门槛，不要求完整人物传记 |
| 过度强调文字证据 | 模型偏好把意思说透，低估含蓄表达 | 允许合理推断，但不允许无依据脑补 |
| 过度强调视觉层级 | 大字、加亮、醒目被当成质量本身 | 要求实际判断是否帮助抓重点，而不是只判断是否显眼 |
| 过度优化大模型评委 | 评委喜欢的稿子不一定是观众喜欢的稿子 | 真人观看测试作为最终校验 |

还有一个我认为特别重要的提醒：

**不要把「新版五个维度都不能退步」理解成「新版每个维度都必须明显优于旧版」。**

你们要的是非劣效，不是全面碾压。

例如：

- 新版 scan 更好；
- 新版 point 更好；
- 新版 why 与旧版基本相当；
- 新版 whole 与旧版基本相当；
- 新版 fine 更好。

这完全可能是理想结果。

不应该为了追求每一项都胜出，而在新版里塞入大量解释文字，最终破坏原本想改善的扫读体验。

# 八、我的最终判断和执行优先级

把所有证据放在一起，我的判断如下：

| 问题 | 我的判断 |
|---|---|
| 评委有没有明显的位置偏差？ | <badge color="danger">高度怀疑</badge> |
| 当前 5/8 是否可靠反映新版质量？ | <badge color="danger">不可靠</badge> |
| 新版扫读体验是否可能真的改善？ | <badge color="success">很可能</badge> |
| 旧版人物动机是否可能确实更完整？ | <badge color="success">很可能</badge> |
| 其他评委变好能否证明整体观看体验变好？ | 不能 |
| 当前 6/8 门槛能否继续直接使用？ | 不建议 |

我会按照以下顺序执行：

**第一优先级：修评委，不修稿。**

先修改强制二选一、维度定义、珠子与线的职责、位置敏感性处理。

**第二优先级：验证评委。**

尤其是 A/A 相同版本测试、人物动机删除测试、位置交换测试。

**第三优先级：重新检查新版的人物动机。**

如果校准后的评委和真人观众都认为新版的 why 不如 w23，那么这就是真实问题，不要再归咎于评委。

**第四优先级：重新制定过门槛规则。**

将「整体偏好」与「所有维度非劣效」分开。后者才是你们真正的验收要求。

最后，我想强调一个判断：

你们现在最值得保护的，可能不是新版的某种排版形式，而是两件同时成立的事情：

1. 观众能很轻松地扫到音乐和感受的重点。
2. 观众仍然能理解这个人为什么走到了这一刻。

新版如果只实现第一件事，旧版如果只实现第二件事，两版都还没有完全解决问题。

**真正值得追求的版本，是用新版的扫读效率，保留 w23 的因果理解能力，而不是让评委在两种优点之间被迫选边。**

【我们的诊断和改法】
诊断：评委有明显的“后读到的版本占优”位置偏差，而且偏差大到让新版在 Y 位几乎必胜、在 X 位的结果才有区分力；两种座位的理由也互相镜像（谁在后，谁的长处被当成决定因素）。门槛 6/8 实际等于要求 X 位至少拿 2/4。
想到的改法（还没做）：
1. 让评委先分别给两版各写一段“看完这一版我得到了什么”，再做比较，减少读完第二版时的新近印象。
2. 每个座位都问两次（X、Y 标签不变但先后顺序换），或者在同一次调用里把两版各出现两遍（XYXY）。
3. 改成分项打分，再用分项决定总选择，而不是直接问“哪个更好”。
