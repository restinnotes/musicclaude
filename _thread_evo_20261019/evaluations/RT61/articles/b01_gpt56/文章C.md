# 文章C

**1—23**

起初，他不敢把那些日子想得太清楚。只要稍稍想起当时有多幸福，心里便先是一暖，随后又忍不住难过，因为他知道，那样的日子如今已经没有了。可若立刻收住念头，又像是自己亲手把它们推远了。他舍不得，却也不敢靠近，只好留住一种模模糊糊的好，不去细想好在哪里，更不去问为什么现在不一样了。可是，这样的回避并没有让他安心。他渐渐觉得委屈：那些日子明明那么值得珍惜，为什么如今连好好想一想，都要如此小心？他不愿再让害怕失去的心情，妨碍自己承认曾经拥有的幸福。

**24—65**

既然不愿再躲，他便开始认真肯定从前的好。他确实幸福过，那些期待曾有过回报，那些快乐也不是后来为了安慰自己才想象出来的。如今不同了，不等于当初的欢喜是假的。这个认识让他心里渐渐有了底气，甚至生出一点倔强：他没有理由因为今天难过，就把过去说得不值一提。他开始更坦然地怀念，不再一想到幸福就急着躲开。想到那时的自己能够放心地期待以后，他甚至也跟着高兴起来。既然回忆真的能让那份快乐再次被感到，他便越来越愿意相信，只要自己记得足够真切，从前的幸福就还能继续安慰今天的自己。他不愿轻易放弃这个希望，因为它让他觉得，那些日子虽然过去了，却还没有完全离开自己。

**66—91**

正因为刚才的怀念确实使他重新高兴起来，他便更愿意顺着这份快乐想下去。他想起那时为什么总有盼头：曾经得到过满足，便敢期待下一次；眼前的日子让他快乐，他也相信往后的日子值得期待。这样的回忆一度使他重新感到轻快，几乎忘记了自己原本为什么不敢细想。可是，越想把这份轻快留在今天，他越发现其中有一件事情不对。那时的期待有真实的生活可以回应，如今的回忆却只能告诉他，当年确实得到过什么，不能保证今天仍会得到。他这才意识到，自己其实向回忆要了两样东西：既要它证明从前真的幸福，也要它把那种幸福继续交还给今天的自己。前一件做得到，后一件却做不到。他并没有因此不再高兴，只是方才越真实的快乐，如今越让他感到失落。

**92—115**

他不甘心刚刚找回的快乐就这样变成失落，于是又把从前想了一遍，想得比先前更仔细，也更舍不得。他想弄明白，为什么同样的幸福，记得越清楚，反而越难受。渐渐地，他发现，当初真正使自己安心的，并不只是那些已经得到的快乐，还有一种不必怀疑的信任。他那时觉得，既然今天能够这样好，明天也会有值得期待的东西；即使幸福尚未到来，他也愿意相信它正在前面等着。原来他留恋的，不只是已经过去的日子，还有当时那个能够毫不费力地相信以后的自己。如今他仍记得那份笃定有多美好，却已经不能像当年一样自然地相信。回忆没有失真，恰恰因为它太真切，他才越来越明白自己失去了什么。这让他既想继续沉浸其中，又急于寻找一种办法，好让过去留下的力量不至于也跟着失去。

**116—147**

既然不能找回当年那种毫不费力的信任，他就想，至少应该保住它曾给自己的力量。他开始要求自己坚强：一个确实拥有过那么多幸福的人，怎么能因为眼前的失落，就变得如此没有把握？他试着像从前那样相信以后，试着把难过压下去，仿佛只要坚持得足够久，就能证明自己并没有失去当年的勇气。起初，这确实能使他振作一点。可很快，他便发现自己越来越疲惫。每当难过时，他不只要承受难过，还要责备自己为什么不能像过去一样坦然。更令他难受的是，当年的幸福原本就不需要这样费力地维持；如今为了证明自己没有变，他却必须一遍遍说服自己。越努力恢复那种笃定，越清楚它已经无法靠努力恢复。到最后，他终于不愿再勉强自己。他开始承认，过去确实给过自己很多，但不能因此要求过去替今天解决所有难题。

**148—180**

不再要求回忆使自己恢复原样，他反而能够安安静静地想念那些日子了。既然当年的好已经得到过证明，就不必再拿它证明自己如今应该怎样。他可以只为了珍惜而回想，不必每次都追问能不能重新拥有。这样一来，许多原先夹杂着不甘的回忆，渐渐显出了本来的温柔。他开始真心为当时的自己感到高兴：那些快乐曾经真实地来到过，他曾经那样满足，也曾经那样信任生活。即使今天已经不同，这些事情也不会因此消失。他甚至开始体谅眼前这个难过的自己，因为会如此舍不得，正说明从前确实有值得舍不得的东西。他不再急着责备自己的软弱，也不再向过去索取什么。一种深切的感激慢慢占据了他的心。他几乎觉得，既然自己确实拥有过那样的幸福，那么即使它已经过去，能够有过，也已经是很值得庆幸的事。

**181—205**

可是，正因为他终于能够完整地珍惜当年的幸福，眼前的缺失也变得更清楚了。过去不再需要被证明，于是他也不能再用“也许当时没有那么好”来减轻失落。他越是温柔地回想，越知道那些幸福为什么难以替代；越是承认自己曾经拥有得那么充实，越无法忽略如今确实少了什么。他原先几乎相信，只要懂得感激，就能够与失去和解，可现在才发现，感谢自己曾经拥有，并不等于已经心甘情愿地接受失去。那份温柔是真的，那份空落也是真的。他试着继续把心思放在已经得到过的东西上，可即使不再责备、不再索求，他仍然会舍不得。他甚至有些想重新抓住旧日那种对未来的确信，好让眼前不再显得如此无望。然而，一想到先前为了恢复它而付出的疲惫，他又不忍再逼自己。他只能慢慢放开那个念头，承认自己已经能够好好珍惜过去，却仍然不知道该怎样面对它不能延续的事实。

**206—213**

既然强求延续只会使自己更疲惫，他便暂时不再追问失去了多少，只重新承认自己曾经得到过多少。这份感激没有半点虚假，也确实让他短暂地安宁下来。他可以真心觉得，幸好那些日子曾经属于自己。可是，他已经不敢像先前那样轻易认定，有过就应该足够了。他知道，能够感谢，并不意味着心里就没有遗憾。

**214—215**

正是这份无法消除的遗憾，使最初的犹疑又回来了。只是他如今不再怀疑那些日子是否真的幸福，而是开始害怕：为什么每次越明白它们有多好，就越难接受它们已经过去？他到底该怎样怀念，才不会一次次让今天的自己受伤？

**216—225**

因为既舍不得忘记，也无法靠感激消除痛苦，他试着让两种心情同时留在心里。他允许自己眷恋过去，也承认如今的日子确实不同；他不想再为了显得坚强而责备自己，也不想为了减轻失落而贬低当年的幸福。可真正这样做时，他发现自己依然难以安稳。刚一体谅今天的难过，他就觉得自己好像在嫌弃过去；刚一维护过去的美好，又觉得自己仿佛非得拒绝眼前的一切，才算没有辜负当年。他明明已经知道两边都是真的，为什么仍觉得承认其中一边，就会伤害另一边？他渐渐察觉，自己心里似乎还有一个从未认真分辨过的要求。

**226—241**

他终于不得不面对这个要求：他一直觉得，既然从前曾经那么幸福，往后的日子本来也就应该一直那么好。他原以为自己只是舍不得失去，直到现在才发现，自己其实还在向今天追讨过去给过的东西。每当他回想当年有多好，心里便会不自觉地追问，为什么如今没有继续那样好；每当他更确信当时的幸福值得珍惜，也就更觉得今天的不同难以原谅。原来他一直把两件事混在一起：从前的幸福确实值得珍惜，却不意味着它有义务永远延续。他可以真心希望好日子不要结束，但这份希望本身，不能使后来的生活必须照它实现。承认这一点让他很疼，因为这意味着他必须放下一个始终不甘心放下的念头：曾经拥有过，便应该还能拥有。可若不肯放下，他就只能一次次拿最爱的过去责备今天，把每一份值得感激的记忆都变成新的失落。他终于看清，真正使自己无法安顿的，不只是幸福已经过去，还有自己一直不肯让“曾经很好”与“如今不同”同时成立。他仍然想要过去延续，却不愿再把这种想要，当成否认今天的理由。

**242—253**

既然终于分清了“我多么希望它继续”和“它本来就应该继续”，他便重新有了一种不需要勉强支撑的坚定。他可以毫不退让地承认：从前确实幸福，如今确实不同。今天没有当年那样好，并不能改变当初的欢喜；当初的欢喜再真实，也不能要求今天照旧。他不必再替过去向现在讨一个交代，也不必为了接受现在，就暗暗把过去说得平淡一些。那些日子好就是好，值得就是值得，即使它们终究没有像他曾经期待的那样延续下去。他第一次觉得，自己可以完整地维护那份幸福，而不必同时与眼前的现实争执。带着这份清醒，他终于又敢尽情地想念了。

**254—288**

因为这一次的怀念不再要求失去的幸福重新回来，他反而能够比先前更完整地感到当时的快乐。他终于不急着追问，为什么那么好的日子不能一直继续；也不再因为今天无法像从前那样相信，就责备自己。他只是认真地想起，那时的自己确实有过那么多满足，确实曾经觉得以后的日子也会值得期待。那些欢喜如今仍然能够打动他。他为当时的自己高兴，甚至有些骄傲，因为那一切不是想象出来的，他真的曾经那么幸福。可是，越是感到当年的快乐有多充实，他也就越清楚，那种放心相信以后的心情，如今已不能照旧拥有。他心里依然很疼，而且因为不再回避，这疼痛反而比先前更加分明。他终于明白，自己没有办法把过去的幸福和今天的遗憾分得干干净净：他越爱那些日子，就越会舍不得它们；越承认它们真的好，就越不能假装失去它们并不重要。但他已经不想再用别的办法消除这种难过了。他不愿因为如今会疼，就责怪自己当初不该那么投入；也不愿为了证明自己已经接受现实，就故意少想一点、少爱一点。他开始愿意让过去的幸福完整地留在过去，也让今天的遗憾如实地留在今天。两者都不必改变，才能使另一者成立。他仍然会为那些日子感到高兴，也仍然会为它们无法重来而难过。他甚至知道，往后每当认真想起，心里大概还是会疼。可这一次，他不再把疼痛当成自己必须克服的失败。那份幸福确实给过他那么多，他当然希望它从未结束；但即使它已经结束，他也不愿因此少珍惜它半分。他终于肯承受这份不能两全：从前是真的好，今天是真的舍不得。他不能因为想念，就让那些日子回来；可他也不必因为回不去，就把它们说得没有那么好。那些日子好到今天想起仍会心疼，而他明明知道会疼，也还是愿意承认：**那时的自己，真的很幸福。**
