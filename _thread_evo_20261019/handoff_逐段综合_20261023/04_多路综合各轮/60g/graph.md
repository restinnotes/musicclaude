# Op.60｜关系图（逐段综合 60g）

**Center：**最初的无名吸引、亲近中的欢喜与美好易逝带来的酸涩，是同一份在意的不同侧面。

### 1–3　（还说不清）

- 某种吸引先让他在意；他还说不清它指向什么，心里像是惦着点什么。

### 4–16　（正在面对）

- 亲近让那点在乎有了指向，他开始舍不得眼前的好，喜悦里泛起浅浅酸意。
  - ← 唤起：（1–3）「未明的吸引」

### 17–23　（没在想）

- 亲近带来的舒服仍在心里自行延续，他沉浸于相处本身，享受当下的轻松。
  - ← 唤起：（4–16）「初生的留恋」

### 24–34　（正在面对）

- 先前的轻松让他更自然地投入，熟悉的亲密感格外浓，欢悦也更强烈。
  - ← 提供理由：（17–23）「安然停留」

### 35–39　（正在面对）

- 更主动地亲近时，那份在意也更藏不住，他一时觉得自己有些脆弱。
  - ← 提供理由：（24–34）「更自然地投入」

### 40–50　（正在面对）

- 亲近过后，在意沉入心底，眼前的好仿佛早成回忆，愉悦也染上独自回味的微酸。
  - ← 改写：（35–39）「投入后的脆弱」

### 51–61　（正在面对）

- 记忆中的相处重新鲜活起来，勾起更迫切的渴望。
  - ← 唤起：（40–50）「独自回味的微酸」

### 62–71　（正在面对）

- 喜欢的畅快让他一时沉醉，那份急切也成了满足。
  - ← 改写：（51–61）「回味牵出渴望」

### 72–77　（没在想）

- 热切稍退，单是亲近就足以打动他，所爱似乎比眼下所求更广。
  - ← 改写：（62–71）「尽兴地喜欢」

### 78–83　（没在想）

- 相处中的美好吸引着他，他短暂沉入超出个人急切的安宁。

### 84–92　（正在面对）

- 能如此深切地在意令他欣喜，也让他更坦然、更自信。
  - ← 提供理由：（78–83）「沉入亲近之美」

### 93–102　（正在面对）

- 想亲近的念头渐难放下，欢喜也透出近乎刺痛的急切。
  - ← 提供理由：（84–92）「坦然地在意」

### 103–110　（正在面对）

- 亲近最鲜明时，先前独自体会的涩意又浮起，让他觉得这份美好也未必留得住。
  - ← 唤起：（40–50）「独自回味的微酸」
  - ← 提供理由：（93–102）「渴望逼近刺痛」

### 111–116　（正在面对）

- 开头那股无名的牵引再度浮现，如今已有了亲近的实感。
  - ← 提供理由：（103–110）「欢喜里的酸楚」
