# Op.60｜关系图（在 v6 上修补，w35）

**Center：**对亲密的投入与自我克制始终相互牵制。

### S01｜1–3 小节　（还说不清）

- 他一想到这个人就柔软起来，很想亲近，也被这份突然到来的心意吓了一下。
- → 他觉得这份喜欢轻得随时可以放下，却偏偏舍不得。
- → 他想过很多次该怎样向对方表明心意，早已清楚自己想说什么。
- → 他怕说出心意会改变关系，眼下不用决定去向，便想让喜欢多留一会儿，靠近时收住一点。

### S02｜4–16 小节　（没在想）

- 他让眼前的亲近自然发生，不再揣摩对方的反应，也不索要回应，便能自在地关心对方，也喜欢自己不计较。
- → 他那时真觉得，只要能这样亲近下去，眼下已经够了。
- 他不敢认定这样的亲近会一直有，便只盼眼下这一刻慢些过去。
- 他一度很想把心意多给一点，热切了一阵，想到还得顾着分寸，便又收了回来。
- ⟲ 仍在起作用：（1–3）「多留一会儿」

### S03｜17–23 小节　（正在面对）

- 他已从眼前的亲近里得到满足，暂时不再惦记还要什么，心思便不必总围着对方转。
  - ← 提供理由：（4–16）「亲近下去」
- → 他仍盼这份亲近长久，原先不必多想的安稳因此松动。
- → 想到长久，他才发现自己能决定怎样珍惜对方，却不能决定对方是否也珍惜自己。
- → 他从前觉得自己在对方心里是否特别无需确认，如今却偶尔在意，不打算求证，亲近也因此被绊住，没法完全走神。
- ⟲ 仍在起作用：（4–16）「慢些」

### S04｜24–34 小节　（正在面对）

- 他知道，对方也没答应过他什么。
  - ← 说明：（17–23）「不能决定」
- → 他把心思转去替对方高兴，觉得真心盼对方好，自己也会开心。
- → 他暂时不太担心自己是否特别，觉得还有许多心意可以给，也不怕显得比对方更在乎，便放开些去喜欢。
  - ← 动摇：（17–23）「无需确认」
- → 他越放开些去喜欢，越舍不得这一刻过去，热切时又怕成了催促，只好收住一点。
- → 他甚至把这阵轻松当成保证，以为自己能尽情喜欢，也不会失去眼前的亲近。

### S05｜35–39 小节　（还说不清）

- 他发现自己尽情喜欢时的快乐，终究说明不了对方是否也珍惜这份亲近。
  - ← 动摇：（24–34）「当成保证」
- → 他难堪地想，或许盼着被珍惜，说不求回报是在骗自己，可那时关心对方、享受亲近，确实没想过换回什么。
- → 他不急着替自己辩白或用热情盖住难堪，想把亲近留住的劲头便松了些。

### S06｜40–50 小节　（没在想）

- 难堪之后，他不愿因自己也盼回应就否定这份喜欢，仍愿意真心关心对方，也不再装作什么都不求。
  - ← 改写：（35–39）「盼着被珍惜」
- → 他关心对方时，把喜欢留在心里独自珍藏，不急着求回应，暂时忘了为何还盼回应，过会儿念头又回来。
- → 他发现，再多对对方好，也不能证明自己什么都不求，偏偏他想被珍惜又不愿开口索取。
- ⟲ 仍在起作用：（17–23）「不能决定」

### S07｜51–61 小节　（正在面对）

- 他尝过关心对方时那份细细的甜，便越来越常惦念对方，喜欢也渐渐收不住，舍不得把它减轻。
- → 他反复回想两人相处时的亲近，也想象彼此身体上更亲密时的情形，独自从中得到欢愉。
  - ← 提供理由：（40–50）「留在心里」
- → 眼前的亲近明明还好，他不想让期待牵着自己走，便想把喜欢留在心里。
- → 他渐渐盼对方懂他的关心，却相信不该催对方，越不愿给对方添负担，越只能自己消化没有着落的盼望。
- 他想到眼下的亲近也在一点点过去，再舍不得也留不住这一刻，便不再指望它停下来。
  - ← 改写：（24–34）「怕成了催促」

### S08｜62–71 小节　（没在想）

- 他记得最初亲近时的安心，也记得不计较地关心对方的满足、独自珍藏喜欢的甜意，对方没许诺，这些仍是真的。
- → 这些经历一点点积起来，他不想再因怕受伤压住欢喜，便任自己高兴，连玩心也冒出来。
- → 他给得多了也不再一笔笔算，高兴得一时顾不上那份沉重，也不急着替未来留退路。
- → 他想被对方同样珍惜的愿望又冒出来，可眼前的亲近不能证明这一点，他便又开始在意对方的心意。
  - ← 限制：（17–23）「不能决定」
- 他想到这一刻终究留不住，便想记住刚才那份欢喜。
  - ← 唤起：（51–61）「一点点过去」

### S09｜72–77 小节　（正在面对）

- 他也盼对方想靠近、把彼此放在心上，却知道喜欢再深也不能因此觉得对方该回应，怕盼得太紧会催到对方。
  - ← 唤起：（62–71）「同样珍惜」
- → 他一再想收回盼望，却觉得这样是在否认刚承认的心意，委屈之余也厌烦自己反复为难。
- 他仍愿为眼前的亲近高兴，因为这份亲近本身值得珍惜，即使对方的心意还没着落。
- ⟲ 仍在起作用：（4–16）「亲近下去」

### S10｜78–83 小节　（正在面对）

- 他不急着替这份感情下结论，也不逼自己立刻选边，便不往前推进，也不假装自己不在乎。
- → 他不把对方的温柔当成必须向前一步的表示，也不拿回应衡量每次关心，便不必等心事理清也能照常关心。
  - ← 限制：（72–77）「盼对方渴望靠近」
- → 他不再硬压住委屈和渴望，承认自己想被珍惜并不等于催促对方回应。
  - ← 改写：（72–77）「否认刚承认的心意」

### S11｜84–92 小节　（正在面对）

- 犹疑许久后，对方重新愿意亲近他，回应了他一直盼着被珍惜的心愿。
  - ← 提供理由：（78–83）「想被珍惜」
  - ← 改写：（24–34）「是否特别」
- → 对方的回应让他不必靠无所求证明体贴，也承认想被珍惜不妨碍真心关心对方。
- → 他知道深情不能替对方作决定，也可能让自己受伤，却仍愿珍惜对方此刻给他的亲近。

### S12｜93–102 小节　（没在想）

- 他不再为想被珍惜自责，也想把积攒的关心给对方，看看两人能过上怎样的日子。
  - ← 提供理由：（84–92）「无所求证明」
- → 他觉得许多真情值得珍惜，想靠近、想被爱，还想把心全交给对方，仿佛想要的都已拥有，满足得他也招架不住。
- → 他愿和对方一起面对日后的琐事和难处，连那些与相爱无关的事也愿意一起操心。
- → 他仍盼对方选择和他一起过日子，曾为此紧张难堪，如今暂不被缺憾折磨，欢喜稍退，未获回应的期待又回来。
- ⟲ 仍在起作用：（17–23）「不能决定」

### S13｜103–110 小节　（正在面对）

- 他真想和对方共享幸福，尽情投入也曾让他幸福，却怕对方并未同样珍惜这份亲近。
  - ← 提供理由：（93–102）「把心全交」
- 他终于重新得到对方的亲近，越觉得珍贵，越清楚它终究不能永远留住，幸福里便有了失落。
  - ← 提供理由：（84–92）「重新愿意亲近」
- 他曾把喜欢收在心里，确实安心些，可想被珍惜的愿望并没有消失。
- → 他不想把所有不安都交给对方解决，也不愿因怕落空就故意把喜欢压淡。
- → 他舍不得否认自己想被珍惜，又不愿逼对方回应，心里便越来越难受。
- → 他宁可继续不舒服，也不愿假装自己不想被珍惜，换来一时平静。

### S14｜111–116 小节　（正在面对）

- 他不再反复盘算该收住还是放开，也不靠克制证明自己清醒，因为两种做法都不能保证自己不受伤。
- 他知道对方有自己的心意，不必和他一样，若要对方接住全部期待，亲近反会失去自在。
- → 他仍想被爱，也还想要更多，却不把自己的渴望当成对方必须满足的事。
- 他记得小心靠近、慷慨付出、独自珍藏和尽情欢喜，都曾让他快乐，也让他一次次愿意继续向前。
- → 这些经历没能解开对方是否会选择他的疑问，却让他看清对方对自己有多重要。
- → 他不拿对方最终是否选择他，来判定自己当初是不是真心，因为那些快乐和在意都是真的。
- → 他接受遗憾留在心里也能继续喜欢，等不到对方主动靠近仍会疼，却不因疼痛否认感情或催对方回应。
- → 他不愿再把日子留在等待对方选择里，便决定彻底结束这段关系，转身离开。
  - ← 提供理由：（93–102）「未获回应」
