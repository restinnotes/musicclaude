# Op.60｜关系图（精简视图）

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3

**此刻：他很想靠近对方，却小心收住期待，暂时允许这份喜欢没有确定的回应。**
- ← **提供理由**（1–3·所求）他已经喜欢这个人，真心希望能够靠近对方。
  　他确实想靠近对方，所以没有打算取消这份喜欢。
- ← **提供理由**（1–3·机制）他压低期待，一方面想让对方自由选择，一方面想给自己留一点免于受伤的余地。
  　尊重对方与保护自己的两种考虑，共同使他保持谨慎。
- ← **说明**（1–3·办法）他暂时不向对方索取回应，也不急着判断对方是否同样在意自己。
  　暂不索取回应，使他能够把喜欢留在心里而不急着推进关系。
- ✦ 机制：他压低期待，一方面想让对方自由选择，一方面想给自己留一点免于受伤的余地。

### 4–16

**此刻：他因能够自在地亲近对方而逐渐放心，愿意让自己的关心更加充分。**
- ← **改写**（1–3·状态）他很想靠近对方，却小心收住期待，暂时允许这份喜欢没有确定的回应。
  　起初的谨慎主要让他收住期待，如今保留分寸也让他敢于充分关心。
- ← **提供理由**（4–16·办法）他继续保留一点距离，不要求每一次靠近都立即推动关系向前。

- ← **说明**（4–16·回报）他因为不急着索取而感到自在，开始放心地给出比先前更多的关心。

- ✦ 机制：他不再把每次亲近都当成衡量得失的机会，心里便少了许多紧张。
- ✦ 发现｜分清：他发现保留分寸也能让关心更加充分，先前把克制误当成了压低热情。
- ⟲ 仍在起作用：（1–3）他已经喜欢这个人，真心希望能够靠近对方。；（1–3）他认为自己的喜欢不能替对方决定该怎样回应。

### 17–23

- ← **提供理由**（17–23·恐惧）他怕把期待充分显露出来，会让自己的真诚变成催促对方回应的压力。

- ✦ 机制：已经尝到亲近的快乐，使他开始在意对方是否也出于自己的心愿珍惜这份关系。
- ✦ 发现｜办法的限度：他发现过去帮助自己安心的分寸，也可能使自己始终得不到充分理解。
- ⟲ 仍在起作用：（1–3）他已经喜欢这个人，真心希望能够靠近对方。；（1–3）他认为自己的喜欢不能替对方决定该怎样回应。

- ✦ 发现｜分清：他发现可以让对方知道自己多么希望被珍惜，同时不给对方规定必须作出的回应。
- ✦ 机制：他能够说清自己想要什么，也允许对方自行回应，因此不必再把自己的心意压得很小。
- ⟲ 仍在起作用：（1–3）他认为自己的喜欢不能替对方决定该怎样回应。；（4–16）他在一次次愿意亲近、又不必立刻确认回应的时候，感到真切的快乐。

- ✦ 机制：他已经真切感受过这份温暖，因此想到可能失去时，心里有了具体舍不得的东西。
