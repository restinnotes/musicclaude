# Op.60｜关系图（逐段综合 60e）

**Center：**未明的期待、亲近中的欲望与深切喜欢，都和彼此心意未必相通的疑问交织在一起。

### 1–3　（没在想）

- 他心里有份说不清指向何处的期待，连自己也不知道究竟在盼什么。

### 4–16　（正在面对）

- 那份模糊的盼望在亲近中初次有了方向，因此他尝到温柔的满足。
  - ← 提供理由：（1–3）「无名的期待」

### 17–23　（没在想）

- 刚才的满足让他浑身放松，心头也松快，只静静享受眼前的惬意。
  - ← 提供理由：（4–16）「期待有了方向」

### 24–34　（正在面对）

- 轻松片刻后，熟悉的亲近再现，他更想把心意放深些。
- → 喜欢得更深，让他感到畅快，亲近也像唤醒了他更多活力。

### 35–39　（正在面对）

- 心意加深后，这份亲近更切身；他开始担心对方是否也珍惜它，心里有些不安。
  - ← 唤起：（24–34）「欢喜扩展」

### 40–50　（正在面对）

- 亲近之中泛起一丝酸楚：他的心意虽真，却未必能与对方完全相通。
  - ← 改写：（35–39）「盼被珍视」

### 51–61　（正在面对）

- 那点只得独自面对的苦楚化成身体里的急切；他沉在亲近带来的热意里，欲望推着他向前。
  - ← 改写：（40–50）「亲近中的独处感」

### 62–71　（没在想）

- 那股急切此刻化成痛快，他尽情享受着喜欢一个人的滋味。
  - ← 改写：（51–61）「沉入热望」
- → 欢喜才涌上来，他便开始留恋这份轻松。

### 72–77　（没在想）

- 尽兴之后，单是喜欢一个人就足以令他动容，欲望满足反倒退居其次。
  - ← 改写：（62–71）「尽兴地喜欢」

### 78–83　（没在想）

- 喜欢让他心头一暖，先前独自体会的苦涩也化成温柔的感动。
  - ← 改写：（40–50）「亲近中的独处感」
  - ← 提供理由：（72–77）「被喜欢本身打动」

### 84–92　（正在面对）

- 亲近的欢喜让他动情，先前的心酸也化成脆弱感。
  - ← 改写：（40–50）「亲近中的独处感」

### 93–102　（没在想）

- 他被自己对这个人的深切喜欢打动，觉得心里很满，已不只是一时愿望得偿的快意。

### 103–110　（正在面对）

- 这份感情让他真切感到内心充实，心意显得郑重而具体。
- → 幸福里浮出苦涩疑问：自己的深情无法替对方决定怎样对待这份情。
  - ← 改写：（35–39）「盼被珍视」

### 111–116　（正在面对）

- 心里的丰足，让他仍珍惜亲近，也在意对方怎样待这份情。
  - ← 提供理由：（103–110）「切身的确认」
  - ← 限制：（103–110）「回应的疑问」
