下面是肖邦《船歌》Op.60的一条 Thread（关系图，叫 v6）。我们在 v6 的基础上逐段修补，前面的段已经修好，现在修 S12（第 93–102 小节）。

Thread 是什么：一个人在这首曲子里经历的一件事。每一段要让人看见他此刻为什么会这样，理由来自他前面真实经历过、相信过、发现过的东西，而不是音乐忽然发生了什么。珠子是另一批人听这段音乐写下的听感，写的是此刻听到、感到的具体样子，会和线并排展示；线不用把珠子再描写一遍，而是给这些感受一个“为什么偏偏此刻会这样”的理由。
关系图的写法：每段先标他和 Center 的关系（还说不清 / 正在面对 / 没在想）；条目前的 → 表示由上一条引出；← 是跨段箭头，指回前面某段的某一条（提供理由、说明、限制、动摇、唤起、改写、失效）；⟲ 是前面仍在起作用的东西。

这次修补只解决三个问题：
1. 覆盖不足：这一段珠子里的感受（主体验、段内变化，以及和它们同时成立的另一侧面），线要给出他此刻为什么会这样；理由和珠子对不上的要改。
2. 啰嗦废话：一个意思拆成几条、翻来覆去说同一件事、没有必要的心理环节、不成立的因果。
3. 不说人话：抽象、像哲理总结、工整对照、作者替他宣布领悟、只说他没做什么。
v6 已经成立的好内容不能丢：整体走向、已经说清的心理事实和前后关系都要留下，可以改写、合并，但意思不能丢、不能变弱；只有换成更有解释力的说法时才可以去掉，并在 changes 里说明。和珠子对不上的解释不算好内容，要改。

要求：
- 覆盖：主体验、段内变化里的每一种感受，都要能从这一段的条目里看出他此刻为什么会这样。线的作用不是把感受写得更细——细节由珠子并排展示，线只给原因；所以不要把珠子的描写搬进线里。一条原因常常能同时解释好几颗珠子，不要为每颗珠子各加一条。同时存在的几种感受可以写在同一条里，不要硬排成先后发生的几件事。真正解释不了的写进 gaps，不要硬补。另一种理解（和主体验不能同时成立的听法）不必解释。
- 精简：一条只说一个别的条目没说过的意思，包括前面各段已经说过的——前面说过的原因不要再说一遍，此刻还在起作用就用 ← 指回去；几条其实是同一个念头就合成一条；删掉也不损失意思的就删。条数跟这一段真正发生了多少相称，没多少事就写一两条；修补后的条数一般不多于 v6 这一段，除非 v6 确实漏掉了这一段的主体验。不强求每段都有新的领悟、办法或转折，不写“试一个办法—不管用—换一个办法”。全曲一直成立的背景（他在乎、对方心意未知、时间在走之类）不能单独当此刻的原因，要说出它此刻因为前面哪一步变了才起了新作用。关键转折写出具体前因，不用“越……越……”“更……了”顶替。
- 人话：直接写他具体在想什么、怕什么、想要什么。不把心情说成一样东西（“这份……”“一种……”），不写听着深刻的总结句，不写整整齐齐的“前半句；后半句”对照，不由作者替他宣布“他终于明白”“他才看清”；但他想明白的东西本身（分清了两件事、发现某个办法管不了什么、对自己的新认识）是内容，不能因此删掉：保留这个认识，用他自己的平常话说出来，并让人看出是前面哪段经历让他想到的；前文没有经历撑着的，不要把无奈写成高尚、坚定的选择。只说他没做什么的空否定，改成说他在做什么（说出变化的“不再……”可以留）。一条只放一个意思，不用分号把两三件事串在一起；每条一般不超过 45 字，但不要为了字数把一个意思拆成几条。
- 边界：不新增前史、往事、身份、外部事件、对白、具体的人物关系或场景；珠子里的比喻——地点、人物、往事画面，以及处境、动作、对白（例如“像要对很亲近的人说一件想了很久的事”“握紧另一个人的手”“像一幕旧场景回来”）——只说明感受像什么，不能写成他真的在做、真的要做或真的想起的事；可以取其中的心理，不取那件事本身；不把音乐本身的变化当成心理原因。可以补一座接在前面已确立内容上的局部心理过程（身体先于念头、刚才的什么让此刻变了）。正文不写小节号、编号、音乐术语，也不写对修改的说明。
- 形式同 v6：relation 是这一段他和 Center 的关系（还说不清 / 正在面对 / 没在想），一般沿用 v6；follows: true 表示由这一段上一条引出（画成 →）；because 是跨段箭头，from 只能写【前面已经修好的段】里的条目编号，rel 取 提供理由、说明、限制、动摇、唤起、改写、失效、仍在起作用，只连真正的前因，主题相近不算。key 是两到八个字，取自这一条的原文，后面的箭头用它指代这一条。explains 写这一条给出原因的珠子编号。Center 不改。

【这一段的珠子】
- B1［主体验］（93–102；超出个人的感受在原稿中明确对应94–102）第62–71小节那支异常温柔、晴朗的歌，在这里被放到了最大尺度：声音明亮、开阔，近乎英雄式，内声部却彼此拉扯，音乐一浪高过一浪。前面做梦、走神般的状态忽然聚焦到“此时此地”，内心的私语仿佛放大成天地的共振。倒不是“我的感情终于变得比一切都伟大”，反而像整个人被卷进一个比自己更大的世界，连“我”都暂时退到了后面。
- B2［另一侧面］（93–102；久别重逢的类比来自覆盖94–104的原稿，不能进一步细定位）这份狂喜像高烧。它也可以像久别重逢：刚才还能够微笑、寒暄，忽然却抱紧对方，久久不愿松手；又可以是喉咙发紧、眼眶湿润，快乐到连自己想笑还是想哭都分不清。
- B3［段内变化］（93–102；尤其96–100附近，释放发生于102–103交界）这股声浪却不是一路畅通地冲到顶。原本温柔的歌带上近乎恳求的力量，旋律一次次向上伸展，仿佛还想要更多，却始终不能完全满足。到第96–100小节附近，乐句末端仍有牵扯、延迟与紧张，那口悬着的气一直带到102–103小节交界，才得到一次重大的释放。
珠子之间：B1 与 B2：可同时成立；B1 与 B3：重叠但新增；B2 与 B3：可同时成立

【两位评审对 v6 这一段的诊断】
评审甲：
- 值得保留 R51、R52、R53：保留当他不再因渴望而自责，反而更清楚自己究竟想要什么：不只是靠近，也想被同样深切地珍惜。这个愿望仍在，却暂时没有像过去那样折磨他。B2的狂喜和B1中自我暂时退后的感受，都允许这种愿望在一阵更大的幸福中暂时不再占据全部心思。
- 值得保留 R55、R56：保留这一刻的幸福感近乎饱和，但对方并没有给出新的保证，所以他暂时不愿用未来的答案打断当前的满足。B2支持快乐强烈到难以承受，B3则支持这种满足仍然带着未完成的期待。
- 珠子 B1：相反。珠子明确强调他被一个比自身更大的世界卷入，连自我都暂时退到后面；R54-R55却把重点放在自己的爱、自己的愿望仿佛全部满足，呈现出更强的自我中心感。
- 珠子 B2：说清。R54-R56解释了为什么幸福像高烧、像久别重逢时紧抱不放：他终于允许自己充分感受想靠近、想被爱、想全心交付的愿望，不再立刻用未来的风险打断这一刻。
- 珠子 B3：偏弱。R52和R55都保留了想被珍惜却没有新保证的事实，能解释满足并非真正完成，但R54-R56把饱满和停留写得太满，没有充分解释为什么旋律仍一次次向上伸展、始终不能完全满足。
- 啰嗦 R51、R52：R51说他更清楚自己多想靠近，R52又具体列出想靠近、想被珍惜、想共同拥有幸福。R51可作为转变的引子，但若R52保留得足够具体，R51可以缩短。
- 啰嗦 R54、R55：两条都在描写愿望得到充分抒发、幸福近乎饱和。R55新增了对方没有给出新保证这一重要限制，因此应保留限制，而不是让R54和R55都重复宣布满足到极点。
- 啰嗦 R54、R55、R56：这里从许多爱可以给、仿佛再无所缺，到所有心愿仿佛得到抒发，再到让幸福停留，连续三次强调饱满和停留。R56有独立的时间态度，但R54可以大幅压缩，否则会掩盖B3仍有未满足张力的事实。
- 啰嗦 R53、R54：R53说愿望暂时不再以缺憾折磨他，R54又说仿佛已经再无所缺，两条从暂时不受折磨迅速推到几乎无所缺。这个升级应表现为当下的情绪高涨，不宜被写成实际缺憾已经消失。
- 不说人话 R52「他想让积攒的温柔有归处。」：温柔有归处是抽象而常见的比喻，没有说明他具体想和对方一起做什么、想从对方那里得到什么。
- 不说人话 R53「这些愿望曾让他紧张、难堪，如今仍在，却暂时不再以缺憾折磨他。」：这把前后心理状态总结得很完整，却缺少此刻为什么能暂时放下缺憾的具体经历；容易成为替他宣布进步。
- 不说人话 R54「他觉得自己有许多爱可以给，也有许多感情值得珍惜，仿佛已经再无所缺。」：许多爱、许多感情、再无所缺都是概括性语言，具体的欲望反而不清楚；同时它与下一条的未获保证、未完全满足形成过强的落差。
- 不说人话 R55「仿佛所有心愿都得到抒发，满足得几乎让他招架不住；可对方没给新保证。」：这是一种工整的满与缺对照，前半句把情绪写得极满，后半句再补限制。需要分清他是把愿望说尽了，还是愿望真的得到满足；目前容易把两者混在一起。
- 不说人话 R56「他一时顾不上以后，只愿让这刻的幸福完整地停留。」：完整地停留是抽象的诗性总结，没有交代他为何在这一刻不愿再想以后；可以保留暂时不顾未来的状态，但应让它有更具体的心理依据。

评审乙：
- 值得保留 R52、R55、R56：他不只想给予，也想被同样深切地珍惜；当下的欢喜让他仿佛已经获得了全部愿望的满足，于是暂时顾不上未来。但R55明确保留了对方没有给出新保证这一事实，因此这是一种当下的内在饱满，不是互相选择已经得到确认。

- 珠子 B2：说清。R52和R55写出了想靠近、想被珍惜、想全心交付的愿望一齐涌现，能够解释这种快乐为什么像高烧或久别重逢般浓烈到分不清哭笑。
- 珠子 B3：偏弱。R52和R55保留了想要更多、但没有新保证的事实，却没有充分解释为什么这股幸福在不断向上伸展时仍不能满足，直到段末才获得一次重大释放。
- 啰嗦 R51、R52：R51说他更清楚自己多想靠近，R52又具体列出想靠近和被珍惜的愿望；两条可以保留为从承认愿望到说清愿望的递进，但应避免重复解释“更想靠近”。
- 啰嗦 R54、R55：R54的“仿佛已经再无所缺”和R55的“仿佛所有心愿都得到抒发”重复制造全满感；R55还保留了无新保证的限制，因此R54中重复的全满结论可以删减，前半句关于内在丰盈的内容若要保留则应更具体。
- 啰嗦 R55、R56：两条都写当下幸福的饱满与停留；R55应承担愿望几乎都被抒发、但没有新保证的矛盾，R56则承担暂时不想未来的结果，不必再次用“完整的幸福”重复前面的满足感。
- 不说人话 R52「他想让积攒的温柔有归处，也想被同样深切地珍惜，知道两人能共同拥有怎样的幸福。」：“温柔有归处”是常见的抽象抒情说法，“共同拥有怎样的幸福”又把具体愿望变成概念；其实这条最重要的是他不仅想付出，还开始明确想要对方同样珍惜自己。
- 不说人话 R55「想靠近、想被爱、想全心交付，仿佛所有心愿都得到抒发，满足得几乎让他招架不住；可对方没给新保证。」：前半句以排比把愿望写成一种总括性的情绪高潮，“所有心愿都得到抒发”也很抽象；后半句的无新保证反而是最具体、最重要的事实，应当成为这条的重心。
- 不说人话 R56「他一时顾不上以后，只愿让这刻的幸福完整地停留。」：“幸福完整地停留”是漂亮但抽象的结尾句，读者看不见他具体忽略了什么、又在留恋什么；应保留暂时不想未来的心理事实，避免用诗意总结代替因果。

跨段、不能丢的关系（涉及这一段的）：
- R50、R51、R52、R53、R55、R56、R57、R59：不再为渴望自责，使他更清楚自己想靠近、想被珍惜的愿望，也能暂时不受缺憾折磨；然而这份饱满没有带来新的保证，幸福仍然会照出未满足的部分。这里的关键是愿望获得承认与愿望得到满足不是一回事。R55中的没有新保证必须留下，才能解释R57和R59为什么仍然成立。
- R50、R51、R52：当他不再因愿望而否认真心，想靠近和想被珍惜的愿望反而更清楚。这个关系很重要：坦然承认期待不是让期待消失，而是让它能够被直接看见。
- R56、R57：R56想让当下幸福完整停留，R57却发现幸福仍鲜明时心里有一处没有着落。后者不是对前者的简单否定，而是说明当下的满足无法替他取得对方同样选择的保证。
