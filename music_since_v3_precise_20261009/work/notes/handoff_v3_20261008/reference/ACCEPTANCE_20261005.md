# 06 — Acceptance Criteria

A new production chain should not be declared valid until the following are demonstrated on all three works.

## Material / research

- [ ] Formal production uses current selected models/prompts or explicitly versioned frozen inputs.
- [ ] A and T first-pass discovery are independent.
- [ ] H1–H5 roles are either retained with measured residual value or intentionally removed with evidence.
- [ ] H5 retrospective material cannot leak into realtime current Affect.
- [ ] H4 expectation state is prefix-valid.

## Anti-dilution / coverage

- [ ] A/T core inventory is explicit and protected.
- [ ] H items are residualized as DUPLICATE / SUPPORT / NEW / ALTERNATIVE.
- [ ] No important A/T unit silently disappears due to supplementary material volume.
- [ ] Coverage reference is canonical source inventory, not a previous MERGE output.
- [ ] Unsupported additions are measured, not just coverage.

## Anti-loss synthesis

- [ ] GPT-5.6w ×1 vs ×2 vs legacy multi-pass has been measured.
- [ ] Production uses the thinnest configuration that satisfies coverage/quality thresholds.

## Beads

- [ ] affect_core is not generated from already A/T-mixed prose.
- [ ] explicit hindsight and future-defined-present both fail validation.
- [ ] facets / alternatives / sequential states are internally distinguished.
- [ ] field/bead scale makes sense; no obvious coarse bead contains multiple sequential current states without review.
- [ ] local content quality is at least as strong as the historically accepted STRUCT_v1 quality.

## Second-order

- [ ] dedicated task exists.
- [ ] NONE is common enough to show the model is not forced to manufacture depth.
- [ ] mechanism claims are grounded in canonical bead content.

## Thread

- [ ] first-pass History/Thread is built from bead sequence only.
- [ ] independent T/H research is adjudicated later, not used as upfront authority.
- [ ] alternatives can remain open.
- [ ] no mandatory single Center.
- [ ] current Thread/Center no longer over-collapses into a generic therapy/moral arc.

## WHY

- [ ] local WHY and long-range WHY can coexist.
- [ ] WHY can be NONE.
- [ ] strongest work-specific WHY is not systematically hidden from the main surface.

## Presentation

- [ ] audible locator is optional and short.
- [ ] stale current-state content retires correctly.
- [ ] final writer cannot invent new semantic conclusions.
- [ ] Humanizer is only used when necessary and has been re-tested on current outputs.

## Reproducibility

- [ ] production code/prompts are versioned.
- [ ] each run records commit + prompt/model/input/output hashes.
- [ ] cache validity depends on exact producer/input identity, not file existence.
