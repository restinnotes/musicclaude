# Op.61｜关系图（在 w4 上逐段聚焦重修 w5）

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### S01｜1–23 小节　（还说不清）

- 他心里有股不肯停的劲，却说不清在等什么，熟悉感先牵动身体，念头还认不出方向。
- → 他怕再拖下去，会把珍惜之物继续受损当成没办法的事，也怕真投进去会失去别的东西。
- → 他想找个能说服自己的理由，可每次刚以为想通，不舍又回来，连那点确信也变得陌生。
- → 他为自己非得想透才肯动而难堪。

### S02｜24–65 小节　（正在面对）

- 他怕再拖下去会慢慢认下眼前的样子，也不愿看着珍惜的东西继续受损，便先接下能做的一份。
  - ← 提供理由：（1–23）「没办法的事」
- → 接下这一步后，他有了些力气，也有点骄傲，心里仍犯嘀咕却已经能继续做。
  - ← 改写：（1–23）「想透才肯动」
- 他仍惦记从前熟悉的亲近，那些珍惜的东西如今不能像过去那样自然地拥有。
- → 他一感到失落，就把心思压回眼前，越逼自己稳住，越显出他仍很在意。
- → 他刚聚起力气，又担心自己会垮，只好再逼自己用力，始终安顿不下来。

### S03｜66–91 小节　（没在想）

- 他因自己不再缩着而短暂高兴，少了些反复自问，可愤怒、不甘和失落仍让他定不下方向。
  - ← 提供理由：（24–65）「仍犯嘀咕」
- → 那种不用时时防备的亲近让他松了口气，可越觉得它可贵，越清楚眼下离它很远。
- → 轻松退去时，先前那份决定又占回他的心思，他开始怀疑刚才的昂扬有几分真心。
- ⟲ 仍在起作用：（24–65）「熟悉的亲近」

### S04｜92–115 小节　（正在面对）

- 轻松退去后，他还记得那一步确实让自己重新动起来，所以仍愿意坚持。
  - ← 提供理由：（24–65）「仍犯嘀咕」
  - ← 唤起：（66–91）「昂扬有几分真心」
- 他确实因熟悉的亲近快乐过，当时看似坚定也在努力撑住自己，如今的不安没让他认定先前那一步走错了。
  - ← 提供理由：（66–91）「不用时时防备」
- → 他反复追问过去还能怎样，问不出答案又拿自己定下的事逼自己往前，一停下来就得面对那份亲近回不到从前。
- → 继续坚持也带不回熟悉的亲近，他仍不知道怎么面对这份不舍。

### S05｜116–147 小节　（正在面对）

- 那次决定曾把他从犹疑里带出来，他舍不得松手，也怕一失望就说明自己变了心。
  - ← 提供理由：（92–115）「重新动起来」
- 他仍想要那种不用时时防备的亲近，想到它会心软，却怕这点软让自己停下来。
- → 他把受苦当成自己还不够坚定，越难受越逼自己继续撑。
- → 他把坚持变成不能示弱的硬规矩，连疲惫都不准承认，最后发现自己正逼着一个累了的人硬撑。
- → 他先有些茫然，撑着的劲也松了，不安没散，他才承认舍不得那种不必防备的生活。
- ⟲ 仍在起作用：（92–115）「亲近快乐过」

### S06｜148–180 小节　（没在想）

- 催逼停下来后，他认出自己舍不得的不是一时舒服，而是曾真心相信过的生活。
  - ← 说明：（116–147）「不必防备的生活」
- → 他盼着人与人靠近时不用时时防备，珍惜的东西也不必靠争抢才能留住。
- 他想付出时只是因为喜欢，不必反复证明自己值得被爱和接纳。
- 他确实尝过那种亲近带来的快乐，所以不肯轻易把这份向往说成软弱。
  - ← 提供理由：（92–115）「亲近快乐过」
- → 他不再逼自己维持坚强，也暂时不盘问这份向往有没有用，压住的委屈和思念终于能露出来。
  - ← 改写：（116–147）「不能示弱」
- → 他允许自己相信这份向往，满足和柔软慢慢回来，连先前的疲惫也暂时淡了。
- → 这份满足让他一时舍不得把心思拉回现实，可那种生活仍没真正实现。

### S07｜181–205 小节　（正在面对）

- 他刚沉进满足里，熟悉的生活感忽然闯来，身体先绷紧，回神后又懊恼自己忘了还有事要面对。
  - ← 提供理由：（148–180）「这份满足」
- → 珍惜的东西仍受威胁，他又想起当初不肯再等，光怀念护不住那种生活。
  - ← 唤起：（24–65）「接下能做的一份」
- → 他想重新投入，却怕又把累当软弱，硬撑到头会磨掉温柔，只剩一股蛮劲，连争取的心也没了。
  - ← 提供理由：（116–147）「不能示弱」
- → 他原以为想明白行动的理由就能安心，如今理由和顾虑都多了，反倒更难定心。
  - ← 改写：（1–23）「连那点确信」

### S08｜206–213 小节　（没在想）

- 为难时，那份曾让他满足的柔软又短暂浮现，他认得它，舍不得马上压下去。
- → 他记得那份满足曾真实地安慰过自己，这次不想一出现就把它变成必须解决的问题。
  - ← 提供理由：（148–180）「说成软弱」
- → 他终于喘过一口气，心里短暂安静下来，却已知道这份安静不会久留。
- ⟲ 仍在起作用：（148–180）「疲惫也暂时淡了」

### S09｜214–215 小节　（正在面对）

- 先前的难处还在，他又拿不定主意。
  - ← 唤起：（206–213）「不会久留」
- → 这回他知道，自己怕往前又把自己逼得太狠，也舍不得那种不必防备的生活。
  - ← 提供理由：（116–147）「不能示弱」
  - ← 提供理由：（148–180）「说成软弱」
- ⟲ 仍在起作用：（181–205）「理由和顾虑」；（148–180）「不必靠争抢」

### S10｜216–225 小节　（正在面对）

- 他知道自己舍不得那种生活，却想不出怎样护住它，光是知道仍提不起劲去争取。
  - ← 限制：（214–215）「不必防备的生活」
- 那一步曾让他从无力里动起来，那份安宁也确实让他缓过来。
  - ← 说明：（24–65）「仍犯嘀咕」
  - ← 说明：（148–180）「疲惫也暂时淡了」
- → 可妨碍那种生活的事还在，光靠行动或怀念都不能替他把它护住。
  - ← 限制：（181–205）「当初不肯再等」
- → 他不想一争取就忘了最初要护住什么，也不想一安宁下来就把眼前的威胁抛开。
  - ← 提供理由：（181–205）「当初不肯再等」
- → 他还不知道怎么兼顾，却发现不必先把其中一边说成错，逼自己立刻选边的劲才松了一点。

### S11｜226–241 小节　（正在面对）

- 他心里仍没底，开始重新想眼前还能承担什么。
  - ← 提供理由：（216–225）「选边的劲」
- → 他记得接下那一步后确实有了力气，可牵挂并没跟着消失。
  - ← 说明：（24–65）「仍犯嘀咕」
- 那种不用时时防备的生活仍能安慰他，可光把它留在心里，挡不住眼前妨碍它的事。
  - ← 说明：（148–180）「疲惫也暂时淡了」
  - ← 限制：（181–205）「当初不肯再等」
- → 他又想怪自己不够坚定，可两边都舍不得，偏顾一边就可能伤到另一边。
  - ← 提供理由：（24–65）「仍犯嘀咕」
  - ← 提供理由：（148–180）「疲惫也暂时淡了」
- → 他心疼争取的代价，也盼着有条少伤一点的路。
- → 他还是怕，也舍不得，却不再等到完全不怕才肯动，先接下眼前该做的事。
  - ← 提供理由：（24–65）「仍犯嘀咕」
- ⟲ 仍在起作用：（181–205）「磨掉温柔」

### S12｜242–253 小节　（正在面对）

- 他没再等一个不会伤到任何东西的办法，接着做眼前的事，久违的劲头又回来了。
  - ← 提供理由：（226–241）「接下眼前该做的事」
- → 他只管把眼前能做的做好，不再逼自己每次努力都得把事情扭转过来。
  - ← 限制：（226–241）「有了力气」
- → 他舍不得那种生活，也不想放下眼前该做的事，怕顾住这头就伤了那头，心里没底也继续往前。
  - ← 提供理由：（226–241）「两边都舍不得」
- → 那份担心又冒出来，他心里晃了一下。
  - ← 动摇：（226–241）「接下眼前该做的事」

### S13｜254–288 小节　（正在面对）

- 带着对那种不必防备的生活的牵挂往前，他反倒觉得它近了些，舍不得它也让他愿意担起眼前的事。
  - ← 提供理由：（242–253）「舍不得那种生活」
  - ← 提供理由：（226–241）「两边都舍不得」
- → 从前一想到那种生活，他就想退回安宁，仿佛不争取便能保住它。如今他愿为它离开安宁去做事。
  - ← 改写：（226–241）「少伤一点的路」
  - ← 提供理由：（226–241）「挡不住眼前妨碍」
  - ← 提供理由：（148–180）「不必靠争抢」
  - ← 提供理由：（181–205）「当初不肯再等」
- → 他知道再拼命也未必换得回那种生活，若只凭舍不得一味硬撑，反会耗掉他想护住的温柔。
  - ← 改写：（181–205）「磨掉温柔」
  - ← 限制：（242–253）「把事情扭转」
- → 担起眼前的事时，他仍肯承认自己舍不得那种亲近，不再把这份依恋当成软弱。
  - ← 改写：（116–147）「会心软」
  - ← 提供理由：（226–241）「两边都舍不得」
- → 他又尝到最初相信生活时的高兴。走过怀疑和疲惫，他更珍惜它，不拿它当作事情会好的保证。
  - ← 唤起：（148–180）「疲惫也暂时淡了」
  - ← 提供理由：（116–147）「不能示弱」
  - ← 限制：（181–205）「理由和顾虑」
- → 那种生活还没回来，努力能改变多少仍说不准。愿望未成，他也不把过去的安宁说成假的。
  - ← 限制：（92–115）「带不回熟悉的亲近」
  - ← 说明：（148–180）「这份满足」
- → 他知道自己还会累，代价真摆到眼前时，也可能又想退回安宁。
  - ← 提供理由：（116–147）「不能示弱」
- → 兴奋退下去，他终于能松口气。心里仍有疑问，他却不再等每个疑问都有答案才肯向前。
  - ← 改写：（1–23）「想透才肯动」
- ⟲ 仍在起作用：（226–241）「少伤一点的路」；（242–253）「久违的劲头」
