**（1—23）**

**我刚知道自己想要什么，就又开始替不选找理由，连自己都不敢信。**

← 因为每个选择的反面都有道理，我分不清自己还没想透，还是想透了却不敢认。

→ 于是我一有疑问就推翻自己，迟迟不敢做主。

**（24—65）**

**我终于敢说“我就要这个”，心里踏实了，却又怕自己变回那个反复改主意的人。**

← 因为前面的摇摆让我渴望果断，我开始急着证明自己已经改变。

→ 于是我不许自己改口，连坚定都成了对自己的考验。

**（66—91）**

**我开始发现，顾虑别人、怕伤到人，也确实是我的一部分。**

← 因为我把坚定逼成了不准动摇，开始担心自己连心软都得压下去。

→ 于是那份昂扬有了阴影，我开始怀疑自己是不是在硬撑。

**（92—115）**

**我还是坚持原来的决定，可那些顾虑并没有消失。**

← 因为我知道一直想下去就会卡住，也不愿假装自己毫不在意。

→ 于是我只能带着犹豫往前走，也不再把所有犹豫都归为软弱。

**（116—147）**

**我终于承认，自己想做主，也想有人懂我，累了能靠一下。**

← 因为先前的坚持没能消除不安，我开始看见自己需要支持的那一面。

→ 于是我慢慢听懂了自己在怕什么，却还不知道该怎么选。

**（148—180）**

**我以为把心里的话说清就能安心，结果每件在意的事都还在拉扯我。**

← 因为我既想顾及别人、把事情想周全，又不想总让步或一直拖着。

→ 于是我看清选与不选都会有损失，想明白之后还是得自己取舍。

**（181—205）**

**我还是得选，哪怕知道自己可能后悔，也舍不得放下别的可能。**

← 因为我已经看见拖延也有代价，不能再拿每一种风险当作观望的理由。

→ 于是我开始接受自己可能后悔，却又忍不住怀疑这样算不算坚定。

**（206—213）**

**刚下定决心，“可是”又来了，我不想赶走它，也不能再任它推翻决定。**

← 因为我依然会心疼别人、想被理解，这些感受不会随着决心消失。

→ 于是我得带着不安继续走，不再等心里的声音全都安静下来。

**（214—215）**

**我又摇摆了，但这回我知道自己想要什么，也知道会舍不得什么。**

← 因为先前的决心没有让心里的拉扯彻底停下。

→ 于是我开始面对一个更具体的问题：我敢不敢认下这个选择？

**（216—225）**

**我不再等到百分之百确定，哪怕只剩一句“我还是想试试”，也肯说出来。**

← 因为我已经能看见自己的心愿，想到另一条路时也不再立刻否定自己。

→ 于是我开始迈步，虽然还会发抖，却不再抹掉自己的那点心愿。

**（226—241）**

**我不再忙着判断自己够不够坚定，只问选了之后愿不愿负责。**

← 因为我知道自己还会看见别的路、害怕后悔，却不能一直拿这些拖延。

→ 于是我带着心里的争吵开始行动，不再让决定一直悬着。

**（242—253）**

**我终于能说清自己为什么选，也承认自己仍然会怕、仍然在乎别人。**

← 因为我看见强硬曾帮我迈步，心软也让我顾及别人，却有时让我迟迟不动。

→ 于是我不必先认定哪一面错了，才肯为自己的决定负责。

**（254—288）**

**我知道以后还会摇摆，却不再因为动摇就认定之前的努力全白费。**

← 因为果断让我尝过行动的踏实，硬撑提醒我听见自己的感受，心软和拖延也各有代价。

→ 于是我开始练习每次怀疑回来，都重新想清自己要什么、怕伤到谁、愿意付出什么代价，再带着矛盾做主。
