**这件事：一个人怎么从想亲近别人又怕丢了自己，走到能珍惜亲密、继续成长，也享受已经得到的满足，并接受这些需要不总能协调。**

**1–3**

**你想有人靠近、回应你，又怕为了留住对方把自己弄丢；连自己究竟要什么都还没弄清。**

**4–16**

**你开始相信，亲密里也能保有各自的声音；被对方回应，让你安心了一点。**

← 因为：1–3里你同时想靠近、被回应、保有自己，这种双方都能表达的关系刚好接住了几种愿望。

↺ 原以为这些愿望还不知道能不能兼顾，现在亲身发现它们至少能暂时共存。

→ 于是：你愿意信任这段关系，却还不知道它遇到变化时会怎样。

**17–23**

**你珍惜这份靠近，却开始担心你们只是当下合拍，还没真的懂得彼此。**

← 因为：4–16的相互回应给了你信任；1–3里不敢把所有希望押在同一个答案上的顾虑也一直在。

↺ 原以为彼此能回应就足以让你放心，现在你开始追问这份回应为什么发生、能维持多久。

→ 于是：你检查这份信任有没有根据，也不愿抹掉曾经的快乐。

**24–34**

**你不想因为没把握就否认那段亲密，也开始放下让它解决所有问题的期待。**

← 因为：4–16的相互回应真实发生过；17–23让你看见它没有长久保证；1–3里几种愿望也一直没分清。

↺ 原以为亲密若不能长久就难以安心，现在愿意珍惜它曾给你的满足，也承认它有自己的边界。

→ 于是：你开始问，亲密之外还有什么需要一直没被照顾。

**35–39**

**你发现自己想守住安稳，也还想成长，看看生活有没有别的可能。**

← 因为：1–3里本来就有多种愿望；4–16的亲密给过你真实满足；24–34让你承认它有边界，才有空间看见其他需要。

↺ 原以为把这段关系守好就能安顿自己，现在发现不能为了安稳把成长压下去。

→ 于是：你准备往熟悉的生活之外走一点。

**40–50**

**你想主动做点事、让自己更有力量，也怕自己一变，原来安心的关系就跟着变。**

← 因为：35–39让成长显出为独立需要；4–16的相互回应给过你安全感；24–34也让你知道这份亲密值得珍惜。

↺ 原以为只要确认自己有没有被在乎就行，现在还得考虑怎样成长，以及关系可能要承受什么变化。

→ 于是：你期待未来，也担心会不会失去现在。

**51–61**

**你确认自己是真的想成长，可你也舍不得那段曾经接住你的亲密。**

← 因为：40–50里成长带来活力，也带来关系焦虑；35–39提醒你只守安稳会压低自己；4–16和24–34证明亲密有真实价值，也有边界。

↺ 原以为向前只是新鲜冲动，或许能替你解开旧问题，现在确认成长是持久需要，却没法独自解决亲密与自由的拉扯。

→ 于是：你开始找一种能同时容纳两种需要的过法，不再逼自己选边。

**62–71**

**你想练习好好享受已经得到的充实，不想每有收获就马上给自己加个目标。**

← 因为：40–50的成长已经带来真实充实；51–61确认它经得起反复思量，无须靠不停追逐来证明；24–34让你知道有限的满足也有价值；35–39则提醒你别让向前变成新的惯性。

↺ 原以为满足主要来自继续向前，现在发现停下来、充分体验所得，也能让自己感到满足。

→ 于是：你开始分辨自己还有重要的东西没得到，还是只是不习惯承认眼前的幸福。

**72–77**

**亲密、成长、安静享受已有的一切都让你满足过，可你还是不知道怎么把它们放进同一种生活。**

← 因为：1–3里混在一起的愿望渐渐分开；4–16证明亲密能满足你；40–50证明成长也能满足你；51–61让你确认两者都不能轻易舍弃；62–71又让你体验到享受所得本身也有价值。

↺ 原以为自己还得追求更多，现在发现难处在于几种真实满足怎样共处，继续增加任何一种也未必能解决它们的拉扯。

→ 于是：你开始问，怎样让这些需要都成为自己生活的一部分。

**78–83**

**你已经知道自己卡在几种需要的拉扯里，却还想不出怎么安排它们。**

← 因为：72–77把问题从“还缺什么”推进到“怎样共处”；51–61早已说明选掉一边会伤到另一边；17–23也让你见过追问不一定马上有保证；62–71则让你练习不把每个不圆满都变成新目标。

↺ 原以为继续分析就能找到让自己彻底安心的答案，现在承认看懂冲突还不能让自己立刻承受它，暂时无解也能继续生活。

→ 于是：你先不随便否定任何一种需要，也不逼自己立刻答出来。

**84–92**

**你又回到亲密这件事上，想知道对方能不能接纳一个还在变化、不会停在原处的你。**

← 因为：4–16的亲密曾让你相信彼此能保有自己；24–34让你承认它真实却有限；35–39和40–50让成长成为不能压下的需要，也暴露关系平衡可能改变；78–83提醒你，光看清矛盾还不够，得在具体关系里面对它。

↺ 原以为自然的相互回应就足以让你信任，现在还要看关系能否容纳你的成长，而不要求你把自己缩小。

→ 于是：你不急着放弃这份亲密，却也不能再假装这个问题不存在。

**93–102**

**你开始想，也许自己成长得更充实，反而能给这段亲密带来更多东西。**

← 因为：4–16让你知道靠近时能保有自己的声音；40–50让你亲身尝到成长的充实；51–61确认两种需要都不能随便取消；62–71让你学会享受成长所得；72–77把问题变成如何让几种满足共同生活；84–92又让你检验关系能否接纳变化。

↺ 原以为认真成长会把自己带离这段关系，现在开始看到，成长也可能成为亲密的一部分。

→ 于是：两种满足开始有了共存的可能，但你还不知道它们能不能长久协调。

**103–110**

**即使亲密和成长眼下合得来，你也不敢把这一刻当成以后都顺利的保证。**

← 因为：17–23提醒你一次真实的靠近无法保证长久理解；24–34让你珍惜有限的真实；35–39让成长显出为不能压下的需要；40–50里的成长一直伴着不安；51–61让你确认成长经得起反复思量；62–71让你分辨真实欠缺和追逐惯性；84–92让你拒绝把旧日回应当成无条件保证；93–102刚让亲密与成长出现融合的可能。

↺ 原以为两种需要能相容，问题就会安定下来，现在知道一时融合无法保证以后没有冲突，重要的愿望也未必要一直强烈才算数。

→ 于是：你重新辨认哪些满足已经得到、哪些愿望仍得保留；不安再来时，也不把以前的努力全盘否定。

**111–116**

**你终于能承认，亲密给过你安稳，成长也确实重要，眼下已经得到的东西值得享受；还有愿望没实现，也可以先放在那里。**

← 因为：1–3里混在一起的愿望一路被分辨；24–34让你承认有限的亲密仍真实；35–39让你不再压下成长；51–61确认亲密与成长都不能被另一边取消；62–71让你分辨欠缺和追逐惯性；72–77指出难处在几种需要如何共处；78–83让你允许暂时无解；93–102证明亲密与成长能初步相容；103–110又提醒你，这种相容不会永远消除冲突。

↺ 原以为不断确认、不断追求，终能找到一个安顿所有愿望的答案，现在承认每种需要都有自己的价值和边界，任何一种满足都没法把其他需要一并照顾好。

→ 于是：你可以继续寻找，照顾还没实现的愿望，也认真享受已经得到的；以后再有拉扯时，不必推翻以前的满足，也不用逼自己马上追求更多。
