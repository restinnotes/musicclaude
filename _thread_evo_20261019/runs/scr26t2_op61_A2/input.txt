下面是同一首器乐作品的几条 Thread 人物经历候选。

你完全看不到珠子，也不依据音乐局部细节选择路线。

你的任务是选出最有可能写成一条独立成立、持续发展、简洁自然、像真实人物经历的 Thread 的候选。

【首先把每条路线连起来读】

暂时忽略 delta_type、depends_on 和 established 等字段，先按顺序只读 situation 与各段 state。

把它当作一个人从头到尾经历的一件事，判断：

- 能否一直看出他真正牵挂什么，为什么会有眼前的感受？
- 前面的经历是否留在后面，改变了他后来对同一处境的体验？
- 不同阶段是否各有实际内容，而不是换着说法解释同一个心理问题？
- 有没有把人物自我调整、检查效果、再次调整当作整条经历的主要发动机，使本来丰富的处境被缩成一套心理办法？
- 人物是否既有具体可懂的所求和顾虑，也有不以新认识或新决定为目的的亲身体验？

真正的发展可以是已有经历的积累、不同侧面的显现、旧有感受的新分量、已成立选择的后果，或者尚未解决的事继续牵动他。

不按转折次数评分，不因为某段只是持续感受或暂时没在想就扣分，也不要求结尾解决问题。

【再核对关键事实及其依据】

找出支撑后续多个段落的重要认识、愿望、选择或事实，尤其注意那些一旦抽掉、后半篇便无法成立的内容。

逐项核对：

1. 这项内容最初是如何成立的？
2. 更早的 state 是否真的提供了依据，而不只是有相近的情绪或主题？
3. 人物知道的事实、对亲历的理解、尚不确定的猜测，是否受到明确区分？
4. 有没有把意向当成已经实行的结果，把预期当成已经发生的事情，或者把未经交代的现实变化当作后文的事实基础？
5. 有没有用笼统的表述代替必要的事实来源？
6. 后文是否重新发明此前未成立的动机、经历或他人的反应？

established、delta 和 depends_on 是记录，不是证明。必须回到 state 实际内容检查。

某项新认识有合理前因，并不自动使这条路线成为优秀经历；还要看整条线是否只剩一次次认识的建立和检验。

【比较人物经历的质量】

- 单独成立：不看音乐和珠子，能否理解整件事的来由及其发展？
- 前进：先前经历怎样持续影响后面？是否有实际积累，而不是只靠情绪变强或反复作出决定？
- 前提完整：重要事实和认识有无可靠来源，特别是后半篇的关键支点？
- 不重复：区分必要的延续与重新发现旧结论、重新作出旧选择、重新解释旧处境。
- 像真人：人物想要和顾虑的东西是否具体可懂？他的感受是否属于真实的个人处境，而不是在讲解自己的心理机制？

允许一件事包含矛盾、反复、犹豫和未解决的问题，不把这些自动判成缺点。

但一条路线若主要靠人物反复评估自己的做法来维持，就算每个步骤都能找到前因，也应当考虑它是否把生活经历缩窄了。

同样，一条路线虽然语言具体、情绪丰富，如果关键发展建立在未经交代的事实之上，也不能排在前面。

【输出】

对每条路线分别给出：

- coherence：1–10，整件事独立成立和自然连贯的程度
- forward_motion：1–10，已有经历如何积累及改变后续处境，不衡量转折数量
- prerequisite_integrity：1–10，重要事实和认识的实际依据强度
- non_repetition：1–10，是否避免重新解释或完成同一变化
- human_plausibility：1–10，所求、顾虑、感受是否具体自然，且不靠无来源的现实事实支撑
- 主要问题：指出影响整条经历成立的实质问题，尤其说明重要发展是否靠心理办法循环或缺少根据的事实推动

选出最多 3 条进入下一步，按优先顺序排列。可以少选，不必凑满。

优先选择无需后续补造事实、能自然容纳不同生活感受、前后经历有真实积累的路线。

不要修改候选，不补写前因，不设计最终文案。

沿用原有 JSON 输出字段和结构。

只输出 JSON。
