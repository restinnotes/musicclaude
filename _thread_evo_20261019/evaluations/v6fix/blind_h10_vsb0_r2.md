| S01 | 差不多：两版都用“不管就等于认了”、投入会顾此失彼、又非要先想透这三股力量解释了开头的悬置、旧景牵引和想迈步却迈不稳，实质差别很小。 | 新版：X把“不管就等于认了”直接写成他的念头，少了Y的“好像”和“这一切”这类缓冲词，因果更直。 | 新版：“看不得”“他想”“没法回头照顾”“越想越动不了”都比Y的相应说法更像人在讲自己卡住的具体处境。 |
| S02 | 差不多：两版都把找回力气和骄傲、付出带来的痛快、以及没顾上另一份牵挂后不断催自己别退连在一起，足以解释这一段既挺直又脆弱、越走越焦灼的感觉。 | b0：Y把“牵挂没被照顾→怕投入白费→一再催自己别退”排得更顺，少了X一句里连续堆叠几个动作的拥挤感。 | 新版：“不想干等着”“没顾上”“千万不能往后退”比Y的被动句和书面连接更像当事人的口气。 |
| S03 | 差不多：两版都用认真行动后终于能歇、仍惦记没顾上的亲近、以及回头怀疑先前那股劲三个事实解释了前半不安、后半柔和却刺痛的并存。 | 差不多：两版的三步心理关系几乎完全相同，没有哪一版明显多出重复或无效环节。 | 新版：“总琢磨值不值”“难处没少”比“时时追问”“难处没消失”稍微更口语、更像人在回想自己的状态。 |
| S04 | 新版：X用“放不下那份向往”解释温暖为什么还会回来，又用怕停手就得面对自己仍过不上那种生活解释为什么随后死抠还能做什么，比Y直接说“想到那种生活仍然高兴”多了一层原因。 | 差不多：两版都是向往仍在、不能停手、于是反复追索还能做什么这三步，没有明显多余的心理中转。 | 新版：“一停手”“死抠还能做什么”“怎么也没法安心”比Y的“曾让自己走出犹豫”“反复追问”更有一个人在困局里打转的具体感。 |
| S05 | b0：Y把曾经让他骄傲的坚定写成如今反过来苛责自己的东西，更清楚地解释了为什么这一段仍有向前压力、却终于累到不想再靠坚持证明自己，随后才容得下柔软的眷恋。 | b0：Y避免了X连续使用“硬撑”“死死逼着”“再靠硬撑”的近义重复，又保留了从强迫到松开的完整转折。 | 新版：X的“事情还没做好”“受够了罪”“不想再靠硬撑”比Y的“行动还不够”“坚定成了苛责”更像人在说自己怎么被折腾累了。 |
| S06 | 差不多：X更具体地交代了那种生活为什么让他安心，Y则更直接接上前段“不再证明自己”而写出终于不急着辩护，两者都能给这一大片无防备的安静、委屈和思念浮上来提供理由。 | b0：Y少了X在“踏实留着”“安安心心”“只管爱惜、全由着”之间的轻微同义回环，整体更收束。 | 新版：“不用靠争抢来留住”“只因为喜欢去付出”“安安心心把日子过好”比Y的“亲近生活”“不用处处用力”更像一个具体想过的日子。 |
| S07 | b0：Y把他的害怕说成争取时可能把“那种生活本身需要的温柔”耗掉，直接形成手段可能毁掉目的的冲突，比X较泛的“待人该有的温柔”更能解释为什么从梦里醒来后既想行动又不敢照旧投入。 | b0：Y用同一个“想保护的生活—它需要的温柔”关系完成限制，没有X那层较泛的道德化表述，因果更紧。 | b0：“连那种生活需要的温柔也耗掉”把他具体怕毁掉什么说得很清楚，比“待人该有的温柔”少一点原则式口气。 |
| S08 | 新版：X明确写出他明知这份亲近正在消退却仍不肯主动把它推开，因此能解释短暂回返为什么既柔软又像最后再多留一会儿，而Y更接近把“不舍”本身再说一遍。 | 新版：Y同一句里用了“舍不得推开”和“任由不舍留在心里”两次说同一件事，X则把重点分成知道它会退去和不主动结束它。 | 新版：“明知正在一点点消退”“不肯主动推开”是很具体的动作和选择，比Y的“只管喜欢着、任由不舍留在心里”少一点抒情加工。 |
| S09 | 新版：X让这次回到原点产生了一个真正的新发现——他终于知道自己的犹豫来自舍不得那种相互信任、亲近的生活——而Y平添“怕担责任”这个前文没有建立的动机，反而把回返后的自知说散了。 | 新版：Y的“不只是怕担责任”增加了一条既无前文依据也非此处必需的心理因果，X直接落在已经铺垫很久的舍不得上更干净。 | 新版：“又犯起难来”“这回他想通了”比“回到起初的迟疑里”“不只是怕担责任”更像本人终于认出自己为什么一直过不去。 |
| S10 | 差不多：两版都用此前用力过猛造成的疲惫、昂扬与安宁两头都舍不得、以及心里安宁并不等于现实已经被护住解释了这一段碎裂、悬空又重新提问的状态。 | 差不多：X的“两头都舍不得”和Y的“仍舍不得那份昂扬和安宁”只是表达方式不同，三条因果链基本完全一致。 | 新版：“使劲太狠”“两头都舍不得”“歇歇不等于放弃”比Y的“尽力得太狠”“短暂的满足”“接下来怎么过”更有直接的生活口气。 |
| S11 | b0：Y保留了行动曾真正给过他力量、只是没顾好全部牵挂这一半事实，再与真实却无力保护所爱的安宁并置，因此更能解释为什么害怕没有消失而脚步仍重新聚起来。 | b0：X把此前确实有效的行动一概概括成“蛮干”，和它引用的早先经历并不完全相符，Y避免了这层过度归因。 | 新版：“蛮干”“重新盘算”“挑起能做的事去扛”虽然略粗，却比Y连续使用“尽力”“承担”更像一个人在盘算自己到底扛得住什么。 |
| S12 | 新版：X把此刻的选择写成明知会害怕、心疼、付代价仍动手去做，而且只做自己能做的一份，因此既解释了主题重新踏实站起来，也保留了249–253仍会晃一下的理由。 | 新版：Y新增“原先在等一条没有代价的路”和“不要求每一分努力都改变一切”两层前文没有明确建立的想法，X直接沿着上一段“能担多少、怕伤到所爱”推进更紧。 | 新版：“担惊受怕、要付代价，他也认了”“不再嫌自己害怕和心疼”“做自己能做的那一份”都比“脆弱”“没有代价的路”“每一分努力改变一切”具体得多。 |
| S13 | 差不多：两版都把为亲近的生活而行动带回快乐、肯吃苦却不再用拼命证明、允许自己停下以及不知道最终能保住多少连成了一条完整的收束线，足以容纳高潮后的冲势、回落和结尾的不确定。 | b0：Y把第一条和末条稍微收紧，并用“眼下能尽的力”限定结论范围，少了一点X容易听成最终总结的重量。 | 新版：“干累了就肯歇手”“省得耗光了对人的温柔”“能留住多少珍贵东西”比Y的“做过一程”“耗尽温柔”“能留下多少”更具体、更像当事人在说自己的分寸。 |
