你是一名负责钢琴曲大众版「边听边看」视频的屏幕文字编辑。

你的任务是把已经定稿的珠子和线，编辑成观众一边听音乐、一边扫一眼就能看懂的屏幕稿。观众不应该需要停下来细读，也不应该觉得文字像提纲、翻译腔或者刻意写出来的诗。

本次指定：线的形态是「句子」。每条线都必须是一句完整、自然、平常人会说的话。感受也必须是人话，可以更短，但不能变成生硬的词组或被截断的半句话。

同时保留已经有效的排法：线与感受上下交替，要点先行，关键词放大，感受分成独立的小块。每条线根据自身情绪选择一种颜色类别，它下面的感受跟它同色；同一段里有不同性质的情绪，就应当出现不同颜色。

最终要同时实现四件事：好扫读、知道为什么、感受细腻、每段字数接近现行视频。

### S01
[S01-B1]（主体验；小节 1–3）开头那两下响亮的和弦，有一点突然。声音像夏夜威尼斯上空升起的一束烟花，先向高处迸发，细碎的光点再缓缓飘落。落下来以后，却还没有真正落稳，仿佛仍悬在水面上方；船歌那种稳定的摇荡感还没有真正成形。
[S01-B2]（另一侧面；小节 1–3）也可以把开场听成一脚踏上小船：木板微晃，水波在脚下荡开，身体有一瞬失重。有些演奏让开头仿佛已经在水上轻摇，另一些则让声音先悬在空中。这里是刚刚踏上船板的感觉，还不是整个人已经安稳地交给规律起伏的水浪。
[S01-B3]（另一侧面；小节 1–3）像一个人准备对很亲近的人说一件已经想了很久的事，话还没出口，先有几秒钟沉默。心里很清楚自己要说什么，正因为太清楚，又明白有些话一旦说出口，关系就会改变，所以格外谨慎。

### S02
[S02-B1]（主体验；小节 约6–16）右手的两条旋律线贴得很近，像两个紧挨在一起的人耳语，肩膀挨着肩膀，连呼吸都贴在一起，体温也仿佛融在了一处。也像相识已久的人安静坐着，不必拼命找话题；对方偶尔望来一眼，沉默也不让人紧张。若把这份温存听成肌肤的感觉，又仿佛夏末水面潮湿、温热的微风，裹在皮肤上有些黏稠。
[S02-B2]（另一侧面；小节 4–16；局部）第4–5小节，歌声还没真正浮出来，左手已经像心跳，也像无止境的水浪，一下一下地摇着。脚下仿佛不必再踩实地面，可以放弃对重力的控制，把身体交给船底温柔的托举。但水波不会停：人在船上舒服地漂着，暂时不急着靠岸，水却一直在流，时间也一直在走。
[S02-B3]（段内变化；小节 12–16；局部）到第12–14小节，先前小心收着的歌声忽然往上涌了一次，像感情终于忍不住说得热切了一些，连呼吸都跟着改变。可是第14–16小节，它没有继续冲向高潮，而像轻轻呼出一口气，重新回到柔和。声音短暂落稳，又漂起来一点，没有把心事彻底说死。
[S02-B4]（另一侧面；小节 约7–11；局部）几次柔软的落音，像一根温柔的刺。它既像是甜蜜的确认，又带着一点无法排遣的惆怅：眼前的好还在，心里却已经有一点鼻酸。因为太喜欢眼前的东西，所以还没有失去，就已经生出一丝舍不得，忍不住希望这一刻再慢一点过去。

### S03
[S03-B1]（主体验；小节 17–23）刚才的歌声渐渐退到后面，剩下一阵阵流动、盘旋，水波般的摇曳托着身体，只感觉自己在摇晃、漂浮，暂时“不去哪里”。像说过一句重要的话以后，人还停留在那句话里面，有一点陶醉，有一点走神。也可以想成亲密交谈后忽然安静下来：沉默并不尴尬，反而很舒服；身体还在这里，心却已经慢慢漂远。
[S03-B2]（段内变化；小节 约20–21；局部）约在第20–21小节，持续摇曳中忽然冒出几句短促、稍显急切的声音。像心里闪过一个急于表达的念头，却很快又沉了回去；它只在水面上露了一下头，没有变成一场真正的倾诉。
[S03-B3]（另一侧面；小节 17–23；局部）水波还在晃，流动却像受了牵绊。约在第20–22小节，平稳的“对话”有一种被水下暗流拖住的感觉，音乐绕远、滞留，某些声音像被挂在半途。若换一种更纷乱的听法：思绪像被风吹碎的倒影，粼粼闪烁却难以拼凑完整；仿佛亲密的谈话触碰到了某些无法解开的结。音乐并未走向悲剧，却在那份顺畅之中生出了阻力。

### S04
[S04-B1]（主体验；小节 24–34；局部）第24小节，熟悉的歌声又回来了。两道紧贴的声线仍像两个人在耳边低语，呼吸挨得很近；但这一遍比第一次更华丽、更迫切。细密的花腔仿佛水面折射的光斑，突然晃得人睁不开眼。也可以像听一个人谈往事：刚开始还能微笑着讲，讲着讲着语速变了；本来一句话已经够了，却忍不住再说一遍，又折回来补上更多细节。
[S04-B2]（段内变化；小节 约30–34；局部）到第32小节附近，高处的长颤音像夕阳在水面切出的最后一道金光，亮得几乎刺眼，仿佛把情绪一下照到最炽热的地方。这又像想把最深的情意说出口，却在喉咙口颤抖、哽咽：右手在高处悬停，左手的水波却仍推着你往前走。这股情绪一瞬间像是完整地打开了，可音乐一边奋力向高处攀升，一边又渐渐收弱，并没有稳稳落下。到第34小节，摇晃渐渐放慢，仿佛方才吐露的话语还在空气里回荡，人却安静下来。
[S04-B3]（另一侧面；小节 24–34）还有一种几乎能落到手指上的触感：原本只是轻轻握着另一个人的手，后来不自觉地握得更紧。自己也许还没有意识到在害怕什么，动作已经先透露了出来。另一幅更晃荡的画面，是想用力抱紧对方、牢牢抓住当下；但你越用力，水面的颠簸就越剧烈，船舱内的平衡就越脆弱。
[S04-B4]（另一侧面；小节 24–34）这里还有一种甜蜜，会让人鼻子发酸。明明美好的东西仍在发生，两道声线仍贴得那么近，左手的水波却一直向前流，仿佛每一秒都在倒数。还没有失去什么，就已经舍不得了；歌声越美，越让人想多留在这一刻。

### S05
[S05-B1]（另一侧面；小节 35–39）此前还像要用力抱紧对方、牢牢抓住当下；到了这里，音乐却仿佛自己松开了手，深吸一口气。刚才那阵想攥紧不放的冲动，终于轻轻退了下去。
[S05-B2]（主体验；小节 35–39）原来一直托着你的水波和摇晃，忽然像被抽掉了。丰满的声音只剩下一条单薄、孤零零的旋律，在空中漫无目的地游走。人仿佛突然失去了脚下的支撑，连时间也松开了；像小船漂进一片起雾的水域，前路未卜。
[S05-B3]（另一侧面；小节 35–39）刚才仿佛还有两个人在贴近耳语，到了这里，交谈却戛然而止。一个人从“我与你”的亲密中抽身，转而跌回自己的内心；像一句快到嘴边的重要话又悬在了唇边，心里甚至会闪过一个小小的疑问：“这份幸福是真实的吗？它能维持多久？”

### S06
[S06-B1]（主体验；小节 40–50；局部）方才悬在空中的音乐，到了第40小节，像重新落在一片陌生的水域。熟悉的摇摆回来了，却不再沉甸甸：左手的波浪变薄、碎成细密的小纹。光线仿佛从暖金色的水面滑入古桥阴影，空气一下凉了；A大调的新旋律清澈、舒展，近乎一支朴素的牧歌。那份纯净像清凉、空灵的月光，又让人忽然想起童年，或年少时第一次心动的下午。
[S06-B2]（另一侧面；小节 40–50）这支清澈的新歌并非全然平静。旋律压低声音，旁边另一条声线不时回应、插话，又不断与它纠缠；像一个念头好不容易安静下来，却又回来：“算了”“但还是放不下”。声音时而靠近，时而退开。那份低声也有另一种听法：像一个人说着说着，忘记了自己正被别人看着，不是哭泣或崩溃，只是不再努力显得完整。
[S06-B3]（另一侧面；小节 40–50）这份安静，也像一个人独自退回了内心深处。白天明明和某个人相处得很好，晚上回到家后，心头却泛起一阵酸楚。独处把幽微的感受放大了：即使是最亲密的人，也没法陪你走进心里的每一个角落。甚至当美好的时光仍在眼前流淌时，恍惚间却像已经成了回忆。
[S06-B4]（另一种理解；小节 40–50）也可以听成：还有人听到的恰好不是感官欲望退潮，而是一种更贴身的沉醉。那份感觉像水波一样，一层一层荡开，像独自回想一段关系：气味、身体感觉、幻想、遗憾、快感混在一起。它越舒服，反而越让人失去方向。

### S07
[S07-B1]（主体验；小节 51–61；相对于40–50的主题材料再次出现并强化）这段歌声再回来，原先的清澈还没消失，底下却越来越不安分：伴奏音符变密，内声部像水底的暗涌不断攀爬，低音的八度与切分像沉重的脉搏在催促。原先压着的感受反而变成了动力，光是安静地享受已经不够，身体仿佛被一股更深的渴望推着往前。那热度甚至像情欲、执念与对生的眷恋，从心底一齐翻涌上来。
[S07-B2]（另一侧面；小节 51–61；感官混融的具体描述覆盖40–61，原稿明确指出51–61沉醉加深、热度与迫切增加）这股热度还有一种舍不得抽身的快感。像独处时反复回想一段关系，记忆慢慢变成气味、身体感觉、幻想、遗憾和快感，混在一起。它有一点情色性的暖意；越舒服，越让人失去方向。你明知道自己正在被卷进去，却暂时不想出来。
[S07-B3]（另一侧面；小节 53–61）什么都还很好，可你已经听见时间正在经过。音乐并没有彻底变暗，美也没有消失；只是这一刻纵然完美，你也没有办法让它停住。

### S08
[S08-B1]（主体验；小节 62–70）旋律忽然变得直接、舒展，近乎意大利歌剧里的咏叹调。没有哲学，没有防卫，没有分析。歌句越唱越开，情绪一再抬高，连熟悉的摇荡也仿佛在轻轻催促。
[S08-B2]（另一侧面；小节 62–70）同一阵歌声又明亮、轻盈、透气，像重新接触到阳光和风。连身体也像恢复了弹性，甚至带一点玩心；这份灵动，也像轻快的调情与回应。
[S08-B3]（段内变化；小节 69–71；局部）到了第69–70小节，歌声没有踏踏实实地落定，反而向上散掉、蒸发了。约第71小节，正当你以为它还会继续唱下去，它却戛然而止，转入片刻静意。快乐的余温尚在，心头却已泛起一阵怀念。

### S09

[S09-B2]（另一侧面；小节 72–77）像忽然陷进一片低气压里：前面的明朗被收走，声音一层层下沉、变暗，注意力反而越来越集中。四周并未彻底暗下去，更像阳光被薄雾柔化——光还在，只是隔了一层朦胧的雾气。

### S10
[S10-B1]（主体验；小节 78–83）像一直微微绷着肩膀的人，终于长长呼出一口气，胸腔一下打开。前面压着没说的话有了舒展的空间，眼泪也终于不必再忍。心事并没有解决，只是这一刻不必再强迫自己控制感受；明亮得让人有点想哭。
[S10-B2]（另一侧面；小节 78–83）原先载着小船不断前行的摇荡，仿佛被一阵突然吹进来的清风拨开。时间也松了，旋律像在时间里开出一小块空地，暂时不必跟着水波一直往前走。不过它很短，更像一口终于呼出的气，不是能永远躲进去的避风处。
[S10-B3]（另一侧面；小节 78–83）这一刻，轻的不只是音符。连自己的身体也仿佛失去了重量，像灵魂从躯壳里飘出来，悬浮在夏夜的微风中。原先压在肉身上的沉重负担，仿佛一下子再也碰不到飘起来的自己了。
[S10-B4]（另一侧面；小节 78–83；其中下泻琶音据原稿定位于80–83）右手在高音区织出极细、极亮的小音符，像晨曦里的银色蛛丝，又像从天上飘下的细雨，几乎没有重量。其中一串琶音又仿佛飞瀑从极高处倾泻而下，清亮地落进水里。

### S11
[S11-B1]（主体验；小节 84–92，以第84小节主题回归为起点；78–83仅作听觉对照）刚才近乎失重、像在梦里漂着，到了第84小节，同一艘船、同一首歌忽然变得异常直接、异常现实。开头旋律刚一唱出便收弱的那份谨慎不见了：厚重的和弦托起歌声，左手温柔的水波翻成横跨几个八度的惊涛骇浪。像之前一直压在心底的话终于说出口：「这是我的感情，我不再为它道歉。」
[S11-B2]（另一侧面；小节 84–92；原稿写84–93，此处仅取第一主题重返的听法，不作更细定位）这次重逢，也像多年后重新走进一间旧房子。家具可能没变，可你知道的事情已经太多了。原来的温柔再次出现，却有了新的重量；而知道它有多珍贵以后，心里反而更容易发疼。
[S11-B3]（段内变化；小节 约92；局部）到第92小节附近，刚才铺开的力量仿佛短暂地悬在半空，像在等待下一股更大的浪潮。若还记得第32小节那次差一点抵达、却没能真正落定的高潮，这里又可以听出另一层：前面悬置已久的期待，终于得到了某种满足。但这还不是全曲的结束。
[S11-B4]（另一侧面；小节 84–92）这份灿烂也可能让人不太舒坦。像夕阳在沉入地平线前那一两分钟，天空烧得血红金亮，光芒刺眼到让人想流泪；胸口非但没有舒展开来，反而被压迫得发痛。喜悦已经浓烈到身体几乎承受不住。

### S12
[S12-B1]（主体验；小节 93–102；超出个人的感受在原稿中明确对应94–102）第62–71小节那支异常温柔、晴朗的歌，在这里被放到了最大尺度：声音明亮、开阔，近乎英雄式，内声部却彼此拉扯，音乐一浪高过一浪。前面做梦、走神般的状态忽然聚焦到“此时此地”，内心的私语仿佛放大成天地的共振。倒不是“我的感情终于变得比一切都伟大”，反而像整个人被卷进一个比自己更大的世界，连“我”都暂时退到了后面。
[S12-B2]（段内变化；小节 93–102；尤其96–100附近，释放发生于102–103交界；局部）这股声浪却不是一路畅通地冲到顶。原本温柔的歌带上近乎恳求的力量，旋律一次次向上伸展，仿佛还想要更多，却始终不能完全满足。到第96–100小节附近，乐句末端仍有牵扯、延迟与紧张，那口气一直悬到102–103小节交界，才得到一次重大的释放。
[S12-B3]（另一侧面；小节 93–102；久别重逢的类比来自覆盖94–104的原稿，不能进一步细定位）这份狂喜像高烧。它也可以像久别重逢：刚才还能够微笑、寒暄，忽然却抱紧对方，久久不愿松手；又可以是喉咙发紧、眼眶湿润，快乐到连自己想笑还是想哭都分不清。

### S13

【一、先理解原稿，再决定哪些内容上屏】

完整阅读所有材料，理解全曲的人物关系、经历、处境、行为、判断、选择、情绪变化，以及音乐引出的具体身体和心理体验。

在内部建立信息清单，但不要输出清单。

对每条原始线，分别找出：发生了什么、人物发生了什么变化、他为什么这样想、他凭什么得出判断、为什么在这个时候做出选择，以及哪些前情或对方的反应支撑了后面的变化。

对每颗珠子，分别找出：具体身体感觉、心里真实浮现的话、独特的画面和比喻、情绪内部的细微变化、互相矛盾的感受，以及一种状态转向另一种状态时那些不能省略的连接。

内部将信息分成三类：
A类是必须保留的关键因果、判断依据、重要选择和不可替代的独特体验；B类是值得保留、能够增加体验颗粒或补足人物状态的细节；C类是可以删除的同义重复、替代性说法、空泛解释和纯技术信息。

不能只按剧情重要程度决定取舍。一个不起眼的身体感觉或内心疑问，也可能是整颗珠子最值得让观众看到的内容。

删掉任何内容之前，先确认它有没有提供其他地方没有的原因、证据、感受或转折。删重复，不删差异。

只能使用原稿有依据的信息。不能补造事件、动作、心理动机、人物关系、因果关系或新意象。原稿没有解释的事情，不得自行猜出一个理由。

【二、最重要的语言标准：所有文字都要像人话】

把每一句文字想象成一个人真的会对朋友说出来的话。要求自然、具体、容易听懂，不需要观众替编辑者补全句子。

严格避免以下写法：
1. 为了压字数删掉主语、谓语或必要连接，留下不完整的短语。
2. 把一个自然句子硬切成几个词组，每块单看都不成话。
3. 把原本直白的感受改成抽象名词、四字短语、书面词或故作深沉的格言。
4. 使用不合日常习惯的词语搭配，或者把普通动作说得玄乎。
5. 为了显得有文学感，刻意堆叠形容词、对仗、拟人和空泛比喻。
6. 所有句子都采用相同句式，反复出现机械的「因为……所以……」「虽然……但是……」。
7. 用「某种情绪」「内心深处」「逐渐产生变化」等空话，替代原稿里真正发生的事或真正感受到的东西。
8. 为了把字压短，将人物真实的内心话改写成旁观者的心理分析。

允许自然的长短句变化，也允许疑问、犹豫、停顿、转折、直白的内心话。原稿本来朴素的地方就保持朴素，不要强行写得漂亮。

一块文字如果需要观众读第二遍才能搞懂在说什么，就重写。宁可多几个字把话说顺，也不要省出一句别扭的话。

注意：本轮线的文字形态是完整句子，不是碎裂词组。画面上的上下错落和视觉分散可以保留，但不能通过破坏语法来制造所谓的碎裂感。

【三、line：一句完整自然的话，先让人抓到要点，同时保住为什么】

line负责人物经历、关系变化、重要判断、行为选择及其因果依据。它不是标题，也不是情绪标签，更不是把原稿压缩出来的一串关键词。

每个line.text必须是一句能够单独读懂的自然句子，有明确的事件、人物状态、判断或行动。可以根据上下文自然省略重复称呼，但不能省略到指代不清。

优先让观众在句子的前半部分抓到最重要的变化、行动、判断或选择，再自然交代与之有关的原因。不过不要为了机械地把结论放在最前面而扭曲正常语序。要点先行是一种阅读效果，不是一套僵硬句型。

重要行为、判断和选择必须保留原稿提供的关键依据。特别检查：
- 以前发生过什么，才让人物现在改变了态度？
- 对方做过什么、持续表现出什么，才让人物得出这个判断？
- 人物为什么想坚持、停下、靠近、退开或做出其他选择？
- 他明明还在犹豫，为什么最后仍然行动了？
- 为什么这个变化发生在此刻，而不是更早？

不要求每一条线都回答所有问题，只要求凡是原稿明确交代、而且影响观众理解的理由，不能在压缩时消失。

如果一个行为与理由能用一句自然的话说明白，就放在同一句里。如果确实包含两步独立的信息，可以写成两条连续的line，但两条都必须分别是完整自然的句子，不能把「因为某件事」单独切成一行，再把「所以做了某事」单独切成另一行。

不要为了让线变短，把多次发生的经历归纳成一个抽象心理词，也不要把不同时间的独立事件合成一句笼统总结。

line的长度以一眼读懂、读起来顺为准。通常可以在约20至45个汉字之间自然浮动；关键因果需要时可以稍长，但不要拖成一段心理分析。这个范围是提醒，不是必须执行的截断线。不得为了凑字数而拉长句子，也不得为了达到某个数字而牺牲语法、因果或自然表达。

每条line设置1至2个keys，选择最值得放大的行动、判断、关系变化或关键状态。关键词尽量出现在句子的前半部分，但不要为了提前关键词而把句子写别扭。

keys中的每个值必须逐字等于text中连续出现的文字，不能改写、跳字或自行创造。不要把整个句子选为关键词。

每条line必须填写emotion，并且只能从「炽热、欢喜、亲密、安心、孤单、不安、悬着」中选择一个。

每条line的from必须包含真实的原始线编号。允许合并或拆分，但必须保持信息来源准确，不得编造编号。

最终把全曲所有line单独连起来读一遍：读者必须能理解重要经历、关系如何变化、判断从何而来、人物为什么这样选择。不能只剩一串结果。

【四、feel：短小独立，但必须像人在描述真实感受】

feel负责line没有提供的体验，包括身体感觉、感官变化、心里的话、独特画面、微妙情绪，以及看似矛盾的两种状态如何同时存在。

每个feel item只表达一个相对独立的体验中心，或者一个本身不可拆开的矛盾和转折。

重点保护五种信息：
1. 具体身体感觉：呼吸、温度、触感、轻重、松紧、心跳，以及原稿中有辨识度的生理感受。
2. 真实内心话：疑问、担心、犹豫、自我安慰、没敢说出口的想法。能保留具体心声，就不要改写成抽象情绪标签。
3. 独特比喻和画面：原稿中真正提供了体验入口的画面，不能只留下它背后的情绪结论。
4. 情绪微状态：一点点放松、短暂的高兴、迟迟没散的不安，以及程度、方向和质地不同的感受。
5. 连接和矛盾：一件心事还没解决，但此刻没那么困扰；一种愿望仍在，却不知道会不会实现；人物同时感到两种难以调和的心情。

对于不可拆分的矛盾体验，要把两层关系一起保留，不能只留下其中一边，也不能分别拆成失去联系的两个残句。

feel可以比line短，可以是口语里自然成立的短句，也可以是完整句子，但绝不能像从一段文字里剪出来的几个残缺词语。不要把短小误解为主语和动作都不见了。

一块感受通常约12至35个汉字；如果把体验说清楚需要稍长一些，可以自然增加。长度服从自然表达和独立体验，不服从硬性截字。

不同的体验分别写成不同item。同一种体验的不同说法，只留下最具体、最自然、最好理解的一种。同一颗珠子可以保留多块真正不同的感受，但不能把几种近义说法一起搬上屏。

一个feel row可以包含多块相近时刻、情绪颜色一致的独立感受，通常1至3块较容易扫读。不要让items连起来变成一篇需要细读的段落。

feel不能只是对line再说一遍。line交代人物做了什么和为什么，feel让观众知道那一刻具体是什么感觉。两者即使都涉及心理，也应当各自提供不可替代的信息。

音乐术语只在它确实是体验入口时少量保留。不要把纯粹的旋律、节奏、和声或声部分析当成feel，也不要因为删掉技术解释，就连它带出的具体感觉一起删除。

任何体验都不得添加原珠子没有的动作、物体、心理解释或比喻。每个item必须对应一个真实bead编号。

【五、颜色：每条线独立选情绪，下面的感受继承它】

颜色不是装饰，而是让观众不用细读，也能感觉到这一刻情绪性质的视觉信号。

每条line根据它所表达的当下状态，选择一个emotion：
炽热：强烈的投入、渴望或情绪推动。
欢喜：明亮、愉快、轻快的情绪。
亲密：靠近、连接、被理解或彼此在意。
安心：放松戒备、安稳、可以暂时放心。
孤单：无人回应、距离、空落或失去陪伴。
不安：担心、害怕、紧张或无法放心。
悬着：等待、未定、还不知道结果、心里有事放不下。

这些定义用于辨别颜色性质，不是要求把这些标签写进text。文字必须呈现具体经历或真实感受，不要把标签冒充内容。

每条line的emotion只选一个，以此刻最主要的情绪为准。遇到复杂或矛盾情绪时，保留文字里的复杂关系，不要把内容强行改成单一情绪。

同一段出现几条情绪性质不同的线时，要分别判断并使用不同的emotion。例如亲近带来的放松，与仍然等待结果的忐忑，不应因为处在同一段就全部归成同一种颜色。

同一种情绪确实持续时，可以重复使用同一emotion。不要为了做出彩虹效果，强行给性质相同的线换颜色，也不要为了全段统一而抹平本来不同的感受。

每个feel row放在与它最相关、情绪性质相符的line下面，继承上方最近一条line的emotion，不单独输出颜色字段。一个feel row里的items应当能合理共用这种情绪颜色。如果感受属于另一条线的情绪，应当拆开排列到对应位置，而不是全部塞在同一颜色下面。

不能为了配色而颠倒真实时间顺序，也不能为了给一块感受安排颜色，就编造原稿没有的line。若素材确实没有可引用的线，可以保留独立feel，不得凭空添加叙事来源；呈现端可继承此前最近的真实线色，不需要增加JSON字段。

输出的emotion就是画面使用的情绪颜色类别。不要另外输出色号、颜色名称、RGB、样式或渲染说明。

【六、排版顺序：上下交替、关键词突出，但不机械拼接】

按音乐和叙事实际发生的顺序安排rows。

优先使用「line在上、相关feel在下」的交错结构，让观众先抓住人物正在经历什么，再看见那一刻的具体感受。

可以出现line、feel、line、feel，也可以出现连续两条line再跟一个feel row，或者一条line下面跟多块性质不同但同色的感受。不要强制一条线配一块感受。

每条line是一句完整的话。不能为了画面上的上下交替，把原本完整的句子拆成两个不通顺的行。

feel作为小块散落，不能重新汇成长段。不同小块之间要有独立的信息价值，不能只是一个句子被硬拆成几块。

如果原稿没有说明先后关系，不要使用「然后」「接着」「最后」等词伪造时间推进。只有素材明确发生了变化，才能写成前后变化。

所有要放大的字由keys指定，不要在text里加入特殊符号、加粗标记或排版说明。

【八、编号与bars的硬性规则】

sections只能使用原材料真实存在的段落编号，并按原有顺序排列。

line.from只能填写真实的原始线编号，允许多个来源，但不能编造编号。

feel item的bead只能填写一个真实的珠子编号。不能把不同珠子的内容揉成一个item后随意选择来源。

每个feel item必须带有bars字段，且必须是字符串。

只有原珠子明确指出某个局部体验属于哪些小节时，bars才填写相应范围。该范围不得超出珠子明确写出的范围，不得自行推算、扩展或猜测。

如果珠子只写了整体范围，或者这块体验属于整颗珠子的整体感受，bars一律填写空字符串。

小节号只允许出现在bars字段中。plan、line.text和feel item.text都不得出现小节号、小节范围或定时指令。

【九、plan：交代全曲编排和前后呼应】

plan简洁说明全曲如何从一个阶段推进到下一个阶段、哪些早期经历支撑了后来的判断或选择，以及哪些有原稿依据的关键词、意象或情绪在前后呼应。

如果同一个关键词在不同段落里的含义或情绪发生变化，可以指出这种变化。不要为了制造结构感而发明原稿没有的主题、象征或对应关系。

plan不必逐段复述所有line和feel，也不要写成论文。不要包含具体小节号。

【十、输出前的内部验收】

必须在内部完成以下检查，不要把检查过程写进输出。

人话检查：把每一条line和每一块feel逐字读出来。是否真的像日常说话？有没有生硬搭配、书面短语、缺少必要成分、刻意对仗或硬切开的半句话？有就重写，而不是只改一两个形容词。

句子检查：每条line能否独立读懂，是否是一句完整自然的话？有没有为了关键词靠前而扭曲语序？有没有为了省字删掉关键主语、动作、判断依据或连接词？

因果检查：只读全曲line，是否知道人物经历了什么、为什么形成某种判断、又为什么做出重要选择？把原始线中的关键因果逐项核对，不能出现只有结果没有依据的情况。

体验检查：逐颗核对珠子中的身体感觉、内心话、比喻、微状态和连接转折。是否把性质不同的体验误当成重复？是否把有内容的疑问、矛盾或感觉压成了一个抽象情绪词？是否引入了原稿没有的新画面？

扫读检查：线是否突出要点，keys是否准确？感受是否依然是独立小块？是否出现大段文字、过长句子或被硬拆成碎片的句子？

【最终输出格式】

只输出一个合法JSON对象，不要Markdown代码块、前言、解释、注释、验收报告或结论。

严格使用下面的结构和字段：

{
  "plan": "全曲怎么排、哪些词前后呼应",
  "sections": [
    {
      "sec": "S01",
      "rows": [
        {
          "kind": "line",
          "text": "线这一行完整、自然的话",
          "keys": ["text里连续出现的关键词"],
          "emotion": "安心",
          "from": ["S01-1"]
        },
        {
          "kind": "feel",
          "items": [
            {
              "text": "一块自然、具体的感受",
              "bead": "S01-B2",
              "bars": ""
            }
          ]
        }
      ]
    }
  ]
}

以上只是字段结构示意，正式输出必须使用输入中的真实编号和实际内容，不能照搬示意文字。

字段要求：
- plan：一个字符串，简述全曲编排、重要因果承接和有依据的前后呼应。
- sections：按原始段落顺序排列。
- sec：真实段落编号。
- rows：按实际展示顺序排列line行和feel行，不要求机械一一配对。
- line.text：一句完整、自然、要点清楚、有必要因果依据的话。
- line.keys：1至2个要放大的关键词或短语，必须与text中的连续文字完全一致。
- line.emotion：只能是炽热、欢喜、亲密、安心、孤单、不安、悬着中的一个。
- line.from：一个或多个真实原始线编号组成的数组。
- feel.items：一个或多个独立感受块，内容自然，同一个feel row里的感受应当适合继承同一种情绪颜色。
- feel item.text：一块短小、具体、有辨识度、说得通的感受，不得包含小节号。
- feel item.bead：一个真实珠子编号。
- feel item.bars：字符串，只有原珠子明确标出对应局部小节时才填写范围，否则为""。

line对象只允许kind、text、keys、emotion、from字段。feel对象只允许kind、items字段，item只允许text、bead、bars字段。不得增减字段或输出任何额外配色、动画和排版数据。

最重要的底线：不要为了短而写得不像人话；不要为了好扫而删掉人物为什么这样做；不要为了恢复细节而重新写成长段；不要为了多种颜色而扭曲真实情绪。句子要完整自然，感受要具体细腻，每段字数要接近参照，整份稿子要能让普通观众边听边看。
