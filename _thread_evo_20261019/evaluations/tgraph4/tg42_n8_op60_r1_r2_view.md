# Op.60｜关系图

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3　（还说不清）

- 他还说不清自己究竟在盼什么，只知道心里有个格外想亲近的人，想到对方便会柔软。
- → 每当他想让这份感觉多停留一会儿，便又本能地把自己往回收。
- 眼下没有什么事要求他决定，他也不知道自己为何如此谨慎。
- 那点喜欢似乎轻得随时可以放下，可他偏偏舍不得放下。

### 4–16　（正在面对）

- 因为还不知道自己怕什么，他不急着给这份在意定去向，也不必现在想清两人会怎样。
  - ← 提供理由：（1–3）「无事仍然谨慎」
- → 他也不必因为喜欢就向对方期待什么，这样想让他慢慢能够安心亲近那个人。
- 他喜欢自由给予温柔，不必确认对方是否领受，也不因对方重要而失去从容。
- → 他渐渐发现，让一个人走进心里也可以不带来不安，他能认真在乎而不抓住什么。
- → 这份快乐给了他安稳，他渐渐不再提防自己的喜欢，也有些满意自己能如此宽和。
- → 他盼着亲近一直自然发生，不必追问和计较，并觉得当时这样已经足够。

### 17–23　（正在面对）

- 正因为这份亲近已经让他尝到幸福，他开始希望这份喜欢能长久，不只属于眼前。
  - ← 唤起：（4–16）「觉得这样足够」
- → 一想到长久，他便想到自己能决定怎样珍惜对方，却不能决定对方是否同样珍惜自己。
- → 他偶尔会想，自己在对方心里是否也有一个特别的位置，起初并没打算索取什么。
- → 多了这一点期待，他便不再像先前那样安稳，也意外发现满足的亲近仍会让人盼望更多。　✦ 满足照出未满足

### 24–34　（正在面对）

- 他不愿新添的紧张破坏先前快乐，也不想让喜欢成为催促，因为对方从未答应什么。
  - ← 提供理由：（17–23）「满足后仍盼更多」
- → 他提醒自己，珍惜对方不必事事索取表示，关心、给予和真心替对方高兴本身就是快乐。
- → 这样想让他真正轻松下来，先前想确认的紧张渐渐退去，他反而更愿意付出。
- → 他不再小心衡量心意，也不再担心多给一点会显得自己更在乎。
- → 他为毫不勉强的热切感到幸福，心里仿佛比从前丰盈，温柔也像有了更宽敞的去处。
- → 那一阵，他甚至相信只要不提出要求，就能尽情去爱，也不会失去什么。

### 35–39　（正在面对）

- 欢喜稍稍平息后，他仍想知道自己是否也被对方放在心上。
  - ← 动摇：（24–34）「相信无要求就不失去」
- → 这个念头让他难堪，他刚为无所求而高兴，转眼又盼望被看见。
- → 他开始怀疑，先前那些体贴里是否一直藏着自己不愿承认的期待。
- → 他暂时答不出来，说自己毫无所求似乎不诚实，可此前的快乐也不能说成只是为换回应。
- → 他只能暂时留在这份不自在里，不替自己辩解，也不急着用新的热烈把它盖过去。

### 40–50　（没在想）

- 这份难堪没有让他不再喜欢，却使他不愿继续用慷慨来证明自己。
  - ← 改写：（35–39）「盼望回应令他难堪」
- → 他既不想时时检查对方是否在意，也不想强迫自己变成完全没有期待的人。
- → 他不再忙着设想两人以后如何，只留心自己此刻确实愿意给予的关切。
- → 这份喜欢更隐秘，也更贴近他自己，他暂时忘了为何在意回应，只觉得细细喜欢很甜。

### 51–61　（正在面对）

- 这份不声张的甜意留久了，已经不像起初那样轻巧。
  - ← 改写：（40–50）「细细喜欢的甜意」
- → 他对对方的珍惜日渐加深，感情渐渐难以收放，他更深地惦念，也希望关切能被领会。
- 他仍觉得不催促对方是对的，也舍不得用自己的期待换取别人的迁就。
- → 他不愿让对方承担，于是只能独自容纳那些没有着落的盼望。　✦ 办法的限度
- 他不觉得这种喜欢不值得，正因它曾给过他细致甜蜜，他舍不得减轻，如今也感到它有了重量。
- ⟲ 仍在起作用：（24–34）「不愿快乐被紧张破坏」

### 62–71　（正在面对）

- 既然心意已经如此深，他忽然不想再时时把它当作需要约束的东西。
  - ← 改写：（51–61）「舍不得减轻深情」
- → 他发现这些快乐都不依赖对方给出承诺，即使心里仍有期待，幸福也不因此变得可疑。
  - ← 说明：（4–16）「喜欢带来安稳」
  - ← 说明：（24–34）「慷慨喜欢带来丰盈」
  - ← 说明：（40–50）「细细喜欢的甜意」
- → 他不愿再因害怕受伤而连高兴都小心翼翼，想充分喜欢一次，不急着追问结果或安排退路。
- → 积攒许久的眷恋成了他可以坦然享受的热情，他不再衡量给出多少，也不再提醒自己收回。
- → 有一阵，欢喜真的大过所有顾虑，他知道前面仍没有保证，却几乎感觉不到那份沉重。

### 72–77　（正在面对）

- 因为刚刚毫无保留地承认感情，欢喜稍落后，他心里真正想要的东西再也含糊不过。
  - ← 唤起：（62–71）「欢喜暂时盖过顾虑」
- → 他不只想尽情喜欢，也想让深情有所相遇，知道对方是否同样渴望靠近并愿彼此重要。
- → 他明白自己想要得很深，却不能把这份真心当作对方应当回应的理由。　✦ 分清
- → 这使他一时进退两难，退回谨慎仿佛辜负刚承认的心意，继续盼望又怕自己变成要求。　✦ 选择的代价
- → 两边都有他舍不得放弃的东西，他想不出兼顾办法，反复思量让他委屈也厌倦。

### 78–83　（正在面对）

- 他终于不想再逼自己立刻作出选择。
  - ← 提供理由：（72–77）「委屈于无法兼顾」
- → 既不能减轻喜欢，也无法决定对方心意，他决定暂时不决定什么。
- → 他不必因为想靠近就立即向前，也不必为了守住分寸把眷恋压得看不见。
- → 两种心思仍然都在，却不再互相催逼，他能带着愿望安静地喜欢，也承认自己没有把握。
- → 暂时放过自己让他松开一点，先前为难并未消失，只是他不必时时与它争执。

### 84–92　（正在面对）

- 不再强迫自己消除渴望后，他重新感到最初亲近一个人的快乐。
  - ← 唤起：（78–83）「暂时放过自己」
- → 当初他从容，是因为还不知道自己会想要这么多，如今已尝过期待的紧张和无从确认的难堪。
- → 他也知道深情不能替对方作答，却仍然愿意喜欢。
- → 他不必再用无所求证明体贴，也不因偶尔想被珍惜就怀疑感情真诚。
- → 这种允许让他更坦荡，他愿全心投入，不再躲避感情的深度，也不为热切羞怯。
- → 经历许多犹疑却依旧能够高兴，使他感动，过去让他警惕的愿望此刻都能与喜欢共存。
- → 他并未重新变得无忧无虑，只是知道自己可能受伤，仍愿充分承认这份幸福。

### 93–102　（正在面对）

- 既然连渴望都不必再遮掩，他比刚才更清楚自己多么想亲近这个人。
  - ← 唤起：（84–92）「知道会受伤仍愿欢喜」
- → 他想让心里积攒的温柔有去处，也想让亲密不只停留在自己的愿望里。
- → 他想被同样深切地珍惜，也想知道两人共同拥有的幸福究竟能有多丰盛。
- → 这些愿望仍然存在，却暂时不再以缺憾的样子折磨他。
- → 那是一阵几乎难以承受的满足，想靠近、被爱、把自己交给亲近的心愿仿佛同时得到抒发。
- → 没有得到任何新的保证，他却真切感到能够这样爱着，本身已让生命充实得不可思议。

### 103–110　（正在面对）

- 可就在幸福仍鲜明时，他感到其中有一处始终没有着落。　✦ 满足照出未满足
  - ← 动摇：（93–102）「让幸福只属于此刻」
- → 他刚刚尽情地爱，也尽情盼望被爱，正因不再遮掩愿望，他更清楚满足还缺少什么。
- → 他能充分拥有自己的深情，却无法凭这份深情得到另一个人同样深切的选择。
- → 想到这里，他仍会酸楚，欢喜并未被推翻，却因如此真实而让酸楚更难忽略。
- → 他已经知道自己能够爱得多深，便再难说服自己对方怎样回应都无所谓。　✦ 知道更多反而更尖锐
- → 若把自己的安稳完全交给对方，他也知道自己会失去什么，不愿让那个人负责消除全部不安。
- 他也不愿因害怕得不到回应，就故意削弱那些曾给过自己巨大幸福的感情。
- → 他终于不能再把克制或尽情投入中的任何一种，当作足以解决一切的答案。　✦ 办法的限度
  - ← 限制：（4–16）「安心亲近对方」
  - ← 动摇：（24–34）「相信无要求就不失去」
  - ← 限制：（62–71）「欢喜暂时盖过顾虑」
- → 他仍迫切想靠近，也坚持不勉强对方，如今更强烈感到两者冲突，因为舍不得否认任何一边。
- → 他不愿为了求得轻松就匆忙舍弃其中一种，宁可承受不轻松，也不靠欺骗自己换平静。

### 111–116　（正在面对）

- 带着这份仍未平息的牵挂，他渐渐不再要求自己找到一种不会受伤的爱法。
  - ← 改写：（103–110）「不靠自欺换平静」
- 他仍想被选择，因为对方重要，也希望两人彼此亲近，即使愿望未必满足，他也不必假装它不存在。
- → 他舍不得放弃克制，因为对方有自己的心意和自由，若要求对方承担全部期待，亲近便会失去自在。
- → 他仍会遗憾，却不再觉得必须先消灭遗憾，才能好好爱一个人。
- → 他不因先前的快乐没解决最后的问题就把它们看成徒劳，反而更珍惜它们一再让他愿意向前。
  - ← 改写：（4–16）「喜欢带来安稳」
  - ← 改写：（24–34）「慷慨喜欢带来丰盈」
  - ← 改写：（40–50）「细细喜欢的甜意」
  - ← 改写：（62–71）「欢喜暂时盖过顾虑」
  - ← 改写：（93–102）「满足几乎难以承受」
- → 这些经历让他更明白这个人多重要，也让他看清收住和投入都不能免去爱的风险。
- 他仍想得到回应，也仍会有所保留，却不再以回应有无判定真心，或以保留多少证明清醒。　✦ 分清
  - ← 改写：（72–77）「真心不能要求回应」
- 没有什么能保证他以后不失望，他知道自己还会想要更多，也会因不能更近而疼痛。
- → 可这些都不必成为他否认感情或催促对方的理由。
- → 他愿继续把这个人放在心里，认真地喜欢、充分地欢喜，也承受自己无法决定的部分。
- → 他终于不必在热切与分寸之间留下一个、把另一个赶走。
- → 他可以渴望被爱，却不把渴望变成对方义务，也能珍惜对方自由而不收回自己的心。
- → 他没有得到想要的一切，却不再为了守住彼此，先放弃自己最想给予的爱。
- ⟲ 仍在起作用：（103–110）「两种办法都不足够」
