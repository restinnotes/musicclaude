我把“为什么偏偏现在”放在最高权重，其次看 Center、前史回流和理解是否真的累积；语言漂亮与否只作为次级项。结论是：**B 最完整；A 的心理链很强，但把材料收成了较具体的民族—故乡叙事；C 的核心机制很干净，但中段有局部原地回旋，且公式句最多；D 的因果其实不错，但抽象名词太多，而且四篇里最接近把珠子的若干落点抽象改写成 Thread。**

## 总排名

**1. 文章B → 2. 文章A → 3. 文章C → 4. 文章D**

四篇里我都**没有判定“大面积照抄/复述珠子”或“主要靠新编事件推动”**，所以没有触发 overall≤4 的硬上限。D 有比较明显的珠子同构痕迹，但还没到“大面积复述”的程度。

### 文章B

**Center：**他想对真正珍贵的东西有所行动，却又怕“坚强”会要求自己背叛仍然疼、仍然眷恋的那一部分；整篇是在弄清，行动的尊严能否不靠消灭柔情来成立。

这是四篇里最像“线”的一篇。它不是简单把“犹疑→坚定→柔软→坚定”串起来，而是不断让一个已经有效的办法显出副作用：等待本来是为了慎重，却变成退让；坚定本来给了自由，却变成“绝不能动摇”的新束缚；回忆本来被怀疑会妨碍行动，后来又发现它恰恰告诉他什么值得行动。66–115尤其好：因为他已经尝过“掌握自己”的满足，才会开始依赖这种感觉；继而又分清“面对外部”和“容许内部脆弱”不是一件事。fileciteturn0file1L13-L17

**最佳 why-now：226–241。**不是突然宣布“我要行动”，而是前面的那点微弱意愿经受过强硬、温柔、犹疑以后仍没消失，于是他终于发现自己一直索要的是一个“不可能的保证”——既要行动，又要保证什么都不伤、永不后悔。这个发现直接解释了为什么此刻可以迈步，并且调用了很早的温暖、委屈和等待史，不只指上一段。fileciteturn0file1L43-L46

**最弱 why-now：214–215。**“一想到必须亲自承担没有把握的选择，最初疑问又回来”是说得通的，但基本是一次短暂的旧问题闪回，解释层次明显低于前后两段。fileciteturn0file1L35-L41

忠实性也最好：它只设定“过去有过温暖、有值得保护之物、现在有现实压力”这种低分辨率前提，没有再编某件事故、某个人的一句话来强行推动。缺点主要在语言：大量“既然”“正因为”“越……越……”“不是……而是……”“终于”“不再”，机制本身很真，但表面有明显的模型式论证节奏。

### 文章A

**Center：**面对故乡/同胞真实的光荣与后来真实的损失，他怎样继续骄傲、心疼和盼望，而不把其中任何一种感情当成能够补偿失去的办法。

A 的优势是 **History 和远距离 Connection 很强**。它不是每一段把上一段推一步而已。最典型的是216–225：当“爱有没有用”的怀疑回来时，它重新调用最开头“少想故乡确实会轻松、但这种轻松不能接受”的经历，拿第一次失败过的办法去限制现在的新结论，于是推出“有效性”和“是否值得继续爱”可能是两件事。fileciteturn0file0L37-L45 这是很好的 Thread 写法。

**最佳 why-now：216–241。**尤其226–241又把骄傲、温柔、平静三个前面试过的办法一起调回来：问题不再是哪个情绪正确，而是自己一直在要求“爱”替自己完成什么。这个理解确实是前面几次失败积出来的。fileciteturn0file0L41-L46

**最弱 why-now：214–215。**“一想到究竟该怎样回应”，就突然重新怀疑自己是在爱同胞还是安慰自己。这个问题很重要，但“为什么恰好现在重新出现”的铰链比较像作者安排出来的门槛句，强度明显弱于其他十二段。fileciteturn0file0L33-L41

主要扣分在忠实/诚实。A 一开始就把对象收得很实：身在异乡、故乡、同胞昔日光荣、后来受苦与被亏待。fileciteturn0file0L5-L13 它没有靠**后续新发生的虚构事件**制造转折，所以我不触发硬上限；但整条线的推理强度有相当一部分来自这套已经具体化的民族历史前提。换言之，它很会推理，但先替作品决定了“究竟是谁、失去了什么”。这是 A 比 B 低一名的主要原因。

语言也有较多成套的“不能……也不能……”“不是因为……而是因为……”“终于”“真正”，不过实词——同胞、故乡、骄傲、苦难、补偿——较稳定，所以一眼看内容仍比 D 强。

### 文章C

**Center：**他要学会完整承认“过去确实幸福、今天确实失去了”，却不再把那份过去当成向今天追讨同样幸福的凭据。

C 有四篇里**最干净的单一心理机制之一**。66–91把问题直接拆成：“回忆可以证明过去确实幸福”与“回忆还能把幸福交回今天”是两件不同的事；前者成立，后者做不到。fileciteturn0file2L11-L17 到226–241又进一步分出“我希望它继续”与“它本来就应该继续”。这不是换个说法重复，而是第二次真正的理解升级：先分清回忆的功能，再分清愿望与要求。fileciteturn0file2L43-L49

**最佳 why-now：226–241。**前面已经证明了感激不能消除遗憾、强迫恢复旧日信心会疲惫、单纯让两边共存仍不安，于是才有理由追问那个隐藏要求。这里的“原来我一直把曾经很好理解成以后也应当一直很好”确实是此前失败的解释，不是横空而来的哲理。

**最弱 why-now：206–213。**这一段又回到“先承认自己得到过多少→短暂安宁→但感激不等于没有遗憾”，基本上重复了148–205已经建立的成果，主要承担过桥功能。214–215也偏门槛句，因此这两段我都判“弱”。fileciteturn0file2L27-L41

C 没有明显编造，也没有明显照抄珠子，所以 faithful 是四篇最高。它输给 A 的原因主要是 **History/Connection 的网络稍薄**：很长一段时间都是“刚才这个办法有效/失败 → 下一段试另一个理解”，回流到较远经历的次数少一些。而语言问题很突出：“越……越……”和“既然……”密度太高，很多本来很好的机制因此显出模板感。

### 文章D

**Center：**失去原来的归属后，他既想凭自己的尊严继续站立，又仍需要被原来的世界认得、回应；问题是怎样承认这种需要，却不把回应变成自己继续生活的条件。

D 的心理结构其实相当好。**最佳 why-now 是66–91：**恰恰因为“靠尊严站住”已经成功，它的限度才第一次显形——一个办法满足了“我不能倒下”，反而照出了另一个尚未满足的“我还想被认得”。这完全符合用户给的“理解的积累”标准。fileciteturn0file3L9-L17

后面也有好的累计：记忆只能证明“曾经属于”，不能制造“此刻仍被回应”；请求暴露了不可控制性，于是214–215本能退回坚硬；但因为已经知道需要不会靠否认消失，那种老办法又不能真正复原。这个因果很扎实。fileciteturn0file3L25-L45

**最弱 why-now：1–23。**一开始直接放进“归属、尊严、被认出、失去位置”四五个高度抽象的变量，它们彼此关系讲清楚了，但缺少一件更低层级的真实经验，使读者知道为什么这个纠缠恰在此刻到了非处理不可的程度。fileciteturn0file3L3-L9

D 最大的问题不是因果，而是**表达层和对珠子的依附程度**。参考珠子的24–65本来就有“整理好衣服、抬起头”“强烈自我控制”的解释，fileciteturn0file4L15-L23 D 对应段直接变成“整理自己、收住散乱情绪、克制、庄重、共同准则”；而参考242–253的核心是“经历动摇以后仍决定怎样站立、不必假装从未受伤”，fileciteturn0file4L93-L99 D 的同段也落在“明知伤口仍在却依然站得住”。这不是逐句照抄，但比另外三篇更像**把珠子的体验抽象化、概念化以后重新写一遍**。254–288再把“柔软 + 公开/宏大”收成“尊严与温情终于不再排斥”，也保持了同样的段落对应。fileciteturn0file4L101-L111

此外，“归属、尊严、共同价值、承认、回应、需要、现实、选择”反复充当主语宾语，导致它虽然逻辑强，扫一眼却最难抓到实物；这正好踩到“一眼有内容”和空姿态词的扣分点。
