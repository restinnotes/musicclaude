# Op61｜候选 3

**Center：**他很在乎自己还能挺直腰、靠自己的力量做决定，可身体越来越虚弱，越想表现得坚定，越清楚地感觉到自己有多吃力。

**1—23**

最让他难受的，还不是身体一天比一天虚弱，而是连挺直腰这样过去根本不用想的事，如今也要先掂量自己还有多少力气。他依然想照自己的意思做决定，可是那个曾经十分自然的念头——只要我想，我就能做到——已经不敢再轻易相信了。每当他想挺起身子，心里总会先掠过一点迟疑。他讨厌这迟疑，因为它让他觉得，自己还没有行动，就已经在向身体的衰弱让步。可是他又不能假装那份吃力不存在。他只好反复试着收拢自己的心神，寻找一种仍然能够依靠的力量。身体未必会像过去那样听话，至少他还可以决定，不让自己的心先退下去。这个念头虽然不能立刻使他安心，却让他有了继续坚持的理由。

**24—65**

因为不愿让那一点迟疑替自己作主，他开始更加认真地要求自己挺直。起初，每一分用力都带着担心，怕身体支撑不住，也怕自己因为害怕而提前放弃。但他渐渐发现，当自己不肯松懈，腰背确实还能找回一点熟悉的支撑。他重新尝到了那种久违的骄傲：原来自己还可以命令自己，还没有完全交出做主的权利。有了这份实实在在的回报，他便更加愿意坚持，甚至觉得，只要这股不认输的劲头还在，过去的自己就没有真正离开。可他越想守住这份坚定，越发现它不像过去那样自然。以前挺直腰时，他根本不需要一直想着自己是不是挺直；现在却仿佛只要稍微不留神，辛苦维持的支撑就会散掉。他不得不一次次把力气重新聚拢。骄傲仍然是真的，疲惫也越来越真。他不愿否定自己好不容易赢回的东西，却忍不住开始怀疑：如果连从容都得这样拼命维持，自己究竟是在变得坚强，还是在用剩下的力气勉强扮演从前的自己？

**66—91**

这个疑问使他第一次不再把坚持当作唯一的办法。既然拼命维持的挺直反而让他越来越疲惫，他便想试试，能不能稍稍放松对自己的要求，而不把这当成认输。他不再时时盯着身体有没有松懈，也不再因为一点无力就立刻催促自己振作。令他意外的是，少了这份逼迫，他反而感到轻快了一些。原来身体虽然虚弱，也并非只能在严厉的命令下勉强支撑；当他肯顺着它一点，它仍然能够给他一些自在。这份轻快使他十分高兴，因为他原本以为，只要不再硬撑，就一定会失去自己珍惜的尊严。现在他却发现，放松也可以是自己主动作出的选择，而不是被衰弱逼退。他甚至觉得，自己终于找到了一种更好的坚定：不必每时每刻和身体较劲，也能保有一点过去那样自然的昂扬。他开始盼望，往后也许可以这样活着，不必那么辛苦，却仍然像自己。

**92—115**

正因为尝过这种轻快，他才更想把它留住。他不愿回到那种时时提防松懈的紧张里，却也舍不得放弃挺直腰时的骄傲。他试着让两者待在一起：仍然照自己的心意要求身体，却不再那么凶狠地逼迫它。可他逐渐发现，那份轻快并不能随意取用。只要他不急着证明什么，身体似乎还能宽裕一些；一旦他重新想要确切地站稳，熟悉的吃力就又回来了。这使他比先前更加失落。过去他只知道硬撑很累，现在却知道，自己明明有可能不那么累，却无法在真正需要坚持的时候留住那份自在。他开始害怕，所谓顺着身体的限度，会不会最终变成一件事：只有身体允许的时候，他才敢照自己的心意行事？可是硬撑的代价他也已经领教过了。他不能再简单地劝自己坚持，也不能轻易劝自己退让。究竟什么样的艰难值得忍受，什么样的坚持只是在逞强？他越来越想把这两件事分清楚。

**116—147**

他之所以要分得这样仔细，是因为两种办法都确实给过他希望，也都留下了不能忽略的困难。硬撑让他重新感到自己的力量，却几乎耗尽了那份力量；放松让他感到自在，却不能保证他在真正想坚持时仍然做得到。他不愿再被一时的骄傲或轻快骗过去，便开始认真衡量自己的每一个念头。想继续坚持时，他会问自己是不是只怕承认虚弱；想稍稍歇下来时，又担心这是不是在替胆怯找理由。他以为想得越明白，就越能作出不后悔的决定。可是渐渐地，连疲惫也仿佛成了一件必须向自己解释清楚、才能被允许的事。他已经很累，却还在追问自己为什么不能再多坚持一点；他明明想保留力气，又怕这份顾惜会把自己养得越来越软弱。这样反复盘问，比单纯硬撑更加折磨他。到后来，他终于察觉，自己一直在用所剩不多的力气检查自己还剩多少力气，又用检查出来的不足责备自己。这样下去，不管他最后选择坚持还是退让，都很难得到安宁。这个发现使他难过极了。他原本只是想保住自己做主的能力，却不知不觉把自己变成了一个永远不能令人满意的人。他终于没有再催促自己振作。

**148—180**

没有了必须振作的命令，他才第一次真正留意到，自己的身体究竟承受着什么。他以前总觉得，身体不肯像过去那样挺直，是它没有尽到自己希望它尽的责任；现在他却忽然想到，它其实一直在尽力。那些酸软和疲惫，并不是身体故意违背他的心愿，而是它已经十分吃力，仍然试着陪他做到想做的事。他想起自己曾经多么自然地挺直腰，那时的轻松确实已经失去了。承认这一点，他心里有一种很深的伤心。但这次他没有因为伤心而责备自己软弱。他开始觉得，一个人失去自己珍惜的能力，本来就是值得难过的事，何必连难过也要忍着？他终于愿意体谅这个疲惫的自己，愿意承认，有些艰难不是再努力一点就能消除的。奇怪的是，当他不再急着证明自己还能怎样，心里反而慢慢安静下来。他仍然希望挺直腰，却不再觉得每一次撑不住都是对自己的羞辱。原来不能像从前那样坚定，并不意味着这个人就不值得尊重。这份安宁来得那么不容易，他甚至觉得，过去一直苦苦追求的，也许并不只是重新变得强大，而是终于能够在不够强大的时候，仍然和自己好好相处。

**181—205**

可是，正因为这份安宁真的使他好受了许多，他才慢慢发现，自己还有一件事放不下。体谅身体，可以让他不再因为疲惫而羞愧，却不能替他回答，那些仍然想做的事究竟该怎么办。如果每当坚持变得困难，他都劝自己不必勉强，当然可以少受一些苦；但如果那些决定对他确实重要，难道也能这样一次次放下吗？他不愿回到先前那种蛮横的硬撑，却渐渐担心，自己是不是太急于摆脱痛苦，以至于把原本珍惜的愿望也安放到了一边。他开始怀念过去那种毫不犹豫的自己。那时他未必比现在想得明白，却可以很自然地相信，自己想做的事应该由自己去做。如今连想坚持都带着顾虑，仿佛每一次抬起心气，都可能亏待这副已经疲惫的身体。他因此感到一种孤单：他终于学会了不伤害自己，却不知道该怎样继续要求自己。他不甘心把体谅变成放弃，也害怕为了摆脱这份不甘，又把自己逼回原来的苦处。曾经让他安静下来的温柔仍然可贵，但他越来越清楚，光有温柔，还不足以安顿他对自己的全部期待。

**206—213**

这样的不甘使他疲惫，甚至差一点又想责怪自己太软弱。可是他已经知道，责怪并不能使身体多出一点力量，只会让自己更加难受。他想起先前终于肯体谅身体时得到的安宁，心里又稍稍松开了一些。这一次，他不再把安宁误认为所有困难都有了答案。他明白，那份温柔并没有答应他从此不再为难，只是让他在为难时不必厌恶自己。他仍可以舍不得过去的坚定，也可以为如今的无力而难过；这些感受不一定要立刻争出谁对谁错。

**214—215**

也正因为终于允许自己同时怀着这些感受，他忽然看清了最初那份恐惧里更隐秘的东西：他不只是害怕身体有一天会垮下去，更害怕自己竟会允许它垮下去。原来他那么急于证明坚定，是怕自己先在心里放弃了自己。

**216—225**

明白了这一点，他反而更加舍不得过去那种不费力的确信。他仍暗暗盼着，哪怕只有一点点，也能重新体会到想挺直就能挺直的感觉。但他已经尝过硬撑的代价，不敢再把这样的渴望轻易当成命令。他越是小心对待它，越发现自己真正放不下的，并不只是身体原先拥有的力量，而是那种能够亲自决定的自由。他可以接受有些事做不到，却不愿意因为害怕做不到，就连想做的权利也一并放弃。这个愿望不再那么容易被他称作逞强了。它是真实的，和身体的疲惫一样真实。他终于不能再为了得到安宁而压下它。

**226—241**

既然仍然想要自己作主，他便不能一直回避这个愿望；但既然身体确实虚弱，他也不能再拿不认输当作不顾一切的理由。这两件事都已经有过充分的根据，他无法再简单地舍弃其中一件。他想起最初拼命挺直时的骄傲，那份骄傲不是虚假的，他确实从中感到自己仍有力量；可随之而来的虚脱也同样真实。他又想起放松时得到的轻快，想起终于不再责怪自己时的安宁，那些也不是逃避的借口；可它们终究没有替他承担那些仍然珍惜的选择。他一再想从中找出一种不用付出代价的办法，却终于承认，也许根本没有这样的办法。只要身体还在衰弱，往后有些坚持就会很难，有些退让也一定会令人遗憾。他真正需要分清的，不再是怎样选择才能证明自己不软弱，而是即使明白会吃力、会失去一些东西，他究竟还愿意承担什么。这样想着，他反而不愿再等过去那个毫不犹豫的自己回来。难道一定要毫无困难，决定才算自己的决定？难道明知身体有了限度，仍愿意承担某件事，就不算坚定吗？他已经不能像从前那样确信结果，却渐渐能够确信自己的心意。他不必先变回原来的样子，才有资格决定怎样继续活着。

**242—253**

有了这份认识，他终于重新愿意挺直腰。这一次，他不是急着证明衰弱奈何不了自己，也不是试图把失去的力量硬抢回来。他知道会吃力，知道自己可能无法一直维持，却仍然觉得，有些时候，他就是愿意这样要求自己。他不再因为身体吃力就怀疑这份意愿是否真实，也不再因为自己作出了决定，就要求身体必须毫无困难地完成它。过去他总要等到确实撑住了，才敢为自己骄傲；现在，即使知道支撑并不稳固，他也能为自己没有放弃作主而高兴。这份喜悦和最初的骄傲十分相似，却又有了不同的分量。那时他想借着挺直的身体确信自己没有变弱；如今他已经承认自己确实变弱，仍然不愿把所有决定都交给这份虚弱。他感到一种久违的昂扬，却不再需要靠否认疲惫来维持它。

**254—288**

而最使他惊讶的是，当他不再拿坚定去否认疲惫，先前只有在放松时才能感到的温柔，竟然也能留在这份骄傲里了。他依旧珍惜挺直腰时的自己，却不再厌恶那个偶尔撑不住的自己；他依旧希望靠自己的力量作决定，却知道真正属于自己的决定，也必须把身体的限度算进去。过去这两份要求总像在彼此争夺：要么坚定，就不能容忍软弱；要么体谅自己，就仿佛得放下一些不甘。如今他才知道，自己并不需要在两者之间选出一个永远正确的答案。他可以一边为失去的力量难过，一边珍惜尚有的力量；可以承认害怕，却仍然愿意坚持；也可以在实在吃力时停下来，而不必因此怀疑先前的决心。

这让他尝到一种比最初更加深厚的满足。因为他终于不必把自己分成两半，一半负责催促，一半负责承受，也不必等到身体重新变得强健，才允许自己感到完整。他曾经那么怕退让，仿佛只要稍稍弯下腰，心里珍惜的一切也会跟着垮下去。现在他知道，有些力气确实不会再回来，有些过去能够轻易做到的事，以后也许只能艰难地完成，甚至再也无法做到。想到这些，他仍然伤心；这份伤心没有被胜利冲淡，也没有因为他想通了什么就失去分量。但他不再觉得，承认这些失去，就等于必须把剩下的一切也交出去。

慢慢地，他心里不再那么急了。他不必时时检验自己是否足够坚定，也不必为了保护自己而时时劝自己放下。往后他仍会遇到难以决定的时候，仍会在想坚持时顾虑身体，在想歇息时舍不得自己的心愿；可这些为难不再使他觉得自己是一个失败的人。他已经知道怎样认真地希望，也知道怎样认真地承认做不到。两者之间依旧有痛苦，却不必再有那种永无休止的自责。

他终于可以安静地接受，自己已经不再是过去那个不费力就能挺直腰的人。而当他真正接受这一点，心里反而留下了一份更踏实的坚定。他无法决定身体还会虚弱到什么程度，也无法保证自己每一次想挺直时都能挺直。但他仍然可以顾惜这副身体，仍然可以有不愿退让的心愿，仍然可以为自己能够承担的事作出决定。

他不必永远站得笔直，才能相信自己没有倒下。
