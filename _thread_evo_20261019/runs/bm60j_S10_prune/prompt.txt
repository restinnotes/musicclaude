第4段（24–34）［没在想］
  话头散了，他更专心体会两人安静待着的快乐，忽然想把这一会儿牢牢记住。
      ← 改写：（17–23）「想续又不舍」　——刚才他想用说话延长相处，又舍不得打断安静；那股想留住这一刻的心思，如今转成了想好好记住它。
  → 想到这一会儿迟早只能靠回想重温，他心里猛地发酸；对方此刻仍在身边，又让他暖起来。
      ← 唤起：（4–16）「舍不得这一刻」　——先前他已在快乐中感到时间流走的酸楚；如今连安静相伴都想记牢，使他提前想到日后只能回味此刻，又被眼前仍有的亲近安慰。
第5段（35–39）［正在面对］
  他刚想把安静相伴的这一刻记牢，却忽然在想：对方也觉得它特别吗？熟悉的亲近一下没了把握。
      ← 唤起：（24–34）「想记牢此刻」　——先前他开始想把安静相伴的快乐牢牢记住。这一次，正因为他已经把这段相处看得特别珍贵，才忽然想到自己不知道对方是否也这样看。刚才足以令他安心的亲近，此刻无法替他回答这个疑问。
  → 他想问一句，又怕打破彼此的自在；念头慢慢退了，心里却像只剩自己在守着这一刻。
      ← 限制：（1–3）「留住眼下的自在」　——最初他为了守住彼此的自在而留下那句心意，这份顾虑在他想问对方怎么看待这一刻时重新起了作用。但这次沉默除了保护自在，还让他更清楚地感到，自己珍藏的东西在对方心里是什么分量，他并不知道。
第6段（40–50）［没在想］
  刚才像只剩自己守着这一刻，他细细回味，竟尝到一种只属于自己的甜。
      ← 改写：（35–39）「想问又怕，独自守着」　——刚才问不出口，让他觉得只有自己在珍藏这一刻。如今这份独自珍藏露出另一面：他细想自己有多喜欢这段相处，心里竟也有快乐。
      ← 唤起：（24–34）「想记牢此刻」　——先前他已经想把安静相伴的快乐牢牢记住。如今心思回到这份值得珍藏的相处上，回味本身也给了他一点甜意。
  → 想起对方未必也会这样记着，他仍有点酸，却舍不得停下回味。
      ← 唤起：（35–39）「不知道对方是否也珍惜」　——他刚刚因为不知道对方是否同样珍惜而失去把握。现在独自回味得开心，那份不知道又轻轻刺了他一下；只是这一次，回味本身也让他舍不得停。
第7段（51–61）［没在想］
  那份亲近在回想里像又经历一遍，他忍不住想象两人还能多待一会儿，身上都暖了起来。
      ← 改写：（40–50）「独自回味的甜」　——他刚刚体验到，独自回想相处本身就能带来快乐。这一次，他顺着那份快乐想象两人还能继续相伴，回忆便成了可以在心里多经历一会儿的亲近。
  → 可想到真正相伴的时间终究留不住，他心里一酸，又忍不住把那段相处从头想了一遍。
      ← 唤起：（24–34）「提前舍不得」　——先前想到相处终将只能靠回忆重温，他已经为此心酸。如今想象中的相伴仿佛可以延续，真实时间却不会跟着延长，这份落差使他发酸，也使他更想反复重温。
第8段（62–71）［没在想］
  又把那段相处想了一遍，他忽然高兴得想笑，甚至暗自打趣自己怎么这么喜欢对方。
      ← 改写：（51–61）「明知留不住仍反复重温」　——上一段他因为舍不得真实相伴的时间流走，又把那段相处从头想了一遍。这次回想让他重新感到自己有多喜欢对方，原先带着酸楚的反复重温，竟让他开心得拿自己的喜欢打趣。
      ← 提供理由：（40–50）「独自回味的甜」　——他此前已经尝过独自回味也能带来的甜意。这份快乐如今不再只是静静品尝，他连自己这样喜欢对方都觉得有趣。
  → 正打趣着，心里的话忽然没了下文；他还在笑，已经开始怀念刚才那阵快活。
      ← 改写：（51–61）「明知留不住仍反复重温」　——先前他舍不得真实相处结束，便想再回味一次；如今回味本身又带来一阵意外的欢喜，他连这份刚刚生出的快乐也想再尝一次。
第9段（72–77）［正在面对］
  笑意停下，他忽然想把这份快乐讲给对方听；怕打乱自在，又把话留在心里。
      ← 改写：（62–71）「欢喜未尽便怀念」　——上一段他连独自回味时生出的快乐都开始怀念。如今笑意渐渐过去，他舍不得这份欢喜只留在自己心里，忽然想让对方也知道。
      ← 限制：（35–39）「想问又怕，独自守着」　——先前他想问对方是否珍惜那一刻，却怕打破自在而收住。如今想分享快乐时，这份顾虑再次使他把话留下；这一次，他想说的已经不只是疑问，还有自己的欢喜。
  → 想到对方未必把那一刻记得特别，刚才的笑忽然有点孤单，心里却还暖着。
      ← 唤起：（35–39）「不知道对方是否也珍惜」　——他曾因为不知道对方是否也珍惜相伴的时刻而失去把握。现在想把自己的快乐告诉对方，那份不知道让他想到，这阵笑也许只有自己才懂，因而感到孤单。
      ← 提供理由：（40–50）「独自回味的甜」　——他此前已经尝过独自回味带来的甜意，所以即使此刻觉得快乐无人分享，刚才回味时得到的温暖仍留在心里。
第10段（78–83）［没在想］
  刚才还为笑意无人分享而孤单，此刻想起自己笑得多傻，他又乐了，胸口也松了。
      ← 改写：（72–77）「欢喜里的孤单」　——上一段，他想到对方未必懂自己的笑，感到孤单，但回味留下的暖意还在。此刻重新想起自己笑得多开心，那份暖意又让他乐起来。与先前只顾傻笑不同，这次是在尝到孤单之后，仍被自己的快乐打动。
  → 那些逗他发笑的小念头接连浮起，他鼻子竟有点酸，只愿这阵短短的欢喜再多留一会儿。
      ← 唤起：（62–71）「欢喜未尽便怀念」　——此前他已经开始怀念独自回味时生出的欢乐。如今刚从孤单里重新尝到这份快乐，那些零星的小念头一一浮起，使他又舍不得这阵欢喜过去；这一次，开心里多了一点感动。

## 路B
第1段（1–3）［还说不清］
  一个想靠近的念头忽然冒出来，他竟为此高兴起来，却说不清自己在盼什么。
  → 这念头迟迟不散，他想再多留一会儿，又怕把一点喜欢当成太大的事。
第2段（4–16）［正在面对］
  那点喜欢留得久了，他开始想象与那人安静相处；光这样想着，心里就很暖。
      ← 提供理由：（1–3）「舍不得放下」　——他先前舍不得让那点喜欢散去，心里便逐渐容得下更具体的相处想象，也开始尝到其中的快乐。
  → 这份自在让他一时想多说些心意，又怕把喜欢看得太重；他轻轻收住，心里有点酸，也仍旧欢喜。
      ← 限制：（1–3）「舍不得放下」　——先前怕把一点喜欢看得过重，使他即使高兴得想多表达一些，也会把话收住。
第3段（17–23）［正在面对］
  心意收住后，他又回到与那人安静相处的想象里，心里慢慢松下来。
      ← 提供理由：（4–16）「想象中的亲近也让他快乐」　——他已经体验过想象中的安静相处也能带来快乐，所以收住表达之后，仍有一处让心安稳停留的地方。
      ← 提供理由：（4–16）「想说又收住，仍觉欢喜」　——刚才把想表达的心意收住，使他暂时从想说些什么，转回只在心里与那人亲近。
  → 刚才压下的喜欢偶尔又催他多说一点，怕说重的顾虑紧跟着回来，那些话便在心里打转。
      ← 限制：（4–16）「想说又收住，仍觉欢喜」　——先前想多表达却收住的经历，留下了尚想表达的心意；而怕把喜欢说得太重的顾虑仍在，使这念头反复冒出又受阻。
第4段（24–34）［正在面对］
  他又想象与那人静静相处，压在心里的喜欢使他想挨得更近，光这样想就甜得发酸。
      ← 提供理由：（17–23）「回到心里的亲近」　——他已经体验过，想象与那人安静相处能让自己快乐，所以仍愿意停留在这样的想象里。
      ← 唤起：（17–23）「收住的话又冒出来」　——那些反复想说又收住的喜欢仍在催促他，使这次的想象多了一股想更亲近的劲头。
  → 那段亲近终究只在心里，他忽然想把它留久些，急得舍不得停；过了一阵才慢慢松开。
第5段（35–39）［正在面对］
  急着留住心里相处的劲一松，他忽然觉得只是自己在想那人，心里空了一块。
      ← 提供理由：（24–34）「舍不得想象散去」　——前段的相处始终只在心里，他又急着延长它；一旦松开这股劲，刚才被亲近感盖住的独自想念便突出了。
  → 刚才光想象就那么快乐，他却怕这份快乐一会儿便散，拿不准还能留多久。
      ← 提供理由：（4–16）「想象中的亲近也让他快乐」　——他曾真切体验到光靠想象也能快乐，所以此刻格外舍不得这份快乐，也开始担心它离开投入的想象后还能持续多久。
第6段（40–50）［正在面对］
  怕刚才的甜意散了，他把心里与那人挨近的感觉想得格外细，竟甜得有些晕。
      ← 提供理由：（35–39）「担心快乐散去」　——他刚担心想象带来的快乐一松就会消失。此刻重新想到亲近，他格外留意每一点细小的感觉；先前急着延长整段相处的劲头，这次落在了眼下的贴近上。
  → 那人仿佛就在身旁，他却总想起自己独自一人；想再挨近些，心里又发酸。
      ← 限制：（35–39）「松开后的孤单」　——他已经体验过，相处的想象背后其实只有自己在想念。这个认识如今在想象仍然鲜明时就插了进来，使他感到甜蜜的同时，也惦记着那人并未真的在身旁。
第7段（51–61）［正在面对］
  独自想念的酸意还在，他反倒把那人想得更贴近，仿佛连气息都挨在一起。
      ← 提供理由：（40–50）「贴近时想起独处」　——上一段，独自一人的感觉已经闯入亲近的想象，使他发酸却仍想挨近。这一次，那份酸楚反而催着他把想象推向更贴身的地方。
  → 这份暖意叫他舍不得抽身，可刚才那点甜已成回味，他急着在眼前再多待一会儿。
      ← 提供理由：（40–50）「细想贴近的甜」　——上一段，他开始细细体会每一点贴近的感觉。如今这些细小的快乐让他深深沉进去，也让他察觉，一点甜意刚尝到便已成为回味，眼下的亲昵正在一刻刻过去。
第8段（62–71）［正在面对］
  先前咽回去的喜欢，这会儿在想象里几乎能对那人一口气说尽，畅快得想笑。
      ← 唤起：（17–23）「收住的话又冒出来」　——先前反复想说又收住的喜欢一直积在心里。这次的欢喜有了一个具体的去处：他仿佛能在想象中向那人尽情表达。
      ← 提供理由：（51–61）「被独处感催得更想贴近」　——上一段，他已经把那人想得几乎气息相接。这份贴近让心里那些话仿佛可以直接说给那人听，表达喜欢也带上了轻松、俏皮的兴致。
  → 还想在心里和那人多说几句，那股畅快却忽然淡了；笑意未退，他已怀念起刚才的放开。
      ← 唤起：（51–61）「沉醉时觉出片刻流逝」　——上一段，他开始切身感到刚尝过的甜意转眼便成回味。这一次，他正沉浸在尽情表达的快乐里，那股畅快却接不上了，使他立刻怀念起刚才；此前是眼看着片刻流走，这次是兴致正浓时突然失去了下文。
第9段（72–77）［正在面对］
  刚才在心里说得那么痛快，如今想到那人其实一句也没听见，胸口忽然发酸。
      ← 提供理由：（62–71）「心里痛快地表达」　——刚才他几乎把压着的喜欢都在想象里说尽了。如今那些话还清清楚楚，他却意识到，这番倾诉始终只发生在自己心里。
      ← 唤起：（40–50）「贴近时想起独处」　——此前，独自一人的感觉曾闯入鲜明的亲近想象。这次同样的距离落在刚才那些具体的话上：自己说得如此热切，那人却并未真的听见。
  → 他还想让那人听见一点，又怕话太重；刚才的暖意仍在，心里便一直悬着。
      ← 提供理由：（62–71）「欢喜未尽便怀念」　——上一段，他正想继续和那人说话，畅快却突然淡去。心里那些话仍有后劲，使他此刻格外希望其中至少有一点能真正传给那人。
      ← 限制：（4–16）「想说又收住，仍觉欢喜」　——他曾因怕把喜欢说得太重而收住表达。如今已经在想象里说了那么多，想到真让那人听见时，这份顾虑又使他迟疑。
第10段（78–83）［正在面对］
  知道那些话只给自己听过，他回味起倾诉时的欢喜，竟仍甜得鼻酸。
      ← 提供理由：（62–71）「心里痛快地表达」　——他曾在想象中尽情倾诉，并从中得到真切的快乐，所以如今仍有一份具体的甜蜜可以回味。
      ← 限制：（72–77）「那些话只有自己听见」　——他已经意识到那人一句也没听见。这使重新尝到的快乐带着一点独自想念的酸楚，而不是被对方听见后的安心。
  → 顺着这点甜，他在心里与那人静静贴近片刻；甜意轻轻过去，他舍不得，心却松了。
      ← 提供理由：（72–77）「想被听见，又怕说重」　——刚才他一直为想让那人听见多少而悬着。此刻重新享受只在心里的亲近，便有了格外松快的感觉；即使片刻过去，心里也还留着暖意。

## 路C
第1段（1–3）［还说不清］
  有句话忽然快到嘴边，他想到对方或许会听懂，心里一亮，又怕被听得太重。
  → 他把话留在心里，因为眼下的自在也很珍贵；可那股想开口的劲还在。
第2段（4–16）［没在想］
  那句话安静地留着，他渐渐敢享受对方的亲近，心里竟比刚才还要轻松。
      ← 提供理由：（1–3）「留住眼下的自在」　——先前把话留在心里，是为了守住彼此的自在；如今他能把注意力放在亲近本身，尝到保留心意也不妨碍的快乐。
  → 他真想多待一会儿，心里一阵发热，又为时间正在过去而发酸；眼前的好仍在，他渐渐安静。
第3段（17–23）［没在想］
  刚才还舍不得时间走，现在静静相伴也让他舒心，心思渐渐飘开。
      ← 提供理由：（4–16）「留话后的轻松」　——他已体验到把在意留在心里也能自在亲近，所以此刻连安静相伴也不觉得拘束，还能享受其中。
  → 他忽然想找些话再多待一会儿，却舍不得打断眼下的安静，话头又轻轻散了。
      ← 唤起：（4–16）「舍不得这一刻」　——先前舍不得相处时光流走，使他安静下来时又一瞬想用说话延长这一会儿；但此刻的安静本身也令他留恋。
第4段（24–34）［正在面对］
  连静静相伴都这样快乐，他忽然很想让对方知道，自己有多喜欢和对方待在一起。
      ← 提供理由：（17–23）「安静也亲近」　——他已经体会到安静相伴本身就令人快乐，所以此刻想让对方知道的，是连这样待着都让自己十分高兴。
      ← 改写：（17–23）「想续又不舍」　——刚才想找话是为了多待一会儿；如今想说话的心思变了，他更想让对方明白自己有多在意。
  → 话几乎要出口，他又怕对方此后难以自在；心里热得发紧，话停在嘴边。
      ← 限制：（1–3）「留住眼下的自在」　——当初把心意留下，是怕说出来改变彼此的自在；如今真想表达时，这个顾虑又拦住了他。
第5段（35–39）［没在想］
  想到那句话收住了，眼下的自在还能继续，他绷紧的心渐渐松了下来。
      ← 提供理由：（24–34）「热切中的迟疑」　——刚才他担心说出心意会使对方难以自在；如今话已停住，眼前珍惜的相处仍能继续，那份急切和紧张便慢慢退下。
  → 可他忽然想：对方也喜欢这样安静待着吗？猜不着，明明仍在一起，他却有点孤单。
      ← 改写：（24–34）「想让对方知道」　——上一段他因为静静相伴太快乐，一心想让对方知道自己的高兴；此刻想开口的劲退去，他开始好奇对方是否也觉得这样的相处很好，原先只顾自己高兴的心思转向了对方。
第6段（40–50）［没在想］
  对方的心思仍猜不透，可想到自己能这样陪着，连暗暗喜欢也变得甜蜜。
      ← 唤起：（17–23）「安静也亲近」　——他先前已经体会过，安静陪着对方本身就令人快乐。如今虽然猜不透对方的心，那份亲身尝过的好仍能让他高兴。

## 路E
第1段（1–3）［还说不清］

  → 这份暖意叫他舍不得抽身，可刚才那点甜已成回味，他急着在眼前再多待一会儿。
      ← 提供理由：（40–50）「细想贴近的甜」　——上一段，他开始细细体会每一点贴近的感觉。如今这些细小的快乐让他深深沉进去，也让他察觉，一点甜意刚尝到便已成为回味，眼下的亲昵正在一刻刻过去。
第8段（62–71）［正在面对］
  先前咽回去的喜欢，这会儿在想象里几乎能对那人一口气说尽，畅快得想笑。
      ← 唤起：（17–23）「收住的话又冒出来」　——先前反复想说又收住的喜欢一直积在心里。这次的欢喜有了一个具体的去处：他仿佛能在想象中向那人尽情表达。
      ← 提供理由：（51–61）「被独处感催得更想贴近」　——上一段，他已经把那人想得几乎气息相接。这份贴近让心里那些话仿佛可以直接说给那人听，表达喜欢也带上了轻松、俏皮的兴致。
  → 还想在心里和那人多说几句，那股畅快却忽然淡了；笑意未退，他已怀念起刚才的放开。
      ← 唤起：（51–61）「沉醉时觉出片刻流逝」　——上一段，他开始切身感到刚尝过的甜意转眼便成回味。这一次，他正沉浸在尽情表达的快乐里，那股畅快却接不上了，使他立刻怀念起刚才；此前是眼看着片刻流走，这次是兴致正浓时突然失去了下文。
第9段（72–77）［正在面对］
  刚才在心里说得那么痛快，如今想到那人其实一句也没听见，胸口忽然发酸。
      ← 提供理由：（62–71）「心里痛快地表达」　——刚才他几乎把压着的喜欢都在想象里说尽了。如今那些话还清清楚楚，他却意识到，这番倾诉始终只发生在自己心里。
      ← 唤起：（40–50）「贴近时想起独处」　——此前，独自一人的感觉曾闯入鲜明的亲近想象。这次同样的距离落在刚才那些具体的话上：自己说得如此热切，那人却并未真的听见。
  → 他还想让那人听见一点，又怕话太重；刚才的暖意仍在，心里便一直悬着。
      ← 提供理由：（62–71）「欢喜未尽便怀念」　——上一段，他正想继续和那人说话，畅快却突然淡去。心里那些话仍有后劲，使他此刻格外希望其中至少有一点能真正传给那人。
      ← 限制：（4–16）「想说又收住，仍觉欢喜」　——他曾因怕把喜欢说得太重而收住表达。如今已经在想象里说了那么多，想到真让那人听见时，这份顾虑又使他迟疑。
第10段（78–83）［正在面对］
  怕说重，又盼那人听见一点；他忽然想象把极轻的一句喜欢送到那人耳边。
      ← 提供理由：（72–77）「想被听见，又怕说重」　——他刚刚生出让那人真正知道一点喜欢的愿望，却又怕表达过重，所以这次想象的是把很轻的一点心意传给那人。
      ← 改写：（72–77）「那些话只有自己听见」　——先前在心里说得痛快，随后却知道对方一句也没听见。这使他这次想象的重点从自己尽情说话，转向那人真的听见一点。
  → 单是想象那人听见一点，他便甜得想哭，仿佛贴近了片刻；念头一散，心里仍发酸。
      ← 限制：（72–77）「那些话只有自己听见」　——他已经切身感到那些话并未传到那人那里，所以眼下仿佛被听见的快乐只能停留在想象里；短暂的甜蜜过去，独自想念的酸楚便又浮现。

## 路F
第1段（1–3）［还说不清］
  有句话忽然快到嘴边，他想到对方或许会听懂，心里一亮，又怕被听得太重。
  → 他把话留在心里，因为眼下的自在也很珍贵；可那股想开口的劲还在。
第2段（4–16）［没在想］
  那句话安静地留着，他渐渐敢享受对方的亲近，心里竟比刚才还要轻松。
      ← 提供理由：（1–3）「留住眼下的自在」　——先前把话留在心里，是为了守住彼此的自在；如今他能把注意力放在亲近本身，尝到保留心意也不妨碍的快乐。
  → 他真想多待一会儿，心里一阵发热，又为时间正在过去而发酸；眼前的好仍在，他渐渐安静。
第3段（17–23）［没在想］
  刚才还舍不得时间走，现在静静相伴也让他舒心，心思渐渐飘开。
      ← 提供理由：（4–16）「留话后的轻松」　——他已体验到把在意留在心里也能自在亲近，所以此刻连安静相伴也不觉得拘束，还能享受其中。
  → 他忽然想找些话再多待一会儿，却舍不得打断眼下的安静，话头又轻轻散了。
      ← 唤起：（4–16）「舍不得这一刻」　——先前舍不得相处时光流走，使他安静下来时又一瞬想用说话延长这一会儿；但此刻的安静本身也令他留恋。
第4段（24–34）［没在想］
  话头散了，他更专心体会两人安静待着的快乐，忽然想把这一会儿牢牢记住。
      ← 改写：（17–23）「想续又不舍」　——刚才他想用说话延长相处，又舍不得打断安静；那股想留住这一刻的心思，如今转成了想好好记住它。
  → 想到这一会儿迟早只能靠回想重温，他心里猛地发酸；对方此刻仍在身边，又让他暖起来。
      ← 唤起：（4–16）「舍不得这一刻」　——先前他已在快乐中感到时间流走的酸楚；如今连安静相伴都想记牢，使他提前想到日后只能回味此刻，又被眼前仍有的亲近安慰。
第5段（35–39）［正在面对］
  他刚想把安静相伴的这一刻记牢，却忽然在想：对方也觉得它特别吗？熟悉的亲近一下没了把握。
      ← 唤起：（24–34）「想记牢此刻」　——先前他开始想把安静相伴的快乐牢牢记住。这一次，正因为他已经把这段相处看得特别珍贵，才忽然想到自己不知道对方是否也这样看。刚才足以令他安心的亲近，此刻无法替他回答这个疑问。
  → 他想问一句，又怕打破彼此的自在；念头慢慢退了，心里却像只剩自己在守着这一刻。
      ← 限制：（1–3）「留住眼下的自在」　——最初他为了守住彼此的自在而留下那句心意，这份顾虑在他想问对方怎么看待这一刻时重新起了作用。但这次沉默除了保护自在，还让他更清楚地感到，自己珍藏的东西在对方心里是什么分量，他并不知道。
第6段（40–50）［没在想］
  刚才像只剩自己守着这一刻，他细细回味，竟尝到一种只属于自己的甜。
      ← 改写：（35–39）「想问又怕，独自守着」　——刚才问不出口，让他觉得只有自己在珍藏这一刻。如今这份独自珍藏露出另一面：他细想自己有多喜欢这段相处，心里竟也有快乐。
      ← 唤起：（24–34）「想记牢此刻」　——先前他已经想把安静相伴的快乐牢牢记住。如今心思回到这份值得珍藏的相处上，回味本身也给了他一点甜意。
  → 想起对方未必也会这样记着，他仍有点酸，却舍不得停下回味。
      ← 唤起：（35–39）「不知道对方是否也珍惜」　——他刚刚因为不知道对方是否同样珍惜而失去把握。现在独自回味得开心，那份不知道又轻轻刺了他一下；只是这一次，回味本身也让他舍不得停。
第7段（51–61）［没在想］
  那份亲近在回想里像又经历一遍，他忍不住想象两人还能多待一会儿，身上都暖了起来。
      ← 改写：（40–50）「独自回味的甜」　——他刚刚体验到，独自回想相处本身就能带来快乐。这一次，他顺着那份快乐想象两人还能继续相伴，回忆便成了可以在心里多经历一会儿的亲近。
  → 可想到真正相伴的时间终究留不住，他心里一酸，又忍不住把那段相处从头想了一遍。
      ← 唤起：（24–34）「提前舍不得」　——先前想到相处终将只能靠回忆重温，他已经为此心酸。如今想象中的相伴仿佛可以延续，真实时间却不会跟着延长，这份落差使他发酸，也使他更想反复重温。
第8段（62–71）［没在想］
  又把那段相处想了一遍，他忽然高兴得想笑，甚至暗自打趣自己怎么这么喜欢对方。
      ← 改写：（51–61）「明知留不住仍反复重温」　——上一段他因为舍不得真实相伴的时间流走，又把那段相处从头想了一遍。这次回想让他重新感到自己有多喜欢对方，原先带着酸楚的反复重温，竟让他开心得拿自己的喜欢打趣。
      ← 提供理由：（40–50）「独自回味的甜」　——他此前已经尝过独自回味也能带来的甜意。这份快乐如今不再只是静静品尝，他连自己这样喜欢对方都觉得有趣。
  → 正打趣着，心里的话忽然没了下文；他还在笑，已经开始怀念刚才那阵快活。
      ← 改写：（51–61）「明知留不住仍反复重温」　——先前他舍不得真实相处结束，便想再回味一次；如今回味本身又带来一阵意外的欢喜，他连这份刚刚生出的快乐也想再尝一次。
第9段（72–77）［正在面对］
  笑意停下，他忽然想把这份快乐讲给对方听；怕打乱自在，又把话留在心里。
      ← 改写：（62–71）「欢喜未尽便怀念」　——上一段他连独自回味时生出的快乐都开始怀念。如今笑意渐渐过去，他舍不得这份欢喜只留在自己心里，忽然想让对方也知道。
      ← 限制：（35–39）「想问又怕，独自守着」　——先前他想问对方是否珍惜那一刻，却怕打破自在而收住。如今想分享快乐时，这份顾虑再次使他把话留下；这一次，他想说的已经不只是疑问，还有自己的欢喜。
  → 想到对方未必把那一刻记得特别，刚才的笑忽然有点孤单，心里却还暖着。
      ← 唤起：（35–39）「不知道对方是否也珍惜」　——他曾因为不知道对方是否也珍惜相伴的时刻而失去把握。现在想把自己的快乐告诉对方，那份不知道让他想到，这阵笑也许只有自己才懂，因而感到孤单。
      ← 提供理由：（40–50）「独自回味的甜」　——他此前已经尝过独自回味带来的甜意，所以即使此刻觉得快乐无人分享，刚才回味时得到的温暖仍留在心里。
第10段（78–83）［正在面对］
  刚才那股想分享的劲还在，一想到对方未必懂自己的笑，他忽然很想哭。
      ← 改写：（72–77）「想分享又收住」　——上一段，他想把独自回味的快乐告诉对方，却为了守住自在收住了话。那股想分享的劲并没有散去；如今想到自己竟如此想让对方懂得那阵欢喜，原先的犹豫转成了一阵强烈的感动。
      ← 提供理由：（72–77）「欢喜里的孤单」　——上一段，他已经尝到那阵笑可能只有自己才懂的孤单。这一次，想分享的愿望仍然鲜明，那份无人确定能否理解的距离便格外让他鼻酸。
  → 想讲给对方的相伴片刻一股脑儿浮起，他胸口像被松开了一下，眼里还热着。
      ← 唤起：（72–77）「想分享又收住」　——先前收住的是想把回味时的欢乐讲给对方听的冲动。此刻这份冲动牵出一个个想讲的相伴片刻，心里积着的欢喜接连涌过，使他短暂地感到舒展；他仍然为对方未必懂得而眼眶发热。
