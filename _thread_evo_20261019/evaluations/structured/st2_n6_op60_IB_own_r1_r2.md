# st2_n6_op60_IB_own_r1_r2

**这件事：**一个人怎样从渴望亲密又怕失去自己，走到分清亲密、成长和享受所得的不同需要，并让它们即使无法总协调，也共同属于自己的生活。

**走向：**他先在相互回应的亲密里发现，靠近别人和保有自己可以同时成立；随后又明白，亲密虽真实，却不能保证长久，也安顿不了所有愿望。接着，他认出成长和享受所得也各自带来满足，困扰便从追问还缺什么，转到几种需要怎样共处。最后，他尝试把成长带回亲密，同时放下永久协调的要求，学会珍惜已有、承认未得，让不同需要各有位置。

### 1–3

**他想靠近，也怕靠得太近会把自己弄丢**
→ 于是这些愿望能否同时被满足？

### 4–16

**他第一次发现，亲密里也能保有自己的声音**
← 因为（1–3）他同时想要回应和保有自己，双方都能表达的关系暂时容下了两者。
↺ 原先不知靠近和独立能否兼得，现在亲身发现它们可以暂时并存。
→ 于是先信任这份亲密，再检验它能否持续

### 17–23

**幸福是真的，可他开始怀疑它能走多远**
← 因为（4–16）相互回应确实发生过，他才有根据追问这份亲近意味着什么。
↺ 原先觉得相互回应足以支撑信任，现在追问它能否持久。
→ 于是查明亲密成立的条件

### 24–34

**他不再因亲密有限，就把它判成假的**
← 因为（17–23）他发现亲近未必长久，却没有理由抹去它曾经的真实。
↺ 原先怕没有长久保证就难以信任，现在承认亲密真实有限，不能包办所有愿望。
→ 于是开始辨认亲密之外的需要

### 35–39

**关系安稳了，他才看见自己还想成长**
← 因为（24–34）他承认亲密真实却有限，才腾出空间看见成长也有独立价值。
↺ 原先只想守住亲密，现在承认它有限，也看见成长是独立需要。
→ 于是走出熟悉的安稳，试试别的可能

### 40–50

**他终于想主动往前走，却怕关系会变**
← 因为（35–39）他已认出成长是自己的需要，不想再为安稳压住它。
↺ 原先主要看自己有没有被回应，现在还要衡量成长带来的变化和代价。
→ 于是寻找成长与亲密都能留下的办法

### 51–61

**他确认成长是认真的，却不想拿亲密来交换**
← 因为（40–50）向外发展带来充实，也让他担心原有关系会被改变。
↺ 原先还疑心成长只是兴奋或逃离，现在确认它是持久需要，却不能替代亲密。
→ 于是想办法让两种需要都留下

### 62–71

**他开始享受已经得到的，不急着追下一步**
← 因为（51–61）成长已被确认，他不必靠不停追逐证明它的重要。
↺ 原先把充实看成持续向前，现在发现停下来体验所得也能满足自己。
→ 于是分清真实欠缺和追逐惯性

### 72–77

**几种满足都是真的，他却不知道怎么让它们共处**
← 因为（62–71）他开始享受已有的充实，仍发现几种满足无法自动协调。
↺ 原先只觉得愿望没被满足，现在看见几种满足各有价值，却难共处。
→ 于是把问题转向怎样安排共同生活

### 78–83

**他看清冲突了，却还没有办法把它解开**
← 因为（72–77）亲密、成长和享受所得都成立，难题已是它们怎样共处。
↺ 原先知道不能二选一，仍盼着找到两全答案；现在承认看清也不等于能解决。
→ 于是先带着未解的拉扯继续生活

### 84–92

**他回头检验亲密：关系容得下变化后的我吗？**
← 因为（40–50）成长曾让他担心关系失衡，现在他要检验亲密能否容纳变化。
↺ 原先因相互回应而信任亲密，现在还要看它能否容纳成长中的自己。
→ 于是把旧日的信任放进变化中检验

### 93–102

**他开始把成长带回亲密，不必每次都选边**
← 因为（72–77）他已看清难题是几种满足怎样共处，开始寻找实际的相容方式。
↺ 原先把成长看作离开亲密，现在发现成长也能丰富亲密。
→ 于是让两种满足进入同一种生活

### 103–110

**他没把眼前的和谐当成永久保证，还重新确认成长仍重要**
← 因为（17–23）他早已知道亲近真实发生过也不能保证它永远成立；如今这条经验再次适用。
↺ 原先刚看到亲密与成长能相容，现在也不把新融合当成永久保证。
→ 于是辨认已满足与仍不能放弃的需要

### 111–116

**他终于能珍惜所得，也允许自己仍有遗憾**
← 因为（1–3）他最初就隐约知道，几种愿望未必能由同一个答案安顿。
↺ 原先想让一个答案消除矛盾，现在承认有限的满足仍有价值，融合也未必永久。
→ 于是珍惜所得，也继续回应未满足的需要
