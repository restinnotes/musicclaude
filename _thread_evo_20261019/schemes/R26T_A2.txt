下面是同一首作品的几条 Thread 人物经历候选。你完全看不到珠子，也不要根据音乐细节评判。

你的任务是从这些候选中，选出最可能写成一条独立成立、连贯、简洁、像真人经历的 Thread 的路线。

不要把戏剧化、认识次数多、结局明确、解释完整当作优点。

【先检查关键前提】

对每条候选，先找出最影响后续发展的重要认识、愿望或选择，尤其是后面多个段落都依赖的转折。

逐项检查：

1. 它最早出现时，人物凭什么会这样想？
2. 前面的 state 是否真正提供了足以支持它的经历，而不只是提供了相近的情绪或主题？
3. 它是人物能够确定的事实、对亲历的理解，还是仍有不确定性的猜测？
4. 后文有没有把猜测当成事实，或者把一种有限的认识扩大成没有依据的结论？
5. 如果这项认识不成立，后面是否会有多段经历失去根据？

established 只能记录首次成立的位置，不能代替前因证明。depends_on 也只有在所指 state 确实能支持当前内容时才有效。

不能因为人物说自己想起了旧经历，就默认新认识已经获得了依据。

【再检查整条经历】

1. 是否从头到尾是一件事，同时有足够丰富的所求、顾虑、感受和后果，而不只是一个心理动作反复出现？
2. 后一阶段是否继承前面已经发生的事？人物的处境是否在积累，而不是每次重新遇到同一个问题？
3. 同一认识、决定或愿望是否被多次写成第一次成立？若重新出现，究竟是延续、后果，还是有依据的新变化？
4. 是否把情绪强弱变化当作了人物处境或认识的变化？
5. 是否反复经历类似的自我解决与重新动摇，却没有新的处境或后果？
6. 段落里没有新进展时，是否允许人物只是继续感受、沉浸、承受或暂时不想整件事？
7. 人物此刻的所求和顾虑是否具体可懂？是否过度依靠心理概念和解释性总结支撑路线？
8. 前后事实、人物动机、确定程度是否一致？有没有在后文重新发明前面没写过的动机或经历？
9. Center 是否确实组织了整件事，而不是被缩成一套狭窄的心理机制，或被当作每段都要重新表述的主题？

【怎样选择】

优先选择关键转折有充分依据、前后经历能够自然积累的路线。

有两条都成立时，再比较哪条更具体、更少重复、更像一个人在真实经历，而不是比较哪条转折更多。

一条路线即使情绪丰富，如果后半篇严重依赖某项没有依据的新事实，也不能因为其他部分精彩就把它排在前面。

反过来，不能因为某条路线允许延续、沉浸或未解决的结尾，就认为它缺乏推进。

允许选择少于 3 条，不必凑满。

【输出】

先分别给每条路线：

- coherence：1–10
- forward_motion：1–10
- prerequisite_integrity：1–10
- non_repetition：1–10
- human_plausibility：1–10
- 主要问题：指出真正影响整条经历成立的问题，尤其说明关键转折是否有足够前因

其中：

- forward_motion 衡量已有经历怎样积累并改变后续处境，不衡量新转折的数量。
- prerequisite_integrity 衡量关键认识和后续事实的依据强度，不只看有没有填写 depends_on。
- non_repetition 区分必要的持续感受与重复完成同一心理动作。
- human_plausibility 同时考虑具体所求、顾虑以及人物知道事情的合理程度。

然后选出最多 3 条进入下一步，按优先顺序排列。

不要修改或改写候选，不要补充候选没有的前因，不要预先设计最终文案。

沿用原有 JSON 输出字段和结构。

只输出 JSON。
