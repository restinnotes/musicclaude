# Op.60｜关系图

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3　（还说不清）

- 他还说不清自己究竟在盼什么，只知道心里有了格外想亲近的人。
- 想到那个人，他心里便不由自主地柔软起来，可想多留一会儿又本能地往回收。
- → 这份喜欢轻得仿佛随时能放下，他却偏偏舍不得放下。

### 4–16　（正在面对）

- 他还不知道自己怕什么，便先不替这份在意安排去向，慢慢安心地亲近那个人。
  - ← 提供理由：（1–3）「亲近时又收回」
- → 他喜欢能自由地给出温柔，不用总确认对方有没有感受到，也能保有从容。
- → 这份快乐让他渐渐放下对喜欢的提防，也有些满意自己竟能如此宽和。
- → 他一度觉得，只要亲近自然、不追问也不计较，这样就已经足够。

### 17–23　（正在面对）

- 这份亲近已经让他尝到幸福，他开始希望这份喜欢能长久，不只属于眼前。
  - ← 唤起：（4–16）「喜欢带来安稳」
- → 一想到长久，他便意识到自己能决定怎样珍惜对方，却不能决定对方是否也珍惜自己。
- → 他偶尔想知道对方是否也把自己看得特别，也意外发现这点期待已让心里没那么平静。　✦ 满足照出未满足
  - ← 动摇：（4–16）「觉得亲近已足够」

### 24–34　（正在面对）

- 对方并未答应什么，他也不想让新添的紧张破坏快乐，或把喜欢变成催促。
  - ← 提供理由：（17–23）「想知道是否特别」
  - ← 限制：（17–23）「不能决定对方心意」
- → 他提醒自己，关心、给予和真心为对方高兴，本身就能带来实实在在的快乐。
- → 这样想让他轻松下来，也更愿意付出，不再小心计算自己给了多少。
- → 他享受毫不勉强地热烈喜欢，一度相信只要不提要求，就不会失去什么。

### 35–39　（还说不清）

- 欢喜稍稍平息后，他仍想知道自己是否也被对方放在心上。　✦ 办法的限度
  - ← 动摇：（24–34）「以为无求就不失去」
- → 他为这个念头感到难堪，开始怀疑那些体贴里是否一直藏着自己不愿面对的期待。
- → 他知道先前的快乐并非为了换取对方同样的珍惜，却也不能再说自己毫无所求，只能暂时停在不自在里。

### 40–50　（正在面对）

- 这份难堪没有减轻他的喜欢，却让他不愿再用慷慨证明自己，也不想逼自己毫无期待。
  - ← 改写：（35–39）「快乐并非交换」
- → 他只顾此刻真心愿意给予的关切，盼对方好，不拿心意衡量两人的关系。
- → 把喜欢留在心里也很甜，他暂时忘了自己为何那么在意对方的态度，先前的疑问却仍未解决。

### 51–61　（正在面对）

- 这份不声张的甜意留久了，喜欢便不像起初那样轻巧。
  - ← 改写：（40–50）「独自喜欢也很甜」
- → 他对那个人的惦念更深，也希望自己的关切能被领会，有时心里满是对方。
- → 他仍觉得不该催促对方，也舍不得让对方迁就自己，只好独自收着还没着落的盼望。　✦ 选择的代价
- → 他仍觉得这份喜欢值得珍惜，只是舍不得减轻它，原以为能轻轻放着的心意如今有了重量。
- ⟲ 仍在起作用：（24–34）「不想催促对方」

### 62–71　（正在面对）

- 心意已经这么深，他忽然不想再把喜欢当成必须时时约束的东西。
  - ← 改写：（51–61）「喜欢不再轻巧」
- → 他想起安心亲近、愿意付出的满足和独自珍藏的甜蜜，这些快乐并不靠承诺才发生。
- → 他不愿因怕受伤连高兴都小心翼翼，想尽情喜欢，不急着追问结果或安排退路。
- → 他终于能坦然享受积攒许久的热情，一度几乎感觉不到没有保证带来的沉重。

### 72–77　（正在面对）

- 欢喜稍稍落下后，他发现自己真正想要的东西已不能再含糊过去。
  - ← 唤起：（62–71）「热情盖过顾虑」
- → 他不只想尽情喜欢，也想知道对方是否同样渴望靠近、同样珍惜这份亲密。
- → 他渐渐看清自己想要得很深，也明白自己的热烈不能成为对方必须同样喜欢的理由。　✦ 分清
- → 他想不出两全的办法：退回谨慎像辜负刚敢面对的真心，继续盼望又怕成了要求，让他委屈又厌倦。　✦ 选择的代价
- ⟲ 仍在起作用：（51–61）「独自收着盼望」

### 78–83　（正在面对）

- 他终于不想逼自己立刻作出选择，决定暂时不替这份感情下结论。
  - ← 改写：（72–77）「两种选择都委屈」
- → 他允许自己带着愿望安静地喜欢，也知道自己没有把握，不急着靠近或压住眷恋。
- → 两种心思仍在，却不再互相催逼，他松了口气，先前的为难也没有消失。

### 84–92　（正在面对）

- 不再强迫自己消除渴望后，他重新感到最初亲近一个人的快乐。
  - ← 唤起：（78–83）「两种心思不再相逼」
- → 这次他尝过期待的紧张和难堪，也知道自己的喜欢不能替对方决定心意，却仍愿意喜欢。
  - ← 改写：（35–39）「快乐并非交换」
- → 他不再拿无所求证明体贴，也不因想被珍惜而怀疑真心，明知可能受伤仍愿投入，仍能高兴也让他感动。

### 93–102　（没在想）

- 他不再遮掩渴望后，更清楚自己多么想和那个人亲近。
  - ← 唤起：（84–92）「不再怀疑热切真诚」
- → 他想被对方同样深切地珍惜，也想把整个自己交给这份亲近，还想知道两人能共享多少幸福。
- → 虽无新保证，他一时顾不上以后会怎样，只觉得爱着本身已让生命充实，几乎无需再添什么。
  - ← 改写：（35–39）「体贴里藏着期待」

### 103–110　（正在面对）

- 幸福还很鲜明时，他也察觉心里仍有一处说不出的缺憾。
  - ← 动摇：（93–102）「爱着已很充实」
- → 他刚尽情地喜欢，也尽情盼望被爱，如今更清楚自己能爱得很深，却不能决定对方是否也这样选择。　✦ 满足照出未满足
- → 这让他酸楚，因为欢喜如此真实，那份缺憾便更难忽略，他已不能骗自己说对方怎样对待感情都无所谓。　✦ 知道更多反而更尖锐
- → 他知道把安稳交给对方会失去些什么，也不愿让对方替他消除不安，自己又舍不得削弱这份幸福。
- → 他发现克制能让他安心却消不掉渴望，尽情投入能带来幸福却不能保证自己不失望。　✦ 办法的限度
- → 他想靠近的迫切和不愿勉强对方的坚持都没退让，他宁可带着不轻松，也不想骗自己舍弃一边。

### 111–116　（正在面对）

- 带着仍未平息的牵挂，他渐渐不再要求自己找到一种不会受伤的爱法。
  - ← 提供理由：（103–110）「两种办法都不够」
- 他仍想被对方选择，因为那个人很重要，也真心盼两人亲近，即使愿望未必实现，他也不想假装无所谓。
- → 他舍不得放弃克制，因为对方有自己的心意和自由，若让对方替他消除所有不安，亲近也会变得不自在。
  - ← 提供理由：（72–77）「真心不构成义务」
- → 他仍会遗憾，却不再要求自己先把遗憾弄没，才好好喜欢一个人。
- → 他发现先前那些快乐并非徒劳，它们也让他更懂那个人对自己有多重要。
  - ← 说明：（4–16）「喜欢带来安稳」
  - ← 说明：（24–34）「轻松后更愿付出」
  - ← 说明：（40–50）「独自喜欢也很甜」
  - ← 说明：（62–71）「热情盖过顾虑」
- → 他仍想被珍惜，却不拿对方的态度判定自己的真心。　✦ 分清
  - ← 改写：（35–39）「快乐并非交换」
- → 他仍会有所保留，却不靠保留多少证明自己清醒。　✦ 分清
- → 他知道以后仍可能失望，也会想要更多、因不能更近而疼痛，却不因此否认感情或催促对方。
- → 他愿继续认真喜欢、充分欢喜，接受无法决定的部分，渴望被爱时不强求，珍惜对方自由时也不收回心意。
- ⟲ 仍在起作用：（72–77）「想要彼此珍惜」；（103–110）「两种办法都不够」
