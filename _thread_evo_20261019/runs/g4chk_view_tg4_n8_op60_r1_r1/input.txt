# Op.60｜关系图

**Center：**对亲密的投入与自我克制始终相互牵制。

### 1–3　（还说不清）

- 他还说不清自己究竟在盼什么。
- 他心里有了一个格外愿意亲近的人。
- 想到对方，他便不由自主地心软。
- 他想让这份柔软多停留一会儿。
- 他又本能地把心往回收。
- 眼下并没有事催他作决定。
- 他也不知自己为何这样谨慎。
- 他觉得那点喜欢似乎随时可以放下。
- 他偏偏舍不得放下。

### 4–16　（正在面对）

- 他不急着为这份在意决定去向。
  - ← 提供理由：（1–3）「这样谨慎」
- 他允许自己暂时不知道两人会怎样。
- 他不因喜欢就向对方期待什么。
- 他慢慢可以安心亲近对方。
  - ← 唤起：（1–3）「舍不得放下」
- 他喜欢自由地给予那份温柔。
- 他不必时时确认心意有没有被领受。
- 他发现重视对方也能保持从容。
- 他有时甚至觉得比先前更自在。
- 他渐渐不再提防自己的喜欢。
- 他有一点满意于自己如此宽和。
- 他希望亲近能一直自然地发生，不必追问计较。
- 他当时觉得这样已经足够。

### 17–23　（正在面对）

- 他开始盼望这份喜欢能够长久。
  - ← 唤起：（4–16）「自然地发生」
- 想到长久，他便想到对方的心意。
- 他能决定自己怎样珍惜对方。
- 他无法决定对方是否同样珍惜自己。
- 对方的回应开始牵动他。
