# Op.61｜关系图

**Center：**维持尊严的行动与对旧日生活及归属的怀念反复拉扯

### 1–23　（还说不清）

- 心里空了一处，却说不清少了什么。
- 旧日生活一浮现，他仍先感到安稳。
- 那时他不必时时担心自己是否够重要。
- 也不怕稍有疏忽就失去依靠。
- 他仍想念那样的生活。
- 有一瞬，他随熟悉的感觉松弛下来。
- 那份安稳里似乎藏着令他不自在的东西。
- 他还说不清为何戒备。
- 他舍不得推远那份温存。
- 连怀念也不再自然，令他怅惘。

### 24–65　（正在面对）

- 过去为了保住亲近，他忍下许多不满。
  - ← 唤起：（1–23）「不自在」
- 旧日委屈如今成了不肯退让的理由。
  - ← 改写：（1–23）「为何戒备」
- 他终于不必为留住别人先委屈自己。
- 这份自由的畅快远超预想。
- 他喜欢此刻的硬气与少顾忌。
- 他甚至为曾受的难堪感到一丝骄傲。
- 那些难堪使如今不再低头格外珍贵。
- 积压已久的力量终于能尽情伸展。
- 先前的迟疑暂时淡了。

### 66–91　（正在面对）

- 他珍惜无需别人认可也能安心的感觉。
- 痛快平息后，他感到另一种安静。
- 许多事如今可以由他自己承担。
- 却少了可以放心依赖的那份亲近。
  - ← 唤起：（1–23）「推远」
- 从前的亲近曾让他少担负许多事。
  - ← 说明：（1–23）「旧日生活」
- 护住自己也换不回被自然接纳的感觉。　✦ 办法的限度
  - ← 限制：（24–65）「先委屈自己」
- 一丝孤单尚不足以动摇他的坚定。
- ⟲ 仍在起作用：（24–65）「远超预想」

### 92–115　（正在面对）

  - ← 提供理由：（66–91）「一丝孤单」
- 他恼怒自己仍这样需要从前的生活。
- 仿佛旧委屈还能借这份不舍牵住他。
- 他的怀念这时带了刺。
- 那份坚定如今变得紧绷。
  - ← 改写：（24–65）「少顾忌」
- 想到那些亲近已失去，他就愤懑难平。
  - ← 提供理由：（1–23）「推远」
- ⟲ 仍在起作用：（1–23）「想念」；（24–65）「忍下许多不满」；（24–65）「先委屈自己」

### 116–147　（正在面对）

  - ← 说明：（92–115）「变得紧绷」

### 148–180　（没在想）
