你要一次写出一首器乐作品最终使用的Thread（线），用于在逐段听感记录旁阅读。线必须是同一个人经历的同一件事；只读线就能跟着他的处境走下去，每段也要与给定TARGETS的体验性质大体接得上。不是对音乐的解说，更不是把珠子的画面变成人物事实。

【段落】
{SECTIONS}

【Center（给定，不修改）】
{CENTER}
Center是回头看时能把全篇组织成一件事的中心，不是人物开头必须知道的结论，也不是每段必须复述的题目。

【已通过宏观评审的路线候选】
{ROUTES}

【珠子的体验性质TARGETS】
{TARGETS}
你不能看见原珠子，也不要猜其用词、画面、人物动作或音乐细节。

【第一步：把选路改为证据准入】
从ROUTES中只选一条作为base_route，不拼接路线。判断“扎实”的首要依据不是转折多或解释圆满，而是人物每个重要判断都能从该路线较早的可读经历找到支撑。路线是可供写成正文的设计，不是外部事实证明；ROUTES的established与depends_on只是待落实的线索，不能代替最终正文前面的句子。遇到关键支点需要新现实事件、他人的新反应或未经证实的相互关系才能成立，优先选不依赖这个支点的路线。不能因此把Center缩成一种固定心理机制。

【第二步：先分清人物能知道多少】
在内部按段记住：此前正文可以确知的、只能盼望或怀疑的、至今仍没有把握的分别是什么。由过去经验推出的新想法，强度不得大过所依据的经验；“重新想到以前”不是自足的证据。若路线把缺少依据的推测写成定论，就把人物此刻的信念写到证据能承担的程度，并让后文只依赖这种程度的信念；不能暗中补写一次发生过的事实。已经成立的选择不重做，暂时轻松不是永久想通，后面回到旧处时要看这次实际多了什么。短暂沉浸、承受后果和没有新认识的延续都可以成立。

【第三步：依此一次写完整条线】
TARGETS在写的时候参与决定各段感受的轻重与相容的侧面，但不能当作证明人物经历的证据。先保证每句话在不看TARGETS时也能明白其前因和分量，再让相同处境容纳本段不同的感受；对tensions不强作唯一解释，对temporal_shape不必写成音乐物理变化。段落情绪再强，也不自行证明产生了新认识；结尾可以保持未解决，不预设必须有最终决断。

正文按给定段落顺序写，每段2–4条，每条仅一句完整、自然的话，只承担一件有用的事；经历少的段落就用两句短句，不把多个独立心理步骤挤进一条。不同条可以是相继发生、并存的感受、某事的后果或已有状态的延续，不必硬造段内转折。全篇从头到尾一次写成，不逐段分别生成，不在成稿后另设改写或补珠子层。人物不靠新编的事件、道具、场景、对白、他人举动或对他人隐秘心态的断言推进，也不把TARGETS里的意象、想象的情节或音乐的物理动作直接变成现实。语言要像普通人讲自己当时真在乎的事，清楚而不说教；允许适当否定，避免固定口头禅或心理概念反复充当句子的内容。

【第四步：根据正文填写元数据】
写完正文后再标注，不让元数据替正文制造因果。cite只列该条真实提及或依赖的更早条目ID，包括本段前面的条目，仅主题相似不算。covers只列本段该条确有相近情境的bead_id，不为凑覆盖乱标，也不逐颗解释。relation只按正文标“没在想/还说不清/正在面对”，仍在挂念或打量Center不能标“没在想”。delta_type只从接口给定六类选，情绪变强不自动算“新变化”，delta没有真正新增便留空。established只收确实在正文首次成立的重要状态、认识、意愿或选择，并准确指向那一条。uncovered_targets仅记录强行覆盖须虚构外部事实的珠子及原因，没有则为空数组。

【输出】
只输出合法JSON，不要解释、Markdown或额外字段；接口固定为：
{
  "base_route": "route_id",
  "segments": [
    {
      "sec": "S01",
      "relation": "没在想/还说不清/正在面对",
      "items": [
        {"id": "S01-1", "text": "...", "cite": [], "covers": ["bead_id"]}
      ],
      "delta_type": "新变化/后果/实行已有想法/延续/回到旧处但有新增/暂时没在想",
      "delta": "本段真正新增的心理事实；没有则为空字符串"
    }
  ],
  "uncovered_targets": [
    {"bead_id": "...", "reason": "若要覆盖就必须虚构外部事实的原因"}
  ],
  "established": [
    {"claim": "首次成立的重要认识或状态", "first_established": "Sxx-x"}
  ]
}
segments按输入段落顺序完整填列，示例中的值只表示字段形状；不增加字段。
