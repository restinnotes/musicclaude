你是一位独立评审。附件里有 {N} 篇匿名文章（{LABELS}），都是为 {WORK}（全曲{TOTAL}小节，按 {RANGES} 共{NSEG}段）写的完整「Thread」。另有一份参考材料「{BEADFILE}」：这首曲子每一段的“当下体验”记录（下称“珠子”），由别的写作者完成。

## 这个产品里 Thread 是做什么的

珠子回答“这一段此刻正在经历什么”。Thread 是把这些珠子串起来的线：它让各段不同的体验逐渐属于同一件持续发生的事，说清前面已经经历过的东西怎样改变了后面这一刻的意义。所以 Thread 需要：

1. **自己读得通**：不看任何参考材料，读者也能跟着读下去，感到一件事在持续发生，能说出什么在变、为什么变、还留下了什么没有解决。
2. **情绪的理由来自“此刻的音乐 + 前面已经经历的”**：为什么这一段会有这样的感受，要能从这一段音乐里实际发生的事情（回来、变化、中断、没有落定、突然转亮……），加上此前真实积累的经历来理解。
3. **有珠子没有的信息**：可以借用珠子里的意象或感受作挂钩，但要在珠子之间建立珠子本身没有说出的关系。只是把珠子按顺序换个说法重讲一遍，等于没有做 Thread 的工作。
4. **不外加情节**：可以有一个轻的、贯穿全篇不变的处境来承载体验（例如一个人在船上，身边有一个在意的人；或直接用“你”的感受）。但如果情绪的转折是靠音乐里不存在、珠子里也没有的具体事件来推动的——另外编出的人生事件、对白、物件、消息（例如某段收到一封信、某段说出一句台词、某段想起某次争吵），而音乐只成了这段故事的配乐——那就是外加情节，是严重问题。
5. 不改写珠子，不把珠子里互相矛盾的不同听法硬串成一个人先后发生的事。

**不要因为这些扣分**：语气戏剧化、笃定、情绪强烈；只沿一条心理线写；不用乐理术语；篇幅长短本身。也不要奖励“写得像小说”“具体细节多”——具体本身不是优点，具体的东西必须来自音乐和体验本身。

## 怎么读

1. 先**只读文章**，不看参考材料，各篇整篇读完，判断它能不能自己成立。
2. 再打开参考材料，逐段对照：这篇的每一段，是在珠子之间建立关系，还是在复述珠子，或者在讲一段与音乐和珠子都无关的故事？

## 输出

先对每篇写简短读后：
- 什么在变、为什么变、留下了什么；
- 有无外加情节（引原文，带小节位置）；
- 复述珠子的程度（引一两处对照）；
- 最好的一处和最差的一处。

最后给一个 ```json 代码块：

```json
{
 "ranking": ["文章X", "..."],
 "articles": {
  "文章A": {
   "external_plot": {"severity": 0, "examples": ["mm.xx: 原文短引"]},
   "bead_retelling": {"share_of_segments": 0.0, "examples": ["mm.xx: 原文短引 ≈ 珠子短引"]},
   "standalone": 1,
   "accumulation": 1,
   "reasons_from_music_and_history": 1,
   "adds_relations_beyond_beads": 1,
   "alive_language": 1,
   "overall": 1,
   "verdict": "一句话"
  }
 }
}
```

- external_plot.severity：0 = 没有；1 = 有零星外加细节但不推动情绪；2 = 有几处外加事件推动情绪；3 = 主线就是一段外加故事。
- bead_retelling.share_of_segments：有多大比例的段落主要是在复述珠子（0–1）。
- 其余各项 1–10 分。overall 是你作为读者、按上面对 Thread 的要求给出的总体判断；严重的外加情节或大面积复述珠子，都应当明显拉低 overall。
- ranking 必须包含全部 {N} 篇，从最好到最差，不许并列。
