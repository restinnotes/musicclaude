# Op.61｜关系图

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### 1–23　（还说不清）

- 他起初不知道自己究竟在等什么，心里却有股不肯就此算了的劲，仿佛放任下去便是亲手认定一切理所当然。
- 他想把自己投进去，又怕丢下珍惜的东西，他并非没有勇气，也非全然眷恋安稳，只是两种牵扯还没显出面目。
- → 他试着找一个足以让自己不再犹豫的理由，刚觉得有把握，另一份舍不得就浮上来，连刚才的确信也变得陌生。
- → 反复摇摆让他难堪，他开始怀疑自己是否非得先理清一切才肯向前。

### 24–65　（正在面对）

- 他渐渐受不了再拿没想清楚当作等候理由，便先认下自己能够承担的那一份。
  - ← 改写：（1–23）「迟疑让他难堪」
- → 没有什么保证，也没有哪份牵挂因此消失，可一旦不再只是等待，他真切感到自己有了力量。
- → 他从反复追问值不值得，转向至少愿意尽力，并为自己仍有疑虑却不再受它支配而骄傲。
- → 投入加深后，他也愈发热切，付出本身使他快乐，仿佛无处安放的不满终于有了去处；他甚至有些贪恋倾尽全力的畅快，不想再时时审视自己或因软弱停下。
- → 用力到深处时，他偶尔触到心里一小块始终没有跟着昂扬起来的地方，知道坚决仍没顾到所有牵挂。　✦ 满足照出未满足

### 66–91　（没在想）

- 这点隐约的不安尚未逼他停下，认真投入过后，他反而能从原先的反复自问里松开一点。
  - ← 提供理由：（24–65）「付出本身带来快乐」
- → 他发现自己并非只有沉重和责任，也会因不再畏缩而高兴，会在愿意向前的热情里感到轻盈。
- → 他偶尔忘了自己为何如此用力，也不觉得那是背叛，仿佛重新尝到许久未有的自由，便顺着它走了一程，没有急着赋予它意义。
- → 快乐稍稍不再那么饱满时，先前那项决定仍在等他。

### 92–115　（正在面对）

- 他重新面对先前的决定，仍愿意坚持，因为它曾把他从无法动弹的犹豫里带出来，那阵轻快也是真实收获。
- → 他不愿因为心里仍有缺口，就把先前的一切都判成错误。
- → 他想确认自己仍有力量，却发觉心里另有一种要求，无法由力量替代。
  - ← 说明：（24–65）「心里仍有缺口」
- → 他逐渐看清，行动值得继续投入，同时仍不足以满足另一种要求；这个答案让他不愿承认，却无法再装作不知道。　✦ 分清
- ⟲ 仍在起作用：（66–91）「决定仍在等他」

### 116–147　（正在面对）

- 明知行动不够，他仍不肯撒手；它曾帮他脱离犹豫，所以他怕失望意味着自己变了心。
  - ← 动摇：（92–115）「行动值得却不够」
  - ← 提供理由：（92–115）「决定曾带他走出犹豫」
- → 他更用力催逼自己，把心里的难处当作可以克服的迟疑，担心停一停就成了退缩。
- → 他清楚自己正在受苦，却不知道除了坚持，还能怎样对得起最初的决意。
- → 原先使他昂然的要求渐渐变成苛责，他觉得自己像在勉强一个已经疲惫的人。　✦ 办法的限度
- → 他终于不想再证明自己有多坚强，暂时放下催逼，却没有立刻安心。
- → 催逼一停，被压住的依恋才有余地回来；他有些茫然，也有些松懈，仿佛终于肯承认自己真舍不得一些东西。

### 148–180　（没在想）

- 停下催逼后，他才看清依恋指向一种曾真心相信的生活，人与人可以不必时时防备。　✦ 分清
  - ← 改写：（116–147）「依恋重新浮现」
- → 他希望珍视之物无需靠争夺才能留下，也不必不断证明自己值得被爱和接纳，付出可以出于喜欢，靠近时也无需先准备受伤。
- → 他曾自然地相信这种生活可能，也确实从中得到快乐，感到人与生活可以亲近，不必时时费力维持，因此无法把这份盼望当作软弱。
- → 他终于肯完整地待在这份盼望里，不急着问它还能否得到，也不急着比较它和眼前坚持哪个更重要。
- → 仅仅允许自己这样爱与相信，就使他深深满足，仿佛又能柔软地活着，几乎忘了疲惫，暂时不想离开。

### 181–205　（正在面对）

- 这份安宁如此真实，他渐渐不能满足于只在心里拥有它，也开始想使这种生活难以存在的事情能否只靠怀念改变。　✦ 满足照出未满足
  - ← 唤起：（148–180）「沉浸旧愿得到满足」
- → 他想起自己起初不肯被动等待，原本也是因为有些重要的东西不能任其受损，于是又不甘心只留恋。
- → 他几乎责怪自己，刚沉浸在满足里就忘了还有必须面对的事，便试着重新要求自己振作。
- → 可这一次，他无法像先前那样毫无顾忌地投入，因为他已充分感到温柔的可贵，害怕重新争取会一点点耗尽它。
- → 他怕自己最终只剩不肯退让的意志，却失去原本使一切值得争取的心。
- → 向前和停留都令他不安，原以为坚定理由足以解开为难，如今理由更多，心却更难平静。　✦ 知道更多反而更尖锐
- ⟲ 仍在起作用：（1–23）「不肯放任现状」

### 206–213　（没在想）

- 就在这样的为难里，那份温柔又短暂地贴近他；他明知自己不能一直停留，仍不忍立刻推开。
  - ← 唤起：（181–205）「理由更多心更难平」
- → 他愿再爱惜片刻，不急着拿它审问自己，也暂时不想那些尚无答案的事；安静仍使他欢喜，欢喜里已有不舍。

### 214–215　（正在面对）

- 等这点安静退去，熟悉的迟疑又回来，仿佛走了很远仍回到原处。
  - ← 失效：（206–213）「欢喜中已有不舍」
- → 他如今看见，迟疑里既有怯懦，也有他真不愿失去的生活希望。　✦ 分清
  - ← 说明：（148–180）「依恋指向旧日生活」

### 216–225　（正在面对）

- 知道自己舍不得什么，却没有使他立刻勇敢；他既无法只凭一股决心向前，也无法安心沉浸在旧愿里。
  - ← 限制：（214–215）「迟疑里有生活希望」
- → 他看见两种办法都曾给过他一些东西，也都留下不能忽略的难处。　✦ 办法的限度
  - ← 说明：（92–115）「决定曾带他走出犹豫」
  - ← 说明：（148–180）「沉浸旧愿得到满足」
- → 他一时无力要求自己作出大改变，只轻轻盼着，若还要争取就别忘了为何争取，若还想爱惜安宁也别放弃面对使它难以存在的事情。
- → 他还不知道怎样才能做到，只反复想着这点微弱的意思，心里非得舍弃一边的逼迫似乎稍稍轻了。

### 226–241　（正在面对）

- 凭着这点尚不牢靠的心意，他重新思考自己还能怎么办。
  - ← 提供理由：（216–225）「舍弃一边的逼迫变轻」
- → 他亲身体会到，尽力承担能使人从无力中起来，却不能消除所有牵挂，心中美好能给安慰，却不能仅凭安慰保护所爱惜的生活。　✦ 办法的限度
  - ← 说明：（92–115）「决定曾带他走出犹豫」
  - ← 说明：（148–180）「沉浸旧愿得到满足」
- → 两样收获都是真的，他再也不愿简单否定其中任何一边。
- → 他渐渐肯承认，想保有那份无需时时奋力的安宁，又为它有所争取，就得承担再次失去安宁的可能。　✦ 选择的代价
- → 过去他会因这种难受责怪自己，仿佛坚定的人就不该如此，如今他渐渐看见，难受来自心里珍视的东西不止一种。　✦ 分清
- → 想到仍要付出的东西，他还是心疼，也盼有一条不必如此艰难的路，却知道继续等不会让那条路自然出现。
- → 他不再要求自己先变成毫不害怕的人，舍不得、没把握、在承担中受苦，都不必成为停止的理由。
- → 他一点点重新聚起力量，不再想压倒犹豫，愿连同不舍一起往前，真正接近承担时仍会怕，却不让惧怕替自己决定。

### 242–253　（正在面对）

- 他不再等一个毫无损失的办法，久违的昂扬又回来了，也不需要靠否认脆弱来维持它。
  - ← 改写：（226–241）「带着不舍继续前行」
- → 他仍愿尽力，却不再要求这份尽力同时证明自己无所不能。
- → 他清楚自己要承担什么，也知道自己难以割舍什么，不再把那些牵挂看成行动的拖累。
- → 他愿为自己真心爱惜的一切负起责任，这次的决心仍然热烈，却比最初踏实得多。
- → 他仍有犹疑，却不再等犹疑消失才允许自己坚定。　✦ 分清
  - ← 改写：（226–241）「带着不舍继续前行」
- ⟲ 仍在起作用：（226–241）「难受来自珍视不止一种」

### 254–288　（正在面对）

- 带着全部牵挂向前时，他有些意外，旧愿似乎没有远去，反而比从前更亲近。
  - ← 改写：（242–253）「不等犹疑消失」
- → 他仍盼人与人无需时时防备就能相爱，珍贵之物不必争夺，付出不耗尽自己，信任也不必反复受考验。
- 过去他一想到旧愿，就想远离艰难，仿佛只有把自己从争取中撤回，才能完整保住它。
- → 如今正因深知这种生活多么可贵，他更不愿任由使它难以实现的事情存在。
- → 他第一次真切感到，自己仍有的温柔，正是让他不肯袖手旁观的理由。
  - ← 提供理由：（148–180）「旧愿曾带来快乐」
- → 他也怕在争取中丢掉这份向往，因为那会让坚强失去原本值得争取的意义。
- → 他仍想过无需拼命就能好好生活的日子，却愿意承认，为了珍惜它，有时不能停留在它给予的安宁里。
- → 他提醒自己，更多投入未必让旧梦更近，美好愿望也不能自动证明每份付出值得，还须留意争取会否伤到所爱惜的东西。
  - ← 限制：（24–65）「心里仍有缺口」
- → 重新理解希望后，他感到比先前更宽广的喜悦，曾分头拉扯的两股心意此刻竟能共同支持他。
- → 他不必因向前而羞于依恋，也不必因保有依恋而厌倦责任。
- → 经历怀疑与疲惫后，他重新尝到最初相信生活时的快乐，也知道这份快乐已不再理所当然。
- → 喜悦渐渐平静，他仍知道有些事情没有答案，承担也未必足以改变什么，他并未回到无需防备的生活。
- → 往后他仍可能疲惫，也可能因不得不付出的代价而动摇，即使愿意把两种渴望一同带着，它们仍可能互相牵制。
- → 他不再急着用一种满足遮盖另一种需要，也不因某种需要尚未满足就否定已经得到的东西。
- → 他仍向往安宁，也仍愿意行动，不知道最终能留下多少珍贵的东西，却不肯遗忘任何一边。
- → 他可以带着这样的不舍继续向前，不再为自己的愿意寻找更多证明。
- ⟲ 仍在起作用：（1–23）「不肯放任现状」
