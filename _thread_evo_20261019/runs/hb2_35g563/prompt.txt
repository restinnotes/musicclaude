根据 {SECTIONS} 的原有顺序，把这段持续经历分配到各段。

每段必须有 state，但不要求每段都有新的心理变化。

有的段落可以呈现同一个动作中的不同体验，有的段落可以呈现已经成立的认识怎样影响人物继续做这件事，有的段落可以只是延续。

音乐情绪变化不等于人物换了处境，也不等于人物开始了另一个动作。

【第五步：不增加外部事实】
不新增聚会、书信、物件、对白、地点、职业、第三人、外部事件或场景。
不新增对方的动作，不推断对方未经检验的隐秘心事。
允许的只有一个不变的轻处境和一个不变的小动作。
所有心理变化必须来自人物已有经历和实际体验。

【第六步：普通人的语言】
写具体的人在做这件事时会想什么、感受到什么、在意什么。不要写心理分析报告、哲理、抽象概念或总结性判断。
不要把身体和注意力的变化写成心理学解释。

【输出格式】
请独立提出 {K} 条完整候选路线。
每条路线严格使用以下字段：
- route_id
- situation：一句普通话，说清整件经历，同时让读者知道贯穿全曲的轻处境和小动作。
- segments：按照 {SECTIONS} 原顺序，每段包含：
  - sec
  - state：本段此刻实际是什么情况，1–3条。必须发生在同一个处境、同一个动作之中；可以是体验、后果、延续，不要求新认识。
  - delta_type：从新变化、后果、实行已有想法、延续、回到旧处但有新增、暂时没在想中选择。
  - delta：本段真正新增的事实或认识，无则留空。
  - depends_on：真正作为前因的更早 state 编号；没有就空。
  - still_open：到这一段仍未解决或仍不知道的东西。
- established：按首次成立顺序列出全文的重要事实、认识、愿望或选择，并标明第一次成立在哪一段。

established 只登记真正成立的心理事实，不把持续体验、身体感觉或情绪变化登记为新认识。

不要写最终文案，不要评价候选。只输出 JSON。

【A2】
下面是同一首作品的几条 Thread 人物经历候选。你完全看不到珠子，也不要根据音乐细节评判。

你的任务是判断哪条路线能够在一个不变的轻处境和小动作中，自然地承载一整段真实经历。

不要选择动作最多、场景最丰富或心理变化最多的路线。这里不需要增加剧情。需要的是一个人持续做着同一件事时，经历仍然有真实的层次。

【逐条检查】
1. 是否确实是同一个人经历同一件事？
2. 是否有一个自然成立、从头到尾不变的轻处境和小动作？
3. 这个动作是否从已有经历中自然产生，而不是编造外部事件、物件或场景？
4. 人物是否始终处于同一处境中，没有为了对应音乐段落不断换任务？
5. 不同段落是否呈现同一动作中的不同实际体验，而不是重复讨论同一个心理矛盾？
6. 有没有把情绪强弱变化写成新的认识或决定？
7. 真正的认识和选择是否有前因？是否在后面被重新当成第一次成立？
8. 人物是否像一个普通人在持续经历一件事，而不是一份心理分析报告？
9. 这个持续处境是否足够自然，能覆盖整首作品，而不需要编造新的外部内容？
10. 结尾是否仍然处在同一个处境的经历之后，而不是突然切换到另一个场景或另一件事？

【重要判断】
同一个动作持续存在，不等于人物的经历没有内容。
人物可以在同一个动作中经历不同的身体感觉、注意力变化、情绪质地和已经成立的事实带来的后果。

但是，不能把这些不同体验全部写成新的心理认识。也不能每隔一段就重新讨论同一个问题。

如果一条路线只能靠增加外部事件才能维持丰富度，应当降低评价。如果一条路线动作很简单，但体验具体、人物可信、整条经历自然，应当优先考虑。

【评分】
逐条给出：
- coherence：1–10
- forward_motion：1–10
- prerequisite_integrity：1–10
- non_repetition：1–10
- human_plausibility：1–10
- 主要问题

特别检查是否有同一个处境被写成多次重新开始，或同一个动作被写成一轮轮新的心理决定。

然后选出最多 3 条进入下一步，按优先顺序排列。

不得改写候选，只能选择和诊断。

候选路线将在本提示词末尾附上。

只输出 JSON，保持原有输出格式。

【A4】
你要为一首钢琴曲写最终使用的 Thread（线）。

Thread 是同一个人在整首作品里经历的一件事。人物从头到尾处于一个不变的轻处境中，持续进行同一个小动作或持续行为。整条线呈现他在这件事中的实际体验，而不是不断重新提出心理问题。

【段落】
{SECTIONS}

【Center（已经给定，不得修改）】
{CENTER}

【已经通过 A2 的人物经历候选】
{ROUTES}

【从珠子提炼出的体验性质（TARGETS）】
{TARGETS}

你看不到原始珠子，也不得猜测珠子的具体画面或措辞。

【第一步：选择路线并锁定锚点】
选择一条最自然、最像真人经历、最不依赖外部加戏的路线。

先从 situation 中确定：
- 全曲不变的轻处境；
- 全曲不变的小动作或持续行为。

这两项一经确定，写作期间不得改变。

如果候选路线的动作描述不够明确，可以根据它已有的事实作最小程度的澄清，但不能新增场景、物件、地点、对方动作或事件。

【第二步：围绕同一个动作写经历】
每个段落都必须发生在同一个轻处境和同一个持续动作之中。

写作时优先呈现人物在继续做这件事时的实际体验：
- 此刻身体是什么感觉；
- 注意力被什么占据；
- 这一刻对他来说有什么具体分量；
- 已经成立的认识如何影响他继续做这件事；
- 他是否比先前更自在、更紧张、更坦然，或者只是继续沉浸在其中。

这些内容可以构成丰富的经历，但不能全部升级成新的心理认识。

只有确实出现新事实、新认识或新选择时，才写成新的心理变化。已经成立的认识不能重新宣布，已经面对过的问题不能换一个问法再次讨论。

不要为了让每段不同而让人物换动作、换处境或换一个心理问题。

【第三步：音乐段落的作用】
音乐段落决定人物此刻经历的时间位置和体验质地，不决定人物必须做什么心理动作。

相似的音乐情绪可以表现为同一动作中相似的体验，不需要人物重新开始一次心理过程。

音乐情绪发生变化时，可以改变人物体验的质地、注意力和身体感受，但不能凭空改变外部处境。

每段必须有条目，但不要求每段产生新认识。一个段落可以只写人物继续处于原有处境中的具体体验。

【第四步：TARGETS】
TARGETS 是体验的情感底色和方向，不是新事件，也不是新心理事实。

如果某个体验性质与人物当前的处境相符，可以用普通人的语言自然呈现。
如果只是情绪强弱变化，不要将它升级成新决定或新认识。
不得为了覆盖 TARGETS 而更换动作、创造场景或重新讨论 Center。
无法自然覆盖的体验可以放入 uncovered_targets。

【第五步：严格限制外部内容】
不新增外部事件、前史、对白、物件、第三人、地点或场景。
不新增对方的动作，不推断对方没有依据的隐秘心事。
只允许一个贯穿全曲的轻处境和一个贯穿全曲的小动作。
不得在不同段落中增加其他动作来推动故事。

【第六步：语言和条目】
必须像普通人平常讲述经历或心里自然冒出的念头。
不写心理分析报告、抽象名词、人生道理、格言和总结。
不要把一个身体感受扩写成心理结论。
不要用不同句式反复解释同一个问题。

每段必须有条目。默认一条，确实有两个不同体验时可以写两条。不要为满足固定条数拆分同一个念头。
每条是一句完整自然的话，只表达一个主要意思。

【第七步：最终检查】
1. 从头到尾是否始终处于同一个轻处境？
2. 是否始终在进行同一个小动作或持续行为？
3. 有没有无依据地增加其他动作、场景或外部事实？
4. 各段是否呈现同一件事的不同体验，而不是重复讨论同一个心理问题？
5. 有没有把体验的变化误写成认识的变化？
6. 已经成立的认识是否被重新宣布？
7. 人物是否具体、鲜活、像普通人？
8. 读者能否在整条线中一直追踪人物正在经历的那件事？

如果同一个动作已经无法自然承载某段内容，不要换动作来填充，优先选择这一段真实存在的体验或延续。

【输出格式】
只输出 JSON，保持以下结构，不增加字段：
{
  "status": "complete",
  "base_route": "route_id",
  "segments": [
    {
      "sec": "S01",
      "relation": "没在想/还说不清/正在面对",
      "items": [
        {
          "id": "S01-1",
          "text": "...",
          "cite": [],
          "covers": ["bead_id"]
        }
      ]
    }
  ],
  "uncovered_targets": [],
  "blocked_sections": []
}

每段严格按 {SECTIONS} 原顺序出现，必须有条目。relation 只作元数据。cite 只在直接依赖前面某条内容时填写编号。covers 只填写实际覆盖的 bead_id。

不得输出 blocked，不得空段。blocked_sections 固定为空数组，status 固定为 complete。
