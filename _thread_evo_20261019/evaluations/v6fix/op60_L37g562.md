# Op.60｜线（L37g562）

**Center：**亲密的幸福与留不住它的痛楚难以分开

### S01｜1–3 小节　（建立人物与妈妈长期共同生活的事实，呈现这份日常在人物心里的分量。）

- 我和妈妈已经在这处旧居里共同生活了很长时间，家里的日常一直是在这里一起过的。
- 有时我会突然意识到，这样一起过日子对我很重要，可这个念头来得很快，过去后心里还没完全安定。 〔1–3 ①〕
- 我偶尔想把这份在意说给妈妈听，又怕说出来显得太重，最后还是先没有开口。 〔1–3 ①〕〔1–3 ②〕

### S02｜4–16 小节　（原有共同生活继续存在，但母亲搬离旧居的安排已经确定，时间限制进入人物的日常。）

- 妈妈已经决定按原来的安排搬离旧居，之后这里不再是我们两个人共同住的地方。 〔1–3 ①〕
- 在她搬走之前，我们仍然在家里一起过日子，很多时候不用特意找话说，也能觉得彼此很近。 〔1–3 ①〕〔4–16 ①〕
- 我知道日子还在往前走，眼下相处时我很自在，想到这种日常不会一直照旧，心里也已经有一点舍不得。 〔4–16 ①〕〔4–16 ②〕
- 我有时很想马上把后面的安排问清楚，可那股热切过去后，我又回到平常，没有急着把所有问题都问完。 〔4–16 ①〕〔4–16 ③〕

### S03｜17–23 小节　（人物明确自己的愿望和顾虑，但尚未把愿望变成要求妈妈改变安排的行动。）

- 知道妈妈要搬走以后，我有时会安静地想一会儿，不急着马上想出办法。 〔4–16 ①〕
- 平静的时候，我也会突然很想问清楚搬走以后怎么相处，但那股急切很快就退下去了。 〔4–16 ①〕〔17–23 ①〕
- 我希望妈妈搬走后我们还是亲近的，也不想因为我舍不得就让她改变已经定下的安排。 〔4–16 ①〕〔17–23 ②〕

### S04｜24–34 小节　（空间限制使保留原有家庭环境成为不可能的事情，人物开始面对具体取舍。）

- 新住处的空间有限，旧居里的东西和原来的摆设没法全都带过去。 〔4–16 ①〕
- 我越想把熟悉的东西留住，越会反复想到它们原来在家里的位置，舍不得的感觉也跟着加重。 〔1–3 ①〕〔24–34 ①〕
- 有时我真想把一切都照原样留下来，可越想把事情抓牢，越发现自己没有办法保证每样东西都能带过去。 〔17–23 ③〕〔24–34 ①〕

### S05｜35–39 小节　（第一次实际改变原有家庭环境，通过清点、取舍和装箱决定哪些共同生活内容能够保留。）

- 我和妈妈一起把旧居里的东西清点了一遍，按新住处能放下的空间列出带走和留下的清单。 〔24–34 ①〕
- 我们照着清单开始装箱，原来属于共同生活环境的一些东西确定不带过去。 〔35–39 ①〕
- 看着清单上已经确定留下的东西，我心里有点空，也没有再要求把每一样都改成带走。 〔35–39 ①〕〔35–39 ②〕

### S06｜40–50 小节　（承受物件取舍造成的实际变化，同时明确搬离之后的联系和共同事务仍然没有安排好。）

- 箱子装起来以后，屋里少了几样原来一直摆着的东西，剩下的地方反而显得清楚、轻一些。 〔35–39 ②〕
- 妈妈搬离以后我们怎么联系、什么时候见面，还有哪些家里的事要一起处理，目前都还没有商量好。 〔4–16 ①〕〔35–39 ②〕
- 家里安静下来时，我会想到以后不能像现在这样随时见到妈妈，心里那点酸楚就更明显。 〔4–16 ②〕〔40–50 ②〕
- 有时我会看着留下来的东西多停一会儿，觉得熟悉的感觉还在，想到没带走的那部分又有点遗憾。 〔35–39 ②〕〔40–50 ①〕

### S07｜51–61 小节　（物件取舍已经进入实际生活，人物开始把注意力放在仍然能够共同经历的日常上。）

- 我没有把已经列入留下清单的东西重新拿出来考虑，家里就按留下来的部分继续过日子。 〔35–39 ①〕〔35–39 ②〕
- 妈妈还住在这里时，我会主动把心思放在还能和她一起做的家里事情上，不再反复盘算哪些东西没能带走。 〔4–16 ②〕〔35–39 ②〕〔51–61 ①〕
- 我知道这样的日子有期限，却还是会沉在眼前这些熟悉的相处里，不想太早从中抽开。 〔4–16 ①〕〔51–61 ②〕

### S08｜62–71 小节　（继续体验尚未结束的共同生活，亲近和轻松仍然存在，但已经改变的家庭环境无法恢复原样。）

- 家里虽然已经少了几样东西，我们还在旧居一起生活时，剩下的日常仍然能照常进行。 〔35–39 ②〕〔51–61 ①〕
- 有些时候我会很自然地享受和妈妈一起过日子的轻松，不再一直分析自己舍不得什么。 〔51–61 ②〕〔62–71 ①〕
- 等到眼前的事情停下来，我又会注意到有些东西已经不在原处，刚才的轻松里便多了一点想念。 〔35–39 ②〕〔62–71 ②〕

### S09｜72–77 小节　（将搬离后的联系从没有约定的状态转变为双方实际商定并能够执行的相处安排。）

- 我和妈妈认真商量了搬离后的联系，最后约定她搬走后每周固定一起吃一次饭。 〔17–23 ③〕〔40–50 ②〕
- 我们还把第一次见面的时间定了下来，以后不能再把每天住在同一个地方当成自然见面的条件。 〔4–16 ①〕〔72–77 ①〕
- 商量时我不再只想着自己想见她的心情，也把我们两个人实际能做到的事放在一起考虑。 〔17–23 ③〕〔72–77 ①〕
- 我原本很想把以后安排得稳妥一些，可最后能确定的只是每周一次和第一次见面的时间，心里还是有些不确定。 〔72–77 ①〕〔72–77 ②〕

### S10｜78–83 小节　（短暂承接已经形成的联系约定，不增加新的事件，也不把暂时平静误认为搬迁问题已经解决。）

- 每周一起吃一次饭和第一次见面的时间都已经定好，我暂时不用再反复想该怎样跟妈妈谈这件事。 〔72–77 ①〕〔72–77 ②〕
- 妈妈还没有搬离，旧居里的日子继续着，但我们已经知道以后不能再靠每天住在一起维持联系。 〔4–16 ①〕〔72–77 ①〕
- 那几天我先把搬离的事放到一边，照常做眼前的家里事情，心里有一阵轻松，但原来的安排并没有改变。 〔78–83 ②〕

### S11｜84–92 小节　（母亲实际搬离，长期共同居住的条件正式结束，此前的物件取舍和联系约定开始面对现实。）

- 按既定安排，妈妈真正搬离了旧居，我们不再住在同一个家里。 〔4–16 ①〕〔72–77 ②〕
- 搬完以后，我想见妈妈不能再像以前那样随时见到，日常陪伴确实少了一大块。 〔4–16 ②〕〔84–92 ①〕
- 我很舍不得以前每天都能见到她的日子，可想到每周一起吃饭的约定还在，心里又有一点踏实。 〔72–77 ①〕〔72–77 ②〕〔84–92 ①〕
- 这次搬离让我明白，妈妈和我还是亲近的，但共同住在一个家里的生活已经结束了。 〔84–92 ①〕〔84–92 ③〕

### S12｜93–102 小节　（在不同住处的条件下执行已经商定的见面安排，亲密关系开始通过新的日常形式延续。）

- 搬离后第一次一起吃饭时，我们按约好的时间见面，吃完以后又各自回到自己的住处。 〔72–77 ②〕〔84–92 ①〕
- 坐在一起吃饭时，我很投入，也觉得熟悉的亲近还在，心里高兴得有些发酸。 〔93–102 ①〕
- 饭后各自回去，我还是希望能多见几次，但现在的约定是每周一次，想念并没有因此完全满足。 〔72–77 ①〕〔84–92 ①〕〔93–102 ①〕

### S13｜103–110 小节　（熟悉的家庭相处方式在新的见面过程中重新出现，但人物仍然需要适应不能每天共同生活的现实。）

- 每次一起吃饭时，旧居里熟悉的家常话题和相处习惯还会自然回来，我会觉得我们并没有变得生疏。 〔93–102 ①〕〔93–102 ②〕
- 可饭后各自回去时，我又会想起以前每天都能见面的日子，心里高兴和难过常常一起出现。 〔84–92 ①〕〔93–102 ①〕
- 每周见面已经是我们定下的办法，可要适应见面后各自回去的节奏，有时还是让我觉得累。 〔72–77 ①〕〔103–110 ①〕
- 我知道我们还在见面，却也会怀疑这样的相处是不是能慢慢变得自然，这个疑问没有抹掉见面时的高兴。 〔103–110 ①〕〔103–110 ②〕

### S14｜111–116 小节　（收束到已经发生的居住变化和新的相处方式，保留亲近，也承认原来的共同生活不能恢复。）

- 现在妈妈住在新的地方，我们也按约定每周一起吃饭，旧居里的共同生活没有恢复。 〔84–92 ①〕〔72–77 ①〕
- 我还是会想起以前每天都能见面的日子，心里会舍不得，但想到每次见面时的熟悉感，紧张也会慢慢缓下来。 〔93–102 ②〕〔103–110 ②〕
- 每次见到妈妈，那种熟悉的亲近会短暂回来，吃完饭后我们又各自回到自己的住处。 〔93–102 ①〕〔111–116 ①〕
- 一开始我还不知道怎么安放这份在意，现在至少知道妈妈搬走了，而我们仍按约定见面，这就是眼下的日子。 〔1–3 ②〕〔84–92 ①〕〔111–116 ①〕
