# Op60 候选 Center 一览

1. 一个人很想和所爱的人真正听懂彼此，可再亲近也无法替对方说出心里话，连温柔的沉默都可能让人猜错。
2. 一个人很想在眼前的好日子里放心地快乐，可身体的不适和亲近的人之间的摩擦，让他连最美好的时候也有点悬心。
3. 一个人很想把曾经美好的时光留得清清楚楚，可每次重新想起，记忆都会沾上此刻的心情，怎么也不再是原先那个样子。
4. 一个人很需要相信在眼前生活之外还有一片更美的天地，可那里只在想象里格外清晰，眼前的烦恼并不会因此消失。
5. 一个人很想把心里极细微的感受表达得丝毫不差，可越在乎说得准确，越怕反复打磨会把它原本的鲜活弄没了。
6. 一个人很想毫无保留地感受心里的热烈，可越是激动，越怕失去自己一直看重的清醒和分寸。
