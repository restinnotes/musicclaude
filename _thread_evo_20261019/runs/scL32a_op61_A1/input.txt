你要为这首钢琴曲设计 Thread 的人物经历路线。

Thread 是同一个人在整首作品里经历的一件事。它应该像一段真实经历自然展开，而不是一份人物心理变化报告，也不是围绕一个命题反复论证的文章。

你的任务是提出 3 条不同的、能够自然写成一条线的经历路线。

【输入】
作品：作曲家：肖邦（Chopin）
作品：《幻想波兰舞曲》Op.61
段落顺序：S01：第 1–23 小节
S02：第 24–65 小节
S03：第 66–91 小节
S04：第 92–115 小节
S05：第 116–147 小节
S06：第 148–180 小节
S07：第 181–205 小节
S08：第 206–213 小节
S09：第 214–215 小节
S10：第 216–225 小节
S11：第 226–241 小节
S12：第 242–253 小节
S13：第 254–288 小节
Center：维持尊严的行动与对旧日生活及归属的怀念反复拉扯

【不可改变的边界】

1. 完全不看任何听感记录或珠子。
2. Center 已经给定，不得修改。它是整件经历的核心，不是人物每段都要重新思考或回答的题目。
3. 从头到尾必须是同一个人经历同一件事。
4. 不得新增外部事件、前史、具体对白、物件、第三人、职业、地点、对方的新动作或其他没有依据的情节来推动故事。
5. 不得凭空推断其他人的隐秘心事。
6. 允许一个从头到尾不变的轻处境和小动作。人物可以在已有处境中有细小的反应、动作和心思变化。
7. 不得为了制造故事发展，擅自改变这件事发生的时间性质。例如，不得把正在发生的经历改成失去之后的回忆，也不得把回忆擅自改成正在发生。只有 Center 或已有事实明确支持时，才能采用相应的时间框架。
8. 不写音乐、旋律、节奏、和声或音乐段落的事件。

【核心思路：让一件事自然展开】

不要把这条线设计成人物不断获得新领悟的过程。

一个人经历一件事，不需要每过一段就对自己产生新的认识、作出新的决定或发现新的心理矛盾。

真正需要的是：每一段都让读者看到这件事中一个之前没有呈现过的具体侧面。

不同段落可以通过以下方式增加内容：

1. 经历的不同阶段：同一件事从开始、进行到后续，自然走到了不同的位置。
2. 不同的具体落点：人物在这一段正在留意、在意、享受、等待、回避或回应的内容，与前面不同。
3. 不同的参与方式：人物在同一处境中有一个细小但真实的动作、反应或态度变化。
4. 前面内容的实际影响：此前已经发生的事情，在这一段改变了人物正在做的事、能够做的事或当下的感受。
5. 同一经历的新侧面：人物对已经存在的事情有了另一个具体的体验，但不是重新讨论同一个问题。
6. 停留和沉浸：人物可以在某个时刻多停留一会儿，但这一段必须呈现此前没有出现过的具体感受或经历侧面，不能只是把原来的情绪再说一遍。

这些新增内容可以很小，不必是重大转折，也不必让人物产生一个新的心理结论。

【每段的设计要求】

严格按照 S01：第 1–23 小节
S02：第 24–65 小节
S03：第 66–91 小节
S04：第 92–115 小节
S05：第 116–147 小节
S06：第 148–180 小节
S07：第 181–205 小节
S08：第 206–213 小节
S09：第 214–215 小节
S10：第 216–225 小节
S11：第 226–241 小节
S12：第 242–253 小节
S13：第 254–288 小节 的顺序，为每段设计一个不同的具体落点。

每段需要回答：

1. 这一段人物正在经历什么、在意什么或做什么？
2. 这一段让读者比前面多看到或感受到什么？
3. 这个新增内容为什么不同于此前的段落？
4. 它与前面已经发生的事情有什么联系？
5. 它怎样自然地把经历带到下一段？

本段新增内容不要求是新认识、新愿望、新代价或新选择。可以是一个具体侧面、一个细小反应、一个新的参与方式或一个前面事情的实际影响。

但以下内容不算新增：

- 同一种情绪变得更强或更弱。
- 同一个问题换一种问法。
- 同一个愿望换一种说法。
- 同一个事实再次被用来证明同一个结论。
- 人物再次思考一个已经思考过的问题，却没有新的前提或后果。
- 只改变心理学标签，实际经历内容没有变化。

每段必须有不同的具体落点。不能用情绪强弱代替段落差异，也不能用新的抽象结论代替实际经历。

【核心两难的使用规则】

整件事可以有一个贯穿始终的核心两难，但它只是一条背景线索，不是每段都要重新讨论的题目。

1. 整条路线只确定一次核心两难。
2. 如果人物确实需要正面思考它，只安排一个最合适的段落。
3. 其他段落不再重新辩论这个问题。
4. 如果这个问题仍然影响人物，后续只写它在当前经历中的具体影响。
5. 不能把同一个两难拆成多个看似不同的问题。
6. 不能通过连续反问、连续自我解释或连续比较正反两面来制造段落数量。

一个问题没有解决，不意味着人物每段都必须重新想一遍。

【时间框架与经历连续性】

每条路线首先确定这件事的时间框架：

- 正在经历。
- 回想过去。
- 设想未来。
- 现有信息无法确定。

必须根据 Center 和已有事实确定，不得为了让故事更容易展开而自行选择。

一旦确定，整条路线必须保持一致。不能无依据地引入失去、分离、结束、重逢或事后回忆。

如果无法确定，不要替人物补充一个确定的时间背景。

同时确定整条经历的连续性：人物从头到尾在经历的究竟是哪一件事，什么内容始终没有改变，什么内容在过程中发生了变化。

【人物和语言】

1. 人物像一个普通人在经历事情，不像一个正在分析自己心理的人。
2. 优先考虑人物实际在意什么、想做什么、正在做什么、舍不得什么、有什么感受。
3. 不要不停制造领悟、判断、反省和总结。
4. 不要为了让段落不同而强行改变人物的立场。
5. 不要把每个细小感受提升成一个抽象的人生认识。
6. 不要替人物解释一整套心理结构。
7. 不得为了制造一个漂亮结尾而强行让人物释怀、成长或作出决定。

【路线容量检查】

完成路线后，逐段比较各段的具体内容。

检查：

- 各段是否有不同的具体落点？
- 是否有几段实际上都在讨论同一个两难？
- 是否有几段只是把同一个心思换一种说法？
- 是否有段落为了制造新内容而改变了原本的时间框架？
- 是否有段落必须依靠编造新事件才能成立？
- 是否有段落只是情绪更强，却没有新的经历内容？

如果某段较薄，但能够从已有经历中找到另一个有依据的具体侧面，标记为 `repairable`。

如果确实没有任何有依据的不同内容，标记为 `thin`，不得伪造一个新的心理领悟填充。

如果整条路线必须依靠改变 Center、编造外部事件或反复辩论同一个问题才能成立，才判定为不合格。

不要因为某段没有新的心理认识，就判定整条路线不合格。

【输出格式】

只输出 JSON。每条路线包含：

- route_id
- route_status：`usable`、`usable_with_thin_sections` 或 `invalid`
- temporal_frame：时间框架
- frame_evidence：确定时间框架的依据
- situation：一句普通话说明这个人经历的是什么事
- throughline：一句普通话说明整条经历如何自然展开
- central_tension：整件事的核心两难，没有则留空，只写一次
- opening_condition：开始时人物的具体处境
- ending_condition：结束时人物实际处于什么位置，不要求解决问题
- segments：严格按照 S01：第 1–23 小节
S02：第 24–65 小节
S03：第 66–91 小节
S04：第 92–115 小节
S05：第 116–147 小节
S06：第 148–180 小节
S07：第 181–205 小节
S08：第 206–213 小节
S09：第 214–215 小节
S10：第 216–225 小节
S11：第 226–241 小节
S12：第 242–253 小节
S13：第 254–288 小节 顺序，每段包含：
  - sec
  - focus：本段具体在经历什么、在意什么或做什么
  - local_move：本段相对前一段发生了什么实际变化或推进
  - new_piece：本段让读者第一次看到的具体内容
  - grounding：这一内容来自哪些已经成立的事实或处境
  - carry_forward：本段承接的前文内容
  - question_use：`首次提出`、`作为背景`、`不出现` 三者之一
  - section_status：`distinct`、`repairable` 或 `thin`
- thin_sections：列出内容确实不足的段落及原因
- repetition_check：列出实际重复的经历内容或两难论证
- frame_check：确认是否始终保持同一时间框架

不得写最终线文案，不得编造外部情节，不得为了填满每段制造心理领悟。
