- 累积问题（中等）：听感条目中相邻短语有时反复表达同一层意思，形成近义信息的堆叠。 证据：S01，感受「身体先记起舞步 / 隐约记起步子 / 脚下有了牵引」；S06，感受「温柔得想放下戒备 / 暂时不必防备」；S07，感受「思绪翻来覆去 / 停不下来 / 身体还没相信结束 / 心里仍在发颤 / 惊醒后的紧张 / 迟迟平复不了」；S10，感受「问题又递回来 / 接下来怎么生活？ / 还是拿不定主意 / 经历过许多以后 / 仍没有彻底答案 / 只剩疲惫」
- 累积问题（轻微）：听感描述中反复使用否定式澄清，逐渐形成一种先排除错误理解、再说明真实感受的表达习惯。 证据：S02，感受「不是轻松恢复自信 / 咬着牙不服 / 不肯就这样垮掉」；S05，感受「心里未必平静 / 不是想通了 / 只是抵抗累了」；S07，感受「不等于好起来」；S11，感受「不是顺畅奔跑 / 一次次顶住 / 再用力撑住」；S11，感受「不是问题解决了 / 终于不再原地打转」；S12，感受「不必假装没受伤 / 不再逼自己选边」
- S02，感受「他仍觉得当初受的那些气不该忍，也不敢多想从前的开心。」：“多想从前的开心”搭配稍显生硬。“开心”在这里直接作为回想的对象，读起来不如日常表达自然。
- S05，感受「最后只剩疏和弦」：“疏和弦”的搭配不够自然。“疏”通常需要通过“稀疏”“疏落”等形式来描述声音分布，直接修饰“和弦”略显生硬。
- S07，感受「亲切却不安慰」：“亲切”描述的是一种感受，“不安慰”则是一个动作，两者直接并列，语义关系不够顺畅。读者需要自行补出它究竟是亲切却没有带来安慰，还是亲切但无法消除难过。
- S09，感受「像从另一面看门 / 还是那扇门」：“看门”在中文里很容易被理解为看守门户的意思。这里想表达的是从门的另一侧重新看待同一扇门，原来的压缩表达容易让读者短暂停顿。
- S13，感受「心跳到最高负荷」：“负荷”通常用于描述身体或系统承受的压力、负担，直接说“心跳到最高负荷”搭配不够自然，也带有明显的技术性表达色彩。
- S13，感受「不再完整挺立 / 不再鲜明成形」：“完整挺立”虽然有一定的比喻色彩，但还能理解为原本鲜明的形象失去了支撑。“鲜明成形”的搭配则比较别扭，鲜明通常描述形象或印象的清晰程度，成形描述的是形态逐渐形成，两者放在一起不够协调。
- S13，话「想起从前相处得自然又亲近的日子，他心里又热了起来。」：“相处得自然又亲近的日子”修饰关系稍显绕。“相处得……”通常描述人与人之间的相处状态，直接放在“日子”前面，读起来不够舒展。
