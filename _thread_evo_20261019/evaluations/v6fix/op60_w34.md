# Op.60｜关系图（在 v6 上修补，w34）

**Center：**对亲密的投入与自我克制始终相互牵制。

### S01｜1–3 小节　（还说不清）

- 他一想到这个人就柔软起来，很想亲近，自己也被这份心意来得突然吓了一下。
- → 他自己也说不清为何谨慎，觉得这份喜欢轻得随时可以放下，却偏偏舍不得。
- → 眼下不用决定关系去向，他想让喜欢多留一会儿，怕心意露得太明白会改变关系，靠近时便收住一点。

### S02｜4–16 小节　（没在想）

- 他让眼前的亲近自然发生，不再揣摩对方的反应，也不索要回应，便能自在地关心对方，也喜欢自己不计较。
- → 他那时真觉得，只要能这样亲近下去，眼下已经够了。
- 他不敢认定这样的亲近会一直有，便只盼眼下这一刻慢些过去。
- 他一度很想把心意多给一点，热切了一阵，想到还得顾着分寸，便又收了回来。
- ⟲ 仍在起作用：（1–3）「多留一会儿」

### S03｜17–23 小节　（正在面对）

- 安静下来后，他才发现，眼前的亲近已经让他满足，却还让他多盼它长久一点，原先的安稳便松动了。
  - ← 动摇：（4–16）「亲近下去」
- → 想到长久，他才发现自己能决定怎样珍惜对方，却不能决定对方是否也珍惜自己。
- → 他还没打算向对方索取答复，只是偶尔想知道自己在对方心里是不是特别，连自己也没想到竟会在意这件事；这念头一冒出来，原先顺畅的亲近就被绊住，他没法完全走神。

### S04｜24–34 小节　（正在面对）

- 他知道，对方也没答应过他什么。
  - ← 说明：（17–23）「珍惜对方」
- → 他把心思转去替对方高兴，觉得真心盼对方好，自己也会开心。
- → 他暂时没那么担心自己是否特别，觉得还有许多心意可给，便放开些去喜欢。
  - ← 改写：（17–23）「索取答复」
- → 他越放开些去喜欢，越舍不得这一刻过去，热切时又怕成了催促，只好收住一点。
- → 他甚至把这阵轻松当成保证，以为自己能尽情喜欢，也不会失去眼前的亲近。

### S05｜35–39 小节　（还说不清）

- 他发现自己尽情喜欢时的快乐，终究说明不了对方是否也珍惜这份亲近。
  - ← 动摇：（24–34）「当成保证」
- → 他难堪地想，或许盼着被珍惜，说不求回报是在骗自己，可那时关心对方、享受亲近，确实没想过换回什么。
- → 他不急着替自己辩白或用热情盖住难堪，想把亲近留住的劲头便松了些。

### S06｜40–50 小节　（没在想）

- 难堪没让他少喜欢，他仍愿意真心关心对方，也不再逼自己装作什么都不求。
  - ← 提供理由：（35–39）「盼着被珍惜」
- → 关心对方时，他觉得这份喜欢留在心里也很甜，暂时忘了自己为何盼回应，可那念头过会儿又回来。
- → 他发现，再多对对方好，也不能证明自己什么都不求，更解不开想被珍惜又不愿索取的矛盾。
  - ← 失效：（24–34）「是否特别」

### S07｜51–61 小节　（正在面对）

- 他尝过关心对方时那份细细的甜，便越来越常惦念对方，喜欢也渐渐收不住，舍不得把它减轻。
  - ← 提供理由：（40–50）「留在心里也很甜」
- → 眼前的亲近明明还好，他不想让期待牵着自己走，便想把喜欢留在心里。
- → 他渐渐盼对方懂他的关心，却相信不该催对方，越不愿给对方添负担，越只能自己消化没有着落的盼望。
- ⟲ 仍在起作用：（24–34）「收住一点」

### S08｜62–71 小节　（没在想）

- 他记得最初亲近时的安心，也记得不计较地关心对方时的满足，即使对方从没许诺过，这些也都真实发生过。
  - ← 提供理由：（4–16）「不必揣摩」
- 他把喜欢留在心里时，也尝过独自珍藏的甜意，即使对方没许诺过什么，那份甜也是真的。
  - ← 提供理由：（40–50）「留在心里也很甜」
- → 这些经历一点点积起来，他不想再因怕受伤压住欢喜，便任自己高兴，连玩心也冒出来。
- → 他给得多了也不再一笔笔算，高兴得一时顾不上那份沉重，也不急着替未来留退路。
- → 他高兴起来，想被对方同样珍惜的愿望也跟着冒出来。

### S09｜72–77 小节　（正在面对）

- 他承认自己也盼对方渴望靠近、把彼此放在心上，却怕继续盼下去会催到对方。
  - ← 唤起：（62–71）「同样珍惜」
- → 他一再想收回盼望，却觉得这样是在否认刚承认的心意，委屈之余也厌烦自己反复为难。
- 他仍愿为眼前的亲近高兴，因为这份亲近本身值得珍惜，即使对方的心意还没着落。
- ⟲ 仍在起作用：（62–71）「压住欢喜」

### S10｜78–83 小节　（正在面对）

- 他先不替这份感情下结论，也不逼自己立刻选边，便先不往前走，也不假装自己不在乎。
- → 他不把温柔当成必须向前一步的表示，便不必等心事理清，也能照常关心对方。
- → 他不再硬压住委屈和渴望，承认自己想被珍惜并不等于催促对方。
  - ← 改写：（72–77）「渴望靠近」

### S11｜84–92 小节　（正在面对）

- 犹疑许久，亲近之乐又回来，让他感动，也让他不必靠无所求证明体贴，承认想被珍惜不妨碍真心关心对方。
  - ← 提供理由：（40–50）「难堪没让他少喜欢」
- → 他知道深情不能替对方作决定，也可能让自己受伤，却仍愿把这份幸福完整认下来。
  - ← 限制：（17–23）「珍惜对方」

### S12｜93–102 小节　（没在想）

- 他不再为想被珍惜自责，也想把积攒的关心给对方，看看两个人能过上怎样的日子。
  - ← 提供理由：（84–92）「亲近之乐」
- → 他觉得许多真情值得珍惜，想靠近、想被爱，还想把心全交给对方，仿佛想要的都已拥有，满足得他也招架不住。
- → 他仍盼对方选择他，这个曾让他紧张难堪的愿望暂时不再以缺憾折磨他，欢喜稍退，未获回应的期待才又回来。
  - ← 改写：（35–39）「盼着被珍惜」

### S13｜103–110 小节　（正在面对）

- 他真想和对方共享幸福，却怕幸福只属于自己。
  - ← 提供理由：（35–39）「自己的快乐」
- → 他曾把喜欢收在心里，确实安心些，可想被珍惜的愿望并没有消失。
  - ← 限制：（51–61）「留在心里」
- → 他不想把所有不安都交给对方解决，也不愿因怕落空就故意把喜欢压淡。
- → 他越来越难受，因为他舍不得否认想被珍惜，也不愿逼对方回应。
- → 他宁可继续不舒服，也不愿假装自己不想被珍惜，换来一时平静。

### S14｜111–116 小节　（正在面对）

- 他不再反复盘算该收住还是放开，也不靠克制证明自己清醒，因为收住和尽情投入都不能保证他不受伤。
- 他知道对方有自己的心意，不必和他一样，若要对方接住全部期待，亲近反会失去自在。
- → 他仍想被爱，也还想要更多，却不把自己的渴望当成对方必须满足的事。
- 他记得小心靠近、慷慨付出、独自珍藏和尽情欢喜，都确实给过他快乐，也让他一次次愿意继续向前。
  - ← 提供理由：（62–71）「压住欢喜」
- → 他知道遗憾不必消失也能好好喜欢，等不到对方主动靠近时仍会疼，却不因疼痛否认感情或催对方回应。
  - ← 改写：（103–110）「一时平静」
