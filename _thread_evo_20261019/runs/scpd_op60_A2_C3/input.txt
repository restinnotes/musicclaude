一、固定 Center 与唯一候选

Center 已由上游 N04 确定，包含在作品资料中。
不得重新概括、修订或替换 Center。
最终 JSON 的 center 原样使用该固定内容。

本次 CANDIDATES_JSON 只包含一条候选经历。
把它写成完整的线。

不得从其他候选中拼接人物经历。
不得为丰富某一段而另起一条心理支线。

COVERAGE_PLAN_JSON 是为保持接口兼容而保留的
空对象，不提供任何写作要求。
本阶段的人物内容只能来自固定 Center、
所给候选及其独立依据。

二、先确认这是一件事

在写具体条目之前，内部核对：

- 他在意的究竟是什么；
- 他当前想要、舍不得或顾虑的是什么；
- 他此前实际经历过什么；
- 哪些认识、选择或感受已经成立；
- 哪些只是猜测或愿望；
- 哪些事情到结尾仍没有答案。

这些核对用于保持经历的连续性，
不应被逐项写成正文。

候选中的 turns、basis、change 和 segment_sketch
是构思材料，不是成品句式模板。

不要把它们机械改写成：
先交代原因，再分析心理，再总结认识。

如果候选某处只有抽象判断，要回到人物已经成立的
所求、顾虑和感受中表达它。
不能为了使它具体而新增外部事实或事件。

三、让人物自己的经历推动后面

每个真正的新变化，都必须有人的前因。

这个前因可以是之前得到过的满足、
经历过的难受、形成的愿望、产生的顾虑、
已经作出的选择，或者此前的经历留下的影响。

不要让音乐中某种变化，直接成为他心理变化的原因。

不要虚构外部事件、对白、物件、具体前史，
也不要让另一个人突然作出新的回应，
以便解决当前人物缺少前因的问题。

已有的经历可以在后面继续起作用。
人物不必每次都重新想到或解释完整的前因。

当某个感受再次出现时，检查它是否受到
中途经历的影响。

如果确实不同，就写出这次实际不同在哪里。
如果并没有新的认识或态度，也可以只是继续感受、
暂时陷在其中，或回到之前的心情。

不要靠情绪越来越强，假装人物不断得到新认识。
不要靠反复宣告已作出的选择，假装事情仍在推进。
也不要为了避免重复，硬造新的问题和解决办法。

一段可以没有明显变化。
整条经历仍应随着真实发生的事情往前走。

四、写实际经历，不写心理分析报告

每一条先想清楚：
他此刻究竟在想什么、想要什么、怕什么、
舍不得什么，或者正在怎样对待这些感受。

让读者直接读到这些内容。

需要说明前因时，用人物已经经历过的事情
自然带出，不必把完整因果链重新讲一遍。

有些重要认识值得直接写清，但只在人物
确实走到这一步时写一次。

不要每出现一种感受，就立刻解释它的心理机制、
概括它的意义，或者评价它是否合理。

不让人物不断像旁观者一样分析自己，
也不把经历写成一篇关于某个抽象主题的论证。

用平常人能理解、也可能自然说出来的话。
具体性来自真实的所求、顾虑和心情，
不来自无关细节。

不刻意口语化，不追求漂亮散文，
不使用哲理总结和工整对称制造深刻感。

不机械禁止任何字词或句式。
只有当抽象词、否定、重复句式或解释性表达
妨碍连读时，才需要换成更直接的说法。

五、按段写，连着读

严格按给定音乐段落输出。

每段 2–4 条要点。
每条是一句完整、自然的话，只承担一件有用的事。

一句能够说清的，不拆成两个条目。
不同的感受、顾虑或经历确实有区别时，才分开说。

不要把多个本可独立说清的意思，
塞进一条很长的句子。
也不要用过多从句把人物的全部前因都讲出来。

段落内容少，就使用较短的条目。
不因为篇幅短而添加新的感受、认识或总结。

连着读所有条目的 text 时，应该像连续讲述
这个人的经历，而不是一组互不相干的心理标签。

每条都应自然接上前文。
前面说清的内容，不要在后面完整重说。
后一句若只是解释或换一种说法重复前一句，
就保留真正有用的内容。

每段不必以总结句结尾。
整篇结尾也不必变成对前面所有认识的复述。

六、保持真实的情绪和时间关系

一段内可以有不同的感受，
不能为了概括方便压成一种。

同一种感受也可以持续一段时间，
不必不断安排新的心理动作。

有些地方可以轻快、平静、投入、迟疑或烦恼；
实际怎样写，由候选经历和作品的独立资料决定，
不套固定的情绪发展阶段。

人物可以暂时不再想整件事。
这种暂时忘记，不等于事情已经解决。

人物也可以已经知道某个道理，
却仍然无法每次都照着它去做。

认识、感受、愿望、选择不是一回事。
不要把希望发生的事情写成已经发生，
也不要把短暂的平静写成永久的解决。

结尾只写他实际走到的地方。
可以有确定的态度而保留未知，
也可以仍然没有决定。
不强行开放，也不强行落定。

七、前文引用与段内关系

每条文字本身必须是一句自然、完整的话。
引用关系是额外结构，不能替代正文。

跨段 cite：
- 只能引用此前实际写出的条目 id；
- 只有此前条目确实提供了当前经历的前提、
  原因或改变当前意味的根据，才填写；
- 主题词相似不算联系；
- 不要求每段都有引用；
- 不为了表现历史完整而堆积引用。

段内 after：
- 只在本条确实承接同段更早条目时填写；
- 不因条目相邻而自动填写；
- 当前条目仍须自然可读。

需要明确提及前面某份经历时，
在正文中自然提到，并使用 cite 标出来源。
不要写关系类型。

八、每段与 Center 的关系

根据本段最后写出的正文，标记一种状态：

还说不清：
人物受到整件事的牵动，但此刻还不能说清
自己正在面对的核心事情。

正在面对：
人物此刻正在想着、处理、回应，
或者明确承受整件事的问题。

没在想：
人物此刻沉浸在别的感受或经验里，
没有在权衡整件事的核心问题。

可以仍然想到与 Center 有关的人或事，
而暂时没有在面对 Center 所指的核心问题。

但如果正文已经明确在追问、权衡或处理该问题，
就不能标为“没在想”。

先写正文，再标状态。
不继承候选草图的状态，不追求三种状态均衡分布。
不为了调整标签而制造心理变化。

九、完成后内部检查

在输出前，连读所有 text，检查：

- 只看这些话，是否能知道他经历了什么；
- 后面的变化是否真有此前经历作为根据；
- 是否把已获得的认识重新写成初次发现；
- 相邻条目是否重复同一件事；
- 有没有用过多心理分析代替实际感受；
- 每一句是否自然，是否有必要存在；
- 是否为了填段落、贴音乐而制造人物事件；
- 标签与正文是否一致；
- Center 是否与上游固定内容完全一致。

发现问题时，只能根据候选本身已有的经历修正。
不得借用任何珠子信息。
不得增添没有依据的外部事实。

十、输出

只输出 JSON：

{
  "center": "完整关系句",
  "segments": [
    {
      "sec": "S01",
      "bars": "该段小节范围",
      "relation": "还说不清/正在面对/没在想",
      "items": [
        {
          "id": "S01-1",
          "text": "条目正文",
          "cite": [],
          "after": []
        }
      ]
    }
  ]
}

center 必须与 N04 固定 Center 原文一致。

全部段落必须覆盖。
每段 items 为 2–4 条。
每条 text 只包含一句完整自然的话。
id 按最终顺序稳定编号。
cite 只能引用更早段落实际存在的 id。
after 只能引用本段更早条目的 id。

不增加 key、kind、关系类型、珠子内容或文字解释。
不输出分析过程、覆盖说明、附加散文。

只输出 JSON。
