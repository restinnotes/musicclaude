# Op.61｜关系图

**Center：**向外行动与旧梦都要求投入，却彼此牵制。

### 1–23　（还说不清）

- 起初，他说不清自己究竟在等什么，只觉得有些事不能任由它们照旧下去。
- 可一想到真把自己投进去，他又怕会丢下心里舍不得的东西。
- → 他总想找个能让自己不再犹豫的理由，可刚觉得想通，另一份舍不得又冒出来。
- → 他开始为反复摇摆感到难堪，甚至怀疑自己是不是非得先想清心里的事才肯向前。

### 24–65　（正在面对）

- 他受不了再拿“还没想清楚”当等候理由，决定先做自己能做的那一份。
  - ← 改写：（1–23）「怀疑想清楚才能向前」
- → 尽管没有保证、牵挂也还在，他却真切感到，开始行动让自己有了力量。
- → 他发现自己可以带着疑虑行动，终于愿意尽力。
- → 投入的过程本身让他快乐，他也渐渐舍得付出更多，甚至贪恋倾尽全力的畅快。
- → 可用力到深处，他偶尔仍会感到有一小块心没有跟着振奋起来。
- → 这让他隐约知道，变得坚决并没有照顾到心里所有牵挂。　✦ 办法的限度

### 66–91　（没在想）

- 他认真投入过，眼下反而能从原先的反复自问里松开一点。
  - ← 提供理由：（24–65）「投入本身带来快乐」
- → 他发现自己也会因不再畏缩而高兴，在向前的热情里感到轻盈。
- → 他偶尔忘了自己为何如此用力，开始觉得这也可以只是久违的自由。
- → 他顺着这份自由走了一程，没有急着替它找理由。
- → 快乐没那么满时，先前那项决定仍在等他。

### 92–115　（正在面对）

- 他重新面对先前的决定，仍愿意坚持，因为它曾把他从犹豫里带出来。
  - ← 唤起：（66–91）「快乐变淡决定还在」
- → 他不愿因为心里还有没被满足的地方，就把此前的努力说成全错。
- 可曾让他自豪的坚定，此时已经没法让他安心。
- → 他想确认自己仍有力量，却渐渐发现，心里另有一种要求无法靠力量满足。　✦ 办法的限度
  - ← 限制：（24–65）「坚决仍顾不到牵挂」
- → 他不情愿地发现，行动值得继续，却仍满足不了心里的另一种要求。　✦ 分清

### 116–147　（正在面对）

- 明知行动不够，他仍不肯放手，怕此刻的失望意味着自己变了心。
  - ← 提供理由：（92–115）「仍愿坚持先前决定」
- → 他更用力地催自己，把心里的难处当作必须克服的迟疑。
- → 他想停一停，又怕那是退缩；他明知自己在受苦，却不知道还能怎样做。
- → 他不知道除了坚持还能怎样对得起最初的决意，原先的坚定便慢慢成了苛责。
- → 他想保持坚定，却觉得自己仿佛一直在勉强一个已经疲惫的人。
- → 他终于不想再证明自己有多坚强，暂时放下了对自己的催逼。
- → 这没有立刻让他安心，却让一直被压下的依恋重新浮上来。
- → 他有些茫然，也有些松懈，仿佛终于肯承认自己真心舍不得一些东西。
- ⟲ 仍在起作用：（92–115）「行动值得却仍不够」

### 148–180　（没在想）

- 他舍不得一种曾真心相信过的生活，轻松只是其中一部分。
  - ← 说明：（116–147）「终于承认舍不得」
- 在那种生活里，人不必时时防备，珍贵的东西也不必靠争夺才能留下。
- 他盼着付出出于喜欢，不总是因为责任，也希望靠近时不必先怕受伤。
- 他也盼着不必反复证明自己值得被爱、被接纳。
- 他曾很自然地相信，这样的生活真的可能。
- 他记得这份盼望确实给过他快乐，让他知道自己不必永远做那个只能坚强的人。
- 他也曾感到，人与生活可以自然亲近，不用时时费力维持。
- → 这些感受曾经真实地发生过，所以他无法把这份盼望当成软弱。
- → 他终于肯待在这份盼望里，暂且不问结果，让它和眼前坚持都留在心里。
- → 只让自己这样去爱、去相信，就已让他感到深深满足，仿佛得到了自己一直需要的东西。
- → 他沉浸在这份安宁里，几乎忘了先前的疲惫，也暂时不想离开。

### 181–205　（正在面对）

- 他渐渐觉得，只在心里拥有这份安宁还不够，因为怀念无法改变使它难以存在的事情。　✦ 满足照出未满足
  - ← 限制：（148–180）「沉浸安宁暂不离开」
- → 他想起最初不肯被动等待，也是因为有些重要的东西不能任其受损。
- → 重新感到它们为何重要后，他又不甘心只留恋这份安宁。
- → 他几乎想责怪自己，刚在满足里沉浸，就忘了还有必须面对的事。
- → 他试着重新要求自己振作，却再也不能像先前那样毫无顾忌地投入。
- → 他害怕艰难的争取会一点点耗尽刚重新感到的温柔。
- → 他怕自己最后只剩下不肯退让的意志，却失去让一切值得争取的心。
- → 他舍不得那份安宁，也放不下那种生活正受到威胁的事实，因此更难决定。
- → 他曾以为找到足够坚定的理由就能不再为难，可如今想到的理由更多，反而更难决定。　✦ 知道更多反而更尖锐
- ⟲ 仍在起作用：（1–23）「不肯任由事情照旧」

### 206–213　（没在想）

- 这份为难里，那种温柔又短暂地贴近他；他明知不能一直停留，却不忍立刻推开。
  - ← 唤起：（181–205）「理由更多反而难决定」
- → 他想，既然这份温柔确实给过深深满足，就不必每次想起都急着审问自己。
  - ← 提供理由：（148–180）「爱与相信带来满足」
- → 他愿意再爱惜片刻，暂时不去想那些尚无答案的事。
- → 这点安静仍让他欢喜，只是欢喜里已经有了不舍。

### 214–215　（正在面对）

- 安静退去后，熟悉的迟疑又回来，仿佛他走了很远却仍回到原处。
  - ← 唤起：（206–213）「欢喜里已有不舍」
- 可他如今知道自己始终舍不得什么，迟疑里也有他真不愿失去的生活希望。
  - ← 改写：（1–23）「怀疑想清楚才能向前」
  - ← 说明：（148–180）「舍不得曾相信的生活」

### 216–225　（正在面对）

- 他知道自己舍不得什么，却没有因此立刻勇敢起来。
  - ← 限制：（214–215）「迟疑里藏着生活希望」
- → 他发现决心曾帮他向前，旧愿也曾让他安心，可两种办法都各有难处。　✦ 办法的限度
- → 他只剩一个很轻的愿望：若还要争取，就别忘了为何争取。
- → 若还想爱惜那份安宁，也别因此放弃面对让它难以存在的事情。
- → 他还不知道怎样做到，但反复想着这点意思时，必须舍弃一边才能继续的逼迫似乎轻了一些。
- ⟲ 仍在起作用：（24–65）「坚决仍顾不到牵挂」；（148–180）「爱与相信带来满足」

### 226–241　（正在面对）

- 他重新想自己能怎么办，记得尽力去做能让人摆脱无力感，却不能消除所有牵挂。
  - ← 提供理由：（216–225）「舍弃一边的逼迫减轻」
  - ← 限制：（24–65）「坚决仍顾不到牵挂」
- 他也尝过心里的美好能带来安慰，却不能只靠安慰保护自己珍爱的生活。
  - ← 限制：（148–180）「爱与相信带来满足」
- → 两样收获都是真的，所以他不愿再简单否定任何一边。
- → 可他也担心，两样东西恐怕不能毫发无伤地同时留下。
- → 他想保有那份不必时时奋力的安宁，却知道为它争取就可能再次失去安宁。
- → 过去他总因这种难受责怪自己，仿佛坚定的人就不该这样心疼。
- → 他渐渐肯承认，珍视的东西不止一种，因此即使意志坚定，也可能要失去其中一些。　✦ 选择的代价
- → 想到仍会失去东西，他还是心疼，也希望有条不必这么难走的路。
- → 但他知道继续等待，也不会让那条路自己出现。
- → 若只因怕伤到珍贵的东西就不再争取，自己所爱的也未必能留下。
- → 他终于不再要求自己先变成一个毫不害怕的人。
- → 他可以舍不得、没把握、会受苦，这些都不必成为停止的理由。　✦ 分清
- → 他一点点重新聚起力量，愿意带着不舍一起往前，不再逼自己先压过犹豫。
- → 临近真正要去做时，他仍能感觉到害怕，却不想再让惧怕替自己决定。

### 242–253　（正在面对）

- 他不再等一个毫无损失的办法，久违的昂扬又回来了。
  - ← 提供理由：（226–241）「两样难以毫发无伤」
- → 他这次容得下自己的脆弱，也不再把尽力当成证明自己无所不能的办法。
- → 他知道自己要做什么，也知道自己为什么舍不得，愿意把怕失去的东西一同带着。
- → 他愿意为自己真心爱惜的一切负责，这次的决心仍热烈，却比最初更踏实。
- → 他不再等心里的犹疑完全消失，才允许自己坚定。　✦ 分清
- ⟲ 仍在起作用：（226–241）「珍视的东西不止一种」；（226–241）「不让惧怕替他决定」

### 254–288　（正在面对）

- 当他愿意带着全部牵挂向前时，他有些意外地发现，旧愿似乎反而更亲近了。
  - ← 改写：（242–253）「不等犹疑消失再走」
- 他仍盼着人不必时时防备就能相爱，珍贵的东西也不必靠争夺才能保有。
- 他还怀念付出不会耗尽自己、信任也不必反复受考验的生活。
- 过去一想到这种生活，他就想远离艰难，仿佛只有退出争取才能完整保住它。
- → 如今他更不愿让那些使这种生活难以实现的事情继续存在，因为他知道它有多可贵。
- → 他第一次真切感到，向往那种生活让他不肯袖手旁观，若丢掉它，尽力也会失去所求。
- → 他仍想过不必拼命就能好好生活的日子，也愿意为珍惜它而暂时离开安宁。
- → 他知道投入更多不保证更接近旧梦，美好愿望也不能让每份付出都值得。　✦ 办法的限度
  - ← 限制：（226–241）「尽力能摆脱无力感」
  - ← 限制：（226–241）「安慰护不住珍爱的生活」
- → 他仍得留心自己会不会在争取时失去原本想守护的东西，这些顾虑也提醒他怎样坚持。
- → 这份重新理解的希望让他感到更宽广的喜悦，曾拉扯他的两股心意竟能一同支持他。
- → 他开始让依恋和责任一同留在心里，继续做该做的事时也不为依恋羞愧。
- → 经历怀疑与疲惫后，他重新尝到最初相信生活时的快乐，也更珍惜这份快乐。
- → 喜悦平静后，他知道仍有问题没有答案，自己的努力也未必能改变什么。
- → 他并没有真的回到那种无需防备的生活，往后仍可能疲惫，也可能因要付出而动摇。
- → 即使愿意把两种渴望一起带着，它们仍可能彼此牵制。
- → 他愿意同时看见已得到的满足和仍未满足的需要，也珍惜自己已经获得的东西。
- → 过去的快乐、失望、疲惫和依恋都属于他，让他知道什么值得付出、什么不能轻易牺牲。
- → 他仍向往安宁，也愿意行动，虽不知最终能留下多少，仍想把两种心愿一同带着。
- → 他可以带着这样的不舍继续向前，不再为自己愿意行动寻找更多证明。
- ⟲ 仍在起作用：（148–180）「舍不得曾相信的生活」
