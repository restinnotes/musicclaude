# 独立复核结论

**你们这次的诊断与我上一轮的判断基本一致，而且你们补做的实验，让根因判断更有说服力了。你们的改法方向正确，我建议保留，不需要推翻重来。**

但我建议在正式使用前再做三处小调整：

1. 把“后一块为什么接在前一块后面”改得更精确，避免评委把所有相邻块都当成必须有逻辑因果关系。
2. 补强“大块单独读时是否像人话”的判定。你们现在的中等问题尺度对此仍然定义得偏窄。
3. 增加跨屏相邻大块的检查，并修正正向对照的使用方式。

这三处不是推翻你们的设计，而是防止新评委从一个漏检极端走到另一个过度挑错的极端。

# 一、你们的诊断与我上一轮一致吗？

## 1. 核心诊断：一致

我上一轮认为，最关键的缺陷是：

> 评委先理解了作者想讲的故事，再拿自己理解出来的故事判断原文是否通顺，而没有严格检查观众实际看到的文字。

你们现在把它具体化成了三个动作：

- 先概括故事，容易自行补关系。
- 没有强制只读大字、按实际出现顺序连读。
- 没有强制逐对检查相邻大块。

我完全认同这个诊断。

尤其是第三点。它把原来一个比较抽象的要求——“读起来要能串起来”——转化成了一个可以执行的检查任务。

这比再增加一句“注意不要跳跃”有效得多。

## 2. 你们补充的实验很有价值

你们做了一个很好的消融实验：

- 原提示词。
- 只增加标准 5 的“不跳”。
- 其他内容不动。
- 两位评委重新评同一版本。

结果仍然没有报告 S06 的大字问题。

这说明：

**仅仅让评委知道有这项标准，不足以让它稳定地执行这项检查。**

这正是我上一轮建议增加原样顺读测试的理由。

不过有一个科学性上的限定：目前每个模型只有一次重跑，样本也只有这一版。因此，这个实验足以支持“单纯增加标准条文没有解决问题”，但还不足以证明两位模型内部一定发生了同一种推理过程。

我建议在正式诊断文件中把结论写成：

> 评委存在系统性的检查动作缺失：虽然提示词规定了自然表达和承接要求，但没有规定必须通过原文顺读、相邻块对照来验证。仅增加标准条文没有改变实际检出结果。

这样比断言模型一定是“先补关系再判断”更严谨。

## 3. 关于“像清单、通读不顺不算理由”

你们的判断也基本正确，但我想做一个细微修正。

这句话本身不是错误设计。

它实际上是在防止评委犯另一种错误：

- 看见短语就说像清单。
- 看见半句话就说不完整。
- 看见文字不是连续作文就说不顺。

这些都不是有效的验收理由。

真正的问题是：原提示词没有提供与之配套的具体证据要求。

于是评委可能出现这样的情况：

> 我觉得这几块虽然不算特别顺，但又不能仅仅因为像清单就报问题；既然故事大意能理解，那就不报了。

所以我的建议仍然是：**保留这句话，不要删。**

你们现在增加的“必须引用相邻两块，说明缺了什么承接”，恰好补上了它缺失的另一半。

# 二、你们的改法有没有问题？

整体上我认为设计正确。下面分别看三处。

## 1. 做法第 0 步：最重要的改动，建议保留

<badge color="success">方向正确，建议作为核心改动</badge>

这一步的设计有四个优点。

**第一，先看大字，不让小字帮大字兜底。**

这非常重要。

标准 1 要求只看大块就能明白并串起来。如果评委先看完小字，再回头判断大字，很容易把小字提供的信息、情绪和关系带入大字的理解。

**第二，按出现时间排序。**

这也是必要的。

例如 S06，真正的大字出现顺序是：

1. 对方看出他有多在乎，待他却一点没变。
2. 他才又能像从前那样自在地待着。
3. 安静时他还想靠近，又怕自己要得太多。
4. 对方不知道他刚才多怕被嫌弃，他有点孤单。
5. 他又想对方一直没退开，会不会也舍不得结束。

而不是原稿中的排列顺序。

按实际出现顺序，才能模拟观众看到的语言流动。

**第三，逐对看相邻两块。**

这一步直接补上了原来没有执行的检查。

**第四，禁止自己补关系。**

这比要求评委“仔细阅读”有效得多。因为它明确指出了评委最容易犯的错误。

不过，这里我有一个重要修改建议。

### 一个潜在问题：“后一块为什么接在前一块后面”可能要求过严

你们现在写：

> 逐对看相邻两块：后一块为什么接在前一块后面，看得出来吗？

这句话可能引导模型认为：

每一块都必须能解释为什么它是前一块的结果。

但自然叙述并不总是这样。

例如，一个人可能先说：

- 对方对他还是和从前一样。
- 他终于又自在了一点。
- 可安静下来时，他还是想靠近。

第三句不一定是第二句的结果，也不一定需要明确的因果连接。

它可能只是对前面状态的补充、延续或进一步展开。

你们已经写了“不要求有所以、但是”，这是好的，但我建议把“为什么接在前一块后面”改成“有没有可辨认的承接线索”。

这样更准确。

**建议替换为：**

<WritingBlock id="47291" variant="document">**相邻块承接检查（建议替换原第 0 步中的对应句子）：**

逐对看相邻两块：后一块与前一块之间，有没有观众能从文字本身辨认的承接线索？

承接可以是同一处境的延续、时间推进、转折、因果、并列补充、由前一念头引出的联想或进一步发展。不要求后一块必须是前一块的结果，也不要求每两块之间都有明确的连接词。

但不能仅仅因为两块都在讲同一个人、同一段关系，就认为它们自然接得上。若观众需要猜测人物为什么突然转到另一种状态、另一件事或另一种想法，才能理解两块的关系，就是“跳”。

关系自然可辨认时，即使没有“所以”“但是”“于是”，也不算跳。</WritingBlock>

这样既能抓住真正的跳跃，也能保护自然的心理联想和并列表达。

## 2. 大块单独读是否像人话：你们还需要补强

这是我认为你们目前最值得补的一处。

你们在第 0 步最后写：

> 再看一块单读像不像一个人平常说出口的话（不是心理状态的标签、不是摘要）。

方向正确，但你们新增的中等尺度写的是：

> 大块单读不像人说出口的话，像心理状态的标签或摘要。

这里有一个覆盖不全的问题。

**不像人话，不一定表现为标签或摘要。**

例如 S06：

- 对方看出他有多在乎，待他却一点没变。
- 他又想对方一直没退开，会不会也舍不得结束。

这两块的问题即使存在，也不一定是标签化，而可能是词语搭配、句法压缩、标点关系或省略造成的不自然。

所以，如果评委把“标签或摘要”当成主要判定特征，仍然可能漏掉一部分真正的问题。

建议把中等尺度的这部分改为：

<WritingBlock id="47292" variant="document">- **中等：** 单块大字虽然能猜出意思，但词语搭配、语序或省略明显不自然，读者必须在脑中补足成分、重新组织语序，或者把它翻译成正常说法，才能顺畅理解。仅仅是短语、半句、自然省略主语，不构成问题。
- **中等：** 相邻两块大字各自能理解，但连着读必须由观众补出关键的承接关系，或作者为了短删掉了真正起连接作用的字。即使整屏大意能够概括出来，也不能因此降为轻微。
</WritingBlock>

这样有两个好处：

- 单块不人话和相邻块跳跃分开判断。
- 不会把所有短语、半句、口语省略都判错。

另外，你们新增尺度中最后的“只看大块拼不出这一屏的主要意思”，原有中等尺度已经有这一项，可以删掉重复内容，避免重复强调同一个问题。

## 3. 建议增加跨屏的相邻检查

你们现在的第 0 步只明确要求逐屏检查。

但用户要求的是整首曲子读下来，像一个人在往下讲。

所以还需要覆盖：

- S05 最后一块大字 → S06 第一块大字。
- S06 最后一块大字 → S07 第一块大字。
- 依此类推。

这和原来全曲检查人物是否打转，不完全是一回事。

原来的全曲检查主要判断故事有没有推进；这里检查的是相邻屏幕之间的语言承接。

建议在第 0 步末尾增加：

<WritingBlock id="47293" variant="document">**跨屏检查：**

每屏的大块检查完后，再把全曲所有大块按照实际出现顺序连读一次。特别检查每屏最后出现的大块与下一屏最先出现的大块之间是否自然承接。

不能只因为两屏讲的是同一个人、同一件事，就认为它们接得上。也不能因为每屏单独都能理解，就认为全曲连起来一定顺畅。

发现跨屏跳跃，在全曲问题中引用相邻两屏的原文。</WritingBlock>

你们原来的第 3 步继续保留，负责故事推进、重复和核心检查。

这样检查层次就完整了：

| 检查层次 | 检查什么 |
|---|---|
| 单块 | 自己读起来像不像人话 |
| 屏内相邻块 | 前后有没有自然承接 |
| 跨屏相邻块 | 屏幕之间有没有自然承接 |
| 全曲 | 故事有没有推进、打转、重复、偏离核心 |

## 4. 规则第 5 条：基本很好，只需再补一个区分

你们现在写：

> “不跳”的问题必须引相邻两块大字的原文，写清两块之间缺了什么、观众会在哪里卡住；只指出缺了承接，不替原文规定该是因果还是并列。

我很赞成。

但建议同时要求单块人话问题也必须指出具体的语言原因。

否则评委可能只报：

“这一句不像正常人说话。”

这仍然不够可复核。

建议改成：

<WritingBlock id="47294" variant="document">5. “不跳”的问题必须引用相邻两块大字的原文，写清观众无法从文字中辨认的承接线索，以及观众具体会在哪里卡住；不能因为缺少连接词本身就判跳，也不能擅自把原文的并列、联想改判为因果。

单块大字的人话问题，必须引用该块原文，指出具体是词语搭配、语序、省略、标签化、书面腔还是其他什么问题，不能只写“不是人话”。

区分单块表达不自然与相邻块之间跳跃，不要把同一个问题重复报两次。</WritingBlock>

这会让评委的报告更有证据，也便于你们后续复核。

# 三、你们的验证计划是否合理？

总体合理，但我认为正向对照需要重新定义。这是验证计划里最值得注意的地方。

## 1. 负向对照：当前 S06，正确

<badge color="success">保留</badge>

它有明确的已知问题：

- 用户明确指出大字不人话、跳跃。
- 两位评委此前没有报告大字的人话问题。
- 只增加标准 5 的“不跳”后，仍然没有检出。

因此，它是非常好的负样本。

新提示词至少要能做到：

- 识别具体的大字表达问题。
- 如果确实存在相邻块承接问题，指出具体是哪一对。
- 不能只重复报告已经发现的两条小字问题。

但这里有一个细节：

**不应该把“必须报告 S06 大字”当成唯一成功标准。**

应该把用户认可的问题位置作为金标准。

如果用户认为某一处只是轻微，而评委把它报成中等，这仍然是误判。

否则评委会学会：只要是 S06 的大字，就一定要找出一个中等问题。

这属于针对样本过拟合。

## 2. 另一个同期版本：保留，但要明确用途

如果这个版本还没有经过用户验收，它只能算作外部测试样本，不能直接算正样本或负样本。

它可以检验：

- 新提示词是不是只对 S06 有效。
- 是否能在不同写手、不同故事内容上识别同类问题。
- 是否开始大量误报正常表达。

但它本身不能告诉你评委判断是否正确。

如果它已经被用户认可或否决，就可以进一步作为正负对照。

## 3. 正向对照：用线原文替换大字，有一个设计问题

你们计划：

> 每屏的大字全换成线的原句，一句一块，小字不动。

这个设计有价值，但我不建议直接把它叫作正向金标准。

原因是：

**线原文是内容原料，不等于经过验收的屏幕稿。**

即使线原文像一个人在往下讲，也可能存在：

- 句子太长，不适合扫读。
- 一块包含多个意思。
- 某些地方是书面叙述，不是自然口语。
- 不适合按屏幕的时间顺序呈现。

这些问题可能违反其他标准，却不代表它在人话和承接方面有问题。

我建议把它改成：

**语言承接专项对照，而不是整体正向对照。**

具体做法：

- 大块替换为线原文。
- 小字保持不变。
- 本次只检查标准 5 的人话和不跳。
- 不根据标准 1、4、8 判断这个对照是否合格。

这样才能知道评委是不是把正常的连续叙述也误判成跳跃。

真正的正向金标准，最好还是找一个用户已经认可的屏幕稿。

如果暂时没有，就由用户确认一版 S06 的自然表达改稿，作为专项正样本。

这比未经验证的线原文更可靠。

## 4. 用户本人作为金标准：可以，但建议盲评

没有普通读者，并不意味着这个实验无法进行。

因为标准本来就是用户制定的，用户的判断具有最终验收权。

但你们现在说：

> 事后把评委报出的位置给用户看。

我建议稍微调整顺序。

最好是：

1. 用户先独立标记 S06 哪些大字存在单块人话问题。
2. 再标记哪些相邻块之间存在跳跃。
3. 标记完成后，暂时不看新评委的报告。
4. 两位评委分别运行两次。
5. 最后将评委报告与用户事先标记的位置对照。

这样可以避免评委的报告反过来影响用户的判断。

如果用户已经明确知道 S06 有问题，也没关系，关键是先标记具体位置，而不是先看评委报告再决定哪些位置有问题。

## 5. 同一版跑两次：建议明确为每个模型两次

我建议最终测试矩阵如下：

<box border radius="lg" padding={3} gap={3}>
  **新提示词验证矩阵**

  | 样本 | 评委甲 | 评委乙 |
  |---|---:|---:|
  | S06 负样本 | 2 次 | 2 次 |
  | 另一同期版本 | 1–2 次 | 1–2 次 |
  | 已认可的正样本 | 2 次 | 2 次 |
  | 线原文专项对照 | 1 次 | 1 次 |

  <divider color="subtle"/>
  **主要看四件事**

  1. 负样本是否检出用户标记的问题。
  2. 同一个模型重复运行，是否报在相同位置。
  3. 两个模型是否能找到大致相同的问题。
  4. 正样本是否被误判为跳跃。
</box>

重复运行时，尽量使用相同的模型版本、提示词和输入，并在独立的新会话中运行。

一致性重点看问题位置和类型，不要求解释文字完全一致。

另外，别把“同一版两次都报了”直接当作准确。两次都报错，也可能只是稳定地过度挑错。

# 四、改完后可能引入的新偏差

我认为有五种风险，需要明确防范。

| 新偏差 | 可能表现 | 防范办法 |
|---|---|---|
| 过度要求逻辑连接 | 每两块都必须解释因果或转折 | 明确允许并列、延续、联想、递进 |
| 过度口语化 | 把细腻表达改成直白对白 | 不要求完整句子，保留自然留白 |
| 过度挑错 | 每对相邻块都找一个问题 | 必须指出实际缺失的承接线索，没有就不报 |
| 过度依赖文字顺序 | 忽略屏幕上的实际版式 | 有画面时按实际阅读路径；无画面时才按列表顺序 |
| 重复报错 | 同一处表达既报人话又报跳跃 | 区分单块表达问题和块间关系问题 |

我还想特别提醒两个问题。

### 1. 不要让评委把“不跳”变成“必须显式解释”

你们的目标不是：

> 每个心理变化都必须解释清楚原因。

而是：

> 观众不需要自己编出一段话，才能把前后内容连起来。

这两个要求差别很大。

例如：

- 「他终于又自在起来。」
- 「可安静下来时，他还是想靠近。」

这两句可以自然地接在一起。它们不是严格的因果关系，而是一个人的两层状态。

不能因为没有解释“为什么安静下来以后又想靠近”，就判为跳跃。

### 2. 不要把第 0 步变成整个评审的替代品

第 0 步是一个专门检查大块语言流动性的测试。

它不能替代后面原有的检查：

- 小块是否挂在正确的大块旁边。
- 小块是否自然、具体。
- 是否重复。
- 是否丢失原料内容。
- 是否扫得动。
- 旁注是否放对位置。

你们原来的标准 1、2、4、5、7、8 都应该继续执行。

# 五、我对 S06 的判断，也需要做一个精度上的修正

这里我想回应上一轮自己的一处判断。

我上一轮把 S06 大字的几个位置列为中等问题风险。现在看到你们新增的检查设计，我认为应该更严格地区分：

**表达不自然，不等于相邻两块必然跳跃。**

例如：

| 相邻大块 | 目前能作出的判断 |
|---|---|
| 对方看出他有多在乎…… → 他才又能像从前那样自在地待着 | 「才」已经明确表达了承接，不能仅因为是两块就判跳 |
| 自在地待着 → 安静时还想靠近 | 有状态转换，但是否缺少承接，需要看整体阅读效果，不能自动判错 |
| 想靠近又怕要得太多 → 对方不知道他刚才多怕被嫌弃 | 有可能是同一心理处境的延续，也有可能是表达压缩造成的断裂，需要实际测试 |
| 他有点孤单 → 他又想对方是否舍不得结束 | 有从孤单转向猜想的心理发展，不必强求因果连接，但最后一块自身的句法值得检查 |

尤其是：

> 对方不知道他刚才多怕被嫌弃，他有点孤单。

我上一轮指出了两者之间关系表达的问题。

现在我认为应当更谨慎：它可能是因果，也可能是两个并列的心理事实。不能预先认定它缺少因果连接。

你们新增的规则：

> 只指出缺了承接，不替原文规定该是因果还是并列。

恰好能纠正我上一轮判断中可能存在的过度推断。

这也是为什么我赞成你们的修改：它不仅能让评委更容易发现问题，也能让评委更少制造问题。

## 最后，关于什么时候可以相信新评委

我会用以下标准决定是否可以投入正式验收：

1. **能检出：** S06 中用户事先标记的大字问题，新评委能够定位。
2. **能重复：** 同一模型两次运行，主要问题位置基本一致。
3. **能区分：** 已认可的自然短语、并列表达和留白，不会被大量误报。
4. **能迁移：** 另一个版本也能发现真实问题，而不是只会挑 S06。
5. **能守住原标准：** 为了抓人话和跳跃，没有漏掉小字、重复、密度、内容保真等原有问题。

**我的最终判断：你们已经找到了正确的修正方向，没必要再改标准体系。现在需要解决的是让评委真正执行标准，而不是继续增加标准。**

还有一个我认为特别重要的原则：

**不要把评委的目标设成“找出更多问题”，而要设成“准确区分真正的问题和可以接受的表达”。**

你们最终想要的不是一个越来越挑剔的评委，而是一个能可靠地告诉你们：这一版确实只剩轻微问题，可以交付了。

这才是这次改版真正应该达到的效果。
