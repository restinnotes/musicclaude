# 一、研究背景

我们正在研究一个潜在的消费者购物产品：

当美国消费者准备在 Amazon、Google Shopping、Temu、AliExpress 或其他美国渠道购买商品时，系统同时搜索：

- Taobao
- Tmall
- JD
- 必要时 1688

然后通过：

- Superbuy
- Sugargoo
- BuckyDrop
- 其他 buying agent / forwarding infrastructure

计算这个商品真实运到美国的 landed cost。

最终展示类似：

Amazon: $39.99 — tomorrow  
AliExpress: $27.40 — 8 days  
Temu: $25.20 — 4 days  
China domestic + forwarding: $16.80 all-in — 9–13 days

核心产品不一定自己进口、自己仓储，也不一定是 AI agent。

可能是：

- browser extension
- shopping search engine
- marketplace
- AI shopping agent
- API
- price-comparison/routing layer

核心 thesis 是：

> 中国国内商品市场可能存在一个很大的、没有被国际电商完全套利掉的价格与 selection advantage。一个消费者入口如果把中国国内 catalog 自动加入美国消费者的 comparison set，可能创造大量 consumer surplus。

我们不是要求“中国永远最便宜”。

系统可以推荐：

- Amazon
- Temu
- AliExpress
- Taobao/Superbuy
- 美国本地 reseller

中的任何一个。

真正研究的是：

> 是否存在一个数量和 GMV 都足够大的 SKU 集合，使 China-direct route 持续具有明显价格优势？

# 二、重要的已有 provisional finding

- FiiO
- Moondrop

- VXE
- ORICO

结果显示：

> 对已经高度国际化的 branded exact SKU，AliExpress 往往已经把中国国内外价差压得很小。

但是上一轮存在严重潜在 selection bias：

> 越容易通过国际网页搜索确认 exact SKU  
> → 越可能本来就是已经高度国际化的 SKU  
> → 越容易在 AliExpress/海外专业零售商找到有效价格。

因此这一轮严禁：

> 先从 Amazon / AliExpress / Google 容易找到的 SKU 出发，再去中国找价格。

必须反过来：

> **China domestic market first → freeze sample → only then inspect overseas channels.**

之前研究的结果只能作为 hypothesis，不允许作为 ground truth。

# 十、非常重要：研究真正的“China-head / US-middle-tail gap”

我们怀疑最大机会可能不是：

> 中国 long tail → 美国 long tail

而是：

> **中国国内 head SKU → 美国 middle/tail SKU**

例如某国产品牌产品：

在中国：
- 大销量
- 数万评价
- 多家店竞争
- 官方店
- 已经经过消费者筛选

但在美国：
- 没有主流 distribution
- Temu 没 exact SKU
- AliExpress international seller 很少
- Amazon 只有 reseller
- markup 很高

这类必须专门识别。
