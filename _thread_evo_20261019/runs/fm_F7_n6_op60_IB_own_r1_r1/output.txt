**1–3**

**我想靠近一个人、想得到回应，又怕亲近之后连自己都弄丢；连自己要什么也没弄清。音乐先替我托住这份说不清的渴望。**

**4–16**

**我开始相信，两个人可以亲近，也能各自做自己，只是还怕这份好维持不了多久。**
← 因为我既想得到回应，又怕失去自己，才开始分辨自己需要怎样的亲密。
→ 于是我愿意相信这段关系，音乐用两条贴近的下行旋律写出刚尝到幸福时的忐忑。

**17–23**

**我开始担心，我们是真的懂彼此，还是只在某个时刻刚好合得来。**
← 因为我刚尝到亲近与自由能同时存在的幸福，却还不敢相信它能持续。
→ 于是我开始检验这份信任，又舍不得抹掉过去的快乐；音乐暂时离开原来的歌唱。

**24–34**

**想过怀疑之后，我还是承认那份亲近是真的，只是不再指望它替我解决所有问题。**
← 因为反复审视关系没有抹掉我经历过的快乐，也让我看清它有做不到的事。
→ 于是我开始珍惜这份感情，也追问自己还想要什么；原来的主题再次出现，旋律更饱满。

**35–39**

**我发现自己还想成长、看看别的可能，也怕守着安稳会漏掉这些愿望。**
← 因为我一直确认这段关系够不够好，没太留意自己还有哪些需要。
→ 于是我开始走出熟悉的地方，音乐也慢慢换了颜色。

**40–50**

**我想主动去做喜欢的事，让自己更有力量，可我怕一改变，关系也跟着变。**
← 因为我发现自己除了被在乎，也需要成长和新的生活经验。
→ 于是我对未来兴奋，也怕现在的安稳会变；旋律转为上行，调性在A大调与升F小调间游移。

**51–61**

**我确认自己真想成长，可也怕停下来会委屈，顾着自己又会辜负这段关系。**
← 因为改变可能动摇眼前的安稳，我才反复确认这份愿望是不是认真想过后仍舍不得放弃的。
→ 于是我不再逼自己选一边，开始找两种需要都能留下的办法；上行旋律再次出现。

**62–71**

**我开始问自己，能不能先享受已经得到的东西，不急着追下一个目标。**
← 因为一直忙着想怎么兼顾亲密和成长，我可能忘了享受已经拥有的满足。
→ 于是我试着分清自己还有什么重要需要，还是不习惯承认已有幸福的价值；琶音变得舒展，却仍没完全放开。

**72–77**

**亲密、成长和安静享受当下都让我开心，可我还不知道怎样让它们同时留在生活里。**
← 因为我开始认真享受已有的东西，才发现这些满足各有分量。
→ 于是我暂时停下来，不再催自己马上回答；音乐也放松了原来的节奏。

**78–83**

**我知道自己卡在几种需要之间，却还没找到让它们共存的办法。**
← 因为想让这些需要共存，我发现否定任何一种只能暂时轻松，反复分析又会拖住生活。
→ 于是我接受自己暂时做不到两全，不随便挑个答案安抚自己；音乐让几股力量短促流动，却还没找到位置。

**84–92**

**我重新审视这段感情，想知道它能不能容得下正在改变的我。**
← 因为我接受暂时没有两全的答案后，仍放不下亲密能不能容纳改变这个问题。
→ 于是我不再躲开这个问题；熟悉旋律带着紧张重现，最后停住，像我还没等到答案。

**93–102**

**我开始相信，成长也许能给这段关系添些内容，我不必为了被接纳把自己缩小。**
← 因为我发现自己没法轻易放弃成长，也仍然很珍惜这段亲密，才愿意重新想象两者能否并存。
→ 于是我试着让成长和亲密一起进入日常；主题回到主调，听起来更热烈有力。

**103–110**

**我知道不安还会回来，也不想再靠一阵强烈的幸福证明自己选对了。**
← 因为眼前的满足无法预先排除冲突，也替不了我判断哪些愿望依然重要。
→ 于是我重新看清哪些需要已得到回应、哪些仍不能放弃；上行主题缩短，留着一点小调的阴影。

**111–116**

**我终于看清每种满足给了我什么，也承认它都有做不到的事。**
← 因为我经历过亲密、成长和享受当下的满足，才逐渐看清每一种能给我什么、又做不到什么。
→ 于是我不再因它有限就否定它，也不急着因为还有缺憾就追求更多。

**烦恼还在，可我不再被它推着反复追逐、确认，也能容下几种愿望。**
← 因为我接受这些需要都重要，却没法由一个答案全部解决。
→ 于是我能珍惜已有的、继续追求没实现的，也允许自己暂时停下；音乐收拢旧主题，安静落回升F大调。
