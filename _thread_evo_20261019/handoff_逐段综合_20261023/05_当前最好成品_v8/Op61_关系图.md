# Op.61｜关系图（v8）

**Center：**无名缺憾与对珍惜之物的牵念始终交织，并与日常生活的投入相连。

### 1–23　（还说不清）

- 某种说不清的缺憾浮上心头，他知道自己被触动，却不知难受从何而来。

### 24–65　（还说不清）

- 那股缺憾里浮出几分熟悉的亲近，仿佛离珍惜之物近了些，心底随之泛起怅惘。
  - ← 改写：（1–23）「无名缺憾」

### 66–91　（没在想）

- 熟悉的失落一靠近，他就急着从牵念中抽身。
  - ← 提供理由：（24–65）「似曾相识的怅惘」
- → 转而感到轻松，他确实松快了一阵，暂时顾不上缺憾。

### 92–115　（正在面对）

- 熟悉的柔意让他觉得，心里所念的珍爱之物又近了。
  - ← 唤起：（24–65）「似曾相识的怅惘」
- → 暖意映出缺憾仍在，短暂的幸福也因此夹着刺痛。
  - ← 限制：（66–91）「片刻松脱」

### 116–147　（正在面对）

- 暖意曾让短暂幸福夹着刺痛；此刻牵念再压来，他又急又吃力。
  - ← 提供理由：（92–115）「暖意照出缺憾」
- → 急迫渐渐磨成疲惫，抵抗的力气一时耗尽，心里才松动片刻。

### 148–180　（正在面对）

- 他静静看着那份珍爱，心里的失落转成温柔而具体的酸楚。
  - ← 唤起：（92–115）「暖意照出缺憾」
  - ← 提供理由：（116–147）「抵抗耗尽」

### 181–205　（正在面对）

- 熟悉的日常忽然贴近，原本柔和的失落也更真切。
  - ← 唤起：（148–180）「温柔地看着失落」
- → 那份亲近感一再浮起，心底的怅惘也随之加深。

### 206–213　（正在面对）

- 怅惘渐歇后，他又能温柔地看着那份真切的失落。
- → 缓和转瞬即逝，余波仍牵动着他，心里静不下来。
  - ← 限制：（181–205）「余波难平」

### 214–215　（正在面对）

- 他才刚能柔和地面对失落，旧日难受又冒出来，他也觉得这般面对难以持续。
  - ← 限制：（206–213）「余波未平」

### 216–225　（正在面对）

- 那股难受重又袭来，他又被拉回怎样与失落相处的疑问。
  - ← 动摇：（214–215）「温柔难以维持」

### 226–241　（正在面对）

- 总被与失落相处的难题缠住，他急着摆脱停滞。
  - ← 提供理由：（216–225）「相处之问」
- → 他开始愿意带着迟疑继续过日子，心里仍怕，却慢慢有了往前走的劲头。

### 242–253　（正在面对）

- 他愿重新把力气花在日常生活上，失落仍与这份用心相伴。
  - ← 改写：（226–241）「带着迟疑继续」

### 254–288　（正在面对）

- 他投入眼前生活时，连温柔牵念也化成充沛的劲头。
  - ← 改写：（242–253）「投入生活」
- → 这股劲让他一时不再摇摆，继续生活的意愿也格外坚定。
  - ← 改写：（226–241）「带着迟疑继续」
