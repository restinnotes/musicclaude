# A 路线第 2 步：纯线稿（不组装、不含珠子）

这些都是 DAG 第 2 步“线”的产物。写的时候**完全没给珠子**，也没给从珠子提炼的 Center。文件名里的分数来自 v5 评审（10 分制，三位评委盲评合并）。

## v5 评审改了什么（按你 10-21 的意见）

- 最重要的一条变成“线自己推动自己”：在心里删掉所有写音乐的句子，剩下的文字必须仍是一条有先后、有因果、一步推一步的过程。
- 评委逐段标注这一段的转折靠什么推动：“内”= 前文的经历或认识，“乐”= 此刻的音乐事件，“无”= 没交代理由。
- 由音乐事件推动转折的、各段像离散卡片的，都要明显扣分。
- 乐谱写得多精确，和“鲜活”无关。
- 校准结果：v5 仍能复现你之前对 A–F 的排序。

## 几种写法（都不看珠子）

| 标记 | 做法 |
|---|---|
| N4 | P0 + “先写一条连续的线，再落到段落；每段体验只写一两句” |
| N5 | 先联网查曲子背景和常见解读，写成连续的线，再落到段落（旧写法，仍允许用音乐开头） |
| N6 | 先写一条**完全不提音乐**的线，每次变化必须由前面发生的事推出；再落到段落，音乐每段最多一句，只能作为已说明来由的状态的“外形” |
| N7 | N6 + 明确禁止用新的外部事件、物件、对白推动变化（N6 有一篇编出了旧钥匙、同乡聚会、旧信） |
| 主线来源 | 自己想 / 先查资料 / A 路线比赛中模型自己提出的 Center |

## 机械旁证：以音乐开头的段落占比

| 稿 | 以音乐开头的段落 | 写音乐的句子 |
|---|---|---|

## 我自己读后的判断

- N6 / N7 的线确实是主干：每段都从上一段的结果写起（“正因为……所以此刻……”），没有“音乐忽然……于是他……”。
- **共同的弱点是抽象**：通篇是一个人在想、在辨认，缺少可感的处境，读起来偏议论。当下体验原本安排在第 4 步由珠子原句补上，所以这一点要等组装后才能看出是否成立。
- Op.61 的几篇比 Op.60 的更具体：先查资料的那几篇围绕“流亡者的尊严与归属”，主线落在了这首曲子上。Op.60 的主线更容易流于“亲密与自由”这类普适的话。
- 反例：`9_反例_音乐驱动` 两篇几乎每段都由音乐开头推动；`8_反例_编故事` 是那篇“旧钥匙”。
